R sin() 関数 - 三角関数の計算

R 言語の例

R は完全な三角関数のセットを提供します：sin()、cos()、tan() およびその逆関数。

これらの関数はデフォルトで弧度法（ラジアン）を使用し、科学計算や信号処理で頻繁に使用されます。

三角関数の構文形式は次の通りです：

sin(x)
cos(x)
tan(x)
asin(x)   # 反正弦
acos(x)   # 反余弦
atan(x)   # 反正切

パラメータの説明：

  • xラジアン値（radians）を入力します。

例

# よく使う角度の三角関数値
angle_deg <- c(0, 30, 45, 60, 90)

# 角度をラジアンに変換
angle_rad <- angle_deg * pi / 180

# サイン値を計算
print("sin 値:")
print(round(sin(angle_rad), 4))

# コサイン値を計算
print("cos 値:")
print(round(cos(angle_rad), 4))

# タンジェント値を計算
print("tan 値（90 度は無限大に注意）:")
print(round(tan(angle_rad), 4))

上記のコードを実行すると、出力結果は次の通りです：

[1] "sin 值:"
[1] 0.0000 0.5000 0.7071 0.8660 1.0000
[1] "cos 值:"
[1] 1.0000 0.8660 0.7071 0.5000 0.0000
[1] "tan 值（注意 90 度无穷大）:"
[1] 0.0000 0.5774 1.0000 1.7321      Inf

逆正接関数 atan2() を使用すると、平面上の点 (x, y) の極角を計算できます：

例

# 点(1,1) の極角を計算（45 度になるはず）
angle_rad <- atan2(1, 1)
angle_deg <- angle_rad * 180 / pi
print(paste("点(1,1)の角度:", angle_deg, "度"))

# 点(-1, 1) の極角を計算（135 度になるはず）
angle_rad <- atan2(1, -1)
angle_deg <- angle_rad * 180 / pi
print(paste("点(-1,1)の角度:", angle_deg, "度"))

上記のコードを実行すると、出力結果は次の通りです：

[1] "点(1,1)的角度: 45 度"
[1] "点(-1,1)的角度: 135 度"
