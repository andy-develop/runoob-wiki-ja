R aov() 関数 - 分散分析

R 言語の実例

R aov() 関数は分散分析（ANOVA）を実行し、3群以上のデータの平均値に有意差があるかどうかを比較するために使用されます。

2群以上のデータを比較する必要がある場合、ANOVAを使用する方が、複数回のt検定よりも適切です。

aov() 関数の構文形式は次のとおりです：

aov(formula, data)

パラメータの説明：

  • formula数式。形式は 応答変数 ~ グループ変数 です。

  • dataデータフレーム。数式内の変数を含みます。

実例

# 3種類の肥料が農作物の収量に与える影響
fertilizer <- factor(rep(c("A", "B", "C"), each = 5))
yield <- c(18, 20, 19, 22, 21,     # 肥料 A
           25, 27, 24, 26, 28,     # 肥料 B
           15, 17, 16, 14, 18)     # 肥料 C

# データフレームを作成
df <- data.frame(fertilizer, yield)
print("データのプレビュー:")
print(df)

# 分散分析を実行
result <- aov(yield ~ fertilizer, data = df)
print(summary(result))

上記のコードを実行すると、出力結果は次のとおりです：

p値は0.001よりはるかに小さく、3種類の肥料が収量に与える影響には極めて有意な差があることを示しています。
