R dnorm() pnorm() qnorm() 関数 - 正規分布関数群

R言語 実例

Rは正規分布に対して4つの中核関数を提供しています：dnorm() 密度関数、pnorm() 累積確率、qnorm() 分位数関数、rnorm() 乱数生成。

これらはそれぞれ異なる質問に答えます：ある値の確率密度はいくらか？累積確率はいくらか？ある確率に対応する分位数はいくらか？

各関数の構文形式は以下の通りです：

dnorm(x, mean = 0, sd = 1)   # 密度函数
pnorm(q, mean = 0, sd = 1)   # 累积分布函数 P(X <= q)
qnorm(p, mean = 0, sd = 1)   # 分位数函数

引数の説明：

  • x/q計算する値。

  • p確率値（0から1）。

  • mean平均値、デフォルトは0。

  • sd標準偏差、デフォルトは1。

実例

# 試験の成績が N(70, 10) に従うと仮定

# dnorm: スコア70での確率密度
print(paste("dnorm(70):", round(dnorm(70, mean = 70, sd = 10), 4)))

# pnorm: スコアが85未満の確率
print(paste("P(score <= 85):", round(pnorm(85, mean = 70, sd = 10), 4)))

# pnorm: スコアが85を超える確率
print(paste("P(score > 85):", round(1 - pnorm(85, mean = 70, sd = 10), 4)))

# qnorm: 上位10%の境界線
print(paste("上位10%のボーダーライン:", round(qnorm(0.9, mean = 70, sd = 10), 2)))

上記のコードを実行すると、出力結果は次のようになります：

[1] "dnorm(70): 0.0399"
[1] "P(score <= 85): 0.9332"
[1] "P(score > 85): 0.0668"
[1] "前 10% 分数线: 82.82"
