CSS outline-styleプロパティ


例

outlineのスタイルを設定：

p
{
outline-style:dotted;
}

試してみる »

このページの下部にさらに多くの例があります。

プロパティの定義と使用説明

outline（アウトライン）は、要素の周囲に描画される線で、ボーダー（枠線）の外側に位置します。

outline-styleプロパティはoutlineのスタイルを指定します。

デフォルト値： none
継承： no
バージョン： CSS2
JavaScript 構文： object.style.outlineStyle="dotted"

ブラウザサポート

表内の数字は、そのプロパティをサポートする最初のブラウザバージョンを示しています。

プロパティ
outline-style 1.0 8.0 1.5 1.2 7.0

ヒントと注釈

outlineは要素を囲みます。要素のマージンを囲みます。ただし、ボーダープロパティとは異なります。

outlineは要素のサイズの一部ではないため、要素のwidthプロパティとheightプロパティにはアウトラインの幅は含まれません。

プロパティ値

值 説明
none デフォルト。輪郭なしを定義します。
dotted 点線の輪郭を定義します。
dashed 破線の輪郭を定義します。
solid 実線の輪郭を定義します。
double 二重線の輪郭を定義します。二重線の幅はoutline-widthの値と同じです。
groove 3Dのグルーブ（溝）状の輪郭を定義します。この効果はoutline-colorの値によって異なります。
ridge 3Dのリッジ（隆線）状の輪郭を定義します。この効果はoutline-colorの値によって異なります。
inset 3Dのインセット（窪み）状の輪郭を定義します。この効果はoutline-colorの値によって異なります。
outset 3Dのアウトセット（出っ張り）状の輪郭を定義します。この効果はoutline-colorの値によって異なります。
inherit 親要素から輪郭スタイルの設定を継承することを指定します。
