CSS 有効な色の値

CSS の有効な色の値は、名前付き色、16進数、RGB、RGBA、HSL、HSLA、および色関数など、複数の方法で指定できます。

以下は、一般的な有効な色の値の形式です:

名前付き色:色名を直接使用します。例: red、blue、green など。

color: red;

16進数の色:使用#RRGGBB 或 #RGB形式の16進値。

color: #FF0000; /* 红色 */
color: #f00;    /* 简写形式，红色 */

RGB 色:使用rgb()関数で赤、緑、青の3色の値を指定します。各値は0〜255の範囲です。

color: rgb(255, 0, 0); /* 红色 */

RGBA 色:類似していますrgb()ただし、追加されたのはalphaアルファチャンネルで、透明度を指定するために使用されます。値の範囲は0(完全に透明)から1(完全に不透明)です。

color: rgba(255, 0, 0, 0.5); /* 半透明红色 */

HSL 色:使用hsl()関数で色相(0〜360°)、彩度(0%〜100%)、輝度(0%〜100%)を指定します。

color: hsl(0, 100%, 50%); /* 红色 */

HSLA 色:類似していますhsl()ただし、透明度を制御するためのアルファチャンネルが追加されています。

color: hsla(0, 100%, 50%, 0.5); /* 半透明红色 */

CSS色関数color()：色空間を使用して色を定義します。例: color(display-p3 1 0 0)。この方法により、より広い色空間を使用できます。

color: color(display-p3 1 0 0);

16進数の色

すべての主要ブラウザーが16進数の色の値をサポートしています。

16進数の色を指定する場合、その構成要素は ＃RRGGBB です。RR(赤)、GG(緑)、BB(青) です。すべての値は0からFFの間でなければなりません。

たとえば、＃0000FF は青色として表示されます。これは、青色の構成要素が最大値(FF)に設定され、他の要素が0に設定されているためです。

例

p {
    background-color:#ff0000;
}

RGB 色

RGB 色の値はすべての主要ブラウザーでサポートされています。

RGB 色の値は RGB(赤、緑、青) で指定します。各パラメータ(赤、緑、青)は色の明るさを定義し、0から255の間の整数、またはパーセント値(0%から100%)を使用できます。

たとえば、RGB(0,0,255) は青色として表示されます。これは、青のパラメータが最大値(255)に設定され、他が0に設定されているためです。

さらに、次の値は同じ色を定義します: RGB(0,0,255)、RGB(0%, 0%, 100%)。

例

p {
    background-color:rgb(255,0,0);
}

RGBA 色

RGBA 色の値は IE9、Firefox3+、Chrome、Safari、Opera10+ でサポートされています。

RGBA 色の値は、RGB 色の値にアルファチャンネルを拡張したもので、オブジェクトの透明度を指定します。

RGBA 色の値は RGBA(赤、緑、青、アルファ) で指定します。アルファパラメータは0.0(完全に透明)から1.0(完全に不透明)の間の値です。

例

p {
    background-color:rgba(255,0,0,0.5);
}

HSL 色

IE9、Firefox、Chrome、Safari、Opera 10+ は HSL 色の値をサポートしています。

HSL は色相、彩度、輝度を表し、色の円柱座標を使用して表現されます。

HSL 色の値は HSL(色相、彩度、明度) で指定します。

色相は色相環上の角度(0から360)です。0(または360)は赤、120は緑、240は青です。彩度はパーセント値で、0%はグレーを意味し、100%はフルカラーです。明度もパーセント値で、0%は黒、100%は白です。

例

p {
    background-color:hsl(120,65%,75%);
}

HSLA 色

HSLA 色の値は IE9、Firefox3+、Chrome、Safari、Opera10+ でサポートされています。

HSLA 色の値は、アルファチャンネルを持つ HSL 色の値を拡張したもので、オブジェクトの透明度を指定します。

HSLA 色の値は HSLA(色相、彩度、輝度、α) で指定します。αはアルファパラメータで定義される不透明度です。アルファパラメータは0.0(完全に透明)から1.0(完全に不透明)の間の値です。

例

p {
    background-color:hsla(120,65%,75%,0.3);
}
