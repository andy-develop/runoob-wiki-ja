CSS セレクター

CSS（カスケーディングスタイルシート）は、スタイルを適用する HTML 要素を選択するためのさまざまなセレクターを提供します。

CSS セレクターは、スタイルを適用したい要素を選択するためのパターンです。

下の表の「CSS」列は、CSS バージョンでの定義を示します。CSS1、CSS2 および CSS3 はカスケーディングスタイルシート（Cascading Style Sheets）の異なるバージョンであり、各バージョンはウェブページのスタイルの制御とデザインを改善するために新しい機能と特徴を導入しました。

一般的な CSS セレクター

以下は一般的な CSS セレクターです：

要素セレクター（Element Selector）：要素名によって HTML 要素を選択します。

次のコードのように、pセレクターはすべての<p>要素:

p {
  color: blue;
}

クラスセレクター（Class Selector）：クラス名によって特定のクラスを持つ HTML 要素を選択します。

クラスセレクターは.で始まり、その後ろにクラス名が続きます。

次のコードのように、.highlightセレクターは、クラスが"highlight"であるすべての要素を選択します。

.highlight {
  background-color: yellow;
}

ID セレクター（ID Selector）：要素の一意の識別子（ID）によって HTML 要素を選択します。

ID セレクターは#で始まり、その後ろに ID 名が続きます。

次のコードのように、#runoobセレクターは、ID が"runoob"である要素を選択します。

#runoob {
  width: 200px;
}

属性セレクター（Attribute Selector）：要素の属性を使用して HTML 要素を選択します。属性セレクターは、属性名と属性値に基づいて選択できます。

次のコードのように、input[type="text"]セレクターはすべてのtype属性が"text"の <input> 要素を選択します。

input[type="text"] {
  border: 1px solid gray;
}

子孫セレクター（Descendant Selector）：要素の子孫関係を指定して HTML 要素を選択します。

子孫セレクターはスペースを使用して要素名を区切ります。

次のコードのように、div p セレクターは <div> 要素内のすべての <p> 要素を選択します。

div p {
  font-weight: bold;
}

    CSS1、CSS2 と CSS3

    CSS1、CSS2 および CSS3 はカスケーディングスタイルシート（Cascading Style Sheets）の異なるバージョンであり、各バージョンはウェブページのスタイルの制御とデザインを改善するために新しい機能と特徴を導入しました。

    • CSS1（1996年登場）：CSS1 は CSS 仕様の最初のバージョンであり、基本的なスタイルプロパティとセレクターのセットを導入し、開発者がスタイルシートを使用して HTML ドキュメントにスタイルを適用できるようにしました。CSS1 はフォント、色、背景、ボーダーなどの基本的なスタイルの制御を提供します。ウェブページのレイアウトとスタイルにいくつかの基盤を提供しましたが、機能は比較的限られていました。

    • CSS2（1998年登場）：CSS2 は CSS の第2版仕様であり、より多くの機能とセレクターを導入し、スタイル制御の能力を強化しました。フロート、配置、カスケードなどの機能を導入し、開発者がウェブページの要素をより適切に制御およびレイアウトできるようにしました。CSS2 はまた、擬似クラスと擬似要素セレクターを導入し、開発者が要素の状態や位置に基づいてスタイルを適用できるようにしました。

    • CSS3（2001年開始、継続的に発展）：CSS3 は CSS の次世代仕様であり、一連のモジュールで構成され、各モジュールが新しい機能と特徴を導入しています。CSS3 は、より多くのセレクター、ボックスモデルプロパティ、色と背景のプロパティ、テキスト効果、トランジションとアニメーション効果、マルチカラムレイアウトなどを導入しました。また、メディアクエリ（Media Queries）を導入し、開発者がデバイスの属性と特性に応じて異なるスタイルを適用できるようにして、レスポンシブデザインを実現しました。CSS3 の発展は段階的であり、新しいモジュールと機能が継続的に追加され、標準化されています。

    注意すべき点は、CSS3 は完全な標準バージョンではなく、複数のモジュールを含む集合であるということです。各モジュールの発展とサポートレベルは異なる場合があります。ただし、通常 CSS3 で導入された新しい機能と特徴を総称して CSS3 と呼び、以前の CSS バージョンと区別しています。開発者は、対象ブラウザと要件に応じて CSS3 の機能を選択して使用し、機能検出とプレフィックスを使用してさまざまなブラウザでの互換性を確保できます。

    CSS は、スタイルを適用する HTML 要素を選択するためのさまざまなセレクターを提供します。

    以下は一般的な CSS セレクターです：

    • 要素セレクター（Element Selector）：要素名によって HTML 要素を選択します。例えば、pセレクターはすべての<p>要素。

    • 类选择器（Class Selector）：クラス名を使用して、特定のクラスを持つHTML要素を選択します。クラスセレクターは.で始まり、その後にクラス名が続きます。例えば、.highlightセレクターは、クラスが "highlight" のすべての要素を選択します。

    • IDセレクター（ID Selector）：要素の一意の識別子（ID）によってHTML要素を選択します。IDセレクターは#で始まり、その後にID名が続きます。例えば、#logoセレクターは、IDが "logo" の要素を選択します。

    • 属性セレクター（Attribute Selector）：要素の属性によってHTML要素を選択します。属性セレクターは、属性名と属性値に基づいて選択できます。例えば、input[type="text"]セレクターは、すべてのtype属性が "text" である<input>要素を選択します。

    • 子孫セレクター（Descendant Selector）：要素の子孫関係を指定してHTML要素を選択します。子孫セレクターは、スペースで要素名を区切ります。例えば、div pセレクターは、すべての<div>要素内の<p>要素を選択します。

    • 子要素セレクター（Child Selector）：要素の直接の子要素関係を指定してHTML要素を選択します。子要素セレクターは>記号で親要素と子要素を区切ります。例えば、ul > liセレクターは、すべての<ul>要素の直接の子要素の中の<li>要素を選択します。

    • 隣接兄弟セレクター（Adjacent Sibling Selector）：要素間の隣接兄弟関係を指定してHTML要素を選択します。隣接兄弟セレクターは+記号で隣接する2つの要素を区切ります。例えば、h2 + pセレクターは、<h2>要素のすぐ後にある<p>要素を選択します。

    • ユニバーサルセレクター（Universal Selector）：すべてのHTML要素を選択します。ユニバーサルセレクターは*記号を使用します。例えば、*セレクターは、ページ上のすべての要素を選択します。

    上記の一般的なセレクターに加えて、要素の特定の状態や位置を選択するための擬似クラスセレクター（Pseudo-Class Selector）と擬似要素セレクター（Pseudo-Element Selector）もあります。

    これはCSSセレクターのほんの一部の例です。CSSにはさらに多くのセレクターと組み合わせ方が用意されており、開発者はHTML要素をより正確に選択してスタイルを適用できます。開発者は必要に応じて適切なセレクターを選択し、目的のスタイル効果を実現できます。
