CSS border-right-colorプロパティ


例

右ボーダーの色を設定します：

p { border-style:solid; border-right-color:#ff0000 }

試してみる »

プロパティの定義と使用説明

border-right-color プロパティは、要素の右ボーダーの色を設定します。

注意border-color プロパティの前に、必ず border-style プロパティを宣言してください。要素は色を変更する前に、ボーダーを取得している必要があります。

デフォルト値: not specified
継承: no
バージョン: CSS1
JavaScript 構文: object object.style.borderRightColor="blue"

ブラウザサポート

表内の数字は、そのプロパティをサポートした最初のブラウザバージョン番号を示しています。

プロパティ
border-right 1.0 4.0 1.0 1.0 3.5

プロパティ値

值 説明
color_name 色名でボーダーの色を指定します（例：red）。
hex_number 16進数値でボーダーの色を指定します（例：#ff0000）。
rgb_number RGB コードでボーダーの色を指定します（例：rgb(255,0,0)）。
transparent デフォルト値です。ボーダーの色は透明です。
inherit 親要素からボーダーの色を継承することを指定します。
