Vue.js リアクティブインターフェース

Vue はデータに動的なリアクティブインターフェースを追加できます。

例えば、次のインスタンスでは、$watch プロパティを使用してデータの監視を実装します。$watch は正しいリアクティブを実現するために Vue インスタンスの外部に追加する必要があります。

インスタンスでは、ボタンをクリックするとカウンターが 1 増加します。setTimeout は 10 秒後にカウンターの値に 20 を加えるように設定されています。

インスタンス

<div id = "app"> <p style = "font-size:25px;">カウンター: {{ counter }}</p> <button @click = "counter++" style = "font-size:25px;">クリック</button> </div> <script type = "text/javascript">var vm = new Vue({ el: '#app', data: { counter: 1 } }); vm.$watch('counter', function(nval, oval) { alert('カウンター値の変化 :' + oval + ' から ' + nval + ' に変わりました!'); }); setTimeout( function(){ vm.counter += 20; },10000 );</script>

試してみる »

Vue は作成済みのインスタンスに新しいルートレベルのリアクティブプロパティを動的に追加することはできません。

Vue はオブジェクトのプロパティの追加や削除を検出できません。最善の方法は、インスタンスを初期化する前にルートレベルのリアクティブプロパティを宣言することです。空の値であっても構いません。

実行中にプロパティの追加や削除を行う必要がある場合は、グローバルな Vue、Vue.set、Vue.delete メソッドを使用できます。

Vue.set

Vue.set メソッドはオブジェクトのプロパティを設定するために使用され、Vue がプロパティの追加を検出できない制限を解決できます。構文は次のとおりです。

Vue.set( target, key, value )

パラメータの説明：

  • target: オブジェクトまたは配列を指定できます。
  • key : 文字列または数値を指定できます。
  • value: 任意の型を指定できます。

インスタンス

<div id = "app"> <p style = "font-size:25px;">カウンター: {{ products.id }}</p> <button @click = "products.id++" style = "font-size:25px;">クリック</button> </div> <script type = "text/javascript">var myproduct = {"id":1, name:"book", "price":"20.00"}; var vm = new Vue({ el: '#app', data: { products: myproduct } }); vm.products.qty = "1"; console.log(vm); vm.$watch('products.id', function(nval, oval) { alert('カウンター値の変化 :' + oval + ' から ' + nval + ' に変わりました!'); });</script>

試してみる »

上記のインスタンスでは、次のコードを使用して最初に変数 myproduct を作成しました。

var myproduct = {"id":1, name:"book", "price":"20.00"};

この変数は Vue インスタンスの data オブジェクトに代入されています。

var vm = new Vue({ el: '#app', data: { products: myproduct } });

myproduct オブジェクトに 1 つ以上のプロパティを追加したい場合は、Vue インスタンス作成後に次のコードを使用できます。

vm.products.qty = "1";

コンソール出力を確認してください：

上の図のように、製品に数量プロパティ qty が追加されましたが、get/set メソッドは id、name、price プロパティでのみ使用でき、qty プロパティでは使用できません。

Vue オブジェクトを追加してもリアクティブを実現できません。Vue は主に開始時にすべてのプロパティを作成します。この機能を実装したい場合は、Vue.set を使用して実現できます。

インスタンス

<div id = "app"> <p style = "font-size:25px;">カウンター: {{ products.id }}</p> <button @click = "products.id++" style = "font-size:25px;">クリック</button> </div> <script type = "text/javascript">var myproduct = {"id":1, name:"book", "price":"20.00"}; var vm = new Vue({ el: '#app', data: { products: myproduct } }); Vue.set(myproduct, 'qty', 1); console.log(vm); vm.$watch('products.id', function(nval, oval) { alert('カウンタ値の変化 :' + oval + ' から ' + nval + '!'); });</script>

試してみる »

コンソール出力の結果から、get/set メソッドが qty プロパティで使用できることがわかります。

Vue.delete

Vue.delete は動的に追加されたプロパティを削除するために使用します。構文は次のとおりです。

Vue.delete( target, key )

パラメータの説明：

  • target: オブジェクトまたは配列を指定できます。
  • key : 文字列または数値を指定できます。

インスタンス

<div id = "app"> <p style = "font-size:25px;">カウンター: {{ products.id }}</p> <button @click = "products.id++" style = "font-size:25px;">クリック</button> </div> <script type = "text/javascript">'カウンタ値の変化 :' + oval + ' から ' + nval + ' に変わりました!'</script>

試してみる »

上の図の出力結果から、price プロパティが削除され、id と name プロパティだけが残り、price プロパティの get/set メソッドも削除されたことがわかります。
