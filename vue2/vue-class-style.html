Vue.js スタイルバインディング

Vue.js class

class と style は HTML 要素の属性であり、要素のスタイルを設定するために使用されます。v-bind を使ってスタイル属性を設定できます。

Vue.js は v-bind が class と style を処理する際に、それを特別に拡張しています。式の結果の型は文字列以外にも、オブジェクトや配列にすることができます。

class 属性バインディング

v-bind:class にオブジェクトを設定することで、class を動的に切り替えることができます:

例 1

この例では isActive を true に設定すると緑色の div ブロックが表示され、false に設定すると表示されません:

<div v-bind:class="{ 'active': isActive }"></div>

試してみる »

上記の例の div class は次の通りです:

<div class="active"></div>

また、オブジェクトにさらに多くの属性を渡して、複数の class を動的に切り替えることもできます。

例 2

text-danger クラスの背景色が active クラスの背景色を上書きします:

<div class="static" v-bind:class="{ 'active' : isActive, 'text-danger' : hasError }"> </div>

試してみる »

上記の例の div class は次の通りです:

<div class="static active text-danger"></div>

データ内のオブジェクトを直接バインドすることもできます:

例 3

text-danger クラスの背景色が active クラスの背景色を上書きします:

<div id="app"> <div v-bind:class="classObject"></div> </div>

試してみる »

例 3 と例 2 のレンダリング結果は同じです。

さらに、ここではオブジェクトを返す算出プロパティをバインドすることもできます。これは一般的で強力なパターンです:

例 4

new Vue({ el: '#app', data: { isActive: true, error: { value: true, type: 'fatal' } }, computed: { classObject: function () { return { base: true, active: this.isActive && !this.error.value, 'text-danger': this.error.value && this.error.type === 'fatal', } } } })

試してみる »

配列構文

私たちは配列をv-bind:classに渡すことができます。例は次の通りです：

例 5

<div v-bind:class="[activeClass, errorClass]"></div>

試してみる »

上記の例の div class は次の通りです:

<div class="active text-danger"></div>

さらに、三項演算子を使用してリスト内の class を切り替えることもできます:

例 6

errorClass は常に存在し、isActive が true のときに activeClass クラスが追加されます:

<div v-bind:class="[errorClass ,isActive ? activeClass : '']"></div>

試してみる »

Vue.js style(インラインスタイル)

私たちはv-bind:styleで直接スタイルを設定できます：

例 7

<div id="app"> <div v-bind:style="{ color: activeColor, fontSize: fontSize + 'px' }">初心者チュートリアル</div> </div>

試してみる »

上記の例の div style は次の通りです:

<div style="color: green; font-size: 30px;">菜鸟教程</div>

スタイルオブジェクトに直接バインドして、テンプレートをより明確にすることもできます:

例 8

<div id="app"> <div v-bind:style="styleObject">初心者チュートリアル</div> </div>

試してみる »

v-bind:style は配列を使用して、複数のスタイルオブジェクトを1つの要素に適用できます:

例 9

<div id="app"> <div v-bind:style="[baseStyles, overridingStyles]">初心者チュートリアル</div> </div>

試してみる »

注意：v-bind:styleが接頭辞を必要とする CSS プロパティ（transform など）を使用する場合、Vue.js は自動的に検出して対応する接頭辞を追加します。

    Mustache（二重中括弧記法）は HTML 属性では使用できません。v-bind ディレクティブを使用してください：

    <div v-bind:id="dynamicId"></div>

    これはブール値の属性にも有効です —— 条件が false と評価された場合、その属性は削除されます：

    <button v-bind:disabled="someDynamicCondition">Button</button>
    • v-bind は動的バインドディレクティブです。デフォルトではタグに付属する属性の値は固定されています。これらの属性に動的に値を追加するには、v-bind:動的に変化させたい値="式" を使用できます。
    • 2: v-bind は属性とデータをバインドするために使用され、その省略形は「:」です。つまり v-bind:id === :id です。
    • 3: v-model はフォームコントロールで使用され、双方向データバインディングを実現します。そのため、フォームコントロール以外のタグで使用しても効果はありません。

    動的な調整では、data 内で data のデータを呼び出すと undefined になることに注意が必要です。正しい使用方法は computed を使うことです。（methods で返しても無効です。そのような設定はサポートされていない可能性があります）

    <div id="app">  
    <div v-bind:style="{color: 'red', fontSize: size + 'px'}">可以动态调节</div> 
    <div v-bind:style="computedStyle">可以动态调节</div>
    <div v-bind:style="objectStyle"> 不可以动态调节</div> 
    <div v-bind:style="methodStyle"> 可以动态调节</div> 
    
    {{size}}   
    <button @click="++size">+</button> 
    <button @click="--size">-</button>
</div>
<script>
var app = new Vue({
    el: '#app',
    data: {
        size: 20,
        objectStyle: {
            color: 'green',
            fontSize: this.size + 'px' //this.size为undefined
        }
    },
    methods:{
       methodStyle: function(){
           return {color: 'green', fontSize: this.size + 'px'} //失效,颜色也不会改变
       } 
    },
    computed: {
       computedStyle: function(){
       return {color: 'red' , fontSize: this.size + 'px'} 
       }
})
</script>

    <div id="app">

    <div v-bind:style="computedStyle">可以动态调节</div>
    <div v-bind:style="objectStyle"> 可以动态调节</div> 
    <div v-bind:style="methodStyle()"> 可以动态调节</div> 
    {{size}}   
    <button @click="++size">+</button> 
    <button @click="--size">-</button>
</div>

<script>
var app = new Vue({
    el: '#app',
    data: {
        size: 20,
        objectStyle: {
            color: 'green',
            fontSize: 20 + 'px' //this.size为undefined
        }
    },
    methods:{
       methodStyle: function(){
           return {color: 'green', fontSize: this.size + 'px'} //失效,颜色也不会改变
       } 
    },
    computed: {
       computedStyle: function(){
       return {color: 'red' , fontSize: this.size + 'px'} 
       }

      this.sizestyle.height = parseInt(this.sizestyle.height)+20+'px'
    }
  },
  computed:{
    judegeuse:function(){ // 判断是否使用某个/些类

        class1: false,
