条件分岐

v-if

条件分岐には v-if ディレクティブを使用します：

v-if ディレクティブ

要素と template で v-if ディレクティブを使用します：

<div id="app"> <p v-if="seen">これで私が見えました</p> <template v-if="ok"> <h1>菜鸟教程</h1> <p>学ぶのは技術だけではなく、夢でもあります！</p> <p>ははは、タイピングは大変だ！！！</p> </template> </div> <script> new Vue({ el: '#app', data: { seen: true, ok: true } }) </script>

試してみる »

ここでは、v-if ディレクティブは式 seen の値（true または false）に基づいて、p 要素を挿入するかどうかを決定します。

Handlebars などの文字列テンプレートでは、次のように条件ブロックを書く必要があります：

<!-- Handlebars 模板 -->
{{#if ok}}
  <h1>Yes</h1>
{{/if}}

v-else

v-else ディレクティブを使用すると、v-if に「else」ブロックを追加できます：

v-else ディレクティブ

ランダムに数値を生成し、0.5 より大きいかどうかを判定して、対応する情報を出力します：

<div id="app"> <div v-if="Math.random() > 0.5"> Sorry </div> <div v-else> Not sorry </div> </div> <script> new Vue({ el: '#app' }) </script>

v-else-if

v-else-if は 2.1.0 で追加されました。名前のとおり、v-if の else-if ブロックとして使用します。連鎖的に複数回使用できます：

v-else ディレクティブ

type 変数の値を判定します：

<div id="app"> <div v-if="type === 'A'"> A </div> <div v-else-if="type === 'B'"> B </div> <div v-else-if="type === 'C'"> C </div> <div v-else> Not A/B/C </div> </div> <script> new Vue({ el: '#app', data: { type: 'C' } }) </script>

v-else、v-else-if は v-if または v-else-if の後に続く必要があります。

v-show ディレクティブ

<h1 v-show="ok">Hello!</h1>

    v-if と v-show の違いは？

    切り替えの際、v-ifブロック時、Vue.js にはローカルなコンパイル/アンマウント処理があります。なぜならv-ifこの中のテンプレートには、データバインディングや子コンポーネントが含まれる場合もあります。v-if真の条件付きレンダリングです。条件ブロックの切り替え中に、条件ブロック内のイベントリスナーと子コンポーネントを適切に破棄し再構築することを保証するからです。

    v-ifまた、遅延的です。初期レンダリング時に条件が偽であれば何も行いません。条件が初めて真になったときにローカルなコンパイルを開始します（コンパイルはキャッシュされます）。

    これに対して、v-showはるかに単純です。要素は常にコンパイルされて保持され、単に CSS に基づいて切り替えられるだけです。

    一般的には、v-ifより高い切り替えコストがかかる一方、v-show より高い初期レンダリングコストがかかります。したがって、頻繁に切り替える必要がある場合はv-showの方が良いです。実行時に条件が変化する可能性が低い場合はv-ifの方が良いです。

    v-if と v-show の違い：

    v-ifは動的に追加され、値がfalseの場合、その要素を完全に削除します。つまりdomDOM ツリー内にその要素は存在しません。

    v-showは単に非表示/表示を切り替えるだけで、値がfalseの場合、その要素は依然としてdomDOM ツリー内に存在します。元のスタイルにdisplay: noneが設定されていると、正常に表示されない原因となります。

    について<template></template>コンテンツの可視性の問題：

    <template> 要素が vue でインスタンス化された後のコンポーネントに含まれている場合、ブラウザは正常にレンダリングします。v-if="false" を使用して非表示にできます。ブラウザは解析しないため、v-show は使用できません。

    <div id="app">
    <p v-if="seen">现在你看到我了</p>
    <template v-if="ok">
      <h1>菜鸟教程</h1>
      <p>学的不仅是技术，更是梦想！</p>
      <p>哈哈哈，打字辛苦啊！！！</p>
    </template>
</div>
    
<script>
new Vue({
  el: '#app',
  data: {
    seen: true,
    ok: false
  }
})
</script>

    vue でインスタンス化されていないコンポーネント内に <template> が存在する場合、正常に非表示にできます。本来display：none。
