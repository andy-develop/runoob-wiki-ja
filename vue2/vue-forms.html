Vue.js フォーム

この節では Vue.js フォームでの応用を紹介します。

v-model ディレクティブを使用して、フォームコントロール要素に双方向データバインディングを作成できます。

v-model はコントロールの種類に応じて自動的に正しい方法を選択して要素を更新します。

入力ボックス

このインスタンスでは、input と textarea 要素で v-model を使用して双方向データバインディングを実現しています：

<div id="app"> <p>input 要素：</p> <input v-model="message" placeholder="編集してください……"> <p>メッセージ: {{ message }}</p> <p>textarea 要素：</p> <p style="white-space: pre">{{ message2 }}</p> <textarea v-model="message2" placeholder="複数行テキスト入力……"></textarea> </div> <script>new Vue({ el: '#app', data: { message: 'Runoob', message2: '菜鸟教程\r\nhttp://www.runoob.com' } })</script>

修飾子

.lazy

デフォルトでは、v-model は input イベントで入力ボックスの値とデータを同期しますが、修飾子 lazy を追加することで、change イベントで同期するように変更できます：

<!-- 在 "change" 而不是 "input" 事件中更新 -->
<input v-model.lazy="msg" >

.number

ユーザーの入力値を自動的に Number 型に変換したい場合（元の値の変換結果が NaN の場合は元の値を返します）、修飾子 number を v-model に追加して入力値を処理できます：

<input v-model.number="age" type="number">

これは通常非常に便利です。なぜなら type="number" の場合、HTML で入力された値も常に文字列型で返されるからです。

.trim

ユーザーが入力した前後の空白を自動的に除去したい場合は、v-model に trim 修飾子を追加して入力をフィルタリングできます：

<input v-model.trim="msg">

    new Vue({
    el: '#app',
    data: {
        checked: false,
        checkedNames: [],
        checkedArr: ["Runoob", "Taobao", "Google"]
    },
    methods: {
        changeAllChecked: function() {
            if (this.checked) {
                this.checkedNames = this.checkedArr
            } else {
                this.checkedNames = []
            }
        }
    },
    watch: {
        "checkedNames": function() {
            if (this.checkedNames.length == this.checkedArr.length) {
                this.checked = true
            } else {
                this.checked = false
            }
        }
    }
})
