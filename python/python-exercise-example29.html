Python100例

問題：5桁以下の正の整数を1つ与えます。要件：一、それが何桁かを求める。二、各桁の数字を逆順に出力する。

プログラム分析：各桁の数字に分解することを学びます。

プログラムソースコード：

例(Python2.x)

#!/usr/bin/python # -*- coding: UTF-8 -*- x = int(raw_input("数値を入力してください:\n")) a = x / 10000 b = x % 10000 / 1000 c = x % 1000 / 100 d = x % 100 / 10 e = x % 10 if a != 0: print "5桁の数：",e,d,c,b,a elif b != 0: print "4桁の数：",e,d,c,b, elif c != 0: print "3桁の数：",e,d,c elif d != 0: print "2桁の数：",e,d else: print "1桁の数：",e

例(Python3.x)

#!/usr/bin/python x = int(input("数値を入力してください:\n")) a = x // 10000 b = x % 10000 // 1000 c = x % 1000 // 100 d = x % 100 // 10 e = x % 10 if a != 0: print ("5桁の数：",e,d,c,b,a) elif b != 0: print ("4桁の数：",e,d,c,b) elif c != 0: print ("3桁の数：",e,d,c) elif d != 0: print ("2桁の数：",e,d) else: print ("1桁の数：",e)

上記の例の出力結果は次のとおりです：

请输入一个数:
23459
5 位数： 9 5 4 3 2

请输入一个数:
3472
4 位数： 2 7 4 3
