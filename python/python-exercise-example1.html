問題：4つの数字：1、2、3、4があります。互いに異なり、数字の重複しない3桁の数はいくつ作れますか？それぞれ何ですか？

プログラム分析：百の位、十の位、一の位に入れられる数字はすべて1、2、3、4です。すべての順列を作成した後、条件を満たさない順列を取り除きます。

プログラムのソースコード：

実例

#!/usr/bin/python # -*- coding: UTF-8 -*- for i in range(1,5): for j in range(1,5): for k in range(1,5): if( i != k ) and (i != j) and (j != k): print (i,j,k)
