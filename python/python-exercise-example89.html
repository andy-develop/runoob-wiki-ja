問題：ある会社は公衆電話を使用してデータを伝送します。データは4桁の整数で、伝送過程で暗号化されます。暗号化ルールは以下の通りです。各桁の数字に5を加え、その和を10で割った余りでその数字を置き換え、その後、1桁目と4桁目を交換し、2桁目と3桁目を交換します。

プログラム分析：なし。

プログラムのソースコード：

例

#!/usr/bin/python # -*- coding: UTF-8 -*- from sys import stdout if __name__ == '__main__': a = int(raw_input('4つの数字を入力してください:\n')) aa = [] aa.append(a % 10) aa.append(a % 100 / 10) aa.append(a % 1000 / 100) aa.append(a / 1000) for i in range(4): aa[i] += 5 aa[i] %= 10 for i in range(2): aa[i],aa[3 - i] = aa[3 - i],aa[i] for i in range(3,-1,-1): stdout.write(str(aa[i]))

上記の例の出力結果は次のとおりです：

输入四个数字:
1234
9876

        j %= 10
        strn[i] = j
    for i in range(lens/2+1):
        strn[i],strn[lens-1-i] = strn[lens-1-i], strn[i]
    strdata = ''
    for i in range(lens):
        strdata += str(strn[i])
    return strdata

    

def decode(strm):

        j -= 5
        j %= 10
        strn[i] = str(j)
