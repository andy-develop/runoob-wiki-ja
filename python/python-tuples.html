Python タプル

Pythonのタプルはリストと似ていますが、タプルの要素は変更できない点が異なります。

タプルは丸括弧を使用し、リストは角括弧を使用します。

タプルの作成はとても簡単で、括弧の中に要素をカンマで区切って追加するだけです。

次の例の通りです：

例(Python 2.0+)

tup1 = ('physics', 'chemistry', 1997, 2000) tup2 = (1, 2, 3, 4, 5 ) tup3 = "a", "b", "c", "d"

空のタプルを作成

tup1 = ()

タプルに要素が1つだけ含まれる場合、要素の後にカンマを追加する必要があります

tup1 = (50,)

タプルは文字列と似ており、インデックスは0から始まり、スライスや結合などができます。

タプルへのアクセス

タプルはインデックスを使用してタプル内の値にアクセスできます。次の例の通りです:

例(Python 2.0+)

#!/usr/bin/python tup1 = ('physics', 'chemistry', 1997, 2000) tup2 = (1, 2, 3, 4, 5, 6, 7 ) print "tup1[0]: ", tup1[0] print "tup2[1:5]: ", tup2[1:5]

上記の例の出力結果：

tup1[0]:  physics
tup2[1:5]:  (2, 3, 4, 5)

タプルの変更

タプルの要素の値は変更できませんが、タプルを連結・結合することはできます。次の例の通りです:

例(Python 2.0+)

#!/usr/bin/python # -*- coding: UTF-8 -*- tup1 = (12, 34.56) tup2 = ('abc', 'xyz') # 以下のタプル要素の変更操作は不正です。 # tup1[0] = 100 # 新しいタプルを作成 tup3 = tup1 + tup2 print tup3

上記の例の出力結果：

(12, 34.56, 'abc', 'xyz')

タプルの削除

タプルの要素の値は削除できませんが、del文を使用してタプル全体を削除することはできます。次の例の通りです:

例(Python 2.0+)

#!/usr/bin/python tup = ('physics', 'chemistry', 1997, 2000) print tup del tup print "After deleting tup : " print tup

上記の例でタプルが削除された後、変数を出力すると例外情報が表示されます。出力は次の通りです：

('physics', 'chemistry', 1997, 2000)
After deleting tup :
Traceback (most recent call last):
  File "test.py", line 9, in <module>
    print tup
NameError: name 'tup' is not defined

タプル演算子

文字列と同様に、タプル間では + 記号と * 記号を使用して演算できます。つまり、タプルを結合および複製でき、演算後に新しいタプルが生成されます。

Python 式結果説明
len((1, 2, 3))3要素数の計算
(1, 2, 3) + (4, 5, 6)(1, 2, 3, 4, 5, 6)連結
('Hi!',) * 4('Hi!', 'Hi!', 'Hi!', 'Hi!')複製
3 in (1, 2, 3)True要素の存在確認
for x in (1, 2, 3): print x,1 2 3反復

タプルのインデックス、スライス

タプルもシーケンスであるため、タプル内の指定した位置の要素にアクセスしたり、インデックスの一部の要素をスライスしたりできます。次の通りです：

タプル：

L = ('spam', 'Spam', 'SPAM!')
Python 式結果説明
L[2]'SPAM!'3番目の要素を読み取る
L[-2]'Spam'逆方向に読み取り、最後から2番目の要素を読み取る
L[1:]('Spam', 'SPAM!')要素のスライス

閉じる区切り文字なし

括弧なしの任意のオブジェクトをカンマで区切ると、デフォルトでタプルになります。次の例の通りです：

例(Python 2.0+)

#!/usr/bin/python print 'abc', -4.24e93, 18+6.6j, 'xyz' x, y = 1, 2 print "Value of x , y : ", x,y

上記の例の実行結果：

abc -4.24e+93 (18+6.6j) xyz
Value of x , y : 1 2
