Python リスト(List)

シーケンスはPythonで最も基本的なデータ構造です。シーケンス内の各要素には数字（その位置、つまりインデックス）が割り当てられ、最初のインデックスは0、2番目のインデックスは1、以降同様です。

Pythonには6つの組み込みシーケンス型がありますが、最も一般的なのはリストとタプルです。

シーケンスで実行できる操作には、インデックス、スライス、加算、乗算、メンバー検査が含まれます。

さらに、Pythonにはシーケンスの長さを決定し、最大および最小の要素を決定するメソッドが組み込まれています。

リストは最もよく使われるPythonデータ型であり、角括弧内にカンマ区切りの値として表すことができます。

リストのデータ項目は同じ型である必要はありません。

リストを作成するには、カンマで区切った異なるデータ項目を角括弧で囲むだけです。次のようにします。

list1 = ['physics', 'chemistry', 1997, 2000] list2 = [1, 2, 3, 4, 5 ] list3 = ["a", "b", "c", "d"]

文字列のインデックスと同様に、リストのインデックスは0から始まります。リストはスライスや結合などを行うことができます。

リストの値にアクセスする

インデックス番号を使ってリストの値にアクセスできます。同様に角括弧を使ってスライスすることもできます。次のようになります。

例(Python 2.0+)

#!/usr/bin/python list1 = ['physics', 'chemistry', 1997, 2000] list2 = [1, 2, 3, 4, 5, 6, 7 ] print "list1[0]: ", list1[0] print "list2[1:5]: ", list2[1:5]

上記の例の出力結果：

list1[0]:  physics
list2[1:5]:  [2, 3, 4, 5]

リストの更新

リストのデータ項目を変更または更新できます。また、append()メソッドを使ってリスト項目を追加することもできます。次のようになります。

例(Python 2.0+)

#!/usr/bin/python # -*- coding: UTF-8 -*- list = [] ## 空リスト list.append('Google') ## append() を使用して要素を追加 list.append('Runoob') print list

注意：次の章でappend()メソッドの使い方について説明します。

上記の例の出力結果：

['Google', 'Runoob']

リストの要素を削除

del文を使ってリストの要素を削除できます。次の例のとおりです。

例(Python 2.0+)

#!/usr/bin/python list1 = ['physics', 'chemistry', 1997, 2000] print list1 del list1[2] print "After deleting value at index 2 : " print list1

上記の例の出力結果：

['physics', 'chemistry', 1997, 2000]
After deleting value at index 2 :
['physics', 'chemistry', 2000]

注意：次の章でremove()メソッドの使い方について説明します。

Pythonリストのスクリプト演算子

リストの + 演算子と * 演算子は文字列と似ています。+ はリストの結合に使用され、* はリストの繰り返しに使用されます。

次のように示します。

Python式結果説明
len([1, 2, 3])3長さ
[1, 2, 3] + [4, 5, 6][1, 2, 3, 4, 5, 6]結合
['Hi!'] * 4['Hi!', 'Hi!', 'Hi!', 'Hi!']繰り返し
3 in [1, 2, 3]True要素がリストに存在するかどうか
for x in [1, 2, 3]: print x,1 2 3反復

Pythonリストのスライス

Pythonのリストスライスの例は次のとおりです。

>>>L = ['Google', 'Runoob', 'Taobao'] >>> L[2] 'Taobao' >>> L[-2] 'Runoob' >>> L[1:] ['Runoob', 'Taobao'] >>>

説明：

Python式結果説明
L[2]'Taobao'リストの3番目の要素を読み取る
L[-2]'Runoob'リストの最後から2番目の要素を読み取る
L[1:]['Runoob', 'Taobao']2番目の要素からリストをスライスする

    リスト内a 与 a[:]異なる。

    私たちは関数を通じてid()確認できます：

    a = [1, 2, 3]
id(a)
id(a[:])

    得られる2つの値が異なることがわかります。

    または直接実行：

    a is a[:]

    戻り値は次のようになります。False。

    簡単に言うと、a[:]作成することですaのコピーであり、これによりコード内で...に対してa[:]操作を行っても、変更されることはありませんaの値です。一方、直接...に対してa操作を行うと、aの値はいくつかの操作の影響を受けます。たとえば、append()などです。

    Pythonリストのスライス応用

    # -*- coding: UTF-8 -*-

s = 'abcdefg'
# 返回从起始位置到索引位置 2 处的字符串切片
print(s[:3]) # 输出 'abc'

# 返回从第三个索引位置到结尾的字符串切片
print(s[3:]) # 输出 'defg'

print(s[::-1]) # 输出 'gfedcba'

# 输出从开始位置间隔一个字符组成的字符串
print(s[::2]) # 输出 'aceg'
print(range(10)[::2])  # 输出偶数：[0, 2, 4, 6, 8]

# 它们也可以相互结合使用。
# 从索引位置 6 到索引位置 2，逆向间隔一个字符
print(s[6:2:-2]) # 输出'ge'

    リスト内包表記 List Comprehensions

    式：[expression for iter_val in iterable if cond_expr]
    • [expression]：最後に実行される結果
    • [for iter_val in iterable]：これは多層ループにできます
    • [if cond_expr]：2つのforの間には条件文を置くことはできません。条件文は最後にのみ置けます。順序は不定ですが、デフォルトは左から右です。

    複数のforループの実行順序について説明します。

    左から右：

    >>> print[(x,y)for x in [1,2]for y in [3,4]]
[(1, 3), (1, 4), (2, 3), (2, 4)]
>>> print[(x,y)for x in [1,2]for y in [3,x]]
[(1, 3), (1, 1), (2, 3), (2, 2)]
>>>

    右から左：

    >>> print[(x,y)for x in [1,y]for y in [3,4]]
[(1, 3), (1, 4), (2, 3), (2, 4)]
>>>
