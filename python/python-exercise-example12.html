問題：101から200までの間に素数がいくつあるかを判定し、すべての素数を出力する。

プログラム分析：素数の判定方法：ある数を2からsqrt(その数)までの各数で割り、割り切れる場合は素数ではないことを示し、割り切れない場合は素数である。

プログラムのソースコード：

サンプル(Python 2.0+)

#!/usr/bin/python # -*- coding: UTF-8 -*- h = 0 leap = 1 from math import sqrt from sys import stdout for m in range(101,201): k = int(sqrt(m + 1)) for i in range(2,k + 1): if m % i == 0: leap = 0 break if leap == 1: print ('%-4d' % m) h += 1 if h % 10 == 0: print ('') leap = 1 print ('The total is %d' % h)

    素数の判定方法として、私は排除法を選びました。スライスで元のリストをコピーし、非素数を逐一排除すると、残りのリストの要素はすべて素数になります。

    #!/usr/bin/python
# -*- coding: UTF-8 -*-

import math
m=range(101,201)
p=m[:]
for i in range(101,201):
    for j in range(2,int(math.sqrt(i)+1)):
        if i % j == 0:
            p.remove(i)
            break
print(p)
print("101至200之间的素数一共有%d个"%len(p))

    Python3 テスト：

    y が 2 から y**0.5 の間の整数で割り切れるかどうかを確認し、割り切れる場合は break し、割り切れない場合はその数をリストに追加して break します。

    #!/usr/bin/python3


def prim(m, n):
    arr = []
    for x in range(m, n + 1):
        for y in range(2, int(x ** 0.5)):
            if (x / y) == int(x / y):
                break
            else:
                arr.append(x)
                break
    return arr

print(prim(101, 200))

    私は2つの方法を書きました。1つはイテレータです：

    #!/usr/bin/python
# -*- coding: UTF-8 -*-

def prime():
    n = 2
    while 1:
        for i in range(2, n+1):
            if n%i:
                continue
            else:
                if i==n :
                    yield n
                else:
                    break
        n+=1
L = []
for i in prime():
    if 101<=i<=200:
        L.append(i)
    if i>=200:
        break
print('一共有{}个素数，这些素数分别是：{}'.format(len(L),L))
