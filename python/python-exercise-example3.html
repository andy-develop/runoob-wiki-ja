問題：ある整数は、100を加えると完全平方数になり、さらに168を加えても完全平方数になります。この数はいくつでしょうか？

プログラム分析：

その数を x と仮定します。

1、すると：x + 100 = n2, x + 100 + 168 = m2

2、等式を計算：m2 - n2 = (m + n)(m - n) = 168

3、設定：m + n = i、m - n = j、i * j =168、i と j の少なくとも一方は偶数

4、得られる：m = (i + j) / 2、n = (i - j) / 2、i と j はどちらも偶数か、どちらも奇数かのいずれか。

5、3 と 4 から導くと、i と j はどちらも 2 以上の偶数であることがわかる。

6、i * j = 168、j>=2 なので、1 < i < 168 / 2 + 1。

7、次に i のすべての値をループして計算すればよい。

プログラムソースコード：

例(Python 3.0+)

# 求解関数を定義
def find_integer():
    for i in range(2, 85):  # i の範囲は 2 から 84
        if 168 % i == 0:  # i は 168 の約数
            j = 168 // i  # 対応する j を計算
            if i > j and (i + j) % 2 == 0 and (i - j) % 2 == 0:  # i と j が両方偶数または両方奇数であることを確認
                m = (i + j) // 2
                n = (i - j) // 2
                x = n * n - 100
                print(f"x: {x}, m: {m}, n: {n}")

# 求解関数を呼び出す
find_integer()

    m=n+k とします（m、n、k はすべて自然数としてよい）：m^2-n^2-168 に代入すると、k^2+2nk=168 が得られます。

    解くと n=84/k - k/2 が得られます；n、k はともに自然数なので、nk>=1、したがって 1<=k^2<168、よって 1<=k<=12 となります。

    みんな計算を通過しました。それから、私は以前の同級生の計算に基づいて、なんと答えを計算できてしまいました。はははは

    過程：

    上記の投稿を引用：

    その数を x とします：x + 100 = n^2、n^2 + 168 = m^2。

    m=n+k とします（m、n、k はすべて自然数としてよい）：m^2-n^2-168 に代入すると、k^2+2nk=168 が得られます。

    これに基づいて k(k+2n)=168 となります。k が奇数なら、k+2n も奇数となり、等式は成り立たないので、k は偶数です。

    すると等式を 4 で割ると、(k/2)(k/2+n) = 42 が得られます。t=k/2 とおきます（t>0）

    t(t+n)=42 なので、n=42/t - t となります。n が 0 より大きいので、t は 6 以下であり、42/t は整数なので、t の値は 1,2,3,6 となります。

    対応して x =1581,261,21,-99 が得られます。

    問題では x が整数であると述べていますが、n と m が必ずしも 0 より大きいとは述べていないため、ここでは n と m が 0 より小さい場合を考慮しています。

    x+100=n^2; x+100+168=m^2;（注意、m、n が必ずしも 0 より大きいとは要求されていません）

    m^2-n^2=168、すなわち (m+n)(m-n)=168 です；

    m+n=i、m-n=j とすると、m=(i+j)/2; n=(i-j)/2 となり、i*j=168 があります。m、n はともに整数で m!=n なので、j、i!=0 です。i*j は正の数なので、abs(i)>=1、abs(j)>=1 です。したがって、i と j の上限は 168 とできます。よって m と n の上限も 168 であり、下限は -168 とできます（注意、m、n の値の範囲は非常に大きく設定してもよく、結果には影響しません。なぜなら制約条件は自分で設定できるからです。ただし、設定する範囲は必ず実際の範囲より大きくする必要があります）

    Python3 でのテストコード：

    x=[]
for m in range(-168,169):
    for n in range(-168,169):
        if (m+n)*(m-n)==168:#m,n都是整数
            x.append(n**2-100)
x=set(x)#用集合的方法去掉重复值
x=list(x)#将集合类型改为列表类型
print('要求的值为：',x)
