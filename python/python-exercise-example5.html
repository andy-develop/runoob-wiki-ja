問題：3つの整数x,y,zを入力し、この3つの数を小さい順から大きい順に出力してください。

プログラム分析：最小の数をxに置く方法を考えます。まずxとyを比較し、x>yならばxとyの値を交換します。次にxとzを比較し、x>zならばxとzの値を交換します。これでxを最小にできます。

プログラムソースコード：

例(Python 2.0+)

#!/usr/bin/python # -*- coding: UTF-8 -*- l = [] for i in range(3): x = int(raw_input('integer:\n')) l.append(x) l.sort() print l

例(Python 3.0+)

#!/usr/bin/python3 l = [] for i in range(3): x = int(input('integer:\n')) l.append(x) l.sort() print (l)

上記の例の出力結果は次のとおりです：

integer:
8
integer:
5
integer:
6
[5, 6, 8]

    #!/usr/bin/env python3

# 利用冒泡排序方法
def Sort(list):
    n = len(list)
    for i in range(1, n):
        # 一次次的将最大的学出来
        for j in range(1, n - i + 1):
            if list[j - 1] > list[j]:
                list[j - 1], list[j] = list[j], list[j - 1]
            # 打印排序过程
            print(list)
    for i in range(0, n):
        print(list[i])

# 读入数据
def inputData():
    list_first = []
    while True:
        a = input("please input num:".strip())
        if len(a) == 0:
            return list_first
        else:

    リスト sort= を使用する。パラメータ reverse を受け付け、デフォルトはブール値 false で昇順にソートされ、true に設定すると降順にソートされる。

    #!/usr/bin/python
# -*- coding: UTF-8 -*-

x = int(input('x='))
y = int(input('y='))
z = int(input('z='))
num = [x, y, z]
num.sort()          # 对列表进行升序排序
print '这三个数由小到大的顺序为：',num
rnum = [x, y, z]                  # 对列表进行降序排序
rnum.sort(reverse=True)
print '这三个数由大到小的顺序为：',rnum

# -*- coding: UTF-8 -*-

#冒泡排序
a = [int(i) for i in raw_input("请输入：").split()]
m = len(a)
while m!=1:
    for i in range(m-1):
        if a[i]>a[i+1]:
            x = a[i]
            a[i] = a[i+1]
            a[i+1] = x
    m -= 1
print a
