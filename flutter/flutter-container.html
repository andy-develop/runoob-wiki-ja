Flutter Container と装飾

Container は Flutter で最もよく使われる汎用コンテナ Widget であり、サイズ、背景、枠線、シャドウなどを設定する機能を提供します。

Container 概要

Container は複合 Widget であり、内部に Padding、ColoredBox、SizedBox、DecoratedBox などの機能をカプセル化しています。

例：Container の基本的な使い方

// 最もシンプルな Container
Container(
  child: Text('Hello'),
)

// サイズ付きの Container
Container(
  width: 200,
  height: 100,
  child: Text('固定サイズ'),
)

// 色付きの Container
Container(
  width: 200,
  height: 100,
  color: Colors.blue,
  child: Text('青い背景', style: TextStyle(color: Colors.white)),
)

BoxDecoration - 装飾効果

BoxDecoration を使用すると、背景、枠線、シャドウ、角丸など、より豊富な装飾効果を追加できます。

背景色

例：背景色の設定

// 単色の背景
Container(
  decoration: BoxDecoration(
    color: Colors.blue,
  ),
  child: const Text('青い背景'),
)

// グラデーション背景を使用
Container(
  decoration: BoxDecoration(
    gradient: LinearGradient(
      colors: [Colors.blue, Colors.green],
      begin: Alignment.topLeft,
      end: Alignment.bottomRight,
    ),
  ),
  child: const Text('グラデーション背景'),
)

// 放射状グラデーション
Container(
  decoration: BoxDecoration(
    gradient: RadialGradient(
      colors: [Colors.yellow, Colors.orange],
    ),
  ),
  child: const Text('放射状グラデーション'),
)

枠線

例：枠線の設定

// シンプルな枠線
Container(
  decoration: BoxDecoration(
    border: Border.all(color: Colors.black, width: 2),
  ),
  child: const Text('黒い枠線'),
)

// 各辺で異なる枠線
Container(
  decoration: BoxDecoration(
    border: Border(
      top: BorderSide(color: Colors.red, width: 2),
      bottom: BorderSide(color: Colors.blue, width: 2),
      left: BorderSide(color: Colors.green, width: 2),
      right: BorderSide(color: Colors.orange, width: 2),
    ),
  ),
  child: const Text('各辺で異なる枠線'),
)

// 円形の枠線
Container(
  decoration: BoxDecoration(
    border: Border.all(color: Colors.purple, width: 3),
    borderRadius: BorderRadius.circular(10),
  ),
  padding: const EdgeInsets.all(16),
  child: const Text('角丸の枠線'),
)

角丸

例：角丸の設定

// 均一な角丸
Container(
  width: 100,
  height: 100,
  decoration: BoxDecoration(
    color: Colors.blue,
    borderRadius: BorderRadius.circular(20),  // 角丸半径 20
  ),
)

// 異なる角丸
Container(
  width: 100,
  height: 100,
  decoration: BoxDecoration(
    color: Colors.green,
    borderRadius: BorderRadius.only(
      topLeft: Radius.circular(20),
      topRight: Radius.circular(10),
      bottomLeft: Radius.circular(10),
      bottomRight: Radius.circular(20),
    ),
  ),
)

// 円形
Container(
  width: 100,
  height: 100,
  decoration: BoxDecoration(
    color: Colors.red,
    shape: BoxShape.circle,
  ),
)

シャドウ

例：シャドウの設定

// シンプルなシャドウ
Container(
  width: 100,
  height: 100,
  decoration: BoxDecoration(
    color: Colors.white,
    boxShadow: [
      BoxShadow(
        color: Colors.black.withOpacity(0.3),
        blurRadius: 10,  // ぼかし半径
        offset: Offset(5, 5),  // オフセット量
      ),
    ],
  ),
)

// 複数のシャドウ
Container(
  width: 100,
  height: 100,
  decoration: BoxDecoration(
    color: Colors.white,
    boxShadow: [
      BoxShadow(
        color: Colors.red.withOpacity(0.3),
        blurRadius: 5,
        offset: Offset(-3, -3),
      ),
      BoxShadow(
        color: Colors.blue.withOpacity(0.3),
        blurRadius: 5,
        offset: Offset(3, 3),
      ),
    ],
  ),
)

// カードシャドウ（elevation を使用）
Card(
  elevation: 8,
  child: Container(
    width: 100,
    height: 100,
    child: const Center(child: Text('カード')),
  ),
)

Clip - 切り抜き

Clip クラスを使用すると、子 Widget の表示領域を切り抜くことができます。

例：切り抜きの使い方

// 円形の切り抜き
ClipOval(
  child: Image.network(
    'https://example.com/avatar.jpg',
    width: 100,
    height: 100,
    fit: BoxFit.cover,
  ),
)

// 角丸矩形の切り抜き
ClipRRect(
  borderRadius: BorderRadius.circular(20),
  child: Image.network(
    'https://example.com/image.jpg',
    width: 200,
    height: 150,
    fit: BoxFit.cover,
  ),
)

// カスタムパスで切り抜き
ClipPath(
  clipper: TriangleClipper(),
  child: Image.network(
    'https://example.com/image.jpg',
    width: 200,
    height: 200,
  ),
)

総合サンプル

例：総合使用のサンプル

// グラデーション、角丸、シャドウ付きのカード
class MyCard extends StatelessWidget {
  final String title;
  final String description;
  final IconData icon;

  const MyCard({
    super.key,
    required this.title,
    required this.description,
    required this.icon,
  });

  @override
  Widget build(BuildContext context) {
    return Container(
      width: 280,
      padding: const EdgeInsets.all(20),
      decoration: BoxDecoration(
        // グラデーション背景
        gradient: LinearGradient(
          colors: [Colors.blue[400]!, Colors.blue[700]!],
          begin: Alignment.topLeft,
          end: Alignment.bottomRight,
        ),
        // 角丸
        borderRadius: BorderRadius.circular(16),
        // シャドウ
        boxShadow: [
          BoxShadow(
            color: Colors.blue.withOpacity(0.4),
            blurRadius: 12,
            offset: const Offset(0, 6),
          ),
        ],
      ),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        mainAxisSize: MainAxisSize.min,
        children: [
          // アイコン
          Container(
            padding: const EdgeInsets.all(12),
            decoration: BoxDecoration(
              color: Colors.white.withOpacity(0.2),
              borderRadius: BorderRadius.circular(12),
            ),
            child: Icon(icon, color: Colors.white, size: 32),
          ),
          const SizedBox(height: 16),
          // タイトル
          Text(
            title,
            style: const TextStyle(
              color: Colors.white,
              fontSize: 22,
              fontWeight: FontWeight.bold,
            ),
          ),
          const SizedBox(height: 8),
          // 説明
          Text(
            description,
            style: TextStyle(
              color: Colors.white.withOpacity(0.9),
              fontSize: 14,
            ),
          ),
        ],
      ),
    );
  }
}
