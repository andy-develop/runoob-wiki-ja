TypeScript インストール

この記事では TypeScript 環境のインストールについて説明します。

npm ツールを使用してインストールする必要があります。npm についてまだよく知らない場合は、次のページを参照してください。NPM の使用紹介。

NPM で TypeScript をインストール

ローカル環境に npm ツールがすでにインストールされている場合は、次のコマンドを使用してインストールできます。

中国国内のミラーを使用：

npm config set registry https://registry.npmmirror.com

typescript をインストール：

npm install -g typescript

インストールが完了したら、次のコマンドを使用できます。tscコマンドで TypeScript 関連のコードを実行します。以下はバージョン番号の確認です：

$ tsc -v
Version 3.2.2

次に、app.ts ファイルを新規作成します。コードは次のとおりです：

var message:string = "Hello World" console.log(message)

通常、私たちは次を使用します.tsTypeScript コードファイルの拡張子として。

次に、以下のコマンドを実行して TypeScript を JavaScript コードに変換します：

tsc app.ts

このとき、現在のディレクトリ（app.ts と同じディレクトリ）に app.js ファイルが生成されます。コードは次のとおりです：

var message = "Hello World"; console.log(message);

node コマンドを使用して app.js ファイルを実行します：

$ node app.js 
Hello World

この章では主に VS Code を紹介します。VS Code は、Mac OS X、Windows、Linux 上で動作する、最新の Web アプリケーションやクラウドアプリケーションの開発向けのクロスプラットフォームなソースコードエディターで、Microsoft 社によって開発されています。
