TypeScript イテレータとジェネレータ

イテレータとジェネレータは、JavaScript/TypeScript においてコレクションを扱う重要なパターンです。

それらはデータを走査する統一的な方法を提供し、大規模なデータストリームや無限シーケンスなどをより簡単に扱えるようにします。

SVG 図: イテレータとジェネレータ

なぜイテレータとジェネレータが必要か

コレクションデータを扱うとき、配列やオブジェクトなどのデータ構造を頻繁に走査する必要があります。

イテレータは統一されたカスタマイズ可能な走査インターフェースを提供し、あらゆるオブジェクトを走査可能にします。

ジェネレータはイテレータを作成する簡潔な方法であり、関数を使用して実行を一時停止・再開できるため、大規模なデータストリームや無限シーケンスの処理に最適です。

概念の説明：イテレータは、データを走査するための next() メソッドを提供するオブジェクトです。ジェネレータは、実行中に一時停止して値を返すことができる特別な関数です。

イテラブルプロトコル

Symbol.iterator メソッドを実装したオブジェクトは、for...of ループで走査できます。

例

// 配列はデフォルトで反復可能
var arr = [1, 2, 3];
for (var _i = 0, arr_1 = arr; _i < arr_1.length; _i++) {
    var item = arr_1[_i];
    console.log("配列要素: " + item);
}

// 文字列はデフォルトで反復可能
var str = "hello";
for (var _i = 0, str_1 = str; _i < str_1.length; _i++) {
    var char = str_1[_i];
    console.log("文字: " + char);
}

実行結果：

数组元素: 1
数组元素: 2
数组元素: 3
字符: h
字符: e
字符: l
字符: l
字符: o

説明：配列と文字列はどちらも Symbol.iterator メソッドを組み込みで実装しているため、for...of で直接走査できます。

カスタムイテラブルオブジェクト

通常のオブジェクトに Symbol.iterator インターフェースを実装させ、走査可能にします。

例

// カスタムイテラブルオブジェクトを作成：範囲
var range = {
    from: 1,
    to: 5,
    // Symbol.iterator メソッドを実装
    [Symbol.iterator]: function() {
        return {
            current: this.from,
            last: this.to,
            // next メソッドは反復結果を返す
            next: function() {
                if (this.current <= this.last) {
                    // 未完了の場合は現在の値を返してインクリメント
                    return { done: false, value: this.current++ };
                }
                // 完了
                return { done: true, value: undefined };
            }
        };
    }
};

// for...of で走査
for (var _i = 0, range_1 = range; _i < range_1.length; _i++) {
    var num = range_1[_i];
    console.log("範囲: " + num);
}

イテレータプロトコル：イテレータには next() メソッドが必要で、{ done: boolean, value: any } の形式のオブジェクトを返します。

ジェネレータ関数

function* 構文を使用してジェネレータを作成し、yield で実行を一時停止して値を返します。

例

// ジェネレータ関数：function* 構文を使用
function* numberGenerator() {
    yield 1;  // 一時停止して 1 を返す
    yield 2;  // 一時停止して 2 を返す
    yield 3;  // 一時停止して 3 を返す
}

// ジェネレータインスタンスを作成
var gen = numberGenerator();

// next() を呼ぶたびに次の yield まで実行される
console.log("最初: " + gen.next().value);
console.log("2番目: " + gen.next().value);
console.log("3番目: " + gen.next().value);
console.log("完了: " + gen.next().done);

実行結果：

第一个: 1
第二个: 2
第三个: 3
完成: true

ジェネレータ：ジェネレータ関数はイテレータを返し、next() を呼ぶたびに次の yield 文まで実行されます。

無限ジェネレータ

ジェネレータは無限シーケンスを生成できますが、遅延評価のため無限のメモリを消費しません。

例

// 無限数値ジェネレータ
// 呼び出しごとに1つの数値を生成し、一度にすべて生成することはない
function* infiniteNumbers() {
    var n = 1;
    while (true) {  // 無限ループ
        yield n++;   // 一時停止して現在の値を返し、その後インクリメント
    }
}

var gen = infiniteNumbers();
console.log("1番目: " + gen.next().value);
console.log("2番目: " + gen.next().value);
console.log("3番目: " + gen.next().value);

// 最初の5つの数値だけを取得
var nums = [];
var iter = infiniteNumbers();
for (var i = 0; i < 5; i++) {
    nums.push(iter.next().value);
}
console.log("最初の5つ: " + nums);

実行結果：

第1个: 1
第2个: 2
第3个: 3
前5个: 1,2,3,4,5

遅延評価：ジェネレータの最大の利点は遅延評価であり、next() を呼び出したときだけ次の値が計算されるため、無限シーケンスの処理に最適です。

委譲ジェネレータ

yield* を使用して、別のジェネレータやイテラブルオブジェクトに委譲します。

例

// 1つ目のジェネレータ
function* gen1() {
    yield 1;
    yield 2;
}

// 2つ目のジェネレータ
function* gen2() {
    yield 3;
    yield 4;
}

// 合成ジェネレータ：yield* を使用して委譲
function* combined() {
    yield* gen1();  // gen1 に委譲
    yield* gen2();  // gen2 に委譲
}

// 合成ジェネレータを走査
for (var _i = 0, combined_1 = combined(); _i < combined_1.length; _i++) {
    var num = combined_1[_i];
    console.log("値: " + num);
}

実行結果：

值: 1
值: 2
值: 3
值: 4

yield*：委譲ジェネレータは複数のジェネレータやイテラブルオブジェクトを組み合わせることができ、再利用可能なデータフローの構築に最適です。

TypeScript ジェネレータの型

ジェネレータの型注釈には Generator 型を使用します。

例

// ジェネレータ型: Generator<yield型, return型, nextパラメータ型>
function* idGenerator(): Generator<number, void, unknown> {
    var i = 1;
    while (i <= 3) {
        yield i++;  // yield は number 型
    }
    // return void
}

var gen = idGenerator();
console.log(Array.from(gen));

型の説明：Generator<T, R, N> は、T が yield の型、R が最終的な戻り値の型、N が next() のパラメータの型を表します。

注意事項

  • イテレータプロトコル：Symbol.iterator を実装して next() メソッドを持つオブジェクトを返す
  • ジェネレータ構文：function ではなく function* を使用する
  • yield キーワード：実行を一時停止して値を返す
  • 遅延評価：ジェネレータは必要なときに計算し、すべての値を一度に生成することはありません。
ベストプラクティス：大規模なデータストリーム、無限シーケンス、一時停止・再開が必要な場面では、ジェネレータを使用します。

まとめ

イテレータとジェネレータは、TypeScript における強力なデータ処理ツールです。

  • イテラブルオブジェクト：Symbol.iterator インターフェースを実装
  • ジェネレータ：function* と yield を使用して作成
  • yield：実行を一時停止して値を返す
  • 委譲：yield* を使用して複数のジェネレータを組み合わせる

提案：カスタムオブジェクトの走査、データフローの処理、または無限シーケンスの作成が必要な場合は、イテレータとジェネレータを使用します。
