TypeScript クラス

クラスはオブジェクト指向プログラミング（OOP）の中核概念であり、同じ属性とメソッドを持つオブジェクトを作成するためのテンプレートまたは設計図です。TypeScript はオブジェクト指向プログラミングを完全にサポートしており、クラス、継承、アクセス修飾子などの機能を提供します。

クラスはデータ（属性）と動作（メソッド）をカプセル化し、コードをよりモジュール化し、再利用可能で保守しやすくします。クラスを使用することで、同じ構造を持つ複数のオブジェクトを作成できます。これらのオブジェクトはクラスのインスタンスと呼ばれます。

クラスの定義

TypeScript はclassclass キーワードを使用してクラスを定義します。クラスには以下のメンバーを含めることができます：

  • フィールド（Field）：クラス内で宣言される変数で、オブジェクトの属性を表します
  • コンストラクタ（Constructor）：クラスのインスタンス化時に呼び出される特別なメソッドで、オブジェクトを初期化するために使用されます
  • メソッド（Method）：クラス内で定義される関数で、オブジェクトの動作を表します

構文形式

class class_name {
    // 字段声明
    field1: type;
    field2: type;

    // 构造函数
    constructor(parameters) {
        // 初始化代码
    }

    // 方法
    methodName(): return_type {
        // 方法实现
    }
}

例：シンプルなクラスの作成

例

// 空の Person クラスを定義する
class Person {
}

コンパイル後の JavaScript：

例

var Person = /** @class */ (function () {
    function Person() {
    }
    return Person;
}());

クラスのフィールドとコンストラクタ

クラスのフィールドはオブジェクトのデータを格納する場所であり、コンストラクタはオブジェクト作成時に自動的に呼び出されて、フィールドを初期化します。

例

// 定义 Car 类
class Car {
// 字段：描述汽车の属性
    engine: string;

// コンストラクター：オブジェクト作成時に engine を初期化する
    constructor(engine: string) {
        this.engine = engine;
    }

// 方法：显示发动机信息
    disp(): void {
console.log("发动机型号: " + this.engine);
    }
}

// クラスのインスタンスを作成
var car = new Car("V8 发动机");

// 访问字段
console.log("读取发动机: " + car.engine);

// 调用方法
car.disp();

実行結果：

读取发动机: V8 发动机
发动机型号: V8 发动机

説明：

  • thisthis キーワードは現在のクラスのインスタンスを指します
  • コンストラクタのパラメータ名はフィールド名と同じにすることができ、this によってthis.field区別します
  • newnewキーワードを使用してクラスのインスタンスを作成します

注意：TypeScript のクラスはコンパイル後に JavaScript のコンストラクタ・プロトタイプパターンに変換され、インターフェースはコンパイル結果には含まれません。

アクセス修飾子

TypeScript は、クラスメンバーのアクセス可能性を制御するための3つのアクセス修飾子を提供します：

修飾子 説明
public パブリックメンバー：どこからでもアクセスできます（デフォルト）
private プライベートメンバー：クラス内部からのみアクセスできます
protected プロテクテッドメンバー：クラス内部およびサブクラスからアクセスできます

public（デフォルト）

例

class Person {
public name: string; // 公有属性
public age: number; // 公有属性

    constructor(name: string, age: number) {
        this.name = name;
        this.age = age;
    }

    public introduce(): void {
console.log("私は " + this.name + "、今年 " + this.age + " 歳");
    }
}

var person = new Person("Alice", 25);
console.log("姓名: " + person.name); // 可以访问
person.introduce(); // 可以访问

private（プライベート）

例

class Person {
    public name: string;
private secret: string; // 私有属性，外部无法直接访问

    constructor(name: string, secret: string) {
        this.name = name;
        this.secret = secret;
    }

// 公有方法可以访问私有属性
    public revealSecret(): void {
console.log("秘密: " + this.secret);
    }
}

var person = new Person("Alice", "我喜欢编程");

console.log("姓名: " + person.name); // 可以访问
// console.log(person.secret); // エラー：'secret' はプライベートプロパティです

person.revealSecret(); // 通过公有方法访问私有属性

protected（プロテクテッド）

例

class Person {
protected name: string; // 受保护属性

    constructor(name: string) {
        this.name = name;
    }

    protected sayHello(): void {
console.log("こんにちは、私は " + this.name);
    }
}

class Student extends Person {
    private grade: string;

    constructor(name: string, grade: string) {
        super(name);
        this.grade = grade;
    }

    public introduce(): void {
// サブクラスは保護されたプロパティとメソッドにアクセスできる
console.log("私は " + this.name + "、学年: " + this.grade);
        this.sayHello();
    }
}

var student = new Student("Bob", "高三");
student.introduce(); // 可以访问

// console.log(student.name); // エラー：'name' はプロテクトされたプロパティです

実行結果：

我是 Bob，年级: 高三
你好，我是 Bob

クラスの継承

継承により、あるクラス（サブクラス）が別のクラス（親クラス）から属性とメソッドを取得できるようになります。サブクラスは親クラスのコードを再利用できるだけでなく、親クラスの動作を拡張またはオーバーライドすることもできます。

基本構文

class child_class extends parent_class {
    // 子类新增的属性和方法
}

単一継承

例

// 父类：形状
class Shape {
    area: number;

    constructor(a: number) {
        this.area = a;
    }
}

// 子类：圆，继承自 Shape
class Circle extends Shape {
    disp(): void {
console.log("円の面積: " + this.area);
    }
}

var circle = new Circle(223);
circle.disp();

実行結果：

圆的面积: 223

多重継承

TypeScript は多重継承（1つのクラスが複数のクラスを継承すること）をサポートしていませんが、多層継承（A が B を継承し、B が C を継承する）はサポートしています：

例

// 根类
class Root {
    str: string;
}

// 子类：继承 Root
class Child extends Root {
}

// 叶子类：继承 Child（多重继承）
class Leaf extends Child {
}

var leaf = new Leaf();
leaf.str = "hello";
console.log("str 值: " + leaf.str);

実行結果：

str 值: hello

メソッドのオーバーライド（Override）

サブクラスは親クラスのメソッドをオーバーライド（Override）できます。つまり、サブクラス内で親クラスと同じ名前のメソッドを定義し、独自の動作を実装します。

supersuperキーワードを使用すると、親クラスのメソッドを呼び出すことができます。

例

// 父类
class PrinterClass {
    doPrint(): void {
console.log("親クラスの doPrint() メソッド");
    }
}

// 子类：重写父类方法
class StringPrinter extends PrinterClass {
    doPrint(): void {
// 親クラスのメソッドを呼び出す
        super.doPrint();

// 子クラス自身のロジック
console.log("子クラスの doPrint() メソッド");
    }
}

var obj = new StringPrinter();
obj.doPrint();

実行結果：

父类的 doPrint() 方法
子类的 doPrint() 方法

静的メンバー

staticstaticキーワードで定義されたメンバーはクラス自体に属し、クラスのインスタンスには属しません。

例

class StaticMem {
// 静态属性
    static num: number;

// 静态方法
    static disp(): void {
console.log("num の値は " + StaticMem.num);
    }
}

// 直接通过类名访问静态成员
StaticMem.num = 12;
StaticMem.disp();

実行結果：

num 值为 12

適用シーン：静的メンバーは、クラスの定数、ユーティリティメソッド、シングルトンパターンの定義によく使用されます。

instanceof 演算子

instanceofオブジェクトが特定のクラスのインスタンスであるかどうかを判定するために使用します。

例

class Person {
}

var obj = new Person();
var isPerson = obj instanceof Person;

console.log("obj は Person クラスのインスタンスですか？ " + isPerson);

実行結果：

obj 是 Person 类的实例吗？ true

クラスによるインターフェースの実装

クラスはimplementsキーワードでインターフェースを実装し、クラスがインターフェース定義の契約に適合することを保証します。

例

// インターフェースを定義
interface ILoan {
interest: number; // 金利
}

// クラスがインターフェースを実装
class AgriLoan implements ILoan {
    interest: number;
rebate: number; // リベート

    constructor(interest: number, rebate: number) {
        this.interest = interest;
        this.rebate = rebate;
    }
}

var loan = new AgriLoan(10, 1);
console.log("利率: " + loan.interest + "%，回扣: " + loan.rebate);

実行結果：

利率: 10%，回扣: 1

抽象クラス

抽象クラスはインスタンス化できず、サブクラスが継承するための基底クラスとしてのみ使用できます。抽象クラスは抽象メソッド（実装のないプレースホルダーメソッド）を含むことができ、サブクラスはこれらのメソッドを実装する必要があります。

例

// 抽象クラス
abstract class Animal {
abstract makeSound(): void; // 抽象メソッド。サブクラスは実装する必要があります

    move(): void {
console.log("動物が移動しています");
    }
}

// 具象クラス：抽象クラスを継承
class Dog extends Animal {
    makeSound(): void {
console.log("汪汪汪!");
    }
}

var dog = new Dog();
dog.move();
dog.makeSound();

実行結果：

動物が動いている
ワンワン!

総合例

クラスのさまざまな特性を総合的に活用します：

例

// インターフェース定義
interface I Printable {
    print(): void;
}

// 抽象クラス
abstract class Item {
    protected name: string;
    protected price: number;

    constructor(name: string, price: number) {
        this.name = name;
        this.price = price;
    }

    abstract getDetails(): string;
}

// 具象クラス
class Product extends Item implements I Printable {
    private category: string;

    constructor(name: string, price: number, category: string) {
        super(name, price);
        this.category = category;
    }

// 抽象メソッドを実装
    getDetails(): string {
return `产品: ${this.name}, 价格: ¥${this.price}, 类别: ${this.category}`;
    }

// インターフェースメソッドを実装
    print(): void {
        console.log(this.getDetails());
    }

// 静的メソッド
    static create(name: string, price: number): Product {
return new Product(name, price, "默认类别");
    }
}

// 使用
var product = Product.create("笔记本电脑", 5999);
product.print();

// 割引メソッド
class DiscountedProduct extends Product {
    private discount: number;

    constructor(name: string, price: number, category: string, discount: number) {
        super(name, price, category);
        this.discount = discount;
    }

    getDetails(): string {
        var discountedPrice = this.price * (1 - this.discount / 100);
return `产品: ${this.name}, 原价: ¥${this.price}, 折扣: ${this.discount}%, 现价: ¥${discountedPrice.toFixed(2)}`;
    }
}

var discountedProduct = new DiscountedProduct("手机", 2999, "电子产品", 20);
discountedProduct.print();

実行結果：

产品: 笔记本电脑, 价格: ¥5999, 类别: 默认类别
产品: 手机, 原价: ¥2999, 折扣: 20%, 现价: ¥2399.20

まとめ

TypeScript のクラスは、完全なオブジェクト指向プログラミングサポートを提供します：

  • クラスの定義：class キーワードを使用し、フィールド、コンストラクタ、メソッドを含みます
  • アクセス修飾子：public、private、protected でメンバーのアクセス権限を制御します
  • 継承：extends を使用してクラスの継承を実現し、多層継承をサポートします
  • メソッドのオーバーライド：サブクラスは親クラスのメソッドをオーバーライドでき、super を使用して親クラスを呼び出します
  • 静的メンバー：static キーワードを使用し、クラス自体に属し、インスタンスではありません
  • インターフェースの実装：implements キーワードを使用してインターフェースを実装します
  • 抽象クラス：abstract キーワードを使用し、インスタンス化できず、基底クラスとして機能します

クラスは TypeScript のオブジェクト指向プログラミングの基礎であり、クラスを適切に使用することで、コードをより構造化し、保守しやすくすることができます。
