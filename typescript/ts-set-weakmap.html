TypeScript Set と WeakMap

TypeScript は JavaScript の Set と WeakMap データ構造を継承し、より強力な型サポートを提供します。

これらのデータ構造は、一意な値の集合、キーと値のペアのマッピング、キャッシュなどのシーンで非常に役立ちます。

SVG 図: Set と Map データ構造

なぜ Set と WeakMap が必要か

開発では、一意な値の集合とキーと値のペアのマッピングを扱う必要がよくあります。

Set は自動的に重複を排除する集合機能を提供し、一意な値を処理する際に配列よりも便利です。

WeakSet と WeakMap は弱参照を使用するため、ガベージコレクションを妨げません。DOM ノードのキャッシュなど、メモリリークを避ける必要があるシーンに適しています。

概念の説明:Set は値の集合で、値は一意です。Map はキーと値のペアの集合で、キーは任意の型にできます。WeakSet と WeakMap は弱参照を使用するため、ガベージコレクションに影響しません。

Set

Set は値の集合で、値は一意であり、重複は許可されません。

実例

// Set を作成し、要素の型を number に指定
var numbers = new Set<number>();

// 要素を追加
numbers.add(1);
numbers.add(2);
numbers.add(3);
numbers.add(1); // 重複する値は無視され、追加されません

// サイズと含むかどうかを確認
console.log("Set サイズ: " + numbers.size);
console.log("2 を含むか: " + numbers.has(2));

// Set を反復処理
numbers.forEach(function(value) {
    console.log("値: " + value);
});

// 配列に変換
var arr = Array.from(numbers);
console.log("配列に変換: " + arr);

実行結果:

Set 大小: 3
是否包含 2: true
值: 1
值: 2
值: 3
转换为数组: 1,2,3

重複排除:Set は重複する値を自動的に無視するため、配列の重複排除に非常に適しています。

Set 型注釈

Set 内の値の型を明示的に指定できます。

実例

// 文字列 Set
// 文字列型の値のみ追加できます
var stringSet: Set<string> = new Set();
stringSet.add("a");
stringSet.add("b");

// オブジェクト Set
// Person インターフェースを定義
interface Person {
    name: string;
}
// Person オブジェクトを格納する Set を作成
var personSet: Set<Person> = new Set();
personSet.add({ name: "Alice" });
personSet.add({ name: "Bob" });

console.log("文字列 Set: " + Array.from(stringSet));
console.log("オブジェクト Set サイズ: " + personSet.size);

ジェネリック:使用Set<T>構文で Set 内の要素の型を指定します。

WeakSet

WeakSet はオブジェクト参照を格納します。参照は弱参照であり、ガベージコレクションに影響しません。

実例

// WeakSet はオブジェクトのみ格納でき、プリミティブ値は格納できません
var weakSet = new WeakSet();

// オブジェクトを作成
var obj1 = { name: "Alice" };
var obj2 = { name: "Bob" };

// オブジェクトを WeakSet に追加
weakSet.add(obj1);
weakSet.add(obj2);

// 含むかどうかを確認
console.log("obj1 を含むか: " + weakSet.has(obj1));

// 参照を削除すると、オブジェクトはガベージコレクションされる可能性があります
weakSet.delete(obj1);
console.log("削除後に obj1 を含むか: " + weakSet.has(obj1));

注意:WeakSet は反復処理ができず、型注釈は次のみ指定できます。objectこれにより、WeakSet はガベージコレクションされる必要があるオブジェクトの格納に適しています。

Map

Map はキーと値のペアの集合で、キーは任意の型にできます。

実例

// Map を作成し、キー型は string、値型は number
var map = new Map<string, number>();

// キーと値のペアを設定
map.set("one", 1);
map.set("two", 2);
map.set("three", 3);

// 値を取得
console.log("two を取得: " + map.get("two"));
console.log("Map サイズ: " + map.size);
console.log("three を含むか: " + map.has("three"));

// Map を反復処理
map.forEach(function(value, key) {
    console.log(key + ": " + value);
});

// 配列に変換
console.log("配列に変換: " + Array.from(map.entries()));

実行結果:

获取 two: 2
Map 大小: 3
是否包含 three: true
one: 1
two: 2
three: 3
转换为数组: one,1,two,2,three,3

利点:Map のキーは任意の型（オブジェクト、関数など）にできるため、オブジェクトをキーとして使用する場合よりも柔軟です。

WeakMap

WeakMap のキーは弱参照であり、ガベージコレクションに影響しません。

実例

// WeakMap のキーはオブジェクトでなければなりません
// キー型は object、値型は string
var weakMap = new WeakMap<object, string>();

// キーとして使用するオブジェクトを作成
var keyObj = { id: 1 };
// キーと値のペアを設定
weakMap.set(keyObj, "value1");

// 値を取得
console.log("値を取得: " + weakMap.get(keyObj));
console.log("含むか: " + weakMap.has(keyObj));

// キーと値のペアを削除
weakMap.delete(keyObj);
console.log("削除後: " + weakMap.has(keyObj));

応用シーン:WeakMap は DOM ノードデータのキャッシュによく使用されます。DOM ノードが削除されるとキャッシュデータも自動的にクリーンアップされるため、メモリリークを防げます。

実際の応用シーン

Map を使用して配列要素の出現回数を集計します。

実例

// Map を使用して配列内の各要素の出現回数を集計
function countElements(arr: string[]): Map<string, number> {
    // Map を作成し、キーは文字列、値は数値
    var counts = new Map<string, number>();

    // 配列を反復処理
    for (var _i = 0, arr_1 = arr; _i < arr_1.length; _i++) {
        var item = arr_1[_i];
        // 現在のカウントを取得し、なければ 0 を返す
        var currentCount = counts.get(item) || 0;
        // カウントを更新
        counts.set(item, currentCount + 1);
    }

    return counts;
}

// テスト
var fruits = ["apple", "banana", "apple", "orange", "banana", "apple"];
var result = countElements(fruits);

// 結果を反復処理
result.forEach(function(count, fruit) {
    console.log(fruit + ": " + count);
});

実行結果:

apple: 3
banana: 2
orange: 1

実用的:Map はキャッシュ、集計、インデックスなどの機能を実装するのに理想的な選択肢です。

注意事項

  • Set の一意性:Set は重複する値を自動的に無視します
  • WeakSet/WeakMap：キーはオブジェクトである必要があり、反復処理はできません
  • Map のキー型:Map のキーは任意の型にできます
  • メモリ管理:WeakSet/WeakMap はガベージコレクションを妨げません

選択の推奨:一意な値の集合が必要な場合は Set、キーと値のマッピングが必要な場合は Map、メモリリークを避ける必要がある場合は WeakSet/WeakMap を使用します。

まとめ

Set と Map は TypeScript で非常に便利なデータ構造です。

  • Set：値の集合で、値は一意、自動的に重複を排除
  • WeakSet：オブジェクトの弱参照集合で、反復処理はできず、ガベージコレクションが必要なシーンに適しています
  • Map：キーと値のペアの集合で、キーは任意の型にできます
  • WeakMap：キーの弱参照で、反復処理はできず、キャッシュやプライベートデータに適しています

提案:具体的なニーズに応じて適切なデータ構造を選択してください: 重複排除が必要な場合は Set、マッピングが必要な場合は Map、メモリ最適化が必要な場合は Weak バージョンを使用します。
