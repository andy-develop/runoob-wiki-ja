TypeScript 条件文

条件文は、異なる条件に基づいて異なる動作を実行するために使用されます。

TypeScript 条件文は、1つまたは複数の文の実行結果（True または False）によって実行するコードブロックを決定します。

以下の図で、条件文の実行プロセスを簡単に理解できます。

条件文

通常、コードを書くときは、異なる決定に対して異なる動作を実行する必要があります。コード内で条件文を使用してこのタスクを実行できます。

TypeScript では、次の条件文を使用できます。

  • if 文- 指定した条件が true の場合のみ、この文を使用してコードを実行します
  • if...else 文- 条件が true の場合はコードを実行し、条件が false の場合は他のコードを実行します
  • if...else if....else 文- この文を使用して、複数のコードブロックのうち1つを選択して実行します
  • switch 文- この文を使用して、複数のコードブロックのうち1つを選択して実行します

if 文

TypeScript の if 文は、ブール式とそれに続く1つ以上の文で構成されます。

構文

構文は次のとおりです。

if(boolean_expression){
    # 在布尔表达式 boolean_expression 为 true 执行
}

ブール式 boolean_expression が true の場合、if 文内のコードブロックが実行されます。ブール式が false の場合、if 文の後の最初のコード（閉じ括弧の後）が実行されます。

フローチャート

例

var num:number = 5 if (num > 0) { console.log("数字は正数です") }

上記のコードをコンパイルすると、次の JavaScript コードが得られます。

var num = 5; if (num > 0) { console.log("数字は正数です"); }

上記の JavaScript コードを実行すると、出力結果は次のとおりです。

数字は正数です

if...else 文

if 文の後には、任意の else 文を続けることができます。else 文はブール式が false の場合に実行されます。

構文

構文は次のとおりです。

if(boolean_expression){
   # 在布尔表达式 boolean_expression 为 true 执行
}else{
   # 在布尔表达式 boolean_expression 为 false 执行
}

ブール式 boolean_expression が true の場合、if ブロック内のコードが実行されます。ブール式が false の場合、else ブロック内のコードが実行されます。

フローチャート

例

TypeScript

var num:number = 12; if (num % 2==0) { console.log("偶数"); } else { console.log("奇数"); }

上記のコードをコンパイルすると、次の JavaScript コードが得られます。

JavaScript

var num = 12; if (num % 2 == 0) { console.log("偶数"); } else { console.log("奇数"); }

上記の JavaScript コードを実行すると、出力結果は次のとおりです。

偶数

if...else if....else 文

if...else if....else 文は、複数の判定条件を実行するときに便利です。

構文

構文は次のとおりです。

if(boolean_expression 1) {
    # 在布尔表达式 boolean_expression 1 为 true 执行
} else if( boolean_expression 2) {
    # 在布尔表达式 boolean_expression 2 为 true 执行
} else if( boolean_expression 3) {
    # 在布尔表达式 boolean_expression 3 为 true 执行
} else {
    # 布尔表达式的条件都为 false 时执行
}

次の点に注意する必要があります。

  • 1 つのif判定文には 0 または 1 個のelse文を含めることができ、それは必ずelse..if文の後に置く必要があります。

  • 1 つのif判定文には 0 または複数のelse..if文を含めることができ、これらの文は必ずelseの前に置く必要があります。

  • 一度実行されるとelse..if内のコード、後ろのelse..if 或 elseは実行されません。

例

TypeScript

var num:number = 2 if(num > 0) { console.log(num+"は正数です") } else if(num < 0) { console.log(num+"は負数です") } else { console.log(num+"正数でも負数でもありません") }

上記のコードをコンパイルすると、次の JavaScript コードが得られます。

JavaScript

var num = 2; if (num > 0) { console.log(num + "は正数です"); } else if (num < 0) { console.log(num + "は負数です"); } else { console.log(num + "正数でも負数でもありません"); }

上記の JavaScript コードを実行すると、出力結果は次のとおりです。

2 是正数

switch…case 文

1 つのswitchswitch 文は、1つの変数が複数の値と等しい場合をテストできます。各値は case と呼ばれ、テスト対象の変数は各switch casecase に対してチェックされます。

switch文の構文：

switch(expression){ case constant-expression : statement(s); break; /*省略可能な*/ case constant-expression : statement(s); break; /*省略可能な*/ /*任意の数の case 文を使用できます*/ default : /*省略可能な*/ statement(s); }

switch文は次の規則に従う必要があります：

  • switch文の中のexpressionexpression は比較される式であり、基本データ型（number、string、boolean など）、オブジェクト型（object、Array、Map など）、カスタム型（class、interface、enum など）を含む任意の型にすることができます。
  • 1 つの switch 内には任意の数の case 文を置くことができます。各 case の後には、比較する値とコロンが続きます。
  • case のconstant-expressionデータ型は、switch 内の変数 expression と同じか、互換性のあるものでなければなりません。
  • テスト対象の変数が case の定数と等しい場合、case の後に続く文は、breakbreak 文に遭遇するまで実行されます。
  • break 文に遭遇するとbreakswitch は終了し、制御フローは switch 文の次の行にジャンプします。
  • すべての case がbreakbreak を含める必要があるわけではありません。case 文が break をbreak含まない場合、制御フローは続けて後続の case を実行し、break に遭遇するまで続行します。
  • 1 つのswitchswitch 文には省略可能なdefaultdefault case を switch の末尾に置くことができます。default キーワードは、式の値がすべての case の値と一致しない場合に実行されるコードブロックを表します。default case 内のbreakbreak 文は必須ではありません。

フローチャート

例

TypeScript

var grade:string = "A"; switch(grade) { case "A": { console.log("优"); break; } case "B": { console.log("良"); break; } case "C": { console.log("合格"); break; } case "D": { console.log("不合格"); break; } default: { console.log("不正な入力"); break; } }

上記のコードをコンパイルすると、次の JavaScript コードが得られます。

JavaScript

var grade = "A"; switch (grade) { case "A": { console.log("优"); break; } case "B": { console.log("良"); break; } case "C": { console.log("合格"); break; } case "D": { console.log("不合格"); break; } default: { console.log("不正な入力"); break; } }

上記の JavaScript コードを実行すると、出力結果は次のとおりです。
