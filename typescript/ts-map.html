TypeScript Map オブジェクト

Map オブジェクトはキーと値のペアを保存し、キーの元の挿入順序を記憶することができます。

任意の値（オブジェクトまたはプリミティブ値）をキーまたは値として使用できます。

Map は ES6 で導入された新しいデータ構造です。参考にしてください：ES6 Map と Set。

Map の作成

TypeScript では、Map 型と new キーワードを使用して Map を作成します：

let myMap = new Map();

Map を初期化するには、配列の形式でキーと値のペアを渡すことができます：

let myMap = new Map([
        ["key1", "value1"],
        ["key2", "value2"]
    ]);

Map に関連する関数とプロパティ：

  • map.clear()– Map オブジェクトのすべてのキー/値ペアを削除します。
  • map.set()– キーと値のペアを設定し、その Map オブジェクトを返します。
  • map.get()– キーに対応する値を返します。存在しない場合は undefined を返します。
  • map.has()– キーに対応する値が Map に含まれているかを判定するブール値を返します。
  • map.delete()– Map の要素を削除します。削除に成功した場合は true、失敗した場合は false を返します。
  • map.size– Map オブジェクトのキー/値ペアの数を返します。
  • map.keys()- Map オブジェクト内の各要素のキーを含む Iterator オブジェクトを返します。
  • map.values()– Map オブジェクト内の各要素の値を含む新しい Iterator オブジェクトを返します。
  • map.entries()– Map 内のすべてのキーと値のペアを含むイテレーターを返します。

よく使う関数

set(key: K, value: V): this- Map にキーと値のペアを追加または更新します。

map.set('key1', 'value1');

get(key: K): V | undefined- キーに基づいて値を取得します。キーが存在しない場合は undefined を返します。

const value = map.get('key1');

has(key: K): boolean - Map に指定されたキーが存在するかどうかを確認します。

const exists = map.has('key1');

delete(key: K): boolean - 指定されたキーのキーと値のペアを削除します。削除に成功した場合は true、それ以外の場合は false を返します。

const removed = map.delete('key1');

clear(): void - Map 内のすべてのキーと値のペアをクリアします。

map.clear();

size: number- Map 内のキーと値のペアの数を返します。

const size = map.size;

反復メソッド

keys(): IterableIterator<K> - Map 内のすべてのキーを含むイテレーターを返します。
for (const key of map.keys()) {
  console.log(key);
}

values(): IterableIterator<V>- Map 内のすべての値を含むイテレーターを返します。

for (const value of map.values()) {
  console.log(value);
}

entries(): IterableIterator<[K, V]>- Map 内のすべてのキーと値のペアを含むイテレーターを返します。各要素は [key, value] 配列です。

for (const [key, value] of map.entries()) {
  console.log(key, value);
}

forEach(callbackfn: (value: V, key: K, map: Map<K, V>) => void, thisArg?: any): void- Map 内の各キーと値のペアに対して、指定されたコールバック関数を1回実行します。

map.forEach((value, key) => {
  console.log(key, value);
});

例

例

const map = new Map<string, number>();

map.set('one', 1);
map.set('two', 2);

console.log(map.get('one')); // 出力: 1

console.log(map.has('two')); // 出力: true

map.delete('one');

console.log(map.size); // 出力: 1

map.forEach((value, key) => {
  console.log(key, value); // 出力: two 2
});

map.clear();

console.log(map.size); // 出力: 0

例 - test.ts ファイル

let nameSiteMapping = new Map(); //Map オブジェクトを設定 nameSiteMapping.set("Google", 1); nameSiteMapping.set("Runoob", 2); nameSiteMapping.set("Taobao", 3); //キーに対応する値を取得 console.log(nameSiteMapping.get("Runoob")); // 2 //Map にキーに対応する値が含まれているかを判定 console.log(nameSiteMapping.has("Taobao")); // true console.log(nameSiteMapping.has("Zhihu")); // false //Map オブジェクトのキー/値ペアの数を返す console.log(nameSiteMapping.size); // 3 //Runoob を削除 console.log(nameSiteMapping.delete("Runoob")); // true console.log(nameSiteMapping); //Map オブジェクトのすべてのキー/値ペアを削除 nameSiteMapping.clear(); //Map をクリア console.log(nameSiteMapping);

使用es6コンパイル：

tsc --target es6 test.ts

Map の反復

Map オブジェクトの要素は順番に挿入されます。Map オブジェクトを反復処理でき、反復のたびに [key, value] 配列が返されます。

TypeScriptではfor...ofを使用して反復処理を実装します：

例 - test.ts ファイル

let nameSiteMapping = new Map(); nameSiteMapping.set("Google", 1); nameSiteMapping.set("Runoob", 2); nameSiteMapping.set("Taobao", 3); //Map 内の key を反復処理 for (let key of nameSiteMapping.keys()) { console.log(key); } //Map 内の value を反復処理 for (let value of nameSiteMapping.values()) { console.log(value); } //Map 内の key => value を反復処理 for (let entry of nameSiteMapping.entries()) { console.log(entry[0], entry[1]); } //オブジェクトの分割代入を使用 for (let [key, value] of nameSiteMapping) { console.log(key, value); }

使用es6コンパイル：

tsc --target es6 test.ts

上記のコードをコンパイルすると、次の JavaScript コードが得られます：

例

let nameSiteMapping = new Map(); nameSiteMapping.set("Google", 1); nameSiteMapping.set("Runoob", 2); nameSiteMapping.set("Taobao", 3); //Map 内の key を反復処理 for (let key of nameSiteMapping.keys()) { console.log(key); } //Map 内の value を反復処理 for (let value of nameSiteMapping.values()) { console.log(value); } //Map 内の key => value を反復処理 for (let entry of nameSiteMapping.entries()) { console.log(entry[0], entry[1]); } //オブジェクトの分割代入を使用 for (let [key, value] of nameSiteMapping) { console.log(key, value); }
