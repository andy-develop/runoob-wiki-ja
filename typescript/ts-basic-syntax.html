最初の TypeScript プログラム

次の TypeScript プログラムを使用して "Hello World" を出力できます：

Runoob.ts ファイルのコード：

const hello : string = "Hello World!" console.log(hello)

試してみる »

上記のコードは、まず次のtscコマンドでコンパイルします：

tsc Runoob.ts

次のような js コードが得られます：

Runoob.js ファイルのコード：

var hello = "Hello World!"; console.log(hello);

最後に node コマンドを使用してその js コードを実行します。

$ node Runoob.js
Hello World

複数の ts ファイルを同時にコンパイルできます：

tsc file1.ts file2.ts file3.ts

tsc の一般的なコンパイルパラメータは次の表のとおりです：

番号 コンパイルパラメータの説明

2.

3.

ECMA バージョンを設定
4.

追加で .d.ts 拡張子のファイルを生成します。

空白と改行

TypeScript はプログラム内のスペース、タブ、改行を無視します。

スペースやタブは通常、コードのインデントに使用され、コードを読みやすく理解しやすくします。

TypeScript は大文字と小文字を区別します

TypeScript は大文字と小文字の文字を区別します。

セミコロンは省略可能です

各行の命令は文です。セミコロンは使用しても使用しなくても構いません。TypeScript ではセミコロンは省略可能ですが、使用することをお勧めします。

以下のコードはすべて有効です：

console.log("Runoob")
console.log("Google");

文を同じ行に書く場合は、セミコロンで区切る必要があります。そうしないとエラーになります。例：

console.log("Runoob");console.log("Google");

TypeScript コメント

コメントを書くことは良い習慣です。多くのプログラマーはコメントを嫌いますが、それでも各コードに説明を書くことをお勧めします。

コメントはプログラムの可読性を高めることができます。

コメントには、コードの作成者や関数の説明など、プログラムに関する情報を含めることができます。

コンパイラはコメントを無視します。

TypeScript は2種類のコメントをサポートしています

  • 単行コメント ( // )− // の後の文字はすべてコメント内容です。

  • 複数行コメント (/* */)− このコメントは複数行にわたることができます。

コメントの例：

// これは一行コメントです
 
/* 
 これは複数行コメントです 
 これは複数行コメントです 
 これは複数行コメントです 
*/

TypeScript とオブジェクト指向

オブジェクト指向は、現実世界を理解し抽象化する方法です。

TypeScript はオブジェクト指向プログラミング言語です。

オブジェクト指向には主に2つの概念があります：オブジェクトとクラスです。

  • オブジェクト：オブジェクトはクラスのインスタンスです（オブジェクトは彼女を見つけることではありません）、状態と振る舞いを持ちます。例えば、犬はオブジェクトです。その状態には色、名前、品種があり、振る舞いには尻尾を振る、吠える、食べるなどがあります。
  • 类：クラスはテンプレートであり、ある種類のオブジェクトの振る舞いと状態を説明します。
  • メソッド：メソッドはクラスの操作の実装手順です。

下図ではgirl、boyがクラスであり、具体的な各人がそのクラスのオブジェクトです：

TypeScript オブジェクト指向プログラミングの例：

class Site { name():void { console.log("Runoob") } } var obj = new Site(); obj.name();

上記の例では、Site というクラスを定義しています。このクラスには name() メソッドがあり、そのメソッドはターミナルに文字列 Runoob を出力します。

new キーワードでクラスのオブジェクトを作成し、そのオブジェクトが name() メソッドを呼び出します。

コンパイル後に生成されるJavaScriptコードは次のとおりです。

var Site = /** @class */ (function () { function Site() { } Site.prototype.name = function () { console.log("Runoob"); }; return Site; }()); var obj = new Site(); obj.name();

上記のJavaScriptコードを実行すると、出力結果は以下のようになります。

Runoob
