TypeScript 変数宣言

変数は、コンピュータのメモリアドレスを参照するための便利なプレースホルダーです。

変数はデータを格納するコンテナと考えることができます。

TypeScript 変数の命名規則：

  • 変数名には数字と文字を含めることができます。

  • アンダースコアと_ドル記号を除き、$他の特殊文字（スペースを含む）を含めることはできません。

  • 変数名は数字で始めることはできません。

変数は使用前に宣言する必要があります。変数を宣言するには var を使用できます。

変数を宣言するには、次の4つの方法があります：

変数の型と初期値を宣言する：

var [变量名] : [类型] = 值;

例：

var uname:string = "Runoob";

変数の型を宣言するが初期値がない場合、変数の値は undefined に設定されます：

var [变量名] : [类型];

例：

var uname:string;

変数を宣言して初期値を設定するが型を指定しない場合、その変数は任意の型にできます：

var [变量名] = 值;

例：

var uname = "Runoob";

変数の宣言で型と初期値を設定しない場合、型は任意の型でよく、デフォルトの初期値は undefined です：

var [变量名];

例：

var uname;

例

var uname:string = "Runoob";
var score1:number = 50;
var score2:number = 42.50
var sum = score1 + score2
console.log("名前: "+uname)
console.log("最初の科目の成績: "+score1)
console.log("2つ目の科目の成績: "+score2)
console.log("合計点: "+sum)

注意：変数に name を使用しないでください。DOM のグローバル window オブジェクトの name プロパティと名前が重複します。

上記のコードを tsc コマンドでコンパイルすると、次の JavaScript コードが得られます：

var uname = "Runoob"; var score1 = 50; var score2 = 42.50; var sum = score1 + score2; console.log("名前:" + uname); console.log("最初の科目の成績:" + score1); console.log("2つ目の科目の成績:" + score2); console.log("合計点:" + sum);

この JavaScript コードを実行すると、出力結果は次のとおりです：

名字: Runoob
第一个科目成绩: 50
第二个科目成绩: 42.5
总成绩: 92.5

TypeScript は強い型付けに従います。異なる型を変数に代入するとコンパイルエラーになります。次の例のとおりです：

var num:number = "hello"     // 这个代码会编译错误

型アサーション（Type Assertion）

型アサーションは、値の型を手動で指定するために使用できます。つまり、変数の型を別の型に変更することができます。

構文形式：

<型>の値

または：

值 as 类型

例

var str = '1' var str2:number = <number> <any> str //str、str2 は string 型です console.log(str2)

TypeScript は単一のアサーションで十分かどうかをどのように判断するのか

S 型が T 型のサブセットであるか、T 型が S 型のサブセットである場合、S は T に正常にアサーションできます。これは、型アサーションを行う際に追加の安全性を提供するためです。完全に根拠のないアサーションは危険です。それを行う場合は、any を使用できます。

それが「型変換」と呼ばれないのは、変換は通常、何らかの実行時サポートを意味するからです。しかし、型アサーションは純粋にコンパイル時の構文であり、同時に、コンパイラにコードの分析方法を提供する方法でもあります。

コンパイル後、上記のコードは次の JavaScript コードを生成します：

var str = '1'; var str2 = str; //str、str2 は string 型です console.log(str2);

型推論

型が指定されていない場合、TypeScript コンパイラは型推論を使用して型を推測します。

宣言が不足しているために型を推論できない場合、その型はデフォルトの動的な any 型と見なされます。

var num = 2; //型推論により number 型と推論されます console.log("num 変数の値は"+num); num = "12"; //コンパイルエラー console.log(num);

  • 1行目のコードは変数 num を宣言し、初期値を2に設定しています。 変数宣言で型が指定されていないことに注意してください。そのため、プログラムは型推論を使用して変数のデータ型を決定します。最初の代入が 2 であるため、numnumber 型に設定されます。

  • 3行目のコードで、再び変数に文字列型の値を設定すると、コンパイルエラーになります。変数がすでに number 型に設定されているためです。

    error TS2322: Type '"12"' is not assignable to type 'number'.

変数のスコープ

変数のスコープは、変数が定義される位置を指定します。

プログラム内での変数の可用性は、変数のスコープによって決まります。

TypeScript には次のスコープがあります：

  • グローバルスコープ− グローバル変数はプログラム構造の外部で定義され、コード内のどこでも使用できます。

  • クラススコープ− この変数はフィールドとも呼ばれます。クラス変数はクラス内で宣言されますが、クラスのメソッドの外側にあります。この変数はクラスのオブジェクトを通じてアクセスできます。クラス変数は静的にもでき、静的変数はクラス名で直接アクセスできます。

  • ローカルスコープ− ローカル変数。ローカル変数は、それが宣言されたコードブロック（例：メソッド）内でのみ使用できます。

次の例は、3つのスコープの使用法を示しています：

var global_num = 12 //グローバル変数 class Numbers { num_val = 13; //インスタンス変数 static sval = 10; //静的変数 storeNum():void { var local_num = 14; //ローカル変数 } } console.log("グローバル変数:"+global_num) console.log(Numbers.sval) //静的変数 var obj = new Numbers(); console.log("インスタンス変数:"+obj.num_val)

上記のコードを tsc コマンドでコンパイルした JavaScript コードは次のとおりです：

var global_num = 12; //グローバル変数 var Numbers = /** @class */ (function () { function Numbers() { this.num_val = 13; //インスタンス変数 } Numbers.prototype.storeNum = function () { var local_num = 14; //ローカル変数 }; Numbers.sval = 10; //静的変数 return Numbers; }()); console.log("グローバル変数:" + global_num); console.log(Numbers.sval); //静的変数 var obj = new Numbers(); console.log("インスタンス変数:" + obj.num_val);

上記の JavaScript コードを実行すると、出力結果は次のとおりです：

全局变量为: 12
10
实例变量: 13

メソッドの外部でローカル変数 local_num を呼び出すと、エラーが発生します：

error TS2322: Could not find symbol 'local_num'.
