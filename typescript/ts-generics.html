TypeScript の特徴

TypeScript ジェネリック

ジェネリック（Generics）は、関数、クラス、インターフェースなどを定義する際に、具体的な型ではなくプレースホルダーを使って型を表すことができるプログラミング言語の機能です。

ジェネリックは、再利用可能で柔軟かつ型安全なコードを書くときに非常に役立つ機能です。

ジェネリックを使用する主な目的は、特定の型に依存しないデータを扱い、型チェックを失わずにコードをさまざまなデータ型に適用できるようにすることです。

ジェネリックの利点は次のとおりです：

  • コードの再利用：特定の型に依存しない汎用コードを記述でき、コードの再利用性を高めます。

  • 型安全性：コンパイル時に型チェックを行い、実行時に型エラーが発生するのを防ぎます。

  • 抽象性：より抽象的で汎用的なコードを記述でき、さまざまなデータ型やデータ構造に対応できます。

ジェネリック識別子

ジェネリックでは、通常、慣例として使われる識別子がいくつかあります。たとえば、一般的なT（Type を表す）、U、Vなどがありますが、実際には任意の識別子を使用できます。

T： 「Type」を表し、最も一般的なジェネリック型パラメータ名です。

function identity<T>(arg: T): T {
    return arg;
}

K, V： キー（Key）と値（Value）を表すためのジェネリック型パラメータです。

interface KeyValuePair<K, V> {
    key: K;
    value: V;
}

E： 配列の要素を表すためのジェネリック型パラメータです。

function printArray<E>(arr: E[]): void {
    arr.forEach(item => console.log(item));
}

R： 関数の戻り値を表すためのジェネリック型パラメータです。

function getResult<R>(value: R): R {
    return value;
}

U, V： 通常、2番目、3番目のジェネリック型パラメータを表すために使用されます。

function combine<U, V>(first: U, second: V): string {
    return `${first} ${second}`;
}

これらの識別子は慣例的なものであり、実際には識別子の規則に適合する任意の名前を選択できます。重要なのはコードを読みやすく理解しやすくすることです。そのため、ジェネリック型パラメータには、その用途を理解しやすいように説明的な名前を使用することをお勧めします。

ジェネリック関数（Generic Functions）

ジェネリックを使用して、さまざまな型を処理できる関数を作成します：

例

function identity<T>(arg: T): T {
    return arg;
}

// ジェネリック関数を使用
let result = identity<string>("Hello");
console.log(result); // 出力: Hello

let numberResult = identity<number>(42);
console.log(numberResult); // 出力: 42

解説：上記の例では、identityはジェネリック関数であり、を使用して<T>ジェネリック型を表します。それは1つのパラメータを受け取ります。argと戻り値はどちらもジェネリック型です。T。使用時には、山括弧を使用して<>ジェネリック型を明示的に指定できます。最初の呼び出しではstring型を指定し、2番目の呼び出しではnumber型を指定しました。

2. ジェネリックインターフェース（Generic Interfaces）

ジェネリックを使用してインターフェースを定義でき、インターフェースのメンバーを任意の型にすることができます：

例

// 基本構文
interface Pair<T, U> {
    first: T;
    second: U;
}

// ジェネリックインターフェースを使用
let pair: Pair<string, number> = { first: "hello", second: 42 };
console.log(pair); // 出力: { first: 'hello', second: 42 }

解説：ここでジェネリックインターフェースを定義しましたPair、それには2つの型パラメータがありますTとU。次に、このジェネリックインターフェースを使用してオブジェクトを作成しましたpair、その中でfirstは文字列型で、secondは数値型です。

3. ジェネリッククラス（Generic Classes）

ジェネリックは、クラスのインスタンス変数やメソッドにも適用できます：

例

// 基本構文
class Box<T> {
    private value: T;

    constructor(value: T) {
        this.value = value;
    }

    getValue(): T {
        return this.value;
    }
}

// ジェネリッククラスを使用
let stringBox = new Box<string>("TypeScript");
console.log(stringBox.getValue()); // 出力: TypeScript

解説：この例では、Boxはジェネリッククラスであり、を使用して<T>ジェネリック型を表します。コンストラクタとメソッドはどちらもジェネリック型を使用できますT。インスタンス化することでBox<string>、文字列を格納するBoxインスタンスを作成し、getValueメソッドで格納された値を取得しました。

4. ジェネリック制約（Generic Constraints）

ジェネリックの型の範囲を制限したい場合は、ジェネリック制約を使用できます：

例

// 基本構文
interface Lengthwise {
    length: number;
}

function logLength<T extends Lengthwise>(arg: T): void {
    console.log(arg.length);
}

// 正しい使用法
logLength("hello"); // 出力: 5

// 誤った使用法。数値には length プロパティがないため
logLength(42); // エラー

解説：この例では、ジェネリック関数を定義しましたlogLength、それは型がTのパラメータを受け取りますが、制約条件があります。すなわちTが実装する必要があるLengthwiseインターフェースです。このインターフェースにはlengthプロパティが必要です。したがって、正しく呼び出せますlogLength("hello")が、呼び出せませんlogLength(42)。なぜなら数値にはlengthプロパティがないからです。

5. ジェネリックとデフォルト値

ジェネリックにデフォルト値を設定でき、型パラメータを指定しない場合にデフォルト型を使用できます：

例

// 基本構文
function defaultValue<T = string>(arg: T): T {
    return arg;
}

// デフォルト値を持つジェネリック関数を使用
let result1 = defaultValue("hello"); // string 型と推論される
let result2 = defaultValue(42);      // number 型と推論される

説明：この例は、デフォルト値を持つジェネリック関数を示しています。関数defaultValueは1つのジェネリックパラメータを受け取りT、それにデフォルト型としてstringを設定しています。使用時に、型を明示的に指定しない場合はデフォルト型が使用されます。この例では、最初の呼び出しではresult1と推論されstring、2番目の呼び出しではresult2と推論されnumberます。
