TypeScript 基本型

基本型を使用すると、開発者はデータの構造と意図をより正確に記述できます。

TypeScript が含むデータ型は以下の表のとおりです:

型説明例
stringテキストデータを表しますlet name: string = "Alice";
number整数と浮動小数点数を含む数値を表しますlet age: number = 30;
booleanブール値を表しますtrue 或 falselet isDone: boolean = true;
array同じ型の要素の配列を表しますlet list: number[] = [1, 2, 3];
tuple型と長さが既知の配列を表しますlet person: [string, number] = ["Alice", 30];
enum名前付き定数のセットを定義しますenum Color { Red, Green, Blue };
any任意の型。型チェックを行いませんlet value: any = 42;
void戻り値なし（主に関数で使用）function log(): void {}
null空値を表しますlet empty: null = null;
undefined未定義を表しますlet undef: undefined = undefined;
never戻り値を持たないことを表しますfunction error(): never { throw new Error("error"); }
objectプリミティブ型以外を表しますlet obj: object = { name: "Alice" };
unionユニオン型。複数の型のいずれかであることを表します`let id: string
unknown不確定な型。型チェック後に使用する必要がありますlet value: unknown = "Hello";

注意：TypeScript と JavaScript には整数型はありません。

1、string 文字列型

テキストデータを表し、文字列のみを格納できます。通常、文字情報を記述するために使用します。

let message: string = "Hello, TypeScript!";

テンプレート文字列：TypeScript はテンプレート文字列をサポートしており、バッククォート`（シングルクォートではなく '）で定義します。文字列内に変数や式を挿入でき、複数行のテキストや変数の連結に非常に適しています。

let name: string = "Alice";
let greeting: string = `Hello, ${name}! Welcome to TypeScript.`;
console.log(greeting); // 输出：Hello, Alice! Welcome to TypeScript.

2、number 数値

TypeScript は、整数と浮動小数点数を含むすべての数値を number で表します。

let age: number = 25;
let temperature: number = 36.5;

3、boolean ブール値

論理値 true または false を表し、条件判断に使用します。

let isCompleted: boolean = false;

4、array 配列

同じ型の要素の集まりを表せます。type[] または Array&lt;type&gt; の2つの方法で表せます。

let numbers: number[] = [1, 2, 3];
let names: Array<string> = ["Alice", "Bob"];

5、tuple タプル

数と型が既知の配列を表します。各要素は異なる型にでき、固定構造のデータを表すのに適しています。

let person: [string, number] = ["Alice", 25];

6、enum 列挙型

名前付き定数のセットを定義するために使用します。デフォルトでは列挙型の値は0から始まって増加します。

enum Color {
  Red,
  Green,
  Blue,
}
let favoriteColor: Color = Color.Green;

7、any 型

任意の型を表せます。データ型が不明な場合に適していますが、any は型チェックを迂回するため、使用時には注意が必要です。

let randomValue: any = 42;
randomValue = "hello";

any 型は、プログラミング時に型が不明確な変数に対して TypeScript が使用するデータ型で、主に以下の3つのケースで使用されます。

1、変数の値が動的に変化する場合、例えばユーザーからの入力などでは、any 型を使用することで、これらの変数はコンパイル段階の型チェックをスキップできます。サンプルコードは次のとおりです：

let x: any = 1;    // 数字类型
x = 'I am who I am';    // 字符串类型
x = false;    // 布尔类型

既存のコードを書き換える場合、any 型を使用すると、コンパイル時に型チェックを選択的に含めたり除外したりできます。サンプルコードは次のとおりです：

let x: any = 4;
x.ifItExists();    // 正确，ifItExists方法在运行时可能存在，但这里并不会检查
x.toFixed();    // 正确

さまざまな型のデータを格納する配列を定義する場合、サンプルコードは次のとおりです：

let arrayList: any[] = [1, false, 'fine'];
arrayList[1] = 100;

8、void 空型

戻り値のない関数に使用します。変数を宣言するとき、void 型は null または undefined のみを代入できることを意味します。

function logMessage(message: string): void {
  console.log(message);
}

9、null と undefined

null と undefined はそれぞれ「空値」と「未定義」を表します。デフォルトでは、これらはすべての型のサブタイプですが、strictNullChecks を設定することで厳密なチェックが可能です。

let empty: null = null;
let notAssigned: undefined = undefined;

null

JavaScript では、null は「何もない」ことを表します。

null は値が1つだけの特別な型です。空のオブジェクト参照を表します。

typeof で null を検出すると object が返ります。

undefined

JavaScript では、undefined は値が設定されていない変数です。

値のない変数に typeof を使用すると undefined が返ります。

Null と Undefined は他のすべての型（void を含む）のサブタイプであり、数値型などの他の型に代入できます。この場合、代入後の型は null または undefined になります。TypeScript で厳密な null チェック（--strictNullChecks）機能を有効にすると、null と undefined は void またはそれ自体に対応する型にのみ代入できます。サンプルコードは次のとおりです：

// 启用 --strictNullChecks
let x: number;
x = 1; // 编译正确
x = undefined;    // 编译错误
x = null;    // 编译错误

上記の例では、変数 x は数値型のみです。ある型で null または undefined が発生する可能性がある場合は、| を使用して複数の型をサポートできます。サンプルコードは次のとおりです：

// 启用 --strictNullChecks
let x: number | null | undefined;
x = 1; // 编译正确
x = undefined;    // 编译正确
x = null;    // 编译正确

詳細については以下を参照してください：JavaScript typeof、null、および undefined

10、never 型

戻り値を持たないことを表し、通常はエラーをスローする関数や無限ループに入る関数に使用され、その関数が決して正常に終了しないことを表します。

function throwError(message: string): never {
  throw new Error(message);
}

never は他のすべての型（null と undefined を含む）のサブタイプであり、決して発生しない値を表します。つまり、never 型として宣言された変数には never 型のみを代入でき、関数内では通常、例外をスローするか終了点に到達できないこと（例：無限ループ）として現れます。サンプルコードは次のとおりです：

let x: never;
let y: number;

// 编译错误，数字类型不能转为 never 类型
x = 123;

// 运行正确，never 类型可以赋值给 never类型
x = (()=>{ throw new Error('exception')})();

// 运行正确，never 类型可以赋值给 数字类型
y = (()=>{ throw new Error('exception')})();

// 返回值为 never 的函数可以是抛出异常的情况
function error(message: string): never {
    throw new Error(message);
}

// 返回值为 never 的函数可以是无法被执行到的终止点的情况
function loop(): never {
    while (true) {}
}

11、object オブジェクト型

プリミティブ型以外の値を表し、複雑なオブジェクト構造に適しています。

let person: object = { name: "Alice", age: 30 };

12、ユニオン型 (Union)

変数が複数の型のいずれかであることを表します。| 記号を使用して実現します。

let id: string | number;
id = "123";
id = 456;

13、unknown 不確定な型

any に似ていますが、より厳格です。型チェックを経てからでないと他の型の変数に代入できません。

let value: unknown = "Hello";
if (typeof value === "string") {
  let message: string = value;
}

14、型アサーション (Type Assertions)

型アサーションを使用すると、開発者はコンパイラに変数の型を明示的に伝えることができ、型を推論できない場合によく使用されます。as または山かっこ構文を使用できます。

let someValue: any = "this is a string";
let strLength: number = (someValue as string).length;

15、リテラル型

リテラル型を使用すると、変数は特定の値のみを持つことができ、ユニオン型と組み合わせて変数の特定の状態を定義するために使用します。

let direction: "up" | "down" | "left" | "right";
direction = "up";

これらの型により、TypeScript はより強力な型安全性とコードチェック機能を提供し、開発者がデータと意図をより明確かつ正確に表現できるようにして、実行時エラーを減らします。

例

以下の例では、TypeScript の主要な基本型の定義と使用法を示し、ユーザーオブジェクトと関連する操作関数をシミュレートしています：

例

// 列挙型を定義し、ユーザーの役割を表す
enum Role {
  Admin,
  User,
  Guest,
}

// interface を使用してユーザーの構造を定義する
interface User {
  id: number;               // number 型。ユーザーを一意に識別するために使用
  username: string;         // string 型。ユーザー名を表す
  isActive: boolean;        // boolean 型。ユーザーがアクティブかどうかを表す
  role: Role;               // enum 型。ユーザーの役割を表すために使用
  hobbies: string[];        // array 型。ユーザーの趣味を格納する
  contactInfo: [string, number]; // tuple 型。電話番号を含むタプル。形式は：[市外局番, 電話番号]
}

// User インターフェースの構造に一致するユーザーオブジェクトを作成する
const user: User = {
  id: 1,
  username: "Alice",
  isActive: true,
  role: Role.User,
  hobbies: ["Reading", "Gaming"],
  contactInfo: ["+1", 123456789],
};

// ユーザー情報を取得するために文字列を返す関数を定義する
function getUserInfo(user: User): string {
  return `User ${user.username} is ${user.isActive ? "active" : "inactive"} with role ${Role[user.role]}`;
}

// void 型を使用して、ユーザー情報を専用に出力する関数を定義する
function printUserInfo(user: User): void {
  console.log(getUserInfo(user));
}

// union 型の関数パラメータを定義し、ユーザー ID（number）またはユーザー名（string）を受け取る
function findUser(query: number | string): User | undefined {
  // typeof を使用して query の型を判定する
  if (typeof query === "number") {
    // 数値の場合は ID に基づいてユーザーを検索する
    return query === user.id ? user : undefined;
  } else if (typeof query === "string") {
    // 文字列の場合はユーザー名に基づいてユーザーを検索する
    return query === user.username ? user : undefined;
  }
  return undefined;
}

// never 型の関数を定義し、プログラムの例外を処理する
function throwError(message: string): never {
  throw new Error(message);
}

// any 型を使用して未知の型のデータを処理する
let unknownData: any = "This is a string";
unknownData = 42; // 数値に再代入する。型は any

// unknown 型を使用して不確かなデータを処理する。より安全
let someData: unknown = "Possible data";
if (typeof someData === "string") {
  console.log(`Length of data: ${(someData as string).length}`);
}

// 各関数を呼び出してテストする
printUserInfo(user);                    // ユーザー情報を出力する
console.log(findUser(1));               // IDでユーザーを検索
console.log(findUser("Alice"));         // ユーザー名でユーザーを検索

// null と undefined 型の変数を使用
let emptyValue: null = null;
let uninitializedValue: undefined = undefined;

説明：

  • 列挙型 (Role)：ユーザーロールを定義するための名前付き定数Admin、UserとGuest。
  • インターフェース (User)：以下を定義しますUserオブジェクトの構造。含まれるもの：id、username、isActiveなどの属性。示しているのはstring、number、boolean、arrayとtuple型の使用です。
  • 関数getUserInfo：ユーザーの説明情報を返します。文字列補間を使用し、enum。
  • 関数printUserInfo：型はvoid、情報を出力するだけで、値を返さないためです。
  • ユニオン型 (number | string)：使用されるのはfindUser関数のパラメータで、数値または文字列を受け取れます。
  • never型：throwError関数はエラーをスローし、正常に戻らないため、never型を使用します。
  • any型：任意の型を受け取れる変数を宣言する方法を示します。
  • unknown型：似ていますany。ただしより安全で、例では型アサーションの前に型チェックを行います。
  • nullとundefined：null値の使用をデモします。
