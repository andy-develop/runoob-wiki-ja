Rust 列挙型

Rust の列挙型は他のプログラミング言語の概念ほど単純ではありませんが、それでも非常に簡単に使用できます。

実例

#[derive(Debug)]

enum Book {
    Papery, Electronic
}

fn main() {
    let book = Book::Papery;
    println!("{:?}", book);
}

実行結果：

Papery

本は紙の本（Papery book）と電子書籍（Electronic book）に分けられます。

もし今、図書管理システムを開発しているなら、2種類の本の異なる属性（紙の本には請求記号、電子書籍にはURLのみ）を記述する必要があります。列挙型のメンバーにタプル属性を追加して記述できます。

enum Book {
    Papery(u32),
    Electronic(String),
}

let book = Book::Papery(1001);
let ebook = Book::Electronic(String::from("url://..."));

属性に名前を付けたい場合は、構造体構文を使用できます。

enum Book {
    Papery { index: u32 },
    Electronic { url: String },
}
let book = Book::Papery{index: 1001};

このように名前を付けることはできますが、構造体のフィールドにアクセスするように列挙型にバインドされた属性にアクセスすることはできないことに注意してください。アクセス方法は match 構文にあります。

match 構文

列挙の目的は、ある種類の事物を分類することであり、分類の目的は異なる状況を記述することです。この原理に基づき、列挙型は最終的に分岐構造で処理されることがよくあります（多くの言語では switch）。switch 構文は古典的ですが、Rust ではサポートされていません。多くの言語が switch を廃止した理由は、break の追加を忘れることによる連鎖実行問題が発生しやすいためです。Java や C# などの言語は安全検査によってこのような状況を防いでいます。

Rust は match 文を使用して分岐構造を実現します。まず、match で列挙型を処理する方法を見てみましょう。

実例

fn main() {
    enum Book {
        Papery {index: u32},
        Electronic {url: String},
    }
   
    let book = Book::Papery{index: 1001};
    let ebook = Book::Electronic{url: String::from("url...")};
   
    match book {
        Book::Papery { index } => {
            println!("Papery book {}", index);
        },
        Book::Electronic { url } => {
            println!("E-book {}", url);
        }
    }
}

実行結果：

Papery book 1001

match ブロックは関数式として扱うこともでき、戻り値を持つこともできます。

match 枚举类实例 {
    分类1 => 返回值表达式,
    分类2 => 返回值表达式,
    ...
}

ただし、すべての戻り値の式の型は同じでなければなりません！

列挙型の付加属性をタプルとして定義した場合、match ブロック内で一時的に名前を指定する必要があります。

実例

enum Book {
    Papery(u32),
    Electronic {url: String},
}
let book = Book::Papery(1001);

match book {
    Book::Papery(i) => {
        println!("{}", i);
    },
    Book::Electronic { url } => {
        println!("{}", url);
    }
}

match は列挙型の分岐選択に加えて、整数、浮動小数点数、文字、文字列スライス参照（&str）型のデータに対しても分岐選択ができます。浮動小数点数型の分岐選択は合法ですが、精度の問題で分岐エラーが発生する可能性があるため、推奨されません。

非列挙型に対して分岐選択を行う場合、例外ケースを処理するように注意する必要があります。たとえ例外ケースで何もする必要がない場合でもです。.例外ケースはアンダースコア_で表します：

実例

fn main() {
    let t = "abc";
    match t {
        "abc" => println!("Yes"),
        _ => {},
    }
}

Option 列挙型

Option は Rust 標準ライブラリの列挙型で、Rust が null 参照をサポートしない空白を埋めるために使用されます。

多くの言語（C/C++、Java）は null の存在をサポートしており、これは便利ですが、大きな問題も引き起こしています。null の発明者もこのことを認めており、「便利なアイデアが累計10億ドルの損失を生んだ」と述べています。

null は、開発者がすべてを null ではないと思い込んでいるときに、プログラムに致命的な打撃を与えることがよくあります。実際、このようなエラーが1つ発生するだけで、プログラムの実行は完全に終了してしまいます。

この問題を解決するために、多くの言語はデフォルトで null を許可しませんが、言語レベルで null の出現をサポートしています（通常、型の前に ? 記号を付けます）。

Java はデフォルトで null をサポートしていますが、@NotNull アノテーションを使用して null の出現を制限できます。これは応急的な対処法です。

Rust は言語レベルで空値 null の存在を完全に許可していませんが、null が少数の問題を効率的に解決できるため、Rust は Option 列挙型を導入しました。

enum Option<T> {
    Some(T),
    None,
}

空値を許可する型を定義したい場合は、次のようにします。

let opt = Option::Some("Hello");

opt に対して何らかの操作を実行したい場合は、まずそれが〜であるかどうかを判断する必要があります。Option::None：

実例

fn main() {
    let opt = Option::Some("Hello");
    match opt {
        Option::Some(something) => {
            println!("{}", something);
        },
        Option::None => {
            println!("opt is nothing");
        }
    }
}

実行結果：

Hello

変数が最初は空値の場合、コンパイラを思いやってください。値が空でないときに変数がどの型であるかを、どうしてコンパイラが知ることができるでしょうか？

したがって、初期値が空の Option は型を明示する必要があります。

実例

fn main() {
    let opt: Option<&str> = Option::None;
    match opt {
        Option::Some(something) => {
            println!("{}", something);
        },
        Option::None => {
            println!("opt is nothing");
        }
    }
}

実行結果：

opt is nothing

このような設計は空値プログラミングを難しくしますが、安定した効率的なシステムを構築するために必要なものです。Option は Rust コンパイラによってデフォルトで導入されるため、使用時に Option:: を省略して None や Some() と直接書くことができます。

Option は特別な列挙型であり、値を持つ分岐選択ができます。

実例

fn main() {
        let t = Some(64);
        match t {
                Some(64) => println!("Yes"),
                _ => println!("No"),
        }
}

if let 構文

実例

let i = 0;
match i {
    0 => println!("zero"),
    _ => {},
}

メイン関数に入れて実行した結果：

zero

このプログラムの目的は、i が数字の 0 であるかを判断し、そうであれば zero を出力することです。

次に、if let 構文を使用してこのコードを短縮します。

let i = 0;
if let 0 = i {
    println!("zero");
}

if let 構文の形式は次のとおりです。

if let 匹配值 = 源变量 {
    语句块
}

その後に else ブロックを追加して、例外ケースを処理できます。

if let 構文は、2つのケースだけを区別する match 文の「糖衣構文」と考えることができます（糖衣構文とは、ある構文と原理が同じで、より便利な代替品を指します）。

列挙型に対しても同様に適用できます。

実例

fn main() {
    enum Book {
        Papery(u32),
        Electronic(String)
    }
    let book = Book::Electronic(String::from("url"));
    if let Book::Papery(index) = book {
        println!("Papery {}", index);
    } else {
        println!("Not papery book");
    }
}
