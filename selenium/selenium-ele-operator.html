Selenium要素操作

Seleniumでは、要素を特定した後、クリック、テキスト入力、属性取得など、さまざまな操作を行うことができます。

以下は、Seleniumで一般的に使用される要素操作とその詳細な説明です。

操作タイプメソッド説明例
テキスト入力send_keys("text")入力ボックスまたはテキストエリアに指定したテキストを入力します。element.send_keys("testuser")
要素をクリックclick()ボタン、リンク、またはその他のクリック可能な要素をクリックします。element.click()
入力ボックスの内容をクリアclear()入力ボックスまたはテキストエリアの内容をクリアします。element.clear()
要素属性の取得get_attribute("attribute_name")要素の指定した属性値を取得します（例：value、href、classなど）。value = element.get_attribute("value")
要素テキストの取得text要素の表示されているテキスト内容を取得します。print(element.text)
チェックボックス/ラジオボタンの操作is_selected() 和 click()チェックボックスまたはラジオボタンが選択されているかどうかを確認し、選択または選択解除を行います。if not checkbox.is_selected(): checkbox.click()
ドロップダウンリスト操作Selectクラスのselect_by_index、select_by_value、select_by_visible_textインデックス、値、または表示テキストによってドロップダウンリストのオプションを選択します。dropdown.select_by_visible_text("China")
マウス操作ActionChainsクラスのclick、double_click、context_click、drag_and_drop、move_to_elementクリック、ダブルクリック、ドラッグ＆ドロップ、ホバーなどの複雑なマウス操作を実行します。actions.move_to_element(element).perform()
キーボード操作Keysクラスのsend_keys(Keys.KEY_NAME)Enterキー、Tabキー、コンビネーションキーなどのキーボード操作をシミュレートします。element.send_keys(Keys.ENTER)
ファイルアップロードsend_keys("file_path")によって<input type="file">要素を使用したファイルのアップロード。element.send_keys("/path/to/file.txt")
JavaScript の実行execute_script("javascript_code")複雑な操作やページ内容の変更のために JavaScript コードを実行します。driver.execute_script("window.scrollTo(0, document.body.scrollHeight);")

1. テキスト入力（send_keys）

自動化テストでは、入力ボックスにテキストを入力する必要がよくあります。Seleniumはsend_keysメソッドを提供してこの機能を実現します。

例

from selenium import webdriver
from selenium.webdriver.chrome.service import Service as ChromeService

# 正しいドライバーパスを設定
service = ChromeService(executable_path="./chromedriver-mac-arm64/chromedriver")
options = webdriver.ChromeOptions()
driver = webdriver.Chrome(service=service, options=options)
# ブラウザを起動
driver = webdriver.Chrome()

# ウェブページを開く
driver.get("https://example.com")

# 入力ボックス要素を特定
input_element = driver.find_element_by_name("username")

# テキストを入力
input_element.send_keys("your_username")

# ブラウザを閉じる
driver.quit()

上記のコードでは、最初に入力ボックス要素を特定し、次にsend_keysメソッドを使用して "your_username" というテキストを入力しました。

2. 要素をクリック（click）

クリック操作は自動化テストで最も一般的な操作の一つです。Seleniumはclickメソッドを提供してユーザーの要素クリックをシミュレートします。

例

# ボタン要素を特定
button_element = driver.find_element_by_id("submit-button")

# ボタンをクリック
button_element.click()

この例では、ボタン要素を特定し、clickメソッドを使用してユーザーがそのボタンをクリックする操作をシミュレートしました。

3. 入力ボックスの内容をクリア（clear）

場合によっては、入力ボックスに既にある内容をクリアしてから、新しい内容を入力する必要があります。Seleniumはclearメソッドを提供してこの機能を実現します。

例

# 入力ボックス要素を特定
input_element = driver.find_element_by_name("username")

# 入力ボックスの内容をクリア
input_element.clear()

# 新しいテキストを入力
input_element.send_keys("new_username")

この例では、最初に入力ボックスの内容をクリアし、次に新しいテキスト "new_username" を入力しました。

4. 要素属性の取得（get_attribute）

自動化テストでは、要素の属性値を取得する必要がある場合があります。Seleniumはget_attributeメソッドを提供して要素の属性を取得します。

例

# 要素を特定
element = driver.find_element_by_id("element-id")

# 要素の属性値を取得
attribute_value = element.get_attribute("class")

print(attribute_value)

この例では、要素のclass属性値を取得して、それを出力しました。

5. 要素テキストの取得（text）

要素内部のテキスト内容を取得する必要がある場合があります。Seleniumはtext属性を提供して要素のテキストを取得します。

例

# 要素を特定
element = driver.find_element_by_id("element-id")

# 要素のテキスト内容を取得
text_content = element.text

print(text_content)

この例では、要素のテキスト内容を取得して、それを出力しました。

6. チェックボックスとラジオボタンの操作

チェックボックスとラジオボタンはWebフォームで一般的な要素です。Seleniumはclickメソッドを提供してこれらの要素を操作します。

チェックボックス操作

例

# チェックボックス要素を特定
checkbox_element = driver.find_element_by_id("checkbox-id")

# チェックボックスが選択されていない場合はクリックして選択
if not checkbox_element.is_selected():
    checkbox_element.click()

この例では、まずチェックボックスがすでに選択されているかどうかを確認し、選択されていない場合はクリックして選択します。

ラジオボタン操作

例

# ラジオボタン要素を特定
radio_button_element = driver.find_element_by_id("radio-button-id")

# ラジオボタンが選択されていない場合はクリックして選択
if not radio_button_element.is_selected():
    radio_button_element.click()

ラジオボタンの操作はチェックボックスと似ており、まずラジオボタンがすでに選択されているかを確認し、選択されていない場合はクリックして選択します。

7. ドロップダウンリスト操作（Select クラス）

ドロップダウンリストはWebフォームで一般的な要素の一つです。SeleniumはSelectクラスを提供してドロップダウンリストを簡単に操作できます。

例

from selenium.webdriver.support.ui import Select

# ドロップダウンリスト要素を特定
dropdown_element = driver.find_element_by_id("dropdown-id")

# Selectオブジェクトを作成
select = Select(dropdown_element)

# 表示テキストでオプションを選択
select.select_by_visible_text("Option 1")

# 値でオプションを選択
select.select_by_value("1")

# インデックスでオプションを選択
select.select_by_index(0)

この例では、まずドロップダウンリスト要素を特定し、次にSelectクラスを使用してそれを操作します。表示テキスト、値、またはインデックスを使用して、ドロップダウンリストのオプションを選択できます。

まとめ

この記事では、Seleniumで一般的な要素操作について詳しく説明しました。テキスト入力、要素のクリック、入力ボックスの内容のクリア、要素属性とテキストの取得、チェックボックスとラジオボタンの操作、ドロップダウンリストの処理などです。これらの基本操作を習得することは、自動化テストを行う上で重要です。この記事が、Seleniumを使用したWeb自動化テストをより深く理解し、活用する助けになることを願っています。
