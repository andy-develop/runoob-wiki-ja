ionic サイドメニュー

コンテナ要素にはサイドメニューとメインコンテンツが含まれます。メインコンテンツ領域を一方からもう一方へドラッグすることで、左または右のサイドメニューを切り替えます。

イメージ図は以下の通りです：

使い方

サイドメニューを使用するには、親要素<ion-side-menus>、中間コンテンツ<ion-side-menu-content>、および1つ以上の<ion-side-menu>ディレクティブを追加します。

<ion-side-menus>
  <!-- 中间内容 -->
  <ion-side-menu-content ng-controller="ContentController">
  </ion-side-menu-content>

  <!-- 左侧菜单 -->
  <ion-side-menu side="left">
  </ion-side-menu>

  <!-- 右侧菜单 -->
  <ion-side-menu side="right">
  </ion-side-menu>
</ion-side-menus>

function ContentController($scope, $ionicSideMenuDelegate) {
  $scope.toggleLeft = function() {
    $ionicSideMenuDelegate.toggleLeft();
  };
}

API

属性 型 詳細
enable-menu-with-back-views
(オプション)
 ブール値

戻るボタンが表示されているときに、サイドメニューを有効にするかどうかを確認します。
delegate-handle 文字列 このハンドルは、$ionicScrollDelegateを持つスクロールビューを識別するために使用されます。

ion-side-menu-content

表示されるメインコンテンツのコンテナであり、同じ階層に1つ以上のionSideMenuディレクティブを持ちます。

使い方

<ion-side-menu-content
  drag-content="true">
</ion-side-menu-content>

API

属性 型 詳細
drag-content
(オプション)
 ブール値

コンテンツをドラッグできるかどうか。デフォルトはtrueです。

ion-side-menu

サイドメニューのコンテナであり、同じ階層にion-side-menu-contentディレクティブを持ちます。

使い方

<ion-side-menu
  side="left"
  width="myWidthValue + 20"
  is-enabled="shouldLeftSideMenuBeEnabled()">
</ion-side-menu>

API

属性 型 詳細
side 文字列

サイドメニューが現在どちら側にあるか。指定可能な値: 'left' または 'right'。
is-enabled
(オプション)
 ブール値

このサイドメニューが使用可能かどうか。
width
(オプション)
 数値

サイドメニューの幅（ピクセル単位）。デフォルトは275です。

menu-toggle

指定されたサイドメニューを切り替えます。

使い方

以下はナビゲーションバー内のリンクの例です。このリンクをクリックすると、指定されたサイドメニューが自動的に開きます。

<ion-view>
  <ion-nav-buttons side="left">
   <button menu-toggle="left" class="button button-icon icon ion-navicon"></button>
  </ion-nav-buttons>
 ...
</ion-view>

menu-close

現在開いているサイドメニューを閉じます。

使い方

以下はナビゲーションバー内のリンクの例です。このリンクをクリックすると、指定されたサイドメニューが自動的に開きます。

<a menu-close href="../index.html" class="item">首页</a>

$ionicSideMenuDelegate

このメソッドは$ionicSideMenuDelegateサービスを直接呼び出し、すべてのサイドメニューを制御します。$getByHandleメソッドを使用して、特定のionSideMenusを制御します。

使い方

<body ng-controller="MainCtrl">
  <ion-side-menus>
    <ion-side-menu-content>
      内容!
      <button ng-click="toggleLeftSideMenu()">
        切换左侧侧栏菜单
      </button>
    </ion-side-menu-content>
    <ion-side-menu side="left">
      左侧菜单!
    <ion-side-menu>
  </ion-side-menus>
</body>

function MainCtrl($scope, $ionicSideMenuDelegate) {
  $scope.toggleLeftSideMenu = function() {
    $ionicSideMenuDelegate.toggleLeft();
  };
}

メソッド

toggleLeft([isOpen])

左側のサイドメニューを切り替えます（存在する場合）。

パラメータ 型 詳細
isOpen
(オプション)
 ブール値

メニューを開くか閉じるか。デフォルト：メニューを切り替えます。

 
toggleRight([isOpen])

右側のサイドメニューを切り替えます（存在する場合）。

パラメータ 型 詳細
isOpen
(オプション)
 ブール値

メニューを開くか閉じるか。デフォルト：メニューを切り替えます。

 
getOpenRatio()

開いたメニュー内容のメニュー幅に対する比率を取得します。たとえば、幅100pxのメニューが50px（50%）開かれた場合、比率0.5が返されます。

戻り値：浮動小数点。0は開いていないことを示します。左側メニューが開いている、または開いている途中の場合は0〜1、右側メニューが開いている、または開いている途中の場合は0〜-1です。

isOpen()

戻り値：ブール値。左側または右側のメニューが開いているかどうかを判定します。

isOpenLeft()

戻り値：ブール値。左側メニューが開いているかどうか。

isOpenRight()

戻り値：ブール値。右側メニューが開いているかどうか。

canDragContent([canDrag])
パラメータ 型 詳細
canDrag
(オプション)
 ブール値

コンテンツをドラッグしてサイドメニューを開くことができるかどうかを設定します。

戻り値：ブール値。コンテンツをドラッグしてサイドメニューを開くことができるかどうか。

$getByHandle(handle)
パラメータ 型 詳細
handle 文字列

例：

$ionicSideMenuDelegate.$getByHandle('my-handle').toggleLeft();
