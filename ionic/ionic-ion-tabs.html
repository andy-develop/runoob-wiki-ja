ionic タブバー操作

ion-tabs

ion-tabs は、一連のページタブで構成されるタブバーです。タブをクリックしてページを切り替えることができます。

iOS では画面の下部に表示され、Android では画面の上部（ナビゲーションバーの下）に表示されます。

使い方

例

<ion-tabs class="tabs-positive tabs-icon-only"> <ion-tab title="ホーム" icon-on="ion-ios-filing" icon-off="ion-ios-filing-outline"> <!--タブ 1 の内容--> </ion-tab> <ion-tab title="概要" icon-on="ion-ios-clock" icon-off="ion-ios-clock-outline"> <!--タブ 2 の内容--> </ion-tab> <ion-tab title="設定" icon-on="ion-ios-gear" icon-off="ion-ios-gear-outline"> <!--タブ 3 の内容--> </ion-tab> </ion-tabs>

ion-tab

ionTabs に属します。

タブコンテンツを1つ含みます。そのコンテンツは、選択された特定のタブにのみ存在します。

各 ionTab には独自の閲覧履歴があります。

使い方

<ion-tab
  title="Tab!"
  icon="my-icon"
  href="../index.html"
  on-select="onTabSelected()"
  on-deselect="onTabDeselected()">
</ion-tab>

通常、クリックするとタブが選択されます。ng-Click が設定されている場合は、選択されません。$ionicTabsDelegate.select() を使用してタブの切り替えを指定できます。

$ionicTabsDelegate

ionTabs ディレクティブを制御するデリゲート。

このメソッドは $ionicTabsDelegate サービスを直接呼び出し、すべての ionTabs ディレクティブを制御します。$getByHandle メソッドを使用して、特定の ionTabs インスタンスを制御します。

使い方

<body ng-controller="MyCtrl">
  <ion-tabs>

    <ion-tab title="Tab 1">
      你好，标签1！
      <button ng-click="selectTabWithIndex(1)">选择标签2</button>
    </ion-tab>
    <ion-tab title="Tab 2">你好标签2！</ion-tab>

  </ion-tabs>
</body>

function MyCtrl($scope, $ionicTabsDelegate) {
  $scope.selectTabWithIndex = function(index) {
    $ionicTabsDelegate.select(index);
  }
}

メソッド

select(index, [shouldChangeHistory])

指定されたインデックスに一致するタブを選択します。

パラメータ タイプ 詳細
index 数値

タブを選択するためのインデックス。
shouldChangeHistory
（任意）
 ブール値

このオプションは、このタブの閲覧履歴（存在する場合）を読み込んで使用するか、またはデフォルトページのみを読み込むかを指定します。デフォルトは false です。ヒント：もしion-nav-viewタブ内にある場合、それを true に設定する必要があるかもしれません。

 
selectedIndex()

戻り値：数値、選択されたタブのインデックス。例：-1。

$getByHandle(handle)
パラメータ タイプ 詳細
handle 数値

例：

$ionicTabsDelegate.$getByHandle('my-handle').select(0);
