C# 属性（Property）

C# のプロパティ（Property）は、クラスや構造体においてデータをカプセル化するメンバーです。これらは、クラスメンバーのアクセスおよび設定ルールを定義する方法を提供し、通常はフィールド（Fields）の内部実装の詳細を隠すために使用され、同時にデータアクセスを制御するメカニズムを提供します。

プロパティはフィールドのラッパーと見なすことができ、通常は get アクセサーと set アクセサーで構成されます。

プロパティ（Property）は格納場所を決定しません。その代わり、読み取り/書き込み可能な値または計算された値を持ちます。访问器（accessors）。

たとえば、Student という名前のクラスに、age、name、code というプライベートフィールドがあるとします。クラスの外部からこれらのフィールドに直接アクセスすることはできませんが、これらのプライベートフィールドにアクセスするプロパティを持つことができます。

基本语法

public class Person
{
    private string name;

    public string Name
    {
        get { return name; }
        set { name = value; }
    }
}

上記のコードでは、Nameプロパティはプライベートフィールドをカプセル化しますname。getアクセサはフィールド値を取得するために使用され、setアクセサはフィールド値を設定するために使用されます。

自動実装プロパティ

単純なプロパティだけでよい場合は、C# では自動実装プロパティを使用できるため、フィールドを明示的に定義する必要はありません。

public class Person
{
    public string Name { get; set; }
}

この場合、コンパイラーは Name プロパティのために、値を格納するプライベートな匿名フィールドを自動的に生成します。

只读属性

読み取り専用のプロパティだけでよい場合は、set アクセサーを省略できます。

public class Person
{
    public string Name { get; }

    public Person(string name)
    {
        Name = name;
    }
}

只写属性

同様に、書き込み専用のプロパティだけでよい場合は、get アクセサーを省略できます。

public class Person
{
    private string name;

    public string Name
    {
        set { name = value; }
    }
}

自定义逻辑

get アクセサーと set アクセサーにカスタムロジックを含めることができます。

public class Person
{
    private string name;

    public string Name
    {
        get { return name; }
        set
        {
            if (string.IsNullOrWhiteSpace(value))
                throw new ArgumentException("Name cannot be empty.");
            name = value;
        }
    }
}

计算属性

プロパティは、フィールドに依存しない計算済みのものにすることもできます。

public class Rectangle
{
    public int Width { get; set; }
    public int Height { get; set; }

    public int Area
    {
        get { return Width * Height; }
    }
}

アクセサー

プロパティの访问器（accessor）プロパティの取得（読み取りまたは計算）または設定（書き込み）に役立つ実行可能ステートメントが含まれます。アクセサー（accessor）宣言には、get アクセサー、set アクセサー、またはその両方を含めることができます。例：

// string型のCodeプロパティを宣言します
public string Code
{
   get
   {
      return code;
   }
   set
   {
      code = value;
   }
}

// string型のNameプロパティを宣言します
public string Name
{
   get
   {
     return name;
   }
   set
   {
     name = value;
   }
}

// int 型の Age 属性を宣言する
public int Age
{
   get
   {
      return age;
   }
   set
   {
      age = value;
   }
}

实例

以下の例はプロパティの使用方法を示しています：

实例

using System;
namespace サンプル
{
   class Student
   {

      private string code = "N.A";
      private string name = "not known";
      private int age = 0;

      // string型のCodeプロパティを宣言します
      public string Code
      {
         get
         {
            return code;
         }
         set
         {
            code = value;
         }
      }
   
      // string型のNameプロパティを宣言します
      public string Name
      {
         get
         {
            return name;
         }
         set
         {
            name = value;
         }
      }

      // int 型の Age 属性を宣言する
      public int Age
      {
         get
         {
            return age;
         }
         set
         {
            age = value;
         }
      }
      public override string ToString()
      {
         return "Code = " + Code +", Name = " + Name + ", Age = " + Age;
      }
    }
    class ExampleDemo
    {
      public static void Main()
      {
         // 新しい Student オブジェクトを作成する
         Student s = new Student();
           
         // student の code、name と age を設定する
         s.Code = "001";
         s.Name = "Zara";
         s.Age = 9;
         Console.WriteLine("Student Info: {0}", s);
         // 增加年龄
         s.Age += 1;
         Console.WriteLine("Student Info: {0}", s);
         Console.ReadKey();
       }
   }
}

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

Student Info: Code = 001, Name = Zara, Age = 9
Student Info: Code = 001, Name = Zara, Age = 10

抽象属性（Abstract Properties）

抽象クラスは抽象プロパティを持つことができ、これらのプロパティは派生クラスで実装される必要があります。次のプログラムはこれを示しています：

实例

using System;
namespace サンプル
{
    public abstract class Person
    {
        public abstract string Name { get; set; }
        public abstract int Age { get; set; }
    }

    class Student : Person
    {
        // 自動実装プロパティを宣言します
        public string Code { get; set; } = "N.A";
        public override string Name { get; set; } = "N.A";
        public override int Age { get; set; } = 0;

        public override string ToString()
        {
            return $"Code = {Code}, Name = {Name}, Age = {Age}";
        }
    }

    class ExampleDemo
    {
        public static void Main()
        {
            // 新しい Student オブジェクトを作成する
            Student s = new Student
            {
                Code = "001",
                Name = "Zara",
                Age = 9
            };

            Console.WriteLine("Student Info:- {0}", s);
           
            // 增加年龄
            s.Age += 1;
            Console.WriteLine("Student Info:- {0}", s);

            Console.ReadKey();
        }
    }
}

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

Student Info: Code = 001, Name = Zara, Age = 9
Student Info: Code = 001, Name = Zara, Age = 10
