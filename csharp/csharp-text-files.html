C# 文本文件的读写

C# 文件的输入与输出

StreamReader 和 StreamWriterクラスはテキストファイルのデータ読み書きに使用されます。これらのクラスは抽象基底クラス Stream から継承され、Stream はファイルストリームのバイト読み書きをサポートします。

StreamReader 类

StreamReaderクラスは抽象基底クラス TextReader から継承され、リーダーが一連の文字を読み取ることを示します。

下表列出了StreamReaderクラスでよく使われるいくつかの方法：

序号メソッド & 説明
1public override void Close()
StreamReader オブジェクトと基になるストリームを閉じ、リーダーに関連するシステムリソースを解放します。
2public override int Peek()
使用可能な次の文字を返しますが、使用しません。
3public override int Read()
入力ストリームから次の文字を読み取り、文字位置を1文字進めます。

完全なメソッド一覧については、マイクロソフトの C# ドキュメントを参照してください。

实例

以下の例は、Jamaica.txt という名前のファイルを読み取ることを示しています。ファイルは次のとおりです。

Down the way where the nights are gay
And the sun shines daily on the mountain top
I took a trip on a sailing ship
And when I reached Jamaica
I made a stop

using System;
using System.IO;

namespace FileApplication
{
    class Program
    {
        static void Main(string[] args)
        {
            try
            {
                // 创建一个 StreamReader 的实例来读取文件 
                // using 语句也能关闭 StreamReader
                using (StreamReader sr = new StreamReader("c:/jamaica.txt", Encoding.UTF8))
                {
                    string line;
                   
                    // 从文件读取并显示行，直到文件的末尾 
                    while ((line = sr.ReadLine()) != null)
                    {
                        Console.WriteLine(line);
                    }
                }
            }
            catch (Exception e)
            {
                // 向用户显示出错消息
                Console.WriteLine("The file could not be read:");
                Console.WriteLine(e.Message);
            }
            Console.ReadKey();
        }
    }
}

上記のプログラムをコンパイルして実行すると、ファイルの内容が表示されます。

StreamWriter 类

StreamWriterクラスは抽象クラス TextWriter から継承され、ライターが一連の文字を書き込むことを示します。

下表列出了StreamWriterクラスでよく使われるいくつかの方法：

序号メソッド & 説明
1public override void Close()
現在の StreamWriter オブジェクトと基になるストリームを閉じます。
2public override void Flush()
現在のライターのすべてのバッファーをクリアし、バッファーされたすべてのデータが基になるストリームに書き込まれるようにします。
3public virtual void Write(bool value)
ブール値のテキスト表現をテキスト文字列またはストリームに書き込みます。(TextWriter から継承。)
4public override void Write( char value )
1つの文字をストリームに書き込みます。
5public virtual void Write( decimal value )
10進値のテキスト表現をテキスト文字列またはストリームに書き込みます。
6public virtual void Write( double value )
8バイト浮動小数点値のテキスト表現をテキスト文字列またはストリームに書き込みます。
7public virtual void Write( int value )
4バイト符号付き整数のテキスト表現をテキスト文字列またはストリームに書き込みます。
8public override void Write( string value )
1つの文字列をストリームに書き込みます。
9public virtual void WriteLine()
行終端記号をテキスト文字列またはストリームに書き込みます。

完全なメソッド一覧については、マイクロソフトの C# ドキュメントを参照してください。

实例

次の例では、StreamWriter クラスを使用してファイルにテキストデータを書き込む方法を示しています。

using System;
using System.IO;

namespace FileApplication
{
    class Program
    {
        static void Main(string[] args)
        {

            string[] names = new string[] {"Zara Ali", "Nuha Ali"};
            using (StreamWriter sw = new StreamWriter("names.txt"))
            {
                foreach (string s in names)
                {
                    sw.WriteLine(s);

                }
            }

            // 从文件中读取并显示每行
            string line = "";
            using (StreamReader sr = new StreamReader("names.txt"))
            {
                while ((line = sr.ReadLine()) != null)
                {
                    Console.WriteLine(line);
                }
            }
            Console.ReadKey();
        }
    }
}

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

Zara Ali
Nuha Ali

    中国語を読み取ると文字化けが表示される場合は、ファイルの内容を読み取るときに次を使用します：

    using (StreamReader sr = new StreamReader("C:/a.txt", Encoding.GetEncoding("GB2312")))

    その後、コンパイル時にエラーが発生し、コンパイルできません。

    エラーが発生した場合の解決策は次のとおりです：

    第一：

    using System.Text;

    第二：

    .csproj ファイルに次のコードを追加する必要があります：

    <ItemGroup>
    <PackageReference Include="System.Text.Encoding.CodePages" Version="4.4.0" />
</ItemGroup

    第三步：

    在使用System.Text.Encoding.GetEncoding ("GB2312")その前に、コード内で以下を実行します：

    System.Text.Encoding.RegisterProvider (System.Text.CodePagesEncodingProvider.Instance);

    登録が完了すると、GB2312 エンコーディングオブジェクトを取得してもエラーは発生せず、その中の関数を正常に使用できます。
