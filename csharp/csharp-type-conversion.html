C# 类型转换

C#では、型変換とは、あるデータ型の値を別のデータ型に変換するプロセスのことです。

C#の型変換は2つの種類に分類できます：暗黙の型変換和明示的な型変換（キャストとも呼ばれる）。

暗黙の型変換

暗黙的変換は、コードを記述して指定する必要がない変換で、コンパイラが自動的に行います。

暗黙的変換とは、より小さい範囲のデータ型をより大きい範囲のデータ型に変換する際に、コンパイラが自動的に型変換を完了することを指します。これらの変換はC#のデフォルトの安全な方法で行われる変換であり、データ損失を引き起こしません。

例えば、int から long、float から double など。

小さい整数型から大きい整数型への変換、派生クラスから基底クラスへの変換です。byte型の変数をint型の変数に代入する場合、コンパイラは自動的にbyte型をint型に変換するため、明示的な変換は不要です。

实例

byte b = 10;
int i = b; // 隐式转换，不需要显式转换

整数を長整数に代入する場合や、浮動小数点数を倍精度浮動小数点数に代入する場合、この変換はデータ損失を引き起こしません：

实例

int intValue = 42;
long longValue = intValue; // 隐式转换，从 int 到 long

显式转换

明示的型変換、すなわちキャストは、プログラマがコード内で明確に指定する必要があります。

明示的変換とは、より大きい範囲のデータ型をより小さい範囲のデータ型に変換する場合、またはあるオブジェクト型を別のオブジェクト型に変換する場合に、キャスト演算子を使用して明示的に変換する必要があることを指します。キャストはデータ損失を引き起こす可能性があります。

例えば、int型の変数をbyte型の変数に代入する場合、明示的な変換が必要です。

实例

int i = 10;
byte b = (byte)i; // 显式转换，需要使用强制类型转换符号

整数型への強制変換：

实例

double doubleValue = 3.14;
int intValue = (int)doubleValue; // 强制从 double 到 int，数据可能损失小数部分

浮動小数点型への強制変換：

实例

int intValue = 42;
float floatValue = (float)intValue; // 强制从 int 到 float，数据可能损失精度

文字列型への強制変換：

实例

int intValue = 123;
string stringValue = intValue.ToString(); // 将 int 转换为字符串

以下の例は、明示的な型変換を示しています：

实例

using System;

namespace TypeConversionApplication
{
    class ExplicitConversion
    {
        static void Main(string[] args)
        {
            double d = 5673.74;
            int i;

            // 强制转换 double 为 int
            i = (int)d;
            Console.WriteLine(i);
            Console.ReadKey();
           
        }
    }
}

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

5673

型変換を実行する際には、以下の点に注意する必要があります：

  • 暗黙的変換は、より小さい範囲のデータ型をより大きい範囲のデータ型にのみ変換でき、より大きい範囲のデータ型をより小さい範囲のデータ型に変換することはできません。
  • 明示的変換はデータ損失や精度の低下を引き起こす可能性があるため、データ型の互換性チェックが必要です。
  • オブジェクト型の変換については、型変換の互換性チェックと型変換の安全性チェックが必要です。

型変換メソッド

C# は、Convert クラス、Parse メソッド、TryParse メソッドなど、さまざまな型変換メソッドを提供しています。これらのメソッドは、異なるデータ型間の変換を処理するのに役立ちます。

Convert クラスの使用

Convertクラスは、さまざまな基本データ型間で変換を行うための一連の静的メソッドを提供します。

实例

string str = "123";
int num = Convert.ToInt32(str);

Parse メソッドの使用

Parseメソッドは、文字列を対応する数値型に変換するために使用され、変換に失敗した場合は例外をスローします。

实例

string str = "123.45";
double d = double.Parse(str);

TryParse メソッドの使用

TryParseメソッドはParseに似ていますが、例外をスローせず、変換が成功したかどうかを示すブール値を返します。

实例

string str = "123.45";
double d;
bool success = double.TryParse(str, out d);

if (success) {
    Console.WriteLine("转换成功: " + d);
} else {
    Console.WriteLine("转换失败");
}

カスタム型変換

C#では、型内にimplicitまたはexplicitキーワードを定義することで、カスタム型変換操作を定義することもできます。

实例

using System;

public class Fahrenheit
{
    public double Degrees { get; set; }

    public Fahrenheit(double degrees)
    {
        Degrees = degrees;
    }

    // 隐式转换从Fahrenheit到double
    public static implicit operator double(Fahrenheit f)
    {
        return f.Degrees;
    }

    // 显式转换从double到Fahrenheit
    public static explicit operator Fahrenheit(double d)
    {
        return new Fahrenheit(d);
    }
}

public class Program
{
    public static void Main()
    {
        Fahrenheit f = new Fahrenheit(98.6);
        Console.WriteLine("Fahrenheit object: " + f.Degrees + " degrees");

        double temp = f; // 隐式转换
        Console.WriteLine("After implicit conversion to double: " + temp + " degrees");

        Fahrenheit newF = (Fahrenheit)temp; // 显式转换
        Console.WriteLine("After explicit conversion back to Fahrenheit: " + newF.Degrees + " degrees");
    }
}

上記の例では、Fahrenheitクラスを定義し、Fahrenheitからdoubleへの暗黙的変換と、doubleからFahrenheitへの明示的変換を実装しました。

出力結果は次のように表示されます：

Fahrenheit object: 98.6 degrees
After implicit conversion to double: 98.6 degrees
After explicit conversion back to Fahrenheit: 98.6 degrees

总结

C#では、組み込みの型変換メソッドは主に以下の方法で実装されます：暗黙的変換、明示的変換（キャスト）、Convertクラスのメソッドの使用、Parseメソッド、TryParseメソッドです。これらのメソッドは、異なるデータ型間の変換に広く使用されています。

    暗黙の変換と明示的な変換

    暗黙的変換：C#のデフォルトの安全な方法で行われる変換です。本質的には、小さい記憶容量のデータ型から大きい記憶容量のデータ型への自動変換、および派生クラスから基底クラスへの変換です。

    }

    {

    Convert.ToInt32() 与 int.Parse() 的区别

    没搞清楚Convert.ToInt32 和 int.Parse()の微妙な違いを理解せずにむやみに使ってはいけません。そうしないと予期しない結果を生じる可能性があります。例えば、URL からパラメータ page の値を取得する場合、この値が int であることがわかっているので、Convert.ToInt32(Request.QueryString["page"])，也可以用int.Parse(Request.QueryString["page"])しかし、pageパラメータがURLに存在しない場合、前者は0を返します。0は有効な値である可能性があるため、URLにそもそもこのパラメータが存在しないことに気づかずに次の処理を続行してしまい、予期しない結果が生じる可能性があります。一方、後者の方法ではpageパラメータがない場合に例外がスローされるため、例外をキャッチして適切な処理を行うことができます。例えば、パラメータ値を0として扱うのではなく、パラメータが不足していることをユーザーに通知する、といった処理です。

    (1) これら2つのメソッドの最大の違いは、null値の処理方法です：Convert.ToInt32(null)は0を返し、例外は発生しませんが、int.Parse(null)例外が発生します。

    (2) データを四捨五入する際の違い

    • a.Convert.ToInt32(double value) は、valueが2つの整数の中間の数値である場合、2つのうちの偶数を返します。つまり、3.5は4に、4.5は4に、5.5は6に変換されます。ただし、4.6は5に、4.4は4に変換されます。
    • b.int.Parse("4.5") 直接报错:「入力文字列の形式が正しくありません」。
    • c.int(4.6) = 4。Intは他の数値型をIntに変換する際、四捨五入は行わず、強制的に変換します。

    (3) 変換対象の型による違いint.ParseString を int に変換することです、Convert.ToInt32は、Objectから継承されたオブジェクトをintに変換するものです（他の多くの型のデータも可能です）。objectオブジェクトを取得し、それをintに変換したい場合に使用します。int.Parseそれができない場合は、使用する必要がありますConvert.ToInt32。

    string から int への変換と例外についての簡単な説明

    string文字列型とintも変換可能です。次の行のコードは誤った変換方法を示しています。

    string a = "123";  // 将a设置为字符串“123”
int x = (int) a;   // 转换

    上記のコードは、間違いなく誤りです。VSではコンパイルが通りません。では、stringをintに変換するにはどうすればよいでしょうか？

    ここでは、int.Parse()を使用する必要があります。核心となるコードは次のとおりです：

    string a = "123";     // 将a设置为字符串“123”
int x = int.Parse(a); // 转换

    それだけなら問題ありませんが、さらに別の例を見てみましょう。

    ユーザーが数値を入力すると、コンピューターはその数値に1を加えた答えを計算して表示します。

    ユーザーが入力したもの、つまりConsole.ReadLine()、必ず文字列形式で表現されます。

    そこで、前述の方法を使用して、以下のコードを書くことができます：

    class 测试
{
    static void Main(string[] args)
    {
        Console.WriteLine("输入数字，将计算出它加一的答案");
        int a = int.Parse(Console.ReadLine());  //转换用户输入的数字
        Console.WriteLine("答案是{0}",++a);     //++a 即 a+1 后的那个数，将它输出出来
        Console.ReadKey();
    }
}

    プログラムを実行すると、次のように表示されます：

    输入数字，将计算出它加一的答案
3
答案是4

    これで完璧でしょうか？いいえ！！

    ユーザーが数字以外の文字（漢字など）を入力した場合は、何が起こるでしょうか？

    このとき、ユーザーが入力すると王、明らかにプログラムは実行を継続できなくなります。int 型は整数しか格納できず、文字を格納できないからです。

    この時点で、プログラムは例外をスローします。

    VSで実行すると、FormatExceptionという例外タイプも表示されます。

    そのため、安全を期すために、try、catchを使用してこの問題を解決できます。核心となるコードは次のとおりです：

    try
{
               
}
catch (Exception)
{
                
}

    try は英語で「試す」という意味です。このコードでは、try{} の部分は、その名の通り、次のコードの実行を試みます。catch{} の部分は、例外を検出します。これにより、例外が発生した場合、catch が例外を捕捉できるため、プログラムは停止しません。

    このプログラムの完全なコードは次のようになります：

    using System;
class 测试
{
    static void Main(string[] args)
    {
        try
        {
           Console.WriteLine("输入数字，将计算出它加一的答案");
           int a = int.Parse(Console.ReadLine());   //有可能会抛出异常
           Console.WriteLine("答案是{0}",++a);   //如果没有异常，程序才会进入这一步
        }
        catch (Exception)
        {
            Console.WriteLine("无法转换");  //如果捕获到异常，就说“无法转换”
        }
         Console.ReadKey();
    }
}

    このように、もし私が入力した場合は王、プログラムの結果は次のとおりです：

    変換できません。

    77

    1）変換対象について、Convert.ToInt32()は複数の型に対応できます（数値型のほか、bool、DateTimeなど）。int.TryParse()とint.Parse()は整数型の文字列のみに対応できます（つまり、各種整数型をToString()した後の形式であり、浮動小数点型は不可。それ以外の場合、int.Parse()では入力された文字列の形式が正しくないというエラーが発生し、int.TryParse()もfalseを返し、出力パラメータは0になります）。(int)は数値型のみに対応できます（例：float、int、uintなど）。

    2）空値 NULL について、実行時エラーの観点から見ると、(int) キャストと int.Parse() はどちらも NULL を受け付けません。Convert.ToInt32() は実際には変換前に判断を行い、パラメータが NULL の場合は直接 0 を返し、それ以外の場合は int.Parse() を呼び出して変換します。int.TryParse() は実際には int.Parse() に対する例外処理であり、例外が発生した場合は false を返し、出力パラメータには 0 を返します。

    3）浮動小数点型の丸め処理についてですが、浮動小数点型は Convert.ToInt32() と (int) のみ変換できますが、これらも丸めが行われます。Convert.ToInt32() は四捨五入を行い、(int) は浮動小数点型の整数部分を切り取り、小数部分を無視します。例えば、Convert.ToInt32(1.499d) と (int)1.499d はどちらも 1 を返し、Convert.ToInt32(1.5d) は 2 を返しますが、(int)1.5d は依然として 1 を返します。

    4）オーバーフローについてですが、大きいデータ型から小さいデータ型へ変換する際、Convert.ToInt32() と int.Parse() はどちらもオーバーフローエラーを報告します。値が Int32 に対して大きすぎるか小さすぎるためです。一方、(int) はエラーを報告しませんが、戻り値は -1 になります。

    このように、データ変換を行う前に変換方法を慎重に選択する必要があります。数値型の場合は (int) によるキャストを直接検討できます。整数を表す文字列型の場合は int.Parse() による変換を検討します。これらのどちらでもない場合は、Convert.ToInt32() による変換を検討します。
