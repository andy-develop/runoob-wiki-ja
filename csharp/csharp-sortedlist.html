C# 排序列表（SortedList）

C# 集合

C# では、SortedList（ソート済みリスト）はキーによって自動的にソートされるコレクションであり、キーと値のペアでデータを格納し、追加または更新時にキーの順序（昇順）に従って自動的にソートされます。

SortedList クラスは、キーによって並べ替えられた一連のキーと値のペアを表します。key => valueこれらのキーと値のペアは、キーとインデックスを使用してアクセスできます。

ソート済みリストは、配列とハッシュテーブルの組み合わせです。キーまたはインデックスを使用して項目にアクセスできるリストが含まれます。インデックスを使用して項目にアクセスする場合は動的配列（ArrayList）であり、キーを使用して項目にアクセスする場合はハッシュテーブル（Hashtable）です。コレクション内の項目は常にキー値によって並べ替えられています。

SortedList には2つのバージョンがあります：

  1. 非泛型SortedList（System.Collections.SortedList）
  2. 泛型SortedList<TKey, TValue>（System.Collections.Generic.SortedList<TKey, TValue>）

特点:

  • 自动排序：すべてのキーは昇順に並べ替えられており、並べ替えメソッドを手動で呼び出す必要はありません。
  • キーと値のペアの格納：各キーは一意であり、関連付けられた値は重複することができます。
  • 動的に容量を調整する：必要に応じて内部ストレージのサイズを自動的に調整します。
  • 索引访问：キーまたはインデックスによってデータにアクセスします。
  • 高效操作：検索、挿入、削除の平均時間計算量は O(log n) です。

实例

以下の例は、ソート済みリスト（SortedList）の概念を示しています。

非ジェネリック版の操作：

实例

using System;
using System.Collections;

namespace CollectionsApplication
{
   class Program
   {
      static void Main(string[] args)
      {
         SortedList sl = new SortedList();

         sl.Add("001", "Zara Ali");
         sl.Add("002", "Abida Rehman");
         sl.Add("003", "Joe Holzner");
         sl.Add("004", "Mausam Benazir Nur");
         sl.Add("005", "M. Amlan");
         sl.Add("006", "M. Arif");
         sl.Add("007", "Ritesh Saikia");

         if (sl.ContainsValue("Nuha Ali"))
         {
            Console.WriteLine("This student name is already in the list");
         }
         else
         {
            sl.Add("008", "Nuha Ali");
         }

         // キーの集合を取得
         ICollection key = sl.Keys;

         foreach (string k in key)
         {
            Console.WriteLine(k + ": " + sl[k]);
         }
      }
   }
}

上記のコードをコンパイルして実行すると、次の結果が生成されます：

001: Zara Ali
002: Abida Rehman
003: Joe Holzner
004: Mausam Banazir Nur
005: M. Amlan 
006: M. Arif
007: Ritesh Saikia
008: Nuha Ali

泛型版:

实例

using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        // 创建泛型 SortedList
        SortedList<int, string> sortedList = new SortedList<int, string>();

        // キーと値のペアを追加
        sortedList.Add(2, "Banana");
        sortedList.Add(1, "Apple");
        sortedList.Add(3, "Cherry");

        // 自动按键排序
        Console.WriteLine("SortedList contents:");
        foreach (var kvp in sortedList)
        {
            Console.WriteLine($"Key: {kvp.Key}, Value: {kvp.Value}");
        }

        // 検索とアクセス
        Console.WriteLine($"\nValue for key 2: {sortedList[2]}"); // 输出：Banana

        // 删除元素
        sortedList.Remove(1);
        Console.WriteLine("\nAfter removing key 1:");
        foreach (var kvp in sortedList)
        {
            Console.WriteLine($"Key: {kvp.Key}, Value: {kvp.Value}");
        }

        // キーと値を確認
        Console.WriteLine($"\nContains key 3: {sortedList.ContainsKey(3)}"); // 输出：True
        Console.WriteLine($"Contains value 'Apple': {sortedList.ContainsValue("Apple")}"); // 输出：False
    }
}
