C# 列挙型（Enum）

列挙型は、名前付き整数定数のセットです。列挙型は、enumキーワードを使用して宣言されます。

C# の列挙型は値型です。言い換えれば、列挙型は独自の値を持ち、継承することも継承させることもできません。

宣言enum変数

列挙型を宣言する一般的な構文：

enum <enum_name>
{ 
    enumeration list 
};

ここで、

  • enum_name列挙型の型名を指定します。
  • enumeration listはカンマで区切られた識別子のリストです。

列挙リストの各シンボルは整数値を表し、その前のシンボルより大きい整数値です。既定では、最初の列挙シンボルの値は 0 です。例：

enum Days { Sun, Mon, tue, Wed, thu, Fri, Sat };

サンプル

以下のサンプルは、列挙型変数の使い方を示しています。

サンプル

using System;

public class EnumTest
{
    enum Day { Sun, Mon, Tue, Wed, Thu, Fri, Sat };

    static void Main()
    {
        int x = (int)Day.Sun;
        int y = (int)Day.Fri;
        Console.WriteLine("Sun = {0}", x);
        Console.WriteLine("Fri = {0}", y);
    }
}

上記のコードがコンパイルされ実行されると、次の結果が生成されます。

Sun = 0
Fri = 5

    列挙体は、配列内の特定のインデックス位置に意味を与えるために使用され、プログラムをより読みやすく、修正しやすくします。

    enum len  { Length, width, height};

static void Main(string[] args)
{
    int[] parameter = new int[3] {1,5,8};
    Console.WriteLine("Length: {0}", parameter[(int)len.Length]);
    Console.WriteLine("width: {0}", parameter[(int)len.width]);
    Console.WriteLine("height: {0}", parameter[(int)len.height]);
}

    このとき、出力される値がパラメータの長さ・幅・高さであることを一目で確認できます。

    使用する場合と比較して

    #define length 0
#define width  1
#define height 2

    この方法は、パラメータを 1 つ挿入する場合により便利です：

    #define area   0
#define length 1
#define width  2
#define height 3

enum len  {area, Length, width, height};

    明らかに、Enum 方式を使用する方が変更しやすいです。

    ビットフラグ列挙型（flags enumeration）

    実際には、常に離散値の列挙型を使うとは限りません。1週間の7日を例にとります。アプリケーションのユーザーに、1週間の各日の任意の組み合わせを指定させる必要があるとします。その場合、「ビットフラグ列挙型」を使用できます。ビットフラグ列挙型を使用するときは、OR演算を使用して新しい組み合わせ値を作成できます。曜日を例にとると、宣言方法は次のとおりです：

    [Flags]
public enum Days
{
    None = 0,
    Sunday = 0x01,          //0000 0001
    Monday = 0x02,          //0000 0010
    Tuesday = 0x04,         //0000 0100
    Wednesday = 0x08,       //0000 1000
    Thursday = 0x10,        //0001 0000
    Friday = 0x20,          //0010 0000
    Saturday = 0x40,        //0100 0000
    Weekend = Sunday | Saturday,     //0100 0001
    Workdays = Monday | Tuesday | Wednesday | Tuesday | Friday, //0011 1110
}

    ビットフラグ列挙型の値を組み合わせられるようにするには、すべての値を 2 の累乗にする必要があります。複数の値を組み合わせた場合に、結果がどの離散値になるかを特定できなければならないためです。

    単純な列挙型では、名前 None または最も一般的な既定の名前を 0 に対応させることができますが、フラグ列挙型では、0 が名前 None に対応することが要求されます。この値は、すべてのフラグが設定されていないことを意味します。

    実行：

    Days days = Days.Weekend;
Console.WriteLine("{0} : {1}",days,(int)days);

    結果出力：

    Weekend : 65

    列挙リストの各シンボルは整数値を表し、その前のシンボルより大きい整数値です。既定では、最初の列挙シンボルの値は 0 です。ただし、各シンボルの値を設定することもできます。シンボル n に値を設定しなかった場合、その値はシンボル (n-1)+1 です。例えば、列挙シンボル g を考えます。その値はシンボル f の値 +1 ですが、f の値がわからないため、(n-1) 番目のシンボル、つまり e の値を探します。このようにして、c の値 1 を見つけ、e=c+1=2、f=e+1=3、g=f+1=4 となります。

    using System;

class Program
{
    enum Day  {a=8,b,c=1,e,f,g};
    static void Main(string[] args)
    {
            int a = (int)Day.a;//8
            int x = (int)Day.b;//9
            int c = (int)Day.c;//1
            int b = (int)Day.e;//2
            int g = (int)Day.g;//4
    }
}

    既定では、最初の列挙シンボルの値は 0 です。

    using System;

class Program
{
    enum Day  { a, b, c, e = 1, f, g };
    static void Main(string[] args)
    {
            int a = (int)Day.a;//0
            int x = (int)Day.b;//1
            int c = (int)Day.c;//2
            int b = (int)Day.e;//1
            int g = (int)Day.g;//3
    }
}

    列挙型の各数値は整数型です。どの要素にも値を代入しなければ、既定では 0 から始まり 1 ずつ増加します。すべてに値を代入した場合は、上でノートを共有した方がすでに説明しているので言うまでもありません。列挙要素の途中（先頭や末尾ではない要素）に値を代入する場合について述べたいと思います。例として、列挙要素の N 番目に a を代入したとします。実行結果は Mon=1、Fri=22 です。したがって、代入した要素より前の要素は、依然として既定の代入規則に従い、0 から始まり 1 インクリメントで N-1 番目まで増加します。しかし、代入した N 番目からは、その値 a を起点として 1 ずつ増加します。すなわち、a+1, a+2, a+3... となります。

    using System;
public class EnumTest
{
    enum Day {  Sun, Mon, Tue=19, Wed, Thu, Fri, Sat };  /*列举其中的元素*/
    static void Main()
    {
        int x = (int)Day.Mon;
        int y = (int)Day.Fri;
        Console.WriteLine("Mon = {0}", x);   /*一般数组中默认的数值第一个就是0，其后是一次增大的，但是也是可以对数组中的每个元素进行赋值*/
        Console.WriteLine("Fri = {0}", y);
        Console.ReadKey();
    }
}

    • 列挙型は一種の型です。
    • 値の範囲が限られているデータに適しています。例えば、春夏秋冬という4つの文字の範囲だけを扱いたい場合、string を使うと値の範囲を固定できません。
    • 列挙型の構文：[アクセス修飾子] enum 列挙型名 { 列挙値 }
    • 列挙型のアクセス修飾子はクラスと同じです。既定のアクセス権限もクラスと同じく internal です。
    • 列挙型名はアッパーキャメルケース（パスカルケース）に従います。
    • 列挙型の各値はすべて整数型で、既定ではすべて 0 から始まります。

    上記の特徴は上のノートでほぼ述べられているので、あと2点あります。

    • 1、列挙型の要素の値は同じに設定できますが、推奨されません。
    • 2、列挙要素の既定の値の型は int 型ですが、他の整数型 byte、sbyte、short、ushort、int、uint、long、ulong に変更できます。
    public enum Season_1
{
    spring_1 = 3,  //3
    sunmmer_1,     //4
    autumn_1 = 3,  //3
    winter_1       //4
}
public enum Season_2 : long  //将枚举默认类型int改为long
{
    spring_2,  //0
    sunmmer_2, //1
    autumn_2,  //2
    winter_2   //3
}
class Program
{
    static void Main(string[] args)
    {
      Season_1 s2 = Season_1.autumn_1;
      Console.WriteLine(s2);  //显示spring_1，而不是autumn_1的原因是spring_1和autumn_1都是3，从前往后                                  //第一个3是spring_1，所以就输出spring_1
      Season_1 s3 = Season_1.spring_1;
        Console.WriteLine(s2 == s3);  //结果是true，表明spring_1和autumn_1是一样的
    }
 }

    public enum CustomType  // 如果是类外写，按照命名规则我们最好在后边加上 Type 字样

  Fri, 
  Sat

public class EnumTest
{   
  CustomType Day  = CustomType.Sun;

    列挙ビットフラグを使用すると、複数の列挙値を単一の値に組み合わせることができます。列挙ビットフラグと言えば、Flags 属性に触れないわけにはいきません。

    簡単に言うと、列挙型をよりスマートにし、ビットフラグの値に対してよりスマートな書式設定を提供します。例：

    public enum a:byte
{
    None=0b_0000_0000,
    apple=0b_0000_0001,
    banana=0b_0000_0010,
    watermelon=0b_0000_0100,
    pineapple=0b_0000_1000  
}

    apple と banana を一緒に設定すると、コンパイラは 3 を出力します。しかし、Flags を追加すると、コンパイラはこれが 1+2=3 であることを認識し、apple と banana を出力します。

    using System;
namespace HelloWorldApplication
{
   class A
   {
       [Flags]
           public enum a:byte//这种格式的值大家应该都看得懂的吧，对吧
       {
           None=0b_0000_0000,
           apple=0b_0000_0001,
           banana=0b_0000_0010,
           watermelon=0b_0000_0100,
           pineapple=0b_0000_1000  
       }
      static void Main(string[] args)
      {
          a bb=a.apple|a.banana;//设置多个位标志
         Console.WriteLine(bb);
         Console.ReadKey();
      }
   }
}

    ビットOR（|）を使用して複数のビットフラグを設定します：

    a bb=a.apple|banana|watermelon;

    ビットAND（&）を使用して、特定のビットが設定されているかどうかを確認することもできます。

    a bb=a.banana|a.watermelon;
bool cha=(bb&a.apple)==a.apple;
