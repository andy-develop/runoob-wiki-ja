C# 运算符

演算子は、コンパイラに特定の数学的または論理的な操作を実行するように指示する記号です。C# には豊富な組み込み演算子があり、次のように分類されます。

  • 算术运算符
  • 关系运算符
  • 逻辑运算符
  • 位运算符
  • 赋值运算符
  • 其他运算符

このチュートリアルでは、算術演算子、関係演算子、論理演算子、ビット演算子、代入演算子、およびその他の演算子について順に説明します。

算术运算符

次の表は、C# がサポートするすべての算術演算子を示しています。変数 A、B を仮定します。Aの値は10、変数Bの値は20、その場合：

运算符描述实例
+2つのオペランドを加算するA + B は 30 になります
-最初のオペランドから2番目のオペランドを減算します。A - B は -10 になります
*2つのオペランドを乗算するA * B は 200 になります
/分子を分母で割るB / A は 2 になります

实例

次の例を見て、C# で使用可能なすべての算術演算子を理解してください：

实例

using System;

namespace OperatorsAppl
{
    class Program
    {
        static void Main(string[] args)
        {
            int a = 21;
            int b = 10;
            int c;

            c = a + b;
            Console.WriteLine("Line 1 - c 的值是 {0}", c);
            c = a - b;
            Console.WriteLine("Line 2 - c 的值是 {0}", c);
            c = a * b;
            Console.WriteLine("Line 3 - c 的值是 {0}", c);
            c = a / b;
            Console.WriteLine("Line 4 - c 的值是 {0}", c);
            c = a % b;
            Console.WriteLine("Line 5 - c 的值是 {0}", c);

            // ++a 先进行自增运算再赋值
            c = ++a;
            Console.WriteLine("Line 6 - c 的值是 {0}", c);

            // 此时 a 的值为 22
            // --a 先进行自减运算再赋值
            c = --a;
            Console.WriteLine("Line 7 - c 的值是 {0}", c);
            Console.ReadLine();
        }
    }
}

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

Line 1 - c 的值是 31
Line 2 - c 的值是 11
Line 3 - c 的值是 210
Line 4 - c 的值是 2
Line 5 - c 的值是 1
Line 6 - c 的值是 22
Line 7 - c 的值是 21
  • c = a++: 最初に a を c に代入し、その後 a をインクリメントします。
  • c = ++a: 最初に a をインクリメントし、その後 a を c に代入します。
  • c = a--: 最初に a を c に代入し、その後 a をデクリメントします。
  • c = --a: 最初に a をデクリメントし、その後 a を c に代入します。

实例

using System;

namespace OperatorsAppl
{
    class Program
    {
        static void Main(string[] args)
        {
            int a = 1;
            int b;

            // a++ 先赋值再进行自增运算
            b = a++;
            Console.WriteLine("a = {0}", a);
            Console.WriteLine("b = {0}", b);
            Console.ReadLine();

            // ++a 先进行自增运算再赋值
            a = 1; // 重新初始化 a
            b = ++a;
            Console.WriteLine("a = {0}", a);
            Console.WriteLine("b = {0}", b);
            Console.ReadLine();

            // a-- 先赋值再进行自减运算
            a = 1;  // 重新初始化 a
            b= a--;
            Console.WriteLine("a = {0}", a);
            Console.WriteLine("b = {0}", b);
            Console.ReadLine();

            // --a 先进行自减运算再赋值
            a = 1;  // 重新初始化 a
            b= --a;
            Console.WriteLine("a = {0}", a);
            Console.WriteLine("b = {0}", b);
            Console.ReadLine();
        }
    }
}

关系运算符

运算符描述实例
==2つのオペランドの値が等しいかどうかをチェックし、等しい場合は条件が真になります。(A == B) は真ではありません。

<=左オペランドの値が右オペランドの値以下かどうかをチェックし、そうである場合は条件が真になります。(A <= B) 为真。

运算符描述实例
&&論理積演算子と呼ばれます。両方のオペランドが非ゼロの場合、条件は真になります。(A && B) 为假。
||論理和演算子と呼ばれます。2つのオペランドのいずれかが非ゼロの場合、条件は真になります。(A || B) 为真。

位运算符

ビット演算子はビットに対して作用し、ビット単位で操作を実行します。&、|、^ の真理値表は次のとおりです。

pqp & qp | qp ^ q
00000
01011
11110
10011

A = 60、B = 13 と仮定します。2進数形式で表すと、次のようになります。

A = 0011 1100

B = 0000 1101

-----------------

A&B = 0000 1100

A|B = 0011 1101

A^B = 0011 0001

~A  = 1100 0011

次の表は、C# がサポートするビット演算子を示しています。変数 A=60、B=13 を仮定します。Aの値は60、変数Bの値は13、その場合：

运算符描述实例
&両方のオペランドに存在する場合、バイナリ AND 演算子は1ビットを結果にコピーします。(A & B) 将得到 12，即为 0000 1100
|いずれかのオペランドに存在する場合、バイナリ OR 演算子は1ビットを結果にコピーします。(A | B) 将得到 61，即为 0011 1101
^いずれか一方のオペランドに存在するが両方には存在しない場合、バイナリ XOR 演算子は1ビットを結果にコピーします。(A ^ B) 将得到 49，即为 0011 0001
~ビット否定演算子は単項演算子であり、ビットを「反転」させる効果があります。つまり、0 は 1 に、1 は 0 になります。符号ビットも含みます。(~A) は -61 になります。これは 1100 0011、つまり符号付き2進数の補数形式です。
<<2進左シフト演算子。左オペランドの値を、右オペランドで指定されたビット数だけ左にシフトします。A << 2 将得到 240，即为 1111 0000
>>2進右シフト演算子。左オペランドの値を、右オペランドで指定されたビット数だけ右にシフトします。A >> 2 将得到 15，即为 0000 1111

C# における演算子の優先順位

演算子の優先順位は、式内の項の組み合わせ方を決定します。これは式の評価方法に影響します。一部の演算子は他の演算子よりも優先順位が高くなります。たとえば、乗算除算演算子は加算減算演算子よりも優先順位が高くなります。

たとえば x = 7 + 3 * 2 の場合、演算子 * は + よりも優先順位が高いため、最初に乗算 3 * 2 が計算され、その後 7 が加算されます。したがって、x には 20 ではなく 13 が代入されます。

次の表は、演算子の優先順位を高い順から低い順に示しています。優先順位の高い演算子は表の上部に表示され、優先順位の低い演算子は表の下部に表示されます。式内では、優先順位の高い演算子が先に評価されます。

優先順位の簡易まとめ: 括弧があれば括弧が先、次に乗算・除算、そして加算・減算、その後シフト、次に関係、論理が終わったら条件、最後はカンマ。, 。

一元 + - ! ~ ++ - - (type)* & sizeof  从右到左
乘除 * / % 从左到右
加减+ -  从左到右
移位 << >>  从左到右
关系< <= > >=  从左到右
相等 == !=  从左到右

    &，|，^ ビット演算に使用されるだけでなく、論理演算にも使用できます。それぞれ論理積、論理和、排他的論理和に対応します。

    ^ 运算符整数型および bool 型に対して、バイナリ ^ 演算子が定義されています。整数型の場合、^ はオペランドのビットごとの XOR を計算します。bool オペランドの場合、^ はオペランドの論理 XOR を計算します。つまり、オペランドのいずれか一方が true の場合にのみ、結果は true になります。

    Console.WriteLine(true ^ false);  // 返回 true
Console.WriteLine(false ^ false);  // 返回 false
Console.WriteLine(true ^ true);  // 返回 false

    | 运算符整数型および bool 型に対して、バイナリ | 演算子が定義されています。整数型の場合、| はオペランドのビットごとの OR を計算します。bool オペランドの場合、| はオペランドの論理 OR を計算します。つまり、両方のオペランドが false の場合にのみ、結果は false になります。

    Console.WriteLine(true | false);  // 返回 true
Console.WriteLine(false | false); // 返回 false

    & 运算符整数型および bool 型に対して、バイナリ & 演算子が定義されています。整数型の場合、& はオペランドのビットごとの AND を計算します。bool オペランドの場合、& はオペランドの論理 AND を計算します。つまり、両方のオペランドが true の場合にのみ、結果は true になります。

    Console.WriteLine(true & false);  // 返回 false
Console.WriteLine(true & true);   // 返回 true

    & と | の演算結果は && と || と完全に同じですが、&& と || の方がパフォーマンスが優れています。&& と || はどちらも最初のオペランドの値を検査し、結果がすでに判断できる場合は、2番目のオペランドをまったく処理しないためです。

    比如：

    bool a = true;               
bool b = false;              
bool c = a || b;

    最初のオペランド a を確認した時点で c が true であるとすでに判明しているため、2番目のオペランド b を処理する必要はありません。

    null許容型修飾子 ?

    参照型は、空の参照を使用して存在しない値を表すことができますが、値型は通常、空として表すことはできません。

    例如：string str=null;是正确的，int i=null;コンパイラはエラーを報告します。

    値型も null を許容できるようにするには、null 許容型を使用できます。つまり、null 許容型修飾子を使用します。?を使用して表します。表現形式はT? 。

    例如：int?null 許容の整数型を表します。DateTime?null 許容の時間を表します。

    T?これは実際には System.Nullable<T>（ジェネリック構造体）の省略形です。つまり、T? を使用する場合、T？コンパイラは、コンパイル時に T? を System.Nullable<T> の形式にコンパイルします。

    例如：int?、コンパイル後は System.Nullable という形式になります。

    三項演算子式 ?:

    例如：x?y:z式 x が true の場合に y を返し、x が false の場合に z を返すことを示します。if{}else{}の簡易形式。

    null合体演算子 ??

    null 許容型および参照型の既定値を定義するために使用されます。

    この演算子の左オペランドが null でない場合、この演算子は左オペランドを返します。それ以外の場合は右オペランドを返します。

    例如：a??ba が null の場合は b を返し、a が null でない場合は a 自体を返します。

    null 合体演算子は右結合演算子です。つまり、操作は右から左へ結合されます。

    如:a??b??c的形式按a??(b??c)计算。

    NULL チェック演算子 ?.

    int? firstX = points?.FirstOrDefault()?.X;

    この例からも、その基本的な使い方がわかります。オブジェクトが NULL の場合、後続のメンバー取得演算は行われず、直接 NULL が返されます。

    注意すべき点は、〜のため?.演算子が返す値は NULL の場合があります。返されるメンバーの型が struct 型の場合、?. 和 .演算子の戻り値の型は異なります。

    Point p = new Point(3, 2); 
Console.WriteLine(p.X.GetType() == typeof(int));        //true

    C# 是用<<(左移) 和 >>（右移）演算子はシフト演算を実行するために使用されます。

    左シフト (<<)：最初のオペランドを、2番目のオペランドで指定されたビット数だけ左にシフトし、空いた位置には 0 を埋めます。

    左シフトは乗算に相当します。1ビット左シフトは 2 を掛けることに相当し、2ビット左シフトは 4 を掛けることに相当し、3ビット左シフトは 8 を掛けることに相当します。

    x<<1= x*2
x<<2= x*4
x<<3= x*8
x<<4= x*16

    同様に、右シフトはその逆です：

    右シフト (>>)：最初のオペランドを、2番目のオペランドで指定されたビット数だけ右にシフトし、空いた位置には 0 を埋めます。

    右シフトは整数除算に相当します。1ビット右シフトは 2 で割ることに相当し、2ビット右シフトは 4 で割ることに相当し、3ビット右シフトは 8 で割ることに相当します。

    x>>1= x/2
x>>2= x/4
x>>3= x/8
x>>4= x/16

    シフト演算は乗算・除算よりも高速であるため、効率が重視され、かつ 2 のべき乗の乗算・除算である場合には、シフト演算を使用できます。
