C# ビット配列（BitArray）

C# コレクション

BitArray は、C# において一連のビット（bit）値を表すために使用されるコレクションです。

BitArray は System.Collections 名前空間に属し、主にバイナリデータの処理やビット操作に使用されます。

ブール配列（bool[]）を使用する場合と比較して、BitArray は各ビットをコンパクトに格納するため、より効率的です。

BitArray クラスは、ブール値を使用して表されるコンパクトなビット値の配列を管理します。

true はビットがオン（1）であることを示し、false はビットがオフ（0）であることを示します。。

ビットを格納する必要があるが、事前にビット数がわからない場合は、ビット配列を使用します。

ビット配列コレクションの各項目にアクセスするには、整数インデックスを使用します。インデックスは 0 から始まります。

例

次の例は、ビット配列（BitArray）の使用法を示しています。

BitArray ではインデックス 0 はバイナリ数の最下位ビットに対応するため、インデックスの正順で走査して得られるビット列は通常の記述順と逆になり、次の例では逆順で走査して出力しています。

And()、Or()、Xor() などのメソッドは呼び出し元のインスタンスをその場で変更し、自身を返すため、毎回の演算の前にコピーコンストラクタを使用してnew BitArray(ba1)コピーを作成します。

同じ数値 13 でも、インデックスの正順で BitArray を走査すると 1 0 1 1 0 0 0 0 となり、通常の記述順とは正反対になるため、例では逆順で走査して出力しています。

例

using System;
using System.Collections;

namespace CollectionsApplication
{
    class Program
    {
        static void Main(string[] args)
        {
            // バイナリビットを格納するための 2 つの BitArray を初期化する
            BitArray ba1 = new BitArray(new byte[] { 60 }); // 60 = 00111100
            BitArray ba2 = new BitArray(new byte[] { 13 }); // 13 = 00001101

            // ba1 と ba2 の内容を出力する
            Console.WriteLine("Bit array ba1 (60):");
            PrintBitArray(ba1);

            Console.WriteLine("Bit array ba2 (13):");
            PrintBitArray(ba2);

            // AND 演算を実行し、結果を出力する
            // And/Or/Xor は呼び出し元のインスタンスをその場で変更するため、演算の前に ba1 のコピーを作成する
            BitArray baAnd = new BitArray(ba1);
            baAnd.And(ba2); // 60 & 13 = 12
            Console.WriteLine("Bit array after AND operation (12):");
            PrintBitArray(baAnd);

            // OR 演算を実行し、結果を出力する
            BitArray baOr = new BitArray(ba1); // 元の ba1 を再度コピーする
            baOr.Or(ba2); // 60 | 13 = 61
            Console.WriteLine("Bit array after OR operation (61):");
            PrintBitArray(baOr);

            // XOR 演算を実行し、結果を出力する
            BitArray baXor = new BitArray(ba1); // 元の ba1 をさらにコピーする
            baXor.Xor(ba2); // 60 ^ 13 = 49
            Console.WriteLine("Bit array after XOR operation (49):");
            PrintBitArray(baXor);

            Console.ReadKey();
        }

        // 逆順で走査し、出力を「上位ビットが先」という記述習慣に合わせる
        static void PrintBitArray(BitArray bitArray)
        {
            for (int i = bitArray.Length - 1; i >= 0; i--)
            {
                Console.Write($"{(bitArray[i] ? 1 : 0)} ");
            }
            Console.WriteLine("\n");
        }
    }
}

上記のコードをコンパイルして実行すると、次の結果が生成されます：

Bit array ba1 (60):
0 0 1 1 1 1 0 0

Bit array ba2 (13):
0 0 0 0 1 1 0 1

Bit array after AND operation (12):
0 0 0 0 1 1 0 0

Bit array after OR operation (61):
0 0 1 1 1 1 0 1

Bit array after XOR operation (49):
0 0 1 1 0 0 0 1
