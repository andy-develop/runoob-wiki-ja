C# 程序结构

C# プログラミング言語の基本構成要素を学ぶ前に、次の章の参考として、C# の最小のプログラム構造を見てみましょう。

C# Hello World 实例

C# プログラムは主に次の部分から構成されます：

  • 名前空間宣言（Namespace declaration）
  • 一个 class
  • Class 方法
  • Class 属性
  • 1つのMainメソッド
  • 语句（Statements）& 表达式（Expressions）
  • 注释

C#ファイルの拡張子は.cs。

以下は〜を作成するtest.csファイル。ファイルには "Hello World" を出力できる簡単なコードが含まれています：

test.csファイルのコード：

using System;
namespace HelloWorldApplication
{
   class HelloWorld
   {
      static void Main(string[] args)
      {
         /* 私の最初の C# プログラム*/
         Console.WriteLine("Hello World");
         Console.ReadKey();
      }
   }
}

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

Hello World

上記のプログラムの各部分を見てみましょう。

  • プログラムの最初の行using System; - usingキーワードはプログラムに含めるために使用されますSystem 名前空間。プログラムは通常、複数...using语句。
  • 次の行はnamespace声明。一个namespace一連のクラスが含まれています。HelloWorldApplication名前空間にはクラスが含まれるHelloWorld。
  • 次の行はclass声明。类HelloWorldプログラムが使用するデータとメソッドの宣言が含まれます。クラスは通常、複数のメソッドを含みます。メソッドはクラスの動作を定義します。ここでは、HelloWorld类只有一个 Main方法。
  • 次の行は〜を定義しているMainメソッドは、すべてのC#プログラムの入口点。Main メソッドは、実行時にクラスがどのような動作を行うかを説明します。
  • 次の行の /*...*/ はコンパイラによって無視され、プログラムに追加の...を追加します。注释。
  • Mainメソッドはステートメントを通じてConsole.WriteLine("Hello World"); その動作を指定する。

    WriteLine〜に定義されているSystem名前空間内のConsoleクラスのメソッド。このステートメントは、画面にメッセージ "Hello World" を表示します。

  • 最后一行Console.ReadKey();VS.NETユーザー向けです。これにより、プログラムはキー入力を待つようになり、Visual Studio .NETから起動したときに画面がすぐに実行されて閉じてしまうのを防ぎます。

以下の点は注目に値する：

  • C#は大文字と小文字を区別します。
  • すべてのステートメントと式は、セミコロン（;）で終わる必要があります。
  • プログラムの実行は Main メソッドから始まります。
  • Java とは異なり、ファイル名はクラス名と異なっていてもかまいません。

C#プログラムのコンパイル＆実行

Visual Studio.Net を使用して C# プログラムをコンパイルおよび実行する場合は、次の手順に従ってください：

  • 启动 Visual Studio。
  • メニューバーで、File -> New -> Project を選択します。
  • テンプレートから Visual C# を選択し、次に Windows を選択します。
  • 选择 Console Application。
  • プロジェクトに名前を付け、[OK] ボタンをクリックします。
  • 新しいプロジェクトは、ソリューションエクスプローラー（Solution Explorer）に表示されます。
  • コードエディター（Code Editor）でコードを記述します。
  • Runボタンをクリックするか、F5キーを押してプログラムを実行します。コマンドプロンプトウィンドウが表示され、Hello Worldが表示されます。

Visual Studio IDE の代わりにコマンドラインを使用して C# プログラムをコンパイルすることもできます：

  • テキストエディターを開き、上記のコードを追加します。
  • ファイルを...として保存helloworld.cs。
  • コマンドプロンプトツールを開き、ファイルが保存されているディレクトリに移動します。
  • 键入csc helloworld.csEnter キーを押してコードをコンパイルします。
  • コードにエラーがなければ、コマンドプロンプトは次の行に進み、...を生成します。helloworld.exe実行可能ファイル。
  • 次に、〜を入力するhelloworldプログラムを実行する。
  • 画面に "Hello World" が表示されます。
