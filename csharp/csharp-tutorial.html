C# 教程

C# はシンプルで、現代的で、汎用的な、オブジェクト指向のプログラミング言語であり、マイクロソフト（Microsoft）によって開発されました。

このチュートリアルでは、C#プログラミングの基礎を説明し、同時にC#プログラミング言語に関するさまざまな先進的な概念についても解説します。

C# の学習を始めましょう！

C# オンラインツール

誰がこのチュートリアルを読むべきですか？

このチュートリアルは初心者がC#プログラミングの基礎を理解するのに役立ちます。このチュートリアルを学び終えると、中級レベルのC#プログラミングスキルに到達します。

このチュートリアルを読む前に必要な知識：

C# プログラミングは C および C++ プログラミング言語に基づいています。そのため、C および C++ プログラミングについて基本的な知識があれば、C# プログラミング言語の学習に役立ちます。

编译/执行 C# 程序

菜鸟教程はオンラインのC#コンパイル環境を提供しています。簡単なクリック操作だけで、高性能なサーバー上で実際のプログラミング体験ができます。これは完全無料のオンラインツールです。

实例

using System;
namespace HelloWorldApplication
{
    /* クラス名は HelloWorld */
    class HelloWorld
    {
        /* main函数 */
        static void Main(string[] args)
        {
            /* 私の最初のC#プログラム */
            Console.WriteLine("Hello World!");
            Console.ReadKey();
        }
    }
}

    ここでは、以下のステートメントの役割について簡単に説明します。

    Console.ReadKey();

    编写Console.Readkey();この関数は、キーボードを打つまでコンソールウィンドウを一時停止させるためのものです。

    そうしないと、実行時に「Hello World!」というメッセージがコンソールウィンドウに一瞬表示されて消えてしまい、確認できません。

    Console.Readkey();
//与
Console.Readline();
//与
Console.Read();

    区别：最初のものはキーボードの任意のキーを押すと終了します。後の2つはほぼ同じで、任意のものを入力して Enter キーを押すと終了します。

    Console.ReadLine()ユーザーが Enter キーを押すまで待機し、一度に1行読み込みます。

    Console.ReadKey()ユーザーが任意のキーを押すのを待ち、一度に1文字読み込みます。

    class Program
{
   private List<Student> allStu = newList<Student>();
   string yesORno;
   bool flag = true;
   
   public void AddStudent()
   {
       while (flag)
       {
           Student s = new Student();
           Console.WriteLine("请输入学生姓名:");
           s.StuName = Console.ReadLine();
           Console.WriteLine("请输入学生学号");
           s.StuNum = Console.ReadLine();
           allStu.Add(s);

           Console.WriteLine("是否继续输入:请输入y或者n");
           yesORno =Console.ReadKey().Key.ToString();
           
           switch (yesORno)
           {
               case "Y":
                   flag = true;
                   break;
               case "N":
                   flag = false;
                   break;
           }
       }
   }

   public void ShowStu()
   {
       for (int i = 0; i < allStu.Count; i++)
       {
           Console.WriteLine(allStu[i].ToString());
       }
   }

   static void Main(string[] args)
   {
       Program p = new Program();
       p.AddStudent();
       p.ShowStu();
       Console.ReadLine();
   }
}

    Console.Write();      输出不换行

    .NET、C#、ASP.NET の3つの違いは次のとおりです。

    一、.NETとは何ですか？

    .NETはマイクロソフト社の開発プラットフォームです。.NETの核心は.NET Framework（.NETフレームワーク）であり、.NETプログラムの開発および実行環境です。このプラットフォームでは、.NETが言語横断的なプラットフォームであるため、異なる言語で開発できます。言語はC#、F#、J#、VB.NETなどです。JAVAと.NETの異なる点は、Javaはプラットフォーム横断的であり、言語横断的ではないことです。.NETのクロスプラットフォームはAndroidシステムとiOS（Apple）システムに限られています。

    1. .NET フレームワークの構成は2つの部分に分けられます。

    • CLR：共通言語ランタイム（Common Language Runtime）。メモリ管理、コードのセキュリティ検査などの機能を提供します。
    • FLC: .NET フレームワーククラスライブラリ（.NET Framework Class Library）は、大量のアプリケーションクラスライブラリを提供します。クラスライブラリには多くのスレッドリソース（例: クラス、メソッド、プロパティ）があり、開発効率を向上させます。

    2、CLRの構造：

    • CLS: 共通言語仕様（CLS）は、さまざまな言語を統一された文法仕様に変換します。
    • CTS: 共通型システム（CTS）は、さまざまな言語のデータ型を統一された型に変換します。
    • JIT: リアルタイムコンパイラ（ジャストインタイムコンパイラ）は、変換後の言語をバイナリ言語にコンパイルし、CPUに実行させるために使用されます。

    3、.NETの実行メカニズムの流れ

    各種言語（C#、F#、J#などの対応するソースプログラム）——>CLS、CTSを経て第一次コンパイル——>統一規範言語（中間言語）MSIL（.EXE、.DLL）——>JITによる第二次コンパイル——>バイナリ言語——>CPUで実行

    Javaの実行メカニズム：

    Java——>コンパイル——>バイトコードファイル（.CLASS）——>JVM解釈（JVM仮想マシン）——>バイナリ言語——>CPUで実行

    二、C#とは何ですか？

    C#は.NETプラットフォーム上のプログラミング言語であり、単なる言語です。.NET CLR上で動作し、アプリケーションを作成するための高水準言語です。プログラミング言語は、開発者とコンピュータのコミュニケーションを容易にするためのツールです。

    三、ASP.NETとは何ですか？

    ASP.NETはWebサイト開発の技術であり、.NETフレームワーク内のアプリケーションモデルです。Webベースのアプリケーションを生成するための、豊富な機能を備えたプログラミングフレームワークです。ASP.NETを使用してWebアプリケーションを開発し、その実行を維持することは、他の開発言語よりも簡単です。Java、PHP、Perlなどの高度な技術と比較して、ASP.NETは利便性、柔軟性、生産性の高さ、セキュリティの高さ、オブジェクト指向などの利点があり、現在主流のネットワークプログラミング技術の一つです。
