C# 堆栈（Stack）

C# 集合

C# では、スタック（Stack）は後入れ先出し（LIFO, Last In First Out）のデータ構造です。

スタック（Stack）は、データを保存し順番に処理するのに適しており、最後に追加された要素が最初に削除されます。

スタック（Stack）は、后进先出オブジェクトのコレクション。各項目に後入れ先出しでアクセスする必要がある場合は、スタックを使用します。リストに項目を追加するときは、推入要素と呼びます。リストから項目を削除するときは、弹出元素。

Stack には2つの実装方法があります：

  1. 非泛型Stack（System.Collections.Stack）：任意の型のオブジェクトを格納できます（ボックス化およびボックス化解除の操作が必要）。
  2. 泛型Stack<T>（System.Collections.Generic.Stack<T>）：強く型指定されたオブジェクトをサポートし、ボックス化とボックス化解除を回避して、パフォーマンスを向上させます。

Stack 特性：

  • 后进先出：最後にスタックにプッシュされた要素が最初にポップされます。
  • 动态大小：スタックの容量は必要に応じて動的に調整されます。
  • 泛型支持：通过Stack<T>型安全性を提供し、型変換エラーを回避します。
  • 非线程安全：默认Stack 和 Stack<T>いずれもスレッドセーフではありません。

实例

以下の例は、スタック（Stack）の使用法を示しています。

非ジェネリックスタック：

实例

using System;
using System.Collections;

namespace CollectionsApplication
{
    class Program
    {
        static void Main(string[] args)
        {
            Stack st = new Stack();

            st.Push('A');
            st.Push('M');
            st.Push('G');
            st.Push('W');
           
            Console.WriteLine("Current stack: ");
            foreach (char c in st)
            {
                Console.Write(c + " ");
            }
            Console.WriteLine();
           
            st.Push('V');
            st.Push('H');
            Console.WriteLine("The next poppable value in stack: {0}",
            st.Peek());
            Console.WriteLine("Current stack: ");          
            foreach (char c in st)
            {
               Console.Write(c + " ");
            }
            Console.WriteLine();

            Console.WriteLine("Removing values ");
            st.Pop();
            st.Pop();
            st.Pop();
           
            Console.WriteLine("Current stack: ");
            foreach (char c in st)
            {
               Console.Write(c + " ");
            }
        }
    }
}

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

Current stack: 
W G M A
The next poppable value in stack: H
Current stack: 
H V W G M A
Removing values
Current stack: 
G M A

泛型堆栈：

实例

using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        Stack<int> stack = new Stack<int>();

        // 压栈
        stack.Push(10);
        stack.Push(20);
        stack.Push(30);

        // 查看堆栈顶部
        Console.WriteLine($"Peek: {stack.Peek()}"); // 输出：30

        // 弹栈
        Console.WriteLine($"Pop: {stack.Pop()}"); // 输出：30

        // 剩余堆栈
        Console.WriteLine("Remaining items:");
        foreach (var item in stack)
        {
            Console.WriteLine(item); // 输出：20, 10
        }
    }
}

Stack 与 Stack<T> 区别

Stack（非ジェネリック）

  • 存储对象为object类型。
  • 使用時には明示的な型変換が必要で、実行時例外が発生する可能性があります。

Stack<T>（泛型）

  • 型安全性を提供し、型変換の問題を回避します。
  • ボックス化とボックス化解除のオーバーヘッドを回避するため、パフォーマンスが優れています。
