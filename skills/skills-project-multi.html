マルチスキル連携ワークフロー

このプロジェクトは、最初の3つの実践プロジェクトを統合し、完全な「データレポート生成」ワークフローにまとめます。

目標：マルチスキルのオーケストレーションと、全体を統括するオーケストレーションスキルの設計方法を習得すること。

ワークフローの目標

ユーザーがビジネスデータファイルをアップロードすると、システムは自動的に以下の全工程を完了し、最終的に完全なビジネスレポートを納品します。

オーケストレーションスキルの設計原則

オーケストレーションスキルは具体的な業務処理は行わず、他のスキルの出力のスケジューリング、中間結果の受け渡し、重要なポイントでのユーザーへの進捗報告のみを担当します。

オーケストレーションスキルが行うことオーケストレーションスキルが行わないこと
子スキルのスクリプトを順番に呼び出す子スキルに既にある機能を重複して実装する
ステップ間でファイルパスを渡すデータ内容を直接操作する
全体の進捗をユーザーに報告する個々のステップの内部詳細に注目する
ステップ失敗後のリカバリロジックを処理する子スキル内部の例外をキャッチする

オーケストレーションスクリプト

実例

# ファイルパス：scripts/orchestrator.py
# マルチスキル連携のオーケストレーションエントリスクリプト

import subprocess
import sys
import json
import os
import shutil

SKILLS_BASE  = "/mnt/skills/public"
WORK_DIR     = "/home/claude/report_work"
OUTPUT_DIR   = "/mnt/user-data/outputs"

def run(script_path: str, *args) -> dict:
    """指定されたスクリプトを実行し、JSON結果を返す"""
    cmd    = [sys.executable, script_path] + list(args)
    result = subprocess.run(cmd, capture_output=True, text=True, timeout=120)
    try:
        return json.loads(result.stdout)
    except json.JSONDecodeError:
        return {
            "status":  "error",
            "message": result.stderr or result.stdout or "スクリプトに出力がありません"
        }

def orchestrate(input_file: str) -> dict:
    """完全なレポート生成ワークフローを実行する"""
    os.makedirs(WORK_DIR, exist_ok=True)

    # ── フェーズ1：データクリーニング ─────────────────────────────────
    print("【1/3】データをクリーニング中...", flush=True)
    clean_result = run(
        f"{SKILLS_BASE}/data-cleaner/scripts/clean_data.py",
        input_file,
        os.path.join(WORK_DIR, "cleaned.csv")
    )
    if clean_result.get("status") != "success":
        return {"status": "error", "stage": "データクリーニング",
                "message": clean_result.get("message")}

    print(fクリーニング完了：重複行 {clean_result.get('dup_removed', 0)} 件を削除、
          f"空値を {clean_result.get('nulls_filled', 0)} 箇所補充", flush=True)

    # ── フェーズ2：統計分析 ─────────────────────────────────
    print("【2/3】統計レポートを生成中...", flush=True)
    stats_result = run(
        f"{SKILLS_BASE}/data-cleaner/scripts/calc_stats.py",
        clean_result["output"],
        os.path.join(WORK_DIR, "stats.json")
    )
    if stats_result.get("status") != "success":
        return {"status": "error", "stage": "統計分析",
                "message": stats_result.get("message")}

    # ── フェーズ3：Excelレポートの生成 ──────────────────────────
    print("【3/3】Excelレポートを生成中...", flush=True)
    output_name  = os.path.splitext(os.path.basename(input_file))[0] + "_report.xlsx"
    output_path  = os.path.join(OUTPUT_DIR, output_name)

    report_result = run(
        f"{SKILLS_BASE}/data-cleaner/scripts/gen_report.py",
        clean_result["output"],
        stats_result.get("output", ""),
        output_path
    )
    if report_result.get("status") != "success":
        return {"status": "error", "stage": "レポート生成",
                "message": report_result.get("message")}

    # 作業ディレクトリをクリーンアップ
    shutil.rmtree(WORK_DIR, ignore_errors=True)

    return {
        "status":     "success",
        "output":     output_path,
        "clean_stats": {
            "dup_removed":  clean_result.get("dup_removed", 0),
            "nulls_filled": clean_result.get("nulls_filled", 0)
        }
    }

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print(json.dumps({"status": "error", "message": "使い方：python orchestrator.py <ファイルパス>"}))
        sys.exit(1)

    result = orchestrate(sys.argv[1])
    print(json.dumps(result, ensure_ascii=False, indent=2))

オーケストレーションスキルのSKILL.md

---
name: report-pipeline
version: 1.0.0
description: >
  完整的数据报告生成流水线：自动对上传的 CSV/Excel 文件执行数据清洗、
  统计分析并生成 Excel 报告。当用户需要一键生成数据报告、
  从原始数据直接输出分析报告时触发。
---

# 数据报告流水线

## 前置条件

需要以下 Skills 已安装：
- data-cleaner v1.0+
- 本 Skill 的脚本位于 /mnt/skills/public/report-pipeline/

## 执行

获取用户上传的文件路径后，直接运行编排脚本：

```bash
python scripts/orchestrator.py <文件路径>
```

脚本会实时输出每阶段的进度，完成后输出最终文件路径。
解析 JSON 输出后调用 present_files 展示报告文件。

## 失败处理

若任意阶段失败，输出包含 stage 和 message 的错误信息，
告知用户是哪个阶段失败以及可能的原因，不要继续执行后续阶段。
