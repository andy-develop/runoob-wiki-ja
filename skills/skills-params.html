Skills パラメータの受け渡しと受信

Skills は従来の関数のように明示的なパラメータを受け取るのではなく、Claude のコンテキストを通じて入力情報を認識します。

この「暗黙的なパラメータ受け渡し」メカニズムを理解することが、実用的な Skill を作成する鍵です。

Skills パラメータの取得方法

Claude が Skill を読み取ると、その Skill のパラメータは会話コンテキスト全体になります。

つまり、ユーザーの発言、アップロードされたファイル、過去の会話履歴はすべて Skill の入力ソースになり得ます。

入力ソース 例 説明
ユーザーの現在のメッセージ 「この PDF を処理して」 最も直接的な入力
アップロードされたファイル ユーザーが report.pdf をアップロード パスまたは内容で渡される
過去の会話 以前に議論したデータ形式 コンテキスト内で参照可能
システム変数 現在の日付、作業ディレクトリのパス Claude が自動的に認識

SKILL.md で期待する入力を宣言する

SKILL.md では自然言語の記述によって、Claude にコンテキストからどの情報を抽出する必要があるかを伝えることができます。

以下は CSV ファイルを処理する Skill の例で、指示の中で入力の期待値を宣言する方法を示しています：

例

---
name: csv-analyzer
description: ユーザーがアップロードした CSV ファイルを分析し、統計サマリーを出力します。ユーザーが CSV、表データ分析に言及したときにトリガーされます。
---

# CSV アナライザー

## 入力要件

ユーザーは以下の情報を提供する必要があります（会話コンテキストから取得）：
- **ファイルパス**：アップロードされた CSV ファイルのパス（/mnt/user-data/uploads/）
- **分析目標**（オプション）：ユーザーが知りたいこと。例："空値を見つける"、"統計分布"
- **出力形式**（オプション）：表、グラフ、またはテキストサマリー

上記の情報が明確でない場合は、ユーザーに確認してから実行します。

Skill 内の「入力要件」は Claude 自身に向けて書かれたものです。Claude はこの説明に基づいて、コンテキストから情報を積極的に抽出するか、情報が不十分な場合はユーザーに質問します。

スクリプトで構造化パラメータを受け取る

Skill に Python または Shell スクリプトが付属している場合、パラメータはコマンドライン引数または標準入力で渡されます。

これは通常のスクリプトのパラメータ処理方法とまったく同じです。

例

# ファイルパス：scripts/analyze.py
import argparse
import pandas as pd

def main():
    # コマンドライン引数を定義
    parser = argparse.ArgumentParser(description="CSV ファイル分析スクリプト")
    parser.add_argument("file",        help="必須：CSV ファイルパス")
    parser.add_argument("--col",       help="オプション：分析する列名を指定")
    parser.add_argument("--limit", type=int, default=10,
                        help="オプション：表示する最大行数、デフォルト 10")
    args = parser.parse_args()

    # ファイルを読み込む
    df = pd.read_csv(args.file)

    # 必要に応じて列をフィルタリング
    if args.col:
        df = df[[args.col]]

    # 統計情報を出力
    print(df.head(args.limit).to_string())
    print("\n--- 統計サマリー ---")
    print(df.describe())

if __name__ == "__main__":
    main()

SKILL.md で Claude がこのスクリプトを呼び出す書き方：

例

## 分析の実行

ファイルパスを取得したら、以下のコマンドを実行します：

```bash
python scripts/analyze.py <ファイルパス> [--col <列名>] [--limit <行数>]
```

コマンドラインの出力をユーザーに表示し、テキストでの解説を提供します。

ファイルパスパラメータの処理規範

ユーザーがアップロードしたファイルはすべて/mnt/user-data/uploads/パスの下に配置されます。

Skill スクリプトでは、常に絶対パスを使用してファイルにアクセスし、パス解決エラーを避けます。

例

import os

# 正しい：絶対パスを使用
UPLOAD_DIR = "/mnt/user-data/uploads"
file_path = os.path.join(UPLOAD_DIR, "report.csv")

# 誤り：相対パスを使用（作業ディレクトリが異なるため失敗する）
# file_path = "uploads/report.csv"

# ファイルが存在するか確認
if not os.path.exists(file_path):
    print(f"エラー：ファイルが存在しません → {file_path}")
    exit(1)

パラメータ検証：実行前に入力をチェック

Skill スクリプトは実行前に、常に主要なパラメータが有効かどうかを検証する必要があります。

これにより、パラメータの欠落や形式エラーによる実行時クラッシュを防ぐことができます。

例

# ファイルパス：scripts/validate_input.py
import sys
import os

def validate_csv_input(file_path: str) -> bool:
    """CSV ファイル入力が有効かどうかを検証"""

    # ファイルパスが提供されているか確認
    if not file_path:
        print("エラー：ファイルパスが提供されていません")
        return False

    # ファイルが存在するか確認
    if not os.path.exists(file_path):
        print(f"エラー：ファイルが存在しません → {file_path}")
        return False

    # ファイル拡張子を確認
    if not file_path.lower().endswith(".csv"):
        print(f"エラー：サポートされていないファイルタイプです。期待：.csv、実際 → {file_path}")
        return False

    # ファイルサイズを確認（100MB を超える場合は警告）
    size_mb = os.path.getsize(file_path) / (1024 * 1024)
    if size_mb > 100:
        print(f"警告：ファイルが大きいです（{size_mb:.1f} MB）、処理に時間がかかる可能性があります")

    return True

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("使用方法：python validate_input.py <ファイルパス>")
        sys.exit(1)

    ok = validate_csv_input(sys.argv[1])
    sys.exit(0 if ok else 1)

パラメータ検証の失敗メッセージは、期待する内容と実際に得られた内容を明確に説明し、Claude がユーザーに具体的な理由をフィードバックしやすくする必要があります。
