Skills の動作原理

不思議に思うかもしれません。エージェントは人間ではないのに、どうやって特定の Skill が何ができるか、どうやるべきかを知るのでしょうか？

答えは簡単です——ファイルを読むことです。

各 Skill の背後には、説明ファイルがあり、通常はSKILL.md、それはまるで取扱説明書のようなものです。

Skills の動作原理

Skills は、プログレッシブ・ディスクロージャー（Progressive Disclosure）の方式を使用して、エージェントが異なる段階で異なる詳細度の情報をロードできるようにします。この設計により、エージェントはコンテキスト空間を使い尽くすことなく、多数のスキルを同時に管理できます。

3つの段階

エージェントがスキルをロードするのは、次の3つの段階に分けられます：

  • 1. 発見段階（Discovery）：対話が始まると、エージェントは利用可能なすべてのスキルフォルダをスキャンし、各スキルの名前（name）と説明（description）だけを読み取ります。これは最も軽量な情報であり、エージェントが特定のスキルが現在のタスクに関連する可能性があるかどうかを判断するのに十分です。

  • 2. 活性化段階（Activation）：

    エージェントが、あるスキルの説明がユーザーのリクエストと一致すると判断した場合、完全な SKILL.md ファイルの内容をコンテキストにロードします。このとき、エージェントは完全な指示と説明を読み取ります。

  • 3. 実行段階（Execution）：エージェントは SKILL.md の指示に従ってタスクを実行します。このプロセスで、エージェントはスキルに付属するスクリプトを呼び出したり、参考資料を読んだり、他のリソースを使用したりする場合があります。

段階的ロードの利点

段階 ロードする内容 典型的なサイズ
発見段階 name + description 約 100 tokens
活性化段階 完全な SKILL.md 5000 tokens を超えないことを推奨
実行段階 スクリプト、参考資料など 必要に応じてロード

エージェントはタスクを実行する前に、この説明書を読んで、次の3つのことを確認します：

  • この Skill は何ができるか？（能力の説明）
  • それを使うために、何を提供する必要があるか？（入力パラメータ）
  • これを行う際のルールは何か？（環境の制約と注意事項）

読んだ後、エージェントは理解します：「ああ、この Skill は現在の問題を解決するのに適している。これを呼び出そう」と。

Skill の実行フロー

  • ユーザーの指示から始まり、まず Skill の意図認識を行い、制御された実行パスに入るかどうかを決定します。

  • Skill にヒットすると、システムは SKILL.md をロードし、ツールの権限と行動の境界を確立し、コンテキストと組み合わせて推論します。

  • 実際に必要な場合にのみ許可された外部ツールを呼び出し、それ以外はルール内でロジックを完了します。

  • 最終結果は制約を統合した後に出力され、ユーザーの次の入力が新たな完全なフローをトリガーします。

Skills の動作プロセス

ユーザーが要件を提示した後、Agent はまずタスクの内容を理解し、次にどの能力（Skills）を使って作業を完了すべきかを分析します。

Skill は、独立した能力モジュールまたはプラグインと理解できます。例えば、天気予報、検索、ファイル処理、データベースアクセスなどです。

Agent は思考と意思決定を担当し、Skill はアクションの実行を担当します。実行が完了すると、結果は Agent に返され、Agent がユーザーにわかりやすい形に整理して出力します。

プロセス全体が完全なループを形成します：理解 → 意思決定 → 実行 → 結果の返却。

ステップ 段階 Agent 内部の動作 例
① ユーザーがリクエストを開始 自然言語タスクを受け取る 「北京の今日の天気を調べて」
② ユーザーの意図を理解する ユーザーが本当にやりたいことを分析し、パラメータを抽出する 動作：検索；タイプ：天気；場所：北京
③ 実行計画を立てる タスクのステップを分解する 天気サービスを探す → 天気データを取得する → 結果を整理する
④ Skill を選択する 最も適した能力モジュールをマッチングする Weather Skill を選択する
⑤ Skill を実行する 外部ツールまたは API を呼び出す 天気 API にリクエストする
⑥ 実行結果を取得する Skill が返したデータを受け取る 温度、湿度、大気質
⑦ 最終的な返答を生成する 整理して自然言語に変換する 「北京は今日晴れ、18℃〜30℃」
⑧ ユーザーに返す 最終結果を出力する ユーザーは完全な返答を見る

Skill の種類 機能の説明 一般的なシーン

天気 Skill 天気データを取得する 天気予報の確認
ファイル Skill ファイルの内容を読み取る PDF、Word、Excel

ブラウザ Skill ウェブページを自動操作する 自動ログイン、コンテンツのクローリング
コード Skill コードを実行する Python、Node.js
画像 Skill 画像処理機能 OCR、画像生成
