HTML 書式設定タグ

HTML ではタグ <b>（"bold"）と <i>（"italic"）を使用して出力テキストを書式設定します。例：太字 or 斜体

これらのHTMLタグは書式設定タグと呼ばれます（下部の完全なタグリファレンスを参照してください）。

通常、タグ <strong> は太字タグ <b> の代わりに使用され、<em> は <i> タグの代わりに使用されます。

ただし、これらのタグの意味は異なります：

<b> と <i> は太字または斜体のテキストを定義します。

<strong> または <em> は、表示するテキストが重要であることを意味するため、強調表示します。現在の主要なブラウザはすべて、さまざまな効果のフォントをレンダリングできます。ただし、将来のブラウザはより良いレンダリング効果をサポートするかもしれません。

HTML テキスト書式設定タグ

タグ 説明
<b> 太字テキストを定義する
<em> 強調テキストを定義する
<i> 斜体文字を定義する
<small> 小さい文字を定義する
<strong> 強い強調を定義する
<sub> 下付き文字を定義する
<sup> 上付き文字を定義する
<ins> 挿入テキストを定義する
<del> 削除テキストを定義する

HTML「コンピュータ出力」タグ

タグ 説明
<code> コンピュータコードを定義する
<kbd> キーボードコードを定義する
<samp> コンピュータコードのサンプルを定義する
<var> 変数を定義する
<pre> 整形済みテキストを定義する

HTML 引用文、引用、およびタグ定義

タグ 説明
<abbr> 省略形を定義する
<address> 住所を定義する
<bdo> 文字の方向を定義する
<blockquote> 長い引用を定義する
<q> 短い引用を定義する
<cite> 引用、引証を定義する
<dfn> 定義項目を定義する。
