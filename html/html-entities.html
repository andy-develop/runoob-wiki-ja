HTML 文字実体

HTML の予約文字は文字実体に置き換える必要があります。

キーボードにない一部の文字も文字実体を使って置き換えることができます。

HTML エンティティ

HTML では、一部の文字は予約されています。

HTML では小なり記号（<）と大なり記号（>）は使用できません。ブラウザがそれらをタグと誤って解釈するためです。

予約文字を正しく表示したい場合は、HTML ソースコードで文字実体（character entities）を使用する必要があります。文字実体は次のようになります：

&entity_name;

或

&#entity_number;

小なり記号を表示するには、次のように記述する必要があります：&lt; 或 &#60; 或 &#060;

ヒント：数字ではなくエンティティ名を使用する利点は、名前が覚えやすいことです。しかし欠点として、ブラウザがすべてのエンティティ名をサポートしているとは限りません（数値エンティティのサポートは非常に良好です）。

改行なしスペース（Non-breaking Space）

HTML でよく使われる文字実体は改行なしスペース（&nbsp;）です。

ブラウザは HTML ページ内のスペースを常に短縮します。テキストに10個のスペースを書いた場合、ページを表示する前にブラウザはそのうち9個を削除します。ページ内のスペースの数を増やすには、&nbsp; 文字実体を使用する必要があります。

結合分音記号

発音記号は文字に追加される「glyph（字形）」です。

一部の分音記号、例えば鋭アクセント（ ̀）や重アクセント（ ́）などがあります。

分音記号は文字の上や下、文字の中、または2つの文字の間に現れることがあります。

分音記号は文字や数字の文字と組み合わせて使用できます。

以下にいくつかの例を示します：

分音記号 文字 Construct 出力結果
  ̀ a a&#768; à
  ́ a a&#769; á
̂ a a&#770; â
  ̃ a a&#771; ã
  ̀ O O&#768; Ò
  ́ O O&#769; Ó
̂ O O&#770; Ô
  ̃ O O&#771; Õ
