HTML5 Geolocation（地理位置情報）

HTML5 Geolocation（地理位置情報）は、ユーザーの位置を特定するために使用されます。

ユーザーの位置を特定する

HTML5 Geolocation API は、ユーザーの地理的な位置を取得するために使用されます。

この機能はユーザーのプライバシーを侵害する可能性があるため、ユーザーが同意しない限り、ユーザーの位置情報は利用できません。

ブラウザサポート

Internet Explorer 9+、Firefox、Chrome、Safari、Opera は Geolocation（地理位置情報）をサポートしています。

注意:Geolocation（地理位置情報）は、GPS を搭載したデバイス（iPhone など）では、より正確な位置情報を提供します。

HTML5 - 地理位置情報の使用

ユーザーの位置を取得するには、getCurrentPosition() メソッドを使用してください。

次の例は、ユーザーの位置の経度と緯度を返す簡単な地理位置情報の例です:

例

var x=document.getElementById("demo"); function getLocation() { if (navigator.geolocation) { navigator.geolocation.getCurrentPosition(showPosition); } else { x.innerHTML="このブラウザは地理位置情報の取得をサポートしていません。"; } } function showPosition(position) { x.innerHTML="緯度:" + position.coords.latitude + "<br>経度:" + position.coords.longitude; }

試してみる »

例の解説:

  • 地理位置情報がサポートされているかどうかを確認する
  • サポートされている場合は、getCurrentPosition() メソッドを実行します。サポートされていない場合は、ユーザーにメッセージを表示します。
  • getCurrentPosition() が成功すると、パラメータ showPosition で指定された関数に coordinates オブジェクトを返します。
  • showPosition() 関数は経度と緯度を取得して表示します。

上記の例は、エラー処理を含まない非常に基本的な地理位置情報スクリプトです。

エラーと拒否の処理

getCurrentPosition() メソッドの2番目のパラメータはエラーを処理するために使用されます。ユーザーの位置の取得に失敗したときに実行される関数を指定します:

例

function showError(error) { switch(error.code) { case error.PERMISSION_DENIED: x.innerHTML="ユーザーが地理位置情報の取得リクエストを拒否しました。" break; case error.POSITION_UNAVAILABLE: x.innerHTML="位置情報は利用できません。" break; case error.TIMEOUT: x.innerHTML="ユーザーの地理位置情報のリクエストがタイムアウトしました。" break; case error.UNKNOWN_ERROR: x.innerHTML="不明なエラー。" break; } }

試してみる »

エラーコード:

  • Permission denied - ユーザーが地理位置情報を許可しませんでした
  • Position unavailable - 現在の位置を取得できません
  • Timeout - 操作がタイムアウトしました

地図に結果を表示する

地図に結果を表示するには、経度と緯度を使用できる地図サービス（Google マップや百度地図など）にアクセスする必要があります:

例

function showPosition(position) { var latlon=position.coords.latitude+","+position.coords.longitude; var img_url="http://maps.googleapis.com/maps/api/staticmap?center=" +latlon+"&zoom=14&size=400x300&sensor=false"; document.getElementById("mapholder").innerHTML="<img src='"+img_url+"'>"; }

試してみる »

上記の例では、返された経度と緯度のデータを使用して、Google マップに位置を表示しています（静的画像を使用）。

指定された位置の情報

このページでは、地図上にユーザーの位置を表示する方法を説明しています。ただし、地理位置情報は指定された位置の情報にも非常に役立ちます。

以下の用途に使用できます:

  • ローカル情報の更新
  • ユーザーの周辺の興味のある地点を表示
  • 対話型カーナビゲーションシステム (GPS)

getCurrentPosition() メソッド - 返されるデータ

成功した場合、getCurrentPosition() メソッドはオブジェクトを返します。常に latitude、longitude、accuracy の各プロパティが返されます。利用可能な場合は、以下の他のプロパティも返されます。

プロパティ 説明
coords.latitude 10進数の緯度
coords.longitude 10進数の経度
coords.accuracy 位置の精度
coords.altitude 標高（海抜メートル単位）
coords.altitudeAccuracy 位置の標高精度
coords.heading 方位（真北からの度数）
coords.speed 速度（メートル毎秒）
timestamp 応答の日付/時刻

Geolocation オブジェクト - その他の便利なメソッド

watchPosition() - ユーザーの現在位置を返し、ユーザーが移動したときの更新位置も継続して返します（車の GPS のように）。

clearWatch() - watchPosition() メソッドを停止します

次の例は watchPosition() メソッドを示しています。この例をテストするには、正確な GPS デバイス（iPhone など）が必要です:

例

var x=document.getElementById("demo"); function getLocation() { if (navigator.geolocation) { navigator.geolocation.watchPosition(showPosition); } else { x.innerHTML="このブラウザは地理位置情報の取得をサポートしていません。"; } } function showPosition(position) { x.innerHTML="緯度:" + position.coords.latitude + "<br>経度:" + position.coords.longitude; }

    百度で経度と緯度を取得する例（IE5を含む各ブラウザに対応）:

    <!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8" />
    <title></title>
    <!--引入百度 API，"ak=" 后面一串码是密钥，最好自己申请-->
    <script type="text/javascript" src="https://api.map.baidu.com/api?v=2.0&ak=7a6QKaIilZftIMmKGAFLG7QT1GLfIncg"></script>
</head>
<body>
    <input type="button" onclick="getLocation()" value="确认" />
    <div id="position"></div>
    <script type="text/javascript">
    var x = document.getElementById('position');
    function getLocation() {
        // 创建百度地理位置实例，代替 navigator.geolocation
        var geolocation = new BMap.Geolocation();
        geolocation.getCurrentPosition(function(e) {
            if(this.getStatus() == BMAP_STATUS_SUCCESS){
                // 百度 geolocation 的经纬度属性不同，此处是 point.lat 而不是 coords.latitude
                x.innerHTML = '纬度：' + e.point.lat + '<br/>经度：' + e.point.lng;
            } else {
                x.innerHTML = 'failed' + this.getStatus();
            }
        });
    }
    </script>
</body>
</html>
