CSSの使い方

CSSはHTML 4から使用され始め、HTML要素をより良くレンダリングするために導入されました。

CSSは以下の方法でHTMLに追加できます:

  • インラインスタイル - HTML要素で"style"を使用属性
  • 内部スタイルシート - HTMLドキュメントのヘッド <head> 領域で<style>を使用要素CSSを含める
  • 外部参照 - 外部CSSを使用ファイル

最良の方法は外部CSSファイルを参照することです。

このサイトのHTMLチュートリアルでは、インラインCSSスタイルを使用して例を紹介しています。これは例を簡素化するためであり、コードをオンラインで編集してインスタンスをオンラインで実行しやすくするためでもあります。

このサイトのCSSチュートリアルでより多くのCSS知識を学ぶことができます。

インラインスタイル

特別なスタイルを個々の要素に適用する必要がある場合は、インラインスタイルを使用できます。インラインスタイルを使用する方法は、関連するタグでスタイル属性を使用することです。スタイル属性には任意のCSSプロパティを含めることができます。次の例は、段落の色と左マージンを変更する方法を示しています。

<p style="color:blue;margin-left:20px;">这是一个段落。</p>

スタイルについてもっと学ぶには、こちらをご覧くださいCSSチュートリアル.

HTMLスタイルの例 - フォント、フォントカラー、フォントサイズ

font-family（フォント）、color（色）、font-size（フォントサイズ）属性を使用してフォントのスタイルを定義できます:

内部スタイルシート

単一のファイルに特別なスタイルが必要な場合は、内部スタイルシートを使用できます。<head> セクションで <style> タグを使用して内部スタイルシートを定義できます:

<head>
<style type="text/css">
body {background-color:yellow;}
p {color:blue;}
</style>
</head>

外部スタイルシート

スタイルを多くのページに適用する必要がある場合、外部スタイルシートが理想的です。外部スタイルシートを使用すると、1つのファイルを変更するだけでサイト全体の外観を変更できます。

<head>
<link rel="stylesheet" type="text/css" href="mystyle.css.html">
</head>

HTMLスタイルタグ

タグ 説明
<style> テキストスタイルを定義
<link> リソース参照アドレスを定義

非推奨のタグと属性

HTML 4では、HTML要素のスタイルを定義するために使用されていたタグと属性は非推奨になりました。これらのタグは新しいバージョンのHTMLタグではサポートされません。

推奨されないタグ: <font>, <center>, <strike>

推奨されない属性: color と bgcolor.

    CSS外部タグの導入

    最初の方法：最も使用され、安定している

    <link rel="stylesheet" href="标签路径.html">

    2番目の方法：

    <style>
@import url("标签路径")
</style>

    拡張知識ポイント:link と import の違い？

    違い1：

    本質的な違い：linkはXHTMLタグに属し、@import完全にCSSが提供する方法です。

    違い2：

    読み込み順序の違い：ページが読み込まれるとき（閲覧者が閲覧しているとき）、link が参照するCSSは同時に読み込まれますが、@import@import が参照するCSSは、ページがすべてダウンロードされるまで読み込まれません。そのため、@import でCSSを読み込むページを閲覧するとき、@import最初はスタイルがない（ちらつき）ことがあり、ネットワーク速度が遅いときはかなり顕著です。

    違い3：

    互換性の違い： @import@import はCSS 2.1で提案されたため、古いブラウザではサポートされず、@importIE5以上でのみ認識されますが、linklink タグにはこの問題はありません。

    違い4：

    dom（document object model ドキュメントオブジェクトモデル）を使用してスタイルを制御する場合の違い：javascript を使用して dom を制御しスタイルを変更するときは、link タグのみ使用できます。なぜなら@import@import は dom で制御できないからです。
