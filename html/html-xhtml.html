HTML - XHTML

XHTML は XML 形式で書かれた HTML です。

XHTML とは？

  • XHTML は Extensible HyperText Markup Language（拡張可能なハイパーテキストマークアップ言語）を指します。
  • XHTML は HTML 4.01 とほぼ同じです。
  • XHTML は、より厳格でより純粋な HTML バージョンです。
  • XHTML は XML アプリケーションとして定義された HTML です。
  • XHTML は2001 年 1 月公開された W3C 勧告です。
  • XHTML はすべての主要ブラウザでサポートされています。

なぜ XHTML を使うのか？

インターネット上の多くのページには「悪い」HTML が含まれています。

ブラウザで表示すると、次の HTML コードは（HTML のルールに従っていなくても）まったく正常に動作します：

<html> <head> <meta charset="utf-8"> <title>これは不適切な HTML です</title> <body> <h1>不適切な HTML<p>これは段落です</body>

XML は、正しくマークアップされ、整形式である必要があるマークアップ言語です。

XML を学びたい場合は、当サイトのXML チュートリアル。

今日のテクノロジー業界には、いくつかの異なるブラウザ技術があります。その一部はコンピュータ上で動作し、また別のものは携帯電話やその他の小型デバイス上で動作する場合があります。小型デバイスには、「悪い」マークアップ言語を解釈するためのリソースと能力が不足していることがよくあります。

そこで、XML と HTML の長所を組み合わせることで、XHTML が開発されました。XHTML は XML として再設計された HTML です。

HTML と比較した最も重要な違い：

ドキュメント構造

  • XHTML DOCTYPE は必須です
  • <html> の XML namespace 属性は必須です
  • <html>、<head>、<title>、<body> も必須です

要素の構文

  • XHTML 要素は正しくネストする
  • XHTML 要素は常に閉じる必要があります
  • XHTML 要素は小文字でなければなりません
  • XHTML ドキュメントにはルート要素が必要です

属性の構文

  • XHTML 属性は小文字を使用する必要があります
  • XHTML 属性値は引用符で囲む必要があります
  • XHTML の属性の最小化も禁止されています

<!DOCTYPE ....> は必須です

XHTML ドキュメントには XHTML 文書型宣言（XHTML DOCTYPE declaration）が必要です。

Runoob のタグリファレンスマニュアルに完全なXHTML 文書型。

<html>、<head>、<title>、<body> 要素も存在しなければならず、<html> 内の xmlns 属性を使用してドキュメントに XML 名前空間を指定する必要があります。

次の例は、必要最小限のタグを備えた XHTML ドキュメントを示しています：

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd"> <html xmlns="http://www.w3.org/1999/xhtml"> <head> <meta charset="utf-8"> <title>ドキュメントのタイトル</title> </head> <body>ドキュメントの内容</body> </html>

XHTML 要素は正しくネストする必要があります

HTML では、一部の要素は次のように互いにネストしなくてもかまいません：

<b><i>太字および斜体のテキスト</b></i>

XHTML では、すべての要素は次のように互いに正しくネストする必要があります：

<b><i>太字および斜体のテキスト</i></b>

XHTML 要素には終了タグが必要です

間違った例：

<p>これは段落です<p>これは別の段落です

正しい例：

<p>これは段落です</p> <p>これは別の段落です</p>

空要素には終了タグを含める必要があります

間違った例：

改行:<br>水平線:<hr>画像:<img src="happy.gif" alt="Happy face">

正しい例：

改行:<br />水平線:<hr />画像:<img src="happy.gif" alt="Happy face" />

XHTML 要素は小文字でなければなりません

間違った例:

<BODY> <P>これは段落です</P> </BODY>

正しい例：

<body> <p>これは段落です</p> </body>

属性名は小文字でなければなりません

間違った例：

<table WIDTH="100%">

正しい例:

<table width="100%">

属性値は引用符で囲む必要があります

間違った例：

<table width=100%>

正しい例：

<table width="100%">

属性の省略形は許可されません

間違った例：

<input checked> <input readonly> <input disabled> <option selected>

正しい例：

<input checked="checked"> <input readonly="readonly"> <input disabled="disabled"> <option selected="selected">

HTML を XHTML に変換する方法

  1. Web ページに XHTML <!DOCTYPE> を追加します
  2. 各ページの html 要素に xmlns 属性を追加します。
  3. すべての要素を小文字に変更します
  4. すべての空要素を閉じます
  5. すべての属性名を小文字に変更します
  6. すべての属性値に引用符を追加します
