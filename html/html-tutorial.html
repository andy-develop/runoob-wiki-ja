HTML チュートリアル-(HTML5 標準)

ハイパーテキスト・マークアップ言語（英語: HyperText Markup Language、略称: HTML）は、Webページを作成するための標準マークアップ言語です。

HTMLを使用して、自分自身のWEBサイトを構築できます。HTMLはブラウザ上で動作し、ブラウザによって解析されます。

このチュートリアルでは、HTMLを使用してサイトを作成する方法を学びます。

HTMLはとても簡単に学べます！きっとすぐに習得できるでしょう。

注意：中国語のWebページでは、以下を使用する必要があります<meta charset="utf-8">エンコーディングを宣言します。そうしないと文字化けが発生します。一部のブラウザ（360ブラウザなど）はGBKをデフォルトエンコーディングに設定するため、次のように設定する必要があります<meta charset="gbk">。

    "UTF-8" は標準的な表記です。PHPはWindowsでは英字の大文字小文字を区別しないため、"utf-8" と書くこともできます。"UTF-8" は中間の "-" を省略して "UTF8" と書くこともできます。一般的なプログラムは認識できますが、例外もあります（下記参照）。厳密にするには、標準の大文字 "UTF-8" を使うのが最適です。

    データベースでは "utf8"（MySQL）のみ使用できます。MySQLのコマンドモードでは "utf8" のみ使用でき、"utf-8" は使用できません。つまり、PHPプログラムでは "set names utf8（ハイフンなし）" のみ使用できます。 "-" を追加すると、このコマンドは機能しません。ただし、PHP で header を設定する場合は "-" を付ける必要があります。IE がハイフンなしの "utf8" を認識しないためです。理由は下記の通りです。

    PHP における header：

    <?php header('Content-Type: text/html; charset=UTF-8'); ?> //奇怪了：Content-Type 用冒号，Chatset却是等号。

    まとめ：【MySQLでのみ "utf-8" の別名 "utf8" を使用できますが、その他の場所では必ず大文字の "UTF-8" を使用してください。】

    htm と html の違い

    前者はハイパーテキストマークアップ（Hypertext Markup）

    後者はハイパーテキストマークアップ言語（Hypertext Markup Language）

    htm = html と言えます

    同時に、これらはどちらも静的Webページファイルの拡張子です。拡張子は互いに交換してもエラーは発生しません（これは開くことに関してです。ただし、リンクの場合、リンクがhtmファイルを指していて、そのhtmファイルがhtmlファイルに変更された場合は、そのリンクは見つからなくなります）

    では、なぜ2つのファイル形式が存在するのでしょうか？

    htm は古い8.3ファイル形式に由来します。DOSオペレーティングシステムは3桁の長さの拡張子しかサポートできなかったため、htm となっています。しかし、Windows では HTM と HTML はどちらでも構いません。html は長いファイル名の形式として命名されました。そのため、htm は過去のDOS命名形式との互換性のために存在しており、効果に違いはありません。以前は htm と html は異なるサーバー上のハイパーテキストファイルとして使われていましたが、現在は同じように使われています。

    8.3ファイル形式とは何ですか？ これは、古い16ビットのWin95またはWin98ファイルシステムにおける短いファイル名のファイル形式で、拡張子は3文字、ファイル名は8文字に制限されています。16ビットシステムとやり取りする場合、例えばパスを16ビットプログラムに渡すには、長いファイル名を使用できず、変換する必要があります。例えば、“C ： /MyLongestPath/MyLongerPath/MyFilename.txt”を“C ： /Mylong~1/MyLong~2/Myfile~1.txt”に変換します。

    これを知って何の役に立つのでしょうか？ FATディスク形式のDOSでは8.3ファイル形式のみがサポートされています。この環境でアプリケーションを開発する場合は、このファイル形式の問題に注意する必要があります。NTFSでは、デフォルトでこのファイル形式と互換性があり、長いファイル名もサポートしています。レジストリを調整して8.3ファイル形式のサポートを無効にすることもできます。

    拡張子の選択：htm を使うか html を使うか？

    長い拡張子を使用することをお勧めしますhtml 。

    命名は、意味が明確で、簡潔で、一貫性があるという原則に従うべきです。意味が明確とは、名前を見れば意味が分かることを指します。例えば、ここでの htm（hypertext markup）や html（hypertext markup language）は、英単語の頭文字をとった略語であり、意味が明確です。簡潔さは、変数名をできるだけ短くすることを要求します。例えば、ここでの拡張子は完全な単語ではなく頭文字の略語を使用しています。一貫性の原則は、同じ環境内の多くの変数名が同じ規則に従うことを要求します。例えば、Linuxのフォルダ命名規則に慣れている人が、Windowsシステムを使用するときに新しいフォルダ名にスペースを使うのを避ける場合、新しいフォルダ名と古いフォルダ名の命名規則が一致しなくなります。

    一貫性の原則はしばしばより重要です。例えば、協力して開発する場合、各自が自分のやり方を守るべきではなく、人為的に開発の難易度を上げてはいけません。

    一路风尘のノートから、htm は歴史的に残された8.3文字制限のある命名方式であり、現在の命名では8.3ルールを守っていないことが分かります。したがって、htm と html のどちらかを選ぶ場合も、長さ制限のない命名方式である html を選ぶべきです。

    いつもなぜか分からないのですが、プログラムを書くたびに、次のような一文があります<!DOCTYPE html>。今、ようやくこの意味が分かりました！

    これは HTML5 標準のウェブページ宣言で、正式名称は Document Type HyperText Mark-up Language であり、マークアップ言語の一種です。HTML5 標準をサポートする主要ブラウザはすべてこの宣言を認識します。ウェブページが HTML5 を採用していることを示します。<!DOCTYPE html>宣言はドキュメントの先頭、<html> タグの前に配置されます。このタグは、ブラウザにドキュメントがどの HTML または XHTML 仕様を使用しているかを伝えます。
