HTML5 新要素

HTML5 新要素

1999年以降、HTML 4.01は大きく変化してきました。今日では、HTML 4.01のいくつかの要素は廃止され、これらの要素はHTML5で削除または再定義されています。

今日のインターネットアプリケーションをより適切に処理するために、HTML5には多くの新要素と機能が追加されました。例えば：グラフィックの描画、マルチメディアコンテンツ、より良いページ構造、より良いフォーム処理、そして複数のAPI（ドラッグ＆ドロップ要素、位置情報、Webアプリケーションキャッシュ、ストレージ、Webワーカーなど）があります。

<canvas> 新要素

タグ 説明
<canvas> タグはグラフィック（チャートやその他の画像など）を定義します。このタグはJavaScriptの描画APIに基づいています。

新しいマルチメディア要素

タグ 説明
<audio> 音声コンテンツを定義します
<video> ビデオ（video または movie）を定義します
<source> マルチメディアリソース <video> と <audio> を定義します
<embed> 埋め込みコンテンツ（プラグインなど）を定義します。
<track> <video> や <audio> 要素などのメディアに外部テキストトラックを指定します。

新しいフォーム要素

タグ 説明
<datalist> オプションリストを定義します。この要素は input 要素と組み合わせて使用し、input の可能な値を定義します。
<keygen> フォーム用のキーペアジェネレーターフィールドを指定します。
<output> さまざまなタイプの出力（スクリプトの出力など）を定義します。

新しいセマンティックおよび構造要素

HTML5はより良いページ構造を作成するための新しい要素を提供します：

タグ 説明
<article> ページの独立したコンテンツ領域を定義します。
<aside> ページのサイドバーコンテンツを定義します。
<bdi> テキストの一部を親要素のテキスト方向設定から切り離して設定できます。
<command> コマンドボタン（ラジオボタン、チェックボックス、ボタンなど）を定義します
<details> ドキュメントまたはドキュメントの一部の詳細を説明するために使用します
<dialog> ダイアログボックス（プロンプトボックスなど）を定義します
<summary> タグは details 要素のタイトルを含みます
<figure> 独立したフローコンテンツ（画像、チャート、写真、コードなど）を指定します。
<figcaption> <figure> 要素のタイトルを定義します
<footer> section または document のフッターを定義します。
<header> ドキュメントのヘッダー領域を定義します
<mark> マーク付きのテキストを定義します。
<meter> 度量衡を定義します。最大値と最小値が既知の測定にのみ使用されます。
<nav> ナビゲーションリンクの部分を定義します。
<progress> あらゆるタイプのタスクの進捗状況を定義します。
<ruby> ruby 注釈（中国語の注音または文字）を定義します。
<rt> 文字（中国語の注音または文字）の解釈または発音を定義します。
<rp> ruby 注釈で使用し、ruby 要素をサポートしないブラウザに表示されるコンテンツを定義します。
<section> ドキュメント内のセクション（section、区段）を定義します。
<time> 日付または時刻を定義します。
<wbr> テキスト内のどこに改行を追加するのが適切かを指定します。

削除された要素

以下の HTML 4.01 要素はHTML5で削除されました：

  • <acronym>
  • <applet>
  • <basefont>
  • <big>
  • <center>
  • <dir>
  • <font>
  • <frame>
  • <frameset>
  • <noframes>
  • <strike>
  • <tt>
