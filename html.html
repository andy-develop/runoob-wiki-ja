HTML チュートリアル -(HTML5 標準)

ハイパーテキストマークアップ言語（英語: HyperText Markup Language、略称: HTML）は、ウェブページを作成するための標準マークアップ言語です。

HTMLを使用して自分のWEBサイトを構築できます。HTMLはブラウザ上で動作し、ブラウザによって解析されます。

このチュートリアルでは、HTMLを使用してサイトを作成する方法を学びます。

HTMLはとても簡単に学べます！きっとすぐに習得できるでしょう！

HTML サンプル

このチュートリアルには数百のHTMLサンプルが含まれています。

当サイトのエディタを使用すると、オンラインでHTMLを簡単に編集し、サンプルの実行結果を確認できます。

注意：中国語のWebページでは、次のものを使用する必要があります<meta charset="utf-8">エンコーディングを宣言しないと、文字化けが発生します。一部のブラウザ（360ブラウザなど）はGBKをデフォルトエンコーディングに設定するため、次のように設定する必要があります<meta charset="gbk">。

サンプル

<!DOCTYPE html> <html> <head> <meta charset="utf-8"> <title>菜鸟教程（runoob.com）</title> </head> <body> <h1>私の最初の見出し</h1> <p>私の最初の段落。</p> </body> </html>
