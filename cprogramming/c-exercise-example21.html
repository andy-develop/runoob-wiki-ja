問題：猿が桃を食べる問題：猿は初日にいくつかの桃を摘み、すぐに半分を食べたが、まだ満足せず、さらに1つ多く食べた。翌朝、残りの桃の半分を食べ、また1つ多く食べた。以後毎朝、前日に残った半分と1つを食べた。10日目の朝にまた食べようとした時、桃が1つだけ残っているのを見た。初日に合計いくつ摘んだのかを求める。

プログラム分析：逆方向の思考方法を採用し、後ろから前に推測する。

1) x1を前日の桃の数、x2を翌日の桃の数とすると、次のようになる：

x2=x1/2-1, x1=(x2+1)*2

x3=x2/2-1, x2=(x3+1)*2

これも同様に： x前=(x後+1)*2

2) 10日目から1日目まで類推でき、これはループ処理である。

プログラムソースコード：

実例

// Created by www.runoob.com on 15/11/9. // Copyright © 2015年 菜鸟教程. All rights reserved. // #include <stdio.h> #include <stdlib.h> int main(){ int day, x1 = 0, x2; day=9; x2=1; while(day>0) { x1=(x2+1)*2; // 初日の桃の数は、2日目の桃の数に1を加えた後の2倍である x2=x1; day--; } printf("合計は %d\n",x1); return 0; }

总数为 1534

// 设每天早上没吃之前的个数为 x 吃掉 x/2 + 1, 没吃的等于 x -(x/2 +1), 第十天早上剩一个,反推回去即可
// x - (x/2 + 1) = left, x/2 -1 = left , x = (left + 1)*2
int main(){
    int sum = 1, i;
    for(i=10; i > 0; i--) {
        printf("第%d天早上没吃的时候的个数 = %d\n", i, sum);
        sum = (sum + 1)*2;
    }
    return 0;
}

#include <math.h>

/*
分析：
角标1—10表示第10到第1天的桃子数量。
则：An = (An-1 + 1)*2，两边同时加2可得
    Bn = An + 2,是一个首项为B1 = 3，公比为2的等比数列：Bn = B1*2^(n-1)
    带入n即可求Bn，减去2即可得到Xn
*/
int main()
{
    int a1,b1,q,n,bn,an;
    a1 = 1;
    b1 = a1 + 2, q = 2;
       n = 10;
    bn = b1 * pow(2,n -1);
    an = bn - 2;
    printf("总共有%d个桃子\n",an);
    return 0;
}
