C標準ライブラリ -<stdarg.h>

<stdarg.h>C標準ライブラリ内のヘッダファイルであり、可変数の引数にアクセスするためのマクロ群を提供します。

stdarg.hヘッダファイルは1つの変数型を定義しています。va_listおよび3つのマクロを定義しています。これらのマクロは、引数の数が不明（すなわち引数の数が可変）の場合に関数の引数を取得するために使用できます。

可変引数の関数は通常、引数リストの末尾に省略記号（...）を使用して...定義されます。

ライブラリ変数

以下はヘッダファイル stdarg.h で定義されている変数型です：

番号変数 & 説明
1va_list
これは、va_start()、va_arg() 和 va_end()3つのマクロが情報を格納するための型です。可変引数情報を格納するために使用される型です。

ライブラリマクロ

以下はヘッダファイル stdarg.h で定義されているマクロです：

番号マクロ & 説明
1void va_start(va_list ap, last_arg)
このマクロは、ap変数を初期化します。これはva_arg 和 va_endマクロと一緒に使用されます。last_argは、関数に渡される最後の既知の固定引数、すなわち省略記号の前の引数です。
2type va_arg(va_list ap, type)
このマクロは、関数の引数リストから型がtypeの次の引数を取得します。
3void va_end(va_list ap)
このマクロにより、va_startマクロを使用した可変引数を持つ関数が戻ることができます。関数から戻る前に呼び出されなかった場合、va_end結果は未定義です。

例

以下は、<stdarg.h>を使用して可変引数関数を実装する例です。この関数はすべての引数の合計を計算します：

例

#include <stdio.h>
#include <stdarg.h>

// 可変引数の合計を計算する
int sum(int count, ...) {
    int total = 0;
    va_list args;
   
    // 可変引数にアクセスするために args を初期化する
    va_start(args, count);
   
    // 可変引数を1つずつ取得する
    for (int i = 0; i < count; i++) {
        total += va_arg(args, int);
    }
   
    // args をクリーンアップする
    va_end(args);
   
    return total;
}

int main() {
    printf("Sum of 1, 2, 3: %d\n", sum(3, 1, 2, 3)); // 6 を出力
    printf("Sum of 4, 5, 6, 7: %d\n", sum(4, 4, 5, 6, 7)); // 22 を出力
    return 0;
}

出力結果：

Sum of 1, 2, 3: 6
Sum of 4, 5, 6, 7: 22

解説

  • va_list args;：1つのva_list変数を宣言し、可変引数にアクセスします。
  • va_start(args, count);：初期化するargs可変引数リストを走査するために、countの後の最初の引数から開始します。
  • total += va_arg(args, int);：可変引数リストの次の引数を取得し、それをtotalに加算します。引数型はint。
  • va_end(args);：クリーンアップするargs。

注意事項

  • 可変引数リスト内の各引数の型は明確でなければならず、一貫してva_arg。
  • に渡して使用する必要があります。va_start使用したva_end後は、va_listを使用してクリーンアップする必要があります。
  • va_start、va_arg 和 va_endマクロは関数内でペアで使用する必要があります。未定義の動作を避けるためです。

    2番目の投稿の方法は安全ではありません！！

    2番目の投稿の非固定引数メソッドを使用中にバグに遭遇しました。私が渡した引数は構造体ポインタで、コードは次のとおりです：

    void AddChildren(Node* parent, ...)
{
    if (parent == NULL) return;
    Node* child = NULL;
    va_list child_list;
    va_start(child_list, parent);
    while (child = va_arg(child_list, Node*)) {
        parent->children[parent->child_ptr++] = child;
    }
    va_end(child_list);
    child = NULL;
}

    しかし、ツリー構造を出力する際にエラーが発生しました。

    Segmentation fault (core dumped)

    当時はエラーの原因がわかりませんでしたが、この関数を次のように変更したところ：

    void AddChildren(Node* parent, int childnum, ...)
{
    if (parent == NULL) return;
    va_list child_list;
    va_start(child_list, childnum);
    for (int i = 0; i < childnum; i++) {
        parent->children[parent->child_ptr++] = va_arg(child_list, Node*);
    }
    va_end(child_list);
}

    その後、コードは正しく実行できました。

    その後、Stackoverflow で関連する回答を見つけました：https://stackoverflow.com/questions/9774803/stdarg-h-reads-too-many-arguments

    関連部分の抜粋は次のとおりです：

    Don't use va_list, especially in member functions. And you need to know the number of the arguments, va_arg will happily read the entire memory if it can。

    そのため、1つの解決策は、上記の私のように明確な引数の個数を渡すことです。

    もう1人の方は別の解決策を示しました。それは、2番目の投稿と同様のコードを引き続き使用しますが、引数を渡す際に追加で0を渡し、while ループの終了条件とすることです：

    Variadic function arguments are not typesafe, or any kind of 'safe' for that matter. It is your responsibility to communicate to your function how many arguments there are and what their types are.

    In your code, the only thing that makes the loop terminate is when x evaluates as false. Your data, obscurely typed as it is, seems to consist of integral values, and that would necessitate your last variadic argument to be zero, which it isn't in your example.

    Try calling the function wtih (n, x1, x2, x3, 0).
