C typedef

C言語はtypedefキーワードを提供しており、それを使用して型に新しい名前を付けることができます。次の例では、単バイトの数値に用語を定義しています。BYTE：

typedef unsigned char BYTE;

この型定義の後、識別子BYTEは型unsigned charの略語として使用できます。例：

BYTE  b1, b2;

慣例として、定義時には大文字を使用し、型名が象徴的な略語であることをユーザーに促します。ただし、次のように小文字を使用することもできます：

typedef unsigned char byte;

を使用することもできますtypedefユーザー定義のデータ型に新しい名前を付けるために。例えば、構造体にtypedefを使用して新しいデータ型名を定義し、その新しいデータ型を使用して構造体変数を直接定義できます。次のようになります：

例

#include <stdio.h> #include <string.h> typedef struct Books { char title[50]; char author[50]; char subject[100]; int book_id; } Book; int main( ) { Book book; strcpy( book.title, "C チュートリアル"); strcpy( book.author, "Runoob"); strcpy( book.subject, "プログラミング言語"); book.book_id = 12345; printf( "本のタイトル : %s\n", book.title); printf( "本の著者 : %s\n", book.author); printf( "本のカテゴリ : %s\n", book.subject); printf( "本のID : %d\n", book.book_id); return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

书标题 : C 教程
书作者 : Runoob
书类目 : 编程语言
书 ID : 12345

typedef vs #define

#defineはCディレクティブであり、さまざまなデータ型のエイリアスを定義するために使用され、typedefに類似していますが、それらには次のようないくつかの違いがあります：

  • typedef型にシンボル名を定義することにのみ限定され、#define型にエイリアスを定義できるだけでなく、数値にもエイリアスを定義できます。例えば、1をONEと定義できます。
  • typedefはコンパイラによって解釈実行され、#defineステートメントはプリプロセッサによって処理されます。

以下は#defineの最も簡単な使用方法です：

例

#include <stdio.h> #define TRUE 1 #define FALSE 0 int main( ) { printf( "TRUEの値: %d\n", TRUE); printf( "FALSEの値: %d\n", FALSE); return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

TRUE 的值: 1
FALSE 的值: 0

    typedef と #define の違い

    （1）#defineは他の型指定子を使用してマクロ型名を拡張できますが、typedefで定義された型名に対してはそれができません。例：

    #define INTERGE int;
unsigned INTERGE n;  //没问题
typedef int INTERGE;
unsigned INTERGE n;  //错误，不能在 INTERGE 前面添加 unsigned

    （2）複数の変数を連続して定義する場合、typedefは定義されたすべての変数が同じ型であることを保証できますが、#defineでは保証できません。例：

    #define PTR_INT int *
PTR_INT p1, p2;        //p1、p2 类型不相同，宏展开后变为int *p1, p2;
typedef int * PTR_INT
PTR_INT p1, p2;        //p1、p2 类型相同，它们都是指向 int 类型的指针。

    typedef と #define の比較

    typdefの一部の機能はdefineの機能と重複しています。例：

    #define BYTE unsigned char

    これはプリプロセッサがBYTEをunsigned charに置き換えることです。

    しかし、#defineにはない機能もあります。例：

    typedef char * STRING;

    コンパイラはSTRINGをcharを指す型の識別子として解釈します。したがって：

    STRING name, sign;

    次と同等です：

    char * name , * sign;

    しかし、次のように仮定すると：

    #define STRING char *

    すると、以下の宣言は：

    STRING name, sign;

    次のように変換されます：

    char * name, sign;

    これにより、ポインタとなるのはnameになります。

    要するに、#defineは単なる文字通りの置換であり、プリプロセッサによって実行され、#define A Bエディタの置換機能を開いて、すべてのBをAに置き換えることに相当します。

    #defineとは異なり、typedefには次の3つの特徴があります：

    • 1.typedefが与えるシンボル名は型に対してのみであり、値に対してではありません。
    • 2.typedefの解釈はプリプロセッサではなくコンパイラによって実行されます。単純なテキスト置換ではありません。
    • 3.範囲は限られていますが、その制限された範囲内ではtypedefは#defineよりも柔軟です。

    typedefにはもう1つの役割があります。複雑な宣言に新しいシンプルなエイリアスを定義することです。コールバック関数で特に便利です：

    1. 元の宣言：int *(*a[5])(int, char*);

    ここで、変数名はaであり、新しいエイリアスpFunで置き換えるaだけで十分です：

    typedef int *(*pFun)(int, char*);

    これで、元の宣言の最も簡略化されたバージョン：

    pFun a[5];

    2. 元の宣言：void (*b[10]) (void (*)());

    ここで、変数名はbです。最初に右側の括弧内を置き換え、pFunParamをエイリアス1とします：

    typedef void (*pFunParam)();

    次に左側の変数を置き換え、b，pFunxをエイリアス2とします：

    typedef void (*pFunx)(pFunParam);

    これで、元の宣言の最も簡略化されたバージョン：

    pFunx b[10];

    実は、次のように理解できます：

    typedef int *(*pFun)(int, char*);

    由 typedefで定義された関数pFunは新しい型であり、この新しい型はintと同じように変数を定義できます。したがって、pFun a[5];を定義することになりますint *(*a[5])(int, char*);

    したがって、これを使用してコールバック関数を定義でき、特に便利です。

    また、typedefは構文上、ストレージクラスのキーワードであることにも注意してください（auto、extern、mutable、static、registerなどと同じです）。実際にはオブジェクトのストレージ特性に影響を与えませんが。例：

    typedef static int INT2; // 不可行

    コンパイルは失敗し、「複数のストレージクラスが指定されました」というエラーが表示されます。
