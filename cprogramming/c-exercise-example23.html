問題：以下の図形（菱形）を出力します。

   *
  ***
 *****
*******
 *****
  ***
   *

プログラム分析：まず図形を2つの部分に分けて考えます。最初の4行は一つの規則、後の3行は別の規則です。二重forループを使用し、最初のループは行を制御し、2番目のループは列を制御します。

プログラムソースコード：

例

// Created by www.runoob.com on 15/11/9. // Copyright © 2015年 菜鸟教程. All rights reserved. // #include <stdio.h> int main() { int i,j,k; for(i=0;i<=3;i++) { for(j=0;j<=2-i;j++) { printf(" "); } for(k=0;k<=2*i;k++) { printf("*"); } printf("\n"); } for(i=0;i<=2;i++) { for(j=0;j<=i;j++) { printf(" "); } for(k=0;k<=4-2*i;k++) { printf("*"); } printf("\n"); } }

上記の例の出力結果は次のとおりです。

   *
  ***
 *****
*******
 *****
  ***
   *

    等差数列を利用する：

    /***************************
实例中的空格可以看作等差数列（空格数）前4项{4，3，2，1}=an3；
后3项为{2，3，4}=an4；
前四项"  * "也是等差数列（个数）{1，3，5，7}=an1;
后三项的等差数列{5，3，1}=an2;
***************************/
#include<stdio.h>
int main(void)
{
    int i,j,an1=0,an2=0,an3=0;
    int k=0,n=1;
    int an4=2;
    for(i=1;i<8;i++)
    {
        an3=5-i;//an3=4+(i-1)*(-1)
        for(k=0;k<an3;k++)
        {
            printf(" ");
        }
        if(i<5)
        {
            an1=2*i-1;//an1=1+(i-1)*2
            for(j=0;j<an1;j++)
            {
                printf("*");
            }
        }
        else
        {
            for(k=0;k<an4;k++)
            {
                printf(" ");
            }
            an2=7-2*n;//an2=5+(n-1)*(-2)
            for(j=0;j<an2;j++)
            {
                printf("*");
            }
            an4++;
            n++;
        }
        printf("\n");
    }
    return 0;
}

    座標系を利用する；

    横方向を i 軸とし、左から右に増加する。縦方向を j 軸とし、上から下に増加する。

    すべての * を点として取ると、座標系上に菱形の領域が得られる。菱形領域の4つの頂点はそれぞれ（3,0）、（0,3）、（6,3）、（3.6）である。4本の直線に囲まれた領域が得られ、4本の直線の i, j の関係はそれぞれ次のようになる：

    j = -i +3;
j = -i +9;
j = i -3;
j = i +3;

    問題で求める * は、4本の直線で囲まれた領域内および境界上の点である。この領域内の点は以下の条件を満たす：

    i + j >= 3 ;
i + j <= 9 ;
j - i >= -3 ;
j - i <= 3 ;

    上記の4つの条件に基づいて走査する；

    #include<stdio.h>

int main()
{
    int i, j; //行，列
    for (i = 0; i < 7; i++)
    {
        for (j = 0; j < 7; j++)
        {
            if (i + j >= 3 && i + j <= 9 && j - i >= -3 && j - i <= 3)
            {
                printf("*");
            }
            else
                printf(" ");
        }
        printf("\n");
    }
    return 0;
}
