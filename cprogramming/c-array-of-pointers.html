C ポインタ配列

C ポインタ

ポインタ配列は配列であり、その各要素は何らかのデータ型を指すポインタです。

ポインタ配列は一連のポインタを格納し、各ポインタは異なるデータオブジェクトを指すことができます。

ポインタ配列は通常、複数のデータオブジェクトを処理するために使用されます。例えば、文字列配列やその他の複雑なデータ構造の配列などです。

3つの整数からなる配列を使用した例を見てみましょう：

例

#include <stdio.h> const int MAX = 3; int main () { int var[] = {10, 100, 200}; int i; for (i = 0; i < MAX; i++) { printf("Value of var[%d] = %d\n", i, var[i] ); } return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

Value of var[0] = 10
Value of var[1] = 100
Value of var[2] = 200

配列に int や char などのデータ型を指すポインタを格納したい場合があるかもしれません。

以下は整数を指すポインタ配列の宣言です：

int *ptr[MAX];

ここで、ptrptr を MAX 個の整数ポインタからなる配列として宣言します。したがって、ptr の各要素は int 値を指すポインタです。次の例では、3つの整数を使用し、それらをポインタ配列に格納します。次のようになります：

例

#include <stdio.h> const int MAX = 3; int main () { int var[] = {10, 100, 200}; int i, *ptr[MAX]; for ( i = 0; i < MAX; i++) { ptr[i] = &var[i]; /*整数のアドレスを代入*/ } for ( i = 0; i < MAX; i++) { printf("Value of var[%d] = %d\n", i, *ptr[i] ); } return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

Value of var[0] = 10
Value of var[1] = 100
Value of var[2] = 200

文字を指すポインタ配列を使用して文字列リストを格納することもできます。次のようになります：

例

#include <stdio.h> const int MAX = 4; int main () { const char *names[] = { "Zara Ali", "Hina Ali", "Nuha Ali", "Sara Ali", }; int i = 0; for ( i = 0; i < MAX; i++) { printf("Value of names[%d] = %s\n", i, names[i] ); } return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

Value of names[0] = Zara Ali
Value of names[1] = Hina Ali
Value of names[2] = Nuha Ali
Value of names[3] = Sara Ali

もう一つ簡単な例を見てみましょう。まず、3つの整数ポインタを含むポインタ配列 ptrArray を宣言します。次に、これらのポインタをそれぞれ異なる整数変数 num1、num2、num3 に向けます。最後に、ポインタ配列を使用してこれらの整数変数の値にアクセスします。

例

#include <stdio.h> int main() { int num1 = 10, num2 = 20, num3 = 30; // 3つのポインタを含む整数ポインタ配列を宣言する int *ptrArray[3]; // ポインタを異なる整数変数に向ける ptrArray[0] = &num1; ptrArray[1] = &num2; ptrArray[2] = &num3; // ポインタ配列を使用してこれらの整数変数の値にアクセスする printf("Value at index 0: %d\n", *ptrArray[0]); printf("Value at index 1: %d\n", *ptrArray[1]); printf("Value at index 2: %d\n", *ptrArray[2]); return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

Value at index 0: 10
Value at index 1: 20
Value at index 2: 30

ポインタ配列は C 言語で非常に有用です。特に、動的に割り当てられた文字列配列や動的に作成された構造体配列など、要素数が不定のデータ構造を扱う場合に役立ちます。

    ポインタ配列と配列ポインタの違い

    ポインタ配列

    ポインタ配列：ポインタ配列は「ポインタの配列」と言えます。まず、この変数は配列です。

    次に、「ポインタ」がこの配列を修飾しており、この配列のすべての要素がポインタ型であることを意味します。

    32 ビットシステムでは、ポインタは4バイトを占めます。

    配列ポインタ

    配列ポインタ：配列ポインタは「配列のポインタ」と言えます。まず、この変数はポインタです。

    次に、「配列」がこのポインタを修飾しており、このポインタが配列の先頭アドレスを格納している、つまりこのポインタが配列の先頭アドレスを指していることを意味します。

    根

    上記の説明から、ポインタ配列と配列ポインタの違いがわかります。なぜなら、両者は根本的に異なる種類の変数だからです。

    ポインタ配列：ポインタの配列であり、実際には配列です。長さは配列自体によって決まり、この配列のすべての要素はポインタ型で、すべてアドレスを格納します。

    int *prt[ 10 ] ; *prt[ 1 ],*prt[ 2 ],*prt[ 3 ]......配列の各要素はそれぞれアドレスを指します。

    配列ポインタ：配列のポインタであり、実際にはポインタです。長さは固定で（32 ビットシステムでは4バイトを占めます）。このポインタは配列を指しますが、指す配列が何バイトを占めるかは不定です。

    int  a[5]={ 1,2,3,4,5 };    //定义一个一维数组 a
int  (*prt)[5];      // 步长为 5 的数组指针，即 prt 指向的数组里有 5 个元素  
prt=&a;    // 把数组 a 的地址付给 prt，则 prt 为数组 a 的地址，*prt 表示数组 a 本身
prt[ 0 ];    //表示数组首元素的地址
*prt[ 0 ]；  //表示数组的首元素的值，即为数组 a 的 1
**prt;         //表示数组的首元素的值，即为数组 a 的 1
*prt[ 1 ] ;   //表示指向数组的下一行元素的首元素的值，但是a是一维数组，只有一行，所以指向的地址中的值不确定

    配列ポインタに1を加えると、ステップサイズは指す配列の列数、すなわち次の行の先頭アドレスになります。これは2次元以上の配列でのみ意味があり、1次元配列には1行しかないため意味がありません。

    ポインタ配列

    int *a[3]：なぜここではポインタ配列なのか、[]の優先順位は より高く*、したがってこれは配列であり、*が配列を修飾するため、ポインタ配列となり、配列の要素は整数型のポインタです。

    例：

    int main() {     
   char *str[3];     
   str[0] = "abc";     
   str[1] = "efg";     
   str[2] = "hij";     
   for (int i = 0; i < 3; ++i) {         
      printf("%s\n", str[i]);     
   } 
}

    結果：

    abc 
efg 
hij

    配列ポインタ

    int (*a)[3]：同様に、まず括弧の優先順位が最も高いため、*aはポインタであり、[]が修飾し、*a、したがって配列ポインタであり、3つの要素を指す1次元配列ポインタです。

    例：

    typedef int arr[3]; 
int main() {     
   arr b = {1, 2, 3};     
   int (*a)[3] = &b;     
   arr *c = a;     
   for (int i = 0; i < 3; ++i) {         
      printf("%d\n", (*a)[i]);     
      
   } 
}

    結果：

    1 
2 
3

    解析：

    ここでは typedef を使用します。配列データ型を表すデータ型を独自に定義しました。そのデータ型は3つの整数要素を持つ配列です。

    配列ポインタの定義方法も2つあります。1つは上記で独自に定義した配列データ型を使用する方法、もう1つは直接定義する方法です。

    ポインタ配列：

    int *p1[3];

    角括弧 [] の優先順位が高いため、p1 と先に結合し、配列を表します。この配列には3つの要素があり、これらの3つの要素はすべてポインタで、int 型データを指します。

    配列ポインタ：

    int (*p2)[3];

    小括弧によって p2 が * と結合し、p2 がポインタであることを表します。このポインタは配列を指しており、配列には3つの要素があり、各要素の型は int 型です。
