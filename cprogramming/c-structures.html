C 構造体

C の配列は、同じ型のデータ項目を格納できる変数を定義できます。構造体は C プログラミングにおけるもう1つのユーザー定義のデータ型であり、異なる型のデータ項目を格納することができます。

構造体内のデータメンバーは、基本データ型（int、float、char など）の場合もあれば、他の構造体型やポインタ型などの場合もあります。

構造体はレコードを表すために使用されます。図書館の本の状況を追跡したい場合、各書籍について次の属性を追跡する必要があるかもしれません：

  • Title
  • Author
  • Subject
  • Book ID

構造体の定義

構造体の定義はキーワードstructと構造体名から構成され、構造体名は必要に応じて自由に定義できます。

struct 文は複数のメンバーを含む新しいデータ型を定義します。struct 文の形式は次のとおりです：

struct tag {
    member-list
    member-list
    member-list  
    ...
} variable-list ;

tagは構造体タグです。

member-listは標準の変数定義であり、例えばint i;またはfloat f;、その他の有効な変数定義です。

variable-list構造変数は構造体の末尾、最後のセミコロンの前に定義され、1つ以上の構造変数を指定できます。以下は Book 構造体を宣言する方法です：

struct Books
{
   char  title[50];
   char  author[50];
   char  subject[100];
   int   book_id;
} book;  

一般的な場合、tag、member-list、variable-listこの3つの部分のうち少なくとも2つが必要です。以下に例を示します：

//この宣言は、3つのメンバーを持つ構造体を宣言しています。それぞれ整数型のa、文字型のb、倍精度浮動小数点型のcです。
//同時に構造体変数s1も宣言しています
//この構造体にはタグが指定されていません
struct
{
    int a;
    char b;
    double c;
} s1;

//この宣言は、3つのメンバーを持つ構造体を宣言しています。それぞれ整数型のa、文字型のb、倍精度浮動小数点型のcです。
//構造体のタグはSIMPLEという名前で、変数は宣言されていません
struct SIMPLE
{
    int a;
    char b;
    double c;
};
//SIMPLEタグの構造体を使用して、変数t1、t2、t3を別途宣言しています
struct SIMPLE t1, t2[20], *t3;

//typedefを使用して新しい型を作成することもできます
typedef struct
{
    int a;
    char b;
    double c;
} Simple2;
//これでSimple2を型として新しい構造体変数を宣言できます
Simple2 u1, u2[20], *u3;

上記の宣言では、1番目と2番目の宣言は、メンバーリストが同じであっても、コンパイラによって完全に異なる型として扱われます。t3=&s1 とすることは非合法です。

構造体のメンバーは他の構造体を含むことができ、また自分自身の構造体型を指すポインタを含むこともできます。通常、このようなポインタは、リンクリストやツリーなどのより高度なデータ構造を実装するために使用されます。

//この構造体の宣言には他の構造体が含まれています
struct COMPLEX
{
    char string[100];
    struct SIMPLE a;
};

//この構造体の宣言には自分自身の型を指すポインタが含まれています
struct NODE
{
    char string[100];
    struct NODE *next_node;
};

2つの構造体が互いに含み合う場合、一方の構造体を不完全宣言する必要があります。次のようになります：

struct B;    //構造体Bの不完全宣言を行います

//構造体Aには構造体Bを指すポインタが含まれます
struct A
{
    struct B *partner;
    //other members;
};

//構造体Bには構造体Aを指すポインタが含まれます。Aの宣言後、Bも続けて宣言されます
struct B
{
    struct A *partner;
    //other members;
};

構造体変数の初期化

他の型の変数と同様に、構造体変数は定義時に初期値を指定できます。

実例

#include <stdio.h>

struct Books
{
   char  title[50];
   char  author[50];
   char  subject[100];
   int   book_id;
} book = {"C 言語", "RUNOOB", "プログラミング言語", 123456};

int main()
{
    printf("title : %s\nauthor: %s\nsubject: %s\nbook_id: %d\n", book.title, book.author, book.subject, book.book_id);
}

実行出力結果は次のとおりです：

title : C 语言
author: RUNOOB
subject: 编程语言
book_id: 123456

構造体メンバーへのアクセス

構造体のメンバーにアクセスするには、メンバーアクセス演算子（.）を使用します。メンバーアクセス演算子は、構造体変数名とアクセスしたい構造体メンバーとの間にあるピリオドです。structキーワードを使用して構造体型の変数を定義できます。次の例は構造体の使い方を示しています：

実例

#include <stdio.h>
#include <string.h>
 
struct Books
{
   char  title[50];
   char  author[50];
   char  subject[100];
   int   book_id;
};
 
int main( )
{
   struct Books Book1;        /* Book1 を宣言、型は Books */
   struct Books Book2;        /* Book2 を宣言、型は Books */
 
   /* Book1 の詳細 */
   strcpy( Book1.title, "C Programming");
   strcpy( Book1.author, "Nuha Ali");
   strcpy( Book1.subject, "C Programming Tutorial");
   Book1.book_id = 6495407;

   /* Book2 の詳細 */
   strcpy( Book2.title, "Telecom Billing");
   strcpy( Book2.author, "Zara Ali");
   strcpy( Book2.subject, "Telecom Billing Tutorial");
   Book2.book_id = 6495700;
 
   /* Book1 の情報を出力 */
   printf( "Book 1 title : %s\n", Book1.title);
   printf( "Book 1 author : %s\n", Book1.author);
   printf( "Book 1 subject : %s\n", Book1.subject);
   printf( "Book 1 book_id : %d\n", Book1.book_id);

   /* Book2 の情報を出力 */
   printf( "Book 2 title : %s\n", Book2.title);
   printf( "Book 2 author : %s\n", Book2.author);
   printf( "Book 2 subject : %s\n", Book2.subject);
   printf( "Book 2 book_id : %d\n", Book2.book_id);

   return 0;
}

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

Book 1 title : C Programming
Book 1 author : Nuha Ali
Book 1 subject : C Programming Tutorial
Book 1 book_id : 6495407
Book 2 title : Telecom Billing
Book 2 author : Zara Ali
Book 2 subject : Telecom Billing Tutorial
Book 2 book_id : 6495700

関数パラメータとしての構造体

構造体を関数パラメータとして渡すことができます。渡し方は他の型の変数やポインタと同様です。上記の例の方法で構造体変数にアクセスできます：

実例

#include <stdio.h>
#include <string.h>
 
struct Books
{
   char  title[50];
   char  author[50];
   char  subject[100];
   int   book_id;
};

/* 関数宣言 */
void printBook( struct Books book );
int main( )
{
   struct Books Book1;        /* Book1 を宣言、型は Books */
   struct Books Book2;        /* Book2 を宣言、型は Books */
 
   /* Book1 の詳細 */
   strcpy( Book1.title, "C Programming");
   strcpy( Book1.author, "Nuha Ali");
   strcpy( Book1.subject, "C Programming Tutorial");
   Book1.book_id = 6495407;

   /* Book2 の詳細 */
   strcpy( Book2.title, "Telecom Billing");
   strcpy( Book2.author, "Zara Ali");
   strcpy( Book2.subject, "Telecom Billing Tutorial");
   Book2.book_id = 6495700;
 
   /* Book1 の情報を出力 */
   printBook( Book1 );

   /* Book2 の情報を出力 */
   printBook( Book2 );

   return 0;
}
void printBook( struct Books book )
{
   printf( "Book title : %s\n", book.title);
   printf( "Book author : %s\n", book.author);
   printf( "Book subject : %s\n", book.subject);
   printf( "Book book_id : %d\n", book.book_id);
}

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

Book title : C Programming
Book author : Nuha Ali
Book subject : C Programming Tutorial
Book book_id : 6495407
Book title : Telecom Billing
Book author : Zara Ali
Book subject : Telecom Billing Tutorial
Book book_id : 6495700

構造体を指すポインタ

構造体を指すポインタを定義できます。方法は他の型の変数を指すポインタの定義と似ています。次のようになります：

struct Books *struct_pointer;

ここで、上記で定義したポインタ変数に構造体変数のアドレスを格納できます。構造体変数のアドレスを調べるには、& 演算子を構造体名の前に置きます。次のようになります：

struct_pointer = &Book1;

構造体を指すポインタを使用して構造体のメンバーにアクセスするには、-> 演算子を使用する必要があります。次のようになります：

struct_pointer->title;

構造体ポインタを使用して上記の例を書き直してみましょう。これにより、構造体ポインタの概念を理解するのに役立ちます：

実例

#include <string.h>
 
struct Books
{
   char  title[50];
   char  author[50];
   char  subject[100];
   int   book_id;
};

/* 関数宣言 */
void printBook( struct Books *book );
int main( )
{
   struct Books Book1;        /* Book1 を宣言、型は Books */
   struct Books Book2;        /* Book2 を宣言、型は Books */
 
   /* Book1 の詳細 */
   strcpy( Book1.title, "C Programming");
   strcpy( Book1.author, "Nuha Ali");
   strcpy( Book1.subject, "C Programming Tutorial");
   Book1.book_id = 6495407;

   /* Book2 の詳細 */
   strcpy( Book2.title, "Telecom Billing");
   strcpy( Book2.author, "Zara Ali");
   strcpy( Book2.subject, "Telecom Billing Tutorial");
   Book2.book_id = 6495700;
 
   /* Book1 のアドレスを渡して Book1 の情報を出力 */
   printBook( &Book1 );

   /* Book2 のアドレスを渡して Book2 の情報を出力 */
   printBook( &Book2 );

   return 0;
}
void printBook( struct Books *book )
{
   printf( "Book title : %s\n", book->title);
   printf( "Book author : %s\n", book->author);
   printf( "Book subject : %s\n", book->subject);
   printf( "Book book_id : %d\n", book->book_id);
}

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

構造体サイズの計算

C 言語では、sizeof演算子を使用して構造体のサイズを計算できます。sizeof戻り値は、指定された型または変数のバイトサイズです。

構造体の場合、sizeof構造体の総バイト数が返されます。これにはすべてのメンバー変数のサイズと、場合によってはパディングバイトが含まれます。

次の例は、構造体のサイズを計算する方法を示しています：

実例

#include <stdio.h>

struct Person {
    char name[20];
    int age;
    float height;
};

int main() {
    struct Person person;
    printf("構造体 Person のサイズ: %zu バイト\n", sizeof(person));
    return 0;
}

上記の例では、Personという名前の構造体を定義しました。この構造体には、文字配列name、整数age、および浮動小数点数が含まれています。height。

にmain関数内で、Person型の変数personを宣言し、次にsizeof演算子を使用してperson構造体のサイズを取得しました。

最後に、printf関数を使用して構造体のサイズを出力しました。出力結果は次のとおりです：

结构体 Person 大小为: 28 字节

注意構造体のサイズは、コンパイラの最適化やアライメント規則の影響を受ける可能性があります。コンパイラは、メモリアクセス効率を向上させるために、構造体のメンバー変数を整列するための追加のパディングバイトを構造体に挿入することがあります。そのため、構造体の実際のサイズはメンバー変数のサイズの合計よりも大きくなる場合があります。構造体のメモリレイアウトとアライメント方法を正確に把握する必要がある場合は、offsetofマクロや__attribute__((packed))属性などを使用して、構造体のサイズとアライメント方式をさらに制御および照会できます。

    構造体のメンバー変数に割り当てられるスペースは、メンバー変数の中で最も大きなスペースを占めるものを割り当て単位とします。同様に、メンバー変数の格納スペースも割り当て単位をまたぐことはできません。現在のスペースが不足している場合は、次の割り当て単位に格納されます。

    #include <stdio.h>

typedef struct
{
    unsigned char a;
    unsigned int  b;
    unsigned char c;
} debug_size1_t;
typedef struct
{
    unsigned char a;
    unsigned char b;
    unsigned int  c;
} debug_size2_t;

int main(void)
{
    printf("debug_size1_t size=%lu,debug_size2_t size=%lu\r\n", sizeof(debug_size1_t), sizeof(debug_size2_t));
    return 0;
}

    コンパイル実行の出力結果：

    debug_size1_t size=12,debug_size2_t size=8

    構造体が占有する格納スペース（32ビット機を例とする）

    • 1.debug_size1_t の格納スペース分布は a(1byte)+空き(3byte)+b(4byte)+c(1byte)+空き(3byte)=12(byte) です。
    • 1.debug_size2_t の格納スペース分布は a(1byte)+b(1byte)+空き(2byte)+c(4byte)=8(byte) です。

    構造体配列

    1つの構造体変数には一組のデータ（例えば、学生の学籍番号、名前、成績などのデータ）を格納できます。10人の学生のデータを演算する必要がある場合、明らかに配列を使用すべきであり、これが構造体配列です。構造体配列が以前に紹介した数値型配列と異なる点は、各配列要素が構造体型のデータであり、それぞれ各メンバー（成分）項目を含むことです。

    構造体配列の定義

    構造体変数を定義する方法と同様で、それが配列であることを宣言するだけでよいです。

    struct student
{
    int num;
    char name[20];
    char sex;
    int age;
    float score;
    char addr[30];
};
struct student stu[3];

    以上で配列 stu を定義しました。その要素は struct student 型のデータで、配列には3つの要素があります。構造体配列を直接定義することもできます。例：

    struct student
{
    int num;
    ....

}stu[3];

或

struct

{
    int num;
    　...
}stu[3];

    構造体配列の初期化

    他の型の配列と同様に、構造体配列は次のように初期化できます：

    struct student
{
    int mum;
    char name[20];
    char sex;
    int age;
    float score;
    char addr[30];
}stu[3] = {{10101,"Li Lin", 'M', 18, 87.5, "103 Beijing Road"},
            {10101,"Li Lin", 'M', 18, 87.5, "103 Beijing Road"},
            {10101,"Li Lin", 'M', 18, 87.5, "103 Beijing Road"}};

    配列 stu を定義するとき、要素数は指定しなくてもよく、つまり次の形式で書けます：

    stu[] = {{...},{...},{...}};

    コンパイル時に、システムは初期値を与えた構造体定数の数に基づいて配列要素の数を決定します。

    もちろん、配列の初期化は次の形式でも行えます：

    struct student
{
    int num;
    ...
};
struct student stu[] = {{...},{...},{...}};

    つまり、最初に構造体型を宣言し、次に配列をその構造体型として定義し、配列を定義するときに初期化します。

    1. 構造体変数の先頭アドレスは、その最も幅の広い基本型メンバーのサイズで割り切れる必要があります。
    2. 構造体の各メンバーの構造体先頭アドレスに対するオフセットは、メンバーサイズの整数倍である必要があります。必要に応じて、コンパイラはメンバー間にパディングバイト（internal adding）を追加します。つまり、構造体メンバーの末尾アドレスから構造体先頭アドレス（最初の構造体メンバーの先頭アドレス）を引いて得られるオフセットは、対応するメンバーサイズの整数倍でなければなりません。
    3. 構造体の総サイズは、構造体の最も幅の広い基本型メンバーのサイズの整数倍である必要があります。必要に応じて、コンパイラはメンバーの末尾にパディングバイトを追加します。

    双方向循環リスト

    双方向循環リスト（Doubly Circular Linked List）は、複数のノード（Node）で構成されるデータ構造です。各ノードは2つのポインタ（Pointer）を含み、それぞれ前のノードと次のノードを指します。最後のノードの後続は先頭ノードを指し、先頭ノードの先行は最後のノードを指し、環状構造を形成します。

    以下は、双方向循環リストの簡単な実装です。ノードの構造体と一般的な操作関数の実装を含みます：

    struct list_link_node * next;

{
    if(head==NULL)
    {
        printf("failed!\n");
        return 0;
    }
    if(head->next==head)
    {
        printf("empty!\n");
        return 0;

    listlink add_node = Display(head,FIND_MODE);//遍历
    if(add_node ==(listlink) 0)

        printf("add falied!\n");

    listlink new_node=Creat_list_node();//新建节点

    printf("请输入要添加的数据：\n");
    scanf("%d",&new_node->data);

    new_node->next=add_node->next;
    new_node->next->pre=new_node;
    new_node->pre=add_node;

    構造体のメモリアライメントの規則はとても簡単です：

    一、メンバー変数のメモリ上の相対開始位置は、データ型が占めるメモリの整数倍である必要があります（例：int 型データの相対開始位置は、構造体内で4バイトの整数倍でなければなりません）。不足する場合は、不足分のメモリをアライメントする必要があります（メモリは前の変数に補充されます）。

    二、構造体が占める総メモリは、メンバー変数の中で占有スペースが最大のデータ型の整数倍である必要があります。

    三、構造体内の各メンバーの構造体開始アドレスに対するオフセットは、そのメンバーのサイズの倍数でなければなりません。

    ここで、最も幅の広い基本型とは、long double、double、long long の中で最もスペースを占める型を指します。構造体にこれらの型のメンバーがない場合、int または char が最も幅の広い基本型となります。

    以下は、構造体のメモリアライメントのプロセスを示す例です：

    struct example {
    char a;       // 1 byte
    int b;        // 4 bytes
    double c;     // 8 bytes
    short d;      // 2 bytes
};

    メモリアライメントの規則に従って、この構造体のメンバー変数は次のように配置されます：

    ------------------------|------------------------|
|  char a                |  padding (3 bytes)      |
|------------------------|------------------------|
|  int b                 |                        |
|------------------------|------------------------|
|  double c              |                        |
|------------------------|------------------------|
|  short d               |  padding (6 bytes)      |
|------------------------|------------------------

    int と double のサイズはそれぞれ4の倍数と8の倍数であるため、それらのオフセットと構造体の総サイズは4と8で割り切れます。一方、short のサイズは2であるため、オフセットが8の要件を満たすために6バイトのパディングが必要です。
