C 入力 & 出力

私たちが言及するとき入力それはプログラムにデータを入力することを意味します。入力はファイル形式またはコマンドラインから行うことができます。C言語は、指定された入力を読み取り、必要に応じてプログラムに取り込むための組み込み関数を一連提供しています。

私たちが言及するとき出力それは画面上、プリンター上、または任意のファイルにデータを表示することを意味します。C言語は、データをコンピュータの画面に出力し、テキストファイルやバイナリファイルに保存するための組み込み関数を一連提供しています。

標準ファイル

C言語はすべてのデバイスをファイルとして扱います。したがって、デバイス（例：ディスプレイ）はファイルと同じ方法で処理されます。次の3つのファイルは、プログラムの実行時に自動的に開かれ、キーボードと画面にアクセスできるようにします。

標準ファイルファイルポインタデバイス
標準入力stdinキーボード
標準出力stdout画面
標準エラーstderrあなたの画面

ファイルポインタはファイルにアクセスする方法です。このセクションでは、キーボードから値を読み取る方法と、結果を画面に出力する方法について説明します。

C言語のI/O（入力/出力）は通常、printf()とscanf()2つの関数を使用します。

scanf() 関数は標準入力（キーボード）から読み取ってフォーマットするために使用され、printf() 関数はフォーマットされた出力を標準出力（画面）に送信します。

printf() 関数

printf() 関数は、フォーマットされたデータを標準出力デバイス（通常は画面）に出力するために使用されます。

構文：

int printf(const char *format, ...);

パラメータ：

  • format：フォーマット文字列。出力の形式を指定します。

  • ...：可変引数リスト。フォーマット文字列中のフォーマット指定子に従って、出力するデータを提供します。

例

#include <stdio.h>// printf() 関数を実行するにはこのライブラリが必要です int main() { printf("サンプル"); // 引用符の中の内容を表示します return 0; }

例の解析：

  • すべてのC言語プログラムには、main()関数を含める必要があります。コードはmain()関数から実行を開始します。
  • printf()画面へのフォーマット出力に使用されます。printf()関数は"stdio.h"ヘッダーファイル内で宣言されています。
  • stdio.hはヘッダーファイル（標準入出力ヘッダーファイル）であり、#includeはヘッダーファイルを導入するためのプリプロセッサコマンドです。printf()関数を使用するとき、ヘッダーファイルがstdio.h見つからない場合、コンパイルエラーが発生します。

%d は整数をフォーマット出力します

#include <stdio.h> int main() { int testInteger = 5; printf("Number = %d", testInteger); return 0; }

scanf() 関数

scanf() 関数は、標準入力デバイス（通常はキーボード）からフォーマットされた入力を読み取るために使用されます。

構文：

int scanf(const char *format, ...);

パラメータ：

  • format：フォーマット文字列。入力の形式を指定します。

  • ...：可変引数リスト。フォーマット文字列中のフォーマット指定子に従って、入力データを格納する変数のアドレスを提供します。

例

#include <stdio.h>

int main() {
    int a;
    float b;
    printf("Enter an integer and a float: ");
    scanf("%d %f", &a, &b);
    printf("You entered: %d and %.2f\n", a, b);
    return 0;
}

上記のコードを実行し、次に入力します：

10 3.14

出力：

You entered: 10 and 3.14

文字の入出力

getchar() & putchar() 関数

int getchar(void)この関数は、画面から次に利用可能な文字を読み取り、それを整数として返します。この関数は、一度に1つの文字だけを読み取ります。このメソッドをループ内で使用して、画面から複数の文字を読み取ることができます。

int putchar(int c)この関数は、文字を画面に出力し、同じ文字を返します。この関数は、一度に1つの文字だけを出力します。このメソッドをループ内で使用して、画面に複数の文字を出力することができます。

次の例をご覧ください：

例

#include <stdio.h> int main( ) { int c; printf( "Enter a value :"); c = getchar( ); printf( "\nYou entered: "); putchar( c ); printf( "\n"); return 0; }

上記のコードがコンパイルおよび実行されると、テキストの入力を待機します。テキストを入力して Enter キーを押すと、プログラムは続行し、1つの文字だけを読み取って、次のように表示します：

$./a.out
Enter a value :サンプル

You entered: r

文字列の入出力

gets() と fgets() 関数

gets() 関数は標準入力デバイスから1行の文字列を読み取るために使用されますが、バッファオーバーフローを引き起こしやすいため推奨されません。推奨されるのはfgets()関数です。

構文：

char *fgets(char *str, int n, FILE *stream);

パラメータ：

  • str：文字配列を指すポインタ。読み取った文字列を格納するために使用されます。

  • n：読み取る最大文字数（ヌル文字を含む\0）。

  • stream：ファイルストリーム。通常はstdin標準入力を表します。

例

#include <stdio.h>

int main() {
    char str[100];
    printf("Enter a string: ");
    fgets(str, sizeof(str), stdin);
    printf("You entered: %s", str);
    return 0;
}

puts() 関数

puts() 関数は、文字列を標準出力デバイスに出力し、末尾に自動的に改行を追加します。

構文：

int puts(const char *str);

パラメータ：

  • str：出力する文字列。

戻り値：

  • 成功時は非負の値を返し、失敗時はEOF。

例

#include <stdio.h>

int main() {
    char str[] = "Hello, World!";
    puts(str);
    return 0;
}

出力：

Hello, World!

fputs() 関数

fputs() 関数は、文字列を指定されたストリーム（標準出力、ファイルなど）に出力するために使用されますが、文字列の末尾に自動的に改行を追加しません。

構文：

int fputs(const char *str, FILE *stream);

パラメータ：

  • str：出力する文字列（ヌル文字\0で終わる文字配列）。

  • stream：出力先のストリームを指定します。標準出力（stdout）、ファイルストリームなどです。

戻り値：

  • 成功時は非負の値（通常は出力された文字数）を返します。

  • 失敗時はEOF。

特徴：

  1. 改行を追加しない：fputs()出力文字列の後に自動的に改行を追加しません。

  2. 柔軟な出力ストリーム：fputs()標準出力、ファイルなど任意のストリームに出力できます。

例

#include <stdio.h>

int main() {
    char str[] = "Hello, World!";
    fputs(str, stdout);  // "Hello, World!" を出力します。改行しません
    return 0;
}

scanf() と printf() 関数

int scanf(const char *format, ...)関数は標準入力ストリームstdinから入力を読み取り、提供されたformatフォーマットに従って入力を解析します。

int printf(const char *format, ...)関数は出力を標準出力ストリームに書き込みstdout 、提供されたフォーマットに従って出力を生成します。

formatこれは単純な定数文字列でも構いませんが、%s、%d、%c、%f などを指定して、文字列、整数、文字、浮動小数点数を出力または読み取ることができます。他にも多くのフォーマットオプションがあり、必要に応じて使用できます。完全な詳細については、これらの関数のリファレンスマニュアルを参照してください。それでは、次の簡単な例を通して理解を深めましょう：

例

#include <stdio.h> int main( ) { char str[100]; int i; printf( "Enter a value :"); scanf("%s %d", str, &i); printf( "\nYou entered: %s %d ", str, i); printf("\n"); return 0; }

上記のコードがコンパイルおよび実行されると、テキストの入力を待機します。テキストを入力して Enter キーを押すと、プログラムは続行して入力を読み取り、次のように表示します：

$./a.out
Enter a value :サンプル 123

You entered: サンプル 123

ここで注意すべきは、scanf() は入力の形式が指定した %s や %d と同じであることを期待しているということです。つまり、有効な入力、例えば "string integer" を提供する必要があります。"string string" や "integer integer" を提供した場合、誤った入力とみなされます。また、文字列を読み取る際、scanf() は空白文字に遭遇すると読み取りを停止するため、"this is test" は scanf() にとって3つの文字列となります。

ファイルの入出力

C言語にはファイル入出力の機能も用意されており、ファイルからデータを読み取ったり、ファイルにデータを書き込んだりすることができます。

fopen() 関数

構文：

FILE *fopen(const char *filename, const char *mode);

パラメータ：

  • filename：開くファイル名。

  • mode：ファイルを開くモード。例："r"（読み取り専用）、"w"（書き込み専用）、"a"（追加）など。

戻り値：

  • 成功時には、FILEオブジェクトへのポインタを返し、失敗時にはNULL。

fclose() 関数

fclose() 関数は開かれているファイルを閉じるために使用されます。

構文：

int fclose(FILE *stream);

パラメータ：

  • stream：オブジェクトへのFILEポインタ。

戻り値：

  • 成功時には0、失敗時にはEOF。

例

#include <stdio.h>

int main() {
    FILE *file;
    file = fopen("example.txt", "w");
    if (file != NULL) {
        fprintf(file, "Hello, world!\n");
        fclose(file);
    }

    char buffer[100];
    file = fopen("example.txt", "r");
    if (file != NULL) {
        fgets(buffer, sizeof(buffer), file);  // 1行全体を読み取る
        printf("Read from file: %s", buffer);  // fgets は改行文字を保持する
        fclose(file);
    }
    return 0;
}

出力内容：

Read from file: Hello, world!
