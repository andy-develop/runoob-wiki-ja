C 入力 & 出力

私たちが言及するとき入力それはプログラムにデータを入力することを意味します。入力はファイル形式またはコマンドラインから行うことができます。C言語は、指定された入力を読み取り、必要に応じてプログラムに取り込むための組み込み関数を一連提供しています。

私たちが言及するとき出力それは画面上、プリンター上、または任意のファイルにデータを表示することを意味します。C言語は、データをコンピュータの画面に出力し、テキストファイルやバイナリファイルに保存するための組み込み関数を一連提供しています。

標準ファイル

C言語はすべてのデバイスをファイルとして扱います。したがって、デバイス（例：ディスプレイ）はファイルと同じ方法で処理されます。次の3つのファイルは、プログラムの実行時に自動的に開かれ、キーボードと画面にアクセスできるようにします。

標準ファイルファイルポインタデバイス
標準入力stdinキーボード
標準出力stdout画面
標準エラーstderrあなたの画面

ファイルポインタはファイルにアクセスする方法です。このセクションでは、キーボードから値を読み取る方法と、結果を画面に出力する方法について説明します。

C言語のI/O（入力/出力）は通常、printf() 和 scanf()2つの関数を使用します。

scanf() 関数は標準入力（キーボード）から読み取ってフォーマットするために使用され、printf() 関数はフォーマットされた出力を標準出力（画面）に送信します。

printf() 関数

printf() 関数は、フォーマットされたデータを標準出力デバイス（通常は画面）に出力するために使用されます。

構文：

int printf(const char *format, ...);

パラメータ：

  • format：フォーマット文字列。出力の形式を指定します。

  • ...：可変引数リスト。フォーマット文字列中のフォーマット指定子に従って、出力するデータを提供します。

例

#include <stdio.h>// printf() 関数を実行するにはこのライブラリが必要です int main() { printf("菜鸟教程"); // 引用符の中の内容を表示します return 0; }

scanf() 関数

scanf() 関数は、標準入力デバイス（通常はキーボード）からフォーマットされた入力を読み取るために使用されます。

構文：

int scanf(const char *format, ...);

パラメータ：

  • format：フォーマット文字列。入力の形式を指定します。

  • ...：可変引数リスト。フォーマット文字列中のフォーマット指定子に従って、入力データを格納する変数のアドレスを提供します。

例

#include <stdio.h>

int main() {
    int a;
    float b;
    printf("Enter an integer and a float: ");
    scanf("%d %f", &a, &b);
    printf("You entered: %d and %.2f\n", a, b);
    return 0;
}

上記のコードを実行し、次に入力します：

10 3.14

出力：

You entered: 10 and 3.14

文字の入出力

getchar() & putchar() 関数

int getchar(void)この関数は、画面から次に利用可能な文字を読み取り、それを整数として返します。この関数は、一度に1つの文字だけを読み取ります。このメソッドをループ内で使用して、画面から複数の文字を読み取ることができます。

int putchar(int c)この関数は、文字を画面に出力し、同じ文字を返します。この関数は、一度に1つの文字だけを出力します。このメソッドをループ内で使用して、画面に複数の文字を出力することができます。

次の例をご覧ください：

例

#include <stdio.h> int main( ) { int c; printf( "Enter a value :"); c = getchar( ); printf( "\nYou entered: "); putchar( c ); printf( "\n"); return 0; }

上記のコードがコンパイルおよび実行されると、テキストの入力を待機します。テキストを入力して Enter キーを押すと、プログラムは続行し、1つの文字だけを読み取って、次のように表示します：

$./a.out

You entered: r

文字列の入出力

gets() と fgets() 関数

gets() 関数は標準入力デバイスから1行の文字列を読み取るために使用されますが、バッファオーバーフローを引き起こしやすいため推奨されません。推奨されるのはfgets()関数です。

構文：

char *fgets(char *str, int n, FILE *stream);

パラメータ：

  • str：文字配列を指すポインタ。読み取った文字列を格納するために使用されます。

  • n：読み取る最大文字数（ヌル文字を含む\0）。

  • stream：ファイルストリーム。通常はstdin標準入力を表します。

例

#include <stdio.h>

int main() {
    char str[100];
    printf("Enter a string: ");
    fgets(str, sizeof(str), stdin);
    printf("You entered: %s", str);
    return 0;
}

puts() 関数

puts() 関数は、文字列を標準出力デバイスに出力し、末尾に自動的に改行を追加します。

構文：

int puts(const char *str);

パラメータ：

  • str：出力する文字列。

戻り値：

  • 成功時は非負の値を返し、失敗時はEOF。

例

#include <stdio.h>

int main() {
    char str[] = "Hello, World!";
    puts(str);
    return 0;
}

出力：

Hello, World!

fputs() 関数

fputs() 関数は、文字列を指定されたストリーム（標準出力、ファイルなど）に出力するために使用されますが、文字列の末尾に自動的に改行を追加しません。

構文：

int fputs(const char *str, FILE *stream);

パラメータ：

  • str：出力する文字列（ヌル文字\0で終わる文字配列）。

  • stream：出力先のストリームを指定します。標準出力（stdout）、ファイルストリームなどです。

戻り値：

  • 成功時は非負の値（通常は出力された文字数）を返します。

  • 失敗時はEOF。

特徴：

  1. 改行を追加しない：fputs()出力文字列の後に自動的に改行を追加しません。

  2. 柔軟な出力ストリーム：fputs()標準出力、ファイルなど任意のストリームに出力できます。

例

#include <stdio.h>

int main() {
    char str[] = "Hello, World!";
    fputs(str, stdout);  // "Hello, World!" を出力します。改行しません
    return 0;
}

scanf() と printf() 関数

int scanf(const char *format, ...)関数は標準入力ストリームstdinから入力を読み取り、提供されたformatフォーマットに従って入力を解析します。

int printf(const char *format, ...)関数は出力を標準出力ストリームに書き込みstdout 、提供されたフォーマットに従って出力を生成します。

formatこれは単純な定数文字列でも構いませんが、%s、%d、%c、%f などを指定して、文字列、整数、文字、浮動小数点数を出力または読み取ることができます。他にも多くのフォーマットオプションがあり、必要に応じて使用できます。完全な詳細については、これらの関数のリファレンスマニュアルを参照してください。それでは、次の簡単な例を通して理解を深めましょう：

例

#include <stdio.h> int main( ) { char str[100]; int i; printf( "Enter a value :"); scanf("%s %d", str, &i); printf( "\nYou entered: %s %d ", str, i); printf("\n"); return 0; }

上記のコードがコンパイルおよび実行されると、テキストの入力を待機します。テキストを入力して Enter キーを押すと、プログラムは続行して入力を読み取り、次のように表示します：

$./a.out
Enter a value :runoob 123

You entered: runoob 123

ここで注意すべきは、scanf() は入力の形式が指定した %s や %d と同じであることを期待しているということです。つまり、有効な入力、例えば "string integer" を提供する必要があります。"string string" や "integer integer" を提供した場合、誤った入力とみなされます。また、文字列を読み取る際、scanf() は空白文字に遭遇すると読み取りを停止するため、"this is test" は scanf() にとって3つの文字列となります。

ファイルの入出力

C言語にはファイル入出力の機能も用意されており、ファイルからデータを読み取ったり、ファイルにデータを書き込んだりすることができます。

fopen() 関数

に変更しました。

構文：

FILE *fopen(const char *filename, const char *mode);

パラメータ：

  • filename：開くファイル名。

  • mode：ファイルを開くモード。例："r"（読み取り専用）、"w"（書き込み専用）、"a"（追加）など。

戻り値：

  • 成功時には、FILEオブジェクトへのポインタを返し、失敗時にはNULL。

fclose() 関数

fclose() 関数は開かれているファイルを閉じるために使用されます。

構文：

int fclose(FILE *stream);

パラメータ：

  • stream：オブジェクトへのFILEポインタ。

戻り値：

  • 成功時には0、失敗時にはEOF。

例

#include <stdio.h>

int main() {
    FILE *file;
    file = fopen("example.txt", "w");
    if (file != NULL) {
        fprintf(file, "Hello, world!\n");
        fclose(file);
    }

    char buffer[100];
    file = fopen("example.txt", "r");
    if (file != NULL) {
        fgets(buffer, sizeof(buffer), file);  // 1行全体を読み取る
        printf("Read from file: %s", buffer);  // fgets は改行文字を保持する
        fclose(file);
    }
    return 0;
}

出力内容：

Read from file: Hello, world!

    gets()

    gets関数のプロトタイプ：char*gets(char*buffer);//文字を配列に読み込む：gets(str);strは配列名です。

    Windows、Unix、Mac の異なるオペレーティングシステムの改行の問題 復帰文字\rと改行文字\n

    一、概念：

    改行文字'\n'和復帰文字'\r'

    （1）改行文字は新しい行に移ることです --- '\n' 10 改行（newline）

    （2）復帰文字は行の先頭に戻ることです --- '\r' 13 復帰（return）

    したがって、普段ファイルに記述する復帰文字は、正確には復帰改行文字

    CR: 復帰(Carriage Return) \rLF: 改行(Line Feed) \n

    二、応用：

    （1）マイクロソフトのMS-DOSとWindowsでは、「復帰CR('\r')」と「改行LF('\n')」の2つの文字を改行文字として使用します。

    （2）Windowsシステムでは、各行の末尾は 復帰+改行(CR+LF)、すなわち「\r\n」です。

    （3）Unixシステムでは、各行の末尾は 改行LF のみ、すなわち「\n」です。

    （4）Macシステムでは、各行の末尾は 復帰CR、すなわち'\r'です。

    Mac OS 9 以前のシステムの改行文字は CR で、Mac OS X （後に「OS X」と改名）以降の改行文字は LF、すなわち'\n'であり、Unix/Linuxと統一されました。

    三、影響：

    （1）直接的な結果として、Unix/MacシステムのファイルをWindowsで開くと、すべての文字が1行になります。

    （2）一方、WindowsのファイルをUnix/Macで開くと、各行の末尾に^M記号が1つ余分に付くことがあります。

    （3）Linuxで保存したファイルをWindowsのメモ帳で見ると、黒い点が表示されることがあります。

    四、相互変換が可能：

    Linuxでは、unix2dos コマンドはLinuxファイル形式をWindowsファイル形式に変換し、dos2unix コマンドはWindows形式をLinuxファイル形式に変換します。

    異なるプラットフォーム間でFTPソフトウェアを使用してファイルを転送する場合、asciiテキストモードの転送モードでは、一部のFTPクライアントプログラムが自動的に改行形式を変換します。このような転送を行ったファイルのバイト数は変化する可能性があります。

    ftpに元のファイルを変更されたくない場合は、binモード（バイナリモード）でテキストを転送できます。

    プログラムがWindows上で実行されるとCR/LF改行形式のテキストファイルが生成され、Linux上で実行されるとLF形式で改行されたテキストファイルが生成されます。

    int i;

    出力を行う際に、実数を出力するために使用するf書式指定子（小数形式で出力）には、以下のいくつかの使い方があります：

    1、基本型。 %f

    出力型の長さを指定せず、システムが状況に応じて決定します。一般的には実数の整数部分をすべて出力し、小数部分は6桁出力します。例：

    #include<stdio.h>
int main()
{
    double a=1.0;
    printf("%f\n",a/3);
    return 0;
}

    実行結果：0.333333

    2、データ幅と小数桁数を指定する。%m.nf

    例：前のプログラムの double 型変数 a を小数15桁で出力するには、%20.15fの書式指定を使用し、出力データが20列を占めるように指定します。その中には小数15桁が含まれます。上記のプログラムを次のように変更します：

    #include<stdio.h>
int main()
{
    double a=1.0;
    printf("%20.15f\n",a/3);
    return 0;
}

    実行結果：   0.333333333333333

    0 の前にはスペースが3つあり、double 型の数は有効数字15桁の正確さしか保証されないことに注意してください。

    3、出力データを左揃えにするには、%-m.nf

    在 m.nの前にマイナス記号を付けます。その働きは%m.nf形式と基本的に同じですが、データの長さがmを超えない場合、データは左に寄せられ、右端にスペースが補われます。

    gets() & puts() 関数

    gets() を使用すると警告が表示されます：

    warning: this program uses gets(), which is unsafe.

    gets() が安全でないのは、バッファサイズが指定されていないためです。fgets() を使用できます。

    char* fgets(char *buf, int bufsize, FILE *stream);
    • buf：文字型ポインタ。取得したデータを格納するためのアドレスを指します。
    • bufsize：整数型データ。バッファのサイズを示し、buf アドレスにコピーされる最大文字数です。
    • stream：入力ストリームの FILE オブジェクトへのポインタを示します。stdin をパラメータとして使用でき、標準入力から読み取ることを表します。

    戻り値：成功した場合、関数は buf を返します。

    文字の読み取りを試みたときにファイルの終端に達した場合、eof が設定され(feof)、まだどの文字も正常に読み取っていない状態でファイルの終端に達した場合は、null が返され、buff の内容は変更されません。読み取りエラーが発生した場合、error indicator(ferror) が設定され、やはり null が返されます。

    C言語では、各データ型の出力にはそれぞれのプレースホルダーがあります。以下はさまざまなデータ型の出力プレースホルダーです：

    short/int : %d

    int a = 1;
printf("这个整数是：%d", a);

    long: %ld(long は int の修飾であり、独立したデータ型とは言えません。int より4バイト多い記憶領域を持つだけです)

    long long : %lld

    char : %c

    float/double : %ffloat はデフォルトで小数6桁まで出力されます。%f で制御できます。例：%.2f：小数2桁を出力します。

    char *s(文字列)：%s

    unsigned: %u(signed：符号付き型、unsigned：符号なし型。デフォルトではすべて符号付きです)

    8進数：%o 以 0先頭

    16進数：%x 以 0x先頭

    int a = 10;
printf("a的八进制输出是：%o \n", a);//输出是12
printf("a的十六进制输出：%x \n", a);//输出是a

    アドレス値/ポインタ値：%p，*ポインタ内のアドレスが指す場所の値を取得します。&その値が格納されている位置のアドレス値を取得します。

    2進数の出力にはプレースホルダーがなく、他の方法を使うしかありません。
