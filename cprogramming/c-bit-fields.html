C ビットフィールド

C 言語のビットフィールド（bit-field）は特別な構造体メンバーであり、ビット単位でメンバーを定義して、その占有ビット数を指定することができます。

プログラムの構造体に複数のスイッチ用変数が含まれる場合、つまり変数の値がTRUE/FALSE、次のようになります：

struct
{
  unsigned int widthValidated;
  unsigned int heightValidated;
} status;

この構造体は8バイトのメモリ空間を必要としますが、実際には各変数には 0 か 1 しか格納しません。

このような場合、C 言語はメモリ空間をより有効に利用する方法を提供します。構造体内でそのような変数を使用するとき、変数の幅を定義して、これらのビットだけを使用することをコンパイラに伝えることができます。

例えば、上記の構造体は次のように書き直すことができます：

struct
{
  unsigned int widthValidated : 1;
  unsigned int heightValidated : 1;
} status;

これで、status 変数は4バイトのメモリ空間しか占有しませんが、そのうち値の格納に使用されるのはわずか2ビットです。

幅1ビットの変数を32個使用する場合、status 構造体は依然として4バイトしか占有しません。しかし33個の変数を使用すると、33ビット目はメモリの次の記憶域に割り当てられ、構造体全体が8バイトを占有し始めます。

この概念を理解するために、次の例を見てみましょう：

例

#include <stdio.h>
#include <string.h>

/* 単純な構造体を定義 */
struct
{
  unsigned int widthValidated;
  unsigned int heightValidated;
} status1;

/* ビットフィールド構造体を定義 */
struct
{
  unsigned int widthValidated : 1;
  unsigned int heightValidated : 1;
} status2;
 
int main( )
{
   printf( "Memory size occupied by status1 : %zu\n", sizeof(status1));
   printf( "Memory size occupied by status2 : %zu\n", sizeof(status2));

   return 0;
}

上記のコードをコンパイルして実行すると、次の結果が生成されます：

Memory size occupied by status1 : 8
Memory size occupied by status2 : 4

次の表は、ビットフィールドの特徴と使用方法をまとめたものです：

特徴説明
幅の指定ビットフィールドを定義するとき、メンバーのビットフィールド幅、つまりメンバーが占有するビット数を指定できます。
幅の上限ビットフィールドの幅は、そのデータ型のサイズを超えることはできません。ビットフィールドは使用する整数型に適合する必要があるためです。
データ型標準 C では、int、unsigned int、signed intなどの整数型です。他の型（列挙型など）を使用する場合は、コンパイラの実装に依存するため、移植性が低くなります。
組み合わせ方ビットフィールドは単独で使用することも、他の通常のメンバーと一緒に構造体を構成することもできます。
アクセス方法ドット演算子（.）またはポインタのアロー演算子（->）を使用してアクセスします。通常の構造体メンバーへのアクセス方法と同じです。

ビットフィールドの宣言

一部の情報は保存時に完全な1バイトを占有する必要はなく、数ビットまたは1ビットを占有するだけで済みます。例えばスイッチ値を格納する場合、0 と 1 の2つの状態しかないため、1ビットで十分です。記憶領域を節約し、処理を簡単にするために、C 言語は「ビットフィールド」または「ビットセグメント」と呼ばれるデータ構造を提供しています。

いわゆる「ビットフィールド」とは、1バイト内のビットをいくつかの異なる領域に分割し、各領域のビット数を示すものです。各フィールドにはフィールド名があり、プログラム内でフィールド名によって操作できます。これにより、複数の異なるオブジェクトを1バイトのビットフィールドで表現できます。

典型的な例：1ビットでスイッチ値を格納する場合、0 と 1 の2つの状態しかありません。

外部ファイル形式の読み取り——標準以外のファイル形式（例えば9ビットの整数）を読み取ることができます。

ビットフィールドの定義とビットフィールド変数の説明

ビットフィールドの定義は構造体の定義に似ており、その形式は次のとおりです：

struct 位域结构名 
{

 位域列表

};

その中のビットフィールドリストの形式は次のとおりです：

type [member_name] : width ;

以下は、ビットフィールド内の変数要素に関する説明です：

要素説明
type型は int（整数型）、unsigned int（符号なし整数型）、signed int（符号付き整数型）の3つだけです。これにより、ビットフィールドの値がどのように解釈されるかが決まります。
member_nameビットフィールドの名前。
widthビットフィールド内のビット数。幅は指定された型のビット幅以下でなければなりません。

事前に定義された幅を持つ変数はビットフィールドと呼ばれます。ビットフィールドは1ビットより多い数を格納できます。例えば、0 から 7 までの値を格納する変数が必要な場合、幅3ビットのビットフィールドを次のように定義できます：

struct
{
  unsigned int age : 3;
} Age;

上記の構造体定義は C コンパイラに、age 変数がこの値を格納するために3ビットだけを使用することを指示します。

代入された値が3ビットで表現できる範囲を超える場合、超過分は切り捨てられます（下記の例2を参照）。

struct bs{
    int a:8;
    int b:2;
    int c:6;
}data;

上記のコードは、struct bsという構造体を定義しており、data は bs 型の構造体変数で、合計4バイトを占めます。

ビットフィールドの場合、その幅はデータ型のサイズを超えることはできません。int 型のサイズは通常4バイト（32ビット）です。

隣接するビットフィールドの型が同じ場合、ビット幅の合計が型のサイズを超えなければ、後続のフィールドは直前のフィールドの直後に格納され、格納できなくなるまで続きます。

もう一つ例を見てみましょう：

ここで、packed_struct には6つのメンバーが含まれます：4つの1ビットの識別子 f1..f4、1つの4ビットの type、そして1つの9ビットの my_int です。

次の例を見てみましょう：

例 1

#include <stdio.h>

struct packed_struct {
   unsigned int f1 : 1;   // 1ビットのビットフィールド
   unsigned int f2 : 1;   // 1ビットのビットフィールド
   unsigned int f3 : 1;   // 1ビットのビットフィールド
   unsigned int f4 : 1;   // 1ビットのビットフィールド
   unsigned int type : 4; // 4ビットのビットフィールド
   unsigned int my_int : 9; // 9ビットのビットフィールド
};

int main() {
   struct packed_struct pack;

   pack.f1 = 1;
   pack.f2 = 0;
   pack.f3 = 1;
   pack.f4 = 0;
   pack.type = 7;
   pack.my_int = 255;

   printf("f1: %u\n", pack.f1);
   printf("f2: %u\n", pack.f2);
   printf("f3: %u\n", pack.f3);
   printf("f4: %u\n", pack.f4);
   printf("type: %u\n", pack.type);
   printf("my_int: %u\n", pack.my_int);

   return 0;
}

上記の例は、packed_struct という名前の構造体を定義しており、複数のビットフィールドメンバーが含まれています。

main 関数内で、packed_struct 型の構造体変数 pack を作成し、各ビットフィールドメンバーにそれぞれ値を代入しています。

次に、printf 文を使用して各ビットフィールドメンバーの値を出力しています。

出力結果は次のとおりです：

f1: 1
f2: 0
f3: 1
f4: 0
type: 7
my_int: 255

例 2

#include <stdio.h>
#include <string.h>

struct
{
  unsigned int age : 3;
} Age;

int main( )
{
   Age.age = 4;
   printf( "Sizeof( Age ) : %zu\n", sizeof(Age) );
   printf( "Age.age : %d\n", Age.age );

   Age.age = 7;
   printf( "Age.age : %d\n", Age.age );

上記のコードはコンパイル時に切り捨て警告が発生しますが、実行すると次の結果が生成されます：

Sizeof( Age ) : 4
Age.age : 4
Age.age : 7
Age.age : 0

バイト数の計算：

例

#include <stdio.h>

struct example1 {
   int a : 4;
   int b : 5;
   int c : 7;
};

int main() {
   struct example1 ex1;

   printf("Size of example1: %zu bytes\n", sizeof(ex1));

   return 0;
}

上記の例では、example1 構造体には3つのビットフィールドメンバー a、b、c が含まれており、それぞれ4ビット、5ビット、7ビットを占有します。

sizeof 演算子を使用して example1 構造体のバイト数を計算し、結果を出力します：

Size of example1: 4 bytes

ビットフィールドの定義については、以下の点を説明します：

  • ビットフィールドメンバーは可能な限り同じ記憶域に格納されます。その記憶域に次のビットフィールドを格納するための十分なスペースが残っていない場合は、次の記憶域からそのビットフィールドを格納します。

    特定のビットフィールドを意図的に次の記憶域から格納することもできます。例えば：

    struct bs{
    unsigned a:4;
    unsigned  :4;    /* 空域 */
    unsigned b:4;    /* 从下一单元开始存放 */
    unsigned c:4;
};

    このビットフィールド定義では、a は最初のバイトの4ビットを占有し、後の4ビットは使用しないことを示すために0が入ります。b は2番目のバイトから始まり4ビットを占有し、c は4ビットを占有します。

  • ビットフィールドの幅は、それが依存するデータ型の長さを超えることはできません。メンバー変数にはすべて型があり、この型がメンバー変数の最大長を制限します。:後ろの数字はこの長さを超えることはできません。

  • ビットフィールドは無名ビットフィールドにすることができます。この場合、それはパディングまたは位置調整にのみ使用されます。無名ビットフィールドは使用できません。例えば：

    struct k{
    int a:1;
    int  :2;    /* 该 2 位不能使用 */
    int b:3;
    int c:2;
};

以上の分析からわかるように、ビットフィールドは本質的に構造体の一種であり、そのメンバーがビット単位で割り当てられている点が異なります。

ビットフィールドの使用

ビットフィールドの使用は構造体メンバーの使用と同じで、その一般的な形式は次のとおりです：

ビットフィールド変数名.ビットフィールド名
ビットフィールド変数名->ビットフィールド名

ビットフィールドはさまざまな形式で出力できます。

次の例を見てください：

例

#include <stdio.h>

int main(){
    struct bs{
        unsigned a:1;
        unsigned b:3;
        unsigned c:4;
    } bit,*pbit;
    bit.a=1;    /* ビットフィールドに代入します（代入はそのビットフィールドの許容範囲を超えないように注意してください） */
    bit.b=7;    /* ビットフィールドに代入します（代入はそのビットフィールドの許容範囲を超えないように注意してください） */
    bit.c=15;   /* ビットフィールドに代入します（代入はそのビットフィールドの許容範囲を超えないように注意してください） */
    printf("%d,%d,%d\n",bit.a,bit.b,bit.c);     /* 整数型の形式で3つのフィールドの内容を出力 */
    pbit=&bit;  /* ビットフィールド変数 bit のアドレスをポインタ変数 pbit に渡す */
    pbit->a=0;  /* ポインタを使用してビットフィールド a に再代入し、0 にする */
    pbit->b&=3; /* 複合ビット演算子 "&=" を使用しています。これは pbit->b = pbit->b & 3 と同等です。ビットフィールド b の元の値は 7 で、3 とビット単位の AND を取ると結果は 3 になります（111&011=011、10進数では3） */
    pbit->c|=1; /* 複合ビット演算子 "|=" を使用しています。これは pbit->c = pbit->c | 1 と同等で、結果は15になります */
    printf("%d,%d,%d\n",pbit->a,pbit->b,pbit->c);       /* ポインタを使用してこれら3つのフィールドの値を出力 */
    return 0;
}

上記のコードをコンパイルして実行すると、次の結果が生成されます：

1,7,15
0,3,15

上記の例のプログラムでは、ビットフィールド構造体 bs を定義し、3つのビットフィールド a、b、c と、bs 型の変数 bit、および bs 型を指すポインタ変数 pbit を定義しています。

これは、ビットフィールドでもポインタを使用できることを示しています。
