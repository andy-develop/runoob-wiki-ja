C 文字列

C言語では、文字列は実際にはヌル文字を使用する\0末尾で終わる一次元文字配列です。したがって、\0は文字列の終わりを示すために使用されます。

ヌル文字（Null character）は終端記号とも呼ばれ、略称はNULであり、値が0の制御文字です。\0はエスケープ文字であり、コンパイラにこれが文字0ではなく、ヌル文字であることを伝えます。

以下の宣言と初期化は、RUNOOB文字列を作成します。配列の末尾にヌル文字が格納されているため、\0文字配列のサイズは単語RUNOOBの文字数より1つ多くなります。

char site[7] = {'R', 'U', 'N', 'O', 'O', 'B', '\0'};

配列の初期化規則に従って、上記の文を次のように書くことができます：

char site[] = "RUNOOB";

以下は C/C++ で定義された文字列のメモリ表現です：

実際には、null文字を文字列定数の末尾に置く必要はありません。Cコンパイラは配列を初期化するときに、自動的に\0を文字列の末尾に置きます。上の文字列を出力してみましょう：

例

#include <stdio.h> int main () { char site[7] = {'R', 'U', 'N', 'O', 'O', 'B', '\0'}; printf("菜鸟教程: %s\n", site ); return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

菜鸟教程: RUNOOB

Cには文字列を操作する関数が多数あります：

番号関数 & 目的
1strcpy(s1, s2);
文字列 s2 を文字列 s1 にコピーします。
2strcat(s1, s2);
文字列 s2 を文字列 s1 の末尾に連結します。
3strlen(s1);
文字列 s1 の長さを返します。
4strcmp(s1, s2);
s1 と s2 が同じ場合は 0 を返し、s1<s2 の場合は 0 より小さい値を返し、s1>s2 の場合は 0 より大きい値を返します。
5strchr(s1, ch);
文字列 s1 内で文字 ch が最初に現れる位置を指すポインタを返します。
6strstr(s1, s2);
文字列 s1 内で文字列 s2 が最初に現れる位置を指すポインタを返します。

以下の例では、上記の関数の一部を使用しています：

例

#include <stdio.h> #include <string.h> int main () { char str1[14] = "runoob"; char str2[14] = "google"; char str3[14]; int len ; /*str1 を str3 にコピー*/ strcpy(str3, str1); printf("strcpy( str3, str1) : %s\n", str3 ); /*str1 と str2 を連結*/ strcat( str1, str2); printf("strcat( str1, str2): %s\n", str1 ); /*連結後の str1 の全長*/ len = strlen(str1); printf("strlen(str1) : %d\n", len ); return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

strcpy( str3, str1) :  runoob
strcat( str1, str2):   runoobgoogle
strlen(str1) :  12

C標準ライブラリには、文字列関連の関数がさらに多数あります。

    文字列を以下のような入力で初期化する場合には、特に\0注意が必要です：

    char greeting[6] = {'H', 'e', 'l', 'l', 'o', '\0'};

    文字配列の最後に\0を追加しない場合、出力結果が正しくありません：

    // 初始化字符串
char greeting[5] = { 'H', 'e', 'l', 'l', 'o' };
printf("Greeting message: %s\n", greeting);

    出力結果：

    Greeting message: Hello烫烫烫?侵7(?╔?╚╔╔

    可変長配列を使用して文字列を初期化する場合、デフォルトの末尾は\0 

    char greeting[] = "Hello";
printf("Greeting message: %s, greeting[] Length: %d\n", greeting, sizeof(greeting));

    出力結果：

    Greeting message: Hello, greeting[] Length: 6

    結論：文字配列のサイズを指定する際は、元の文字列の文字数に 1 を加える必要があります。

    strlen と sizeof の違い：

    strlen は関数であり、sizeof は演算子です。両者の結果の型は size_t、つまり unsigned int 型です。

    sizeof は変数のサイズを計算し、文字\0の影響を受けません；

    一方、strlen は文字列の長さを計算し、\0を長さの判定基準とします。

    sizeof() と strlen() について
    • 1、sizeof()文字列の長さを計算し、末尾の'\0'
    • 2、strlen()文字列の長さを計算し、文字列末尾の'\0'

    • 例：

      #include<stdio.h>
#include<stdlib.h>
#include<string.h>

void msg()
{
    char s[] = { "hello,world!" };
    printf("s = %s\n", s);
    printf("sizeof(s) = %d\n", sizeof(s));
    printf("strlen(s) = %d\n", strlen(s));
}

int main(int argc, char* argv[], char* envp[])
{
    msg();
    return 0;
}

      出力結果：

      s = hello,world!
sizeof(s) = 13
strlen(s) = 12

    Visual C における文字列安全関数 strcpy_s と strcat_s の説明：

    MSVCではコードに安全関数を使用することが求められているため、安全関数は元の関数に比べて size_t 型のパラメータが1つ多くなっており、バッファサイズとして使用されます。したがって、_countof(dst)（ヘッダーファイル stdlib.h のインクルードが必要）を使用して、ターゲット文字列のサイズをバッファサイズとして取得できます。

    例を挙げます：

    #include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main()
{
    char s1[] = "Hello world";
    char s2[] = " from secure function";
    char dst[50]; // 此处数组大小根据实际情况调整，或通过calloc、malloc分配动态内存
    strcpy_s(dst, _countof(dst), s1);
    strcat_s(dst, _countof(dst), s2);
    printf_s(dst);
    return 0;
}

    コードの実行結果：

    Hello world from secure function
