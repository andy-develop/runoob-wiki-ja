Cライブラリ関数 -vprintf()

C標準ライブラリ - <stdio.h>

説明

Cライブラリ関数int vprintf(const char *format, va_list arg)引数リストを使用して、フォーマットされた出力を標準出力 stdout に送信します。

宣言

以下が vprintf() 関数の宣言です。

int vprintf(const char *format, va_list arg)

引数

  • format-- これは文字列で、標準出力stdoutに書き込まれるテキストを含みます。埋め込みのformatタグを含めることができ、formatタグは後続の追加引数で指定された値に置き換えられ、必要に応じてフォーマットされます。formatタグの属性は、 %[flags][width][.precision][length]specifier具体的な説明は次のとおりです：
specifier（指定子）出力
c文字
d または i符号付き10進整数
ee 文字を使用した科学的記数法（仮数と指数）
EE 文字を使用した科学的記数法（仮数と指数）
f10進浮動小数点数
g%e または %f の適切な表現を自動選択
G%E または %f の適切な表現を自動選択
o符号付き8進数
s文字列
u符号なし10進整数
x符号なし16進整数
X符号なし16進整数（大文字）
pポインタのアドレス
n出力なし
%文字

flags（フラグ）説明
-指定されたフィールド幅内で左揃えにします。デフォルトは右揃えです（width 副指定子を参照）。
+結果の前にプラス記号またはマイナス符号（+ または -）を強制的に表示します。つまり、正数の前には + 記号が表示されます。デフォルトでは、負数の前にのみ - 記号が表示されます。
(space)符号が書き込まれない場合は、値の前にスペースを挿入します。
#o、x、X 指定子と一緒に使用すると、ゼロ以外の値の前にそれぞれ 0、0x、0X が表示されます。
e、E、f と一緒に使用すると、小数点を含む出力が強制され、後ろに数字がなくても小数点が表示されます。デフォルトでは、後ろに数字がない場合、小数点は表示されません。
g または G と一緒に使用すると、結果は e または E を使用した場合と同じですが、末尾のゼロは削除されません。
0パディング（padding）の数字の左側にスペースではなくゼロ（0）を配置します（width 副指定子を参照）。

width（幅）説明
(number)出力する文字の最小数。出力される値がこの数より短い場合、結果はスペースで埋められます。出力される値がこの数より長い場合、結果は切り詰められません。
*幅が format 文字列内で指定されていない場合、フォーマットされる引数の前に追加の整数値引数として配置されます。

.precision（精度）説明
.number整数指定子（d、i、o、u、x、X）の場合：precision は書き込む数字の最小桁数を指定します。書き込まれる値がこの数より短い場合、結果は先頭ゼロで埋められます。書き込まれる値がこの数より長い場合、結果は切り詰められません。精度0は文字が書き込まれないことを意味します。
e、E、f 指定子の場合：小数点の後に出力する小数部の桁数。
g および G 指定子の場合：出力する最大有効桁数。
s の場合：出力する最大文字数。デフォルトでは、末尾のヌル文字に達するまで、すべての文字が出力されます。
c 型の場合：影響はありません。
精度が指定されていない場合、デフォルトは1です。明示的な値を付けずに指定された場合は、0とみなされます。
.*精度が format 文字列内で指定されていない場合、フォーマットされる引数の前に追加の整数値引数として配置されます。

length（長さ）説明
h引数は short 型または unsigned short 型として解釈されます（整数指定子：i、d、o、u、x、Xにのみ適用）。
l引数は long 型または unsigned long 型として解釈され、整数指定子（i、d、o、u、x、X）および指定子 c（ワイド文字を表す）と s（ワイド文字列を表す）に適用されます。
L引数は long double 型として解釈されます（浮動小数点指定子：e、E、f、g、Gにのみ適用）。
  • arg-- 可変引数リストを表すオブジェクト。これは <stdarg> で定義されている va_start マクロで初期化する必要があります。

戻り値

成功した場合は書き込まれた文字の総数を返し、そうでない場合は負の数を返します。

例

以下の例は、vprintf() 関数の使用方法を示しています。

例

#include <stdio.h>
#include <stdarg.h>

void WriteFrmtd(char *format, ...)
{
   va_list args;
   
   va_start(args, format);
   vprintf(format, args);
   va_end(args);
}

int main ()
{
   WriteFrmtd("%d variable argument\n", 1);
   WriteFrmtd("%d variable %s\n", 2, "arguments");
   
   return(0);
}

上記のプログラムをコンパイルして実行すると、次の結果が得られます：

1 variable argument
2 variable arguments

    vprintf を使用して printf を実装します。printf と区別するため、関数を print と名付けます：

    #include<stdio.h>
//#include<stdlib.h>
#include<stdarg.h>//ANSI C可变参数的头文件

int print(char* format, ...) {
    va_list ap;
    int n;
    va_start(ap, format);
    n = vprintf(format, ap);
    va_end(ap);
    return 0;
}

int main() {
    int ch1 = 10, ch2 = 20;
    print("%d\t%d\n", ch1, ch2);
    return 0;
}
