C 標準ライブラリ -<stdio.h>

概要

stdio .hヘッダーファイルは、入出力を実行するための3つの変数型、いくつかのマクロ、およびさまざまな関数を定義しています。

<stdio.h>は C 標準ライブラリ内のヘッダーファイルであり、ファイルおよび標準入出力ストリームを処理するためのさまざまな関数と型を定義しています。

ライブラリ変数

以下はヘッダーファイル stdio.h で定義されている変数型です：

番号変数 & 説明
1size_t
これは符号なし整数型です。それはsizeofsizeof キーワードの結果であり、オブジェクトのサイズを表します。
2FILE
ファイルストリーム型。ファイルストリーム情報を格納するのに適したオブジェクト型です。
3fpos_t
ファイル位置型。ファイル内の任意の位置を格納するのに適したオブジェクト型です。

ライブラリマクロ

以下はヘッダーファイル stdio.h で定義されているマクロです：

番号マクロ & 説明
1NULL
このマクロは、ヌルポインタ定数の値です。
2_IOFBF、_IOLBF 和 _IONBF
これらのマクロは、特定の値を持つ整数定数式に展開され、setvbuf関数の3番目の引数に適用されます。
3BUFSIZ
このマクロは整数であり、setbuf関数が使用するバッファサイズを表します。
4EOF
このマクロは、ファイルの終わりに達したことを示す負の整数です。
5FOPEN_MAX
このマクロは整数であり、システムが同時に開くことができるファイルの数を表します。
6FILENAME_MAX
このマクロは整数であり、文字配列が格納できるファイル名の最大長を表します。実装に制限がない場合、この値は推奨される最大値とすべきです。
7L_tmpnam
このマクロは整数であり、文字配列が格納できる、tmpnam 関数によって作成された一時ファイル名の最大長を表します。
8SEEK_CUR、SEEK_END 和 SEEK_SET
これらのマクロは、fseek関数内で使用され、ファイル内のさまざまな位置を特定するために使われます。
9TMP_MAX
このマクロは、tmpnam 関数が生成できる一意のファイル名の最大数です。
10stderr、stdin 和 stdout
これらのマクロは FILE 型へのポインタであり、それぞれ標準エラー、標準入力、標準出力ストリームに対応します。

ライブラリ関数

以下はヘッダーファイル stdio.h で定義されている関数です：

関数をよりよく理解するために、以下の順序でこれらの関数を学習してください。最初の関数で作成されたファイルが後続の関数で使用されるためです。
番号関数 & 説明
1int fclose(FILE *stream)
ストリーム stream を閉じます。すべてのバッファをフラッシュします。
2void clearerr(FILE *stream)
指定されたストリーム stream のファイル終了およびエラー識別子をクリアします。
3int feof(FILE *stream)
指定されたストリーム stream のファイル終了識別子をテストします。
4int ferror(FILE *stream)
指定されたストリーム stream のエラー識別子をテストします。
5int fflush(FILE *stream)
ストリーム stream の出力バッファをフラッシュします。
6int fgetpos(FILE *stream, fpos_t *pos)
ストリーム stream の現在のファイル位置を取得し、それを pos に書き込みます。
7FILE *fopen(const char *filename, const char *mode)
指定されたモード mode を使用して、filename が指すファイルを開きます。
8size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream)
指定されたストリーム stream から、ptr が指す配列にデータを読み取ります。
9FILE *freopen(const char *filename, const char *mode, FILE *stream)
新しいファイル名 filename を指定された開いているストリーム stream に関連付け、同時にストリーム内の古いファイルを閉じます。
10int fseek(FILE *stream, long int offset, int whence)
ストリーム stream のファイル位置を指定されたオフセット offset に設定します。パラメータoffsetwhence は、指定されたwhence位置からシークするバイト数を意味します。
11int fsetpos(FILE *stream, const fpos_t *pos)
指定されたストリーム stream のファイル位置を指定された位置に設定します。パラメータpospos は、関数 fgetpos によって指定された位置です。
12long int ftell(FILE *stream)
指定されたストリーム stream の現在のファイル位置を返します。
13size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream)
ptr が指す配列内のデータを、指定されたストリーム stream に書き込みます。
14int remove(const char *filename)
指定されたファイル名 filename を削除して、アクセスできないようにします。
15int rename(const char *old_filename, const char *new_filename)
old_filename が指すファイル名を new_filename に変更します。
16void rewind(FILE *stream)
ファイル位置を、指定されたストリーム stream のファイルの先頭に設定します。
17void setbuf(FILE *stream, char *buffer)
ストリーム stream がどのようにバッファリングされるかを定義します。
18int setvbuf(FILE *stream, char *buffer, int mode, size_t size)
ストリーム stream がどのようにバッファリングされるかを定義する別の関数です。
19FILE *tmpfile(void)
バイナリ更新モード（wb+）で一時ファイルを作成します。
20char *tmpnam(char *str)
有効な一時ファイル名を生成して返します。このファイル名は以前は存在しません。
21int fprintf(FILE *stream, const char *format, ...)
フォーマットされた出力をストリーム stream に送信します。
22int printf(const char *format, ...)
フォーマットされた出力を標準出力 stdout に送信します。
23int sprintf(char *str, const char *format, ...)
フォーマットされた出力を文字列に送信します。
24int vfprintf(FILE *stream, const char *format, va_list arg)
引数リストを使用して、フォーマットされた出力をストリーム stream に送信します。
25int vprintf(const char *format, va_list arg)
引数リストを使用して、フォーマットされた出力を標準出力 stdout に送信します。
26int vsprintf(char *str, const char *format, va_list arg)
引数リストを使用して、フォーマットされた出力を文字列に送信します。
27int fscanf(FILE *stream, const char *format, ...)
ストリーム stream からフォーマットされた入力を受け取ります。
28int scanf(const char *format, ...)
標準入力 stdin からフォーマットされた入力を受け取ります。
29int sscanf(const char *str, const char *format, ...)
文字列からフォーマットされた入力を受け取ります。
30int fgetc(FILE *stream)
指定されたストリーム stream から次の文字（符号なし文字）を取得し、位置識別子を前に移動します。
31char *fgets(char *str, int n, FILE *stream)
指定されたストリーム stream から1行読み取り、それを str が指す文字列内に格納します。(n-1)文字を読み取ったとき、または改行文字を読み取ったとき、またはファイルの終わりに達したときに停止します。状況に応じて異なります。
32int fputc(int char, FILE *stream)
引数 char で指定された文字（符号なし文字）を指定されたストリーム stream に書き込み、位置識別子を前に移動します。
33int fputs(const char *str, FILE *stream)
指定されたストリーム stream に文字列を書き込みます。ただし、ヌル文字は含みません。
34int getc(FILE *stream)
指定されたストリーム stream から次の文字（符号なし文字）を取得し、位置識別子を前に移動します。
35int getchar(void)
標準入力 stdin から1文字（符号なし文字）を取得します。
36char *gets(char *str)
標準入力 stdin から1行読み取り、それを str が指す文字列に格納します。改行文字を読み取ったとき、またはファイルの終わりに達したときに停止します。状況に応じて異なります。
37int putc(int char, FILE *stream)
引数 char で指定された文字（符号なし文字）を指定されたストリーム stream に書き込み、位置識別子を前に移動します。
38int putchar(int char)
引数 char で指定された文字（符号なし文字）を標準出力 stdout に書き込みます。
39int puts(const char *str)
標準出力 stdout に、ヌル文字まで（ヌル文字は含まない）文字列を書き込みます。出力には改行文字が追加されます。
40int ungetc(int char, FILE *stream)
文字 char（符号なし文字）を指定されたストリーム stream に押し戻し、それが次に読み取られる文字になるようにします。
41void perror(const char *str)
説明的なエラーメッセージを標準エラー stderr に出力します。まず文字列 str を出力し、その後にコロン、そしてスペースが続きます。
42int snprintf(char *str, size_t size, const char *format, ...)
フォーマット文字列を str に出力します。

例

以下は、stdio.h の関数を<stdio.h>使用したいくつかの例です：

ファイルを開いて閉じる：

例

#include <stdio.h>

int main() {
    FILE *file = fopen("example.txt", "r");
    if (file == NULL) {
        perror("Error opening file");
        return 1;
    }
    // ファイル操作を行う
    fclose(file);
    return 0;
}

ファイルの内容を読み取る：

例

#include <stdio.h>

int main() {
    FILE *file = fopen("example.txt", "r");
    if (file == NULL) {
        perror("Error opening file");
        return 1;
    }

    char buffer[256];
    while (fgets(buffer, sizeof(buffer), file) != NULL) {
        printf("%s", buffer);
    }

    fclose(file);
    return 0;
}
ファイルの内容を書き込む：

例

#include <stdio.h>

int main() {
    FILE *file = fopen("example.txt", "w");
    if (file == NULL) {
        perror("Error opening file");
        return 1;
    }

    fprintf(file, "Hello, World!\n");

    fclose(file);
    return 0;
}

注意事項

  • fopen を使用してfopenファイルを開いた後は、必ずfclosefclose を使用してファイルを閉じ、ファイルリソースのリークを防いでください。
  • fgets を使用してfgets文字列を読み取る際は、バッファオーバーフローを防ぐためにバッファのサイズに必ず注意してください。
  • printf などの関数をprintf、scanf使用する際は、未定義の動作を避けるためにフォーマット文字列の正確さに必ず注意してください。

<stdio.h> を理解して使用することで、<stdio.h>提供される関数を利用して、ファイルおよび標準入出力操作を簡単に行い、より堅牢で柔軟な C プログラムを作成できます。
