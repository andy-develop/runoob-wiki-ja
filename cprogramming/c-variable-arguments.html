C 可変引数

時には、関数が事前定義された数の引数ではなく、可変数の引数を持つようにしたい場合があるかもしれません。

C言語はこのような状況に対する解決策を提供します。特定のニーズに応じて可変数の引数を受け取る関数を定義できます。

宣言方法は次のとおりです：

int func_name(int arg1, ...);

ここで、省略記号は...可変引数リストを表します。

次の例は、このような関数の使用法を示しています：

int func(int, ... ) { . . . } int main() { func(2, 2, 3); func(3, 2, 3, 4); }

注意してください。関数func()の最後の引数は省略記号、つまり3つのドット（...）で記述されています。省略記号の前の引数はintであり、渡される可変引数の総数を表します。この機能を使用するには、stdarg.hヘッダーファイルが必要です。このファイルには、可変引数機能を実装するための関数とマクロが用意されています。具体的な手順は次のとおりです：

  • 最後の引数が省略記号である関数を定義します。省略記号の前にカスタム引数を設定できます。
  • 関数定義内にva_list型変数を作成します。この型は stdarg.h ヘッダーファイルで定義されています。
  • 使用してint引数とva_start()マクロで初期化しますva_list変数を引数リストとして。マクロva_start()は stdarg.h ヘッダーファイルで定義されています。
  • 使用してva_arg()マクロとva_list変数で引数リストの各項目にアクセスします。
  • マクロを使用してva_end()、割り当てられたva_list変数のメモリをクリーンアップします。

一般的に使用されるマクロは次のとおりです：

  • va_start(ap, last_arg)：可変引数リストを初期化します。apはva_list型の変数であり、last_argは最後の固定引数の名前です（つまり、可変引数リストの前の引数）。このマクロはapを可変引数リストの最初の引数に向けます。

  • va_arg(ap, type)：可変引数リストの次の引数を取得します。apはva_list型の変数であり、typeは次の引数の型です。このマクロは型typeの値を返し、apを次の引数に向けます。

  • va_end(ap)：可変引数リストへのアクセスを終了します。apはva_list型の変数です。このマクロはapを NULL に設定します。NULL。

それでは、上記の手順に従って、可変数の引数を持つ関数を作成し、それらの平均値を返すようにしましょう：

例

#include <stdio.h> #include <stdarg.h> double average(int num,...) { va_list valist; double sum = 0.0; int i; /*num 個の引数に対して valist を初期化する*/ va_start(valist, num); /*valist に割り当てられたすべての引数にアクセスする*/ for (i = 0; i < num; i++) { sum += va_arg(valist, int); } /*valist のために確保されたメモリをクリーンアップする*/ va_end(valist); return sum/num; } int main() { printf("Average of 2, 3, 4, 5 = %f\n", average(4, 2,3,4,5)); printf("Average of 5, 10, 15 = %f\n", average(3, 5,10,15)); }

上記の例では、average() 関数は整数 num と任意の数の整数引数を受け取ります。関数内部では、va_list 型の変数 va_list を使用して可変引数リストにアクセスします。ループ内では、毎回 va_arg() マクロを使用して次の整数引数を取得し、出力します。最後に、関数の終了時に va_end() マクロを使用して可変引数リストへのアクセスを終了します。

上記のコードをコンパイルして実行すると、次の結果が生成されます。なお、関数 average()は2回呼び出され、毎回最初の引数は渡された可変引数の総数を示します。省略記号は可変数の引数を渡すために使用されます。

Average of 2, 3, 4, 5 = 3.500000
Average of 5, 10, 15 = 10.000000

    一、可変引数

    #include <stdio.h>

void debug_arg(unsigned int num, ...) 
{
    unsigned int i = 0;
    unsigned int *addr = &num;
    for (i = 0; i <= num; i++) 
    {
        /* *(addr + i) 从左往右依次取出传递进来的参数,类似于出栈过程 */
        printf("i=%d,value=%d\r\n", i, *(addr + i));
    }
}
int main(void)
{
    debug_arg(3, 66, 88, 666);
    return 0;
}

    可変引数の動作原理を、32ビットマシンを例に説明します：

    • 1. 関数の引数の受け渡しはスタックに格納され、右から左へスタックにプッシュされます。プッシュの過程ではアドレスが減少していきます。
    • 2. 引数の受け渡しは4バイトアライメントで行われます。float/double についてはここでは説明しません。

    C 関数ではプログラム内で以下のマクロを使用する必要があります：

    void va_start( va_list arg_ptr, prev_param ); 
type va_arg( va_list arg_ptr, type ); 
void va_end( va_list arg_ptr );

    va_list：マクロ va_start、va_arg、va_end に必要な情報を保存するための型です。可変長引数リストの引数にアクセスするには、va_list 型のオブジェクトを宣言する必要があります。定義は次のとおりです：typedef char * va_list;

    va_start：可変長引数リストの引数にアクセスする前に使用するマクロで、va_list で宣言されたオブジェクトを初期化します。初期化結果はマクロ va_arg と va_end が使用します；

    va_arg：可変長引数リストの次の引数の値と型を持つ式に展開されるマクロです。va_arg を呼び出すたびに、va_list で宣言されたオブジェクトが変更され、それによってそのオブジェクトは引数リストの次の引数を指すようになります；

    va_end：このマクロにより、プログラムは可変長引数リストでマクロ va_start が参照する関数から正常に戻ることができます。

    vaここでは va は variable-argument（可変引数）という意味です。

    これらのマクロは stdarg.h で定義されているため、可変引数を使用するプログラムはこのヘッダーファイルを含める必要があります。

    次に、簡単な可変引数の関数を作成します。この関数は少なくとも1つの整数引数を持ち、2番目の引数も整数であり、オプションです。関数はこれら2つの引数の値を出力するだけです。

    #include <stdio.h>;  
#include <string.h>;  
#include <stdarg.h>;  

/* ANSI标准形式的声明方式，括号内的省略号表示可选参数 */  
int demo(char *msg, ... )  
{  
    va_list argp;                    /* 定义保存函数参数的结构 */  
    int argno = 0;                    /* 纪录参数个数 */  
    char *para;                        /* 存放取出的字符串参数 */                                      
    va_start( argp, msg );          /* argp指向传入的第一个可选参数，      msg是最后一个确定的参数 */  
    
    while (1) 
    {  
        para = va_arg( argp, char *);                 /*      取出当前的参数，类型为char *. */  
        if ( strcmp( para, "/0") == 0 )  
                                                      /* 采用空串指示参数输入结束 */  
            break;  
        printf("Parameter #%d is: %s/n", argno, para);  
        argno++;  
    }  
    va_end( argp );                                   /* 将argp置为NULL */  
    return 0;  
}

int main( void )  
{  
    demo("DEMO", "This", "is", "a", "demo!" ,"333333", "/0");  
}

    この関数の実装から、可変引数を使用するには次の手順が必要であることがわかります：

    • 1) まず関数内で va_list 型の変数を定義します。ここでは arg_ptr であり、この変数は引数を指すポインタです。
    • 2) 次に va_start マクロを使用して変数 arg_ptr を初期化します。このマクロの2番目の引数は、最初の可変引数の前の引数であり、固定の引数です。
    • 3) 次に va_arg を使用して可変引数を返し、整数 j に代入します。va_arg の2番目の引数は、返したい引数の型であり、ここでは int 型です。
    • 4) 最後に va_end マクロを使用して可変引数の取得を終了します。その後、関数内で2番目の引数を使用できます。関数に複数の可変引数がある場合は、va_arg を順に呼び出して各引数を取得します。

    このチュートリアルをここまで見てきましたが、ここは私にとって一番理解しにくい節でした。他の人による stdarg.h の注釈を参考にした後も、理解するのにかなり時間がかかりました。この節で使用する stdarg.h 内の関数ソースコードに、自分なりの注釈をいくつか追加しました：

    // 本质上，va_list 类型，就是「char指针」类型，指向 1B 大小的内存地址
typedef char* va_list;

// 把 n 圆整到 sizeof(int) 的倍数，和内存的边界对齐有关，下面移动指针、计算地址时会用到
// 函数的参数都是压栈传递，在内存中连续分布，每个参数的地址均为 sizeof(int) 的整数倍
#define _INTSIZEOF(n)       ( (sizeof(n)+sizeof(int)-1) & ~(sizeof(int)-1) )

// 初始化 ap 指针，使其指向第一个可变参数。v 是变参列表的前一个参数
// 对参数 v 取地址，转成 char* 类型的地址，再加上 v 的大小，ap 就指向了下一个参数地址，
// 即第一个「可变参数」的地址
#define va_start(ap,v)      ( ap = (va_list)&v + _INTSIZEOF(v) )

// 该宏返回「当前变参值」,并使 ap 指向列表中的「下个变参」
// 把当前 ap 所指参数称为「第i个参数」
// 获取「第i个参数」的大小，圆整到 int 大小的整数倍（为了边界对齐）：_INTSIZEOF(type)
// 为 ap 加上「圆整后的大小」，使 ap 更新，指向「第i+1个参数」的地址
// 此刻，「更新后的 ap 」减「圆整后的大小」，就是「第i个参数」的地址，类型为 char*
// 「第i个参数」的地址转为「type*」类型：(type*)
// 再用 * 对「转换类型后的地址」取值
// 最终，就得到了「第i个参数」，同时 ap 也指向了「第i+1个参数」地址
#define va_arg(ap, type)    ( *(type*)((ap += _INTSIZEOF(type)) - _INTSIZEOF(type)) )

// 将指针 ap 置为无效，结束变参的获取
// 本质上就是将一个 char* 指针指向 0 地址
#define va_end(ap)             ( ap = (va_list)0 )

    C言語は可変引数のサポートを提供しており、<stdarg.h> ヘッダーファイル内のマクロと関数を使用することで可変引数を実装できます。主に関係する関数とマクロは次のとおりです：

    • va_start(va_list ap, last_arg) マクロ：ap を可変引数リストの最初の引数に向けるために使用します。last_arg は可変引数リストの最後の既知の引数であり、通常は関数の仮引数です。可変引数を使用する前に、このマクロを呼び出す必要があります。
    • va_arg(va_list ap, type) マクロ：ap が指す現在の引数を取得し、ポインタを次の引数に移動するために使用します。type は現在の引数の型を示します。
    • va_copy(va_list dest, va_list src) マクロ：src が指す引数を dest にコピーするために使用します。
    • va_end(va_list ap) マクロ：可変引数の取得を終了し、リソースを解放するために使用します。

    以下は、可変引数の使用方法を示すサンプルプログラムです：

    #include <stdarg.h>
#include <stdio.h>

int sum(int count, ...) {
    va_list ap;  // 定义可变参数列表
    int result = 0;
    va_start(ap, count);  // 将ap指向可变参数列表的第一个参数
    for (int i = 0; i < count; ++i) {
        result += va_arg(ap, int);  // 获取当前参数，并将指针移动到下一个参数
    }
    va_end(ap);  // 结束可变参数的获取
    return result;
}

int main() {
    printf("sum(3, 1, 2, 3) = %d\n", sum(3, 1, 2, 3));
    printf("sum(5, 1, 2, 3, 4, 5) = %d\n", sum(5, 1, 2, 3, 4, 5));
    return 0;
}

    出力結果は次のとおりです：

    sum(3, 1, 2, 3) = 6
sum(5, 1, 2, 3, 4, 5) = 15
