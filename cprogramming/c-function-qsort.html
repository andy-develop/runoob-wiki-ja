C ライブラリ関数 -qsort()

C 標準ライブラリ - <stdlib.h>

説明

qsortC 標準ライブラリで提供される関数で、配列をクイックソートするために使用されます。これは<stdlib.h>ヘッダーファイル内で定義されています。qsort使用されているのはクイックソートアルゴリズム（quicksort）で、これは効率的なソートアルゴリズムであり、平均時間計算量は O(n log n) です。

C ライブラリ関数void qsort(void *base, size_t nitems, size_t size, int (*compar)(const void *, const void*)) 配列をソートします。

宣言

以下は qsort() 関数の宣言です。

void qsort(void *base, size_t nitems, size_t size, int (*compar)(const void *, const void *));

パラメータ

  • base: ソート対象の配列の最初の要素を指すポインタ。
  • nitems: 配列内の要素数。
  • size: 配列内の各要素のサイズ（バイト単位）。
  • compar: 2つの要素を比較するための比較関数へのポインタ。比較関数は比較結果を表す整数を返す必要があります：
    • ゼロ未満：最初の要素が2番目の要素より小さいことを示します。
    • ゼロに等しい：2つの要素が等しいことを示します。
    • ゼロより大きい：最初の要素が2番目の要素より大きいことを示します。

戻り値

この関数は何も返しません。

例

以下の例は qsort() 関数の使い方を示しています。

例

#include <stdio.h>
#include <stdlib.h>

// 5つの整数を含む配列を定義します
int values[] = { 88, 56, 100, 2, 25 };

// 2つの整数を比較するための比較関数
int cmpfunc (const void * a, const void * b)
{
   return ( *(int*)a - *(int*)b );
}

int main()
{
   int n;

   // ソート前の配列の内容を出力
   printf("ソート前のリスト：\n");
   for( n = 0 ; n < 5; n++ ) {
      printf("%d ", values[n]);
   }

   // qsort 関数を使用して配列をソートします
   qsort(values, 5, sizeof(int), cmpfunc);

   // ソート後の配列の内容を出力
   printf("\nソート後のリスト：\n");
   for( n = 0 ; n < 5; n++ ) {
      printf("%d ", values[n]);
   }
 
   return 0;
}

上記のプログラムをコンパイルして実行すると、次の結果が得られます：

排序之前的列表：
88 56 100 2 25 
排序之后的列表：
2 25 56 88 100

    compar パラメータ

    compar パラメータは2つの要素を比較する関数を指します。比較関数のプロトタイプは次のようになります。2つの仮引数はconst void *型でなければならず、同時に compar 関数を呼び出すとき（compar は実質的に関数ポインタであり、ここではそれが指す関数も compar と呼びます）、渡す実引数もconst void *型に変換する必要があります。compar 関数の内部ではconst void *型を実際の型に変換します。以下を参照してください。

    int compar(const void *p1, const void *p2);

    compar の戻り値が 0 未満（< 0）の場合、p1 が指す要素は p2 が指す要素の前に配置されます。compar の戻り値が 0 に等しい（= 0）場合、p1 が指す要素と p2 が指す要素の順序は未定義です。compar の戻り値が 0 より大きい（> 0）場合、p1 が指す要素は p2 が指す要素の後に配置されます。

    int 値の大小比較に関して、例で示されている cmpfunc の実装は安全ではなく、オーバーフローが発生する可能性があります。

    int cmpfunc (const void * a, const void * b)
{
   return ( *(int*)a - *(int*)b );
}

    次の場合を考えてみましょう（int の長さが4バイトとします）：

    int small_negative_val = (int)(0x80000000); // -2147483648
int big_positive_val = 0x7fffffff; // 2147483647
printf("%d", cmpfunc(&small_negative_val, &big_positive_val));
// 输出1。负数减正数却得出了正数，代表结果已经溢出，不再可靠。

    変数aが小さい負の整数を指し、b が大きい正の整数を指す場合、(*(int*)a - *(int*)b)その式は正の数を計算し、これは誤った結果です。

    したがって、int の大小を比較するために減算を使ってはなりません。オーバーフローが発生します。代わりに、大なり演算子と小なり演算子を使って比較できます。これはオーバーフローを発生させません：

    int cmpfunc (const void * a, const void * b)
{
    const int *aa = a;
    const int *bb = b;
    if (*aa < *bb)
        return -1;
    else if (*aa > *bb)
        return 1;
    else 
        return 0;
}

    より簡潔な書き方は次のとおりです：

    int cmpfunc(const void *a, const void *b) {
    const int *aa = a;
    const int *bb = b;
    return (*aa > *bb) - (*aa < *bb);
}

    これら2つの方法は、強制型変換の際に、ポインタが指すメモリの const 属性を保持していることに注意してください。これは、aa、bb が指すメモリが変更できないことを強調しており、より規範的な書き方です。

    compar - 比較関数。

    最初の引数が2番目より小さい場合は負の整数値を返し、最初の引数が2番目より大きい場合は正の整数値を返し、2つの引数が同等の場合はゼロを返します。

    比較関数のシグネチャは次の形式と同等である必要があります：

    int compar(const void *a, const void *b);

    この関数は渡されたオブジェクトを変更してはならず、同じオブジェクトを比較する場合には、配列内の位置に関係なく一貫した結果を返さなければなりません。

    上のコメントのこの書き方：

    return (*(int*)a) > (*(int*)b) ? 1 : -1;//升序排序
return (*(int*)a) > (*(int*)b) ? -1 : 1;//降序排序

    C言語標準に適合しないだけでなく、配列に多数の等しい要素がある場合、所要時間が大幅に増加し、その場合 qsort の時間計算量の利点は失われます。return (*(int*)a - *(int*)b);確かに性能は高いですが、安全ではありません。素朴なif-else書き方でも性能はあまり変わりません。

    if-else1行にまとめることができます：

    return *(int *)a < *(int *)b ? -1 : *(int *)a > *(int *)b;
