次の例では、unsigned long 型のポインタを関数に渡し、関数内でこの値を変更します。

( ) は write 操作を呼び出します。以下同様です。実際には、ポインタ action をマウスや他の GUI オブジェクトに関連付けて、対応する目的を達成できます。

#include <stdio.h>
#include <time.h>
 
void getSeconds(unsigned long *par);

int main ()
{
   unsigned long sec;


   getSeconds( &sec );

   /* 実際の値を出力 */
   printf("Number of seconds: %ld\n", sec );

   return 0;
}

void getSeconds(unsigned long *par)
{
   /* 現在の秒数を取得 */
   *par = time( NULL );
   return;
}

上記のコードがコンパイルされて実行されると、次の結果が生成されます。

Number of seconds :1294450468

ポインタを引数として受け取れる関数は、配列も引数として受け取ることができます。次のようになります。

例

#include <stdio.h>
 
/* 関数宣言 */
double getAverage(int *arr, int size);
 
int main ()
{
   /* 5 つの要素を持つ整数配列 */
   int balance[5] = {1000, 2, 3, 17, 50};
   double avg;
 
   /* 配列を指すポインタを引数として渡す */
   avg = getAverage( balance, 5 ) ;
 
   /* 戻り値を出力 */
   printf("Average value is: %f\n", avg );
   
   return 0;
}

double getAverage(int *arr, int size)
{
  int    i, sum = 0;      
  double avg;          
 
  for (i = 0; i < size; ++i)
  {
    sum += arr[i];
  }
 
  avg = (double)sum / size;
 
  return avg;
}

上記のコードがコンパイルされて実行されると、次の結果が生成されます。

Average value is: 214.40000

    ポインタと関数の関係

    1. 関数ポインタ（関数を指すポインタ）

    関数はコンパイル後にメモリの一部を占め、その関数名がその関数の先頭アドレスになります。

    ポインタを関数を指すポインタとして宣言できます。

    C 言語では、関数名はこの関数を指すポインタに変換されることになっています。ただし、その関数名が & 演算子または sizeof 演算子のオペランドとして使用される場合を除きます（注意：関数名を sizeof のオペランドとして使用することは非合法です）。つまり、f = test; では test は自動的に &test に変換されますが、f = &test; では &test が明示的に使用されているため、test は変換されません。したがって、関数名を直接参照することは、関数名に & 演算子を適用することと同等であり、どちらの方法でもその関数を指すポインタが得られます。

    関数を指すポインタは、関数呼び出しで使用するために、初期化されているか、0 の値を持つ必要があります。

    配列と同様に：

    • (1) 関数を指すポインタに対するインクリメント演算 ++ は禁止されています。
    • (2) 関数名への代入は禁止されており、関数名は算術演算にも使用できません。

    2. ポインタ関数（戻り値がポインタの関数）

    いわゆるポインタ関数とは、ポインタを返す関数のことです。前述のノート「関数から配列を返す」で既に紹介されています。

    C 言語のライブラリ関数にはポインタ関数が多くあります。例えば文字列処理関数などです。以下にいくつかの関数プロトタイプを示します。

    char *strcat( char *dest, const char *src );​
char *strcpy( char *dest, const char *src );
​char *strchr( const char *s, int c );​
char *strstr( const char *src, const char *sub );

    3. 両者の混用（あまり使われない）

    関数の戻り値は変数を指すポインタだけでなく、関数を指すポインタにもなり得ることに注意してください。

    まずこの宣言を見てみましょう：*int (*function(int)) (double*, char); この宣言の意味を理解するには、まず function(int) を見ます。function は int 型の仮引数を1つ持つ関数として宣言されています。この関数の戻り値はポインタであり、それが関数ポインタ int (*) (double*, char); です。このポインタは、int 型を返し、double* 型と char 型の2つの仮引数を持つ関数を指します。

    typedef を使用すると、この宣言を簡略化できます：（よくわかりませんでした。。。。後の構造体で補足します）

    typedef  int (*ptf) (double*, char);​
ptf  function( int );

    もう1つの例：

    void (*signal (int sig, void (*func) (int siga)) ) ( int siga );

    次に分析するのは signal です。signal に最も近いのは優先順位が最も高い括弧なので、最初に括弧と結合し、signal は関数です。括弧内は signal の2つの仮引数で、1つは int 型、もう1つは関数を指すポインタです。次に左を見ると、* は何かを指すポインタを表し、その位置から signal の戻り値型であることがわかります。ここで、分析済みの signal 全体を取り除くと、void (*) ( int siga ) が得られます。これも関数ポインタであり、このポインタは signal の仮引数リストの2番目の引数と同じ型で、いずれも int 型の仮引数を1つ受け取り、何も返さない関数を指すポインタです。

    typedef を使用すると、この宣言を簡略化できます：

    typedef int (*p_sig) (double*, char);​
p_sig signal(int sig, p_sig func);

    この signal 関数は C 言語のライブラリ関数で、signal.h で定義されており、システムで発生するシグナルを処理するために使用されます。

    4. 関数ポインタ配列

    ここにファイル処理プログラムがあるとします。メニューボタンを使用して対応する操作（ファイルを開く、ファイルを読む、ファイルを書く、ファイルを閉じる）を選択します。これらの操作はすべて関数として実装され、型は同じで、それぞれ次のとおりです：

    void open();
void read();
void write();
void close();

    ここで関数ポインタ型のエイリアス PF を定義します：

    typedef void (*PF) ( );

    上記の4つの操作のアドレスを配列に入れると、次のようになります：

    PF file_options[ ] = {
    &open,
    &read,
    &write,
    &close
};

    typedef を使用しない場合、分析はより複雑になり、結果は void (*file_options[ ]) ( ); となります。

    この配列の要素はすべて、引数を受け取らず何も返さない関数を指すポインタであるため、これは関数ポインタ配列です。次に、関数ポインタ型のポインタ action を定義し、関数ポインタ配列の最初の要素に初期化します：PF* action = file_options;。理解しにくい場合は、次のように類推できます：

    int ia[4] = {0, 1, 2, 3};
int *ip = ia;，

    5. 関数とポインタの複雑な宣言（必須ではありません。通常は typedef で代用します）

    例を1つだけ挙げます：

    int *(*(*fp)(int)) [10];

    解読手順：

    1．从未定义的变量名开始阅读 -------------------------------------------- fp
2．往右看，什么也没有，遇到了)，因此往左看，遇到一个* ------ 一个指向某对象的指针
3．跳出括号，遇到了(int) ----------------------------------- 一个带一个int参数的函数
4．向左看，发现一个* --------------------------------------- （函数）返回一个指向某对象的指针
5．跳出括号，向右看，遇到[10] ------------------------------ 一个10元素的数组
6．向左看，发现一个* --------------------------------------- 一个指向某对象指针
7．向左看，发现int ----------------------------------------- int类型

    したがって、fp は関数を指すポインタ（関数ポインタ）であり、その関数は、10 個の int* 型の要素を持つ配列を指すポインタを返します。
