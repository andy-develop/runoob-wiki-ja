C 標準ライブラリ<stdint.h>

<stdint.h>C99 標準で導入されたヘッダーファイルであり、明確なサイズと符号属性を持つ整数型の定義を提供し、異なるプラットフォーム間での一貫性を保証します。

<stdint.h>このライブラリは、C 言語におけるプラットフォームごとの整数型のサイズ不一致の問題を補うためのものであり、コードの移植性と保守性を向上させます。

<stdint.h>主に、固定サイズの整数型、整数型の最小値/最大値、および整数型の型修飾子を定義するために使用されます。これにより、コンパイラやオペレーティングシステムのプラットフォーム固有の整数サイズに依存することを回避できます。

<stdint.h>固定幅の整数型と関連マクロを提供することで、プログラマーはプラットフォームの実装詳細に依存せずに、必要な整数のサイズを明確に指定できるようになります。

<stdint.h>の主な目的は次のとおりです：

  • 固定幅の整数型（例：int8_t、int16_tなど）を提供し、そのサイズが異なるプラットフォーム間で一致することを保証します。

  • プラットフォームに依存しない整数型（例：int_least8_t、int_fast16_tなど）を定義し、パフォーマンスとメモリ使用量を最適化します。

  • 最大幅の整数型（例：intmax_t、uintmax_t）を提供し、可能な最大の整数を表します。

固定幅整数型

これらの型はその幅（ビット数）を明確に指定し、異なるプラットフォーム間で同じサイズであることを保証します。

型 説明
int8_t 8 ビット符号付き整数
int16_t 16 ビット符号付き整数
int32_t 32 ビット符号付き整数
int64_t 64 ビット符号付き整数
uint8_t 8 ビット符号なし整数
uint16_t 16 ビット符号なし整数
uint32_t 32 ビット符号なし整数
uint64_t 64 ビット符号なし整数

注意：

  • プラットフォームが特定の固定幅型をサポートしていない場合、その型は定義されません。

最小幅整数型

これらの型は指定された幅を少なくとも持ちますが、より大きくなる場合があります。

型 説明
int_least8_t 少なくとも 8 ビットの符号付き整数
int_least16_t 少なくとも 16 ビットの符号付き整数
int_least32_t 少なくとも 32 ビットの符号付き整数
int_least64_t 少なくとも 64 ビットの符号付き整数
uint_least8_t 少なくとも 8 ビットの符号なし整数
uint_least16_t 少なくとも 16 ビットの符号なし整数
uint_least32_t 少なくとも 32 ビットの符号なし整数
uint_least64_t 少なくとも 64 ビットの符号なし整数

最速最小幅整数型

これらの型は、指定された幅を持つ最速の整数型であり、通常はパフォーマンスの最適化に使用されます。

型 説明
int_fast8_t 少なくとも 8 ビットの最速の符号付き整数
int_fast16_t 少なくとも 16 ビットの最速の符号付き整数
int_fast32_t 少なくとも 32 ビットの最速の符号付き整数
int_fast64_t 少なくとも 64 ビットの最速の符号付き整数
uint_fast8_t 少なくとも 8 ビットの最速の符号なし整数
uint_fast16_t 少なくとも 16 ビットの最速の符号なし整数
uint_fast32_t 少なくとも 32 ビットの最速の符号なし整数
uint_fast64_t 少なくとも 64 ビットの最速の符号なし整数

最大幅整数型

これらの型は、可能な最大の整数を表すために使用されます。

型 説明
intmax_t 最大幅の符号付き整数
uintmax_t 最大幅の符号なし整数

ポインタ幅整数型

これらの型は、ポインタサイズの整数を表すために使用されます。

型 説明
intptr_t ポインタを格納できる符号付き整数
uintptr_t ポインタを格納できる符号なし整数

例

以下は<stdint.h>を使用した例です：

例

#include <stdio.h>
#include <stdint.h>

int main() {
    // 固定幅整数型
    int32_t a = 100;
    uint64_t b = 1000000000000ULL;

    // 最小幅整数型
    int_least16_t c = 200;

    // 最速最小幅整数型
    int_fast32_t d = 300;

    // 最大幅整数型
    intmax_t e = INTMAX_MAX;

    // 値を出力
    printf("a = %d\n", a);
    printf("b = %llu\n", b);
    printf("c = %d\n", c);
    printf("d = %d\n", d);
    printf("e = %jd\n", e);

    return 0;
}

注意事項

  • <stdint.h>C99 以降でのみ使用できます。

  • 固定幅型（例：int32_t）は一部のプラットフォームでは利用できない場合があるため、使用時には定義されているかどうかを確認する必要があります。

  • 使用<stdint.h>コードの移植性を向上させることができます。特に、整数サイズを正確に制御する必要がある場面で。
