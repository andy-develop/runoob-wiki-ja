C 練習例20 - ボールの自由落下

C言語の定番100例

問題：ボールが100メートルの高さから自由落下し、着地するたびに元の高さの半分に跳ね返り、再び落下する。10回目の着地時までに合計で何メートル進むか？10回目の跳ね返りは何メートルか？

プログラムの分析：下の注釈を参照。

プログラムのソースコード：

例

#include <stdio.h> #define INITIAL_HEIGHT 100.0 #define BOUNCE_COUNT 10 int main() { double h = INITIAL_HEIGHT; double s = INITIAL_HEIGHT; // 1回目の跳ね返り高さ h /= 2; // その後の跳ね返り高さと合計距離を計算する for (int i = 2; i <= BOUNCE_COUNT; i++) { s += 2 * h; h /= 2; } // 結果を出力し、小数位を2桁に指定する printf("第%d回着地時、合計%.5fメートル、第%d回の跳ね返り高さ%.5fメートル\n", BOUNCE_COUNT, s, BOUNCE_COUNT, h); return 0; }

上記の例の出力結果は次のとおりです。

第10次落地时，共经过299.60938米，第10次反弹高0.09766米

    例が複雑化されていて、コードからロジックが見えてこない。

    これは単なる落下 + 跳ね返りの周期です。

    #include <stdio.h>
int main()
{
    float s,h;
    h=100;
    for(int i=1; i<=10; i++){
        s=s+h;  // 下落
        h = h / 2;
        s=s+h;  // 反弹
    }
    s=s-h;      // 去掉最后一次反弹
    printf("第10次落地时，共经过%f米，第10次反弹高%f米\n",s,h);
    return 0;
}

    上記のノートは少し複雑でしたが、これは実に純粋な数学のアルゴリズムです。2回目からは毎回、上がって下がるだけで、高さは前回の半分です。要するに等比数列の和と第10項の大きさを求めることです。

    等比数列の一般項の公式は次のとおりです。

    等比数列の和：

    ①当q≠1时
或 
②当q=1时

    したがって、運動経路の長さを計算するには、2回目から10回目までの経路を *2 して、1回目の落下高さ100を加えるだけでよい。

    # include <stdio.h>
# include <math.h>

int main(void)
{
    float a = 100;//等比数列首项；
    float q = 0.5;//公比
    float s,h;//定义等比数列的和s，第十项h；

    h = a*pow(q,10);//第十次弹起的高度，注意第十次落地的高度需要h*2
    s = 2*(50-h*q*2)/(1-q)+100;
    printf("第十次的高度为%f;总路程为%f",h,s);
    return 0;
}

    参考方法（再帰法）：

    #include<stdio.h>
#include<stdlib.h>

double digui(double a,int n)//这里的n为下落与反弹的总次数，一个来与回n=2
/*
    该函数返回第N次落地后经过的总长度，
        并打印出第N次反弹的高度（N与该函数参数n意义不同）
*/
{
    if(n>0)
        if(n%2)//判断是下落还是反弹
            return digui(a/2,--n)+a;//递归调用自身函数，a变为a/2
        else
            return digui(a,--n)+a;//递归调用自身函数，a不变
    else
    {
        printf("反弹高度为%lf米\n",a);
        return 0;
    }
}

void main()    
{
    double a;
    int n;
    printf("请输入原始高度：");
    scanf("%lf",&a);
    printf("请输入有多少次落地：");
    scanf("%d",&n);
    printf("第%d次",n);
    printf("在第%d次落地时，共经过%lf米\n",n,digui(a,2*n-1));
    /*2*n-1表示来与回的总次数*/
    system("pause");
}
