Cライブラリ関数 -strtok()

C標準ライブラリ - <string.h>

strtok() は C 標準ライブラリ内の文字列処理関数で、文字列を一連の部分文字列（つまり「トークン」）に分割するために使用されます。

Cライブラリ関数char *strtok(char *str, const char *delim)文字列を分割するstr一連の文字列に、delimを区切り文字とします。

宣言

以下は strtok() 関数の宣言です。

char *strtok(char *str, const char *delim)

パラメータ

  • str: 分割する文字列。最初の呼び出しでは、分割する文字列を渡します。以降の呼び出しでは、NULLを渡し、同じ文字列の分割を続けることを示します。

  • delim: 区切り文字列。strtok()は、この文字列内の任意の文字を使用して分割します。str。

戻り値

次のトークンを指すポインタを返します。それ以上トークンがない場合は NULL を返します。

例

以下の例は strtok() 関数の使い方を示しています。

例

#include <string.h> #include <stdio.h> int main () { char str[80] = "This is - www.example.com - website"; const char s[2] = "-"; char *token; /*最初の部分文字列を取得する*/ token = strtok(str, s); /*他の部分文字列を取得し続ける*/ while( token != NULL ) { printf( "%s\n", token ); token = strtok(NULL, s); } return(0); }

上記のプログラムをコンパイルして実行すると、次の結果が得られます：

This is 
 www.example.com 
 website

注意事項

  1. 元の文字列を変更する: strtok()は渡された文字列を変更し、区切り文字を次のものに置き換えます：\0（ヌル文字）。したがって、元の文字列は破壊されます。

  2. リエントラントではない: strtok()状態を保存するために静的バッファを使用するため、スレッドセーフではありません。マルチスレッド環境で使用する場合は、次の使用を検討できます：strtok_r()（リエントラント版）。

  3. 連続する区切り文字: 文字列内に連続する区切り文字がある場合、strtok()はそれらを無視し、次の有効なトークンを返します。

リエントラント版：strtok_r()

strtok_r() は strtok() のリエントラント版で、マルチスレッド環境で安全に使用できます。そのプロトタイプは次のとおりです：

char *strtok_r(char *str, const char *delim, char **saveptr);

saveptr: 分割状態を保存するための char* へのポインタです。

例

#include <stdio.h>
#include <string.h>

int main() {
    char str[] = "This is a sample string";
    char *token;
    char *saveptr;

    // 最初に strtok_r を呼び出し、分割する文字列を渡す
    token = strtok_r(str, " ", &saveptr);

    // NULL が返されるまで strtok_r を呼び続ける
    while (token != NULL) {
        printf("%s\n", token);
        token = strtok_r(NULL, " ", &saveptr);
    }

    return 0;
}

strtok() は便利な文字列分割関数ですが、副作用（元の文字列の変更）とリエントラントではないことに注意する必要があります。マルチスレッド環境では、競合状態を避けるために strtok_r() を使用することをお勧めします。
