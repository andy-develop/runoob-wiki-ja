C 共用体

共用体共用体は、同じメモリ位置に異なるデータ型を格納できる特別なデータ型です。複数のメンバーを持つ共用体を定義できますが、常に値を持つことができるのは1つのメンバーだけです。共用体は、同じメモリ位置を効率的に使用する方法を提供します。

共用体の定義

共用体を定義するには、次を使用する必要があります：union文を使用します。方法は構造体の定義と似ています。union文は、複数のメンバーを持つ新しいデータ型を定義します。union文の形式は次のとおりです：

union [union tag] { member definition; member definition; ... member definition; } [one or more union variables];

union tagは省略可能で、各 member definition（メンバー定義）は標準の変数定義です。たとえば int i; や float f; などの有効な変数定義です。共用体定義の末尾、最後のセミコロンの前に、1つ以上の共用体変数を指定できます。これは省略可能です。次に、3つのメンバー i、f、str を持つ Data という名前の共用体型を定義します：

union Data { int i; float f; char str[20]; } data;

これで、Data変数が20バイトを占めるため）。4+4+20=28バイトではありません。

共用体が占有するメモリは、共用体の中で最大のメンバーを格納するのに十分な大きさでなければなりません。たとえば、上記の例では、各メンバーの中で文字列が占める領域が最も大きいため、Data は20バイトのメモリ領域を占有します。次の例では、上記の共用体が占有する合計メモリサイズを表示します：

例

#include <stdio.h> #include <string.h> union Data { int i; float f; char str[20]; }; int main( ) { union Data data; printf( "Memory size occupied by data : %d\n", sizeof(data)); return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

Memory size occupied by data : 20

共用体メンバーへのアクセス

共用体のメンバーにアクセスするには、メンバーアクセス演算子（.）を使用します。メンバーアクセス演算子は、共用体変数名とアクセスする共用体メンバーの間にあるピリオドです。unionキーワードを使用して共用体型の変数を定義できます。次の例は、共用体の使用方法を示しています：

例

#include <stdio.h> #include <string.h> union Data { int i; float f; char str[20]; }; int main( ) { union Data data; data.i = 10; data.f = 220.5; strcpy( data.str, "C Programming"); printf( "data.i : %d\n", data.i); printf( "data.f : %f\n", data.f); printf( "data.str : %s\n", data.str); return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

data.i : 1917853763
data.f : 4122360580327794860452759994368.000000
data.str : C Programming

ここでは、共用体のi 和 fメンバーの値が破損していることがわかります。最後に変数に代入された値がメモリ位置を占有しているためです。これがstrメンバーが正しく出力できる理由です。それでは、同じ例をもう一度見てみましょう。今回は一度に1つの変数だけを使用します。これも共用体を使用する主な目的を示しています：

例

#include <stdio.h> #include <string.h> union Data { int i; float f; char str[20]; }; int main( ) { union Data data; data.i = 10; printf( "data.i : %d\n", data.i); data.f = 220.5; printf( "data.f : %f\n", data.f); strcpy( data.str, "C Programming"); printf( "data.str : %s\n", data.str); return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

data.i : 10
data.f : 220.500000
data.str : C Programming

ここでは、一度に1つのメンバーだけが使用されるため、すべてのメンバーが正しく出力されます。

    共用体の役割

    メモリを節約できます。2つの非常に長いデータ構造があり、同時に使用しない場合（たとえば、1つは教師を表し、もう1つは学生を表す）、教師と学生の情報をまとめて統計する場合に構造体を使用すると少し無駄になります。共用体を使用すれば、最も長いデータ構造が占有するスペースだけで十分です！

    共用体の応用シーン

    通信におけるデータパケットで共用体が使用されます。相手がどのようなパケットを送ってくるかわからないため、共用体を使うと非常に簡単です。いくつかの形式のパケットを定義し、パケットを受信したらパケットの形式に基づいて直接データを取り出すことができます。

    これまでの皆さんのメモリ占有サイズの計算を見ましたが、核心を分析したものはありませんでした。以下に一部の概念を示します：

    • ビット：「ビット(bit)」は、電子計算機における最小のデータ単位です。各ビットの状態は0または1のみです。
    • バイト：8つの2進ビットで1つの「バイト(Byte)」を構成します。これは記憶容量の基本的な計量単位です。1バイトで英字1文字または漢字半分を格納できます。言い換えると、漢字1文字は2バイトの記憶領域を占有します。
    • ワード：「ワード」は複数のバイトで構成され、ワードのビット数をワード長と呼びます。異なるグレードのマシンは異なるワード長を持ちます。たとえば、8ビット機では、1ワードは1バイトに等しく、ワード長は8ビットです。16ビット機の場合、1ワードは2バイトで構成され、ワード長は16ビットです。ワードはコンピュータがデータ処理や演算を行う単位です。
    • 一般的なコンピュータはすでに64ビット機になっています。つまり、1つの基本単位は64ビット、すなわち8バイトです。これと上記の分析を総合すると、構造体、共用体、ビットフィールドの定義では、メモリが順番に割り当てられ、次のフィールドのサイズが前のフィールドが占有するメモリユニットの残り部分を超える場合、次のメモリユニットを再度申請し、前のフィールドの余った部分は空いたままになることがわかります。

    上の方への補足；

    共用体が占有するメモリは、9個のchar、つまり9バイトではなく、doubleの2倍、つまり16バイトです。また、出力されるのは常にその直前の最も近い値です。

    補足説明：これはバイトアライメントが原因です。

    アライメントの原則：

    • 【原則1】データメンバーのアライメント規則：構造体(struct)（または共用体(union)）のデータメンバーは、最初のデータメンバーをoffset 0の場所に配置し、以降の各データメンバーのアライメントは、#pragma packで指定された値とそのデータメンバー自身の長さのうち、小さい方に従って行われます。
    • 【原則2】構造体（または共用体）全体のアライメント規則：データメンバーがそれぞれのアライメントを完了した後、構造体（または共用体）自体もアライメントを行う必要があります。アライメントは、#pragma packで指定された値と構造体（または共用体）の最大データメンバー長のうち、小さい方に従って行われます。
    • 【原則3】構造体がメンバーである場合：構造体内に構造体メンバーがある場合、その構造体メンバーは内部の最大要素サイズの整数倍のアドレスから格納を開始する必要があります。
    union Data{
    int i;
    float f;
    char str[9];
    double d;
}data;

    原則2に従うと、VSではデフォルトで #pragma park(8) ですが、char

    8<9;

    8の倍数かつ9より大きい値とするため、16になります。
