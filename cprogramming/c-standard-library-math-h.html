C 標準ライブラリ -<math.h>

概要

math.hヘッダファイルはさまざまな数学関数と1つのマクロを定義しています。このライブラリで利用可能なすべての関数は、1つのdouble型の引数を持ち、すべてdouble型の結果を返します。

<math.h>は C 標準ライブラリ内のヘッダファイルの1つで、数学演算に使用される多くの関数とマクロを含んでいます。これらの関数とマクロは、基本的な算術演算、三角関数、指数関数、対数関数、累乗関数、丸め関数などを提供します。

ライブラリマクロ

宏説明
HUGE_VAL関数の結果がオーバーフローしたときに返される値（正の無限大）。このマクロは非常に大きな倍精度浮動小数点数を表し、通常、結果が表現可能な範囲を超えた場合の一部の数学関数の戻り値として使用されます。関数の結果が大きすぎて通常の浮動小数点数で表現できない場合（つまりオーバーフローが発生した場合）、errno に ERANGE（範囲エラー）が設定され、HUGE_VAL またはその負の値（負の無限大の場合）が返されます。
HUGE_VALF関数の結果がオーバーフローしたときに返される値（正の無限大、浮動小数点型）
HUGE_VALL関数の結果がオーバーフローしたときに返される値（正の無限大、long double型）
INFINITY正の無限大
NAN非数値（Not-A-Number）

以下は、<math.h>の関数と定数を使用したサンプルコード：

例

#include <stdio.h>
#include <math.h>

int main() {
    double x = 2.0;
    double y = 3.0;

    // 基本的な演算
    printf("sqrt(%.1f) = %.2f\n", x, sqrt(x));
    printf("pow(%.1f, %.1f) = %.2f\n", x, y, pow(x, y));
    printf("exp(%.1f) = %.2f\n", x, exp(x));
    printf("log(%.1f) = %.2f\n", x, log(x));
    printf("log10(%.1f) = %.2f\n", x, log10(x));

    // 三角関数
    double angle = M_PI / 4; // 45 degrees
    printf("sin(%.2f) = %.2f\n", angle, sin(angle));
    printf("cos(%.2f) = %.2f\n", angle, cos(angle));
    printf("tan(%.2f) = %.2f\n", angle, tan(angle));

    // 丸め関数
    double z = 5.8;
    printf("ceil(%.1f) = %.1f\n", z, ceil(z));
    printf("floor(%.1f) = %.1f\n", z, floor(z));
    printf("fabs(%.1f) = %.1f\n", z, fabs(z));

    return 0;
}

上記のプログラムを実行すると、以下のような内容が出力されます：

sqrt(2.0) = 1.41
pow(2.0, 3.0) = 8.00
exp(2.0) = 7.39
log(2.0) = 0.69
log10(2.0) = 0.30
sin(0.79) = 0.71
cos(0.79) = 0.71
tan(0.79) = 1.00
ceil(5.8) = 6.0
floor(5.8) = 5.0
fabs(5.8) = 5.8

<math.h>一連の数学関数と定数を提供し、C言語でさまざまな数学計算を行うプログラマーを支援します。これらの関数と定数を使用することで、複雑な数学演算を簡単に実装でき、プログラムの効率と可読性を向上させることができます。
