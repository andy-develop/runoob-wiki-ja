Bootstrap 4 デフォルト設定

Bootstrap 4 デフォルトのfont-size16px は、line-height1.5 です。

デフォルトのfont-family"Helvetica Neue"、Helvetica、Arial、sans-serif です。

さらに、すべての<p>元素margin-top: 0 、 margin-bottom: 1rem (16px)。

<h1> - <h6>

Bootstrap ではすべての HTML 見出し（h1 から h6）のスタイルが定義されています。次の例を参照してください：

实例

<div class="container"> <h1>h1 Bootstrap 标题 (2.5rem = 40px)</h1> <h2>h2 Bootstrap 标题 (2rem = 32px)</h2> <h3>h3 Bootstrap 标题 (1.75rem = 28px)</h3> <h4>h4 Bootstrap 标题 (1.5rem = 24px)</h4> <h5>h5 Bootstrap 标题 (1.25rem = 20px)</h5> <h6>h6 Bootstrap 标题 (1rem = 16px)</h6> </div>

Display 見出しクラス

Bootstrap はさらに、見出しのスタイルを制御するための 4 つの Display クラスを提供しています: .display-1, .display-2, .display-3, .display-4。

实例

<div class="container"> <h1>Display 标题</h1> <p>Display 見出しは、より大きく太いフォントスタイルで出力できます。</p> <h1 class="display-1">Display 1</h1> <h1 class="display-2">Display 2</h1> <h1 class="display-3">Display 3</h1> <h1 class="display-4">Display 4</h1> </div>
