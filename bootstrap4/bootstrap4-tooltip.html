Bootstrap4 ツールチップ

ツールチップは小さなポップアップで、マウスが要素の上に移動すると表示され、要素の外に移動すると消えます。

ツールチップの作成方法

要素に追加することでdata-toggle="tooltip"ツールチップを作成します。

title属性の内容は、ツールチップに表示される内容です：

<a href="#" data-toggle="tooltip" title="私はヒント内容です！">マウスをここに移動</a>

注意:ツールチップは jQuery の初期化コード内に記述します: その後、指定した要素上で呼び出します。tooltip()方法。

以下の例は、ドキュメント内のどこでもツールチップを使用できます：

实例

$(document).ready(function(){ $('[data-toggle="tooltip"]').tooltip(); });

ツールチップの位置を指定する

デフォルトでは、ツールチップは要素の上に表示されます。

可以使用data-placement属性を使用してツールチップの表示方向を設定します: top、bottom、left または right:

实例

<a href="#" data-toggle="tooltip" data-placement="top" title="私はヒント内容です！">マウスをここに移動</a> <a href="#" data-toggle="tooltip" data-placement="bottom" title="私はヒント内容です！">マウスをここに移動</a> <a href="#" data-toggle="tooltip" data-placement="left" title="私はヒント内容です！">マウスをここに移動</a> <a href="#" data-toggle="tooltip" data-placement="right" title="私はヒント内容です！">マウスをここに移動</a>

ボタンで使用する:

实例

<button type="button" class="btn btn-secondary" data-toggle="tooltip" data-placement="top" title="Tooltip on top"> Tooltip on top </button> <button type="button" class="btn btn-secondary" data-toggle="tooltip" data-placement="right" title="Tooltip on right"> Tooltip on right </button> <button type="button" class="btn btn-secondary" data-toggle="tooltip" data-placement="bottom" title="Tooltip on bottom"> Tooltip on bottom </button> <button type="button" class="btn btn-secondary" data-toggle="tooltip" data-placement="left" title="Tooltip on left"> Tooltip on left </button>

ツールチップの内容に HTML タグを追加する場合、data-html="true" を設定し、内容を title タグ内に置きます：

实例

<button type="button" class="btn btn-secondary" data-toggle="tooltip" data-html="true" title="<em>Tooltip</em> <u>with</u> <b>HTML</b>"> Tooltip with HTML </button>
