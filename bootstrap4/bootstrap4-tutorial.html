Bootstrap4 教程

Bootstrap は、レスポンシブレイアウトやモバイルファーストのWEBプロジェクトを開発するための、世界で最も人気のあるフロントエンドコンポーネントライブラリです。

Bootstrap4 は、HTML、CSS、JS 開発のためのオープンソースツールセットです。当社が提供する Sass 変数と多数の mixin、レスポンシブグリッドシステム、拡張可能な既製コンポーネント、jQuery ベースの強力なプラグインシステムを利用することで、アイデアのプロトタイプを迅速に開発したり、アプリ全体を構築したりすることができます。

このチュートリアルは誰向けですか？

HTML と CSS の基礎知識があれば、このチュートリアルを読んで、自分のウェブサイトを開発することができます。このチュートリアルを学び終えた後、Bootstrap を使用して Web プロジェクトを開発する中級レベルに到達できます。

このチュートリアルを読む前に、理解しておく必要がある知識：

このチュートリアルを読み始める前に、HTML、CSS、JavaScript の基礎知識が必要です。これらの概念をまだ理解していない場合は、まず私たちのこれらのチュートリアルを読むことをお勧めします：

  • HTML 教程
  • CSS 教程
  • JavaScript 教程

Bootstrap4 と Bootstrap3

Bootstrap4 は Bootstrap の最新バージョンであり、Bootstrap3 と比較して、より具体的なクラスを持ち、関連する部分を関連コンポーネントに変えました。同時に Bootstrap.min.css の容量は40%以上削減されました。

Bootstrap4 は IE8 および iOS 6 のサポートを終了し、現在は IE9 以上および iOS 7 以上のバージョンのブラウザのみをサポートしています。以前のブラウザを使用する必要がある場合は、どうぞBootstrap3。
