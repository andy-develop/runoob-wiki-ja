间距

間隔設定の構文は次の通りです:

{property}{sides}-{size}  // 适用 xs(<=576px)
{property}{sides}-{breakpoint}-{size} // 适用 sm (>=576px), md (>=768px), lg (>=992px), xl (>=1200px)

breakpointsは画面幅を指します: xs (<=576px), sm (>=576px), md (>=768px), lg (>=992px), xl (>=1200px)。

property属性を表し、以下を含みます：

  • m- 設定に使用margin
  • p- 設定に使用padding

sides主に方向を指します：

  • t- 設定に使用margin-top 或 padding-top
  • b- 設定に使用margin-bottom 或 padding-bottom
  • l- 設定に使用margin-left 或 padding-left
  • r- 設定に使用margin-right 或 padding-right
  • x- 設定に使用*-leftと*-right
  • y- 設定に使用*-topと*-bottom
  • blank - 要素の4方向を設定するために使用しますmargin 或 padding

sizeマージンのサイズを指します：

  • 0- 设置margin 或 paddingために0
  • 1- 设置margin 或 paddingために$spacer * .25
  • 2- 设置margin 或 paddingために$spacer * .5
  • 3- 设置margin 或 paddingために$spacer
  • 4- 设置margin 或 paddingために$spacer * 1.5
  • 5- 设置margin 或 paddingために$spacer * 3
  • auto- 设置marginauto として

外边距margin数字の前に文字を追加すると、負の数値を設定できます。"n" :

  • n1margin を -.25rem に設定します (font-size が 16px の場合、-4px になります)
  • n2- margin を -.5rem に設定します (font-size が 16px の場合は -8px)
  • n3margin を -1rem に設定します（font-size が 16px の場合は -16px）
  • n4margin を -1.5rem に設定します (font-size が 16px の場合は -24px になります)
  • n5margin を -3rem に設定します（font-size が 16px の場合は -48px）

一部の余白のソースコード設定を見てみましょう：

.mt-0 {
  margin-top: 0 !important;
}

.ml-1 {
  margin-left: ($spacer * .25) !important;
}

.px-2 {
  padding-left: ($spacer * .5) !important;
  padding-right: ($spacer * .5) !important;
}

.p-3 {
  padding: $spacer !important;
}
