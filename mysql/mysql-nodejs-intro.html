MySQL Node.js 接続と使用

MySQLは最も人気のあるオープンソースのリレーショナルデータベースの1つであり、Node.jsはChrome V8エンジンベースのJavaScriptランタイム環境です。両者を組み合わせることで、強力なバックエンドサービスを構築できます。

なぜMySQL + Node.jsを選ぶのか？

  • MySQLは信頼性の高いデータストレージと管理を提供します
  • Node.jsのノンブロッキングI/Oモデルはデータベース操作に適しています
  • JavaScriptフルスタック開発（フロントエンドとバックエンドで同じ言語を使用）
  • 豊富なnpmエコシステムには多くのMySQL関連パッケージがあります

必要な依存関係のインストール

始める前に、インストールする必要がありますmysql2パッケージ。これはNode.jsでMySQLに接続するための人気のある選択肢です。

npm install mysql2

なぜmysqlではなくmysql2を選ぶのか？

  • より良いパフォーマンス
  • Promise APIをサポート
  • プリペアドステートメントをサポート
  • 活発なメンテナンス

データベース接続の確立

基本接続設定

例

const mysql = require('mysql2');

// 接続プールを作成（本番環境での使用を推奨）
const pool = mysql.createPool({
  host: 'localhost',     // データベースサーバーのアドレス
  user: 'root',          // データベースのユーザー名
  password: 'password',  // データベースのパスワード
  database: 'test_db',   // 接続するデータベース名
  waitForConnections: true,
  connectionLimit: 10,   // 接続プールの最大接続数
  queueLimit: 0
});

// Promiseバージョンの接続を取得
const promisePool = pool.promise();

接続プール vs 単一接続

接続プールの利点：

  • 接続を再利用し、オーバーヘッドを削減
  • 接続のライフサイクルを自動管理
  • 接続リークを防止
  • より良いパフォーマンス

単一接続が適しているシナリオ：

  • 簡単なスクリプト
  • テスト環境
  • 低同時実行アプリケーション

基本的なCRUD操作の実行

データのクエリ（SELECT）

例

async function getUsers() {
  try {
    const [rows, fields] = await promisePool.query('SELECT * FROM users');

    return rows;
  } catch (err) {
    console.error('クエリエラー:', err);
    throw err;

高度な機能とベストプラクティス

トランザクション処理

例

async function transferFunds(fromId, toId, amount) {
  let connection;
  try {
    // 接続プールから接続を取得
    connection = await promisePool.getConnection();
   
    // トランザクションを開始
    await connection.beginTransaction();
   
    // 振込操作を実行
    await connection.query(
      'UPDATE accounts SET balance = balance - ? WHERE id = ?',
      [amount, fromId]
    );
   
    await connection.query(
      'UPDATE accounts SET balance = balance + ? WHERE id = ?',
      [amount, toId]
    );
   
    // トランザクションをコミット
    await connection.commit();
    console.log('振込成功');
  } catch (err) {
    // エラー時はロールバック
    if (connection) await connection.rollback();
    console.error('振込失敗:', err);
    throw err;
  } finally {
    // 接続を接続プールに戻す
    if (connection) connection.release();
  }
}

プリペアドステートメント

プリペアドステートメントはパフォーマンスを向上させ、SQLインジェクションを防ぐことができます：

例

async function getUserById(id) {
  try {
    // プリペアドステートメントを準備
    const [rows] = await promisePool.execute(
      'SELECT * FROM users WHERE id = ?',
      [id]
    );
    return rows[0];
  } catch (err) {
    console.error('クエリエラー:', err);
    throw err;
  }
}

エラー処理とデバッグ

よくあるエラーの種類

  1. 接続エラー：データベースサーバーに到達できない、認証失敗など
  2. クエリ構文エラー：SQL文に誤りがある
  3. 制約違反：主キーの重複、外部キー制約など
  4. タイムアウトエラー：クエリの実行時間が長すぎる

エラー処理戦略

例

async function safeQuery(sql, params) {
  try {
    const [rows] = await promisePool.query(sql, params);
    return rows;
  } catch (err) {
    // エラーの種類に応じて異なる対策を講じる
    switch (err.code) {
      case 'ER_DUP_ENTRY':
        console.warn('重複エントリ:', err.sqlMessage);
        throw new Error('データは既に存在します');
      case 'ECONNREFUSED':
        console.error('データベースに接続できません');
        throw new Error('サービスを利用できません。後でもう一度お試しください');
      default:
        console.error('データベースエラー:', err);
        throw err;
    }
  }
}

パフォーマンス最適化のアドバイス

  1. 接続プールのサイズを適切に設定：通常はCPUコア数の2〜3倍
  2. 単一接続ではなく接続プールを使用：特にWebアプリケーションで
  3. インデックスを適切に使用：クエリのパフォーマンスを向上
  4. バッチ操作：ラウンドトリップ回数を削減
  5. プリペアドステートメントを使用：繰り返しのクエリのパフォーマンスを向上
  6. 定期的にリソースを解放：接続リークを防止

バッチ挿入の例：

例

async function batchInsertUsers(users) {
  const values = users.map(user => [user.name, user.email]);
 
  try {
    const [result] = await promisePool.query(

      [values]
    );
    console.log('挿入行数:', result.affectedRows);
    return result;
  } catch (err) {
    console.error('バッチ挿入エラー:', err);
    throw err;
  }
}

セキュリティ上の注意事項

  1. SQL文字列を絶対に連結しない：パラメータ化クエリを使用してSQLインジェクションを防ぐ
  2. データベースユーザーの権限を制限：アプリケーションアカウントには必要な権限のみを付与
  3. 機密データを暗号化：パスワードはソルト付きハッシュで保存する
  4. SSL接続を使用：本番環境では暗号化接続を推奨
  5. 依存関係を定期的に更新：mysql2パッケージを最新バージョンに保つ
