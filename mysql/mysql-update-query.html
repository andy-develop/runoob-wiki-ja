MySQL UPDATE 更新

MySQL のデータを変更または更新する必要がある場合は、次を使用できます。UPDATEコマンドで操作します。

構文

以下は、UPDATE コマンドで MySQL データテーブルのデータを変更するための一般的な SQL 構文です：

UPDATE table_name
SET column1 = value1, column2 = value2, ...
WHERE condition;

パラメータの説明：

  • table_nameは、データを更新するテーブルの名前です。
  • column1, column2, ... は、更新する列の名前です。
  • value1, value2, ... は、古い値を置き換えるための新しい値です。
  • WHERE conditionは、更新する行を指定するためのオプションの句です。省略した場合WHERE句を指定すると、テーブル内のすべての行が更新されます。

詳細な説明：

  • 1つまたは複数のフィールドを同時に更新できます。
  • WHERE 句で任意の条件を指定できます。
  • 単一のテーブルでデータを同時に更新できます。

データテーブル内の特定の行のデータを更新する必要がある場合、WHERE 句は非常に便利です。

例

次の例は、UPDATE 文の使用方法を示しています。

1. 単一の列の値を更新：

UPDATE employees
SET salary = 60000
WHERE employee_id = 101;

2. 複数の列の値を更新：

UPDATE orders
SET status = 'Shipped', ship_date = '2023-03-01'
WHERE order_id = 1001;

3. 式を使用して値を更新：

UPDATE products
SET price = price * 1.1
WHERE category = 'Electronics';

上記の SQL 文は、「Electronics」カテゴリに属する各製品の価格を 10% 引き上げます。

4. 条件を満たすすべての行を更新：

UPDATE students
SET status = 'Graduated';

上記の SQL 文は、すべての学生のステータスを「Graduated」に更新します。

5. サブクエリを使用して値を更新：

UPDATE customers
SET total_purchases = (
    SELECT SUM(amount)
    FROM orders
    WHERE orders.customer_id = customers.customer_id
)
WHERE customer_type = 'Premium';

上記の SQL 文は、サブクエリを使用して「Premium」タイプの各顧客の合計購入金額を計算し、その値を total_purchases 列に更新します。

注意：UPDATE 文を使用するときは、更新したい行だけが変更されるように十分な条件を指定してください。WHERE 句を指定しない場合、テーブル内のすべての行が更新され、予期しない結果が生じる可能性があります。

コマンドプロンプトでデータを更新する

以下では、UPDATE コマンドで WHERE 句を使用して、runoob_tbl テーブルの指定されたデータを更新します。

次の例では、データテーブル内の runoob_id が 3 の runoob_title フィールドの値を更新します：

SQL UPDATE 文：

mysql> UPDATE runoob_tbl SET runoob_title='C++ を学ぶ' WHERE runoob_id=3; Query OK, 1 rows affected (0.01 sec) mysql> SELECT * from runoob_tbl WHERE runoob_id=3; +-----------+--------------+---------------+-----------------+ | runoob_id | runoob_title | runoob_author | submission_date | +-----------+--------------+---------------+-----------------+ | 3| 学ぶC++ | RUNOOB.COM | 2016-05-06 | +-----------+--------------+---------------+-----------------+ 1 rows in set (0.01 sec)

結果から、runoob_id が 3 の runoob_title が変更されたことがわかります。

PHPスクリプトを使用したデータの更新

PHP では、関数 mysqli_query() を使用して SQL 文を実行します。SQL UPDATE 文では WHERE 句を使用することも、使用しないこともできます。

注意：WHERE 句を使用せずにデータテーブルのすべてのデータを更新することになるため、注意が必要です。

この関数は、mysql>コマンドプロンプトで SQL 文を実行するのと同じ効果があります。

例

次の例では、runoob_id が 3 の runoob_title フィールドのデータを更新します。

MySQL UPDATE 文のテスト：

<?php $dbhost = 'localhost'; //MySQLサーバーのホストアドレス $dbuser = 'root'; //MySQLユーザー名 $dbpass = '123456'; //MySQLユーザーパスワード $conn = mysqli_connect($dbhost, $dbuser, $dbpass); if(! $conn ) { die('接続失敗：' . mysqli_error($conn)); } //エンコーディングを設定して、中国語の文字化けを防ぐ mysqli_query($conn , "set names utf8"); $sql = 'UPDATE runoob_tbl SET runoob_title="学习 Python" WHERE runoob_id=3'; mysqli_select_db( $conn, 'RUNOOB' ); $retval = mysqli_query( $conn, $sql ); if(! $retval ) { die('データを更新できません：' . mysqli_error($conn)); } echo 'データの更新に成功しました！'; mysqli_close($conn); ?>

    UPDATEで特定のフィールド内の特定の文字を置換する

    フィールド内の特定の文字列を他の文字列に一括変更する必要がある場合は、次の操作を使用できます：

    UPDATE table_name SET field=REPLACE(field, 'old-string', 'new-string') 
[WHERE Clause]

    例：

    次の例では、runoob_id が 3 の runoob_title フィールドの値の「C++」を「Python」に置き換えます：

    UPDATE runoob_tbl SET runoob_title = REPLACE(runoob_title, 'C++', 'Python') where 
runoob_id = 3;
