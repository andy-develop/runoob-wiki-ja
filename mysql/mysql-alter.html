MySQL ALTER コマンド

データテーブル名やデータテーブルのフィールドを変更する必要がある場合は、MySQLALTERコマンドを使用する必要があります。

MySQL のALTERコマンドは、データベース、テーブル、インデックスなどのオブジェクトの構造を変更するために使用されます。

ALTERコマンドを使用すると、データベースオブジェクトを追加、変更、削除でき、テーブルの列定義の変更、制約の追加、インデックスの作成と削除などの操作に使用できます。

ALTER コマンドは非常に強力で、データベース構造が変化したときに柔軟に変更や調整を行うことができます。

以下はALTERコマンドの一般的な使用方法と例です：

1. 列の追加

ALTER TABLE table_name
ADD COLUMN new_column_name datatype;

次の SQL ステートメントは、employees テーブルに birth_date という名前の日付列を追加します：

例

ALTER TABLE employees
ADD COLUMN birth_date DATE;

2. 列のデータ型の変更

例

ALTER TABLE TABLE_NAME
MODIFY COLUMN column_name new_datatype;

次の SQL ステートメントは、employees テーブルの salary 列のデータ型を DECIMAL(10,2) に変更します：

例

ALTER TABLE employees
MODIFY COLUMN salary DECIMAL(10,2);

3. 列名の変更

ALTER TABLE table_name
CHANGE COLUMN old_column_name new_column_name datatype;

次の SQL ステートメントは、employees テーブルの特定の列名を old_column_name から new_column_name に変更し、同時にデータ型も変更できます：

例

ALTER TABLE employees
CHANGE COLUMN old_column_name new_column_name VARCHAR(255);

4. 列の削除

ALTER TABLE table_name
DROP COLUMN column_name;

次の SQL ステートメントは、employees テーブルの birth_date 列を削除します：

例

ALTER TABLE employees
DROP COLUMN birth_date;

5. PRIMARY KEY の追加

ALTER TABLE table_name
ADD PRIMARY KEY (column_name);

次の SQL ステートメントは、employees テーブルに主キーを追加します：

例

ALTER TABLE employees
ADD PRIMARY KEY (employee_id);

6. FOREIGN KEY の追加

ALTER TABLE child_table
ADD CONSTRAINT fk_name
FOREIGN KEY (column_name)
REFERENCES parent_table (column_name);

次の SQL ステートメントは、orders テーブルに外部キーを追加し、customers テーブルの customer_id 列に関連付けます：

例

ALTER TABLE orders
ADD CONSTRAINT fk_customer
FOREIGN KEY (customer_id)
REFERENCES customers (customer_id);

7. テーブル名の変更

ALTER TABLE old_table_name
RENAME TO new_table_name;

次の SQL ステートメントは、テーブル名を employees から staff に変更します：

例

ALTER TABLE employees
RENAME TO staff;

注意：

ただし、ALTERコマンドを使用する際は特に注意が必要です。一部の操作ではテーブルやインデックスの再構築が必要になる場合があり、データベースのパフォーマンスや実行時間に影響を与える可能性があります。

重要な構造変更を行う場合は、事前にデータをバックアップし、本番環境では慎重に操作することをお勧めします。

例

この章のチュートリアルを始める前に、テーブルを作成しましょう。テーブル名は次のとおりです：testalter_tbl。

例

root@host# mysql -u root -p password;
Enter password:*******
mysql> USE RUNOOB;
DATABASE changed
mysql> CREATE TABLE testalter_tbl
    -> (
    -> i INT,
    -> c CHAR(1)
    -> );
Query OK, 0 ROWS affected (0.05 sec)
mysql> SHOW COLUMNS FROM testalter_tbl;
+-------+---------+------+-----+---------+-------+
| FIELD | TYPE    | NULL | KEY | DEFAULT | Extra |
+-------+---------+------+-----+---------+-------+
| i     | INT(11) | YES  |     | NULL    |       |
| c     | CHAR(1) | YES  |     | NULL    |       |
+-------+---------+------+-----+---------+-------+
2 ROWS IN SET (0.00 sec)

テーブルフィールドの削除、追加、変更

次のコマンドは、ALTER コマンドと DROP 句を使用して、上記で作成したテーブルの i フィールドを削除します：

mysql> ALTER TABLE testalter_tbl  DROP i;

データテーブルにフィールドが1つしか残っていない場合、DROP を使用してフィールドを削除することはできません。

MySQL では ADD 句を使用してデータテーブルに列を追加します。次の例では、テーブル testalter_tbl に i フィールドを追加し、データ型を定義しています：

mysql> ALTER TABLE testalter_tbl ADD i INT;

上記のコマンドを実行すると、i フィールドはデータテーブルのフィールドの末尾に自動的に追加されます。

mysql> SHOW COLUMNS FROM testalter_tbl;
+-------+---------+------+-----+---------+-------+
| Field | Type    | Null | Key | Default | Extra |
+-------+---------+------+-----+---------+-------+
| c     | char(1) | YES  |     | NULL    |       |
| i     | int(11) | YES  |     | NULL    |       |
+-------+---------+------+-----+---------+-------+
2 rows in set (0.00 sec)

新しいフィールドの位置を指定する必要がある場合は、MySQL が提供するキーワード FIRST（先頭の列に設定）、AFTER フィールド名（特定のフィールドの後に設定）を使用できます。

次の ALTER TABLE ステートメントを試してください。実行が成功したら、SHOW COLUMNS を使用してテーブル構造の変更を確認します：

ALTER TABLE testalter_tbl DROP i;
ALTER TABLE testalter_tbl ADD i INT FIRST;
ALTER TABLE testalter_tbl DROP i;
ALTER TABLE testalter_tbl ADD i INT AFTER c;

FIRST および AFTER キーワードは ADD と MODIFY 句で使用できます。そのため、データテーブルのフィールドの位置をリセットしたい場合は、最初に DROP を使用してフィールドを削除し、次に ADD を使用してフィールドを追加して位置を設定する必要があります。

フィールドの型と名前の変更

フィールドの型と名前を変更する必要がある場合は、ALTER コマンドで MODIFY または CHANGE 句を使用できます。

たとえば、フィールド c の型を CHAR(1) から CHAR(10) に変更するには、次のコマンドを実行できます：

mysql> ALTER TABLE testalter_tbl MODIFY c CHAR(10);

CHANGE 句を使用する場合、構文は大きく異なります。 CHANGE キーワードの直後には、変更するフィールド名が続き、その後に新しいフィールド名と型を指定します。次の例を試してください：

mysql> ALTER TABLE testalter_tbl CHANGE i j BIGINT;

mysql> ALTER TABLE testalter_tbl CHANGE j j INT;

ALTER TABLE が Null 値とデフォルト値に与える影響

フィールドを変更するときに、値を含めるかどうか、またはデフォルト値を設定するかどうかを指定できます。

次の例では、フィールド j を NOT NULL かつデフォルト値 100 として指定しています。

mysql> ALTER TABLE testalter_tbl 
    -> MODIFY j BIGINT NOT NULL DEFAULT 100;

デフォルト値を設定しない場合、MySQL は自動的にそのフィールドのデフォルトを NULL に設定します。

フィールドのデフォルト値の変更

ALTER を使用してフィールドのデフォルト値を変更できます。次の例を試してください：

mysql> ALTER TABLE testalter_tbl ALTER i SET DEFAULT 1000;
mysql> SHOW COLUMNS FROM testalter_tbl;
+-------+---------+------+-----+---------+-------+
| Field | Type    | Null | Key | Default | Extra |
+-------+---------+------+-----+---------+-------+
| c     | char(1) | YES  |     | NULL    |       |
| i     | int(11) | YES  |     | 1000    |       |
+-------+---------+------+-----+---------+-------+
2 rows in set (0.00 sec)

ALTER コマンドと DROP 句を使用してフィールドのデフォルト値を削除することもできます。次の例のとおりです：

mysql> ALTER TABLE testalter_tbl ALTER i DROP DEFAULT;
mysql> SHOW COLUMNS FROM testalter_tbl;
+-------+---------+------+-----+---------+-------+
| Field | Type    | Null | Key | Default | Extra |
+-------+---------+------+-----+---------+-------+
| c     | char(1) | YES  |     | NULL    |       |
| i     | int(11) | YES  |     | NULL    |       |
+-------+---------+------+-----+---------+-------+
2 rows in set (0.00 sec)

注意：データテーブルの型を確認するには、SHOW TABLE STATUS ステートメントを使用できます。

テーブル名の変更

データテーブルの名前を変更する必要がある場合は、ALTER TABLE ステートメントで RENAME 句を使用して実現できます。

次の例を試して、データテーブル testalter_tbl を alter_tbl に名前変更します：

mysql> ALTER TABLE testalter_tbl RENAME TO alter_tbl;

ALTER コマンドは、MySQL データテーブルのインデックスの作成と削除にも使用できます。この機能については、次の章で紹介します。
