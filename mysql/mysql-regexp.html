MySQL 正規表現

前の章で、MySQL は次の方法を使用してLIKE ...%あいまいマッチングを行うことができることを学びました。

MySQL は他の正規表現によるマッチングもサポートしています。MySQL ではREGEXPとRLIKE演算子を使用して正規表現マッチングを行います。

PHP や Perl を知っていれば、操作は非常に簡単です。MySQL の正規表現マッチングはこれらのスクリプトと似ているからです。

以下の表の正規表現パターンは、REGEXP 演算子に適用できます。

パターン説明
^入力文字列の先頭位置にマッチします。RegExp オブジェクトの Multiline プロパティが設定されている場合、^ は '\n' または '\r' の後の位置にもマッチします。
$入力文字列の末尾位置にマッチします。RegExp オブジェクトの Multiline プロパティが設定されている場合、$ は '\n' または '\r' の前の位置にもマッチします。
."\n" 以外の任意の 1 文字にマッチします。'\n' を含む任意の文字にマッチさせるには、'[.\n]' のようなパターンを使用してください。
[...]文字セット。含まれる任意の 1 文字にマッチします。例えば、'[abc]' は "plain" の 'a' にマッチします。
[^...]否定文字セット。含まれない任意の文字にマッチします。例えば、'[^abc]' は "plain" の 'p' にマッチします。
p1|p2|p3p1 または p2 または p3 にマッチします。例えば、'z|food' は "z" または "food" にマッチします。'(z|f)ood' は "zood" または "food" にマッチします。
*前の部分式に 0 回以上マッチします。例えば、zo* は "z" および "zoo" にマッチします。* は {0,} と同等です。
+前の部分式に 1 回以上マッチします。例えば、'zo+' は "zo" および "zoo" にマッチしますが、"z" にはマッチしません。+ は {1,} と同等です。
{n}n は非負の整数です。ちょうど n 回マッチします。例えば、'o{2}' は "Bob" の 'o' にはマッチしませんが、"food" の 2 つの o にはマッチします。
{n,m}m と n はともに非負の整数で、n <= m です。最低 n 回、最大 m 回マッチします。

正規表現でマッチする文字クラス

  • .：任意の 1 文字にマッチします。
  • ^：文字列の先頭にマッチします。
  • $：文字列の末尾にマッチします。
  • *：前の要素の 0 個以上にマッチします。
  • +：前の要素の 1 個以上にマッチします。
  • ?：前の要素の 0 個または 1 個にマッチします。
  • [abc]：文字セット内の任意の 1 文字にマッチします。
  • [^abc]：文字セット内の任意の 1 文字以外の文字にマッチします。
  • [a-z]：範囲内の任意の小文字 1 文字にマッチします。
  • [0-9]：数字 1 文字にマッチします。
  • \w：英数字文字（アンダースコアを含む）1 文字にマッチします。
  • \s：空白文字 1 文字にマッチします。

REGEXP を使用したパターンマッチング

REGEXP は正規表現マッチングを行うための演算子です。

REGEXP は、文字列が指定された正規表現パターンにマッチするかどうかを確認するために使用します。以下は REGEXP 演算子の基本構文です。

SELECT column1, column2, ...
FROM table_name
WHERE column_name REGEXP 'pattern';

パラメータの説明：

  • column1, column2, ... は選択する列の名前です。もし * を使用する場合、*すべての列を選択することを示します。
  • table_nameはデータをクエリするテーブルの名前です。
  • column_nameは正規表現マッチングを行う列の名前です。
  • 'pattern'は正規表現パターンです。

name フィールドで先頭が'st'で始まるすべてのデータを検索します：

mysql> SELECT name FROM person_tbl WHERE name REGEXP '^st';

name フィールドで末尾が'ok'で終わるすべてのデータを検索します：

mysql> SELECT name FROM person_tbl WHERE name REGEXP 'ok$';

name フィールドに'mar'文字列を含むすべてのデータを検索します：

mysql> SELECT name FROM person_tbl WHERE name REGEXP 'mar';

name フィールドで母音文字で始まるか、または'ok'文字列で終わるすべてのデータを検索します：

mysql> SELECT name FROM person_tbl WHERE name REGEXP '^[aeiou]|ok$';

注文テーブルから、説明に "item" の後に 1 つ以上の数字が続くレコードを選択します。

SELECT * FROM orders WHERE order_description REGEXP 'item[0-9]+';

使用BINARYキーワードにより、マッチングで大文字と小文字が区別されます：

SELECT * FROM products WHERE product_name REGEXP BINARY 'apple';

OR を使用して複数のマッチ条件を指定します。以下では、姓が "Smith" または "Johnson" である従業員のレコードを選択します：

SELECT * FROM employees WHERE last_name REGEXP 'Smith|Johnson';

RLIKE を使用したパターンマッチング

RLIKE は MySQL で正規表現マッチングを行うための演算子で、REGEXP と同じです。RLIKE と REGEXP は互換性があり、違いはありません。

以下は RLIKE を使用した正規表現マッチングの基本構文です：

SELECT column1, column2, ...
FROM table_name
WHERE column_name RLIKE 'pattern';

パラメータの説明：

  • column1, column2, ... は選択する列の名前です。もし * を使用する場合、*すべての列を選択することを示します。
  • table_nameはデータをクエリするテーブルの名前です。
  • column_nameは正規表現マッチングを行う列の名前です。
  • 'pattern'は正規表現パターンです。
SELECT * FROM products WHERE product_name RLIKE '^[0-9]';

上記の SQL 文は、製品名が数字で始まるすべての製品を選択します。
