Webセマンティクス


単語のセマンティクスはその意味を表します。

物事のセマンティクスはその物事を意味します。

Web セマンティクス = Web の意味。

Web セマンティクスとは？

セマンティクスとは何か？簡単に言えば、機械がコンテンツを読み取れるようにすることです。

  • ビートルズはリバプール出身の人気バンドです。
  • ジョン・レノンはビートルズのメンバーです。
  • 「Hey Jude」はビートルズの代表曲です。

私たちは上記の文の意味を簡単に理解できます。しかし、これらの文はどうやってコンピュータに理解されるのでしょうか？

文は文法規則によって作成されます。言語の文法は、言語の文を作成する規則を定義します。しかし、どのように文法をセマンティクスに変えるのでしょうか？

セマンティックウェブは、機械がデータを理解できるようにするものです。セマンティックウェブ技術は、一連の記述言語と推論ロジックを含みます。それはいくつかの形式を通じてオントロジーを記述します。

セマンティックウェブはウェブページ間のリンクではありません。

セマンティックウェブは、物事間の関連性（例：A は B の一部である、Y は Z のメンバーである）と、物事の属性（例：大きさ、高さ、年齢、価格など）を記述します。

セマンティックウェブの実装は、XML（eXtensible Markup Langauge、拡張可能なマークアップ言語）言語とリソース記述フレームワーク（RDF）に基づいて行われます。XMLはマークアップ言語を定義するためのツールであり、その内容にはXML宣言、言語の文法を定義するDTD（document type declaration、文書型定義）、マークを記述する詳細な説明、および文書自体が含まれます。文書自体にはマークと内容が含まれます。RDFはウェブページの内容を表現するために使用されます。


リソース記述フレームワーク

RDF（Resource Description Framework）、すなわちリソース記述フレームワークは、W3Cが推奨する、WWW上の情報リソースとその間の関係を記述するための言語仕様です。

RDF（S）はセマンティックウェブの重要な構成要素であり、URIを使用して異なるオブジェクト（リソースノード、プロパティクラス、プロパティ値を含む）を識別し、異なるURIを接続して、オブジェクト間の関係を明確に表現できます。


実装

セマンティックウェブはより素晴らしいネットワークですが、実装は複雑で大規模なプロジェクトです。現在、セマンティックウェブのアーキテクチャは構築中であり、主に以下の2つの側面のサポートが必要です：

（1）データネットワークの実装

すなわち、統一された完全なデータ標準を通じてネットワーク情報をより徹底的かつ詳細にマークし、セマンティックウェブが情報を正確に識別し、情報の役割と意味を区別できるようにすることです。セマンティックウェブ検索をより正確かつ徹底的にし、情報の真偽を判断しやすくして実用化の目標を達成するには、まず標準を策定する必要があります。この標準により、ユーザーはネットワークコンテンツにメタデータ（すなわち、詳細な説明マーク）を追加でき、ユーザーが探しているものを正確に指定できるようになります。次に、異なるプログラムが異なるウェブサイトのコンテンツを共有できるようにする方法を見つける必要があります。最後に、ユーザーがアプリケーションソフトウェアの追加などの他の機能を追加できるようにする必要があります。

セマンティックウェブの実装は、XML（eXtensible Markup Langauge、拡張可能なマークアップ言語）言語とリソース記述フレームワーク（RDF）に基づいて行われます。XMLはマークアップ言語を定義するためのツールであり、その内容にはXML宣言、言語の文法を定義するDTD（document type declaration、文書型定義）、マークを記述する詳細な説明、および文書自体が含まれます。文書自体にはマークと内容が含まれます。RDFはウェブページの内容を表現するために使用されます。

（2）セマンティック分析機能を備えた検索エンジン

データネットワークが短時間に数億の個人によって実現できるとすれば、ネットワークのセマンティック化とインテリジェント化は、人類の最先端の知性集団の努力によって実現される必要があります。セマンティック分析機能を備えた情報検索エンジンの研究開発は、セマンティックウェブの最も重要な一歩となるでしょう。このようなエンジンは人間の自然言語を理解でき、一定の推論と判断能力を持ちます。

セマンティック検索エンジン（semantic search engine）とセマンティック分析機能を備えた検索エンジン（semantically enabled search engine）は別物です。前者はセマンティックウェブの利用に過ぎず、一種の情報検索方法です。一方、セマンティック分析機能を備えた検索エンジンは、自然言語を理解でき、コンピュータの推論を通じてユーザーの意図により合致した回答を提供できるものです。

展望

セマンティックウェブのアーキテクチャは構築中であり、現在国際的にはこのアーキテクチャに関する研究は、満足のいく厳密な論理的記述と理論体系をまだ形成していません。中国の学者もこのアーキテクチャについて海外の研究に基づいて簡単な紹介を行っているだけで、体系的な説明には至っていません。

セマンティックウェブの実装には、XML、RDF、オントロジーという3つの主要技術のサポートが必要です。

XML（eXtensible Marked Language、すなわち拡張可能なマークアップ言語）は、情報提供者がニーズに応じてマークと属性名を独自に定義できるようにし、XMLファイルの構造を任意の複雑さにすることができます。

それは優れたデータ保存形式と拡張性、高度な構造化、ネットワーク伝送の容易さなどの利点を持ち、さらに独自のNSメカニズムとXML Schemaがサポートする複数のデータ型と検証メカニズムにより、セマンティックウェブの主要技術の1つとなっています。

現在、セマンティックウェブの主要技術に関する議論は、主にRDFとオントロジーに集中しています。

RDFはW3Cが推奨する、リソースとその間の関係を記述するための言語仕様であり、シンプルさ、拡張の容易さ、開放性、交換の容易さ、統合の容易さなどの特徴を持っています。

注目すべき点は、RDFはリソースの記述方法のみを定義しており、リソースを記述するためにどのデータを使用するかは定義していないことです。RDFは3つの部分から構成されています：RDF Data Model、RDF Schema、RDF Syntax。

参考までに：

1. セマンティックウェブは既存のインターネットを拡張し、情報にその意味を表す内容を追加することで、コンピュータが自動的に人間と協調して作業できるようにします。つまり、セマンティックウェブの各種リソースは、もはや単なる相互接続された情報ではなく、その情報の真の意味も含み、これによりコンピュータの情報処理の自動化とインテリジェント化が向上します。もちろん、コンピュータは真の知性を持っているわけではなく、セマンティックウェブの構築には、研究者が情報を効果的に表現し、統一された標準を策定して、コンピュータが情報を効果的に自動処理できるようにする必要があります。

（出典：何斌、張立厚『情報管理の原理と方法』清華大学出版社、2007年7月第2版）


セマンティックウェブのアーキテクチャ

  • 第1層：UnicodeとURIは、アーキテクチャ全体の基盤です。
  • 第2層：XML+NS+XMLSchemaは、データの内容と構造を構文上表現する役割を担い、標準の形式言語を使用してネットワーク情報の表現形式、データ構造、内容を分離します。
  • 第3層：RDF+RDF Schemaは、オンラインの情報とタイプを記述するためのセマンティックモデルを提供します。ここで、RDF（Resource Description Framework）、すなわちリソース記述フレームワークは、W3Cが推奨する、WWW上の情報リソースとその間の関係を記述するための言語仕様です。RDF（S）はセマンティックウェブの重要な構成要素であり、URIを使用して異なるオブジェクト（リソースノード、プロパティクラス、プロパティ値を含む）を識別し、異なるURIを接続して、オブジェクト間の関係を明確に表現できます。
  • 第4層：オントロジー語彙層。オントロジーは、ドメイン知識の概念化・形式化された明確な仕様です。セマンティックウェブのアーキテクチャにおいて、オントロジーの役割は主に以下の通りです：（1）概念記述：概念の記述を通じてドメイン知識を明らかにする。（2）セマンティックな提示：オントロジーはRDFより強力な表現能力を持ち、より豊かなセマンティックな関係を明らかにできる。（3）一貫性：オントロジーはドメイン知識の明確な仕様として、セマンティックな一貫性を保証し、一語多義、多語一義、語義の曖昧さを徹底的に解決する。（4）推論サポート：オントロジーの概念記述における決定性と強力なセマンティックな提示能力は、データレベルで推論の有効性を強力に保証する。
  • 第5層：論理層は、公理と推論原則を提供し、インテリジェントサービスの基盤を提供します。ここで、記述論理（DescriptionLogic）はオブジェクトベースの知識表現の形式化であり、KL-ONEの主要な考え方を取り入れた、一階述語論理の決定可能なサブセットです。一階述語論理と異なり、記述論理システムは決定可能な推論サービスを提供できます。知識表現以外にも、記述論理は他の多くの分野で使用されており、オブジェクト中心の表現言語の最も重要な正規形と考えられています。記述論理の重要な特徴は、非常に強い表現力と決定可能性であり、推論アルゴリズムが常に停止し、正しい結果を返すことを保証できます。多くの知識表現の形式化手法の中で、記述論理は10年以上にわたって特に注目されてきました。主な理由は以下の通りです：明確なモデル理論的メカニズムを持ち、概念分類学を通じて応用領域を表現するのに非常に適しており、非常に有用な推論サービスを提供します。
  • 第6層の証明層と第7層の信頼層は、認証と信頼メカニズムを提供する役割を担います。
