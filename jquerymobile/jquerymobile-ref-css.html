jQuery Mobile CSS クラス

jQuery CSS クラス

jQuery Mobile CSS クラスを使用して、さまざまな要素のスタイルを設定します。

以下のリストには、一般的な CSS スタイルが含まれています：

グローバルクラス

以下のクラスは、jQuery Mobile ウィジェット（ボタン、ツールバー、パネル、テーブル、リストなど）で使用できます：

Class 説明
ui-corner-all 要素に角丸を追加します
ui-shadow 要素に影を追加します
ui-overlay-shadow 要素に複数の影を追加します
ui-mini 要素を小さくします

ボタンクラス

グローバルクラスに加えて、<a> または <button> 要素（<input> ボタンではありません）に次のクラスを追加できます：

Class 説明
ui-btn <a> 要素に追加し、ボタンとして表示します
ui-btn-inline ボタンを同じ行に表示します
ui-btn-icon-top アイコンをボタンのテキストの上に配置します
ui-btn-icon-right アイコンをボタンのテキストの右に配置します
ui-btn-icon-bottom アイコンをボタンのテキストの下に配置します
ui-btn-icon-left アイコンをボタンのテキストの左に配置します
ui-btn-icon-notext アイコンのみを表示
ui-btn-a|b ボタンのスタイルを指定します。「a」はデフォルト（灰色の背景に黒いテキストスタイル）、「b」は黒い背景に白いテキストに色を変更します。

テーマクラス Classes

jQuery Mobile は、2つのテーマクラス a（グレー）と b（黒）を提供します。ただし、独自のカスタムクラスを作成できます - アルファベットの「z」まで定義できます（jQuery Mobile テーマ）。 次の表に、利用可能なテーマクラスを示します。 文字（a-z）は、スタイルが a から z まで指定できることを意味します。例：ui-bar-a や ui-bar-b など。

Class 説明
ui-bar-(a-z) バーのスタイルを指定します - ヘッダー、フッター、およびその他のバー
ui-body-(a-z) コンテンツブロックの色を指定します - ページコンテンツ部分（バージョン 1.4.0 で非推奨）、リストビュー、ポップアップ、サイドバー、パネル、ローディング、折りたたみ。
ui-btn-(a-z) ボタンの色を指定します
ui-group-theme-(a-z) コントロールグループ、listview、collapsible セットのスタイルを定義します。
ui-overlay-(a-z) ページの背景色を定義します。ダイアログ、ポップアップ、および最上部に表示されるその他のページコンテナを含みます。
ui-page-theme-(a-z) ページのスタイルを定義します

グリッドクラス

グリッドの列は等幅です（合計 100%）。枠線、背景、margin、padding はありません。ここでは、4つのレイアウトグリッドを使用できます：

グリッドクラス 列 列幅 対応 例
ui-grid-solo 1 100% ui-block-a 試してみる
ui-grid-a 2 50% / 50% ui-block-a|b 試してみる
ui-grid-b 3 33% / 33% / 33% ui-block-a|b|c  試してみる
ui-grid-c 4 25% / 25% / 25% / 25% ui-block-a|b|c|d 試してみる
ui-grid-d 5 20% / 20% / 20% / 20% / 20% ui-block-a|b|c|d|e 試してみる

詳細については、jQuery Mobile グリッドの章を参照してください。
