FastAPI パスパラメータ

パスパラメータは URL パス内の動的な部分であり、波括弧を使用して{}宣言します。FastAPI はパスパラメータを自動的にパス操作関数に渡し、型アノテーションに基づいてデータ変換と検証を行います。

基本的な使い方

Python のフォーマット文字列構文を使用してパスパラメータを宣言します：

例

from fastapi import FastAPI

app = FastAPI()

# {item_id} はパスパラメータです
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    return {"item_id": item_id}

アクセスhttp://127.0.0.1:8000/items/5すると、戻り値：

{"item_id": 5}

返り値がitem_id整数である5、文字列ではないことに注意してください"5"。FastAPI は型アノテーションを通じてitem_id: intURL 内の文字列を整数に自動変換します。

データ変換

型をintと宣言すると、FastAPI は自動的に型変換を行います：

# 传入整数，正常工作
GET /items/3       -> {"item_id": 3}

# 传入非整数，返回校验错误
GET /items/foo     -> 错误：Input should be a valid integer

# 传入浮点数，同样报错
GET /items/4.2     -> 错误：Input should be a valid integer

アクセスhttp://127.0.0.1:8000/items/fooすると、FastAPI が返す検証エラーメッセージ：

{
  "detail": [
    {
      "type": "int_parsing",
      "loc": ["path", "item_id"],
      "msg": "Input should be a valid integer, unable to parse string as an integer",
      "input": "foo"
    }
  ]
}

FastAPI の検証エラーメッセージは非常に明確で、具体的なエラー位置（loc）、エラータイプ（type）、エラーの説明（msg）を示します。これはデバッグの際に非常に役立ちます。
