FastAPI Webアプリ

この章では、ゼロからFastAPIを使って最初のWebアプリを作成し、自動生成されるAPIドキュメントを体験します。

FastAPIとDjango/Flaskの位置付けの違い

FastAPIはPython Webフレームワークの新星であり、DjangoとFlaskの中間に位置付けられます。

特徴DjangoFlaskFastAPI
設計思想バッテリー同梱マイクロフレームワーク、必要に応じて拡張高性能、型駆動
非同期サポート3.1+からサポートネイティブサポートなしネイティブasync/await
APIドキュメントdrf-spectacularが必要Flasggerが必要Swagger UIを自動生成
データ検証Django Forms / DRF SerializerFlask-WTF / 手動Pydantic（内蔵）
サーバーWSGI（Gunicorn）WSGI（Gunicorn）ASGI（Uvicorn）
型安全性任意任意Python型ヒントを強制

FastAPIの最大の違い：Pythonの型ヒントで全てを駆動する——ルートパラメータの自動検証、リクエスト/レスポンスの自動シリアライズ、対話型ドキュメントの自動生成。

環境準備

$ python3 -m venv venv
$ source venv/bin/activate
(venv) $ pip install fastapi uvicorn jinja2 python-multipart

3つのコア依存関係の説明：

  • fastapi：Webフレームワーク本体
  • uvicorn：ASGIサーバー（FlaskにおけるGunicornに相当）
  • jinja2：テンプレートエンジン（オプションだが、SSRを行うには必要）

FastAPI最小アプリ

例

# ファイルパス：main.py
from fastapi import FastAPI

# FastAPIインスタンスを作成
app = FastAPI(
    title="サンプルブログ",
    description="FastAPIで構築した個人ブログ展示サイト",
    version="1.0.0"
)

@app.get("/")           # GETリクエストのルートデコレータ
def index():
    """ホームページ"""
    return {"message": "サンプルブログへようこそ"}

@app.get("/hello/{name}")   # パスパラメータ {name}
def hello(name: str):       # FastAPIが型ヒントに基づいて自動検証
    return {"greeting": f"こんにちは、{name}！"}

サーバー起動

(venv) $ uvicorn main:app --reload
INFO:     Uvicorn running on http://127.0.0.1:8000

起動方法がFlaskとは異なる点に注意：

  • Flask：flask run（Werkzeugベース）
  • FastAPI：uvicorn main:app（ASGIベース、ネイティブで非同期をサポート）

自動生成されるAPIドキュメント

これはFastAPIで最も魅力的な機能です——追加のコードを一切書かずに、対話型ドキュメントを自動生成。

アクセス/docsSwagger UIが表示され、ページ上で直接APIをテストできます：

http://127.0.0.1:8000/docs      # Swagger UI（交互式测试）
http://127.0.0.1:8000/redoc     # ReDoc（只读文档，更美观）

Swagger UIで：GET /hello/{name}をクリック → Try it out → nameを入力 → Executeで、実際のレスポンスを確認できます。

プロジェクトディレクトリ構成の計画

blog_project/
├── main.py               # 应用入口
├── models.py             # SQLAlchemy ORM 模型
├── schemas.py            # Pydantic Schema（FastAPI 独有）
├── database.py           # 数据库连接与 Session
├── auth.py               # JWT 认证逻辑
├── routers/              # APIRouter 路由模块
│   ├── posts.py
│   ├── categories.py
│   ├── users.py
│   └── favorites.py
├── templates/            # Jinja2 模板
├── static/               # 静态文件
└── alembic/              # 数据库迁移

FlaskはBlueprintでルートを整理し、FastAPIはAPIRouter。概念は似ていますが構文が異なり、APIRouterは標準で型制約を持ちます。

本章のまとめ

この章では、FastAPI + Uvicornのインストール、型ヒント付きの最初のルートの作成、自動生成された /docs 対話型APIドキュメントへのアクセスという3つのことを行いました。

中心となる学び：FastAPIはPythonの型ヒントでパラメータ検証とドキュメント生成を駆動します。これがDjango/Flaskと異なる最も本質的な特徴です。
