WSDL 入門

WSDL は、Web サービスとそのアクセス方法を記述するための XML ベースの言語です。

必要な基礎知識

学習を進める前に、以下の知識について基本的な理解が必要です。

  • XML
  • XML 名前空間
  • XML Schema

これらの項目を先に学習したい場合は、私たちのXML チュートリアルシリーズ。

WSDLとは？

  • WSDL は Web サービス記述言語を指します。
  • WSDL は XML を使用して記述されます。
  • WSDL は XML ドキュメントです。
  • WSDL は Web サービスを記述するために使用されます。
  • WSDL は Web サービスの位置を特定するためにも使用できます。
  • WSDL はまだ W3C 標準ではありません。

WSDL は Web サービスを記述することができます。

WSDL は Web サービス記述言語 (Web Services Description Language) を指します。

WSDL は XML を使用して記述されたドキュメントです。このドキュメントは、特定の Web サービスを記述できます。サービスの場所と、そのサービスが提供する操作（またはメソッド）を指定できます。

W3C における WSDL の開発史

2001年3月、WSDL 1.1 は、IBM とマイクロソフトによって、Web サービスを記述するための W3C ノートとして、XML プロトコルに関する W3C XML アクティビティに提出されました。

（W3C ノートは議論のためのものです。W3C ノートの発行は、W3C または W3C チーム、あるいは W3C メンバーによる承認を意味するものではありません。）

2002年7月、W3C は最初の WSDL 1.2 作業草案を公開しました。
