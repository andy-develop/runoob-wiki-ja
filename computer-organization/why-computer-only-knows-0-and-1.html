コンピュータ構成原理
進数変換 — 2進数、10進数、16進数

なぜコンピュータは0と1しか認識しないのか

この講義で理解できること：コンピュータが10進数ではなく2進数を選んだ理由、そしてその選択が現代のコンピュータの全アーキテクチャをどう決定づけたか。

スイッチから始めよう

あなたの目の前に電灯のスイッチが一列あると想像してみてください。

各スイッチには2つの状態しかありません：开或关。

スイッチを「半分オン」や「37%オン」にすることはできません——それは2状態であり、中間状態はありません。

コンピュータ内部の最も基本的な部品——トランジスタは、本質的にスイッチと同じものです。

それには2つの安定状態しかありません：導通（通電）と遮断（断電）。

電圧の2つの状態

デジタル回路では、この2つの状態にそれぞれ記号を割り当てます：

  • 高電圧（例：3.3V や 5V）は次のものを表します1
  • 低電圧（ほぼ0V）は次のものを表します0

電圧と2進数の関係

下のカラーバーは、トランジスタの0Vから3.3Vまでの電圧範囲をシミュレートし、論理0、論理1、禁止領域の関係を直感的に示しています。

0.0V
論理0 . 0.5V 1.0V 1.5V
禁止領域 1.8V
開始 2.1V 2.7V 3.3V
論理1

論理0の範囲：0.0V ~ 1.5V（青色領域） | 禁止領域：1.5V ~ 1.8V（灰色領域、信号は留まらない） | 論理1の範囲：1.8V ~ 3.3V（オレンジ色領域）

注意：回路は電圧値を正確に測定する必要はなく、「高いか低いか」を判断するだけです。

これは「いくつか」を判断するよりはるかに簡単です。

なぜ10進数を使わないのか

人間が10進数を使うのは、指が10本あるからです。

しかし、なぜコンピュータは10進数を使えないのでしょうか？

理由1：工学的な実装が極めて困難

回路に10進数の10個の数字（0〜9）を表させるには、10個の異なる電圧レベルを正確に区別する必要があります。

例：0V = 0、0.33V = 1、0.66V = 2、...、3.3V = 9。

問題はここです：信号は伝送中に減衰やノイズが発生します。

例えば、数字の2を表す0.66Vを送信しても、目的地に到達したとき電圧が0.71Vに変わっていたとします。

受信側は困惑します：これは2（0.66V）なのか、それとも3（0.99V）なのか？

理由2：2進数は本来ノイズに強い

2進数は2つの状態を区別するだけでよいため、許容範囲が非常に大きいです。

図のように：論理0の範囲は0〜1.5V、論理1の範囲は1.8V〜3.3Vです。

間には0.3Vの保護領域があります。

信号に大きな変動があっても、保護領域を越えなければデータは誤りません。

理由3：数学と完全に合致する

0と1は、ブール代数における「偽」と「真」に正確に対応します。

ブール代数（AND、OR、NOTなどの論理演算）には、完全な数学理論があります。

技術者はこの理論を使って回路を設計、分析、最適化できます——これは非常に幸運なことです。

コンピュータが2進数を選んだのは偶然ではありません。それは工学的制約（実装が容易）、物理的特性（ノイズ耐性）、数学的ツール（ブール代数）の3つが共同して作用した結果です。

ビットとバイト——情報の基本単位

1つの2進数ビットは 1 ビットbit（bit）と呼ばれ、0または1しか表せません。

明らかに、1ビットだけでは表せる情報が少なすぎます。

そこで8個のビットをまとめて 1byte（バイト）と呼びます。

1バイトで何通りの異なる値を表せるでしょうか？

各ビットには2つの選択肢（0または1）があり、8ビットの組み合わせ数は：

2 x 2 x 2 x 2 x 2 x 2 x 2 x 2 = 28 = 256

すなわち00000000（10進数の0）から11111111（10進数の255）まで、合計256通りの異なる値です。

バイト数表現可能な数値範囲一般的な用途
1バイト (8ビット)0 ~ 2551つのASCII文字、RGBカラーにおける1チャンネルの値
2バイト (16ビット)0 ~ 65,535ポート番号、初期のCPUのレジスタサイズ
4バイト (32ビット)0 ~ 4,294,967,295IPv4アドレス、int型
8バイト (64ビット)0〜約1.8 x 1019現代CPUのワード長、long型

インタラクティブデモ：1バイトの電球シミュレーター

次のインタラクティブパネルでは、8ビットがどのように組み合わさって0から255までの任意の数値を表すのかを直感的に体験できます。

各電球は1ビットを表します。電球をクリックすると0/1の状態を切り替えられます右側に対応する10進数の値がリアルタイムに表示されます。

電球シミュレーター：1バイト = 8ビット

電球をクリックして状態を切り替え、2進数が10進数にどう対応するかを観察してください。

10進数：0
2進数：00000000

各電球の下にある重み（ウェイト）の表示をよく見てください。

一番左の電球の重みが最大（128）、一番右の電球の重みが最小（1）です。

これが「重み付け展開」の考え方です——各位置の数値にその重みを掛け、すべて足し合わせたものが最終結果です。

コードで2進数を理解する

Pythonには2進数のサポートが組み込まれているので、それを使って上記の電球デモを直接検証できます。

例

# 2進数の基本操作（runoobデモ）

# 1. ある数値の2進数表現を確認する
print("10進数 → 2進数：")
for n in [0, 1, 2, 7, 8, 15, 16, 42, 65, 97, 127, 255]:
    # bin() は '0b...' 形式を返すので、[2:] でプレフィックスを除去
    # zfill(8) で8桁に揃える
    print(f"  {n:3d} → {bin(n)[2:].zfill(8)}")

print()

# 2. 2進数文字列を10進数として解析する
print("2進数 → 10進数：")
binary_strings = ["00000000", "01000001", "01100001", "11111111"]
for b in binary_strings:
    # int(string, 2) で2進数文字列を整数に変換
    dec = int(b, 2)
    print(f"  {b} → {dec:3d}")

print()

# 3. 検証：1バイトはちょうど256個の値
print("1バイトの範囲：")
print(f" 最小値: {int('00000000', 2)}")
print(f" 最大値: {int('11111111', 2)}")
print(f" 総数: {int('11111111', 2) - int('00000000', 2) + 1}")

print()

# 4. ビット演算：ビットごとのAND、OR、左シフト、右シフト
print("ビット演算の例：")
a = 0b0011  # 3
b = 0b0101  # 5
print(f" {bin(a)} & {bin(b)} = {bin(a & b)} (ビットごとのAND)")
print(f" {bin(a)} | {bin(b)} = {bin(a | b)} (ビットごとのOR)")
print(f" {bin(a)} << 1 = {bin(a << 1)} (1ビット左シフト、2倍に相当)")
print(f" {bin(b)} >> 1 = {bin(b >> 1)} (1ビット右シフト、2で割ることに相当)")

print()

# 5. RUNOOB テスト文字列
text = "RUNOOB"
print(f"文字列 '{text}' の各文字の2進数表現：")
for ch in text:
    ascii_val = ord(ch)
    print(f" '{ch}' → ASCII={ascii_val:3d} → 2進数={bin(ascii_val)[2:].zfill(8)}")

なぜ2進数が「情報表現」の基盤なのか

2進数を理解すれば、ある重要な事実を理解したことになります：

コンピュータ内部のすべて——数値、文字、画像、音声、動画——は最終的に0と1の形で保存・処理されます。

今後の講義で次のことを学びます：

  • 第2講：異なる進数間でどう変換するか
  • 第3講：負の数は2進数でどのように表すか（2の補数）
  • 第4講：小数は2進数でどのように表すか（浮動小数点数）
  • 第5講：文字は2進数でどのように表すか（文字コード）

これらの内容はすべて、「すべてが0と1である」という基盤の上に成り立っています。

このモジュール全5講の最も核心的な結論：コンピュータは情報を「理解」しているのではなく、精巧な符号化ルールによって、世の中の万物を0と1の組み合わせにマッピングしているのです。
