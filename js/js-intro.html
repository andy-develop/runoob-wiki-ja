JavaScript 紹介

JavaScript はインターネット上で最も人気のあるスクリプト言語で、HTML や Web で使用でき、さらにサーバー、PC、ノートパソコン、タブレット、スマートフォンなどのデバイスで広く使用できます。

JavaScript はスクリプト言語です

JavaScript は軽量なプログラミング言語です。

JavaScript は HTML ページに挿入できるプログラミングコードです。

JavaScript は HTML ページに挿入されると、すべての現代的なブラウザで実行できます。

JavaScript はとても学びやすいです。

学ぶ内容

以下は、このチュートリアルで学ぶ主な内容です。

JavaScript：HTML出力ストリームに直接書き込む

例

document.write("<h1>这是一个标题</h1>"); document.write("<p>这是一个段落。</p>");

試してみる »

document.write は HTML 出力でのみ使用できます。ドキュメントの読み込み後にこのメソッドを使用すると、ドキュメント全体が上書きされます。

JavaScript：イベントへの反応

例

<button type="button" onclick="alert('欢迎!')">点我!</button>

試してみる »

alert() 関数は JavaScript ではあまり一般的ではありませんが、コードのテストには非常に便利です。

onclick イベントは、このチュートリアルでこれから学ぶ数多くのイベントのうちの1つにすぎません。

JavaScript：HTMLコンテンツを変更する

JavaScript を使用して HTML コンテンツを処理することは、非常に強力な機能です。

例

x=document.getElementById("demo"); //要素を検索する x.innerHTML="Hello JavaScript"; //コンテンツを変更する

試してみる »

あなたはよく目にするでしょうdocument.getElementById("some id")。このメソッドは HTML DOM で定義されています。

DOM (Document Object Model)（ドキュメントオブジェクトモデル）は、HTML 要素にアクセスするための正式な W3C 標準です。

このチュートリアルの複数の章で、HTML DOM に関する知識を学びます。

JavaScript：HTML画像を変更する

この例では、HTML <image> のソース（src）を動的に変更します。

電球を点ける

<script> function changeImage() { element=document.getElementById('myimage') if (element.src.match("bulbon")) { element.src="/images/pic_bulboff.gif"; } else { element.src="/images/pic_bulbon.gif"; } } </script> <img id="myimage" onclick="changeImage()" src="/images/pic_bulboff.gif" width="100" height="180">

下の電球をクリックして効果を確認してください：

電球をクリックすると、このランプをオン/オフできます。


試してみる »

上記の例のコードはelement.src.match("bulbon")の意味は、検索することです：<img id="myimage" onclick="changeImage()" src="../images/pic_bulboff.gif" width="100" height="180">の中の src 属性の値に含まれているかどうかbulbonこの文字列が存在する場合、bulbon、画像はsrcに更新されますbulboff.gif、一致しない場合はbulbon文字列、srcに更新されますbulbon.gif

JavaScript は画像だけでなく、あらゆる HTML 要素のほとんどの属性を変更できます。

JavaScript：HTMLスタイルを変更する

HTML 要素のスタイルを変更することは、HTML 属性を変更する変種です。

例

x=document.getElementById("demo") //要素を見つける x.style.color="#ff0000"; //スタイルを変更する

試してみる »

JavaScript：入力の検証

JavaScript はユーザーの入力を検証するためによく使われます。

例

if isNaN(x) { alert("数字ではありません"); }

試してみる »

上記の例は単なる一般的な検証です。本番環境で使用する場合は厳密な判断が必要です。入力がスペース、または連続スペースの場合、isNaN では判別できません。正規表現を追加して判断することができます（後の章で説明します）：

例

if(isNaN(x)||x.replace(/(^\s*)|(\s*$)/g,"")==""){ alert("数字ではありません"); }

試してみる »

ご存知ですか？

JavaScript と Java は、概念上も設計上もまったく異なる言語です。
Java（Sun によって開発）は、より複雑なプログラミング言語です。

ECMA-262 は JavaScript 標準の正式名称です。

JavaScript は Brendan Eich によって開発されました。1995 年に Netscape（このブラウザは更新が停止されています）に登場し、1997 年に ECMA（標準化団体）によって採用されました。

ECMAScript のバージョン

JavaScript は、ECMA（欧州コンピュータメーカー協会）によって ECMAScript を通じて標準化されています。

    上記の @IT攻城狮 さんへの返信です。

    このコードでは、~function(e){...}(this) は、次を使用していることを示しています：自己実行型の無名関数（Immediately Invoked Function Expression、IIFE）。この無名関数は1つの引数を受け取りますe、現在クリックされた画像要素を表し、その要素の src 属性を変更して、電球のオン/オフを実現します。

    具体的には、ユーザーが画像をクリックすると、onclickイベントがトリガーされ、現在の画像要素が引数として無名関数に渡されます。無名関数内のコードは、正規表現を使用して現在の画像のパスに次の文字列が含まれているかどうかを判断しますbulboff、含まれている場合は、パスを次のように変更します/images/pic_bulbon.gif、それ以外の場合は、パスを次のように変更します/images/pic_bulboff.gif。これにより電球のオンとオフが実現され、ユーザーは画像をクリックして電球の状態を切り替えることができます。

    注意すべき点として、~function(e){...}(this) の中のチルダ ~ は必須ではありません。その役割は、無名関数を式に変換し、次のキーワードをfunction文として扱うことで構文エラーになるのを防ぐことです。したがって、このチルダは省略でき、コードは (function(e){...})(this) の形式で書いても効果は同じです。
