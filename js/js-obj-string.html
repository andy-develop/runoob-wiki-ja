JavaScript 文字列（String）オブジェクト

String オブジェクトは、既存の文字ブロックを処理するために使用されます。

JavaScript の文字列

文字列は "John Doe" のような一連の文字を格納するために使用されます。

文字列は一重引用符または二重引用符を使用できます：

例

var carname="Volvo XC60";
var carname='Volvo XC60';

位置（インデックス）を使用して、文字列内の任意の文字にアクセスできます：

例

var character=carname[7];

文字列のインデックスは0から始まるため、文字列の最初の文字は

次の例のように、文字列内で引用符を使用できます：

例

var answer="It's alright";
var answer="He is called 'Johnny'";
var answer='He is called "Johnny"';

または、エスケープ文字(\)を使用して文字列内で引用符を使用できます：

例

var answer='It\'s alright';
var answer="He is called \"Johnny\"";

例

文字列内で文字列を検索する

文字列は indexOf() を使用して、文字列内の指定した文字が最初に出現する位置を特定します：

例

var str="Hello world, welcome to the universe.";
var n=str.indexOf("welcome");

内容のマッチング

match()この関数は、文字列内の特定の文字を検索し、見つかった場合はその文字を返します。

例

var str="Hello world!";
document.write(str.match("world") + "<br>");
document.write(str.match("World") + "<br>");
document.write(str.match("world!"));

replace()メソッドは、文字列内の一部の文字を別の文字に置き換えます。

例

文字列の大文字小文字変換

文字列の大文字小文字変換には関数を使用しますtoUpperCase() / toLowerCase():

例

var txt="Hello World!";       // String
var txt1=txt.toUpperCase(); // txt1 テキストは大文字に変換されます
var txt2=txt.toLowerCase(); // txt2 テキストは小文字に変換されます

文字列を配列に変換

文字列はsplit()関数で配列に変換します：

例

txt="a,b,c,d,e"   // String
txt.split(","); // カンマで区切る
txt.split(" "); // スペースで区切る
txt.split("|"); // 縦棒で区切る

特殊文字

Javascript では、バックスラッシュ（\）を使用して特殊記号を挿入できます。例：アポストロフィ、引用符などのその他の特殊記号。

次の JavaScript コードを参照してください：

var txt="We are the so-called "Vikings" from the north.";
document.write(txt);

JavaScript では、文字列の開始と終了に一重引用符または二重引用符を使用します。つまり、上記の文字列は次のように切り出されます： We are the so-called

上記の問題を解決するには、バックスラッシュを使用して引用符をエスケープできます：

var txt="We are the so-called \"Vikings\" from the north.";
document.write(txt);

JavaScript は正しいテキスト文字列を出力します：We are the so-called "Vikings" from the north.

次の表に、バックスラッシュでエスケープできるその他の特殊文字を示します：

コード 出力
\' 一重引用符
\" 二重引用符
\\ スラッシュ
\n 改行
\r 復帰
\t tab
\b スペース
\f 改ページ

    indexOf() と lastIndexOf() の違いと使い方を整理しました：

    var str = 'xxa xxa xxax';

//不带参数
var firstA1 = str.indexOf('a');
    firstA1 = firstA1 + 1;             //默认计算的位数实际是到a的前一位，所以+1才是a的所处位置

var endA1 = str.lastIndexOf('a')         
    endA1 = endA1 + 1;                 //同上

//带参数   
var firstA2 = str.indexOf('a',5);
    firstA2 = firstA2 + 1;             //默认计算的位数实际是到a的前一位，所以+1才是a的所处位置
  
var endA2 = str.lastIndexOf('a',7)         
    endA2 = endA2 + 1;                 //同上
      
    
console.log('字符串总长度是>>>>>>>>>>' + str.length);

console.log('第一个a字符，在总长度中的位置是>>>>>>>>>>' + firstA1);              //输出3
console.log('最后一个a字符，在总长度中的位置是>>>>>>>>>>' + endA1);              //输出11


console.log('字符串的前5位之后，第一个a在总长度中的位置是>>>>>>>>>>' + firstA2);  //输出7    
console.log('字符串的前7位之内，最后一个a在总长度中的位置是>>>>>>>>>>' + endA2);  //输出7

    注意：

    • 1. indexOf('a', 5) は、文字列の先頭5文字より後の最初のaを検索します
    • 2. lastIndexOf('a', 7) は、文字列の先頭7文字以内の最後のaを検索します
    • 3. lastIndexOf('a', 7) を文字列の末尾から7番目のaを検索するものと混同しないでください
    • 4. スペースも1文字として数えます
    • 5. パラメータを付けるのは位置を特定するためです。どの部分の文字列の中でaを探すかを指定し、そのaを見つけたら、先頭から数えて、全体の文字列の中での位置を計算して返します。
