JavaScript データ型

値型（基本型）：文字列（String）、数値（Number）、ブーリアン（Boolean）、空（Null）、未定義（Undefined）、Symbol。

参照データ型（オブジェクト型）：オブジェクト(Object)、配列(Array)、関数(Function)、さらに特別なオブジェクトとして正規表現（RegExp）と日付（Date）があります。

注：Symbol は ES6 で導入された新しいプリミティブデータ型であり、唯一無二の値を表します。

JavaScript は動的型付けです

JavaScript は動的型付けです。これは、同じ変数を異なる型として使用できることを意味します：

例

var x; // x は undefined
var x = 5; // 現在 x は数値
var x = "John"; // 現在 x は文字列

変数のデータ型はtypeoftypeof 演算子を使用して確認できます：

例

typeof "John"                // string を返す
typeof 3.14                  // number を返す
typeof false                 // boolean を返す
typeof [1,2,3,4]             // object を返す
typeof {name:'John', age:34} // object を返す

typeof [1,2,3,4] は "object" を返しますこれは JavaScript の初期設計における「欠陥」であり、配列は本質的に特殊な型のオブジェクトです。

配列を正しく検出する方法：

Array.isArray([1,2,3]); // true
[1,2,3] instanceof Array; // true

JavaScript 文字列

文字列は文字（例："Bill Gates"）を格納する変数です。

文字列は引用符で囲まれた任意のテキストです。一重引用符または二重引用符を使用できます：

例

var carname="Volvo XC60";
var carname='Volvo XC60';

文字列を囲む引用符と一致しない限り、文字列内で引用符を使用できます：

例

var answer="It's alright";
var answer="He is called 'Johnny'";
var answer='He is called "Johnny"';

JavaScript 数値

JavaScript の数値型は1つだけです。数値は小数点を含むことも、含まないこともできます：

例

var x1=34.00; //小数点を使用して記述
var x2=34; //小数点を使用せずに記述

非常に大きいまたは非常に小さい数値は、科学（指数）表記で記述できます：

例

var y=123e5;      // 12300000
var z=123e-5;     // 0.00123

JavaScript ブーリアン

ブーリアン（論理）は true または false の2つの値のみを持ちます。

var x=true;
var y=false;

ブーリアンは条件テストでよく使用されます。条件テストの詳細については、このチュートリアルの後の章で学びます。

JavaScript 配列

次のコードは cars という名前の配列を作成します：

var cars=new Array();
cars[0]="Saab";
cars[1]="Volvo";
cars[2]="BMW";

または (condensed array):

var cars=new Array("Saab","Volvo","BMW");

または (literal array):

例

var cars=["Saab","Volvo","BMW"];

JavaScript オブジェクト

オブジェクトは波括弧で区切られます。括弧内では、オブジェクトのプロパティは名前と値のペア (name : value) として定義されます。プロパティはカンマで区切られます：

var person={firstname:"John", lastname:"Doe", id:5566};

上記の例のオブジェクト (person) には、firstname、lastname、id の3つのプロパティがあります。

スペースと改行は重要ではありません。宣言は複数行にまたがることができます：

var person={
firstname : "John",
lastname  : "Doe",
id        :  5566
};

オブジェクトのプロパティには2つのアクセス方法があります：

例

name=person.lastname;
name=person["lastname"];

Undefined と Null

Undefined は変数が値を持たないことを表します。

変数の値を null に設定することで、変数を空にできます。

例

cars=null;
person=null;

変数型の宣言

新しい変数を宣言するときは、キーワード "new" を使用して型を宣言できます：

var carname=new String;
var x=      new Number;
var y=      new Boolean;
var cars=   new Array;
var person= new Object;

JavaScript の変数はすべてオブジェクトです。変数を宣言すると、新しいオブジェクトが作成されます。
