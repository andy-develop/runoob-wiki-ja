JavaScript 演算子

演算子 = は代入に使用します。

演算子 + は加算に使用します。

演算子 = は JavaScript 変数に値を代入するために使用します。

算術演算子+値を加算するために使用します。

例

変数に値を指定し、値を加算します：

y=5; z=2; x=y+z;

上記のステートメントを実行した後、xの値は：

文字列に使用する + 演算子

+ 演算子はテキスト値または文字列変数を加算（連結）するために使用します。

2 つ以上の文字列変数を連結するには、+演算子を使用してください。

例

2 つ以上の文字列変数を連結するには、+演算子を使用します：

txt1="What a very"; txt2="nice day"; txt3=txt1+txt2;

txt3演算結果は次のとおりです:

What a verynice day

2 つの文字列の間にスペースを追加するには、スペースを一方の文字列に挿入する必要があります：

例

txt1="What a very "; txt2="nice day"; txt3=txt1+txt2;

上記のステートメントを実行した後、変数txt3が含む値は：

What a very nice day

またはスペースを式に挿入します：:

例

txt1="What a very"; txt2="nice day"; txt3=txt1+" "+txt2;

上記のステートメントを実行した後、変数txt3が含む値は：

What a very nice day

文字列と数値に対する加算演算

2 つの数値を加算すると数値の合計が返されます。数値と文字列を加算すると文字列が返されます。次の例のとおりです：

例

x=5+5; y="5"+5; z="Hello"+5;

x,y, とz出力結果は:

    JavaScript == と === の違い

    1. string、number などの基本型の場合、== と === には違いがあります。

    • a) 異なる型間の比較では、== は「同じ型に変換した後の値」を比較して「値」が等しいかどうかを調べます。=== は型が異なる場合、その結果は等しくありません。
    • b) 同じ型の比較では、直接「値」を比較するため、両者の結果は同じです。

    2. Array、Object などの高度な型の場合、== と === に違いはありません。

    「ポインタアドレス」の比較を行います。

    3. 基本型と高度な型の場合、== と === には違いがあります。

    • a) == の場合、高度な型を基本型に変換して「値」の比較を行います。
    • b) 型が異なるため、=== の結果は false になります。
