JavaScript 関数定義

JavaScript はキーワードを使用してfunction関数を定義します。

関数は宣言によって定義することも、式にすることもできます。

関数宣言

以前のチュートリアルで、関数宣言の構文をすでに学びました：

function functionName(parameters) {
  执行的代码
}

関数宣言後はすぐには実行されず、必要なときに呼び出されます。

例

function myFunction(a, b) {
    return a * b;
}

セミコロンは、実行可能な JavaScript 文を区切るために使用されます。
関数宣言は実行可能な文ではないため、セミコロンで終わりません。

関数式

JavaScript 関数は式によって定義できます。

関数式は変数に格納できます：

例

var x = function (a, b) {return a * b};

試してみる »

関数式を変数に格納した後、その変数も関数として使用できます：

例

var x = function (a, b) {return a * b};
var z = x(4, 3);

試してみる »

上記の関数は実際には匿名関数（関数には名前がありません）。

関数は変数に格納されるため、関数名は不要で、通常は変数名で呼び出されます。

上記の関数は実行文であるため、セミコロンで終わります。

Function() コンストラクタ

上記の例では、関数はキーワードfunctionによって定義されることを学びました。

関数は、組み込みの JavaScript 関数コンストラクタ（Function()）を使用しても定義できます。

例

var myFunction = new Function("a", "b", "return a * b");

var x = myFunction(4, 3);

実際には、コンストラクタを使う必要はありません。上記の例は次のように書けます：

例

var myFunction = function (a, b) {return a * b};

var x = myFunction(4, 3);

関数の巻き上げ（Hoisting）

以前のチュートリアルで「hoisting（巻き上げ）」についてすでに学びました。

巻き上げ（Hoisting）は、JavaScript が既定で現在のスコープを先頭に持ち上げる動作です。

巻き上げ（Hoisting）は変数の宣言と関数の宣言に適用されます。

したがって、関数は宣言の前に呼び出すことができます：

myFunction(5);

function myFunction(y) {
    return y * y;
}

式を使って定義した関数は巻き上げることができません。

自己呼び出し関数

関数式は「自己呼び出し」ができます。

自己呼び出し式は自動的に呼び出されます。

式の直後に () が続く場合、自動的に呼び出されます。

宣言された関数は自己呼び出しできません。

括弧を追加することで、それが関数式であることを示します：

例

(function () {
var x = "Hello!!"; // 自分自身を呼び出します
})();

試してみる »

上記の関数は実際には匿名の自己呼び出し関数（関数名はありません）。

関数は値として使用できる

JavaScript 関数を値として使用する：

例

function myFunction(a, b) {
    return a * b;
}

var x = myFunction(4, 3);

試してみる »

JavaScript 関数は式として使用できます：

例

function myFunction(a, b) {
    return a * b;
}

var x = myFunction(4, 3) * 2;

試してみる »

関数はオブジェクト

JavaScript では、typeof演算子で関数の型を判定すると "function" が返ります。

しかし、JavaScript 関数はオブジェクトとして説明する方がより正確です。

JavaScript 関数にはプロパティとメソッド。

arguments.length プロパティは、関数呼び出し時に受け取った引数の数を返します：

例

function myFunction(a, b) {
    return arguments.length;
}

toString() メソッドは関数を文字列として返します:

例

function myFunction(a, b) {
    return a * b;
}

var txt = myFunction.toString();

アロー関数

ES6 でアロー関数が追加されました。

アロー関数式の構文は、通常の関数式よりも簡潔です。

(参数1, 参数2, …, 参数N) => { 函数声明 }

(参数1, 参数2, …, 参数N) => 表达式(单一)
// 相当于：(参数1, 参数2, …, 参数N) =>{ return 表达式; }

引数が1つだけの場合は、丸括弧は省略可能です：

(単一パラメータ) => {関数宣言}
単一パラメータ => {関数宣言}

引数がない関数は、空の丸括弧を書く必要があります:

() => {関数宣言}

例

// ES5 var x = function(x, y) { return x * y; } // ES6 const x = (x, y) => x * y;

試してみる »

一部のアロー関数には独自のthis。 定義するのに適していませんオブジェクトのメソッド。

アロー関数を使用すると、アロー関数はデフォルトで外側の this の値をバインドしてくれるため、アロー関数内の this の値は外側の this と同じになります。

アロー関数は巻き上げできないため、使用する前に定義する必要があります。

を使用する方がconstを使用するよりもvarより安全です。なぜなら、関数式は常に定数だからです。

関数の本体が単一の文だけの場合、return キーワードと中括弧 {} を省略できます。これは良い習慣です：

例

const x = (x, y) => { return x * y };
