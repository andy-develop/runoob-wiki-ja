JavaScript 宣言の巻き上げ

JavaScript では、関数と変数の宣言はすべて関数の最上部に巻き上げられます。

JavaScript では、変数は使用後に宣言することができます。つまり、変数は先に使用してから宣言することができます。

以下の2つの例は同じ結果になります。

例 1

x = 5; // 変数 x に 5 を設定
elem = document.getElementById("demo"); // 要素を検索
 elem.innerHTML = x;                     // 要素に x を表示

var x; // x を宣言

試してみる »

例 2

var x; // x を宣言
 x = 5; // 変数 x に 5 を設定

elem = document.getElementById("demo"); // 要素を検索
elem.innerHTML = x;                     // 要素に x を表示

試してみる »

上記の例を理解するには、「hoisting（宣言の巻き上げ）」を理解する必要があります。

宣言の巻き上げ：関数宣言と変数宣言は常にインタープリタによってメソッド本体の最上部に静かに「巻き上げ」られます。

JavaScript の初期化は巻き上げられない

JavaScript の初期化は巻き上げられません。JavaScript では宣言された変数の部分だけが巻き上げられ、初期化の部分は巻き上げられません。

以下の2つの例は結果が異なります。

例 1

var x = 5; // x を初期化
var y = 7; // y を初期化

elem = document.getElementById("demo"); // 要素を検索
 elem.innerHTML = x + " " + y;           // x と y を表示

試してみる »

例 2

var x = 5; // x を初期化
elem = document.getElementById("demo"); // 要素を検索
 elem.innerHTML = x + " " + y;           // x と y を表示
var y = 7; // y を初期化

試してみる »

例 2 の y は出力されましたundefined、これは変数宣言（var y）が巻き上げられたが、初期化（y = 7）は巻き上げられないため、y 変数は未定義の変数になっているからです。

例 2 は以下のコードに似ています:

var x = 5; // 初始化 x
var y;     // 声明 y

elem = document.getElementById("demo"); // 查找元素
elem.innerHTML = x + " " + y;           // 显示 x 和 y

y = 7;    // 设置 y 为 7

変数は先頭で宣言しましょう

ほとんどのプログラマーは JavaScript の宣言の巻き上げを知りません。

プログラマーが宣言の巻き上げを十分に理解していないと、書いたプログラムに問題が発生しやすくなります。

これらの問題を避けるために、通常は各スコープの開始前に変数を宣言します。これは通常の JavaScript の解析手順でもあり、理解しやすくなります。

JavaScript の厳格モード（strict mode）では、宣言されていない変数の使用は許可されていません。

    実際には、JS の解析メカニズムを理解すれば十分です。

    script タグに遭遇すると、JS は事前解析を行い、変数 var と function の宣言を巻き上げますが、function は実行しません。その後、コンテキスト実行に入ります。コンテキスト実行でも同じ事前解析操作を実行し、var と function がなくなるまで繰り返してから、コンテキストを実行します。例:

    a=5;
show();
var a;
function show(){};

    事前解析:

    function show(){};
var a;
a=5;
show();

    注意すべき点は、関数宣言の巻き上げでは、関数全体が実行環境の最上部に直接持ち上げられることです。

    上記の関数宣言の方法以外に、匿名関数を使用する方法もあります。

    宣言:

    var 变量名称=function(形参列表){
  //函数体
}

    呼び出し:

    変数名(実引数リスト)

    注意: 匿名関数を使用する方法では関数の巻き上げは発生しません。関数名が変数で表されているため、変数の巻き上げのみが存在します。例:

    var getName=function(){
  console.log(2);
}

function getName(){
  console.log(1);
}

getName();
//结果为2

    最後に出力される結果が 1 だと思う人もいるかもしれません。しかし getName は変数であるため、この変数の宣言も最上部に巻き上げられますが、変数の代入は元の位置に残ります。注意すべき点は、関数が優先されることです。関数宣言と変数宣言はどちらも巻き上げられますが、最初に巻き上げられるのは関数であり、その後に変数です。

    //函数、变量声明提升后
function getName(){    //函数声明提升到顶部
  console.log(1);
}

var getName;    //变量声明提升
getName = function(){    //变量赋值依然保留在原来的位置
  console.log(2);
}

getName();    // 最终输出：2

    変数の宣言と関数の宣言の巻き上げは、巻き上げのタイミングがプリパース（事前解析）プロセス中に発生します。

    プリパースプロセスとは、AO（Activation Object）を作成するプロセスでもあります。

    AO作成プロセス：

    • AOオブジェクトを作成する。
    • 仮引数と関数内の変数宣言をオブジェクトのプロパティ名とし、プロパティ値を一律にundefinedにする。undefined。
    • 実引数を仮引数に代入する。
    • 関数内の関数宣言をオブジェクトのプロパティ名とし、プロパティ値を関数本体とする。

    変数の巻き上げとは何ですか？

    原則として変数は先に宣言してから使用すべきですが、プログラマー初心者はしばしば宣言を忘れて変数を使用してしまいます。そうしてもJSコードは実行時にエラーを報告せず、undefinedを返すだけです。この状況が変数の巻き上げです。

    コンピューターが実行するとき、宣言せずに使用した変数を暗黙的にコードの最上部に置きます。注意すべき点は、変数は巻き上げられますが、変数に代入した値は一緒に巻き上げられないため、結果としてundefinedが得られるということです。

    関数の巻き上げとは何ですか？

    変数の巻き上げと意味はほぼ同じです。関数を先に使用し、後から関数を宣言するという、論理に反するようなことがJavaScriptでは許可されています。この言語はそれほど柔軟なのです。

    変数の巻き上げと異なるのは、関数の戻り値も一緒に巻き上げられることです。そのため、<script>タグ内のどこでも関数を呼び出して戻り値を使用できることがわかります。
