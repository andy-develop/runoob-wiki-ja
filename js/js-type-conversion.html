JavaScript 型変換

Number() は数値に変換、String() は文字列に変換、Boolean() はブール値に変換します。

JavaScript データ型

JavaScript には6つの異なるデータ型があります：

  • string
  • number
  • boolean
  • object
  • function
  • symbol

3つのオブジェクト型：

  • Object
  • Date
  • Array

値を含まない2つのデータ型：

  • null
  • undefined

typeof 演算子

あなたは使うことができますtypeof演算子でJavaScript変数のデータ型を確認できます。

例

typeof "John"                 // string を返す
 typeof 3.14                   // number を返す
 typeof NaN                    // number を返す
typeof false                  // boolean を返す
typeof [1,2,3,4]              // object を返す
 typeof {name:'John', age:34}  // object を返す
typeof new Date()             // object を返す
typeof function () {}         // function を返す
 typeof myCar                  // undefined を返す (myCar が宣言されていない場合)
 typeof null                   // object を返す

試してみる »

注意してください：

  • NaN のデータ型は number です
  • 配列(Array)のデータ型は object です
  • 日付(Date)のデータ型は object です
  • null のデータ型は object です
  • 未定義変数のデータ型は undefined です

オブジェクトが JavaScript Array または JavaScript Date の場合、私たちは〜を介してはtypeofそれらの型を判断できません。なぜなら、どちらも object を返すからです。

JavaScript 変数は新しい変数や他のデータ型に変換できます：

数値を文字列に変換する

グローバルメソッドString()数値を文字列に変換できます。

このメソッドはあらゆる種類の数値、文字、変数、式に使用できます：

例

String(x)         // 変数 x を文字列に変換して返す
 String(123)       // 数値 123 を文字列に変換して返す
 String(100 + 23)  // 数値式を文字列に変換して返す

試してみる »

Number メソッドtoString()これも同様の効果があります。

例

x.toString()
(123).toString()
(100 + 23).toString()

文字列を数値に変換する

グローバルメソッドNumber()文字列を数値に変換できます。

数字を含む文字列（例: "3.14"）は数値（例: 3.14）に変換されます。

空の文字列は 0 に変換されます。

その他の文字列は NaN（非数）に変換されます。

Number("3.14")    // 3.14 を返す
 Number(" ")       // 0 を返す
 Number("")        // 0 を返す
 Number("99 88")   // NaN を返す

自動型変換

JavaScript が「間違った」データ型を操作しようとすると、自動的に「正しい」データ型に変換されます。

以下の出力結果は、あなたが期待するものではありません：

5 + null    // 5 を返す null は 0 に変換される
"5" + null  // "5null" を返す null は "null" に変換される
 "5" + 1     // "51" を返す 1 は "1" に変換される
 "5" - 1     // 4 を返す "5" は 5 に変換される

自動で文字列に変換

オブジェクトまたは変数を出力しようとすると、JavaScript は自動的に変数の toString() メソッドを呼び出します：

document.getElementById("demo").innerHTML = myVar;

myVar = {name:"Fjohn"} // toString は "[object Object]" に変換する
 myVar = [1,2,3,4] // toString は "1,2,3,4" に変換する
 myVar = new Date() // toString は "Fri Jul 18 2014 09:08:55 GMT+0200" に変換する

数値とブール値もよく相互変換されます：

myVar = 123 // toString は "123" に変換する
 myVar = true // toString は "true" に変換する
 myVar = false // toString は "false" に変換する

    undefined と null の違い：

    表面的には undefined と null はどちらも何もないという意味ですが、実際には undefined は未定義（つまり変数が初期化されていない）であり、null は変数が初期化されているが値が何も与えられず、空のオブジェクトだけが与えられた状態です。さらに言えば、undefined と null は値は等しく、型は等しくありません。

    配列かどうかを判断します。

    <p id="demo"></p>
<script>
var fruits = ["Banana", "Orange", "Apple", "Mango"];
document.getElementById("demo").innerHTML = isArray(fruits);
function isArray(myArray) {
    return myArray.constructor.toString().indexOf("Array") > -1;
}
</script>

    return myArray.constructor.toString().indexOf("Array") > -1; この文はどう解釈すればよいですか？

    1、myArray は関数 isArray のパラメータです。ここで関数を呼び出すと、配列 fruits が渡されます。

    2、constructor はプロパティ、つまりコンストラクタプロパティです。データの型が異なると、対応する異なる値が得られます。myArray は配列なので、ここでの myArray.constructor の値はfunction Array() { [native code] }。（myArray が文字列の場合、myArray.constructor の値はfunction String() { [native code] }。また、number、boolean、object などがあります。）

    3、toString() はメソッドで、文字列に変換するメソッドです。ここではfunction Array() { [native code] }を文字列に変換して、後で検索しやすくしています。

    4、indexOf("Array") はメソッドで、文字列を検索します。ここでは文字列function Array() { [native code] }の中に Array があるかどうかを確認します。あれば最初に出現する位置を返します。これは数値で、ここでは 9 です。最初の文字に出現する場合は 0 を返します。空白も数えます。見つからない場合は -1 を返します。-1 より大きければ Array があることを意味し、元の関数呼び出しで渡された fruits が配列であると判断できます。もしmyArray.constructor.toString().indexOf("Object")>-1ならば、myArray は Object オブジェクトです。しかしその場合、このパラメータの名前は適切ではなく、myObject と呼ぶべきでしょう。

Date.prototype.format = function (fmt) {
    var o = {
        "M+": this.getMonth() + 1,                 //月份 
        "d+": this.getDate(),                    //日 
        "h+": this.getHours(),                   //小时 
        "m+": this.getMinutes(),                 //分

    var reYear = /(y+)/; 
    var resultYear = reYear.exec(fmt);
    if (resultYear) 
    {
        var yearformatPart = resultYear[0];//匹配到的格式化字符
        var yearVal = (this.getFullYear() + "").substr(4 - yearformatPart.length);
        fmt = fmt.replace(yearformatPart, yearVal);
    }
    for (var k in o) {
        var re = new RegExp("(" + k + ")");
        var re = re.exec(fmt);
        if (re) {

            var replaceVal = (formatPart.length == 1) ? (Val) : (("00" + Val).substr(Val.length));

        }
    }
