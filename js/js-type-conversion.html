JavaScript 型変換

Number() は数値に変換、String() は文字列に変換、Boolean() はブール値に変換します。

JavaScript データ型

JavaScript には6つの異なるデータ型があります：

  • string
  • number
  • boolean
  • object
  • function
  • symbol

3つのオブジェクト型：

  • Object
  • Date
  • Array

値を含まない2つのデータ型：

  • null
  • undefined

typeof 演算子

あなたは使うことができますtypeof演算子でJavaScript変数のデータ型を確認できます。

例

typeof "John"                 // string を返す
 typeof 3.14                   // number を返す
 typeof NaN                    // number を返す
typeof false                  // boolean を返す
typeof [1,2,3,4]              // object を返す
 typeof {name:'John', age:34}  // object を返す
typeof new Date()             // object を返す
typeof function () {}         // function を返す
 typeof myCar                  // undefined を返す (myCar が宣言されていない場合)
 typeof null                   // object を返す

試してみる »

注意してください：

  • NaN のデータ型は number です
  • 配列(Array)のデータ型は object です
  • 日付(Date)のデータ型は object です
  • null のデータ型は object です
  • 未定義変数のデータ型は undefined です

オブジェクトが JavaScript Array または JavaScript Date の場合、私たちは〜を介してはtypeofそれらの型を判断できません。なぜなら、どちらも object を返すからです。

constructor プロパティを使用して、オブジェクトが配列かどうか（文字列 "Array" を含むかどうか）を確認できます。

例

JavaScript 型変換

JavaScript 変数は新しい変数や他のデータ型に変換できます：

  • JavaScript 関数を使用して
  • JavaScript 自体による自動変換

数値を文字列に変換する

グローバルメソッドString()数値を文字列に変換できます。

このメソッドはあらゆる種類の数値、文字、変数、式に使用できます：

例

String(x)         // 変数 x を文字列に変換して返す
 String(123)       // 数値 123 を文字列に変換して返す
 String(100 + 23)  // 数値式を文字列に変換して返す

試してみる »

Number メソッドtoString()これも同様の効果があります。

例

x.toString()
(123).toString()
(100 + 23).toString()

試してみる »

メソッド 説明
toExponential() オブジェクトの値を指数表記に変換します。
toFixed() 数値を文字列に変換し、結果の小数点以下に指定した桁数の数字を表示します。
toPrecision() 数値を指定した長さにフォーマットします。

ブール値を文字列に変換する

グローバルメソッドString()ブール値を文字列に変換できます。

String(false)        // "false" を返す
 String(true)         // "true" を返す

Boolean メソッドtoString()これも同じ効果があります。

false.toString()     // "false" を返す
 true.toString()      // "true" を返す

日付を文字列に変換する

Date() は文字列を返します。

Date()      // Thu Jul 17 2014 15:38:19 GMT+0200 (W. Europe Daylight Time) を返す

グローバルメソッド String() は日付オブジェクトを文字列に変換できます。

String(new Date())      // Thu Jul 17 2014 15:38:19 GMT+0200 (W. Europe Daylight Time) を返す

Date メソッドtoString()これも同じ効果があります。

例

obj = new Date()
obj.toString()   // Thu Jul 17 2014 15:38:19 GMT+0200 (W. Europe Daylight Time) を返す

文字列を数値に変換する

グローバルメソッドNumber()文字列を数値に変換できます。

数字を含む文字列（例: "3.14"）は数値（例: 3.14）に変換されます。

空の文字列は 0 に変換されます。

その他の文字列は NaN（非数）に変換されます。

Number("3.14")    // 3.14 を返す
 Number(" ")       // 0 を返す
 Number("")        // 0 を返す
 Number("99 88")   // NaN を返す

にNumber メソッドこの章では、文字列を数値に変換する方法をさらに確認できます。

メソッド 説明
parseFloat() 文字列を解析して浮動小数点数を返します。
parseInt() 文字列を解析して整数を返します。

単項演算子 +

Operator + 変数を数値に変換するために使用できます：

例

var y = "5";      // y は文字列
 var x = + y;      // x は数値

ブール値を数値に変換する

グローバルメソッドNumber()ブール値を数値に変換できます。

Number(false)     // 0 を返す
 Number(true)      // 1 を返す

日付を数値に変換する

グローバルメソッドNumber()日付を数値に変換できます。

d = new Date();
Number(d)          // 1404568027739 を返す

日付メソッドgetTime()も同じ効果があります。

d = new Date();
d.getTime()        // 1404568027739 を返す

自動型変換

JavaScript が「間違った」データ型を操作しようとすると、自動的に「正しい」データ型に変換されます。

以下の出力結果は、あなたが期待するものではありません：

5 + null    // 5 を返す null は 0 に変換される
"5" + null  // "5null" を返す null は "null" に変換される
 "5" + 1     // "51" を返す 1 は "1" に変換される
 "5" - 1     // 4 を返す "5" は 5 に変換される

自動で文字列に変換

オブジェクトまたは変数を出力しようとすると、JavaScript は自動的に変数の toString() メソッドを呼び出します：

document.getElementById("demo").innerHTML = myVar;

myVar = {name:"Fjohn"} // toString は "[object Object]" に変換する
 myVar = [1,2,3,4] // toString は "1,2,3,4" に変換する
 myVar = new Date() // toString は "Fri Jul 18 2014 09:08:55 GMT+0200" に変換する

数値とブール値もよく相互変換されます：

myVar = 123 // toString は "123" に変換する
 myVar = true // toString は "true" に変換する
 myVar = false // toString は "false" に変換する
