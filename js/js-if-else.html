条件文

通常、コードを書くときは、異なる決定に対して異なる動作を実行する必要があります。コード内で条件文を使用してこのタスクを実行できます。

JavaScript では、次の条件文を使用できます。

  • if 文- 指定された条件が true の場合にのみ、この文を使用してコードを実行します
  • if...else 文- 条件が true の場合はコードを実行し、条件が false の場合は別のコードを実行します
  • if...else if....else 文- この文を使用して、複数のコードブロックのいずれかを選択して実行します
  • switch 文- この文を使用して、複数のコードブロックのいずれかを選択して実行します

if 文

指定された条件が true の場合にのみ、この文はコードを実行します。

構文

if (condition)
{
条件が true の場合に実行されるコード
}

小文字を使用してください if。大文字（IF）を使用すると、JavaScript エラーが発生します！

例

時刻が 20:00 未満の場合、"Good day" という挨拶を生成します：

if (time<20) { x="Good day"; }

if...else 文

条件が true の場合はコードを実行し、条件が false の場合は他のコードを実行するには、if....else 文を使用してください。

構文

if (condition)
{
条件が true の場合に実行されるコード
}
else
{
条件が true でない場合に実行されるコード
}

例

時刻が 20:00 未満の場合は "Good day" という挨拶を生成し、それ以外の場合は "Good evening" という挨拶を生成します。

if (time<20) { x="Good day"; } else { x="Good evening"; }

if...else if...else 文

if....else if...else 文を使用して、複数のコードブロックのいずれかを選択して実行します。

構文

if (condition1)
{
条件 1 が true の場合に実行されるコード
}
else if (condition2)
{
条件 2 が true の場合に実行されるコード
}
else
{
条件 1 と条件 2 の両方が true でない場合に実行されるコード
}

例

時刻が 10:00 未満の場合は "Good morning" という挨拶を生成し、時刻が 10:00 を超え 20:00 未満の場合は "Good day" という挨拶を生成し、それ以外の場合は "Good evening" という挨拶を生成します：

if (time<10) { document.write("<b>おはようございます</b>"); } else if (time>=10 && time<20) { document.write("<b>こんにちは</b>"); } else { document.write("<b>こんばんは!</b>"); }
