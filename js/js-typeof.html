typeof 演算子

typeof 演算子を使用して、変数のデータ型を検出できます。

例

typeof "John"                // string を返す
 typeof 3.14                  // number を返す
 typeof false                 // boolean を返す
 typeof [1,2,3,4]             // object を返す
 typeof {name:'John', age:34} // object を返す

JavaScript では、配列は特別なオブジェクト型です。したがって typeof [1,2,3,4] は object を返します。

配列を正しく検出する方法：

Array.isArray([1,2,3]); // true
[1,2,3] instanceof Array; // true

typeofは JavaScript の演算子であり、指定された変数のデータ型を返すために使用されます。

完全な型検出表：

式戻り値説明
typeof undefined"undefined"未定義の値
typeof true"boolean"ブール値
typeof 42"number"すべての数値型
typeof "text""string"文字列
typeof {a:1}"object"オブジェクト、配列、null
typeof function(){}"function"関数
typeof Symbol()"symbol"ES6 で追加された Symbol 型
typeof BigInt(10)"bigint"ES2020 で追加された BigInt 型

未定義の変数を検出する：

if (typeof variable === "undefined") {...}

関数が存在するかどうかを検出する：

if (typeof myFunction === "function") {...}

配列と null の特別な場合に注意してください：

// 正确检测数组
if (Array.isArray(myVar)) {...}

// 正确检测null
if (myVar === null) {...}

null

JavaScript では null は「何もない」を表します。

null は、値が1つだけの特別な型です。空のオブジェクト参照を表します。

typeof で null を検出すると object を返します。

null に設定することで、オブジェクトを空にできます：

例

var person = null;           // 値は null (空) ですが、型はオブジェクトです

undefined に設定することで、オブジェクトを空にできます：

例

var person = undefined;     // 値は undefined、 型は undefined

undefined

JavaScript では、undefinedは値が設定されていない変数です。

typeof値のない変数は次の値を返します。 undefined。

例

var person;                  // 値は undefined (空)、型は undefined

試してみる »

任意の変数は値をundefinedにすることでクリアできます。 型はundefined.

例

person = undefined;          // 値は undefined、 型は undefined

undefined と null の違い

例

null と undefined の値は等しいですが、型は等しくありません：

typeof undefined             // undefined
typeof null                  // object
null === undefined           // false
null == undefined            // true
