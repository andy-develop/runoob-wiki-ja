typeof 演算子

typeof 演算子を使用して、変数のデータ型を検出できます。

例

typeof "John"                // string を返す
 typeof 3.14                  // number を返す
 typeof false                 // boolean を返す
 typeof [1,2,3,4]             // object を返す
 typeof {name:'John', age:34} // object を返す

試してみる »

JavaScript では、配列は特別なオブジェクト型です。したがって typeof [1,2,3,4] は object を返します。

配列を正しく検出する方法：

Array.isArray([1,2,3]); // true
[1,2,3] instanceof Array; // true

typeofは JavaScript の演算子であり、指定された変数のデータ型を返すために使用されます。

完全な型検出表：

式戻り値説明
typeof undefined"undefined"未定義の値
typeof true"boolean"ブール値
typeof 42"number"すべての数値型
typeof "text""string"文字列
typeof {a:1}"object"オブジェクト、配列、null
typeof function(){}"function"関数
typeof Symbol()"symbol"ES6 で追加された Symbol 型
typeof BigInt(10)"bigint"ES2020 で追加された BigInt 型

未定義の変数を検出する：

if (typeof variable === "undefined") {...}

関数が存在するかどうかを検出する：

if (typeof myFunction === "function") {...}

配列と null の特別な場合に注意してください：

// 正确检测数组
if (Array.isArray(myVar)) {...}

// 正确检测null
if (myVar === null) {...}

null

JavaScript では null は「何もない」を表します。

null は、値が1つだけの特別な型です。空のオブジェクト参照を表します。

typeof で null を検出すると object を返します。

null に設定することで、オブジェクトを空にできます：

例

var person = null;           // 値は null (空) ですが、型はオブジェクトです

試してみる »

undefined に設定することで、オブジェクトを空にできます：

例

var person = undefined;     // 値は undefined、 型は undefined

試してみる »

undefined

JavaScript では、undefinedは値が設定されていない変数です。

typeof値のない変数は次の値を返します。 undefined。

例

var person;                  // 値は undefined (空)、型は undefined

試してみる »

任意の変数は値をundefinedにすることでクリアできます。 型はundefined.

例

person = undefined;          // 値は undefined、 型は undefined

試してみる »

undefined と null の違い

例

null と undefined の値は等しいですが、型は等しくありません：

typeof undefined             // undefined
typeof null                  // object
null === undefined           // false
null == undefined            // true

    1、定義

    • （1）undefined：値が代入されていないすべての変数のデフォルト値であり、自動的に代入されます。
    • （2）null：変数が参照するオブジェクトを積極的に解放し、変数がどのオブジェクトのアドレスも指していないことを表します。

    2、いつ null を使用しますか？

    比較的大きなオブジェクトを使い終わった後、そのメモリを解放する必要がある場合、null に設定します。

    3、null と undefined の異同点は何でしょうか？

    共通点：どちらもプリミティブ型であり、スタック内のローカル変数に保存されます。

    相違点：

    （1）undefined——変数が宣言されているが代入されたことがないことを表します。

    これはすべての未代入変数のデフォルト値です。例：

    var a;    // a 自动被赋值为 undefined

    （2）null——変数が将来オブジェクトを指す可能性があることを表します。

    一般的に、オブジェクトへの参照を積極的に解放するために使用されます。例：

    var emps = ['ss','nn'];
emps = null;     // 释放指向数组的引用

    4、発展——ガベージコレクタ

    これはオブジェクトのメモリを解放するための専用プログラムです。

    • （1）低レベルでは、バックグラウンドで現在のプログラムと同時に実行されます。エンジンは定期的に自動でガベージコレクタを呼び出します。
    • （2）オブジェクトがどの変数からも参照されなくなったときにのみ解放されます。

    JavaScript には以下の7つのデータ型があります：

    • string：テキスト内容を表します。例： "Hello"。

    • number：数値を表します。例：123。

    • boolean：真または偽の値を表します。例：true または false。

    • undefined：未定義または値が代入されていない変数やプロパティを表します。例：var x;。

    • object：複雑なデータ構造を表します。例：{ x: 1, y: 2 }。

    • function：実行可能なコードブロックを表します。例：function() { ... }。

    • symbol：一意の識別子を表します。例：Symbol("foo")。

    typeof演算子はオペランドのデータ型に応じて対応する文字列を返します。例：

    typeof "Hello" // 返回"string"

typeof 123 // 返回"number"

typeof true // 返回"boolean"

typeof x // 返回"undefined"

typeof { x: 1, y: 2 } // 返回"object"

typeof function() { ... } // 返回"function"

typeof Symbol("foo") // 返回"symbol"

    いくつか特別な場合に注意が必要です：

    • typeof null は "object" を返します。これは歴史的な問題であり、実際には null は空または存在しない値であり、オブジェクトではありません。

    • typeof NaN は "number" を返します。これは NaN が特別な数値型であり、Not a Number（数字ではない）を表すためです。

    • typeof [] は "object" を返します。これは配列が特別なオブジェクト型であり、length プロパティと要素を操作するいくつかのメソッドを持っているためです。
