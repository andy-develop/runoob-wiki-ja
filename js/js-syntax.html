JavaScript 構文

JavaScript はプログラミング言語です。構文規則は言語構造を定義します。

JavaScript 構文

JavaScript はスクリプト言語です。

軽量でありながら、強力なプログラミング言語です。

JavaScript リテラル

プログラミング言語では、通常、固定値をリテラルと呼びます（例: 3.14）。

数値（Number）リテラル整数または小数、あるいは科学的記数法（e）で表すことができます。

3.14

1001

123e5

文字列（String）リテラル一重引用符または二重引用符を使用できます:

"John Doe"

'John Doe'

試してみる »

式リテラル計算に使用されます:

5 + 6

5 * 10

試してみる »

配列（Array）リテラル配列を定義します:

[40, 100, 1, 5, 25, 10]

オブジェクト（Object）リテラルオブジェクトを定義します:

{firstName:"John", lastName:"Doe", age:50, eyeColor:"blue"}

関数（Function）リテラル関数を定義します:

function myFunction(a, b) { return a * b;}

JavaScript 変数

プログラミング言語では、変数はデータ値を格納するために使用されます。

JavaScript ではキーワードを使用しvar変数を定義し、等号を使用して変数に値を代入します:

var x, length

x = 5

length = 6

試してみる »

変数は変数名でアクセスできます。命令型言語では、変数は通常変更可能です。リテラルは一定の値です。

変数は名前です。リテラルは值。

JavaScript 演算子

JavaScript は算術演算子を使用して値を計算します:

(5 + 6) * 10

試してみる »

JavaScript は代入演算子を使用して変数に値を代入します:

x = 5
y = 6
z = (x + y) * 10

試してみる »

JavaScript 言語には複数の種類の演算子があります:

型 例 説明
代入、算術、ビット演算子 =  +  -  *  / JS 演算子で説明
条件、比較、論理演算子 ==  != <  >  JS 比較演算子で説明

JavaScript 文

HTML では、JavaScript 文はブラウザにコマンドを送信するために使用されます。

文はセミコロンで区切ります：

x = 5 + 6;
y = x * 10;

JavaScript キーワード

JavaScript キーワードは、実行する操作を識別するために使用されます。

他のプログラミング言語と同様に、JavaScript もいくつかのキーワードを自らのために予約しています。

varキーワードはブラウザに新しい変数を作成するように指示します：

var x = 5 + 6;
var y = x * 10;

JavaScript は、現在の言語バージョンでは使用されていないが、将来の JavaScript 拡張で使用されるいくつかのキーワードも予約しています。

JavaScript コメント

すべての JavaScript 文が「コマンド」であるわけではありません。ダブルスラッシュ//の後の内容はブラウザによって無視されます：

// 私は実行されません

JavaScript データ型

JavaScript には、数値、文字列、配列、オブジェクトなど、複数のデータ型があります:

var length = 16; // Number 数値リテラルで代入
var points = x * 10; // Number 式リテラルで代入
var lastName = "Johnson"; // String 文字列リテラルで代入
var cars = ["Saab", "Volvo", "BMW"]; // Array 配列リテラルで代入
var person = {firstName:"John", lastName:"Doe"}; // Object オブジェクトリテラルで代入

データ型の概念

プログラミング言語において、データ型は非常に重要な内容です。

変数を操作するには、データ型の概念を理解することが非常に重要です。

データ型を使用しない場合、以下の例は実行できません：

16 + "Volvo"

16 に "Volvo" を加えるとどう計算されるのでしょうか? 上記はエラーになるのでしょうか、それとも以下の結果を出力するのでしょうか？

"16Volvo"

ブラウザで上記のコードを実行して、結果を確認できます。

次の章では、データ型についてさらに詳しく学びます。

JavaScript 関数

JavaScript の文は関数内に記述でき、関数は繰り返し参照できます：

関数を参照する= 関数を呼び出す（関数内の文を実行する）。

function myFunction(a, b) {
return a * b; // a に b を掛けた結果を返す
}

JavaScript 大文字と小文字

JavaScript は大文字と小文字を区別します。

JavaScript の文を書くときは、Caps Lock がオフになっているかどうかに注意してください。

関数getElementByIdとgetElementbyIDは異なります。

同様に、変数myVariableとMyVariableも異なります。

JavaScript 文字セット

JavaScript は Unicode 文字セットを使用します。

Unicode は、句読点などのすべての文字をカバーしています。

詳細については、私たちの完全な Unicode リファレンスマニュアル。

    キャメルケース命名規則：

    変数名や関数名が1つ以上の単語を連結して構成される一意の識別子である場合、最初の単語は小文字で始まり、2番目の単語の先頭文字は大文字にするか、またはすべての単語の先頭文字を大文字にします。例：myFirstName、myLastName。このような変数名はラクダのこぶのように見えることから、この名前が付けられました。

    キャメルケース命名規則は慣習と見なされ、絶対的なものでも強制されるものでもなく、識別性と可読性を高めるためのものです。
