JavaScript スコープ

スコープとは、アクセス可能な変数の集合です。

JavaScript スコープ

JavaScript では、オブジェクトと関数も同様に変数です。

JavaScript では、スコープはアクセス可能な変数、オブジェクト、関数の集合です。

JavaScript 関数スコープ: スコープは関数内で変更されます。

JavaScript ローカルスコープ

関数内で宣言された変数はローカル変数であり、ローカルスコープを持ちます。

ローカル変数: 関数内部でのみアクセスできます。

サンプル

//ここでは carName 変数にアクセスできません function myFunction() { var carName = "Volvo"; //関数内では carName 変数にアクセスできます }

ローカル変数は関数内でのみ有効なため、異なる関数は同じ名前の変数を使用できます。

ローカル変数は関数の実行開始時に作成され、関数の実行完了後に自動的に破棄されます。

JavaScript グローバル変数

関数の外で定義された変数はグローバル変数になります。

グローバル変数にはグローバルスコープ: ページ内のすべてのスクリプトと関数が使用できます。

サンプル

var carName = " Volvo"; //ここでは carName 変数にアクセスできます function myFunction() { //関数内では carName 変数にアクセスできます }

関数内で変数が宣言されていない場合（var キーワードを使用していない場合）、その変数はグローバル変数です。

次のサンプルでは carName は関数内にありますが、グローバル変数です。

サンプル

//ここでは carName 変数にアクセスできます function myFunction() { carName = "Volvo"; //ここでは carName 変数にアクセスできます }

JavaScript 変数のライフサイクル

JavaScript の変数のライフサイクルは、宣言されたときに初期化されます。

ローカル変数は関数の実行が完了すると破棄されます。

グローバル変数はページが閉じられると破棄されます。

関数パラメータ

関数パラメータは関数内でのみ有効で、ローカル変数です。

HTML 内のグローバル変数

HTML では、グローバル変数は window オブジェクトです。そのため、window オブジェクトは関数内で宣言されていない（var を付けていない）ローカル変数にアクセスできます。

注意：すべてのグローバル変数は window オブジェクトに属します。

サンプル

//ここでは window.carName を使用できます function myFunction() { carName = "Volvo"; }

ご存知ですか？

あなたのグローバル変数または関数は、window オブジェクトの変数や関数を上書きできます。
ローカル変数は、window オブジェクトを含めて、グローバル変数や関数を上書きできます。

JavaScript では、関数内部のローカル変数は通常、外部スコープから直接アクセスできませんが、関数内のローカル変数を外部スコープに公開する方法はいくつかあります。具体的には次のとおりです。

  • グローバルオブジェクトを介する：関数内部では、ローカル変数を window オブジェクトのプロパティに代入することで、グローバルにアクセス可能にできます。例えば、window.a = a;ステートメントを使用すると、関数外部ではwindow.aこのローカル変数の値にアクセスできます。
  • グローバル変数を定義する：関数内部でvar、let 或 constなどのキーワードを使用せずに変数を宣言すると、その変数はグローバル変数と見なされ、関数外部からアクセスできます。ただし、この方法は予期しない副作用を引き起こし、コードの保守が難しくなる可能性があるため、通常は推奨されません。
  • 戻り値：関数内部でreturnステートメントを使用してローカル変数の値を返し、関数外部でその戻り値を受け取ることができます。これにより、ローカル変数自体は公開されませんが、その値は関数呼び出しを介して外部に渡すことができます。
  • クロージャ：JavaScript のクロージャ機能により、内部関数は外部関数のローカル変数にアクセスできます。外部関数の実行が完了した後でも、そのローカル変数は内部関数から参照できます。
  • プロパティとメソッド：グローバルスコープで定義された変数と関数はすべて window オブジェクトのプロパティとメソッドになるため、呼び出し時に window を省略して、変数名や関数名を直接使用できます。
