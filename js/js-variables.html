JavaScript 変数

変数は情報を格納するための「コンテナ」です。

JavaScriptでは、変数はデータを格納するために使用され、プログラムの実行中に動的に変更できます。

JavaScriptでは、変数は数値、文字列、オブジェクト、関数など、さまざまな種類のデータを格納できます。

変数名は識別子であり、変数に格納されたデータを参照するために使用されます。

JavaScriptでは、以下を使用できますvar、letとconstキーワードを使用して変数を宣言します。

  • var：ES5で導入された変数宣言方法で、関数スコープを持ちます。

  • let：ES6で導入された変数宣言方法で、ブロックスコープを持ちます。

  • const：ES6で導入された定数宣言方法で、ブロックスコープを持ち、値は変更できません。

例

var x=5; var y=6; var z=x+y;

代数のように

x=5
y=6
z=x+y

代数では、文字（例：x）を使用して値（例：5）を保持します。

上記の式 z=x+y により、z の値が 11 であると計算できます。

JavaScriptでは、これらの文字は変数と呼ばれます。

変数はデータを格納するコンテナと考えることができます。

JavaScript 変数

代数と同様に、JavaScript 変数は値（例：x = 5）や式（例：z = x + y）。

変数は短い名前（例：x や y）を使用できますが、より説明的な名前（例：age, sum, totalvolume）も使用できます。

  • 変数はアルファベットで始まる必要があります
  • 変数は $ と _ 記号で始めることもできます（ただし、お勧めしません）
  • 変数名は大文字と小文字を区別します（y と Y は異なる変数です）
JavaScript のステートメントと JavaScript 変数は、どちらも大文字と小文字を区別します。

JavaScript データ型

JavaScript 変数は、テキスト値 (name="Bill Gates") などの他のデータ型も保持できます。

JavaScriptでは、"Bill Gates" のようなテキストは文字列と呼ばれます。

JavaScript 変数には多くの種類がありますが、今回は数値と文字列にだけ注目します。

変数にテキスト値を代入する場合は、その値を二重引用符または一重引用符で囲む必要があります。

変数に数値を代入する場合は、引用符を使用しないでください。引用符で数値を囲むと、その値はテキストとして扱われます。

例

var pi=3.14; //ES6 に精通している場合、pi は const キーワードを使用して定数を表すことができます // const pi = 3.14; var person="John Doe"; var answer='Yes I am!';

宣言（作成） JavaScript 変数

JavaScript で変数を作成することは、通常「変数の宣言」と呼ばれます。

var キーワードを使用して変数を宣言します：

var carname;

変数を宣言した後、その変数は空です（値を持ちません）。

変数に値を代入するには、等号を使用します：

carname="Volvo";

ただし、変数を宣言するときに値を代入することもできます：

var carname="Volvo";

次の例では、carname という名前の変数を作成し、"Volvo" を代入して、id="demo" の HTML 段落に配置します：

例

var carname="Volvo"; document.getElementById("demo").innerHTML=carname;

var 宣言の特徴：

  • 変数は繰り返し宣言できます（元の変数を上書きします）。
  • 変数に値が代入されていない場合、デフォルト値は undefined です。
  • var で宣言された変数は巻き上げ（Hoisting）されますが、初期化はされません。

良いプログラミング習慣として、コードの先頭で必要な変数をまとめて宣言します。

1つの文で複数の変数

1つの文で多くの変数を宣言できます。その文は var で始まり、カンマで変数を区切ります：

var lastname="Doe", age=30, job="carpenter";

宣言は複数行にまたがることもできます：

var lastname="Doe",
age=30,
job="carpenter";

1つの文で宣言された複数の変数に同じ値を同時に代入することはできません:

var x, y, z = 1;

x, y は undefined で、z は 1 です。


Value = undefined

コンピュータープログラムでは、値を持たない変数を宣言することがよくあります。値を指定せずに宣言された変数の値は、実際にはundefined。

次のステートメントを実行した後、変数 carname の値は undefined になります：

var carname;

JavaScript 変数の再宣言

JavaScript 変数を再宣言しても、その変数の値は失われません：

次の2つのステートメントを実行した後、変数 carname の値は依然として "Volvo" です：

var
carname="Volvo"; 
var carname;

let と const (ES6) を使用する

2015年以前は、var キーワードを使用して JavaScript 変数を宣言していました。

2015年以降の JavaScript バージョン (ES6) では、const キーワードを使用して定数を定義し、let キーワードを使用して限定されたスコープの変数を定義できます。

let

let は ES6 で導入された新しい変数宣言方法であり、推奨されています。

let 構文：

let variableName = value;

例

let city = "北京";
let age = 30;
console.log(city, age); // 出力: 北京 30

const

const は定数を定義するために使用され、一度代入すると変数の値は変更できません。

const 構文：

const variableName = value;

例

const z = 10;
// z = 20; // エラー、定数は再代入できません
if (true) {
    const z = 20; // 異なる定数
    console.log(z); // 出力 20
}
console.log(z); // 出力 10
