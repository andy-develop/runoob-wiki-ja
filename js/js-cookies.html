JavaScript Cookie

CookieはWebページのユーザー情報を保存するために使用されます。

Cookieとは？

Cookieは、あなたのコンピュータ上のテキストファイルに保存されるデータです。

WebサーバーがブラウザにWebページを送信するとき、接続が閉じられた後、サーバー側はユーザーの情報を記録しません。

Cookieの役割は、「クライアントのユーザー情報を記録する方法」を解決することです：

  • ユーザーがWebページにアクセスすると、その名前をCookieに記録できます。
  • ユーザーが次回そのページにアクセスしたとき、Cookieからユーザーのアクセス記録を読み取ることができます。

Cookieは名前/値のペア形式で保存されます。次のようになります：

username=John Doe

ブラウザがサーバーからWebページをリクエストするとき、そのページに属するCookieがリクエストに追加されます。サーバー側はこの方法でユーザーの情報を取得します。

JavaScriptを使用してCookieを作成する

JavaScriptは使用できますdocument.cookie属性を使用してCookieの作成、読み取り、削除ができます。

JavaScriptでCookieを作成するには、次のようにします：

document.cookie="username=John Doe";

Cookieに有効期限（UTCまたはGMT時間）を追加することもできます。デフォルトでは、Cookieはブラウザを閉じると削除されます：

document.cookie="username=John Doe; expires=Thu, 18 Dec 2043 12:00:00 GMT";

pathパラメータを使用して、Cookieのパスをブラウザに通知できます。デフォルトでは、Cookieは現在のページに属します。

document.cookie="username=John Doe; expires=Thu, 18 Dec 2043 12:00:00 GMT; path=/";

JavaScriptを使用してCookieを読み取る

JavaScriptでは、次のコードを使用してCookieを読み取ることができます：

var x = document.cookie;

document.cookieはすべてのCookieを文字列として返します。形式：cookie1=value; cookie2=value; cookie3=value;

JavaScriptを使用してCookieを変更する

JavaScriptでは、Cookieの変更はCookieの作成に似ています。次のようになります：

document.cookie="username=John Smith; expires=Thu, 18 Dec 2043 12:00:00 GMT; path=/";

古いCookieは上書きされます。

JavaScriptを使用してCookieを削除する

Cookieの削除は非常に簡単です。expiresパラメータを過去の時間に設定するだけです。次のように、Thu, 01 Jan 1970 00:00:00 GMTに設定します：

document.cookie = "username=; expires=Thu, 01 Jan 1970 00:00:00 GMT";

削除するときにCookieの値を指定する必要はありません。

Cookie文字列

document.cookieプロパティは普通のテキスト文字列のように見えますが、実際にはそうではありません。

document.cookieに完全なCookie文字列を書き込んだ場合でも、Cookie情報を再読み取りすると、Cookie情報は名前/値のペアの形式で表示されます。

新しいCookieを設定しても、古いCookieは上書きされません。新しいCookieはdocument.cookieに追加されます。したがって、document.cookieを再読み取りすると、次のようなデータが得られます：

cookie1=value; cookie2=value;

     

特定のCookie値を検索する必要がある場合は、Cookie文字列内でCookie値を検索するJavaScript関数を作成する必要があります。

JavaScript Cookieサンプル

次のサンプルでは、訪問者の名前を保存するCookieを作成します。

まず、訪問者がWebページにアクセスすると、自分の名前を入力するよう求められます。その名前はCookieに保存されます。

訪問者が次回ページにアクセスすると、歓迎メッセージが表示されます。

このサンプルでは、3つのJavaScript関数を作成します：

  1. Cookie値を設定する関数
  2. Cookie値を取得する関数
  3. Cookie値を検出する関数

Cookie値を設定する関数

まず、訪問者の名前を保存する関数を作成します：

function setCookie(cname,cvalue,exdays) { var d = new Date(); d.setTime(d.getTime()+(exdays*24*60*60*1000)); var expires = "expires="+d.toGMTString(); document.cookie = cname + "=" + cvalue + "; " + expires; }

関数の説明：

上記の関数パラメータでは、Cookieの名前はcname、Cookieの値はcvalueで、Cookieの有効期限expiresも設定されています。

この関数は、Cookie名、Cookie値、Cookieの有効期限を設定します。

Cookie値を取得する関数

次に、指定されたCookieの値を返す関数を作成します：

function getCookie(cname) { var name = cname + "="; var ca = document.cookie.split(';'); for(var i=0; i<ca.length; i++) { var c = ca[i].trim(); if (c.indexOf(name)==0) return c.substring(name.length,c.length); } return ""; }

関数の説明：

Cookie名のパラメータはcnameです。

指定されたCookieを検索するためのテキスト変数を作成します：cname + "="。

セミコロンを使用してdocument.cookie文字列を分割し、分割された文字列配列をcaに代入します（ca = document.cookie.split(';')）。

ca配列をループし（i=0;i<ca.length;i++）、配列内の各値を読み取り、前後の空白を削除します（c=ca[i].trim()）。

Cookieが見つかった場合（c.indexOf(name) == 0）、Cookieの値を返します（c.substring(name.length,c.length)）。

Cookieが見つからない場合、""を返します。

Cookie値を検出する関数

最後に、Cookieが作成されているかどうかを検出する関数を作成できます。

Cookieが設定されている場合、挨拶メッセージが表示されます。

Cookieが設定されていない場合、訪問者の名前を尋ねるポップアップが表示され、setCookie関数を呼び出して訪問者の名前を365日間保存します：

function checkCookie() { var username=getCookie("username"); if (username!="") { alert("Welcome again " + username); } else { username = prompt("Please enter your name:",""); if (username!="" && username!=null) { setCookie("username",username,365); } } }
