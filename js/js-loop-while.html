JavaScript while ループ

指定した条件が true である限り、ループはコードブロックを実行し続けることができます。

while ループ

while ループは、指定した条件が真の場合にコードブロックを繰り返し実行します。

構文

while (条件)
{
実行するコード
}

例

この例のループは、変数 i が 5 未満である限り実行され続けます：

例

while (i<5) { x=x + "The number is " + i + "<br>"; i++; }

試してみる »

条件で使用する変数の値を増やすのを忘れると、ループは永遠に終わりません。これによりブラウザがクラッシュする可能性があります。

do/while ループ

do/while ループは while ループの変形です。このループは、条件が真かどうかを確認する前にコードブロックを一度実行し、その後、条件が真であればこのループを繰り返します。

構文

do
{
実行するコード
}
while (条件);

例

次の例では do/while ループを使用しています。このループは少なくとも 1 回は実行されます。条件が false でも 1 回は実行されます。コードブロックが条件をテストする前に実行されるためです：

例

do { x=x + "The number is " + i + "<br>"; i++; } while (i<5);

試してみる »

条件で使用する変数の値を増やすのを忘れないでください。そうしないとループは永遠に終わりません！

for と while の比較

前の章で for ループについて読んだなら、while ループが for ループとよく似ていることに気づくでしょう。

この例のループは、以下を使用しますfor ループcars 配列のすべての値を表示します：

例

cars=["BMW","Volvo","Saab","Ford"]; var i=0; for (;cars[i];) { document.write(cars[i] + "<br>"); i++; }

この例のループは、以下を使用しますwhile ループcars 配列のすべての値を表示します：

例

cars=["BMW","Volvo","Saab","Ford"]; var i=0; while (cars[i]) { document.write(cars[i] + "<br>"); i++; }
