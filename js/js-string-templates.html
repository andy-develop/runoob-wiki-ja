JavaScript テンプレート文字列

JavaScript のテンプレート文字列は、文字列内に式や変数を埋め込むことができる便利な文字列構文です。

テンプレート文字列はバッククォートを使用します``文字列の区切り文字として使用されるリテラルです。

テンプレートリテラルはバッククォート（`）で区切られたリテラルであり、複数行の文字列、埋め込み式を使った文字列補間、および「タグ付きテンプレート」と呼ばれる特別な構造を許可します。

構文

`string text`

`string text line 1
 string text line 2`

`string text ${expression} string text`

tagFunction`string text ${expression} string text`

パラメータ

  • string text：テンプレートリテラルの一部となる文字列テキスト。改行やその他の空白文字を含むほとんどすべての文字が許可されます。ただし、タグ関数を使用しない限り、無効なエスケープシーケンスは構文エラーを引き起こします。

  • expression：現在の位置に挿入する式。その値は文字列に変換されるか、tagFunction に渡されます。

  • tagFunction：指定された場合、テンプレート文字列の配列と置換式を使用して呼び出され、戻り値がテンプレートリテラルの値になります。

例

let text = `Hello RUNOOB!`;

テンプレートリテラル内のバッククォート（`）をエスケープするには、バッククォートの前にバックスラッシュ（\）。

`\`` === "`"; // true

テンプレートリテラルはバッククォート（`）で囲みます。二重引用符（"）や単一引用符（'）。

通常の文字列に加えて、テンプレートリテラルにはプレースホルダーを含めることもできます。これは、ドル記号と中括弧で区切られた埋め込み式です：${expression}。

文字列とプレースホルダーは関数（デフォルト関数またはカスタム関数）に渡されます。デフォルト関数（カスタム関数が指定されていない場合）は、文字列補間を実行してプレースホルダーを置き換え、それらの部分を1つの文字列に結合します。

テンプレート文字列では変数を使用できます：

例

const name = 'Runoob'; const age = 30; const message = `My name is ${name} and I'm ${age} years old.`;

試してみる »

上記の例では、${name}と${age}はテンプレート文字列の式部分であり、これらは${}の内部に含まれ、実行時に評価されます。

テンプレート文字列を使用すると、文字列内で変数を参照したり、関数呼び出しを実行したり、任意の JavaScript 式を実行したりできます。

テンプレート文字列では式を使用できます：

例

let price = 10;
let VAT = 0.25;

let total = `Total: ${(price * (1 + VAT)).toFixed(2)}`;

let header = "";

    私も一つ書いてみます:

    // 定义标签函数
function tagFunction(strings, ...values) {
    // strings是模板字符串中不包含变量部分的数组
    // values是插值中的所有变量
    return strings.reduce((accumulator, str, i) => {
        // 对插值变量进行处理
        const value = values[i];

        // 处理插值变量
        const processedValue = (typeof value === 'string')
            ? `[${value.toUpperCase()}]`
            : (typeof value === 'number')
                ? `[${value * 2}]`
                : '';

        return accumulator + str + processedValue;
    }, '');
}

// 使用标签函数
const xm = 'Fitten';
const ll = 5; 

const result = tagFunction`Hello, my name is ${xm} and I am ${ll} years old.`;
console.log(result); // 输出: Hello, my name is [FITTEN] and I am [10] years old.

    この例では、`tagFunction` を使用してテンプレート文字列を処理し、変数部分の文字列変数を大文字に変換し、数値を2倍にし、同時に角括弧のマークを追加しています。
