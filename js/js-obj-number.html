JavaScript Numberオブジェクト

JavaScriptには数値型は1つしかありません。

数値は小数点を使用しても、しなくても記述できます。

JavaScript 数値

JavaScriptの数値は小数点を使用しても、しなくても記述できます：

例

var pi=3.14; // 小数点を使用
var x=34; // 小数点を使用しない

非常に大きいまたは非常に小さい数値は、科学（指数）表記法で記述できます：

例

var y=123e5;    // 12300000
var z=123e-5;   // 0.00123

すべてのJavaScript数値は64ビットです

JavaScriptは型付き言語ではありません。他の多くのプログラミング言語とは異なり、JavaScriptは整数、short、long、浮動小数点などの異なる数値型を定義していません。

JavaScriptでは、数値は整数型と浮動小数点型に分けられず、すべての数値は浮動小数点型です。JavaScriptはIEEE754標準で定義された64ビット浮動小数点形式で数値を表し、その最大値（Number.MAX_VALUE）は±1.7976931348623157e+308、最小値（Number.MIN_VALUE）は±5e-324。

この形式は64ビットで数値を格納し、0〜51ビットは数値（仮数）を格納し、52〜62ビットは指数を格納し、63ビットは符号を格納します：

値（別名: Fraction/Mantissa） 指数（Exponent） 符号（Sign）
52 bits (0 - 51)  11 bits (52 - 62) 1 bit (63)


精度

整数（小数点や指数表記を使用しない）は最大15桁です。

例

var x = 999999999999999; //x は 999999999999999 var y = 9999999999999999; //y は 10000000000000000

例

var x = 0.2+0.1; // 出力結果は 0.30000000000000004

8進数と16進数

接頭辞が0の場合、JavaScriptは数値定数を8進数として解釈し、接頭辞が0と"x"の場合は16進数として解釈します。

例

var y = 0377;
var z = 0xFF;

試してみる »

8進数変換が必要でない限り、数値の前にゼロを書かないでください。

デフォルトでは、JavaScriptの数値は10進数で表示されます。

ただし、toString() メソッドを使用して16進数、8進数、2進数を出力できます。

例

var myNumber=128;
myNumber.toString(16); // 80を返す
myNumber.toString(8); // 200を返す
myNumber.toString(2); // 10000000を返す

無限大（Infinity）

数値演算の結果がJavaScriptで表現できる数値の上限を超えると（オーバーフロー）、結果は特別な無限大（infinity）値となり、JavaScriptではInfinityで表されます。同様に、負の数の値がJavaScriptで表現できる負の数の範囲を超えると、結果は負の無限大となり、JavaScriptでは-Infinityで表されます。無限大の値の挙動は期待どおりです。それらに対する加算、減算、乗算、除算の結果も無限大です（もちろん符号は保持されます）。

例

myNumber=2;
while (myNumber!=Infinity)
{
myNumber=myNumber*myNumber; // myNumber が Infinity に等しくなるまで繰り返し計算
}

試してみる »

0で割ると無限大も生成されます:

例

var x = 2/0;
var y = -2/0;

NaN - 非数値

NaN プロパティは非数値を表す特別な値です。このプロパティは、ある値が数値でないことを示すために使用されます。Number オブジェクトをこの値に設定して、数値でないことを示すことができます。

isNaN() グローバル関数を使用して、値が NaN かどうかを判定できます。

例

var x = 1000 / "Apple";
isNaN(x); // true を返す
var y = 100 / "1000";
isNaN(y); // false を返す

試してみる »

0で割ると無限大になり、無限大は数値です:

例

var x = 1000 / 0;
isNaN(x); // false を返す

数値は数値またはオブジェクトにできます

数値はリテラルで初期化できます。例: x = 123;

JavaScript数値オブジェクトで初期化する場合、var y = new Number(123);

例

var x = 123;
var y = new Number(123);
typeof(x) // Number を返す
typeof(y) // Object を返す

Number プロパティ

プロパティ 説明
Number.MAX_VALUE 最大値
Number.MIN_VALUE 最小値
Number.NaN 非数値
Number.NEGATIVE_INFINITY 負の無限大。オーバーフロー時に返される
Number.POSITIVE_INFINITY 正の無限大。オーバーフロー時に返される
Number.EPSILON

1と、1に最も近く1より大きい最小のNumberとの差を表します
Number.MIN_SAFE_INTEGER 最小の安全整数。
Number.MAX_SAFE_INTEGER 最大の安全整数。

数値メソッド

メソッド 説明
Number.parseFloat() 文字列を浮動小数点数に変換します。グローバルメソッドparseFloat()と同じ働きです。
Number.parseInt()

文字列を整数に変換します。グローバルメソッドparseInt()と同じ働きです。
Number.isFinite() 渡された引数が有限数値かどうかを判定します。
Number.isInteger() 渡された引数が整数かどうかを判定します。
Number.isNaN() 渡された引数が isNaN() かどうかを判定します。
Number.isSafeInteger() 渡された引数が安全な整数かどうかを判定します。

数値型プロトタイプのメソッド

メソッド 説明
toExponential() 数値の指数形式の文字列を返します。例: 1.23e+2
toFixed()

指定された小数桁数の表現を返します。

var a=123;
b=a.toFixed(2); // b="123.00"
toPrecision()

指定された精度の数値を返します。次の例では、a=123 の場合、3は精度の制限により消えます:

var a=123;
b=a.toPrecision(2); // b="1.2e+2"

    Infinity、-Infinity と NaN について

    • Infinity、-Infinity、NaN はすべてJavaScriptの予約語であり、識別子として使用できません。大文字と小文字を区別します。
    • -Infinity の負号と "Infinity" の間にはスペースを入れることはできません。
    • -Infinity 括弧で囲む必要はありません。1 - (-Infinity) と 1 - -Infinity は同等です。
    • 他の数値と同様に、これら3つを文字列と加算すると文字列になります。
    • これら3つは、いかなる有限数値とも等しくありません。
    • オブジェクトの .stringgify() メソッドを使用して JSON テキストに変換する場合、これら3つは null に変換されます。

    Infinity の演算規則

    • 正の数を 0 で割ると Infinity になります。
    • Infinity に任意の有限数を加えるか減じると、結果は Infinity になります。Infinity + Infinity または Infinity - -Infinity も Infinity になります。
    • Infinity に任意の有限正数を掛けるか、または任意の有限正数で割ると Infinity になります。Infinity に任意の有限負数を掛けるか、または任意の有限負数で割ると -Infinity になります。Infinity * Infinity または Infinity / 0 も Infinity になります。Infinity * -Infinity は -Infinity になります。
    • Infinity - Infinity は NaN になります。Infinity / Infinity は NaN になります。Infinity * 0 は NaN になります。
    • Infinity == Infinity は真です。Infinity.isNaN() は偽です。Infinity.isFinite() は偽です。Boolean(Infinity) は真です。

    -Infinity の演算規則

    • 負の数を 0 で割ると -Infinity になります。
    • -Infinity に任意の有限数を加えるか減じると、結果は -Infinity になります。-Infinity + -Infinity または -Infinity - Infinity も -Infinity になります。
    • -Infinity に任意の有限正数を掛けるか、または任意の有限正数で割ると -Infinity になります。-Infinity に任意の有限負数を掛けるか、または任意の有限負数で割ると Infinity になります。-Infinity * Infinity または -Infinity / 0 も -Infinity になります。-Infinity * -Infinity は Infinity になります。
    • -Infinity - -Infinity は NaN になります。-Infinity / -Infinity は NaN になります。-Infinity * 0 は NaN になります。
    • -Infinity == -Infinity は真です。-Infinity.isNaN() は偽です。-Infinity.isFinite() は偽です。Boolean(-Infinity) は真です。

    NaN の演算規則

    • 0 / 0 は NaN になります。上記にも NaN になる場合がいくつかあります。
    • NaN に任意の数を加える、減じる、掛ける、または任意の数で割ると（Infinity、-Infinity、NaN 自体を含む）、NaN になります。
    • 変数 x がどのような値を取っても（undefined、null、true、 false 、Infinity、-Infinity、およびNaN 自体）、NaN == x は常に偽です。NaN.isNaN() は真です。NaN.isFinite() は偽です。Boolean(NaN) は偽です。
