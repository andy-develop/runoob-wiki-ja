JavaScript オブジェクト

JavaScript オブジェクトは、プロパティとメソッドを持つデータです。

実生活におけるオブジェクト、プロパティ、メソッド

実生活では、自動車はオブジェクトです。

オブジェクトには、重量や色などのプロパティがあり、メソッドには起動や停止などがあります:

オブジェクト プロパティ メソッド

car.name = Fiat

car.model = 500

car.weight = 850kg

car.color = white
car.start()

car.drive()

car.brake()

car.stop()

すべての自動車にはこれらのプロパティがありますが、車種ごとにプロパティの値は異なります。

すべての自動車にはこれらのメソッドがありますが、実行されるタイミングはそれぞれ異なります。

JavaScript オブジェクト

JavaScript では、ほぼすべてのものがオブジェクトです。

JavaScript では、オブジェクトは非常に重要です。オブジェクトを理解すれば、JavaScript を理解することができます。

JavaScript 変数への代入について学びました。

次のコードは変数carに "Fiat" という値を設定します:

var car = "Fiat";

オブジェクトも変数ですが、オブジェクトは複数の値（複数の変数）を含むことができます。各値はname:valueのペアで表されます。

var car = {name:"Fiat", model:500, color:"white"};

上記のサンプルでは、3 つの値（"Fiat", 500, "white"）が変数 car に割り当てられています。

JavaScript オブジェクトは変数のコンテナです。

オブジェクト定義

文字を使用して JavaScript オブジェクトを定義および作成できます:

サンプル

var person = {firstName:"John", lastName:"Doe", age:50, eyeColor:"blue"};

試してみる »

JavaScript オブジェクトの定義は複数行にまたがることができ、スペースと改行は必須ではありません：

サンプル

var person = {
    firstName:"John",
    lastName:"Doe",
    age:50,
    eyeColor:"blue"
};

試してみる »

オブジェクトプロパティ

「JavaScript オブジェクトは変数のコンテナである」と言えます。

しかし、通常は「JavaScript オブジェクトはキーと値のペアのコンテナである」と考えられています。

キーと値のペアは通常、次のように記述しますname : value（キーと値はコロンで区切ります）。

キーと値のペアは JavaScript オブジェクトでは通常、オブジェクトプロパティと呼ばれます。。

JavaScript オブジェクトはプロパティ変数のコンテナです。

オブジェクトのキーと値のペアの書き方は次に似ています：

  • PHP の連想配列
  • Python の辞書
  • C 言語のハッシュテーブル
  • Java のハッシュマップ
  • Ruby と Perl のハッシュテーブル

オブジェクトプロパティへのアクセス

オブジェクトプロパティには 2 つの方法でアクセスできます:

サンプル 1

person.lastName;

試してみる »

サンプル 2

person["lastName"];

試してみる »

オブジェクトメソッド

オブジェクトのメソッドは関数を定義し、それをオブジェクトのプロパティとして格納します。

オブジェクトメソッドは () を追加して（関数として）呼び出します。

このサンプルは person オブジェクトの fullName() メソッドにアクセスしています:

サンプル

name = person.fullName();

試してみる »

person オブジェクトの fullName プロパティにアクセスすると、関数を定義する文字列として返されます：

サンプル

name = person.fullName;

試してみる »

 

JavaScript オブジェクトはプロパティとメソッドのコンテナです。

以降のチュートリアルでは、関数、プロパティ、メソッドについてさらに詳しく学びます。

オブジェクトメソッドへのアクセス

次の構文を使用してオブジェクトメソッドを作成できます：

methodName : function() {
    // 代码 
}

次の構文を使用してオブジェクトメソッドにアクセスできます：

サンプル

objectName.methodName()

試してみる »

通常、fullName() は person オブジェクトのメソッドとして扱われ、 fullName はプロパティとして扱われます。

fullName プロパティを使用する場合、() を追加しないと、()関数の定義が返されます：

サンプル

objectName.methodName

試してみる »

JavaScript オブジェクトを作成、使用、変更する方法は複数あります。

同様に、プロパティとメソッドを作成、使用、変更する方法も複数あります。

    オブジェクトの格納はキーと値のペアの形式で行われます。一般的には[]どのような形式の値の取得にも適用できますが、.すべての状況に適用できるとは限りません。以下に 2 つの状況の違いを説明します。

    • 1. 取得するプロパティ名が動的な値の場合は、[] のみ使用でき、. は使用できません。
    • 2. 取得するキー名が特別な文字列の場合は、[] のみ使用でき、. は使用できません。

    特別とはどういうことか：キー名が次のような場合は、キー名に数字が含まれる文字列の場合、キー名に特殊記号がある場合、キー値が引用符で囲まれた文字列の場合です。

    let person = {
    name : '饺子',
    age : 18,
    //以下属加引号是为了将其视为整体，两种访问方式区别情况2也体现在这
    "123":"chinese", 
    "my-job" : "我的工作，中间是连字符",
    "my word" : "我的，中间含有一个空格",
    say(){
        console.log(this.name+"年龄是:" + this.age);
    } 
};

// 两种方式都可以访问属性和方法
console.log(person.name) 
console.log(person.age)
person.say()

console.log(person["name"])
console.log(person["age"])
person["say"]()

// 区别1：动态变量作为属性
// 这里定义一个myName,值为对象属性中的一个键名，在这里是直接定义的，但是在开发环境中可能是接手的其他的可变化的值
let myName = "name"
console.log(person.myName)        // undefined，使用.访问，不会取出myName的值，会在person对象上查找键名为"myName"的属性值，因为没有所以肯定也找不到了
console.log(person[myName])        // zhangsan，使用[]访问，中括号访问会把动态变量转换为实际的变量,这里就相当于person[name]

//区别2：特殊字符
//console.log(person.123)        // 报错
//console.log(person.my-job)    // 报错
//console.log(person.my word)    // 报错
console.log(person[123])        // undefined
console.log(person["123"])        // chinese，注意只有合理的数字才能省略引号
console.log(person["my-job"])   // 我的工作，中间是连字符
console.log(person["my word"])  // 我的，中间含有一个空格
