JavaScript フォーム検証

HTML フォーム検証は JavaScript で行うことができます。

次のサンプルコードは、フォームフィールド (fname) の値が存在するかどうかを判断するために使用します。存在しない場合は、メッセージを表示してフォームの送信を阻止します：

JavaScript 例

function validateForm() { var x = document.forms["myForm"]["fname"].value; if (x == null || x == "") { alert("名前を入力してください。"); return false; } }

上記の JavaScript コードは HTML コードから呼び出すことができます：

HTML フォーム例

<form name="myForm" action="demo_form.php" onsubmit="return validateForm()" method="post"> 名前: <input type="text" name="fname"> <input type="submit" value="送信"> </form>

HTML フォーム自動検証

HTML フォーム検証はブラウザーで自動的に行うこともできます。

フォームフィールド (fname) の値が空の場合、required属性はフォームの送信を阻止します：

例

<form action="demo_form.php" method="post"> <input type="text" name="fname" required="required"> <input type="submit" value="送信"> </form>

データ検証

データ検証は、ユーザーが入力したデータが有効であることを保証するために使用されます。

一般的なデータ検証には以下があります：

  • 必須フィールドに入力があるか？
  • ユーザーが正当なデータを入力したか？
  • 数値フィールドにテキストが入力されていないか？

ほとんどの場合、データ検証はユーザーが正しくデータを入力することを保証するために使用されます。

データ検証はさまざまな方法で定義でき、複数の方法で呼び出すことができます。

サーバーサイドデータ検証データをサーバーに送信した後に検証します。

クライアントサイドデータ検証データをサーバーに送信する前に、ブラウザー上で検証を完了します。

HTML制約検証

HTML5 では HTML フォームの検証方法として制約検証（constraint validation）が追加されました。

制約検証は、フォームが送信されるときにブラウザーが検証を実装するために使用するアルゴリズムです。

HTML 制約検証は次に基づいています：

  • HTML入力属性
  • CSS 疑似クラスセレクター
  • DOM 属性とメソッド

制約検証 HTML入力属性

属性 説明
disabled 入力要素を無効として指定します
max 入力要素の最大値を指定します
min 入力要素の最小値を指定します
pattern 入力要素の値のパターンを指定します
required 入力要素フィールドが必須であることを指定します
type  入力要素のタイプを指定します

制約検証 CSS 疑似クラスセレクター

セレクター 説明
:disabled 「disabled」属性を持つ input 要素を選択します
:invalid 無効な input 要素を選択します
:optional 「optional」属性を持たない input 要素を選択します
:required 「required」属性を持つ input 要素を選択します
:valid 有効な値を持つ input 要素を選択します
