JavaScript Math オブジェクト

例

ある数値のコサイン値を返します：

Math.cos(3);

上記の例の出力結果：

-0.9899924966004454

試してみる »

定義と使い方

cos() メソッドは数値のコサイン値を返します。

注意：cos() は -1.0 から 1.0 の間の数を返します。

ブラウザサポート

すべての主要ブラウザが cos() メソッドをサポートしています

構文

Math.cos(x)

パラメータ値

引数 説明
x 必須です。数値でなければなりません。

戻り値

型 説明
Number x のコサイン値。 -1.0 から 1.0 の間の数を返します。

技術詳細

JavaScript バージョン： 1.0

その他の例

例

PI と 2*PI のコサイン値を返します：

var a=Math.cos(Math.PI);
var b=Math.cos(2*Math.PI);

aとb出力結果：

-1
1
