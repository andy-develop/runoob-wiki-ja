JavaScript Array オブジェクト

例

3つの配列の値を結合する：

var a = ["Google", "Taobao"]; var b = ["Runoob", "Wiki", "Zhihu"]; var c = a.concat(b); document.write(c);

children出力結果：

Google,Taobao,Runoob,Wiki,Zhihu

試してみる »

定義と用法

concat() メソッドは、2つ以上の配列を連結するために使用されます。

このメソッドは既存の配列を変更せず、新しい配列を返します。

ブラウザサポート

すべての主要ブラウザが concat() プロパティをサポートしています。

構文

array1.concat(array2, array3,..., arrayX)

パラメータ

パラメータ 説明
array2, array3,..., arrayX 必須。連結する必要がある配列。

戻り値

Type 説明
Array オブジェクト 新しい配列を返します。この配列は、すべての arrayX パラメータを arrayObject に追加することで生成されます。concat() 操作の引数が配列の場合、追加されるのは配列自体ではなく、配列の要素です。

技術詳細

JavaScript バージョン: 1.2

その他の例

2つの配列を結合する：

const array1 = ['a', 'b', 'c']; const array2 = ['d', 'e', 'f']; const array3 = array1.concat(array2); console.log(array3); //出力：['a', 'b', 'c', 'd', 'e', 'f']

例

3つの配列を結合する：

const array1 = ['a', 'b', 'c']; const array2 = ['d', 'e', 'f']; const array3 = ['g', 'h', 'i']; const array4 = array1.concat(array2, array3); console.log(array4); //出力：['a', 'b', 'c', 'd', 'e', 'f', 'g', 'h', 'i']

['a', 'b', 'c', 'd', 'e', 'f', 'g', 'h', 'i']
