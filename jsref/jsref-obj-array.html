JavaScript Arrayオブジェクト

JavaScript の Array オブジェクトは、複数の値を格納するための特別なタイプのオブジェクトです。

Array は要素を順番に格納し、インデックス（0 から始まる）を使ってアクセスできます。

配列の作成

配列はいくつかの方法で作成できます：

Array コンストラクタを使用する：

let arr1 = new Array(3);  // 创建一个长度为 3 的空数组
let arr2 = new Array(1, 2, 3);  // 创建一个包含 1, 2, 3 的数组

リテラルを使用する（推奨）：

let arr = [1, 2, 3];  // 创建一个包含 1, 2, 3 的数组

最初の配列要素のインデックスは 0、2 番目のインデックスは 1、以降も同様です。

JavaScript Array の詳細については、以下を参照してくださいJavaScript Array オブジェクト。

配列のプロパティ

プロパティ 説明
constructor 配列オブジェクトを作成したプロトタイプ関数を返します。
length 配列要素の数を設定または返します。
prototype 配列オブジェクトにプロパティまたはメソッドを追加できます。

Array オブジェクトのメソッド

メソッド 説明
[...] 新しい配列を作成します。
concat() 2 つ以上の配列を連結し、その結果を返します。
copyWithin() 配列の指定位置から、配列の別の指定位置へ要素をコピーします。
entries() 配列の反復可能オブジェクトを返します。
every() 配列のすべての要素が条件を満たすかどうかを判定します。
fill() 固定値で配列を埋めます。
filter() 配列要素をチェックし、条件を満たすすべての要素の配列を返します。
find() 渡されたテスト（関数）条件を満たす配列要素を返します。
findIndex() 渡されたテスト（関数）条件を満たす配列要素のインデックスを返します。
forEach() 配列の各要素に対してコールバック関数を 1 回実行します。
from() 指定されたオブジェクトから配列を作成します。
fromAsync() 非同期反復可能オブジェクト、反復可能オブジェクト、または配列風オブジェクトから新しい配列を作成します。
includes() 配列が指定された値を含むかどうかを判定します。
indexOf() 配列内の要素を検索し、その位置を返します。
isArray() オブジェクトが配列かどうかを判定します。
join() 配列のすべての要素を 1 つの文字列にまとめます。
keys() 元の配列のキー（key）を含む配列の反復可能オブジェクトを返します。
map() 指定された関数で配列の各要素を処理し、処理後の配列を返します。
pop() 配列の最後の要素を削除し、削除した要素を返します。
push() 配列の末尾に 1 つ以上の要素を追加し、新しい長さを返します。
reduce() 配列の要素を 1 つの値に計算します（左から右へ）。
reduceRight() 配列の要素を 1 つの値に計算します（右から左へ）。
reverse() 配列の要素の順序を反転します。
shift() 配列の最初の要素を削除して返します。
slice() 配列の一部を選択し、新しい配列を返します。
some() 配列要素に指定された条件を満たす要素があるかどうかを判定します。
sort() 配列の要素を並べ替えます。
splice() 配列に要素を追加または配列から要素を削除します。
toString() 配列を文字列に変換し、結果を返します。
toLocaleString() 現在の環境のロケール設定に基づいて、配列内の各要素をフォーマットします。
unshift() 配列の先頭に 1 つ以上の要素を追加し、新しい長さを返します。
valueOf() 配列オブジェクトのプリミティブ値を返します。
Array.of() 一連の値を配列に変換します。
Array.at() 整数値を受け取り、そのインデックスに対応する要素を返します。正数と負数を使用できます。負の整数は配列の最後の要素から逆算します。
Array.flat() 新しい配列を作成します。この新しい配列は、元の配列の各要素に対して指定された関数を 1 回呼び出した後の戻り値で構成されます。
Array.flatMap() マッピング関数で各要素をマップし、その結果を新しい配列に平坦化します。
Array.with() 配列の要素を更新します。
Array.findLastIndex() 配列内の各要素に対して関数を実行します。
Array.lastIndexOf() 配列内の各要素に対して関数を実行します。
Array.findLast() 配列内の各要素に対して関数を実行します。
Array.toReversed() 配列内の要素の順序を反転します。
Array.toSorted() 配列内の要素をアルファベット順に並べ替えます。
Array.toSpliced() 配列に要素を追加および/または削除します。
[Symbol.iterator]() 配列の各インデックスの値を生成する配列イテレータオブジェクトを返します。
