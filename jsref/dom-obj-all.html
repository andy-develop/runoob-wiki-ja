HTML DOM 要素オブジェクト

HTML DOM ノード

HTML DOM（Document Object Model）では、すべてのものはノードです:

  • ドキュメント自体がドキュメントオブジェクトです
  • すべてのHTML要素は要素ノードです
  • すべてのHTML属性は属性ノードです
  • HTML要素に挿入されたテキストはテキストノードです
  • コメントはコメントノードです

要素オブジェクト

HTML DOMでは、要素オブジェクトはHTML要素を表します。

要素オブジェクトの子ノードには、要素ノード、テキストノード、コメントノードがあります。

NodeList オブジェクトノードのリストを表し、HTML要素の子ノードの集合に似ています。

要素は属性を持つことができます。属性は属性ノードに属します（次の章を参照してください）。

ブラウザサポート

すべての主要ブラウザは要素オブジェクトとNodeListオブジェクトをサポートしています。

element.offsetTop 現在の要素の相対的な垂直オフセット位置を持つオフセットコンテナを返します

element.setAttribute() 指定した属性を設定または変更し、値を指定します。
