JavaScript Numberオブジェクト

Number オブジェクト

Number オブジェクトはプリミティブ数値のラッパーオブジェクトです。

Number の作成方法は new Number() です。

構文

var num = new Number(value);

注意：パラメータ値を数値に変換できない場合は NaN (非数値) を返します。

Number オブジェクトのプロパティ

プロパティ 説明
constructor このオブジェクトを作成した Number 関数への参照を返します。
MAX_VALUE 表現可能な最大の数。
MIN_VALUE 表現可能な最小の数。
NEGATIVE_INFINITY 負の無限大。オーバーフロー時にこの値を返します。
NaN 非数値 (NaN)。
POSITIVE_INFINITY 正の無限大。オーバーフロー時にこの値を返します。
prototype オブジェクトにプロパティとメソッドを追加できます。

Number オブジェクトのメソッド

メソッド 説明
isFinite 指定されたパラメータが無限大かどうかを検出します。
isInteger 指定されたパラメータが整数かどうかを検出します。
isNaN 指定されたパラメータが NaN かどうかを検出します。
isSafeInteger 指定されたパラメータが安全整数かどうかを検出します。
toExponential(x) オブジェクトの値を指数表記に変換します。
toFixed(x) 数値を文字列に変換し、結果の小数点以下を指定した桁数にします。
toLocaleString(locales, options) 特定のロケールでの数値の表現文字列を返します。
toPrecision(x) 数値を指定された長さにフォーマットします。
toString() 指定された基数を使用して数値を文字列に変換します。
valueOf() Number オブジェクトの基本数値を返します。

ES6 で追加された Number プロパティ

ES6 では、以下の 3 つの Number オブジェクトのプロパティが追加されました：

  • EPSILON: 1 と、1 に最も近く 1 より大きい最小の Number との差を表します
  • MIN_SAFE_INTEGER: JavaScript における最小の安全な整数型の数値を表します (-(253 - 1))。
  • MAX_SAFE_INTEGER: JavaScript における最大の安全整数を表します (253 - 1）。

例

var x = Number.EPSILON; var y = Number.MIN_SAFE_INTEGER; var z = Number.MAX_SAFE_INTEGER;

ES6 で追加された Number メソッド

ES6 では、以下の 2 つの Number オブジェクトのメソッドが追加されました：

  • Number.isInteger(): 指定されたパラメータが整数かどうかを判定します。
  • Number.isSafeInteger(): 渡されたパラメータ値が「安全整数」かどうかを判定します。

Number.isInteger() はパラメータが整数のときに true を返します。

例

Number.isInteger(10); //true を返します Number.isInteger(10.5); //false を返します

Number.isSafeInteger() は渡されたパラメータ値が「安全整数」かどうかを判定します。

安全整数の範囲は-(253 - 1)到 253 - 1 の間の整数で、以下を含みます-(253 - 1)和 253 - 1。

例

Number.isSafeInteger(10); //true を返します Number.isSafeInteger(12345678901234567890); //false を返します
