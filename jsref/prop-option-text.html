Option text属性

Option オブジェクト

定義と用法

text 属性は、オプションのテキスト値を設定または返します。

提示：この属性は、<option> 要素に含まれるプレーンテキストを設定または返します。このテキストは、オプションのラベルとして表示されます。

语法

text 属性を設定：

optionObject.text="text"

text 属性を返す：

optionObject.text

浏览器支持

すべての主要ブラウザは text 属性をサポートしています。

实例

实例

次の例では、ドロップダウンリスト内のすべてのオプションのテキストを返します。

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>サンプル(example.com)</title>
<script>
function displayResult(selTag){
    var x=selTag.options[selTag.selectedIndex].text;
alert("選択した: " + x);
}
</script>
</head>
<body>

<form>
一番好きな果物を選択してください:
<select onchange="displayResult(this)">
    <option>Apple</option>
    <option>Orange</option>
    <option>Pineapple</option>
    <option>Banana</option>
</select>
</form>

</body>
</html>
