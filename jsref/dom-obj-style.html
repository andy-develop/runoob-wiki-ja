Style オブジェクト

Style オブジェクトは個々のスタイル宣言を表します。

Style オブジェクトへのアクセス

Style オブジェクトは、ドキュメントのヘッド領域から、または指定された HTML 要素からアクセスできます。

ドキュメントのヘッド領域から style オブジェクトにアクセスする：

var x = document.getElementsByTagName("STYLE"); 試してみる

指定された要素の style オブジェクトにアクセスする：

var x = document.getElementById("myH1").style; 試してみる

Style オブジェクトの作成

document.createElement() メソッドを使用して <style> 要素を作成できます：

var x = document.createElement("STYLE"); 試してみる

既存の要素の style 属性を設定することもできます：

document.getElementById("myH1").style.color = "red"; 試してみる
