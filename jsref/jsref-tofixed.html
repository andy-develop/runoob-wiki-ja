定義と使い方

toFixed() メソッドは、浮動小数点数を指定された小数桁数の文字列表現に変換します。小数桁数が数字より多い場合は、0 を使用して埋めます。

toFixed() メソッドは、Number を指定された小数桁数の数値に四捨五入します。

注意：toFixed() メソッドは四捨五入時に不正確な結果を生じる可能性があります。これは、toFixed() メソッドが浮動小数点数を処理する際に、標準の四捨五入ではなく、最近接偶数への丸め（銀行家丸め）戦略を実際に使用しているためです。この丸め戦略は、多数の演算時の累積誤差を減らすためのものです。

var numObj = 12345.6789;

numObj.toFixed();         // 返回 "12346"：进行四舍六入五看情况，不包括小数部分
numObj.toFixed(1);        // 返回 "12345.7"：进行四舍六入五看情况

numObj.toFixed(6);        // 返回 "12345.678900"：用 0 填充

(1.23e+20).toFixed(2);    // 返回 "123000000000000000000.00"

(1.23e-10).toFixed(2);    // 返回 "0.00"

2.34.toFixed(1);          // 返回 "2.3"

2.35.toFixed(1)           // 返回 '2.4'  向上舍入

2.55.toFixed(1)           // 返回 '2.5' 向下舍入，参考以上注意事项

-2.34.toFixed(1);         // 返回 -2.3（由于操作符优先级，负数不会返回字符串）

(-2.34).toFixed(1);       // 返回 "-2.3"（若用括号提高优先级，则返回字符串）

ブラウザサポート

すべての主要ブラウザが toFixed() メソッドをサポートしています

構文

number.toFixed(x)

パラメータ値

パラメータ 説明
x 必須。小数の桁数を指定します。0 から 20 までの値で、0 と 20 を含みます。一部の実装ではより大きな値の範囲をサポートできます。このパラメータを省略した場合は、0 で置き換えられます。

戻り値

型 説明
String 数値文字列。

技術詳細

JavaScript バージョン： 1.5

toFixed() メソッドが浮動小数点数を処理する際に、標準の四捨五入ではなく、最近接偶数への丸め（銀行家丸め）戦略を実際に使用している例は次のとおりです：

インスタンス

let num1 = 0.615;
console.log(num1.toFixed(2)); // "0.62" ではなく "0.61" を出力

より正確な四捨五入が必要な場合は、数値を特定の倍数で乗算し、Math.round() 関数を呼び出して小数桁数を手動で処理するなどの方法を使用できます。例は次のとおりです：

インスタンス

function roundNumber(number, decimals) {
  const factor = 10 ** decimals;
  return Math.round(number * factor) / factor;
}

let num2 = 0.615;
console.log(roundNumber(num2, 2)); // "0.62" を出力
