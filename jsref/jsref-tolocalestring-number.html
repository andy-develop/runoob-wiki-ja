JavaScript Number.toLocaleString()メソッド

JavaScript Number オブジェクト

例

ローカル設定を使用して文字列をフォーマットする：

let num1 = 1000000; let text1 = num1.toLocaleString(); //特定のロケールを使用して数値を文字列にフォーマットする let num2 = 1000000; let text2 = num2.toLocaleString("fi-FI"); //特定のロケールを使用して数値を通貨文字列にフォーマットする //人民元 let num3 = 1000000; let text3 = num3.toLocaleString("zh-CN", {style:"currency", currency:"CNY"}); //米ドル let num4 = 1000000; let text4 = num4.toLocaleString("en-US", {style:"currency", currency:"USD"});

定義と用法

toLocaleString() メソッドは、特定のロケールにおける数値の表現文字列を返します。

新しい locales および options パラメータにより、アプリケーションはフォーマット変換を行う言語を指定し、関数の動作をカスタマイズできます。古い実装では、locales と options パラメータは無視され、使用されるロケールと返される文字列の形式は実装に完全に依存します。

ブラウザサポート

Number.toLocaleString() は ECMAScript3 (ES3) の機能です。

例

オプションパラメータを使用して、通貨文字列をフォーマットします：
