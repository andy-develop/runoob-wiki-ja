LangChain 会話記憶 -- Checkpointer

デフォルトでは、agent.invoke() は毎回独立しており、Agent は以前の会話を覚えていません。

Checkpointer（チェックポイント保存器）を使用すると、Agent が会話履歴を記憶し、本当のマルチターン会話を実現できます。

Checkpointer がない場合の問題

まず、Checkpointer がない場合の状況を見てみましょう：

例

from dotenv import load_dotenv
load_dotenv()

from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.messages import HumanMessage

model = init_chat_model("deepseek:deepseek-v4-flash", temperature=0)
agent = create_agent(
    model=model,
    system_prompt="あなたは菜鳥教程（サンプル）のアシスタントです。",
)

# 第1ターン
result1 = agent.invoke({
    "messages": [HumanMessage(content="我叫小明")]
})
print(f"第一轮: {result1['messages'][-1].content}")

# 第2ターン——Agent は第1ターンの内容を覚えていません！
result2 = agent.invoke({
    "messages": [HumanMessage(content="我叫什么名字？")]
})
print(f"第二轮: {result2['messages'][-1].content}")

実行結果：

第1ラウンド: 你好小明！很高兴认识你。  
→ 第一ラウンド：こんにちは、小明！お会いできて嬉しいです。  
第2ラウンド: 抱歉，我没有你的信息，不知道你叫什么名字。  
→ 第二ラウンド：申し訳ありません、あなたの情報を持っていないので、お名前がわかりません。

Checkpointer を使用して会話を記憶する

Checkpointer を追加すると、同じ thread_id の会話が自動的に関連付けられます：

例

from langgraph.checkpoint.memory import InMemorySaver
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.messages import HumanMessage

# インメモリ Checkpointer を作成
checkpointer = InMemorySaver()

model = init_chat_model("deepseek:deepseek-v4-flash", temperature=0)
agent = create_agent(
    model=model,
    checkpointer=checkpointer,  # Checkpointer を渡す
    system_prompt="あなたは菜鳥教程（サンプル）のアシスタントです。",
)

# thread_id を使用して会話スレッドを識別する
config = {"configurable": {"thread_id": "user-001"}}

# 第1ターン
result1 = agent.invoke(
    {"messages": [HumanMessage(content=私はシャオミンです。Pythonを勉強しています。)]},
    config=config,
)
print(f"第一轮: {result1['messages'][-1].content}")

# 第2ターン——同じ thread_id を使用すると、Agent は覚えていました！
result2 = agent.invoke(
    {"messages": [HumanMessage(content="私の名前は何ですか？私は何を学んでいますか？")]},
    config=config,
)
print(f"第二轮: {result2['messages'][-1].content}")

実行結果：

第1ラウンド: こんにちは、小明さん！Pythonは入門に最適な言語です。何かお手伝いできることはありますか？
第2ラウンド: あなたの名前は小明さんで、Pythonを学習しています。具体的な質問はありますか？

thread_id が鍵です。同じ thread_id の会話は連続しており、異なる thread_id の会話は完全に分離されています。これにより、1つの Agent インスタンスで複数のユーザーを同時にサービスを提供できます。

Checkpointer の仕組み

Checkpointer は、Agent が実行されるたびに状態スナップショット（checkpoint）を自動保存します。次に同じ thread_id で呼び出すと、最新の checkpoint から状態を自動的に復元します。

具体的な処理フロー：

  1. agent.invoke() を呼び出し、config（thread_id を含む）を渡します。
  2. Agent はその thread_id の checkpoint があるかどうかを確認します。
  3. あれば、履歴メッセージを読み込み、新しいメッセージを追加して続行します。
  4. 実行完了後、新しい checkpoint を自動保存します。

例

from langgraph.checkpoint.memory import InMemorySaver
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.messages import HumanMessage

checkpointer = InMemorySaver()
agent = create_agent(
    model=init_chat_model("deepseek:deepseek-v4-flash", temperature=0),
    checkpointer=checkpointer,
    system_prompt="あなたは菜鳥教程（サンプル）のアシスタントです。",
)

config = {"configurable": {"thread_id": "demo-001"}}

# マルチターン会話をシミュレート
questions = [
    "我叫小明",
    "私はPythonを学んでいます",
    私に関する情報を要約してください,
]

for i, q in enumerate(questions, 1):
    result = agent.invoke(
        {"messages": [HumanMessage(content=q)]},
        config=config,
    )

    # checkpoint の状態を確認
    state = agent.get_state(config)
    print(f"\n第 {i} 轮后:")
    print(f" 消息数: {len(state.values.get('messages', []))}")
    print(f" 下一步: {state.next}")
    print(f" 回复: {result['messages'][-1].content[:80]}...")

実行結果：

第1ラウンド後:
  メッセージ数: 2
  次のステップ: ()
  返答: こんにちは、小明さん！お会いできてうれしいです。

第2ラウンド後:
  メッセージ数: 4
  次のステップ: ()
  返答: Pythonは非常に人気のあるプログラミング言語で、シンプルで学びやすいです。

第3ラウンド後:
  メッセージ数: 6
  次のステップ: ()
  返答: 会話に基づくと、あなたの情報は次のとおりです: 名前は小明さんで、Pythonを学習しています。

Checkpointer の種類

種類 保存場所 永続化 インストール 適用シーン
InMemorySaver インメモリ いいえ（プログラム終了後は失われる） 組み込み 開発デバッグ、ユニットテスト
SqliteSaver SQLite データベース である langgraph-checkpoint-sqlite スタンドアロン展開、小規模アプリ
PostgresSaver PostgreSQL である langgraph-checkpoint-postgres 本番環境、マルチインスタンス共有

Agent がainvoke()非同期呼び出しを使用する場合、対応する非同期バージョンに変更する必要があります。AsyncSqliteSaver / AsyncPostgresSaver。使い方は同期バージョンと似ていますが、async withと組み合わせて使用する必要があります。

SqliteSaver の例

InMemorySaverメモリ内にのみ保存されるため、プログラムが終了するとデータは失われます。会話を永続化して保存したい場合は、使用できます。SqliteSaver。

初めて使用する場合は、SQLite Checkpointer をインストールする必要があります：

pip install langgraph-checkpoint-sqlite

例

from langgraph.checkpoint.sqlite import SqliteSaver
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.messages import HumanMessage

model = init_chat_model(
    "deepseek:deepseek-v4-flash",
    temperature=0,
)

# with 文で囲む必要があり、抜けるとデータベース接続が自動的に閉じられます
with SqliteSaver.from_conn_string("conversations.db") as checkpointer:
    agent = create_agent(
        model=model,
        checkpointer=checkpointer,
        system_prompt="あなたは菜鳥教程（サンプル）のアシスタントです。",
    )

    config = {"configurable": {"thread_id": "user-001"}}

    result = agent.invoke(
        {
            "messages": [
                HumanMessage(content="你好")
            ]
        },
        config=config,
    )

    print(result["messages"][-1].content)

SqliteSaver は毎回の会話で生成された checkpoint を SQLite データベースに保存します。プログラムが終了したり再起動したりしても、同じデータベースファイルとthread_idを使用し続ける限り、Agent は以前保存した会話状態を復元できます。注意：withコードブロックが終了するとデータベース接続が閉じられるため、Agent を複数回呼び出すロジックはすべて、withブロック内に置く必要があります。長期間実行されるサービス（Web アプリなど）の場合は、アプリケーションのライフサイクル内で接続を保持するか、非同期バージョンに変更することをお勧めします。AsyncSqliteSaver。

会話スレッドの管理

会話状態の確認

例

# 会話状態の確認
state = agent.get_state(config)
print(f"下一步: {state.next}")  # () は空きを表します
print(f"消息数: {len(state.values.get('messages', []))}")

# 会話履歴を表示
for msg in state.values.get("messages", []):
    print(f"  [{msg.type}] {str(msg.content)[:60]}")

新しいスレッドの作成

例

# 異なる thread_id = 異なる独立した会話
config_alice = {"configurable": {"thread_id": "alice"}}
config_bob = {"configurable": {"thread_id": "bob"}}

# Alice の会話
agent.invoke(
    {"messages": [HumanMessage(content="私はアリスです")]},
    config=config_alice,
)

# Bob の会話——完全に独立しており、Alice が何を言ったかは知らない
agent.invoke(
    {"messages": [HumanMessage(content="私はBob")]},
    config=config_bob,
)

# 分離性の検証
alice_state = agent.get_state(config_alice)
bob_state = agent.get_state(config_bob)
print(fAlice の会話メッセージ数: {len(alice_state.values['messages'])})
print(fBob の会話メッセージ数: {len(bob_state.values['messages'])})

状態の更新——会話の手動編集

場合によっては、会話状態を手動で変更する必要があります。たとえば、会話のクリア、システムメッセージの挿入など：

例

from langchain.messages import SystemMessage

# 状態を更新——システムメッセージを1件挿入
agent.update_state(
    config,
    {
        "messages": [
            SystemMessage(content=（ユーザーはVIP会員にアップグレードしました）)
        ]
    }
)

# 以降の会話には、この挿入されたメッセージが含まれます

update_state() のパラメータは add_messages reducer を介して処理されます（messages フィールドに関して）。そのため、新しいメッセージは上書きではなく追加されます。履歴をクリアして最初からやり直したい場合、最も簡単な方法は新しいものに切り替えることです。thread_id；どうしても特定の履歴メッセージを削除する必要がある場合は、update_state() に対応するRemoveMessage（取得元：langchain.messages）を渡すことで、指定されたメッセージを正確に削除できます。
