LangChain 設定とエラークラス

RunnableConfig 設定項目

フィールド型説明
configurabledict実行時設定。最もよく使うのは: thread_id（Checkpointer 用）
recursion_limitint最大再帰深度（デフォルト 9999）
metadatadict追加メタデータ
tagslist[str]タグリスト（トレースのフィルタリングやグループ化に使用）
callbackslist[BaseCallbackHandler]コールバックハンドラー

例

config = {
    "configurable": {"thread_id": "user-001"},
    "metadata": {"source": "web"},
    "tags": ["production", "chat"],
}
result = agent.invoke(inputs, config=config)

Checkpointer 実装クラス

类インポートパス永続化
InMemorySaverlanggraph.checkpoint.memory否
SqliteSaverlanggraph.checkpoint.sqliteである
PostgresSaverlanggraph.checkpoint.postgresである

例

# メモリ
from langgraph.checkpoint.memory import InMemorySaver
checkpointer = InMemorySaver()

# SQLite
from langgraph.checkpoint.sqlite import SqliteSaver
checkpointer = SqliteSaver.from_conn_string("checkpoints.db")

# PostgreSQL
# from langgraph.checkpoint.postgres import PostgresSaver
# checkpointer = PostgresSaver.from_conn_string("postgresql://...")

Store 実装クラス

类インポートパス永続化
InMemoryStorelanggraph.store.memory否
PostgresStorelanggraph.store.postgresである

例

from langgraph.store.memory import InMemoryStore

store = InMemoryStore()
store.put(("namespace",), "key", {"data": "value"})
item = store.get(("namespace",), "key")
items = store.search(("namespace",))
store.delete(("namespace",), "key")

よくある例外クラス

例外発生源説明
ToolExceptionlangchain.toolsツール内部の例外。Agent はこれを捕捉して再判断できます
ImportErrorPython 組み込み依存パッケージの欠落。エラーメッセージにインストールコマンドが表示されます
ValueErrorPython 組み込みパラメータ検証の失敗、または設定エラー
NotImplementedErrorPython 組み込みMiddleware メソッドが未実装（例：同期のみ定義されているのに非同期で呼び出した場合）
StructuredOutputErrorlangchain.agents.structured_output構造化出力に関連するエラー（形式不一致、複数出力など）
StructuredOutputValidationErrorlangchain.agents.structured_output構造化出力の検証失敗
MultipleStructuredOutputsErrorlangchain.agents.structured_outputモデルが複数の構造化出力を返した
TimeoutErrorPython 組み込み / 各 SDKリクエストタイムアウト
