LangChain Chat Model API

このドキュメントでは、init_chat_model() と BaseChatModel の完全な API リファレンスを一覧表示します。

init_chat_model() の完全パラメータ

パラメータ型デフォルト値説明
modelstr または None无モデル名。形式は provider:model_name。None を渡すと設定可能なモデルを作成します。
model_providerstr または NoneNoneプロバイダーを個別に指定します。model から自動的に推測できない場合に使用します。
configurable_fields"any" または list または NoneNone実行時に変更可能なフィールド。None=固定モデル、"any"=すべて設定可能。
config_prefixstr または NoneNone複数モデルシナリオにおける設定キーのプレフィックス
temperaturefloatモデルによって異なります。ランダム性を制御します。0〜2。0=決定論的、2=最大の創造性。
max_tokensintモデル上限出力最大トークン数
timeoutint/float または NoneNoneリクエストタイムアウト秒数
max_retriesintモデルによって異なります。失敗再試行回数
base_urlstr または None公式アドレスカスタム API エンドポイント
rate_limiterBaseRateLimiter无レートリミッター
top_pfloat または Noneモデルによって異なります。核サンプリングパラメータ、0〜1
stoplist[str]无停止シーケンス

BaseChatModel メソッド

メソッド説明戻り値
invoke(input, config=None, **kwargs)モデルを同期的に呼び出すAIMessage
ainvoke(input, config=None, **kwargs)モデルを非同期的に呼び出すAIMessage
stream(input, config=None, **kwargs)同期ストリーミング呼び出しIterator[AIMessageChunk]
astream(input, config=None, **kwargs)非同期ストリーミング呼び出しAsyncIterator[AIMessageChunk]
batch(inputs, config=None, **kwargs)バッチ呼び出しlist[AIMessage]
bind_tools(tools, **kwargs)ツールリストをバインドするRunnable[input, AIMessage]
with_structured_output(schema, **kwargs)構造化出力スキーマをバインドするRunnable[input, BaseModel/dict]
bind(**kwargs)実行時パラメータをバインドするRunnable

一般的な使用例

例

from langchain.chat_models import init_chat_model

# 固定モデル
model = init_chat_model("deepseek:deepseek-v4-flash", temperature=0)
response = model.invoke("你好")

# 設定可能なモデル
model = init_chat_model(configurable_fields=("model", "temperature"))
response = model.invoke("你好", config={
    "configurable": {"model": "deepseek:deepseek-v4-flash", "temperature": 0.3}
})

# ツールをバインド
model_with_tools = model.bind_tools([my_tool])
response = model_with_tools.invoke("查询天气")

# 構造化出力
model_structured = model.with_structured_output(MySchema)
result = model_structured.invoke("提取信息")
