最初のLangChain Agent

AgentはLangChainの中核となる概念であり、AIがいつツールを呼び出す必要があるかを自動的に判断し、ツールの結果を取得した後に考え続けて、タスクが完了するまで処理します。

Agentとは

通常のモデル呼び出しは一問一答です：

あなたがメッセージを送り、モデルがメッセージを返し、終了。

Agentは異なり、次のような思考-行動-観察ループに入ります：

モデルが特定のツールを呼び出す必要があると判断 → ツールを実行して結果を取得 → モデルが結果に基づいて思考を続ける → 再度ツールを呼び出す可能性 → 最終的な答えに到達するまで。

例を挙げると、「今日の杭州の天気はどうですか？」と尋ねた場合、通常のモデルは学習データ内の天気（数か月前の可能性があります）しか答えられません。一方Agentは、自ら天気照会ツールを呼び出してリアルタイムデータを取得し、その実データに基づいて回答します。

最初のAgentを作成する

プロセス全体は3ステップだけです：(1) ツールを定義する；(2) Agentを作成する；(3) 実行する。

ステップ1：ツール関数を定義する

使用する@toolデコレータで、通常のPython関数をAgentが呼び出せるツールに変換します：

例

# ファイルパス：04_first_agent.py
from dotenv import load_dotenv
load_dotenv()

from langchain.tools import tool

# ステップ1：@toolデコレータでツールを定義する
# 関数のdocstringがツールの説明になります
# モデルはこの説明に基づいて、いつこのツールを呼び出すかを判断します
@tool
def get_weather(city: str) -> str:
    """指定された都市の天気状況を照会します。

    Args:
city: 都市名。例："杭州"、"北京"
    """
    # ここではモックデータでデモしています
    # 実際のプロジェクトでは、実際の天気API呼び出しに置き換えることができます
    weather_data = {
        "杭州": "晴れ、25°C、湿度60%",
        "北京": "くもり、18°C、湿度45%",
        "上海": "小雨、22°C、湿度80%",
    }
    return weather_data.get(city, f"{city} の天気データが見つかりません")


@tool
def calculate(expression: str) -> str:
    """数学計算を実行します。加減乗除などの基本演算に対応しています。

    Args:
expression: 数式。例："3 * 7 + 2"
    """
    try:
        # 数式を安全に計算します
        result = eval(expression, {"__builtins__": {}}, {})
        return f"計算結果: {expression} = {result}"
    except Exception as e:
        return f"計算エラー: {e}"

ドキュメント文字列（関数の """...""" の部分）は非常に重要です。モデルはツールの説明を読み、このツールを呼び出すかどうか、どのパラメータを渡すかを決定します。説明が明確であればあるほど、モデルが誤って使う可能性は低くなります。

ステップ2：Agentを作成する

例

# ステップ2：Agentを作成する
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model

# モデルを初期化する
model = init_chat_model("openai:gpt-4o-mini")

# Agentを作成し、モデルとツールリストを渡す
agent = create_agent(
    model=model,
    tools=[get_weather, calculate],
    system_prompt="あなたは親切なアシスタントで、ツールを使って質問に答えます。",
)
パラメータ説明必須かどうか
model使用する言語モデルである
toolsツールリスト。Agentはこれらのツールを呼び出せますいいえ（渡さない場合、Agentはツールを呼び出せません）
system_promptシステムプロンプト。Agentの役割と行動を定義します否

ステップ3：Agentを実行する

例

# ステップ3：Agentを実行する

# 入力メッセージを構築する
# メッセージリストの最初の要素は通常HumanMessage（ユーザーメッセージ）です
from langchain.messages import HumanMessage

inputs = {"messages": [HumanMessage(content="今日の杭州の天気はどうですか？")]}

# invoke() でAgentを実行し、最終状態を返す
result = agent.invoke(inputs)

# メッセージ履歴を表示する（AIのツール呼び出しとツールの戻り結果を含む）
print("=== 完全なメッセージ履歴 ===")
for msg in result["messages"]:
    print(f"[{msg.type}] {msg.content[:100]}")  # 最初の100文字を切り出す

print("\n"=== 最終回答 ===")
# 最後のAIメッセージが最終回答です
print(result["messages"][-1].content)

実行結果：

=== 完整消息历史 ===
[human] 杭州今天天气怎么样？
[ai]
[tool] 晴，25°C，湿度 60%
[ai] 今天杭州的天气是晴天，气温25°C，湿度60%。非常适合出门活动！

=== 最终回复 ===
今天杭州的天气是晴天，气温25°C，湿度60%。非常适合出门活动！

Agentの実行フロー解説

上記の例の完全な実行プロセスは次のとおりです：

  1. ユーザーがメッセージを送信：「今日の杭州の天気はどうですか？」
  2. モデルはメッセージを受信して判断：天気を照会する必要がある → tool_callを返す（get_weatherを呼び出し、パラメータ city="杭州"）
  3. Agentはget_weatherツールを実行 → "晴れ、25°C、湿度60%" を返す
  4. モデルはツール結果を受け取る → タスク完了と判断 → 最終回答を生成

これがAgentの思考-行動-観察ループです。

Agentに複数のツールを呼び出させる

Agentの真の威力は、複数のツールを自動的に組み合わせられることです：

例

# 天気の照会と計算を同時に必要とする複雑な質問をしてみる
inputs = {"messages": [HumanMessage(
    content="今日の杭州と北京の気温差は何度ですか？"
)]}

result = agent.invoke(inputs)

print("=== 完全なメッセージ履歴 ===")
for msg in result["messages"]:
    if msg.type == "tool":
        print(f"[tool {msg.name}] {msg.content}")
    else:
        print(f"[{msg.type}] {msg.content[:120]}")

print("\n"=== 最終回答 ===")
print(result["messages"][-1].content)

実行結果：

=== 完整消息历史 ===
[human] 杭州和北京今天温差多少度？
[ai]
[tool get_weather] 晴，25°C，湿度 60%
[tool get_weather] 多云，18°C，湿度 45%
[tool calculate] 计算结果: 25 - 18 = 7
[ai] 今天杭州和北京的温差是7°C。

=== 最终回复 ===
今天杭州和北京的温差是7°C。

Agentは自動的に3ステップを実行しました：(1) 杭州の天気を照会；(2) 北京の天気を照会；(3) 気温差を計算。これらのステップを制御するロジックを書く必要はなく、Agentが自動的に計画と実行を完了しました。

注意：Agentは最初のモデル呼び出しで2つのツール呼び出し（get_weather("杭州") と get_weather("北京")）を発行し、これらは並行して実行されます。モデルはどのツール呼び出しを並行できるかを自動的に判断します。

完全なコード

例

# ファイルパス：04_first_agent.py（完全版）
from dotenv import load_dotenv
load_dotenv()

from langchain.tools import tool
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.messages import HumanMessage


# ツールを定義する
@tool
def get_weather(city: str) -> str:
    """指定された都市の天気状況を照会します。

    Args:
city: 都市名。例："杭州"、"北京"
    """
    weather_data = {
        "杭州": "晴れ、25°C、湿度60%",
        "北京": "くもり、18°C、湿度45%",
        "上海": "小雨、22°C、湿度80%",
    }
    return weather_data.get(city, f"{city} の天気データが見つかりません")


@tool
def calculate(expression: str) -> str:
    """数学計算を実行します。加減乗除などの基本演算に対応しています。

    Args:
expression: 数式。例："3 * 7 + 2"
    """
    try:
        result = eval(expression, {"__builtins__": {}}, {})
        return f"計算結果: {expression} = {result}"
    except Exception as e:
        return f"計算エラー: {e}"


# Agentを作成する
model = init_chat_model("openai:gpt-4o-mini")
agent = create_agent(
    model=model,
    tools=[get_weather, calculate],
    system_prompt="あなたは親切なアシスタントで、ツールを使って質問に答えます。",
)

# Agentを実行する
def ask(question: str):
    """質問をAgentに送信し、結果を出力します"""
    inputs = {"messages": [HumanMessage(content=question)]}
    result = agent.invoke(inputs)
    print(f"質問: {question}")
    print(f"回答: {result['messages'][-1].content}")
    print("-" * 50)
    return result


# いくつかの問題をテストする
ask("今日の杭州の天気はどうですか？")
ask("今日の杭州と北京の気温差は何度ですか？")
ask("サンプル は素晴らしい学習プラットフォームです。もし3人の友人が推薦し、さらに2人加わったら、全部で何人推薦したことになりますか？")

実行結果：

質問: 杭州今天天气怎么样？
回答: 今天杭州的天气是晴天，气温25°C，湿度60%。非常适合出门活动！
--------------------------------------------------
質問: 杭州和北京今天温差多少度？
回答: 今天杭州和北京的温差是7°C。
--------------------------------------------------
質問: サンプル 是一个非常棒的学习平台，如果我有 3 个朋友都推荐了，再加上 2 个，一共多少人推荐？
回答: 一共 5 人推荐了サンプル！
--------------------------------------------------

3つ目の質問に注目してください：Agentは「推薦人数」が計算問題であることを理解し、自動的にcalculateツールを呼び出しました。これは、ツール呼び出しの決定がモデルの意味理解によって駆動されており、ハードコードされたルールではないことを示しています。

同期 vs 非同期実行

Agentは非同期モードに対応しており、Webサービスなどの非同期環境での使用に適しています：

例

# Agentを非同期で実行する
import asyncio
from langchain.messages import HumanMessage


async def main():
    # ainvoke() は invoke() の非同期バージョンです
    inputs = {"messages": [HumanMessage(content="杭州の天気はどうですか？")]}
    result = await agent.ainvoke(inputs)
    print(result["messages"][-1].content)


# 非同期関数を実行する
asyncio.run(main())

ここまでで、LangChain の最も核となる使い方をマスターしました：

  • 用 @toolデコレータで Python 関数をツールに変換する

  • 用 agent.invoke()Agent を実行して結果を取得する
