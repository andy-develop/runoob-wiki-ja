Web 開発

<AppML> とは?

<AppML> appML は、Web アプリケーション向けに設計された HTML 拡張ボックスです:

  • XML 言語はアプリケーションのモデルを定義します
  • JavaScript はクライアントブラウザ上で動作します
  • PHP または ASP スクリプトはサーバー上で動作します

AppML はアプリケーションモデル言語（Application Modeling Language）。

学習はとても簡単です

  • 超シンプルなモデル
  • 超シンプルな属性
  • 超シンプルなアプリケーション開発
  • あらゆるプラットフォームとあらゆるブラウザで動作
  • インストールは簡単です

HTML、JavaScript、XML だけです

<AppML> は、HTML ページ内に JavaScript を含めるだけで、サーバー上に XML データを保存します:

HTML ページ:

<h1>My First Web Application</h1>

<div id="Place01">
<table id="Template01" class="appmltable">
<tr>
  <th>Customer</th>
  <th>City</th>
 <th>Country</th>
</tr>
<tr id="appml_row">
  <td>#CustomerName#</td>
 <td>#City#</td>
  <td>#Country#</td>
</tr>
</table>
</div>

<script src="appml.js.html"></script>
<script>
app=new AppML("appml.htmlx","Models/Customers");
app.run("Place01","Template01");
</script>

XML :

<appml>

<datasource>
<database>
  <connection>Demo</connection>
  <sql>SELECT CustomerName,City,Country FROM Customers</sql>
</database>
</datasource>

</appml>

もしあなたが以前に Web 開発を学んだことがあるなら、<AppML> の使用が非常に簡単であることに気づくでしょう。

もしあなたが以前に PHP、ASP、または ASP.NET の開発を学んだことがあるなら、<AppML> を使用する利点がはっきりとわかるでしょう。

モダン Web アーキテクチャ

<AppML> は、最新のテクノロジーとモダンな Web 開発のアイデアを組み合わせ、低消費で高速かつシンプルなアーキテクチャを使用しています:

  • MVC アーキテクチャを採用
  • 極めて低い帯域幅消費
  • クラウドコンピューティングの最適化
  • コンテンツの完全分離
  • スマートで、柔軟で、高速な Web 開発
  • 高度な拡張性とテスト可能性
  • シンプルな設定と再設定
  • ユーザーアカウントとロールをスマートにサポート

<Appml> の歴史

1999年、Refsnes Data 社は、XML ベースで Internet アプリケーションを定義するための言語である AppML の開発を開始しました。2000年9月、ノルウェーハンドボール連盟のための大規模プロジェクトが開始されました。その目的は、AppML のみを使用して、巨大な情報システムを古い DOS 環境から現代の Internet へ移行することでした。そして、この主要なプロジェクトはまさに大きな成功を収めました。開発者の見積もりによると、従来の Web 開発と比較して、今回の開発時間は最大 75% 短縮されました。

2007年9月中旬、AppML は ASP と IE をサポートしていたため、コンテンツのオフライン使用を実現しました。

2013年10月、AppML はオープンソース製品として、PHP、ASP.NET バージョンで全てのブラウザと互換性があることを発表しました。

AppML の 1999 年当時の設計目標:

  • AppML アプリケーションは、あらゆるネットワーク上で動作しなければなりません
  • AppML アプリケーションはプラットフォームに依存しないものであるべき
  • AppML アプリケーションはインターネット標準 (HTTP, HTML, CSS, XML) を使用しなければなりません
  • AppML アプリケーションはさまざまなアプリケーションの要件をサポートしなければなりません
  • AppML アプリケーションは自己記述的でなければなりません
  • AppML アプリケーションは、開発、保守、変更が容易でなければなりません
  • AppML アプリケーションは未来志向でなければなりません
