SciPy 定数モジュール

SciPy 定数モジュールconstants多くの組み込みの数学定数が用意されています。

円周率は数学定数であり、円の周長と直径の比率です。近似値は約3.14159で、一般的な記号はで表されます。

次の例は円周率を出力します：

例

from scipy import constants

print(constants.pi)

上記のコードを実行すると、出力結果は次のようになります：

3.141592653589793

次の例は黄金比を出力します：

例

from scipy import constants

print(constants.golden)

上記のコードを実行すると、出力結果は次のようになります：

1.618033988749895

私たちはdir()関数を使用してconstantsモジュールに含まれる定数を確認できます：

例

from scipy import constants

print(dir(constants))

上記のコードを実行すると、出力結果は次のようになります：

['Avogadro', 'Boltzmann', 'Btu', ...]

単位の種類

定数モジュールには次の単位が含まれています：

  • メートル法単位
  • 二進法（バイト単位）
  • 質量単位
  • 角度換算
  • 時間単位
  • 長さの単位
  • 圧力単位
  • 体積単位
  • 速度単位
  • 温度単位
  • エネルギー単位
  • 仕事率の単位
  • 力学単位

面積単位

平方メートル数を返します。平方メートルは面積のメートル法単位であり、その定義は次のとおりです：平面上で、一辺が1メートルの正方形の面積。(hectare は 10000.0 を返します)。

例

from scipy import constants

print(constants.hectare) #10000.0
print(constants.acre)    #4046.8564223999992

体積単位

立方メートル数を返します。立方メートルは容量の計量単位で、1立方メートルの容量は、縦・横・高さがすべて1メートルの立方体の体積に相当し、1キロリットルおよび1度の水の容積と等しく、1000000立方センチメートルの体積とも等しくなります。(liter は 0.001 を返します)。

例

from scipy import constants

print(constants.liter)            #0.001
print(constants.litre)            #0.001
print(constants.gallon)           #0.0037854117839999997
print(constants.gallon_US)        #0.0037854117839999997
print(constants.gallon_imp)       #0.00454609
print(constants.fluid_ounce)      #2.9573529562499998e-05
print(constants.fluid_ounce_US)   #2.9573529562499998e-05
print(constants.fluid_ounce_imp)  #2.84130625e-05
print(constants.barrel)           #0.15898729492799998
print(constants.bbl)              #0.15898729492799998

温度単位

ケルビン数を返します。(zero_Celsius は 273.15 を返します)。

例

from scipy import constants

print(constants.zero_Celsius)      #273.15
print(constants.degree_Fahrenheit) #0.5555555555555556

エネルギー単位

ジュール数を返します。ジュール（略称J）は、国際単位系におけるエネルギー、仕事、または熱量の組立単位で、記号はJです。(calorie は 4.184 を返します)。

例

from scipy import constants

print(constants.zero_Celsius)      #273.15
print(constants.degree_Fahrenheit) #0.5555555555555556

仕事率の単位

ワット数を返します。ワット（記号：W）は国際単位系の仕事率の単位です。1ワットは1ジュール/秒（1 J/s）と定義され、毎秒変換・使用・消費される（アンペアで測定される）エネルギーの割合です。(horsepower は 745.6998715822701 を返します)。

例

from scipy import constants

print(constants.hp)         #745.6998715822701
print(constants.horsepower) #745.6998715822701

力学単位

ニュートン数を返します。ニュートン（記号：N、英語：Newton）は物理量の次元であり、力のメートル法単位です。これは古典力学を確立したアイザック・ニュートンにちなんで名付けられました。。(kilogram_force は 9.80665 を返します)。

例

from scipy import constants

print(constants.dyn)             #1e-05
print(constants.dyne)            #1e-05
print(constants.lbf)             #4.4482216152605
print(constants.pound_force)     #4.4482216152605
print(constants.kgf)             #9.80665
print(constants.kilogram_force)  #9.80665
