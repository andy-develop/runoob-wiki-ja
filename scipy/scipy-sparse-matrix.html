SciPy 疎行列

疎行列（英語：sparse matrix）とは、数値解析において、大半の値がゼロである行列のことを指します。逆に、ほとんどの要素がゼロでない場合、その行列は密行列（Dense）です。

科学と工学の分野で線形モデルを解く際に、大規模な疎行列がよく出現します。

上の図の左側は疎行列で、多くの0要素が含まれていることがわかります。右側は密行列で、ほとんどの要素が0ではありません。

簡単な例を見てみましょう：

上記の疎行列は、9個の非ゼロ要素のみを含み、さらに26個のゼロ要素を含みます。そのスパース度は74%、密度は26%です。

SciPy のscipy.sparseモジュールは疎行列を処理する関数を提供します。

ここでは主に次の2種類の疎行列を使用します：

  • CSC - 圧縮スパース列（Compressed Sparse Column）、列方向に圧縮します。
  • CSR - 圧縮スパース行（Compressed Sparse Row）、行方向に圧縮します。

この章では主にCSR行列を使用します。

CSR 行列

我々は、scipy.sparse.csr_matrix()関数に配列を渡すことでCSR行列を作成できます。

例

CSR行列を作成します。

import numpy as np
from scipy.sparse import csr_matrix

arr = np.array([0, 0, 0, 0, 0, 1, 1, 0, 2])

print(csr_matrix(arr))

上記のコードの出力結果は次のとおりです：

  (0, 5)        1
  (0, 6)        1
  (0, 8)        2

結果の解析：

  • 出力の1行目：行列の第1行（インデックス0）の第6列（インデックス5）に値1があります。
  • 出力の2行目：行列の第1行（インデックス0）の第7列（インデックス6）に値1があります。
  • 出力の3行目：行列の第1行（インデックス0）の第9列（インデックス8）に値2があります。

CSR 行列メソッド

我々はdata属性を使用して、保存されているデータ（0要素を除く）を表示できます。

例

import numpy as np
from scipy.sparse import csr_matrix

arr = np.array([[0, 0, 0], [0, 0, 1], [1, 0, 2]])

print(csr_matrix(arr).data)

上記のコードの出力結果は次のとおりです：

[1 1 2]

使用count_nonzero()メソッドで非0要素の総数を計算します：

例

import numpy as np
from scipy.sparse import csr_matrix

arr = np.array([[0, 0, 0], [0, 0, 1], [1, 0, 2]])

print(csr_matrix(arr).count_nonzero())

上記のコードの出力結果は次のとおりです：

3

使用eliminate_zeros()メソッドで行列内の0要素を削除します：

例

import numpy as np
from scipy.sparse import csr_matrix

arr = np.array([[0, 0, 0], [0, 0, 1], [1, 0, 2]])

mat = csr_matrix(arr)
mat.eliminate_zeros()

print(mat)

上記のコードの出力結果は次のとおりです：

  (1, 2)    1
  (2, 0)    1
  (2, 2)    2

sum_duplicates() メソッドを使用して重複項目を削除します：

例

import numpy as np
from scipy.sparse import csr_matrix

arr = np.array([[0, 0, 0], [0, 0, 1], [1, 0, 2]])

mat = csr_matrix(arr)
mat.sum_duplicates()

print(mat)

上記のコードの出力結果は次のとおりです：

  (1, 2)    1
  (2, 0)    1
  (2, 2)    2

csr を csc に変換するには tocsc() メソッドを使用します：

例

import numpy as np
from scipy.sparse import csr_matrix

arr = np.array([[0, 0, 0], [0, 0, 1], [1, 0, 2]])

newarr = csr_matrix(arr).tocsc()

print(newarr)
  (2, 0)    1
  (1, 2)    1
  (2, 2)    2
