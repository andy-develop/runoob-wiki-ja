SciPy 補間

補間とは？

数学の数値解析の分野では、補間（英語: interpolation）とは、既知の離散データ点から範囲内の新しいデータ点を推測するプロセスまたは方法です。

簡単に言うと、補間は与えられた点の間に点を生成する方法です。

例えば：2つの点1と2に対して、補間によって点1.33と1.66を見つけることができます。

補間には多くの用途があります。機械学習では欠損データを扱うことがよくありますが、補間は通常これらの値を置き換えるために使用できます。

この値を埋める方法は「補完（インピュテーション）」と呼ばれます。

補完に加えて、補間はデータセット内の離散点を滑らかにする必要がある場合によく使用されます。

SciPy で補間を実装するには？

SciPy は補間を処理するための scipy.interpolate モジュールを提供しています。

1次元補間

1次元データの補間演算は、メソッドを使用してinterp1d()完了します。

このメソッドは、x点とy点の2つのパラメータを受け取ります。

戻り値は呼び出し可能な関数で、新しい x で呼び出すと対応する y を返します。y = f(x)。

指定された xs と ys を補間し、2.1、2.2... から 2.9 まで：

実例

from scipy.interpolate import interp1d
import numpy as np

xs = np.arange(10)
ys = 2*xs + 1

interp_func = interp1d(xs, ys)

newarr = interp_func(np.arange(2.1, 3, 0.1))

print(newarr)

出力結果は次のとおりです。

[5.2  5.4  5.6  5.8  6.   6.2  6.4  6.6  6.8]

注意：新しい xs は古い xs と同じ範囲にある必要があります。つまり、10より大きい値や0より小さい値で interp_func() を呼び出すことはできません。

単変量補間

1次元補間では、点は単一の曲線にフィッティングされますが、スプライン補間では、点は多項式を使用して区分的に定義された関数にフィッティングされます。

単変量補間では UnivariateSpline() 関数を使用します。この関数は xs と ys を受け取り、新しい xs で呼び出すことができる呼び出し可能な関数を生成します。

区分的関数とは、独立変数 x の値の範囲が異なると、異なる解析式を持つ関数です。

非線形の点に対する 2.1、2.2...2.9 の単変量スプライン補間を求めます：

実例

from scipy.interpolate import UnivariateSpline
import numpy as np

xs = np.arange(10)
ys = xs**2 + np.sin(xs) + 1

interp_func = UnivariateSpline(xs, ys)

newarr = interp_func(np.arange(2.1, 3, 0.1))

print(newarr)

出力結果は次のとおりです。

[5.62826474 6.03987348 6.47131994 6.92265019 7.3939103  7.88514634
   8.39640439 8.92773053 9.47917082]

動径基底関数補間

動径基底関数は、固定された基準点に対応して定義される関数です。

曲面補間では、通常、動径基底関数補間を使用します。

Rbf() 関数は xs と ys をパラメータとして受け取り、新しい xs で呼び出すことができる呼び出し可能な関数を生成します。

実例

from scipy.interpolate import Rbf
import numpy as np

xs = np.arange(10)
ys = xs**2 + np.sin(xs) + 1

interp_func = Rbf(xs, ys)

newarr = interp_func(np.arange(2.1, 3, 0.1))

print(newarr)

出力結果は次のとおりです。

  [6.25748981  6.62190817  7.00310702  7.40121814  7.8161443   8.24773402
   8.69590519  9.16070828  9.64233874]
