VSCode チュートリアル

VS Code（正式名称 Visual Studio Code）は、Microsoftが提供する無料・オープンソース・クロスプラットフォームのコードエディターです。

VS Code は Windows、macOS、Linux に対応し、強力な機能と柔軟な拡張性を備えています。

VS Code の最初のリリースは2015年4月29日です。

2019年のStack Overflowによる開発者調査では、Visual Studio Codeは開発者に最も人気のある開発環境とされました。

ライセンス

VS Code のソースコードは GitHub 上で MIT ライセンスで公開されています。これはソースコードがオープンソースであり、ユーザーは MIT ライセンスの条項に従えば、ソースコードを自由に使用、複製、変更、配布できることを意味します。

VS Code 製品自体には、Microsoftのソフトウェアライセンス条項が適用されます。これらの条項は、ユーザーが VS Code をどのようにインストールして使用できるかを定めており、アプリケーションの開発・テスト、社内ネットワークへの展開、アプリケーションのデモなどが含まれます。

  • 2015年11月18日、オープンソース化され、GitHub上で拡張機能のサポートが発表されました。
  • 2016年4月14日、正式版がリリースされました。

機能の特徴

  • 多言語サポート：デフォルトで JS/TS/CSS/HTML に対応し、拡張機能をインストールすることで Python、C/C++、Java、Go などもサポート
  • 中核となる編集機能：シンタックスハイライト、括弧の自動補完、コード折りたたみ、スニペット、IntelliSense
  • デバッグ機能：内蔵の Node.js デバッガー
  • クロスプラットフォーム：Electronベースで、Windows/macOS/Linux で一貫した操作性
  • ワークスペース：複数のディレクトリを同時に開くことができ、プロジェクト設定を保存・再利用可能
  • 柔軟な設定：ファイルのエンコーディング、改行コード、言語モードを切り替え、さまざまな環境に対応
