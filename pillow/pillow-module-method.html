Pillow よく使うモジュールとメソッド

Pillow は、画像のオープン、編集、保存、フォーマット変換など、豊富な機能を提供します。

本記事では、Pillow のよく使うモジュールとメソッドを紹介し、簡単なコード例を提供します。

モジュールの動作プロセス

応用処理の組み合わせ：

  • エフェクト制作：ImageFilter + ImageEnhance
  • 画像分析：ImageStat + ImageChops
  • GUI開発：ImageTk/ImageQt + ImageDraw

専門分野のサポート：

  • 科学画像：TIFFTags + ImageSequence
  • 印刷出版：PSDraw + ImageColor
  • コンピュータビジョン：ImageMorph + ImageOps

よく使うメソッド

PIL.Imageモジュールのよく使うメソッド

メソッド 説明 例
Image.open() 画像ファイルを開く img = Image.open("example.jpg")
Image.save() 画像ファイルを保存する img.save("output.png")
Image.show() 画像を表示する img.show()
Image.resize() 画像サイズを調整する new_img = img.resize((200, 200))
Image.rotate() 画像を回転する rotated_img = img.rotate(45)
Image.crop() 画像を切り抜く cropped_img = img.crop((50, 50, 200, 200))

サンプルコード：

例

from PIL import Image

# 画像を開く
img = Image.open("example.jpg")

# サイズを調整して保存
resized_img = img.resize((300, 300))
resized_img.save("resized_example.jpg")

# 90度回転して表示
rotated_img = img.rotate(90)
rotated_img.show()

PIL.ImageDrawモジュールのよく使うメソッド

メソッド 説明 例
ImageDraw.Draw() 描画オブジェクトを作成 draw = ImageDraw.Draw(img)
draw.line() 線を描画 draw.line([(0, 0), (100, 100)], fill="red", width=2)
draw.rectangle() 長方形を描画 draw.rectangle([(50, 50), (150, 150)], outline="blue", width=3)
draw.text() テキストを描画 draw.text((10, 10), "Hello", fill="black")

サンプルコード：

例

from PIL import Image, ImageDraw

# 空白画像を作成
img = Image.new("RGB", (300, 300), "white")
draw = ImageDraw.Draw(img)

# 赤い線を描画
draw.line([(0, 0), (300, 300)], fill="red", width=2)

# 青い長方形を描画
draw.rectangle([(50, 50), (250, 250)], outline="blue", width=3)

# テキストを追加
draw.text((100, 100), "Hello Pillow!", fill="black")

# 画像を保存
img.save("draw_example.png")
img.show()

PIL.ImageFilterモジュールのよく使うメソッド

メソッド 説明 例
ImageFilter.BLUR ぼかしフィルター img.filter(ImageFilter.BLUR)
ImageFilter.CONTOUR 輪郭フィルター img.filter(ImageFilter.CONTOUR)
ImageFilter.SHARPEN シャープ化フィルター img.filter(ImageFilter.SHARPEN)

サンプルコード：

例

from PIL import Image, ImageFilter

# 画像を開く
img = Image.open("example.jpg")

# ぼかしフィルターを適用
blurred_img = img.filter(ImageFilter.BLUR)
blurred_img.save("blurred_example.jpg")

# シャープ化フィルターを適用
sharpened_img = img.filter(ImageFilter.SHARPEN)
sharpened_img.show()
