Pillow ImageGrab モジュール

ImageGrab を使用すると、ユーザーは画面または指定した領域の画像をキャプチャし、画像ファイルとして保存したり、さらに処理したりできます。

ImageGrab モジュールは、自動化テスト、画面録画の補助、画像認識などのシーンに適しています。

インポート方法：

from PIL import ImageGrab

ImageGrab コアメソッド

次の表は、ImageGrab モジュールの主要なメソッドとその説明です：

メソッド 説明 パラメータ 戻り値
ImageGrab.grab() 画面全体または指定された領域の画像をキャプチャします bbox（オプション）：スクリーンショット領域を指定するタプル(x1, y1, x2, y2)。デフォルトは全画面 PIL.Imageオブジェクト
ImageGrab.grabclipboard() システムクリップボードから画像を取得します 无 PIL.Imageオブジェクト（クリップボードに画像がある場合）。それ以外の場合はNone
ImageGrab.grab_to_file() 画面をキャプチャして直接ファイルに保存します（非推奨。代わりにgrab().save()） filename：保存先のファイルパス 无

メソッドの詳細説明

ImageGrab.grab()

機能：
画面または指定された領域の画像をキャプチャします。

パラメータ：

  • bbox（オプション）：4要素のタプル(x1, y1, x2, y2)。スクリーンショット領域を定義します。デフォルトでは画面全体をキャプチャします。

サンプルコード：

実例

from PIL import ImageGrab

# 画面全体をキャプチャ
screenshot = ImageGrab.grab()
screenshot.save("full_screen.png")

# 指定領域をキャプチャ（左上 (100, 100) から右下 (500, 500) まで）
partial_screenshot = ImageGrab.grab(bbox=(100, 100, 500, 500))
partial_screenshot.save("partial_screen.png")

ImageGrab.grabclipboard()

機能：
システムクリップボードから画像データを取得します（例：スクリーンショット後にCtrl+Cを押してコピーした画像）。

戻り値：

  • クリップボードに画像がある場合は、PIL.Imageオブジェクトを返します。
  • それ以外の場合はNone。

サンプルコード：

実例

from PIL import ImageGrab

# クリップボードから画像を取得
clipboard_image = ImageGrab.grabclipboard()

if clipboard_image:
    clipboard_image.save("clipboard_image.png")
else:
    print("クリップボードに画像データがありません")

ImageGrab.grab_to_file()（非推奨）

注意：
このメソッドは新しいバージョンの Pillow では非推奨です。代わりにgrab().save()を使用することをお勧めします。

代替コードの例：

実例

from PIL import ImageGrab

# 代替案：最初に grab() してから save() する
screenshot = ImageGrab.grab()
screenshot.save("screenshot.png")

実際の応用例

定期スクリーンショットツール

実例

import time
from PIL import ImageGrab

# 5秒ごとにスクリーンショットを撮る、合計3回
for i in range(3):
    screenshot = ImageGrab.grab()
    screenshot.save(f"screenshot_{i+1}.png")
    time.sleep(5)

OpenCV と連携したリアルタイム画面分析

実例

import numpy as np
from PIL import ImageGrab
import cv2

# 画面をリアルタイムにキャプチャして表示
while True:
    screenshot = ImageGrab.grab()
    img_np = np.array(screenshot)  # NumPy 配列に変換
    cv2.imshow("Screen Capture", cv2.cvtColor(img_np, cv2.COLOR_RGB2BGR))
   
    if cv2.waitKey(1) & 0xFF == ord('q'):  # 'q' を押して終了
        break

cv2.destroyAllWindows()

注意事項

  1. クロスプラットフォーム対応：

    • Windows：完全にサポートされています。
    • macOS：追加の権限が必要です（システム設定 > プライバシーとセキュリティ > 画面収録で端末または IDE を有効にしてください）。
    • Linux：依存X11 或 Waylandが必要で、インストールが必要な場合がありますscrot 或 maimなどのツール。

  2. パフォーマンス最適化：

    • 頻繁なスクリーンショットはシステムパフォーマンスに影響を与える可能性があります。スクリーンショットの間隔を適切に設定することをお勧めします。

  3. 画像処理：

    • キャプチャした画像は、Pillow の他のモジュール（例：ImageFilter）を使用してさらに処理できます。
