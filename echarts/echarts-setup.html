ECharts 設定構文

この章では、ECharts を使用してグラフを生成するための各種設定を紹介します。

ステップ1：HTML ページを作成します

HTML ページを作成し、echarts.min.js を読み込みます：

<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <!-- 引入 ECharts 文件 -->
    <script src="echarts.min.js.html"></script>
</head>
</html>

ステップ2：ECharts 用に高さと幅を備えた DOM コンテナを用意します

例では、id が main の div が、ECharts で描画されたグラフを保持するために使用されます：

<body>
    <!-- 为 ECharts 准备一个具备大小（宽高）的 DOM -->
    <div id="main" style="width: 600px;height:400px;"></div>
</body>

ステップ3：設定情報を設定します

ECharts ライブラリは、設定に JSON 形式を使用します。

echarts.init(document.getElementById('main')).setOption(option);

ここで option は、JSON データ形式の設定を使用してグラフを描画することを示します。手順は次のとおりです：

タイトル

グラフにタイトルを設定します：

title: {
    text: '第一个 ECharts 实例'
}

ツールチップ

ツールチップを設定します：

tooltip: {},

凡例コンポーネント

凡例コンポーネントは、異なるシリーズのマーカー（symbol）、色、名前を表示します。凡例をクリックすると、どのシリーズを非表示にするかを制御できます。

legend: {
    data: [{
        name: '系列1',
        // 强制设置图形为圆。
        icon: 'circle',
        // 设置文本为红色
        textStyle: {
            color: 'red'
        }
    }]
}

X 軸

X 軸に表示する項目を設定します：

xAxis: {
    data: ["衬衫","羊毛衫","雪纺衫","裤子","高跟鞋","袜子"]
}

Y 軸

Y 軸に表示する項目を設定します。

yAxis: {}

シリーズリスト

各シリーズは、type によって自身のグラフタイプを決定します：

series: [{
    name: '销量',  // 系列名称
    type: 'bar',  // 系列图表类型
    data: [5, 20, 36, 10, 10, 20]  // 系列中的数据内容
}]

各シリーズは、type によって自身のグラフタイプを決定します：

  • type: 'bar'：縦棒グラフ/横棒グラフ
  • type: 'line'：折れ線グラフ/面グラフ
  • type: 'pie'：円グラフ
  • type: 'scatter'：散布図（バブル）
  • type: 'effectScatter'：リップルアニメーション付き散布図（バブル）
  • type: 'radar'：レーダーチャート
  • type: 'tree'：ツリー図
  • type: 'treemap'：ツリー図
  • type: 'sunburst'：サンバースト図
  • type: 'boxplot'：箱ひげ図
  • type: 'candlestick'：ローソク足チャート
  • type: 'heatmap'：ヒートマップ
  • type: 'map'：地図
  • type: 'parallel'：平行座標系のシリーズ
  • type: 'lines'：線グラフ
  • type: 'graph'：関係図
  • type: 'sankey'：サンキーダイアグラム
  • type: 'funnel'：ファネルチャート
  • type: 'gauge'：ゲージチャート
  • type: 'pictorialBar'：ピクトリアル棒グラフ
  • type: 'themeRiver'：テーマリバー
  • type: 'custom'：カスタムシリーズ

例

以下は完全な例です：

例

<!DOCTYPE html> <html> <head> <meta charset="utf-8"> <title>最初の ECharts 例</title> <!--echarts.js の読み込み--> <script src="https://cdn.staticfile.org/echarts/4.3.0/echarts.min.js"></script> </head> <body> <!--ECharts 用にサイズ（幅と高さ）を持つ DOM を用意する--> <div id="main" style="width: 600px;height:400px;"></div> <script type="text/javascript">// 準備した DOM に基づいて、ECharts インスタンスを初期化する var myChart = echarts.init(document.getElementById('main')); // グラフの設定項目とデータを指定する var option = { title: { text: '最初の ECharts 例' }, tooltip: {}, legend: { data:['売上'] }, xAxis: { data: ["シャツ","セーター","シフォンブラウス","ズボン","ハイヒール","靴下"] }, yAxis: {}, series: [{ name: '売上', type: 'bar', data: [5, 20, 36, 10, 10, 20] }] }; // 指定した設定項目とデータを使用してグラフを表示する。 myChart.setOption(option);</script> </body> </html>
