Bootstrap5 メッセージトースト(Toasts)

Bootstrap5 トースト(Toasts) は、ページの隅や下部に一時的な情報、通知、警告を表示する軽量な通知コンポーネントです。

トーストは通常、成功メッセージ、エラーメッセージ、警告、その他の通知など、短期間のメッセージをユーザーに表示するために使用されます。

トーストは、ページの左上、右上、左下、右下、ページ下部中央など、さまざまな位置に表示できます。

トーストの作成方法

トーストを作成するには、.toastクラスを使用し、そのクラス内に .toast-header と .toast-body クラスを追加して、タイトルとコンテンツを表します。

注意：トーストはデフォルトで非表示です。表示するには、.show を使用して表示を設定します。トーストを閉じるには、<button> 要素に追加します。data-bs-dismiss="toast":

例

<div class="toast show"> <div class="toast-header">トーストのタイトル<button type="button" class="btn-close" data-bs-dismiss="toast"></button> </div> <div class="toast-body">これはBootstrap 5のトーストの例です。</div> </div>

ボタンをクリックしてトーストを表示するには、JavaScript で初期化する必要があります: ID で指定した要素のクリックイベントを取得し、toast()メソッドを呼び出します。

ボタンをクリックすると、次のコードはページ内のすべてのtoastクラスを表示します:

例

document.getElementById("toastbtn").onclick = function() { var toastElList = [].slice.call(document.querySelectorAll('.toast')) var toastList = toastElList.map(function(toastEl) { return new bootstrap.Toast(toastEl) }) toastList.forEach(toast => toast.show()) }
