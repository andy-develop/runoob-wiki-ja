Bootstrap5 ユーティリティ

Bootstrap 5 には、CSSコードを繰り返し書く必要なく、素早く効果を実現するための便利なクラスが多数用意されています。

背景色

さまざまな要素の背景色を設定するには、次のものが必要です。.text-*クラスを使用して、対応するテキストの色を設定します。

例

<div class="p-3 mb-2 bg-primary text-white">.bg-primary</div> <div class="p-3 mb-2 bg-secondary text-white">.bg-secondary</div> <div class="p-3 mb-2 bg-success text-white">.bg-success</div> <div class="p-3 mb-2 bg-danger text-white">.bg-danger</div> <div class="p-3 mb-2 bg-warning text-dark">.bg-warning</div> <div class="p-3 mb-2 bg-info text-dark">.bg-info</div> <div class="p-3 mb-2 bg-light text-dark">.bg-light</div> <div class="p-3 mb-2 bg-dark text-white">.bg-dark</div> <div class="p-3 mb-2 bg-body text-dark">.bg-body</div> <div class="p-3 mb-2 bg-white text-dark">.bg-white</div> <div class="p-3 mb-2 bg-transparent text-dark">.bg-transparent</div>

フロートとフロートの解除

要素を右にフロートさせるには .float-end クラス、左にフロートさせるには .float-start クラスを使用します。.clearfix クラスはフロートを解除するために使用します。

例

<div class="clearfix"> <span class="float-start">Float left</span> <span class="float-end">Float right</span> </div>

試してみる »

画面サイズに基づいてフロート効果を設定することもできます（.float-*-left|right - * は sm (>=576px)、md (>=768px)、lg (>=992px)、xl (>=1200px)、xxl (>=1400px) を表します）。

例

<div class="float-sm-end">小画面で右にフロート</div><br> <div class="float-md-end">中画面で右にフロート</div><br> <div class="float-lg-end">大画面で右にフロート</div><br> <div class="float-xl-end">超大画面で右にフロート</div><br> <div class="float-xxl-end">特大画面で右にフロート</div><br> <div class="float-none">フロートなし</div>

試してみる »

幅と高さ

幅はw-* (.w-25, .w-50, .w-75, .w-100, .mw-auto, .mw-100)クラスを使用して設定します。

例

スペーシング

スペーシングの設定構文は次のとおりです。

{property}{sides}-{size}  // 适用 xs(<=576px)
{property}{sides}-{breakpoint}-{size} // 适用 sm (>=576px), md (>=768px), lg (>=992px), xl (>=1200px) 或 xxl (>=1400px)

ブレークポイントは画面幅を指します: xs (<=576px)、sm (>=576px)、md (>=768px)、lg (>=992px)、xl (>=1200px)、または xxl (>=1400px)。

propertyプロパティを表し、以下が含まれます。

  • m- 設定に使用margin
  • p- 設定に使用padding

sides主に方向を指します：

  • t- 設定に使用margin-top 或 padding-top
  • b- 設定に使用margin-bottom 或 padding-bottom
  • s- 設定に使用margin-left 或 padding-left
  • e- 設定に使用margin-right 或 padding-right
  • x- 設定に使用*-leftと*-right
  • y- 設定に使用*-topと*-bottom
  • blank - 要素の4方向の設定に使用margin 或 padding

sizeマージンのサイズを指します：

  • 0- 設定margin 或 paddingために0
  • 1- 設定margin 或 paddingために$spacer * .25
  • 2- 設定margin 或 paddingために$spacer * .5
  • 3- 設定margin 或 paddingために$spacer
  • 4- 設定margin 或 paddingために$spacer * 1.5
  • 5- 設定margin 或 paddingために$spacer * 3
  • auto- 設定marginを auto に

一部のマージンのソースコード設定を見てみましょう。

.mt-0 {
  margin-top: 0 !important;
}

.ml-1 {
  margin-left: ($spacer * .25) !important;
}

.px-2 {
  padding-left: ($spacer * .5) !important;
  padding-right: ($spacer * .5) !important;
}

.p-3 {
  padding: $spacer !important;
}

例

<div class="mx-auto" style="width: 200px;">要素を中央揃えに設定</div> <form > <div class="form-row"> <div class="form-group"> <label for="text" class="mt-2">margin-top を設定：</label> <input type="text" class="form-control" id="text" placeholder="email"> <label for="color" class="mt-2">色：</label> <input type="color" id="color" class="form-control" style="width: 60px;padding: 4px;" autocomplete="off" value="#656565"> </div> </div> </form>

試してみる »
