Bootstrap5 サイドバーナビゲーション(Offcanvas)

Bootstrap5 サイドバーはモーダルに似ており、モバイル端末でよく使われます。

スライドナビゲーションの作成

JavaScript を使用して、クラスの後に.offcanvasクラスを追加するかどうかを設定できます。.showクラスを追加することで、サイドバーの表示と非表示を制御します。

  • .offcanvasコンテンツを非表示（デフォルト）
  • .offcanvas.showコンテンツを表示

a リンクのhref属性、または button 要素のdata-bs-target属性を使用してサイドバーを設定します。どちらの場合も使用します。data-bs-toggle="offcanvas"。

スライドナビゲーションの作成例は次のとおりです。

例

<a class="btn btn-primary" data-bs-toggle="offcanvas" href="#offcanvasExample" role="button" aria-controls="offcanvasExample">リンクの href 属性を使用</a> <button class="btn btn-primary" type="button" data-bs-toggle="offcanvas" data-bs-target="#offcanvasExample" aria-controls="offcanvasExample">ボタンで data-bs-target を使用</button> <div class="offcanvas offcanvas-start" tabindex="-1" id="offcanvasExample" aria-labelledby="offcanvasExampleLabel"> <div class="offcanvas-header"> <h5 class="offcanvas-title" id="offcanvasExampleLabel">サイドバー</h5> <button type="button" class="btn-close text-reset" data-bs-dismiss="offcanvas" aria-label="Close"></button> </div> <div class="offcanvas-body"> <div> Some text as placeholder. In real life you can have the elements you have chosen. Like, text, images, lists, etc. </div> <div class="dropdown mt-3"> <button class="btn btn-secondary dropdown-toggle" type="button" id="dropdownMenuButton" data-bs-toggle="dropdown"> Dropdown button </button> <ul class="dropdown-menu" aria-labelledby="dropdownMenuButton"> <li><a class="dropdown-item" href="#">Action</a></li> <li><a class="dropdown-item" href="#">Another action</a></li> <li><a class="dropdown-item" href="#">Something else here</a></li> </ul> </div> </div> </div>

サイドバーの方向

次の4つのクラスでサイドバーの方向を制御できます。

  • .offcanvas-start左側に表示されます。上記の例のとおりです。
  • .offcanvas-end右側に表示
  • .offcanvas-top上部に表示
  • .offcanvas-bottom下部に表示

例

<button class="btn btn-primary" type="button" data-bs-toggle="offcanvas" data-bs-target="#offcanvasTop" aria-controls="offcanvasTop">上部ナビゲーションバー</button> <div class="offcanvas offcanvas-top" tabindex="-1" id="offcanvasTop" aria-labelledby="offcanvasTopLabel"> <div class="offcanvas-header"> <h5 id="offcanvasTopLabel">上部ナビゲーションバーに表示</h5> <button type="button" class="btn-close text-reset" data-bs-dismiss="offcanvas" aria-label="Close"></button> </div> <div class="offcanvas-body"> ... </div> </div>

背景と背景のスクロール可否の設定

サイドバーをポップアップ表示するときに設定できます<body>要素をスクロールできるかどうか、および背景キャンバスを表示するかどうかも設定できます。 使用data-bs-scroll属性で設定します<body>要素をスクロールできるかどうか、data-bs-backdrop背景キャンバスの表示を切り替えます。

例

<button class="btn btn-primary" type="button" data-bs-toggle="offcanvas" data-bs-target="#offcanvasScrolling" aria-controls="offcanvasScrolling">body 要素はスクロール可能</button> <button class="btn btn-primary" type="button" data-bs-toggle="offcanvas" data-bs-target="#offcanvasWithBackdrop" aria-controls="offcanvasWithBackdrop">キャンバスを表示（デフォルト）</button> <button class="btn btn-primary" type="button" data-bs-toggle="offcanvas" data-bs-target="#offcanvasWithBothOptions" aria-controls="offcanvasWithBothOptions">スクロールを許可し、キャンバスを表示</button> <div class="offcanvas offcanvas-start" data-bs-scroll="true" data-bs-backdrop="false" tabindex="-1" id="offcanvasScrolling" aria-labelledby="offcanvasScrollingLabel"> <div class="offcanvas-header"> <h5 class="offcanvas-title" id="offcanvasScrollingLabel">本文コンテンツはスクロール可能</h5> <button type="button" class="btn-close text-reset" data-bs-dismiss="offcanvas" aria-label="Close"></button> </div> <div class="offcanvas-body"> <p>ページをスクロールして効果を確認してください。</p> </div> </div> <div class="offcanvas offcanvas-start" tabindex="-1" id="offcanvasWithBackdrop" aria-labelledby="offcanvasWithBackdropLabel"> <div class="offcanvas-header"> <h5 class="offcanvas-title" id="offcanvasWithBackdropLabel">背景キャンバスを使用</h5> <button type="button" class="btn-close text-reset" data-bs-dismiss="offcanvas" aria-label="Close"></button> </div> <div class="offcanvas-body"> <p>本文コンテンツはスクロール不可</p> </div> </div> <div class="offcanvas offcanvas-start" data-bs-scroll="true" tabindex="-1" id="offcanvasWithBothOptions" aria-labelledby="offcanvasWithBothOptionsLabel"> <div class="offcanvas-header"> <h5 class="offcanvas-title" id="offcanvasWithBothOptionsLabel">背景キャンバスを使用し、本文コンテンツはスクロール可能</h5> <button type="button" class="btn-close text-reset" data-bs-dismiss="offcanvas" aria-label="Close"></button> </div> <div class="offcanvas-body"> <p>ページをスクロールして効果を確認してください。</p> </div> </div>
