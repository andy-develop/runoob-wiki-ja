Ollama 関連コマンド

Ollama は、ユーザーがローカルで実行中のモデルと対話するためのさまざまなコマンドラインツール（CLI）を提供します。

基本形式：

ollama <command> [args]

次のコマンドを使用してollama --help含まれるコマンドを確認できます：

Large language model runner

Usage:
  ollama [flags]
  ollama [command]

Available Commands:
  serve       Start ollama
  create      Create a model from a Modelfile
  show        Show information for a model
  run         Run a model
  stop        Stop a running model
  pull        Pull a model from a registry
  push        Push a model to a registry
  list        List models
  ps          List running models
  cp          Copy a model
  rm          Remove a model
  help        Help about any command

Flags:
  -h, --help      help for ollama
  -v, --version   Show version information

1、使用方法

  • ollama [flags]：フラグ（flags）を使用して ollama を実行します。

  • ollama [command]：ollama の特定のコマンドを実行します。

2、利用可能なコマンド

  • serve：ollama サービスを起動します。
  • create：Modelfile に基づいてモデルを作成します。
  • show：特定のモデルの詳細情報を表示します。
  • run：モデルを実行します。
  • stop：実行中のモデルを停止します。
  • pull：モデルレジストリ（registry）からモデルを取得します。
  • push：モデルをモデルレジストリにプッシュします。
  • list：すべてのモデルを一覧表示します。
  • ps：実行中のすべてのモデルを一覧表示します。
  • cp：モデルをコピーします。
  • rm：モデルを削除します。
  • help：任意のコマンドに関するヘルプ情報を取得します。

3、フラグ（Flags）

  • -h, --help：ollama のヘルプ情報を表示します。
  • -v, --version：バージョン情報を表示します。

完全な例：

コマンド (Command) 説明 (Description) 例 (Example)
ollama run モデルの実行。存在しない場合は自動的に取得します。 ollama run llama3
ollama pull モデルの取得。リポジトリからモデルをダウンロードしますが、実行はしません。 ollama pull mistral
ollama list モデルの一覧表示。ローカルにダウンロード済みのすべてのモデルを表示します。 ollama list
ollama rm モデルの削除。ローカルモデルを削除してスペースを解放します。 ollama rm llama3
ollama cp モデルのコピー。既存のモデルを新しい名前でコピーします（テスト用）。 ollama cp llama3 my-model
ollama create モデルの作成。Modelfile に基づいてカスタムモデルを作成します（上級）。 ollama create my-bot -f ./Modelfile
ollama show 情報の表示。モデルのメタデータ、パラメータ、または Modelfile を確認します。 ollama show --modelfile llama3
ollama ps プロセスの確認。現在実行中のモデルと GPU メモリ使用量を表示します。 ollama ps
ollama push モデルのプッシュ。カスタムモデルを ollama.com にアップロードします。 ollama push my-username/my-model
ollama serve サービスの起動。Ollama の API サービスを起動します（通常はバックグラウンドで自動実行されます）。 ollama serve
ollama help ヘルプ。任意のコマンドのヘルプ情報を確認します。 ollama help run

1. モデルの取得と削除

pull
リモートモデルをローカルに取得します。

ollama pull <model>

rm / remove
ローカルモデルを削除します。

ollama rm <model>

list / ls
すべてのローカルモデルを一覧表示します。

ollama list

2. モデルの実行

run
対話モードでモデルを実行し、終了しません。

ollama run <model>

システム情報とプロンプトを指定できます：

ollama run <model> -s "<system>" -p "<prompt>"

run + script
ファイルからプロンプトを読み取ります：

ollama run <model> < input.txt

次のように入力するとollama runチャットインターフェースに入ると、コマンドラインを操作しているのではなく、AI と対話しています。このとき、次の接頭辞で始まる/ショートカットコマンドを使用して対話を制御できます：

  • /bye 或 /exit：最も重要！チャットインターフェースを終了してコマンドラインに戻ります。
  • /clear：現在のコンテキストメモリをクリアします（新しい会話を開始します）。
  • /show info：現在のモデルの詳細なパラメータ情報を表示します。
  • /set parameter seed 123：ランダムシードを設定します（上級者向け、結果を再現するために使用）。
  • /help：チャットで利用可能なすべてのショートカットキーを表示します。

3. 推論インターフェース（一回限りの実行）

generate
単回の推論を実行し、テキストを出力します。

ollama generate <model> -p "<prompt>"

4. モデルの作成と変更

create
Modelfile を使用してローカルモデルを作成します。

ollama create <model-name> -f Modelfile

cp
モデルを新しい名前でコピーします。

ollama cp <src> <dst>

5. サーバー関連

serve
Ollama ローカルサービスを起動します（デフォルト 11434）。

ollama serve

run serverless
当 ollama runのときにバックグラウンドサービスが自動的に起動されるため、個別に実行する必要はありません。

6. モデル情報

show
モデルのメタデータ、パラメータ、テンプレートを表示します。

ollama show <model>

7. 専用パラメータ

これらのパラメータのほとんどは run/generate で使用できます：

--num-predict <number>    限制输出 token 数
--temperature <float>     控制随机性
--top-k <int>             采样范围
--top-p <float>           核采样
--seed <int>              固定随机性
--format json             输出 JSON
--keepalive <seconds>     会话保持时间

8. Modelfile ディレクティブ

モデル構築時に使用します：

  • FROM <model>：ベースモデル
  • SYSTEM "xxx"：システムプロンプトを設定
  • PARAMETER key=value：デフォルトパラメータを設定
  • TEMPLATE "xxx"：カスタム Chat テンプレート
  • LICENSE "xxx"：ライセンスを設定
  • ADAPTER <file> / WEIGHTS <file>：LoRA または追加の重みを読み込み

9. API（serve 実行時）

REST エンドポイントhttp://localhost:11434/api：

  • /api/generate：テキスト生成
  • /api/chat：対話ストリーミングインターフェース
  • /api/pull：リモートからの取得
  • /api/tags：ローカルモデル一覧

呼び出し例（curl）：

curl http://localhost:11434/api/generate \
  -d '{"model":"qwen2.5","prompt":"hello"}'

10. 上級

カスタムパラメータで実行：

ollama run <model> --temperature 0.2 --top-p 0.9

永続セッション（コンテキスト保持）：
セッションはモデル内部のキャッシュによって自動管理されるため、追加のコマンドは不要です。
