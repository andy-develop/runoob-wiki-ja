Chart.js の使用

Chart.js インストール

Chart.js はさまざまなインストール方法を提供しており、異なる開発シーンに適しています：

  • NPM/Yarn - ビルドツールを使用するプロジェクト開発に適しています
  • CDN - 迅速なプロトタイプ開発や学習に適しています
  • GitHub - 最新機能が必要な場合やコントリビュート（貢献）する開発に適しています

1. NPM/Yarn によるインストール

NPM (Node Package Manager) は JavaScript のパッケージ管理ツールであり、現代のフロントエンドプロジェクト開発に適しています。

インストール手順

# 使用 npm 安装
npm install chart.js

# 或者使用 yarn 安装
yarn add chart.js

プロジェクトでの導入

インストールが完了したら、JavaScript ファイルで次のように Chart.js を導入できます：

例

// Chart.js ライブラリ全体をインポート
import Chart from 'chart.js/auto';

// または必要に応じて特定のチャートタイプをインポート（バンドルサイズを削減）
import { Line } from 'chart.js';

バージョン管理

特定のバージョンの Chart.js をインストールするには、バージョン番号を指定します：

npm install chart.js@3.9.1

2. CDN を使用する

CDN (Content Delivery Network) は、ネットワーク経由でライブラリファイルを直接読み込む方法であり、迅速なプロトタイプ開発に適しています。

推奨 CDN アドレス

<!-- 字节跳动 CDN（国内推荐） -->
<script src="&lt.html"https://lf6-cdn-tos.bytecdntp.com/cdn/expire-1-M/Chart.js/3.7.1/chart.min.js"></script>"></script>

<!-- Staticfile CDN（国内备选） -->
<script src="https://cdn.staticfile.net/Chart.js/3.9.1/chart.min.js"></script>

<!-- cdnjs CDN（海外推荐） -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/Chart.js/3.9.1/chart.min.js"></script>

例

<!DOCTYPE html>
<html>
<head>
    <title>Chart.js CDN の例</title>
    <!-- Chart.js を導入 -->
   <script src="<script src="https://lf6-cdn-tos.bytecdntp.com/cdn/expire-1-M/Chart.js/3.7.1/chart.min.js"></script>"></script>
</head>
<body>
    <div style="width: 600px; height: 400px;">
        <canvas id="myChart"></canvas>
    </div>

    <script>
// canvas 要素を取得
        const ctx = document.getElementById('myChart').getContext('2d');
       
// チャートを作成
        const myChart = new Chart(ctx, {
type: 'bar', // チャートタイプ
            data: {
labels: ['1月', '2月', '3月', '4月', '5月', '6月'],
                datasets: [{
label: '月間売上高',
                    data: [12, 19, 3, 5, 2, 3],
                    backgroundColor: 'rgba(54, 162, 235, 0.5)'
                }]
            },
            options: {
responsive: true, // レスポンシブデザイン
                scales: {
                    y: {
beginAtZero: true // y軸は0から始まる
                    }
                }
            }
        });
    </script>
</body>
</html>

3. GitHub から取得する

GitHub はオープンソースプロジェクトのホスティングプラットフォームであり、最新機能が必要な開発者やプロジェクトへのコントリビュートを希望する開発者に適しています。

取得方法

リポジトリをクローン（Git が必要）：

git clone https://github.com/chartjs/Chart.js.git

ZIP ファイルのダウンロード

  • アクセスChart.js GitHub
  • "Code" ボタンをクリック
  • "Download ZIP" を選択

プロジェクトのビルド

ダウンロード後、独自の Chart.js バージョンをビルドできます：

cd Chart.js
npm install
npm run build

ビルドが完了すると、dist/ ディレクトリに生成されたファイルがあります。
