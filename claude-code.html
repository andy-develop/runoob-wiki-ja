Claude Code チュートリアル

Claude Code は Anthropic が提供する、開発者向けの AI プログラミングコラボレーションツールです。

Claude Code はチャットではなく、ローカルコードリポジトリ内で高権限かつコンテキスト認識型のエンジニアリングタスクを実行することを目的としています。

Claude Code はチャットウィンドウでコードを数行書くのとは異なり、プロジェクト全体を理解し、ファイルを直接読み取り、テストを実行し、フィードバックに基づいてコードを修正できます。

Claude Code はコード生成ツールではなく、プロジェクトを読み、コンテキストを理解し、制約を守る AI プログラミングパートナーです。

Claude Code は Agent（エージェントツール）であり、Chat（チャットツール）ではありません。

このチュートリアルは誰向けですか？

  • 少なくとも 1 つのプログラミング言語（JavaScript / Python / Java / Go など）を学習したことがある方
  • 基本的な構文、関数、条件分岐、ループを理解できる方
  • 簡単なプロジェクトや練習用コードを書いたことがある方
  • AI を活用して開発効率とエンジニアリング能力を向上させたい方
  • 独立系開発者、またはプロジェクトを長期的にメンテナンスする必要があるエンジニア
  • 技術責任者またはチームの中核メンバー

必要な基礎スキル

  • 基本的なプログラミングスキル（簡単なコードを読み書きできる）
  • 基本的なコードの読み取り・理解能力
  • 一般的な開発ツール（エディタ、コマンドライン）を使用できる
  • AI に完全に依存するのではなく、コードを理解しようとする姿勢

Claude Code vs. ウェブ版Claude

特徴 Claude ウェブ版 / アプリ Claude Code (CLI)
インタラクション方式 コードをコピー＆ペーストしてダイアログに入力 ターミナルで直接コマンドにより操作
ファイルアクセス 手動でファイルをアップロード 自動プロジェクトディレクトリ全体の読み取り/検索
実行能力 テキスト生成のみ 実行Shell コマンド、テスト実行、ファイル作成
コンテキスト認識 限られた会話コンテキスト プロジェクト構造と Git 履歴を深く認識
