Go fmt.Sprintf フォーマット文字列

Go 言語の基本構文

Go は fmt.Sprintf を使用して文字列をフォーマットできます。形式は次のとおりです：

fmt.Sprintf(格式化样式, 参数列表…)
  • フォーマット様式：文字列形式では、フォーマット記号は%で始まり、%s は文字列形式、%d は10進数の整数形式です。
  • パラメータリスト：複数のパラメータはカンマで区切ります。数はフォーマット様式の数と1対1で対応する必要があります。そうしないと実行時にエラーになります。

例

package main


import (
    "fmt"
    "io"
    "os"
)


func main() {
    // Go で文字列をフォーマットして新しい文字列に代入するには、fmt.Sprintf を使用します
    // %s は文字列を表します
    var stockcode="000987"
    var enddate="2020-12-31"
    var url="Code=%s&endDate=%s"
    var target_url=fmt.Sprintf(url,stockcode,enddate)
    fmt.Println(target_url)

    // もう一つの例、%d は整数型を表します
    const name, age = "Kim", 22
    s := fmt.Sprintf("%s is %d years old.\n", name, age)
    io.WriteString(os.Stdout, s) // 簡単のため、一部のエラーは無視します
}

出力結果は次のとおりです：

Code=000987&endDate=2020-12-31
Kim is 22 years old.

例

package main
import (
    "fmt"
    "io"
    "os"
)
func main() {
 
    // 数値変数を宣言します
    const num1, num2, num3 = 5, 10, 15
 
    // Sprintf() 関数を呼び出します
    s := fmt.Sprintf("%d + %d = %d", num1, num2, num3)
 
    // WriteString() 関数を使用して結果を端末に出力します to write the
    // "os.Stdout" は文字列の内容です
    io.WriteString(os.Stdout, s)
 
}

出力結果は次のとおりです：

5 + 10 = 15

Go 文字列フォーマット記号：

形式 説明
%v 値の本来の値で出力する
%+v %v に基づいて、構造体のフィールド名と値を展開します
%#v Go 言語の構文形式の値を出力します
%T Go 言語の構文形式の型と値を出力します
%% % そのものを出力します
%b 整数型を2進数で表示します
%o 整数型を8進数で表示します
%d 整数型を10進数で表示します
%x 整数型を16進数で表示します
%X 整数型を16進数、大文字で表示します
%U Unicode 文字
%f 浮動小数点数
%p ポインタ、16進数で表示します

例

package main

import "fmt"

func main() {
    name := "John"
    age := 30
    height := 175.5

    result := fmt.Sprintf("Name: %s, Age: %d, Height: %.2f", name, age, height)
    fmt.Println(result)
}

上記の例では、フォーマット文字列 "Name: %s, Age: %d, Height: %.2f" の %s、%d、%.2f はそれぞれ name、age、height 変数の値に置き換えられます。ここで%.2fは小数第2位までを保持する浮動小数点形式を表します。

出力結果は次のとおりです：

Name: John, Age: 30, Height: 175.50

%.2fは浮動小数点数のフォーマットオプションであり、浮動小数点数の小数精度を制御するために使用されます。ここで2は保持する小数桁数を表します。必要に応じて変更できます。

整列方法

フォーマット文字列で幅と整列パラメータを使用することで、生成される文字列の整列方法を制御できます。

一般的に使用される整列パラメータは次のとおりです：

  • %s：文字列形式では、以下の整列パラメータを使用できます：
    • %s：デフォルトの整列方法は左揃えです。
    • %10s：幅を10として右揃えにします。
    • %-10s：幅を10として左揃えにします。
  • %d：整数形式では、以下の整列パラメータを使用できます：
    • %d：デフォルトの整列方法は右揃えです。
    • %10d：幅を10として右揃えにします。
    • %-10d：幅を10として左揃えにします。
  • %f：浮動小数点形式では、以下の整列パラメータを使用できます：
    • %f：デフォルトの整列方法は右揃えです。
    • %10f：幅を10として右揃えにします。
    • %-10f：幅を10として左揃えにします。

例

package main

import "fmt"

func main() {
    str := "Hello"
    num := 42
    floatNum := 3.14159

    fmt.Printf("|%s|\n", str)
    fmt.Printf("|%10s|\n", str)
    fmt.Printf("|%-10s|\n", str)

    fmt.Printf("|%d|\n", num)
    fmt.Printf("|%10d|\n", num)
    fmt.Printf("|%-10d|\n", num)

    fmt.Printf("|%f|\n", floatNum)
    fmt.Printf("|%10f|\n", floatNum)
    fmt.Printf("|%-10f|\n", floatNum)
}

出力結果は次のとおりです：

|Hello|
|     Hello|
|Hello     |
|42|
|        42|
|42        |
|3.141590|
|  3.141590|
|3.141590  |
