Go言語 if 文

Go言語の条件文

if 文は、ブール式の後に1つ以上の文が続くことで構成されます。

構文

Goプログラミング言語におけるif文の構文は次のとおりです：

if 布尔表达式 {
   /* 在布尔表达式为 true 时执行 */
}

if は、ブール式が true の場合、その直後の文ブロックが実行され、false の場合は実行されません。

フローチャートは次のとおりです：

実例

if を使用して数値変数の大小を判定します：

実例

package main

import "fmt"

func main() {
   /* ローカル変数を定義 */
   var a int = 10
 
   /* if 文を使用してブール式を判定 */
   if a < 20 {
       /* 条件が true の場合、次の文を実行 */
       fmt.Printf("a は 20 より小さい\n" )
   }
   fmt.Printf("a の値は : %d\n", a)
}

上記のコードの実行結果は次のとおりです：

a 小于 20
a 的值为 : 10

    Go の if にはもう1つ強力な点があります。それは、条件文内で変数を宣言できることです。この変数のスコープはその条件ロジックブロック内のみで、他の場所では有効になりません。次のようになります：

    package main
  
import "fmt"
func main() {
    if num := 9; num < 0 {
        fmt.Println(num, "is negative")
    } else if num < 10 {
        fmt.Println(num, "has 1 digit")
    } else {
        fmt.Println(num, "has multiple digits")
    }
}

    実行結果：

    9 has 1 digit

    if 文使用の tips：

    （1） 条件を括弧で囲む必要はありません

    （2） 中括弧 {} は必須です。たとえ1行の文だけでも存在しなければなりません。

    （3） 左括弧は if または else と同じ行になければなりません。

    （4） if の後、条件文の前に、変数初期化文を追加でき、；で区切ります。

    （5） 戻り値のある関数では、最終的な return を条件文の中に置くことはできません。

    if にはもう1つの形式があります。それは statement というオプションの文部分を含み、この部分は条件判定の前に実行されます。その構文は次のとおりです：

    if statement; condition {  
}

    例：

    package main

import (  
    "fmt"
)

func main() {  
    if num := 10; num % 2 == 0 { // 判断数字是否为偶数
        fmt.Println(num,"偶数") 
    }  else {
        fmt.Println(num,"奇数")
    }
}
