Go言語ループ文

多くの実際の問題には規則性のある反復操作が多く含まれるため、プログラムでは特定の文を繰り返し実行する必要があります。

以下は、ほとんどのプログラミング言語のループプログラムのフローチャートです。

Go言語では、以下の種類のループ処理文が提供されています。

ループの種類 説明
for ループ 文のブロックを繰り返し実行する
ループのネスト for ループの中に1つ以上の for ループをネストする

ループ制御文

ループ制御文は、ループ本体内の文の実行プロセスを制御できます。

GO言語は以下のループ制御文をサポートしています：

制御文 説明
break 文 現在の for ループを中断したり、switch 文から抜け出すためによく使用されます。
continue 文 現在のループの残りの文をスキップし、次の反復に進みます。
goto 文 ラベル付けされた文に制御を移します。

無限ループ

ループ内の条件文が決して false にならない場合、無限ループになります。for ループ文に条件式を1つだけ設定することで、無限ループを実行できます：

サンプル

package main

import "fmt"

func main() {
    for true  {
        fmt.Printf(これは無限ループです。\n");
    }
}

    100 以内の素数を求める、私も最終版を貼っておきます：

    // 打印100内的素数
// 素数定义：在大于1的自然数中，因数只有1和自身的数称为素数。
func t01_test2() {
    const RANGE = 100
    for num := 2; num <= RANGE; num++ {
        // 当前因数 factor 对应的另一个因数就是 num / factor。
        // 当前者大于后者时，可以认为所有因数已经分析完毕。
        for factor := 2; factor <= (num / factor); factor++ {
            //能除尽，则表示 factor 是 num 的一个因子。那么num就不是素数。
            if num%factor == 0 {
                goto NEXT_NUM
            }
        }
        fmt.Printf("%d\t是素数\n", num)
    NEXT_NUM:
    }
}
