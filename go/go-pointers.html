Go言語ポインタ

Go言語のポインタは非常に簡単に学べます。Go言語でポインタを使用すると、いくつかのタスクをより簡単に実行できます。

次に、Go言語のポインタを段階的に学んでいきましょう。

ご存知のとおり、変数はコンピュータのメモリアドレスを参照するための便利なプレースホルダーです。

Go言語のアドレス演算子は & で、変数の前につけるとその変数のメモリアドレスを返します。

次の例は、メモリ内の変数のアドレスを示しています：

例

package main

import "fmt"

func main() {
   var a int = 10  

   fmt.Printf("変数のアドレス: %x\n", &a  )
}

上記のコードを実行すると、出力結果は次のとおりです：

变量的地址: 20818a220

これで、メモリアドレスとは何か、そしてそれにアクセスする方法を理解しました。次に、ポインタについて具体的に説明します。

ポインタとは

ポインタ変数は、値のメモリアドレスを指します。

変数や定数と同様に、ポインタを使用する前にポインタを宣言する必要があります。ポインタの宣言形式は次のとおりです：

var var_name *var-type

var-type はポインタ型、var_name はポインタ変数名、* は変数がポインタであることを指定します。以下は有効なポインタ宣言です：

var ip *int        /* 指向整型*/
var fp *float32    /* 指向浮点型 */

この例では、これは int と float32 を指すポインタです。

ポインタの使用方法

ポインタの使用手順：

  • ポインタ変数を定義します。
  • ポインタ変数に値を代入します。
  • ポインタ変数が指すアドレスの値にアクセスします。

ポインタ型の前に *（プレフィックス）を付けると、ポインタが指す内容を取得できます。

例

package main

import "fmt"

func main() {
   var a int= 20   /* 実際の変数を宣言 */
   var ip *int        /* ポインタ変数を宣言 */

   ip = &a  /* ポインタ変数の格納アドレス */

   fmt.Printf("a 変数のアドレスは: %x\n", &a  )

   /* ポインタ変数の格納アドレス */
   fmt.Printf("ip 変数に格納されたポインタアドレス: %x\n", ip )

   /* ポインタを使用して値にアクセス */
   fmt.Printf("*ip 変数の値: %d\n", *ip )
}

上記の例を実行すると、出力結果は次のとおりです：

a 变量的地址是: 20818a220
ip 变量储存的指针地址: 20818a220
*ip 变量的值: 20

Go ヌルポインタ

ポインタが定義されてもどの変数にも割り当てられていない場合、その値は nil です。

nil ポインタはヌルポインタとも呼ばれます。

nil は概念的には他の言語の null、None、nil、NULL と同じで、ゼロ値または空値を指します。

ポインタ変数は通常、ptr と略されます。

次の例を参照してください：

例

package main

import "fmt"

func main() {
   var  ptr *int

   fmt.Printf("ptr の値 : %x\n", ptr  )
}

上記の例の出力結果は次のとおりです：

ptr 的值为 : 0

ヌルポインタの判定：

if(ptr != nil)     /* ptr 不是空指针 */
if(ptr == nil)    /* ptr 是空指针 */
