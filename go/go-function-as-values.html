Go言語の関数を実引数として渡す

Goの関数

Go言語では、関数はファーストクラスシチズン（First-class citizen）であり、通常の変数と同じように代入、受け渡し、使用ができます。関数を実引数として別の関数に渡すことは、Goでよく使われるプログラミングパターンであり、コールバックやストラテジーパターンなどの場面でよく利用されます。

関数を変数に代入する

関数は変数に代入でき、その変数を介して関数を呼び出すことができます：

実例

package main

import (
    "fmt"
    "math"
)

func main() {
    /* 匿名関数を変数 getSquareRoot に代入する */
    getSquareRoot := func(x float64) float64 {
        return math.Sqrt(x)
    }

    /* 変数を介して関数を呼び出す */
    fmt.Println(getSquareRoot(9))   // 出力：3
    fmt.Println(getSquareRoot(16))  // 出力：4
}

上記のコードの実行結果は次のとおりです：

3
4

関数を実引数として渡す

関数を実引数として別の関数に渡す場合、受け取り側は対応する関数型のパラメータを宣言する必要があります。次の例では、ある関数を定義しています。applyその関数は、操作関数と2つのオペランドを受け取り、2つの数値に対して任意に指定された操作を実行します：

実例

package main

import (
    "fmt"
    "math"
)

/* 関数型のパラメータ op を受け取る関数を定義する */
/* op の型は func(float64, float64) float64 で、2つの float64 パラメータを受け取り float64 を返す関数を表す */
func apply(op func(float64, float64) float64, a, b float64) float64 {
    return op(a, b)
}

func main() {
    /* 加算関数を定義する */
    add := func(a, b float64) float64 {
        return a + b
    }

    /* 乗算関数を定義する */
    multiply := func(a, b float64) float64 {
        return a * b
    }

    /* add 関数を実引数として apply に渡す */
    fmt.Println(apply(add, 3, 4))       // 出力：7

    /* multiply 関数を実引数として apply に渡す */
    fmt.Println(apply(multiply, 3, 4))  // 出力：12

    /* 匿名関数を直接渡すこともできる */
    fmt.Println(apply(func(a, b float64) float64 {
        return math.Pow(a, b) // a の b 乗
    }, 2, 10))                          // 出力：1024
}

上記のコードの実行結果は次のとおりです：

7
12
1024

実際の応用：カスタムソートルール

関数を実引数として使う最も一般的な応用の1つは、カスタムソートルールです。Go標準ライブラリのsort.Slicesort.Slice は比較関数をパラメータとして受け取ります：

実例

package main

import (
    "fmt"
    "sort"
)

func main() {
    nums := []int{5, 2, 8, 1, 9, 3}

    /* 比較関数を実引数として sort.Slice に渡し、小さい順にソートする */
    sort.Slice(nums, func(i, j int) bool {
        return nums[i] < nums[j]
    })
    fmt.Println("昇順：", nums)  // 出力：昇順：[1 2 3 5 8 9]

    /* 異なる比較関数を渡して、大きい順にソートする */
    sort.Slice(nums, func(i, j int) bool {
        return nums[i] > nums[j]
    })
    fmt.Println("降順：", nums)  // 出力：降順：[9 8 5 3 2 1]
}

上記のコードの実行結果は次のとおりです：

升序：[1 2 3 5 8 9]
降序：[9 8 5 3 2 1]

異なる関数を実引数として渡すことで、同じ sort.Slice でsort.Sliceまったく異なるソートロジックを実現できます。これこそが、関数を実引数として渡すことの核心的な価値です——動作をパラメータ化し、コードをより柔軟で再利用可能にする。
