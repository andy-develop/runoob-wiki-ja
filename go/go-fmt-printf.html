Go fmt.Printf フォーマット文字列

Go 言語の基本構文

fmt.Printf は Go 言語における強力な出力フォーマット関数であり、主に文字列をフォーマットして結果を標準出力（通常はコンソール）に出力するために使用されます。

fmt.Printf は指定されたフォーマット文字列に従って後続の変数をフォーマットします。構文は次のとおりです：

fmt.Printf(格式化样式, 参数列表…)
  • フォーマットスタイル：文字列形式で、フォーマット記号は%で始まります。%s は文字列形式、%d は10進数の整数形式です。
  • パラメータリスト：複数のパラメータはカンマで区切られ、その数はフォーマットスタイル内の数と1対1で対応する必要があります。そうしないと実行時にエラーが発生します。

実例

package main

import (
   "fmt"
   "strings"
)


func main() {
  name := "John Doe"
  age := 27

  // 文字列を小文字で出力する
  fmt.Printf("hello, %s\n", strings.ToLower(name))

  // 文字列を大文字で出力する
  fmt.Printf("hello, %s\n", strings.ToUpper(name))

  // 年齢を10進数で出力する
  fmt.Printf("%s is %d years old\n", name, age)

  // 年齢を小数第2位までの浮動小数点数として出力する
  fmt.Printf("%s is %.2f years old\n", name, age)
}

出力結果は次のとおりです：

hello, John Doe
hello, JOHN DOE
John Doe is 27 years old
John Doe is %!f(int=27) years old

Go 文字列フォーマット記号：

フォーマット記号説明例
一般的な形式
%vデフォルト形式で変数を出力fmt.Printf("%v", 42)
%+v構造体にフィールド名を付けて出力fmt.Printf("%+v", struct{A int}{A: 42})
%#vGo の構文でフォーマットして出力fmt.Printf("%#v", map[string]int{"a": 1})
%T値の型を出力fmt.Printf("%T", 42)
%%パーセント記号を出力fmt.Printf("%%")
ブール値
%t出力true 或 falsefmt.Printf("%t", true)
整数
%b2進数表現fmt.Printf("%b", 5)
%cUnicode 対応文字fmt.Printf("%c", 65)
%d10進数表現fmt.Printf("%d", 42)
%o8進数表現fmt.Printf("%o", 10)
%x16進数表現（小文字英字）fmt.Printf("%x", 15)
%X16進数表現（大文字英字）fmt.Printf("%X", 15)
%UUnicode 形式で出力fmt.Printf("%U", 65)
浮動小数点数
%f10進浮動小数点数fmt.Printf("%f", 3.14)
%e科学表記法（小文字の e）fmt.Printf("%e", 3.14)
%E科学表記法（大文字の E）fmt.Printf("%E", 3.14)

%s通常の文字列fmt.Printf("%s", "Go")
%q二重引用符付きの文字列または文字fmt.Printf("%q", "Go")
%x各バイトを2文字の16進数で表現fmt.Printf("%x", "abc")
%X16進数（大文字）表現fmt.Printf("%X", "abc")
ポインタ
%pポインタのアドレスfmt.Printf("%p", &x)

フォーマット文字列は通常のテキストとフォーマットプレースホルダで構成されます。

フォーマットプレースホルダは% で始まり、その後に1つ以上の文字が続いてフォーマットの種類を示します。

フォーマットプレースホルダの構造は次のとおりです：

%[flags][width][.precision]verb
  • flags：フォーマット出力を制御するためのフラグ（オプション）。
    • -：左揃え。
    • +：数値の符号を常に表示。
    • 0：ゼロで埋める。
    • #：2進数、8進数、16進数などに接頭辞を付ける。
    • スペース：正数の前にスペースを追加し、負数の前に-。
  • width：出力幅（オプション）。
  • .precision：浮動小数点数の小数点以下の桁数（オプション）。
  • verb：データのフォーマット方法を指定するために使用します。

1. 整数のフォーマット

fmt.Printf("十进制: %d, 二进制: %b, 八进制: %o, 十六进制: %x\n", 42, 42, 42, 42)
// 输出：十进制: 42, 二进制: 101010, 八进制: 52, 十六进制: 2a

2. 浮動小数点数のフォーマット

fmt.Printf("普通: %f, 科学计数法: %e, 自动: %g\n", 123.456, 123.456, 123.456)
// 输出：普通: 123.456000, 科学计数法: 1.234560e+02, 自动: 123.456

3. 文字列のフォーマット

fmt.Printf("普通字符串: %s, 带引号: %q, 十六进制: %x\n", "Go", "Go", "Go")
// 输出：普通字符串: Go, 带引号: "Go", 十六进制: 476f

4. 幅と揃えを使用する

fmt.Printf("|%10s|%-10s|\n", "right", "left")
// 输出：|     right|left      |

5. 構造体のフォーマット

type User struct {
    Name string
    Age  int
}
user := User{Name: "Alice", Age: 30}
fmt.Printf("默认: %v\n带字段名: %+v\nGo语法: %#v\n", user, user, user)
// 输出：
// 默认: {Alice 30}
// 带字段名: {Name:Alice Age:30}
// Go语法: main.User{Name:"Alice", Age:30}

6. ブール値のフォーマット

fmt.Printf("布尔值: %t, %t\n", true, false)
// 输出：布尔值: true, false

実例

package main

import (
    "fmt"
    "os"
)

type point struct {
    x, y int
}

func main() {

    p := point{1, 2}
    fmt.Printf("%v\n", p)

    fmt.Printf("%+v\n", p)

    fmt.Printf("%#v\n", p)

    fmt.Printf("%T\n", p)

    fmt.Printf("%t\n", true)

    fmt.Printf("%d\n", 123)

    fmt.Printf("%b\n", 14)

    fmt.Printf("%c\n", 33)

    fmt.Printf("%x\n", 456)

    fmt.Printf("%f\n", 78.9)

    fmt.Printf("%e\n", 123400000.0)
    fmt.Printf("%E\n", 123400000.0)

    fmt.Printf("%s\n", "\"string\"")

    fmt.Printf("%q\n", "\"string\"")

    fmt.Printf("%x\n", "hex this")

    fmt.Printf("%p\n", &p)

    fmt.Printf("|%6d|%6d|\n", 12, 345)

    fmt.Printf("|%6.2f|%6.2f|\n", 1.2, 3.45)

    fmt.Printf("|%-6.2f|%-6.2f|\n", 1.2, 3.45)

    fmt.Printf("|%6s|%6s|\n", "foo", "b")

    fmt.Printf("|%-6s|%-6s|\n", "foo", "b")

    s := fmt.Sprintf("a %s", "string")
    fmt.Println(s)

    fmt.Fprintf(os.Stderr, "an %s\n", "error")
}
