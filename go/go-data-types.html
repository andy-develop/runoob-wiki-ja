Go言語データ型

Goプログラミング言語では、データ型は関数と変数を宣言するために使用されます。

データ型が登場したのは、データを必要なメモリサイズが異なるデータに分類するためです。プログラミング時に大きなデータが必要な場合にのみ大きなメモリを申請すればよいので、メモリを十分に活用できます。

Go言語には、カテゴリ別に以下のデータ型があります。

番号型と説明
1ブール型
ブール型の値は、定数 true または false のみです。簡単な例：var b bool = true。
2数値型
整数型 int と浮動小数点型 float32、float64。Go言語は整数型と浮動小数点型の数値をサポートし、複素数もサポートしています。ビット演算には補数を使用します。
3文字列型：
文字列とは、固定長の文字が連結された文字シーケンスです。Goの文字列は、単一のバイトが連結されて構成されています。Go言語の文字列のバイトは、UTF-8エンコーディングを使用してUnicodeテキストを表します。
4派生型：
以下を含みます：
  • (a) ポインタ型（Pointer）
  • (b) 配列型
  • (c) 構造体型（struct）
  • (d) チャネル型（Channel）
  • (e) 関数型
  • (f) スライス型
  • (g) インターフェース型（interface）
  • (h) マップ型（Map）

数値型

Goにはアーキテクチャベースの型もあります。例：int、uint、uintptr。

番号型と説明
1uint8
符号なし8ビット整数型（0〜255）
2uint16
符号なし16ビット整数型（0〜65535）
3uint32
符号なし32ビット整数型（0〜4294967295）
4uint64
符号なし64ビット整数型（0〜18446744073709551615）
5int8
符号付き8ビット整数型（-128〜127）
6int16
符号付き16ビット整数型（-32768〜32767）
7int32
符号付き32ビット整数型（-2147483648〜2147483647）
8int64
符号付き64ビット整数型（-9223372036854775808〜9223372036854775807）

浮動小数点型

番号型と説明
1float32
IEEE-754 32ビット浮動小数点数
2float64
IEEE-754 64ビット浮動小数点数
3complex64
32ビット実数と虚数
4complex128
64ビット実数と虚数

    文字列からスペースと改行を除去する 

    package main  
  
import (  
    "fmt"  
    "strings"  
)  
  
func main() {  
    str := "这里是 www\n.runoob\n.com"  
    fmt.Println("-------- 原字符串 ----------")  
    fmt.Println(str)  
    // 去除空格  
    str = strings.Replace(str, " ", "", -1)  
    // 去除换行符  
    str = strings.Replace(str, "\n", "", -1)  
    fmt.Println("-------- 去除空格与换行后 ----------")  
    fmt.Println(str)  
}

    出力結果は：

    -------- 原字符串 ----------
这里是 www
.runoob
.com
-------- 去除空格与换行后 ----------
这里是www.runoob.com
