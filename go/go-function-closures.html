Go言語の関数クロージャ（匿名関数）

Goの関数

Go言語は匿名関数をサポートしており、クロージャとして使用できます。匿名関数は「インライン」の文または式です。匿名関数の利点は、関数内の変数を直接使用でき、宣言する必要がないことです。

匿名関数は関数名を持たない関数であり、通常は関数の内部で関数を定義するために、または関数のパラメータとして渡すために使用されます。

以下の例では、関数 getSequence() を作成し、別の関数を返します。この関数の目的は、クロージャ内で i 変数をインクリメントすることです。コードは次のとおりです。

例

package main

import "fmt"

func getSequence() func() int {
   i:=0
   return func() int {
      i+=1
     return i  
   }
}

func main(){
   /* nextNumber は関数であり、関数 i は 0 */
   nextNumber := getSequence()  

   /* nextNumber 関数を呼び出すと、i 変数が 1 増加して返されます */
   fmt.Println(nextNumber())
   fmt.Println(nextNumber())
   fmt.Println(nextNumber())
   
   /* 新しい関数 nextNumber1 を作成し、結果を確認します */
   nextNumber1 := getSequence()  
   fmt.Println(nextNumber1())
   fmt.Println(nextNumber1())
}

上記のコードの実行結果は次のとおりです：

1
2
3
1
2

以下の例では、複数の匿名関数を定義し、匿名関数を変数に代入する方法、関数内部で匿名関数を使用する方法、および匿名関数を他の関数にパラメータとして渡す方法を示しています。

例

package main

import "fmt"

func main() {
    // 匿名関数を定義して変数 add に代入します
    add := func(a, b int) int {
        return a + b
    }

    // 匿名関数を呼び出します
    result := add(3, 5)
    fmt.Println("3 + 5 =", result)

    // 関数内部で匿名関数を使用します
    multiply := func(x, y int) int {
        return x * y
    }

    product := multiply(4, 6)
    fmt.Println("4 * 6 =", product)

    // 匿名関数をパラメータとして他の関数に渡します
    calculate := func(operation func(int, int) int, x, y int) int {
        return operation(x, y)
    }

    sum := calculate(add, 2, 8)
    fmt.Println("2 + 8 =", sum)

    // 関数呼び出しの中で直接匿名関数を定義することもできます
    difference := calculate(func(a, b int) int {
        return a - b
    }, 10, 4)
    fmt.Println("10 - 4 =", difference)
}

上記のコードの実行結果は次のとおりです：

3 + 5 = 8
4 * 6 = 24
2 + 8 = 10
10 - 4 = 6

匿名関数の使用はGo言語において非常に柔軟であり、コード構造を簡素化し、コードの可読性を向上させるのに役立ちます。

  fmt.Println(add_func(1, 3))
  fmt.Println(add_func(2, 2))

    fmt.Println(nextNumber())この章は説明が不十分で、例もコードが1行足りないので、補足しておきます。

    package main

import "fmt"

func getSequence() func() int {
   i := 0
   return func() int {
      i += 1
      return i
   }
}

func main() {
   /* nextNumber 为一个函数，函数 i 为 0 */
   nextNumber := getSequence()

   /* 调用 nextNumber 函数，i 变量自增 1 并返回 */
   fmt.Println(nextNumber()) //这个执行结果是1
   fmt.Println(nextNumber()) //这个执行结果是2
   fmt.Println(nextNumber()) //这个执行结果是3

   /* 创建新的函数 nextNumber1，并查看结果 */
   nextNumber1 := getSequence() //当getSequence()被重新赋值之后，nextNumber的值应该销毁丢失的，但并没有
   fmt.Println(nextNumber1()) //这儿因为是新赋值的，所以是1
   fmt.Println(nextNumber()) //这一行代码是补充上例子的。这儿可不是新赋的值，重点说明这一个，这儿执行居然是4，这个值并没有被销毁，原因就是闭包导致的，尽管外面的函数销毁了，但是内部函数仍然存在，还可以继续走。这个就是闭包
   fmt.Println(nextNumber1()) //新赋值的，继续执行是2
}

    出力される結果は次のとおりです：

    1
2
3
1
4
2

    なぜこうなるのか説明すると、これはコールバック関数を持つすべての言語に存在する状況であり、これがクロージャです。
