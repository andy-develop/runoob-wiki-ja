Go言語の定数

定数とは、簡単な値の識別子であり、プログラム実行中に変更されない量です。定数のデータ型は、論理型（ブール型）、数値型（整数型、浮動小数点型、複素数型）、および文字列型のみです。

単語の意味： const 是 constant（定数）の略で、プログラム内で不変の値を表します。

基本構文とパラメータ

定数の定義形式：

const identifier [type] = value

構文の説明

  • identifier：定数名。Goの識別子の命名規則（英字、数字、アンダースコア、および数字で始まらないこと）に従います。
  • type（オプション）：型名。省略した場合はコンパイラが自動的に推論します。
  • value：定数の値。

定義方法

  • 明示的な型定義：const b string = "abc"
  • 暗黙的な型定義：const b = "abc"
  • 一括定義：const c_name1, c_name2 = value1, value2

例

例1：基本的な定数定義

例

package main

import "fmt"

func main() {
   const LENGTH int = 10
   const WIDTH int = 5
   var area int
   const a, b, c = 1, false, "str" // 多重代入

   area = LENGTH * WIDTH
   fmt.Printf("面積は : %d", area)
   println()
   println(a, b, c)
}

期待される実行結果:

面积为 : 50
1 false str

コードの解説:

  1. const LENGTH int = 10整数型定数LENGTHを定義し、値を10とします。
  2. const WIDTH int = 5整数型定数WIDTHを定義し、値を5とします。
  3. const a, b, c = 1, false, "str"多重代入を使用して、異なる型の複数の定数を同時に定義します。
  4. area = LENGTH * WIDTH面積を計算し、変数areaに代入します。

定数グループと列挙

Go言語には列挙（enum）キーワードがありません。通常は定数グループを使用して列挙の効果を実現します：

例

package main

import "fmt"

// 性別の列挙を定義
const (
    Unknown = 0
    Female  = 1
    Male    = 2
)

func main() {
    fmt.Printf("未知=%d, 女性=%d, 男性=%d\n", Unknown, Female, Male)
}

期待される実行結果:

未知=0, 女性=1, 男性=2

コードの解説:

  • 定数グループを使用すると、関連する一連の定数値を定義できます。
  • 数字の0、1、2はそれぞれ、性別不明、女性、男性を表します。

定数における組み込み関数の応用

定数式では、len()、cap()、unsafe.Sizeof()などの組み込み関数を使用して式の値を計算できます。

注意：定数式内の関数は組み込み関数でなければなりません。

例

package main

import (
    "fmt"
    "unsafe"
)

const (
    a = "abc"
    b = len(a)
    c = unsafe.Sizeof(a)
)

func main() {
    fmt.Printf("a=%s, b=%d, c=%d\n", a, b, c)
}

期待される実行結果:

a=abc, b=3, c=16

コードの解説:

  • a = "abc"：文字列定数。
  • b = len(a)：len()を使用して文字列の長さを取得します。結果は3です。
  • c = unsafe.Sizeof(a)：unsafe.Sizeof()を使用して変数のメモリ使用量を取得します。結果は16バイトです（文字列構造体は64ビットシステム上で16バイトを占めます）。

iota定数カウンター

iotaはGo言語の特別な定数で、定数カウンターとも呼ばれます。const宣言ブロック内で自動的に増加する一連の値を生成できます。

重要な特性：

  • iota 在 constキーワードが出現すると、は0にリセットされます。
  • const内で定数宣言が1行追加されるごとに、iotaの自動カウントが1増加します。
  • const文ブロック内の行インデックス（0から開始）と考えることができます。

例1：基本的なiotaの使い方

例

package main

import "fmt"

// iotaは0から始まり、1行ごとに1加算
const (
    a = iota   // 0
    b          // 1（値が省略されているため、デフォルトで前の行のiotaを使用）
    c          // 2
)

func main() {
    fmt.Printf("a=%d, b=%d, c=%d\n", a, b, c)
}

期待される実行結果:

a=0, b=1, c=2

コードの解説:

  • 定数値が省略された場合、デフォルトで前の行のiota値を使用します。
  • したがって、b=1、c=2となります。

例2：iotaの詳細な使い方

例

package main

import "fmt"

func main() {
    const (
        a = iota   // 0
        b          // 1
        c          // 2
        d = "ha"   // 独立した値、iota += 1
        e          // "ha"，iota += 1
        f = 100    // 独立した値、iota += 1
        g          // 100，iota += 1
        h = iota   // 7、iota値の使用を再開
        i          // 8
    )
    fmt.Printf("a=%d, b=%d, c=%d, d=%s, e=%s, f=%d, g=%d, h=%d, i=%d\n", a, b, c, d, e, f, g, h, i)
}

期待される実行結果:

a=0, b=1, c=2, d=ha, e=ha, f=100, g=100, h=7, i=8

コードの解説:

  • 明示的に値を代入する場合はその値を使用しますが、iotaは依然として増加します。
  • 代入を省略した場合は、前の行の値を使用します。
  • 在 h = iotaのときは、iotaの現在の値（7）を使用します。

例3：iotaとシフト演算

例

package main

import "fmt"

const (
    i = 1 << iota  // 1 << 0 = 1
    j = 3 << iota  // 3 << 1 = 6
    k              // 3 << 2 = 12
    l              // 3 << 3 = 24
)

func main() {
    fmt.Printf("i=%d, j=%d, k=%d, l=%d\n", i, j, k, l)
}

期待される実行結果:

i=1, j=6, k=12, l=24

コードの解説:

  • <<は左シフト演算子で、x << nと等価です。x * 2^n。
  • i = 1 << 0 = 1：1を0ビット左シフト、結果は1。
  • j = 3 << 1 = 6：3を1ビット左シフト、2進数の11は110になり、すなわち6。
  • k = 3 << 2 = 12：3を2ビット左シフト、2進数の11は1100になり、すなわち12。
  • l = 3 << 3 = 24：3を3ビット左シフト、2進数の11は11000になり、すなわち24。

補足説明

  • 1 << n = 1 * 2^n
  • 3 << n = 3 * 2^n

    左シフト演算子<<は二項演算子です。nビット左シフトするのは2のn乗を掛けることです。その機能は、<<左側の演算数の各2進ビットをすべて左に指定されたビット数だけシフトし、<<右側の数で移動するビット数を指定します。高位は破棄され、低位には0が詰められます。

    右シフト演算子>>は二項演算子です。nビット右シフトするのは2のn乗で割ることです。その機能は、>>左側の演算数の各2進ビットをすべて右に指定されたビット数だけシフトし、>>右側の数で移動するビット数を指定します。

    Go言語では、文字列型は構造体であり、基盤となるデータへのポインタと文字列の長さを表す整数を含みます。64ビットシステムでは、各ポインタは8バイト、整数は8バイトを占有します。したがって、文字列型は64ビットシステム上で合計16バイトの領域を占有します。

    与えられたコードa = "hello"では、aは文字列型の変数ですが、代入時には実際には文字列"hello"の基盤となるデータを指すポインタがaに代入されます。したがって、unsafe.Sizeof(a)が返すのはポインタのサイズ、すなわち8バイトです。

    そのため、コードa = "hello"; unsafe.Sizeof(a)の実行結果は8です。
