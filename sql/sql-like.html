SQL LIKE演算子

LIKE 演算子は、WHERE句で列内の指定されたパターンを検索するために使用します。

LIKE演算子はSQLにおいてWHERE句で曖昧検索を行うためのキーワードであり、通常は%と_ワイルドカードと一緒に使用されます。

SQL LIKE 構文

SELECT column1, column2, ...
FROM table_name
WHERE column_name LIKE pattern;

パラメータの説明：

  • column1, column2, ...：選択するフィールド名。複数のフィールドを指定できます。フィールド名を指定しない場合は、すべてのフィールドが選択されます。
  • table_name：クエリするテーブル名。
  • column：検索するフィールド名。
  • pattern：検索パターン。

ワイルドカード

  • %：任意の文字（ゼロ文字を含む）に一致します。
  • _：1文字に一致します。

例

Products という名前のテーブルがあり、次のデータが含まれているとします：

ProductIDProductNameCategory
1iPhone 12Electronics
2Samsung Galaxy S21Electronics
3Dell XPS 13Electronics
4Nike Air ZoomFootwear
5Adidas UltraboostFootwear
6Sony PlayStation 5Electronics

使用%ワイルドカードで、"iPhone" で始まるすべての製品を検索します：

SELECT ProductName, Category
FROM Products
WHERE ProductName LIKE 'iPhone%';

次のデータが返されます：

ProductNameCategory
iPhone 12Electronics

使用_ワイルドカードで、製品名の2番目の文字が "e" であるすべての製品を検索します：

SELECT ProductName, Category
FROM Products
WHERE ProductName LIKE '_e%';

次のデータが返されます：

ProductNameCategory
Dell XPS 13Electronics

組み合わせて%と_ワイルドカードで、製品名に "Zoom" を含むすべての製品を検索します：

SELECT ProductName, Category
FROM Products
WHERE ProductName LIKE '%Zoom%';

次のデータが返されます：

ProductNameCategory
Nike Air ZoomFootwear

SQL LIKE 演算子の例

次のSQL文は、name が文字 "G" で始まるすべての顧客を選択します：

例

SELECT * FROM Websites
WHERE name LIKE 'G%';

実行出力結果：

ヒント："%" 記号は、パターンの前後にワイルドカード（デフォルトの文字）を定義するために使用されます。ワイルドカードについては、次の章で詳しく学びます。

次のSQL文は、name が文字 "k" で終わるすべての顧客を選択します：

例

SELECT * FROM Websites
WHERE name LIKE '%k';

次のSQL文は、name にパターン "oo" を含むすべての顧客を選択します：

例

SELECT * FROM Websites
WHERE name LIKE '%oo%';

実行出力結果：

NOT キーワードを使用することで、パターンに一致しないレコードを選択できます。

次のSQL文は、name にパターン "oo" を含まないすべての顧客を選択します：

例

SELECT * FROM Websites
WHERE name NOT LIKE '%oo%';
