SQL 汎用データ型

データ型は、列に格納される値の種類を定義します。

SQL 汎用データ型

データベーステーブルの各列には、名前とデータ型が必要です。

SQL開発者は、SQLテーブルを作成する際に、テーブルの各列が格納するデータの種類を決定する必要があります。データ型はラベルであり、SQLが各列にどのような種類のデータが格納されることを期待しているかを理解するためのガイドであり、SQLが格納されたデータとどのように相互作用するかを識別します。

以下の表に、SQLで一般的なデータ型を示します。

データ型 説明
CHARACTER(n) 文字/文字列。固定長 n。
VARCHAR(n) または
CHARACTER VARYING(n)		 文字/文字列。可変長。最大長 n。
BINARY(n) バイナリ文字列。固定長 n。
BOOLEAN TRUE または FALSE の値を格納します。
VARBINARY(n) または
BINARY VARYING(n)		 バイナリ文字列。可変長。最大長 n。
INTEGER(p) 整数値（小数点なし）。精度 p。
SMALLINT 整数値（小数点なし）。精度 5。
INTEGER 整数値（小数点なし）。精度 10。
BIGINT 整数値（小数点なし）。精度 19。
DECIMAL(p,s) 正確な数値。精度 p、小数点以下の桁数 s。例：decimal(5,2) は、小数点の前に3桁、小数点の後に2桁の数値です。
NUMERIC(p,s) 正確な数値。精度 p、小数点以下の桁数 s。（DECIMAL と同じ）
FLOAT(p) 近似数値。仮数精度 p。10を基数とする指数表記法を用いた浮動小数点数です。この型の size パラメータは、最小精度を指定する単一の数字で構成されます。

TIMESTAMP 年、月、日、時、分、秒の値を格納します。
INTERVAL いくつかの整数フィールドで構成され、間隔の種類に応じて一定の期間を表します。
