SQL さまざまなデータベースで使用されるデータ型

Microsoft Access、MySQL、SQL Server で使用されるデータ型と範囲。

AutoNumber AutoNumber フィールドは各レコードに自動的に番号を割り当てます。通常は 1 から始まります。 4 バイト

MySQL データ型

MySQL には、主に Text（テキスト）、Number（数値）、Date/Time（日付/時刻）の 3 つのタイプがあります。

Text 型：

データ型 説明
CHAR(size) 固定長の文字列を保存（文字、数字、特殊文字を含む）。括弧内で文字列の長さを指定。最大255文字。
VARCHAR(size) 可変長の文字列を保存（文字、数字、特殊文字を含む）。括弧内で文字列の最大長を指定。最大255文字。注釈：値の長さが 255 を超える場合、TEXT 型に変換されます。
TINYTEXT 最大長255文字の文字列を格納。
TEXT 最大長65,535文字の文字列を格納。
BLOB BLOB（Binary Large OBjects）に使用。最大65,535バイトのデータを格納。
MEDIUMTEXT 最大長16,777,215文字の文字列を格納。
MEDIUMBLOB BLOB（Binary Large OBjects）に使用。最大16,777,215バイトのデータを格納。
LONGTEXT 最大長4,294,967,295文字の文字列を格納。
LONGBLOB BLOB（Binary Large OBjects）に使用。最大4,294,967,295バイトのデータを格納。
ENUM(x,y,z,etc.) 可能な値のリストを入力できます。ENUM リストには最大65,535個の値を列挙できます。リストに存在しない値を挿入すると、空の値が挿入されます。

注釈：これらの値は、入力した順序で並べ替えられます。

可能な値は次の形式で入力できます： ENUM('X','Y','Z')
SET ENUM に似ていますが、SET は最大64個のリスト項目しか含めることができず、SET は複数の選択肢を格納できます。

Number 型：

データ型 説明
TINYINT(size) 符号付き -128 から 127、符号なし 0 から 255。
SMALLINT(size) 符号付き範囲 -32768 から 32767、符号なし 0 から 65535、size のデフォルトは 6。
MEDIUMINT(size) 符号付き範囲 -8388608 から 8388607、符号なし範囲は 0 から 16777215。 size のデフォルトは 9。
INT(size) 符号付き範囲 -2147483648 から 2147483647、符号なし範囲は 0 から 4294967295。 size のデフォルトは 11。
BIGINT(size) 符号付き範囲は -9223372036854775808 から 9223372036854775807、符号なし範囲は 0 から 18446744073709551615。 size のデフォルトは 20。
FLOAT(size,d) 浮動小数点数を伴う小さい数値。size パラメータで表示可能な最大桁数を指定。d パラメータで小数点以下の最大桁数を指定。
DOUBLE(size,d) 浮動小数点数を伴う大きな数値。size パラメータで表示可能な最大桁数を指定。d パラメータで小数点以下の最大桁数を指定。
DECIMAL(size,d) 文字列として格納される DOUBLE 型で、固定小数点を許可。size パラメータで表示可能な最大桁数を指定。d パラメータで小数点以下の最大桁数を指定。

注意：上記の size はデータベースに格納される具体的な長さを表すわけではありません。たとえば int(4) は長さ4の数値しか格納できないというわけではありません。

実際、int(size) がどれだけのストレージ容量を占めるかは関係ありません。int(3)、int(4)、int(8) はディスク上ではすべて 4 バイトのストレージ容量を占有します。ユーザーに表示される方法が少し異なるだけで、int(M) は int データ型と同じです。

例：

1、int の値が 10 の場合（zerofill 指定）

int（9）显示结果为000000010
int（3）显示结果为010

表示される長さが異なるだけで、どちらも4バイトの領域を占有します。

Date 型：

データ型 説明
DATE() 日付。形式：YYYY-MM-DD

注釈：サポート範囲は '1000-01-01' から '9999-12-31' まで。
DATETIME() *日付と時刻の組み合わせ。形式：YYYY-MM-DD HH:MM:SS

注釈：サポート範囲は '1000-01-01 00:00:00' から '9999-12-31 23:59:59' まで。
TIMESTAMP() *タイムスタンプ。TIMESTAMP 値は Unix エポック（'1970-01-01 00:00:00' UTC）からの秒数を使用して格納されます。形式：YYYY-MM-DD HH:MM:SS

注釈：サポート範囲は '1970-01-01 00:00:01' UTC から '2038-01-09 03:14:07' UTC まで。
TIME() 時刻。形式：HH:MM:SS

注釈：サポート範囲は '-838:59:59' から '838:59:59' まで。
YEAR() 2桁または4桁形式の年。

注釈：4桁形式で許可される値：1901 から 2155。2桁形式で許可される値：70 から 69。1970 から 2069 を表します。

*DATETIME と TIMESTAMP は同じ形式を返しますが、動作は大きく異なります。INSERT または UPDATE クエリでは、TIMESTAMP は自動的に現在の日付と時刻に設定されます。TIMESTAMP は YYYYMMDDHHMMSS、YYMMDDHHMMSS、YYYYMMDD、YYMMDD などの異なる形式も受け入れます。

String 型：

データ型 説明 格納

varchar(n) 可変長の文字列。最大 8,000 文字。 2 bytes + number of chars
varchar(max) 可変長の文字列。最大 1,073,741,824 文字。 2 bytes + number of chars
text 可変長の文字列。最大 2GB のテキストデータ。 4 bytes + number of chars
nchar 固定長のUnicode文字列。最大4,000文字。 Defined width x 2
nvarchar 可変長のUnicode文字列。最大4,000文字。
nvarchar(max) 可変長のUnicode文字列。最大536,870,912文字。
ntext 可変長のUnicode文字列。最大2GBのテキストデータ。
bit 0、1、またはNULLを許可
binary(n) 固定長のバイナリ文字列。最大8,000バイト。
varbinary 可変長のバイナリ文字列。最大8,000バイト。
varbinary(max) 可変長のバイナリ文字列。最大2GB。
image 可変長のバイナリ文字列。最大2GB。

s パラメータは、小数点の右側に格納される最大桁数を示します。s は 0 から p までの値である必要があります。デフォルトは 0 です。

データ型 説明 ストレージ
