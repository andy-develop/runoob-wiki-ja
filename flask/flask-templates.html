Flask テンプレートレンダリング

Python コードで HTML 文字列を連結するのは煩雑で危険です（XSS 脆弱性を引き起こしやすい）。Flask はこの問題を解決するために Jinja2 テンプレートエンジンを統合しています。

テンプレートを使用すると、ビジネスロジックとページ表示を分離し、より安全で保守しやすいコードを書くことができます。

render_template の基本

render_template()これは Flask で最もよく使われるテンプレートレンダリング関数です。

最初の引数はテンプレートファイル名で、後続のキーワード引数は変数としてテンプレートに渡されます。

例

# ファイルパス：app.py
from flask import Flask, render_template

app = Flask(__name__)

@app.route("/")
def index():
    # templates/index.html テンプレートをレンダリングし、title と name 変数を渡す
    return render_template("index.html", title="RUNOOB ホームページ", name="World")

@app.route("/user/<username>")
def profile(username):
    # URL 内の username をテンプレートに渡す
    return render_template("user.html", username=username, posts=[
        {"title": "Flask 入門", "date": "2026-05-01"},
        {"title": "Jinja2 テンプレート", "date": "2026-05-10"},
    ])

テンプレートファイルはプロジェクトディレクトリ内のtemplates/フォルダーに置きます：

runoob-flask-test/
├── app.py
└── templates/
    ├── index.html
    └── user.html

index.html の内容は次のようになります：

例（ index.html ）

<!-- ファイルパス：templates/index.html -->
<!DOCTYPE html>
<html>
<head>
    <title>{{ title }} - RUNOOB</title>
</head>
<body>
    <h1>{{ title }} </h1>
     <p>Hello {{ name }}。</p>
</body>
</html>

Jinja2 基本構文

Jinja2 テンプレート内の3つの中核構文：

構文 用途 例
{{ ... }} 変数の値を出力し、HTML を自動エスケープする {{ username }}
{% ... %} 制御文（if、for、block など） {% if user %}
{# ... #} コメント。レンダリング結果には表示されない {# これはコメントです #}

テンプレート例

例（ user.html ）

<!-- ファイルパス：templates/user.html -->
<!DOCTYPE html>
<html>
<head>
    <title>{{ username }} - RUNOOB</title>
</head>
<body>
    <h1>{{ username }} の個人ホームページ</h1>

    <!-- 条件分岐：posts リストが空の場合は、案内メッセージを表示する -->
    {% if posts %}
        <h2>最近の記事：</h2>
        <ul>
        <!-- posts リストをループ処理する -->
        {% for post in posts %}
            <!-- loop.index は Jinja2 の組み込み変数で、1 から始まる番号です -->
            <li>{{ loop.index }}. {{ post.title }} ({{ post.date }})</li>
        {% endfor %}
        </ul>
    {% else %}
        <p>記事はまだありません</p>
    {% endif %}

    <!-- フィルターを使用：upper でテキストを大文字に変換 -->
    <p>ユーザー名（大文字）：{{ username|upper }}</p>
</body>
</html>

よく使うフィルター

フィルターは変数の出力形式を変更するために使用します。パイプ記号|で呼び出します。

フィルター 機能 例 出力
upper 大文字に変換 {{ "hello"|upper }} HELLO
lower 小文字に変換 {{ "HELLO"|lower }} hello
title 先頭文字を大文字に {{ "hello world"|title }} Hello World
length 長さを取得 {{ [1,2,3]|length }} 3
default デフォルト値を設定 {{ name|default("匿名") }} 匿名（name が空の場合）
safe 安全な HTML としてマーク（エスケープしない） {{ "太字"|safe }} 太字テキストとしてレンダリング
join リストを連結 {{ ["a","b"]|join(",") }} a,b

セキュリティ警告：safeフィルターは自動エスケープを無効にするため、データの出所を絶対に信頼できる場合のみ使用してください。ユーザー入力の内容には絶対に使用しないでください。safe。

自動エスケープ——XSS 対策

Jinja2 はデフォルトで全ての変数出力を HTML エスケープします。これは Web セキュリティの重要な防御線です。

例えば、ユーザーが送信したユーザー名が<script>alert("xss")</script>の場合、テンプレートレンダリング時に自動的に安全なテキストに変換されます：

<!-- 模板中直接使用变量 -->
<p>{{ username }}</p>

<!-- 渲染结果（HTML 特殊字符已被转义） -->
&lt;p&gt;&amp;lt;script&amp;gt;alert(&amp;quot;xss&amp;quot;)&amp;lt;/script&amp;gt;&lt;/p&gt;

エスケープは.html、.htm、.xml、.xhtml、.svgで終わるテンプレートファイルに適用されます。

テンプレート継承——重複コードを排除する

テンプレート継承は Jinja2 の最も強力な機能の一つで、基本レイアウトを定義し、子テンプレートでコンテンツを埋めることができます。

これにより、各ページでヘッダー、ナビゲーション、フッターなどの共通部分を繰り返し記述することを避けられます。

基本テンプレート（親テンプレート）

例

<!-- ファイルパス：templates/base.html -->
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>{% block title %}RUNOOB Flask チュートリアル{% endblock %}</title>
    <link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
</head>
<body>
    <header>
        <h1>RUNOOB Flask チュートリアル</h1>
        <nav>
            <a href="/">ホーム</a> |
            <a href="/about">概要</a>
        </nav>
    </header>

    <main>
    <!-- block はプレースホルダー領域で、子テンプレートで埋めたり上書きしたりできます -->
    {% block content %}{% endblock %}
    </main>

    <footer>
        <p>&copy; 2026 RUNOOB.com</p>
    </footer>
</body>
</html>

子テンプレート（親テンプレートを継承）

例

<!-- ファイルパス：templates/index.html -->
{% extends "base.html" %}

<!-- 親テンプレートの title block を上書き -->
{% block title %}RUNOOB チュートリアル - ホーム{% endblock %}

<!-- 親テンプレートの content block を埋める -->
{% block content %}
    <h2>RUNOOB へようこそ</h2>
    <p>{{ greeting }}</p>

    {% if user %}
        <p>現在のユーザー：{{ user }}</p>
    {% else %}
        <p><a href="/login">先にログインしてください</a></p>
    {% endif %}
{% endblock %}
タグ 機能
{% extends "base.html" %} 現在のテンプレートが base.html から継承することを宣言（最初の行に置く必要があります）
{% block name %}...{% endblock %} 子テンプレートが上書きできる領域を定義する
{{ super() }} 子テンプレートの block 内で親テンプレートの同名 block の内容を呼び出す

テンプレート継承を使用すれば、変更が必要なのはbase.html1か所だけで、全ページの共通部分（ナビゲーション、フッターなど）が自動的に更新されます。

テンプレート内の組み込みオブジェクト

以下の Flask オブジェクトはテンプレート内で直接使用でき、render_template()渡す必要はありません：

オブジェクト 説明 テンプレートでの使用例
request 現在のリクエストオブジェクト {{ request.path }}
session 現在のセッションデータ {{ session.get("username") }}
g リクエストレベルのグローバル変数 {{ g.user }}
config アプリケーション設定 {{ config["APP_NAME"] }}
url_for() URL生成関数 {{ url_for("index") }}
get_flashed_messages() flash メッセージを取得 {% for msg in get_flashed_messages() %}...

他のテンプレートを含める——include

使用する{% include %}あるテンプレートに別のテンプレートを埋め込むことができます：

例

<!-- ファイルパス：templates/_navbar.html（アンダースコア始まりは部分テンプレートを表します） -->
<nav style="background:#f0f0f0;padding:10px;">
    <a href="/">ホーム</a> |
    <a href="/posts">記事</a> |
    <a href="/about">概要</a>
</nav>

例

<!-- 任意のテンプレートにナビゲーションバーを読み込む -->
<!DOCTYPE html>
<html>
<head><title>ページ</title></head>
<body>
    {% include "_navbar.html" %}

    <h1>ページコンテンツ</h1>
    <p>これはページのメインコンテンツです。</p>
</body>
</html>

ベストプラクティス：テンプレート継承（extends）はページレベルのレイアウト再利用に使用され、includeinclude はコンポーネントレベルのコード再利用に使用されます。ナビゲーションバー、サイドバーなどの再利用可能なコンポーネントは include に適しています。

完全な例：ブログのホームページ

上記の知識を実際のシナリオに統合します：

例

# ファイルパス：app.py
from flask import Flask, render_template

app = Flask(__name__)

@app.route("/")
def index():
    # データベース内の記事データを模擬する
    articles = [
        {"id": 1, "title": "Flask 入門ガイド", "author": "runoob", "views": 1024},
        {"id": 2, "title": "Jinja2 テンプレート解説", "author": "admin", "views": 512},
        {"id": 3, "title": "RESTful API 設計", "author": "runoob", "views": 256},
    ]
    return render_template("blog.html", articles=articles)

例

<!-- ファイルパス：templates/blog.html -->
{% extends "base.html" %}

{% block title %}RUNOOB ブログ{% endblock %}

{% block content %}
    <h2>最新記事</h2>

    {% if articles %}
        {% for article in articles %}
            <!-- 閲覧数に応じて異なるスタイルを追加 -->
            <div class="article" {% if article.views > 1000 %}style="background:#fff3cd;"{% endif %}>
                <h3>{{ article.title }}</h3>
                <p>作者：{{ article.author }} | 閲覧：{{ article.views }}</p>
                <!-- loop 変数を使用して区切り線を実現する -->
                {% if not loop.last %}
                    <hr>
                {% endif %}
            </div>
        {% endfor %}
    {% else %}
        <p>まだ記事がありません。後で再度お越しください。</p>
    {% endif %}
{% endblock %}
