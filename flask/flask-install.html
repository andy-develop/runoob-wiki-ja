Flask インストール

Flask アプリケーションの作成を始める前に、Python 環境を準備し、Flask をインストールする必要があります。

Flask のインストールは比較的簡単です。

Flask は Python のライブラリなので、まずコンピューターに Python がインストールされていることを確認する必要があります。

Python バージョン要件

Flask 3.x の要件Python 3.9 以上。

まだ Python をインストールしていない場合は、python.orgからダウンロードしてインストールしてください。

インストール完了後、ターミナルを開いて確認してください：

$ python3 --version
Python 3.12.3

$ pip3 --version
pip 24.0 from /usr/lib/python3.12/site-packages/pip (python 3.12)

macOS とほとんどの Linux ディストリビューションには Python 3 がプリインストールされています。Windows を使用している場合は、インストール時にAdd Python to PATHオプションにチェックを入れてください。

仮想環境

仮想環境（Virtual Environment）は Python プロジェクトの標準的な方法で、プロジェクトごとに独立した Python パッケージスペースを作成します。

仮想環境を使う理由

2つのプロジェクトがあるとします：プロジェクト A には Flask 3.0 が必要で、プロジェクト B には Flask 2.3 が必要です。

グローバルにインストールすると、2つのバージョンの Flask が互いに競合します。

仮想環境により、各プロジェクトは独立した依存パッケージを持ち、互いに干渉しません。

Python に組み込みのvenvモジュールで仮想環境を作成でき、追加ツールのインストールは不要です。

仮想環境の作成

まずプロジェクトディレクトリを作成し、その中に仮想環境を作成します：

$ mkdir runoob-flask-test
$ cd runoob-flask-test
$ python3 -m venv .venv

.venvは仮想環境のディレクトリ名です。好きな名前に変更できますが、.venvがコミュニティで最も一般的な慣例です。

仮想環境のアクティブ化

オペレーティングシステム アクティブ化コマンド
macOS / Linux . .venv/bin/activate 或 source .venv/bin/activate
Windows (CMD) .venv\Scripts\activate
Windows (PowerShell) .venv\Scripts\Activate.ps1

アクティブ化に成功すると、ターミナルのプロンプトの前に(.venv)という識別表示が現れ、仮想環境が有効であることを示します。

$ . .venv/bin/activate
(.venv) $   # <-- 提示符变了，说明虚拟环境已经激活

仮想環境の終了

開発完了後、deactivateコマンドで終了します：

(.venv) $ deactivate
$

新しいターミナルウィンドウを開くたびに、Flask を使用するには仮想環境を再度アクティブ化する必要があります。

また、Python パッケージと環境管理ツールである uv を使用することもできます。参照：https://www.runoob.com/python3/uv-tutorial.html

# 使用指定 Python 版本创建虚拟环境
uv venv --python 3.12
激活虚拟环境：

# macOS / Linux
source .venv/bin/activate

# Windows（PowerShell）
.venv\Scripts\activate

Flask のインストール

仮想環境がアクティブ化された状態で、pip を使用して Flask をインストールします：

(.venv) $ pip install Flask

インストール完了後、Flask が正常にインストールされたか確認します：

flask --version

出力は以下のような情報になります：

Python 3.9.6
Flask 3.0.0
Werkzeug 3.1.5

以下のコードで確認することもできます：

from importlib.metadata import version

flask_version = version("flask")
print(flask_version)

正常にインストールされると、以下のようなバージョン番号が出力されます：

3.1.3

このとき、以下の依存パッケージも一緒にインストールされます：Werkzeug、Jinja2、Click、itsdangerous、blinker。

オプション：python-dotenv のインストール

python-dotenvこれにより、.envと.flaskenvファイルで環境変数を管理でき、Flask コマンドの使用が簡素化されます：

(.venv) $ pip install python-dotenv

必須ではありませんが、実際の開発では強く推奨されます。毎回--appパラメータを入力する手間が省け、チームで環境設定を共有するのにも便利です。

プロジェクトディレクトリ構造

コーディングを始める前に、標準的な Flask プロジェクトのディレクトリ構造を理解しておくと役立ちます：

myflaskapp/
├── .venv/          # 虚拟环境（不要提交到 Git）
├── app.py           # 应用入口文件
├── templates/       # Jinja2 模板文件目录
├── static/          # CSS、JS、图片等静态文件目录
├── .flaskenv        # Flask 环境变量（可选）
└── .gitignore       # 忽略 .venv 等不需要提交的文件

仮想環境ディレクトリ.venvGit にコミットすべきではありません。.gitignoreに.venv/を追加するだけです。
