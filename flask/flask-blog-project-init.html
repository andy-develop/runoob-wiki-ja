Flask Web アプリ

この章では、ゼロから始めて Flask で最初の Web アプリを作成し、マイクロフレームワークの設計思想を理解します。

Flask と Django の位置づけの違い

Django は「大きくて全部入り」のフルスタックフレームワークであり、ORM、テンプレートエンジン、管理画面、ユーザー認証、フォーム処理などを標準で備えています。

Flask はマイクロフレームワークです——中核は非常にシンプルで、ルーティングとテンプレートレンダリングのみを提供し、他の機能は拡張機能で必要に応じて追加します。

特徴DjangoFlask
設計思想すぐに使える（バッテリー同梱）マイクロフレームワーク、必要に応じて拡張
ORMDjango ORM 内蔵Flask-SQLAlchemy（拡張機能）
データベースマイグレーションmakemigrations/migrate 内蔵Flask-Migrate（拡張機能）
ユーザー認証auth モジュール内蔵Flask-Login（拡張機能）
管理画面Django Admin 内蔵Flask-Admin（拡張機能）
テンプレートエンジンDjango TemplatesJinja2（構文はほぼ同じ）
ルーティング設定urls.py で集中設定デコレータで関数の近くに宣言

選択のアドバイス：初心者が素早く成果を出したいなら Django、自分でコントロールし、必要に応じて組み立てるのが好きなら Flask。

環境準備

Python のバージョンを確認します（3.8 以上が必要）：

$ python3 --version
Python 3.12.0

仮想環境を作成して Flask をインストールする

$ python3 -m venv venv
$ source venv/bin/activate           # Windows：venv\Scripts\activate
(venv) $ pip install flask

インストールを検証：

(venv) $ python -c "import flask; print(flask.__version__)"
3.1.0

Flask 最小アプリ

Flask アプリは Python ファイル 1 つだけで済みます。

サンプル

# ファイルパス: app.py
from flask import Flask

# Flask アプリのインスタンスを作成
# __name__ は Flask に現在のモジュールの場所を伝えます（テンプレートと静的ファイルの検索に使用）
app = Flask(__name__)

# @app.route("/") — ルートデコレータ：/ パスにアクセスすると下の関数を実行
@app.route("/")
def index():
    return '<h1>RUNOOB ブログへようこそ</h1>'

# python app.py を直接実行した場合（flask run ではなく）、開発サーバーを起動
if __name__ == '__main__':
    app.run(debug=True)

開発サーバーを起動

(venv) $ flask run
 * Running on http://127.0.0.1:5000

ブラウザで http://127.0.0.1:5000/ にアクセスすると、ページ内容が表示されます。

ホットリロード（コード変更後にサーバーを自動再起動）を有効にする：

(venv) $ flask run --debug

flask runデフォルトで検索するのはapp.pyの中のappインスタンス。ファイル名またはインスタンス名が異なる場合は、環境変数を設定する必要があります：FLASK_APP=myapp.py（ファイル名）、FLASK_APP=myapp:create_app()（ファクトリ関数）。

Flask コマンドラインツール

以外にもflask run、Flask はその他の便利なコマンドも提供しています。

コマンド機能
flask run開発サーバーを起動
flask run --debugサーバー起動 + ホットリロード + デバッグモード
flask routes登録済みのすべてのルートを一覧表示
flask shellインタラクティブシェルに入る（app インスタンスを自動インポート）

プロジェクトディレクトリ構成の設計

Flask は単一ファイルのアプリをサポートしていますが、実際のプロジェクトでは明確なディレクトリ構成が必要です。

blog_project/
├── app/
│   ├── __init__.py          # 应用工厂 create_app()（第十章引入）
│   ├── blueprints/          # 路由 Blueprint（第四章分离）
│   ├── templates/           # Jinja2 模板（第二章创建）
│   ├── static/              # 静态文件 CSS/JS/图片
│   ├── models.py            # SQLAlchemy 模型（第三章创建）
│   └── forms.py             # Flask-WTF 表单（第八章创建）
├── config.py                # 配置文件
├── app.py                   # 应用入口（第一章从这里开始）
└── .env                     # 环境变量

実践：ブログホームページのルート

プロジェクトのスケルトンを作成し、ホームページのルートを設定して、ブラウザにウェルカムメッセージを表示させます。

サンプル

# ファイルパス: app.py
from flask import Flask

app = Flask(__name__)

@app.route("/")
def index():
    """ブログホームページ"""
    return """
<h1>RUNOOB ブログへようこそ</h1>
<p>これは Flask で構築された個人ブログの展示サイトです。</p>
<p>その他のコンテンツは近日公開予定です。お楽しみに。</p>
    """

@app.route("/about")
def about():
    """アバウトページ"""
    return '<h1>このサイトについて</h1><p>フロントエンドとバックエンドの学習ノートを記録しています。</p>'

実行：

flask run

ホームページとアバウトページにアクセスして、ルートが正常に動作することを確認します。

本章のまとめ

この章では3つのことを達成しました：仮想環境の作成と Flask のインストール、Flask マイクロフレームワークと Django の大きくて全部入りという位置づけの違いの理解、最初のルートページの作成です。

核心となる学び：Flask 最小アプリに必要なのはFlask(__name__) + @app.route()デコレータと、flask run起動です。
