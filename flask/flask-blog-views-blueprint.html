ビュー関数 — 記事一覧と詳細ページのレンダリング

この章では、ビュー関数を使ってデータベースからデータを取得し、ホームページと詳細ページをレンダリングし、Blueprintを使ってルートを分割する方法を学びます。

ビュー関数の役割

Flaskのビュー関数の役割はDjangoと同じです：リクエスト受信 → データ取得 → テンプレートレンダリング。

例

# ファイルパス：app.py
from flask import Flask, render_template
from models import Post, Category

@app.route("/")
def index():
    """ブログホームページ：すべての記事を表示"""
    posts = Post.query.order_by(Post.created_at.desc()).all()
    categories = Category.query.all()
    return render_template('index.html', posts=posts, categories=categories)

パスパラメータとクエリパラメータ

パラメータの種類URLの例ビューでの取得方法
パスパラメータ/post/3ルートの <型:変数名> → 関数引数
クエリパラメータ/?category=pythonrequest.args.get('key')

Flaskのルートは複数の型コンバーターをサポートしています：<int:id>（整数）、<string:slug>（デフォルト、/ を含まない）、<path:path>（/ を含む）、<float:price>など。

記事詳細ページ

例

# ファイルパス：app.py 追記
from flask import abort

@app.route("/post/<int:post_id>")
def post_detail(post_id):
    """記事詳細ページ"""
    # get_or_404 は次と等価：Post.query.get(post_id) or abort(404)
    post = Post.query.get_or_404(post_id,
        description=f'記事 #{post_id} は存在しません')
    return render_template('post_detail.html', post=post)

カテゴリによる絞り込み

例

# ファイルパス：app.py の index ビューを改造
from flask import request

@app.route("/")
def index():
    category_slug = request.args.get('category', '')
    keyword = request.args.get('q', '')       # 検索キーワード（第6章で実装）

    posts_query = Post.query.order_by(Post.created_at.desc())

    # カテゴリで絞り込み
    if category_slug:
        posts_query = posts_query.join(Category).filter(Category.slug == category_slug)

    posts = posts_query.all()
    categories = Category.query.all()

    return render_template('index.html',
        posts=posts, categories=categories,
        category_slug=category_slug, keyword=keyword)

request.args不変のMultiDictであり、URLクエリパラメータの読み取りに使用されます。.get('key', '默认值')安全に取得し、パラメータが存在しない場合はエラーではなくデフォルト値を返します。

Blueprint — ルートの分割

ビュー関数が増えると、すべてを app.py に詰め込むと手に負えなくなります。

BlueprintFlask のルートグループ化方式であり、機能モジュールごとにビューを分割し、app.register_blueprint() で登録します。

app/
├── blueprints/
│   ├── __init__.py
│   ├── main.py          # 首页、关于、搜索
│   └── posts.py         # 文章列表、详情
├── templates/
├── models.py
└── __init__.py

例

# ファイルパス：app/blueprints/main.py
from flask import Blueprint, render_template, request
from app.models import Post, Category

# Blueprint('ブループリント名', __name__, url_prefix='/')
main_bp = Blueprint('main', __name__)

@main_bp.route("/")
def index():
    """ブログホームページ"""
    category_slug = request.args.get('category', '')
    posts_query = Post.query.order_by(Post.created_at.desc())
    if category_slug:
        posts_query = posts_query.join(Category).filter(Category.slug == category_slug)
    return render_template('index.html',
        posts=posts_query.all(),
        categories=Category.query.all(),
        category_slug=category_slug)

例

# ファイルパス：app/blueprints/posts.py
from flask import Blueprint, render_template, abort
from app.models import Post

posts_bp = Blueprint('posts', __name__)

@posts_bp.route("/post/<int:post_id>")
def post_detail(post_id):
    post = Post.query.get_or_404(post_id)
    return render_template('post_detail.html', post=post)

アプリケーションのエントリポイントで Blueprint を登録します：

例

# ファイルパス：app.py
from flask import Flask
from app.blueprints.main import main_bp
from app.blueprints.posts import posts_bp

app = Flask(__name__)

# ブループリント登録：すべてのブループリントのビュー関数が1つのアプリケーションに統合されます
app.register_blueprint(main_bp)
app.register_blueprint(posts_bp)

Blueprint は指定できますurl_prefix（例えばurl_prefix='/blog'）を指定すると、ブループリント内のすべてのルートに自動的にこのプレフィックスが付きます。Blueprint は独自のテンプレートと静的ファイルディレクトリを持つこともできます。

ホームページと詳細ページのテンプレートの作成

index.html

例

<!-- ファイルパス：app/templates/index.html -->
{% extends 'base.html' %}

{% block title %}サンプル ブログ - ホーム{% endblock %}

{% block content %}
<h2 class="section-title">最新記事</h2>

<!-- カテゴリ絞り込みナビゲーション -->
<div class="category-bar">
    <a href="{{ url_for('main.index') }}"
      class="{% if not category_slug %}active{% endif %}">すべて</a>
    {% for cat in categories %}
    <a href="{{ url_for('main.index', category=cat.slug) }}"
      class="{% if category_slug == cat.slug %}active{% endif %}">
        {{ cat.name }}
    </a>
    {% endfor %}
</div>

{% if posts %}
<div class="article-grid">
    {% for post in posts %}
    <a href="{{ url_for('posts.post_detail', post_id=post.id) }}" class="card-link">
        <div class="article-card">
            <div class="card-content">
                <span class="card-category">{{ post.category.name }}</span>
                <h3>{{ post.title }}</h3>
                <p>{{ post.summary|truncate(80) }}</p>
                <span class="card-date">{{ post.created_at.strftime('%Y-%m-%d') }}</span>
            </div>
        </div>
    </a>
    {% endfor %}
</div>
{% else %}
<p class="empty-tip">このカテゴリにはまだ記事がありません。</p>
{% endif %}
{% endblock %}

url_for() で Blueprint ビューを使用する場合、形式はurl_for('蓝图名.函数名')、例えばurl_for('posts.post_detail', post_id=3)。Django の{% url %}タグとの比較：Flask は{{ url_for() }}、Python式にネストできるため、より柔軟です。

この章では、Flaskのビューとルーティング構成を習得しました：Post.query でのデータ取得、パスパラメータ <int:post_id> とクエリパラメータ request.args、get_or_404 による安全なクエリ、abort(404) とカスタムエラーページ、Blueprint によるモジュール単位のルート分割。
