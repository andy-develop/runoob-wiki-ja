Pandas groupby.mean() 関数

Pandas のよく使う関数

groupby.mean()は Pandas でグループ化後に平均値を計算するための集約関数です。これはgroupby.sum()と組み合わせて使用し、まずデータをある列の値でグループ化し、各グループの数値列の算術平均を計算します。

データ分析では、平均値の計算は非常に一般的なニーズです。たとえば、各部門の平均給与、各地域の平均売上、各クラスの平均成績などを計算します。mean()関数を使えば、これらのタスクをすばやく完了できます。

基本構文とパラメータ

mean()は GroupBy オブジェクトのメンバー関数であり、先にgroupby()でグループ化してから呼び出す必要があります。

構文形式

GroupBy.mean(numeric_only=False, engine=None, engine_kwargs=None)

パラメータの説明

パラメータ 型 説明 デフォルト値
numeric_only bool True の場合、数値列のみ平均値を計算します。False の場合、すべての列に対して平均値の計算を試みます。 False
engine str 計算エンジンを指定します。'cython' または 'numba' を指定できます。None は Pandas が自動選択することを意味します。 None
engine_kwargs dict 基盤となるエンジンに渡す追加パラメータの辞書。 None

戻り値

  • 戻り値の型：Series 或 DataFrame
  • 説明：グループ化して平均値を計算した結果を返します。単一列に使用した場合は Series を返し、複数列に使用した場合は DataFrame を返します。

実例

簡単なものから複雑なものまで、一連の例を通してgroupby.mean()の使い方を完全にマスターしましょう。

例1：基本の使い方 - 1列でグループ化して平均値を計算

最も基本的な使い方は、ある列の値でグループ化し、別の列の平均値を計算することです。

実例

import pandas as pd

# 学生の成績データ DataFrame を作成
# 学生名、クラス、国語、数学、英語の成績を含む
data = {
    '姓名': ['张三', '李四', '王五', '赵六', '孙七', '周八', '吴九', '郑十'],
    '班级': ['A', 'A', 'A', 'B', 'B', 'B', 'B', 'A'],
    '语文': [85, 92, 78, 88, 95, 82, 90, 87],
    '数学': [90, 85, 92, 78, 88, 91, 85, 89],
    '英语': [88, 90, 85, 92, 87, 89, 91, 86]
}

# DataFrame を作成
df = pd.DataFrame(data)

print("学生成绩数据：")
print(df)
print()

# "班级"列でグループ化し、各クラスの平均成績を計算
avg_by_class = df.groupby('班级').mean(numeric_only=True)

print("每个班级的平均成绩：")
print(avg_by_class)
print()

# 特定の列だけの平均値も計算できます
math_avg_by_class = df.groupby('班级')['数学'].mean()

print("每个班级的数学平均成绩：")
print(math_avg_by_class)

コードの解説:

  1. df.groupby('班级')「班级」列の値に従って学生を A、B の2つのグループに分けます。
  2. .mean(numeric_only=True)すべての数値列（国語、数学、英語）に対して平均値を計算します。
  3. 返される結果では、クラスがインデックス、各科目の平均値が列データとなります。

例2：複数列でグループ化して平均値を計算

複数の列で同時にグループ化し、数値列の平均値を計算できます。

実例

import pandas as pd

# 販売データを作成
data = {
    '地区': ['华北', '华东', '华南', '华北', '华东', '华南', '华北', '华东'],
    '产品': ['A', 'B', 'C', 'B', 'A', 'C', 'A', 'B'],
    '销售额': [1000, 2000, 1500, 1800, 2200, 1600, 1200, 2100],
    '利润': [200, 400, 300, 360, 440, 320, 240, 420]
}
df = pd.DataFrame(data)

print("销售数据：")
print(df)
print()

# 「地区」と「产品」でグループ化し、平均売上高と利益を計算
avg_grouped = df.groupby(['地区', '产品'], as_index=False).mean(numeric_only=True)

print("按地区和产品分组后的平均销售额和利润：")
print(avg_grouped)
print()

# マルチインデックス形式を保持
avg_indexed = df.groupby(['地区', '产品']).mean(numeric_only=True)
print("多级索引形式的结果：")
print(avg_indexed)

  • ['地域', '製品']リストを使うと、複数の列で同時にグループ化できます。

例3：欠損値がある場合の平均値計算

データに欠損値（NaN）が存在する場合、mean()はこれらの欠損値を自動的に無視して計算します。

実例

import pandas as pd
import numpy as np

# 欠損値を含む従業員の給与データを作成
data = {
    '部门': ['销售', '销售', '销售', '技术', '技术', '技术', '行政', '行政'],
    '工资': [5000, 6000, np.nan, 8000, 9000, np.nan, 4500, np.nan]
}
df = pd.DataFrame(data)

print("员工工资数据（包含缺失值）：")
print(df)
print()

# デフォルトでは、mean() は NaN 値を無視して計算します
avg_with_nan = df.groupby('部门')['工资'].mean()
print("默认计算平均值（忽略NaN）：")
print(avg_with_nan)
print()

# NaN 値を 0 として含めて計算したい場合は、先に埋める必要があります
avg_filled = df.groupby('部门')['工资'].apply(lambda x: x.fillna(0).mean())
print("将NaN视为0后的平均工资：")
print(avg_filled)
print()

# skipna パラメータを使用（デフォルトは True）
# skipna=False に設定すると、NaN を含むすべてのグループは NaN を返します
# 注意：groupby の mean には skipna パラメータがありませんが、fillna で同様の効果を実現できます

コードの解説:

  • デフォルトでは、mean()は NaN 値を自動的に無視し、平均値の計算に含めません。
  • 営業部門には有効な値が2つ（5000, 6000）あり、平均値は 5500 です。
  • NaN を 0 とみなして平均値を計算する場合は、fillna(0)を使用して欠損値を先に埋めます。

    • 例4：transform と組み合わせてグループ内の割合を計算

    transform メソッドを通じて、transformグループ平均値を元のデータの各行にブロードキャストできます。これは、グループ内の割合やグループ平均との差を計算するときに非常に役立ちます。

    実例

    import pandas as pd

    # 学生の成績データを作成
    data = {
        '姓名': ['张三', '李四', '王五', '赵六', '孙七', '周八'],
        '班级': ['A', 'A', 'A', 'B', 'B', 'B'],
        '语文': [85, 92, 78, 88, 95, 82],
        '数学': [90, 85, 92, 78, 88, 91]
    }
    df = pd.DataFrame(data)

    print("学生成绩数据：")
    print(df)
    print()

    # 各クラスの数学の平均点を計算し、各行にブロードキャスト
    df['班级数学平均分'] = df.groupby('班级')['数学'].transform('mean')

    # 各生徒の成績とクラス平均点の差を計算
    df['与平均分差值'] = df['数学'] - df['班级数学平均分']

    print("添加班级平均分和差值后的数据：")
    print(df)
    print()

    # 各生徒の数学の成績がクラス合計点に占める割合を計算
    df['班级内百分比'] = (df['数学'] / df['班级数学平均分'] * 100).round(2)

    print("添加百分比后的数据：")
    print(df)

1  A   0.3   索引

    コードの解説:

    • transform('mean')は各グループの平均値を計算し、元のデータの各行にブロードキャストします。
    • これにより、各生徒は自分のクラスの平均点を知ることができ、比較しやすくなります。
    • この方法は、「集団内における個人の位置」を計算するなどの分析シーンで非常に実用的です。

    注意事項：mean()関数はデフォルトでNaN値を無視して計算します。データがすべて欠損値の場合はNaNを返します。とsum()は異なり、mean()にはmin_countパラメータがありません。
