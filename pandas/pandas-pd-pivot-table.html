Pandas pd.pivot_table() 関数

Pandas よく使う関数

pd.pivot_table()Pandas ライブラリで使用されるピボットテーブルを作成する関数です。ピボットテーブルはスプレッドシートの一般的な機能であり、データをグループ化、集約、再形成して、さまざまな角度からデータを分析するのに便利です。

とpd.crosstab()に比べて、pivot_table()より強力で、複数の集約関数のサポート、欠損値の処理、より複雑なデータの再形成が可能です。

単語の意味： pivot_table「ピボットテーブル」を意味し、データのレイアウトを動的に変更できる表であり、複数の視点からデータを集計・分析できます。

基本構文とパラメータ

pd.pivot_table()Pandas ライブラリのトップレベル関数であり、ピボットテーブルの作成に使用されます。

構文形式

pd.pivot_table(data, values=None, index=None, columns=None, aggfunc='mean', fill_value=None, margins=False, dropna=True, margins_name='All')

パラメータ説明

  • パラメータ： data
    • 型： DataFrame。
    • 説明： ソースデータの DataFrame。
  • パラメータ： values
    • 型： 列名または列名のリスト。
    • 説明： 集約する列。指定しない場合、すべての数値列が集約されます。
  • パラメータ： index
    • 型： 列名、列名のリスト、または関数。
    • 説明： 行インデックスとして使用する列。単一の列または複数の列（リスト）を指定できます。複数の列を指定すると、階層インデックスが作成されます。
  • パラメータ： columns
    • 型： 列名または列名のリスト。
    • 説明： 列インデックスとして使用する列。
  • パラメータ： aggfunc
    • 型： 関数、文字列、または関数のリスト。
    • 説明： 集約関数。一般的な値には 'sum'、'mean'、'count'、'min'、'max'、'median'、'std' などがあります。デフォルトは 'mean' です。
  • パラメータ： fill_value
    • 型： スカラーまたは None。
    • 説明： 欠損値を埋めるための数値。
  • パラメータ： margins
    • 型： ブール値。
    • 説明： 行と列の合計を追加するかどうか。デフォルトはFalse。

関数説明

  • 戻り値： DataFrame、つまりピボットテーブルを返します。
  • 効果： 指定された行、列、および集約関数に基づいて、データを再形成し集計します。

例

簡単なものから複雑なものまでの一連の例を通じて、pd.pivot_table()の使い方を徹底的にマスターしましょう。

例1：基本用法 - 単純なピボットテーブルの作成

例

import pandas as pd
import numpy as np

# 1. 创建销售数据
sales = pd.DataFrame({
    'date': pd.date_range('2023-01-01', periods=12, freq='D'),
    'product': ['A', 'B', 'C', 'A', 'B', 'C', 'A', 'B', 'C', 'A', 'B', 'C'],
    'region': ['North', 'North', 'North', 'South', 'South', 'South', 'East', 'East', 'East', 'West', 'West', 'West'],
    'sales': [100, 150, 200, 180, 170, 160, 190, 200, 210, 220, 230, 240]
})

print("=== 销售数据 ===")
print(sales)

# 2. ピボットテーブルの作成 - 製品と地域別に売上を集計する
pivot = pd.pivot_table(sales, values='sales', index='product', columns='region', aggfunc='sum')
print("n=== pd.pivot_table() 销售透视表 ===")
print(pivot)

# 3. 使用 fill_value 填充缺失值
print("n=== 填充缺失值 (fill_value=0) ===")
pivot_fill = pd.pivot_table(sales, values='sales', index='product', columns='region', aggfunc='sum', fill_value=0)
print(pivot_fill)

例2：異なる集約関数の使用

aggfuncパラメータを使用すると、複数の集約方法を指定してデータを分析できます。

例

import pandas as pd
import numpy as np

# 1. より豊富な売上データを作成
sales = pd.DataFrame({
    'product': ['A', 'B', 'A', 'B', 'A', 'B', 'A', 'B', 'A', 'B'],
    'region': ['North', 'North', 'South', 'South', 'East', 'East', 'West', 'West', 'North', 'South'],
    'sales': [100, 150, 200, 180, 190, 200, 220, 230, 110, 190],
    'quantity': [10, 15, 20, 18, 19, 20, 22, 23, 11, 19]
})

print("=== 销售数据 ===")
print(sales)

# 2. 集計（合計）
print("n=== 売上合計 ===")
sum_result = pd.pivot_table(sales, values='sales', index='product', columns='region', aggfunc='sum')
print(sum_result)

# 3. 计算平均销售额
print("n=== 销售额平均值 ===")
mean_result = pd.pivot_table(sales, values='sales', index='product', columns='region', aggfunc='mean')
print(mean_result.round(1))

# 4. 同时计算多种统计量（传递列表）
print("n=== 件数と平均を同時に計算 ===")
multi_agg = pd.pivot_table(sales, values='sales', index='product', columns='region', aggfunc=['sum', 'mean'])
print(multi_agg)

  • 複数の集約関数を同時に渡すと、ピボットテーブルは複数レベルの列インデックスを作成します。

例3：margins を使用して合計を追加

パラメータをmargins使用することで、行と列の合計を追加でき、集計データを確認しやすくなります。

例

import pandas as pd

# 以前の売上データを使用
sales = pd.DataFrame({
    'product': ['A', 'B', 'A', 'B', 'A', 'B'],
    'region': ['North', 'North', 'South', 'South', 'East', 'East'],
    'sales': [100, 150, 200, 180, 190, 200]
})

# 1. 无合计
print("=== 无合计 ===")
print(pd.pivot_table(sales, values='sales', index='product', columns='region', aggfunc='sum'))

# 2. 添加行列合计
print("n=== 添加合计 (margins=True) ===")
result = pd.pivot_table(sales, values='sales', index='product', columns='region', aggfunc='sum', margins=True)
print(result)

# 3. 自定义合计名称
print("n=== 自定义合计名称 ===")
result_name = pd.pivot_table(sales, values='sales', index='product', columns='region', aggfunc='sum', margins=True, margins_name='总计')
print(result_name)

# 4. マルチレベル行インデックスの合計
print("n=== 多层行索引 ===")
multi_index = pd.pivot_table(sales, values='sales', index=['product', 'region'], aggfunc='sum')
print(multi_index)

実行結果の予想:

コード解析:

  • margins=True「All」の行と列が追加され、合計データが表示されます。

例4：複数レベルのインデックスと複雑なピボット

複数の列を使用して、複数レベルのインデックスを持つピボットテーブルを作成できます。

例

import pandas as pd

# 1. 複数のカテゴリ変数を含むデータを作成
data = pd.DataFrame({
    'year': [2022, 2022, 2022, 2023, 2023, 2023],
    'quarter': ['Q1', 'Q2', 'Q3', 'Q1', 'Q2', 'Q3'],
    'product': ['A', 'A', 'B', 'B', 'A', 'B'],
    'sales': [100, 150, 200, 220, 180, 250]
})

print("=== 数据 ===")
print(data)

# 2. 複数の列を行インデックスとして使用
print("n=== 多年份多季度透视 ===")
pivot = pd.pivot_table(data, values='sales', index=['year', 'quarter'], columns='product', aggfunc='sum')
print(pivot)

# 3. 複数の列を列インデックスとして使用
print("n=== 复杂交叉透视 ===")
pivot_multi = pd.pivot_table(data, values='sales', index='year', columns=['product', 'quarter'], aggfunc='sum')
print(pivot_multi)

# 4. 使用 fill_value 处理缺失值
print("n=== 填充缺失值 ===")
pivot_fill = pd.pivot_table(data, values='sales', index=['year', 'quarter'], columns='product', aggfunc='sum', fill_value=0)
print(pivot_fill)

実行結果の予想:

=== 数据 ===
   year quarter product  sales
0  2022      Q1      A    100
1  2022      Q2      A    150
2  2022      Q3      B    200
3  2023      Q1      B    220
4  2023      Q2      A    180
5  2023      Q3      B    250

=== 多年份多季度透视 ===
product           A      B
year quarter
2022 Q1       100.0    NaN
2022 Q2       150.0    NaN
2022 Q3         NaN  200.0
2023 Q1         NaN  220.0
2023 Q2       180.0    NaN
2023 Q3         NaN  250.0

=== 复杂交叉透视 ===
product         A         B
quarter        Q1    Q2   Q3   Q1   Q2   Q3
year
2022          100  150  200  NaN  NaN  NaN
2023          NaN  180  250  NaN  NaN  NaN

=== 填充缺失值 ===
product         A      B
year quarter
2022 Q1         100    0
2022 Q2         150    0
2022 Q3           0  200
2023 Q1           0  220
2023 Q2         180    0
2023 Q3           0  250

コード解析:

  • 複数レベルのインデックスは、リスト形式で指定するindex=['year', 'quarter']ことによって実現されます。
  • fill_value=0欠損データを一律に 0 で埋めることで、後続の計算が容易になります。

ヒント： pd.pivot_table()強力なピボット機能を提供します。2つのカテゴリ変数の頻度を集計するだけでよい場合は、pd.crosstab()より簡潔かもしれません。pd.crosstab()頻度の数値を返す一方、pivot_table()平均、合計、標準偏差など、複数の統計量を計算できます。pd.crosstab()これは、`pd.pivot_table()` のpivot_table()にaggfunc='count'特殊なケースと見なすことができます。
