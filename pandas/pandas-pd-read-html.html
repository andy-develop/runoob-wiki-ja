Pandas pd.read_html() 関数

Pandas よく使われる関数

read_html()pandasライブラリでHTMLテーブルを解析するための関数であり、WebページまたはHTMLファイルからテーブルデータを読み取り、DataFrameに変換できます。

Webページ内のテーブルデータは非常に重要なデータソースであり、多くの公開データ（株式情報や統計データなど）はHTMLテーブルの形式で提供されています。read_html()を利用してlxmlとBeautifulSoupライブラリでHTMLを解析し、ページ内のすべてのテーブルまたは指定したテーブルを自動的に抽出できます。

基本構文とパラメータ

構文形式

pandas.read_html(io, match='.+', flavor=None, header=None, index_col=None,
                skiprows=None, attrs=None, parse_dates=False, thousands=',',
                decimal='.', converters=None, ...)

パラメータの説明

パラメータ型説明デフォルト値
iostr, path object, file-like objectHTMLファイルのパス、URL、または文字列必須
matchstr, regex正規表現を使用してテーブルのテキスト内容をマッチングします'.+'
flavorstrパーサー：'lxml', 'html5lib', 'bs4'None
headerint, list of int列名として使用する行番号None
index_colint, str行インデックスとして使用する列None
skiprowsint, list, slice指定した行をスキップしますNone
attrsdictテーブルをフィルタリングするためのHTMLタグ属性None
parse_datesbool, list日付列を解析するかどうかFalse

戻り値

  • 戻り値の型：list of DataFrames
  • DataFrameのリストを返します。ページ上にあるテーブルの数だけDataFrameを返します。
  • 一致するテーブルが見つからない場合は、空のリストを返します。

例

以下の例を通じて、詳細に理解しますread_html()の様々な使い方をマスターしましょう。

例1：ローカルHTMLファイル内のテーブルを読み取る

まずテーブルを含むHTMLファイルを作成し、次にread_html()読み取ります。

例

        <tr>

            <td>30</td>
        </tr>

    f.write(html_content)

# read_html を使用してすべてのテーブルを読み取る
# io: HTMLファイルのパス（必須）
tables = pd.read_html('tables.html')

# 読み取り結果を確認する
print(f"合計 {len(tables)} 個のテーブルが見つかりました")
print()

# すべてのテーブルをループ処理する
for i, df in enumerate(tables):
    print(f"--- テーブル {i+1} ---")
    print(df)
    print()

  • 最初の行は自動的に列名として認識されます（th<th>タグがあるため）。

例2：attrs と match を使用してテーブルをフィルタリングする

ページに複数のテーブルがある場合、属性またはテキストマッチングを使用して必要なテーブルをフィルタリングできます。

例

import pandas as pd

# 属性を持つHTMLファイルを作成する
html_with_attrs = '''



    <table id="employees" class="data-table">
        <tr><th>name</th><th>age</th></tr>
        <tr><td>Tom</td><td>28</td></tr>
        <tr><td>Jerry</td><td>35</td></tr>
    </table>

    <table id="products" class="data-table">
        <tr><th>product</th><th>price</th></tr>
        <tr><td>A</td><td>100</td></tr>
        <tr><td>B</td><td>200</td></tr>
    </table>

    <table class="summary">
        <tr><td>Total</td><td>2</td></tr>
    </table>


'''

with open('tables_attrs.html', 'w', encoding='utf-8') as f:
    f.write(html_with_attrs)

# 例2a: attrs を使用して id 属性でフィルタリングする
# id="employees" のテーブルを読み取る
tables_by_id = pd.read_html('tables_attrs.html', attrs={'id': 'employees'})
print("id でフィルタリング:")
print(tables_by_id[0])
print()

# 例2b: attrs を使用して class 属性でフィルタリングする
# class="data-table" のすべてのテーブルを読み取る
tables_by_class = pd.read_html('tables_attrs.html', attrs={'class': 'data-table'})
print("class でフィルタリング ({} 個のテーブルが見つかりました):".format(len(tables_by_class)))
for i, df in enumerate(tables_by_class):
    print(f"テーブル {i+1}:")
    print(df)
    print()

# 例2c: match を使用して特定のテキストを含むテーブルをフィルタリングする
# match は正規表現を使用してテーブル内のテキストにマッチングする
tables_by_text = pd.read_html('tables_attrs.html', match='Tom')
print("'Tom' というテキストを含むテーブル:")
print(tables_by_text[0])

実行結果の想定:

使用 id 筛选:
   name  age
0   Tom   28
1  Jerry   35

使用 class 筛选 (找到 2 个表格):
表格 1:
   name  age
0   Tom   28
1  Jerry   35

表格 2:
  product  price
0       A    100
1       B    200

包含 'Tom' 文本的表格:
   name  age
0   Tom   28
1  Jerry   35

コードの解説:

  • attrsパラメータは、HTMLタグの属性（id、class、styleなど）を指定してテーブルをフィルタリングできます。
  • matchパラメータは正規表現を使用してテーブル内のテキスト内容にマッチングし、一致するテキストを含むテーブルを返します。
  • テーブルが1つだけ返された場合は、tables[0]最初のDataFrameを取得できます。

例3：ヘッダーとインデックスを処理する

HTMLテーブルの形式は複雑な場合があるため、ヘッダーとインデックスを柔軟に処理する必要があります。

h2 class="example">例
import pandas as pd

# 複雑な構造のHTMLを作成する
html_complex = '''



<!-- ヘッダーのないテーブル -->
    <table id="no_header">
        <tr><td>Tom</td><td>28</td></tr>
        <tr><td>Jerry</td><td>35</td></tr>
    </table>

<!-- 複数行のヘッダー -->
    <table id="multi_header">
<tr><th>氏名</th><th colspan="2">連絡先</th></tr>
<tr><th></th><th>電話</th><th>メール</th></tr>
        <tr><td>Tom</td><td>123456</td><td>tom@example.com</td></tr>
        <tr><td>Jerry</td><td>789012</td><td>jerry@example.com</td></tr>
    </table>

<!-- 属性を持つテーブル -->
    <table id="with_index" data-type="employee">
<tr><th>氏名</th><th>年齢</th><th>都市</th></tr>
        <tr><th></th><th></th><th></th></tr>
        <tr><td>Tom</td><td>28</td><td>Beijing</td></tr>
    </table>


'''

with open('tables_complex.html', 'w', encoding='utf-8') as f:
    f.write(html_complex)

# 例3a: ヘッダーがない場合
# header=None は最初の行を列名として使用しない
df_no_header = pd.read_html('tables_complex.html', attrs={'id': 'no_header'}, header=None)[0]
print("ヘッダーなし:")
print(df_no_header)
print()

# 例3b: 複数行のヘッダー
# 0行目と1行目をまとめてヘッダーとして使用する
df_multi_header = pd.read_html('tables_complex.html', attrs={'id': 'multi_header'})[0]
print("複数行のヘッダー:")
print(df_multi_header)
print()

# 例3c: インデックス列を設定する
# index_col は0列目をインデックスとして指定する
df_with_index = pd.read_html('tables_complex.html', attrs={'id': 'with_index'}, index_col=0)[0]
print("インデックスを設定:")
print(df_with_index)

実行結果の想定:

没有表头:
      0     1
0  Tom    28
1  Jerry  35

多行表头:
       姓名    联系方式
        NaN    电话          邮箱
0     Tom  123456  tom@example.com
1   Jerry  789012  jerry@example.com

设置索引:
                年龄       城市
姓名
Tom            28    Beijing
</空行>
空字符串    NaN       NaN
Tom            28    Beijing

コードの解説:

  • header=None自動ヘッダー認識を無効にし、デフォルトの整数インデックスを列名として使用できます。
  • 複数行のヘッダーは多層インデックス（MultiIndex）として処理されます。
  • index_colパラメータは、特定の列を行インデックスとして指定できます。

注意事項

  • を使用するにはread_html()のインストールが必要ですlxmlライブラリ：pip install lxml。
  • 返されるのはDataFrameのリストであり、インデックスに基づいて特定のテーブルを選択する必要があります。
  • ページに複数のテーブルがある場合は、attrs 或 matchパラメータを使用してフィルタリングします。
  • read_html()すべてのテーブルの解析を試みるため、遅くなる可能性があります。大きなページでは、matchパラメータを使用して範囲を絞り込むことができます。
  • ネットワークページを読み取るにはネットワークサポートが必要であり、アクセス制限やスクレイピング防止メカニズムが存在する可能性があります。

まとめ

read_html()pandasでHTMLテーブルデータを読み取るための強力なツールです。Webページ内のテーブルを自動的に解析し、構造化されたDataFrame形式に変換できます。

実際の業務でWebページからデータを取得する必要がある場合、read_html()非常に実用的な選択肢です。attrs と match パラメータの使用方法を理解すれば、複雑なページから必要なデータを効率的に抽出できます。Webページのテーブルを取得する必要がある場合は、この関数を優先的に検討することをお勧めします。
