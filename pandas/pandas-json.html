Pandas JSON

JSON（JavaScript Object Notation、JavaScriptオブジェクト表記法）は、テキスト情報を保存および交換するための構文であり、XMLに似ています。

JSON は XML よりも小さく、高速で、解析が容易です。JSON の詳細については、以下を参照してください。JSON チュートリアル。

Pandas は JSON 形式のデータを処理するための強力なメソッドを提供しており、JSON ファイルや文字列からデータを読み取って DataFrame に変換したり、DataFrame を JSON 形式に変換したりすることができます。

操作メソッド説明
JSONファイル/文字列からデータを読み取るpd.read_json()JSONデータを読み取ってDataFrameとして読み込む
DataFrameをJSONに変換するDataFrame.to_json()DataFrameをJSON形式のデータに変換し、構造化の方法を指定できます。
JSONの構造化方式をサポートorientパラメータ複数の構造化方式をサポートしています。例：split、records、columns

Pandas は JSON データを簡単に処理できます。本記事では、sites.jsonを例として、内容は以下の通りです：

例

[ { "id": "A001", "name": "菜鸟教程", "url": "www.runoob.com", "likes": 61 }, { "id": "A002", "name": "Google", "url": "www.google.com", "likes": 124 }, { "id": "A003", "name": "淘宝", "url": "www.taobao.com", "likes": 45 } ]

JSONファイル/文字列からデータを読み込む

pd.read_json() - JSONデータを読み込む

read_json() は、JSON形式のデータから読み取ってDataFrameとして読み込むために使用します。JSONファイル、JSON文字列、JSONのURLからデータを読み込むことができます。

構文形式：

import pandas as pd

df = pd.read_json(
    path_or_buffer,      # JSON 文件路径、JSON 字符串或 URL
    orient=None,         # JSON 数据的结构方式，默认是 'columns'
    dtype=None,          # 强制指定列的数据类型
    convert_axes=True,   # 是否转换行列索引
    convert_dates=True,  # 是否将日期解析为日期类型
    keep_default_na=True # 是否保留默认的缺失值标记
)

パラメータの説明：

パラメータ説明デフォルト値
path_or_bufferJSONファイルのパス、JSON文字列、またはURL必須パラメータ
orientJSONデータの形式を定義します。一般的な値は以下の通りです：split、records、index、columns、values。None（ファイルから自動的に推測）
dtype列のデータ型を強制的に指定None
convert_axes軸を適切なデータ型に変換するかどうかTrue
convert_dates日付を日付型として解析するかどうかTrue
keep_default_naデフォルトの欠損値マーカー（例：NaN）True

一般的な orient パラメータのオプション：

orient の値JSON形式の例説明
split{"index":["a","b"],"columns":["A","B"],"data":[[1,2],[3,4]]}キーを使用index、columnsとdata構造
records[{"A":1,"B":2},{"A":3,"B":4}]各レコードは辞書であり、1行のデータを表します。
index{"a":{"A":1,"B":2},"b":{"A":3,"B":4}}インデックスをキーとし、値を辞書とする方式
columns{"A":{"a":1,"b":3},"B":{"a":2,"b":4}}列名をキーとし、値を辞書とする方式
values[[1,2],[3,4]]データのみを返し、インデックスと列名は含まれません。

JSONファイルからデータを読み込む：

例

import pandas as pd

df = pd.read_json('sites.json')
   
print(df.to_string())

import pandas as pd

DataFrameをJSONに変換する

DataFrame.to_json() - DataFrameをJSONデータに変換する

to_json() メソッドは、DataFrameをJSON形式のデータに変換するために使用され、JSONの構造化方式を指定できます。

構文形式：

df.to_json(
    path_or_buffer=None,    # 输出的文件路径或文件对象，如果是 None 则返回 JSON 字符串
    orient=None,            # JSON 格式方式，支持 'split', 'records', 'index', 'columns', 'values'
    date_format=None,       # 日期格式，支持 'epoch', 'iso'
    default_handler=None,   # 自定义非标准类型的处理函数
    lines=False,            # 是否将每行数据作为一行（适用于 'records' 或 'split'）
    encoding='utf-8'        # 编码格式
)

パラメータの説明：

パラメータ説明デフォルト値
path_or_buffer出力ファイルのパスまたはファイルオブジェクト。もしNoneの場合は、JSON文字列を返します。None
orientJSON形式の構造を指定します。サポートされるのはsplit、records、index、columns、valuesNone（デフォルトはcolumns）
date_format日付形式。サポート対象：'epoch' 或 'iso'形式。None
default_handler非標準型（例：datetimeなど）の処理関数をカスタマイズします。None
lines各行のデータを1行として出力するかどうか（適用対象：records 或 split）False
encoding出力ファイルのエンコーディング形式'utf-8'

例

import pandas as pd

# DataFrameを作成
df = pd.DataFrame({
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Age': [25, 30, 35],
    'City': ['New York', 'Los Angeles', 'Chicago']
})

# DataFrameをJSON文字列に変換
json_str = df.to_json()

print(json_str)

DataFrameをJSONファイルに変換する（orient='records' を指定）：

例

import pandas as pd

# DataFrameを作成
df = pd.DataFrame({
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Age': [25, 30, 35],
    'City': ['New York', 'Los Angeles', 'Chicago']
})

# DataFrame を JSON ファイルに変換し、orient='records' を指定
df.to_json('data.json', orient='records', lines=True)

# 生成されたファイルの内容を出力：
# [
#   {"Name":"Alice","Age":25,"City":"New York"},
#   {"Name":"Bob","Age":30,"City":"Los Angeles"},
#   {"Name":"Charlie","Age":35,"City":"Chicago"}
# ]

DataFrame を JSON に変換し、日付形式を指定：

例

import pandas as pd

# 日付データを含む DataFrame を作成
df = pd.DataFrame({
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Date': pd.to_datetime(['2021-01-01', '2022-02-01', '2023-03-01']),
    'Age': [25, 30, 35]
})

# DataFrame を JSON に変換し、日付形式を 'iso' に指定
json_str = df.to_json(date_format='iso')

print(json_str)
