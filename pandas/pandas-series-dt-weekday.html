Pandas Series.dt.weekday 属性

Pandas よく使う関数

Series.dt.weekdayPandas において使用される日付に対応する曜日を抽出する属性です。これは dt アクセサの一部で、曜日を表す整数を返します（0=月曜、6=日曜）。

時系列データ分析において、曜日は重要な次元です。例えば、週末と平日の差異、毎週の販売パターンなどを分析します。dt.weekdayこの属性により、この種の分析が簡単かつ効率的になります。

単語の意味： weekday「平日」または「曜日」を意味し、0〜6 の整数値を返します。

基本構文とパラメータ

Series.dt.weekdaySeries の dt アクセサの属性で、曜日を抽出するために使用します。

構文形式

Series.dt.weekday

パラメータの説明

この属性はパラメータを一切必要とせず、datetime Series の曜日情報に直接アクセスします。

戻り値の説明

  • 戻り値： 曜日を含む整数の Series（0〜6）を返します。
  • 効果： 0〜6 の整数を返します。0 は月曜、1 は火曜、...、6 は日曜を表します。

例

簡単なものから複雑なものまでの一連の例を通して、徹底的にSeries.dt.weekdayの使い方をマスターしましょう。

例1：基本の使い方 - 曜日の取得

例

import pandas as pd

# 1. 日時 Series を作成
print("=== 日時 Series の作成 ===")
dates = pd.Series([
    '2023-01-02',  # 月曜
    '2023-01-03',  # 火曜
    '2023-01-04',  # 水曜
    '2023-01-05',  # 木曜
    '2023-01-06',  # 金曜
    '2023-01-07',  # 土曜
    '2023-01-08',  # 日曜
])

# datetime 型に変換
datetime_series = pd.to_datetime(dates)
print("元の日付:")
print(datetime_series)

# 2. dt.weekday で曜日を抽出
print("n=== dt.weekday で曜日を抽出 ===")
weekdays = datetime_series.dt.weekday
print("曜日（0=月曜、6=日曜）:")
print(weekdays)

# 3. dt.day_name() で曜日の名前を取得
print("n=== dt.day_name() で曜日名を取得 ===")
weekday_names = datetime_series.dt.day_name()
print(weekday_names)

# 4. dt.day_name(locale='zh_CN') で中国語の曜日を取得（利用可能な場合）
# 注意：中国語のローカライズには対応する設定が必要な場合があります
weekday_abbrev = datetime_series.dt.day_name().str[:3]
print("n=== 曜日の略称 ===")
print(weekday_abbrev)

# 5. より直感的な比較表を作成
print("n=== 日付と曜日の対照表 ===")
result = pd.DataFrame({
    '日付': datetime_series.dt.date,
    '曜日値': weekdays,
    '曜日名': weekday_names
})
print(result)

例2：平日と週末の区別

例

import pandas as pd
import numpy as np

# 取引データを作成
print("=== 取引データの作成 ===")
np.random.seed(100)

# 35日分のデータを生成（複数の週末を含む）
dates = pd.date_range('2023-03-01', periods=35, freq='D')
df = pd.DataFrame({
    'date': dates,
    'sales': np.random.randint(1000, 5000, 35)
})

# 曜日を抽出
df['weekday'] = df['date'].dt.weekday
df['day_name'] = df['date'].dt.day_name()

# 平日と週末をマーク
df['is_weekend'] = df['weekday'].isin([5, 6])
df['day_type'] = df['is_weekend'].map({True: '週末', False: '平日'})

print(df.head(15))

# 平日/週末でグループ化して集計
print("n=== 平日 vs 週末の売上比較 ===")
day_type_stats = df.groupby('day_type')['sales'].agg(['sum', 'mean', 'count'])
day_type_stats.columns = ['総売上', '平均売上', '日数']
print(day_type_stats)

# 各曜日ごとの統計に詳細化
print("n=== 各曜日の売上統計 ===")
weekday_stats = df.groupby('weekday')['sales'].agg(['sum', 'mean'])
weekday_stats.index = ['月曜', '火曜', '水曜', '木曜', '金曜', '土曜', '日曜']
weekday_stats.columns = ['総売上', '平均売上']
print(weekday_stats.round(2))

# 週末のデータをすべて抽出
print("n=== 週末データ ===")
weekend_data = df[df['is_weekend']][['date', 'day_name', 'sales']]
print(weekend_data)

  • isin([5, 6])週末かどうかを判定できます（土曜=5、日曜=6）。

例3：曜日パターンの詳細分析

例

import pandas as pd
import numpy as np

# より長期間のデータセットを作成
print("=== 90日間のデータセットを作成 ===")
np.random.seed(200)

# 90日分のデータを生成
dates = pd.date_range('2023-01-01', periods=90, freq='D')
df = pd.DataFrame({
    'date': dates,
    'visitors': np.random.randint(100, 1000, 90),
    'revenue': np.random.randint(5000, 30000, 90)
})

# 曜日の特徴を抽出
df['weekday'] = df['date'].dt.weekday
df['is_weekend'] = df['weekday'].isin([5, 6])

# 1. 各曜日の平均パフォーマンスを計算
print("=== 各曜日のパフォーマンス分析 ===")
weekday_analysis = df.groupby('weekday').agg({
    'visitors': 'mean',
    'revenue': 'mean'
}).round(2)

weekday_analysis.index = ['月曜', '火曜', '水曜', '木曜', '金曜', '土曜', '日曜']
weekday_analysis.columns = ['平均訪問者', '平均収入']
print(weekday_analysis)

# 2. 最も好調な曜日と最も不振な曜日を特定
print("n=== 最も好調な曜日と最も不振な曜日 ===")
best_day = weekday_analysis['平均収入'].idxmax()
worst_day = weekday_analysis['平均収入'].idxmin()
print(f"収入最高: {best_day}、平均 {weekday_analysis.loc[best_day, '平均収入']:,.0f}")
print(f"収入最低: {worst_day}、平均 {weekday_analysis.loc[worst_day, '平均収入']:,.0f}")

# 3. 平日と週末の比較
print("n=== 平日vs週末の詳細比較 ===")
weekend_comparison = df.groupby('is_weekend').agg({
    'visitors': ['mean', 'std', 'sum'],
    'revenue': ['mean', 'std', 'sum']
}).round(2)
weekend_comparison.index = ['平日', '週末']
print(weekend_comparison)

# 4. 平日タイプをマーク
print("n=== 平日タイプのマーク ===")

注意事項

重要なお知らせ：

  • Series.dt.weekdaydatetime64 型の Series でのみ使用できます。
  • 戻り値の範囲は 0〜6 で、0 は月曜、6 は日曜を表します。
  • 曜日名が必要な場合は、dt.day_name()メソッドを使用します。
  • 欠損値（NaT）を含むデータを処理する場合、dt.weekday対応する位置の NaT を返します。
  • 注意：weekday属性とdayofweek属性は同等ですが、名前が異なるだけです。
