C 言語チュートリアル

C言語は、汎用的な手続き型のコンピュータプログラミング言語です。1972年、UNIXオペレーティングシステムの移植と開発のために、デニス・リッチーがベル電話研究所でC言語を設計・開発しました。

C言語は広く使用されているコンピュータ言語であり、Javaプログラミング言語と同じくらい普及していて、両者とも現代のソフトウェアプログラマーの間で広く使用されています。

現在の最新のC言語標準はC18であり、それ以前のC言語標準にはC17、C11...C99などがあります。

さあ、Cプログラミングの学習を始めましょう！

Cプログラムのコンパイル/実行

サンプル

#include <stdio.h> int main() { /*私の最初のCプログラム*/ printf("Hello, World! \n"); return 0; }

サンプルを実行 »

サンプル解説：

  • すべてのC言語プログラムには、次のものを含める必要がありますmain()関数。コードはmain()関数から実行を開始します。
  • /* ... */コメントに使用します。
  • printf()画面へのフォーマット出力に使用します。printf()関数は"stdio.h"ヘッダーファイルで宣言されています。
  • stdio.hはヘッダーファイル（標準入出力ヘッダーファイル）です。#includeはプリプロセッサ命令であり、ヘッダーファイルをインクルードするために使用します。printf()関数の場合、もしstdio.hヘッダーファイルが見つからないと、コンパイルエラーが発生します。
  • return 0;文はプログラムの終了を示すために使用します。

    939

    warning: implicitly declaring library function 'printf' with type'int (const char *, ...)' [-Wimplicit-function-declaration]

    上記の警告は通常、ヘッダーファイルを含めずに#include <stdio.h>使用するprintf場合に発生します。

    int main(){
    printf("Hello, World!\n");
    return 0;
}

    この警告が示す意味は次のとおりです：型「int (const char *,...)」でライブラリ関数printfが暗黙的に宣言されています。

    この警告の背景知識：printfのようなライブラリ関数はあまりにも一般的に使用されるため、コンパイラはコンパイル中に、ソースファイル内でprintf関数が宣言されていないのに直接使用されていることを発見すると、printf関数の暗黙的な宣言を生成します。そのコンパイラは、printfに対して生成した暗黙の宣言を次のように通知しています：int printf(const char *, ...)

    この警告の結果：通常、この警告はエラーではなく単なるwarningであり、コンパイルは依然として成功します。

    解決策：この警告を消すには、printfの宣言を追加するだけで十分です。printf関数はライブラリ関数であり、その宣言はstdio.hファイルにあります。したがって、ソースファイルに#include <stdio.h>それだけで十分です。
