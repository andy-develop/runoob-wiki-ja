Matplotlib colorbar() 関数

Matplotlib リファレンスドキュメント

colorbar()グラフにカラーバー（色スケール）を追加し、色を数値範囲にマッピングするために使用します。

カラーバーは colormap と組み合わせて使用する必要な要素であり、読者が色を元のデータ値にマッピングできるようにします。

関数定義

matplotlib.pyplot.colorbar(mappable=None, cax=None, ax=None, **kwargs)
Figure.colorbar(mappable=None, cax=None, ax=None, use_gridspec=True,
    **kwargs)

パラメータ説明

パラメータ説明
mappable色をマッピングできるオブジェクト。例：imshow()、scatter()、contourf() の戻り値（必須）
axカラーバーが属する Axes（推奨、レイアウトを自動調整）
cax専用のカラーバー Axes（詳細に制御する場合に使用）
shrinkカラーバーの Axes に対する拡大縮小比率。デフォルトは 1.0、よく使われるのは 0.8
aspectカラーバーのアスペクト比。デフォルトは 20
labelカラーバーのラベルテキスト
orientation'vertical'（デフォルト）または 'horizontal'
ticksカスタム目盛り位置
extend'neither'/'both'/'min'/'max'、範囲外の色の指示
padカラーバーと Axes の間隔

使用fig.colorbar(im, ax=ax)は推奨される書き方で、サブプロットのレイアウトを自動調整してカラーバーのためのスペースを確保します。

使用例

例1：imshow + 垂直カラーバー

例

import matplotlib.pyplot as plt
import numpy as np

data = np.random.rand(10, 10)

fig, ax = plt.subplots(figsize=(6, 5), layout='constrained')

im = ax.imshow(data, cmap='viridis', aspect='auto')

# 垂直カラーバーを追加
cbar = fig.colorbar(im, ax=ax, label='Value', shrink=0.8)

ax.set_title('imshow with Colorbar')
ax.set_xlabel('Column')
ax.set_ylabel('Row')
plt.show()

例2：水平カラーバー + カスタム目盛り

例

import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(-3, 3, 100)
y = np.linspace(-3, 3, 100)
X, Y = np.meshgrid(x, y)
Z = np.sin(X) * np.cos(Y)

fig, ax = plt.subplots(figsize=(7, 5), layout='constrained')

im = ax.contourf(X, Y, Z, levels=15, cmap='coolwarm')

# 水平カラーバー（Axes の下）
cbar = fig.colorbar(im, ax=ax,
                     orientation='horizontal',
                     label='Amplitude',
                     shrink=0.8,
                     pad=0.08,
                     ticks=[-0.8, -0.4, 0, 0.4, 0.8])

ax.set_title('Horizontal Colorbar')
ax.set_xlabel('X')
ax.set_ylabel('Y')
plt.show()

例3：scatter + カラーバー

例

import matplotlib.pyplot as plt
import numpy as np

np.random.seed(42)
n = 100
x = np.random.rand(n) * 10
y = np.random.rand(n) * 10
values = np.random.rand(n) * 100  # 色マッピングのデータ

fig, ax = plt.subplots(figsize=(7, 5), layout='constrained')

sc = ax.scatter(x, y, c=values, cmap='YlOrRd',
                s=100, edgecolors='white', linewidth=0.5)

# scatter が返す PathCollection も colorbar に渡せます
cbar = fig.colorbar(sc, ax=ax, label='Score', shrink=0.8)

ax.set_title('Scatter with Colorbar')
ax.set_xlabel('X')
ax.set_ylabel('Y')
plt.show()

よくある質問

カラーバーによってサブプロットのサイズが一貫しなくなる？

使用layout='constrained'パラメータで自動処理できます。

または Figure 上で呼び出しますfig.colorbar(im, ax=axes)影響を受けるすべての Axes のリストを渡します。

複数のサブプロットで1つのカラーバーを共有するには？

1つの colorbar を複数のサブプロットに関連付ける場合、次を渡しますax=axes_list。
