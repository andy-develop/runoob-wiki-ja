Matplotlib リファレンスドキュメント

Matplotlib は Python で最も広く使用されているデータ可視化ライブラリであり、静的、動的、およびインタラクティブなグラフを作成できます。

このドキュメントは、Matplotlib のすべての公開インターフェースの関数とメソッドを完全にまとめており、対応する機能と使用方法をすばやく参照できます。

2つのプログラミングインターフェース

Matplotlib は2つの使用方法を提供しており、さまざまなシナリオに適しています。

特性 Axes インターフェース（明示的/オブジェクト指向） pyplot インターフェース（暗黙的/関数型）
使用方法 最初に Figure と Axes オブジェクトを作成し、次にオブジェクトメソッドを呼び出す pyplot モジュールの関数を直接呼び出し、現在のグラフを暗黙的に操作する
適用シーン 複雑なグラフ、複数のサブプロット、細かい制御が必要な場合 高速プロット、インタラクティブな探索、単純なグラフ
コード例 fig, ax = plt.subplots(); ax.plot(x, y) plt.plot(x, y); plt.title("标题")
推奨度 推奨（より明確で、より制御しやすい） 単純なシナリオと迅速なプロトタイピングに適しています

Axes インターフェースは公式推奨のプログラミング方法であり、コードロジックがより明確で、複数のサブプロットや複雑なグラフを扱う際にエラーが発生しにくくなります。簡単に参照できるように、以下では pyplot 関数と対応する Axes メソッドを併記しています。

例1：基本的な折れ線グラフと散布図

明示的な Axes インターフェースを使用して、複数の曲線と注釈を含むグラフを作成します。

実例

import matplotlib.pyplot as plt
import numpy as np

# データを生成：0 から 10 までの等間隔な 100 点
x = np.linspace(0, 10, 100)
y1 = np.sin(x)   # 正弦関数
y2 = np.cos(x)   # 余弦関数

# Figure と Axes を作成（明示的インターフェース、推奨）
fig, ax = plt.subplots(figsize=(8, 4), layout='constrained')

# 2 本の折れ線を描画し、色・線種・ラベルを設定
ax.plot(x, y1, label='sin(x)', color='blue', linewidth=2)
ax.plot(x, y2, label='cos(x)', color='red', linestyle='--', linewidth=2)

# ピーク位置にハイライト散布点を追加
peak_idx_sin = np.argmax(y1)
peak_idx_cos = np.argmax(y2)
ax.scatter(x[peak_idx_sin], y1[peak_idx_sin],
           color='blue', s=100, zorder=5)
ax.scatter(x[peak_idx_cos], y2[peak_idx_cos],
           color='red', s=100, zorder=5)

# 装飾：タイトル、軸ラベル、凡例、グリッド
ax.set_title('Sine and Cosine Functions', fontsize=14)
ax.set_xlabel('x (radians)')
ax.set_ylabel('Amplitude')
ax.legend(loc='upper right')
ax.grid(True, alpha=0.3)

plt.show()
print("runoob: plot displayed successfully")

例2：複数サブプロットレイアウト（2x2）

1 つの Figure 内で異なるタイプのサブプロットを作成する方法を示します。

実例

import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(0, 2 * np.pi, 100)

# 2x2 のサブプロットを作成（オブジェクト指向インターフェース）
fig, axes = plt.subplots(2, 2, figsize=(10, 8), layout='constrained')
fig.suptitle('Multi-panel RUNOOB Demo', fontsize=16)

# サブプロット (0,0)：折れ線グラフ
axes[0, 0].plot(x, np.sin(x), color='tab:blue', linewidth=2)
axes[0, 0].set_title('Line Plot')
axes[0, 0].set_ylabel('sin(x)')

# サブプロット (0,1)：散布図
np.random.seed(42)
colors = np.random.rand(50)
sizes = np.random.rand(50) * 200
axes[0, 1].scatter(np.random.rand(50), np.random.rand(50),
                   c=colors, s=sizes, alpha=0.6, cmap='viridis')
axes[0, 1].set_title('Scatter Plot')

# サブプロット (1,0)：棒グラフ（数値ラベル付き）
categories = ['A', 'B', 'C', 'D', 'E']
values = [23, 45, 56, 78, 32]
bars = axes[1, 0].bar(categories, values,
                       color='tab:green', edgecolor='white')
axes[1, 0].bar_label(bars)  # 棒の上に数値を表示
axes[1, 0].set_title('Bar Chart')

# サブプロット (1,1)：ヒストグラム
data = np.random.randn(1000)
axes[1, 1].hist(data, bins=30, color='tab:orange',
                edgecolor='white', alpha=0.8)
axes[1, 1].axvline(x=0, color='red', linestyle='--', linewidth=2)
axes[1, 1].set_title('Histogram')

plt.show()

例3：ヒートマップと等高線の比較

同じ Figure 内で imshow と contourf の 2 つの方法で 2 次元データを可視化します。

実例

import matplotlib.pyplot as plt
import numpy as np

# 2 次元グリッドデータを作成
x = np.linspace(-3, 3, 100)
y = np.linspace(-3, 3, 100)
X, Y = np.meshgrid(x, y)
Z = np.sin(X) * np.cos(Y)  # 2 次元関数の値

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5),
                                layout='constrained')

# 左の図：ヒートマップ（imshow）
im = ax1.imshow(Z, extent=[-3, 3, -3, 3], origin='lower',
                cmap='viridis', aspect='auto')
ax1.set_title('Heatmap (imshow)', fontsize=14)
ax1.set_xlabel('X')
ax1.set_ylabel('Y')
fig.colorbar(im, ax=ax1, label='Amplitude', shrink=0.8)

# 右の図：塗りつぶし等高線（contourf）
contour = ax2.contourf(X, Y, Z, levels=15, cmap='RdYlBu')
# 等高線の境界を重ねる
ax2.contour(X, Y, Z, levels=15, colors='black', linewidths=0.5)
ax2.set_title('Filled Contour (contourf)', fontsize=14)
ax2.set_xlabel('X')
ax2.set_ylabel('Y')
fig.colorbar(contour, ax=ax2, label='Amplitude', shrink=0.8)

plt.show()

例4：スタイルの切り替えと画像の保存

スタイルシートと rcParams を使用して外観をカスタマイズし、高品質な画像を保存します。

実例

import matplotlib.pyplot as plt
import numpy as np

# ggplot スタイルを使用し、一部のパラメータを微調整
plt.style.use('ggplot')
plt.rcParams['figure.figsize'] = [8, 6]
plt.rcParams['font.size'] = 12

x = np.linspace(0, 10, 50)
y1 = np.exp(-x/3) * np.sin(2 * x)  # 減衰正弦波
y2 = np.exp(-x/3) * np.cos(2 * x)  # 減衰余弦波

fig, ax = plt.subplots()
ax.plot(x, y1, 'o-', label='Damped sin', markersize=6)
ax.plot(x, y2, 's--', label='Damped cos', markersize=6)

# 最初のピークに注釈を付ける
peak_idx = np.argmax(y1)
ax.annotate(f'Peak: {y1[peak_idx]:.2f}',
            xy=(x[peak_idx], y1[peak_idx]),
            xytext=(x[peak_idx] + 1.5, y1[peak_idx] + 0.15),
            arrowprops=dict(arrowstyle='-&gt;', color='gray'),
            fontsize=10)

ax.set_title('Damped Oscillation', fontsize=16)
ax.set_xlabel('Time (s)')
ax.set_ylabel('Amplitude')
ax.legend()
ax.grid(True)

# 300 DPI の高品質 PNG として保存
fig.savefig('runoob_damped_oscillation.png',
            dpi=300, bbox_inches='tight')
print("runoob: figure saved successfully")

plt.show()

例5：mosaic 複雑レイアウト

subplot_mosaic を使用して不均一なサブプロット配置を作成します。

実例

import matplotlib.pyplot as plt
import numpy as np

# mosaic 文字列でレイアウトを定義：
# 'A' は上部の 1 行全体にまたがり、'B' と 'C' は左下と左中央、'D' は右下を縦方向に占有
layout = """
A A A
B C D
"""

fig, axes = plt.subplot_mosaic(layout, figsize=(10, 6),
                                layout='constrained')
fig.suptitle('Complex Mosaic Layout (RUNOOB)', fontsize=16)

# パネル A：折れ線グラフ（上部にまたがる）
x = np.linspace(0, 10, 100)
axes['A'].plot(x, np.sin(x), label='sin(x)')
axes['A'].plot(x, np.cos(x), label='cos(x)')
axes['A'].set_title('Panel A: Line Plot')
axes['A'].legend()

# パネル B：円グラフ
sizes = [30, 25, 20, 15, 10]
labels = ['Python', 'Java', 'C++', 'Rust', 'Go']
axes['B'].pie(sizes, labels=labels, autopct='%1.1f%%',
              startangle=90)
axes['B'].set_title('Panel B: Pie Chart')

# パネル C：棒グラフ
axes['C'].bar(['X', 'Y', 'Z'], [10, 25, 15],
              color=['#ff6b6b', '#4ecdc4', '#45b7d1'])
axes['C'].set_title('Panel C: Bar Chart')

# パネル D：ヒートマップ
matrix = np.random.rand(5, 5)
im = axes['D'].imshow(matrix, cmap='Blues', aspect='auto')
axes['D'].set_title('Panel D: Heatmap')
fig.colorbar(im, ax=axes['D'])

plt.show()

例6：双 y 軸と埋め込みサブプロット

secondary_axis、twinx、inset_axes の使い方を示します。

実例

import matplotlib.pyplot as plt
import numpy as np

fig, ax = plt.subplots(figsize=(8, 5), layout='constrained')

x = np.linspace(0, 10, 100)

# メインのグラフ：次元の異なる 2 本の曲線を描画
ax.plot(x, np.sin(x), 'b-', label='sin(x) [amplitude]')
ax.set_xlabel('x (radians)')
ax.set_ylabel('sin(x)', color='blue')
ax.tick_params(axis='y', labelcolor='blue')

# 二重 y 軸を作成（x 軸を共有）
ax2 = ax.twinx()
ax2.plot(x, np.exp(x/5), 'r--', label='exp(x/5) [growth]')
ax2.set_ylabel('exp(x/5)', color='red')
ax2.tick_params(axis='y', labelcolor='red')

# ax に埋め込みサブプロットを追加（局所領域を拡大）
axins = ax.inset_axes([0.15, 0.5, 0.3, 0.35])
axins.plot(x, np.sin(x), 'b-')
axins.set_xlim(3, 5)
axins.set_ylim(-1.2, 1.2)
axins.set_title('Zoomed Region')
axins.grid(True, alpha=0.3)

# メインのグラフに埋め込み領域をマーク
ax.indicate_inset_zoom(axins, edgecolor='gray')

ax.set_title('Dual Y-Axes with Inset Zoom', fontsize=14)
plt.show()

よくある質問

グラフが表示されない

を呼び出したか確認してくださいplt.show()。

非インタラクティブバックエンド（Agg など）では明示的に呼び出す必要がありますshow()。

Jupyter Notebook では、を使用します%matplotlib inlineマジックコマンドにより、グラフがインライン表示されるようにします。

目盛りが多すぎる、または順序が乱れる

よくある原因は、文字列リストを（数値や日時ではなく）データとして渡していることです。

Matplotlib は文字列リストをカテゴリ変数として扱い、一意の値ごとに1つの目盛りを作成し、出現順に並べます。

解決方法：文字列を数値に変換します。例：np.asarray(data, dtype='float') 或 np.asarray(data, dtype='datetime64[s]')。

中国語が四角い枠で表示される

Matplotlib のデフォルトフォント（DejaVu Sans）には中国語のグリフが含まれていないため、中国語をサポートするフォントを指定する必要があります。

設定plt.rcParams['font.sans-serif'] = ['SimHei', 'Arial Unicode MS', ...]また、そのシステムに当該フォントがインストールされていることを確認してください。

ラベルが重なる、または切り詰められる

Figure を作成する際に使用することを推奨します。layout='constrained' 或 layout='compressed'パラメータを使用すると、ラベル・タイトル・凡例の重なりを自動的に処理できます。

また、使用することもできます。fig.tight_layout() 或 fig.subplots_adjust()手動で調整します。

pcolor と pcolormesh の違い

pcolor()PolyCollection を作成し、レンダリングは遅いですが、より正確です。

pcolormesh()QuadMesh を作成し、レンダリング速度が速いため、ほとんどのシナリオで推奨される選択肢です。

非常に大きなグリッドの場合、pcolorfast()imshow 方式で描画すると、速度は最速ですが精度は最低です。
