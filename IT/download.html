JSのdownloadライブラリを使用してリソースをダウンロード

カテゴリ プログラミング技術

HTML5のaタグはdownload属性を使用してリソースのダウンロードを設定できますが、同一オリジンである必要があり、ブラウザが解析できる場合は直接開かれてしまいます。

このような場合、サードパーティ製ライブラリのdownloadを使用して、より完全なダウンロード機能を実現できます。

download.js 関連リソース：

  • Github アドレス：https://github.com/rndme/download
  • CDN ライブラリ：https://lf26-cdn-tos.bytecdntp.com/cdn/expire-1-M/downloadjs/1.4.8/download.min.js
  • NPM インストール：npm install downloadjs

download.jsライブラリは、ファイルをダウンロードするためのdownload()関数を提供します。

ダウンロードする内容は、URL、文字列、Blob、型付きデータ配列、またはファイルデータをbase64またはURLエンコード文字列として表したdataURLのいずれかです。

入力形式に関係なく、download()は指定されたファイル名とMIME情報を使用して、Content-Disposition HTTPヘッダーを使用するサーバーと同じ方法でファイルを保存します。

download(data, strFileName, strMimeType);
  • data - ダウンロードするデータ内容。Blob、File、String、またはdataURLを指定できます。
  • strFileName - 作成するファイルの名前。
  • strMimeType - ダウンロードするファイルのMIMEコンテンツタイプ。

例

テキスト

文字列をdlText.txtファイルに保存してダウンロード：

download("hello world", "dlText.txt", "text/plain");

dataURLテキストの例：

download("data:text/plain,hello%20world", "dlDataUrlText.txt", "text/plain");

blobテキストの例：

download(new Blob(["hello world"]), "dlTextBlob.txt", "text/plain");

urlの例：

download("/robots.txt");

UInt8テキスト配列の例：

var str= "hello world",    arr= new Uint8Array(str.length);
str.split("").forEach(function(a,b){
  arr[b]=a.charCodeAt();
});

download( arr, "textUInt8Array.txt", "text/plain" );

HTML

HTML文字列の例：
download(document.documentElement.outerHTML, "dlHTML.html", "text/html");

HTML Blobの例：

download(new Blob(["hello world".bold()]), "dlHtmlBlob.html", "text/html");

ajaxコールバックの例：

$.ajax({
        url: "/download.html",
        success: download.bind(true, "text/html", "dlAjaxCallback.html")
});

バイナリファイル

画像URL：

download("/diff6.png");

画像を非同期でダウンロード：

var x=new XMLHttpRequest();
x.open( "GET", "/diff6.png" , true);
x.responseType="blob";
x.onload= function(e){download(e.target.response, "awesomesauce.png", "image/png");};
x.send();
