Font Awesome アイコン

Font Awesome は、Web デザインと開発に使用される人気のアイコンフォントライブラリです。

Font Awesome には一連のベクターアイコンが含まれており、CSS で簡単に呼び出して使用できます。サイズ、色、影などをカスタマイズできます。

Font Awesome はもともと Dave Gandy によって作成されたオープンソースプロジェクトで、従来の画像アイコンに代わる、柔軟で使いやすく拡張性のあるアイコンセットを提供することを目的としています。

Font Awesome は多くのバージョンに更新されており、現在主流なのはFont Awesome 6 、Font Awesome 5およびFont Awesome 4です。すべてのバージョンは次のものを参照できます：https://fontawesome.com/versions。

当サイトのテストでは、次を使用していますFont Awesome 4。アイコンリスト：https://fontawesome.com/v4/icons/。

Font Awesome アイコンを使用するには、HTML ページの<head>セクションに次の行を追加してください：

1. 中国国内推奨CDN：

<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/4.7.0/css/font-awesome.min.css">

2. 海外推奨CDN

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/font-awesome@4.7.0/css/font-awesome.min.css">

3. ローカルに直接ダウンロード

Download

注意：ダウンロードしてインストールするのはあまりおすすめしません。HTML 文書のヘッダーで CDN ファイルを直接参照するだけでよいです。

注意：本チュートリアルでは 4.7.0 バージョンを使用しています。

プレフィックスを使用でき、faアイコン名を使用して Font Awesome アイコンを配置できます。

例

<!DOCTYPE html> <html> <head> <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/4.7.0/css/font-awesome.min.css"> </head> <body> <i class="fa fa-car"></i> <i class="fa fa-car" style="font-size:48px;"></i> <i class="fa fa-car" style="font-size:60px;color:red;"></i> </body> </html>

Font Awesome はインライン要素と一緒に使用するように設計されています。アイコンには <i> 要素と <span> 要素が広く使用されます。

また、アイコンのコンテナのフォントサイズや色を変更すると、アイコンも変更されますので注意してください。

大きいアイコン

fa-lg（33% 増加）、fa-2x、fa-3x、fa-4x、または fa-5x クラスは、コンテナに対するアイコンのサイズを拡大するために使用します。

例

<!DOCTYPE html> <html> <head> <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/4.7.0/css/font-awesome.min.css"> </head> <body> <i class="fa fa-car fa-lg"></i> <i class="fa fa-car fa-2x"></i> <i class="fa fa-car fa-3x"></i> <i class="fa fa-car fa-4x"></i> <i class="fa fa-car fa-5x"></i> </body> </html>

リストアイコン

fa-ul クラスと fa-li クラスは、順序なしリストのデフォルトの先頭記号を置き換えるために使用します。

例

<ul class="fa-ul"> <li><i class="fa-li fa fa-check-square"></i>List icons</li> <li><i class="fa-li fa fa-spinner fa-spin"></i>List icons</li> <li><i class="fa-li fa fa-square"></i>List icons</li> </ul>

結果：

  • List icons
  • List icons

枠線と引き出しアイコン

fa-border、fa-pull-right または fa-pull-left クラスは、プル引用や記事内アイコンに使用します。

スタックされたアイコン

複数のアイコンを積み重ねるには、親要素で fa-stack クラスを使用します。fa-stack-1x クラスは通常サイズのアイコン、fa-stack-2x クラスは大きめのアイコンに使用します。

fa-inverse クラスはアイコンの色を反転させるために使用できます。親要素にさらに大きなアイコンのクラスを追加して、サイズを細かく調整することもできます。

例

<span class="fa-stack fa-lg"> <i class="fa fa-circle-thin fa-stack-2x"></i> <i class="fa fa-twitter fa-stack-1x"></i> </span> fa-twitter on fa-circle-thin<br> <span class="fa-stack fa-lg"> <i class="fa fa-circle fa-stack-2x"></i> <i class="fa fa-twitter fa-stack-1x fa-inverse"></i> </span> fa-twitter (inverse) on fa-circle<br> <span class="fa-stack fa-lg"> <i class="fa fa-camera fa-stack-1x"></i> <i class="fa fa-ban fa-stack-2x text-danger" style="color:red;"></i> </span> fa-ban on fa-camera

結果：

fa-twitter on fa-circle-thin
fa-twitter (inverse) on fa-circle
fa-ban on fa-camera

固定幅アイコン

fa-fw クラスは、アイコンの固定幅を設定するために使用します。異なるアイコンの幅が揃っていない場合に便利です。特に Bootstrap のナビゲーションリストやリストグループに適しています。

例

<div class="list-group"> <a href="#" class="list-group-item"><i class="fa fa-home fa-fw"></i> Home</a> <a href="#" class="list-group-item"><i class="fa fa-book fa-fw"></i> Library</a> <a href="#" class="list-group-item"><i class="fa fa-pencil fa-fw"></i> Applications</a> <a href="#" class="list-group-item"><i class="fa fa-cog fa-fw"></i> Settings</a> </div>
