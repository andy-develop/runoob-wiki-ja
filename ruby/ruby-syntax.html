Ruby 構文

簡単なRubyプログラムを書いてみましょう。すべてのRubyファイル拡張子は.rbです。したがって、以下のソースコードをtest.rbファイルに保存してください。

サンプル

#!/usr/bin/ruby -w puts "Hello, Ruby!";

サンプルを実行 »

ここでは、/usr/bin ディレクトリにRubyインタープリタが既に利用可能であると仮定します。では、このプログラムを以下のように実行してみてください：

$ ruby test.rb

これにより以下の結果が得られます：

Hello, Ruby!

簡単なRubyプログラムを確認しました。次に、Ruby構文に関連するいくつかの基本概念を見てみましょう：

Rubyプログラムの空白

Rubyコード内の空白文字（スペースやタブなど）は、文字列内に現れる場合を除いて通常無視されます。ただし、あいまいな文を解釈するために使用されることもあります。-w オプションを有効にすると、この解釈により警告が生成されます。

サンプル：

a + b 被解释为 a+b （这是一个局部变量）
a  +b 被解释为 a(+b) （这是一个方法调用）

Rubyプログラムの行末

Rubyはセミコロンと改行を文の終わりとして解釈します。ただし、Rubyが行末で +、-、またはバックスラッシュなどの演算子に遭遇した場合、それらは文の継続を示します。

Ruby識別子

識別子は変数、定数、メソッドの名前です。Ruby識別子は大文字と小文字を区別します。つまり、Ram と RAM はRubyでは2つの異なる識別子です。

Ruby識別子の名前には、英字、数字、アンダースコア文字（ _ ）を含めることができます。

予約語

次の表はRubyの予約語を示しています。これらの予約語は定数や変数の名前として使用できません。ただし、メソッド名としては使用できます。

RubyのHere Document

"Here Document" は複数行の文字列を作成することを指します。<< の後に、文字列を終了するための文字列または識別子を指定でき、現在の行から終了子までのすべての行が文字列の値になります。

終了子が引用符で囲まれている場合、引用符の種類によって行指向の文字列の型が決まります。<< と終了子の間にスペースがないように注意してください。

以下は異なるサンプルです：

サンプル

#!/usr/bin/ruby -w # -*- coding : utf-8 -*- print <<EOFこれは最初の方法で作成しますhere document。複数行の文字列。EOF print <<"EOF"; #上記と同じこれは2番目の方法で作成しますhere document。複数行の文字列。EOF print <<`EOC` #コマンドを実行 echo hi there echo lo there EOC print <<"foo", <<"bar" #それらを積み重ねることができます I said foo. foo I said bar. bar

サンプルを実行 »

これにより以下の結果が得られます：

这是第一种方式创建here document 。
多行字符串。
这是第二种方式创建here document 。
多行字符串。
hi there
lo there
I said foo.
I said bar.

Ruby BEGIN文

構文

BEGIN {
   code
}

宣言codeプログラムの実行前に呼び出されます。

サンプル

#!/usr/bin/ruby puts "これはメインのRubyプログラムです" BEGIN { puts "Rubyプログラムを初期化します" }

これにより以下の結果が得られます：

初始化 Ruby 程序
这是主 Ruby 程序

Ruby END文

構文

END {
   code
}

宣言codeプログラムの終了時に呼び出されます。

サンプル

#!/usr/bin/ruby puts "これはメインのRubyプログラムです" END { puts "Rubyプログラムを停止します" } BEGIN { puts "Rubyプログラムを初期化します" }

これにより以下の結果が得られます：

初始化 Ruby 程序
这是主 Ruby 程序
停止 Ruby 程序

Rubyコメント

コメントは、Rubyインタープリタから1行、または1行の一部、または複数行を隠します。行頭で文字（ # ）を使用できます：

#私はコメントです。無視してください。

または、コメントは文や式と同じ行の後ろに続けることもできます：

name = "Madisetti" #これもコメントです

次のように複数行をコメントアウトできます：

#これはコメントです。 #これもコメントです。 #これもコメントです。 #これもまだコメントです。

以下は別の形式です。このブロックコメントは、=begin/=end の間の行をインタープリタから隠します：

=beginこれはコメントです。これもコメントです。これもコメントです。これもまだコメントです。=end

    here document の紹介

    構築するhere document最も一般的な構文は<<識別子が続き、次の行から引用したいテキストが始まり、その後、別の行で同じ識別子を使用して閉じます。

    puts <<EOF
这是第一行
这是第二行
EOF

    実行出力結果は次のとおりです：

    これは一行目です
これは二行目です

    より多くの使い方は以下のサンプルを参照してください：

    #!/usr/bin/ruby -w
# -*- coding : utf-8 -*-

#（<<）here doucument 感觉本来单行是一个整体变成是一种多行作为一个整体进行导入的方式和 sh 语法相似

print <<EOF
    这是第一种方式创建 here document
    多行字符串。
EOF

print <<"EOF";                # 与上面相同
    这是第二种方式创建here document
    多行字符串。
EOF

print <<`EOC`                 # 执行命令
    ls -al;
    ps -a
EOC

print <<"foo", <<"bar"          # 您可以把它们进行堆叠
    I said foo.
foo
    I said bar.
bar
text =  <<`foo`            # 您可以把它们进行转存
    cat /etc/passwd
foo

puts text

File.open("/home/abc","w") do |io|
    io.write(text)
end
puts "------------------------"
exec "ls -al /home/ && cat /home/abc"
