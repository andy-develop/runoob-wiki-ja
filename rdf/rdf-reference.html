RDF 拡張子とMIMEタイプ

RDFファイルの推奨拡張子は.rdfただし、拡張子.XMLは、古いXMLパーサーとの互換性のために頻繁に使用されます。

MIMEタイプ："application/rdf+xml"。

RDFS / RDF クラス

要素 类 サブクラス
rdfs:Class All classes  
     
rdfs:Datatype Data types Class
rdfs:Resource All resources Class
     
rdfs:Container Containers Resource
rdfs:Literal Literal values (text and numbers) Resource
     
rdf:List Lists Resource
rdf:Property Properties Resource
rdf:Statement Statements Resource
     
rdf:Alt Containers of alternatives Container
rdf:Bag Unordered containers Container
rdf:Seq Ordered containers Container
     
rdfs:ContainerMembershipProperty Container membership properties Property
rdf:XMLLiteral XML literal values Literal

RDFS / RDF プロパティ

要素 ドメイン レンジ 説明
rdfs:domain Property Class リソースのドメイン
rdfs:range Property Class リソースのレンジ
rdfs:subPropertyOf Property Property このプロパティは別のプロパティのサブプロパティです
       
rdfs:subClassOf Class Class このリソースは別のクラスのサブクラスです
rdfs:comment Resource Literal 人間が読めるリソースの説明
rdfs:label Resource Literal 人間が読めるリソースのラベル（名前）
rdfs:isDefinedBy Resource Resource リソースの定義
rdfs:seeAlso Resource Resource リソースに関するその他の情報
rdfs:member Resource Resource リソースのメンバー
       
rdf:first List Resource  
rdf:rest List List  
rdf:subject Statement Resource RDFステートメントのリソースの主語
rdf:predicate Statement Resource RDFステートメント内のリソースの述語
rdf:object Statement Resource RDFステートメントのリソースの目的語
rdf:value Resource Resource value属性
rdf:type Resource Class リソースはクラスのインスタンスです

RDF プロパティ

要素 ドメイン レンジ 説明
       
rdf:about     記述されているリソースを定義します
rdf:Description     リソース記述のコンテナ
rdf:resource     プロパティを識別するためのリソースを定義します
rdf:datatype     要素のデータ型を定義します
rdf:ID     要素のIDを定義します
rdf:li     リストを定義します
rdf:_n     ノードを定義します
rdf:nodeID     要素ノードのIDを定義します
rdf:parseType     要素の解析方法を定義します
rdf:RDF     RDFドキュメントのルート
xml:base     XMLベースを定義します
xml:lang     要素コンテンツの言語を定義します
       
rdf:aboutEach     （削除）
rdf:aboutEachPrefix     （削除）
rdf:bagID     （削除）

「削除」と説明されているものは、最近RDF標準から削除された要素です。
