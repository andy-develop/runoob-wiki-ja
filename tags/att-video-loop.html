HTML <video> タグ

例

ループ再生に設定された video 要素：

<video controls loop>
  <source src="movie.mp4.html" type="video/mp4">
  <source src="movie.ogg.html" type="video/ogg">
お使いのブラウザは video タグをサポートしていません。

ブラウザサポート

すべての主要ブラウザが loop 属性をサポートしています。

注意：Internet Explorer 8 およびそれ以前の IE バージョンは <video> タグをサポートしていません。

定義と使い方

loop 属性は boolean（ブール）属性です。

loop 属性は、動画が終了した後に再生を再開することを指定します。

この属性を設定すると、動画はループ再生されます。

HTML 4.01 と HTML5 の違い

<video> タグは HTML5 の新しいタグです。

HTML と XHTML の違い

XHTML では属性の省略は許可されておらず、loop 属性は <video loop="loop"> と定義する必要があります。

構文

<video loop>
