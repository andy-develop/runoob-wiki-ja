HTML ISO-8859-1リファレンスマニュアル

現代のブラウザがサポートする文字セット：

  • ASCII 文字セット
  • 標準 ISO 文字セット
  • 数学記号、ギリシャ文字、その他の記号

ISO-8859-1

ISO-8859-1 は、ほとんどのブラウザのデフォルトの文字セットです。

ISO-8859-1 の下位部分（1 から 127 のコード）は、元々の ASCII 文字セット（0-9 の数字、大文字と小文字の英字、およびいくつかの特殊文字）です。

ISO-8859-1 の上位部分（160 から 255 のコード）には、一部の西ヨーロッパ諸国で使用される文字と、広く使用されているいくつかの特殊文字が含まれており、それらにはすべて実体名があります。

これらの記号のほとんどは、実体参照なしで使用できますが、実体名または実体番号は、キーボードから入力しにくい記号を表現する方法を提供します。
