HTML Emoji

Emoji は UTF-8 文字セットに含まれる文字です: 😄 😍 💗。

絵文字（英語: emoji、日本語: 絵文字／えもじ emoji）は、ウェブページやチャットで使用される表意記号で、もともとは日本の無線通信で使用されていた視覚的な感情記号（絵文字）です。表情は顔の表情を意味し、アイコンは図形記号を意味し、笑顔は笑い、ケーキは食べ物など、さまざまな表情を表すために使用されます。Emoji は画像やアイコンのように見えますが、実際にはそうではありません。

Emoji は実際には UTF-8 (Unicode) 文字セット上の文字です。

UTF-8 は、世界のほぼすべての文字と記号をカバーしています。

HTML charset 属性

HTML ページを正常に表示するには、ブラウザはWebページで使用される文字セットを知る必要があります。Webページの文字セットは、<meta>タグで指定します：
<meta charset="UTF-8">

注記：meta 属性を特に指定しない場合、デフォルトの文字セットエンコーディングも UTF-8 です。

UTF-8 エンコーディングの詳細は、以下を参照してください：HTML Unicode（UTF-8）リファレンスマニュアル

UTF-8 文字

多くの UTF-8 文字はキーボードで入力できませんが、数字（エンティティ番号と呼ばれる）を使用して表すことができます：

  • A は 65
  • B は 66
  • C は 67

例

<!DOCTYPE html> <html> <head> <meta charset="UTF-8"> </head> <body> <p>表示結果： A B C</p> <p>表示結果： &#65; &#66; &#67;</p> </body> </html>

例の説明：

<meta charset="UTF-8">文字セットを定義します。

A、B、C は 65、66、67 を使用して表すこともできます。

エンティティ番号は、&#で始まり、セミコロン;で終わる必要があります。これにより、文字を正しく表示できます。

同様に、Emoji も文字であり、HTML ページ内で他の文字と同じように使用できます：

例

<!DOCTYPE html> <html> <head> <meta charset="UTF-8"> </head> <body> <h1>Emoji タグ記号</h1> <p>font-size 属性を使用して、フォントサイズを設定するのと同じように、絵文字のサイズを設定できます。</p> <p style="font-size:48px"> &#165EA6; &#165EA6; &#165EA6; &#175EA6; </p> </body> </html>
