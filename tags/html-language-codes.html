HTML 言語コードリファレンスマニュアル

ISO 言語コード

HTML の lang 属性は、ウェブページまたはウェブページの一部の言語を宣言するために使用でき、これは検索エンジンやブラウザにとって役立ちます。

W3C の勧告に従い、各ページの主要言語は <html> タグ内の lang 属性で宣言する必要があります：

たとえば、原文版の言語を宣言する場合：

<html lang="en"> ... </html>

XHTML では、次のように <html> タグ内で言語を宣言します：

<html xmlns="http://www.w3.org/1999/xhtml" lang="en" xml:lang="en"> ... </html>

ISO 639-1 言語コード

ISO 639-1 は、さまざまな言語の略語を定義しています。これらは HTML および XHTML の lang 属性と xml:lang 属性で使用できます。
