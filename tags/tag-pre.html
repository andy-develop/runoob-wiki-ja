ブラウザサポート

現在、ほとんどのブラウザは <pre> タグをサポートしています。

タグの定義と使い方

<pre> タグは整形済みテキストを定義できます。

<pre> タグ要素内のテキストは通常、スペースと改行を保持します。また、テキストは等幅フォントで表示されます。

ヒントと注釈

ヒント:タグの一般的な用途は、コンピュータのソースコードを表示することです。

HTML 4.01 と HTML5 の違い

HTML 4.01 では、"width" 属性は非推奨であり、使用できません。 HTML5 は "width" 属性をサポートしません。

属性

属性 值 説明
width number HTML5 はこの属性をサポートしません。HTML 4.01 ではこの属性は非推奨です。各行の最大文字数を定義します（通常は 40、80、または 132）。

グローバル属性

<pre> タグはグローバル属性をサポートします。完全な属性表を参照してください。HTML グローバル属性。

イベント属性

<pre> タグはすべてのHTML イベント属性をサポートしています。。
