jQuery セレクター

例

class が "intro"、"demo" または "end" のすべての要素を選択：

$(".intro,.demo,.end")

試してみる »

定義と使い方

.classセレクターは複数の class を選択するために使用できます。

注意：各 class はカンマで区切ります。

注意：数字で始まる class 属性は使用しないでください！一部のブラウザでは問題が発生する可能性があります。

構文

$(".class1,.class2,.class3,...")

パラメータ 説明
class 必須です。選択する要素の class を指定します。
