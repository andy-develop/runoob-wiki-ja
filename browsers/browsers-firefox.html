Firefox ブラウザ

Firefox ブラウザは、中国語名「火狐ブラウザ」で、Mozilla による無料のオープンソース Web ブラウザです。

Firefox は 2004 年にリリースされ、現在最も人気のあるブラウザの一つでもあります。

Firefox は Windows、Mac OS X、Linux、Android 上で動作します。

Firefox 29

Firefox 29 は 2014 年 4 月 29 日にリリースされました。

Firefox 29 は Windows、Mac、Linux、Android 上で動作します。

新機能：

  • 再設計されたツールと更新されたインターフェース
  • 強化された Firefox Sync サービス
  • メニューが右上に移動
  • 新しい「カスタマイズツール」。機能やアドオンを追加・移動できます。
  • ユーザーはクリック一つでブックマークを作成できます。
  • CSS box-sizing プロパティをサポート（-moz- プレフィックスなし）
  • HTML5 input type="number" をサポート
  • HTML5 input type="color" をサポート

Firefox 28

Firefox 28 は 2014 年 3 月 18 日にリリースされました。

Firefox 28 は Windows、Mac、Linux、Android 上で動作します。

新機能：

  • Mac OS X：通知センター（Notification Center）が Web 通知をサポート
  • 水平方向の HTML5 オーディオ/ビデオの音量コントロール
  • WebM 内の Opus をサポート
  • VP9 ビデオデコードを実装
  • MathML 2.0 の 'mathvariant' 属性をサポート
  • バックグラウンドスレッドレポート
  • レイアウトでの複数行 flexbox をサポート

Firefox 27

Firefox 27 は 2014 年 2 月 4 日にリリースされました。

Firefox 27 は Windows、Mac、Linux、Android 上で動作します。

新機能：

  • Firefox Social API の大幅な更新- ユーザーが複数のサービスを同時に実行できるようになりました
  • Google の SPDY 3.1 プロトコルと、トランスポート層セキュリティ（TLS - Transport Layer Security）バージョン 1.1 および 1.2 をサポート- これらは基本的に、有名な SSL 暗号化プロトコルの後継です
  • "all:unset" を使用してスタイルシートをリセット
  • スクロールする fieldset をサポート
  • CSS カーソルキーワード -moz-grab と -moz-grabbing がプレフィックスなしになりました
  • 数学関数 Math.hypot() をサポート
  • キャンバス（Canvas）上で破線をサポート

Firefox 26

Firefox 26 は 2013 年 12 月 10 日にリリースされました。

Firefox 26 は Windows、Mac、Linux、Android 上で動作します。

新機能：

  • すべての Java プラグインはデフォルトで「クリックして再生」
  • パスワードマネージャーがスクリプト生成のパスワードフィールドをサポート
  • Linux 上で H.264 エンコードのビデオをサポート
  • Windows XP 上で MP3 オーディオをサポートこれにより、Windows OS バージョン全体での MP3 サポートが完了しました
  • サイトが AppCache を要求するときのプロンプトを削除
  • CSS3 の image-orientation プロパティをサポート
  • 新しいアプリケーションマネージャー（App Manager）- Firefox OS スマートフォンおよび Firefox OS エミュレーター上で HTML5 アプリを展開およびデバッグできます
  • IndexedDB を「オプティミスティック」ストレージ領域として使用可能LRU 退避ポリシーを使用し、プールにヒントやデータを保存する必要がなく、単なる短期のな一時ストレージです
  • メモリ使用量を削減し、画像処理を改善

Firefox 4

Firefox 4 は 2011 年 3 月にリリースされました。

Firefox 4 は Windows、Mac OS X、Linux で動作します。

新機能：

  • 80 以上の言語をサポート！
  • これまでで最速の Firefox -Firefox は以前のリリースより 6 倍高速になりました。
  • アプリケーションタブ- よく訪れるサイト（Web メール、Twitter、Pandora、Flickr など）のための常設のホーム。
  • タブに切り替え- Awesome Bar で開いている任意のタブを簡単に見つけて切り替えられます。
  • パノラマ（Panorama）- タブを管理可能なグループにドラッグ＆ドロップして、複数の開いているタブの操作で時間を節約します。
  • Firefox Sync- 複数のコンピューターとモバイルデバイス間で、Awesome Bar の履歴、ブックマーク、開いているタブ、パスワード、データにアクセスできます。
  • 新しいアドオンマネージャー- 200,000 以上のアドオンで、Firefox の機能・動作・外観をカスタマイズできます。
  • Do Not Track- ユーザーは行動広告のためのトラッキングをオプトアウトできます。
  • プライバシーファースト- 他の人があなたのブラウザーの履歴にアクセスするのを防ぎます。
  • HTTP ストリクト・トランスポート・セキュリティ（HSTS、HTTP Strict Transport Security）- 中間者攻撃を防ぐために安全な接続を確立し、機密データを保護します。
  • コンテンツセキュリティポリシー（CSP、Content Security Policy）Webサイトがブラウザーにどのコンテンツが正当であるかを明示的に伝えることで、クロスサイトスクリプティング攻撃を防ぎます。
  • JIT コンパイラー- 既存のTraceMonkey JITとSpiderMonkeyインタープリターを強化することにより、より高速なページ読み込みとより良いパフォーマンスを実現します。
  • HTML5 サポート- ハードウェアアクセラレーション、HDビデオ（WebM）、3Dグラフィックス、オフラインデータストレージ、プロフェッショナルなタイポグラフィ、タッチスクリーンインターフェース、Mozilla Audio APIが含まれます。
  • 既存のツールの改善- 例えば、CSS、キャンバス（Canvas）、SVGなどです。
  • 途切れないブラウジング- Adobe Flash、Apple QuickTime、またはMicrosoft Silverlightプラグインがクラッシュしても、ユーザーのブラウジングを中断しません。

Firefox 3.6

Firefox 3.6は2011年1月にリリースされました。

Firefox 3.6は、MozillaのGecko 1.9.2ウェブレンダリングプラットフォーム上に構築されており、このプラットフォームは2009年初めから開発が始まり、Web開発者、プラグイン開発者、ユーザー向けに多くの改善機能が含まれています。また、このバージョンは以前のバージョンよりも高速で応答性が高く、Maemoなどの小型デバイス向けオペレーティングシステムで動作するように最適化されています。

新機能：

  • Personas テーマ- クリックするだけでFirefoxの外観を変更できます。
  • 古いプラグインのインストールを防止- ユーザーがウェブを閲覧する際の安全性を確保します。
  • ローカルビデオを開いて全画面表示にでき、通知フレームワークをサポートします。
  • JavaScriptパフォーマンスの改善
  • Web開発者にスクリプトを非同期で実行する機能を提供します。- ページの読み込み時間を短縮するためです。
  • ダウンロード可能なWebフォントのサポート- 新しいWOFFフォント形式を使用します。
  • CSS3、DOM、HTML5のサポートを改善
