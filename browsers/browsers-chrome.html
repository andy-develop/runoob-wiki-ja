Google Chrome ブラウザ

Google Chrome ブラウザ（中国語名「谷歌浏览器」）は、Google が開発し、2008 年にリリースした無料のオープンソース Web ブラウザです。

Google がブラウザの開発を決めたとき、彼らはこのブラウザを根本から再設計する必要がありました。なぜなら、今日のブラウザは、単純なテキストページを閲覧するだけでよかった時代とは大きく異なっているからです。現在では、ブラウザ上でメールを送信したり、買い物をしたり、請求書を支払ったり、その他の大規模なアプリケーションを実行したりしています。

Google Chrome は今日最もよく使われているブラウザです：Chrome をダウンロード。

Google Chrome 34

Chrome 34 は 2014 年 4 月 8 日にリリースされました。

Chrome 34 は Windows、Mac、Linux、Android で動作します（4 月 2 日）。

新機能：

  • autocomplete=off が設定されている場合でも、Chrome はパスワードフィールドを記憶して自動入力します。
  • レスポンシブ画像のサポート -Google は "srcset" 属性を導入し、ウェブサイト開発者が 1 つの画像に対して異なる解像度の複数のリソースを提供できるようにしました。要するに、これはブラウザがデバイスに一致するリソースを選択することを意味します。そのデバイスには、デスクトップ、ノートパソコン、タブレット、スマートフォン、テレビなどがあります。
  • Web Audio API のプレフィックスなしバージョン
  • 監視対象ユーザーを新しいコンピューターにインポートする -監視対象ユーザーをインポートすると、そのすべての権限も一緒にインポートされ、デバイスに自動的に同期されます。
  • 多くの新しいアプリケーション/拡張機能の API
  • Win8 Metro モード用の異なる外観
  • 31 件のセキュリティ修正

Google Chrome 33

Chrome 33 は 2014 年 2 月 20 日にリリースされました。

Chrome 33 は Windows、Mac、Linux、Android で動作します（2 月 26 日）。

Chrome Frame（Internet Explorer 向けの Chrome プラグイン）は正式に廃止されました。

新機能：

  • Web Speech API - 音声認識と合成機能
  • カスタム要素 -新しい HTML および DOM 要素を作成できます（任意の名前を使用できます）。また、他の要素から新しい要素を拡張し、カスタム機能を単一の要素にまとめることもできます。
  • オフラインモードでは、Google ドライブ内のフォルダーを作成、名前変更、削除できます。
  • オフラインモードでは、Google ドライブ内のファイルの名前を変更できます。
  • 28 件のセキュリティ修正
