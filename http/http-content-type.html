HTTP content-type

Content-Type（コンテンツタイプ）は、一般的にウェブページに存在する Content-Type を指し、ネットワークファイルのタイプとウェブページのエンコーディングを定義するために使用されます。ブラウザがどの形式、どのエンコーディングでこのファイルを読み取るかを決定します。これが、PHP ウェブページをクリックした結果、ファイルや画像がダウンロードされるのをよく見かける理由です。

Content-Type ヘッダーは、クライアントに実際に返されるコンテンツのコンテンツタイプを通知します。

構文形式：

Content-Type: text/html; charset=utf-8
Content-Type: multipart/form-data; boundary=something

例：

一般的なメディア形式タイプは次のとおりです：

  • text/html：HTML 形式
  • text/plain：プレーンテキスト形式
  • text/xml：XML 形式
  • image/gif：GIF画像形式
  • image/jpeg：jpg画像形式
  • image/png：PNG画像形式

application で始まるメディア形式タイプ：

  • application/xhtml+xml：XHTML 形式
  • application/xml：XML データ形式
  • application/atom+xml：Atom XML アグリゲーション形式
  • application/json：JSON データ形式
  • application/pdf：PDF 形式
  • application/msword：Word 文書形式
  • application/octet-stream：バイナリストリームデータ（一般的なファイルダウンロードなど）
  • application/x-www-form-urlencoded：`<form encType="">` 内のデフォルトの encType で、フォームデータは key/value 形式にエンコードされてサーバーに送信されます（フォームのデフォルトのデータ送信形式）

もう1つの一般的なメディア形式は、ファイルをアップロードするときに使用されるものです：

  • multipart/form-data：フォームでファイルアップロードを行う必要がある場合に使用する形式です
