NumPy 数学関数

NumPy には、三角関数、算術演算の関数、複素数処理関数など、さまざまな数学演算の関数が豊富に含まれています。

三角関数

NumPy は標準の三角関数を提供しています：sin()、cos()、tan()。

例

import numpy as np a = np.array([0,30,45,60,90]) print ('さまざまな角度の正弦値：') # pi/180 を掛けてラジアンに変換 print (np.sin(a*np.pi/180)) print ('\n') print ('配列内の角度の余弦値：') print (np.cos(a*np.pi/180)) print ('\n') print ('配列内の角度の正接値：') print (np.tan(a*np.pi/180))

出力結果は次のとおりです：

不同角度的正弦值：
[0.         0.5        0.70710678 0.8660254  1.        ]


数组中角度的余弦值：
[1.00000000e+00 8.66025404e-01 7.07106781e-01 5.00000000e-01
 6.12323400e-17]


数组中角度的正切值：
[0.00000000e+00 5.77350269e-01 1.00000000e+00 1.73205081e+00
 1.63312394e+16]

arcsin、arccos、arctan 関数は、指定された角度の sin、cos、tan の逆三角関数を返します。

これらの関数の結果は、numpy.degrees() 関数を使用してラジアンを角度に変換できます。

例

import numpy as np a = np.array([0,30,45,60,90]) print ('正弦値を含む配列：') sin = np.sin(a*np.pi/180) print (sin) print ('\n') print ('角度の逆正弦を計算し、戻り値はラジアン単位です：') inv = np.arcsin(sin) print (inv) print ('\n') print ('度数法に変換して結果を確認します：') print (np.degrees(inv)) print ('\n') print ('arccos 関数と arctan 関数も同様に動作します：') cos = np.cos(a*np.pi/180) print (cos) print ('\n') print ('逆余弦：') inv = np.arccos(cos) print (inv) print ('\n') print ('度数法の単位：') print (np.degrees(inv)) print ('\n') print ('tan 関数：') tan = np.tan(a*np.pi/180) print (tan) print ('\n') print ('逆正接：') inv = np.arctan(tan) print (inv) print ('\n') print ('度数法の単位：') print (np.degrees(inv))

出力結果は次のとおりです：

含有正弦值的数组：
[0.         0.5        0.70710678 0.8660254  1.        ]


计算角度的反正弦，返回值以弧度为单位：
[0.         0.52359878 0.78539816 1.04719755 1.57079633]


通过转化为角度制来检查结果：
[ 0. 30. 45. 60. 90.]


arccos 和 arctan 函数行为类似：
[1.00000000e+00 8.66025404e-01 7.07106781e-01 5.00000000e-01
 6.12323400e-17]


反余弦：
[0.         0.52359878 0.78539816 1.04719755 1.57079633]


角度制单位：
[ 0. 30. 45. 60. 90.]


tan 函数：
[0.00000000e+00 5.77350269e-01 1.00000000e+00 1.73205081e+00
 1.63312394e+16]


反正切：
[0.         0.52359878 0.78539816 1.04719755 1.57079633]


角度制单位：
[ 0. 30. 45. 60. 90.]

丸め関数

numpy.around() 関数は、指定された数値を四捨五入した値を返します。

numpy.around(a,decimals)

パラメータの説明：

  • a: 配列
  • decimals: 丸めるときの小数桁数。デフォルト値は0。負の場合、整数は小数点の左側の位置で四捨五入されます。

例

import numpy as np a = np.array([1.0,5.55, 123, 0.567, 25.532]) print ('元の配列：') print (a) print ('\n') print ('四捨五入後：') print (np.around(a)) print (np.around(a, decimals = 1)) print (np.around(a, decimals = -1))

出力結果は次のとおりです：

原数组：
[  1.      5.55  123.      0.567  25.532]


舍入后：
[  1.   6. 123.   1.  26.]
[  1.    5.6 123.    0.6  25.5]
[  0.  10. 120.   0.  30.]

numpy.floor()

numpy.floor() は、指定された式以下で最大の整数を返します。つまり、切り捨てです。

例

import numpy as np a = np.array([-1.7, 1.5, -0.2, 0.6, 10]) print ('指定された配列：') print (a) print ('\n') print ('変更後の配列：') print (np.floor(a))

出力結果は次のとおりです：

提供的数组：
[-1.7  1.5 -0.2  0.6 10. ]


修改后的数组：
[-2.  1. -1.  0. 10.]

numpy.ceil()

numpy.ceil() は、指定された式以上で最小の整数を返します。つまり、切り上げです。

例

import numpy as np a = np.array([-1.7, 1.5, -0.2, 0.6, 10]) print ('指定された配列：') print (a) print ('\n') print ('変更後の配列：') print (np.ceil(a))

出力結果は次のとおりです：

提供的数组：
[-1.7  1.5 -0.2  0.6 10. ]


修改后的数组：
[-1.  2. -0.  1. 10.]
