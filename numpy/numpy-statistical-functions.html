NumPy 統計関数

NumPy は、配列から最小要素、最大要素、パーセンタイル、標準偏差、分散などを求めるための多くの統計関数を提供しています。

numpy.amin() と numpy.amax()

numpy.amin() は、配列内の要素の指定した軸に沿った最小値を計算します。

numpy.amin(a, axis=None, out=None, keepdims=<no value>, initial=<no value>, where=<no value>)

パラメータの説明：

  • a: 入力する配列。NumPy配列または配列に似たオブジェクトを指定できます。
  • axis: オプションのパラメータ。最小値を計算する軸を指定します。このパラメータを指定しない場合は、配列全体の最小値を返します。軸のインデックスを表す整数、または複数の軸を表すタプルを指定できます。
  • out: オプションのパラメータ。結果の格納場所を指定します。
  • keepdims: オプションのパラメータ。Trueの場合、結果の配列の次元数は入力配列と同じになります。False（デフォルト）の場合、計算後に次元が1の軸は削除されます。
  • initial: オプションのパラメータ。初期値を指定し、その上で配列の要素に対して最小値を計算します。
  • where: オプションのパラメータ。条件を満たす要素のみを考慮するためのブール配列を指定します。

numpy.amax() は、配列内の要素の指定した軸に沿った最大値を計算します。

numpy.amax(a, axis=None, out=None, keepdims=<no value>, initial=<no value>, where=<no value>)

パラメータの説明：

  • a: 入力する配列。NumPy配列または配列に似たオブジェクトを指定できます。
  • axis: オプションのパラメータ。最大値を計算する軸を指定します。このパラメータを指定しない場合は、配列全体の最大値を返します。軸のインデックスを表す整数、または複数の軸を表すタプルを指定できます。
  • out: オプションのパラメータ。結果の格納場所を指定します。
  • keepdims: オプションのパラメータ。Trueの場合、結果の配列の次元数は入力配列と同じになります。False（デフォルト）の場合、計算後に次元が1の軸は削除されます。
  • initial: オプションのパラメータ。初期値を指定し、その上で配列の要素に対して最大値を計算します。
  • where: オプションのパラメータ。条件を満たす要素のみを考慮するためのブール配列を指定します。

例

import numpy as np a = np.array([[3,7,5],[8,4,3],[2,4,9]]) print ('私たちの配列は：') print (a) print ('\n') print ('amin() 関数を呼び出します：') print (np.amin(a,1)) print ('\n') print ('amin() 関数を再度呼び出します：') print (np.amin(a,0)) print ('\n') print ('amax() 関数を呼び出します：') print (np.amax(a)) print ('\n') print ('amax() 関数を再度呼び出します：') print (np.amax(a, axis = 0))

出力結果は：

我们的数组是：
[[3 7 5]
 [8 4 3]
 [2 4 9]]


调用 amin() 函数：
[3 3 2]


再次调用 amin() 函数：
[2 4 3]


调用 amax() 函数：
9


再次调用 amax() 函数：
[8 7 9]

numpy.ptp()

numpy.ptp()この関数は、配列内の要素の最大値と最小値の差（最大値 - 最小値）を計算します。

numpy.ptp(a, axis=None, out=None, keepdims=<no value>, initial=<no value>, where=<no value>)

パラメータの説明：

  • a: 入力する配列。NumPy 配列または配列に似たオブジェクトを指定できます。
  • axis: オプションのパラメータ。ピークツーピーク値を計算する軸を指定します。このパラメータを指定しない場合は、配列全体のピークツーピーク値を返します。軸のインデックスを表す整数、または複数の軸を表すタプルを指定できます。
  • out: オプションのパラメータ。結果の格納場所を指定します。
  • keepdims: オプションのパラメータ。Trueの場合、結果の配列の次元数は入力配列と同じになります。False（デフォルト）の場合、計算後に次元が1の軸は削除されます。
  • initial: オプションのパラメータ。初期値を指定し、その上で配列の要素に対してピークツーピーク値を計算します。
  • where: オプションのパラメータ。条件を満たす要素のみを考慮するためのブール配列を指定します。

例

import numpy as np a = np.array([[3,7,5],[8,4,3],[2,4,9]]) print ('私たちの配列は：') print (a) print ('\n') print ('ptp() 関数を呼び出します：') print (np.ptp(a)) print ('\n') print ('軸1に沿って ptp() 関数を呼び出します：') print (np.ptp(a, axis = 1)) print ('\n') print ('軸0に沿って ptp() 関数を呼び出します：') print (np.ptp(a, axis = 0))

出力結果は：

我们的数组是：
[[3 7 5]
 [8 4 3]
 [2 4 9]]


调用 ptp() 函数：
7


沿轴 1 调用 ptp() 函数：
[4 5 7]


沿轴 0 调用 ptp() 函数：
[6 3 6]

numpy.percentile()

パーセンタイルは統計で使用される尺度であり、この値より小さい観測値の割合を表します。numpy.percentile() 関数は以下のパラメータを受け取ります。

numpy.percentile(a, q, axis)

パラメータの説明：

  • a: 入力配列
  • q: 計算するパーセンタイル。0 ~ 100 の間です。
  • axis: パーセンタイルを計算する軸

まずパーセンタイルを明確にします：

第 p パーセンタイルは、少なくとも p% のデータ項目がこの値以下であり、少なくとも (100-p)% のデータ項目がこの値以上であるような値です。

例を挙げます：高等教育機関の入学試験の成績は、しばしばパーセンタイルの形式で報告されます。例えば、ある受験者が入学試験の国語の部分で素点が54点だったとします。同じ試験を受けた他の学生と比較して、彼の成績がどうなのかは簡単には分かりません。しかし、素点54点がちょうど第70パーセンタイルに対応するなら、約70%の学生の得点が彼より低く、約30%の学生の得点が彼より高いことが分かります。

ここでは p = 70 です。

例

import numpy as np a = np.array([[10, 7, 4], [3, 2, 1]]) print ('私たちの配列は：') print (a) print ('percentile() 関数を呼び出します：') # 50% 分位数は、a をソートした後の中央値です print (np.percentile(a, 50)) # axis が 0 の場合、縦方向に求めます print (np.percentile(a, 50, axis=0)) # axis が 1 の場合、横方向に求めます print (np.percentile(a, 50, axis=1)) # 次元を維持します print (np.percentile(a, 50, axis=1, keepdims=True))

出力結果は：

我们的数组是：
[[10  7  4]
 [ 3  2  1]]
调用 percentile() 函数：
3.5
[6.5 4.5 2.5]
[7. 2.]
[[7.]
 [2.]]

numpy.median()

numpy.median() 関数は、配列 a 内の要素の中央値を計算します。

numpy.median(a, axis=None, out=None, overwrite_input=False, keepdims=<no value>)

パラメータの説明：

  • a: 入力する配列。NumPy 配列または配列に似たオブジェクトを指定できます。
  • axis: オプションのパラメータ。中央値を計算する軸を指定します。このパラメータを指定しない場合は、配列全体の中央値を計算します。軸のインデックスを表す整数、または複数の軸を表すタプルを指定できます。
  • out: オプションのパラメータ。結果の格納場所を指定します。
  • overwrite_input: オプションのパラメータ。Trueの場合、計算に入力配列のメモリを使用できるようにします。これにより、状況によってはパフォーマンスが向上する場合がありますが、入力配列の内容が変更される可能性があります。
  • keepdims: オプションのパラメータ。Trueの場合、結果の配列の次元数は入力配列と同じになります。False（デフォルト）の場合、計算後に次元が1の軸は削除されます。

例

import numpy as np a = np.array([[30,65,70],[80,95,10],[50,90,60]]) print ('私たちの配列は：') print (a) print ('\n') print ('median() 関数を呼び出します：') print (np.median(a)) print ('\n') print ('軸0に沿って median() 関数を呼び出します：') print (np.median(a, axis = 0)) print ('\n') print ('軸1に沿って median() 関数を呼び出します：') print (np.median(a, axis = 1))

出力結果は：

我们的数组是：
[[30 65 70]
 [80 95 10]
 [50 90 60]]


调用 median() 函数：
65.0


沿轴 0 调用 median() 函数：
[50. 90. 60.]


沿轴 1 调用 median() 函数：
[65. 80. 60.]

numpy.mean()

numpy.mean() 関数は、配列内の要素の算術平均を返します。軸が指定された場合は、その軸に沿って計算します。

算術平均は、軸に沿った要素の合計を要素数で割ったものです。

numpy.mean(a, axis=None, dtype=None, out=None, keepdims=<no value>)

パラメータの説明：

  • a: 入力する配列。NumPy 配列または配列に似たオブジェクトを指定できます。
  • axis: オプションのパラメータ。平均値を計算する軸を指定します。このパラメータを指定しない場合は、配列全体の平均値を計算します。軸のインデックスを表す整数、または複数の軸を表すタプルを指定できます。
  • dtype: オプションのパラメータ。出力のデータ型を指定します。指定しない場合は、入力データの型に基づいて適切なデータ型が選択されます。
  • out: オプションのパラメータ。結果の格納場所を指定します。
  • keepdims: オプションのパラメータ。Trueの場合、結果の配列の次元数は入力配列と同じになります。False（デフォルト）の場合、計算後に次元が1の軸は削除されます。

例

import numpy as np a = np.array([[1,2,3],[3,4,5],[4,5,6]]) print ('私たちの配列は：') print (a) print ('\n') print ('mean() 関数を呼び出します：') print (np.mean(a)) print ('\n') print ('軸0に沿って mean() 関数を呼び出します：') print (np.mean(a, axis = 0)) print ('\n') print ('軸1に沿って mean() 関数を呼び出します：') print (np.mean(a, axis = 1))

出力結果は：

我们的数组是：
[[1 2 3]
 [3 4 5]
 [4 5 6]]


调用 mean() 函数：
3.6666666666666665


沿轴 0 调用 mean() 函数：
[2.66666667 3.66666667 4.66666667]


沿轴 1 调用 mean() 函数：
[2. 4. 5.]

numpy.average()

numpy.average() 関数は、別の配列で指定された対応する重みに基づいて、配列内の要素の加重平均を計算します。

この関数は軸パラメータを受け取ることができます。軸が指定されていない場合は、配列はフラットに展開されます。

加重平均とは、各数値に対応する重みを掛けて合計し、全体の値を得て、それを重みの合計で割ったものです。

配列 [1,2,3,4] と対応する重み [4,3,2,1] を考えると、対応する要素の積を足し合わせ、その和を重みの合計で割ることにより加重平均を計算します。

加权平均值 = (1*4+2*3+3*2+4*1)/(4+3+2+1)

関数の構文：

numpy.average(a, axis=None, weights=None, returned=False)

パラメータの説明：

  • a: 入力する配列。NumPy 配列または配列に似たオブジェクトを指定できます。
  • axis: オプションのパラメータ。加重平均を計算する軸を指定します。このパラメータを指定しない場合は、配列全体の加重平均を計算します。軸のインデックスを表す整数、または複数の軸を表すタプルを指定できます。
  • weights: オプションのパラメータ。対応するデータポイントの重みを指定します。重みの配列を指定しない場合、デフォルトで等しい重みになります。
  • returned: オプションのパラメータ。Trueの場合、加重平均と重みの合計の両方を返します。

例

import numpy as np a = np.array([1,2,3,4]) print ('私たちの配列は：') print (a) print ('\n') print ('average() 関数を呼び出します：') print (np.average(a)) print ('\n') # 重みを指定しない場合は mean 関数と同等です wts = np.array([4,3,2,1]) print ('再度 average() 関数を呼び出します。') print (np.average(a,weights = wts)) print ('\n') # returned パラメータを true に設定すると、重みの合計が返されます print ('重みの合計：') print (np.average([1,2,3, 4],weights = [4,3,2,1], returned = True))

出力結果は次のとおりです。

我们的数组是：
[1 2 3 4]


调用 average() 函数：
2.5


再次调用 average() 函数：
2.0


权重的和：
(2.0, 10.0)

多次元配列では、計算に使用する軸を指定できます。

例

import numpy as np a = np.arange(6).reshape(3,2) print ('私たちの配列は次のとおりです。') print (a) print ('\n') print ('変更後の配列：') wt = np.array([3,5]) print (np.average(a, axis = 1, weights = wt)) print ('\n') print ('変更後の配列：') print (np.average(a, axis = 1, weights = wt, returned = True))

出力結果は次のとおりです。

我们的数组是：
[[0 1]
 [2 3]
 [4 5]]


修改后的数组：
[0.625 2.625 4.625]


修改后的数组：
(array([0.625, 2.625, 4.625]), array([8., 8., 8.]))

標準偏差

標準偏差は、データセットの平均値からのばらつきの度合いを示す尺度です。

標準偏差は分散の正の平方根です。

標準偏差の公式は次のとおりです。

std = sqrt(mean((x - x.mean())**2))

配列が [1，2，3，4] の場合、その平均値は 2.5 です。 したがって、偏差の平方は [2.25,0.25,0.25,2.25] となり、さらにその平均値の平方根を 4 で割ったもの、すなわち sqrt(5/4) を求めると、結果は 1.1180339887498949 になります。

例

import numpy as np print (np.std([1,2,3,4]))

出力結果は次のとおりです。

1.1180339887498949

分散

統計における分散（標本分散）は、各標本値と全体の標本値の平均との差の平方の平均値、すなわち mean((x - x.mean())** 2) です。

言い換えれば、標準偏差は分散の平方根です。

例

import numpy as np print (np.var([1,2,3,4]))

出力結果は次のとおりです。

1.25
