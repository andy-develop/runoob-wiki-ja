Java 8 Stream

Java 8 新機能

Java 8 APIは、Streamと呼ばれる新しい抽象化を追加しました。これにより、宣言的な方法でデータを処理できます。

Streamは、SQL文でデータベースからデータをクエリするのと似た直感的な方法で、Javaコレクションの演算と表現に対する高階抽象化を提供します。

Stream APIはJavaプログラマーの生産性を大幅に向上させ、効率的でクリーンかつ簡潔なコードを書くことを可能にします。

このスタイルでは、処理する要素の集合をストリームとみなし、ストリームはパイプライン内を伝送され、フィルタリング、ソート、集約などの処理をパイプラインのノードで行うことができます。

要素のストリームはパイプライン内で中間操作（intermediate operation）による処理を受け、最終的に終端操作（terminal operation）によって前述の処理結果を得ます。

+--------------------+       +------+   +------+   +---+   +-------+
| stream of elements +-----> |filter+-> |sorted+-> |map+-> |collect|
+--------------------+       +------+   +------+   +---+   +-------+

上記のフローをJavaコードに変換すると、次のようになります。

List<Integer> transactionsIds = 
widgets.stream()
             .filter(b -> b.getColor() == RED)
             .sorted((x,y) -> x.getWeight() - y.getWeight())
             .mapToInt(Widget::getWeight)
             .sum();

Streamとは？

Stream（ストリーム）は、データソースからの要素のキューであり、集約操作をサポートします。

  • 要素は特定の型のオブジェクトであり、キューを形成します。 JavaのStreamは要素を格納せず、必要に応じて計算します。
  • データソースストリームのソースです。 コレクション、配列、I/Oチャネル、ジェネレータ（generator）などです。
  • 集約操作SQL文のような操作で、例えばfilter、map、reduce、find、match、sortedなどです。

以前のCollection操作とは異なり、Stream操作にはさらに2つの基本的な特徴があります。

  • Pipelining： 中間操作はすべてストリームオブジェクト自体を返します。 これにより、複数の操作を1つのパイプラインに連結でき、流れるようなスタイル（fluent style）になります。 これにより、遅延実行（laziness）や短絡（short-circuiting）などの操作の最適化が可能になります。
  • 内部反復： 以前はコレクションの走査はIteratorまたはFor-Eachを使用して、コレクションの外部で明示的に反復処理を行っていました。これを外部反復と呼びます。 Streamは、ビジターパターン（Visitor）によって実装された内部反復の方法を提供します。

ストリームの生成

Java 8では、コレクションインターフェースにストリームを生成する2つのメソッドがあります。

  • stream()− コレクション用の逐次ストリームを作成します。

  • parallelStream()− コレクション用の並列ストリームを作成します。

List<String> strings = Arrays.asList("abc", "", "bc", "efg", "abcd","", "jkl"); List<String> filtered = strings.stream().filter(string -> !string.isEmpty()).collect(Collectors.toList());

forEach

Streamは、ストリーム内の各データを反復処理するための新しいメソッド 'forEach' を提供します。次のコードスニペットは、forEachを使用して10個の乱数を出力します。

Random random = new Random(); random.ints().limit(10).forEach(System.out::println);

map

map メソッドは各要素を対応する結果にマッピングするために使用されます。次のコードスニペットは、mapを使用して要素に対応する平方数を出力します。

List<Integer> numbers = Arrays.asList(3, 2, 2, 3, 7, 3, 5); //対応する平方数を取得 List<Integer> squaresList = numbers.stream().map( i -> i*i).distinct().collect(Collectors.toList());

filter

filter メソッドは、設定した条件で要素をフィルタリングするために使用されます。次のコードスニペットは、filterメソッドを使用して空文字列をフィルタリングします。

List<String>strings = Arrays.asList("abc", "", "bc", "efg", "abcd","", "jkl"); //空文字列の数を取得 long count = strings.stream().filter(string -> string.isEmpty()).count();

limit

limit メソッドは、指定された数のストリームを取得するために使用されます。次のコードスニペットは、limitメソッドを使用して10件のデータを出力します。

Random random = new Random(); random.ints().limit(10).forEach(System.out::println);

sorted

sorted メソッドはストリームをソートするために使用されます。次のコードスニペットは、sortedメソッドを使用して出力される10個の乱数をソートします。

Random random = new Random(); random.ints().limit(10).sorted().forEach(System.out::println);

並行（parallel）プログラム

parallelStream は、ストリームの並列処理の代替方法です。次の例では、parallelStreamを使用して空文字列の数を出力します。

List<String> strings = Arrays.asList("abc", "", "bc", "efg", "abcd","", "jkl"); //空文字列の数を取得 long count = strings.parallelStream().filter(string -> string.isEmpty()).count();

逐次実行と並列実行を簡単に切り替えることができます。

Collectors

Collectors クラスは多くの還元操作を実装しています。例えば、ストリームをコレクションに変換したり、要素を集約したりします。 Collectors はリストや文字列を返すために使用できます。

List<String>strings = Arrays.asList("abc", "", "bc", "efg", "abcd","", "jkl"); List<String> filtered = strings.stream().filter(string -> !string.isEmpty()).collect(Collectors.toList()); System.out.println("リストをフィルタリング:" + filtered); String mergedString = strings.stream().filter(string -> !string.isEmpty()).collect(Collectors.joining(", ")); System.out.println("文字列を結合:" + mergedString);

統計

さらに、統計結果を生成する一部のコレクターも非常に便利です。これらは主にint、double、longなどの基本型で使用され、以下のような統計結果を生成するために使用できます。

List<Integer> numbers = Arrays.asList(3, 2, 2, 3, 7, 3, 5); IntSummaryStatistics stats = numbers.stream().mapToInt((x) -> x).summaryStatistics(); System.out.println("リスト内の最大数 :" + stats.getMax()); System.out.println("リスト内の最小数 :" + stats.getMin()); System.out.println("すべての数の合計 :" + stats.getSum()); System.out.println("平均値 :" + stats.getAverage());
