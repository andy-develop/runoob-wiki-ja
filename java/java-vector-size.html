Java Vector size() メソッド

Java Vector

Vectorクラスのsize()メソッドは、現在のVectorVector 内に含まれる要素の数を取得するために使用されます。これは非常に基本的でありながら重要なメソッドで、コレクション操作で頻繁に使用されます。

構文の説明

public int size()

メソッドの特徴

  • 戻り値の型：int
  • 戻り値：現在のVectorVector 内の要素の数
  • 時間計算量：O(1)（定数時間）

使用例

基本的な使い方

例

import java.util.Vector;

public class VectorSizeExample {
    public static void main(String[] args) {
        // Vector を作成する
        Vector<String> fruits = new Vector<>();
       
        // 要素を追加する
        fruits.add("Apple");
        fruits.add("Banana");
        fruits.add("Orange");
       
        // size() メソッドを使用して要素数を取得する
        int size = fruits.size();
        System.out.println("Vector 内の要素数: " + size);
    }
}

出力：

Vector 中的元素数量: 3

容量(capacity)との違い

初心者はよく混同しますsize()とcapacity()メソッド：

例

Vector<Integer> numbers = new Vector<>(10); // 初期容量は10
numbers.add(1);
numbers.add(2);

System.out.println("Size: " + numbers.size());     // 出力: 2
System.out.println("Capacity: " + numbers.capacity()); // 出力: 10
  • size()：現在格納されている要素の数
  • capacity()：Vector が現在格納できる最大要素数（拡張不要）

よくある使用場面

1. Vector を反復処理する

例

for (int i = 0; i < vector.size(); i++) {
    System.out.println(vector.get(i));
}

2. Vector が空かどうかを確認する

使用できますがisEmpty()、次のようにすることもできます：

例

if (vector.size() == 0) {
    System.out.println("Vector は空です");
}

3. ループ回数を制御する

例

while (vector.size() < 10) {
    vector.add("Item " + (vector.size() + 1));
}

注意事項

  1. スレッドセーフ：ただし、VectorVector はスレッドセーフですが、size()size() メソッドが返す値は、マルチスレッド環境ではすぐに無効になる可能性があります（他のスレッドが Vector を変更している場合）。Vector）。

  2. パフォーマンスに関する考慮事項：挿入と削除を頻繁に行う必要がある場面では、ArrayList通常、Vectorよりもパフォーマンスが優れています。なぜなら、Vectorの同期操作によって追加のオーバーヘッドが発生するからです。

  3. 代替案：Java 5 以降では、～を使用してCollections.synchronizedList()ラップすることにより、ArrayListスレッドセーフなリストを取得できます：

List<String> syncList = Collections.synchronizedList(new ArrayList<String>());

まとめ

Vectorのsize()size() メソッドはシンプルですが非常に重要なメソッドであり、次のことに役立ちます：

  • コレクションに現在いくつの要素が含まれているかを把握する
  • ループと反復処理を制御する
  • コレクションの状態を確認する

ただし、Vector現代の Java 開発では使用頻度が低下しています（ArrayListに置き換えられました）が、スレッドセーフなコレクションが必要な場面では、依然として信頼できる選択肢です。size()size() メソッドを理解することは、Java コレクションフレームワークの基本操作を習得するために非常に重要です。
