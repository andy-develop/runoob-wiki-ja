Java 演算子

コンピュータの最も基本的な用途の1つは数学演算を実行することです。コンピュータ言語であるJavaも、変数を操作するための豊富な演算子を提供しています。演算子は次のグループに分類できます：

  • 算術演算子
  • 関係演算子
  • ビット演算子
  • 論理演算子
  • 代入演算子
  • その他の演算子

算術演算子

算術演算子は数式の中で使用され、その役割は数学における役割と同じです。次の表にすべての算術演算子を示します。

表の例では、整数変数Aの値が10、変数Bの値が20であると仮定します：

演算子 説明 例
+ 加算 - 演算子の両側の値を加算します A + B は 30 です
- 減算 - 左オペランドから右オペランドを引きます A - B は -10 です
* 乗算 - 演算子の両側の値を掛けます A * B は 200 です
/ 除算 - 左オペランドを右オペランドで割ります B / A は 2 です
％ 剰余 - 左オペランドを右オペランドで割った余り B % A は 0 です
++ インクリメント: オペランドの値を1増やします B++ または ++B は 21 です（違いは後述）
-- デクリメント: オペランドの値を1減らします B-- または --B は 19 です（違いは後述）

インクリメント/デクリメント演算子

1. インクリメント（++）およびデクリメント（--）演算子これは特別な算術演算子です。算術演算子では演算に2つのオペランドが必要ですが、インクリメント/デクリメント演算子は1つのオペランドで演算します。

例

public class selfAddMinus{ public static void main(String[] args){ int a = 3;//変数を定義します； int b = ++a;//インクリメント演算 int c = 3; int d = --c;//デクリメント演算 System.out.println("インクリメント演算を行った後の値は次と等しくなります："+b); System.out.println("デクリメント演算を行った後の値は次と等しくなります："+d); } }

実行結果は次のとおりです：

进行自增运算后的值等于4
进行自减运算后的值等于2

解説：

  • int b = ++a; 演算過程を分解すると、a=a+1=4; b=a=4、最終結果はb=4、a=4です。

  • int d = --c; 演算過程を分解すると、c=c-1=2; d=c=2、最終結果はd=2、c=2です。

2. 前置インクリメント/デクリメント（++a, --a）：最初にインクリメントまたはデクリメント演算を行い、その後に式の演算を行います。

3. 後置インクリメント/デクリメント（a++, a--）：最初に式の演算を行い、その後にインクリメントまたはデクリメント演算を行います。例：

例

public class selfAddMinus{ public static void main(String[] args){ int a = 5;//変数を定義します； int b = 5; int x = 2*++a; int y = 2*b++; System.out.println("インクリメント演算子の前置演算後のa="+a+",x="+x); System.out.println("インクリメント演算子の後置演算後のb="+b+",y="+y); } }

ビット演算子

Javaはビット演算子を定義しており、整数型（int）、長整数型（long）、短整数型（short）、文字型（char）、バイト型（byte）などの型に適用されます。

ビット演算子はすべてのビットに作用し、ビット単位で演算します。a = 60、b = 13とすると、それらの2進数形式での表現は次のようになります：

A = 0011 1100
B = 0000 1101
-----------------
A&B = 0000 1100
A | B = 0011 1101
A ^ B = 0011 0001
~A= 1100 0011

次の表はビット演算子の基本演算を示しています。整数変数Aの値が60、変数Bの値が13であるとします：

演算子 説明 例
＆ 対応するビットが両方とも1の場合、結果は1、それ以外の場合は0です。 （A & B）は12、すなわち0000 1100になります。
| 対応するビットが両方とも0の場合、結果は0、それ以外の場合は1です。 （A | B）は61、すなわち0011 1101になります。
^ 対応するビットの値が同じ場合、結果は0、それ以外の場合は1です。 （A ^ B）は49、すなわち0011 0001になります。
〜 ビット反転演算子はオペランドの各ビットを反転させます。つまり0は1に、1は0になります。 （~A）は-61、すなわち1100 0011になります。
<<  ビット左シフト演算子。左オペランドを右オペランドで指定されたビット数だけ左にシフトします。 A << 2 は240、すなわち1111 0000になります。
>>  ビット右シフト演算子。左オペランドを右オペランドで指定されたビット数だけ右にシフトします。 A >> 2 は15、すなわち1111になります。
>>>  ゼロ埋め右シフト演算子。左オペランドの値を右オペランドで指定されたビット数だけ右にシフトし、移動によって生じた空きビットは0で埋められます。 A>>>2 は15、すなわち0000 1111になります。

例

以下の簡単なサンプルプログラムはビット演算子を示しています。次のJavaプログラムをコピーして貼り付け、Test.javaファイルとして保存し、コンパイルして実行してください：

Test.java ファイルのコード：

上記の例をコンパイルして実行した結果は次のとおりです：

論理演算子

次の表は論理演算子の基本演算を示しています。ブール変数Aはtrue、変数Bはfalseとします。

演算子 説明 例
&& 論理AND演算子と呼ばれます。2つのオペランドが両方ともtrueの場合にのみ、条件はtrueになります。 （A && B）はfalseです。
| | 論理OR演算子と呼ばれます。2つのオペランドのいずれかがtrueの場合、条件はtrueになります。 （A || B）はtrueです。

短絡論理演算子

論理AND演算子を使用する場合、両方のオペランドがtrueのときにのみ結果がtrueになりますが、最初のオペランドがfalseと判定された時点で結果は必ずfalseになるため、2番目のオペランドは評価されません。

例

public class LuoJi{ public static void main(String[] args){ int a = 5;//変数を定義します。 boolean b = (a<4)&&(a++<10); System.out.println("短絡論理演算子を使用した結果は次のとおりです。"+b); System.out.println("aの結果は"+a); } }

実行結果は次のとおりです。

使用短路逻辑运算符的结果为false
a的结果为5

解説：このプログラムは短絡論理演算子(&&)を使用しています。まず a<4 の結果が false と判断されるため、b の結果は必ず false になります。したがって、2番目のオペランド a++<10 の判定は実行されないため、a の値は 5 のままです。

代入演算子

以下はJava言語がサポートする代入演算子です。

演算子 説明 例
= 単純な代入演算子。右オペランドの値を左オペランドに代入します。 C = A + B は A + B で得られた値を C に代入します。

* = 乗算代入演算子。左オペランドと右オペランドを乗算し、その結果を左オペランドに代入します。 C *= A は C = C * A と同等です。
/ = 除算代入演算子。左オペランドを右オペランドで除算し、その結果を左オペランドに代入します。 C /= A は、C と A が同じ型の場合、C = C / A と同等です。
（％）= 剰余代入演算子。左オペランドを右オペランドで除算した余りを左オペランドに代入します。 C %= A は C = C % A と同等です。
<< = 左シフト代入演算子 C <<= 2 は C = C << 2 と同等です。
>> = 右シフト代入演算子 C >>= 2 は C = C >> 2 と同等です。
＆= ビットAND代入演算子 C &= 2 は C = C & 2 と同等です。
^ = ビットXOR代入演算子 C ^= 2 は C = C ^ 2 と同等です。
| = ビットOR代入演算子 C |= 2 は C = C | 2 と同等です。

instanceof 演算子

この演算子はオブジェクトインスタンスを操作するために使用され、そのオブジェクトが特定の型（クラス型またはインターフェイス型）であるかどうかをチェックします。

instanceof 演算子の使用形式は次のとおりです。

( Object reference variable ) instanceof  (class/interface type)

演算子の左側の変数が指すオブジェクトが、演算子の右側のクラスまたはインターフェイス（class/interface）のオブジェクトである場合、結果は true になります。

次に例を示します。

String name = "James";
boolean result = name instanceof String; // 由于 name 是 String 类型，所以返回真

比較されるオブジェクトが右側の型と互換性がある場合、この演算子は引き続き true を返します。

次の例を見てください。

class Vehicle {} public class Car extends Vehicle { public static void main(String[] args){ Vehicle a = new Car(); boolean result = a instanceof Car; System.out.println( result); } }

上記の例をコンパイルして実行した結果は次のとおりです。

true

Java 演算子の優先順位

複数の演算子が1つの式に含まれる場合、どれが先に評価されるのでしょうか。これは演算子の優先順位の問題に関わります。複数の演算子を含む式では、演算子の優先順位が異なると、最終的な結果が大きく異なることがあります。

例えば、（1+3）＋（3+2）*2 という式では、加算を最優先で計算すると答えは 18 になりますが、乗算を最優先で計算すると答えは 14 になります。

もう1つの例として、x = 7 + 3 * 2; の場合、x は 20 ではなく 13 になります。これは、乗算演算子が加算演算子よりも優先順位が高いため、最初に 3 * 2 を計算して 6 を得て、それから 7 を加算するからです。

次の表では、最も優先順位が高い演算子が表の最上部にあり、最も低い優先順位のものが表の下部にあります。

    サブクラスはスーパークラスの型ですが、スーパークラスはサブクラスの型ではありません。

    サブクラスのインスタンスはスーパークラス型として宣言できますが、スーパークラスのインスタンスはサブクラス型として宣言できません。

    class Vehicle {}

public class Car extends Vehicle {
    public static void main(String args[]){
        Vehicle v1 = new Vehicle(); //父类型
        Vehicle v2 = new Car(); //子类的实例可以声明为父类型
        Car c1 = new Car();    // 子类型
        Car c2 = new Vehicle(); //这句会报错，父类型的实例不能声明为子类型

        //Car（子类）是Vehicle（父类）类型, Vehicle（父类）不是Car（子类）类型
        boolean result1 =  c1 instanceof Vehicle;    // true
        boolean result2 =  c1 instanceof Car;        // true
        boolean result3 =  v1 instanceof Vehicle;    // true
        boolean result4 =  v1 instanceof Car;          // false
        boolean result5 =  v2 instanceof Vehicle;    // true
        boolean result6 =  v2 instanceof Car;          // true

        System.out.println(result1);
        System.out.println(result2);
        System.out.println(result3);
        System.out.println(result4);
        System.out.println(result5);
        System.out.println(result6);
   }
}

    実行結果からわかるように、v2 は Vehicle（スーパークラス）として宣言されていますが、instanceof Vehicle でも instanceof Car でも true になります。つまり v2 は実際には Car（サブクラス）です。そうでなければ v2 instanceof Car は false になるはずです。

    Java における演算子の左右結合性とはどういう意味ですか

    すべての数学演算子は左から右へ演算されるとみなされます。Java 言語でもほとんどの演算子は左から右への結合性を持ちますが、単項演算子、代入演算子、三項演算子は例外です。これらの演算子は右から左への結合性を持ち、つまり右から左へ演算されます。

    乗算と加算は結合可能な演算です。つまり、これらの演算子の左右のオペランドは、結果に影響を与えることなく入れ替えることができます。

    複数の演算子が演算に関与する場合、まず優先順位を考慮します。同じ優先順位の場合は結合性を見て演算順序を決定します。

    このため、同じ優先順位の演算が2つなければ、結合性を考慮する問題はありません。1つだけでは?:結合性は現れません。

    a?b:c?d:e

    これはどう計算するのでしょうか？まず優先順位を見ます。2つは同じです。次に結合性を見ると、右結合なので、最初に計算するのは：

    c?d:e

    次に計算するのは：

     a?b:(c?d:e)

    これがいわゆる右結合です。左結合の場合は、最初に計算するのは：

    a?b:c

    次に計算するのは：

    (a?b:c)?d:e

    実際には、結合性の問題は通常、括弧を使って解決できます。
