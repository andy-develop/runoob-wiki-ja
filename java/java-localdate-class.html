Java LocalDate クラス

LocalDate は Java 8 で導入された不変の日付クラスであり、java.timeパッケージの一部です。

LocalDate はタイムゾーンを含まない日付（年-月-日）を表します。例: "2023-05-15"。LocalDate は時刻やタイムゾーンの情報を含まないため、誕生日や祝日など日付のみが必要な場面に最適です。

LocalDate の主な特徴

1. 不変性

LocalDate インスタンスは不変であり、変更操作を行うと常に新しい LocalDate オブジェクトが返され、元のオブジェクトは変更されません。

2. スレッドセーフ

不変性により、LocalDate はスレッドセーフであり、マルチスレッド環境で安全に使用できます。

3. ISO-8601 規格

LocalDate は ISO-8601 暦法に準拠しています。これは現代の日付と時刻表現の国際標準です。

LocalDate オブジェクトの作成

1. 現在の日付を取得

LocalDate today = LocalDate.now();
System.out.println("今天的日期: " + today);

2. 特定の日付を指定して作成

LocalDate specificDate = LocalDate.of(2023, Month.MAY, 15);
// 或者
LocalDate specificDate2 = LocalDate.of(2023, 5, 15);

3. 文字列から解析

LocalDate parsedDate = LocalDate.parse("2023-05-15");

よく使う操作メソッド

1. 日付情報の取得

例

LocalDate date = LocalDate.of(2023, 5, 15);
int year = date.getYear();        // 2023
Month month = date.getMonth();    // MAY
int day = date.getDayOfMonth();   // 15
DayOfWeek dow = date.getDayOfWeek(); // MONDAY
int len = date.lengthOfMonth();   // 31 (5月の日数)
boolean leap = date.isLeapYear(); // false (2023年はうるう年ではない)

2. 日付の加算・減算

例

LocalDate tomorrow = today.plusDays(1);
LocalDate nextWeek = today.plusWeeks(1);
LocalDate nextMonth = today.plusMonths(1);
LocalDate nextYear = today.plusYears(1);
LocalDate yesterday = today.minusDays(1);

3. 日付の比較

例

LocalDate date1 = LocalDate.of(2023, 5, 15);
LocalDate date2 = LocalDate.of(2023, 6, 20);

boolean isBefore = date1.isBefore(date2); // true
boolean isAfter = date1.isAfter(date2);   // false
boolean isEqual = date1.isEqual(date2);   // false

4. 日付の調整

例

LocalDate date = LocalDate.of(2023, 5, 15);
LocalDate firstDayOfMonth = date.withDayOfMonth(1);
LocalDate lastDayOfYear = date.with(TemporalAdjusters.lastDayOfYear());

フォーマットと解析

1. 日付のフォーマット

例

LocalDate date = LocalDate.now();
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy/MM/dd");
String formattedDate = date.format(formatter);

2. 文字列を日付に解析

例

String dateStr = "2023/05/15";
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy/MM/dd");
LocalDate date = LocalDate.parse(dateStr, formatter);

実際の応用例

1. 2つの日付間の日数を計算

例

LocalDate startDate = LocalDate.of(2023, 5, 1);
LocalDate endDate = LocalDate.of(2023, 5, 15);
long daysBetween = ChronoUnit.DAYS.between(startDate, endDate);
System.out.println("日数差: " + daysBetween);

2. 日付が範囲内かどうかを確認

例

LocalDate dateToCheck = LocalDate.of(2023, 5, 10);
LocalDate startDate = LocalDate.of(2023, 5, 1);
LocalDate endDate = LocalDate.of(2023, 5, 31);
if (dateToCheck.isAfter(startDate) && dateToCheck.isBefore(endDate)) {
    System.out.println("日付は範囲内です");
}

3. ある月のすべての日付を取得

例

LocalDate date = LocalDate.of(2023, 5, 1);
int daysInMonth = date.lengthOfMonth();

for (int i = 1; i &lt;= daysInMonth; i++) {
    System.out.println(date.withDayOfMonth(i));
}

総合例

例

import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.format.DateTimeFormatter;
import java.time.temporal.ChronoUnit;
import java.util.Locale;

public class LocalDateDemo {

    public static void main(String[] args) {
        // 1. LocalDate インスタンスの作成
        System.out.println("=== LocalDate インスタンスの作成 ===");
        LocalDate today = LocalDate.now();
        LocalDate specificDate = LocalDate.of(2023, Month.JULY, 15);
        LocalDate parsedDate = LocalDate.parse("2023-08-20");
       
        System.out.println(現在の日付: + today);
        System.out.println("特定の日付: " + specificDate);
        System.out.println("解析した日付: " + parsedDate);

        // 2. 日付情報の取得
        System.out.println("\n"=== 日付情報の取得 ===");
        System.out.println("年: " + today.getYear());
        System.out.println("月: " + today.getMonth() + " (" + today.getMonthValue() + ")");
        System.out.println("日: " + today.getDayOfMonth());
        System.out.println("曜日: " + today.getDayOfWeek());
        System.out.println("年内の何日目: " + today.getDayOfYear());
        System.out.println("月の日数: " + today.lengthOfMonth());
        System.out.println("年の日数: " + today.lengthOfYear());
        System.out.println("うるう年かどうか: " + today.isLeapYear());

        // 3. 日付計算
        System.out.println("\n"=== 日付計算 ===");
        System.out.println("5日加算: " + today.plusDays(5));
        System.out.println("2週間加算: " + today.plusWeeks(2));
        System.out.println("3か月加算: " + today.plusMonths(3));
        System.out.println("1年減算: " + today.minusYears(1));
       
        System.out.println("翌月の1日: " + today.plusMonths(1).withDayOfMonth(1));
        System.out.println("今月の最終日: " + today.withDayOfMonth(today.lengthOfMonth()));

        // 4. 日付の比較
        System.out.println("\n"=== 日付の比較 ===");
        LocalDate date1 = LocalDate.of(2023, 6, 15);
        LocalDate date2 = LocalDate.of(2023, 6, 20);
       
        System.out.println(date1 + " は " + date2 + " より前? " + date1.isBefore(date2));
        System.out.println(date1 + " は " + date2 + " より後? " + date1.isAfter(date2));
        System.out.println(date1 + " と等しい " + date2 + "? " + date1.isEqual(date2));
       
        // 5. 日付差の計算
        System.out.println("\n"=== 日付差の計算 ===");
        LocalDate startDate = LocalDate.of(2023, 1, 1);
        LocalDate endDate = LocalDate.of(2023, 12, 31);
       
        System.out.println("2つの日付間の日数: " + ChronoUnit.DAYS.between(startDate, endDate));
        System.out.println("2つの日付間の月数: " + ChronoUnit.MONTHS.between(startDate, endDate));
        System.out.println("2つの日付間の年数: " + ChronoUnit.YEARS.between(startDate, endDate));

        // 6. 日付のフォーマット
        System.out.println("\n"=== 日付のフォーマット ===");
        DateTimeFormatter basicFormatter = DateTimeFormatter.ofPattern("yyyy/MM/dd");
        DateTimeFormatter chineseFormatter = DateTimeFormatter.ofPattern("yyyy年MM月dd日 EEEE", Locale.CHINA);
        DateTimeFormatter customFormatter = DateTimeFormatter.ofPattern("MMM dd, yyyy", Locale.US);
       
        System.out.println("基本フォーマット: " + today.format(basicFormatter));
        System.out.println("中国語フォーマット: " + today.format(chineseFormatter));
        System.out.println("英語フォーマット: " + today.format(customFormatter));

        // 7. その他の便利なメソッド
        System.out.println("\n"=== その他の便利なメソッド ===");
        System.out.println("次の月曜日に調整: " + today.with(DayOfWeek.MONDAY));
        System.out.println("週末かどうか: " +
            (today.getDayOfWeek() == DayOfWeek.SATURDAY || today.getDayOfWeek() == DayOfWeek.SUNDAY));
       
        // 8. 日付範囲の反復
        System.out.println("\n"=== 日付範囲の反復 ===");
        System.out.println("次の7日間の日付: ");
        today.datesUntil(today.plusDays(7))
             .forEach(System.out::println);
    }
}

まとめ

LocalDate クラスは Java 8 の日時 API の重要な構成要素であり、日付関連の操作を処理するための豊富なメソッドを提供します。従来の Date クラスや Calendar クラスと比較して、LocalDate はより直感的で使いやすく、スレッドセーフです。LocalDate の使い方をマスターすることで、日付処理の効率とコードの可読性を大幅に向上させることができます。

以下はそのよく使うメソッドです：

静的ファクトリメソッド

メソッド 説明 例
static LocalDate now() 現在の日付を取得 LocalDate.now()
static LocalDate of(int year, int month, int dayOfMonth) 年・月・日を指定して作成 LocalDate.of(2023, 6, 15)
static LocalDate of(int year, Month month, int dayOfMonth) 年・月・日を指定して作成（Month 列挙型を使用） LocalDate.of(2023, Month.JUNE, 15)
static LocalDate parse(CharSequence text) 文字列から解析（ISO形式：yyyy-MM-dd） LocalDate.parse("2023-06-15")
static LocalDate parse(CharSequence text, DateTimeFormatter formatter) 指定した形式で解析 LocalDate.parse("15/06/2023", DateTimeFormatter.ofPattern("dd/MM/yyyy"))

メソッド 説明 例

boolean isLeapYear() うるう年かどうかを判定 false
