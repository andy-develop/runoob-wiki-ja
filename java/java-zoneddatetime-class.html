Java ZonedDateTime クラス

ZonedDateTime は Java 8 で導入された日時 API (java.time パッケージ) の重要なクラスで、タイムゾーン付きの日付と時刻を表します。このクラスは LocalDateTime と ZoneId を組み合わせ、特定のタイムゾーンにおける時点を正確に表すことができます。

主な特徴

  • 日付（年、月、日）を含む
  • 時刻（時、分、秒、ナノ秒）を含む
  • タイムゾーン情報を含む
  • 不変でスレッドセーフなクラスです
  • タイムゾーン変換と夏時間の自動調整をサポートします

ZonedDateTime の作成方法

1. 現在時刻を使用して作成

例

// 現在のシステム既定タイムゾーンの日時を取得
ZonedDateTime now = ZonedDateTime.now();

// 指定したタイムゾーンの現在日時を取得
ZonedDateTime nowInTokyo = ZonedDateTime.now(ZoneId.of("Asia/Tokyo"));

2. 構成要素から作成

例

// 年、月、日、時、分、秒、タイムゾーンを指定
ZonedDateTime customDateTime = ZonedDateTime.of(
    2023, 12, 25, 15, 30, 0, 0,
    ZoneId.of("America/New_York")
);

3. LocalDateTime と ZoneId の組み合わせから作成

例

LocalDateTime localDateTime = LocalDateTime.of(2023, 6, 15, 10, 30);
ZoneId zoneId = ZoneId.of("Europe/Paris");
ZonedDateTime parisTime = ZonedDateTime.of(localDateTime, zoneId);

よく使う操作メソッド

1. 時刻情報の取得

例

ZonedDateTime zdt = ZonedDateTime.now();

int year = zdt.getYear();          // 年
Month month = zdt.getMonth();      // 月
int day = zdt.getDayOfMonth();     // 日
int hour = zdt.getHour();          // 時
int minute = zdt.getMinute();      // 分
int second = zdt.getSecond();      // 秒
ZoneId zone = zdt.getZone();       // タイムゾーン

2. 時刻の加算・減算操作

例

ZonedDateTime zdt = ZonedDateTime.now();

// 1日加算
ZonedDateTime tomorrow = zdt.plusDays(1);

// 2時間減算
ZonedDateTime twoHoursEarlier = zdt.minusHours(2);

// 3週間加算
ZonedDateTime threeWeeksLater = zdt.plusWeeks(3);

3. タイムゾーン変換

例

ZonedDateTime tokyoTime = ZonedDateTime.now(ZoneId.of("Asia/Tokyo"));

// ニューヨーク時刻に変換
ZonedDateTime newYorkTime = tokyoTime.withZoneSameInstant(ZoneId.of("America/New_York"));

// UTC時刻に変換
ZonedDateTime utcTime = tokyoTime.withZoneSameInstant(ZoneOffset.UTC);

実践的な使用例

1. 2つのタイムゾーンの時差を計算

例

ZonedDateTime londonTime = ZonedDateTime.now(ZoneId.of("Europe/London"));
ZonedDateTime sydneyTime = ZonedDateTime.now(ZoneId.of("Australia/Sydney"));

// 時差（時間）を計算
long hoursBetween = ChronoUnit.HOURS.between(londonTime, sydneyTime);
System.out.println("ロンドンとシドニーの現在の時差: " + hoursBetween + "時間");

2. タイムゾーンをまたぐ会議時刻の処理

例

// ニューヨークの会議時刻は午後3時
ZonedDateTime meetingTimeNY = ZonedDateTime.of(
    LocalDate.now(),
    LocalTime.of(15, 0),
    ZoneId.of("America/New_York")
);

// 東京時刻に変換
ZonedDateTime meetingTimeTokyo = meetingTimeNY.withZoneSameInstant(ZoneId.of("Asia/Tokyo"));
System.out.println("東京の参加者は現地時刻: " + meetingTimeTokyo);

3. 夏時間の処理

例

// ニューヨークの夏時間切替前後の時刻
ZonedDateTime beforeDST = ZonedDateTime.of(
    LocalDateTime.of(2023, 3, 11, 1, 30),
    ZoneId.of("America/New_York")
);

ZonedDateTime afterDST = beforeDST.plusHours(1);
System.out.println("実際の時差: " +
    Duration.between(beforeDST, afterDST).toHours() + "時間");

ZonedDateTime と他の日時クラスとの変換

1. Instant への変換

例

ZonedDateTime zdt = ZonedDateTime.now();
Instant instant = zdt.toInstant();  // UTCタイムスタンプに変換

2. LocalDateTime への変換

例

ZonedDateTime zdt = ZonedDateTime.now();
LocalDateTime ldt = zdt.toLocalDateTime();  // タイムゾーン情報が失われる

3. Instant からの作成

例

Instant instant = Instant.now();
ZonedDateTime zdt = instant.atZone(ZoneId.of("Asia/Shanghai"));

総合例

例

import java.time.ZonedDateTime;
import java.time.ZoneId;
import java.time.format.DateTimeFormatter;

public class ZonedDateTimeDemo {
    public static void main(String[] args) {
        // 1. 現在のタイムゾーンの現在時刻を取得
        ZonedDateTime now = ZonedDateTime.now();
        System.out.println("現在のタイムゾーンの時刻: " + now);
       
        // 2. 指定したタイムゾーンの現在時刻を取得
        ZonedDateTime tokyoTime = ZonedDateTime.now(ZoneId.of("Asia/Tokyo"));
        System.out.println("東京時刻: " + tokyoTime);
       
        // 3. 特定のタイムゾーン付き時刻を作成
        ZonedDateTime specificTime = ZonedDateTime.of(
            2023, 5, 15, 10, 30, 0, 0,
            ZoneId.of("America/New_York")
        );
        System.out.println("ニューヨークの特定時刻: " + specificTime);
       
        // 4. タイムゾーン変換
        ZonedDateTime londonTime = specificTime.withZoneSameInstant(ZoneId.of("Europe/London"));
        System.out.println("対応するロンドン時刻: " + londonTime);
       
        // 5. フォーマットして出力
        DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss z");
        System.out.println("フォーマットされた時刻: " + now.format(formatter));
       
        // 6. 各要素の情報を取得
        System.out.println("タイムゾーン: " + now.getZone());
        System.out.println("年: " + now.getYear());
        System.out.println("月: " + now.getMonth());
        System.out.println("時: " + now.getHour());
    }
}

东京时间: 2025-05-01T12:29:07.417938+09:00[Asia/Tokyo]
纽约特定时间: 2023-05-15T10:30-04:00[America/New_York]
对应的伦敦时间: 2023-05-15T15:30+01:00[Europe/London]
格式化时间: 2025-05-01 11:29:07 CST
时区: Asia/Shanghai
年份: 2025
月份: MAY
小时: 11

ベストプラクティス

  1. 保存と転送：データベース保存やネットワーク転送時は、Instant または UTC 時刻の ZonedDateTime を使用することを推奨します
  2. 表示：ユーザーインターフェースに表示するときだけローカルタイムゾーンに変換します
  3. 比較：異なるタイムゾーンの時刻を比較するときは、同じタイムゾーンまたは Instant に変換してから行います
  4. 夏時間：単純なオフセット（例："-05:00"）ではなく、常に完全なタイムゾーンID（例："America/New_York"）を使用します

ZonedDateTime はタイムゾーンに敏感なアプリケーションを扱うための強力なツールであり、正しく使用することで多くの一般的な日時問題を回避できます。
