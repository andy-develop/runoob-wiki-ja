Java Vector subList() メソッド

Java Vector

Vectorクラスは Java コレクションフレームワークの重要な構成要素であり、動的配列の機能を実装しています。subList()メソッドはVectorクラスが提供する実用的なメソッドで、既存のVectorから一部の要素を抽出して、新しいリストビューを形成します。

メソッド構文：

public List<E> subList(int fromIndex, int toIndex)

パラメータ説明

  • fromIndex：サブリストの開始インデックス（含む）
  • toIndex：サブリストの終了インデックス（含まない）

注意事項

  1. インデックス値は次の条件を満たす必要があります0 ≤ fromIndex ≤ toIndex ≤ size()
  2. もしfromIndexとtoIndex等しい場合、返されるサブリストは空です
  3. パラメータが負の数または範囲外の場合、例外をスローしますIndexOutOfBoundsException

戻り値の特性

subList()メソッドが返すのは元のVectorのビュー（view）であり、独立したコピーではありません。つまり：

ビュー特性

  • サブリストへの変更は元のVector
  • 原 Vectorの構造的変更（要素の追加/削除など）により、サブリストが無効になります
  • サブリストはすべてのリスト操作をサポートします

使用例

例

import java.util.Vector;
import java.util.List;

public class VectorSubListExample {
    public static void main(String[] args) {
        // Vector を作成して要素を追加する
        Vector<String> colors = new Vector<>();
        colors.add("Red");
        colors.add("Green");
        colors.add("Blue");
        colors.add("Yellow");
        colors.add("Black");
       
        System.out.println("元の Vector: " + colors);
       
        // サブリストを取得（インデックス1～3）
        List<String> subColors = colors.subList(1, 4);
        System.out.println("サブリスト: " + subColors);
       
        // サブリストを変更すると元の Vector に影響する
        subColors.set(0, "Light Green");
        System.out.println("サブリスト変更後の Vector: " + colors);
       
        // サブリストから要素を削除
        subColors.remove("Yellow");
        System.out.println("要素削除後の Vector: " + colors);
    }
}

サンプル出力

原始 Vector: [Red, Green, Blue, Yellow, Black]
子列表: [Green, Blue, Yellow]
修改子列表后的 Vector: [Red, Light Green, Blue, Yellow, Black]
移除元素后的 Vector: [Red, Light Green, Blue, Black]

よくある応用シナリオ

1. 部分データの処理

`Vector` の一部の要素のみを処理する必要がある場合、`subList()` を使用して特定の範囲のビューを取得できます。

2. 一括操作

サブリストに対する一括操作（`clear()`、`addAll()` など）は、単一要素を操作するよりも効率的です。

3. 範囲チェック

`Vector` の一部の要素が特定の条件を満たすかどうかを簡単に確認できます。

注意事項とベストプラクティス

1. 並行性の問題

`Vector` はスレッドセーフですが、サブリスト操作には追加の同期措置が必要な場合があります。

2. 構造的変更

元の `Vector` が構造的に変更された（要素の追加/削除など）場合、サブリストは `ConcurrentModificationException` をスローします。

3. パフォーマンスの考慮

頻繁なサブリスト操作の場合は、サブリストを新しい `ArrayList` に変換することを検討してください： ```java List independentSubList = new ArrayList<>(vector.subList(from, to)); ```

4. Arrays.asList() との違い

`subList()` は動的ビューを返しますが、`Arrays.asList()` は固定サイズのリストを返します。

まとめ

VectorのsubList()メソッドは、コレクションの部分ビューを効率的に処理できる強力なツールです。そのビュー特性を理解することは、正しく使用するために非常に重要です。実際の開発では、具体的な要件に応じて、サブリストビューを直接使用するか独立したコピーを作成するかを決定する必要があります。
