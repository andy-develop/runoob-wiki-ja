Java Number & Math クラス

Java Number

一般的に、数値が必要なときは、通常組み込みのデータ型を使用します。例：byte、int、long、doubleなど。

例

int a = 5000; float b = 13.65f; byte c = 0x4a;

しかし、実際の開発プロセスでは、組み込みデータ型ではなくオブジェクトを使用する必要がある状況に頻繁に遭遇します。この問題を解決するために、Java 言語は各組み込みデータ型に対応するラッパークラスを提供しています。

すべてのラッパークラスは（Integer、Long、Byte、Double、Float、Short）抽象クラス Number のサブクラスです。

クラス名対応する基本型説明
Bytebyteバイト型ラッパークラス
Shortshort短整数型ラッパークラス
Integerint整数型ラッパークラス
Longlong長整数型ラッパークラス
Floatfloat単精度浮動小数点型ラッパークラス
Doubledouble倍精度浮動小数点型ラッパークラス
BigInteger-不変の任意精度整数
BigDecimal-不変の任意精度符号付き十進数

このようなコンパイラによって特別にサポートされるラッピングをボクシング（装箱）と呼びます。組み込みデータ型がオブジェクトとして使用されるとき、コンパイラは組み込み型をラッパークラスにボクシングします。同様に、コンパイラはオブジェクトを組み込み型にアンボクシングすることもできます。

Number クラスは java.lang パッケージに属します。

Number は抽象クラスであり、主にさまざまな数値型に統一的な変換メソッドを提供する役割を持ちます：

例

public abstract class Number implements Serializable {
    // 抽象メソッド
    public abstract int intValue();
    public abstract long longValue();
    public abstract float floatValue();
    public abstract double doubleValue();
   
    // Java 8 で追加
    public byte byteValue() {
        return (byte)intValue();
    }
    public short shortValue() {
        return (short)intValue();
    }
}

以下は Integer オブジェクトを使用した例です：

Test.java ファイルコード：

public class Test{ public static void main(String[] args){ Integer x = 5; x = x + 10; System.out.println(x); } }

上記の例をコンパイルして実行した結果は次のとおりです：

15

x に整数値が代入されると、x はオブジェクトであるため、コンパイラは x をボクシングします。その後、x に加算演算を行えるようにするため、x をアンボクシングする必要があります。

よく使うメソッドの例

基本型の変換

例

Number num = 1234.56; // 実際は Double 型です

System.out.println(num.intValue());    // 1234 (小数切り捨て)
System.out.println(num.longValue());   // 1234
System.out.println(num.floatValue());  // 1234.56
System.out.println(num.doubleValue()); // 1234.56

数値の比較

例

java
Integer x = 10;
Double y = 10.0;

// 正しい比較方法：同じ型に変換してから比較する
System.out.println(x.doubleValue() == y.doubleValue()); // true

自動ボクシングとアンボクシング

Java 5+ は自動変換をサポートしています：

例

// 自動ボクシング
Integer autoBoxed = 42; // コンパイラは Integer.valueOf(42) に変換します

// 自動アンボクシング

Java Math クラス

Math クラスは Java が提供する数学ユーティリティクラスで、java.lang パッケージにあり、基本的な数値演算を実行する静的メソッドを含みます。

Java の Math には、初等指数、対数、平方根、三角関数などの基本的な数学演算を実行するためのプロパティとメソッドが含まれています。

Math のメソッドはすべて static 形式で定義されており、Math クラスを通じてメイン関数内で直接呼び出すことができます。

Test.java ファイルコード：

public class Test { public static void main (String []args) { System.out.println("90 度の正弦値：" + Math.sin(Math.PI/2)); System.out.println("0 度の余弦値：" + Math.cos(0)); System.out.println("60 度の正接値：" + Math.tan(Math.PI/3)); System.out.println("1 の逆正接値：" + Math.atan(1)); System.out.println("π/2 の角度値：" + Math.toDegrees(Math.PI/2)); System.out.println(Math.PI); } }

上記の例をコンパイルして実行した結果は次のとおりです：

90 度的正弦值：1.0
0度的余弦值：1.0
60度的正切值：1.7320508075688767
1的反正切值： 0.7853981633974483
π/2的角度值：90.0
3.141592653589793

高度な数学演算

1. 指数・対数演算

例

Math.exp(1);    // e^1 ≈ 2.718
Math.log(Math.E); // ln(e) = 1
Math.log10(100); // log10(100) = 2

2. 乱数生成

例

// [0.0, 1.0) の間の乱数を生成
double random = Math.random();

// [1, 100] のランダムな整数を生成
int randomInt = (int)(Math.random() * 100) + 1;

3. その他の演算

例

Math.hypot(3, 4); // sqrt(x²+y²) を計算 → 5.0
Math.IEEEremainder(10, 3); // IEEE 剰余 → 1.0

4. 定数フィールド

例

Math.PI;    // π ≈ 3.141592653589793
Math.E;     // 自然対数の底 e ≈ 2.718281828459045

    （1）Java は-128 ~ 127の整数をキャッシュするため、2 つの変数を定義して初期化値が-128 ~ 127の範囲内にある場合、2 つの変数は同じアドレスを使用します：

    Integer a=123;
Integer b=123;
System.out.println(a==b);        // 输出 true
System.out.println(a.equals(b));  // 输出 true

    （2）2 つの Integer 変数の値が-128 ~ 127の範囲を超える場合、変数は異なるアドレスを使用します：

    a=1230;
b=1230;
System.out.println(a==b);        // 输出 false
System.out.println(a.equals(b));  // 输出 true

    Java における int と Integer の違い

    1.int は基本データ型であり、int 変数は数値を格納します。Integer は参照型であり、実際にはオブジェクトで、Integer は参照オブジェクトのアドレスを格納します。

    2.

    Integer i = new Integer(100);
Integer j = new Integer(100);
System.out.print(i == j); //false

    new で生成されるのは2つのオブジェクトであり、そのメモリアドレスは異なります。

    3.

    int と Integer が占めるメモリの比較：

    Integer オブジェクトはより多くのメモリを占有します。Integer はオブジェクトであり、オブジェクトのメタデータを格納する必要があります。しかし int はプリミティブ型のデータなので、占有するスペースは少なくなります。

    4.非 new 生成の Integer 変数とnew Integer()new で生成された変数との比較結果は false です。

    /**
 * 比较非new生成的Integer变量与new生成的Integer变量
 */
public class Test {
    public static void main(String[] args) {
        Integer i= new Integer(200);
        Integer j = 200;
        System.out.print(i == j);
        //输出：false
    }
}

    非 new 生成の Integer 変数は java の定数プール内のオブジェクトを指しているため、一方new Integer()new で生成された変数はヒープ内に新規作成されたオブジェクトを指しており、両者のメモリアドレスは異なります。したがって出力は false です。

    5.2つの非 new 生成の Integer オブジェクトを比較する場合、2つの変数の値が区間[-128,127]の間にある場合、比較結果は true です。それ以外の場合は false です。

    /**
 * 比较两个非new生成的Integer变量
 */
public class Test {
    public static void main(String[] args) {
        Integer i1 = 127;
        Integer ji = 127;
        System.out.println(i1 == ji);//输出：true
        Integer i2 = 128;
        Integer j2 = 128;
        System.out.println(i2 == j2);//输出：false
    }
}

    java はコンパイル時にInteger i1 = 127、次のように変換されますInteger i1 = Integer.valueOf(127)。

    6.Integer 変数（new で生成されたかどうかに関わらず）と int 変数を比較する場合、2つの変数の値が等しければ、結果は常に true です。

    /**
 * 比较Integer变量与int变量
 */
public class Test {
    public static void main(String[] args) {
        Integer i1 = 200;
        Integer i2 = new Integer(200);
        int j = 200;
        System.out.println(i1 == j);//输出：true
        System.out.println(i2 == j);//输出：true
    }
}

    ラッパークラス Integer 変数が基本データ型 int 変数と比較される場合、Integer は自動的にアンボクシングされて int になり、その後比較が行われます。実際には2つの int 変数の比較であり、値が等しいため true になります。

    Math.floorは切り捨てです。

    Math.ceilは切り上げです。

    Math.roundは四捨五入して整数にすることです。ただし、注意が必要です：

    • 1、引数の小数点以下第1位が5未満の場合、演算結果は引数の整数部分になります。
    • 2、引数の小数点以下第1位が5より大きい場合、演算結果は引数の整数部分の絶対値 +1 となり、符号（すなわち正負）は変わりません。
    • 3、引数の小数点以下第1位が5に等しい場合、正数の演算結果は整数部分 +1 になり、負数の演算結果は整数部分になります。

    ～について言えばfloor()とceil()の概念理解：

    1. floor文字通りその意味を取り、つまり「床（フロア）」、床は足元にあり、つまり切り捨て。

    2. ceilであるceilingの略であり、つまり「天井（シーリング）」、天井は頭の上にあり、つまり切り上げ。

    ここでは注意が必要です、floor() と ceil() の戻り値はどちらもdouble 型の数値です。

    round() の四捨五入は y 軸を導入して決定することもできます：

    正数でも負数でも、四捨五入法では、.5 の小数はすべて切り上げます。

    したがって、負数の .5 小数の四捨五入は、単に直接絶対値を取り，さらに負号を加えるだけで完了します。
