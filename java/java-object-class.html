Java Object クラス

Java Object クラスはすべてのクラスの親クラスであり、つまり Java のすべてのクラスは Object を継承しています。サブクラスは Object のすべてのメソッドを使用できます。。

Object クラスは java.lang パッケージにあり、コンパイル時に自動的にインポートされます。クラスを作成する際、明示的に親クラスを継承しない場合、自動的に Object を継承し、Object のサブクラスになります。

Object クラスは明示的に継承することも、暗黙的に継承することもできます。以下の2つの方法は同じです：

明示的継承：

public class Runoob extends Object{

}

暗黙的継承：

public class Runoob {

}

クラスのメソッド

番号 メソッド & 説明
1 protected Object clone()

オブジェクトのコピーを作成して返します。
2 boolean equals(Object obj)

2つのオブジェクトが等しいかどうかを比較します。
3 protected void finalize()

GC（ガベージコレクタ）がこのオブジェクトへの参照がもはや存在しないと判断したとき、このメソッドはガベージコレクタによって呼び出されます。
4 Class<?> getClass()

オブジェクトの実行時クラスを取得します。
5 int hashCode()

オブジェクトのハッシュ値を取得します。
6 void notify()

このオブジェクト上で待機しているいずれかのスレッドを起床させます。
7 void notifyAll()

このオブジェクト上で待機しているすべてのスレッドを起床させます。
8 String toString()

オブジェクトの文字列表現を返します。
9 void wait()

現在のスレッドを待機状態にします。他のスレッドがこのオブジェクトの notify() メソッドまたは notifyAll() メソッドを呼び出すまで。
10 void wait(long timeout)

現在のスレッドを待機（ブロック）状態にします。他のスレッドがこのオブジェクトの notify() メソッドまたは notifyAll() メソッドを呼び出すか、パラメータで設定された timeout タイムアウト時間を超えるまで。
11 void wait(long timeout, int nanos)

wait(long timeout) メソッドと似ていますが、nanos パラメータが追加されています。このパラメータは追加時間（ナノ秒単位、範囲は 0〜999999）を表します。したがって、タイムアウト時間に nanos ナノ秒を加算する必要があります。
