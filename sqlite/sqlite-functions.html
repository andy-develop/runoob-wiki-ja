SQLite 常用関数

SQLite には、文字列や数値データを処理するための組み込み関数が多数あります。以下に、便利な SQLite 組み込み関数をいくつか示します。すべての関数は大文字と小文字を区別しません。つまり、これらの関数を小文字、大文字、または混合形式で使用できます。詳細については、SQLite の公式ドキュメントを参照してください：

番号関数 & 説明
1SQLite COUNT 関数
SQLite COUNT 集約関数は、データベーステーブル内の行数を計算するために使用されます。
2SQLite MAX 関数
SQLite MAX 集約関数を使用すると、列の最大値を選択できます。
3SQLite MIN 関数
SQLite MIN 集約関数を使用すると、列の最小値を選択できます。
4SQLite AVG 関数
SQLite AVG 集約関数は、列の平均値を計算します。
5SQLite SUM 関数
SQLite SUM 集約関数を使用すると、数値列の合計を計算できます。
6SQLite RANDOM 関数
SQLite RANDOM 関数は、-9223372036854775808 から +9223372036854775807 までの間の擬似ランダム整数を返します。
7SQLite ABS 関数
SQLite ABS 関数は、数値引数の絶対値を返します。
8SQLite UPPER 関数
SQLite UPPER 関数は、文字列を大文字に変換します。
9SQLite LOWER 関数
SQLite LOWER 関数は、文字列を小文字に変換します。
10SQLite LENGTH 関数
SQLite LENGTH 関数は、文字列の長さを返します。
11SQLite sqlite_version 関数
SQLite sqlite_version 関数は、SQLite ライブラリのバージョンを返します。

SQLite COUNT 関数

SQLite COUNT 集約関数は、データベーステーブル内の行数を計算するために使用されます。次に例を示します：

sqlite> SELECT count(*) FROM COMPANY;

上記の SQLite SQL ステートメントを実行すると、次の結果が生成されます：

count(*)
----------
7

SQLite MAX 関数

SQLite MAX 集約関数を使用すると、列の最大値を選択できます。次に例を示します：

sqlite> SELECT max(salary) FROM COMPANY;

上記の SQLite SQL ステートメントを実行すると、次の結果が生成されます：

max(salary)
-----------
85000.0

SQLite MIN 関数

SQLite MIN 集約関数を使用すると、列の最小値を選択できます。次に例を示します：

sqlite> SELECT min(salary) FROM COMPANY;

上記の SQLite SQL ステートメントを実行すると、次の結果が生成されます：

min(salary)
-----------
10000.0

SQLite AVG 関数

SQLite AVG 集約関数は、列の平均値を計算します。次に例を示します：

sqlite> SELECT avg(salary) FROM COMPANY;

上記の SQLite SQL ステートメントを実行すると、次の結果が生成されます：

avg(salary)
----------------
37142.8571428572

SQLite SUM 関数

SQLite SUM 集約関数を使用すると、数値列の合計を計算できます。次に例を示します：

sqlite> SELECT sum(salary) FROM COMPANY;

上記の SQLite SQL ステートメントを実行すると、次の結果が生成されます：

sum(salary)
-----------
260000.0

SQLite RANDOM 関数

SQLite RANDOM 関数は、-9223372036854775808 から +9223372036854775807 までの間の擬似ランダム整数を返します。次に例を示します：

sqlite> SELECT random() AS Random;

上記の SQLite SQL ステートメントを実行すると、次の結果が生成されます：

Random
-------------------
5876796417670984050

SQLite ABS 関数

SQLite ABS 関数は、数値引数の絶対値を返します。次に例を示します：

sqlite> SELECT abs(5), abs(-15), abs(NULL), abs(0), abs("ABC");

上記の SQLite SQL ステートメントを実行すると、次の結果が生成されます：

abs(5)      abs(-15)    abs(NULL)   abs(0)      abs("ABC")
----------  ----------  ----------  ----------  ----------
5           15                      0           0.0

SQLite UPPER 関数

SQLite UPPER 関数は、文字列を大文字に変換します。次に例を示します：

sqlite> SELECT upper(name) FROM COMPANY;

上記の SQLite SQL ステートメントを実行すると、次の結果が生成されます：

upper(name)
-----------
PAUL
ALLEN
TEDDY
MARK
DAVID
KIM
JAMES

SQLite LOWER 関数

SQLite LOWER 関数は、文字列を小文字に変換します。次に例を示します：

sqlite> SELECT lower(name) FROM COMPANY;

上記の SQLite SQL ステートメントを実行すると、次の結果が生成されます：

lower(name)
-----------
paul
allen
teddy
mark
david
kim
james

SQLite LENGTH 関数

SQLite LENGTH 関数は、文字列の長さを返します。次に例を示します：

sqlite> SELECT name, length(name) FROM COMPANY;

上記の SQLite SQL ステートメントを実行すると、次の結果が生成されます：

NAME        length(name)
----------  ------------
Paul        4
Allen       5
Teddy       5
Mark        4
David       5
Kim         3
James       5

SQLite sqlite_version 関数

SQLite sqlite_version 関数は、SQLite ライブラリのバージョンを返します。次に例を示します：

sqlite> SELECT sqlite_version() AS 'SQLite Version';

上記の SQLite SQL ステートメントを実行すると、次の結果が生成されます：

SQLite Version
--------------
3.6.20
