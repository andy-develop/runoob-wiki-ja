アニメーションプロパティ

プロパティ 説明 CSS
@keyframes アニメーションを定義します。@keyframesで定義されたアニメーション名は、animation-nameによって使用されます。 3
animation 複合プロパティ。オブジェクトに適用されるアニメーション効果を取得または設定します。 3
animation-name オブジェクトに適用されるアニメーション名を取得または設定します。アニメーション名は@keyframesで定義されるため、@keyframesルールと併用する必要があります。 3
animation-duration オブジェクトのアニメーションの所要時間を取得または設定します。 3
animation-timing-function オブジェクトのアニメーションの遷移タイプを取得または設定します。 3
animation-delay オブジェクトのアニメーションの遅延時間を取得または設定します。 3
animation-iteration-count オブジェクトのアニメーションの繰り返し回数を取得または設定します。 3
animation-direction オブジェクトのアニメーションがループ中に逆方向に動くかどうかを取得または設定します。 3
animation-play-state オブジェクトのアニメーションの状態を取得または設定します。 3
