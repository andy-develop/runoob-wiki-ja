Dart 制御フロー

制御フローは、プログラム内のコードがどの順序で実行されるかを決定します。

この章では、Dart の条件分岐（if/else、switch）とループ文（for、while）、および break と continue の使い方を紹介します。

if / else / else if 条件分岐

if 文は最も基本的な制御フロー構造で、条件に基づいてコードを実行するかどうかを決定します。

例

基本的な if 判定：

void main() {
  int score = 85;

  // 基本 if：条件が true のときに実行
  if (score >= 60) {
    print('RUNOOB おめでとう、合格です！');
  }

  // if-else：どちらか一方
  if (score >= 90) {
    print('優秀');
  } else {
    print('引き続き頑張れ');
  }

  // if-else if-else：多分岐選択
  if (score >= 90) {
    print('等級：A');
  } else if (score >= 80) {
    print('等級：B');
  } else if (score >= 70) {
    print('等級：C');
  } else if (score >= 60) {
    print('等級：D');
  } else {
    print('等級：F（不合格）');
  }
}
RUNOOB 恭喜，你及格了！
继续加油
等级：B

Dart の条件式は bool 型でなければなりません。JavaScript のように 0、''、null などを条件として使用することはできません。これらの書き方は Dart ではコンパイルエラーになります。

if 文のネスト

if 文の内部にはさらに if をネストでき、より複雑なロジックを処理できます。

例

void main() {
  bool isLoggedIn = true;
  bool isAdmin = false;
  String username = 'runoob';

  if (isLoggedIn) {
    // 外側の判定：ログインしているか
    if (isAdmin) {
      // 内側の判定：管理者かどうか
      print('おかえりなさい、管理者 $username');
    } else {
      print('おかえりなさい、$username');
    }
  } else {
    print('先にログインしてください');
  }
}
欢迎回来，runoob

ネストの階層が深すぎると可読性が低下するため、3 階層以内に抑えることをお勧めします。

ロジックが確かに複雑な場合は、早期リターン（return）や関数の分割を使って簡素化することを検討できます。

例

早期リターンで深いネストを置き換える：

// 早期リターンで深いネストを置き換えた方が読みやすい
String getAccessMessage(bool isLoggedIn, bool isAdmin, String name) {
  // まず「条件を満たさない場合は return する」ケースを処理する
  if (!isLoggedIn) {
    return '先にログインしてください';
  }

  if (!isAdmin) {
    return 'あなたには管理者権限がありません';
  }

  // 最後にメインロジック
  return 'おかえりなさい、管理者 $name';
}

void main() {
  print(getAccessMessage(true, false, 'runoob'));
  print(getAccessMessage(true, true, 'runoob'));
}
你没有管理权限
欢迎回来，管理员 runoob

switch / case 多分岐選択

変数が複数の固定された取り得る値を持つ場合、switch は if-else if よりも明確です。

例

void main() {
  String day = '水曜日';

  switch (day) {
    case '月曜日':
      print('新しい一週間が始まった');
      break;  // break は現在の case を終了し、次の case への「フォールスルー」を防ぐ
    case '火曜日':
      print('2日目の奮闘');
      break;
    case '水曜日':
      print('一週間が半分過ぎた');
      break;
    case '木曜日':
      print('もうすぐ金曜日だ');
      break;
    case '金曜日':
      print('TGIF！');
      break;
    case '土曜日':
    case '日曜日':
      // 複数の case で同じコードを共有できる
      print('週末を楽しんで！');
      break;
    default:
      // すべての case が一致しない場合に実行
      print('不明な日付');
  }
}
今週も半分過ぎた

Dart の switch は自動的に「フォールスルー」しません。空でない各 case は break、return、throw、continue のいずれかで終わらせる必要があります。フォールスルーを実現したい場合は、continue とラベル（label）を使います。

switch 式（Dart 3.0+）

Dart 3.0 で switch 式が導入され、直接値を生成できるため、より簡潔に記述できます。

例

void main() {
  String day = '水曜日';

  // switch 式：直接値を返す
  String mood = switch (day) {
    '月曜日' => '少し眠い',
    '火曜日' => '慣れてきた',
    '水曜日' => 'やる気満々',
    '木曜日' => '週末が待ち遠しい',
    '金曜日' => '気分がいい',
    '土曜日' || '日曜日' => '自由気まま',
    _ => '不明'  // _ はワイルドカードで、default に相当する
  };

  print('RUNOOB 気分: $mood');
}
RUNOOB 心情: 干劲十足

switch 式はすべての可能なケースを網羅する必要があり、コンパイラが漏れがないかチェックしてくれます。

for ループ

for ループは最も一般的なループ構造で、ループ回数が分かっている場合に適しています。

標準 for ループ

例

void main() {
  // 標準 for ループ：初期化; 条件; 更新
  for (int i = 1; i <= 5; i++) {
    print('RUNOOB 第 $i 回目のループ');
  }

  // ループ変数は外部で宣言することもできる
  int j = 0;
  for (; j < 3; j++) {
    print('j = $j');
  }
}

RUNOOB 第 2 次循环
RUNOOB 第 3 次循环
RUNOOB 第 4 次循环
RUNOOB 第 5 次循环
j = 0
j = 1
j = 2

for-in ループ（コレクションの走査）

for-in は List や Set などのコレクションを反復する最も簡潔な方法です。

例

void main() {
  List<String> fruits = ['りんご', 'バナナ', 'オレンジ', 'ぶどう'];

  // for-in：コレクション内の要素を 1 つずつ取り出す
  for (var fruit in fruits) {
    print('RUNOOB フルーツ: $fruit');
  }
}
RUNOOB 水果: 苹果
RUNOOB 水果: 香蕉
RUNOOB 水果: 橙子
RUNOOB 水果: 葡萄

forEach メソッド

List と Set には forEach メソッドもあり、コールバック関数を使って各要素を処理します。

例

void main() {
  List<int> scores = [85, 92, 78, 60];

  // forEach：各要素に対してコールバック関数を実行
  scores.forEach((score) {
    String result = score >= 60 ? '合格' : '不合格';
    print('RUNOOB 点数: $score -> $result');
  });
}
RUNOOB 分数: 85 -> 及格
RUNOOB 分数: 92 -> 及格
RUNOOB 分数: 78 -> 及格
RUNOOB 分数: 60 -> 及格

while と do-while ループ

while ループは各反復の前に条件をチェックし、ループ回数が不明なシナリオに適しています。

例

void main() {
  // while：条件を判定してから実行
  int count = 3;
  while (count > 0) {
    print('RUNOOB カウントダウン: $count');
    count--;  // 条件変数を更新するのを忘れないこと。そうしないと無限ループになる
  }
  print('発射！');
}
RUNOOB 倒计时: 3
RUNOOB 倒计时: 2
RUNOOB 倒计时: 1
发射！

do-while と while の違いは、do-while は条件が最後にチェックされるため、ループ本体が少なくとも 1 回は実行されることです。

例

void main() {
  // do-while：1 回実行してから条件を判定
  int num = 0;
  do {
    print('RUNOOB 少なくとも 1 回は実行、num = $num');
    num++;
  } while (num < 0);  // 条件は最初から false

  print(ループ終了、num = $num);
}
RUNOOB 至少执行一次，num = 0
循环结束，num = 1

do-while は、条件が最初から満たされていなくても、ループ本体が少なくとも 1 回は実行されることを保証します。これは「試してから判断する」シナリオ、たとえば有効な入力が得られるまでユーザー入力を受け取る場合などに役立ちます。

while vs for：どう選ぶか

シナリオ推奨ループ理由
ループ回数が確定しているfor初期化、条件、更新が一箇所に書かれていて一目瞭然
ループ回数が不明while条件だけに注目でき、より柔軟
少なくとも 1 回は実行するdo-while先に実行してから判定する
コレクションの走査for-in または forEach最も簡潔なコレクション走査方法

break と continue

break はループ全体を即座に終了するために使い、continue は現在の反復をスキップして次の反復に進むために使います。

例

void main() {
  // break：ターゲットを見つけたらすぐにループを停止
  List<String> names = ['Alice', 'Bob', 'runoob', 'David'];

  for (var name in names) {
    print('チェック: $name');
    if (name == 'runoob') {
      print('RUNOOB を見つけました！');
      break;  // ループを終了し、以降の要素はチェックしない
    }
  }

  print('---区切り線---');

  // continue：現在の反復をスキップ
  for (int i = 1; i <= 5; i++) {
    if (i == 3) {
      continue;  // i=3 の反復をスキップ
    }
    print('RUNOOB $i 回目');
  }
}

检查: Bob
检查: runoob
找到 RUNOOB 了！
---分隔线---
RUNOOB 第 1 次
RUNOOB 第 2 次
RUNOOB 第 4 次
RUNOOB 第 5 次

ラベル付き break と continue

ネストされたループでは、ラベルを使用して指定した外側のループを抜け出すことができます。

例

void main() {
  // ラベル outerLoop は外側のループを表す
  outerLoop:
  for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
      print('i=$i, j=$j');
      if (i == 2 && j == 2) {
        print('ターゲットを見つけたので、外側のループを終了');
        break outerLoop;  // outerLoop とマークされた外側のループを抜ける
      }
    }
  }
  print('ループ終了');
}
i=1, j=1
i=1, j=2
i=1, j=3
i=2, j=1
i=2, j=2
找到目标，退出外层循环
循环结束

ラベル（label）は慎重に使用すべきです。ほとんどの場合、ネストされたループのロジックを独立した関数に抽出し、return で終了する方が明確です。
