Dart 基本構文

すべてのプログラミング言語には独自の基本ルールがあり、Dart も例外ではありません。

この章では、Dart プログラムの基本構造、コメントの書き方、文と式の違い、および識別子の命名規則について説明します。

プログラム構造と main() 関数

Dart ファイル名の拡張子は.dart各 Dart プログラムには、エントリーポイントである main() 関数が必要です。

プログラムの実行は main() 関数の最初の行から始まり、最後の行の中括弧で終わります。

例

最もシンプルな Dart プログラムの構造：

// プログラムのエントリーポイント：main() 関数は Dart プログラムの起点です
void main() {
  // ここにコードを記述します
  print('サンプル Dart チュートリアルへようこそ！');
}
欢迎来到 サンプル Dart 教程！

このコードの各部分を詳しく見ていきましょう：

コード要素説明
void戻り値の型。void はこの関数が何も値を返さないことを示します
main関数名。Dart で規定されたエントリーポイント関数名であり、変更できません
()引数リスト。main() は引数を受け取らないか、コマンドライン引数を受け取ることができます
{ }関数本体。中括弧内のコードが関数で実行される内容です
print()組み込み関数。コンソールにテキストを出力するために使用します
;文の終端記号。Dart では各文はセミコロンで終わらせる必要があります

Dart では各文をセミコロン（;）で終わらせることが厳密に要求されます。セミコロンの付け忘れは、初心者にとって最もよくある構文エラーです。幸い、VS Code の Dart プラグインは、セミコロンが不足している箇所を自動的に示してくれます。

コマンドライン引数付きの main() 関数

main() 関数は文字列のリストをコマンドライン引数として受け取ることができます：

例

// List<String> args はコマンドラインから渡された引数リストを受け取ります
void main(List<String> args) {
  // 引数の数を出力
  print('引数の数：${args.length}');

  // 各引数を反復処理して出力
  for (var i = 0; i &lt; args.length; i++) {
    print('引数 $i: ${args[i]}');
  }
}

コメントの書き方

コメントはコードの説明であり、コンパイラはコメントの内容を無視します。

適切なコメントは、他の人（数か月後の自分自身も含む）がコードの意図をより速く理解するのに役立ちます。

Dart は3種類のコメント方式をサポートしています：

種類構文適用シーン
単行コメント// コメント内容特定の1行のコードの役割を簡潔に説明する
複数行コメント/* コメント内容 */複数行にわたる詳細な説明
ドキュメントコメント/// ドキュメントコメント関数やクラスの API ドキュメントを生成する

例

/// これはプログラムの機能を説明するためのドキュメントコメントです
/// ドキュメントコメントは [dart doc] コマンドを使用して HTML ドキュメントを生成できます
void main() {
  // 単行コメント：歓迎メッセージを出力
  print('Dart の学習へようこそ！'); // インラインコメント：これも有効です

  /*
* 複数行コメント：長い説明を書くのに適しています
* 2行目のコメント
* 3行目のコメント
   */
  print('サンプル チュートリアル - Dart 基本構文');
}

コメントの原則は「何をしたかではなく、なぜそうしたかを説明する」ことです。コード自体が何をするかを示しているため、コメントはなぜそのように書いたかを説明するか、コードだけでは伝えられない背景情報を補足するべきです。

文と式

Dart では、コードは文（Statement）と式（Expression）で構成されています。

両者の違いを理解することで、コードロジックをより適切に構成できます。

式（Expression）

式とは評価可能なコードであり、値を作り出します。

例

void main() {
  // 以下の各行はすべて式であり、それぞれ値を作り出します
  42;              // リテラル式、値は 42
  3 + 5;           // 算術式、値は 8
  'Hello'.length;  // プロパティアクセス式、値は 5
  (10 > 5);        // 関係式、値は true
}

文（Statement）

文は何らかの動作を実行する命令であり、値を作り出しません。

例

void main() {
  // 変数宣言文：変数を宣言して値を代入する
  var name = 'サンプル';

  // 関数呼び出し文：print() を呼び出して出力動作を実行する
  print(name);

  // 制御フロー文：条件に応じて実行するコードを決定する
  if (name.length > 3) {
    print('名前の長さが 3 より大きい');
  }
}
サンプル
名称长度大于 3

簡単に言うと：式は値を生成し、文は動作を実行します。

値が必要な場所では式を使用できますが、文は使用できません。

よくある誤解は、すべてのコードを「文」とみなすことです。実際には、Dart の多くの構造（関数呼び出しや変数代入など）はそれ自体が式であり、それらを入れ子にして使用できることを意味します。これは Dart と他の C 系言語に共通する特徴です。

識別子の命名規則

識別子（Identifier）とは、変数、関数、クラスなどのコード要素に付ける名前です。

Dart には識別子に関するいくつかの規則と規約があります：

命名規則（必須）

識別子は、英字、数字、アンダースコア（_）、ドル記号（$）のみで構成できます。

識別子は数字で始めることはできません。

識別子は Dart の予約キーワード（class、if、var など）にすることはできません。

命名規約（推奨）

コード要素命名スタイル例
クラス名アッパーキャメルケース（UpperCamelCase）StudentInfo、HttpClient
列挙型アッパーキャメルケース（UpperCamelCase）Color、Status
ライブラリ名、ファイル名小文字 + アンダースコア（lowercase_with_underscores）my_utils、user_service
変数名ローワーキャメルケース（lowerCamelCase）userName、maxCount
関数名ローワーキャメルケース（lowerCamelCase）getUserInfo()、calculateTotal()
定数名ローワーキャメルケース（lowerCamelCase）piValue、defaultPort
プライベートメンバーアンダースコアのプレフィックス_internalState、_privateMethod()

例

さまざまな命名スタイルの実際の適用例：

// クラス名：アッパーキャメルケース
class UserAccount {
  // パブリックメンバー：ローワーキャメルケース
  String userName;

  // プライベートメンバー：アンダースコアのプレフィックス（このファイル内でのみアクセス可能）
  String _password;

  // コンストラクタ
  UserAccount(this.userName, this._password);

  // パブリックメソッド：ローワーキャメルケース
  bool verifyPassword(String input) {
    return input == _password;
  }

  // プライベートメソッド：アンダースコアのプレフィックス
  void _encryptPassword() {
    // 暗号化ロジック...
  }
}

// エントリーポイント関数：小文字
void main() {
  // 変数名：ローワーキャメルケース
  var userAccount = UserAccount('サンプル', '123456');

  // 定数：ローワーキャメルケース（Dart スタイル）
  const maxLoginAttempts = 3;

  print('ユーザー名: ${userAccount.userName}');
  print('最大ログイン試行回数: $maxLoginAttempts');
}
用户名: サンプル
最大登录尝试次数: 3

Dart の命名規約では、定数には他の言語でよく見られるすべて大文字 + アンダースコア（UPPER_CASE）ではなく、ローワーキャメルケース（lowerCamelCase）を使用します。これは Dart コミュニティ独自のスタイルなので、必ず注意してください。
