Dart 基礎文法

最初の Dart プログラム

プログラミング言語を学ぶ最良の方法は、まず文法規則を暗記することではなく、まずプログラムを動かしてみて、それから一行ずつ「これはどういう意味だろう？」と問うことです。

この章では、最も簡単なプログラムから出発し、徐々に少し完成度の高い小さなプログラムへと拡張していきます。その過程で、Dart の最も基本的な概念を一通り見ていきます。

Dart 言語の標準ファイル拡張子.dart、例えばhello.dart。

最も簡単なプログラム：Hello, Dart!

DartPad を開くhttps://dartpad.dev（またはローカルエディタで hello.dart ファイルを作成し）、次のコードを入力します：

例

void main() {
  print('Hello, Dart!');
}

実行をクリックすると、出力は次のようになります：

Hello, Dart!

ローカル環境での実行コマンド：

dart hello.dart

わずか3行のコードです。それでは、すべての文字を一つひとつはっきりさせていきましょう。

行ごとの解説

void main() {

これはプログラムのエントリポイント関数の宣言です。Dart プログラムは常に main() から実行が始まります。

分解して見ると：

部分意味
void戻り値の型。void は「この関数が実行完了後に何も値を返さない」ことを意味します
main関数名。これは Dart で取り決められたエントリポイント関数名であり、他の名前に変更することはできません
()引数リスト。ここでは空であり、main 関数が引数を受け取らないことを示します
{関数本体の開始。最後の行の } と対になって、関数のすべてのコードを囲みます

main() は Dart の唯一のエントリポイントです。プログラムにファイルがいくつあっても、クラスがいくつあっても、実行は常に main() の最初の行から始まります。

print('Hello, Dart!');

これは1つの文で、括弧内の内容をコンソールに出力する働きをします。

分解して見ると：

部分意味
print組み込み関数名。コンソールに1行のテキストを出力するために使います
(...)関数呼び出しの引数リスト
'Hello, Dart!'文字列リテラル。シングルクォート ' で囲みます
;文の終端記号。各文はセミコロンで終わらせる必要があります
先頭のスペース2つインデント。この行のコードが main() 関数の内部に属することを示します。Dart ではスペース2つのインデントを使う約束です

}

main() 関数本体の終了マーク。最初の { と対になります。

全体構造図

void main() {          ← 函数签名（返回类型 + 函数名 + 参数）
  print('Hello,        ← 函数体：调用 print 函数
         Dart!');      ← 传入字符串参数，以 ; 结尾
}                      ← 函数体结束

文字列の2つの書き方

Dart では文字列はシングルクォートまたはダブルクォートで囲むことができ、両者は完全に同等です。

例

void main() {
  print('Hello, Dart!');   // シングルクォート
  print("Hello, Dart!");   // ダブルクォート、同じ効果
}
Hello, Dart!
Hello, Dart!

どのような場合にどちらの引用符を使うのでしょうか？ 次のシナリオを参考にできます：

シナリオ推奨例
一般的な場合シングルクォート（Dart コミュニティの取り決め）'Hello'
文字列内にシングルクォートが含まれる場合ダブルクォート"It's a beautiful day!"
文字列内にダブルクォートが含まれる場合シングルクォート彼は「こんにちは」と言った

文字列自体にシングルクォートが含まれる場合は、ダブルクォートで囲む方が便利で、エスケープの手間が省けます。Dart コミュニティではシングルクォートを優先する取り決めがあり、本チュートリアルでも以降はシングルクォートを中心に使います。

コメント

コメントは人に向けて書く説明文であり、Dart コンパイラは完全に無視します。

例

void main() {
  // これは単行コメントです。// から行末まで
  print('Hello, Dart!'); // 文の後ろにも書けます

  /*
これは複数行コメントです。
複数行にまたがれます。
長いコードを一時的にコメントアウトするときによく使います。
  */

  /// これはドキュメントコメントです。関数・クラス・変数の働きを説明するために使います。
  /// IDE はドキュメントコメントをホバーによるヒントとして表示します。
}
コメントの種類構文用途
単行コメント// 内容特定の1行のコードを説明する
複数行コメント/* 内容 */コードをコメントアウトする、または長い説明を書く
ドキュメントコメント/// 内容API を説明し、ドキュメント生成に使う

良いコメントは「何をしているか」ではなく「なぜ」を説明します。コード自体がすでに「何をしているか」を示しているので、コメントはその背後にある理由や意図を補うべきです。

変数：データに名前を付ける

プログラムは固定の文字だけを出力するわけにはいきません。データを保存して使うために変数が必要です。

例

void main() {
  String name = 'RUNOOB';
  int age = 25;
  double height = 1.68;
  bool isStudent = true;

  print(name);
  print(age);
  print(height);
  print(isStudent);
}
RUNOOB
25
1.68
true

変数宣言の書式

类型名  变量名  =  初始值  ;
 │       │         │    └─ 语句结束符
 │       │         └─ 赋值运算符
 │       └─ 你给这个数据起的名字
 └─ 告诉 Dart 这个变量存储什么类型的数据

基本データ型の概要

型説明例
Stringテキスト文字列'RUNOOB'、"hello"
int整数25、-10、0
double小数（浮動小数点数）1.68、3.14
boolブール値（真/偽）true、false

データ型の詳細については後の章で説明します。ここではまず大まかな印象を持っておいてください。

var による型の自動推論

毎回型名を書くのは少し面倒です。

Dart は var キーワードによる変数の型自動推論をサポートしています。代入された値に基づいてコンパイラが型を判断します。

例

void main() {
  var name = 'RUNOOB';    // String と推論される
  var age = 25;           // int と推論される
  var height = 1.68;      // double と推論される
  var isStudent = true;   // bool と推論される

  print(name);
  print(age);
}
RUNOOB
25

var で推論された型はコンパイル時に確定するため、その後別の型の値を代入することはできません。

例

void main() {
  var name = 'RUNOOB';
  name = 'Bob';    // 可能。依然として String
  // name = 123; // エラー：int を String 型の変数に代入することはできない
}

どのようなときに var を使い、どのようなときに型を明記するのでしょうか？

シナリオ推奨理由
型が一目でわかるローカル変数varより簡潔
関数の引数、クラスのフィールド、戻り値の型型を明記するコードがより明確になり、自己文書化できる

文字列補間：文字列に変数を埋め込む

変数の値を文字列に埋め込みたい場合、Dart は非常に簡潔な文字列補間構文を提供しています。$変数名 または ${式} を使います。

例

void main() {
  var name = 'RUNOOB';
  var age = 25;

  print('我叫 $name，今年 $age 岁。');
  print('明年我将 ${age + 1} 岁。');
}
我叫 RUNOOB，今年 25 岁。
明年我将 26 岁。
構文用途例
$変数名変数の値を直接埋め込む。簡潔$name
${式}任意の式（計算・メソッド呼び出しなど）を埋め込む${age + 1}、${name.toUpperCase()}

print('私の名前は ' + name + '、今年で ' + age.toString() + ' 歳です。') のような文字列連結の書き方と比べて、補間構文はより明確で安全であり、Dart の慣用のなスタイルです。

少し完成度の高い小さなプログラム

ここまで学んだことをまとめて、もう少し現実的なプログラムを書いてみましょう。簡単な自己紹介ジェネレーターです。

例

void main() {
  // 個人情報
  var name = 'RUNOOB';
  var age = 25;
  var city = '上海';
  var isStudent = false;
  var hobby = 'Dart プログラミング';

  // 紹介文の生成：三項演算子で身分を判断
  var occupation = isStudent ? '学生' : '社会人';

  print('=============================');
  print(' 個人プロフィール');
  print('=============================');
  print('氏名：$name');
  print('年齢：$age 歳');
  print('都市：$city');
  print('身分：$occupation');
  print('趣味：$hobby');
  print('-----------------------------');
  print('皆さん、こんにちは。$city出身の$nameです、');
  print('今年は$age歳で、$occupationです。');
  print('私の趣味は${hobby}で、皆さんにお会いできて嬉しいです！');
  print('=============================');
}
=============================
       个人简介
=============================
姓名：RUNOOB
年龄：25 岁
城市：上海
身份：职场人
爱好：Dart 编程
-----------------------------
大家好，我是来自上海的RUNOOB，
今年 25 岁，是一名职场人。
我的爱好是Dart 编程，很高兴认识大家！
=============================

新しく出てきた構文：三項演算子

例

var occupation = isStudent ? '学生' : '社会人';

これがDartの三項演算子です。形式は：

条件 ? 条件が真の場合の値 : 条件が偽の場合の値

以下のif/elseの書き方と同等です：

例

String occupation;
if (isStudent) {
  occupation = '学生';
} else {
  occupation = '社会人';
}

三項演算子は値が2通りしかない場合に非常に簡潔です。if/elseの完全な使い方については、後の章で詳しく説明します。

コードスタイル：Dart の記述規範

良いコードスタイルはコードをより読みやすく、よりプロフェッショナルにします。

Dartには公式に推奨されている規範があります。初心者の段階では、次のポイントを押さえれば十分です。

インデントはスペース2つ

例

// 正しい：スペース2つ
void main() {
  print('Hello');
}

// 推奨されない：スペース4つ（他の言語では一般的だが、Dartコミュニティは2つを好む）

変数・関数名は lowerCamelCase（小文字始まりのキャメルケース）

例

var firstName = 'RUNOOB';     // 小キャメルケース：正しい
// var first_name = 'RUNOOB'; // スネークケース：Dartの慣例ではない
// var FirstName = 'RUNOOB'; // 大キャメルケース：クラス名用に予約されている

クラス名は UpperCamelCase（大文字始まりのキャメルケース）

例

class UserProfile { }   // 正しい
// class user_profile { } // 間違い
// class userProfile { } // 間違い

定数は lowerCamelCase（すべて大文字ではない）

例

const maxRetries = 3;       // Dartの慣例：正しい
// const MAX_RETRIES = 3; // これはC/Javaスタイル。Dartでは推奨されない

dart format で自動フォーマットする

規範を暗記する必要はありません。プロジェクトディレクトリで次のコマンドを実行するだけです：

$ dart format .

Dartの公式フォーマットツールがコードを自動的に標準スタイルに調整します。保存時にVS Codeで自動フォーマットを設定することもできます。

よくあるエラーとその解釈

初心者が最初のプログラムを書くときによく遭遇するエラーを以下に示します。これらを理解しましょう。

エラー1：セミコロンの付け忘れ

例

void main() {
  print('Hello, Dart!')  // ; がありません
}

エラーメッセージ：

Error: Expected ';' after this.

解決方法：文の末尾に ; を付けます。

エラー2：括弧の対応が取れていない

例

void main() {
  print('Hello, Dart!'   // 右括弧 ) がありません
}

エラーメッセージ：

Error: Expected ')' before this.

解決方法：すべての ( に対応する ) があるかどうか注意深く確認してください。VS Codeは対応していない括弧をハイライト表示します。

エラー3：文字列の引用符が一致しない

void main() {
  print('Hello, Dart!");  // 一个单引号、一个双引号
}

エラーメッセージ：

Error: Unterminated string literal.

解決方法：文字列の両端に同じ種類の引用符を使用してください。

エラー4：main のスペルミス

例

void Main() {  // Mが大文字になっている
  print('Hello, Dart!');
}

Dartは大文字と小文字を区別します。Mainとmainは完全に異なる名前です。

プログラムはコンパイルできますが、実行時にエラーになります：

Error: No 'main' method found.

解決方法：エントリー関数は小文字の main である必要があります。

エラー5：変数を使用する前に値を代入していない

例

void main() {
  String name;
  print(name);  // name が初期化されていない
}

DartのNull安全機構によるエラーメッセージ：

Error: Non-nullable variable 'name' must be assigned before it can be used.

解決方法：変数を宣言するときに初期値も代入するか、null許容型 String? name として宣言します（詳細は後の章で説明します）。
