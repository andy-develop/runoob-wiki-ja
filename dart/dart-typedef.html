Dart typedef と関数型

typedef は Dart における型エイリアス（型別名）の仕組みであり、複雑な型に対して短く読みやすい名前を定義できます。

この章では typedef の2つの使い方を紹介します: 従来の関数型エイリアスと、Dart 3.0 で導入されたジェネリック型エイリアスです。

typedef 関数型エイリアス

関数型が頻繁に使用される場合、typedef で明確な名前を付けることができます。

これはコールバック関数やイベントハンドラーなどの場面で特に役立ちます。

実例

// 関数型エイリアスを定義する
// 2つの int パラメータを受け取り、int を返す関数を表す
typedef IntOperation = int Function(int a, int b);

// コールバック型を定義する
// String メッセージを受け取り、戻り値がない関数を表す
typedef MessageCallback = void Function(String message);

// typedef をパラメータ型として使用する
int performOperation(int x, int y, IntOperation operation) {
  return operation(x, y);
}

void logMessage(String msg, MessageCallback callback) {
  print('メッセージを出力する準備をしています...');
  callback('[RUNOOB] $msg');
}

void main() {
  // IntOperation シグネチャに一致する関数を渡す
  int add(int a, int b) => a + b;
  int multiply(int a, int b) => a * b;

  print('10 + 5 = ${performOperation(10, 5, add)}');
  print('10 × 5 = ${performOperation(10, 5, multiply)}');

  // 匿名関数を直接渡すこともできます
  int result = performOperation(20, 4, (a, b) => a ~/ b);
  print('20 ÷ 4 = $result');

  // MessageCallback を使用する
  logMessage('操作が完了しました', (msg) {
    print('メッセージを受信: $msg');
  });
}
10 + 5 = 15
10 × 5 = 50
20 ÷ 4 = 5
准备输出消息...
收到消息: [RUNOOB] 操作完成

typedef がない場合、各パラメータの位置で冗長な関数型シグネチャを繰り返し記述する必要があります。

typedef を使うと、型宣言が明確で統一され、変更時には1か所を修正するだけで済みます。

typedef は型にエイリアスを付けるだけで、新しい型を作成するわけではありません。IntOperation と int Function(int, int) は型システム上で完全に等価です。

関数型をパラメータとして

Dart では、関数は第一級市民（First-class Citizen）であり、通常の値のように渡すことができます。

実例

// 関数型を直接使用してパラメータを宣言する（typedef を使用しない）
void processNumbers(
  List<int> numbers,
  bool Function(int) filter,
  String Function(int) formatter,
) {
  var filtered = numbers.where(filter);
  for (var n in filtered) {
    print(formatter(n));
  }
}

// 関数を返す高階関数
int Function(int) makeMultiplier(int factor) {
  // 返されるクロージャは factor をキャプチャする
  return (int n) => n * factor;
}

void main() {
  var scores = [55, 78, 92, 60, 45, 88];

  print('--- 合格点 ---');
  processNumbers(
    scores,
    (n) => n >= 60,                    // フィルタ条件
    (n) => 'RUNOOB スコア: $n 点',       // フォーマット
  );

  print('--- 高得点（> 80）---');
  processNumbers(
    scores,
    (n) => n > 80,
    (n) => '高得点: $n 点',
  );

  // 関数を戻り値として
  var doubler = makeMultiplier(2);
  var tripler = makeMultiplier(3);
  print('5 × 2 = ${doubler(5)}');
  print('5 × 3 = ${tripler(5)}');
}

コールバックパターン

コールバックパターンは関数型の最も一般的な適用シーンです。

それは「何をするか」の制御を呼び出し側に委ね、コードをより柔軟で再利用可能にします。

実例

// コールバック型を定義する
typedef ResultCallback<T> = void Function(T result);
typedef ErrorCallback = void Function(String error);

// 非同期操作をシミュレートする
void fetchUserData(
  String userId, {
  required ResultCallback<Map<String, dynamic>> onSuccess,
  required ErrorCallback onError,
}) {
  // ネットワークリクエストをシミュレートする
  print('ユーザーデータを取得中...');

  // 成功/失敗をシミュレートする
  if (userId == 'runoob') {
    var data = {
      'id': 'runoob',
      'name': 'RUNOOB ユーザー',
      'level': 'VIP',
    };
    onSuccess(data);
  } else {
    onError('ユーザー $userId は存在しません');
  }
}

void main() {
  // コールバックで結果を処理する
  fetchUserData(
    'runoob',
    onSuccess: (data) {
      print('取得成功！');
      print('ユーザー名: ${data['name']}');
      print('レベル: ${data['level']}');
    },
    onError: (error) {
      print('取得失敗: $error');
    },
  );

  print('---');

  // 失敗ケースをテストする
  fetchUserData(
    'unknown',
    onSuccess: (data) {
      print('取得成功');
    },
    onError: (error) {
      print('取得失敗: $error');
    },
  );
}

获取成功！
用户名: RUNOOB 用户
等级: VIP
---
正在获取用户数据...
获取失败: 用户 unknown 不存在

コールバックパターンの一般的な適用シーン:

シーンコールバック型の例
ネットワークリクエストonSuccess(data) / onError(error)
UI イベントonTap() / onLongPress()
データ変換map()、where()、reduce() 内のコールバック
タイマーTimer(callback, duration)
アニメーション完了onComplete()

コールバックパターンは柔軟ですが、多層の非同期操作を扱うと「コールバック地獄」を引き起こす可能性があります。Dart は async/await を提供して非同期フローをよりエレガントに処理します。これについては第17章で詳しく説明します。

Dart 3.0 ジェネリック型エイリアス

Dart 3.0 は typedef の機能を拡張し、関数型だけでなくあらゆる型のエイリアスを作成できるようになりました。

実例

// Dart 3.0: typedef はあらゆる型のエイリアスを作成できる

// 複雑なコレクション型のエイリアス
typedef JsonMap = Map<String, dynamic>;
typedef UserList = List<Map<String, dynamic>>;

// ジェネリックエイリアス
typedef Result<T> = ({T data, String? error});

// 関数型エイリアス（従来の使い方）
typedef Validator<T> = String? Function(T value);

// 型エイリアスを使用する
void processJson(JsonMap json) {
  print('JSON を処理: $json');
  print('キーの数: ${json.length}');
}

void validateAndPrint<T>(T value, Validator<T> validator) {
  var error = validator(value);
  if (error != null) {
    print('検証失敗: $error');
  } else {
    print('検証成功: $value');
  }
}

void main() {
  // JsonMap エイリアスを使用する
  JsonMap userData = {
    'name': 'runoob',
    'age': 10,
    'isVip': true,
  };
  processJson(userData);

  // Result エイリアスを使用する
  Result<String> successResult = (data: '操作成功', error: null);
  Result<String> errorResult = (data: '', error: 'ネットワーク接続がタイムアウトしました');
  print('成功: ${successResult.data}');
  print('失敗: ${errorResult.error}');

  // ジェネリック Validator を使用する
  Validator<String> nameValidator = (value) {
    if (value.isEmpty) return '名前は空にできません';
    if (value.length < 3) return '名前は少なくとも3文字必要です';
    return null;  // null は検証成功を意味する
  };

  validateAndPrint('RUNOOB', nameValidator);
  validateAndPrint('AB', nameValidator);
}
处理 JSON: {name: runoob, age: 10, isVip: true}
键的数量: 3
成功: 操作成功
失败: 网络连接超时
验证通过: RUNOOB
验证失败: 名称至少 3 个字符

Dart 3.0 の型エイリアスは冗長な型宣言を大幅に減らし、コードをより簡潔で読みやすくします。

型エイリアス（typedef）と型自体は実行時に完全に等価であり、それらはコンパイル時の「ニックネーム」にすぎません。つまり、typedef を使って構造が同じだが意味が異なる2つの型を区別することはできません。それらは同じ型として扱われます。
