Dart コレクション型

コレクションは、複数のデータを格納するためのデータ構造です。

Dart には3つの主要なコレクション型が組み込まれています：List（リスト）、Set（セット）、Map（マップ）です。この章では、それぞれの使い方を説明します。

List：順序付きリスト

List は最もよく使われるコレクション型で、順序付けられた一連の要素を格納し、重複を許可します。

インデックス（0から始まる）を使って List 内の任意の要素にアクセスできます。

List を作成

例

void main() {
  // リテラルを使用して List を作成
  List<String> sites = ['RUNOOB', 'Google', 'GitHub'];
  print('サイトリスト: $sites');

  // 型推論（ジェネリクス省略）
  var numbers = [1, 2, 3, 4, 5];
  print('数値リスト: $numbers');

  // 空リストを作成
  var emptyList = <String>[];

  // List.filled を使用して固定長リストを作成
  var zeros = List.filled(3, 0);  // [0, 0, 0]
  print('埋め込みリスト: $zeros');

  // List.generate を使用してリストを生成
  var squares = List.generate(5, (i) => i * i);
  print('平方数リスト: $squares');
}
网站列表: [RUNOOB, Google, GitHub]
数字列表: [1, 2, 3, 4, 5]
填充列表: [0, 0, 0]
平方数列表: [0, 1, 4, 9, 16]

List 要素のアクセスと変更

例

void main() {
  var fruits = ['りんご', 'バナナ', 'オレンジ'];

  // インデックスでアクセス（0から始まる）
  print('最初の果物: ${fruits);  // りんご
  print('最後の果物: ${fruits[fruits.length - 1]}');  // オレンジ

  // 要素を変更
  fruits[1] = 'ぶどう';
  print('変更後: $fruits');  // [りんご, ぶどう, オレンジ]

  // 長さを取得
  print('果物の数: ${fruits.length}');

  // 空かどうかを確認
  print('リストは空ですか? ${fruits.isEmpty}');
  print('リストは空でない? ${fruits.isNotEmpty}');
}

最后一个: 橙子
修改后: [苹果, 葡萄, 橙子]
水果数量: 3
列表为空? false
列表非空? true

List の基本操作

例

void main() {
  var list = ['RUNOOB', 'Dart'];

  // 要素を追加
  list.add('Flutter');           // 単一要素を追加
  list.addAll(['Google', 'AI']);  // 複数要素を追加
  print('追加後: $list');

  // 要素を挿入（指定位置に）
  list.insert(1, 'チュートリアル');
  print('挿入後: $list');

  // 要素を削除
  list.remove('AI');             // 値を指定して削除
  list.removeAt(0);              // インデックスを指定して削除
  list.removeLast();             // 最後の要素を削除
  print('削除後: $list');

  // 要素を検索
  bool hasDart = list.contains('Dart');
  int index = list.indexOf('Dart');
  print('Dart を含む? $hasDart, 位置: $index');

  // ソート
  var nums = [3, 1, 4, 1, 5, 9];
  nums.sort();
  print('ソート後: $nums');

  // 反転
  var reversed = nums.reversed.toList();
  print('反転後: $reversed');

  // サブリストを抽出
  var subList = nums.sublist(0, 3);
  print('最初の3つ: $subList');
}
添加后: [RUNOOB, Dart, Flutter, Google, AI]
插入后: [RUNOOB, 教程, Dart, Flutter, Google, AI]
删除后: [教程, Dart, Flutter]
包含 Dart? true, 位置: 1
排序后: [1, 1, 3, 4, 5, 9]
反转后: [9, 5, 4, 3, 1, 1]
前3个: [1, 1, 3]

List の関数型メソッド

Dart の List は map、where、reduce などの関数型メソッドをサポートしており、データ処理をより簡潔にします。

例

void main() {
  var scores = [55, 78, 92, 60, 45, 88];

  // where：フィルタリング（条件を満たす要素を保持）
  var passed = scores.where((s) => s >= 60);
  print('合格点: $passed');

  // map：変換（各要素を新しい値に変換）
  var grades = scores.map((s) => s >= 60 ? '合格' : '不合格');
  print('評価: $grades');

  // where + map のチェーン呼び出し
  var highScores = scores
      .where((s) => s >= 80)
      .map((s) => '高得点: $s')
      .toList();
  print('高得点リスト: $highScores');

  // reduce：累積計算
  var total = scores.reduce((sum, s) => sum + s);
  print('RUNOOB 合計点: $total');

  // fold：初期値付きの累積計算
  var avg = scores.fold(0, (sum, s) => sum + s) / scores.length;
  print('平均点: ${avg.toStringAsFixed(1)}');

  // any / every：存在チェック
  bool hasFullMark = scores.any((s) => s == 100);
  bool allPassed = scores.every((s) => s >= 60);
  print('満点はありますか? $hasFullMark');
  print('全員合格ですか? $allPassed');
}
及格分数: (78, 92, 60, 88)
评级: (不及格, 及格, 及格, 及格, 不及格, 及格)
高分列表: [高分: 92, 高分: 88]
RUNOOB 总分: 418
平均分: 69.7
有满分吗? false
全部及格? false

map() と where() は Iterable（遅延評価）を返すため、toList() で List に変換して初めて実際に計算が実行されます。1回だけループ処理する場合は、Iterable をそのまま使えばよく、変換は不要です。

Set：一意の要素の集合

Set は List に似ていますが、Set 内の各要素は1回しか出現できず、重複は許可されません。

Set は順序を持たず、インデックスで要素にアクセスできません。

例

void main() {
  // Set を作成（要素は自動的に重複排除）
  Set<String> tags = {'Dart', 'Flutter', 'Dart', 'RUNOOB'};
  print('タグ集合: $tags');  // {Dart, Flutter, RUNOOB}、重複した Dart は除去された
  print('タグ数: ${tags.length}');  // 3

  // 要素を追加
  tags.add('Google');
  tags.add('Dart');  // Dart は既に存在するため、重複追加されない
  print('追加後: $tags');

  // 要素を削除
  tags.remove('Google');
  print('削除後: $tags');

  // 含むかどうかを確認
  print('RUNOOB を含む? ${tags.contains('RUNOOB')}');

  // 集合演算
  var setA = {1, 2, 3, 4};
  var setB = {3, 4, 5, 6};

  print('積集合: ${setA.intersection(setB)}');  // {3, 4}
  print(和集合: ${setA.union(setB)});          // {1, 2, 3, 4, 5, 6}
  print('差集合: ${setA.difference(setB)}');     // {1, 2}
}
标签集合: {Dart, Flutter, RUNOOB}
标签数量: 3
添加后: {Dart, Flutter, RUNOOB, Google}
删除后: {Dart, Flutter, RUNOOB}
包含 RUNOOB? true
交集: {3, 4}
并集: {1, 2, 3, 4, 5, 6}
差集: {1, 2}

Set の典型的な使用シーンは「重複排除」です。重複する要素が不要な場合、Set を使う方が List で手動により重複を除去するよりはるかに効率的です。

Map：キーと値のペアのマッピング

Map はキーと値のペア（Key-Value Pair）を格納するために使われ、各キーは1つの値に対応します。

Map 内のキーは一意である必要がありますが、値は重複しても構いません。

Map の作成とアクセス

例

void main() {
  // リテラルを使用して Map を作成
  Map<String, String> siteInfo = {
    'name': 'RUNOOB',
    'url': 'https://www.runoob.com',
    'type': 'プログラミングチュートリアル',
  };

  // キーを使って値にアクセス
  print('サイト名: ${siteInfo['name']}');
  print('サイト URL: ${siteInfo['url']}');

  // 存在しないキーにアクセスすると null を返す
  print('説明: ${siteInfo['description']}');  // null

  // キーと値のペアを追加/変更
  siteInfo['language'] = '中国語';
  siteInfo['name'] = 'RUNOOB.COM';  // 既存キーの値を変更
  print('更新後: $siteInfo');

  // すべてのキーとすべての値を取得
  print('すべてのキー: ${siteInfo.keys}');
  print('すべての値: ${siteInfo.values}');

  // キーが存在するかどうかを確認
  print('url キーはありますか? ${siteInfo.containsKey('url')}');
  print('desc キーはありますか? ${siteInfo.containsKey('desc')}');
}
站点名称: RUNOOB
站点 URL: https://www.runoob.com
描述: null
更新后: {name: RUNOOB.COM, url: https://www.runoob.com, type: 编程教程, language: 中文}
所有键: (name, url, type, language)
所有值: (RUNOOB.COM, https://www.runoob.com, 编程教程, 中文)
有 url 键? true
有 desc 键? false

Map の基本操作

例

void main() {
  var scores = {
    'runoob': 95,
    'Alice': 87,
    'Bob': 72,
  };

  // Map を反復処理
  scores.forEach((name, score) {
    print('$name: $score 点');
  });

  // キーと値のペアを削除
  scores.remove('Bob');
  print('Bob を削除後: $scores');

  // 値またはデフォルト値を取得
  int aliceScore = scores['Alice'] ?? 0;
  int eveScore = scores['Eve'] ?? 0;  // 存在しない場合、デフォルト値 0 を返す
  print('Alice: $aliceScore, Eve: $eveScore');

  // putIfAbsent：キーが存在しない場合のみ追加
  scores.putIfAbsent('runoob', () => 100);  // 既に存在する場合は追加しない
  scores.putIfAbsent('David', () => 80);    // 存在しない、追加
  print('最終: $scores');

  // 長さを取得
  print('人数: ${scores.length}');
}
runoob: 95 分
Alice: 87 分
Bob: 72 分
删除 Bob 后: {runoob: 95, Alice: 87}
Alice: 87, Eve: 0
最终: {runoob: 95, Alice: 87, David: 80}
人数: 3

Map のキーは任意の型（String、int など）にできますが、キーの等価性が意味を持つことを保証する必要があります。カスタムオブジェクトをキーとして使用する場合は、== と hashCode が正しく実装されていることを確認する必要があります。

コレクションのスプレッド演算子 ... と ...?

展開演算子は、あるコレクションの要素を別のコレクションに「展開」することができます。

例

void main() {
  var basics = ['Dart', 'Flutter'];
  var advanced = ['非同期プログラミング', '状態管理'];

  // ... 展開演算子：別のコレクションの要素を挿入
  var allCourses = ['RUNOOB 入門', ...basics, ...advanced];
  print('すべてのコース: $allCourses');

  // ...? null安全展開：コレクションが null の場合はスキップ
  List<String>? optionalList;  // null の可能性がある
  var safeList = ['最初の項目', ...?optionalList];
  print('安全展開: $safeList');  // 最初の項目のみ

  optionalList = ['追加コンテンツ'];
  safeList = ['最初の項目', ...?optionalList];
  print('値あり展開: $safeList');
}
所有课程: [RUNOOB 入门, Dart, Flutter, 异步编程, 状态管理]
安全展开: [第一项]
有值展开: [第一项, 额外内容]

コレクション内の if と for（コレクション制御フロー）

Dart ではコレクションリテラル内で直接 if と for を使用できます。これは非常に便利なシンタックスシュガーです。

例

void main() {
  bool showAdmin = true;

  // コレクション内の if：条件に応じて要素を含めるかどうかを決定
  var menuItems = [
    'ホーム',
    'チュートリアル',
    if (showAdmin) '管理画面',  // 条件が true の場合のみ追加
    'について',
  ];
  print('メニュー: $menuItems');

  // コレクション内の for：別のコレクションから要素を生成
  var numbers = [1, 2, 3];
  var doubled = [
    for (var n in numbers) n * 2,  // 反復処理して新しい要素を生成
  ];
  print('2倍: $doubled');

  // if + for は組み合わせて使用可能
  var tags = ['Dart', 'Flutter'];
  var links = [
    'RUNOOB ホーム',
    for (var tag in tags) 'https://runoob.com/$tag',
  ];
  print('リンク: $links');
}
菜单: [首页, 教程, 管理后台, 关于]
翻倍: [2, 4, 6]
链接: [RUNOOB 首页, https://runoob.com/Dart, https://runoob.com/Flutter]

3種類のコレクションの比較

特性ListSetMap
順序性順序あり順序なし順序なし（ただし反復順序はある）
重複許可許可許可しないキーは重複不可、値は重複可
インデックスアクセス[] をサポートサポートしないキーによる [] アクセス
代表的な用途順序付きリスト、シーケンス重複排除、タグ集合キーバリューマッピング、設定項目
リテラルの作成[]{}{key: value}

注意事項

Set と Map はどちらも{}リテラルとして。

違いは次のとおりです：

  • Map はkey: value形式（コロンあり）
  • Set は要素を直接書く（コロンなし）

例：

var map = {'name': 'Tom'};   // Map
var set = {'Tom', 'Jerry'}; // Set

特に注意が必要です：

var x = {};

これは空の Set を作成せず、Dart によって次のように推論されます：

Map<dynamic, dynamic>

空の中括弧では要素の型を判断できないため、Dart はデフォルトで Map として扱います。

空の Set を作成する場合は、明示的に指定する必要があります：

var x = <String>{};

或

： 
Set<String> x = {};
