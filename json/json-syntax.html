JSON 構文

JSON 構文は JavaScript 構文のサブセットです。

JSON 構文規則

JSON 構文は JavaScript オブジェクト表記構文のサブセットです。

  • データは名前/値ペアの中に
  • データはカンマで,区切られます
  • スラッシュを使用して\文字をエスケープします
  • 波括弧{}オブジェクトを保存します
  • 角括弧[]配列を保存します。配列には複数のオブジェクトを含めることができます。

JSON の2つの構造：

1. オブジェクト：波括弧{}保存されるオブジェクトは順序のない名前/値ペアの集合です。オブジェクトは左括弧で{始まり、右括弧で}終わります。各「キー」の後にコロンが続きます:，名前/値ペアはカンマで,区切られます。

2. 配列：角括弧[]保存される配列は値（value）の順序付き集合です。配列は左角括弧で[始まり、右角括弧で]終わり、値の間はカンマで,区切られます。

値（value）は、二重引用符で囲まれた文字列（string）、数値（number）、true、false、null、オブジェクト（object）、または配列（array）にすることができ、これらは入れ子にすることができます。

JSON 名前/値ペア

JSON データの記述形式は次のとおりです：

key : value

名前/値ペアは、フィールド名（二重引用符内）を含み、その後にコロンを書き、次に値を記述します：

"name" : "初心者向けチュートリアル"

これは簡単に理解できます。次の JavaScript ステートメントと同等です：

name = "初心者向けチュートリアル"

JSON 値

JSON 値には次のものを使用できます：

  • 数値（整数または浮動小数点数）
  • 文字列（二重引用符内）
  • 論理値（true または false）
  • 配列（角括弧内）
  • オブジェクト（波括弧内）
  • null

JSON 数値

JSON 数値は整数型または浮動小数点型にすることができます：

{ "age":30 }

JSON オブジェクト

JSON オブジェクトは波括弧{}の中に記述します：

{key1 : value1, key2 : value2, ... keyN : valueN }

オブジェクトには複数の名前/値ペアを含めることができます：

{ "name":"初心者向けチュートリアル" , "url":"www.runoob.com" }

これも簡単に理解できます。次の JavaScript ステートメントと同等です：

name = "初心者向けチュートリアル" url = "www.runoob.com"

JSON 配列

JSON 配列は角括弧[]の中に記述します：

配列には複数のオブジェクトを含めることができます：

[
    { key1 : value1-1 , key2:value1-2 }, 
    { key1 : value2-1 , key2:value2-2 }, 
    { key1 : value3-1 , key2:value3-2 }, 
    ...
    { key1 : valueN-1 , key2:valueN-2 }, 
]
{ "sites": [ { "name":"初心者向けチュートリアル" , "url":"www.runoob.com" }, { "name":"google" , "url":"www.google.com" }, { "name":"Weibo" , "url":"www.weibo.com" } ] }

上記の例では、オブジェクトsitesは3つのオブジェクトを含む配列です。各オブジェクトは、特定のウェブサイト（name、url）に関するレコードを表します。

JSON ブール値

JSON ブール値は true または false にすることができます：

{ "flag":true }

JSON null

JSON は null 値を設定できます：

{ "runoob":null }

JSON は JavaScript 構文を使用

JSON は JavaScript 構文を使用するため、追加のソフトウェアなしで JavaScript 内の JSON を処理できます。

JavaScript を使用すると、オブジェクトの配列を作成し、次のように代入できます：

例

var sites = [ { "name":"runoob" , "url":"www.runoob.com" }, { "name":"google" , "url":"www.google.com" }, { "name":"Weibo" , "url":"www.weibo.com" } ];

JavaScript オブジェクト配列の最初の項目（インデックスは 0 から始まります）には、次のようにアクセスできます：

sites[0].name;

返される内容は次のとおりです：

runoob

データは次のように変更できます：

sites[0].name="初心者向けチュートリアル";
