JSON.parse()

JSONは通常、サーバー側とのデータ交換に使用されます。

サーバーデータを受信する際は、通常は文字列です。

JSON.parse() メソッドを使用して、データをJavaScriptオブジェクトに変換できます。

構文

JSON.parse(text[, reviver])

パラメータの説明：

  • text:必須。有効なJSON文字列。
  • reviver:オプション。変換結果の関数。オブジェクトの各メンバーに対してこの関数が呼び出されます。

JSON 解析の例

例えば、サーバーから以下のデータを受信したとします：

{ "name":"runoob", "alexa":10000, "site":"www.runoob.com" }

JSON.parse() メソッドを使用して上記のデータを処理し、JavaScriptオブジェクトに変換します：

var obj = JSON.parse('{ "name":"runoob", "alexa":10000, "site":"www.runoob.com" }');

解析する前に、データが標準のJSON形式であることを確認してください。そうしないと解析エラーが発生します。

オンラインツールで確認できます：https://www.jyshare.com/front-end/53。

解析が完了すると、WebページでJSONデータを使用できます：

例

<p id="demo"></p> <script> var obj = JSON.parse('{ "name":"runoob", "alexa":10000, "site":"www.runoob.com" }'); document.getElementById("demo").innerHTML = obj.name + "：" + obj.site; </script>

サーバーからJSONデータを受信する

AJAXを使用してサーバーからJSONデータをリクエストし、JavaScriptオブジェクトに解析できます。

例

var xmlhttp = new XMLHttpRequest(); xmlhttp.onreadystatechange = function() { if (this.readyState == 4 && this.status == 200) { myObj = JSON.parse(this.responseText); document.getElementById("demo").innerHTML = myObj.name; } }; xmlhttp.open("GET", "/try/ajax/json_demo.txt", true); xmlhttp.send();

サーバーから配列のJSONデータを受信する

サーバーから受信したJSONデータが配列の場合、JSON.parse はそれをJavaScript配列に変換します：

例

var xmlhttp = new XMLHttpRequest(); xmlhttp.onreadystatechange = function() { if (this.readyState == 4 && this.status == 200) { myArr = JSON.parse(this.responseText); document.getElementById("demo").innerHTML = myArr[1]; } }; xmlhttp.open("GET", "/try/ajax/json_demo_array.txt", true); xmlhttp.send();

データの解析

JSONはDateオブジェクトを保存できません。

Dateオブジェクトを保存する必要がある場合は、文字列に変換する必要があります。

その後、文字列をDateオブジェクトに変換します。

例

var text = '{ "name":"Runoob", "initDate":"2013-12-14", "site":"www.runoob.com"}'; var obj = JSON.parse(text); obj.initDate = new Date(obj.initDate); document.getElementById("demo").innerHTML = obj.name + "日付を作成:" + obj.initDate;

試してみる »

JSON.parse の2番目のパラメータ reviver（変換結果の関数）を使用できます。オブジェクトの各メンバーに対してこの関数が呼び出されます。

例

var text = '{ "name":"Runoob", "initDate":"2013-12-14", "site":"www.runoob.com"}'; var obj = JSON.parse(text, function (key, value) { if (key == "initDate") { return new Date(value); } else { return value; }}); document.getElementById("demo").innerHTML = obj.name + "日付を作成：" + obj.initDate;

関数の解析

JSONは関数を含めることを許可していませんが、関数を文字列として保存し、後で文字列を関数に変換することができます。

例

var text = '{ "name":"Runoob", "alexa":"function () {return 10000;}", "site":"www.runoob.com"}'; var obj = JSON.parse(text); obj.alexa = eval("(" + obj.alexa + ")"); document.getElementById("demo").innerHTML = obj.name + "Alexaランキング：" + obj.alexa();

JSONでの関数の使用はお勧めしません。

    サーバーから返されたJSON文字列について、jQueryの非同期リクエストで型指定をしていない場合、または文字列として受け取った場合は、オブジェクト化処理を一度行う必要があります。方法はそれほど面倒ではなく、その文字列を eval() に入れて一度実行するだけです。この方法は通常のJavaScript方式でJSONオブジェクトを取得する場合にも適しています。以下に例を挙げて説明します：

    var u = eval('('+user+')');

    なぜ eval ではここに () を追加する必要がある('('+user+')')のか？

    原因は eval 自体の問題にあります。JSONは{}という形式で始まり、終わるため、JSでは文ブロックとして扱われます。そのため、強制的に式に変換する必要があります。

    括弧を追加する目的は、eval関数がJavaScriptコードを処理する際に、括弧内の式（expression）を強制的にオブジェクトとして変換し、文（statement）として実行しないようにすることです。例えば、オブジェクトリテラル {} の場合、外側の括弧を追加しないと、eval は中括弧をJavaScriptコードブロックの開始と終了のマーカーとして認識するため、{} は空文を1つ実行したと見なされます。したがって、以下の2つの実行結果は異なります：

    alert(eval("{}"); // return undefined
alert(eval("({})");// return object[Object]

    テスト例

    var user = '{name:"张三",age:23,'+   
    'address:{city:"青岛",zip:"266071"},'+    'email:"iteacher@haiersoft.com.cn",'+  
    'showInfo:function(){'+  
    'document.write("姓名："+this.name+"<br/>");'+  
    'document.write("年龄："+this.age+"<br/>");'+  
    'document.write("地址："+this.address.city+"<br/>");'+  
    'document.write("邮编："+this.address.zip+"<br/>");'+  
    'document.write("E-mail："+this.email+"<br/>");} }';   
var u = eval('('+user+')');  
u.showInfo();
