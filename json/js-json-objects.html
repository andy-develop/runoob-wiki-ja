JSON オブジェクト

オブジェクト構文

例

{ "name":"runoob", "alexa":10000, "site":null }

JSONオブジェクトは波括弧{...}で記述します。

オブジェクトは複数のkey/value（キー/値）のペアを含むことができます。

キーは文字列である必要があり、値は有効なJSONデータ型（文字列、数値、オブジェクト、配列、ブール値、またはnull）を使用できます。

キーと値の間はコロンで:区切ります。

各 key/value ペアはカンマで,区切ります。

オブジェクトの値にアクセス

ドット（.）を使用して.オブジェクトの値にアクセスできます：

例

var myObj, x; myObj = { "name":"runoob", "alexa":10000, "site":null }; x = myObj.name;

角括弧（[]）を使用してオブジェクトの値にアクセスすることもできます：

例

var myObj, x; myObj = { "name":"runoob", "alexa":10000, "site":null }; x = myObj["name"];

試してみる »

オブジェクトをループ

for-in を使用してオブジェクトのプロパティをループできます：

例

var myObj = { "name":"runoob", "alexa":10000, "site":null }; for (x in myObj) { document.getElementById("demo").innerHTML += x + "<br>"; }

試してみる »

for-in でオブジェクトのプロパティをループする場合、角括弧（[]）を使用してプロパティの値にアクセスします：

例

var myObj = { "name":"runoob", "alexa":10000, "site":null }; for (x in myObj) { document.getElementById("demo").innerHTML += myObj[x] + "<br>"; }

試してみる »

ネストされたJSONオブジェクト

JSONオブジェクトの中に別のJSONオブジェクトを含めることができます：

例

myObj = { "name":"runoob", "alexa":10000, "sites": { "site1":"www.runoob.com", "site2":"m.runoob.com", "site3":"c.runoob.com" } }

ドット（.）または.角括弧（[]）を使用して[...]ネストされたJSONオブジェクトにアクセスできます。

例

x = myObj.sites.site1; //または x = myObj.sites["site1"];

試してみる »

値の変更

ドット（.）を使用して.JSONオブジェクトの値を変更できます：

例

myObj.sites.site1 = "www.google.com";

試してみる »

角括弧（[]）を使用して[...]JSONオブジェクトの値を変更できます：

例

myObj.sites["site1"] = "www.google.com";

試してみる »

オブジェクトのプロパティを削除

私たちはキーワードを使用してdeleteJSONオブジェクトのプロパティを削除できます：

例

delete myObj.sites.site1;

試してみる »

角括弧（[]）を使用して[...]JSONオブジェクトのプロパティを削除できます：

例

delete myObj.sites["site1"]

    json では、キー名を使用して値を取得する場合、特に注意が必要です。

    キー名を別の変数に代入し、ドット（.）方式で値を取得しようとしても、この方法はうまくいきません。

    var myObj, x;
myObj = { "name":"runoob", "alexa":10000, "site":null };
x = "name";
document.getElementById("demo").innerHTML = myObj.x;  // 结果是 undefined

    次の方法でのみ[]アクセスできます：

    var myObj, x;
myObj = { "name":"runoob", "alexa":10000, "site":null };
x = "name";
document.getElementById("demo").innerHTML = myObj[x];  // 结果是 runoob
