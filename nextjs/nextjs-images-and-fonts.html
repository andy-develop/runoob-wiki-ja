Next.js 画像とフォント

Next.js は、アプリケーションのパフォーマンスとユーザーエクスペリエンスを向上させるために、組み込みの画像およびフォント最適化機能を提供します。

Next.js の画像およびフォント最適化機能は、開発者に強力なツールを提供し、高性能でユーザーエクスペリエンスに優れた Web アプリケーションの構築を支援します。

機能説明
画像最適化使用<Image>コンポーネントは、ローカルおよびリモートの画像をサポートし、サイズと読み込みパフォーマンスを自動的に最適化します。
フォント最適化使用next/fontモジュールは、Google フォントとローカルフォントをサポートし、自動的にホストして読み込みを最適化します。
静的リソース管理静的リソースをpublicディレクトリに配置し、/filenameを介して直接アクセスできます。

静的リソース管理

Next.js では、静的リソース（画像、フォントなど）を public ディレクトリに配置できます。

これらのリソースは /filename で直接アクセスできます。

ディレクトリ構造の例：

my-next-app/
├── app/
├── public/
│   ├── images/
│   │   └── logo.png
│   └── fonts/
│       └── my-font.woff2
├── package.json
└── next.config.js

public/images/logo.pngを介して/images/logo.pngアクセスできます。

画像最適化

Next.js は<Image>コンポーネントを提供し、画像の読み込みを最適化します。これは HTML の<img>要素を拡張し、以下の機能を提供します：

  • サイズ最適化：さまざまなデバイスに適切なサイズの画像を自動的に提供し、WebP などの最新の画像フォーマットをサポートします。

  • 視覚的安定性：画像読み込み時のレイアウトシフト（Layout Shift）を防ぎます。

  • より速い読み込み：ブラウザ標準の遅延読み込みを使用し、画像がビューポートに入ったときのみ読み込みます。

  • リソースの柔軟性：リモート画像でも、必要に応じて画像サイズを調整できます。

使用<Image>コンポーネント

从 next/imageインポート<Image>コンポーネントをインポートし、コンポーネント内で使用します。

例

import Image from 'next/image';

export default function Page() {
  return <Image src="/images/logo.png" alt="Logo" width={500} height={300} />;
}

ローカル画像

ローカル画像は public ディレクトリから直接参照できます。

例

import Image from 'next/image';
import profilePic from './me.png';

export default function Page() {
  return (
    <Image
      src={profilePic}
      alt="Picture of the author"
      // width と height は画像ファイルから自動的に取得されます
      // blurDataURL と placeholder はオプションです
    />
  );
}

リモート画像

リモート画像では、レイアウトシフトを避けるために width と height を手動で指定する必要があります。

例

import Image from 'next/image';

export default function Page() {
  return (
    <Image
      src="https://s3.amazonaws.com/my-bucket/profile.png"
      alt="Picture of the author"
      width={500}
      height={500}
    />
  );
}

リモート画像の設定

next.config.js で許可するリモート画像のドメインを設定します。

例

const nextConfig = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 's3.amazonaws.com',
        port: '',
        pathname: '/my-bucket/**',
      },
    ],
  },
};

export default nextConfig;

フォント最適化

Next.js はnext/fontモジュールを提供し、フォントの読み込みを最適化します。フォントファイルを自動的にホストすることで、プライバシーとパフォーマンスを向上させます。

Google フォントを使用

next/font/google からフォントをインポートし、HTML 要素に適用します。

例

import { Geist } from 'next/font/google';

const geist = Geist({
  subsets: ['latin'],
});

export default function Layout({ children }) {
  return (
    <html lang="en" className={geist.className}>
      <body>{children}</body>
    </html>
  );
}

非可変フォントを使用する場合は、weight を指定する必要があります：

例

import { Roboto } from 'next/font/google';

const roboto = Roboto({
  weight: '400',
  subsets: ['latin'],
});

export default function Layout({ children }) {
  return (
    <html lang="en" className={roboto.className}>
      <body>{children}</body>
    </html>
  );
}

ローカルフォントを使用

next/font/local からローカルフォントファイルをインポートします。

例

import localFont from 'next/font/local';

const myFont = localFont({
  src: './my-font.woff2',
});

export default function Layout({ children }) {
  return (
    <html lang="en" className={myFont.className}>
      <body>{children}</body>
    </html>
  );
}

複数のフォントファイルを使用する場合：

例

const roboto = localFont({
  src: [
    {
      path: './Roboto-Regular.woff2',
      weight: '400',
      style: 'normal',
    },
    {
      path: './Roboto-Italic.woff2',
      weight: '400',
      style: 'italic',
    },
    {
      path: './Roboto-Bold.woff2',
      weight: '700',
      style: 'normal',
    },
    {
      path: './Roboto-BoldItalic.woff2',
      weight: '700',
      style: 'italic',
    },
  ],
});
