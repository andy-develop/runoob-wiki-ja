イテレータ（iterator）はオブジェクトの一種であり、標準テンプレートライブラリのコンテナ内の一部または全部の要素を走査するために使用できます。各イテレータオブジェクトはコンテナ内の特定のアドレスを表します。

Lua においてイテレータはポインタ型をサポートする構造であり、集合のすべての要素を走査できます。

ジェネリックforイテレータ

ジェネリックforは内部にイテレータ関数を保存します。実際にはイテレータ関数、状態定数、制御変数の3つの値を保存します。

ジェネリックforイテレータは集合の key/value ペアを提供します。構文形式は以下のとおりです：

for k, v in pairs(t) do
    print(k, v)
end

上記のコードでは、k, v は変数リストです。pairs(t) は式リストです。

以下の実例を参照してください：

実例

array = {"Google", "Runoob"}

for key,value in ipairs(array)
do
   print(key, value)
end

上記のコードを実行した出力結果は次のとおりです：

1  Google
2  Runoob

上記の実例では、Lua がデフォルトで提供するイテレータ関数 ipairs を使用しました。

次に、ジェネリックforの実行プロセスを見てみましょう：

  • まず、初期化として、in の後の式の値を計算します。式はジェネリックforが必要とする3つの値、すなわちイテレータ関数、状態定数、制御変数を返す必要があります。複数値の代入と同様に、式が返す結果の数が3つ未満の場合は自動的に nil で補完され、余分な部分は無視されます。
  • 次に、状態定数と制御変数を引数としてイテレータ関数を呼び出します（注意：for 構造にとって状態定数は役に立たず、初期化時にその値を取得してイテレータ関数に渡すだけです）。
  • 次に、イテレータ関数が返した値を変数リストに代入します。
  • 次に、返された最初の値が nil であればループを終了し、そうでなければループ本体を実行します。
  • 次に、ステップ2に戻って再びイテレータ関数を呼び出します。

Lua では、イテレータを記述するために関数をよく使用します。この関数を呼び出すたびに集合の次の要素が返されます。Lua のイテレータには以下の2つのタイプがあります：

  • ステートレスイテレータ
  • マルチステートイテレータ

ステートレスイテレータ

ステートレスイテレータとは、いかなる状態も保持しないイテレータのことです。そのため、ループ内でステートレスイテレータを利用することで、クロージャを作成する余分なコストを回避できます。

各イテレーションにおいて、イテレータ関数は2つの変数（状態定数と制御変数）の値を引数として呼び出されます。ステートレスイテレータはこの2つの値だけを利用して次の要素を取得できます。

このようなステートレスイテレータの典型的で単純な例は ipairs です。これは配列のすべての要素を走査し、要素のインデックスは数値である必要があります。

以下の実例では、単純な関数を使用してイテレータを実装し、数値 n の平方を実現します：

実例

function square(iteratorMaxCount,currentNumber)
   if currentNumber<iteratorMaxCount
   then
      currentNumber = currentNumber+1
   return currentNumber, currentNumber*currentNumber
   end
end

for i,n in square,3,0
do
   print(i,n)
end

上記の実例の出力結果は次のとおりです：

1    1
2    4
3    9

イテレータの状態には、走査対象のテーブル（ループ中に変更されない状態定数）と現在のインデックス（制御変数）が含まれます。ipairs とイテレータ関数はどちらも非常に単純なので、Lua では次のように実装できます：

実例

function iter (a, i)
    i = i + 1
    local v = a[i]
    if v then
       return i, v
    end
end
 
function ipairs (a)
    return iter, a, 0
end

Lua が ipairs(a) を呼び出してループを開始すると、イテレータ関数 iter、状態定数 a、制御変数の初期値 0 の3つの値を取得します。次に Lua は iter(a,0) を呼び出して 1, a

マルチステートイテレータ

多くの場合、イテレータは単純な状態定数と制御変数ではなく、複数の状態情報を保存する必要があります。最も簡単な方法はクロージャを使用することです。もう1つの方法は、すべての状態情報を table 内にカプセル化し、その table をイテレータの状態定数として使用することです。この場合、すべての情報を table 内に格納できるため、イテレータ関数は通常2番目の引数を必要としません。

以下の実例では、独自のイテレータを作成しました：

実例

array = {"Google", "Runoob"}

function elementIterator (collection)
   local index = 0
   local count = #collection
   -- クロージャ関数
   return function ()
      index = index + 1
      if index <= count
      then
         -- イテレータの現在の要素を返す
         return collection[index]
      end
   end
end

for element in elementIterator(array)
do
   print(element)
end

上記の実例の出力結果は次のとおりです：

Google
Runoob

上記の実例では、elementIterator 内でクロージャ関数を使用しており、集合のサイズを計算して各要素を出力しています。

    pairs と ipairs の違い

    • pairs: table をイテレートし、テーブル内のすべての key を走査でき、nil を返すことができます
    • ipairs: 配列をイテレートし、nil を返すことはできません。nil に遭遇した場合は終了します

    コード例：

    local tab= { 
[1] = "a", 
[3] = "b", 
[4] = "c" 
} 
for i,v in pairs(tab) do        -- 输出 "a" ,"b", "c"  ,
    print( tab[i] ) 
end 

for i,v in ipairs(tab) do    -- 输出 "a" ,k=2时断开 
    print( tab[i] ) 
end

    pairs と ipairs の異同

    同じ点：どちらも集合（テーブル、配列）を走査できます

    異なる点：ipairs は値のみを走査し、インデックスの昇順で走査し、インデックスが途切れると走査を停止します。つまり、nil を返すことはできず、数値のみを返せます。nil に遭遇すると終了します。集合内に現れる最初の整数でない key までしか走査できません。

    pairs は集合のすべての要素を走査できます。つまり、pairs は集合内のすべての key を走査でき、イテレータ自体と走査するテーブル自体に加えて nil も返すことができます。

    例1：

    local tabFiles = {
        [1] = "test2",
        [6] = "test3",
        [4] = "test1"
    }

for k, v in ipairs(tabFiles) do    --输出"test2",在key等于2处断开
    print(k, v)
end

    例2：

    local tabFiles = {
    [2] = "test2",
    [6] = "test3",
    [4] = "test1"
}

for k, v in ipairs(tabFiles) do  --[[什么都没输出，为什么？因为控制变量初始值是按升序来遍历的，当key为1时，value为nil，此时便停止了遍历， 所有什么结果都没输出]]--
    print(k, v)
end

    例3：

    local tabFiles = {
    [2] = "test2",
    [6] = "test3",
    [4] = "test1"
}

for k, v in pairs(tabFiles) do  --输出2 test2, 6 test3, 4 test1
    print(k, v)
end

    例4：

    local tabFiles = {"alpha", "beta", [3] = "no", ["two"] = "yes"}  for i,v in ipairs(tabFiles ) do    --输出前三个   备注：因为第四个key不是整数
    print( tabFiles [i] )   
end   
  
for i,v in pairs(tabFiles ) do    --全部输出   
    print( tabFiles [i] )   
end

    function split(str,delimiter)
    local dLen = string.len(delimiter)
    local newDeli = ''
    for i=1,dLen,1 do
        newDeli = newDeli .. "["..string.sub(delimiter,i,i).."]"
    end

    local locaStart,locaEnd = string.find(str,newDeli)
    local arr = {}
    local n = 1
    while locaStart ~= nil
    do
        if locaStart>0 then
            arr[n] = string.sub(str,1,locaStart-1)
            n = n + 1
        end

        str = string.sub(str,locaEnd+1,string.len(str))
        locaStart,locaEnd = string.find(str,newDeli)
    end
    if str ~= nil then
        arr[n] = str
    end
    return arr
end

    ジェネリックfor内では3つの要素が維持されます：

    • 1. イテレータ関数自体、例：pairs(tab)
    • 2. イテレータ関数の状態定数、例：tab
    • 3. イテレータ関数の制御変数、例：idx

    要件：イテレータ関数を呼び出すたびに、関数の実行後に制御変数が一度変更されます。ただし、制御変数が条件を満たすと、イテレータ関数の再呼び出しが終了します。

    例：

    function iter (a, i)
    i = i + 1
    local v = a[i]
    if v then
       return i, v
    end
end

function ipairss (a)
    i=0;
   while(true) do
        k,v=iter(a,i)
        if k=nil then
           break;
       end
end

t={"asdf1","asdf2","asdf3","asdf4"}
for k,v in ipairss(t) do  //--内部维持iter,t,i三个要素,其中i隐含--这是我的理解
    print(k,v)
end
