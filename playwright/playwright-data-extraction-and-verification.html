Playwright データ抽出と検証

データ抽出と検証は自動化テストの鍵であり、主に次のものを含みますページデータの取得、アサーション検証、スクリーンショットと録画、機能が正しいかどうかを検証できるだけでなく、デバッグや回帰テストに役立ちます。

要素情報の取得

テストではページ情報を読み取って検証する必要がよくあり、Playwright は豊富な API を提供しています。

1. テキスト内容の取得

例

// 単一要素のテキストを取得
const text = await page.textContent('#welcome');
console.log(text);

// 複数要素のテキストを取得
const items = await page.$$eval('.list-item', els => els.map(e => e.textContent));
console.log(items);

2. 属性値の取得

const value = await page.getAttribute('#username', 'placeholder');
console.log(value); // "请输入用户名"

3. スタイル情報の取得

// 获取元素的 style 属性
const color = await page.$eval('#btn', el => getComputedStyle(el).color);
console.log(color);

4. 要素状態の確認

await page.isVisible('#dialog');   // 是否可见
await page.isHidden('#loading');   // 是否隐藏
await page.isEnabled('#submit');   // 是否可用
await page.isDisabled('#submit');  // 是否禁用
await page.isChecked('#agree');    // 复选框是否选中

アサーションと検証

Playwright は提供しています組み込みアサーションライブラリ（@playwright/test）、テストケースを書きやすくなります。

1. 組み込みアサーションメソッド

に@playwright/test中で、使用expectアサーションを行います。

例

import { test, expect } from '@playwright/test';

test('検証例', async ({ page }) => {
  await page.goto('https://example.com');

  // テキストアサーション
  await expect(page.locator('h1')).toHaveText('Example Domain');

  // 属性アサーション
  await expect(page.locator('a')).toHaveAttribute('href', 'https://www.iana.org/domains/example');

  // 可視性アサーション
  await expect(page.locator('h1')).toBeVisible();
});

2. テキスト内容の検証

await expect(page.locator('#message')).toHaveText('登录成功');
await expect(page.locator('#username')).toHaveValue('testuser');

3. 要素状態の検証

await expect(page.locator('#submit')).toBeEnabled();
await expect(page.locator('#agree')).toBeChecked();
await expect(page.locator('#loading')).toBeHidden();

4. ページタイトルとURLの検証

await expect(page).toHaveTitle(/Playwright/);
await expect(page).toHaveURL('https://playwright.dev/');

スクリーンショットと録画

スクリーンショットと録画は、デバッグ、失敗ケースの分析、回帰テストで非常に役立ちます。

1. ページスクリーンショット

await page.screenshot({ path: 'screenshot.png', fullPage: true });
  • path: 保存パス
  • fullPage: ページ全体をキャプチャするかどうか

2. 要素スクリーンショット

const element = page.locator('#logo');
await element.screenshot({ path: 'logo.png' });

3. ビデオ録画

作成時にcontext録画を有効にする：

const context = await browser.newContext({
  recordVideo: { dir: 'videos/' }
});
const page = await context.newPage();
await page.goto('https://example.com');
await context.close(); // 关闭后保存视频

4. スクリーンショット比較（スナップショットテスト）

Playwright はスナップショット比較をサポートしており、回帰テストでよく使用されます。

import { test, expect } from '@playwright/test';

test('页面快照测试', async ({ page }) => {
  await page.goto('https://playwright.dev');
  expect(await page.screenshot()).toMatchSnapshot('homepage.png');
});

スクリーンショットを基準画像とhomepage.png比較して、UIの変化を検出します。

実践例 —— ログイン検証とスクリーンショットスナップショット

このケースには次のものが含まれます：情報抽出 + アサーション検証 + ページスクリーンショット。

例

// login-test.spec.js
import { test, expect } from '@playwright/test';

test('ユーザーログインと結果検証', async ({ page }) => {
  // 1. ログインページを開く
  await page.goto('https://example.com/login');

  // 2. ユーザー名とパスワードを入力
  await page.fill('#username', 'testuser');
  await page.fill('#password', 'Password123');

  // 3. ログインをクリック
  await page.click('#submit');

  // 4. 遷移を待ってタイトルを確認
  await expect(page).toHaveTitle(/Dashboard/);

  // 5. ウェルカムテキストを検証
  await expect(page.locator('.welcome')).toHaveText('ようこそ、testuser');

  // 6. ボタンの状態を確認
  await expect(page.locator('#logout')).toBeVisible();
  await expect(page.locator('#logout')).toBeEnabled();

  // 7. ユーザーID属性を取得して検証
  const userId = await page.getAttribute('#user-profile', 'data-id');
  console.log('ユーザーID:', userId);
  expect(userId).not.toBeNull();

  // 8. ページスクリーンショット
  await page.screenshot({ path: 'login-success.png', fullPage: true });

  // 9. スナップショット比較（UI回帰テスト）
  expect(await page.screenshot()).toMatchSnapshot('dashboard.png');
});

このテストでは次のことを検証します：

  • ページタイトルとウェルカムテキストが正しいかどうか
  • 要素が可視かどうか / 使用可能かどうか
  • ユーザー情報属性が存在するかどうか
  • ページスクリーンショットとUIスナップショットの比較

よく使うAPI一覧表

以下はデータ抽出と検証関連APIの一覧表です。

メソッド 説明 例
page.textContent(selector) 要素のテキスト内容を取得 await page.textContent('#msg')
page.innerText(selector) レンダリング後のプレーンテキストを取得 await page.innerText('#msg')
page.innerHTML(selector) 要素のHTMLを取得 await page.innerHTML('#content')
page.getAttribute(selector, name) 属性値を取得 await page.getAttribute('#btn', 'class')
page.$eval(selector, fn) 要素上で関数を実行 await page.$eval('#logo', el => el.tagName)
page.$$eval(selector, fn) 一括で関数を実行 await page.$$eval('.item', els => els.length)
page.isVisible(selector) 可視かどうか await page.isVisible('#dialog')
page.isHidden(selector) 非表示かどうか await page.isHidden('#loading')
page.isEnabled(selector) 有効かどうか await page.isEnabled('#submit')
page.isDisabled(selector) 無効かどうか await page.isDisabled('#submit')
page.isChecked(selector) 選択されているかどうか await page.isChecked('#agree')
