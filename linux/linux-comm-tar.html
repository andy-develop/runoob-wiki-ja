Linux tar コマンド

Linux コマンド大全

Linux tar（英語の正式名称：tape archive）コマンドはファイルのバックアップに使用されます。

tar は Linux および Unix システムでファイルやディレクトリをアーカイブするための強力なコマンドラインツールです。

tar という名前は "tape archive"（テープアーカイブ）に由来し、当初はファイルをテープデバイスにまとめるために使用されていましたが、現在ではファイルシステム上でファイルをまとめたり圧縮したりするために広く使用されています。

tar は通常、複数のファイルやディレクトリを "tarball"（通常 .tar 拡張子）と呼ばれる単一のアーカイブファイルにまとめるために使用されます。

tar 自体はファイルを圧縮しませんが、gzip や bzip2 などの圧縮ツールと組み合わせて、圧縮されたアーカイブファイル（.tar.gz や .tar.bz2 など）を作成できます。

構文

tar [options] -f archive.tar [files...]
  • -f archive.tar：アーカイブファイルの名前を指定します。
  • [files...]：アーカイブするファイルとディレクトリ。

options パラメータ

基本操作オプション

  • -c：新しいアーカイブファイルを作成します。
  • -x：アーカイブファイルを解凍します。
  • -t：アーカイブファイルの内容を一覧表示します。
  • -r：既存のアーカイブファイルにファイルを追加します。
  • -u：アーカイブファイル内の既存ファイルよりも新しいファイルのみを追加します。
  • -d：アーカイブファイルとファイルシステムの間で同期していない差分を検出します。
  • -A：1つの.tarファイルを別の.tarファイルに追加します。

ファイルの選択と除外

  • -f <file>：アーカイブファイルの名前を指定します（オプションリストの最後に置く必要があります）。
  • -C <directory>：指定したディレクトリに切り替えて操作します。
  • --exclude=<pattern>：指定したパターンに一致するファイルを除外します。
  • --exclude-from=<file>：指定したファイルから除外するパターンを読み取ります。
  • --exclude-caches：ディレクトリ内のキャッシュファイルを除外します。
  • --exclude-backups：で終わる~バックアップファイルを除外します。
  • --exclude-vcs：バージョン管理システムが生成したファイルを除外します（例：.git、.svnなど）。

圧縮・解凍オプション

  • -z：を使用してgzipアーカイブファイルを圧縮します。
  • -j：を使用してbzip2アーカイブファイルを圧縮します。
  • -J：を使用してxzアーカイブファイルを圧縮します。
  • --lzip：を使用してlzipアーカイブファイルを圧縮します。
  • --lzma：を使用してlzmaアーカイブファイルを圧縮します。
  • --lzop：を使用してlzopアーカイブファイルを圧縮します。
  • --zstd：を使用してzstdアーカイブファイルを圧縮します。
  • -a：アーカイブファイルの拡張子に基づいて圧縮方式を自動選択します（例：.tar.gz、.tar.bz2など）。
  • -I <command>：指定した圧縮プログラムを使用して圧縮または解凍します。

出力および対話オプション

  • -v：詳細な操作過程を表示します（verbose）。
  • --progress：プログレスバーを表示します（-vと一緒に使用する場合）。
  • -w 或 --interactive：各操作の前にユーザーに確認を求めます。
  • --checkpoint：各ファイルの処理後にチェックポイントを表示します。
  • --checkpoint-action=<action>：チェックポイントで指定したアクションを実行します（例：echo、dotなど）。
  • --totals：操作終了後に処理された総バイト数を表示します。
  • --verbose：処理情報を詳細に表示します。
  • --quiet：出力情報をできるだけ少なくします。

ファイルおよび権限関連オプション

  • -p：ファイルの元の権限を保持します（解凍時）。
  • --same-owner：解凍したファイルを元の所有者に設定しようとします（スーパーユーザー権限が必要）。
  • --no-same-owner：ファイル所有者を設定しません。
  • --same-permissions：ファイルの元の権限を保持します（-pと同じ）。
  • --no-same-permissions：元の権限を保持せず、現在のユーザーの umask を使用して権限を設定します。
  • -m：解凍時にファイルの変更時間を復元せず、現在の時刻を使用します。

アーカイブ管理オプション

  • -k 或 --keep-old-files：解凍時に既存のファイルを保持し、上書きしません。
  • --overwrite：解凍時に既存のファイルを強制的に上書きします。
  • --remove-files：アーカイブが成功した後に元のファイルを削除します。
  • --delete：アーカイブファイルから指定したファイルを削除します（gnu tar）。
  • --keep-newer-files：解凍時にアーカイブ内のファイルよりも新しいファイルを保持します。
  • --listed-incremental=<file>：増分バックアップを作成するか、増分バックアップから復元します。

ファイルシステムおよびデバイスオプション

  • -L <N>：分割の対象はNバイトを超えるアーカイブファイルです（テープドライブ用）。
  • --tape-length=<number>：テープの長さを指定します（テープドライブ用）。
  • --multi-volume：マルチボリュームアーカイブファイルを作成または復元します。
  • -M：と--multi-volume一緒に使用して、マルチボリュームアーカイブファイルを処理します。
  • --use-compress-program=<prog>：指定した圧縮プログラムを使用します。

その他の便利なオプション

  • --transform=<expression>：アーカイブ内のファイル名を変更します。
  • --strip-components=<number>：解凍時に指定した数のパスコンポーネントを除去します。
  • --ignore-failed-read：読み取りエラーを無視して操作を続行します。
  • --occurrence=<number>：アーカイブ内でnumber番目に出現するファイルを選択します。
  • -S：スパースファイルを処理します（実際に使用されているブロックのみをアーカイブします）。
  • --no-recursion：ディレクトリに再帰的に入りません。
  • -h 或 --dereference：シンボリックリンク自体ではなく、シンボリックリンクが指すファイルをアーカイブします。

ヘルプおよびバージョン情報

  • --help：ヘルプ情報を表示します。
  • --version：のバージョン情報をtar表示します。

例

1、アーカイブファイルを作成：ファイル file1、file2、directory を archive.tar という名前のアーカイブファイルにまとめます。

tar -cvf archive.tar file1 file2 directory
  • -c: 新しいアーカイブファイルを作成
  • -v: 詳細な出力を表示し、アーカイブに追加されたファイルを一覧表示
  • -f: アーカイブファイルの名前を指定

2、アーカイブファイルを解凍：archive.tar という名前のアーカイブファイルを解凍し、含まれているファイルとディレクトリを復元します。

tar -xvf archive.tar
  • -x: アーカイブファイルを解凍
  • -v: 詳細な出力を表示し、解凍されたファイルを一覧表示
  • -f: 解凍するアーカイブファイルの名前を指定

3、アーカイブファイルを圧縮：directory という名前のディレクトリをアーカイブファイルにまとめ、gzip を使用して圧縮し、archive.tar.gz という名前のファイルを生成します。

tar -czvf archive.tar.gz directory
  • -c: 新しいアーカイブファイルを作成
  • -z: gzip を使用してアーカイブファイルを圧縮
  • -v: 詳細な出力を表示し、アーカイブに追加されたファイルを一覧表示
  • -f: アーカイブファイルの名前を指定

4、アーカイブファイルの内容を一覧表示：archive.tar という名前のアーカイブファイルに含まれるすべてのファイルとディレクトリを一覧表示します。

tar -tvf archive.tar
  • -t: アーカイブファイルの内容を一覧表示
  • -v: 詳細な出力を表示し、アーカイブファイル内のすべてのファイルとディレクトリを一覧表示
  • -f: 内容を一覧表示するアーカイブファイルの名前を指定

5、既存のアーカイブにファイルを追加：newfile という名前のファイルを、既存の archive.tar という名前のアーカイブファイルに追加します。

tar -rvf archive.tar newfile
  • -r: 既存のアーカイブにファイルを追加
  • -v: 詳細な出力を表示し、アーカイブに追加されたファイルを一覧表示
  • -f: 既存のアーカイブファイルの名前を指定

6、gzip で圧縮されたアーカイブファイルを作成：directory ディレクトリ内のすべてのファイルとサブディレクトリをまとめ、gzip を使用して圧縮し、archive.tar.gz という名前のアーカイブファイルを生成します。

tar -zcvf archive.tar.gz directory
  • -z: gzip を使用して圧縮することを示します。
  • -c: 新しいアーカイブファイルを作成することを示します。
  • -v: 詳細な出力を表示し、アーカイブに追加されたファイルを一覧表示することを示します。
  • -f archive.tar.gz: アーカイブファイルの名前をarchive.tar.gz。

7、gzip で圧縮されたアーカイブファイルを解凍：example.tar.gz ファイルを解凍し、含まれているファイルとディレクトリを現在のディレクトリに復元します。

tar -zxvf example.tar.gz
  • -z: gzip を使用してアーカイブファイルを解凍することを示します。
  • -x: 解凍操作を示します。
  • -v: 詳細な出力を表示し、解凍されたファイルを一覧表示することを示します。
  • -f example.tar.gz: 解凍するアーカイブファイルの名前をexample.tar.gz。

圧縮形式の指定

tar はさまざまな圧縮プログラムと組み合わせて、圧縮アーカイブファイルを作成および解凍できます。

z: gzip を使用して圧縮します。

tar -czvf archive.tar.gz directory
tar -xzvf archive.tar.gz

j: bzip2 を使用して圧縮します。

tar -cjvf archive.tar.bz2 directory
tar -xjvf archive.tar.bz2

J: xz を使用して圧縮します。

tar -cJvf archive.tar.xz directory
tar -xJvf archive.tar.xz

    ディレクトリ内の特定のファイルを除外して、圧縮します。

    コマンドの形式は次のとおりです：

    tar --exclude=目录名/* 或者 文件名 -zcvf 备份文件名.tgz 目录名

    具体的な例：

    # 创建一个名为 abc 的目录
mkdir abc

# 进入 abc 这个目录
cd abc

# 创建两个文件,文件名为1.txt 2.txt
touch 1.txt 2.txt

# 切换到 abc 的父目录
cd ..

# 将文件 abc 进行压缩时，排除1.txt，压缩后的文件名为 abc.tar
tar --exclude=abc/1.txt -zcvf abc.tgz abc

# 解压文件
tar -zxvf abc.tgz

# 删除压缩文件
rm abc.tgz

# 删除解压后的文件，并删除文件夹
rm -rf abc
