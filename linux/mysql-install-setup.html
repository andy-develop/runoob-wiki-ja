MySQL インストール設定

MySQL は最も人気のあるリレーショナルデータベース管理システムで、スウェーデンのMySQL AB社によって開発され、現在はOracle社に属しています。

MySQL が使用するSQL言語は、データベースにアクセスするための最も一般的な標準化言語です。

MySQL はその軽量さ、高速性、総所有コストの低さ、特にオープンソースという特徴により、一般的に中小規模のWebサイト開発ではMySQLがWebサイトのデータベースとして選ばれています。

MySQL インストール

本チュートリアルのシステムプラットフォーム: CentOS release 6.6 (Final) 64ビット。

一、コンパイルツールとライブラリファイルのインストール

yum -y install gcc gcc-c++ make autoconf libtool-ltdl-devel gd-devel freetype-devel libxml2-devel libjpeg-devel libpng-devel openssl-devel curl-devel bison patch unzip libmcrypt-devel libmhash-devel ncurses-devel sudo bzip2 flex libaio-devel

二、cmake コンパイラのインストール

cmake バージョン: cmake-3.1.1。

1、ダウンロードアドレス：http://www.cmake.org/files/v3.1/cmake-3.1.1.tar.gz 

$ wget http://www.cmake.org/files/v3.1/cmake-3.1.1.tar.gz

2、インストールパッケージを解凍

$ tar zxvf cmake-3.1.1.tar.gz

3、インストールパッケージのディレクトリに入る

$ cd cmake-3.1.1

4、コンパイルしてインストール

$ ./bootstrap
$ make && make install

三、MySQL のインストール

MySQLバージョン: mysql-5.6.15。

1、ダウンロードアドレス：http://dev.mysql.com/get/Downloads/MySQL-5.6/mysql-5.6.15.tar.gz 

$ wget http://dev.mysql.com/get/Downloads/MySQL-5.6/mysql-5.6.15.tar.gz

2、インストールパッケージを解凍

$ tar zxvf mysql-5.6.15.tar.gz

3、インストールパッケージのディレクトリに入る

$ cd mysql-5.6.15

4、コンパイルしてインストール

$ cmake -DCMAKE_INSTALL_PREFIX=/usr/local/webserver/mysql/ -DMYSQL_UNIX_ADDR=/tmp/mysql.sock -DDEFAULT_CHARSET=utf8 -DDEFAULT_COLLATION=utf8_general_ci -DWITH_EXTRA_CHARSETS=all -DWITH_MYISAM_STORAGE_ENGINE=1 -DWITH_INNOBASE_STORAGE_ENGINE=1 -DWITH_MEMORY_STORAGE_ENGINE=1 -DWITH_READLINE=1 -DWITH_INNODB_MEMCACHED=1 -DWITH_DEBUG=OFF -DWITH_ZLIB=bundled -DENABLED_LOCAL_INFILE=1 -DENABLED_PROFILING=ON -DMYSQL_MAINTAINER_MODE=OFF -DMYSQL_DATADIR=/usr/local/webserver/mysql/data -DMYSQL_TCP_PORT=3306
$ make && make install

5、mysqlバージョンを確認:

$ /usr/local/webserver/mysql/bin/mysql --version

ここまでで、mysqlのインストールは完了です。

MySQL 設定

1、mysqlの実行に使用するユーザーmysqlを作成：

$ /usr/sbin/groupadd mysql
$ /usr/sbin/useradd -g mysql mysql

2、binlogとデータベースの保存パスを作成し、mysqlユーザーに権限を付与

$ mkdir -p /usr/local/webserver/mysql/binlog /www/data_mysql
$ chown mysql.mysql /usr/local/webserver/mysql/binlog/ /www/data_mysql/

5、起動時自動実行スクリプトを作成

$ cd /usr/local/webserver/mysql/
$ cp support-files/mysql.server /etc/rc.d/init.d/mysqld 
$ chkconfig --add mysqld 
$ chkconfig --level 35 mysqld on

6、mysqlサーバーを起動

$ service mysqld start

7、MySQL に接続

$ /usr/local/webserver/mysql/bin/mysql -u root -p

MySQLユーザーパスワードの変更

mysqladmin -u用户名 -p旧密码 password 新密码

またはmysqlコマンドラインに入る

SET PASSWORD FOR '用户名'@'主机' = PASSWORD(‘密码');

新しいユーザーを作成して権限を付与:

grant all privileges on *.* to 用户名@'%' identified by '密码' with grant option;

その他のコマンド

  • 起動：service mysqld start
  • 停止：service mysqld stop
  • 再起動：service mysqld restart
  • 設定再読み込み：service mysqld reload
