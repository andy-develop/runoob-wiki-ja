Linux chfnコマンド

Linux コマンド大全

chfn（Change Finger Information）は、Linux においてユーザーの個人記述情報を変更するためのコマンドラインツールです。

chfnこのコマンドは、システム上のユーザーの finger 情報（氏名、オフィスの住所、オフィスの電話番号、自宅の電話番号など）を変更するために使います。

これらの情報は、fingerコマンドによって他のユーザーが閲覧でき、複数人で協力するサーバー環境でお互いの連絡先を把握するのに便利です。

初期のUnixシステムでは、fingerコマンドでユーザーの詳細情報を確認でき、chfnは、それらの情報を変更する入り口を提供しました。

とはいえ、finger現代のシステムでは使用頻度は低下しましたが、chfnが管理する GECOS フィールドは、今でも多くのプログラムでユーザーの表示名の由来として使用されています。

GECOS フィールドは、/etc/passwdファイル内の5番目のコロン区切りフィールドであり、ユーザーの記述情報を格納します。chfn本質的には、このフィールドを変更していることになります。

コマンド構文

chfnの基本的な構文は次のとおりです：

chfn [选项] [用户名]

ユーザー名を指定しない場合、デフォルトで現在ログインしているユーザーの情報を変更します。

一般ユーザーは自分の情報しか変更できませんが、rootユーザーは任意のユーザーの情報を変更できます。

オプション説明

chfnの一般的なオプションは次のとおりです：

オプション機能例
-f, --full-nameユーザーのフルネーム（Full Name）を設定しますchfn -f "Zhang San"
-r, --roomオフィスの部屋番号（Room Number）を設定しますchfn -r "A-301"
-w, --work-phone勤務先の電話番号（Work Phone）を設定しますchfn -w "010-12345678"
-h, --home-phone自宅の電話番号（Home Phone）を設定しますchfn -h "010-87654321"
-o, --otherその他の情報（Other、GECOS フィールドの残りの部分）を設定しますchfn -o "Developer"
-u, --helpヘルプ情報を表示しますchfn -u

詳細な使い方

対話形式で個人情報を変更

オプションなしで実行するとchfn、対話形式で項目ごとに入力を促します：

# 交互式修改当前用户信息
$ chfn
Password:
Changing the user information for runoob
Enter the new value, or press ENTER for the default
        Full Name: runoob
        Room Number []: A-301
        Work Phone []: 010-12345678
        Home Phone []: 010-87654321

各プロンプト行には現在の値が表示されます。変更したくない項目がある場合は、Enterキーを押してスキップするだけです。

システムは最初にパスワードの認証を要求し、ユーザー本人またはrootだけが変更できるようにします。

オプションを使って直接変更

スクリプトや一括操作では、オプションを使って対話形式のプロンプトをスキップし、新しい値を直接指定できます：

# 一次性设置用户全名和办公室号码
$ chfn -f "Li Si" -r "B-202" runoob

実行後、ユーザーrunoobのフルネームは "Li Si" に設定され、オフィス番号は "B-202" に設定されます。

変更後の情報を確認

変更が完了したら、fingerコマンドで更新された情報を確認できます：

# 使用 finger 查看用户信息
$ finger runoob
Login: runoob                    Name: Li Si
Directory: /home/runoob          Shell: /bin/bash
Office: B-202, 010-12345678      Home Phone: 010-87654321
Last login Tue May 19 10:30 (CST) on pts/0
No mail.
No Plan.

システムにインストールされていない場合は、finger、使用できますgetent passwd runoob直接確認する/etc/passwd内の GECOS フィールド。

/etc/passwd を直接読んで確認

GECOS フィールド内の各部分はカンマで区切られ、形式は次のとおりです：氏名、オフィス、勤務先電話、自宅電話、その他。

# 查看 /etc/passwd 中 runoob 用户的 GECOS 字段
$ grep runoob /etc/passwd
runoob:x:1001:1001:Li Si,B-202,010-12345678,010-87654321:/home/runoob:/bin/bash

GECOS フィールド（5番目のコロン区切りの内容）に、先ほど設定したすべての情報が完全に記録されていることがわかります。

特定の項目だけを変更

他の情報は変更せずに、特定の項目だけを変更できます：

# 只修改全名，其他信息保持不变
$ chfn -f "Wang Wu" runoob

# 验证修改结果
$ finger runoob | grep Name
Login: runoob                    Name: Wang Wu

chfn 設定ファイル

chfnの動作は、/etc/login.defs内の設定によって制御されます：

設定項目説明デフォルト値
CHFN_RESTRICT変更を許可するフィールドを制限し、文字の組み合わせを使用します：f（フルネーム）、r（部屋）、w（勤務先電話）、h（自宅電話）frwh

空の文字列に設定すると、どのユーザーも finger 情報を変更できません。

システム管理者はこの設定を調整することで、ユーザーが変更できるフィールドを制御できます。

注意事項

一般ユーザーは自分の finger 情報のみ変更でき、現在のパスワードを入力して認証する必要があります。root ユーザーは任意のユーザーの情報を変更でき、パスワード認証は不要です。

chfn変更した情報は、/etc/passwdに書き込まれます。誤った変更は、GECOS フィールドに依存する一部のプログラムで表示が異常になる可能性があります。変更前に関連行のバックアップを取ることをお勧めします。

システムで無効にされている場合、chfn機能（CHFN_RESTRICTが空の場合）、このコマンドを実行すると権限不足のメッセージが表示されます。

一部の現代的なLinuxディストリビューション（例：Ubuntu）では、デフォルトではインストールされていませんfingerパッケージは、手動でapt install fingerインストールする必要があります。

LDAP や NIS などの集中認証環境では、chfn正常に動作しない可能性があります。このような環境では、対応する管理ツールを使用する必要があります。
