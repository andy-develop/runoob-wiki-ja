Linux at コマンド

Linux コマンド大全

atは Linux システムにおける強力なタスクスケジューリングツールであり、指定した時刻に一度限りのタスクを実行できます。croncronのように周期的に実行するのではありません。

与 cronと比較して、at以下のシナリオに適しています：

  • 一度だけ実行する必要があるタスク
  • 将来の特定の時点で実行するタスク
  • 一時的なシステムメンテナンス操作

インストールと基本使用

インストールの確認

ほとんどの Linux ディストリビューションにはデフォルトでインストールされていますat。以下のコマンドで確認できます：

which at

インストールされていない場合は、パッケージマネージャーでインストールできます：

実例

# Debian/Ubuntu
sudo apt-get install at

# CentOS/RHEL
sudo yum install at

at サービスの起動

インストール後、atdデーモンを起動する必要があります：

実例

sudo systemctl start atd
sudo systemctl enable atd  # 自動起動を設定

コマンド構文とパラメータ

基本構文

at [选项] 时间

よく使うオプション

オプション 説明
-f 文件 標準入力ではなく指定されたファイルからコマンドを読み込みます
-m タスク完了後にユーザーへメールを送信します
-l 実行待ちのタスクを一覧表示します（atq）
-d 任务ID 指定されたタスクを削除します（atrm）
-v タスクが実行される予定の時刻を表示します

時間形式

atさまざまな時間形式をサポートしています：

  1. 絶対時刻

    • HH:MM（例：14:30）
    • YYYY-MM-DD（例：2023-12-25）
    • 組み合わせ形式HH:MM YYYY-MM-DD

  2. 相対時間

    • now + 数量 单位（例：now + 2 hours)
    • 単位は minutes、hours、days、weeks を使用できます

  3. 特別なキーワード

    • noon（正午12時）
    • midnight（真夜中）
    • teatime（午後4時）
    • tomorrow（明日の同じ時刻）

使用例

例1：基本使用

実例

$ at 15:30
warning: commands will be executed using /bin/sh
at> echo "Hello at command" > ~/at_test.txt
at>   # Ctrl+D を押して入力を終了します
job 1 at Tue Jul 18 15:30:00 2023

例2：ファイルからコマンドを読み込む

スクリプトファイルを作成しますmyscript.sh：

実例

#!/bin/bash
echo "This is a test" >> /tmp/at_log
date >> /tmp/at_log

その後、使用します：

at -f myscript.sh now + 5 minutes

例3：タスクの表示と削除

実例

$ atq  # または at -l
1       Tue Jul 18 15:30:00 2023 a username

$ atrm 1  # または at -d 1

高度な使い方

環境変数の設定

実例

$ at 16:00
at> export MY_VAR="test"
at> echo $MY_VAR > ~/env_test.txt
at>

複雑なコマンドの実行

実例

$ at 17:00 today
at> cd /var/log && grep "error" syslog > ~/error_log.txt
at>

here document の使用

実例

at 18:00 << 'EOF'
#!/bin/bash
echo "Starting backup..."
tar -czf ~/backup-$(date +%F).tar.gz ~/Documents
EOF

注意事項

  1. 権限制御

    • /etc/at.allow 和 /etc/at.denyファイルがユーザーのアクセス権限を制御します
    • もしat.allow存在する場合、リストされたユーザーのみが使用できますat
    • もしat.allow存在しない場合は、at.deny を確認しますat.denyそこにリストされたユーザーは禁止されます

  2. 出力処理

    • デフォルトでは、コマンドの出力はメールでユーザーに送信されます
    • 使用します-m-m オプションを指定すると、出力がなくてもメールが強制送信されます

  3. 環境の違い

    • at実行時の環境は対話型シェルとは異なる場合があります
    • 重要な環境変数はコマンド内で明示的に設定する必要があります

  4. エラー処理

    • 確認atdサービスが実行されているかどうか：systemctl status atd
    • システムログを確認してエラー情報を取得します：journalctl -u atd

実践演習

  1. 5分後に現在の日付と時刻を~/time_log.txtファイルに追記するタスクを作成します
  2. スクリプトを作成して/etcディレクトリをバックアップし、at を使用してat明日の午前2時に実行するようにスケジュールします
  3. 現在実行待ちのすべてのatタスクを一覧表示し、そのうちの1つを削除します

まとめ

atコマンドは、Linux システムで一度限りのタスクを管理するための強力なツールです。この記事を通じて、以下の内容を習得できたはずです：

  • atの基本概念とインストール方法
  • さまざまな時間形式の指定方法
  • タスクの作成、表示、削除の操作
  • 高度な使い方と注意事項

定期的に実行する必要があるタスクには、cron の使用を検討できますcron。ただし、一度限りのタスクには、atat が間違いなく最適な選択肢です。
