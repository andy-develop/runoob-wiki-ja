Linux xargs コマンド

Linux コマンド大全

xargs（英語のフルスペル： eXtended ARGuments）は、コマンドに引数を渡すためのフィルターであり、複数のコマンドを組み合わせるためのツールでもあります。

xargs は、パイプまたは標準入力（stdin）データをコマンドライン引数に変換でき、ファイルの出力からデータを読み取ることもできます。

xargs は、単一行または複数行のテキスト入力を他の形式に変換することもできます。例えば、複数行を単一行に、単一行を複数行に変換できます。

xargs のデフォルトのコマンドは echo です。つまり、パイプを介して xargs に渡される入力には改行と空白が含まれますが、xargs の処理により、改行と空白はスペースに置き換えられます。

xargs は強力なコマンドで、あるコマンドの出力をキャプチャして、別のコマンドに渡すことができます。

このコマンドが使われるのは、多くのコマンドが | パイプによる引数の受け渡しをサポートしておらず、日常業務でその必要があるためです。そこで xargs コマンドが生まれました。例：

find /sbin -perm +700 |ls -l       #这个命令是错误的
find /sbin -perm +700 |xargs ls -l   #这样才是正确的

xargs は通常、パイプと一緒に使用されます。

コマンド形式：

somecommand |xargs -item  command

パラメータ：

  • -a file ファイルから stdin として読み込む
  • -e flag 、注意として -E の場合もあります。flag はスペースで区切られたフラグである必要があり、xargs が flag を含むと分析した時点で停止します。
  • -p 引数を実行するたびにユーザーに確認を求めます。
  • -n num 後ろに回数を付けます。コマンド実行時に一度に使用する引数の数を示します。デフォルトはすべて使用します。
  • -t コマンドを先に表示してから実行することを示します。
  • -i または -I は、Linux のサポートに依存します。xargs の各項目名を、通常は1行ごとに {} に代入し、{} で置き換えることができます。
  • -r no-run-if-empty xargs の入力が空の場合、xargs を停止し、実行する必要はありません。
  • -s num コマンドラインの最大文字数。xargs の後ろのコマンドの最大コマンドライン文字数を指します。
  • -L num 標準入力から一度に num 行を読み取り、command コマンドに渡します。
  • -l -L と同じ。
  • -d delim 区切り文字。デフォルトの xargs 区切り文字は改行で、引数の区切り文字はスペースです。ここで変更するのは xargs の区切り文字です。
  • -x exit の意味で、主に -s と組み合わせて使用します。
  • -P 最大プロセス数を変更します。デフォルトは 1 で、0 の場合は as many as it can（可能な限り多く）です。この例は思いつきませんでしたが、普段は使うことはないでしょう。

例

xargs は置換ツールとして使用され、入力データを読み取って再フォーマットし出力します。

複数行のテキストデータを含むテストファイルを定義します：

# cat test.txt

a b c d e f g
h i j k l m n
o p q
r s t
u v w x y z

複数行入力・単一行出力：

# cat test.txt | xargs
a b c d e f g h i j k l m n o p q r s t u v w x y z

-n オプションで複数行出力：

# cat test.txt | xargs -n3

a b c
d e f
g h i
j k l
m n o
p q r
s t u
v w x
y z

-d オプションで区切り文字をカスタマイズできます：

# echo "nameXnameXnameXname" | xargs -dX

name name name name

-n オプションと組み合わせて使用：

# echo "nameXnameXnameXname" | xargs -dX -n2

name name
name name

stdin を読み取り、フォーマットされた引数をコマンドに渡します

コマンドが sk.sh で、引数を保存するファイルが arg.txt であると仮定します：

#!/bin/bash
#sk.sh命令内容，打印出所有参数。

echo $*

arg.txt ファイルの内容：

# cat arg.txt

aaa
bbb
ccc

xargs のオプションの1つである -I は、-I を使用して置換文字列 {} を指定します。この文字列は xargs の展開時に置き換えられます。-I を xargs と組み合わせて使用すると、各引数コマンドが1回ずつ実行されます：

# cat arg.txt | xargs -I {} ./sk.sh -p {} -l

-p aaa -l
-p bbb -l
-p ccc -l

すべての画像ファイルを /data/images ディレクトリにコピーします：

ls *.jpg | xargs -n1 -I {} cp {} /data/images

xargs と find を組み合わせて使用

rm でファイルを削除しすぎると、エラーメッセージが表示される可能性があります：/bin/rm Argument list too long.xargs を使用してこの問題を回避します：

find . -type f -name "*.log" -print0 | xargs -0 rm -f

xargs -0 は \0 を区切り文字として使用します。

ソースコードディレクトリ内のすべての php ファイルの行数を集計します：

find . -type f -name "*.php" -print0 | xargs -0 wc -l

すべての jpg ファイルを検索し、それらを圧縮します：

find . -type f -name "*.jpg" -print | xargs tar -czvf images.tar.gz

xargs の他の応用

ダウンロードしたい URL が多数含まれるファイルがある場合、xargs を使用してすべてのリンクをダウンロードできます：

# cat url-list.txt | xargs wget -c
