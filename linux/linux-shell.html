Shell チュートリアル

Shell は C 言語で書かれたプログラムであり、ユーザーが Linux を利用するための橋渡しです。Shell はコマンド言語であると同時に、プログラミング言語でもあります。

Shell とはアプリケーションの一種であり、このアプリケーションはインターフェースを提供し、ユーザーはそのインターフェースを通じてオペレーティングシステムのカーネルサービスにアクセスします。

Ken Thompson の sh は最初の Unix Shell であり、Windows Explorer は典型的なグラフィカルインターフェースの Shell です。

Shell オンラインツール

Shell スクリプト

Shell スクリプト（shell script）とは、shell のために書かれたスクリプトプログラムです。

業界で言う shell は通常 shell スクリプトを指しますが、読者の皆さんは shell と shell script が異なる概念であることを知っておいてください。

習慣の都合上、簡潔にするため、本文中の「shellプログラミング」はすべて shell スクリプトプログラミングを指し、shell 自体の開発を指すものではありません。

Shell 環境

Shell プログラミングは JavaScript、php プログラミングと同じように、コードを書けるテキストエディタと、解釈実行できるスクリプトインタプリタがあれば十分です。

Linux の Shell は種類が多く、一般的なものは次のとおりです：

  • Bourne Shell（/usr/bin/sh または /bin/sh）
  • Bourne Again Shell（/bin/bash）
  • C Shell（/usr/bin/csh）
  • K Shell（/usr/bin/ksh）
  • Shell for Root（/sbin/sh）
  • ……

このチュートリアルで扱うのは Bash、つまり Bourne Again Shell です。使いやすく無料であるため、Bash は日常業務で広く使用されています。また、Bash はほとんどの Linux システムでデフォルトの Shell でもあります。

一般に、人々は Bourne Shell と Bourne Again Shell を区別しないため、例えば#!/bin/sh、それは同様に次のように変更することもできます#!/bin/bash。

#!その後のパスで指定されたプログラムが、このスクリプトファイルを解釈する Shell プログラムであることをシステムに伝えます。

最初のShellスクリプト

テキストエディタを開き（vi/vim コマンドでファイルを作成できます）、新しいファイル test.sh を作成します。拡張子は sh（sh は shell を表します）です。拡張子はスクリプトの実行に影響しないので、名前を見て意味が分かればよいです。もし php で shell スクリプトを書くなら、拡張子は php にすればよいです。

コードを入力します。最初の行は通常次のようになります：

実例

#!/bin/bash
echo "Hello World !"

実例を実行 »

#!これは取り決めのマークであり、このスクリプトがどのインタプリタで実行される必要があるか、つまりどの Shell を使用するかをシステムに伝えます。

echo コマンドはウィンドウにテキストを出力するために使われます。

Shell スクリプトを実行するには2つの方法があります：

1. 実行可能プログラムとして

上記のコードを test.sh として保存し、対応するディレクトリに cd します：

chmod +x ./test.sh  #使脚本具有执行权限
./test.sh  #执行脚本

注意してください。必ず次のように書きます./test.sh、ではなくtest.sh他のバイナリプログラムを実行する場合も同様で、test.sh と直接書くと、Linux システムは PATH の中に test.sh という名前のファイルがないか探します。しかし、/bin, /sbin, /usr/bin, /usr/sbin などだけが PATH にあり、現在のディレクトリは通常 PATH に含まれていないため、test.sh と書くとコマンドが見つかりません。./test.sh と書いて、現在のディレクトリで探すようにシステムに伝える必要があります。

2. インタプリタの引数として

この実行方法は、インタプリタを直接実行し、その引数が shell スクリプトのファイル名です。例：

/bin/sh test.sh
/bin/php test.php

この方法で実行されるスクリプトは、最初の行にインタプリタ情報を指定する必要はなく、書いても意味がありません。

    sh/bash/csh/Tcsh/ksh/pdksh などの shell の違い

    • sh（正式名称 Bourne Shell）: UNIX で最初に使われた shell であり、あらゆる UNIX で使用できます。
      Bourne Shell は shell プログラミングの面では非常に優れていますが、ユーザーとの対話処理に関しては他のいくつかの shell ほどではありません。
    • bash（正式名称 Bourne Again Shell）: Linux OS のデフォルトであり、Bourne Shell の拡張です。 Bourne Shell と完全に互換性があり、Bourne Shell を基盤に多くの機能が追加されています。コマンド補完、コマンド編集、コマンド履歴などの機能を提供できます。また、C Shell と Korn Shell の多くの長所を取り入れており、柔軟で強力な編集インターフェースを持ち、同時に非常にユーザーフレンドリーなインターフェースを備えています。
    • csh（正式名称 C Shell）: Bourne Shell よりも適した変種 Shell であり、その構文は C 言語に非常に似ています。
    • Tcsh: Linux が提供する C Shell の拡張版です。
      Tcsh にはコマンドライン編集、プログラマブル単語補完、スペル修正、履歴コマンド置換、ジョブ制御、C 言語に似た構文が含まれます。Bash Shell のプロンプトと互換性があるだけでなく、Bash Shell よりも多くのプロンプトパラメータを提供します。
    • ksh（正式名称 Korn Shell）: C Shell と Bourne Shell の長所を兼ね備え、Bourne Shell と完全に互換性があります。
    • pdksh: Linux システムが提供する ksh の拡張です。
      pdksh はジョブ制御をサポートし、コマンドライン上でプログラムを一時停止、バックグラウンド実行、再開、終了することができます。

    まず、スクリプト言語とは何でしょうか？

    スクリプト言語とは、脚本のようにコンピュータにあることを行わせるための言語です。

    例えば、コンピュータにあるファイルをコピーする操作を実行させたい場合、次のようにします：cp ~/Desktop/*.txt ~/text

    テキストエディタに上記のコードを書き込んでファイルを保存し、そのテキストファイルを実行することで上記のコードを実行できます。上記のコードを繰り返し手動入力する必要はありません。

    次の文はインターネットで見かけたものです：

    つまりスクリプトとは、コンピュータに一連の作業を自動で完了させるための短いプログラムであり、テキストエディタで修正でき、コンパイルは不要で、通常はインタプリタで実行されます。

    ubuntu（linux）で source、sh、bash、./ を使ってスクリプトを実行する違いは何ですか？

    1. source コマンドの使い方：

    source FileName

    機能: 現在の bash 環境で FileName 内のコマンドを読み込んで実行します。この filename ファイルには「実行権限」がなくても構いません。

    注：このコマンドは通常、コマンド.で置き換えられます。

    2. sh、bash コマンドの使い方：

    sh FileName
或
bash FileName

    機能: 子 shell を開いて FileName 内のコマンドを読み込んで実行します。この filename ファイルには「実行権限」がなくても構いません。

    注：shell スクリプトを実行すると、別のコマンドインタプリタが起動します。

    3. ./ の使い方：

    ./FileName

    機能: 子 shell を開いて FileName 内のコマンドを読み込んで実行します。この filename ファイルには「実行権限」が必要です。

    注：shell スクリプトを実行すると、別のコマンドインタープリタが起動されます。
