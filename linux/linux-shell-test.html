Shell test コマンド

testこのコマンドは Shell 組み込みの条件判定ツールであり、式を評価してブール値（真/偽）を返します。これは通常if文と組み合わせて使用され、Shell スクリプトで論理制御を実装する基礎です。

Shell の test コマンドは、ある条件が成立するかどうかを確認するために使用され、数値・文字・ファイルの3つの側面についてテストできます。

構文形式

test EXPRESSION
# 或
[ EXPRESSION ]  # 注意方括号内必须有空格

ファイルテスト操作

testこのコマンドはファイル属性の確認に最もよく使われます。以下はよく使われるファイルテストオプションです：

演算子 説明 例
-e ファイルが存在するか [ -e file.txt ]
-f 通常ファイルである [ -f /path/to/file ]
-d ディレクトリである [ -d /path/to/dir ]
-r 読み取り可能 [ -r file.txt ]
-w 書き込み可能 [ -w file.txt ]
-x 実行可能 [ -x script.sh ]
-s ファイルサイズが0より大きい [ -s logfile ]
-L シンボリックリンクである [ -L symlink ]

サンプルスクリプト：

例

#!/bin/bash

file="/etc/passwd"

if [ -e "$file" ]; then
    echo "$file存在します"
    if [ -r "$file" ]; then
        echo "かつ読み取り可能です"
    fi
else
    echo "$file存在しません"
fi

出力結果は次のとおりです：

/etc/passwd 存在
并且可读

文字列比較

testさまざまな文字列比較方法が用意されています：

演算子 説明 例
-z STRING 文字列が空である [ -z "$var" ]
-n STRING 文字列が空でない [ -n "$var" ]
STRING1 = STRING2 文字列が等しい [ "$var1" = "$var2" ]
STRING1 != STRING2 文字列が等しくない [ "$var1" != "$var2" ]

重要な注意：文字列変数は常にダブルクォートで囲む必要があります。空の変数による構文エラーを防ぎます。

例：

例

#!/bin/bash

read -p "ユーザー名を入力: " username

if [ -z "$username" ]; then
    echo "エラー：ユーザー名は空にできません"
    exit 1
elif [ "$username" = "root" ]; then
    echo "警告：rootアカウントの使用は推奨されません"
else
    echo "ようこそ、$username"
fi

実行後、ターミナルで runoob と入力すると、出力結果は次のようになります：

输入用户名: runoob
欢迎, runoob

数値比較

数値比較には、test異なる演算子を使用します：

演算子 説明 例
-eq 等しい [ "$a" -eq "$b" ]
-ne 等しくない [ "$a" -ne "$b" ]
-gt より大きい [ "$a" -gt "$b" ]
-ge 以上 [ "$a" -ge "$b" ]
-lt より小さい [ "$a" -lt "$b" ]
-le 以下 [ "$a" -le "$b" ]

例：

例

#!/bin/bash

read -p "年齢を入力: " age

if [ "$age" -lt 0 ]; then
    echo "年齢は負の数にできません"
elif [ "$age" -lt 18 ]; then
    echo "未成年"
elif [ "$age" -ge 18 ] && [ "$age" -lt 60 ]; then
    echo "成人"
else
    echo "高齢者"
fi

実行後、ターミナルで 12 と入力すると、出力結果は次のようになります：

输入年龄: 12
未成年人

論理演算子

test論理結合をサポートします：

演算子 説明 例
! 論理否定 [ ! -f "$file" ]
-a 論理積 [ "$a" -eq 1 -a "$b" -eq 2 ]
-o 論理和 [ "$a" -eq 1 -o "$b" -eq 2 ]

現代の推奨記法：使用&& 和 ||の代わりに-a 和 -o、POSIX 標準により適合します：

例

[ "$a" -eq 1 ] && [ "$b" -eq 2 ]  # かつ
[ "$a" -eq 1 ] || [ "$b" -eq 2 ]  # または

高度な使い方：[[ ]] と (( ))

Bash はより強力なテスト構文を提供します：

二重括弧 [[ ]]

  • パターンマッチングをサポート：[[ "$var" == *.txt ]]
  • 正規表現をサポート：[[ "$var" =~ ^[0-9]+$ ]]
  • より安全な文字列処理

算術比較 (( ))

  • 数値比較専用に設計されています：(( a > b ))
  • より複雑な算術式をサポート

例：

例

if [[ "$file" == *.log ]]; then
    echo "これはログファイルです"
fi

if (( $count > 10 )); then
    echo "数量が10を超えています"
fi

実際の応用例

1. サービスが実行中かどうかを確認する

例

#!/bin/bash

service="nginx"

if systemctl is-active --quiet "$service"; then
    echo "$service実行中です"
else
    echo "$service実行されていません"
    # サービスを起動するコマンドを追加できます
fi

2. バックアップファイルの確認

例

#!/bin/bash

backup_file="/backups/data_$(date +%Y%m%d).tar.gz"

if [ ! -f "$backup_file" ]; then
    echo "エラー：バックアップファイル$backup_fileが存在しません"
    exit 1
elif [ ! -s "$backup_file" ]; then
    echo "警告：バックアップファイルが空です"
else
    echo "バックアップの検証に成功しました"
fi

よくあるエラーとデバッグのコツ

  1. スペースの欠落：[ "$a"="$b" ]は誤りで、正しくは[ "$a" = "$b" ]
  2. 引用されていない変数：[ -f $file ]は次のようにすべき[ -f "$file" ]
  3. 文字列比較と数値比較の混同：使用=文字列を比較し、-eq数値を比較する

デバッグのコツ：スクリプトの先頭に追加set -xを追加してデバッグモードを有効にするか、次を使用echoテスト式を出力します：

例

echo "テスト式: [$a -eq $b ]"
[ "$a" -eq "$b" ] && echo "成立" || echo "不成立"

    フォルダが存在しない場合は作成する

    if [ ! -d "/data/" ];then
  mkdir /data
  else
  echo "文件夹已经存在"
fi

    ファイルが存在する場合は削除する

    if [ ! -f "/data/filename" ];then
  echo "文件不存在"
  else
  rm -f /data/filename
fi

    フォルダが存在するか確認する

    if [ -d "/data/" ];then
  echo "文件夹存在"
  else
  echo "文件夹不存在"
fi

    ファイルが存在するか確認する

    if [ -f "/data/filename" ];then
  echo "文件存在"
  else
  echo "文件不存在"
fi

    ファイル比較演算子

    -e 判断对象是否存在
-d 判断对象是否存在，并且为目录
-f 判断对象是否存在，并且为常规文件
-L 判断对象是否存在，并且为符号链接
-h 判断对象是否存在，并且为软链接
-s 判断对象是否存在，并且长度不为0
-r 判断对象是否存在，并且可读
-w 判断对象是否存在，并且可写
-x 判断对象是否存在，并且可执行
-O 判断对象是否存在，并且属于当前用户
-G 判断对象是否存在，并且属于当前用户组
-nt 判断file1是否比file2新  [ "/data/file1" -nt "/data/file2" ]

    自分が何をしているのかはっきり理解しているのでなければ、そうでない場合は、”Shell testコマンド“でシングルクォートを使うのは避けてください——それを使うと気づきにくいエラーを引き起こす可能性があり、特にShell初心者にとっては危険です。

    次の例を使って、その理由をさらに詳しく説明します：

    #! /bin/bash
# 模拟终端某一指令输出为空时用 test -z 配合单引号进行判断的效果 
wrong=``
#注意：反引号内没有任何字符
echo $wrong
if test -z '$wrong'; then
   echo "The result is empty."
else
   echo "The result is not empty."
fi

    実行してみてください：

    $ ./script-name.sh
The result is not empty.

    実行後の結果は、私たちが期待していたものとちょうど逆です。これはシングルクォートが内部の内容をそのまま出力するためです。

    このとき、コマンドの出力がどうであれ非空でなくても、最終的にはと判定され非空になります。

    そして、もしこのときエラーの根源がシングルクォートであることに気づかなければ、私を信じてください：あなたはスクリプト出力のスペースを何とかして取り除こうとするでしょう——しかしスペースはそもそも取り除くこともできず、実際の役割もありません。
