Linux scp コマンド

Linux コマンド大全

Linux scp コマンドは、Linux 間でファイルやディレクトリをコピーするために使用されます。

scp は secure copy の略で、scp は Linux システム上で ssh ログインに基づいて安全なリモートファイルコピーを行うコマンドです。

scp は暗号化されており、rcprcp は暗号化されておらず、scp は rcp の強化版です。

Linux システムでは、scpコマンドは非常に実用的なツールですscp「secure copy」の略であり、SSH（Secure Shell）プロトコルに基づいて、データ転送の安全性を確保します。

構文

scp [-1246BCpqrv] [-c cipher] [-F ssh_config] [-i identity_file]
[-l limit] [-o ssh_option] [-P port] [-S program]
[[user@]host1:]file1 [...] [[user@]host2:]file2

簡易的な書き方:

scp [选项] [源文件] [目标路径]
  • [オプション]：指定するために使用しますscpコマンドの動作。例えば、再帰コピー、ファイル属性の保持などです。
  • [ソースファイル]：コピーするファイルまたはディレクトリのパス。
  • [宛先パス]：ファイルまたはディレクトリのコピー先のパス。

よく使うオプション:

以下はよく使うscpコマンドオプションです：

  • -r：ディレクトリ全体を再帰的にコピーします。
  • -P：リモートホストの SSH ポート番号を指定します（デフォルトは 22）。
  • -p：ファイルの変更時刻、アクセス時刻、権限を保持します。
  • -v：詳細なデバッグ情報を表示し、問題の調査に役立ちます。
  • -C：圧縮を有効にし、転送速度を向上させることができます。

完全なオプションの説明：

  • -1： scp コマンドにプロトコル ssh1 を強制的に使用させます
  • -2： scp コマンドにプロトコル ssh2 を強制的に使用させます
  • -4： scp コマンドに IPv4 アドレッシングのみを使用させます
  • -6： scp コマンドに IPv6 アドレッシングのみを使用させます
  • -B： バッチモードを使用します（転送中にパスワードやパスフレーズを尋ねません）
  • -C： 圧縮を許可します。（-C フラグを ssh に渡して圧縮機能を有効にします）
  • -p：元のファイルの変更時刻、アクセス時刻、アクセス権限を保持します。
  • -q： 転送の進行状況バーを表示しません。
  • -r： ディレクトリ全体を再帰的にコピーします。
  • -v：詳細モードで出力を表示します。scp と ssh(1) はプロセス全体のデバッグ情報を表示します。これらの情報は、接続、認証、設定の問題をデバッグするために使用されます。
  • -c cipher： cipher でデータ転送を暗号化します。このオプションは ssh に直接渡されます。
  • -F ssh_config： 代替の ssh 設定ファイルを指定します。このパラメータは ssh に直接渡されます。
  • -i identity_file： 転送時に使用する鍵ファイルを指定されたファイルから読み取ります。このパラメータは ssh に直接渡されます。
  • -l limit： ユーザーが使用できる帯域幅を制限します。単位は Kbit/s です。
  • -o ssh_option： ssh_config(5) のパラメータ渡し方式を使用することに慣れている場合は、
  • -P port：注意することは大文字の P です。port はデータ転送に使用するポート番号を指定します。
  • -S program： 暗号化転送時に使用するプログラムを指定します。このプログラムは ssh(1) のオプションを理解できる必要があります。

ローカルからリモートホストへファイルをコピーする

あなたがファイルexample.txt、それをリモートホストの/home/user/ディレクトリにコピーしたい場合、以下のコマンドを使用できます：

scp example.txt user@remote_host:/home/user/

このコマンドでは：

  • example.txtはローカルファイルです。
  • user@remote_hostはリモートホストのユーザー名とアドレスです。
  • /home/user/はリモートホスト上のターゲットパスです。

リモートホストからローカルへファイルをコピーする

リモートホスト上のファイルexample.txtをローカルのカレントディレクトリにコピーしたい場合、以下のコマンドを使用できます：

scp user@remote_host:/home/user/example.txt .

このコマンドでは：

  • user@remote_host:/home/user/example.txtはリモートホスト上のファイルパスです。
  • .はカレントディレクトリを表します。

ディレクトリを再帰的にコピーする

ディレクトリ全体とその内容をコピーしたい場合は、-rオプションを使用できます。例えば、ローカルのmy_directoryディレクトリをリモートホストの/home/user/ディレクトリにコピーします：

scp -r my_directory user@remote_host:/home/user/

ポート番号を指定する

リモートホストの SSH サービスがデフォルト以外のポート（例：2222）で動作している場合、-Pオプションを使用してポート番号を指定できます：

scp -P 2222 example.txt user@remote_host:/home/user/

ファイル属性を保持する

ファイルをコピーする際に、ファイルの変更時刻、アクセス時刻、権限を保持したい場合は、-pオプションを使用します：

scp -p example.txt user@remote_host:/home/user/

圧縮を有効にする

大きなファイルやネットワークが遅い場合は、-Cオプションで圧縮を有効にし、転送速度を速めることができます：

scp -C large_file.zip user@remote_host:/home/user/

適用例

1. ローカルからリモートへコピー

コマンド形式：

scp local_file remote_username@remote_ip:remote_folder 
或者 
scp local_file remote_username@remote_ip:remote_file 
或者 
scp local_file remote_ip:remote_folder 
或者 
scp local_file remote_ip:remote_file

  • 1 番目と 2 番目はユーザー名を指定しており、コマンド実行後にパスワードを入力する必要があります。1 番目はリモートのディレクトリのみを指定しているためファイル名は変わりません。2 番目はファイル名を指定しています。
  • 3 番目と 4 番目はユーザー名を指定しておらず、コマンド実行後にユーザー名とパスワードを入力する必要があります。3 番目はリモートのディレクトリのみを指定しているためファイル名は変わりません。4 番目はファイル名を指定しています。

適用例：

scp /home/space/music/1.mp3 root@www.runoob.com:/home/root/others/music 
scp /home/space/music/1.mp3 root@www.runoob.com:/home/root/others/music/001.mp3 
scp /home/space/music/1.mp3 www.runoob.com:/home/root/others/music 
scp /home/space/music/1.mp3 www.runoob.com:/home/root/others/music/001.mp3

ディレクトリコピーのコマンド形式：

scp -r local_folder remote_username@remote_ip:remote_folder 
或者 
scp -r local_folder remote_ip:remote_folder
  • 1 番目はユーザー名を指定しており、コマンド実行後にパスワードを入力する必要があります。
  • 2 番目はユーザー名を指定しておらず、コマンド実行後にユーザー名とパスワードを入力する必要があります。

適用例：

scp -r /home/space/music/ root@www.runoob.com:/home/root/others/ 
scp -r /home/space/music/ www.runoob.com:/home/root/others/

上記のコマンドは、ローカルの music ディレクトリをリモートの others ディレクトリにコピーします。

2. リモートからローカルへコピー

リモートからローカルへのコピーは、ローカルからリモートへのコピーコマンドの最後の 2 つのパラメータの順序を入れ替えるだけです。以下の例のとおりです。

適用例：

scp root@www.runoob.com:/home/root/others/music /home/space/music/1.mp3 
scp -r www.runoob.com:/home/root/others/ /home/space/music/

説明

1. リモートサーバーのファイアウォールが scp コマンド用に特定のポートを設定している場合、-P パラメータを使用してコマンドのポート番号を設定する必要があります。コマンド形式は以下のとおりです：

#scp 命令使用端口号 4588
scp -P 4588 remote@www.runoob.com:/usr/local/sin.sh /home/administrator

2. scp コマンドを使用する際は、使用するユーザーがリモートサーバーの該当ファイルを読み取る権限を持っていることを確認してください。そうでない場合、scp コマンドは機能しません。

注意事項

  • ソースファイルとターゲットパスにアクセスするための十分な権限があることを確認してください。
  • リモートホストの SSH サービスが実行されていないか、設定が正しくない場合、scpコマンドは正常に動作しません。
  • 使用-vオプションは、接続の問題をデバッグするのに役立ちます。
