Linux snap コマンド

Linux コマンド大全

snap は Canonical 社が開発したソフトウェアのパッケージングおよびデプロイシステムで、Linux ディストリビューション向けに提供されています。アプリケーションを安全かつ確実にインストール、更新、管理する方法を提供します。

snap の主な特徴

  1. コンテナ化されたアプリケーション：各 snap アプリケーションは独自のサンドボックス環境で実行されます
  2. 自動更新：バックグラウンドでのアプリケーションの自動更新をサポートします
  3. ディストリビューション間の互換性：同じ snap パッケージが複数の Linux ディストリビューションで動作します
  4. 依存関係の内包：すべての依存関係が snap 内にパッケージ化され、システムの依存関係の競合を回避します

snap と従来のパッケージ管理の違い

特性 snap 従来のパッケージ管理（apt/yum）
依存関係の管理 自己完結型 システムレベルの共有
更新メカニズム 自動ローリング更新 手動更新が必要
分離性 強力な分離 弱い分離
ディストリビューション間のサポート 対応 非対応
ロールバック機能 対応 限定的な対応

snap コマンドの基本構文

snap コマンドの基本的な構文は次のとおりです：

snap [命令] [选项] [包名]

よく使うコマンド一覧

  • install- snap パッケージをインストールする
  • remove- snap パッケージを削除する
  • refresh- snap パッケージを更新する
  • list- インストール済みの snap パッケージを一覧表示する
  • find- 利用可能な snap パッケージを検索する
  • info- snap パッケージの情報を表示する
  • revert- 以前のバージョンにロールバックする
  • disable/enable- snap パッケージを無効化/有効化する
  • services- snap サービスを管理する

snap コマンドの詳しい使い方

snap パッケージをインストールする

sudo snap install <package-name>

よく使うオプション：

  • --channel：インストールチャネルを指定します（例：stable、candidate、beta、edge）
  • --devmode：開発者モードでインストールします（セキュリティ制限を緩和）
  • --classic：クラシックモードでインストールします（制限を緩和）

例：

sudo snap install code --classic  # 安装 VS Code

インストール済みの snap パッケージを一覧表示する

snap list

出力例：

Name    Version    Rev    Tracking       Publisher    Notes
code    v1.70.2    xxxxx  latest/stable  vscode✓      classic

snap パッケージを検索する

snap find <search-term>

例：

snap find telegram

snap パッケージを更新する

単一のパッケージを更新：

sudo snap refresh <package-name>

すべてのパッケージを更新：

sudo snap refresh

snap パッケージを削除する

sudo snap remove <package-name>

snap パッケージの情報を確認する

snap info <package-name>

出力には、バージョン、チャネル、説明などの詳細情報が含まれます。

snap の高度な機能

チャネル管理

snap には複数のリリースチャネルがあります：

例

graph LR
    A[Edge] --> B[Beta]
    B --> C[Candidate]
    C --> D[Stable]

チャネルを切り替えるコマンド：

sudo snap refresh <package-name> --channel=<channel-name>

バージョンのロールバック

新しいバージョンに問題がある場合は、以前のバージョンにロールバックできます：

sudo snap revert <package-name>

サービス管理

サービスを提供する snap パッケージの場合：

サービスのステータスを確認：

snap services

サービスの起動/停止：

例

sudo snap start
sudo snap stop

実際の使用例

例1：Nextcloud をインストールして実行する

例

# Nextcloud をインストール
sudo snap install nextcloud

# 管理者アカウントを設定
sudo nextcloud.manual-install  

# アクセス URL を取得
sudo nextcloud.occ config:system:get overwrite.cli.url

例2：開発ツールチェーンをインストールする

例

# Go 言語をインストール
sudo snap install go --classic

# Node.js をインストール
sudo snap install node --channel=14/stable --classic

# Docker をインストール
sudo snap install docker

よくある問題の解決

問題1：snap アプリの起動が遅い

解決策：

例

# snap のコアコンポーネントをプリロード
sudo snap install core
sudo snap install snapd

# snap サービスを再起動
sudo systemctl restart snapd

問題2：権限エラー

システムリソースへのアクセスが必要なアプリケーションには、次を使用します：

例

# 必要なインターフェースを接続
sudo snap connect : :

# 例：VLC がリムーバブルデバイスにアクセスできるようにする
sudo snap connect vlc:removable-media

問題3：ディスク容量の使用

古いバージョンをクリーンアップ：

例

# 保持するバージョン数を設定（デフォルトは3）
sudo snap set system refresh.retain=2

# 手動でクリーンアップ
sudo snap system prune

ベストプラクティスの推奨事項

  1. 安定チャネルを優先的に使用する：本番環境で使用する--channel=stable
  2. 古いバージョンを定期的にクリーンアップする：ディスク容量を過剰に占有しないようにする
  3. インターフェース接続を適切に使用する：必要なシステム権限のみを付与する
  4. 自動更新を監視する：重要なサービスでは更新タイミングを手動で制御することを検討する
  5. 従来のパッケージ管理と組み合わせる：システムの重要なコンポーネントには、引き続きディストリビューションの公式リポジトリを使用することを推奨します

snap コマンドを習得することで、Linux 上のアプリケーションをより効率的に管理し、コンテナ化による利便性とセキュリティを享受できます。
