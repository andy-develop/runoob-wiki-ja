Linux dnf コマンド

Linux コマンド大全

dnf (Dandified YUM) は、RPM ベースの Linux ディストリビューション（Fedora、RHEL 8+、CentOS 8+ など）向けの次世代 RPM ソフトウェアパッケージマネージャーです。これは yum の置き換えであり、より高速な依存関係解決、より現代的なコードベース、より優れたパフォーマンスを提供します。

dnf の主な機能は次のとおりです。

  • ソフトウェアリポジトリからパッケージをインストール、更新、削除する
  • パッケージの依存関係を自動的に解決する
  • パッケージ情報を照会する
  • リポジトリを管理する

dnf 基本構文

dnf コマンドの基本構文は次のとおりです。

dnf [选项] <命令> [参数]

ここで：

  • [オプション]：dnf の動作を変更するためのオプションパラメータ
  • <コマンド>：実行する主な操作（install、remove など）
  • [パラメータ]：コマンドに必要な追加情報（通常はパッケージ名）

よく使う dnf コマンド

パッケージ管理

例

# パッケージをインストールする
dnf install

# パッケージを再インストールする
dnf reinstall

# パッケージを更新する
dnf update

# 更新可能なすべてのパッケージを更新する
dnf update

# パッケージを削除する
dnf remove

# 不要な依存関係を削除する
dnf autoremove

クエリ操作

例

# パッケージを検索する
dnf search

# インストール済みパッケージを一覧表示する
dnf list installed

# 利用可能なすべてのパッケージを一覧表示する
dnf list available

# パッケージ情報を表示する
dnf info

# パッケージが提供するファイルを表示する
dnf provides

リポジトリ管理

例

# 有効なすべてのリポジトリを一覧表示する
dnf repolist

# すべてのリポジトリを一覧表示する（無効なものを含む）
dnf repolist all

# リポジトリを有効にする
dnf config-manager --enable

# リポジトリを無効にする
dnf config-manager --disable

# 新しいリポジトリを追加する
dnf config-manager --add-repo

システムアップグレード

例

# システムアップグレードを確認する
dnf check-update

# システムアップグレードを実行する
dnf upgrade

# 新しいディストリビューションへアップグレードする
dnf system-upgrade

dnf のよく使うオプション

オプション 説明
-y 自動的に "yes" と回答する
-q クワイエットモード、出力を減らす
-v 詳細な出力
--refresh 操作前にリポジトリのメタデータをリフレッシュする
--nogpgcheck GPG 署名チェックを無効にする
--skip-broken 問題のあるパッケージをスキップする
--best 利用可能な最良のバージョンのインストールを試みる

実践例

例1：開発ツールグループのインストール

例

# 開発ツールグループをインストールする（gcc、make などを含む）
sudo dnf groupinstall "Development Tools" -y

例2：特定のソフトウェアの検索とインストール

例

# nginx を含むパッケージを検索する
dnf search nginx

# nginx をインストールする
sudo dnf install nginx -y

# nginx サービスを起動する
sudo systemctl start nginx

例3：キャッシュのクリア

例

# ダウンロードしたパッケージのキャッシュをクリアする
sudo dnf clean packages

# すべてのキャッシュ（メタデータとパッケージ）をクリアする
sudo dnf clean all

例4：履歴の表示

例

# dnf 操作の履歴を一覧表示する
dnf history

# 特定のトランザクションの詳細情報を表示する
dnf history info

# 特定のトランザクションを元に戻す
dnf history undo

dnf 設定ファイル

dnf の主要な設定ファイルは/etc/dnf/dnf.conf、一般的な設定項目は次のとおりです。

例

[main]
gpgcheck=1 # GPG署名をチェックするかどうか
installonly_limit=3 # 保持するカーネルバージョンの数
clean_requirements_on_remove=True # 削除時に依存関係をクリーンアップする
best=True # 常に最良のバージョンをインストールしようとする

現在の設定は次のコマンドで確認できます：

dnf config-manager --dump

dnf と yum の比較

特徴 dnf yum
依存関係解決アルゴリズム libsolv（より高速） カスタム（より低速）
API 安定 不安定
メモリ使用量 低い 高い
性能 より速い より遅い
プラグインシステム yum プラグインと互換性あり ネイティブプラグイン
履歴 より詳細 基本記録

トラブルシューティング

1. 依存関係の衝突

例

# 依存関係の問題を自動的に解決する
sudo dnf --skip-broken install

# または特定のパッケージを除外する
sudo dnf install  --exclude=

2. リポジトリのメタデータ破損

例

# リポジトリのキャッシュをクリアして再構築する
sudo dnf clean all
sudo dnf makecache

3. パッケージバージョンのロック

例

# パッケージをロックして更新を防ぐ
sudo dnf versionlock add

# ロックされたパッケージを一覧表示する
sudo dnf versionlock list

# ロックを削除する
sudo dnf versionlock delete

ベストプラクティス

  1. システムを定期的に更新する：

    sudo dnf update -y

  2. インストール前に検索する：

    dnf search &lt;keyword&gt;

  3. 変更の影響を確認する：

    sudo dnf update --assumeno

  4. グループコマンドを使用して関連ソフトウェアを管理する：

    # 列出可用组
dnf group list

# 安装组
sudo dnf groupinstall "组名"

  5. リポジトリをクリーンに保つ：

    # 定期清理不需要的包
sudo dnf autoremove

この記事を通じて、dnf コマンドの基本的な使い方と高度なテクニックを習得できたはずです。dnf は、現代の RPM システムのパッケージ管理ツールとして、強力で効率的なソフトウェア管理機能を提供します。実際の使用では、さまざまなコマンドやオプションを試して、その機能に徐々に慣れることをお勧めします。
