Linux tmux コマンド

Linux コマンド大全

tmux（Terminal Multiplexer）はターミナル多重化ツールで、単一のターミナルウィンドウ内に複数の仮想ターミナルセッションを作成し、それらのセッションをバックグラウンドで実行し続けることができます。ターミナルを直接使用するのに比べ、tmux はより強力なセッション管理機能を提供します。

主な利点：

  • セッションの永続化：ネットワークが切断されても、セッションはサーバー上に保持されます
  • 複数ウィンドウ/ペイン管理：複数の作業環境を効率的に整理
  • セッション共有：複数のユーザーが同じセッションに同時に接続できます

tmux のインストール

ほとんどの Linux ディストリビューションでは、tmux はパッケージマネージャーで簡単にインストールできます：

実例

# Ubuntu/Debian
sudo apt-get install tmux

# CentOS/RHEL
sudo yum install tmux

# macOS（Homebrew を使用）
brew install tmux

インストールが完了したら、tmuxコマンドを入力すると、新しいセッションを開始できます。

基本概念

セッション（Session）

tmux セッションは独立した実行環境であり、複数のウィンドウを含むことができます。接続が切断されても、セッションはバックグラウンドで実行し続けます。

ウィンドウ（Window）

各セッションには複数のウィンドウを含めることができ、ブラウザのタブに似ています。

ペイン（Pane）

各ウィンドウは複数のペインに分割でき、複数のターミナルを同時に表示・操作できます。

よく使うコマンドとショートカットキー

tmux のすべての操作は、まずプレフィックスキー（デフォルトはCtrl+b）を押してから、コマンドキーを入力します。

セッション管理

コマンド/ショートカットキー 説明
tmux new -s <name> name という名前の新しいセッションを作成
Ctrl+b d 現在のセッションを切り離す（セッションはバックグラウンドで実行を継続）
tmux ls すべてのセッションを一覧表示
tmux attach -t <name> 指定したセッションに再接続
Ctrl+b $ 現在のセッション名を変更
Ctrl+b s セッションを切り替える

ウィンドウ管理

コマンド/ショートカットキー 説明
Ctrl+b c 新しいウィンドウを作成
Ctrl+b & 現在のウィンドウを閉じる
Ctrl+b n 次のウィンドウに切り替え
Ctrl+b p 前のウィンドウに切り替え
Ctrl+b <number> 指定した番号のウィンドウに切り替え
Ctrl+b , 現在のウィンドウ名を変更

ペイン管理

コマンド/ショートカットキー 説明
Ctrl+b % 現在のペインを垂直分割
Ctrl+b " 現在のペインを水平分割
Ctrl+b <arrow> ペイン間でフォーカスを移動
Ctrl+b x 現在のペインを閉じる
Ctrl+b z 現在のペインを最大化/復元
Ctrl+b Space ペインのレイアウトを切り替え

tmux の設定

tmux の設定ファイルは~/.tmux.confにあります。以下はよく使う設定の例です：

実例

# プレフィックスキーを Ctrl+a に設定（デフォルトの Ctrl+b より押しやすい）
unbind C-b
set -g prefix C-a
bind C-a send-prefix

# マウスサポートを有効にする（マウスクリックでペイン/ウィンドウを切り替え可能）
set -g mouse on

# ステータスバーの色を設定
set -g status-bg black
set -g status-fg white

# ペインの枠線の色を設定
set -g pane-border-style fg=green
set -g pane-active-border-style fg=red

# ウィンドウ番号を1から始める（デフォルトは0）
set -g base-index 1
setw -g pane-base-index 1

設定を変更したら、Ctrl+b :を押してから、source-file ~/.tmux.confと入力して、設定を再読み込みします。

実用的なテクニック

1. セッションの復元

サーバーが再起動しても、tmux セッションを復元できます：

実例

# プラグインをインストール
git clone https://github.com/tmux-plugins/tmux-resurrect ~/clone/path

# .tmux.conf に追加
set -g @plugin 'tmux-plugins/tmux-resurrect'

2. コピーモード

  • Ctrl+b [コピーモードに入る
  • 矢印キーでカーソルを移動
  • スペースで選択開始、Enter でコピー
  • Ctrl+b ]貼り付け

3. 同期入力

複数のペインで同じコマンドを同時に入力：

実例

# 同期モードに入る
Ctrl+b :setw synchronize-panes on

# 同期モードをオフにする
Ctrl+b :setw synchronize-panes off

4. 開発環境のクイックセットアップ

実例

# 3つのペインを含む開発セッションを作成
tmux new -s dev -d
tmux send-keys -t dev:0 "vim" C-m
tmux split-window -h -t dev:0
tmux split-window -v -t dev:0.1
tmux attach -t dev

よくある問題の解決

1. マウスホイールが使えない

在 .tmux.confに追加：

set -g terminal-overrides 'xterm*:smcup@:rmcup@'

2. 色が正しく表示されない

ターミナルが256色に対応していることを確認し、次を追加：

set -g default-terminal "screen-256color"

3. ショートカットキーの競合

一部のショートカットキーが他のツールと競合する場合は、設定ファイルで再バインドできます。

学習パスの提案

  1. まず基本的なセッション管理（作成、切り離し、再接続）を習得
  2. ウィンドウとペインの基本操作を練習
  3. よく使うショートカットキーに慣れる
  4. ニーズに合わせて設定をカスタマイズ
  5. 高度な機能とプラグインを探索

継続的な実践を通じて、tmux がターミナルの作業効率を大幅に向上させることを実感できるでしょう。
