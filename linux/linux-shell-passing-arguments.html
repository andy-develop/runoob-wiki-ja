Shell パラメータ渡し

Shell スクリプトを実行するときに、スクリプトにパラメータを渡すことができます。スクリプト内でパラメータを取得する形式は次のとおりです：$n，nは数字を表します。1は実行スクリプトの最初のパラメータです。2は実行スクリプトの2番目のパラメータです。

例えば、次を使用できます：$1、$2などでスクリプトに渡されたパラメータを参照できます。ここで$1は最初のパラメータを表し、$2は2番目のパラメータを表し、以下同様です。

実例

次の実例では、スクリプトに3つのパラメータを渡し、それぞれ出力します。ここで$0は実行するファイル名（ファイルパスを含む）です：

実例

#!/bin/bash
# author:菜鸟教程
# url:www.runoob.com

echo "Shell パラメータ渡しの実例！";
echo "実行するファイル名：$0";
echo "最初のパラメータ：$1";
echo "2番目のパラメータ：$2";
echo "3番目のパラメータ：$3";

スクリプトに実行権限を設定し、スクリプトを実行すると、出力結果は次のようになります：

$ chmod +x test.sh 
$ ./test.sh 1 2 3
Shell 传递参数实例！
执行的文件名：./test.sh
第一个参数为：1
第二个参数为：2
第三个参数为：3

その他にも、パラメータを処理するための特殊文字がいくつかあります：

パラメータ処理 説明
$# スクリプトに渡されるパラメータの数
$* スクリプトに渡されたすべてのパラメータを単一の文字列として表示します。
「"」で囲まれた "$*" の場合、すべてのパラメータを "$1 $2 … $n" の形式で出力します。
$$ スクリプト実行中の現在のプロセスのID番号
$! バックグラウンドで実行されている最後のプロセスのID番号
$@ $* と同じですが、使用時に引用符を付け、引用符内で各パラメータを返します。
「"」で囲まれた "$@" の場合、すべてのパラメータを "$1" "$2" … "$n" の形式で出力します。
$- Shell が使用している現在のオプションを表示します。set コマンドと同じ機能です。
$? 最後に実行したコマンドの終了ステータスを表示します。0 はエラーがないことを示し、その他の値はエラーがあることを示します。

実例

#!/bin/bash
# author:菜鸟教程
# url:www.runoob.com

echo "Shell パラメータ渡しの実例！";
echo "最初のパラメータ：$1";

echo "パラメータの数：$#";
echo "渡されたパラメータを文字列として表示：$*";

スクリプトを実行すると、出力結果は次のようになります：

$ chmod +x test.sh 
$ ./test.sh 1 2 3
Shell 传递参数实例！
第一个参数为：1
参数个数为：3
传递的参数作为一个字符串显示：1 2 3

$* と $@ の違い：

  • 共通点：どちらもすべてのパラメータを参照することです。
  • 相違点：二重引用符内でのみ違いが現れます。スクリプト実行時に 1、2、3 の3つのパラメータを指定したとすると、" * " は "1 2 3"（1つのパラメータとして渡される）に相当し、"@" は "1" "2" "3"（3つのパラメータとして渡される）に相当します。

実例

#!/bin/bash
# author:菜鸟教程
# url:www.runoob.com

echo "-- \$* デモ ---"
for i in "$*"; do
    echo $i
done

echo "-- \$@ デモ ---"
for i in "$@"; do
    echo $i
done

スクリプトを実行すると、出力結果は次のようになります：

$ chmod +x test.sh 
$ ./test.sh 1 2 3
-- $* 演示 ---
1 2 3
-- $@ 演示 ---
1
2
3

    shell スクリプトに渡すパラメータにおいてスペースが含まれる場合は、そのパラメータをシングルクォートまたはダブルクォートで囲み、スクリプトがそのパラメータを全体として受け取れるようにする必要があります。。

    パラメータがある場合、パラメータを検証する方法を使用してエラーの発生を減らすことができます：

    if [ -n "$1" ]; then
    echo "包含第一个参数"
else
    echo "没有包含第一参数"
fi

    注意：角括弧[]とその間のコードはスペースで区切る必要があります

    Shell 内の角括弧（単一の角括弧と二重の角括弧を含む）は、いくつかの条件のテストに使用できます：

    • 算術比較、例えば変数が0であるかどうか、[ $var -eq 0 ]。
    • ファイル属性のテスト、例えばファイルが存在するかどうか、[ -e $var ]、ディレクトリであるかどうか、[ -d $var ]。
    • 文字列比較、例えば2つの文字列が同じであるかどうか、[[ $var1 = $var2 ]]。

    [] は多くの場合 test コマンドで代用できます。詳細は次を参照してください：Shell における角括弧の使い方まとめ。

    スペースを含むパラメータは、パラメータを渡すときにダブルクォートを付けるだけで済みます。

    #!/bin/bash 

echo "---------------with double quote ---------------"
echo "$1"
echo "$2"
echo "$3"
my_procedure() {
   echo "$1"
   echo "$2"
   echo "$3"
}
my_procedure "$@"

echo "---------------withtout double quote ---------------"
echo $1
echo $2
echo $3
my_procedure() {
   echo $1
   echo $2
   echo $3
}
my_procedure "$@"
echo "---------------withtout double quote by passing arguments---------------"
my_procedure $@

    入力：

    ./test.sh "a b" "c d" "e f"

    出力結果は次のとおりです：

    ---------------with double quote ---------------
a b
c d e
f g
a b
c d e
f g
---------------withtout double quote ---------------
a b
c d e
f g
a b
c d e
f g
---------------withtout double quote by passing arguments ---------------
a
b
c

    最初の2つの部分は、関数の内外に関わらず、引用符を付けても付けなくても同じですが、関数に渡すときは必ず引用符を付けてください。
