Linux finger コマンド

Linux コマンド大全

fingerコマンドは、ローカルまたはリモートシステム上のユーザーの詳細情報（ログイン名、フルネーム、ログイン時間、アイドル時間など）を表示するために使用されます。

これは who コマンドよりもwhoとidより豊富なユーザー情報の表示を提供し、複数人で共有するサーバー上で他のユーザーの状態を把握するのに適しています。

fingerは初期のUnixシステムでよく使われたユーザー情報照会ツールであり、名前は「誰かを指す」という意味に由来します。

これは/etc/passwdのGECOSフィールドからユーザーの個人記述情報を読み取り、そのログイン状態を表示します。

セキュリティ上の理由から、現代のLinuxディストリビューションはデフォルトではインストールしなくなりましたがfinger、イントラネット環境や教育現場では今でも利用価値があります。

fingerシステムがfingerdサービスを実行している必要があります。これによりリモートユーザー情報を照会できます。セキュリティ上の理由から、ほとんどのパブリックサーバーではこのサービスが無効になっています。

コマンド構文

fingerの基本的な構文は次のとおりです：

finger [选项] [用户@主机]

引数を指定しない場合、現在ログインしているすべてのユーザーの概要情報が一覧表示されます。

ユーザー名を指定すると、そのユーザーの詳細情報が表示されます。

指定したユーザー@ホスト形式でリモートホスト上のユーザー情報を照会できます。

fingerの一般的なオプションは次のとおりです：

オプション機能例
-s簡潔な形式でユーザー情報を表示するfinger -s
-l詳細な長い形式でユーザー情報を表示するfinger -l runoob
-p.plan と .project ファイルの内容を表示しないfinger -p runoob
-mユーザー名に対する一致検索を無効にするfinger -m runoob

詳細な使い方

現在のログインユーザーを確認する

引数なしで実行するとfinger、システム内のすべてのログインユーザーの概要情報が一覧表示されます。

# 查看所有当前登录的用户
$ finger
Login     Name           Tty      Idle  Login Time   Office     Office Phone
root      root           tty1           May 19 09:00
runoob    Zhang San      pts/0      3  May 19 10:30  A-301      010-12345678

出力には、ログイン名、フルネーム、端末、アイドル時間、ログイン時間、オフィス、電話などの情報が含まれます。

指定したユーザーの詳細情報を確認する

ユーザー名を指定すると、そのユーザーの完全な情報を確認できます。

# 查看 runoob 用户的详细信息
$ finger runoob
Login: runoob                    Name: Zhang San
Directory: /home/runoob          Shell: /bin/bash
Office: A-301, 010-12345678      Home Phone: 010-87654321
Last login Tue May 19 10:30 (CST) on pts/0
Mail last read Tue May 19 09:00 2026 (CST)
No Plan.

詳細情報には、ユーザーのホームディレクトリ、デフォルトシェル、最終ログイン時間、メール閲覧時間などが含まれます。

「No Plan.」は、ユーザーのホームディレクトリに.planファイルがないことを示します。このファイルを作成すると、その内容がここに表示され、個人の紹介や現在のステータスを表示するために使用できます。

簡潔な形式での出力

を使用すると-sオプションで重要なフィールドのみを出力でき、すばやく確認するのに適しています。

# 以简短格式查看用户信息
$ finger -s runoob
Login     Name           Tty      Idle  Login Time   Office     Office Phone
runoob    Zhang San      pts/0      3  May 19 10:30  A-301      010-12345678

簡潔な形式では、ホームディレクトリ、シェル、最終ログイン時間などの詳細情報が省略され、1行の表として出力されます。

曖昧一致を無効にする

デフォルトでは、finger指定された文字列を含むすべてのユーザー名、フルネームなどの情報を一致させようとします。-mこの動作を無効にして、ユーザー名のみを完全一致で検索できます。

# 精确匹配用户名，不搜索全名和其他字段
$ finger -m runoob

システムに対象のユーザー名と似たフルネームやエイリアスが存在する場合、-m予期しない結果が返るのを防ぐことができます。

複数ユーザーを確認する

複数のユーザー名を同時に指定して、一度に複数のユーザー情報を確認できます。

# 同时查看多个用户
$ finger runoob root
Login: runoob                    Name: Zhang San
Directory: /home/runoob          Shell: /bin/bash
Office: A-301, 010-12345678      Home Phone: 010-87654321
Last login Tue May 19 10:30 (CST) on pts/0
No Plan.

Login: root                      Name: root
Directory: /root                 Shell: /bin/bash
Last login Tue May 19 09:00 (CST) on tty1
No Plan.

リモートユーザー情報を確認する

fingerリモートホスト上のユーザーを照会できます。形式は次のとおりです：ユーザー名@ホストアドレス。

# 查看远程主机上的用户信息（需要远程主机开启 fingerd 服务）
$ finger runoob@192.168.1.100
Login: runoob                    Name: Zhang San
Directory: /home/runoob          Shell: /bin/bash
Last login Tue May 19 08:00 (CST) on pts/1
No Plan.

リモート照会では、対象ホストがfingerd（fingerデーモン）を実行し、79番ポートを外部に開放している必要があります。ほとんどのクラウドサーバーはセキュリティ上の理由からこの機能を無効にしています。

.plan と .project ファイルの設定

ユーザーはホームディレクトリに.planと.projectファイルを作成して、個性的な情報を表示できます。

# 创建 .project 文件（单行项目说明）
$ echo "RUNOOB Platform Development" > ~/.project

# 创建 .plan 文件（多行计划或简介）
$ cat > ~/.plan &lt;&lt; 'EOF'
当前任务：
1. 负责 RUNOOB 后端 API 开发
2. 维护数据库迁移脚本
3. Code Review 本周三之前完成
EOF

# 再次查看用户信息
$ finger runoob
Login: runoob                    Name: Zhang San
Directory: /home/runoob          Shell: /bin/bash
Office: A-301, 010-12345678      Home Phone: 010-87654321
Last login Tue May 19 10:30 (CST) on pts/0
Project: RUNOOB Platform Development
Plan:
当前任务：
1. 负责 RUNOOB 后端 API 开发
2. 维护数据库迁移脚本
3. Code Review 本周三之前完成

.projectファイルの内容は1行で表示され、.planファイルの内容は複数行にでき、個人の紹介や現在の作業タスクを書くのに適しています。

.planファイルのデフォルトの余分なインデントは、レイアウトを揃えるためのものです。インデントを削除したい場合は、コンテンツの前に空行を追加します。

who および w コマンドとの違い

コマンド情報の豊富さ主な用途代表的なシナリオ
who基本ログインユーザー、端末、ログイン時間のみを一覧表示誰がオンラインかをすばやく確認
w中程度ログインユーザーと現在実行中のプログラムを表示ユーザーが現在何をしているかを把握
finger詳細ユーザーの完全な情報（連絡先、計画など）を表示特定のユーザーの詳細なプロフィールを確認

よくある質問

現代のLinuxディストリビューション（Ubuntu、Debian、CentOSなど）はデフォルトではインストールしません。finger。手動でapt install finger 或 yum install fingerを実行してインストールします。

fingerのインストールと使用はセキュリティリスクをもたらす可能性があります。ユーザーの個人情報やログイン状態を公開するためです。企業サーバーで使用する前に、セキュリティポリシーが許可していることを確認してください。

finger表示されるオフィス、電話などの情報はGECOSフィールドに由来し、chfnコマンドを使用して変更できます。

もしfingerがユーザー情報を表示しない場合は、確認してください：/etc/passwd内のユーザーエントリが存在するかどうか、および操作権限が十分かどうか。
