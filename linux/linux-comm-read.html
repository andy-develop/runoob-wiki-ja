Linux read コマンド

Linux コマンド大全

Linux read コマンドは、標準入力から値を読み取るために使用されます。

read 組み込みコマンドは、標準入力から1行のデータを読み取るために使用されます。このコマンドはキーボード入力の読み取りに使用でき、リダイレクトを使用する場合は、ファイル内の1行のデータを読み取ることができます。

構文

read [-ers] [-a aname] [-d delim] [-i text] [-n nchars] [-N nchars] [-p prompt] [-t timeout] [-u fd] [name ...]

パラメータの説明:

  • -a の後に変数を指定します。この変数は配列と見なされ、値が代入されます。デフォルトではスペースが区切り文字です。
  • -d の後には区切り文字を指定します。実際にはその後ろの最初の文字だけが有効で、終了のフラグとして使用されます。
  • -p の後にはプロンプトメッセージを指定します。つまり、入力前にプロンプトメッセージを表示します。
  • -e は入力時にコマンド補完機能を使用できます。
  • -n の後に数値を指定し、入力テキストの長さを定義します。非常に実用的です。
  • -r は \ を無効にします。このオプションがない場合、\ はエスケープ文字として扱われますが、ある場合、\ は普通の文字になります。
  • -s はサイレントモードで、文字入力時に画面に表示されません。例えば、ログイン時にパスワードを入力する場合です。
  • -t の後に秒数を指定し、入力文字の待機時間を定義します。
  • -u の後にfdを指定し、ファイルディスクリプタから読み取ります。そのファイルディスクリプタはexecで新しく開かれたものでも構いません。

実例

1、簡単な読み取り

#!/bin/bash

#这里默认会换行  
echo "输入网站名: "  
#读取从键盘的输入  
read website  
echo "你输入的网站名是 $website"  
exit 0  #退出

テスト結果は次のとおりです：

输入网站名: 
www.runoob.com
你输入的网站名是 www.runoob.com

2、-p パラメータを使用すると、read コマンドラインで直接プロンプトを指定できます。

#!/bin/bash

read -p "输入网站名:" website
echo "你输入的网站名是 $website" 
exit 0

テスト結果は次のとおりです：

输入网站名:www.runoob.com
你输入的网站名是 www.runoob.com

3、-t パラメータは read コマンドが入力を待機する秒数を指定します。タイマーが満了すると、read コマンドは非ゼロの終了ステータスを返します。

#!/bin/bash

if read -t 5 -p "输入网站名:" website
then
    echo "你输入的网站名是 $website"
else
    echo "\n抱歉，你输入超时了。"
fi
exit 0

プログラムを実行して入力せず、5秒待つと：

ウェブサイト名を入力してください:

4、入力時間の計測に加えて、次を使用できます-nパラメータ設定readコマンドは入力された文字をカウントします。入力された文字数が所定の数に達すると、自動的に終了し、入力されたデータが変数に代入されます。

#!/bin/bash

read -n1 -p "Do you want to continue [Y/N]?" answer
case $answer in
Y | y)
      echo "fine ,continue";;
N | n)
      echo "ok,good bye";;
*)
     echo "error choice";;

esac
exit 0

この例では -n オプションを使用し、その後に数値 1 を指定して、read コマンドが1文字を受け取ったら終了するように指示しています。1文字を押して回答するだけで、read コマンドは即座に入力を受け取って変数に渡すため、Enterキーを押す必要はありません。

2つの入力を受け取ったら終了します：

#!/bin/bash

read -n2 -p "请随便输入两个字符: " any
echo "\n您输入的两个字符是:$any"
exit 0

プログラムを実行して2文字を入力します：

请随便输入两个字符: 12
您输入的两个字符是:12

5、-sオプションにより、次のことが可能になりますreadコマンドに入力されたデータがコマンドターミナルに表示されません（実際には、データは表示されています。ただ、readコマンドがテキストの色を背景色と同じ色に設定しているだけです）。パスワードの入力にはこのオプションがよく使用されます。

#!/bin/bash

read  -s  -p "请输入您的密码:" pass
echo "\n您输入的密码是 $pass"
exit 0

プログラムを実行してパスワードを入力しても、表示されません：

请输入您的密码:
您输入的密码是 runoob

6. ファイルの読み取り

read コマンドを呼び出すたびに、ファイル内の「1行」のテキストを読み取ります。ファイルに読み取り可能な行がない場合、read コマンドは非ゼロのステータスで終了します。

どのような方法でファイル内のデータを read に渡すのでしょうか？ cat コマンドを使用し、パイプで結果を read コマンドを含む while コマンドに直接渡します。

テストファイル test.txt の内容は次のとおりです：

123
456
runoob

テストコード：

#!/bin/bash
  
count=1    # 赋值语句，不加空格
cat test.txt | while read line      # cat 命令的输出作为read命令的输入,read读到>的值放在line中
do
   echo "Line $count:$line"
   count=$[ $count + 1 ]          # 注意中括号中的空格。
done
echo "finish"
exit 0

実行結果は次のとおりです：

Line 1:123
Line 2:456
Line 3:runoob
finish

使用する-eパラメータ。次の例では、文字を入力しaた後に押すとTabキーが関連するファイル名（そのディレクトリに存在するもの）を出力します：

$ read -e -p "输入文件名:" str 
输入文件名:a
a.out    a.py     a.pyc    abc.txt  
输入文件名:a
