Linux sestatus コマンド

Linux コマンド大全

sestatusLinux システムで SELinux (Security-Enhanced Linux) の現在の状態を確認するためのコマンドラインツールです。SELinux は米国家安全保障局(NSA)によって開発された強制アクセス制御(MAC)セキュリティメカニズムで、Linux システムに追加のセキュリティ層を提供します。

コマンド構文

sestatus [选项]

よく使うオプション

オプション 説明
-v プロセスとファイルのコンテキスト情報を含む詳細な出力を表示する
-b 現在ロードされているポリシーのブール値(ルールのオン/オフ)を表示する

コマンド出力の解説

実行sestatusコマンドを実行すると、典型的な出力は次のようになります：

例

SELinux status:                 enabled
SELinuxfs mount:                /sys/fs/selinux
SELinux root directory:         /etc/selinux
Loaded policy name:             targeted
Current mode:                   enforcing
Mode from config file:          enforcing
Policy MLS status:              enabled
Policy deny_unknown status:     allowed
Memory protection checking:     actual (secure)
Max kernel policy version:      33

主要フィールドの説明

  1. SELinux status

    • enabled: SELinux は有効
    • disabled: SELinux は無効

  2. Current mode

    • enforcing: セキュリティポリシーを強制執行
    • permissive: 違反行為を記録するだけでブロックしない
    • disabled: 完全に無効

  3. Loaded policy name

    • targeted: デフォルトポリシー、特定のサービスのみを保護
    • mls: 多段階セキュリティポリシー(より厳格)
    • minimum: 最小ポリシー

実際の使用例

例1：SELinux の基本状態を確認する

$ sestatus

これは最も基本的な使い方で、SELinux が有効かどうかとその動作モードをすばやく確認できます。

例2：詳細なコンテキスト情報を表示する

$ sestatus -v

出力にはプロセスとファイルのコンテキスト情報が含まれます。例：

例

Process contexts:
Current context:            unconfined_u:unconfined_r:unconfined_t:s0-s0:c0.c1023
Init context:               system_u:system_r:init_t:s0
...
File contexts:
Controlling terminal:       unconfined_u:object_r:user_devpts_t:s0
...

例3：現在のポリシーのブール値を確認する

$ sestatus -b

出力には設定可能なすべてのポリシールールのオン/オフ状態が表示されます。例：

例

Policy booleans:
abrt_anon_write                            off
abrt_handle_event                          off
...
httpd_can_network_connect                  off
...

よくある問題のトラブルシューティング

問題1：SELinux が正常な操作をブロックしている

解決策：

  1. まず、問題が SELinux によるものかどうかを確認します：
    grep "avc:" /var/log/audit/audit.log
  2. その場合は、一時的に permissive モードに設定してテストできます：
    sudo setenforce 0
  3. 恒久的な解決策は、SELinux ポリシーを調整するか、ファイルのコンテキストを変更することです

問題2：sestatus が SELinux 無効を表示する

考えられる原因：

  • システム起動時に SELinux が無効化されている
  • /etc/selinux/configファイルに設定されているSELINUX=disabled

解決策：

  1. 編集/etc/selinux/configファイル
  2. 変更SELINUX=enforcing 或 SELINUX=permissive
  3. システムを再起動

ベストプラクティス

  1. 本番環境での推奨事項

    • SELinux を に維持するenforcingモードにして最大限のセキュリティを確保する
    • むやみに SELinux を無効化せず、正しく設定する方法を学びましょう

  2. トラブルシューティングの手順

    • 最初に を使用してsestatus状態を確認する
    • を表示して/var/log/audit/audit.log詳細な拒否情報を取得する
    • を使用してaudit2allowカスタムポリシーモジュールを生成する

  3. ポリシー調整

    • を優先的に使用してsetseboolブール値を調整する
    • 次にファイルのコンテキストの変更を検討する(chcon)
    • 最後にカスタムポリシーモジュールの作成を検討する

まとめ

sestatusコマンドは SELinux システムを管理するための最初のツールであり、これを使用してシステムのセキュリティ状態をすばやく把握できます。このコマンドの使い方をマスターすると、システム管理者が Linux システムのセキュリティをより適切に維持し、権限の問題が発生した際に原因をすばやく特定するのに役立ちます。
