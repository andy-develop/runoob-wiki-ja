Linux ps コマンド

Linux コマンド大全

Linux ps (英語の正式名称: process status) コマンドは現在のプロセスの状態を表示するために使用され、Windows のタスクマネージャーに似ています。

構文

ps [options] [--help]

パラメータ：

  • ps のパラメータは非常に多いですが、ここではよく使われるいくつかのパラメータだけを挙げて、その意味を大まかに紹介します。
  • -A すべてのプロセスを一覧表示
  • -w 表示を拡幅して、より多くの情報を表示できる
  • -au より詳細な情報を表示
  • -aux 他のユーザーのプロセスも含むすべてのプロセスを表示

  • au(x) 出力形式 :

    USER PID %CPU %MEM VSZ RSS TTY STAT START TIME COMMAND
    • USER: プロセスの所有者
    • PID: pid
    • %CPU: 使用中の CPU 使用率
    • %MEM: 使用中のメモリ使用率
    • VSZ: 使用中の仮想メモリサイズ
    • RSS: 使用中のメモリサイズ
    • TTY: 端末の副装置番号 (minor device number of tty)

    • STAT: そのプロセスの状態:

      • D: 中断できない休止状態 (通常 IO のプロセス)
      • R: 実行中
      • S: スリープ状態
      • T: 実行を一時停止
      • Z: 存在しないが、一時的に消去できない
      • W: 割り当てるのに十分なメモリページがない
      • <: 高優先度のプロセス
      • N: 低優先度のプロセス
      • L: メモリページが割り当てられ、メモリ内にロックされている (リアルタイムシステムまたはI/O待ち)
    • START: プロセスの開始時間
    • TIME: 実行時間
    • COMMAND: 実行されたコマンド

実例

指定したプロセスを検索する形式:

ps -ef | grep 进程关键字

例: php のプロセスを表示:

# ps -ef | grep php
root       794     1  0  2020 ?        00:00:52 php-fpm: master process (/etc/php/7.3/fpm/php-fpm.conf)
www-data   951   794  0  2020 ?        00:24:15 php-fpm: pool www
www-data   953   794  0  2020 ?        00:24:14 php-fpm: pool www
www-data   954   794  0  2020 ?        00:24:29 php-fpm: pool www
...
