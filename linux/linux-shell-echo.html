Shell echo コマンド

echoは組み込みの Shell コマンドであり、標準出力（通常はターミナル）に1行のテキストまたは変数の値を表示するために使用されます。

Shell の echo コマンドは PHP の echo コマンドと似ており、どちらも文字列の出力に使用されます。

コマンド形式：

echo [选项] [字符串]

なぜ echo が必要なのか？

  • 情報フィードバック：スクリプトの実行状態や結果をユーザーに表示する
  • デバッグツール：変数の値や実行位置を出力し、スクリプトのデバッグを支援する
  • 対話型インターフェース：シンプルなユーザー対話型インターフェースを作成する
  • ファイル生成：設定ファイルやスクリプトを素早く生成する

基本的な使い方

1. シンプルなテキスト出力

最も基本的な使い方は、文字列を直接出力することです：

実例

echo "Hello, World!"

実行結果：

Hello, World!

2. 変数の出力

echo変数の値を表示できます：

実例

name="Linux User"
echo "Welcome, $name!"

実行結果：

Welcome, Linux User!

3. 引用符なしの出力

引用符は必須ではありませんが、予期しない問題を避けるために使用することをお勧めします：

実例

echo This is a test

実行結果：

This is a test

よく使うオプション

-n オプション：改行なしで出力

デフォルトでは、echo出力の後に改行を追加します。使用-nすると、この動作を無効にできます：

実例

echo -n "Loading..."
echo " Done!"

実行結果：

Loading... Done!

-e オプション：エスケープ文字の解釈を有効化

バックスラッシュエスケープの解釈を有効にします：

実例

echo -e "First line\nSecond line"

実行結果：

First line
Second line

よく使うエスケープシーケンス

エスケープシーケンス 説明
\n 改行
\t 水平タブ
\v 垂直タブ
\b バックスペース
\r キャリッジリターン
\\ バックスラッシュ文字そのもの

高度な使い方

1. ファイルへの出力

リダイレクトを使用して出力をファイルに保存します：

実例

echo "This will be saved to file" > output.txt

ファイルに内容を追記します：

実例

echo "Additional line" >> output.txt

2. カラー出力

ANSI エスケープコードを使用してカラーテキストを実現します：

実例

echo -e "\033[31mRed Text\033[0m"
echo -e "\033[42;31mGreen Background with Red Text\033[0m"

色コードリファレンス：

  • 前景色：30(黒)、31(赤)、32(緑)、33(黄)、34(青)、35(紫)、36(シアン)、37(白)
  • 背景色：40-47 は上記の色に対応
  • \033[0mすべての属性をリセット

3. コマンド実行結果の出力

コマンド置換を使用してコマンド結果を出力します：

実例

echo "Today is $(date)"

実行結果：

Today is Wed Jul 12 14:30:22 CST 2023

実際の応用例

1. シンプルなメニューの作成

実例

echo -e "\n\033[1mSystem Menu\033[0m"
echo "1. Check disk space"
echo "2. List running processes"
echo "3. Show system info"
echo -n "Please enter your choice [1-3]: "

2. プログレスバーのシミュレーション

実例

echo -n "Progress: ["
for i in {1..20}; do
    echo -n "#"
    sleep 0.1
done
echo "] Done!"

3. 設定ファイルの生成

実例

cat <<EOF | sudo tee /etc/myapp.conf
# Generated by script on $(date)
[Database]
host = localhost
port = 3306
user = appuser
password = secret123
EOF

注意事項

1、引用符の重要性：

実例

var="Hello World"
echo $var    # 変数にスペースが含まれる場合、問題が発生する可能性があります
echo "$var"  # 正しい方法

2、シェルによる実装の違い：

  • Bash 組み込みechoサポート-eオプション
  • 一部のシステムの/bin/echoすべてのオプションをサポートしていない場合があります
  • 移植性のあるスクリプトでは、使用を推奨printf複雑な ... の代替としてecho

3、特殊文字の処理：

実例

echo "Cost: \$100"  # $ 記号を出力
echo "Path: /usr/local/bin"  # スラッシュはエスケープ不要

要点まとめ

重要なポイント 説明
基本構文 echo [选项] [字符串]
よく使うオプション -n改行なし、-eエスケープを有効化
変数の出力 使用$変数名、二重引用符で囲むことをお勧めします
カラー出力 ANSI エスケープコードを使用\033[XXm
出力リダイレクト >ファイルを上書き、>>ファイルに追記
複数行の出力 使用\n改行またはヒアドキュメント
移植性に関する推奨事項 複雑な出力には使用を検討printf
その他の拡張

    read コマンドは入力されたパラメータを単語ごとに受け取ります。各単語はスペースで区切る必要があります。入力された単語数が必要なパラメータ数より多い場合、余った単語は全体として最後のパラメータとして受け取られます。

    テストファイル test.sh のコードは次のとおりです：

    read firstStr secondStr
echo "第一个参数:$firstStr; 第二个参数:$secondStr"

    テストを実行：

    $ sh test.sh 
一 二 三 四
第一个参数:一; 第二个参数:二 三 四

    実例、ファイル test.sh:

    read -p "请输入一段文字:" -n 6 -t 5 -s password
echo -e "\npassword is $password"
    パラメータの説明：
    • -p入力プロンプト文字
    • -n入力文字数の制限(6文字に達すると自動終了)
    • -t入力制限時間
    • -s入力内容を非表示
    $ sh test.sh 
请输入一段文字:
password is asdfgh
