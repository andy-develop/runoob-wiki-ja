Linux pacman コマンド

Linux コマンド大全

pacman (Package Manager) は、Arch Linux およびその派生ディストリビューション（Manjaro など）のデフォルトのパッケージ管理ツールです。これは、ソフトウェアパッケージをインストール、更新、削除、管理するための強力なコマンドラインツールです。

pacman の主な特徴：

  • シンプルで使いやすいコマンドラインインターフェース
  • 依存関係を自動的に処理
  • ローカルおよびリモートのソフトウェアパッケージをサポート
  • 完全なシステム更新機能を提供
  • 効率的なパッケージ照会および検索機能

基本構文

pacman コマンドの基本構文は以下のとおりです：

sudo pacman [选项] [操作] [包名/其他参数]

ここで：

  • sudo：ほとんどの pacman 操作には root 権限が必要です
  • オプション：コマンドの動作を変更するフラグ
  • 操作：実行する主な機能を指定
  • パッケージ名：操作対象のソフトウェアパッケージ名

よく使う操作コマンド

システム更新

例

# インストール済みのすべてのソフトウェアパッケージを更新
sudo pacman -Syu

# ソフトウェアパッケージデータベースのみ更新（実際にソフトウェアは更新しない）
sudo pacman -Sy

ソフトウェアパッケージのインストール

例

# 単一のソフトウェアパッケージをインストール
sudo pacman -Sパッケージ名

# 複数のソフトウェアパッケージをインストール
sudo pacman -Sパッケージ名1パッケージ名2パッケージ名3

# ローカルのソフトウェアパッケージファイルをインストール（依存関係を処理しない）
sudo pacman -U /パス/到/パッケージ名.pkg.tar.zst

ソフトウェアパッケージの削除

例

# ソフトウェアパッケージを削除するが、その依存関係は残す
sudo pacman -Rパッケージ名

# ソフトウェアパッケージと、不要になった依存関係を削除
sudo pacman -Rsパッケージ名

# ソフトウェアパッケージとそのすべての設定ファイルを削除
sudo pacman -Rnsパッケージ名

ソフトウェアパッケージの照会

例

# ソフトウェアパッケージを検索（名前と説明）
pacman -Ssキーワード

# インストール済みのソフトウェアパッケージを一覧表示
pacman -Q

# 指定したファイルがどのソフトウェアパッケージに属するかを照会
pacman -Qo /パス/到/ファイル

# ソフトウェアパッケージの詳細情報を表示
pacman -Qiパッケージ名

キャッシュのクリーンアップ

例

# インストールされていないソフトウェアパッケージのキャッシュをクリア
sudo pacman -Sc

# すべてのソフトウェアパッケージのキャッシュをクリア（インストール済みのものも含む）
sudo pacman -Scc

よく使うオプションパラメータ

オプション 説明
-S 同期/ソフトウェアパッケージのインストール
-R ソフトウェアパッケージの削除
-Q ローカルソフトウェアパッケージデータベースの照会
-U ローカルソフトウェアパッケージファイルのインストール
-y ソフトウェアパッケージデータベースの更新
-u ソフトウェアパッケージのアップグレード
-s 検索時に説明を含める
-i ソフトウェアパッケージ情報の表示
-c キャッシュのクリーンアップ
-d 依存関係のチェックをスキップ
-f 強制操作
--noconfirm すべての確認プロンプトをスキップ

実際の応用例

例1：開発環境のインストールと設定

例

# システムを更新
sudo pacman -Syu

# 開発ツールパッケージをインストール
sudo pacman -S base-devel git python

# インストールを検証
pacman -Q | grep python

例2：メディアプレイヤーの検索とインストール

例

# メディアプレイヤーを検索
pacman -Ss media player

# VLCメディアプレイヤーをインストール
sudo pacman -S vlc

# VLCの依存関係を確認
pacman -Qi vlc

例3：不要になったソフトウェアを完全に削除する

例

# 削除するソフトウェアパッケージを探す
pacman -Qs game

# ゲームとその依存関係および設定を削除
sudo pacman -Rns steam

よくある問題の解決

1. 依存関係の競合

依存関係の競合が発生した場合は、次のことを試せます：

例

# 特定のソフトウェアパッケージを強制的にダウングレード
sudo pacman -U https://archive.archlinux.org/packages/p/パッケージ名/パッケージ名-バージョン.pkg.tar.zst

# または依存関係の修復を試みる
sudo pacman -Syu --overwrite '*'

2. データベースのロック

「could not lock database」エラーが発生した場合：

例

# ロックファイルを削除
sudo rm /var/lib/pacman/db.lck

3. ディスク容量不足

古いバージョンのキャッシュをクリーンアップ：

例

# キャッシュの使用容量を確認
du -sh /var/cache/pacman/pkg/

# 古いバージョンをクリーンアップ
sudo pacman -Sc

ベストプラクティスの提案

  1. システムを定期的に更新：少なくとも週に1回実行sudo pacman -Syu
  2. 出力情報を読む：pacman の出力には重要な情報が含まれるため、盲目的に確認しない
  3. 重要なデータをバックアップ：大規模なシステム更新を行う前に重要なファイルをバックアップ
  4. AURヘルパーを使用：Archユーザーリポジトリ（AUR）内のソフトウェアには、yay または paru の使用を検討
  5. Arch Wiki を参照：問題が発生した場合、Arch Wiki に詳細な解決策が通常あります

上級テクニック

パッケージのファイル内容を確認する

例

# ソフトウェアパッケージに含まれるファイルを一覧表示
pacman -Qlパッケージ名

# 特定のソフトウェアパッケージファイルを抽出
sudo pacman -Swパッケージ名&amp;&amp; tar -xf /var/cache/pacman/pkg/パッケージ名*.pkg.tar.zst

カスタムパッケージの構築

例

# PKGBUILD ファイルをダウンロード
asp exportパッケージ名

# ディレクトリに入ってビルド
cdパッケージ名
makepkg -si

ファイルの所属を調べる

例

# 特定のコマンドを提供するソフトウェアパッケージを探す
pacman -Qo $(whichコマンド名)

# 例えば、vim コマンドがどのパッケージに属するかを調べる
pacman -Qo $(which vim)

pacman コマンドを習得することで、Arch Linux システム上のすべてのソフトウェアパッケージを効率的に管理できます。pacman は強力なツールであり、誤ったコマンドはシステムに問題を引き起こす可能性があることを覚えておいてください。操作を実行する前に、必ずコマンドの動作を理解してください。
