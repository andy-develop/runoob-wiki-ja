Linux htop コマンド

Linux コマンド大全

htop とは

htop は Linux システム上の対話型プロセスビューアです。従来の top コマンドよりも豊富な機能と使いやすいユーザーインターフェースを提供します。

htop の主な特徴

  • カラー表示: 色分けにより、さまざまなタイプのプロセスやシステム状態を区別します
  • 視覚的なレイアウト: CPU、メモリ、スワップ領域の使用状況を直感的に表示します
  • マウス対応: マウスで直接クリックして操作できます
  • プロセスのツリービュー: プロセスの階層関係を表示できます
  • カスタム並べ替え: さまざまな指標でプロセスを並べ替えられます
  • プロセス操作: プロセスの終了や優先度の調整などを直接行えます

htop のインストール

Debian/Ubuntu ベースのシステムの場合

sudo apt update
sudo apt install htop

RHEL/CentOS ベースのシステムの場合

sudo yum install epel-release  # 先安装 EPEL 仓库
sudo yum install htop

Arch Linux ベースのシステムの場合

sudo pacman -S htop

htop 基本インターフェースの解説

htop を起動するには、ターミナルで次のように入力するだけです：

htop

インターフェースは主に以下の部分に分かれています：

  1. 上部エリア: システム概要情報

    • CPU使用率（コアごとに表示）
    • メモリ使用状況
    • スワップ領域の使用状況
    • システム稼働時間と平均負荷

  2. 中央エリア: プロセスリスト

    • PID: プロセスID
    • USER: プロセスの所有者
    • PRI: プロセスの優先度
    • NI: nice 値
    • VIRT: 仮想メモリ使用量
    • RES: 物理メモリ使用量
    • SHR: 共有メモリサイズ
    • S: プロセスの状態（実行中、スリープなど）
    • CPU%: CPU使用率
    • MEM%: メモリ使用率
    • TIME+: CPU時間
    • COMMAND: コマンド名

  3. 下部エリア: ファンクションキーのヒント

htop 高度な機能

1. プロセスのツリービュー

按 F5 或 tプロセスのツリービューに切り替えて、プロセス間の親子関係を表示できます。

2. プロセスのフィルタリング

按 F4 或 \フィルタ条件を入力して、条件に一致するプロセスのみを表示できます。

3. 複数選択操作

スペースキーで複数のプロセスをマークした後、一括操作（終了など）ができます。

4. 表示のカスタマイズ

按 F2設定メニューに入ると、次のことができます：

  • 表示する列を調整する
  • カラーテーマを変更する
  • 更新間隔を設定する
  • その他の表示オプションを設定する

5. システムモニタリング

htop の上部エリアには、豊富なシステム監視情報が表示されます：

  • CPU使用率（コアごと）
  • メモリとスワップ領域の使用状況
  • システムの平均負荷

htop と top コマンドの比較

特性 htop top
インターフェース カラーで直感的 モノクロで基本的
マウス対応 是 否
プロセスのツリービュー 対応 非対応
並べ替え方法 多種多様で動的に調整可能 限定的
プロセス操作 より豊富 基本的
カスタマイズ 高度に設定可能 限定的
リソース使用量 やや高い 低い

実践的な使用例

例1: CPU使用率が高いプロセスを検索して終了する

  1. htop を起動
  2. 按 PCPU使用率で並べ替える
  3. 対象のプロセスを見つける
  4. 按 F9終了シグナルを選択する（通常は 15 SIGTERM を選択）
  5. Enter キーを押して確認

例2: 特定ユーザーのプロセスを監視する

  1. htop を起動
  2. 按 u 键
  3. 監視するユーザー名を選択
  4. そのユーザーのプロセスのみを表示

例3: 更新間隔を設定する

  1. 按 F2設定に入る
  2. "Display options" を選択
  3. "Delay" の値（秒）を変更
  4. 按 F10保存して終了

よくある質問と回答

Q1: htop と top はどちらが良いですか？

htop はより豊富な機能と使いやすいインターフェースを提供し、対話的な使用に適しています。top はより軽量で、スクリプトでの使用に適しています。

Q2: 一部のプロセスが緑色/赤色で表示されるのはなぜですか？

緑色は通常、正常に動作しているプロセスを示し、赤色は高いリソース使用率またはゾンビプロセスを示す可能性があります。

Q3: 完全なコマンドラインを表示するにはどうすればよいですか？

按 F2設定に入り、"Display options" で "Show program path" オプションを調整します。

Q4: htop が表示するメモリ情報はどういう意味ですか？

  • VIRT: プロセスが使用する仮想メモリの総量
  • RES: プロセスが使用する物理メモリ
  • SHR: プロセスが使用する共有メモリ
