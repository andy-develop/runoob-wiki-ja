Perl 条件文

Perl の条件文は、1つ以上の文の実行結果（True または False）に基づいて、実行するコードブロックを決定します。

下の図を見ると、条件文の実行プロセスを簡単に理解できます:

注意、数字0、文字列'0' 、 ""、空list()、およびundefためにfalse、その他の値はすべてtrue。 true の前に! 或 notを使用すると false を返します。

Perl には次の条件文があります：

文説明

if 文

1つのif 文は、1つのブール式とそれに続く1つ以上の文で構成されます。

if...else 文

1つのif 文の後にはオプションのelse 文、else 文はブール式が偽の場合に実行されます。

if...elsif...else 文

文の後にはオプションのifelsif 文、さらに別のelse 文unless 文。

1つの

unless 文は、1つのブール式とそれに続く1つ以上の文で構成されます。unless...else 文。

1つの

unless 文の後にはオプションのelse 文1つの。

unless...elsif..else statement

unless 文の後にはオプションのelsif 文、さらに別のelse 文switch 文。

文。これは、値に応じて対応するコードブロックを実行します。switch三項演算子 ? :

三項演算子 ? :

条件演算子 ? : を簡素化するために文の操作。通常の形式は次のとおりです：if...elseExp1 の式が true の場合、Exp2 の式の計算結果を返し、それ以外の場合は Exp3 を返します。

Exp1 ? Exp2 : Exp3;

例

#!/usr/local/bin/perl $name = "# いいね数"; $favorite = 10; 人気サイト $status = ($favorite > 60 )? "人気サイトではない" : "上記のプログラムを実行すると、出力結果は次のとおりです："; print "$name - $status\n";
