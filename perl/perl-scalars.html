Perl スカラー

スカラーは単純なデータユニットです。

スカラーは整数、浮動小数点数、文字、文字列、段落、または完全なWebページです。

以下の例では、スカラーの簡単な適用を示しています。

例

#!/usr/bin/perl $age = 20; # 整数の代入 $name = "Runoob"; # 文字列 $salary = 130.50; # 浮動小数点数 print "Age = $age\n"; print "Name = $name\n"; print "Salary = $salary\n";

上記のプログラムを実行すると、出力結果は次のようになります。

Age = 20
Name = Runoob
Salary = 130.5

数値スカラー

スカラーは通常、数値または文字列です。以下の例では、さまざまな種類の数値スカラーの使用を示しています。

例

#!/usr/bin/perl $integer = 200; $negative = -300; $floating = 200.340; $bigfloat = -1.2E-23; # 8進数 377 、10進数は 255 $octal = 0377; # 16進数 FF、10進数は 255 $hexa = 0xff; print "integer = $integer\n"; print "negative = $negative\n"; print "floating = $floating\n"; print "bigfloat = $bigfloat\n"; print "octal = $octal\n"; print "hexa = $hexa\n";

上記のプログラムを実行すると、出力結果は次のようになります。

integer = 200
negative = -300
floating = 200.34
bigfloat = -1.2e-23
octal = 255
hexa = 255

文字列スカラー

以下の例では、さまざまな種類の文字列スカラーの使用を示しています。シングルクォートとダブルクォートの使用上の違いに注意してください。

例

#!/usr/bin/perl $var = "文字列スカラー - 菜鸟教程!"; $quote = '私はシングルクォートの中にいます - $var'; $double = "私はダブルクォートの中にいます -$var"; $escape = "エスケープ文字の使用 -\tHello, World!"; print "var = $var\n"; print "quote = $quote\n"; print "double = $double\n"; print "escape = $escape\n";

上記のプログラムを実行すると、出力結果は次のようになります。

var = 字符串标量 - 菜鸟教程!
quote = 我在单引号内 - $var
double = 我在双引号内 - 字符串标量 - 菜鸟教程!
escape = 转义字符使用 -    Hello, World!

スカラー演算

以下の例では、スカラーの簡単な演算を示しています。

例

#!/usr/bin/perl $str = "hello" . "world"; # 文字列連結 $num = 5 + 10; # 2つの数値の加算 $mul = 4 * 5; # 2つの数値の乗算 $mix = $str . $num; # 文字列と数値の連結 print "str = $str\n"; print "num = $num\n"; print "mix = $mix\n";

上記のプログラムを実行すると、出力結果は次のようになります。

str = helloworld
num = 15
mix = helloworld15

複数行文字列

例

#!/usr/bin/perl $string = '菜鸟教程 —— 学ぶのは技術だけではなく、夢でもある！'; print "$string\n";

上記のプログラムを実行すると、出力結果は次のようになります。

特殊文字

以下では、Perl の特殊文字の応用を示します。__FILE__, __LINE__, __PACKAGE__ はそれぞれ、現在実行中のスクリプトのファイル名、行番号、パッケージ名を表します。

注意： __はアンダースコア2本です。__FILE__前後にそれぞれアンダースコア2本が付きます。

これらの特殊文字は独立したマーカーであり、文字列の中に書くことはできません。例：

例

#!/usr/bin/perl print "ファイル名". __FILE__ . "\n"; print "行番号" . __LINE__ ."\n"; print "パッケージ名" . __PACKAGE__ ."\n"; # 解析できません print "__FILE__ __LINE__ __PACKAGE__\n";

上記のプログラムを実行すると、出力結果は次のようになります。

文件名 test.pl
行号 4
包名 main
__FILE__ __LINE__ __PACKAGE__

v 文字列

v で始まり、その後にピリオドで区切られた1つ以上の整数が続くものは、文字列リテラルとして扱われます。

各文字の数値を直接指定したい場合、v-文字列は "\x{1}\x{14}\x{12c}\x{fa0}" のような理解しにくい方法よりも、明確にそのような文字列を構築する方法を提供します。次の例を見てみましょう。

例

#!/usr/bin/perl $smile = v9786; $foo = v102.111.111; $martin = v77.97.114.116.105.110; print "smile = $smile\n"; print "foo = $foo\n"; print "martin = $martin\n";

上記のプログラムを実行すると、出力結果は次のようになります。

Wide character in print at test.pl line 7.
smile = &#x263a;
foo = foo
martin = Martin
