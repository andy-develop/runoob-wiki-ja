Perl 特殊変数

Perl言語ではいくつかの特殊変数が定義されており、通常は $, @, または % をプレフィックスとして持ちます。例：$_。

多くの特殊変数には長い英語名があり、オペレーティングシステム変数 $! は $OS_ERROR と書くことができます。

英語名の特殊変数を使用したい場合は、プログラムの先頭に追加する必要がありますuse English;。これにより、説明的な英語の特殊変数を使用できます。

最もよく使われる特殊変数は $_ で、この変数はデフォルトの入力とパターンマッチングの内容を保持します。例は以下の通りです：

例

#!/usr/bin/perl foreach ('Google','Runoob','Taobao') { print $_; print "\n"; }

上記のプログラムを実行すると、出力結果は次のようになります：

Google
Runoob
Taobao

次の例では、$_ を使用せずに内容を出力します：

例

#!/usr/bin/perl foreach ('Google','Runoob','Taobao') { print; print "\n"; }

上記のプログラムを実行すると、出力結果は次のようになります：

Google
Runoob
Taobao

この例では、最初に "Google" を出力し、次に "Runoob" を出力し、最後に "Taobao" を出力します。

反復ループでは、現在のループの文字列が $_ に格納され、print で出力されます。また、print は出力変数を指定しない場合、デフォルトで $_ を使用します。

以下は、明示的に書かなくても Perl が $_ を使用すると見なす場所です：

  • さまざまな単項関数（ord() や int() などの関数を含む）、および "-t" を除くすべてのファイルテスト演算子 ("-f"、"-d")。 "-t" はデフォルトで STDIN を操作します。
  • さまざまなリスト関数、例えば print() や unlink()。
  • "=~" 演算子を使用しない場合のパターンマッチ操作 "m//"、"s///"、"tr///"。
  • 他の変数が指定されていない場合、"foreach" ループのデフォルトの反復変数です。
  • grep() と map() 関数の暗黙の反復変数。
  • "while" の条件が単一で、その条件が <> 操作の結果をテストする場合、$_ は入力レコードを格納するデフォルトの場所になります。このようなことは "while" のテスト条件以外では発生しません。（記憶の助け：アンダースコアは特定の操作では省略できます。）

特殊変数の種類

特殊変数の使用上の性質に応じて、以下のように分類できます：

  • グローバルスカラ特殊変数。

  • グローバル配列特殊変数。

  • グローバルハッシュ特殊変数。

  • グローバル特殊ファイルハンドル。

  • グローバル特殊定数。

  • 正規表現特殊変数。

  • ファイルハンドル特殊変数。

    Perlで .ini 形式の設定ファイルを読み込む Config::IniFiles

    Perl スクリプトに設定すべきパラメータが多すぎる場合、コマンドライン引数を使用する方法は適切ではありません。設定ファイルを使用してこれらのパラメータを設定できます。ちょうど Config::IniFiles モジュールが .ini 形式の設定ファイルの解析を提供してくれます。.ini重要なのは、Python などの他の言語にも .ini.ini形式の設定ファイルを解析するパッケージがあることです。したがって、この方法を使用すると、プログラムの汎用性が高まります。

    Config::IniFiles

    まず .ini 形式の設定ファイルの形式を見てみましょう：

    [section]          #参数模块
Parameter=Value    #该模块某参数的值。配置文件使用'#'或者';'注释

    使用方法：

    use Config::IniFiles; #加载模块
my $cfg = new Config::IniFiles( -file => "/path/configfile.ini" ); #读取配置文件
my $value = $cfg->val('Section', 'Parameter'); #读取参数

    より便利な読み取り方法：

    my %ini
tie %ini, 'Config::IniFiles', ( -file => "/path/configfile.ini" );
#该方法把参数读进了二维哈希（引用的引用），即$ini{Section}{Parameter}

    詳細な使用方法は以下を参照してください：http://search.cpan.org/~wadg/Config-IniFiles-2.38/IniFiles.pm
