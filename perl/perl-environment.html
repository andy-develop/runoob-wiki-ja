Perl 环境安装 → Perl環境のインストール

在我们开始学习 Perl 语言前，我们需要先安装 Perl 的执行环境。 → Perl言語の学習を始める前に、Perlの実行環境をインストールする必要があります。

Perl 可以在以下平台下运行： → Perlは以下のプラットフォームで実行できます：

  • Unix (Solaris, Linux, FreeBSD, AIX, HP/UX, SunOS, IRIX etc.)
  • Win 9x/NT/2000/
  • WinCE
  • Macintosh (PPC, 68K)
  • Solaris (x86, SPARC)
  • OpenVMS
  • Alpha (7.2 and later)
  • Symbian
  • Debian GNU/kFreeBSD
  • MirOS BSD
  • 等等... → など...

很多系统平台上已经默认安装了 perl，我们可以通过以下命令来查看是否已安装： → 多くのシステムプラットフォームにはPerlがデフォルトでインストールされています。以下のコマンドでインストールされているかどうかを確認できます：

$ perl -v

This is perl 5, version 18, subversion 2 (v5.18.2) built for darwin-thread-multi-2level
(with 2 registered patches, see perl -V for more detail)

Copyright 1987-2013, Larry Wall
……

如果输出以上信息说明已安装，如果还未安装，可以看接下来的安装指导。 → 上記の情報が出力されればインストール済みです。まだインストールされていない場合は、以下のインストールガイドを参照してください。

安装 Perl → Perlのインストール

我们可以在 Perl 的官网下载对应平台的安装包: → Perlの公式サイトから対応するプラットフォームのインストールパッケージをダウンロードできます：https://www.perl.org/get.html

Unix 和 Linux 安装 Perl → UnixおよびLinuxへのPerlのインストール

Unix/Linux 系统上 Perl 安装步骤如下： → Unix/LinuxシステムでのPerlのインストール手順は次のとおりです：

  • 通过浏览器打开 → ブラウザで開くhttp://www.perl.org/get.html。

  • 下载适用于 Unix/Linux 的源码包。 → Unix/Linux用のソースパッケージをダウンロードします。

  • 下载 → ダウンロードしたperl-5.x.y.tar.gz文件后执行以下操作。 → ファイルの後、以下の操作を実行します。

    $ tar -xzf perl-5.x.y.tar.gz
$ cd perl-5.x.y
$ ./Configure -de
$ make
$ make test
$ make install

接下来我们如果 → 次に、以下のコマンドでperl -v命令查看是否安装成功。 → コマンドでインストールが成功したかどうかを確認します。

安装成功后，Perl 的安装路径为 → インストールが成功すると、Perlのインストールパスは/usr/local/bin，库安装在 → 、ライブラリは/usr/local/lib/perlXX, XX 为版本号。 → 、XXはバージョン番号です。

Window 安装 Perl → WindowsへのPerlのインストール

Perl 在 Window 平台上有 ActiveStatePerl 和 Strawberry Perl 编译器。 → Windowsプラットフォームには、ActiveStatePerlとStrawberry Perlコンパイラがあります。

ActiveState Perl和 Strawberry Perl最大的区别是 Strawberry Perl 里面有多包含一些 CPAN 里的模块， 所以Strawberry Perl 下载的安装文件有 80多M, 而ActiveState Perl 只有20M 左右。 → ActiveState PerlとStrawberry Perlの最大の違いは、Strawberry PerlにはCPANのモジュールが多く含まれていることです。そのため、Strawberry Perlのインストールファイルは80MB以上ありますが、ActiveState Perlは約20MBしかありません。

我们这里使用了 Strawberry Perl 。 → ここではStrawberry Perlを使用します。

Window 系统上 Perl 安装步骤如下： → WindowsシステムでのPerlのインストール手順は次のとおりです：

  • Strawberry 安装包链接： → Strawberryインストールパッケージのリンク：http://strawberryperl.com。

  • 下载对应你系统的版本： 32bit 或 64bit 。 → お使いのシステムに合わせて、32bitまたは64bitのバージョンをダウンロードします。

  • 下载后双击打开，按安装向导一步步安装即可。 → ダウンロード後、ダブルクリックして開き、インストールウィザードに従って順にインストールするだけです。

Mac OS 安装 Perl → Mac OSへのPerlのインストール

Mac OS 系统一般默认已经安装了 Perl，如果未安装则执行以下步骤： → Mac OSシステムには通常デフォルトでPerlがインストールされています。インストールされていない場合は、次の手順を実行します：

  • 通过浏览器打开 → ブラウザで開くhttp://www.perl.org/get.html。

  • 下载适用于 Mac OS 的源码包。 → Mac OS用のソースパッケージをダウンロードします。

  • 下载 → ダウンロードしたperl-5.x.y.tar.gz文件后执行以下操作。 → ファイルの後、以下の操作を実行します。

    $ tar -xzf perl-5.x.y.tar.gz
$ cd perl-5.x.y
$ ./Configure -de
$ make
$ make test
$ make install

执行成功后 Perl 的安装路径为 → 実行が成功すると、Perlのインストールパスは/usr/local/bin，库安装在 → 、ライブラリは/usr/local/lib/perlXX, XX 为版本号。 → 、XXはバージョン番号です。

运行 Perl → Perlの実行

Perl 有不同的执行方式。 → Perlにはさまざまな実行方法があります。

1、対話式

我们可以在命令行中直接执行 perl 代码，语法格式如下： → コマンドラインで直接perlコードを実行できます。構文形式は次のとおりです：

$perl  -e <perl code>           # Unix/Linux

或 

C:>perl -e <perl code>          # Windows/DOS

命令行参数如下所示： → コマンドラインのパラメータは次のとおりです：

选项 → オプション説明
-d[:debugger]在调试模式下运行程序 → デバッグモードでプログラムを実行
-Idirectory指定 @INC/#include 目录 → @INC/#includeディレクトリを指定
-T

允许污染检测 → 汚染チェックを許可

-t允许污染警告 → 汚染警告を許可
-U允许不安全操作 → 安全でない操作を許可
-w允许很多有用的警告 → 多くの有用な警告を許可
-W允许所有警告 → すべての警告を許可
-X禁用使用警告 → すべての警告を無効化
-e program执行 perl 代码 → perlコードを実行
file执行 perl 脚本文件 → perlスクリプトファイルを実行

2、脚本执行 → 2、スクリプト実行

我们可以将 perl 代码放在脚本文件中，通过以下命令来执行文件代码： → perlコードをスクリプトファイルに記述し、以下のコマンドでファイルのコードを実行できます：

$perl  script.pl          # Unix/Linux

或 

C:>perl script.pl         # Windows/DOS

集成开发环境(IDE:Integrated Development Environment) → 統合開発環境（IDE：Integrated Development Environment）

我们也可以在一些图形用户界面(GUI) 环境上执行 perl 脚本。以下推荐两款常用的 Perl 集成开发环境： → グラフィカルユーザーインターフェース（GUI）環境でもperlスクリプトを実行できます。以下に、よく使われる2つのPerl統合開発環境を紹介します：

  • Padre：Padre 是一个为 Perl 语言开发者提供的集成开发环境，提供了语法高亮和代码重构功能。 → ：PadreはPerl言語開発者向けの統合開発環境で、構文ハイライトとコードリファクタリング機能を提供します。

  • EPIC: EPIC 是 Perl Eclipse IDE 的插件，如果你熟悉 Eclipse，你可以使用它。 → ：EPICはPerl Eclipse IDEのプラグインです。Eclipseを使い慣れていれば、それを利用できます。

    安装步骤：Help-->Eclipse Marketplace-->输入EPIC--> 选择安装并更新即可。 → インストール手順：Help→Eclipse Marketplace→EPICと入力→インストールを選択して更新するだけです。
