Perl サブルーチン(関数)

Perl サブルーチン（subroutine）とは、ユーザー定義の関数です。

Perl サブルーチンとは、特定のタスクを実行するための独立したコードの一節で、コードの重複を減らし、プログラムを読みやすくします。

Perl サブルーチンは、一連の操作や計算をカプセル化したコードブロックであり、プログラム内で繰り返し呼び出して再利用することができます。

Perl サブルーチンはプログラムをモジュール化するのに役立ち、コードをより理解しやすく、保守しやすく、再利用しやすくします。

Perl サブルーチンはプログラムのどこにでも置くことができます。構文は次のとおりです：

sub subroutine{
   statements;
}

サブルーチン呼び出しの構文：

subroutine( 参数列表 );

Perl 5.0 以前のバージョンでサブルーチンを呼び出す方法は次のとおりです：

&subroutine( 参数列表 );

新しいバージョンでは、この呼び出し方法もサポートされていますが、推奨されません。

次に、簡単な例を見てみましょう：

例

#!/usr/bin/perl # 函数定义 sub Hello{ print "Hello, World!\n"; } # 函数调用 Hello();

上記のプログラムを実行すると、出力結果は次のとおりです：

Hello, World!

サブルーチンにパラメータを渡す

Perl サブルーチンは他のプログラミングと同様に複数のパラメータを受け取ることができ、サブルーチンのパラメータは特別な配列 @_ で示されます。

したがって、サブルーチンの最初のパラメータは $_

パラメータがスカラー型であれ配列型であれ、ユーザーがサブルーチンにパラメータを渡すとき、Perlはデフォルトで参照渡しで呼び出します。

例

#!/usr/bin/perl # 定义求平均值函数 # 获取所有传入的参数 $n; print '传入的参数为 : ',"@_\n"; # 打印整个数组 print "第一个参数值为 : $_ sub Average{ 上記のプログラムを実行すると、出力結果は次のとおりです： $n = scalar(@_); $sum = 0; foreach $item (@_){ $sum += $item; } $average = $sum /ユーザーは @_ 配列の値を変更することで、対応する実際の引数の値を変更できます。

心绪留香 my と local の違い

    内部 -> 外部：

      mrl***w@163.com

    112

    （1）my と local はどちらも1つのブロック内でのみ有効で、外に出ると無効になります；

    （2）ただし、local の変数は、このブロック内で呼び出されるサブルーチンの中では引き続き存在できます；

    • （3）外部と同じ名前の変数がある場合、どちらもブロックを退出した後は外部の同名変数に影響を与えません；
    • 外部 -> 内部：
    • （3）もし外界と同名の変数がある場合、両者はblockを退出した後も外界の同名の変数に影響を与えません；

    外部 -> 内部：

    （1）外部で設定された my、local、デフォルトはすべてブロック内で有効ですが、同名の変数が外部で my の場合、block 内で local とすることはできません。両方とも block 内で呼び出されるサブルーチン内で有効になり、競合するからです。

    （2）ある block 内に my で修飾された変数と外部の変数が同名で、さらにその block 内で外部の変数を使用する必要がある場合、2つの方法があります。

    • 最初の方法は、main の package でその変数名を修飾することです。$main::global。
    • 2番目の方法は、our で修飾することです。our $globalそうすれば、その block 内で以降に出現するすべての $global は外部の global になります。

    （3）スクリプトを作成する際は、スコープに注意して、外部が内部に影響を与えないようにしてください。
