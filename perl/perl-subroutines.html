Perl サブルーチン(関数)

Perl サブルーチン（subroutine）とは、ユーザー定義の関数です。

Perl サブルーチンとは、特定のタスクを実行するための独立したコードの一節で、コードの重複を減らし、プログラムを読みやすくします。

Perl サブルーチンは、一連の操作や計算をカプセル化したコードブロックであり、プログラム内で繰り返し呼び出して再利用することができます。

Perl サブルーチンはプログラムをモジュール化するのに役立ち、コードをより理解しやすく、保守しやすく、再利用しやすくします。

Perl サブルーチンはプログラムのどこにでも置くことができます。構文は次のとおりです：

sub subroutine{
   statements;
}

サブルーチン呼び出しの構文：

subroutine( 参数列表 );

Perl 5.0 以前のバージョンでサブルーチンを呼び出す方法は次のとおりです：

&subroutine( 参数列表 );

新しいバージョンでは、この呼び出し方法もサポートされていますが、推奨されません。

次に、簡単な例を見てみましょう：

例

#!/usr/bin/perl # 函数定义 sub Hello{ print "Hello, World!\n"; } # 函数调用 Hello();

上記のプログラムを実行すると、出力結果は次のとおりです：

Hello, World!

サブルーチンにパラメータを渡す

Perl サブルーチンは他のプログラミングと同様に複数のパラメータを受け取ることができ、サブルーチンのパラメータは特別な配列 @_ で示されます。

したがって、サブルーチンの最初のパラメータは $_

パラメータがスカラー型であれ配列型であれ、ユーザーがサブルーチンにパラメータを渡すとき、Perlはデフォルトで参照渡しで呼び出します。

例

#!/usr/bin/perl # 平均値を求める関数を定義する # 渡されたすべてのパラメータを取得する $n; print '渡されたパラメータは : ',"@_\n"; # 配列全体を出力する print "最初のパラメータの値は : $_ sub Average{ 上記のプログラムを実行すると、出力結果は次のとおりです： $n = scalar(@_); $sum = 0; foreach $item (@_){ $sum += $item; } $average = $sum /ユーザーは @_ 配列の値を変更することで、対応する実際の引数の値を変更できます。

サブルーチンのプライベート変数

演算子を使用して設定できます。

演算子は、レキシカルスコープの変数を作成するために使用されます。これによりmy作成された変数は、宣言された場所から閉じたスコープの終わりまで存続します。

my閉じたスコープとは、一対の波括弧の中の領域、ファイル、または if, while, for, foreach, eval 文字列を指します。my次の例では、1つ以上のプライベート変数を宣言する方法を示します：

例

# グローバル変数

sub somefunc {
   my $variable; # $variable 在方法 somefunc() 外不可见
   my ($another, @an_array, %a_hash); #  同时声明多个变量
}

例

#!/usr/bin/perl # PrintHello 関数のプライベート変数 $string = "Hello, World!"; 函数内字符串： sub PrintHello{ # 调用函数 my $string; $string = "Hello, Runoob!"; print "函数外字符串：$string\n"; } 上記のプログラムを実行すると、出力結果は次のとおりです： PrintHello(); print "変数の一時代入$string\n";

local を使用してグローバル変数に一時的な値を提供し、スコープを終了したときに元の値を戻すことができます。
