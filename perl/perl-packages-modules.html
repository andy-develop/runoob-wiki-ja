Perl パッケージとモジュール

Perl では、各パッケージが独立したシンボルテーブルを持ちます。定義構文は次のとおりです：

package mypack;

このステートメントは、mypackという名前のパッケージを定義します。この後で定義されるすべての変数とサブルーチンの名前は、別のpackageステートメントに遭遇するまで、そのパッケージに関連付けられたシンボルテーブルに格納されます。

各シンボルテーブルは独自の変数とサブルーチン名のセットを持ち、各グループの名前は互いに関連しません。そのため、異なるパッケージで同じ変数名を使用できますが、それらは異なる変数を表します。

あるパッケージから別のパッケージの変数にアクセスするには、「パッケージ名 + ダブルコロン( :: ) + 変数名」の方法で指定できます。

変数とサブルーチンの名前を格納するデフォルトのシンボルテーブルは、mainという名前のパッケージに関連付けられています。プログラム内で他のパッケージを定義した場合、デフォルトのシンボルテーブルに戻したいときは、main パッケージを再指定できます： 
package main;

これにより、以降のプログラムはパッケージを定義したことがなかったかのように、変数とサブルーチンの名前が通常どおり格納されます。

以下の例では、ファイルには main パッケージと Foo パッケージがあります。特別な変数__PACKAGE__はパッケージ名を出力するために使用されます：

例

#!/usr/bin/perl # main パッケージ $i = 1; print "パッケージ名 :" , __PACKAGE__ , " $i\n"; package Foo; # Foo パッケージ $i = 10; print "パッケージ名 :" , __PACKAGE__ , " $i\n"; package main; # main パッケージを再指定 $i = 100; print "パッケージ名 :" , __PACKAGE__ , " $i\n"; print "パッケージ名:" , __PACKAGE__ , " $Foo::i\n"; 1;

上記のプログラムを実行すると、出力結果は次のとおりです：

包名 : main 1
包名 : Foo 10
包名 : main 100
包名: main 10

BEGIN と END モジュール

Perl 言語には、BEGIN と END という2つのキーワードがあります。これらはそれぞれ一連のスクリプトを含むことができ、プログラム本体の実行前または実行後に実行されます。

構文形式は次のとおりです：

BEGIN { ... }
END { ... }
BEGIN { ... }
END { ... }

  • 各BEGINモジュールは、Perl スクリプトがロードおよびコンパイルされた後、他のステートメントが実行される前に実行されます。

  • ステートメントブロックは、インタープリタが終了する前に実行されます。ENDステートメントブロックは、Perl モジュールを作成する際に特に役立ちます。

  • BEGINとENDまだあまり理解できていない場合は、例を見てみましょう：

例

@EXPORT = qw(bar blat);  # 默认导出的符号

sub bar { print "Hello $_[0]\n" }
sub blat { print "World $_[0]\n" }
sub splat { print "Not $_[0]\n" }  # Not exported!

ファイル内にある場合、次のコマンドを使用します：Person.pm上記のプログラムを実行すると、次のように出力されます：

$ h2xs -AX -n Person

Person ディレクトリ内には、新しく追加されたディレクトリとファイルの説明があります：

Writing Person/lib/Person.pm
Writing Person/Makefile.PL
Writing Person/README
Writing Person/t/Person.t
Writing Person/Changes
Writing Person/MANIFEST

README ：このファイルには、インストール情報、モジュールの依存関係、著作権情報などが含まれています。

  • Changes ：このファイルは、プロジェクトの変更ログ（changelog）ファイルとして機能します。

  • Makefile.PL ：これは標準の Perl Makefile コンストラクタです。このモジュールをコンパイルするための Makefile.PL ファイルを作成するために使用されます。

  • MANIFEST ：このファイルは、tar.gz タイプのモジュールバージョン配布を自動的に構築するために使用されます。これにより、モジュールを CPAN で公開したり、他の人に配布したりできます。このファイルには、このプロジェクト内のすべてのファイルのリストが含まれています。

  • Person.pm ：これはメインモジュールファイルであり、mod_perl ハンドラコード（handler code）が含まれています。

  • Person.t ：このモジュール用のいくつかのテストスクリプトです。デフォルトではモジュールのロードをチェックするだけで、新しいテストユニットを追加できます。

  • t/ ：テストファイル

  • lib/ ：実際のソースコードを格納するディレクトリ

  • tar（Linux 上）コマンドを使用して、上記のディレクトリを Person.tar.gz にパッケージ化できます。

Perl モジュールのインストール

Perl モジュールのインストール

ファイルを解凍してインストールできます。実行手順は次のとおりです：Person.tar.gzまず "perl Makefile.PL" を実行して、カレントディレクトリに Makefile を生成します；

tar xvfz Person.tar.gz
cd Person
perl Makefile.PL
make
make install

次に "make" を実行してコンパイルし、必要なライブラリファイルを作成します；

その後、"make test" でコンパイル結果が正しいかどうかをテストします；最後に "make install" を実行してライブラリファイルをシステムディレクトリにインストールします。これでコンパイルプロセス全体が終了します。
