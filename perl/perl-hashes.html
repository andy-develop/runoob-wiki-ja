Perl ハッシュ

ハッシュはkey/valueペアの集合です。

Perlではハッシュ変数はパーセント記号（%）で始まります。

ハッシュ要素へのアクセス形式：${key}。

以下は簡単なハッシュの例です：

例

#!/usr/bin/perl %data = ('google', 'google.com', 'runoob', 'runoob.com', 'taobao', 'taobao.com'); print "\$data{'google'} = $data{'google'}\n"; print "\$data{'runoob'} = $data{'runoob'}\n"; print "\$data{'taobao'} = $data{'taobao'}\n";

ハッシュの作成

ハッシュの作成は次の2つの方法で行えます：

1. 各キーに値を設定する

$data{'google'} = 'google.com';
$data{'runoob'} = 'runoob.com';
$data{'taobao'} = 'taobao.com';

2. リストを介して設定する

リストの最初の要素がキー、2番目が値になります。

%data = ('google', 'google.com', 'runoob', 'runoob.com', 'taobao', 'taobao.com');

また、以下の記号を使用して=>キー/値を設定することもできます：

%data = ('google'=>'google.com', 'runoob'=>'runoob.com', 'taobao'=>'taobao.com');

以下の例は上記の例の変種で、-を引用符の代わりに使用します：

%data = (-google=>'google.com', -runoob=>'runoob.com', -taobao=>'taobao.com');

この方法ではキーにスペースを含めることはできません。要素の読み取り方法は次のとおりです：

$val = $data{-google}
$val = $data{-runoob}

ハッシュ要素へのアクセス

ハッシュ要素へのアクセス形式：${key}、例は次のとおりです：

例

#!/usr/bin/perl %data = ('google'=>'google.com', 'runoob'=>'runoob.com', 'taobao'=>'taobao.com'); print "\$data{'google'} = $data{'google'}\n"; print "\$data{'runoob'} = $data{'runoob'}\n"; print "\$data{'taobao'} = $data{'taobao'}\n";

上記のプログラムを実行すると、出力結果は次のようになります：

ハッシュ値の読み取り

配列と同じようにハッシュから値を抽出できます。

ハッシュ値を配列に抽出する構文形式：@{key1,key2}。

例

#!/uer/bin/perl %data = (-taobao => 45, -google => 30, -runoob => 40); @array = @data{-taobao, -runoob}; print "Array : @array\n";

上記のプログラムを実行すると、出力結果は次のようになります：

Array : 45 40

ハッシュのキーと値の読み取り

すべてのキーの読み取り

私たちは次の関数を使って、keysハッシュのすべてのキーを読み取ることができます。構文形式は次のとおりです：

keys %HASH

この関数は、すべてのハッシュのすべてのキーの配列を返します。

例

#!/usr/bin/perl %data = ('google'=>'google.com', 'runoob'=>'runoob.com', 'taobao'=>'taobao.com'); @names = keys %data; print "$names[0]\n"; print "$names[1]\n"; print "$names[2]\n";

上記のプログラムを実行すると、出力結果は次のようになります：

taobao
google
runoob

同様に、次の関数を使って、valuesハッシュのすべての値を読み取ることができます。構文形式は次のとおりです：

values %HASH

この関数は、すべてのハッシュのすべての値の配列を返します。

例

#!/usr/bin/perl %data = ('google'=>'google.com', 'runoob'=>'runoob.com', 'taobao'=>'taobao.com'); @urls = values %data; print "$urls[0]\n"; print "$urls[1]\n"; print "$urls[2]\n";

上記のプログラムを実行すると、出力結果は次のようになります：

taobao.com
runoob.com
google.com

要素が存在するかどうかの確認

ハッシュ内に存在しないキー/値ペアを読み取ると、undefined値が返され、実行時に警告が表示されます。

この事態を回避するには、exists関数を使用してキーが存在するかどうかを判断し、存在する場合に読み取ります：

例

#!/usr/bin/perl %data = ('google'=>'google.com', 'runoob'=>'runoob.com', 'taobao'=>'taobao.com'); if( exists($data{'facebook'} ) ){ print "facebook のURLは$data{'facebook'} \n"; } else { print "facebook キーは存在しません\n"; }

上記のプログラムを実行すると、出力結果は次のようになります：

facebook 键不存在

上記のコードでは、IF...ELSEステートメントを使用しています。後の章で詳しく説明します。

ハッシュサイズの取得

ハッシュサイズは要素の数です。まずキーまたは値のすべての要素の配列を取得し、その配列の要素数を計算することで、ハッシュのサイズを取得できます。例は次のとおりです：

例

#!/usr/bin/perl %data = ('google'=>'google.com', 'runoob'=>'runoob.com', 'taobao'=>'taobao.com'); @keys = keys %data; $size = @keys; print "1 - ハッシュサイズ:$size\n"; @values = values %data; $size = @values; print "2 - ハッシュサイズ:$size\n";

上記のプログラムを実行すると、出力結果は次のようになります：

1 - 哈希大小: 3
2 - 哈希大小: 3

ハッシュへの要素の追加または削除

キー/値ペアの追加は簡単な代入で行えます。ただし、ハッシュ要素の削除には、delete関数を使用する必要があります：

例

#!/usr/bin/perl %data = ('google'=>'google.com', 'runoob'=>'runoob.com', 'taobao'=>'taobao.com'); @keys = keys %data; $size = @keys; print "1 - ハッシュサイズ:$size\n"; # 要素を追加 $data{'facebook'} = 'facebook.com'; @keys = keys %data; $size = @keys; print "2 - ハッシュサイズ:$size\n"; # ハッシュ内の要素を削除 delete $data{'taobao'}; @keys = keys %data; $size = @keys; print "3 - ハッシュサイズ:$size\n";

上記のプログラムを実行すると、出力結果は次のようになります：

1 - 哈希大小: 3
2 - 哈希大小: 4
3 - 哈希大小: 3

ハッシュの反復処理

foreach と while を使用してハッシュを反復処理できます：

例 - foreach を使用

#!/usr/bin/perl %data = ('google'=>'google.com', 'runoob'=>'runoob.com', 'taobao'=>'taobao.com'); foreach $key (keys %data){ print "$data{$key}\n"; }

例 - while を使用

#!/usr/bin/perl %data = ('google'=>'google.com', 'runoob'=>'runoob.com', 'taobao'=>'taobao.com'); while(($key, $value) = each(%data)){ print "$data{$key}\n"; }

上記のプログラムを実行すると、出力結果は次のようになります：

runoob.com
google.com
taobao.com
