ASP.NET Web Forms - ArrayList オブジェクト

ArrayList オブジェクトは、単一のデータ値を含む項目のコレクションです。

試してみる - サンプル

ArrayList DropDownList

ArrayList RadioButtonList

ArrayList を作成する

ArrayList オブジェクトは、単一のデータ値を含む項目のコレクションです。

Add() メソッドを使用して ArrayList に項目を追加します。

次のコードは、mycountries という名前の ArrayList オブジェクトを作成し、4 つの項目を追加します：

<script runat="server">
Sub Page_Load
if Not Page.IsPostBack then
dim mycountries=New ArrayList
mycountries.Add("Norway")
mycountries.Add("Sweden")
mycountries.Add("France")
mycountries.Add("Italy")
end if
end sub
</script>

デフォルトでは、ArrayList オブジェクトには 16 個のエントリが含まれます。TrimToSize() メソッドを使用すると、ArrayList を最終サイズに調整できます：

<script runat="server">
Sub Page_Load
if Not Page.IsPostBack then
dim mycountries=New ArrayList
mycountries.Add("Norway")
mycountries.Add("Sweden")
mycountries.Add("France")
mycountries.Add("Italy")
mycountries.TrimToSize()
end if
end sub
</script>

Sort() メソッドを使用すると、ArrayList はアルファベット順または数字順に並べ替えることもできます：

<script runat="server">
Sub Page_Load
if Not Page.IsPostBack then
dim mycountries=New ArrayList
mycountries.Add("Norway")
mycountries.Add("Sweden")
mycountries.Add("France")
mycountries.Add("Italy")
mycountries.TrimToSize()
mycountries.Sort()
end if
end sub
</script>

逆順に並べ替えるには、Sort() メソッドの後に Reverse() メソッドを適用します：

<script runat="server">
Sub Page_Load
if Not Page.IsPostBack then
dim mycountries=New ArrayList
mycountries.Add("Norway")
mycountries.Add("Sweden")
mycountries.Add("France")
mycountries.Add("Italy")
mycountries.TrimToSize()
mycountries.Sort()
mycountries.Reverse()
end if
end sub
</script>

ArrayList へのデータバインド

ArrayList オブジェクトは、次のコントロールに対してテキストと値を自動的に生成できます：

  • asp:RadioButtonList
  • asp:CheckBoxList
  • asp:DropDownList
  • asp:Listbox

RadioButtonList コントロールにデータをバインドするには、まず .aspx ページに RadioButtonList コントロール（asp:ListItem 要素なし）を作成します：

<html>
<body>

<form runat="server">
<asp:RadioButtonList id="rb" runat="server" />
</form>

</body>
</html>

次に、リストを作成するスクリプトを追加し、リスト内の値を RadioButtonList コントロールにバインドします：

サンプル

<script runat="server">
Sub Page_Load
if Not Page.IsPostBack then
dim mycountries=New ArrayList
mycountries.Add("Norway")
mycountries.Add("Sweden")
mycountries.Add("France")
mycountries.Add("Italy")
mycountries.TrimToSize()
mycountries.Sort()
rb.DataSource=mycountries
rb.DataBind()
end if
end sub
</script>

<html>
<body>

<form runat="server">
<asp:RadioButtonList id="rb" runat="server" />
</form>

</body>
</html>

デモ »

RadioButtonList コントロールの DataSource プロパティは ArrayList に設定され、この RadioButtonList コントロールのデータソースを定義します。RadioButtonList コントロールの DataBind() メソッドは、RadioButtonList コントロールをデータソースにバインドします。

注記：データ値は、コントロールの Text および Value プロパティとして使用されます。Text とは異なる Value を追加する場合は、Hashtable オブジェクトまたは SortedList オブジェクトを使用してください。
