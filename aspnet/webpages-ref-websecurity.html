ASP.NET Web Pages - WebSecurity オブジェクト

描述

WebSecurity オブジェクトASP.NET Web Pages アプリケーションのセキュリティと認証を提供します。

WebSecurity オブジェクトを使用して、ユーザーアカウントの作成、ユーザーのログインとログアウト、パスワードのリセットまたは変更、その他のセキュリティ関連機能を実行できます。

WebSecurity オブジェクトリファレンスマニュアル - プロパティ

属性 描述
CurrentUserId 現在ログインしているユーザーの ID を取得します。
CurrentUserName 現在ログインしているユーザーの名前を取得します。
HasUserId 現在ユーザー ID がある場合は、true を返します。
IsAuthenticated 現在のユーザーがログインしている場合は、true を返します。

GeneratePasswordResetToken() パスワードリセットトークンを生成します。これは電子メールでユーザーに送信でき、ユーザーがパスワードをリセットできるようにするためのものです。
GetCreateDate() 指定したメンバーの作成日時を取得します。

GetUserId() ユーザー名からユーザー ID を取得します。

IsConfirmed() ユーザーが確認済みかどうかを確認します。確認済みの場合は true を返します。（例えば、電子メールで確認できます。）

WebSecurity データベースを初期化する

コード内で WebSecurity オブジェクトを使用したい場合は、まず WebSecurity データベースを作成または初期化する必要があります。

Web ルートディレクトリの下に、次の名前のものを作成します。_AppStart.cshtmlのページ（既に存在する場合は、そのページを直接編集します）。

以下のコードをファイルにコピーします：

_AppStart.cshtml

@{
WebSecurity.InitializeDatabaseConnection("Users", "UserProfile", "UserId", "Email", true);
}

上記のコードは、Web サイト（アプリケーション）が起動するたびに実行されます。これは WebSecurity データベースを初期化します。

"Users"WebSecurity データベース（Users.sdf）の名前です。

"UserProfile"ユーザープロファイル情報を含むデータベーステーブルの名前です。

"UserId"ユーザー ID（主キー）を含む列の名前です。

"Email"ユーザー名を含む列の名前です。

最後のパラメータtrueユーザープロファイルテーブルとメンバーシップテーブルが存在しない場合にテーブルを自動的に作成するかどうかを示すブール値です。テーブルを自動的に作成したくない場合は、パラメータを次のように設定してください。false。

虽然trueデータベースを自動的に作成することを示します表ただし、データベースは自動的に作成されません。そのため、データベースは存在している必要があります。

シンプルなメンバーシップ設定

WebSecurity オブジェクトを使用する際に、サイトが ASP.NET Web Pages メンバーシップシステムを使用するように構成されていない場合SimpleMembership、エラーが発生する可能性があります。

ホスティングサービスプロバイダーのサーバーの構成がローカルサーバーの構成と異なる場合も、エラーが発生する可能性があります。この問題を解決するには、Web サイトの Web.config ファイルに次の要素を追加してください。

<appSettings>
<add key="enableSimpleMembership" value="true" />
</appSettings>
