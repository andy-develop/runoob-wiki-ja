ASP.NET ListItem控件

Web 服务器控件

定義と用法

ListItem コントロールは、リスト内の項目を作成できます。

このコントロールは、次のリスト コントロールと一緒に使用されます。<asp:ListBox>、 <asp:RadioButtonList>と<asp:BulletedList>。

语法

<asp:ListItem
Enabled="True|False"
Selected="True|False"
Text="label"
Value="value" />

属性

属性 描述 .NET
Attributes オプション。このクラスで直接サポートされない ListItem の属性名と値のペアのコレクション。 1.0
Enabled オプション。項目を無効にするか有効にするかを指定します。 2.0
Selected オプションです。この項目を選択するかどうかを指定します。 1.0
Text オプション。ListItem に表示されるテキスト。 1.0
Value オプション。ListItem の値。 1.0

Webコントロールの標準プロパティ

AccessKey, Attributes, BackColor, BorderColor, BorderStyle, BorderWidth, CssClass, Enabled, Font, EnableTheming, ForeColor, Height, IsEnabled, SkinID, Style, TabIndex, ToolTip, Width

コントロールの標準プロパティ

AppRelativeTemplateSourceDirectory, BindingContainer, ClientID, Controls, EnableTheming, EnableViewState, ID, NamingContainer, Page, Parent, Site, TemplateControl, TemplateSourceDirectory, UniqueID, Visible

表示されるリスト項目のテキストは、Text または Value プロパティ、および inner HTML テキストを使用して設定できます。

实例

<asp:ListItem Value="Text1" Text="Text2">Text3</asp:ListItem>

ヒントと注釈

注释：Text プロパティと Value プロパティはどちらも既定値が空文字列であるため、リスト コントロールには空のリスト項目が含まれる可能性があります。
