ASP.NET ヘルパー - オブジェクトリファレンスマニュアル

Analytics オブジェクトリファレンスマニュアル（Google）

Helper 描述
Analytics.GetGoogleHtml(webPropertyId) 指定された ID に対して Google Analytics JavaScript コードを表示します。
Analytics.GetStatCounterHtml(project, security) 指定したプロジェクトに StatCounter Analytics JavaScript コードをレンダリングします。
Analytics.GetYahooHtml(account) 指定したアカウントに Yahoo Analytics JavaScript コードをレンダリングします。

Bing オブジェクトリファレンスマニュアル

Helper 描述
Bing.SearchBox([boxWidth]) Bing に検索を渡します。Bing.SiteUrl と Bing.SiteTitle プロパティを設定して、サイト検索と検索ボックスのタイトルを指定できます。通常は_AppStartページがこれらのプロパティを設定します。
Bing.AdvancedSearchBox([, boxWidth] [, resultWidth] [, resultHeight]
[, themeColor] [, locale])		 Bing の検索結果をオプションの形式でページに表示します。Bing.SiteUrl と Bing.SiteTitle プロパティを設定して、サイト検索と検索ボックスのタイトルを指定できます。通常は_AppStartページがこれらのプロパティを設定します。

Chart オブジェクトリファレンスマニュアル

Helper 描述
Chart(width, height [, template] [, templatePath]) グラフを初期化します。
Chart.AddLegend([title] [, name]) グラフに凡例を追加します。
Chart.AddSeries([name] [, chartType] [, chartArea]
[, axisLabel] [, legend] [, markerStep] [, xValue]
[, xField] [, yValues] [, yFields] [, options]) 		グラフにデータ系列を追加します。

Crypto オブジェクトリファレンスマニュアル

Helper 描述
Crypto.Hash(string [, algorithm])
Crypto.Hash(bytes [, algorithm])		 指定されたデータのハッシュを返します。デフォルトのアルゴリズムは sha256 です。

Json オブジェクトリファレンスマニュアル

ModelState オブジェクトリファレンスマニュアル

Helper 描述
ModelStateDictionary.AddError(key, errorMessage) エラーメッセージをフォームフィールドに関連付けます。ModelState ヘルパーを使用してメンバーにアクセスします。
ModelStateDictionary.AddFormError(errorMessage) エラーメッセージとフォームを関連付けます。ModelState ヘルパーを使用してメンバーにアクセスします。
ModelStateDictionary.IsValid 検証エラーがない場合は true を返します。ModelState ヘルパーを使用してメンバーにアクセスします。

Recaptcha オブジェクトリファレンスマニュアル

Helper 描述
Recaptcha.GetHtml([, publicKey] [, theme] [, language] [, tabIndex]) reCAPTCHA 検証テストをレンダリングします。
ReCaptcha.PublicKey
ReCaptcha.PrivateKey		 reCAPTCHA サービスの公開鍵と秘密鍵を設定します。通常は_AppStartページがこれらのプロパティを設定します。
ReCaptcha.Validate([, privateKey]) reCAPTCHA テスト結果を返します。
ServerInfo.GetHtml() Renders: ASP.NET Web Pages の状態情報をレンダリングします。

Video オブジェクトリファレンスマニュアル

Helper 描述
Video.Flash(filename [, width, height]) 指定されたファイルに対して、幅と高さをオプションとする Flash ビデオプレーヤーを表示します。

WebCache オブジェクトリファレンスマニュアル

Helper 描述
WebCache.Get(key) 通过key指定されたオブジェクトを返します。オブジェクトが見つからない場合は null を返します。
WebCache.Remove(key) 通过keyキャッシュから指定されたオブジェクトを削除します。
WebCache.Set(key, value [, minutesToCache] [, slidingExpiration]) 通过keyをvalue指定された名前のキャッシュに格納します。

WebGrid オブジェクトリファレンスマニュアル

WebGrid.GetHtml() Renders markup: HTML テーブルにデータを表示します。
WebGrid.Pager() WebGrid オブジェクトのページを表示します。

WebImage オブジェクトリファレンスマニュアル

Helper 描述
WebImage(path) 指定されたパスから画像を読み込みます。
WebImage.AddImagesWatermark(image) 指定した画像に透かしを追加します。
WebImage.AddTextWatermark(text) 画像に指定されたテキストを追加します。
WebImage.FlipHorizontal()
WebImage.FlipVertical()		 水平/垂直翻转图像
WebImage.GetImageFromRequest() 画像がファイルアップロードページに送信されると、画像を読み込みます。
WebImage.Resize(width, height) 画像のサイズを変更します。
WebImage.RotateLeft()
WebImage.RotateRight()		 画像を左または右に回転します。
WebImage.Save(path [, imageFormat]) 画像を指定されたパスに保存します。
