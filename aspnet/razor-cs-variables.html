ASP.NET Razor - C# 变量

変数は、データを格納するための名前付きエンティティです。

变量

変数はデータを格納するために使用されます。

変数名は英字で始まる必要があり、スペースや予約文字を含めることはできません。

変数は、格納するデータの型を表す指定された型にすることができます。string 変数は文字列値（"Welcome to RUNOOB.COM"）を格納し、integer 変数は数値（103）を格納し、date 変数は日付値を格納します。などです。

変数は var キーワードを使用して宣言するか、型を指定して宣言します（型を宣言したい場合）。ただし、ASP.NET は通常、データ型を自動的に決定できます。

实例

// Using the var keyword:
var greeting = "Welcome to RUNOOB.COM";
var counter = 103;
var today = DateTime.Today;

// Using data types:
string greeting = "Welcome to RUNOOB.COM";
int counter = 103;
DateTime today = DateTime.Today;

データ型の変換

あるデータ型から別のデータ型への変換は、役立つ場合があります。

最も一般的な例は、文字列入力を整数や日付などの別の型に変換することです。

一般的な規則として、ユーザー入力は、たとえ数字を入力した場合でも、文字列として扱われます。したがって、数値入力は計算に使用する前に数値に変換する必要があります。

以下に一般的に使用される変換方法を示します：

方法 描述 实例
AsInt()
IsInt()		 文字列を整数に変換する。 if (myString.IsInt())
{myInt=myString.AsInt();}
AsFloat()
IsFloat()		 文字列を浮動小数点数に変換します。 if (myString.IsFloat())
{myFloat=myString.AsFloat();}
AsDecimal()
IsDecimal()		 文字列を10進数に変換します。 if (myString.IsDecimal())
{myDec=myString.AsDecimal();}
AsDateTime()
IsDateTime()		 文字列をASP.NET DateTime型に変換する。 myString="10/10/2012";
myDate=myString.AsDateTime();
AsBool()
IsBool()		 文字列をブール値に変換します。 myString="True";
myBool=myString.AsBool();
ToString() 任意のデータ型を文字列に変換します。 myInt=1234;
