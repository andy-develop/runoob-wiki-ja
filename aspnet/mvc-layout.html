ASP.NET MVC - スタイルとレイアウト


ASP.NET MVC を学ぶために、インターネットアプリケーションを構築します。

パート3: スタイルと統一された外観（レイアウト）の追加。

添加布局

_Layout.cshtml ファイルは、アプリケーション内の各ページのレイアウトを表します。これは、Views フォルダー内の Shared フォルダーにあります。

_Layout.cshtml ファイルを開き、内容を次のように置き換えます：

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8" />
<title>@ViewBag.Title</title>
<link href="@Url.Content("~/Content/Site.css")" rel="stylesheet" type="text/css" />
<script src="@Url.Content("~/Scripts/jquery-1.5.1.min.js")"></script>
<script src="@Url.Content("~/Scripts/modernizr-1.7.min.js")"></script>
</head>
<body>
<ul id="menu">
<li>@Html.ActionLink("Home", "Index", "Home")</li>
<li>@Html.ActionLink("Movies", "Index", "Movies")</li>
<li>@Html.ActionLink("About", "About", "Home")</li>
</ul>
<section id="main">
@RenderBody()
<p>Copyright RUNOOB 2012. All Rights Reserved.</p>
</section>
</body>
</html>

HTML ヘルパー

上記のコードでは、HTML ヘルパーが HTML 出力を変更するために使用されています。

@Url.Content() - URL コンテンツがここに挿入されます。

@Html.ActionLink() - HTML リンクがここに挿入されます。

このチュートリアルの後の章では、HTML ヘルパーについてさらに詳しく学びます。

Razor 语法

上記のコードでは、赤でマークされたコードは Razor 構文を使用した C# です。

@ViewBag.Title - ページタイトルがここに挿入されます。

@RenderBody() - ページコンテンツがここにレンダリングされます。

あなたは私たちのRazor 教程中で C# および VB（Visual Basic）の Razor マークアップに関する知識を学ぶことができます。

_ViewStart 文件

Shared フォルダー（Views フォルダー内にあります）にある _ViewStart ファイルには、次の内容が含まれています：

@{Layout = "~/Views/Shared/_Layout.cshtml";}

このコードは、アプリケーションによって表示されるすべてのビューに自動的に追加されます。

このファイルを削除した場合、すべてのビューにこのコード行を追加する必要があります。

このチュートリアルの後の章では、ビューについてさらに詳しく学びます。
