ASP.NET Razor - C# 逻辑条件

プログラミングロジック：条件に基づいてコードを実行する。

If 条件

C# は条件に基づいてコードを実行できます。

使用if 语句条件を判断します。判断結果に基づいて、if ステートメントは true または false を返します：

  • if ステートメントはコードブロックを開始します
  • 条件は括弧の中に書く
  • 条件が真の場合、波括弧内のコードが実行されます。

实例

@{var price=50;}
<html>
<body>
@if (price>30)
{
<p>The price is too high.</p>
}
</body>
</html>

Else 条件

if文は含むことができるelse 条件。

else 条件は、条件が偽の場合に実行されるコードを定義します。

实例

@{var price=20;}
<html>
<body>
@if (price>30)
{
<p>The price is too high.</p>
}
else
{
<p>The price is OK.</p>
}
</body>
</html>

运行实例 »

注释：上記の例では、最初の条件が真の場合、if ブロックのコードが実行されます。else 条件は、if 条件以外の「その他すべてのケース」をカバーします。

Else If 条件

複数の条件判断には、次を使用できますelse if 条件：

实例

@{var price=25;}
<html>
<body>
@if (price>=30)
{
<p>The price is high.</p>
}
else if (price>20 && price<30)
{
<p>The price is OK.</p>
}
else
{
<p>The price is low.</p>
}
</body>
</html>

运行实例 »

上記の例では、最初の条件が真の場合、if ブロックのコードが実行されます。

最初の条件が真ではなく、2番目の条件が真の場合、else if ブロックのコードが実行されます。

else if 条件の数に制限はありません。

if と else if の条件がすべて真でない場合、最後の else ブロック（条件なし）が「その他すべての場合」をカバーします。

Switch 条件

switch 块個別の条件をテストするために使用できます：

实例

@{
var weekday=DateTime.Now.DayOfWeek;
var day=weekday.ToString();
var message="";
}
<html>
<body>
@switch(day)
{
case "Monday":
message="This is the first weekday.";
break;
case "Thursday":
message="Only one day before weekend.";
break;
case "Friday":
message="Tomorrow is weekend!";
break;
default:
message="Today is " + day;
break;
}
<p>@message</p>
</body>
</html>

运行实例 »

テスト値（day）は括弧内に記述されます。各テスト条件には、セミコロンで終わる case 値と、break 文で終わる任意の数のコード行があります。テスト値が case 値と一致する場合、対応するコード行が実行されます。

switch ブロックにはデフォルトのケース（default:）があり、指定されたすべてのケースが一致しない場合、「その他すべての場合」をカバーします。
