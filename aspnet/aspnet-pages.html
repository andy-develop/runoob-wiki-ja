ASP.NET Web Forms - HTML ページ

シンプルな ASP.NET ページは、普通の HTML ページのように見えます。

Hello example.com

ASP.NET の学習を始める前に、まずブラウザに「Hello example.com」と表示する簡単な HTML ページを作成しましょう。

Hello example.com!

HTML で書かれた Hello example.com

以下のコードは、この例を HTML ページとして表示します。

<html>
<body bgcolor="yellow">
<center>
<h2>Hello example.com!</h2>
</center>
</body>
</html>

ご自身で試してみたい場合は、上記のコードを「firstpage.htm」という名前のファイルに保存し、そのファイルへのリンクを作成してください：firstpage.htm。

ASP.NET で書かれた Hello example.com

HTML ページを ASP.NET ページに変換する最も簡単な方法は、HTML ファイルを直接コピーし、新しいファイルの拡張子を変更することです。.aspx 。

以下のコードは、この例を ASP.NET ページとして表示します。

<html>
<body bgcolor="yellow">
<center>
<h2>Hello example.com!</h2>
</center>
</body>
</html>

ご自身で試してみたい場合は、上記のコードを「firstpage.aspx」という名前のファイルに保存し、そのファイルへのリンクを作成してください：firstpage.aspx。

どのように動作するのでしょうか？

根本的に、ASP.NET ページは HTML と完全に同じです。

HTML ページの拡張子は .htm です。ブラウザがサーバーに HTML ページをリクエストした場合、サーバーは何も変更せずに、そのページをブラウザに直接送信します。

ASP.NET ページの拡張子は .aspx です。ブラウザがサーバーに ASP.NET ページをリクエストした場合、サーバーは結果をブラウザに送信する前に、ページ内の実行可能コードを処理する必要があります。

上記の ASP.NET ページには実行可能なコードが含まれていないため、何も実行されません。次の例では、静的 HTML ページと動的 ASP ページの違いを示すために、ページに実行可能コードを追加します。

クラシック ASP

Active Server Pages (ASP) は長年にわたって普及しています。ASP を使用すると、HTML ページに実行可能コードを配置できます。

以前の ASP バージョン（ASP.NET より前のもの）は、通常、クラシック ASP と呼ばれます。

ASP.NET はクラシック ASP と完全には互換性がありませんが、少しの変更だけで、ほとんどのクラシック ASP ページは ASP.NET ページとして問題なく動作します。

クラシック ASP についてもっと詳しく学びたい場合は、当サイトのASP チュートリアル。

クラシック ASP で書かれた動的ページ

ASP が動的なコンテンツを含むページをどのように表示するかを示すために、上記の例にいくつかの実行可能コード（赤い文字で示されています）を追加します。

<html>
<body bgcolor="yellow">
<center>
<h2>Hello example.com!</h2>
<p><%Response.Write(now())%></p>
</center>
</body>
</html>

<% --%> タグ内のコードはサーバー上で実行されます。

Response.Write は、HTML 出力ストリームに出力を書き込むために使用される ASP コードです。

Now() は、サーバーの現在の日付と時刻を返す関数です。

ご自身で試してみたい場合は、上記のコードを「dynpage.asp」という名前のファイルに保存し、そのファイルへのリンクを作成してください：dynpage.asp。

ASP.NET で書かれた動的ページ

<html>

<center>
<h2>Hello example.com!</h2>

</center>

</html>
