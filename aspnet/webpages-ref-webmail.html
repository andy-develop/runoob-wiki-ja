ASP.NET Web Pages - WebMail オブジェクト

WebMail オブジェクトを使用すると、Web ページから簡単に電子メールを送信できます。

描述

WebMail オブジェクトASP.NET Web Pages に SMTP（Simple Mail Transfer Protocol、簡易メール転送プロトコル）を使用してメールを送信する機能を提供します。

实例

请查看WebPages Email章の例。

WebMail オブジェクト リファレンス - プロパティ

属性 描述
SmtpServer 電子メールの送信に使用する SMTP サーバーの名前。
SmtpPort サーバーが SMTP 電子メールの送信に使用するポート。
EnableSsl サーバーが SSL（Secure Socket Layer セキュアソケットレイヤー）暗号化を使用する場合、値は true です。
UserName 電子メールの送信に使用する SMTP 電子メール アカウントの名前。
Password SMTP 電子メール アカウントのパスワード。
From 送信者アドレス欄に表示される電子メール（通常は UserName と同じ）。

WebMail オブジェクト リファレンス - メソッド

方法 描述
Send() 送信する電子メール情報を SMTP サーバーに送信します。

Send() メソッドには以下のパラメーターがあります：

参数 类型 描述
to String 宛先（セミコロンで区切る）
subject String 邮件主题
body String 邮件正文

Send() メソッドには、次の省略可能なパラメータがあります。

参数 类型 描述
from String 发件人
cc String カーボンコピー（CC）する電子メール アドレス（セミコロンで区切る）
filesToAttach Collection 附件名
isBodyHtml Boolean メッセージ本文が HTML 形式の場合は true
additionalHeaders Collection 追加のタイトル

名称 值

WebMail ヘルパーを初期化する

WebMail ヘルパーを使用するには、SMTP サーバーにアクセスできなければなりません。SMTP は電子メールの「出力」部分です。仮想ホストを使用している場合、SMTP サーバーの名前を既に知っているかもしれません。会社のネットワークで作業している場合は、会社の IT 部門が名前を提供してくれます。自宅で作業している場合は、通常の電子メールサービスプロバイダーを使用できるかもしれません。

電子メールを送信するには、次のものが必要です。

  • SMTP サーバーの名前
  • ポート番号（通常は 25）
  • 電子メールのユーザー名
  • 電子メールのパスワード

Web ルートディレクトリの下に、次の名前で作成します。_AppStart.cshtmlのページ（既に存在する場合は、そのページを直接編集します）。

以下のコードをファイルにコピーします：

_AppStart.cshtml

@{
WebMail.SmtpServer = "smtp.example.com";
WebMail.SmtpPort = 25;
WebMail.EnableSsl = false;
WebMail.UserName = "support@example.com";
WebMail.Password = "password";
WebMail.From = "john@example.com"
}

上記のコードは、ウェブサイト（アプリケーション）が起動するたびに実行されます。それは...WebMail オブジェクト初期値を割り当てました。

请替换：

将 smtp.example.com電子メールの送信に使用する SMTP サーバーの名前に置き換えます。

将 25サーバーが SMTP トランザクション（電子メール）の送信に使用するポート番号に置き換えます。

サーバーが SSL（Secure Socket Layer）暗号化を使用する場合は、falsetrue に置き換えます。

将 support@example.com電子メールの送信に使用する SMTP 電子メール アカウントの名前に置き換えます。

将 passwordSMTP 電子メール アカウントのパスワードに置き換えます。

将 john@example 送信者アドレス欄に表示される電子メールに置き換えます。

AppStart ファイルでは、開始する必要はありませんWebMail オブジェクト、ただし、呼び出し時にはWebMail.Send()メソッドの前に、これらのプロパティを設定する必要があります。
