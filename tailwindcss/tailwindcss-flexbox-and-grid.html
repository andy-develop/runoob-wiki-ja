Tailwind CSS と Flexbox および Grid レイアウト

Tailwind CSS は、特に Flexbox と Grid のレイアウトを管理するための強力なユーティリティクラスを提供しています。

Flexbox と Grid のこれらのユーティリティクラスにより、カスタム CSS を書くことなく、レスポンシブで柔軟なレイアウトを非常に効率的に作成できます。

Tailwind CSS の理念は、低レベルのユーティリティクラス（utility-first）でレイアウトを制御し、クラスを柔軟に組み合わせてさまざまなデザイン要件を満たすことです。

1、Flexbox レイアウト

Flexbox は、開発者が一次元（水平または垂直）のレイアウトを作成するのに役立つレイアウトモードです。

Tailwind CSS は、方向、整列、伸縮など、Flexbox レイアウトのさまざまな側面を制御するための簡潔なユーティリティクラスを多数提供しています。

Flex コンテナの設定

Flexbox レイアウトを作成するには、まず要素を flex コンテナに設定する必要があります。

例

<div class="flex">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>

Flex の方向

flex-direction は主軸の方向（つまり Flex コンテナ内のアイテムが並ぶ方向）を制御します。

Tailwind は方向を設定するための以下のユーティリティクラスを提供しています：

  • flex-row: デフォルト値で、子アイテムは水平方向に左から右へ並びます。
  • flex-row-reverse: 子アイテムは水平方向に右から左へ並びます。
  • flex-col: 子アイテムは垂直方向に上から下へ並びます。
  • flex-col-reverse: 子アイテムは垂直方向に下から上へ並びます。

例

<div class="flex flex-row ...">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>

<div class="flex flex-row-reverse ...">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>

<div class="flex flex-col ...">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>

Flex ラップ（Flex Wrap）

デフォルトでは、Flexbox コンテナ内のアイテムは単一の行に配置されます。

それらを折り返したい場合は、flex-wrap ユーティリティクラスを使用できます。

  • flex-wrap: アイテムの折り返しを許可します。
  • flex-nowrap: アイテムの折り返しを禁止します。
  • flex-wrap-reverse: 逆方向に折り返します。

例

<div class="flex flex-nowrap">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>

<div class="flex flex-wrap">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>

<div class="flex flex-wrap-reverse">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>

Flexbox は、利用可能なスペースに応じて要素のサイズを伸縮させることを可能にします。

Tailwind CSS は伸縮を制御するための以下のユーティリティクラスを提供しています：

Tailwind クラス名CSS プロパティと値説明
flex-1flex: 1 1 0%;flex アイテムに等量の flex 成長と収縮の能力を持たせ、基本サイズを 0% にします。等幅または等しい高さの flex レイアウトを作成するためによく使用されます。
flex-autoflex: 1 1 auto;flex アイテムに自動の基本サイズと等量の flex 成長・収縮の能力を持たせます。flex アイテムに余分なスペースを埋めさせるためによく使用されます。

flex-noneflex: none;flex アイテムの拡大や縮小を防ぎ、基本サイズを維持します。固定要素のサイズによく使用されます。

整列と分布

Flexbox と同様に、Grid にも整列と分布のオプションが用意されています。

justify-content プロパティは、コンテナ内の子要素を主軸（水平方向）に沿って整列させるために使用されます。

Tailwind クラス名CSS プロパティと値説明
justify-normaljustify-content: normal;デフォルトの整列方法を使用します。通常は次と同等です：start。
justify-startjustify-content: flex-start;すべての子要素をコンテナの先頭側に移動します。水平レイアウトでは、子要素は左揃えになります。
justify-endjustify-content: flex-end;すべての子要素をコンテナの末尾側に移動します。水平レイアウトでは、子要素は右揃えになります。
justify-centerjustify-content: center;すべての子要素を中央揃えにします。
justify-betweenjustify-content: space-between;子要素の間のスペースを均等に分配します。両端には空白を残しません。
justify-aroundjustify-content: space-around;子要素の間のスペースを均等に分配します。両端には半分のスペースを残します。
justify-evenlyjustify-content: space-evenly;子要素の間のスペースを、両端の空白も含めて完全に均等にします。
justify-stretchjustify-content: stretch;子要素はコンテナを埋めるように引き伸ばされ、各子要素が同じスペースを占めます。

例

<div class="flex justify-start ...">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>

その他の整列設定：

  • justify-items: グリッドセルの内容の整列方法を制御します。
  • justify-self: 単一のグリッドアイテムの整列方法を制御します。
  • align-items: グリッドセルの垂直方向の整列方法を制御します。
  • align-self: 単一のグリッドアイテムの垂直方向の整列方法を制御します。

例

<div class="grid justify-items-start ...">
  <div>01</div>
  <div>02</div>
  <div>03</div>
  <div>04</div>
  <div>05</div>
  <div>06</div>
</div>
