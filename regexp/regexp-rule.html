正規表現マッチングルール

基本パターンマッチング

すべては最も基本的なところから始まります。パターンは、正規表現の最も基本的な要素であり、文字列の特徴を記述する一連の文字です。パターンは単純で、普通の文字列から構成されることもありますが、非常に複雑で、特殊な文字を使って文字の範囲や繰り返し、または文脈を表すこともよくあります。例えば：

^once

このパターンには特殊な文字が含まれています^これは、そのパターンが次で始まる文字列のみにマッチすることを示しますonceで始まる文字列です。例えば、このパターンは文字列"once upon a time"にマッチし、"There once was a man from NewYork"にはマッチしません。ちょうど^記号が先頭を表すのと同じように、$記号は、指定されたパターンで終わる文字列にマッチするために使われます。

bucket$

このパターンは"Who kept all of this cash in a bucket"にマッチし、"buckets"にはマッチしません。文字^と$を同時に使用すると、完全一致（文字列とパターンが同じ）を意味します。例えば：

^bucket$

文字列"bucket"のみにマッチします。パターンが^と$を含まない場合、そのパターンを含む任意の文字列にマッチします。例えばパターン：

once

は文字列

There once was a man from NewYork
Who kept all of his cash in a bucket.

にマッチします。

このパターン内の文字(o-n-c-e)はリテラル文字です。つまり、それらはその文字自体を表し、数字も同様です。他のもう少し複雑な文字、例えば句読点や空白文字（スペース、タブなど）は、エスケープシーケンスを使う必要があります。すべてのエスケープシーケンスはバックスラッシュ\で始まります。タブのエスケープシーケンスは\tです。したがって、文字列がタブで始まるかどうかを調べるには、次のパターンを使うことができます：

^\t

同様に、\nを表し、「改行」，\rキャリッジリターンを表します。その他の特殊記号は、前にバックスラッシュを付けることで表せます。例えば、バックスラッシュ自体は\\で表し、句点は. 用 \.で表します。という具合です。

文字クラス

INTERNET のプログラムでは、正規表現は通常ユーザーの入力を検証するために使われます。ユーザーが FORM を送信した後、入力された電話番号、住所、EMAIL アドレス、クレジットカード番号などが有効かどうかを判断するには、通常のリテラルベースの文字では不十分です。

そのため、より自由にパターンを記述する方法が必要です。それが文字クラスです。すべての母音文字を表す文字クラスを作るには、すべての母音文字を角かっこ内に入れます：

[AaEeIiOoUu]

このパターンは任意の母音文字にマッチしますが、1文字だけを表せます。ハイフンを使うと文字の範囲を表せます。例えば：

[a-z] // 匹配所有的小写字母 
[A-Z] // 匹配所有的大写字母 
[a-zA-Z] // 匹配所有的字母 
[0-9] // 匹配所有的数字 
[0-9\.\-] // 匹配所有的数字，句号和减号 
[ \f\r\t\n] // 匹配所有的白字符

同様に、これらも1文字だけを表します。これは非常に重要です。1つの小文字と1つの数字からなる文字列（例："z2"、"t6"、"g7"）にマッチさせたいが、"ab2"、"r2d3"、"b52" にはマッチさせたくない場合は、次のパターンを使います：

^[a-z][0-9]$

たとえ[a-z]26文字の範囲を表しますが、ここでは最初の文字が小文字である文字列にのみマッチします。

前に^は文字列の先頭を表すと述べましたが、それにはもう1つの意味があります。角かっこのセット内で使用する場合、^それは「非」または「除外」を意味し、特定の文字を除外するためによく使われます。先ほどの例で、最初の文字が数字であってはならない場合を考えます：

^[^0-9][0-9]$

このパターンは "&5"、"g7"、"-2" にはマッチしますが、"12"、"66" にはマッチしません。以下は特定の文字を除外する例です：

[^a-z] //除了小写字母以外的所有字符 
[^\\\/\^] //除了(\)(/)(^)之外的所有字符 
[^\"\'] //除了双引号(")和单引号(')之外的所有字符

特殊文字.（点、句点）は正規表現において「改行」以外のすべての文字を表すために使われます。したがって、パターン^.5$は、任意の2文字で、数字の5で終わり、かつ他の「改行」以外の文字で始まる文字列にマッチします。パターン.は任意の文字列にマッチします改行文字（\n、\r）を除く。

PHP の正規表現には、いくつかの組み込みの汎用文字クラスがあります。一覧は次のとおりです：

文字クラス 説明
[[:alpha:]] 任意の英字
[[:digit:]] 任意の数字
[[:alnum:]] 任意の英数字
[[:space:]] 任意の空白文字
[[:upper:]] 任意の大文字
[[:lower:]] 任意の小文字
[[:punct:]] 任意の句読点
[[:xdigit:]] 任意の16進数の数字、[0-9a-fA-F] に相当

繰り返しの指定

これまでに、1つの文字や数字にマッチさせる方法を学びましたが、多くの場合、単語や数字のグループにマッチさせる必要があります。単語は複数の文字で構成され、数字のグループは複数の数字で構成されます。文字または文字クラスの後に続く波かっこ（{}）は、その前の内容が繰り返し出現する回数を指定します。

文字クラス 説明
^[a-zA-Z_]$ すべての英字とアンダースコア
^[[:alpha:]]{3}$ すべての3文字の単語
^a$ 文字 a
^a{4}$ aaaa
^a{2,4}$ aa、aaa、または aaaa
^a{1,3}$ a、aa、または aaa
^a{2,}$ 2つ以上の a を含む文字列
^a{2,} 例：aardvark と aaab は該当しますが、apple は該当しません
a{2,} 例：baad と aaa は該当しますが、Nantucket は該当しません
\t{2} 2つのタブ文字
.{2} すべての2文字の文字列

これらの例は、波かっこの3つの異なる使い方を示しています。1つの数字{x} の意味は前の文字または文字クラスが x 回だけ出現することです；1つの数字とカンマ{x,}の意味は前の内容が x 回以上出現することです；カンマで区切られた2つの数字{x,y}は前の内容が少なくとも x 回、ただし y 回を超えて出現しないことです。パターンをより多くの単語や数字に拡張できます：

^[a-zA-Z0-9_]{1,}$      // 所有包含一个以上的字母、数字或下划线的字符串 
^[1-9][0-9]{0,}$        // 所有的正整数 
^\-{0,1}[0-9]{1,}$      // 所有的整数 
^[-]?[0-9]+\.?[0-9]+$   // 所有的浮点数

最後の例は分かりにくいですね？こう見てください：省略可能なマイナス記号（[-]?）で始まり（^）、1つ以上の数字が続き（[0-9]+）、小数点（\.）に続いて1つ以上の数字([0-9]+）、そして後ろに他のものが何もない（$）。次に、使えるもっと簡単な方法を紹介します。

特殊文字?と{0,1}は同じで、どちらも次を表します：前の内容が0個または1個 或 前の内容は省略可能。したがって、先ほどの例は次のように簡略化できます：

^\-?[0-9]{1,}\.?[0-9]{1,}$

特殊文字*と{0,}は同じで、どちらも次のことを表します前の内容が0個以上。最後に、文字+と{1,}は同じで、次のことを表します前の内容が1個以上。したがって、上記の4つの例は次のように書けます：

^[a-zA-Z0-9_]+$      // 所有包含一个以上的字母、数字或下划线的字符串 
^[1-9][0-9]*$        // 所有的正整数 
^\-?[0-9]+$          // 所有的整数 
^[-]?[0-9]+(\.[0-9]+)?$ // 所有的浮点数

もちろん、これによって正規表現の複雑さが技術的に減るわけではありませんが、読みやすくすることはできます。

    正規表現における [] と () の違い

    丸かっこ()はグループであり、主に複数選択構造の範囲の制限、グループ化、テキストのキャプチャ、ルックアラウンド、特殊パターン処理に適用されます。

    例：

    • 1、(abc|bcd|cde)：この部分が abc、bcd、cde のいずれかであることを示し、順序も一致している必要があります。
    • 2、(abc)?：このグループは一緒に出現するか、まったく出現しないかのどちらかであり、出現する場合はこのグループ内の順序で出現します。
    • 3、(?:abc)：このような abc のグループを見つけますが、記録せず、$ 変数に保存しません。そうでなければ、$x を使って何番目のかっこにマッチした項目を取得できます。例えば：(aaa)(bbb)(ccc)(?:ddd)(eee) の場合、$1 で (aaa) にマッチした内容を取得でき、$3 で (ccc) にマッチした内容を取得でき、$4 で (eee) にマッチした内容を取得できます。その前の括弧のペアは変数を保存しないためです。
    • 4、a(?=bbb)：順序ルックアラウンド。a の後ろに3つの連続する b が続かなければならないことを示します。
    • 5、(?i:xxxx)：大文字と小文字を区別しない (?s:.*) 複数行マッチング。キャリッジリターン文字にマッチできます。

    角かっこ[]単一マッチであり、文字セット/除外文字セット/名前付き文字セットです。

    例：

    • 1、[0-3]：その位置にある文字は0から3までの4つの数字のみであることを示します。(abc|bcd|cde) と似た働きですが、丸括弧は複数の連続する文字にマッチできますが、一組の角括弧は単一文字のみにマッチできます。
    • 2、[^0-3]：その位置にある文字は、0から3以外のすべての文字のみであることを示します。

    () と [] は本質的に異なります。

    ()() 内の内容はサブ式を表し、() 自体は何にもマッチせず、何も制限せず、括弧内の内容を同じ式として扱うだけです。例えば (ab){1,3} は、ab が連続して最低1回、最大3回出現することを表します。括弧がない場合、ab{1,3} は a と、その直後に続く b が最低1回、最大3回出現することを表します。また、括弧はマッチングパターンにおいても重要です。これ以上は掘り下げませんが、興味があれば自分で調べてみてください。

    []マッチする文字が [] 内にあり、1回だけ出現でき、特殊文字は [] 内に書くと通常の文字としてマッチされます。例えば [(a)] は、(、a、)、の3つの文字にマッチします。

    したがって()、[]作用も表す意味も、雲泥の差があります。
