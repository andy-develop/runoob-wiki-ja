Zig環境のインストール

Zigプログラミング言語の開発環境を設定する際には、Zigコンパイラをインストールし、関連する開発ツールを設定する必要があります。

以下は、異なるオペレーティングシステム上でZigを設定する手順です：

パッケージマネージャーを使用してインストールする

Windows

Zig は Chocolatey で利用できます：

choco install zig

Windows (winget)

winget install zig.zig

Windows (scoop)：

scoop install zig

MacOS

Homebrew 安装：

brew install zig

Linux

Ubuntu (snap)

安定版のインストール：

snap install zig --classic --beta

Fedora:

dnf install zig

FreeBSD:

pkg install lang/zig

設定が完了すると、Zigプログラミング言語を使用した開発を開始できます。

源码安装

ソースコードをダウンロードしてコンパイルインストールすることもできます。

Zigソースパッケージのダウンロード先：https://ziglang.org/zh/download/。

ダウンロード後、tarコマンドで解凍します：

tar -xvf zig-macos-aarch64-0.13.0.tar.xz

その後、ソースパッケージに移動して、後続のコンパイルインストールを実行します：

cd zig-macos-aarch64-0.13.0

ZigのGitHubリポジトリからソースコードをクローンすることもできます：

git clone https://github.com/ziglang/zig.git

依赖项

  • cmake >= 3.5
  • gcc >= 7.0.0 或者 clang >= 6.0.0
  • LLVM、Clang、LLD 開発ライブラリ == 18.x、同じバージョンの gcc または clang でコンパイル
    • システムのパッケージマネージャーを使用してインストールするか、ソースコードからビルドできます。

指令

  1. Zigソースディレクトリの下に、buildディレクトリを作成します：

    mkdir build
cd build

  2. 运行 cmake：

    cmake ..

  3. Zigのビルドとインストール：

    make install

请注意CMAKE_PREFIX_PATHこの便利なcmake変数。CMakeはこの位置でLLVMや他の依存関係を優先的に検索します。

これらの手順により生成されますstage3/bin/zig、これはZig自身によって構築されたZigコンパイラです。

macOS + Homebrew

macOS では Homebrew を使用します：

  1. Zigソースディレクトリの下に、buildディレクトリを作成します：

    mkdir build
cd build

  2. cmakeを実行し、静的LLVMを有効にします：

    cmake .. -DZIG_STATIC_LLVM=ON -DCMAKE_PREFIX_PATH="$(brew --prefix llvm@18);$(brew --prefix zstd)"

  3. Zigのビルドとインストール：

    make install

FreeBSD

FreeBSD について：

  1. pkgを使用して必要な依存関係をインストールします：

    sudo pkg install -qyr FreeBSD devel/llvm18 devel/cmake archivers/zstd textproc/libxml2 archivers/lzma

  2. Zigソースディレクトリの下に、buildディレクトリを作成します：

    mkdir build
cd build

  3. cmakeを実行し、静的LLVMを有効にします：

    cmake .. -DZIG_STATIC_LLVM=ON -DCMAKE_PREFIX_PATH="/usr/local/llvm18;/usr/local"

  4. Zigのビルドとインストール：

    make install

これらの手順により、システムにZigコンパイラがインストールされます。
