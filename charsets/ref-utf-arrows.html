UTF-8 矢印（Arrows）

範囲：10進数 8592-8703、16進数 2190-21FF。

これらの文字を HTML で表示するには、次の表の HTML エンティティを使用できます。

文字に HTML エンティティがない場合は、10進数または16進数の参照を使用できます。

例

<p>私は &larr; を表示します<p>
<p>私は &#8592; を表示します<p>
<p>私は &#x2190; を表示します<p>

結果は次のとおりです：

私は ← を表示します
私は ← を表示します
私は ← を表示します
