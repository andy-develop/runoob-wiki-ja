HTML 記号

HTML 文字実体

HTML 記号は標準キーボードには表示されない記号です。例：数学演算子、矢印記号、技術記号、図形など。

これらの記号を HTML ページに追加する場合は、HTML 実体名を使用できます。

実体名がない場合は、実体番号を使用できます。

文字に実体名がない場合は、10進数（または16進数）の参照を使用できます。

HTML 実体名または16進数を使用する場合、文字は常に正しく表示されます。
これはページで使用している文字セットとは独立しています！

例

<p>私は &euro; を表示します</p>
<p>私は &#8364; を表示します</p>
<p>私は &#x20AC; を表示します</p>

結果は次のとおりです：

私は € を表示します
私は € を表示します
私は € を表示します
