HTML ASCIIリファレンスマニュアル

ASCII は、インターネット上でコンピュータ間で使用された最初の文字セット（符号化標準）です。

ISO-8859-1（HTML 4.01 ではデフォルト）と UTF-8（HTML5 ではデフォルト）は、どちらも ASCII に基づいて作られています。

ASCII 文字セット

ASCII の正式名称は "American Standard Code for Information Interchange"（アメリカ情報交換標準コード）です。

これは1960年代初頭に、コンピュータや電子機器の標準文字セットとして設計されました。

ASCII は7ビット文字セットであり、128文字を含みます。

0〜9の数字、英語の大文字・小文字（a-z、A-Z）、およびいくつかの特殊文字をサポートします。

現代のコンピュータ、HTML、インターネットで使用される文字セットは、すべて ASCII に基づいています。

次の表は、128文字の ASCII 文字と、それに対応する HTML エンティティ符号化の一覧です。

ASCII デバイス制御文字

ASCII 制御文字（00-31、および127）は、元々プリンタやテープドライブなどのハードウェア機器を制御するために設計されました。

制御文字（水平タブ、改行、復帰を除く）は、HTML ドキュメントでは何の役割も果たしません。
