Highcharts 散布図

この章では、Highcharts の散布図について紹介します。

前の章で Highcharts の設定構文について学びました。次に、Highcharts の他の設定を見ていきましょう。

設定

chart 設定

chart の type を 'scatter' に設定します。chart.type はグラフのタイプを表します。デフォルト値は "line" です。

chart.zoomType 属性はグラフの拡大縮小を設定でき、マウスをドラッグしてズームします。x軸またはy軸に沿って拡大縮小でき、'x'、'y'、'xy' に設定できます。

var chart = {
   type: 'scatter',
   zoomType: 'xy'
};
