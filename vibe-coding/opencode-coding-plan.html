OpenCode Coding Plan

現在、市場には多くの大規模モデルベンダーがあります。海外には Anthropic、OpenAI、Grok、Gemini などがありますが、海外へのアクセスは不便です。国内には DeepSeek、Qwen、ZLM、Minimax などがあります。

Claude Code を使ってコードを書く際、最もお金がかかるのはトークンです。海外へのアクセスは不便で、しかも高額です。国内には今、定額プランがあります。長期利用するなら定額プランの方がお得です。

本記事では、Alibaba Cloud Bailian の Coding Plan を紹介します。これは AI プログラミングツール向けに設計されたサブスクリプションサービスで、千问（Qwen）、GLM、Kimi、MiniMax などのトップ大規模モデルを統合し、主流の AI プログラミングアシスタント（OpenCode、Claude Code、OpenClaw など）に対応しています。固定月額制で、コストは従量課金 API よりはるかに低く、未払いリスクも完全に排除します。

Coding Plan の主な利点：

  • トップモデルをワンクリックで接続：自分で百炼 API を呼び出す必要はなく、使い慣れたプログラミングツールで最強モデルを直接使用できます。
  • コストが非常に低い：固定月額（Lite 月額40元、Pro 月額200元）、初月限定割引はわずか7.9元 / 39.9元。
  • 安全で安心：API 直接接続は禁止で、対話型プログラミングツールのみで使用でき、濫用によるアカウント停止リスクを回避します。
  • 画像理解サポート：qwen3.5-plus、kimi-k2.5 はスクリーンショットやデザイン図をアップロードして直接コードを生成できます。

推奨モデル（公式対応済み）：

  • qwen3.5-plus（画像理解対応、推奨・最優先）
  • kimi-k2.5（画像理解対応）
  • glm-5
  • MiniMax-M2.5

Coding Plan は以下のツールに対応：Cursor、Claude Code、OpenClaw、OpenCode、Cline（VS Code 拡張機能）、Kilo Code / Kilo CLI、Qwen Code、Codex など。

方舟 Coding Planは、開発者向けの AI コーディングサブスクリプションサービスで、効率的な開発を支援します。主な利点は以下のとおりです：

  • モデルが豊富：主流の大規模言語モデルと Embedding モデルに対応し、Doubao、DeepSeek、Kimi、GLM、MiniMax などの人気シリーズをカバーしています。
  • ツール互換性が広い：Claude Code、Cursor、Cline、OpenCode、Codex CLI などの主流 AI コーディングツールに対応。
  • 利用枠の共有：複数ツールでプランの利用枠を共有でき、柔軟に切り替えてさまざまな開発シーンに対応します。
  • プランが柔軟：Lite / Pro の複数プランを提供し、軽度から高強度の開発ニーズに対応します。
  • 安定した高可用性：マルチテナント分離とリソーススケジューリングにより、ピーク時でも安定してスムーズに動作します。

ツールごとに設定する Base URL は、互換プロトコルによって異なります：

  • Anthropic API プロトコル互換ツール：https://ark.cn-beijing.volces.com/api/coding
  • OpenAI API プロトコル互換ツール：https://ark.cn-beijing.volces.com/api/coding/v3

注意：https://ark.cn-beijing.volces.com/api/v3 は使用しないでください。この Base URL は Coding Plan の利用枠を消費せず、追加料金が発生します。

OpenCode を設定

OpenCode 設定ファイルを編集：

  • macOS / Linux：~/.config/opencode/opencode.json
  • Windows：C:\Users\您的用户名\.config\opencode\opencode.json

設定項目を変更

実際の状況に合わせて以下を置き換えてください：

  • <ARK_API_KEY>：API Key を取得
  • model：使用するモデル名に置き換えます

具体的なモデルは次のとおりです：doubao-seed-2.0-code、doubao-seed-2.0-pro、doubao-seed-2.0-lite、doubao-seed-code、minimax-m2.5、glm-4.7、deepseek-v3.2、kimi-k2.5。
