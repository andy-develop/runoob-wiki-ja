7.0 MapReduce プログラミング

カテゴリ Hadoop チュートリアル

MapReduce の使用方法を学んだ後、Word Count のような統計や検索タスクを処理できるようになりましたが、実際には MapReduce でできることはまだまだたくさんあります。

MapReduce は主に開発者がプログラミングを通じて機能を実装するもので、開発者は Map および Reduce に関連するメソッドを実装することでデータ処理を行うことができます。

このプロセスを簡単に示すために、Word Count プログラムを手作業で作成します。

注意：MapReduce は Hadoop のライブラリに依存しますが、このチュートリアルで使用する Hadoop 実行環境は Docker コンテナであり、開発環境の構築が難しいため、実際の開発作業（デバッグを含む）には Hadoop が動作するコンピュータが必要です。ここでは完成済みプログラムのデプロイのみを学習します。

MyWordCount.java ファイルコード

/**
* 引用宣言
* このプログラムは http://hadoop.apache.org/docs/r1.0.4/cn/mapred_tutorial.html から引用しています
 */
package com.サンプル.hadoop;
import java.io.IOException;
import java.util.*;
import org.apache.hadoop.fs.Path;
import org.apache.hadoop.io.*;
import org.apache.hadoop.mapred.*;
/**
* `Map` に関連するメソッド
 */
class Map extends MapReduceBase implements Mapper<LongWritable, Text, Text, IntWritable> {
   private final static IntWritable one = new IntWritable(1);
   private Text word = new Text();
   public void map(LongWritable key,
               Text value,
               OutputCollector<Text, IntWritable> output,
               Reporter reporter)
         throws IOException {
      String line = value.toString();
      StringTokenizer tokenizer = new StringTokenizer(line);
      while (tokenizer.hasMoreTokens()) {
         word.set(tokenizer.nextToken());
         output.collect(word, one);
      }
   }
}
/**
* `Reduce` に関連するメソッド
 */
class Reduce extends MapReduceBase implements Reducer<Text, IntWritable, Text, IntWritable> {
   public void reduce(Text key,
                  Iterator<IntWritable> values,
                  OutputCollector<Text, IntWritable> output,
                  Reporter reporter)
         throws IOException {
      int sum = 0;
      while (values.hasNext()) {
         sum += values.next().get();
      }
      output.collect(key, new IntWritable(sum));
   }
}
public class MyWordCount {
   public static void main(String[] args) throws Exception {
      JobConf conf = new JobConf(MyWordCount.class);
      conf.setJobName("my_word_count");
      conf.setOutputKeyClass(Text.class);
      conf.setOutputValueClass(IntWritable.class);
      conf.setMapperClass(Map.class);
      conf.setCombinerClass(Reduce.class);
      conf.setReducerClass(Reduce.class);
      conf.setInputFormat(TextInputFormat.class);
      conf.setOutputFormat(TextOutputFormat.class);
      // 最初のパラメータは入力を表します
      FileInputFormat.setInputPaths(conf, new Path(args[0]));
      // 2番目のパラメータは出力を表します
      FileOutputFormat.setOutputPath(conf, new Path(args[1]));
      JobClient.runJob(conf);
   }
}

この Java ファイルの内容を NameNode コンテナに保存してください。推奨場所：

/home/hadoop/MyWordCount/com/サンプル/hadoop/MyWordCount.java

注意：現在の状況によっては、一部の Docker 環境にインストールされている JDK が中国語に対応していないため、念のため上記コード内の中国語のコメントを削除してください。

ディレクトリに移動：

cd /home/hadoop/MyWordCount

コンパイル：

javac -classpath ${HADOOP_HOME}/share/hadoop/mapreduce/hadoop-mapreduce-client-core-3.1.4.jar -classpath ${HADOOP_HOME}/share/hadoop/client/hadoop-client-api-3.1.4.jar com/サンプル/hadoop/MyWordCount.java

パッケージ化：

jar -cf my-word-count.jar com

実行：

hadoop jar my-word-count.jar com.サンプル.hadoop.MyWordCount /wordcount/input /wordcount/output2

結果を確認：

hadoop fs -cat /wordcount/output2/part-00000

出力：

I       4
hadoop  2
like    2
love    2
サンプル  2
