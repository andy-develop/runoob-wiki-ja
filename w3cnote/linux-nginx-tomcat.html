LinuxでのNginx+Tomcatの負荷分散と静的/動的分離の設定ポイント

カテゴリ プログラミング技術

この記事で使用するLinuxディストリビューション：CentOS6.7 ダウンロード先：https://wiki.centos.org/Download

一、Nginxのインストール

ダウンロード元：wget http://nginx.org/packages/centos/6/noarch/RPMS/nginx-release-centos-6-0.el6.ngx.noarch.rpm

インストール元：yum install nginx-release-centos-6-0.el6.ngx.noarch.rpm -y（-yパラメータに注意）

Nginxのインストール：yum install nginx

Nginxサービスの起動：service nginx start

Nginxサービスの停止：service nginx stop

Nginxの実行状態の確認：service nginx status

Nginx設定ファイルのチェック：nginx -t

サービス実行中に設定を再読み込み：nginx -s reload

Nginxサービスの自動起動設定：chkconfig nginx on

二、ファイアウォールルールの変更

Nginxが稼働しているホストのファイアウォール設定を変更：vi /etc/sysconfig/iptables を実行し、nginxが使用するポートを許可リストに追加します。

例：-A INPUT -m state --state NEW -m tcp -p tcp --dport 80 -j ACCEPT （80ポートの通過を許可することを示します）

Tomcatが稼働しているホストのファイアウォール設定を変更：vi /etc/sysconfig/iptables を実行し、tomcatが使用するポートを許可リストに追加します。

例：-A INPUT -m state --state NEW -m tcp -p tcp --dport 8080 -j ACCEPT （8080ポートの通過を許可することを示します）

ホスト上に複数のtomcatがある場合は、このルールを複数追加し、対応するポート番号を変更するだけで済みます。

保存後、ファイアウォールを再起動：service iptables restart

三、Tomcat負荷分散設定

Nginxは起動時にデフォルトで設定ファイル/etc/nginx/nginx.confを読み込みます。そしてnginx.confは/etc/nginx/conf.dディレクトリ内のすべての.confファイルを参照します。

したがって、自分でカスタマイズした設定を個別の.confファイルに記述できます。ファイルを/etc/nginx/conf.dディレクトリ内に置くだけでよく、保守が容易になります。

tomcats.confを作成：vi /etc/nginx/conf.d/tomcats.conf 内容は以下の通り：

upstream tomcats {
     ip_hash;
    server 192.168.0.251:8080;
     server 192.168.0.251:8081;
     server 192.168.0.251:8082;
 }

default.confを変更：vi /etc/nginx/conf.d/default.conf 以下のように変更します：

#注释原有的配置
#location / {
#    root   /usr/share/nginx/html;
#    index  index.html index.htm;
#}

#新增配置默认将请求转发到tomcats.conf配置的upstream进行处理
location / {
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header REMOTE-HOST $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_pass http://tomcats; #与tomcats.conf里配置的upstream同名
}

保存後、設定を再読み込みします：nginx -s reload

四、静的リソース分離設定

default.confを変更：vi /etc/nginx/conf.d/default.conf 次の設定を追加します：

#所有js,css相关的静态资源文件的请求由Nginx处理
location ~.*\.(js|css)$ {
    root    /opt/static-resources; #指定文件路径
    expires     12h; #过期时间为12小时
}
#所有图片等多媒体相关静态资源文件的请求由Nginx处理
location ~.*\.(html|jpg|jpeg|png|bmp|gif|ico|mp3|mid|wma|mp4|swf|flv|rar|zip|txt|doc|ppt|xls|pdf)$ {
    root    /opt/static-resources; #指定文件路径
    expires     7d; #过期时间为7天
}

五、SELinuxセキュリティルールの変更

Nginxにアクセスした際に502 Bad Gatewayエラーが発生した場合、Nginxホスト上のSELinuxがhttpアクセス権限の使用を制限している可能性があります。コマンド setsebool -P httpd_can_network_connect 1 を入力して権限を有効にすればOKです。

/etc/nginx/nginx.confファイルの完全な設定は以下の通り：

user  nginx;
worker_processes  auto;

error_log  /var/log/nginx/error.log warn;
pid        /var/run/nginx.pid;
worker_rlimit_nofile    100000;


events {
    use epoll;
    multi_accept on; 
    worker_connections  1024;
}


http {
    include       /etc/nginx/mime.types;
    default_type  application/octet-stream;

    #log_format  main  '$remote_addr - $remote_user [$time_local] "$request" '
    #                  '$status $body_bytes_sent "$http_referer" '
    #                  '"$http_user_agent" "$http_x_forwarded_for"';

    #access_log  /var/log/nginx/access.log  main;

    sendfile        on;
    server_tokens off;
    #tcp_nopush     on;

    keepalive_timeout  65;

    gzip on;
    gzip_disable "msie6";
    gzip_static on;
    gzip_proxied any;
    gzip_min_length 1000;
    gzip_comp_level 4;
    gzip_types text/plain text/css application/json application/x-javascript text/xml application/xml application/xml+rss text/javascript;

    include /etc/nginx/conf.d/*.conf;
}

/etc/nginx/conf.d/default.confファイルの完全な設定は以下の通り：

server {
    listen       80;
    server_name  localhost;

    #charset koi8-r;
    #access_log  /var/log/nginx/log/host.access.log  main;

    #location / {
    #    root   /usr/share/nginx/html;
    #    index  index.html index.htm;
    #}

    location / {
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header REMOTE-HOST $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_pass http://web_servers;
    }

    location ~.*\.(js|css)$ {
        root    /opt/static-resources;
        expires     12h;
    }

    location ~.*\.(html|jpg|jpeg|png|bmp|gif|ico|mp3|mid|wma|mp4|swf|flv|rar|zip|txt|doc|ppt|xls|pdf)$ {
        root    /opt/static-resources;
        expires     7d;
    }

    #error_page  404              /404.html;

    # redirect server error pages to the static page /50x.html
    #
    error_page   500 502 503 504  /50x.html;
    location = /50x.html {
        root   /usr/share/nginx/html;
    }

    # proxy the PHP scripts to Apache listening on 127.0.0.1:80
    #
    #location ~ \.php$ {
    #    proxy_pass   http://127.0.0.1;
    #}

    # pass the PHP scripts to FastCGI server listening on 127.0.0.1:9000
    #
    #location ~ \.php$ {
    #    root           html;
    #    fastcgi_pass   127.0.0.1:9000;
    #    fastcgi_index  index.php;
    #    fastcgi_param  SCRIPT_FILENAME  /scripts$fastcgi_script_name;
    #    include        fastcgi_params;
    #}

    # deny access to .htaccess files, if Apache's document root
    # concurs with nginx's one
    #
    #location ~ /\.ht {
    #    deny  all;
    #}
}

注意：コマンド実行時にroot権限がない場合は、コマンドの前に sudo を付けて実行してください。
