6.0 MapReduce の使用

カテゴリ Hadoop チュートリアル

前回の MapReduce の概念を学んだ後、私たちは Map と Reduce が何であるかを知り、それらの動作方法を理解したはずです。

この章では、MapReduce の使用方法を学びます。

Word Count

Word Count とは「単語統計」であり、これは MapReduce プログラムの中でもっとも古典的なものです。その主なタスクは、テキストファイル内の単語を集計し、出現した各単語の総出現回数を統計することです。

Hadoop には多くの古典的な MapReduce サンプルプログラムが含まれており、その中には Word Count も含まれています。

注意：このケースは HDFS が動作していない状態でも実行できるため、まずスタンドアロンモードでテストします。

まず、以前作成した hadoop_proto イメージの新しいコンテナを起動します：

docker run -d --name=word_count hadoop_proto

コンテナに入ります：

docker exec -it word_count bash

HOME ディレクトリに入ります：

cd ~

次に、テキストファイル input.txt を準備します：

I love サンプル
I like サンプル
I love hadoop
I like hadoop

上記の内容をテキストエディタで保存します。

MapReduce を実行します：

hadoop jar $HADOOP_HOME/share/hadoop/mapreduce/hadoop-mapreduce-examples-3.1.4.jar wordcount input.txt output

意味を説明します：

hadoop jar は jar ファイルから MapReduce タスクを実行します。その後に続くのはサンプルプログラムパッケージのパスです。

wordcount はサンプルプログラムパッケージ内の Word Count プログラムを実行することを示し、その後に2つのパラメータが続きます。1つ目は入力ファイル、2つ目は出力結果のディレクトリ名です（出力結果は複数のファイルになるため）。

実行後、output というフォルダが出力されるはずです。このフォルダには _SUCCESS と part-r-00000 という2つのファイルがあります。

そのうち _SUCCESS は実行成功を示すための空ファイルにすぎず、part-r-00000 は処理結果です。その内容を表示してみると：

cat ~/output/part-r-00000

次のような情報が表示されるはずです：

I       4
hadoop  2
like    2
love    2
サンプル  2

クラスターモード

次に、クラスターモードで MapReduce を実行します。

前の章で設定したクラスターコンテナを起動します：

docker start nn dn1 dn2

NameNode コンテナに入ります：

docker exec -it nn su hadoop

HOME に入ります：

cd ~

input.txt を編集します：

I love サンプル
I like サンプル
I love hadoop
I like hadoop

HDFS を起動します：

start-dfs.sh

ディレクトリを作成します：

hadoop fs -mkdir /wordcount
hadoop fs -mkdir /wordcount/input

input.txt をアップロードします

hadoop fs -put input.txt /wordcount/input/

Word Count を実行します：

hadoop jar $HADOOP_HOME/share/hadoop/mapreduce/hadoop-mapreduce-examples-3.1.4.jar wordcount /wordcount/input /wordcount/output

実行結果を確認します：

hadoop fs -cat /wordcount/output/part-r-00000

すべてが正常に動作していれば、以下の結果が表示されます：

I       4
hadoop  2
like    2
love    2
サンプル  2
