1.2 選択ソート

分类 算法

選択ソート（Selection Sort）は、シンプルで直感的なソートアルゴリズムであり、どのようなデータであっても時間計算量は O(n²) です。そのため、これを使用する場合は、データ規模が小さいほど良いです。唯一の利点は、余分なメモリ空間を消費しないことかもしれません。

選択ソートの基本的な考え方は、毎回ソート待ちのデータから最小（または最大）の要素を選択し、ソート済みシーケンスの末尾に配置して、すべてのデータのソートが完了するまで繰り返すことです。

1. アルゴリズムの手順

  1. 初始化：リストをソート済み部分と未ソート部分に分けます。初期状態では、ソート済み部分は空で、未ソート部分はリスト全体です。

  2. 查找最小值：未ソート部分で最小の要素を探します。

  3. 交换位置：見つけた最小要素を未ソート部分の最初の要素と交換します。

  4. 更新范围：未ソート部分の開始位置を1つ後ろに移動し、ソート済み部分の範囲を拡大します。

  5. 重复步骤：未ソート部分が空になり、リストが完全にソートされるまで、上記の手順を繰り返します。

2. アニメーションによるデモ

ソート待ちのリスト [64, 25, 12, 22, 11] があるとします。選択ソートのプロセスは次のとおりです：

  1. 第一轮：

    • 未ソート部分：[64, 25, 12, 22, 11]。

    • 找到最小值11、それを最初の要素と64交换。

    • リストは[11, 25, 12, 22, 64]。

    • ソート済み部分：[11]、未ソート部分：[25, 12, 22, 64]。

  2. 第二轮：

    • 未ソート部分：[25, 12, 22, 64]。

    • 找到最小值12、それを最初の要素と25交换。

    • リストは[11, 12, 25, 22, 64]。

    • ソート済み部分：[11, 12]、未ソート部分：[25, 22, 64]。

  3. 第三轮：

    • 未ソート部分：[25, 22, 64]。

    • 找到最小值22、それを最初の要素と25交换。

    • リストは[11, 12, 22, 25, 64]。

    • ソート済み部分：[11, 12, 22]、未ソート部分：[25, 64]。

  4. 第四轮：

    • 未ソート部分：[25, 64]。

    • 找到最小值25、それはすでに正しい位置にあるため、交換は不要です。

    • リストは変更されない：[11, 12, 22, 25, 64]。

    • ソート済み部分：[11, 12, 22, 25]、未ソート部分：[64]。

  5. 第五轮：

    • 未ソート部分：[64]。

    • 要素が1つだけなので、操作は不要です。

    • リストは完全にソート済み：[11, 12, 22, 25, 64]。

实例

def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        # 現在の未ソート部分の最初の要素が最小値であると仮定する
        min_idx = i
        # 未ソート部分で最小値のインデックスを検索する
        for j in range(i+1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        # 最小値と未ソート部分の最初の要素を交換する
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

# 示例
arr = [64, 25, 12, 22, 11]
sorted_arr = selection_sort(arr)
print(sorted_arr)  # 输出: [11, 12, 22, 25, 64]

时间复杂度

  • 最坏情况：O(n²)、入力データが整列されているかどうかに関わらず、n(n-1)/2 回の比較が必要です。

  • 最好情况：O(n²)、リストがすでに整列されていても、同じ回数の比較が必要です。

  • 平均情况：O(n²)。

空间复杂度

  • O(1)、選択ソートはインプレースソートアルゴリズムであり、追加のストレージスペースは不要です。

优缺点

  • 优点：

    • 実装が簡単で、コードが理解しやすい。

    • インプレースソートであり、追加のストレージスペースは不要です。

    • 小規模なデータセットに対しては、性能はまだ許容範囲です。

  • 缺点：

    • 時間計算量が高く、大規模なデータセットには適していません。

    • 不安定なソートアルゴリズムです（同じ要素が存在する場合、それらの相対的な順序が変わる可能性があります）。

适用场景

  • データ量が小さく、性能要件が高くないシナリオ。

  • シンプルな実装が必要な場面。

代码实现

JavaScript コード実装

实例

function selectionSort(arr) {
    var len = arr.length;
    var minIndex, temp;
    for (var i = 0; i < len - 1; i++) {
        minIndex = i;
        for (var j = i + 1; j < len; j++) {
            if (arr[j] < arr[minIndex]) {     // 最小の数を見つける
                minIndex = j;                 // 最小数のインデックスを保存
            }
        }
        temp = arr[i];
        arr[i] = arr[minIndex];
        arr[minIndex] = temp;
    }
    return arr;
}

Java コード実装

实例

public class SelectionSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        // 总共要经过 N-1 轮比较
        for (int i = 0; i < arr.length - 1; i++) {
            int min = i;

            // 各ラウンドで必要な比較回数 N-i
            for (int j = i + 1; j < arr.length; j++) {
                if (arr[j] < arr[min]) {
                    // 現在見つかっている最小値要素のインデックスを記録
                    min = j;
                }
            }

            // 見つかった最小値と i の位置にある値を交換する
            if (i != min) {
                int tmp = arr[i];
                arr[i] = arr[min];
                arr[min] = tmp;
            }

        }
        return arr;
    }
}

C++

实例

template<typename T> //整数または浮動小数点数はどちらでも使用できます。オブジェクト（クラス）を使用する場合は、大なり（>）演算子の機能を設定する必要があります。
void selection_sort(std::vector<T>& arr) {
        for (int i = 0; i < arr.size() - 1; i++) {
                int min = i;
                for (int j = i + 1; j < arr.size(); j++)
                        if (arr[j] < arr[min])
                                min = j;
                std::swap(arr[i], arr[min]);
        }
}

static void selection_sort<T>(T[] arr) where T : System.IComparable<T>{//整數或浮點數皆可使用
        int i, j, min, len = arr.Length;
        T temp;
        for (i = 0; i < len - 1; i++) {
                min = i;
                for (j = i + 1; j < len; j++)
                        if (arr[min].CompareTo(arr[j]) > 0)
                                min = j;

                arr[i] = temp;
        }
}

import Foundation

func selectionSort(_ list: inout [Int]) -> Void {
    for j in 0..<list.count - 1 {
        var minIndex = j
        for i in j..<list.count {

                minIndex = i
