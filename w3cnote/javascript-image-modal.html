JavaScript 画像ポップアップ

カテゴリ プログラミング技術

この記事では、JavaScript と CSS を使用して画像ポップアップを作成する方法を紹介します。

画像素材：

HTML コード：

<!--ポップアップをトリガー - 画像をあなたの画像アドレスに変更--> <img id="myImg" src="img.jpg" alt="テキスト説明情報" width="300" height="200"> <!--ポップアップ--> <div id="myModal" class="modal"> <!--閉じるボタン--> <span class="close" onclick="document.getElementById('myModal').style.display='none'">&times;</span> <!--ポップアップ内容--> <img class="modal-content" id="img01"> <!--テキスト説明--> <div id="caption"></div> </div>

CSS コード：

/*ポップアップをトリガーする画像のスタイル*/ #myImg { border-radius: 5px; cursor: pointer; transition: 0.3s; } #myImg:hover {opacity: 0.7;} /*ポップアップの背景*/ .modal { display: none; /* Hidden by default */ position: fixed; /* Stay in place */ z-index: 1; /* Sit on top */ padding-top: 100px; /* Location of the box */ left: 0; top: 0; width: 100%; /* Full width */ height: 100%; /* Full height */ overflow: auto; /* Enable scroll if needed */ background-color: rgb(0,0,0); /* Fallback color */ background-color: rgba(0,0,0,0.9); /* Black w/ opacity */ } /*画像*/ .modal-content { margin: auto; display: block; width: 80%; max-width: 700px; } /*テキスト内容*/ #caption { margin: auto; display: block; width: 80%; max-width: 700px; text-align: center; color: #ccc; padding: 10px 0; height: 150px; } /*アニメーションを追加*/ .modal-content, #caption { -webkit-animation-name: zoom; -webkit-animation-duration: 0.6s; animation-name: zoom; animation-duration: 0.6s; } @-webkit-keyframes zoom { from {-webkit-transform:scale(0)} to {-webkit-transform:scale(1)} } @keyframes zoom { from {transform:scale(0)} to {transform:scale(1)} } /*閉じるボタン*/ .close { position: absolute; top: 15px; right: 35px; color: #f1f1f1; font-size: 40px; font-weight: bold; transition: 0.3s; } .close:hover, .close:focus { color: #bbb; text-decoration: none; cursor: pointer; } /*小さい画面では画像の幅は 100%*/ @media only screen and (max-width: 700px){ .modal-content { width: 100%; } }

JavaScript コード：

//ポップアップを取得 var modal = document.getElementById('myModal'); //画像を取得してポップアップに挿入 - "alt" 属性をテキスト部分の内容として使用 var img = document.getElementById('myImg'); var modalImg = document.getElementById("img01"); var captionText = document.getElementById("caption"); img.onclick = function(){ modal.style.display = "block"; modalImg.src = this.src; captionText.innerHTML = this.alt; } //<span> 要素を取得し、閉じるボタンを設定 var span = document.getElementsByClassName("close")[0]; //(x) をクリックすると、ポップアップを閉じる span.onclick = function() { modal.style.display = "none"; }
