プロジェクト名: excalidraw -- 手書き図形を描く仮想ホワイトボード

Github オープンソースアドレス： https://github.com/excalidraw/excalidraw

オンラインテストアドレス： https://excalidraw.com/

excalidraw はオープンソースで無料の仮想ホワイトボードであり、オンラインでリアルタイムコラボレーションが可能なホワイトボードツールを提供し、ユーザーは簡単な図形や図表を作成できます。

excalidraw の設計目標は、使いやすい描画ツールを提供し、チームコラボレーションをサポートすることであり、同時にクロスプラットフォームとリアルタイムコラボレーションの機能を備えています。

  • シンプルで使いやすい：excalidraw はシンプルで直感的なインターフェースを提供し、ユーザーはホワイトボード上で基本的な図形、線、テキストなど、さまざまな図形を簡単に描くことができます。

  • リアルタイムコラボレーション：このプロジェクトはリアルタイムコラボレーションをサポートしており、複数のユーザーが同時に同じホワイトボードで作業できます。各ユーザーの変更は、すべての共同作業者の画面に即座に反映されるため、チームコラボレーションがより便利になります。

  • エクスポートと共有：ユーザーは作成した図形を画像ファイルとしてエクスポートでき、ホワイトボードはリンクを介して他の人と共有できます。

  • クロスプラットフォーム：excalidraw は Web アプリであり、さまざまなオペレーティングシステムやデバイスで動作します。最新の Web ブラウザを使用するだけで利用できます。

  • オープンソース：excalidraw は無料かつオープンソースで、GitHub でホストされています。誰でもコードを閲覧、使用、変更、貢献できます。

  • ローカライゼーション（i18n）サポート：多言語をサポートしています。

  • 手書きスタイル：excalidraw の描画スタイルは手書き風の図形です。

  • 要素ライブラリとカスタム要素：excalidraw は、矩形、円、矢印などの一般的な図形要素を提供しています。ユーザーは要素ライブラリから選択してキャンバスにドラッグ＆ドロップでき、要素の外観やスタイルをカスタマイズすることもできます。

インストール

インストール方法も簡単です。まず excalidraw をクローンします：

git clone https://github.com/excalidraw/excalidraw.git

次に excalidraw ディレクトリに移動します：

cd excalidraw

以下のコマンドを実行します：

yarn

起動：

yarn start
