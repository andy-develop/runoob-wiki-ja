2の32乗を求める：

码农：

System.out.println(Math.pow(2, 32));

黑客：

System.out.println(1L<<32);

2Bプログラマー：

System.out.println(2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2*2);

2つの数を交換する：

码农：

void swap(int &a,int &b)
{
    int temp;
    temp=a;
    a=b;
    b=temp;
}

黑客：

void swap(int &a,int &b)
{

    a=a^b;

    b=a^b;

    a=a^b;

}

2Bプログラマー：

void swap(int a,int b)
{
    int temp;
    temp=a;
    a=b;
    b=temp;
}
