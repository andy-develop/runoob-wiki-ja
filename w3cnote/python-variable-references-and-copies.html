Pythonにおける変数代入時の参照とコピー

カテゴリ プログラミング技術

以前、こんな問題を見たことがある。辞書の中の要素がリストで、そのリスト要素を変数に代入し、そのリスト内の要素の値を変更すると、辞書の中のそのリストも同様に変更されていた。その問題は以下の通り：

dict = {'a':[1,2,3,4,5],'b':2}
x = dict['a']
for i in range(5):
    x[i] = 0
print(dict['a'])

プログラムの実行結果は以下の通り： [0, 0, 0, 0, 0]

ここではPythonの代入が参照なのかコピーなのか、つまり代入時に値渡しかアドレス渡しかという問題に関わってくる。上記の問題は"a"の値をxに代入したことで上記の状況が発生した。"b"の値をxに代入した場合、xの値を変更しても辞書dictの値は影響を受けない。

>>> dict = {'a':[1,2,3,4,5],'b':2}
>>> x = dict['b']
>>> x
2
>>> x=x+3
>>> x
5
>>> dict
{'a': [1, 2, 3, 4, 5], 'b': 2}
>>>

では問題は、変数の代入・受け渡し時に、どのような場合に値渡し（コピー）で、どのような場合にアドレス渡し（参照）なのか？

1、直接コピー

参照なのかコピーなのかわからない場合は、明示的にコピーすることができる。例えば辞書オブジェクト自体にはコピーメソッドがある：

x=dict.copy()

コピーメソッドがないオブジェクトでもコピーは可能である。ここで深いコピー（ディープコピー）の概念を紹介する。深いコピーとは、Pythonのcopyモジュールが提供するdeepcopyメソッドのことである。深いコピーは元の変数に関連するすべてのデータを完全に複製し、メモリ内に完全に同じ内容を生成する。この過程で、2つの変数の一方を任意に変更しても他の変数には影響しない。上記のコードを以下のように変更すると：

import copy
dict = {'a':[1,2,3,4,5],'b':2}
x = copy.deepcopy(dict['a'])
for i in range(5):
    x[i] = 0
print(dict['a'])

実行結果ではdictの値は影響を受けない。

深いコピーの他に、copyモジュールはcopyメソッドも提供しており、これを浅いコピー（シャローコピー）と呼ぶ。単純なオブジェクトの場合、深いコピーも浅いコピーも同じである。上記の辞書オブジェクトのcopyメソッドは浅いコピーである。

>>> dict
{'a': [8, 2, 3, 4, 5], 'b': 4}
>>> dd=copy.copy(dict)
>>> dd
{'a': [8, 2, 3, 4, 5], 'b': 4}
>>> dd['a'][0]=7
>>> dd
{'a': [7, 2, 3, 4, 5], 'b': 4}
>>> dict
{'a': [7, 2, 3, 4, 5], 'b': 4}
>>> ee=dict.copy()
>>> ee
{'a': [7, 2, 3, 4, 5], 'b': 4}
>>> ee['a'][0]=9
>>> ee
{'a': [9, 2, 3, 4, 5], 'b': 4}
>>> dict
{'a': [9, 2, 3, 4, 5], 'b': 4}
>>> ee['b']=5
>>> ee
{'a': [9, 2, 3, 4, 5], 'b': 5}
>>> dict
{'a': [9, 2, 3, 4, 5], 'b': 4}
>>>

浅いコピーの場合、第一階層の変更は互いに影響しない（上記の例では辞書bの値の変更）。第二階層（上記の例では辞書aのリスト値の変更）は互いに影響し合い、一つを変更すると他もそれに伴って変わる。idを見てみよう：

>>> id(dict)
20109472
>>> id(dd)
20244496
>>> id(ee)
20495072
>>> id(dd['a'])
20272112
>>> id(ee['a'])
20272112
>>> id(dict['a'])
20272112
>>>

辞書の各コピーのidは異なるが、辞書aの値のidは同じであることがわかる。本当の意味でのコピーが必要なら、深いコピーを使おう。

2、受け渡しルール

Pythonの代入プロセスではコピーと参照を明確に区別しない。一般的に静的変数の受け渡しはコピー、動的変数の受け渡しは参照となる。（注：静的変数の初回受け渡しも参照である。静的変数を変更する必要がある場合、静的変数は変更できないため、新しい領域を生成してデータを保存する必要がある。）

  • 文字列、数値、タプルはすべて静的変数である。
  • リスト、辞書は動的変数である。

変数は時には複雑で、組み合わせが存在する。例えば辞書の中にリストが含まれ、リストの中に辞書が含まれる場合などがあるが、代入時には常に何らかの型に属する。状況がどうしてもわからない場合は、実験してみるとよい。id()関数を使って確認すれば、参照の場合、2つの変数が指すアドレスは同じである。例えば：

>>> a=6
>>> id(a)
10413476
>>> b=a
>>> id(b)
10413476
>>> b=8
>>> id(b)
10413452
>>>

変数bを変更する前は、aとbが指すアドレスは同じだが、bを変更するとアドレスが変わる。
