C++ 時間型詳解 time_t

分類 プログラミング技術

Unixタイムスタンプ(Unix timestamp)、またはUnix時間(Unix time)、POSIX時間(POSIX time)とも呼ばれ、時間の表現方法の一つであり、グリニッジ標準時1970年1月1日00時00分00秒から現在までの総秒数と定義されます。UnixタイムスタンプはUnixシステムやUnix系システムだけでなく、多くの他のオペレーティングシステムでも広く採用されています。

現在、かなりの数のオペレーティングシステムが32ビットの2進数で時間を表現しています。このようなシステムのUnixタイムスタンプは、グリニッジ標準時2038年1月19日03時14分07秒（2進数：01111111 11111111 11111111 11111111）までしか使用できません。その1秒後、2進数は10000000 00000000 00000000 00000000になり、オーバーフローエラーが発生し、システムは時間を1901年12月13日20時45分52秒と誤って解釈します。これはソフトウェア障害を引き起こす可能性が高く、システム停止に至ることもあります。64ビットの2進数で時間を表現するシステム（最大でグリニッジ標準時292,277,026,596年12月04日15時30分08秒まで使用可能）は、このようなオーバーフローの問題には基本的に遭遇しません。

まず、時間に関する関連概念とその違いを理解しましょう。理解しておく必要がある時間の概念は以下のとおりです。

  • ローカル時間(locale time)
  • グリニッジ標準時（Greenwich Mean Time GMT）
  • 協定世界時（Universal Time Coordinated UTC）

ローカル時間は、言うまでもなく説明の必要はありません。

まず時間の標準を見てみましょう。

（1）世界時

世界時は最も初期の時間標準です。1884年、国際的に1秒は1年間の1日あたりの平均長さの1/8.64×10^4と定められました。この標準に基づいて形成された時間システムは世界時、すなわちUT1と呼ばれます。1972年に国際原子時が国際的に使用され始めてから、グリニッジ旧天文台の本初子午線を通過する時間は世界時、すなわちUT2、またはグリニッジ標準時（GMT）と呼ばれるようになりました。これは地球の自転速度の周期的な差異を補正した世界時です。

（2）原子時

1967年、人々はセシウム原子の振動周期が極めて規則的である特性を利用して、高精度の原子時計を開発し、セシウム原子のエネルギー準位遷移による放射9192631770周期にかかる時間を1秒と定めました。現在使われている時間は1971年10月に定義された国際原子時であり、世界の約200台以上の原子時計を比較した後、国際度量衡局の時間部門がデータ処理を行って得られた統一された原子時で、略してTAIと呼ばれます。

（3）協定世界時

協定世界時は地球の自転に基づく時間標準です。地球の自転速度は均一ではないため、毎日が正確に86400原子秒というわけではなく、そのため自転時間と世界時の間には18か月で1秒の誤差が生じます。この誤差を修正するため、国際地球回転研究所は地球の自転の実際の状況に基づいてグリニッジ標準時にうるう秒を加減する調整を行い、国際度量衡局の時間部門と共同で世界中に標準時を発表しています。これがいわゆる協定世界時（UTC: Coordinated Universal Time）です。UTCの表現方法は、年（y）、月（m）、日（d）、時（h）、分（min）、秒（s）で、すべて数字で表されます。

GPSシステムには2つの時間区分があります。1つはUTC、もう1つはLT（地方時）です。両者の違いは時区が異なることです。UTCは0時区の時間であり、地方時はローカル時間です。例えば北京が朝8時（東8区）の場合、UTC時間は0時で、北京時間より8時間遅れます。このように計算できます。上記の理解により、グリニッジ標準時は協定世界時（GMT=UTC）と考えることができ、グリニッジ標準時とUTC時間はどちらも秒数で計算されます。

一方、普段の仕事で見るコンピュータのログに書かれている時間の多くはUTC時間で計算されています。では、UTC時間をローカル時間に変換してログを確認しやすくするにはどうすればいいでしょうか。また、プログラム開発時にローカル時間をUTC時間に変換するにはどうすればいいでしょうか。

以下では、シンプルで実用的なツールを紹介します。それはlinux/unixコマンドのdateを使用して、ローカル時間とlocal時間の変換を行うことです。

ご存知のとおり、コンピュータで見られるUTC時間はすべて（1970年1月1日 0:00:00）から秒数を計算し始めます。見られるUTC時間は、1970年という時点から特定の時間までに合計何秒あるかということです。

プログラミングでは時間を頻繁に使用することがあります。例えば、システムの時間を取得する（システムの年、月、日、時、分、秒、曜日などを取得する）、または一定時間ごとに何かを行う場合などです。そのようなときは、いくつかの時間関数を使用します。

Linuxで時間を保存する一般的な方法は2つあります。1つは1970年から現在までに経過した秒数、もう1つは構造体を使用して年月日時分秒をそれぞれ保存する方法です。

time_t 型は、1970年から現在までに経過した秒数を保存するために使用されます。より正確にしたい場合は、struct timeval構造体を使用できます。これはマイクロ秒まで正確です。

struct timeval
{
    long tv_sec; /*秒*/
    long tv_usec; /*微秒*/
};

一方、年月日を直接保存するのは構造体です：

struct tm
{
    int tm_sec;  /*秒，正常范围0-59， 但允许至61*/
    int tm_min;  /*分钟，0-59*/
    int tm_hour; /*小时， 0-23*/
    int tm_mday; /*日，即一个月中的第几天，1-31*/
    int tm_mon;  /*月， 从一月算起，0-11*/  1+p->tm_mon;
    int tm_year;  /*年， 从1900至今已经多少年*/  1900＋ p->tm_year;
    int tm_wday; /*星期，一周中的第几天， 从星期日算起，0-6*/
    int tm_yday; /*从今年1月1日到目前的天数，范围0-365*/
    int tm_isdst; /*日光节约时间的旗标*/
};

特に注意すべき点は、年は1900年から現在までの年数であり、2011年などのように直接保存されるわけではないことです。月は0から始まり、0は1月を表します。曜日も0から始まり、0は日曜日、1は月曜日を表します。

以下では、一般的に使用される時間関数を紹介します。

#include <time.h>
char *asctime(const struct tm* timeptr);

構造体内の情報を現実世界の時間に変換し、文字列の形式で表示します。

char *ctime(const time_t *timep);

timepを現実世界の時間に変換し、文字列で表示します。asctimeとの違いは、渡されるパラメータの形式が異なる点です。

double difftime(time_t time1, time_t time2);

2つの時間の差の秒数を返します。

int gettimeofday(struct timeval *tv, struct timezone *tz);

現在から1970年までの秒数とマイクロ秒数を返します。後ろのtzは時区（タイムゾーン）で、通常は使用しません。

struct tm* gmtime(const time_t *timep);

time_tで表される時間を、タイムゾーン変換を経ていないUTC時間に変換します。struct tm構造体へのポインタです。

stuct tm* localtime(const time_t *timep);

gmtimeに似ていますが、これはタイムゾーン変換を経た時間です。

time_t mktime(struct tm* timeptr);

struct tm構造体の時間を1970年から現在までの秒数に変換します。

time_t time(time_t *t);

1970年1月1日から現在までの秒数を取得します。

以上が簡単な紹介です。次に実践を通してこれらの関数の使い方を見てみましょう。

/*gettime1.c*/
#include <time.h>

int main()
{
    time_t timep;
   
    time(&timep); /*获取time_t类型的当前时间*/
    /*用gmtime将time_t类型的时间转换为struct tm类型的时间按，／／没有经过时区转换的UTC时间
      然后再用asctime转换为我们常见的格式 Fri Jan 11 17:25:24 2008
    */
    printf("%s", asctime(gmtime(&timep)));
    return 0;
}

コンパイルして実行する：

$gcc -o gettime1 gettime1.c
$./gettime1
Fri Jan 11 17:04:08 2008

以下は、time_t型を私たちがよく見る形式に直接変換するものです:

/* gettime2.c*/
#include <time.h>

int main()
{
    time_t timep;
   
    time(&timep); /*获取time_t类型当前时间*/   
    /*转换为常见的字符串：Fri Jan 11 17:04:08 2008*/
    printf("%s", ctime(&timep));
    return 0;
}

コンパイルして実行する：

$gcc -o gettime2 gettime2.c
$./gettime2
Sat Jan 12 01:25:29 2008

ある本で読んだのですが、この2つの例を続けて実行した場合、2つの結果は秒の違い（プログラムの実行に時間がかかるため）を除けば同じになるはずです。しかし、私の環境で実行したところ、結果がかなり長い時間ずれていました。1つは金曜日で、もう1つは土曜日でした。その後、dateコマンドで実行してみました。

$ date
六 1月 12 01:25:19 CST 2008

dateとgettime2は比較的一致していることがわかりました。おそらくgettime1はタイムゾーンの変換を経ていないため、それらには違いがあるのだと思います。

/*gettime3.c */
#include <time.h>

int main()
{
    char *wday[] = {"Sun", "Mon", "Tue", "Wed", "Thu", "Fri", "Sat"};
    time_t timep;
    struct tm *p;
   
    time(&timep); /*获得time_t结构的时间，UTC时间*/
    p = gmtime(&timep); /*转换为struct tm结构的UTC时间*/
    printf("%d/%d/%d ", 1900 + p->tm_year, 1+ p->tm_mon, p->tm_mday);
    printf("%s %d:%d:%d\n", wday[p->tm_wday], p->tm_hour,
        p->tm_min, p->tm_sec);
    return 0;
}

コンパイルして実行する：

$gcc -o gettime3 gettime3.c
$./gettime3
2008/1/11 Fri 17:42:54

この時間の結果から見ると、それはgettime1と一致しています。

/*gettime4.c*/
#include <time.h>

int main()
{
    char *wday[] = {"Sun", "Mon", "Tue", "Wed", "Thu", "Fri", "Sat"};
    time_t timep;
    struct tm *p;
   
    time(&timep); /*获得time_t结构的时间，UTC时间*/
    p = localtime(&timep); /*转换为struct tm结构的当地时间*/
    printf("%d/%d/%d ", 1900 + p->tm_year, 1+ p->tm_mon, p->tm_mday);
    printf("%s %d:%d:%d\n", wday[p->tm_wday], p->tm_hour, p->tm_min, p->tm_sec);
    return 0;
}

コンパイルして実行する：

$gcc -o gettime4 gettime4.c
$./gettime4
2008/1/12 Sat 1:49:29

上記の結果から、次のように言えます：

time, gmtime, asctime が表す時間はすべてUTC時間ですが、データ型が異なるだけです。

一方、localtime, ctime が表す時間はすべてタイムゾーン変換を経た時間であり、システムコマンドdateが表すCST時間と一致するはずです。

/*gettime5.c*/
#include <time.h>

int main()
{
    time_t timep;
    struct tm *p;

    time(&timep); /*当前time_t类型UTC时间*/
    printf("time():%d\n",timep);
    p = localtime(&timep); /*转换为本地的tm结构的时间按*/
    timep = mktime(p); /*重新转换为time_t类型的UTC时间，这里有一个时区的转换*/ //by lizp 错误，没有时区转换， 将struct tm 结构的时间转换为从1970年至p的秒数
    printf("time()->localtime()->mktime(): %d\n", timep);
    return 0;
}

コンパイルして実行する：

$gcc -o gettime5 gettime5.c
$./gettime5
time():1200074913
time()->localtime()->mktime(): 1200074913

ここではUTC時間をローカル時間に変換し、その後ローカル時間をUTC時間に変換していますが、変換結果は一致しています。

/*gettime6.c */
#include <time.h>

int main()
{
    time_t timep;
    struct tm *p;

    time(&timep);  /*得到time_t类型的UTC时间*/
    printf("time():%d\n",timep);
    p = gmtime(&timep); /*得到tm结构的UTC时间*/
    timep = mktime(p); /*转换，这里会有时区的转换*/ //by lizp 错误，没有时区转换， 将struct tm 结构的时间转换为从1970年至p的秒数
    printf("time()->gmtime()->mktime(): %d\n", timep);
    return 0;
}

コンパイルして実行する：

$gcc -o gettime6 gettime6.c
$./gettime6
time():1200075192
time()->gmtime()->mktime(): 1200046392

これからわかるように、変換後の時間は一致しなくなります。計算してみると、ちょうど8時間の差があります（(1200075192-1200046392)/3600 = 8）。つまり、mktimeはローカル時間をUTC時間に変換するということです。ここでは元々UTC時間だったため、さらにタイムゾーン変換を行うと、結果として8時間の差が生じます。使用する際は注意が必要です。

strftime() 関数は時間をフォーマットします

strftime() 関数を使用すると、時間を任意の形式にフォーマットできます。そのプロトタイプは以下のとおりです。

size_t strftime(
     char *strDest,
     size_t maxsize,
     const char *format,
     const struct tm *timeptr
);

formatが指す文字列中の書式コマンドに従って、timeptrに保存された時間情報をstrDestが指す文字列に格納できます。strDestには最大maxsize文字まで格納できます。この関数は、strDestが指す文字列に格納された文字数を返します。

関数strftime()の操作はsprintf()にいくらか似ています。パーセント記号(%)で始まる書式コマンドのセットを認識し、フォーマットされた出力結果を文字列に格納します。書式コマンドは、strDest中のさまざまな日付・時刻情報の正確な表現方法を指定します。書式文字列中の他の文字はそのまま文字列に挿入されます。書式コマンドは以下に示します。これらは大文字と小文字を区別します。

%a 星期几的简写
%A 星期几的全称
%b 月分的简写
%B 月份的全称
%c 标准的日期的时间串
%C 年份的后两位数字
%d 十进制表示的每月的第几天
%D 月/天/年
%e 在两字符域中，十进制表示的每月的第几天
%F 年-月-日
%g 年份的后两位数字，使用基于周的年
%G 年分，使用基于周的年
%h 简写的月份名
%H 24小时制的小时
%I 12小时制的小时
%j 十进制表示的每年的第几天
%m 十进制表示的月份
%M 十时制表示的分钟数
%n 新行符
%p 本地的AM或PM的等价显示
%r 12小时的时间
%R 显示小时和分钟：hh:mm
%S 十进制的秒数
%t 水平制表符
%T 显示时分秒：hh:mm:ss
%u 每周的第几天，星期一为第一天 （值从0到6，星期一为0）
%U 第年的第几周，把星期日做为第一天（值从0到53）
%V 每年的第几周，使用基于周的年
%w 十进制表示的星期几（值从0到6，星期天为0）
%W 每年的第几周，把星期一做为第一天（值从0到53）
%x 标准的日期串
%X 标准的时间串
%y 不带世纪的十进制年份（值从0到99）
%Y 带世纪部分的十制年份
%z，%Z 时区名称，如果不能得到时区名称则返回空字符。
%% 百分号

現在の時刻を12時間制で表示したい場合は、次のようなプログラムになります：

#include "time.h"
#include "stdio.h"
int main(void)
{
    struct tm *ptr;
    time_t lt;
    char str[80];
    lt=time(NULL);
    ptr=localtime(<);
    strftime(str,100,"It is now %I %p",ptr);
    printf(str);
    return 0;
}

その実行結果は次のとおりです：

It is now 4PM

一方、次のプログラムは現在の完全な日付を表示します：

#include<stdio.h>
#include<string.h>
#include<time.h>
int main( void )
{
    struct tm *newtime;
    char tmpbuf[128];
    time_t lt1;
   
    time( &lt1 );
    newtime=localtime(&lt1);
   
    strftime( tmpbuf, 128, "Today is %A, day %d of %B in the year %Y.\n", newtime);
    printf(tmpbuf);

    return 0;
}
