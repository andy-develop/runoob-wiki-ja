1.4 シェルソート

分类 算法

シェルソート（Shell Sort）は挿入ソートの改良版であり、縮小増分ソートとも呼ばれます。ソート対象のリストを複数のサブリストに分割し、各サブリストに対して挿入ソートを行い、サブリストの間隔を徐々に縮小して、最終的に全体を完了します。

シェルソートは、挿入ソートの以下の2つの性質に基づいて改良方法として提案されたものです：

  • 挿入ソートは、ほぼ整列済みのデータに対して操作する場合、効率が高く、線形ソートの効率を達成できます；
  • しかし、挿入ソートは一般的に非効率です。なぜなら、挿入ソートは毎回データを1桁だけ移動できるからです；

シェルソートの基本思想は、まずソート対象のレコードシーケンス全体をいくつかのサブシーケンスに分割し、それぞれ直接挿入ソートを行い、シーケンス全体のレコードが「基本的に整列」されたら、全レコードに対して順次直接挿入ソートを行うというものです。

1. アルゴリズムの手順

  1. 増分シーケンスを選択：増分シーケンス（gap sequence）を選択し、リストを複数のサブリストに分割するために使用します。一般的な増分シーケンスには、シェル増分（n/2, n/4, ..., 1）等。

  2. グループごとに挿入ソート：増分シーケンスに従ってリストを複数のサブリストに分割し、各サブリストに対して挿入ソートを行います。

  3. 缩小增量：増分を徐々に縮小し、上記の分割とソートのプロセスを増分が1になるまで繰り返します。

  4. 最终排序：増分が1のとき、リスト全体に対して1回の挿入ソートを行い、ソートを完了します。

2. 動画デモ

ソート対象のリスト [8, 3, 1, 2, 7, 5, 6, 4] があると仮定し、シェル増分（初期増分は n/2）を使用すると、ソートプロセスは次のとおりです：

  1. 初始状态：

    • 列表：[8, 3, 1, 2, 7, 5, 6, 4]。

    • 初始增量：4（列表长度8の半分）。

  2. 第1ラウンド（増分4）：

    • リストを4つのサブリストに分割する：

      • サブリスト 1：[8, 7]。

      • サブリスト 2：[3, 5]。

      • サブリスト 3：[1, 6]。

      • サブリスト 4：[2, 4]。

    • 各サブリストに対して挿入ソートを行う：

      • サブリスト 1：[7, 8]。

      • サブリスト 2：[3, 5]。

      • サブリスト 3：[1, 6]。

      • サブリスト 4：[2, 4]。

    • ソート後のリスト：[7, 3, 1, 2, 8, 5, 6, 4]。

  3. 第2ラウンド（増分2）：

    • リストを2つのサブリストに分割する：

      • サブリスト 1：[7, 1, 8, 6]。

      • サブリスト 2：[3, 2, 5, 4]。

    • 各サブリストに対して挿入ソートを行う：

      • サブリスト 1：[1, 6, 7, 8]。

      • サブリスト 2：[2, 3, 4, 5]。

    • ソート後のリスト：[1, 2, 6, 3, 7, 4, 8, 5]。

  4. 第3ラウンド（増分1）：

    • リスト全体を1つのサブリストとみなして、挿入ソートを行います。

    • ソート後のリスト：[1, 2, 3, 4, 5, 6, 7, 8]。

实例

def shell_sort(arr):
    n = len(arr)
    gap = n // 2  # 初始增量
    while gap > 0:
        # 各サブリストに対して挿入ソートを実行する
        for i in range(gap, n):
            temp = arr[i]  # 当前待插入元素
            j = i
            # サブリスト内の適切な位置を見つけて挿入
            while j >= gap and arr[j - gap] > temp:
                arr[j] = arr[j - gap]
                j -= gap
            arr[j] = temp
        gap //= 2  # 缩小增量
    return arr

# 示例
arr = [8, 3, 1, 2, 7, 5, 6, 4]
sorted_arr = shell_sort(arr)
print(sorted_arr)  # 输出: [1, 2, 3, 4, 5, 6, 7, 8]

时间复杂度

シェルソートの時間複雑性は増分シーケンスの選択に依存します：

  • 最坏情况：O(n²)、増分シーケンスの選択が不適切な場合。

  • 最好情况：O(n log n)、増分シーケンスが適切に選択された場合。

  • 平均情况：O(n log n) 到 O(n²) 之间。

一般的な増分シーケンス：

  • 希尔增量：n/2, n/4, ..., 1時間計算量はO(n²)である。

  • Hibbard 增量：1, 3, 7, 15, ..., 2^k - 1，時間計算量は O(n^(3/2)) である。

  • Sedgewick 增量：1, 5, 19, 41, 109, ...，時間計算量は O(n^(4/3)) である。

空间复杂度

  • O(1)、シェルソートは原地（インプレース）ソートアルゴリズムであり、追加の記憶領域を必要としません。

优缺点

  • 优点：

    • 単純な挿入ソートと比較して、効率がより高いです。

    • 原地（インプレース）ソートであり、追加の記憶領域を必要としません。

    • 中規模のデータセットに適している。

  • 缺点：

    • 時間複雑性は増分シーケンスの選択に依存します。

    • 不安定なソートアルゴリズムです（同じ要素の相対的な順序を変える可能性があります）。

适用场景

  • 中規模のデータセット。

  • パフォーマンス要件は高くないが、単純な挿入ソートより高い効率が必要なシナリオ。

  • より複雑なソートアルゴリズムの前処理ステップとして。

代码实现

JavaScript

实例

function shellSort(arr) {
    var len = arr.length,
        temp,
        gap = 1;
    while(gap < len/3) {          //动态定义间隔序列
        gap =gap*3+1;
    }
    for (gap; gap > 0; gap = Math.floor(gap/3)) {
        for (var i = gap; i < len; i++) {
            temp = arr[i];
            for (var j = i-gap; j >= 0 && arr[j] > temp; j-=gap) {
                arr[j+gap] = arr[j];
            }
            arr[j+gap] = temp;
        }
    }
    return arr;
}

public static void shellSort(int[] arr) {
    int length = arr.length;
    int temp;
    for (int step = length / 2; step >= 1; step /= 2) {
        for (int i = step; i < length; i++) {
            temp = arr[i];
            int j = i - step;
            while (j >= 0 && arr[j] > temp) {

                j -= step;
            }
            arr[j + step] = temp;
        }
    }
}

        for (gap = len >> 1; gap > 0; gap >>= 1)

C++

实例

template<typename T>
void shell_sort(T array[], int length) {
    int h = 1;
    while (h < length / 3) {
        h = 3 * h + 1;
    }
    while (h >= 1) {
        for (int i = h; i < length; i++) {
            for (int j = i; j >= h && array[j] < array[j - h]; j -= h) {
                std::swap(array[j], array[j - h]);
            }
        }
        h = h / 3;
    }
}
