RSAの基本的な考え方は以下のとおりです。

分类 编程技术

1.公開鍵と秘密鍵の生成：

  • (1) ランダムに2つの大きな素数pとqを選び、n = p*qを構成する;
  • (2)オイラー関数φ(n) = (p-1) * (q-1) を計算する;
  • (3) e をランダムに選び、gcd(e, φ(n)) = 1 となるようにする。すなわち、e と φ(n) は互いに素である。gcd は最大公約数を求めることを指す。
  • (4) e*d ≡ 1 (mod φ(n)) となるように d を計算する。すなわち、d は e の乗法逆元である。

2. 暗号化プロセス：

  • (1) 暗号化する情報（平文）はmであり、m < n；（モジュロ演算を行うため、mがnより大きい場合、後の演算は成立しない。したがって、情報がnより大きい場合は、ブロックに分けて暗号化すべきである）

  • (2))密文 c 的生成是 $$ c = m^e mod (n) $$

3.解密

$$ c^d mod (n) = (m^e)^d mod (n) = m^(d*e) mod (n) ; $$

3.解密

$$ c^d mod (n) = (m^e)^d mod (n) = m^(d*e) mod (n) ; $$

なぜ復号できるのか？

オイラーの定理を使用する必要がある（実際にはフェルマーの小定理の一般化である）

a^φ(n) ≡ 1 (mod n)，

さらに一般化：a^(φ(n)k) ≡ 1 (mod n)，

得到 a^(φ(n)k+1) ≡ a (mod n)

注意到 ed ≡ 1 mod φ(N)，即：ed = 1 + k*φ(N)。

因此，$$ M^(de) mod N = M^1 + kφ(N) mod N = M $$
