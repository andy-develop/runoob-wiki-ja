余りとモジュロの違い

分类 编程技术

通常、剰余演算はモジュロ演算とも呼ばれ、どちらも戻り値は余りです。.rem 和 mod唯一の違いは次のとおりです：

x と y の符号が同じ場合、2つの関数の結果は同じになります。x と y の符号が異なる場合、rem 関数の結果の符号は x と同じになり、mod は y と同じになります。

これはこれら2つの関数の生成メカニズムが異なるためです。rem 関数は fix 関数を採用し、mod 関数は floor 関数を採用しています（これら2つの関数は整数化に使われ、fix 関数は 0 方向に丸め、floor 関数は負の無限大方向に丸めます）。 rem（x，y）コマンドは x-n.*y を返します。y が 0 でない場合、その中の n = fix(x./y) です。一方、mod(x,y) は x-n.*y を返し、y が 0 でない場合、n=floor(x./y) です。

2つの異符号整数のモジュロ演算の値の規則（小数の場合もこの演算規則になります。この点は C 言語とは少し異なるようです）

まず2つの整数を正の数と見なしてから、除算演算を行います:

  • 1、割り切れる場合、その値は 0 です。
  • 2、割り切れない場合、その値 = 除数×(整数商+1) - 被除数

例：mod(36,-10)=-4

すなわち、36 を 10 で割った整数商は 3 で、1 を加えると 4 になります。その除数との積は 40 です。被除数との差は（40-36=4）です。除数の符号を取ります。したがって値は -4 です。

例：mod(9,1.2)=0.6;

例：

>> mod(5,2)
ans =1                   % 除数是正，余数就是正
>> mod(-5,2)
ans =1
>> mod(5,-2)
ans =-1                  % 除数是负，余数就是负
>> mod(-5,-2)
ans =-1                  % 用 rem 时，不管除数是正是负，余数的符号与被除数的符号相同
>> rem(5,2)
ans =1                   % 被除数是正，余数就是正
>> rem(5,-2); 
ans =1
>> rem(-5,2)
ans =-1                 % 被除数是负， 余数就是负
>> rem(-5,-2)
ans =-1

じっくり考えると、両者は確かに異なります。

    对于整数 a，b 来说，取模运算或者求余运算的方法要分如下两步：
    • 1. 整数の商を求める：c=a/b
    • 2、モジュロまたは余りを計算します：r=a-(c*b)

    モジュロ演算と剰余演算は最初のステップが異なります

    剰余演算では商の値を計算する際に 0 方向に小数位を切り捨てます

    モジュロ演算では商の値を計算する際に負の無限大方向に小数位を切り捨てます

    例：4/(-3) は約 -1.3

    剰余演算のとき、商の値は 0 方向に小数位を切り捨てると -1 になります

    モジュロ演算のとき、商の値は負の無限大方向に小数位を切り捨てると -2 になります

    所以

    4rem(-3)=1
4mod(-3)=-2

    1. モジュロ演算は主にコンピュータ分野で見られ、剰余演算は一般に数学分野で使われます。

    2. モジュロ演算（剰余演算）の計算手順

    a. 整数の商を求める

    c=a/b

    b. モジュロ（余り）を求める

    r=a-c*b

    3. 両者の違い: モジュロ演算では c は負の無限遠方向に整数化し、剰余演算では c は 0 方向に整数化します。

    4. 結論：a が正の整数の場合、モジュロ演算と剰余演算の結果は同じです。a が負の整数の場合、両者の結果は異なります。

    上記の2人の方がとても明確に説明していますが、結論には少し問題があります

    a と b の符号が同じであれば、モジュロ演算と剰余演算の結果は同じになります。

    両者の計算手順は同じであり、主な違いは最初のステップの c = a/b にあります。剰余演算は 0 方向に整数化し、モジュロ演算は負の無限大方向に整数化します。

    したがって、a と b が同符号であれば、C の値は同じになり、最後の r = a - （c * b）も同じになります。

    同様に、a と b の符号が異なる場合、結果に違いが出る可能性があります。
