1.9 バケットソート

分類 アルゴリズム

バケットソート（Bucket Sort）は分散型ソートアルゴリズムであり、ソート対象の要素を複数のバケット（Bucket）に割り当て、各バケット内の要素をソートし、最後にすべてのバケットの要素を順番にマージします。バケットソートの核となる考え方は、データを有限個のバケットに分割し、各バケットをそれぞれソートする（他のソートアルゴリズムを使用するか、再帰的にバケットソートを使用することができます）ことです。

バケットソートは計数ソートの拡張版です。関数のマッピング関係を利用しており、効率が良いかどうかの鍵はこのマッピング関数の決定にあります。バケットソートをより効率的にするために、次の2点を実現する必要があります：

  1. 追加の領域が十分にある場合は、できるだけバケットの数を増やします
  2. 使用するマッピング関数が、入力されたN個のデータをK個のバケットに均等に割り当てられるようにします

また、バケット内の要素のソートでは、どの比較ソートアルゴリズムを選ぶかがパフォーマンスに与える影響が非常に重要です。

アルゴリズムの手順：

  1. バケットの初期化：データの範囲と分布に基づいて、複数のバケットを作成します。

  2. 要素の割り当て：ソート対象のリストを走査し、各要素を対応するバケットに割り当てます。

  3. 各バケットのソート：各バケット内の要素をソートします（挿入ソートやクイックソートなどを使用できます）。

  4. バケットのマージ：すべてのバケットの要素を順番にマージして、最終的なソート結果を得ます。

1. いつ最速になるか

入力データが各バケットに均等に割り当てられる場合。

2. いつ最も遅くなるか

入力データが同じバケットに割り当てられる場合。

3. 模式図

バケット内の要素の分布：

次に、各バケット内で要素をソートします：

ソート対象のリスト [0.42, 0.32, 0.33, 0.52, 0.37, 0.47, 0.51] があるとします。バケットソートの手順は次のとおりです：

  1. バケットの初期化：

    • データ範囲が [0, 1) であると仮定し、10個のバケットを作成します。各バケットの範囲は0.1です。

    • バケット 0：[0.0, 0.1)

    • バケット 1：[0.1, 0.2)

    • ...

    • バケット 9：[0.9, 1.0)

  2. 要素の割り当て：

    • リストを走査し、要素を対応するバケットに割り当てます：

      • 0.42→ バケット 4

      • 0.32→ バケット 3

      • 0.33→ バケット 3

      • 0.52→ バケット 5

      • 0.37→ バケット 3

      • 0.47→ バケット 4

      • 0.51→ バケット 5

    • 割り当て後のバケット：

      • バケット 3：[0.32, 0.33, 0.37]

      • バケット 4：[0.42, 0.47]

      • バケット 5：[0.52, 0.51]

  3. 各バケットのソート：

    • 各バケット内の要素をソートします：

      • バケット 3：[0.32, 0.33, 0.37]（すでに整列済み）。

      • バケット 4：[0.42, 0.47]（すでに整列済み）。

      • バケット 5：[0.51, 0.52]（ソート後）。

  4. バケットのマージ：

    • すべてのバケットの要素を順番にマージします：

      • バケット 3：[0.32, 0.33, 0.37]

      • バケット 4：[0.42, 0.47]

      • バケット 5：[0.51, 0.52]

    • マージ後のリスト：[0.32, 0.33, 0.37, 0.42, 0.47, 0.51, 0.52]。

例

def bucket_sort(arr, bucket_size=10):
    if len(arr) == 0:
        return arr

    # 最小値と最大値を見つける
    min_val = min(arr)
    max_val = max(arr)

    # バケットを初期化する
    bucket_count = (max_val - min_val) // bucket_size + 1
    buckets = [[] for _ in range(bucket_count)]

    # 要素をバケットに割り当てる
    for num in arr:
        index = int((num - min_val) // bucket_size)
        buckets[index].append(num)

    # 各バケット内の要素をソートする
    sorted_arr = []
    for bucket in buckets:
        sorted_arr.extend(sorted(bucket))  # 組み込みのソート関数を使用する

    return sorted_arr

# 例
arr = [0.42, 0.32, 0.33, 0.52, 0.37, 0.47, 0.51]
sorted_arr = bucket_sort(arr)
print(sorted_arr)  # 出力: [0.32, 0.33, 0.37, 0.42, 0.47, 0.51, 0.52]

時間計算量

  • 要素の割り当て：O(n)。リストを1回走査します。

  • 各バケットのソート：各バケット内の要素数を m とすると、1つのバケットをソートする時間計算量は O(m log m) です。バケットの数が k の場合、合計時間計算量は O(k * m log m) になります。

  • バケットのマージ：O(n)。すべてのバケットを1回走査します。

  • 合計時間計算量：O(n + k * m log m)。ここで、n はリストの長さ、k はバケットの数、m は各バケットの平均要素数です。

空間計算量

  • O(n + k)。バケットとソート後の結果を格納するために、追加の記憶領域が必要です。

長所と短所

  • 長所：

    • データの分布が均等な場合、パフォーマンスが優れています。

    • 外部ソート（ディスクファイルのソートなど）に適しています。

  • 短所：

    • データの分布が不均等な場合、一部のバケット内の要素数が多すぎるため、パフォーマンスが低下します。

    • 追加の記憶領域が必要です。

適用シーン

  • データの分布が均等なシーン。

  • データ範囲が既知かつ有限であるシーン。

  • 外部ソート（ディスクファイルのソートなど）に適しています。

コード実装

JavaScript

例

function bucketSort(arr, bucketSize) {
    if (arr.length === 0) {
      return arr;
    }

    var i;
    var minValue = arr[0];
    var maxValue = arr[0];
    for (i = 1; i < arr.length; i++) {
      if (arr[i] < minValue) {
          minValue = arr[i];                // 入力データの最小値
      } else if (arr[i] > maxValue) {
          maxValue = arr[i];                // 入力データの最大値
      }
    }

    // バケットの初期化
    var DEFAULT_BUCKET_SIZE = 5;            // バケットのデフォルト数を5に設定する
    bucketSize = bucketSize || DEFAULT_BUCKET_SIZE;
    var bucketCount = Math.floor((maxValue - minValue) / bucketSize) + 1;  
    var buckets = new Array(bucketCount);
    for (i = 0; i < buckets.length; i++) {
        buckets[i] = [];
    }

    // マッピング関数を使用してデータを各バケットに割り当てる
    for (i = 0; i < arr.length; i++) {
        buckets[Math.floor((arr[i] - minValue) / bucketSize)].push(arr[i]);
    }

    arr.length = 0;
    for (i = 0; i < buckets.length; i++) {
        insertionSort(buckets[i]);                      // 各バケットをソートする。ここでは挿入ソートを使用
        for (var j = 0; j < buckets[i].length; j++) {
            arr.push(buckets[i][j]);                      
        }
    }

    return arr;
}

Java

例

public class BucketSort implements IArraySort {

    private static final InsertSort insertSort = new InsertSort();

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // arr をコピーし、引数の内容を変更しない
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        return bucketSort(arr, 5);
    }

    private int[] bucketSort(int[] arr, int bucketSize) throws Exception {
        if (arr.length == 0) {
            return arr;
        }

        int minValue = arr[0];
        int maxValue = arr[0];
        for (int value : arr) {
            if (value < minValue) {
                minValue = value;
            } else if (value > maxValue) {
                maxValue = value;
            }
        }

        int bucketCount = (int) Math.floor((maxValue - minValue) / bucketSize) + 1;
        int[][] buckets = new int[bucketCount][0];

        // マッピング関数を使用してデータを各バケットに割り当てる
        for (int i = 0; i < arr.length; i++) {
            int index = (int) Math.floor((arr[i] - minValue) / bucketSize);
            buckets[index] = arrAppend(buckets[index], arr[i]);
        }

        int arrIndex = 0;
        for (int[] bucket : buckets) {
            if (bucket.length <= 0) {
                continue;
            }
            // 各バケットをソートする。ここでは挿入ソートを使用
            bucket = insertSort.sort(bucket);
            for (int value : bucket) {
                arr[arrIndex++] = value;
            }
        }

        return arr;
    }

    /**
* 自動拡張してデータを保存する
     *
     * @param arr
     * @param value
     */
    private int[] arrAppend(int[] arr, int value) {
        arr = Arrays.copyOf(arr, arr.length + 1);
        arr[arr.length - 1] = value;
        return arr;
    }

}

function bucketSort($arr, $bucketSize = 5)
{
    if (count($arr) === 0) {
      return $arr;
    }

    $minValue = $arr[0];
    $maxValue = $arr[0];
    for ($i = 1; $i < count($arr); $i++) {
      if ($arr[$i] < $minValue) {
          $minValue = $arr[$i];
      } else if ($arr[$i] > $maxValue) {
          $maxValue = $arr[$i];
      }
    }

    $bucketCount = floor(($maxValue - $minValue) / $bucketSize) + 1;
    $buckets = array();
    for ($i = 0; $i < $bucketCount; $i++) {
        $buckets[$i] = [];
    }

    for ($i = 0; $i < count($arr); $i++) {
        $buckets[floor(($arr[$i] - $minValue) / $bucketSize)][] = $arr[$i];
    }

    $arr = array();
    for ($i = 0; $i < count($buckets); $i++) {
        $bucketTmp = $buckets[$i];
        sort($bucketTmp);
        for ($j = 0; $j < count($bucketTmp); $j++) {
            $arr[] = $bucketTmp[$j];
        }
    }

    return $arr;
}

C++

例

#include<iterator>
#include<iostream>
#include<vector>
using namespace std;
const int BUCKET_NUM = 10;

struct ListNode{
        explicit ListNode(int i=0):mData(i),mNext(NULL){}
        ListNode* mNext;
        int mData;
};

ListNode* insert(ListNode* head,int val){
        ListNode dummyNode;
        ListNode *newNode = new ListNode(val);
        ListNode *pre,*curr;
        dummyNode.mNext = head;
        pre = &dummyNode;
        curr = head;
        while(NULL!=curr && curr->mData<=val){
                pre = curr;
                curr = curr->mNext;
        }
        newNode->mNext = curr;
        pre->mNext = newNode;
        return dummyNode.mNext;
}


ListNode* Merge(ListNode *head1,ListNode *head2){
        ListNode dummyNode;
        ListNode *dummy = &dummyNode;
        while(NULL!=head1 && NULL!=head2){
                if(head1->mData <= head2->mData){
                        dummy->mNext = head1;
                        head1 = head1->mNext;
                }else{
                        dummy->mNext = head2;
                        head2 = head2->mNext;
                }
                dummy = dummy->mNext;
        }
        if(NULL!=head1) dummy->mNext = head1;
        if(NULL!=head2) dummy->mNext = head2;
       
        return dummyNode.mNext;
}

void BucketSort(int n,int arr[]){
        vector<ListNode*> buckets(BUCKET_NUM,(ListNode*)(0));
        for(int i=0;i<n;++i){
                int index = arr[i]/BUCKET_NUM;
                ListNode *head = buckets.at(index);
                buckets.at(index) = insert(head,arr[i]);
        }
        ListNode *head = buckets.at(0);
        for(int i=1;i<BUCKET_NUM;++i){
                head = Merge(head,buckets.at(i));
        }
        for(int i=0;i<n;++i){
                arr[i] = head->mData;
                head = head->mNext;
        }
}
