1.1 バブルソート

カテゴリ アルゴリズム

バブルソート（Bubble Sort）は、単純なソートアルゴリズムの一種で、ソート対象のリストを繰り返し走査し、隣接する要素を比較してそれらの位置を交換することでソートを実現します。このアルゴリズムの名前は、小さい要素が「泡」のように徐々にリストの先頭へ「浮かび上がる」ことに由来します。

1. アルゴリズムの手順

  1. 隣接する要素を比較：リストの最初の要素から始めて、隣接する2つの要素を比較します。

  2. 位置を交換：前の要素が後ろの要素より大きい場合、それらの位置を交換します。

  3. 繰り返し走査：リスト内の隣接する各要素のペアについて、リストの末尾に達するまで上記の手順を繰り返します。これにより、最大の要素がリストの最後に「泡」として浮かび上がります。

  4. 範囲を縮小：すでにソート済みの最後の要素を無視し、リスト全体がソート完了するまで上記の手順を繰り返します。

2. 動画デモ

ソート対象のリスト [5, 3, 8, 4, 6] があると仮定すると、バブルソートの過程は次のとおりです：

  1. 1回目の走査：

    • 5 と 3 を比較し、位置を交換すると、リストは次のようになります[3, 5, 8, 4, 6]。

    • 5 と 8 を比較し、交換しません。

    • 8 と 4 を比較し、位置を交換すると、リストは次のようになります[3, 5, 4, 8, 6]。

    • 8 と 6 を比較し、位置を交換すると、リストは次のようになります[3, 5, 4, 6, 8]。

    • 1回目の走査が終わると、最大の要素 8 がリストの最後に「泡」として浮かび上がっています。

  2. 2回目の走査：

    • 3 と 5 を比較し、交換しません。

    • 5 と 4 を比較し、位置を交換すると、リストは次のようになります[3, 4, 5, 6, 8]。

    • 5 と 6 を比較し、交換しません。

    • 2回目の走査が終わると、2番目に大きい要素 6 がリストの後ろから2番目の位置に「泡」として浮かび上がっています。

  3. 3回目の走査：

    • 3 と 4 を比較し、交換しません。

    • 4 と 5 を比較し、交換しません。

    • 3回目の走査が終わると、リストはすでに整列されています。

  4. 4回目の走査：

    • 3 と 4 を比較し、交換しません。

    • リストは完全に整列されています。

例

def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        # 交換が発生したかどうかを示すフラグ
        swapped = False
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                # 位置を交換
                arr[j], arr[j+1] = arr[j+1], arr[j]
                swapped = True
        # 交換が発生しなければ、リストはすでに整列されているため、早期に終了
        if not swapped:
            break
    return arr

# 例
arr = [5, 3, 8, 4, 6]
sorted_arr = bubble_sort(arr)
print(sorted_arr)  # 出力: [3, 4, 5, 6, 8]

3. 時間計算量

  • 最悪の場合：O(n²)、リストが逆順の場合。

  • 最良の場合：O(n)、リストがすでに整列されている場合。

  • 平均の場合：O(n²)。

4. 空間計算量

  • O(1)、バブルソートはインプレースソートアルゴリズムであり、追加の記憶領域を必要としないためです。

5. 長所と短所

  • 長所：

    • 実装が簡単で、コードが理解しやすい。

    • インプレースソートであり、追加の記憶領域を必要としない。

  • 短所：

    • 効率が低い、特に大規模なデータセットに対しては。

    • ほぼ整列済みのリストの処理には適さない、なぜなら依然として複数回の走査が必要だからです。

6. 最速になる場合

入力データがすでに昇順の場合（すでに昇順なら、バブルソートを使う意味があるでしょうか）。

7. 最も遅くなる場合

入力データが逆順の場合（for ループで逆順にデータを出力すればいいのに、どうしてバブルソートを使うんだ、暇なのか）。

8. JavaScript コード実装

例

function bubbleSort(arr) {
    var len = arr.length;
    for (var i = 0; i < len - 1; i++) {
        for (var j = 0; j < len - 1 - i; j++) {
            if (arr[j] > arr[j+1]) {        // 隣接する要素を2つずつ比較
                var temp = arr[j+1];        // 要素の交換
                arr[j+1] = arr[j];
                arr[j] = temp;
            }
        }
    }
    return arr;
}

11. Java コード実装

例

public class BubbleSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // arr をコピーし、引数の内容を変更しない
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        for (int i = 1; i < arr.length; i++) {
            // フラグを設定し、true の場合はこのループで交換が行われなかったことを示します。つまり、ソート対象のシーケンスがすでに整列されており、ソートが完了していることを意味します。
            boolean flag = true;

            for (int j = 0; j < arr.length - i; j++) {
                if (arr[j] > arr[j + 1]) {
                    int tmp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = tmp;

                    flag = false;
                }
            }

            if (flag) {
                break;
            }
        }
        return arr;
    }
}

14. C++ 言語

例

#include <iostream>
using namespace std;
template<typename T> //整数や浮動小数点数でも使用可能。クラス(class)や構造体(struct)を使用する場合は、大なり(>)演算子をオーバーロードする必要があります。
void bubble_sort(T arr[], int len) {
        int i, j;
        for (i = 0; i < len - 1; i++)
                for (j = 0; j < len - 1 - i; j++)
                        if (arr[j] > arr[j + 1])
                                swap(arr[j], arr[j + 1]);
}
int main() {
        int arr[] = { 61, 17, 29, 22, 34, 60, 72, 21, 50, 1, 62 };
        int len = (int) sizeof(arr) / sizeof(*arr);
        bubble_sort(arr, len);
        for (int i = 0; i < len; i++)
                cout << arr[i] << ' ';
        cout << endl;
        float arrf[] = { 17.5, 19.1, 0.6, 1.9, 10.5, 12.4, 3.8, 19.7, 1.5, 25.4, 28.6, 4.4, 23.8, 5.4 };
        len = (float) sizeof(arrf) / sizeof(*arrf);

        return 0;

15. C#

例

static void BubbleSort(int[] intArray) {
    int temp = 0;
    bool swapped;
    for (int i = 0; i < intArray.Length; i++)
    {
        swapped = false;
        for (int j = 0; j < intArray.Length - 1 - i; j++)
            if (intArray[j] > intArray[j + 1])
            {
                temp = intArray[j];
                intArray[j] = intArray[j + 1];
                intArray[j + 1] = temp;
                if (!swapped)
                    swapped = true;
            }
        if (!swapped)
            return;
    }
}
