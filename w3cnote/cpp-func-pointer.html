C++ 関数ポインタ & クラスメンバ関数ポインタ

カテゴリ プログラミング技術

一、関数ポインタ

関数はメモリのコード領域に格納されており、それらにもアドレスがあります。もし私たちにあるint test(int a)という関数があれば、そのアドレスは関数名です。これは配列と同じで、配列名は配列の開始アドレスです。

1、関数ポインタの定義方法

data_types (*func_pointer)( data_types arg1, data_types arg2, ...,data_types argn);

例えば：

int (*fp)(int a); // 这里就定义了一个指向函数(这个函数参数仅仅为一个 int 类型，函数返回值是 int 类型)的指针 fp。

実例

int test(int a) { return a; } int main(int argc, const char * argv[]) { int (*fp)(int a); fp = test; cout<<fp(2)<<endl; return 0; }

注意：関数ポインタが指す関数は、関数の戻り値の型、関数のパラメータの個数、型が一致している必要があります。

2、typedef定義は関数ポインタの定義を簡略化できる

実例

int test(int a) { return a; } int main(int argc, const char * argv[]) { typedef int (*fp)(int a); fp f = test; cout<<f(2)<<endl; return 0; }

3、関数ポインタも同様に関数のパラメータとして渡すことができる

実例

int test(int a) { return a-1; } int test2(int (*fun)(int),int b) { int c = fun(10)+b; return c; } int main(int argc, const char * argv[]) { typedef int (*fp)(int a); fp f = test; cout<<test2(f, 1)<<endl; // test2 を呼び出すとき、test関数のアドレスをパラメータとして test2 に渡しました return 0; }

上記のコードを実行すると、出力結果は次のようになります：

10

4、関数ポインタを利用して、関数ポインタ配列を構成できます。より明確に言うと、関数を指すポインタ配列を構成します。

実例

void t1(){cout<<"test1"<<endl;} void t2(){cout<<"test2"<<endl;} void t3(){cout<<"test3"<<endl;} int main(int argc, const char * argv[]) { typedef void (*fp)(void); fp b[] = {t1,t2,t3}; // b[] は関数を指すポインタ配列です b[0](); // 関数を指すポインタ配列を使って添字操作を行うことで、関数の間接呼び出しができます return 0; }

二、クラスメンバ関数を指す関数ポインタ

定義：クラスメンバ関数ポインタ（member function pointer）は、C++言語のポインタデータ型の一種であり、指定されたクラスが持つ、所定の仮引数リストと戻り値型を持つメンバ関数のアクセス情報を格納するために使用されます。

基本的に注意すべき点は2つあります：

  • 1、関数ポインタの代入には & を使用します&
  • 2、.* を使用します.*(インスタンスオブジェクト)または->*（インスタンスオブジェクトポインタ）を使用して、クラスメンバ関数ポインタが指す関数を呼び出します

以下に2つの例を見てみましょう：

A) クラスメンバ関数ポインタがクラス内の非静的メンバ関数を指す

についてnonstatic member function（非静的メンバ関数）アドレスを取得すると、その関数のメモリ上の実際のアドレスが得られます

についてvirtual function（仮想関数）、そのアドレスはコンパイル時には不明であるため、virtual member function（仮想メンバ関数）のアドレスを取得しても、得られるのは単なるインデックス値です

実例

//クラスメンバ関数を指す関数ポインタ #include <iostream> #include <cstdio> using namespace std; class A { public: A(int aa = 0):a(aa){} ~A(){} void setA(int aa = 1) { a = aa; } virtual void print() { cout << "A: " << a << endl; } virtual void printa() { cout << "A1: " << a << endl; } private: int a; }; class B:public A { public: B():A(), b(0){} B(int aa, int bb):A(aa), b(bb){} ~B(){} virtual void print() { A::print(); cout << "B: " << b << endl; } virtual void printa() { A::printa(); cout << "B: " << b << endl; } private: int b; }; int main(void) { A a; B b; void (A::*ptr)(int) = &A::setA; A* pa = &a; //非仮想関数の場合、メモリ上の実際のアドレスを返します printf("A::set(): %p\n", &A::setA); //仮想関数の場合、仮想関数テーブル上のオフセット位置を返します printf("B::print(): %p\n", &A::print); printf("B::print(): %p\n", &A::printa); a.print(); a.setA(10); a.print(); a.setA(100); a.print(); //クラスメンバ関数を指す関数ポインタの場合、参照する際にはクラスオブジェクトのthisポインタを渡す必要があるため、クラス実体から呼び出さなければなりません (pa->*ptr)(1000); a.print(); (a.*ptr)(10000); a.print(); return 0; }

上記のコードを実行すると、出力結果は次のようになります：

A::set(): 0x8048a38
B::print(): 0x1
B::print(): 0x5
A: 0
A: 10
A: 100
A: 1000
A: 10000

B) クラスメンバ関数ポインタがクラス内の静的メンバ関数を指す

実例

#include <iostream> using namespace std; class A{ public: //p1は非staticメンバ関数を指す関数ポインタです void (A::*p1)(void); //p2はstaticメンバ関数を指す関数ポインタです void (*p2)(void); A(){ /*について **非staticメンバ関数を指すポインタ **と **staticメンバ関数を指すポインタ **の変数の代入方法は同じで、どちらも&ClassName::memberVariableの形式です **違いは： **p1には非staticメンバ関数のみ代入できる **p2にはstaticメンバ関数のみ代入できる ** **また、代入時に&memberVariableを直接使用すると、VSでは"コンパイラエラー C2276"が報告されます **参照：http://msdn.microsoft.com/zh-cn/library/850cstw1.aspx*/ p1 =&A::funa; //関数ポインタの代入には必ず & を使用します p2 =&A::funb; //p1 =&A::funb;//error //p2 =&A::funa;//error //p1=&funa;//error,コンパイラエラー C2276 //p2=&funb;//error,コンパイラエラー C2276 } void funa(void){ puts("A"); } static void funb(void){ puts("B"); } }; int main() { A a; //pはA内の非staticメンバ関数を指す関数ポインタです void (A::*p)(void); (a.*a.p1)(); //Aを出力 //.*(インスタンスオブジェクト)または->*（インスタンスオブジェクトポインタ）を使用して、クラスメンバ関数ポインタが指す関数を呼び出します p = a.p1; (a.*p)();//Aを出力 A *b = &a; (b->*p)(); //Aを出力 /*a.p2自体は非static変数ですが、a.p2はstatic関数を指す関数ポインタです。 **なので次の文は間違いです！*/ // p = a.p2;//error void (*pp)(void); pp = &A::funb; pp(); //Bを出力 return 0; }

まとめ

クラスメンバ関数ポインタと通常の関数ポインタは同じものではありません。前者は.*.* と ->*>*演算子を使用しますが、後者は** 演算子を使用できます（"デリファレンス"dereference、または"間接参照"indirectionと呼ばれます）

通常の関数ポインタは実際には関数本体の開始アドレスを格納しているため、"コードポインタ"とも呼ばれ、C/C++で最も一般的に使用されるデータポインタと区別されます。

一方、クラスメンバ関数ポインタはクラスメンバ関数のメモリ上の開始アドレスだけでなく、C++の多重継承や仮想継承によって生じるクラスインスタンスアドレスの調整問題を解決する必要があるため、クラスメンバ関数ポインタを呼び出すときは必ずクラスインスタンスオブジェクトを渡さなければなりません。
