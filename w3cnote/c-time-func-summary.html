C言語におけるtime関数のまとめ

カテゴリ

プログラミングでは、時間の表現や変換に使う関数がよく用いられます。これらはすべてtime.hライブラリに関数として定義されています。ここでまとめて、後で参照しやすくします。

いくつかの時間の概念：

1：Coordinated Universal Time(UTC)：

協定世界時は、世界標準時とも呼ばれ、グリニッジ標準時(Greenwich Mean Time, GMT)と同じです。中国本土の時間とUTCの時差は+8、つまりUTC+8です。アメリカはUTC-5です。

2：Calendar Time：

暦時間は、「ある標準時点から現在までの経過秒数」で表される時間です。標準時点はコンパイラによって異なる場合がありますが、あるコンパイルシステムにとっては標準時は不変です。通常はUTC時間 1970-01-01 00:00:00 からの秒数で表されます。

3：epoch：

時間点。標準C/C++では整数であり、現在の時刻と標準時点との差の秒数（すなわち暦時間）で表されます。

4：clock tick：

クロック計時ユニット（クロックティック数とは呼ばない）。1つのクロック計時ユニットの時間の長さはCPUによって制御されます。clock tickはCPUのクロックサイクルではなく、C/C++の基本的な計時単位です。

time.h の定義

time.h ヘッダーファイルは、4つの変数型、2つのマクロ、および日付と時刻を操作するさまざまな関数を定義しています。

4つの変数

size_t 符号なし整数型であり、sizeof キーワードの結果です。
clock_t これはプロセッサ時間を格納するのに適した型で、型はunsigned longです。
time_t これは暦時間を格納するのに適した型です。
struct tm これは時刻と日付を保存するための構造体です。

tm 構造体の定義は次のとおりです：

struct tm
{
   int tm_sec;         /* 秒、範囲は0から59 */
   int tm_min;         /* 分、範囲は0から59 */
   int tm_hour;        /* 時、範囲は0から23 */
   int tm_mday;        /* 月の何日目か、範囲は1から31 */
   int tm_mon;         /* 月、範囲は0から11（注意） */
   int tm_year;        /* 1900年からの年数 */
   int tm_wday;        /* 週の何日目か、範囲は0から6 */
   int tm_yday;        /* 年の何日目か、範囲は0から365 */
   int tm_isdst;       /* 夏時間 */
};

2つのマクロ

NULL このマクロはヌルポインタ定数の値です。
CLOCKS_PER_SEC このマクロは1秒あたりのプロセッサクロック数を表します。clock()関数の結果を秒単位の量に変換するために使用されます。この量の具体的な値はオペレーティングシステムに依存し、通常は1000です。

ライブラリ関数

1：clock関数

関数プロトタイプ：clock_t clock(void)

関数の戻り値：clock関数の実行開始時（通常はプログラムの先頭）からプロセッサクロックが使用した時間を返します。

関数の機能：プログラムまたはプログラムの特定の区間の実行時間を計算するために使用します。

例

#include<stdio.h>
#include<time.h>

int main()
{
    clock_t start_t,finish_t;
    double total_t = 0;
    int i = 0;
    start_t = clock();
    for(;i<100000;++i)
    {
        //do someting;
    }
    finish_t = clock();
    total_t = (double)(finish_t - start_t) / CLOCKS_PER_SEC;//時間を秒に変換する

    printf("CPU が使用した合計時間：%f\n", total_t);
    return 0;
}

2：time関数

関数プロトタイプ: time_t time(time_t *timer)

パラメータの説明: timer=NULLの場合は現在の暦時間（1970-01-01 00:00:00から現在までの秒数）を取得します。timer=時刻値の場合は、暦時間を設定するために使用します。time_tはunsigned long型です。timerがNULLでない場合、戻り値は変数timerにも格納されます。

関数の機能: 現在の暦時間を取得するか、暦時間を設定します。

関数の戻り値: 現在の暦時間

例

#include <stdio.h>
#include <time.h>

int main ()
{
  time_t seconds;

  seconds = time(NULL);
  printf("1970-01-01 からの経過時間数 = %ld\n", seconds/3600);

  return(0);
}

3：asctime関数

関数プロトタイプ: char* asctime(struct tm * ptr)

関数の機能: 構造体struct tm * ptrが表す時刻を文字列で表現します。

関数の戻り値: 返される時刻文字列の形式は「曜日,月,日,時:分:秒,年」です。

パラメータの説明: 構造体ポインタptrはlocaltime()関数またはgmtime()関数で取得する必要があります。

例

#include <stdio.h>
#include <time.h>

int main()
{
   struct tm t;//より多くの場合、localtime関数およびgmtime関数によってtm構造体を取得します。

   t.tm_sec    = 10;
   t.tm_min    = 10;
   t.tm_hour   = 6;
   t.tm_mday   = 25;
   t.tm_mon    = 2;
   t.tm_year   = 89;
   t.tm_wday   = 6;

   printf("%s\n",asctime(&t));

   return(0);
}

4：localtime関数

関数プロトタイプ: struct tm *localtime(const time_t *timer)

関数の機能: timerの値を使用してtm構造体を埋めます。timerの値はtm構造体に分解され、ローカルタイムゾーンで表されます。

関数の戻り値: tm構造体で表される時刻

例

#include <stdio.h>
#include <time.h>

int main ()
{
   time_t timer;
   struct tm *Now;

   time( &timer );
   Now = localtime( &timer );
   printf(現在のローカル時刻と日付：%s, asctime(Now));

   return(0);
}

5：ctime関数

関数プロトタイプ: char *ctime(const time_t * timer)

関数の機能: 暦時間パラメータtimerを、ローカルの現在時刻を表す文字列に変換します。

関数の戻り値: 返される文字列の形式：「曜日,月,日,時:分:秒,年」

パラメータの説明: timerパラメータはtime関数で取得する必要があります。これは astime( localtime(timer) ) と同等です。

例

#include <stdio.h>
#include <time.h>

int main ()
{
   time_t curtime;
   time(&curtime);
   printf("現在時刻 = %s", ctime(&curtime));

   return(0);
}

6：difftime関数

関数プロトタイプ: double difftime(time_t time2, time_t time1)

関数の機能: 2つのマシン時刻の差を秒単位で取得します。

関数の戻り値: 時刻の差（秒単位）

パラメータの説明: time1, time2はそれぞれ異なるマシン時刻を表します。このパラメータはtime関数で取得する必要があります。

例

#include <time.h>  
#include <stdio.h>  
int main()  
{  
    time_t first,second;  
    time(&first);  
    sleep(2000);  
    time(&second);
    printf("The difference is: %f seconds",difftime(second,first));  

    return 0;  
}  

7：gmtime関数

関数プロトタイプ: struct tm *gmtime(time_t *timer)

関数の機能: 構造体tmで表される時刻情報を取得し、グリニッジ標準時で表します。

関数の戻り値: 構造体tmで表される時刻情報へのポインタ

パラメータの説明: timerはtime()関数で取得した時刻情報を使用します。

例

#include <stdio.h>
#include <time.h>

#define BST (+1)
#define CCT (+8)

int main ()
{

   time_t rawtime;
   struct tm *info;

   time(&rawtime);
   /* GMT 時刻を取得 */
   info = gmtime(&rawtime );

   printf("現在の世界時計：\n");
   printf("ロンドン：%2d:%02d\n", (info->tm_hour+BST)%24, info->tm_min);
   printf("中国：%2d:%02d\n", (info->tm_hour+CCT)%24, info->tm_min);

   return(0);
}

8：mktime関数

関数プロトタイプ：time_t mktime(struct tm *timeptr)

関数の機能：timeptrが指す構造体を、ローカルタイムゾーンに基づくtime_t値に変換します。

関数の戻り値：この関数は、パラメータで渡された暦時間に対応するtime_t値を返します。エラーが発生した場合は-1を返します。

例

#include <stdio.h>
#include <time.h>

int main ()
{
   int ret;
   struct tm info;
   char buffer[80];

   info.tm_year = 2001 - 1900;
   info.tm_mon = 7 - 1;
   info.tm_mday = 4;
   info.tm_hour = 0;
   info.tm_min = 0;
   info.tm_sec = 1;
   info.tm_isdst = -1;

   ret = mktime(&info);
   if( ret == -1 )
   {
       printf("エラー：mktimeを使用して時刻を変換できません。\n");
   }
   else
   {
      strftime(buffer, sizeof(buffer), "%c", &info );
      print(buffer);
   }

   return(0);
}

9：strftime関数

関数プロトタイプ: size_t strftime( char *strDest, size_t maxsize, const char *format, const struct tm *timeptr);

関数の機能: formatが指す文字列中の書式コマンドに従って、timeptrに保存されている時刻情報をstrDestが指す文字列に格納します。strDestには最大maxsize文字まで格納されます。

パラメータの説明: 変換結果はsに格納され、最大maxsize文字がsに書き込まれます。

関数の戻り値: この関数はstrDestが指す文字列に格納された文字数（'\0'を含まない）を返します。文字数がmaxsizeより多い場合は0を返します。

例

/* formatは以下のとおりです。これらは大文字と小文字を区別します。
%a 曜日の省略形
%A 曜日の完全な名前
%b 月の省略形
%B 月の完全な名前
%c 標準の日時文字列
%C 年の下2桁
%d 10進数で表した各月の第何日
%D 月/日/年
%e 2文字のフィールドで、10進数で表した各月の第何日
%F 年-月-日
%g 年の下2桁。週ベースの年を使用
%G 年。週ベースの年を使用
%h 月の省略名
%H 24時間制の時間
%I 12時間制の時間
%j 10進数で表した年の第何日
%m 10進数で表した月
%M 10進数で表した分
%n 改行文字
%p ローカルのAMまたはPMに相当する表示
%r 12時間制の時刻
%R 時間と分を表示：hh:mm
%S 10進数の秒
%t 水平タブ
%T 時分秒を表示：hh:mm:ss
%u 週の第何日。月曜日を週の初めとする（値は0から6、月曜日が0）
%U 年の第何週。日曜日を週の初めとする（値は0から53）
%V 年の第何週。週ベースの年を使用
%w 10進数で表した曜日（値は0から6、日曜日が0）
%W 年の第何週。月曜日を週の初めとする（値は0から53）
%x 標準の日付文字列
%X 標準の時刻文字列
%y 世紀を含まない10進数の年（値は0から99）
%Y 世紀を含む10進数の年
%z、%Z タイムゾーン名。タイムゾーン名を取得できない場合は空文字を返す。
%% パーセント記号
*/  

#include <stdio.h>
#include <time.h>

int main ()
{
   time_t rawtime;
   struct tm *info;
   char buffer[80];

   time( &rawtime );

   info = localtime( &rawtime );

   strftime(buffer,80,"%Y%m%e_%H%M%S", info);//現在時刻を年_月_日_時分秒の形式で表す
   printf("%s\n", buffer );

   return(0);
}
