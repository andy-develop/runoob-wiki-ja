1.0 Hadoop チュートリアル

カテゴリ Hadoop チュートリアル

Hadoop は、Apache 財団によって開発・保守されているオープンソースの分散計算・ストレージフレームワークです。

Hadoop は、大規模なコンピュータクラスタに信頼性が高くスケーラブルなアプリケーション層の計算・ストレージサポートを提供します。単純なプログラミングモデルを使用して、コンピュータクラスタ全体で大規模データセットを分散処理できるようにし、単一のコンピュータから数千台のコンピュータまでの拡張をサポートします。

Hadoop は Java で開発されているため、さまざまなハードウェアプラットフォームのコンピュータに導入して使用できます。その中核コンポーネントには、分散ファイルシステム (Hadoop DFS、HDFS) と MapReduce が含まれます。

Hadoop の歴史

2003年と2004年に、Google は GFS と MapReduce という2つの有名な論文を相次いで発表しました。

この2つの論文と2006年に発表された BigTable は、現在有名な「Google 三大論文」となりました。

Doug Cutting はこれらの理論の影響を受け、Hadoop の開発を開始しました。

Hadoop には2つの中核コンポーネントが含まれています。Google の論文では、GFS は大規模なコンピュータクラスタ上で動作する分散ファイルシステムであり、Hadoop では HDFS がその機能を実装しています。MapReduce は分散計算の方法であり、Hadoop は同名の MapReduce フレームワークでその機能を実装しています。これについては、後の MapReduce の章で詳しく説明します。 2008年以降、Hadoop は Apache のトップレベルプロジェクトとして存在しています。Hadoop とその多くのサブプロジェクトは、Yahoo、Alibaba、Tencent などの大規模なネットワークサービス企業で広く使用されており、IBM、Intel、Microsoft などのプラットフォーム企業によってサポート対象として挙げられています。

Hadoop の役割

Hadoop の役割は非常に単純です。つまり、複数のコンピュータからなるクラスタ環境に、統一された安定したストレージと計算環境を構築し、他の分散アプリケーションサービスにプラットフォームサポートを提供することです。

つまり、Hadoop はある意味で複数のコンピュータを1台のコンピュータ（同じことを行う）として組織化します。その場合、HDFS はこのコンピュータのハードディスクに相当し、MapReduce はこのコンピュータの CPU コントローラーに相当します。
