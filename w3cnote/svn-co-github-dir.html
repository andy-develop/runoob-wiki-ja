svn を使用して github 上の単一のディレクトリまたはファイルをダウンロードする

分类 编程技术

GitHub上のプロジェクトは、git cloneを使用するとプロジェクト全体しかダウンロードできません。時には単一のディレクトリやファイルだけが必要な場合もありますが、そのような場合はsvnコマンドを使用して操作することができます。

主な変更箇所は、開いたディレクトリファイルのURL内にあります：以下を/tree/master/（或/tree/分支/） 换成/trunk/ 。

实例 1 ：/tree/master/

例えば、コピーしたいのはhttps://github.com/Mooophy/Cpp-Primerプロジェクトの下の ch03 ディレクトリです。

1、まずマウスでch03ディレクトリをクリックして開き、URLアドレスをコピーします：

https://github.com/Mooophy/Cpp-Primer/tree/master/ch03

2、/tree/master/ を /trunk/ に置き換え、svn コマンドを使用してチェックアウトします:

svn co https://github.com/Mooophy/Cpp-Primer/trunk/ch03

例 2 ：/tree/ブランチ/

例えば、ダウンロードしたいのはhttps://github.com/numbbbbb/the-swift-programming-language-in-chinese/下のsource目录。

1、先点击打开 source 目录，复制 URL 地址：
https://github.com/numbbbbb/the-swift-programming-language-in-chinese/tree/gh-pages/source

将 /tree/gh-pages/ 换成 /trunk/。

2、その後、以下のコマンドを入力すれば読み込むことができます。

svn co https://github.com/numbbbbb/the-swift-programming-language-in-chinese/trunk/source
