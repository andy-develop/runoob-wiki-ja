AWK配列

カテゴリ プログラミング技術

　

AWKは連想配列というデータ構造を使用でき、インデックスは数字または文字列にすることができます。

AWKの連想配列はサイズを事前に宣言する必要もなく、実行時に自動的に拡大または縮小できます。

配列を使用する構文形式：

array_name[index]=value
  • array_name：配列の名前
  • index：配列インデックス
  • value：配列内の要素に割り当てられる値

配列の作成

次に、配列の作成方法と配列要素へのアクセス方法を見てみましょう。

$ awk 'BEGIN {
sites["サンプル"]="www.example.com";
sites["google"]="www.google.com"
print sites["サンプル"] "\n" sites["google"]
}'

上記のコマンドを実行すると、出力結果は次のようになります。

www.example.com
www.google.com

上記の例では、サイト(sites)配列を定義しました。この配列のインデックスはウェブサイトの英語略称で、値はウェブサイトのアクセスアドレスです。次の形式で配列要素にアクセスできます。

array_name[index]

配列要素の削除

delete 文を使用して配列要素を削除できます。構文形式は次のとおりです。

delete array_name[index

次の例では、配列内のgoogle要素が削除されます（削除コマンドは出力を行いません）。

$ awk 'BEGIN {
sites["サンプル"]="www.example.com";
sites["google"]="www.google.com"
delete sites["google"];
print fruits["google"]
}'

多次元配列

AWK自体は多次元配列をサポートしていませんが、1次元配列を使用して多次元配列を簡単にシミュレートできます。

次の例は、3x3の2次元配列です。

100 200 300
400 500 600
700 800 900

上記の例では、array

インデックスとして0,0を使用しましたが、これは2つのインデックス値ではありません。実際には、これは文字列インデックス0,0です。

次は2次元配列をシミュレートする例です。

$ awk 'BEGIN {
array["0,0"] = 100;
array["0,1"] = 200;
array["0,2"] = 300;
array["1,0"] = 400;
array["1,1"] = 500;
array["1,2"] = 600;
# 输出数组元素
print "array[0,0] = " array["0,0"];
print "array[0,1] = " array["0,1"];
print "array[0,2] = " array["0,2"];
print "array[1,0] = " array["1,0"];
print "array[1,1] = " array["1,1"];
print "array[1,2] = " array["1,2"];
}'

上記のコマンドを実行すると、次の結果が得られます。

array[0,0] = 100
array[0,1] = 200
array[0,2] = 300
array[1,0] = 400
array[1,1] = 500
array[1,2] = 600

配列に対しては多くの操作を実行できます。たとえば、asortを使用して配列要素の並べ替えを行ったり、asortiを使用して配列インデックスの並べ替えを実現したりできます。
