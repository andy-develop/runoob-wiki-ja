2.1 ES6 let と const

カテゴリ ES6 チュートリアル

ES2015(ES6) では、2つの重要な JavaScript キーワードが新たに追加されました:letとconst。

let で宣言された変数は、let コマンドが存在するコードブロック内でのみ有効です。

const は読み取り専用の定数を宣言し、一度宣言すると、定数の値は変更できません。

let コマンド

基本的な使い方:

{ let a = 0; a // 0 } a //エラー ReferenceError: a is not defined

コードブロック内で有効

let はコードブロック内で有効であり、var はグローバルスコープで有効です:

{ let a = 0; var b = 1; } a // ReferenceError: a is not defined b // 1

重複宣言は不可

let は一度しか宣言できません。var は複数回宣言できます:

let a = 1; let a = 2; var b = 3; var b = 4; a // Identifier 'a' has already been declared b // 4

for ループのカウンターには let を使うのが最適です

for (var i = 0; i < 10; i++) { setTimeout(function(){ console.log(i); }) } //10 が10個出力されます for (let j = 0; j < 10; j++) { setTimeout(function(){ console.log(j); }) } //0123456789 が出力されます

変数 i は var で宣言されているため、グローバルスコープで有効です。つまり、グローバルには変数 i が1つしかありません。ループのたびに、setTimeout タイマー内の i はグローバル変数 i を指します。そして、ループ内の10個の setTimeout はループ終了後に実行されるため、このときの i はすべて 10 になります。

変数 j は let で宣言されているため、現在の j は今回のループ内でのみ有効です。ループごとの j は実際には新しい変数なので、setTimeout タイマー内の j は実に異なる変数となり、最終的に 12345 が出力されます。（ループごとに変数 j が再宣言される場合、前のループの値をどうやって知るのでしょうか？これは JavaScript エンジンが内部的に前のループの値を記憶しているためです）。

変数巻き上げが存在しない

let は変数巻き上げがなく、var は変数巻き上げが発生します:

console.log(a); //ReferenceError: a is not defined let a = "apple"; console.log(b); //undefined var b = "banana";

変数 b は var で宣言されているため変数巻き上げが発生します。スクリプトの実行開始時点で b はすでに存在していますが、まだ代入されていないため、undefined が出力されます。

変数 a は let で宣言されているため変数巻き上げがなく、変数 a を宣言する前に a は存在しないので、エラーになります。

const コマンド

const は読み取り専用の変数を宣言し、宣言後は変更が許可されません。つまり、一度宣言したら初期化が必要であり、そうでなければエラーになります。

基本的な使い方:

const PI = "3.1415926";
PI  // 3.1415926

const MY_AGE;  // SyntaxError: Missing initializer in const declaration

一時的デッドゾーン:

var PI = "a";
if(true){
  console.log(PI);  // Cannot access 'PI' before initialization
  const PI = "3.1415926";
}

ES6 では明確に規定されており、コードブロック内に let または const が存在する場合、コードブロックはこれらのコマンドで宣言された変数に対してブロックの開始時点から閉じたスコープを形成します。コードブロック内で、変数 PI を宣言する前にそれを使用するとエラーになります。

注意点

const はどうやって変数が宣言・初期化された後に変更を許可しないのでしょうか？実際、const が保証するのは変数の値が変わらないことではなく、変数が指すメモリアドレスに保存されたデータの変更が許可されないことです。ここで、単純型と複合型では値の保存方法が異なることにお気づきかもしれません。その通りです。単純型（数値 number、文字列 string、ブール値 boolean）の場合、値は変数が指すメモリアドレスに保存されるため、const で宣言された単純型の変数は定数と同等です。一方、複合型（オブジェクト object、配列 array、関数 function）の場合、変数が指すメモリアドレスには実際のデータを指すポインタが保存されています。そのため、const はポインタが固定されていることだけを保証でき、ポインタが指すデータ構造が変わるかどうかは制御できません。したがって、const で複合型オブジェクトを宣言する際には注意が必要です。
