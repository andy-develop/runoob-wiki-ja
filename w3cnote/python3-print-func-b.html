Python3 print 関数の使い方まとめ

カテゴリ プログラミング技術

1. 文字列と数値を出力する

>>>print("runoob") # 文字列を出力 runoob >>> print(100) # 数値を出力 100 >>> str = 'runoob' >>> print(str) # 変数を出力 runoob >>> L = [1,2,'a'] # リスト >>> print(L) [1, 2, 'a'] >>> t = (1,2,'a') # タプル >>> print(t) (1, 2, 'a') >>> d = {'a':1, 'b':2} # 辞書 >>> print(d) {'a': 1, 'b': 2}

2. 整数をフォーマットして出力する

パラメータフォーマットをサポートしており、C言語のprintfと似ています。

>>>str = "the length of (%s) is %d" %('runoob',len('runoob')) >>> print(str) the length of (runoob) is 6

Pythonの文字列フォーマット記号:

記号 説明
      %c文字とそのASCIIコードをフォーマット
      %s文字列をフォーマット
      %d整数をフォーマット
      %u符号なし整数をフォーマット
      %o符号なし8進数をフォーマット
      %x符号なし16進数をフォーマット
      %X符号なし16進数をフォーマット（大文字）
      %f浮動小数点数をフォーマットし、小数点以下の精度を指定可能
      %e科学表記法で浮動小数点数をフォーマット
      %E%eと同じ機能で、科学表記法で浮動小数点数をフォーマット
      %g%fと%eの略記
      %G%fと%Eの略記
      %p16進数で変数のアドレスをフォーマット

フォーマット演算子の補助指定:

記号機能
*幅または小数点以下の精度を定義
-左揃えに使用
+正の数の前にプラス記号(+)を表示
<sp>正の数の前にスペースを表示
#8進数の前にゼロ('0')を表示し、16進数の前に'0x'または'0X'を表示（'x'か'X'かによって異なる）
0表示する数字の前にデフォルトのスペースではなく'0'を埋める
%'%%'で単一の'%'を出力
(var)変数をマッピング（辞書パラメータ）
m.n.mは表示する最小の全体幅、nは小数点以下の桁数です（使用可能な場合）

3. 16進数、10進数、8進数の整数をフォーマットして出力する

#%x--- hex 16進数

#%d--- dec 10進数

#%o--- oct 8進数

>>>nHex = 0xFF >>> print("nHex = %x,nDec = %d,nOct = %o" %(nHex,nHex,nHex)) nHex = ff,nDec = 255,nOct = 377

4. 浮動小数点数(float)をフォーマットして出力する

>>>pi = 3.141592653 >>> print('%10.3f' % pi) #フィールド幅10、精度3 3.142 >>> print("pi = %.*f" % (3,pi)) #*を使用して後方のタプルからフィールド幅または精度を読み取る pi = 3.142 >>> print('%010.3f' % pi) #0で空白を埋める 000003.142 >>> print('%-10.3f' % pi) #左揃え 3.142 >>> print('%+f' % pi) #正負の符号を表示 +3.141593

5. 自動改行

printは自動的に行末に改行を追加します。改行が不要な場合は、print文の末尾にカンマを追加するだけです。,さらに、区切り文字パラメータendを設定することで、その動作を変更できます。
>>>for i in range(0,6): ... print(i) ... 0 1 2 3 4 5 >>> for i in range(0,6): ... print(i, end=" ") ... 0 1 2 3 4 5

6. printで改行しない

Pythonではprintはデフォルトで改行します:

>>>for i in range(0,3): ... print (i) ... 0 1 2 >>>

改行しないようにするには、次のように書く必要があります。print(i, end = '' )

>>>for i in range(0,3): ... print(i, end = '' ) ... 012
