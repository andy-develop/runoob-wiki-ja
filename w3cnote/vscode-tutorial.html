VScode入門チュートリアル

カテゴリ プログラミング技術

VSCode（正式名称：Visual Studio Code）は、マイクロソフトが開発したクロスプラットフォームの無料ソースコードエディターです。このソフトウェアは、シンタックスハイライト、コード自動補完（IntelliSenseとも呼ばれる）、コードリファクタリング、定義の表示機能をサポートし、コマンドラインツールとGitバージョン管理システムを内蔵しています。ユーザーはテーマやキーボードショートカットを変更してパーソナライズ設定を行うことができ、内蔵の拡張機能ストアから拡張機能をインストールしてソフトウェアの機能を拡張することもできます。

VS Codeは、その基盤となるコードエディターとしてMonaco Editorを使用しています。

2019年にStack Overflowが実施した開発者調査において、Visual Studio Codeは開発者に最も人気のある開発環境と見なされました。

Visual Studio Codeは、JavaScript、TypeScript、CSS、HTMLなどの多くのプログラミング言語をデフォルトでサポートしています。また、拡張機能をダウンロードすることで、Python、C/C++、Java、Goなどの他の言語もサポートできます。サポートされる機能には、シンタックスハイライト、括弧の自動補完、コード折りたたみ、コードスニペットがあります。一部の言語では、IntelliSenseを使用できます。Visual Studio CodeはNode.jsプログラムのデバッグもサポートしています。GitHubのAtomと同様に、Visual Studio CodeもElectronフレームワークに基づいて構築されています。

Visual Studio Codeは、複数のディレクトリを同時に開くことができ、情報をワークスペースに保存して再利用できるようにします。

クロスプラットフォームのエディターとして、Visual Studio Codeはユーザーがファイルのコードページ、改行文字、プログラミング言語を変更することを可能にします。
