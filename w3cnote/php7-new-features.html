PHP 7 の新機能

カテゴリ PHP よく使う実例

スカラー型宣言

PHP 7 では関数の仮引数の型宣言にスカラー型を使用できます。PHP 5 ではクラス名、インターフェース、array または callable (PHP 5.4、つまり関数を含む匿名関数) のみでしたが、現在では string、int、float、bool も使用できます。

<?php
// 强制模式
function sumOfInts(int ...$ints)
{
    return array_sum($ints);
}

var_dump(sumOfInts(2, '3', 4.1));

上記の例の出力は次のとおりです。

int(9)

上記の厳格モードに関する注意点はここでも同様に適用されます。強制モード（デフォルト、つまり型強制）では想定外のパラメータに対して強制的に型変換が行われますが、厳格モードでは TypeError の致命的なエラーが発生します。

戻り値の型宣言

PHP 7 では戻り値の型宣言のサポートが追加されました。パラメータの型宣言と同様に、戻り値の型宣言は関数の戻り値の型を指定します。使用できる型はパラメータ宣言で使用できる型と同じです。

<?php

function arraysSum(array ...$arrays): array
{
    return array_map(function(array $array): int {
        return array_sum($array);
    }, $arrays);
}

print_r(arraysSum([1,2,3], [4,5,6], [7,8,9]));

上記の例の出力は次のとおりです。

Array
(
    [0] => 6
    [1] => 15
    [2] => 24
)

NULL 合体演算子

日常的に三項演算子と isset() を同時に使うケースが多くありますが、NULL 合体演算子は変数が存在し、値が NULL でない場合にその値を返し、それ以外の場合は第2オペランドを返します。

例は次のとおりです。

<?php
// 如果 $_GET['user'] 不存在返回 'nobody'，否则返回 $_GET['user'] 的值
$username = $_GET['user'] ?? 'nobody';
// 类似的三元运算符
$username = isset($_GET['user']) ? $_GET['user'] : 'nobody';
?>

スペースシップ演算子（組み合わせ比較演算子）

スペースシップ演算子は2つの式を比較するために使用されます。$a が $b より大きい場合、等しい場合、小さい場合に、それぞれ -1、0、1 を返します。

例は次のとおりです。

<?php
// 整型
echo 1 <=> 1; // 0
echo 1 <=> 2; // -1
echo 2 <=> 1; // 1

// 浮点型
echo 1.5 <=> 1.5; // 0
echo 1.5 <=> 2.5; // -1
echo 2.5 <=> 1.5; // 1
 
// 字符串
echo "a" <=> "a"; // 0
echo "a" <=> "b"; // -1
echo "b" <=> "a"; // 1
?>

define() による定数配列の定義

例は次のとおりです。

<?php
define('ANIMALS', [
    'dog',
    'cat',
    'bird'
]);

echo ANIMALS[1]; // 输出 "cat"
?>

無名クラス

現在では new class による無名クラスのインスタンス化をサポートしています。例は次のとおりです。

<?php
interface Logger {
    public function log(string $msg);
}

class Application {
    private $logger;

    public function getLogger(): Logger {
         return $this->logger;
    }

    public function setLogger(Logger $logger) {
         $this->logger = $logger;
    }
}

$app = new Application;
$app->setLogger(new class implements Logger {
    public function log(string $msg) {
        echo $msg;
    }
});

var_dump($app->getLogger());
?>

上記の例の出力は次のとおりです。

object(class@anonymous)#2 (0) {
}

Unicode codepoint エスケープ構文

これは16進数形式の Unicode コードポイントを受け入れ、二重引用符または heredoc で囲まれた UTF-8 エンコード形式の文字列を出力します。任意の有効なコードポイントを受け入れることができ、先頭の 0 は省略可能です。

echo "\u{aa}";
echo "\u{0000aa}";
echo "\u{9999}";

上記の例の出力は次のとおりです。

ª
ª (same as before but with optional leading 0's)
香

Closure::call()

Closure::call() はより良いパフォーマンスを持ち、メソッドをオブジェクトのクロージャに一時的にバインドして呼び出すことを簡潔に行えます。

<?php
class A {private $x = 1;}

// Pre PHP 7 代码
$getXCB = function() {return $this->x;};
$getX = $getXCB->bindTo(new A, 'A'); // intermediate closure
echo $getX();

// PHP 7+ 代码
$getX = function() {return $this->x;};
echo $getX->call(new A);

上記の例の出力は次のとおりです。

1
1

unserialize() へのフィルタリング提供

この機能は、信頼できないデータをより安全にアンパック（復元）する方法を提供することを目的としています。ホワイトリスト方式により、潜在的なコードインジェクションを防ぎます。

<?php

// 转换对象为 __PHP_Incomplete_Class 对象
$data = unserialize($foo, ["allowed_classes" => false]);

// 转换对象为 __PHP_Incomplete_Class 对象，除了 MyClass 和 MyClass2
$data = unserialize($foo, ["allowed_classes" => ["MyClass", "MyClass2"]);

// 默认接受所有类
$data = unserialize($foo, ["allowed_classes" => true]);

IntlChar

新しく追加された IntlChar クラスは、より多くの ICU 機能を公開することを目的としています。このクラスは、複数文字セットの Unicode 文字を操作するための多くの静的メソッドを定義しています。

<?php
printf('%x', IntlChar::CODEPOINT_MAX);
echo IntlChar::charName('@');
var_dump(IntlChar::ispunct('!'));

上記の例の出力は次のとおりです。

10ffff
COMMERCIAL AT
bool(true)

このクラスを使用するには、まず Intl 拡張機能をインストールしてください。

期待

期待は、以前の assert() と後方互換性があり、それを拡張する方法です。これにより、本番環境でアサーションを有効にしてもコストがゼロになり、アサーションが失敗したときに特定の例外をスローする機能を提供します。

<?php
ini_set('assert.exception', 1);

class CustomError extends AssertionError {}

assert(false, new CustomError('Some error message'));
?>

上記の例の出力は次のとおりです。

Fatal error: Uncaught CustomError: Some error message

use の拡張

同じ namespace からインポートするクラス、関数、定数は、現在では単一の use 文で一度にインポートできます。

<?php

//  PHP 7 之前版本用法
use some\namespace\ClassA;
use some\namespace\ClassB;
use some\namespace\ClassC as C;

use function some\namespace\fn_a;
use function some\namespace\fn_b;
use function some\namespace\fn_c;

use const some\namespace\ConstA;
use const some\namespace\ConstB;
use const some\namespace\ConstC;

// PHP 7+ 用法
use some\namespace\{ClassA, ClassB, ClassC as C};
use function some\namespace\{fn_a, fn_b, fn_c};
use const some\namespace\{ConstA, ConstB, ConstC};
?>

ジェネレータの拡張

ジェネレータの機能が拡張され、多くの高度な機能を実現できます。

<?php
<?php

function gen()
{
    yield 1;
    yield 2;

    yield from gen2();
}

function gen2()
{
    yield 3;
    yield 4;
}

foreach (gen() as $val)
{
    echo $val, PHP_EOL;
}

?>

上記の例の出力は次のとおりです。

1
2
3
4

整数除算

整数除算関数 intdiv() が新しく追加されました。使用例：

<?php
var_dump(intdiv(10, 3));
?>

上記の例の出力は次のとおりです。

int(3)
