開発者に最も人気のある15のAndroidコードエディタ

カテゴリ プログラミング技術

スマートフォンやタブレットなどのAndroidデバイスで、いつでもどこでもコードを書けるようにしたいなら、以下で紹介する15のAndroidコードエディタをぜひチェックしてみてください。きっとあなたの理想的なツールになるはずです。

1.Deuter IDE

モバイル開発向けのテキストエディタ、オンラインコンパイラ、Android対応の統合開発環境を内蔵したアプリです。仮想キーはよく使うプログラミング記号やシンタックスハイライト機能を提供し、40以上のプログラミング言語に対応しているため、移動中にコードを書くことがこれまでになく簡単になります。

公式サイト：https://play.google.com/store/apps/details?id=com.didactic.DeuterIDE

2.DroidEdit

DroidEditは、Androidタブレットとスマートフォンをサポートするテキストおよびソースコードエディタです（geditに類似）。以下の機能を備え、いくつかのプログラミング言語（C、C++、C#、Java、HTML、CSS、JavaScript、Python、Ruby、Lua、LaTeX、SQLなど）のシンタックスハイライトをサポートしています。

公式サイト：https://play.google.com/store/apps/details?id=com.aor.droidedit&feature=also_installed

3.Code Peeker

ソースコードを読むときにシンタックスハイライト、スニペット検索、クイックフィックスだけが必要なら、Code Peekerを選びましょう！これは小型のコードリーダーで、過去のコーディング専門知識をハイライトすることで、現在のコーディング知識を向上させます。

公式サイト：https://play.google.com/store/apps/details?id=twig.nguyen.codepeeker

4.Code Me Silly

Code Me Sillyは「WYSIWYG」エディタではありません…シンタックスハイライト対応のHTML、CSS、JavaScript、PHPエディタです。このアプリはPython、Java、C、C++、CoffeeScript、Haskell、Clojure、Groovyもサポートしていますが、主にWeb開発向けです。Code Me Sillyは検索/置換、元に戻す、やり直し機能を提供します。

公式サイト：https://play.google.com/store/apps/details?id=com.hoodwebmedia.hello

5.Java Code Viewer

Java CodeViewer（Java Code Viewer）——CodeViewerはテキストビューア、Javaビューア、C#ビューア、その他のAndroid対応プログラミング言語ビューアです。Java、C#、C/C++、CSS、PHP、ASP、JavaScriptのシンタックスハイライトをサポートしています。

公式サイト：https://play.google.com/store/apps/details?id=org.codein.codeviewer

6.AIDE—Android IDE—Java，C ++

AIDEは、Androidデバイス上で本格的なAndroidアプリを直接開発できる統合開発環境（IDE）です。ステップバイステップの手順で、アプリ開発のエキスパートになれます。機能：ビジュアルなアプリデザイン、多機能なコードエディタ、リアルタイムエラーチェック、リファクタリングとスマートコードナビゲーション、ワンクリックでのアプリ実行。

公式サイト：https://play.google.com/store/apps/details?id=com.aide.ui

7.JavaIDEdroid

JavaIDEdroidは初心者プログラマーには適していません。その役割はAIDEに似ており、Androidデバイス上で直接Androidアプリを作成できます。ただし、JavaIDEdroidはユーザーフレンドリーとは言えず、外観よりも機能を重視するユーザーに向いています。

公式サイト：https://play.google.com/store/apps/details?id=com.t_arn.JavaIDEdroid&feature=also_installed

8.Terminal IDE

Terminal IDEは拡張可能なターミナルアプリで、Androidデバイス上で動作する完全なJava / C / C++ / HTML / Android開発キットです。コマンドラインを使用し、多くの強力で堅牢なオープンソースアプリケーションを備えています。さらに、画面上のカスタムASCII「ソフト」キーボード（デバイスのメインキーボード設定で有効にする必要があります）や、広く一般的な外部「ハード」キーボードのキーマッピングも備えています。CTRL / ALT / ESCなどにアクセスできます。

公式サイト：https://play.google.com/store/apps/details?id=com.spartacusrex.spartacuside

9.C4droid—C / C ++ comliler&IDE

C4droidは、Androidデバイスで使用できる典型的なCコンパイラです。Unixで一般的に使用されるgccコンパイラを使用しています。C4droidのインストールは少し厄介な場合があるので、そのつもりでいてください。

公式サイト：https://play.google.com/store/apps/details?id=com.n0n3m4.droidc

10.MobileC（Offline Compiler）

C/C++コンパイラは、完全互換のC/C++コンパイラと言われています。しかし、実際にはCコードのみをコンパイルでき、C++には対応していません。とはいえ、Cコンパイラは正常に動作するようなので、Cコンパイラが必要な場合には非常に役立つでしょう。

公式サイト：https://play.google.com/store/apps/details?id=GDE.Main

11.C＃To Go

え、C#を使いたいのに、気に入ったものが見つからない？はは、それなら小型のC#コンパイラであるC# To Goが、いつでも使えるお気に入りのツールになるでしょう。

公式サイト：https://play.google.com/store/apps/details?id=com.gregshackles.csharptogo

12.C++, Java Programs & Reference

テストや面接の準備に最適なプログラムとリファレンスのコレクションです。このアプリには、Java、C++、Intel 8086のリファレンスが含まれています。Aiutoは無料のリファレンスアプリです。

公式サイト：https://play.google.com/store/apps/details?id=in.nishitp.aiuto&hl=en

13.AWD—PHP / HTML / CSS / JS IDE

Android Web Developer（AWD）は、Web開発をサポートするIDE（統合開発環境）です。以下の言語とフォーマットをサポートしています：PHP、CSS、JS、HTML、JSON。

公式サイト：https://play.google.com/store/apps/details?id=org.kidinov.awd

14.Quoda Code Editor

Quodaは複雑でありながら使いやすいソースコードエディタであり、いくつかの強力な機能を備えたIDEでもあります——テーマ別シンタックスハイライト、セッションをまたいだ編集、コード補完、タブストップと変数のスニペットなど。

公式サイト：https://play.google.com/store/apps/details?id=com.henrythompson.quoda&hl=en

15.920 Text Editor

920 Text Editorは、Androidスマートフォンで動作する強力なテキストエディタです。どこにいても、コードを簡単に表示・編集できます。さらに、電子書籍リーダーとしてTXT小説を開くこともできます。

公式サイト：https://play.google.com/store/apps/details?id=com.jecelyin.editor
