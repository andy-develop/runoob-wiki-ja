2.5.4 AutoCompleteTextView（自動補完テキストボックス）の基本的な使い方

カテゴリ Android 基礎入門チュートリアル

この節の前置き：

この節では引き続きAdapterクラスのコントロールを学んでいきます。今回はAutoCompleteTextView（自動補完テキストボックス）を取り上げます。注意深いあなたならお気づきでしょうが、Adapterに関係するコントロールは、どれもitemのスタイルを自分で定義できますよね！つまり各Itemのレイアウトも自由自在にカスタマイズできます～さて、余談はこのくらいにして、この節の内容を始めましょう～そうそう、公式APIも載せておきます：AutoCompleteTextView

1. 関連属性：

  • android:completionHint：ドロップダウンメニュー内のヒントタイトルを設定します
  • android:completionHintView：ドロップダウンメニューを表示するヒントビューを定義します
  • android:completionThreshold：ヒントを表示するためにユーザーが最低でも何文字入力する必要があるかを指定します
  • android:dropDownAnchor：ドロップダウンメニューの位置決め「アンカー」コンポーネントを設定します。この属性が指定されていない場合、このTextViewが位置決め「アンカー」コンポーネントとして使用されます。
  • android:dropDownHeight：ドロップダウンメニューの高さを設定します
  • android:dropDownWidth：ドロップダウンメニューの幅を設定します
  • android:dropDownHorizontalOffset：ドロップダウンメニューとテキスト間の水平間隔を指定します
  • android:dropDownVerticalOffset：ドロップダウンメニューとテキスト間の垂直間隔を指定します
  • android:dropDownSelector：ドロップダウンメニューのクリック効果を設定します
  • android:popupBackground：ドロップダウンメニューの背景を設定します

ちなみに、実はもう一つありますMultiAutoCompleteTextView（複数のヒント項目を持つ自動補完テキストボックス）これはAutoCompleteTextViewと機能がほぼ同じで、属性も同じです。具体的な違いはどこにあるのか、以下のコードで体験してみましょう～また、これらはどちらも全単語一致です。例えば「小猪猪」：あなたが「小」を入力すると「小猪猪」がヒントされますが、「猪猪」と入力しても「小猪猪」はヒントされません！

実装コード：

ここではレイアウトをカスタマイズせずに、ArrayAdapterを直接使って実装しましょう！

レイアウトファイル：activity_main.xml：

<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:tools="http://schemas.android.com/tools"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical"
    tools:context=".MainActivity">

    <AutoCompleteTextView
        android:id="@+id/atv_content"
        android:layout_width="match_parent"
        android:layout_height="48dp"
        android:completionHint="请输入搜索内容"
        android:completionThreshold="1"
        android:dropDownHorizontalOffset="5dp" />

    <MultiAutoCompleteTextView
        android:id="@+id/matv_content"
        android:layout_width="match_parent"
        android:layout_height="48dp"
        android:completionThreshold="1"
        android:dropDownHorizontalOffset="5dp"
        android:text="" />
    
</LinearLayout>

MainActivity.java：

public class MainActivity extends AppCompatActivity {

    private AutoCompleteTextView atv_content;
    private MultiAutoCompleteTextView matv_content;

    private static final String[] data = new String[]{
            "小猪猪", "小狗狗", "小鸡鸡", "小猫猫", "小咪咪"
    };


    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        atv_content = (AutoCompleteTextView) findViewById(R.id.atv_content);
        matv_content = (MultiAutoCompleteTextView) findViewById(R.id.matv_content);


        ArrayAdapter<String> adapter = new ArrayAdapter<String>(MainActivity.
                this, android.R.layout.simple_dropdown_item_1line, data);
        atv_content.setAdapter(adapter);

        ArrayAdapter<String> adapter2 = new ArrayAdapter<String>(getApplicationContext(), android.R.layout.simple_dropdown_item_1line, data);
        matv_content.setAdapter(adapter);
        matv_content.setTokenizer(new MultiAutoCompleteTextView.CommaTokenizer());
    }
}

コードの一部解説：

  1. android:completionThreshold="1"：ここでは1文字入力するとヒントを表示するように設定しています
  2. android:completionHint="请输入搜索内容"：これはボックスの下部に表示されるテキストです。見た目が悪いと思うなら、android:completionHintViewでViewを設定できます！
  3. android:dropDownHorizontalOffset="5dp"：水平マージンを5dpに設定しています
  4. matv_content.setTokenizer(new MultiAutoCompleteTextView.CommaTokenizer()); setTokenizerはこれに区切り文字を設定するためのものです。
