Visual Studio 必知のショートカットキー

カテゴリ プログラミング技術

この記事では、Visual Studioでよく使われるショートカットキーを紹介します。ショートカットキーを正しく使いこなすことで、プログラミングの作業効率が大幅に向上します。


プロジェクト関連のショートカットキー

Ctrl + Shift + B= プロジェクトをビルド
Ctrl + Alt + L= ソリューション エクスプローラーを表示
Shift + Alt+ C= 新しいクラスを追加
Shift + Alt + A= プロジェクトに新しい項目を追加

編集関連のキーボードショートカット

Ctrl + Enter= 現在の行に空行を挿入
Ctrl + Shift + Enter= 現在の行の下に空行を挿入
Ctrl + Space= IntelliSense（インテリセンス）を使用して自動補完
Alt + Shift + 矢印キー(←,↑,↓,→) = コードの任意の部分を選択
Ctrl + }= 中括弧、括弧の対応を検索
Ctrl + Shift +}= 対応する括弧、括弧内のテキストを選択
Ctrl + Shift + S= すべてのファイルとプロジェクトを保存
Ctrl + K，Ctrl + C= 選択した行をコメントアウト
Ctrl + K，Ctrl + U= 選択した行のコメントを解除
Ctrl + K，Ctrl + D= すべてのコードを正しく整列
Shift + End= 行の先頭から末尾まで選択
Shift + Home= 行の末尾から先頭まで選択
Ctrl + Delete= カーソルの右側のすべての文字を削除

ナビゲーション関連のキーボードショートカット

Ctrl +Up/Down= カーソルを移動せずにウィンドウをスクロール
Ctrl + -= カーソルを前の位置に移動
Ctrl ++= カーソルを次の位置に移動
F12= 定義へ移動

デバッグ関連のキーボードショートカット

Ctrl + Alt + P= プロセスにアタッチ
F10= デバッグのステップ実行
F5= デバッグを開始
Shift + F5= デバッグを停止
Ctrl + Alt + Q= クイック一致を追加
F9= ブレークポイントを設定または削除

検索関連のキーボードショートカット

Ctrl + K  Ctrl + K= 現在の行にブックマークを追加
Ctrl + K  Ctrl + N= 次のブックマークへ移動
Ctrl + .= Collection<string>のようなクラス名を入力し、名前空間のインポートが正しくない場合、このショートカットキーの組み合わせでインポートが自動的に挿入されます
Ctrl + Shift + F= ファイル内を検索
Shift  + F12= すべての参照を検索
Ctrl + F= 検索ダイアログを表示
Ctrl + H= 置換ダイアログを表示
Ctrl + G= 行番号または行にジャンプ
Ctrl + Shift + F= 選択した項目のソリューション全体での参照を検索

以上がVisual Studioのすべてのショートカットキーです。漏れがあれば、補足して共有してください。
