Java 正規表現のキャプチャグループ(capture group)

カテゴリ プログラミング技術

キャプチャグループは以下のように分けられます：

  • 通常のキャプチャグループ(Expression)
  • 命名キャプチャグループ(?Expression)

通常のキャプチャグループ

正規表現の左側から始まり、左括弧"("が現れるたびに1つのグループとして数えます。グループ番号は1から始まります。0は式全体を表します。

時刻文字列：2017-04-25の場合、式は次のようになります

(\\d{4})-((\\d{2})-(\\d{2}))

左括弧が4つあるので、4つのグループがあります：

番号 キャプチャグループ マッチ
0 (\d{4})-((\d{2})-(\d{2})) 2017-04-25
1 (\d{4}) 2017
2 ((\d{2})-(\d{2})) 04-25
3 (\d{2}) 04
4 (\d{2}) 25
public static final String DATE_STRING = "2017-04-25"; public static final String P_COMM = "(\\d{4})-((\\d{2})-(\\d{2}))"; Pattern pattern = Pattern.compile(P_COMM); Matcher matcher = pattern.matcher(DATE_STRING); matcher.find();//この一文が必須です System.out.printf("\nmatcher.group(0) value:%s", matcher.group(0)); System.out.printf("\nmatcher.group(1) value:%s", matcher.group(1)); System.out.printf("\nmatcher.group(2) value:%s", matcher.group(2)); System.out.printf("\nmatcher.group(3) value:%s", matcher.group(3)); System.out.printf("\nmatcher.group(4) value:%s", matcher.group(4));

命名キャプチャグループ

左括弧で始まる各キャプチャグループの直後には、?、その後ろに正規表現が続きます。

時刻文字列：2017-04-25の場合、式は次のようになります：

(?<year>\\d{4})-(?<md>(?<month>\\d{2})-(?<date>\\d{2}))

4つの命名キャプチャグループがあり、それぞれ次のとおりです：

番号 名前 キャプチャグループ マッチ
0 0 (?\d{4})-(?(?\d{2})-(?\d{2})) 2017-04-25
1 year (?\d{4})- 2017
2 md (?(?\d{2})-(?\d{2})) 04-25
3 month (?\d{2}) 04
4 date (?\d{2}) 25

命名キャプチャグループでも番号を使用して対応する値を取得できます。

public static final String P_NAMED = "(?<year>\\d{4})-(?<md>(?<month>\\d{2})-(?<date>\\d{2}))"; public static final String DATE_STRING = "2017-04-25"; Pattern pattern = Pattern.compile(P_NAMED); Matcher matcher = pattern.matcher(DATE_STRING); matcher.find(); System.out.printf("\n===========名前を使用して取得============="); System.out.printf("\nmatcher.group(0) value:%s", matcher.group(0)); System.out.printf("\n matcher.group('year') value:%s", matcher.group("year")); System.out.printf("\nmatcher.group('md') value:%s", matcher.group("md")); System.out.printf("\nmatcher.group('month') value:%s", matcher.group("month")); System.out.printf("\nmatcher.group('date') value:%s", matcher.group("date")); matcher.reset(); System.out.printf("\n===========番号を使用して取得============="); matcher.find(); System.out.printf("\nmatcher.group(0) value:%s", matcher.group(0)); System.out.printf("\nmatcher.group(1) value:%s", matcher.group(1)); System.out.printf("\nmatcher.group(2) value:%s", matcher.group(2)); System.out.printf("\nmatcher.group(3) value:%s", matcher.group(3)); System.out.printf("\nmatcher.group(4) value:%s", matcher.group(4));

PS:非キャプチャグループ

左括弧の直後に?:、その後に正規表現を追加すると、非キャプチャグループになります。(?:Expression)。

時刻文字列：2017-04-25の場合、式は次のようになります：

(?:\\d{4})-((\\d{2})-(\\d{2}))

この正規表現には左括弧が4つあり、理論上は4つのキャプチャグループがあります。ただし、最初のグループは(?:\d{4})、実際には無視されます。matcher.group(4) を使用すると、システムはエラーを報告します。

番号 キャプチャグループ マッチ
0 (\d{4})-((\d{2})-(\d{2})) 2017-04-25
1 ((\d{2})-(\d{2})) 04-25
2 (\d{2}) 04
3 (\d{2}) 25
public static final String P_UNCAP = "(?:\\d{4})-((\\d{2})-(\\d{2}))"; public static final String DATE_STRING = "2017-04-25"; Pattern pattern = Pattern.compile(P_UNCAP); Matcher matcher = pattern.matcher(DATE_STRING); matcher.find(); System.out.printf("\nmatcher.group(0) value:%s", matcher.group(0)); System.out.printf("\nmatcher.group(1) value:%s", matcher.group(1)); System.out.printf("\nmatcher.group(2) value:%s", matcher.group(2)); System.out.printf("\nmatcher.group(3) value:%s", matcher.group(3)); // Exception in thread "main" java.lang.IndexOutOfBoundsException: No group 4 System.out.printf("\nmatcher.group(4) value:%s", matcher.group(4));

まとめ

  • 通常のキャプチャグループは使いやすいです。
  • 命名キャプチャグループは明確です。
  • 非キャプチャグループは現在のところプロジェクトではまだ使い道がありません。
