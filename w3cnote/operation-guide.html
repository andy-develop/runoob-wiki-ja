運用入門に関する知識の紹介

カテゴリ プログラミング技術

運用入門

最も基本的なところから話します

1. デバイス

LANケーブルの線順の接続方法、100MbpsとギガビットのLANケーブル、光ファイバーケーブル、シスコルーター、Huaweiルーター、スイッチなど、VLAN構築やスイッチとルーター間の学習を含め、一般的にはCCNPまで学習すれば十分だと思います。コンピュータハードウェアの理解は、自分でPCをDIYしたことがあれば、普通ははっきり分かります。サーバーと一般PCの違いを理解しましょう。サーバーはそれぞれ1U、2U、4Uです。そして、ハウジング先を探してサーバーを預託します。費用はデータセンターの回線数、帯域幅、地域によって決まります。ドメイン名の登録、ICP备案（届出）もできれば理解しておくのが良いです。

2. データリンク層

関係するのはMACアドレスの流れ、スイッチの学習、LAN（ローカルエリアネットワーク）のことです。

3. ネットワーク層

中国のインターネットの主要ISPである中国電信、中国移動、中国聯通、教育網（CERNET）が相互接続する際の欠点を理解し、tcpdump、wiresharkなどのパケットキャプチャソフトウェア、TCP/IPプロトコルを習得します。もちろんルーターのプロトコルもたくさんあります。

4. キャッシュ層

中国の有名なCDNベンダーをいくつか知っておきましょう。

いくつかのオープンソースキャッシュソフトウェア

  • 1.squid
  • 2.varnish
  • 3.Traffic Server

5. システム層

まず三大システム、Linux、Unix、Windowsがあります。市場では一般的にこの3つがサーバー用システムとして使われています。Linuxは現在のインターネットの主流なので、一般的に重点的に学習します。WindowsはWindows 2008 R2、UnixはAIX、Free BSDです。ここでプラットフォームを差別する意図はありません。Windows自体のドメインコントローラ管理も非常に強力だからです。しかし、Windowsの著作権問題により費用が高額なため、ほとんどの場合Linuxの学習に重点を置き、インターネット業界もこちらを志向しています。AIXとFree BSDは、実はLinuxを学べばほとんど同じで、ほんの少し違いがあるだけです。興味のある方はLinuxとUnixの歴史について学んでみるとよいでしょう。

6. データベース層

データベースは、私は一般的にMySQLを好みますが、Oracleにも少し触れたことがあります。一つの言語をしっかり習得すれば、他もそれほど難しくないでしょう。MySQLを選ぶ理由は、応用すれば使えるようになり、深く学べばソースコードも理解できるからです。非リレーショナルデータベースのMongoDBもあります。

7. コンテナ層

Tomcat、Nginx、Apache、Redis、IISについては特に言うことはありません。それぞれの言語に合わせて各種コンテナを選んでアプリケーションを動かせばよいのです。

Linux

  • まずはシステム関連です。Linux業界ではRed HatのRHCEコースを参考にできます。
  • 鳥哥的Linux私房菜（必読）（サーバー版はあまり良くないので選ばないこと）
  • Linuxシステム管理技術マニュアル（任意購入、分厚い本）

    Windowsサーバーにおすすめの英文書籍をいくつか

    • Pearson.Windows.Server.2008.Portable.Command.Guide
    • Microsoft.Press.Windows.PowerShell.3.0.First.Steps
    • Professional.IIS.7

    通常コマンド => batスクリプト作成 => PowerShell（LinuxのBashシェルに相当）=> ドメインコントローラ

    ネットワーク

    シスコのCCNP学習資料（必購、スイッチングとルーティング）

    『构建高性能Web站点』（この本は必購です。初心者にとって、特に運用にとって重要です）

    『TCP/IPプロトコル』第1巻（必読）

    『高可用Linuxサーバーの構築』（任意購入）

    スクリプト

    Shell（ここでは特にアドバイスはありません。私は本を買いませんでした。ネットで見てもいいし、本を買ってもいいです。京東やChina-Pubで自由に選んでください）

    Shellを理解する以外に、PythonやPerlについては自分で選ぶことをおすすめします。私はPerlerなので、もちろんPerlを選ぶことを勧めます。

    O'Reilly：『Perl言語入門』（必読）

    『Perl高効率プログラミング（Effective Perl Programming）第2版』（任意購入）

    『Higher-Order Perl』（任意購入）

    Python

    『Python基礎教程』（必読）

    基礎を理解したら、DjangoやTornadoなどのフレームワークを活用できます。深く理解したいならもちろんソースコードを見てください。さらに興味が続き、自分のC言語も得意だと思うなら、Python仮想マシンのソースコードを見てみるとよいでしょう。

    正規表現スクリプト（正規表現の原理、正規表現はLinuxに不可欠）

    『正規表現クラシック実例』（任意閲覧）

    『詳説正規表現』（任意閲覧）

    データベース

    『高性能MySQL』（必読）

    『高可用性MySQL』（必読）

    『Effective MySQL：バックアップとリカバリ』（任意購入）

    『Oracle Database 9i/10g/11gプログラミングアート：データベースアーキテクチャの深淵（第2版）』（Oracleを使うなら読んでみてください）

    監視

    監視には多くの種類があります。Cacti、bmon、nload、iftop、vnstat、iptrafなど、関連内容をインターネットで調べてみてください。

    まとめ

    CLI（コマンドライン）は運用のすべての根源です。スクリプトに精通し、いつでも自由に書けるようにしましょう。おおよそのトラブルシューティング手順を考えておきましょう。初心者はネット上のワンクリックXXXを参考にして例を作り、それを自分で改良してみてください。例えばシステムの初期化、SSHの設定、パラメータの設定などです。高い楼閣も地面から始まるように、上記の書籍は多くありますが、やはり読んでおく必要があります。

    国内で評判の良い運用フォーラムを紹介します：http://bbs.linuxtone.org/
