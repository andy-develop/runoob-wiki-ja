JavaScript/CSS テーブル検索機能

カテゴリー プログラミング技術

この章では、JS/CSSを使用してテーブルの検索或フィルタリング機能を実装する方法を学びます。

まず、以下のような効果をご覧ください：

オンラインサンプルを見る：https://www.jyshare.com/codedemo/6228/

基本的な HTML コード

サンプル

<input type="text" id="myInput" onkeyup="myFunction()" placeholder="検索.."> <table id="myTable"> <tr class="header"> <th style="width:60%;">Name</th> <th style="width:40%;">Url</th> </tr> <tr> <td>Google</td> <td>www.google.com</td> </tr> <tr> <td>Runoob</td> <td>www.runoob.com</td> </tr> <tr> <td>Taobao</td> <td>www.taobao.com</td> </tr> <tr> <td>Baidu</td> <td>www.baidu.com</td> </tr> </table>

以下は検索ボックスとサジェストメニューのスタイルです：

サンプル

#myInput { background-image: url('/css/searchicon.png'); /*検索ボタンを追加*/ background-position: 10px 12px; /*検索ボタンを配置*/ background-repeat: no-repeat; /*画像を繰り返さない*/ width: 100%; /*全画面表示*/ font-size: 16px; /*フォントサイズ*/ padding: 12px 20px 12px 40px; /*パディングを設定*/ border: 1px solid #ddd; /*グレーの枠線を追加*/ margin-bottom: 12px; /*上部のマージンを追加*/ } #myTable { border-collapse: collapse; /*枠線を折りたたむ*/ width: 100%; /*全画面表示*/ border: 1px solid #ddd; /*グレーの枠線を設定*/ font-size: 18px; /*フォントサイズ*/ } #myTable th, #myTable td { text-align: left; /*テキストを左揃えにする*/ padding: 12px; /*パディングを設定*/ } #myTable tr { /*各行に下枠線を設定*/ border-bottom: 1px solid #ddd; } #myTable tr.header, #myTable tr:hover { /*テーブルヘッダーに背景を設定*/ background-color: #f1f1f1; }

以下は検索ボックスとサジェストメニューのJavaScriptコードです：

サンプル

function myFunction() { //変数を宣言 var input, filter, table, tr, td, i, txtValue; input = document.getElementById("myInput"); filter = input.value.toUpperCase(); table = document.getElementById("myTable"); tr = table.getElementsByTagName("tr"); //すべてのリスト項目をループし、検索クエリに一致しない項目を非表示にします for (i = 0; i < tr.length; i++) { td = tr[i].getElementsByTagName("td")[0]; if (td) { txtValue = td.textContent || td.innerText; if (txtValue.toUpperCase().indexOf(filter) > -1) { tr[i].style.display = ""; } else { tr[i].style.display = "none"; } } } }

試してみる »

ヒント：大文字と小文字を区別して検索する場合は、toUpperCase()メソッドを削除できます。

ヒント：2列目を検索する場合は、tr[i].getElementsByTagName('td')[0]の中の[0]に変更します[1]。
