JAVA 三角形の出力

カテゴリ プログラミング技術

まず、出力結果を確認しましょう：

では、どうすればこのようにできるのでしょうか？

1、まず図形の構造を分析します

見てわかるように、図形は全部で5行あります。では、forループ文を1つ作成して、それを5行に制御することはできるでしょうか？答えは「はい」です。

for(int i = 1 ;i <= 5 ;i++ ){

}

これで、5回ループするforループのコードブロックを作成しました。これが最も外側のループです。

2、次に、図形がどのように構成されているかを分析します。図形を以下の部分に分割できます：/p>

図形をこのように3つの三角形に分割できます。

3、1番の空白三角形を作成します

見てわかるように、1行目はスペース4個、2行目はスペース3個、3行目は2個、4行目は1個を出力し、5行目は出力しません。

この規則から、順番に減少していく規則であることがわかります。では、どうやって実現するのでしょうか？

1から5までを考えると、間には4つの数字があります。2から5までなら3つ、3から5までなら……

この原理を利用できるのではないでしょうか？答えはもちろん「その通り」です。では、どう実現するのでしょうか？コードを見てください：

for(int i = 1;i<=5 ;i++) {
    for(int j = 5; j >= i ; j--)//建立1号图形
        System.out.print(" ");
    System.out.println();
}

最初のfor文は、先ほど定義した5回ループの文です。

2番目のforループを解析してみましょう：

まず、int型の変数jを定義し、jに5を代入します。

次に考えます。距離を縮めたいので、ループごとにjを-1すれば、ちょうど要件に合います：

最初の外側ループでは i=1、j=5 なので、j>=i の条件を満たし、スペースを1つ出力します。そして j-1 すると、j の値は4になり、j>=i を満たすので、さらに出力します。

……

j=0 になるまで続け、j>=i が満たされなくなるので、内側ループを抜け出します。

次に System.out.println(); で改行します。

外側ループに戻り、i++ で i が2になります。i<=5 を満たすので、内側ループに入ります。

j=5 と定義し、j>=i を満たすのでスペースを1つ出力し、j-1 します。

j は今4なので、j>=i を満たし、スペースを1つ出力し、j-1 します。

……

j=1 まで続け、j>=i が成立しないので、内側ループを抜け出し、改行します。

そして i+1 して、再び内側ループに入ります……

このようにループを続けると、4行の逆三角形が形成され、1番の図形が完成します。

4、2番の図形を作成します。1番の図形と原理はまったく同じですが、向きがちょうど逆です。

for(int i = 1 ;i<=5 ;i++){
    for(int j = 5; j >= i ; j--)//建立1号图形
        System.out.print(" ");
    for(int j = 1; j <= i; j++)//建立2号图形
        System.out.print("*");
    System.out.println();
}

1番の図形の作成と同じなので、各自で理解してください。このようにして2番が作成されます。

5、3番の図形を作成します

for(int i = 1; i <= 5; i++){
    for(int j = 5 ;i <= j; j--)//建立1号图形
        System.out.print(" ");
    for(int j = 1; j <= i; j++)//建立2号图形
        System.out.print("*");
    for(int j = 1; j < i; j ++)//建立3号图形
        System.out.print("*");

}

同様に、1番・2番と同じく、3番の図形を作成する原理も同じです。

ただし、注意点が1つあります。3番の図形は1行目では出力されないので、最初の外側ループでは出力を抑えて、2回目の外側ループで出力させます。

そのため、今回の判断条件は j < i とし、等号を除きます。

完全なソースコード：

class Demo{ public static void main(String[] args){ for(int i=1;i<=5;i++){ for(int j=5; i<=j; j--) System.out.print(" "); for(int j=1; j<=i; j++) System.out.print("*"); for(int j=1; j<i; j++) System.out.print("*"); System.out.println(); } } }
