QRCode.js：JavaScript を使用して QR コードを生成

カテゴリ プログラミング技術

QRCode.js とは？

QRCode.js は QR コードを生成するための JavaScript ライブラリです。主に DOM のタグを取得し、HTML5 Canvas で描画することで構成されており、いかなるライブラリにも依存しません。

基本的な使い方

<div id="qrcode"></div>
<script type="text/javascript">
new QRCode(document.getElementById("qrcode"), "https://www.example.com");  // 设置要生成二维码的链接
</script>

または、いくつかのオプションパラメータを使用して設定できます：

var qrcode = new QRCode("test", {
    text: "https://www.example.com",
    width: 128,
    height: 128,
    colorDark : "#000000",
    colorLight : "#FFFFFF",
    correctLevel : QRCode.CorrectLevel.H
});

同様に、以下の方法を使用することもできます：

qrcode.clear(); // 清除代码
qrcode.makeCode("https://www.jyshare.com"); // 生成另外一个二维码

ブラウザサポート

このライブラリをサポートするブラウザは、IE6~10、Chrome、Firefox、Safari、Opera、Mobile Safari、Android、Windows Mobile などです。

サンプルコード

HTML コード

<input id="text" type="text" value="https://www.example.com" /><br />
<div id="qrcode"></div>

CSS コード

#qrcode {
width:160px;
  height:160px;
  margin-top:15px;
}

JavaScript コード

var qrcode = new QRCode("qrcode");

function makeCode () {      
    var elText = document.getElementById("text");
    
    if (!elText.value) {
        alert("Input a text");
        elText.focus();
        return;
    }
    
    qrcode.makeCode(elText.value);
}

makeCode();

$("#text").
on("blur", function () {
    makeCode();
}).
on("keydown", function (e) {
    if (e.keyCode == 13) {
        makeCode();
    }
});
