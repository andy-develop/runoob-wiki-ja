プロジェクト名: bruno -- APIテスト用のオープンソースIDE

Github オープンソースURL： https://github.com/usebruno/bruno

公式サイト： https://www.usebruno.com/

ダウンロードURL： https://www.usebruno.com/downloads

使用ドキュメント： https://docs.usebruno.com/

Bruno は、Postman、Insomnia などのツールに代表される現状を変えることを目的とした、高速で使いやすいオープンソースのAPIクライアントです。

  • 保存方法：Bruno は、あなたのコレクションをファイルシステムのフォルダに直接保存し、プレーンテキストのマークアップ言語 Bru を使用して API リクエストに関する情報を保存します。

  • バージョン管理：Git またはお好みのバージョン管理ツールを使用して、API コレクションを共同で管理できます。

  • オフライン使用：Bruno はオフライン使用のみをサポートしており、作者によるとクラウド同期を追加する計画は今後も決してないとのことです。これはデータのプライバシーを保護し、データの安全性を確保するためでもあります。

Bruno クライアントのダウンロード先 https://www.usebruno.com/downloads、Mac、Windows、Linux をサポート：

もちろん、Homebrew、Chocolatey、Scoop、Snap、Apt などのパッケージマネージャーから Bruno をインストールすることもできます：

# 在 Mac 电脑上用 Homebrew 安装
brew install bruno

# 在 Windows 上用 Chocolatey 安装
choco install bruno

# 在 Windows 上用 Scoop 安装
scoop bucket add extras
scoop install bruno

# 在 Linux 上用 Snap 安装
snap install bruno

# 在 Linux 上用 Apt 安装
sudo mkdir -p /etc/apt/keyrings
sudo gpg --no-default-keyring --keyring /etc/apt/keyrings/bruno.gpg --keyserver keyserver.ubuntu.com --recv-keys 9FA6017ECABE0266

echo "deb [signed-by=/etc/apt/keyrings/bruno.gpg] http://debian.usebruno.com/ bruno stable" | sudo tee /etc/apt/sources.list.d/bruno.list

sudo apt update
sudo apt install bruno

使用方法

簡単な GET リクエストを送信する：

get {
  url: https://api.github.com/users/usebruno
}

簡単な POST リクエストを送信する：

post {
  url: https://reqres.in/api/login
}
body {
  {
    "username": "johnnash",
    "password": "governingdynamics"
  }
}
