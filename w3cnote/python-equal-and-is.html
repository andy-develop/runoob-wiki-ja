Pythonで等しいを表すには結局==とisのどちらを使うのか

カテゴリ プログラミング技術

Pythonにおいて、「等しい」の意味は異なる解釈ができるため、状況に応じて使い分けます== 或 is。それらには異なる用途と意味があります：

==（等価演算子）：

  • 2つのオブジェクトの値が等しいかどうかを比較するために使います。
  • これはオブジェクトの__eq__メソッドを呼び出します（そのメソッドが定義されている場合）。
  • 数値、文字列、リストなどの内容が同じかどうかを比較するのに適しています。

例

a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)  # 出力: True、a と b の内容が同じだからです

is（同一性演算子）：

  • 2つのオブジェクトの同一性が同じかどうか、つまり2つのオブジェクトがメモリ上の同じアドレスにあるかどうかを比較するために使います。
  • 2つの変数が同じオブジェクトを参照している場合にのみ、isTrue を返します。

例

a = [1, 2, 3]
b = [1, 2, 3]
c = a
print(a is b)  # 出力: False、a と b は内容が同じでも異なるオブジェクトだからです
print(a is c)  # 出力: True、c と a は同じオブジェクトを参照しているからです

まとめ：

  • 使用して==2つのオブジェクトの値が等しいかどうかを確認します。
  • 使用してis2つのオブジェクトが同じインスタンスであるかどうか（つまりメモリ上のアドレスが同じかどうか）を確認します。

例で説明します：

例

# 数値の比較
x = 10
y = 10
print(x == y)  # 出力: True
print(x is y)  # 出力: True、Python は小さな整数オブジェクトをキャッシュするため、x と y は実際には同じオブジェクトです

# 文字列の比較
a = "hello"
b = "hello"
print(a == b)  # 出力: True
print(a is b)  # 出力: True、短い文字列はキャッシュされるため

# リストの比較
list1 = [1, 2, 3]
list2 = [1, 2, 3]
print(list1 == list2)  # 出力: True
print(list1 is list2)  # 出力: False、list1 と list2 は異なるオブジェクトだからです

# None の比較
c = None
d = None
print(c == d)  # 出力: True
print(c is d)  # 出力: True、None はシングルトンだからです
