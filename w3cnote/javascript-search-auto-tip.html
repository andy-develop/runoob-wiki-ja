JavaScript 検索ボックス自動提案

カテゴリ プログラミング技術

この記事では、百度検索のような検索ボックスの提案機能を実装する方法を紹介します。

HTML コード：

<input type="text" id="myInput" onkeyup="myFunction()" placeholder="検索..."> <ul id="myUL"> <li><a href="#" class="header">A</a></li> <li><a href="#">Adele</a></li> <li><a href="#">Agnes</a></li> <li><a href="#" class="header">B</a></li> <li><a href="#">Billy</a></li> <li><a href="#">Bob</a></li> <li><a href="#" class="header">C</a></li> <li><a href="#">Calvin</a></li> <li><a href="#">Christina</a></li> <li><a href="#">Cindy</a></li> </ul>

注意：この例では href="../index.html" を使用しています。実際のアプリケーションでは、これを自分のURLに置き換える必要があります。

CSS コード：

#myInput { background-image: url('https://static.jyshare.com/images/mix/searchicon.png'); /*検索ボタン*/ background-position: 10px 12px; /*検索ボタンの位置指定*/ background-repeat: no-repeat; /*画像を繰り返さない*/ width: 100%; font-size: 16px; /*フォントを大きくする*/ padding: 12px 20px 12px 40px; border: 1px solid #ddd; margin-bottom: 12px; } #myUL { /*デフォルトのリストスタイルを削除*/ list-style-type: none; padding: 0; margin: 0; } #myUL li a { border: 1px solid #ddd; /*リンクに枠線を追加*/ margin-top: -1px; background-color: #f6f6f6; padding: 12px; text-decoration: none; font-size: 18px; color: black; display: block; } #myUL li a.header { background-color: #e2e2e2; cursor: default; } #myUL li a:hover:not(.header) { background-color: #eee; }

JavaScript コード：

function myFunction() { //変数を宣言 var input, filter, ul, li, a, i; input = document.getElementById('myInput'); filter = input.value.toUpperCase(); ul = document.getElementById("myUL"); li = ul.getElementsByTagName('li'); //すべてのリストをループして、一致する項目を探す for (i = 0; i < li.length; i++) { a = li[i].getElementsByTagName("a")[0]; if (a.innerHTML.toUpperCase().indexOf(filter) > -1) { li[i].style.display = ""; } else { li[i].style.display = "none"; } } }

ヒント：大文字と小文字を区別する必要がある場合は、toUpperCase() メソッドを削除できます。
