2.1 Verilog 基本文法

分類 Verilog チュートリアル

書式

Verilog は大文字と小文字を区別します。

書式は自由で、1行で記述することも、複数行にまたがって記述することもできます。

各ステートメントはセミコロンを終端文字とする必要があります。空白文字（改行、タブ、スペース）には実際の意味はなく、コンパイル時に無視できます。例えば、以下の2つの記述方法はどちらも同等です。

改行しない（非推奨）

例

wire [1:0]  results ;assign results = (a == 1'b0) ? 2'b01 ： (b==1'b0) ? 2'b10 ： 2'b11 ;

改行する（推奨）

例

wire [1:0]  results ;
assign      results = (a == 1'b0) ? 2'b01 ：
            (b==1'b0) ? 2'b10 ：
                2'b11 ;

コメント

Verilog には2つのコメント方法があります:

用 //1行コメント:

reg [3:0] counter ;  // A definition of counter register
用 /*と*/複数行コメント:
wire [11:0]  addr ;
/* 
Next are notes with multiple lines.
Codes here cannot be compiled.
*/
assign   addr = 12'b0 ;

識別子とキーワード

識別子（identifier）は、任意のアルファベット、数字、$記号と_(アンダースコア)記号の組み合わせですが、識別子の最初の文字はアルファベットまたはアンダースコアでなければならず、数字またはドル記号で始めることはできません。

さらに、識別子は大文字と小文字を区別します。

キーワードは、Verilog で言語構造を定義するために予約された特別な識別子です。

Verilog のキーワードはすべて小文字です。

例

reg [3:0] counter ; //reg はキーワード、counter は識別子です
input clk; //input はキーワード、clk は識別子です
input CLK; //CLK と clk は2つの異なる識別子です
