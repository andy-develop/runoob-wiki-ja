1. GitHubリポジトリの作成

AS 上に新しいプロジェクトを作成し、名前はDrySister、パッケージ名：com.coderpig.drysisterプロジェクトのルートディレクトリで git bash を開き、以下のコマンドを入力して Git リポジトリを作成します： git init Github 上に新しいリポジトリを作成し、名前を DrySister にします。続いてリモートリポジトリを設定し、コマンドを入力します： git remote add origin git@github.com:coder-pig/DrySister.git master ブランチを pull し、それから add、commit、push で github リポジトリに送ります。続いて、私は .gitignore ファイルを変更し、新しい develop ブランチを作成しました。そしてそのブランチ上でコミットし、master ブランチにマージしました。はい、Git に関する準備はだいたい完了です。

2. プログラムの作成開始

ローカルで develop ブランチを切り、コードを書き始めます。レイアウトはとても簡単で、女の子の画像を表示する ImageView と Button があります。activity_main.xml続いて、画像をダウンロードして読み込む簡単なクラスを書きます。PictureLoader.javaロジックは簡単です。スレッドが入力ストリームをバイト配列に変換し、変換完了後、handler 内で decodeByteArray がバイト配列をビットマップにデコードして、表示します～

public class PictureLoader {
    private ImageView loadImg;
    private String imgUrl;
    private byte[] picByte;

    Handler handler = new Handler() {
        @Override
        public void handleMessage(Message msg) {
            super.handleMessage(msg);
            if (msg.what == 0x123) {
                if (picByte != null) {
                    Bitmap bitmap = BitmapFactory.decodeByteArray(picByte, 0, picByte.length);
                    loadImg.setImageBitmap(bitmap);
                }
            }
        }
    };

    public void load(ImageView loadImg, String imgUrl) {
        this.loadImg = loadImg;
        this.imgUrl = imgUrl;
        Drawable drawable = loadImg.getDrawable();
        if(drawable != null && drawable instanceof BitmapDrawable) {
            Bitmap bitmap = ((BitmapDrawable)drawable).getBitmap();
            if(bitmap != null && !bitmap.isRecycled()) {
                bitmap.recycle();
            }
        }
        new Thread(runnable).start();
    }

    Runnable runnable = new Runnable() {
        @Override
        public void run() {
            try {
                URL url = new URL(imgUrl);
                HttpURLConnection conn = (HttpURLConnection) url.openConnection();
                conn.setRequestMethod("GET");
                conn.setReadTimeout(10000);
                if (conn.getResponseCode() == 200) {
                    InputStream in = conn.getInputStream();
                    ByteArrayOutputStream out = new ByteArrayOutputStream();
                    byte[] bytes = new byte[1024];
                    int length = -1;
                    while ((length = in.read(bytes)) != -1) {
                        out.write(bytes, 0, length);
                    }
                    picByte = out.toByteArray();
                    in.close();
                    out.close();
                    handler.sendEmptyMessage(0x123);
                }

            } catch (IOException e) {
                e.printStackTrace();
            }
        }
    };
}

public class MainActivity extends AppCompatActivity implements View.OnClickListener {

4. まとめ

まず、この節で私たちがやったことを説明します。：

  • 1. DrySister プロジェクトを作成し、プロジェクトを Github にホスティングしました。
  • 2. ネットワーク画像を表示する非常に簡単な機能を書きました。

最適化待ち・追加したいもの：

  • 1. コード内の画像ソースはハードコーディングしているため、毎日見られる画像は同じ数枚だけです。Gank が提供する API は使っていません。
  • 2. 画像読み込みクラスはネットワークからの読み込みしか対応していないので、ローカル画像の読み込みも追加すべきです。

次の節でやること：

  • 1. Android 標準の簡易パーサーを使用して API データを解析し、画像表示用のデータソースを取得します。
