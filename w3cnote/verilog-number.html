2.2 Verilog 数値表現

分類 Verilog チュートリアル

数値の種類

Verilog HDL には、ハードウェア回路のレベル論理を表すための基本的な値が次の4種類あります：

  • 0：論理0または「偽」
  • 1：論理1または「真」
  • x または X：未知
  • z または Z：ハイインピーダンス

x信号の数値が不確定であることを意味します。つまり、実際の回路では、信号は1の場合もあれば0の場合もあります。

z信号がハイインピーダンス状態にあることを意味し、信号（input、reg）がドライブされていないときの論理結果によく見られます。例えば、pad の input がハイインピーダンス状態を示す場合、その論理値はプルアップ/プルダウンの状態に関係します。プルアップなら論理値は1、プルダウンなら0です。

整数値の表現方法

数値の宣言時、有効な基数フォーマットは4種類あります：10進数（'d または 'D）、16進数（'h または 'H）、2進数（'b または 'B）、8進数（'o または 'O）。数値はビット幅を指定することも、指定しないこともできます。

ビット幅を指定する：

例

4'b1011         // 4bit 数値
32'h3022_c0de   // 32bit の数値

ここで、アンダースコア_はコードの可読性を高めるためのものです。

ビット幅を指定しない場合：

通常、直接数値を書く場合は、デフォルトで10進数表記になります。例えば、以下の3つの書き方は等価です：

例

counter = 'd100 ; // 通常はコンパイラが自動的にビット幅を決定し、一般的には32bitです
counter = 100 ;
counter = 32'h64 ;

負数の表現

通常、ビット幅を表す数値の前にマイナス記号を付けて負数を表します。例：

-6'd15  
-15

-15 は5ビット2進数では 5'b10001、6ビット2進数では 6'b11_0001 となります。

マイナス記号を基数と数値の間に置くのは不正であることに注意してください。例えば、以下の表現方法は誤りです：

4'd-2 //非法说明

実数の表現方法

実数の表現方法には主に2つの方式があります：

10進数：

30.123
6.0
3.0
0.001

科学的表記法：

1.2e4         //大小为12000
1_0001e4      //大小为100010000
1E-3          //大小为0.001

文字列の表現方法

文字列は二重引用符で囲まれた文字の並びです。文字列は複数行にわたって記述できません。つまり、文字列には改行文字を含めることはできません。Verilog は文字列を一連の1バイト ASCII 文字の並びとして扱います。例えば、文字列 "www.runoob.com" を格納するには、14*8bit の記憶ユニットが必要です。例：

例

reg [0: 14*8-1]       str ;
initial begin
    str = "www.runoob.com";
end
