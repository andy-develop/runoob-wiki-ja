菜鸟教程で使用されている技術

分类 编程技术

菜鸟教程の技術構造図は次のとおりです：

1、系统：Centos

CentOS は Linux ディストリビューションの一つで、Red Hat Enterprise Linux（レッドハット商用版）がオープンソースの規定に従って公開したソースコードからコンパイルされたものです。

最新安定版：7.3

菜鸟教程にチュートリアルがあるか：あり

官网地址：https://www.centos.org/

2、スクリプト言語：PHP

PHP は HHVM を使用して解析・実行されます。

HHVM は Facebook が開発した、PHP コードを実行するための仮想マシンです。PHP の JIT（Just-In-Time）コンパイラであり、高速なコード生成と即時コンパイルの利点を併せ持っています。

HHVM はパフォーマンスにおいて PHP 5.x バージョンより優れていましたが、その後 PHP が 7.x バージョンをリリースし、ようやくパフォーマンスが HHVM に追いつきました。

HHVM 最新安定版：3.15.0

PHP 最新安定版：7.1.0

菜鸟教程にチュートリアルがあるか：あり

HHVM 公式サイトアドレス：http://hhvm.com/

PHP 公式サイトアドレス：http://php.net/

3、データベース：MySQL

MySQL は現在 Oracle 傘下の製品であり、コミュニティ版は MySQL の中で唯一の無料バージョンです。そのため、今後もオープンソースであり続けるかどうか懸念されています。

現在、MySQL の創始者であるミカエル・ウィデニウスは MySQL を基盤として、分岐プロジェクト MariaDB を立ち上げました。ウィキペディアは 2013 年に MySQL から MariaDB データベースへ移行することを正式に発表しました。

最新安定版：5.7.16

菜鸟教程にチュートリアルがあるか：あり

官网地址：https://www.mysql.com/

4、サーバー：Tengine

Tengine は、淘宝が Nginx からフォークした HTTP サーバーであり、Nginx と設定互換性があります。

これは Nginx をベースに、大規模なアクセスが見込まれるサイトのニーズに応じて、多くの高度な機能と特性が追加されています。

最新安定版：2.2.0

菜鸟教程にチュートリアルがあるか：なし

官网地址：http://tengine.taobao.org/

5、ウェブサイトシステム：wordpress

WordPress は PHP と MySQL をプラットフォームとする、自由かつオープンソースの、現在インターネット上で最も人気のあるブログおよびコンテンツ管理システムです。

最新安定版：4.7

菜鸟教程にチュートリアルがあるか：なし

官网地址：https://cn.wordpress.org/

6、キャッシュサーバー：Redis

Redis はオープンソースで、ネットワーク対応、メモリベース、キーバリューストア型のデータベースであり、ANSI C で記述されています。

Redis は最も人気のあるキーバリューストア型データベースです。

最新安定版：3.2.5

菜鸟教程にチュートリアルがあるか：あり

官网地址：https://redis.io/

7、オンラインコード実行：Docker

Docker はオープンソースのアプリケーションコンテナエンジンであり、Go 言語をベースに、Apache 2.0 プロトコルに従ってオープンソース化されています。

コンテナは完全にサンドボックス機構を採用しており、相互にインターフェースは一切ありません（iPhone のアプリと同様）。さらに重要なのは、コンテナのパフォーマンスオーバーヘッドが極めて低いことです。

最新安定版：1.10.3

菜鸟教程にチュートリアルがあるか：あり

Docker 官网：http://www.docker.com
