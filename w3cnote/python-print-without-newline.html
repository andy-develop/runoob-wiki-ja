Python2 と Python3 print 改行しない

カテゴリ プログラミング技術

この記事では、Python2 と Python3 で print を改行しないようにする方法を主に紹介します。

Python 3.x

Python 3.x では、print()関数に追加するend=""パラメータを指定すると、改行しない効果を実現できます。

Python3 では、print 関数のパラメータendデフォルト値は"\n"、つまりend="\n"、改行を表し、endに空の値を代入すると、つまりend=""、改行されません。例：

Python3.x サンプル

print('これは文字列です、', end="")
print('ここでは文字列は改行されません')

上記コードを実行すると、出力結果は次のとおりです。

これは文字列です。ここの文字列は改行されません。

end=""特定の記号や文字列を設定することもできます：

サンプル

print('12345', end=" ")  # スペースを設定
print('6789')

print('admin', end="@")  # 記号を設定
print('example.com')

print('Google ', end="サンプル ")  # 文字列を設定
print('Taobao')

上記コードを実行すると、出力結果は次のとおりです。

12345 6789
admin@example.com
Google サンプル Taobao

Python 2.x

Python 2.x では、カンマを使って,改行しない効果を実現できます：

Python2.x サンプル

#!/usr/bin/python
# -*- coding: UTF-8 -*-

print "これは文字列です、",         # 末尾にカンマを追加
print "ここでは文字列は改行されません"

# print 括弧付き
print ("これは文字列です、"),        # 末尾にカンマを追加
print ("ここでは文字列は改行されません")

上記コードを実行すると、出力結果は次のとおりです。

これは文字列です。ここの文字列は改行されません。
これは文字列です。ここの文字列は改行されません。

変数がある場合は、カンマ,の後に直接変数を追加できます：

Python2.x サンプル

#!/usr/bin/python
# -*- coding: UTF-8 -*-

x= 2
print "数字は：", x

上記コードを実行すると、出力結果は次のとおりです。

字为： 2

注意：この出力方法では、,末尾にスペースが1つ出力されます。これは Python 3 のend=" "。

Python2.x と Python3.x の互換モード

Python2.x で Python3.x のprint関数を使用したい場合は、__future__パッケージをインポートします。このパッケージは Python2.x の print 文を無効にし、Python3.x のprint関数を採用します。

以下のコードは Python2.x と Python3.x の両方で正しく実行できます：

Python2.x サンプル

#!/usr/bin/python
# -*- coding: UTF-8 -*-

from __future__ import print_function

print('12345', end=" ")  # スペースを設定
print('6789')

print('admin', end="@")  # 記号を設定
print('example.com')

print('Google ', end="サンプル ")  # 文字列を設定
print('Taobao')

注：Python3.x と Python2.x の多くの互換性機能は、__future__このパッケージを使用してインポートできます。
