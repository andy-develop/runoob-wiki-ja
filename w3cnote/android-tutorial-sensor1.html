10.10 センサー特集(1)——関連紹介

カテゴリ Android 基礎入門チュートリアル

1.センサーの関連紹介：

センサーといえば、皆さんもご存知でしょう。例えば、微信の「摇一摇」（シェイク）は加速度センサーを使用しています。

センサーの定義：物理デバイスまたは生物器官であり、外部の信号、物理的条件（光、熱、湿度など）または化学組成（煙など）を探知・感知し、探知した情報を他のデバイスまたは器官に伝達するものです！

センサーの種類：異なる角度からセンサーを分類できます。変換原理（センサーが動作する基本的な物理的・化学的効果）、用途、出力信号、および製作材料や工芸などです。一般的には動作原理によって分類されます：物理センサーと化学センサーの2種類です！スマホに搭載されているのは基本的に物理センサーで、スマホに搭載されているセンサーには以下のものがあります：

  • 方位センサー（Orientation sensor）
  • 加速度センサー（Accelerometer sensor）
  • ジャイロスコープセンサー（Gyroscope sensor）
  • 磁界センサー（Magnetic field sensor）
  • 近接センサー（Proximity sensor）
  • 光センサー（Light sensor）
  • 気圧センサー（Pressure sensor）
  • 温度センサー（Temperature sensor）
  • 重力センサー（Gravity sensor、Android 2.3で導入）
  • 線形加速度センサー（Linear acceleration sensor、Android 2.3で導入）
  • 回転ベクトルセンサー（Rotation vector sensor、Android 2.3）
  • 相対湿度センサー（Relative humidity sensor、Android 4.0）
  • 近距離無線通信（NFC）センサー（Android 2.3で導入）、NFCは他とは異なり、読み書き機能を持っています。

もちろん、これ以外にも心拍センサー、歩数センサー、指紋センサーなどがあります。Androidデバイスが対応しているセンサーの種類については公式ドキュメントを参照してください：SensorSummary部分の内容〜

2.自分のスマホが対応しているセンサーを確認する方法は？

上記で述べたように、このように多くの種類がすべてのスマホに備わっているわけではなく、各スマホに搭載されているセンサーの種類や数は異なる場合があります。例えば、私が手元に持っているNexus 5が対応しているセンサーの種類は、重力、光、距離、気圧、ジャイロスコープです！また、もう1台のmoto x 二代目には重力、光、距離、赤外線センサーがあります！自分のスマホが対応しているセンサーの種類については、中关村手机在线、太平洋などの関連するレビューサイトで自分の機種を検索して関連パラメータを確認できます！もちろん、自分でコードを書いて自分のスマホが対応しているセンサーの種類を確認することもできます〜

MainActivity.java：

public class MainActivity extends AppCompatActivity {

    private TextView txt_show;
    private SensorManager sm;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        sm = (SensorManager) getSystemService(Context.SENSOR_SERVICE);
        txt_show = (TextView) findViewById(R.id.txt_show);

        List<Sensor> allSensors = sm.getSensorList(Sensor.TYPE_ALL);
        StringBuilder sb = new StringBuilder();

        sb.append("此手机有" + allSensors.size() + "个传感器，分别有：\n\n");
        for(Sensor s:allSensors){
            switch (s.getType()){
                case Sensor.TYPE_ACCELEROMETER:
                    sb.append(s.getType() + " 加速度传感器(Accelerometer sensor)" + "\n");
                    break;
                case Sensor.TYPE_GYROSCOPE:
                    sb.append(s.getType() + " 陀螺仪传感器(Gyroscope sensor)" + "\n");
                    break;
                case Sensor.TYPE_LIGHT:
                    sb.append(s.getType() + " 光线传感器(Light sensor)" + "\n");
                    break;
                case Sensor.TYPE_MAGNETIC_FIELD:
                    sb.append(s.getType() + " 磁场传感器(Magnetic field sensor)" + "\n");
                    break;
                case Sensor.TYPE_ORIENTATION:
                    sb.append(s.getType() + " 方向传感器(Orientation sensor)" + "\n");
                    break;
                case Sensor.TYPE_PRESSURE:
                    sb.append(s.getType() + " 气压传感器(Pressure sensor)" + "\n");
                    break;
                case Sensor.TYPE_PROXIMITY:
                    sb.append(s.getType() + " 距离传感器(Proximity sensor)" + "\n");
                    break;
                case Sensor.TYPE_TEMPERATURE:
                    sb.append(s.getType() + " 温度传感器(Temperature sensor)" + "\n");
                    break;
                default:
                    sb.append(s.getType() + " 其他传感器" + "\n");
                    break;
            }
            sb.append("设备名称：" + s.getName() + "\n 设备版本：" + s.getVersion() + "\n 供应商："
                    + s.getVendor() + "\n\n");
        }
        txt_show.setText(sb.toString());
    }
}

3.Sensorセンサー関連のメソッドおよび使用手順

2の例から、Sensorセンサーの取得やセンサー関連情報の取得の流れを大まかにまとめることができます。以下の通りです：

1)Sensorセンサーの関連メソッド

Step 1：センサーマネージャーを取得する：

SensorManager sm = (SensorManager)getSystemService(SENSOR_SERVICE);
  • Step 2：デバイスのセンサーオブジェクトのリストを取得する：
List<Sensor> allSensors = sm.getSensorList(Sensor.TYPE_ALL);
  • Step 3：反復処理でSensorオブジェクトを取得し、対応するメソッドを呼び出してセンサーの関連情報を取得します：
for(Sensor s:allSensors){
    sensor.getName();   //获得传感器名称
    sensor.getType();     //获得传感器种类
    sensor.getVendor();    //获得传感器供应商
    sensor.getVersion();    //获得传感器版本
    sensor.getResolution();  //获得精度值
    sensor.getMaximumRange(); //获得最大范围
    sensor.getPower();        //传感器使用时的耗电量 
}

2)センサーの使用手順

一般的に、直接Sensorを取得して上記の情報を取得することはほとんどありません。なぜなら、それはあまり大きな意味がないからです。私たちはどちらかというと、センサーが収集したデータを取得することが多いです。例えば、現在の大気圧を取得したり、方位センサーの3つの角度の値を取得したり、ジャイロスコープの値を取得したりします。そして、ほとんどのセンサーデータ収集は以下のような手順です：

~Step 1：センサーマネージャーを取得する：

SensorManager sm = (SensorManager)getSystemService(SENSOR_SERVICE);

~Step 2：特定のメソッドを呼び出して必要なセンサーを取得する：

例えばここでは方位センサーを取得しています。どのセンサーを取得したいかは自分でAPIを調べてください〜：

Sensor mSensorOrientation = sm.getDefaultSensor(Sensor.TYPE_ORIENTATION);

~Step 3：SensorEventListenerインターフェースを実装し、onSensorChangedとonAccuracyChangedのメソッドをオーバーライドします！

onSensorChanged：センサーの値が変化したときにコールバックされます

onAccuracyChanged：センサーの精度が変化したときにコールバックされます

@Override
public void onSensorChanged(SensorEvent event) {
    final float[] _Data = event.values;
   this.mService.onSensorChanged(_Data[0],_Data[1],_Data[2]);
}
@Override
public void onAccuracyChanged(Sensor sensor, int accuracy) {
}

私たちが一般的にセンサーデータを取得する元となるのはこのSensorEventで、このクラスにはvaluesという変数があり、型は`float[]`でFloat[]、この変数は最大で3つの要素しか持ちません。また、センサーによって対応する要素の意味も異なります。例えば、方位センサーでは最初の要素は方位角の値であり、気圧センサーでは最初の値が気圧値です！

~Step 4：SensorManagerオブジェクトがregisterListenerを呼び出してリスナーを登録します：

<code>ms.registerListener(mContext, mSensorOrientation, android.hardware.SensorManager.SENSOR_DELAY_UI);
</code>

メソッドも非常に簡単で、対応するパラメータは：コンテキストオブジェクト，Sensorセンサーオブジェクト、およびセンサーの遅延時間の精度密度、4つの選択可能な値があります：

  • SENSOR_DELAY_FASTEST——遅延：0ms
  • SENSOR_DELAY_GAME——遅延：20ms
  • SENSOR_DELAY_UI——遅延：60ms
  • SENSOR_DELAY_NORMAL——遅延：200ms

もちろん、低遅延はより頻繁なチェックを意味し、より多くの電力消費を意味します。精度が非常に要求されない限り、あまり高精度のものを使わないことをお勧めします。一般的には3つ目を使うことが多いです〜自分で判断してください〜

~Step 5：リスナーの登録解除：

使い終わったら解放する、とても良い習慣です。一般的にはActivityやServiceの破棄メソッドに書くことができます：

ms.registerListener(mContext, mSensorOrientation, android.hardware.SensorManager.SENSOR_DELAY_UI);

では、手順はとても簡単です〜
