テンソルとは？

分類 プログラミング技術

1つの数字から、数字の並びへ、そして表へ——次元が増え続けると、テンソルが得られます。これはAIの世界でデータを記述する最も汎用的なコンテナです。

テンソル Tensor表をもう1枚重ねる
1. 直感的導入

1. 直感的導入：テンソルとは一体何か？

まず数式は見ずに、1枚の写真を見てみましょう。3×3ピクセルの小さなカラー画像で、各ピクセルにはR、G、Bの3つの輝度値があります。この画像を完全に記述するには、3方向の座標が必要です：何行目、何列目、どの色チャンネルか。

これが「3階テンソル」です——これは神秘的な新しい概念ではなく、「表」という考え方を3つ目の方向に沿ってもう1層広げただけです。「複数の層を重ねた行列」と理解して構いません。

一言で理解する：スカラーは点、ベクトルは点の並び、行列は面、テンソルは「面」をさらに多くの方向に積み重ねたものです。階数（rank）とは「1つの要素を特定するために必要な座標の数」です。
2. 数学的定義

2. 数学的定義

2.1 スカラーからテンソルへの統一的表現

それらは本質的に同じものです：複数の座標でインデックス付けして値を取得するオブジェクトであり、インデックスの数が異なるだけです。

名称階数要素を特定するのに必要な座標の数記号
スカラー00個$s$
ベクトル11個：$i$ 番目$v_i$
行列22個：$i$ 行 $j$ 列$M_{ij}$
テンソル$n$$n$ 個の座標$T_{i_1 i_2 \dots i_n}$

2.2 形状（Shape）

テンソルの「形状」は、各方向にそれぞれいくつの要素があるかを表します。この講義の3×3 RGB画像の場合：

$$ \text{shape}(T) = (3,\ 3,\ 3) \quad \text{対応 } (\text{行}, \text{列}, \text{チャンネル}) $$

テンソル内の要素の総数は、形状内のすべての数字の積です：

$$ \text{要素総数} = \prod_{k=1}^{n} d_k $$

ここで $d_k$ は $k$ 番目の次元のサイズです。上の例では要素総数は $3 \times 3 \times 3 = 27$ です。

2.3 2つのテンソルの加算

形状が同じテンソル同士の加算は、対応する位置の要素を足し合わせるだけです。これはベクトル、行列から高階テンソルまで一貫しています：

$$ (A + B)_{i_1 i_2 \dots i_n} = A_{i_1 i_2 \dots i_n} + B_{i_1 i_2 \dots i_n} $$

3. Python 実践

3. Python 実践

NumPyを使って上記の3×3 RGB画像の例を実行し、「階数」と「形状」という2つの概念を直感的に体感しましょう。

3.1 3階テンソルを作成する

import numpy as np

# 模拟一张 3x3 像素的彩色小图，最后一维是 RGB 三个通道
image_tensor = np.random.randint(0, 256, size=(3, 3, 3))

print("阶数 (ndim):", image_tensor.ndim)
print("形状 (shape):", image_tensor.shape)
print("元素总数 (size):", image_tensor.size)
階数 (ndim): 3 形状 (shape): (3, 3, 3) 要素総数 (size): 27

3.2 座標で値を取得する

# 取第 0 行、第 1 列、G 通道（索引 1）的像素值
pixel_g = image_tensor[0, 1, 1]
print("该位置 G 通道值:", pixel_g)

# 取第 0 行、第 1 列的完整 RGB 三个值（一个 1 阶张量，即向量）
pixel_rgb = image_tensor[0, 1, :]
print("该位置 RGB 向量:", pixel_rgb)
その位置のGチャンネル値：143 その位置のRGBベクトル：[ 87 143 22]
観察してみましょう：スライスを使うと[0, 1, :]3階テンソルから取り出した結果は1階テンソル（ベクトル）です。これは「高階テンソルからいくつかの座標を固定すると、より低階のテンソルが得られる」ことを示しています——この法則は後でニューラルネットワークのバッチデータ処理を説明するときに繰り返し使われます。
4. 3D可視化

4. 3次元可視化：テンソルを「見る」

次にPlotlyを使って、この3×3×3テンソルを空間内の27個の点として描画します：3つの座標軸はそれぞれ「行、列、チャンネル」に対応し、各点の色の濃淡はその位置の値の大きさを表します。マウスをドラッグすると視点を回転できます。

3×3×3テンソルの空間分布 · 色が明るいほど値が大きい

注意して観察してください：「チャンネル」の層を固定すると、3×3の平面が見えます——それはまさに2階テンソル（行列）です。これが「行列はテンソルの特殊なケースである」と言われる理由でもあります。

5. AIとの関連

5. AIとの関連

テンソルがディープラーニングフレームワーク（PyTorch、TensorFlow）で最も中核的なデータ構造である理由は、ほとんどすべてのAIデータが自然にテンソルとして表現できるからです：

データ型典型的な形状各次元の意味
テキストの単語ベクトル(系列長, 単語ベクトル次元数)何番目の単語か、単語ベクトルの何次元目か
1枚のカラー画像(高さ, 幅, チャンネル)行、列、RGBチャンネル
1バッチのカラー画像(バッチサイズ, 高さ, 幅, チャンネル)何枚目の画像か、さらに画像自体の3次元
1本の動画(フレーム数, 高さ, 幅, チャンネル)何フレーム目か、さらに1フレーム画像の3次元

このように、「バッチサイズ（batch size）」というトレーニング中に最も頻繁に調整するパラメータは、本質的にはテンソルに次元を1つ追加したものです。テンソルの階数と形状を理解していれば、モデルをデバッグしているときにshape mismatchエラーを見れば、すぐにどの次元が合っていないかを特定できます。
