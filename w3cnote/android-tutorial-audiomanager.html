10.3 AudioManager(オーディオマネージャー)

カテゴリ Android 基礎入門チュートリアル

この節の導入：

マルチメディアの最初の節では、SoundPoolを使用してDuangのサンプルを作成しました。子ブタがボタンをクリックすると、突然「Duang」という音が鳴り、しかもその時の音がとても大きかったので、本当に驚きました。幸い、勤務時間中ではありませんでした。もし勤務時間中にこっそりブログを書いてマネージャーに知られたら、大変なことになっていましたね。さて、この音量の大小について言えば、Androidが提供している（音量調節の）APIを紹介する必要があります。

AudioManager(オーディオマネージャー)このクラスはAndroid.Mediaパッケージにあり、音量制御や着信音モードの操作を提供しています。この節ではこの使い方を学びましょう。簡単なミュート機能を持つDemoを作成して、毎回動画を見る前に、まずDemoに入ってミュートをクリックしてから、冗談ですよ〜。ええ、前置きはこれくらいにして、この節の内容を始めましょう！

公式APIドキュメント：AudioManager

1. AudioManagerオブジェクトのインスタンスを取得する

AudioManager audiomanage = (AudioManager)context.getSystemService(Context.AUDIO_SERVICE);

2. 関連メソッドの詳細

よく使うメソッド：

  • adjustVolume(int direction, int flags)：スマートフォンの音量を制御し、1単位ずつ大きくまたは小さくします。最初のパラメータに基づいて判断します。AudioManager.ADJUST_LOWER、1単位小さくできます；AudioManager.ADJUST_RAISE、1単位大きくできます
  • adjustStreamVolume(int streamType, int direction, int flags)：上記と同様ですが、調節するサウンドタイプを選択できます。 1）streamTypeパラメータは、サウンドタイプを指定します。以下のサウンドタイプがあります。STREAM_ALARM：スマホのアラームSTREAM_MUSIC：スマホの音楽
    STREAM_RING：電話の着信音STREAM_SYSTEAM：スマホのシステム
    STREAM_DTMF：トーン（音調）STREAM_NOTIFICATION：システム通知
    STREAM_VOICE_CALL：音声通話FLAG_SHOW_UI、プログレスバーを表示、AudioManager.PLAY_SOUND：サウンドを再生
  • setStreamVolume(int streamType, int index, intflags)：音量の大小を直接設定します
  • getMode( )：現在のオーディオモードを返します
  • setMode( )：サウンドモードを設定しますMODE_NORMAL(通常)、MODE_RINGTONE(着信音)、MODE_IN_CALL(電話中)、MODE_IN_COMMUNICATION(通話)
  • getRingerMode( )：現在の着信音モードを返します
  • setRingerMode(int streamType)：着信音モードを設定しますRINGER_MODE_NORMAL（通常）、RINGER_MODE_SILENT（ミュート）、RINGER_MODE_VIBRATE（バイブレーション）
  • getStreamVolume(int streamType)：スマートフォンの現在の音量を取得します。最大値は7、最小値は0で、0に設定すると自動的にバイブレーションモードに調整されます。
  • getStreamMaxVolume(int streamType)：スマートフォンの特定のサウンドタイプの最大音量値を取得します
  • setStreamMute(int streamType,boolean state)：スマートフォンの特定のサウンドタイプをミュートに設定します
  • setSpeakerphoneOn(boolean on)：スピーカーをオンにするかどうかを設定します
  • setMicrophoneMute(boolean on)：マイクをミュートにするかどうかを設定します
  • isMicrophoneMute()：マイクがミュートになっているか、またはオンになっているかを判定します
  • isMusicActive()：アクティブな音楽があるかどうかを判定します
  • isWiredHeadsetOn()：イヤホンが挿入されているかどうかを判定します

その他のメソッド：

  • abandonAudioFocus(AudioManager.OnAudioFocusChangeListenerl)：オーディオのフォーカスを放棄します
  • adjustSuggestedStreamVolume(int,int suggestedStreamType intflags)：最も関連するストリームの音量を調整するか、指定されたフォールバックストリームを調整します
  • getParameters(String keys)：オーディオハードウェアに可変数のパラメータ値を設定します
  • getVibrateSetting(int vibrateType)：ユーザーのバイブレーション設定が指定されたバイブレーションタイプに一致するかどうかを返します
  • isBluetoothA2dpOn()：A2DP Bluetoothヘッドセットのオーディオルーティングがオンまたはオフであるかどうかを確認します
  • isBluetoothScoAvailableOffCall()：現在のプラットフォームがSCOを使用した通話外ユースケース（オフコール）をサポートしているかどうかを表示します
  • isBluetoothScoOn()：通信がBluetooth SCOを使用しているかどうかを確認します
  • loadSoundEffects()：サウンドエフェクトをロードします
  • playSoundEffect((int effectType, float volume)：サウンドエフェクトを再生します
  • egisterMediaButtonEventReceiver(ComponentName eventReceiver)：MEDIA_BUTTONインテントの唯一のレシーバーとしてコンポーネントを登録します
  • requestAudioFocus(AudioManager.OnAudioFocusChangeListener l,int streamType,int durationHint) オーディオフォーカスをリクエストします
  • setBluetoothScoOn(boolean on)：コミュニケーションにBluetooth SCOヘッドセットを使用することを要求します
  • startBluetoothSco/stopBluetoothSco()()：Bluetooth SCOオーディオ接続を開始/停止します
  • unloadSoundEffects()：サウンドエフェクトをアンロードします

MainActivity.java：

public class MainActivity extends AppCompatActivity implements View.OnClickListener {

    private Button btn_start;
    private Button btn_stop;
    private Button btn_higher;
    private Button btn_lower;
    private Button btn_quite;
    private MediaPlayer mePlayer;
    private AudioManager aManager;
    //定义一个标志用来标示是否点击了静音按钮
    private int flag = 1;


    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        //获得系统的音频对象
        aManager = (AudioManager) getSystemService(Service.AUDIO_SERVICE);
        //初始化mediaplayer对象,这里播放的是raw文件中的mp3资源
        mePlayer = MediaPlayer.create(MainActivity.this, R.raw.countingstars);
        //设置循环播放:
        mePlayer.setLooping(true);
        bindViews();
    }

    private void bindViews() {
        btn_start = (Button) findViewById(R.id.btn_start);
        btn_stop = (Button) findViewById(R.id.btn_stop);
        btn_higher = (Button) findViewById(R.id.btn_higher);
        btn_lower = (Button) findViewById(R.id.btn_lower);
        btn_quite = (Button) findViewById(R.id.btn_quite);

        btn_start.setOnClickListener(this);
        btn_stop.setOnClickListener(this);
        btn_higher.setOnClickListener(this);
        btn_lower.setOnClickListener(this);
        btn_quite.setOnClickListener(this);
    }

    @Override
    public void onClick(View v) {
        switch (v.getId()) {
            case R.id.btn_start:
                btn_stop.setEnabled(true);
                mePlayer.start();
                btn_start.setEnabled(false);
                break;
            case R.id.btn_stop:
                btn_start.setEnabled(true);
                mePlayer.pause();
                btn_stop.setEnabled(false);
                break;
            case R.id.btn_higher:
                // 指定调节音乐的音频，增大音量，而且显示音量图形示意
                aManager.adjustStreamVolume(AudioManager.STREAM_MUSIC,
                        AudioManager.ADJUST_RAISE, AudioManager.FLAG_SHOW_UI);
                break;
            case R.id.btn_lower:
                // 指定调节音乐的音频，降低音量，只有声音,不显示图形条
                aManager.adjustStreamVolume(AudioManager.STREAM_MUSIC,
                        AudioManager.ADJUST_LOWER, AudioManager.FLAG_PLAY_SOUND);
                break;
            case R.id.btn_quite:
                // 指定调节音乐的音频，根据isChecked确定是否需要静音
                flag *= -1;
                if (flag == -1) {
                    aManager.setStreamMute(AudioManager.STREAM_MUSIC, true);   //API 23过期- -
//                    aManager.adjustStreamVolume(AudioManager.STREAM_MUSIC, AudioManager.ADJUST_MUTE,
//                            AudioManager.FLAG_SHOW_UI);   //23以后的版本用这个
                    btn_quite.setText("取消静音");
                } else {
                    aManager.setStreamMute(AudioManager.STREAM_MUSIC, false);//API 23过期- -
//                    aManager.adjustStreamVolume(AudioManager.STREAM_MUSIC, AudioManager.ADJUST_UNMUTE,
//                            AudioManager.FLAG_SHOW_UI);  //23以后的版本用这个
                    aManager.setMicrophoneMute(false);
                    btn_quite.setText("静音");
                }
                break;
        }
    }
}

コードはとても簡単です。また、ミュートを設定するメソッドはsetStreamMute()はAPI 23で非推奨になったため、別のメソッドadjustStreamVolume(int, int, int)を使用できます。その後、3番目の属性を設定します：

ADJUST_MUTE 或 ADJUST_UNMUTE！

そうそう、あともう一つ：

もしadjustStreamVolume()の3番目のパラメータにバイブレーション(Vibrator)を設定した場合は、AndroidManifest.xmlにこの権限を追加する必要がありますよ！

<**uses-permission android:name="android.permission.VIBRATE"**/>
