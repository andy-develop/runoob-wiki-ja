2.0 Zookeeper インストールと設定

カテゴリ Zookeeper チュートリアル

Linux インストール

zookeeper のダウンロードアドレスは次のとおりです:https://zookeeper.apache.org/releases.html。

安定版を1つ選択してください。本チュートリアルで使用するリリースバージョンは3.4.14です。ダウンロードしてインストールします。

ウェブサイトを開くhttps://www.apache.org/dyn/closer.lua/zookeeper/zookeeper-3.4.14/zookeeper-3.4.14.tar.gz、次のような画面が表示されます：

ダウンロードアドレスを1つ選択し、wget コマンドを使用してダウンロードしてインストールします：

Zookeeper ダウンロードとインストール

$ wget https://mirror.bit.edu.cn/apache/zookeeper/zookeeper-3.4.14/zookeeper-3.4.14.tar.gz
$ tar -zxvf zookeeper-3.4.14.tar.gz
$ cd zookeeper-3.4.14
$ cd conf/
$ cp zoo_sample.cfg zoo.cfg
$ cd ..
$ cd bin/
$ sh zkServer.sh start

実行後、サーバー側の起動に成功しました：

サーバー側の状態を確認します（単一ノードを起動）:

クライアントを起動:

$ sh zkCli.sh

ヘルプコマンド:

ZooKeeper -server host:port cmd args
        stat path [watch]
        set path data [version]
        ls path [watch]
        delquota [-n|-b] path
        ls2 path [watch]
        setAcl path acl
        setquota -n|-b val path
        history 
        redo cmdno
        printwatches on|off
        delete path [version]
        sync path
        listquota path
        rmr path
        get path [watch]
        create [-s] [-e] path data acl
        addauth scheme auth
        quit 
        getAcl path
        close 
        connect host:port

Windows でのインストール

zookeeper のダウンロードアドレスは次のとおりです:https://zookeeper.apache.org/releases.html。

アドレスを選択してバージョンをクリックしダウンロード：

ダウンロード後に解凍:

conf ディレクトリ内の zoo_sample.cfg ファイルをコピーして、zoo.cfg にリネームします:

インストールディレクトリの下に空の data フォルダーと log フォルダーを新規作成します:

zoo.cfg 設定ファイルを変更し、dataDir=/tmp/zookeeper を zookeeper インストールディレクトリにある data フォルダーに変更し、さらにデータログを追加する設定を1つ追加します（自分のインストールパスに応じて変更する必要があります）。

zkServer.cmd をダブルクリックしてプログラムを起動:

コンソールに表示されるbind to port 0.0.0.0/0.0.0.0:2181、サーバー側の起動成功を示します!

zkCli.cmd をダブルクリックしてクライアントを起動

Welcome to Zookeeper！ が表示されたら、クライアントの起動に成功したことを示します。
