カテゴリ ES6 チュートリアル

はじめに

ES6（正式名称 ECMAScript 6.0）は、JavaScript の次世代バージョン標準であり、2015年6月にリリースされました。

ES6 は主に ES5 の先天的な欠点を解決するためのものです。例えば、JavaScript にはクラスの概念がありませんでした。しかし、現在のブラウザの JavaScript は ES5 バージョンで、多くの新しいバージョンのブラウザも ES6 をサポートしていますが、実装されているのは ES6 の一部の特徴と機能にすぎません。

あなたも先にご覧いただけますECMAScript 6 簡明チュートリアルで、すぐに理解できます。

ECMAScript の背景

JavaScript は広く知られている言語名ですが、この言語名は商標（Oracle社が登録した商標）です。したがって、JavaScript の正式名称は ECMAScript です。1996年11月、JavaScript の生みの親であるネットスケープ社は、JS を国際標準化団体 ECMA（European computer manufactures association、欧州コンピュータ製造者協会）に提出し、この言語が国際標準になることを望みました。その後、ECMA はブラウザのスクリプト言語を規定する標準、すなわち ECMAScript を公開しました。これは、この言語の開放性と中立性にもつながりました。

ECMAScript の歴史

ES6 は、ECMAScript 標準の中でここ10年以上で最も大きな変更が加えられたバージョンであり、多くの新しい構文機能が追加されました。

  • 1997年、ECMAScript 1.0 が誕生しました。
  • 1998年6月、ECMAScript 2.0 が誕生しました。これは、独立した ISO 国際標準に同期させるための小さな変更を含んでいました。
  • 1999年12月、ECMAScript 3.0 が誕生しました。これは大きな成功を収め、業界で広く支持されました。JS の基本構文を確立し、その後のバージョンに完全に引き継がれました。今日に至るまで、私たちが最初に JS を学ぶとき、実は 3.0 版の構文を学んでいるのです。
  • 2000年の ECMAScript 4.0 は現在の ES6 の前身ですが、このバージョンはあまりにも急進的で、ES3 を徹底的にアップグレードするものだったため、一時的に「棚上げ」にされました。
  • 2009年12月、ECMAScript 5.0 が正式にリリースされました。ECMA の専門家グループは、ECMAScript の第5版が2013年半ばから2018年までの間、主流の開発標準になると予想しました。2011年6月、ES 5.1 がリリースされ、ISO 国際標準にもなりました。
  • 2013年、ES6 の草案が凍結され、新しい機能は追加されなくなりました。新しい機能は ES7 に回されることになりました。2015年6月、ES6 が正式に承認され、国際標準となりました。

ES6 の目標とビジョン

より書きやすい開発言語になるための目標は次のとおりです。

より複雑なアプリケーションに適応する；コードベース間の共有を実現する；新しいバージョンを継続的に反復・維持する。
