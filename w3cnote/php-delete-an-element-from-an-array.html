PHP 配列の要素を削除

カテゴリ プログラミング技術

PHPで配列の要素を削除するには複数の方法があります。以下によく使われる方法をいくつか挙げます。

データ内の1つの要素を削除

配列内の1つの要素を削除したい場合は、unset() またはarray_splice()方法。

配列要素の値(value)はわかっているが、キー(key)がわからない場合は、次を使用できますarray_search()キー(key)を取得するために。

unset() 方式

注意：unset() 方式を使用しても、他のキー(key)は変更されません。他のキー(key)を並べ替えたい場合は、次を使用できます。array_values()。

<?php
$array = array(0 => "a", 1 => "b", 2 => "c");
unset($array[1]);
           //↑ 你要删除的数组元素值的键
print_r($array);
?>

出力結果：

Array (
    [0] => a
    [2] => c
)

array_splice() 方式

使用する場合array_splice()方式を使用すると、配列のキーは自動的に再インデックスされますが、連想配列には効果がないため、次を使用する必要があります。array_values()キーを数値キーに変換します。

<?php
$array = array(0 => "a", 1 => "b", 2 => "c");
array_splice($array, 1, 1);
                   //↑ Offset which you want to delete
print_r($array);
?>

出力結果：

Array
(
    [0] => a
    [1] => c
)

array_splice()配列の指定された要素を解放する点では、unset() 関数と同じ働きをします。

配列内の複数の要素を削除

配列内の複数の要素を削除したい場合は、unset() またはarray_splice()関数を使用することはできません。次を使用する必要があります。array_diff() 或 array_diff_key()この方法を使用するには、削除するキー(key)または値(value)を知っている必要があります。

array_diff() 方式

削除する配列要素がわかっている場合は、array_diff() を使用できます。

<?php
$array = array(0 => "a", 1 => "b", 2 => "c");
$array = array_diff($array, ["a", "c"]);
                          //└────────┘→你要删除的元素
print_r($array );
?>

出力結果は次のとおりです：

Array
(
    [1] => b
)

array_diff_key() 方式

削除する配列要素のキー(key)がわかっている場合は、array_diff_key() を使用できます。関数の2番目のパラメータのキー位置に削除するキーを入力する必要があります。値は不要なので、任意で構いません。

<?php
$array = array(0 => "a", 1 => "b", 2 => "c");
$array = array_diff_key($array, [0 => "xy", "2" => "xy"]);
                               //↑           ↑ 你要删除的数组键
print_r($array);
?>

出力結果は次のとおりです：

Array (
    [1] => b
)
