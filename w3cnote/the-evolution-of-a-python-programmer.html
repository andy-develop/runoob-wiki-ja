分类 程序员人生

先日、インターネット上に面白い記事が登場した。同じ問題に対して、レベルの異なるプログラマーが書いたPythonコードが異なるスタイルを示しているという内容で、コードはどれもシンプルで面白い。

编程新手

def factorial(x):
    if x == 0:
        return 1
    else:
        return x * factorial(x - 1)
print factorial(6)

プログラミング経験1年（Pascalを学んだ人）

def factorial(x):
    result = 1
    i = 2
    while i <= x:
        result = result * i
        i = i + 1
    return result
print factorial(6)

プログラミング経験1年（SICPを読んだ人）

@tailcall
def fact(x, acc=1):
    if (x > 1): return (fact((x - 1), (acc * x)))
    else: return acc
print(fact(6))

1年のプログラミング経験（Python）

def Factorial(x):
    res = 1
    for i in xrange(2, x + 1):
        res *= i
    return res
print Factorial(6)

怠惰なPythonプログラマー

def fact(x):
    return x > 1 and x * fact(x - 1) or 1
print fact(6)

もっと怠惰なPythonプログラマー

f = lambda x: x and x * f(x - 1) or 1
print f(6)

Python 专家

import operator as op
import functional as f
fact = lambda x: f.foldl(op.mul, 1, xrange(2, x + 1))
print fact(6)

Python 黑客

import sys
@tailcall
def fact(x, acc=1):
    if x: return fact(x.__sub__(1), acc.__mul__(x))
    return acc
sys.stdout.write(str(fact(6)) + '\n')
