1.1 Verilog チュートリアル

カテゴリ Verilog チュートリアル

Verilog HDL（略して Verilog）は、デジタル回路のシステム設計に使用されるハードウェア記述言語です。アルゴリズムレベル、ゲートレベル、スイッチレベルなど、様々な抽象設計レベルでモデリングできます。

Verilog は C 言語の多くの演算子と構造を受け継いでおり、もう1つのハードウェア記述言語 VHDL と比較して、文法はそれほど厳格ではなく、コードはより簡潔で、習得しやすいです。

Verilog は文法を定義するだけでなく、文法構造に対して明確なシミュレーション意味論も定義しています。そのため、Verilog で書かれたデジタルモデルは Verilog シミュレータを使用して検証できます。

本チュートリアルの対象読者

本チュートリアルは主に Verilog 初心者向けに作られています。

Verilog の基礎がある程度ある方は、応用編や実例編を学習・交流することもできます。

本チュートリアルを読む前に必要な知識

本チュートリアルを学ぶ前に、デジタル回路の基本的な情報を理解しておく必要があります。

もしあなたがC 言語ある程度理解していれば、Verilog を早く習得するのに役立ちます。

最初の Verilog デザイン

4 ビット幅 10 進カウンタ：

実例

module counter10(
        //ポート定義
        input                   rstn,   //リセット端子、ローアクティブ
        input                   clk,    //入力クロック
        output [3:0]    cnt,    //カウント出力
        output                  cout);  //オーバーフロービット

        reg [3:0]               cnt_temp ;      //カウンタレジスタ
        always@(posedge clk or negedge rstn) begin
                if(! rstn)begin         //リセット時、カウントを0にリセット
                        cnt_temp        <= 4'b0 ;
                end
                else if (cnt_temp==4'd9) begin  //10サイクルカウントすると、カウントは0に戻る
                        cnt_temp        <=4'b000;
                end
                else begin                                      //カウントを+1
                        cnt_temp        <= cnt_temp + 1'b1 ;
                end
        end

        assign  cout = (cnt_temp==4'd9) ;       //周期ビットを出力
        assign  cnt  = cnt_temp ;                       //現在のカウント値を出力

endmodule
