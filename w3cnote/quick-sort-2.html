1.6 クイックソート

分類 アルゴリズム

クイックソート（Quick Sort）は、効率的なソートアルゴリズムであり、分割統治法（Divide and Conquer）の考え方に基づいています。その核心は、基準要素（pivot）を選択し、リストを2つの部分に分けることです。一方は基準要素より小さく、もう一方は基準要素より大きくなります。そして、これら2つの部分を再帰的にソートします。クイックソートの平均時間計算量は O(n log n) で、実際のアプリケーションでは優れた性能を発揮します。

クイックソートは、トニー・ホーアによって開発されたソートアルゴリズムです。平均的な状況では、n 個の項目をソートするのに Ο(n log n) 回の比較を必要とします。最悪の状況では Ο(n²) 回の比較が必要ですが、このような状況は一般的ではありません。実際、クイックソートは通常、他の Ο(n log n) アルゴリズムよりも明らかに高速です。なぜなら、その内部ループ（inner loop）は、ほとんどのアーキテクチャで非常に効率的に実装できるからです。

クイックソートは、分割統治法（Divide and conquer）戦略を使用して、リストを2つのサブリスト（sub-lists）に分割します。

クイックソートは、分割統治の考え方をソートアルゴリズムに応用した代表的な例でもあります。本質的に、クイックソートはバブルソートを基にした再帰的分割統治法とみなすことができます。

クイックソートという名前は、単純で乱暴です。というのも、この名前を聞けば存在意義がわかるからです。つまり、速い、そして効率が高い！大規模データを処理する最速のソートアルゴリズムの1つです。最悪の場合（Worst Case）の時間計算量は O(n²) ですが、それでも優れています。ほとんどの場合、平均時間計算量が O(n log n) のソートアルゴリズムよりも優れた性能を発揮します。では、なぜでしょうか、私にもわかりません。幸い、私の完璧主義がまた発動し、多くの資料を調べた末に、ついに『アルゴリズムの芸術と情報学コンテスト』で満足のいく答えを見つけました。

クイックソートの最悪の実行状況は O(n²) です。例えば、順序数列のクイックソートなどです。しかし、その償却期待時間は O(n log n) であり、O(n log n) の記法に暗黙に含まれる定数因子は非常に小さく、複雑度が安定して O(n log n) であるマージソートよりもはるかに小さいです。したがって、ほとんどの順序性が弱いランダムな数列に対して、クイックソートは常にマージソートよりも優れています。

1. アルゴリズムの手順

  1. 基準要素の選択：リストから1つの要素を基準（pivot）として選択します。選択方法は、最初の要素、最後の要素、中央の要素、またはランダムな要素にすることができます。

  2. 分割：基準要素より小さいすべての要素が基準の左側に、基準要素より大きいすべての要素が基準の右側に来るようにリストを並べ替えます。基準要素の位置は分割完了後に確定します。

  3. 再帰的ソート：基準要素の左側と右側のサブリストに対して、それぞれ再帰的にクイックソートを実行します。

  4. マージ：分割操作はインプレースで行われるため、再帰が終了するとリスト全体が整列済みになります。

2. アニメーションデモ

ソート対象のリストがあるとします[3, 6, 8, 10, 1, 2, 1]、最後の要素を基準（pivot）として選択し、ソートの過程は以下のとおりです。

  1. 初期状態：

    • リスト：[3, 6, 8, 10, 1, 2, 1]。

    • 基準要素：1（最後の要素）。

  2. 第1ラウンドの分割：

    • 基準より小さい要素を左側に、基準より大きい要素を右側に置きます。

    • 分割後のリスト：[1, 1, 2, 10, 6, 8, 3]。

    • 基準要素1の位置が確定します。

  3. 再帰的ソート：

    • 左側のサブリスト[1]と右側のサブリスト[2, 10, 6, 8, 3]に対して、それぞれクイックソートを実行します。

    • 左側のサブリストはすでに整列済みです。

    • 右側のサブリストについて[2, 10, 6, 8, 3]基準要素を選択3（最後の要素）：

      • 分割後のリスト：[2, 3, 6, 8, 10]。

      • 基準要素3の位置が確定します。

    • 右側のサブリストの再帰的ソートを続けます[6, 8, 10]：

      • 基準要素を選択10（最後の要素）：

        • 分割後のリスト：[6, 8, 10]。

        • 基準要素10の位置が確定します。

      • 左側のサブリストの再帰的ソートを続けます[6, 8]：

        • 基準要素を選択8（最後の要素）：

          • 分割後のリスト：[6, 8]。

          • 基準要素8の位置が確定します。

        • 左側のサブリストの再帰的ソートを続けます[6]、すでに整列済みです。

  4. 最終結果：

    • リストが完全に整列されました：[1, 1, 2, 3, 6, 8, 10]。

例

def quick_sort(arr):
    if len(arr) <= 1:
        return arr

    # 基準要素を選択（ここでは最後の要素を選択）
    pivot = arr[-1]
    # 分割：基準より小さい要素は左側、基準より大きい要素は右側に置く
    left = [x for x in arr[:-1] if x <= pivot]
    right = [x for x in arr[:-1] if x > pivot]
    # 再帰的にソートして結合
    return quick_sort(left) + [pivot] + quick_sort(right)

# 例
arr = [3, 6, 8, 10, 1, 2, 1]
sorted_arr = quick_sort(arr)
print(sorted_arr)  # 出力: [1, 1, 2, 3, 6, 8, 10]

時間計算量

  • 分解：毎回リストを半分に分割するため、O(log n) 層の再帰が必要です。

  • マージ：各層の再帰では、サブリストをマージするのに O(n) の時間が必要です。

  • 総時間計算量：O(n log n)。

空間計算量

  • O(n)。マージソートは一時リストを格納するために追加のスペースが必要です。

長所と短所

  • 長所：

    • 平均時間計算量は O(n log n) で、ほとんどの場合に非常に効率的です。

    • インプレースソート方式であり、O(log n) の追加スペース（再帰スタック）のみ必要です。

    • メモリ内の大規模データのソートに適しており、汎用ソート関数（例: std::sort）でよく使用されます。

  • 短所：

    • 不安定なソートであり、同じ要素の相対的な順序が変わる可能性があります。

    • 最悪の時間計算量は O(n²) です（例: 配列がほぼ整列済みの場合）。ただし、ランダム化や「三数取中」による最適化が可能です。

    • 小規模データでは性能が低く、挿入ソートなどの単純なアルゴリズムに劣ります。

適用シーン

  • 大規模データセットのソート。

  • 安定ソートアルゴリズムが必要なシーン。

  • 外部ソート（例: ディスクファイルのソート）。

function quickSort(arr, left, right) {
    var len = arr.length,
        partitionIndex,
        left = typeof left != 'number' ? 0 : left,
        right = typeof right != 'number' ? len - 1 : right;

    if (left < right) {
        partitionIndex = partition(arr, left, right);
        quickSort(arr, left, partitionIndex-1);
        quickSort(arr, partitionIndex+1, right);
    }
    return arr;
}

function partition(arr, left ,right) {     // 分割操作
    var pivot = left,                      // 基準値（pivot）を設定
        index = pivot + 1;
    for (var i = index; i <= right; i++) {
        if (arr[i] < arr[pivot]) {
            swap(arr, i, index);
            index++;
        }        
    }
    swap(arr, pivot, index - 1);
    return index-1;
}

function swap(arr, i, j) {
    var temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}
function partition2(arr, low, high) {
  let pivot = arr[low];
  while (low < high) {
    while (low < high && arr[high] > pivot) {
      --high;
    }
    arr[low] = arr[high];
    while (low < high && arr[low] <= pivot) {
      ++low;
    }
    arr[high] = arr[low];
  }
  arr[low] = pivot;
  return low;
}

function quickSort2(arr, low, high) {
  if (low < high) {
    let pivot = partition2(arr, low, high);
    quickSort2(arr, low, pivot - 1);
    quickSort2(arr, pivot + 1, high);
  }
  return arr;
}

def partition(arr, left, right):
    pivot = left
    index = pivot+1
    i = index
    while  i <= right:
        if arr[i] < arr[pivot]:
            swap(arr, i, index)
            index+=1
        i+=1

def swap(arr, i, j):

func partition(arr []int, left, right int) int {

        index := pivot + 1

        for i := index; i <= right; i++ {

                        index += 1

        }
        swap(arr, pivot, index-1)
        return index - 1

        arr[i], arr[j] = arr[j], arr[i]

public class QuickSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // arr をコピーし、パラメータの内容を変更しない
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        return quickSort(arr, 0, arr.length - 1);
    }

    private int[] quickSort(int[] arr, int left, int right) {
        if (left < right) {
            int partitionIndex = partition(arr, left, right);
            quickSort(arr, left, partitionIndex - 1);
            quickSort(arr, partitionIndex + 1, right);
        }
        return arr;
    }

    private int partition(int[] arr, int left, int right) {
        // 基準値（pivot）を設定
        int pivot = left;
        int index = pivot + 1;
        for (int i = index; i <= right; i++) {
            if (arr[i] < arr[pivot]) {
                swap(arr, i, index);
                index++;
            }
        }
        swap(arr, pivot, index - 1);
        return index - 1;
    }

    private void swap(int[] arr, int i, int j) {
        int temp = arr[i];
        arr[i] = arr[j];
        arr[j] = temp;
    }

}

void quick_sort(int arr[], const int len) {
    if (len <= 0)
        return; // lenが負の値のときにセグメンテーションフォルト（Segment Fault）を引き起こさないようにする
    // r[]はリストを模擬し、pは数量、r[p++]はpush、r[--p]はpopであり要素を取得する
    Range r[len];
    int p = 0;
    r[p++] = new_Range(0, len - 1);
    while (p) {
        Range range = r[--p];
        if (range.start >= range.end)
            continue;
        int mid = arr[(range.start + range.end) / 2]; // 中間点を基準点として選択
        int left = range.start, right = range.end;
        do {
            while (arr[left] < mid) ++left;   // 基準点の左側が要件を満たしているか確認
            while (arr[right] > mid) --right; // 基準点の右側が要件を満たしているか確認
            if (left <= right) {
                swap(&arr[left], &arr[right]);
                left++;
                right--;               // ポインタを移動して続行
            }
        } while (left <= right);
        if (range.start < right) r[p++] = new_Range(range.start, right);
        if (range.end > left) r[p++] = new_Range(left, range.end);
    }
}

void quick_sort_recursive(int arr[], int start, int end) {
    if (start >= end)
        return;
    int mid = arr[end];
    int left = start, right = end - 1;
    while (left < right) {
        while (arr[left] < mid && left < right)
            left++;
        while (arr[right] >= mid && left < right)
            right--;
        swap(&arr[left], &arr[right]);
    }
    if (arr[left] >= arr[end])
        swap(&arr[left], &arr[end]);
    else
        left++;
    if (left)
        quick_sort_recursive(arr, start, left - 1);
    quick_sort_recursive(arr, left + 1, end);
}

struct Range {
    int start, end;
    Range(int s = 0, int e = 0) {
        start = s, end = e;
    }
};
template <typename T> // 整数または浮動小数点数はどちらも使用可能。オブジェクト（class）を使用する場合は、「小なり」(<)、「大なり」(>)、「以上」(>=) の演算子機能を設定する必要があります。
void quick_sort(T arr[], const int len) {
    if (len <= 0)
        return; // lenが負の値のときにスタック配列を宣言してクラッシュするのを防ぐ
    // r[]はスタックを模擬し、pは数量、r[p++]はpush、r[--p]はpopであり要素を取得する
    Range r[len];
    int p = 0;
    r[p++] = Range(0, len - 1);
    while (p) {
        Range range = r[--p];
        if (range.start >= range.end)
            continue;
        T mid = arr[range.end];
        int left = range.start, right = range.end - 1;
        while (left < right) {
            while (arr[left] < mid && left < right) left++;
            while (arr[right] >= mid && left < right) right--;
            std::swap(arr[left], arr[right]);
        }
        if (arr[left] >= arr[range.end])
            std::swap(arr[left], arr[range.end]);
        else
            left++;
        r[p++] = Range(range.start, left - 1);
        r[p++] = Range(left + 1, range.end);
    }
}

template <typename T>
void quick_sort_recursive(T arr[], int start, int end) {
    if (start >= end)
        return;
    T mid = arr[end];
    int left = start, right = end - 1;
    while (left < right) { // 全体の範囲でピボット値より小さいまたは大きい要素を探し、左側の要素と右側の要素を交換する
        while (arr[left] < mid && left < right) // 左側でピボットより大きい要素を探す
            left++;
        while (arr[right] >= mid && left < right) // 右側でピボットより小さい要素を探す
            right--;
        std::swap(arr[left], arr[right]); // 要素を交換
    }
    if (arr[left] >= arr[end])
        std::swap(arr[left], arr[end]);
    else
        left++;
    quick_sort_recursive(arr, start, left - 1);
    quick_sort_recursive(arr, left + 1, end);
}
