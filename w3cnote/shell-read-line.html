SHELL はファイルの各行の内容を読み取って出力する

分类 编程技术

読み取るファイルが現在のディレクトリにある test.txt ファイルであると仮定し、内容は以下の通りです：

Google 
Runoob
Taobao

实例 1

#!/bin/bash

while read line
do
    echo $line
done < test.txt

実行出力結果は：

Google
Runoob
Taobao

实例 2

#!/bin/bash

cat test.txt | while read line
do
    echo $line
done

実行出力結果は：

Google
Runoob
Taobao

实例 3

for line in `cat  test.txt`
do
    echo $line
done

実行出力結果は：

Google
Runoob
Taobao

for の行ごとの読み取りと while の行ごとの読み取りには違いがあります。例:

$ cat test.txt
Google
Runoob
Taobao

$ cat test.txt | while read line; do echo $line; done
Google
Runoob
Taobao


$ for line in $(<test.txt); do echo $line; done
Google
Runoob
Taobao
