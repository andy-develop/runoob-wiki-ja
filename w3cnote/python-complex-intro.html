Python 複素数属性およびメソッド操作例

カテゴリ プログラミング技術

複素数は実数と虚数の組み合わせで構成され、次のように表されます：x+yj

複素数は、一対の順序付けられた浮動小数点数 (x,y) であり、x は実数部、y は虚数部です。

Python言語における複素数に関する概念：

1、虚数は単独では存在できず、常に値が 0.0 の実数部と一緒に複素数を構成します。

2、複素数は実数部と虚数部から構成されます。

3、虚数を表す構文：real+imagej

4、実数部と虚数部はどちらも浮動小数点数です。

5、虚数部には接尾辞 j または J が必要です。

#coding=utf8

aa=123-12j
print aa.real  # output 实数部分 123.0  
print aa.imag  # output虚数部分 -12.0

出力結果は次のとおりです：

123.0
-12.0

複素数の組み込み属性：

複素数オブジェクトはデータ属性を持ち、それぞれその複素数の実部と虚部です。

複素数には conjugate メソッドもあり、これを呼び出すとその複素数の共役複素数オブジェクトを返します。

複素数属性：real（複素数の実部）、imag（複素数の虚部）、conjugate()（複素数の共役複素数を返す）

#coding=utf8

class Complex(object):
    '''创建一个静态属性用来记录类版本号'''
    version=1.0
    '''创建个复数类，用于操作和初始化复数'''
    def __init__(self,rel=15,img=15j):
        self.realPart=rel
        self.imagPart=img
       
    #创建复数
    def creatComplex(self):
        return self.realPart+self.imagPart
    #获取输入数字部分的虚部
    def getImg(self):
        #把虚部转换成字符串
        img=str(self.imagPart)
        #对字符串进行切片操作获取数字部分
        img=img[:-1] 
        return float(img)  
                       
def test():
    print "run test..........."
    com=Complex()
    Cplex= com.creatComplex()
    if Cplex.imag==com.getImg():
        print com.getImg()
    else:
        pass
    if Cplex.real==com.realPart:
        print com.realPart
    else:
        pass
    #原复数
    print "the religion complex is :",Cplex
    #求取共轭复数
    print "the conjugate complex is :",Cplex.conjugate()
    
if __name__=="__main__":
    test()
