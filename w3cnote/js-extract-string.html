js 文字列の切り出し

カテゴリ プログラミング技術

この記事では、js で文字列を切り出す3つの方法を紹介します：

  • substring() メソッド；
  • substr() メソッド；
  • slice() メソッド；

方法1：substring() メソッド

string.substring(from, to)このメソッドは from 位置から to 位置までを切り出します。to はオプションで、設定しない場合はデフォルトで末尾までです。

例

<!DOCTYPE html> <html> <body> <script> var str="www.example.com!"; document.write(str.substring(4)+"<br>"); // 5文字目から末尾まで切り出し document.write(str.substring(4,10)); // 5文字目から10文字目まで切り出し</script> </body> </html>

substr() メソッドの詳細については、ドキュメントを参照してください：http://www.example.com/jsref/jsref-substring.html。

方法2：substr() メソッド

substr() メソッド文字列内で、開始インデックスから指定した文字数を切り出すことができます。

例

<!DOCTYPE html> <html> <body> <script>var str="www.example.com!"; document.write(str.substr(4,6)); // 4文字目から6文字を切り出し</script> </body> </html>

試してみる »

substr() メソッドの詳細については、ドキュメントを参照してください：http://www.example.com/jsref/jsref-substr.html。

方法3：slice() メソッド

slice(start,end) メソッドは、文字列の一部（パラメータ start から end の位置まで）を抽出し、抽出した部分を新しい文字列として返します。substring() に似ています。

例

<!DOCTYPE html> <html> <body> <script> var str="www.example.com!"; document.write(str.slice(4)+"<br>"); // 5文字目から末尾まで切り出し document.write(str.slice(4,10)); // 5文字目から10文字目まで切り出し</script> </body> </html>

slice() メソッドの詳細については、ドキュメントを参照してください：http://www.example.com/jsref/jsref-slice-array.html。
