4.6 Verilog 多分岐文

カテゴリ Verilog チュートリアル

キーワード：case，セレクタ

case 文は多路条件分岐の一種で、if 文で複数の条件オプションがある場合に使いにくいという問題を解決できます。

case 文

case 文の書式は次のとおりです：

case(case_expr)
    condition1     :             true_statement1 ;
    condition2     :             true_statement2 ;
    ……
    default        :             default_statement ;
endcase

case 文を実行するとき、condition1 が真なら true_statement1 を実行します。condition1 が偽で condition2 が真なら true_statement2 を実行します。以下同様に続きます。どの condition も真でない場合は、default_statement 文を実行します。

default 文はオプションであり、1 つの case 文中に複数の default 文を置くことはできません。

条件オプションは複数持つことができ、condition1、condition2 などに限られません。また、これらの条件オプションは相互排他的である必要はありません。これらの条件オプションは並行して比較されますが、実行効果としては、前にありかつ条件が真であるものが実行されます。

ture_statement1 などの実行文は、1 つの文でも複数の文でも構いません。複数の実行文の場合は、begin と end キーワードで囲む必要があります。

case 文はネストして使用できます。

以下では if 文の代わりに case 文を使用して、4 路セレクタの機能を実装します。シミュレーション結果と testbench は条件文の章を参照してください。両者は完全に一致します。

例

module mux4to1(
    input [1:0]     sel ,
    input [1:0]     p0 ,
    input [1:0]     p1 ,
    input [1:0]     p2 ,
    input [1:0]     p3 ,
    output [1:0]    sout);
 
    reg [1:0]     sout_t ;
    always @(*)
        case(sel)
            2'b00:   begin      
                    sout_t = p0 ;
                end
            2'b01:       sout_t = p1 ;
            2'b10:       sout_t = p2 ;
            default:     sout_t = p3 ;
        endcase
    assign sout = sout_t ;
 
endmodule

case 文の条件オプションの式は必ずしも定数である必要はなく、x 値や z 値でも構いません。

複数の条件オプションで同じ文を実行する必要がある場合は、複数の条件オプションをカンマで区切って、同じ文ブロックの候補に置くことができます。

ただし、case 文中の x または z の比較ロジックは合成できないため、一般に case 文で x や z を比較値として使用することは推奨されません。

例えば、4 路セレクタの case 文を拡張した例は次のとおりです：

例

case(sel)
    2'b00:   sout_t = p0 ;
    2'b01:   sout_t = p1 ;
    2'b10:   sout_t = p2 ;
    2'b11:     sout_t = p3 ;
    2'bx0, 2'bx1, 2'bxz, 2'bxx, 2'b0x, 2'b1x, 2'bzx :
        sout_t = 2'bxx ;
    2'bz0, 2'bz1, 2'bzz, 2'b0z, 2'b1z :
        sout_t = 2'bzz ;
    default:  $display("Unexpected input control!!!");
endcase

casex/casez 文

casex、casez 文は case 文の変形であり、条件オプション中のドントケア項を表すために使用されます。

casex は「x」でドントケア値を表し、casez は疑問符「?」でドントケア値を表します。

両者の実現機能は完全に同じであり、構文も case 文と完全に同じです。

ただし、casex、casez は一般に合成できず、主にシミュレーションで使用されます。

例えば、casez 文を使用して 4bit 制御端の 4 路セレクタを実装します。

例

module mux4to1(
    input [3:0]     sel ,
    input [1:0]     p0 ,
    input [1:0]     p1 ,
    input [1:0]     p2 ,
    input [1:0]     p3 ,
    output [1:0]    sout);
 
    reg [1:0]     sout_t ;
    always @(*)
        casez(sel)
            4'b???1:     sout_t = p0 ;
            4'b??1?:     sout_t = p1 ;
            4'b?1??:     sout_t = p2 ;
            4'b1???:     sout_t = p3 ;  
        default:         sout_t = 2'b0 ;
    endcase
    assign      sout = sout_t ;
 
endmodule
