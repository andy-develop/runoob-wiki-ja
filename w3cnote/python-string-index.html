Python 文字列のインデックス

カテゴリ プログラミング技術

 wraith

文字列は文字の順序付けられた集合であり、その位置によって特定の要素を取得できます。Pythonでは、文字列内の文字はインデックスによって抽出され、インデックスは0から始まります。

Pythonでは負の値も指定でき、末尾から抽出することを示します。最後の文字は-1、最後から2番目は-2です。つまり、プログラムは終端から逆方向に数えることができると見なします。

以下はPythonのインデックスとスライスのまとめです：

1. インデックスで特定のオフセットの要素を取得する

  • 文字列内の最初の要素のオフセットは0です
  • 文字列内の最後の要素のオフセットは-1です
  • str[0]最初の要素を取得
  • str[-2]最後から2番目の要素を取得

2. スライスで対応する部分のデータを抽出する

  • 通常、上界は抽出する文字列には含まれません
  • 値が指定されていない場合、スライスの境界はデフォルトで0とシーケンスの長さになります
  • str[1:3]オフセット1の文字からオフセット3までの文字列を取得します。オフセット3の文字は含みません : "tr"
  • str[1:]オフセット1の文字から文字列の最後の文字まで（最後の文字を含む）を取得します : "tring"
  • str[:3]オフセット0の文字からオフセット3までの文字列を取得します。オフセット3の文字は含みません : "str"
  • str[:-1]オフセット0の文字から最後の文字まで（最後の文字は含みません）を取得します : "strin"
  • str[:]文字列の先頭から末尾までのすべての要素を取得します : "string"
  • str[-3:-1]オフセット-3からオフセット-1までの文字を取得します。オフセット-1の文字は含みません : "in"
  • str[-1:-3]とstr[2:0]取得されるのは空文字で、システムはエラーを表示しません : ""
  • スライスするときは、ステップ（刻み幅）を追加することもできます。str[::2]出力結果は次のとおりです : "srn"
