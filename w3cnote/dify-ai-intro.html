プロジェクト名: Dify -- ゼロハードルで専用AIアプリを作成

GitHub オープンソースアドレス： https://github.com/nashsu/FreeAskInternet

公式アドレス：https://dify.ai/zh

中国語ドキュメント：https://docs.dify.ai/zh-hans

オンライン利用：https://cloud.dify.ai/

AIアプリ開発のハードルは今やどんどん低くなっています。今日はAIアプリ開発界の「スイスアーミーナイフ」をご紹介します ----Dify。

Difyはオープンソースの大規模言語モデル（LLM）アプリケーション開発プラットフォームであり、開発者にワンストップでローコード、さらにはノーコードのAIアプリ開発体験を提供することに注力しています。

Difyの中核的な目標は、AIアプリ開発のハードルを下げ、プロトタイプ設計から本番導入までの全プロセス管理をサポートすることです。

Difyは直感的なビジュアルインターフェースを備えており、開発者が基盤コードを深く理解する必要はなく、簡単なドラッグ＆ドロップや設定操作だけで、アプリのPrompt（プロンプト）、コンテキスト、各種プラグインを定義できます。

スマートカスタマーサービスと対話アシスタント：自然言語処理技術によりユーザーの問い合わせに迅速に対応し、コンテキストの記憶とマルチターン対話設計をサポートします。

コンテンツ生成とドキュメント処理：記事、要約、コードを自動生成したり、長文ドキュメントを解析して構造化抽出（例：請求書認識、契約分析）を行うことができます。

ビジネスインテリジェンスとデータ分析：企業データベースと連携し、データレポートを生成したり意思決定の提案を提供します。例えばNL2SQLにより自然言語クエリをデータベース命令に変換します。

また、外来案内全体を構築することもできます：

Difyは主要なLLM（DeepSeek、OpenAI、Anthropic、ChatGLM、通义千问など）およびEmbedding、Rerankなどの補助モデルの統合をサポートし、カスタムモデルの接続も許可します。

RAG（Retrieval-Augmented Generation）技術はDifyの大きな特徴であり、検索された外部知識と言語モデルが生成したコンテンツを組み合わせることで、AIの回答の正確性と豊富さを高めます。

さらに、ドキュメント解析やベクトル化インデックスを提供し、PDF、PPTなどの形式からテキスト抽出をサポートして、プライベート知識ベースとLLMの対話チャネルを構築し、生成コンテンツの正確性を向上させます。

インストールと使用方法

Difyシステムのデバイス最低要件：

CPU >= 2 Core

RAM >= 4 GiB

Difyをインストールする前に、お使いのコンピュータにDockerとDocker Composeがインストールされていることを確認してください。Docker Composeを使用してDifyサーバーを起動するのが最も簡単な方法です。

git clone https://github.com/langgenius/dify.git
cd dify
cd docker
cp .env.example .env
docker compose up -d
