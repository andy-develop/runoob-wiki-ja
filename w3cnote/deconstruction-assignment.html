2.2 ES6 分割代入

分類 ES6 チュートリアル

概要

分割代入は、代入演算子の拡張です。

これは、配列やオブジェクトに対してパターンマッチングを行い、その中の変数に代入する方法です。

コード記述が簡潔で読みやすく、意味がより明確になります。また、複雑なオブジェクトからデータフィールドを取得するのも便利になります。

分割モデル

分割代入には、以下の2つの部分が関与します。

    分割のソース：分割代入式の右辺部分。
  • 分割のターゲット：分割代入式の左辺部分。

配列モデルの分割代入（Array）

基本

let [a, b, c] = [1, 2, 3]; // a = 1 // b = 2 // c = 3

ネスト可能

let [a, [[b], c]] = [1, [[2], 3]]; // a = 1 // b = 2 // c = 3

無視可能

let [a, , b] = [1, 2, 3]; // a = 1 // b = 3

不完全な分割代入

let [a = 1, b] = []; // a = 1, b = undefined

残余演算子

let [a, ...b] = [1, 2, 3]; //a = 1 //b = [2, 3]

文字列など

配列の分割代入では、分割の対象が反復可能オブジェクトであれば、分割代入を行うことができます。反復可能オブジェクトとは、Iterator インターフェースを実装したデータです。

let [a, b, c, d, e] = 'hello'; // a = 'h' // b = 'e' // c = 'l' // d = 'l' // e = 'o'

分割代入のデフォルト値

let [a = 2] = [undefined]; // a = 2

分割パターンに一致する結果があり、その結果が undefined の場合、デフォルト値が戻り値として使用されます。

let [a = 3, b = a] = []; // a = 3, b = 3 let [a = 3, b = a] = [1]; // a = 1, b = 1 let [a = 3, b = a] = [1, 2]; // a = 1, b = 2
  • a と b のマッチング結果が undefined の場合、デフォルト値が使用されます：a = 3; b = a =3
  • a は通常の分割代入で、マッチング結果：a = 1、b のマッチング結果 undefined の場合、デフォルト値が使用されます：b = a =1
  • a と b は通常の分割代入で、マッチング結果：a = 1，b = 2

オブジェクトモデルの分割代入（Object）

基本

let { foo, bar } = { foo: 'aaa', bar: 'bbb' }; // foo = 'aaa' // bar = 'bbb' let { baz : foo } = { baz : 'ddd' }; // foo = 'ddd'

ネスト可能、無視可能

let obj = {p: ['hello', {y: 'world'}] }; let {p: [x, { y }] } = obj; // x = 'hello' // y = 'world' let obj = {p: ['hello', {y: 'world'}] }; let {p: [x, { }] } = obj; // x = 'hello'

不完全な分割代入

let obj = {p: [{y: 'world'}] }; let {p: [{ y }, x ] } = obj; // x = undefined // y = 'world'

残余演算子

let {a, b, ...rest} = {a: 10, b: 20, c: 30, d: 40}; // a = 10 // b = 20 // rest = {c: 30, d: 40}

分割代入のデフォルト値

let {a = 10, b = 5} = {a: 3}; // a = 3; b = 5; let {a: aa = 10, b: bb = 5} = {a: 3}; // aa = 3; bb = 5;
