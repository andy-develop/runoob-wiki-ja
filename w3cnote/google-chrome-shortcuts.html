Chrome ブラウザのショートカットキー

カテゴリ プログラミング技術

Chrome ブラウザは、現在のところほとんどのフロントエンドプログラマーが開発・デバッグに使用していると言えます。以下に Chrome ブラウザのショートカットキーをまとめました。

Windows および Linux 版の Chrome

タブとウィンドウのショートカットキー

操作 ショートカットキー
新しいウィンドウを開く Ctrl + n
シークレットモードで新しいウィンドウを開く Ctrl + Shift + n
新しいタブを開いて、そのタブに移動する Ctrl + t
最後に閉じたタブを再度開いて、そのタブに移動する Ctrl + Shift + t
次に開いているタブに移動する Ctrl + Tab または Ctrl + PgDn
前に開いているタブに移動する Ctrl + Shift + Tab または Ctrl + PgUp
特定のタブに移動する Ctrl + 1 から Ctrl + 8
最後のタブに移動する Ctrl + 9
現在のタブでホームページを開く Alt + Home
現在のタブを閉じる Ctrl + w または Ctrl + F4
開いているすべてのタブとブラウザを閉じる Ctrl + Shift + w
現在のウィンドウを最小化する Alt + スペースキー + n
現在のウィンドウを最大化する Alt + スペースキー + x
Google Chrome を終了する Ctrl + Shift + q または Alt + F4

Chrome 機能のショートカットキー

操作 ショートカットキー
「メニュー」を開く Alt + f、Alt + e または F10
ブックマークバーを表示または非表示にする Ctrl + Shift + b
ブックマークマネージャーを開く Ctrl + Shift + o
新しいタブで「履歴」ページを開く Ctrl + h
新しいタブで「ダウンロード」ページを開く Ctrl + j
Chrome のタスクマネージャーを開く Shift + Esc
Chrome ツールバーの最初の項目にフォーカスを置く Shift + Alt + t
アドレスバー、ブックマークバー（表示されている場合）、ページコンテンツの間でフォーカスを前方に切り替える F6
アドレスバー、ブックマークバー（表示されている場合）、ページコンテンツの間でフォーカスを後方に切り替える Shift + F6
検索バーを開いて現在のウェブページを検索する Ctrl + f または F3
検索バーに入力した検索語に一致する次の項目に移動する Ctrl + g
検索バーに入力した検索語に一致する前の項目に移動する Ctrl + Shift + g
「デベロッパーツール」を開く Ctrl + Shift + j または F12
「閲覧履歴データの消去」オプションを開く Ctrl + Shift + Delete
新しいタブで Chrome ヘルプセンターを開く F1
別のアカウントでログインするか、シークレットモードに入る Ctrl + Shift + m
フィードバックフォームを開く Ctrl + Shift + i

アドレスバーのショートカットキー

操作 ショートカットキー
デフォルトの検索エンジンで検索する 検索語を入力して Enter キーを押す
別の検索エンジンで検索する 検索エンジン名を入力して Tab キーを押す
サイト名に www. と .com を追加して、現在のタブでそのサイトを開く サイト名を入力して Ctrl + Enter キーを押す
サイト名に www. と .com を追加して、新しいタブでそのサイトを開く サイト名を入力して Alt + Enter キーを押す
アドレスバーに移動する Ctrl + l、Alt + d または F6
ページ内の任意の場所から検索する Ctrl + k または Ctrl + e

ウェブページのショートカットキー

操作 ショートカットキー
現在のウェブページを印刷するオプションを開く Ctrl + p
現在のウェブページを保存するオプションを開く Ctrl + s
現在のウェブページを再読み込みする F5 または Ctrl + r
現在のウェブページを再読み込みする（キャッシュされたコンテンツを無視） Shift + F5 または Ctrl + Shift + r
ウェブページの読み込みを停止する Esc
次のクリック可能な項目に移動する Tab
前のクリック可能な項目に移動する Shift + Tab
Chrome でコンピューター内のファイルを開く Ctrl + o キーを押しながらファイルを選択する
現在のウェブページの HTML ソースを表示する（変更不可） Ctrl + u
現在のウェブページをブックマークとして保存する Ctrl + d
開いているすべてのタブを新しいフォルダーにブックマークとして保存する Ctrl + Shift + d
全画面モードのオン/オフを切り替える F11
ウェブページ上のすべてのコンテンツを拡大する Ctrl と +
ウェブページ上のすべてのコンテンツを縮小する Ctrl と -
ウェブページ上のすべてのコンテンツをデフォルトのサイズに戻す Ctrl + 0
ウェブページを1画面分下にスクロールする スペースキーまたは PgDn
ウェブページを1画面分上にスクロールする Shift + スペースキーまたは PgUp
ウェブページの先頭に移動する Home
ウェブページの末尾に移動する End
ウェブページ上で水平にスクロールする Shift キーを押しながらマウスホイールをスクロールする
テキストフィールド内の前の単語の先頭にカーソルを移動する Ctrl + 左矢印キー
テキストフィールド内の前の単語の後にカーソルを移動する Ctrl + 右矢印キー
テキストフィールド内の前の単語を削除する Ctrl + Backspace
通知にフォーカスを移動する Alt + n
通知で許可する Alt + Shift + a
通知で拒否する Alt + Shift + d
現在のタブでホームページを開く Alt + Home

ウェブページのショートカットキー

操作 ショートカットキー
現在のタブでリンクを開く（マウスのみ） リンクをタブにドラッグする
新しいバックグラウンドタブでリンクを開く Ctrl キーを押しながらリンクをクリックする
リンクを開いて、そのリンクに移動する Ctrl + Shift キーを押しながらリンクをクリックする
リンクを開いて、そのリンクに移動する（マウスのみ） リンクをタブバーの空白領域にドラッグする
新しいウィンドウでリンクを開く Shift キーを押しながらリンクをクリックする
新しいウィンドウでタブを開く（マウスのみ） タブをタブバーの外にドラッグする
タブを現在のウィンドウに移動する（マウスのみ） タブを既存のウィンドウにドラッグする
タブを元の位置に戻す タブをドラッグしながら Esc を押す
現在のウェブページをブックマークとして保存する 対応する URL をブックマークバーにドラッグする
リンク先をダウンロードする Alt キーを押しながらリンクをクリックする
閲覧履歴を表示する 「戻る」矢印（戻る）または「進む」矢印（次へ）を右クリックするか、クリックしたまま押し続けます。
ウィンドウを最大化または最小化する タブバーの空白領域をダブルクリックする
ウェブページ上のすべてのコンテンツを拡大する Ctrl キーを押しながらマウスホイールを上にスクロールする
ウェブページ上のすべてのコンテンツを縮小する Ctrl キーを押しながらマウスホイールを下にスクロールする

Mac システム

操作 ショートカットキー

シークレットモードで新しいウィンドウを開く ⌘ + Shift + n

最後に閉じたタブを再度開いて、そのタブに移動する ⌘ + Shift + t
次に開いているタブに移動する ⌘ + Option + 右矢印キー

特定のタブに移動する ⌘ + 1 到 ⌘ + 8
最後のタブに移動する ⌘ + 9
現在のタブの閲覧履歴に記録されている前のページを開く ⌘ + [ 或 ⌘ + 左矢印キー
現在のタブの閲覧履歴に記録されている次のページを開く ⌘ + ] 或 ⌘ + 右矢印キー
現在のタブまたはポップアップウィンドウを閉じる ⌘ + w
