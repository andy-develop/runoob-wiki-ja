SQL構文リファレンス

分类 编程技术

Select

用途：

指定されたテーブルから指定された列のデータを取得します。

语法：

SELECT column_name(s) FROM table_name

解释：

データベースから指定された列を選択し、1つまたは複数の指定されたテーブルから、1つまたは複数の指定された列または行を選択することができます。SELECT ステートメントの完全な構文はかなり複雑ですが、主要な句は次のように要約できます：

SELECT select_list 
[ INTO new_table ] 
FROM table_source 
[ WHERE search_condition ] 
[ GROUP BY group_by_expression ] 
[ HAVING search_condition ] 
[ ORDER BY order_expression [ ASC | DESC ] ]

实例：

「Persons」テーブルには次のデータがあります：

LastName FirstName Address City
Hansen Ola Timoteivn 10 Sandnes
Svendson Tove Borgvn 23 Sandnes
Pettersen Kari Storgt 20 Stavanger

フィールド名「LastName」、「FirstName」のデータを選択します：

SELECT LastName,FirstName FROM Persons

返回结果：

LastName FirstName
Hansen Ola
Svendson Tove
Pettersen Kari

すべてのフィールドのデータを選択する：

SELECT * FROM Persons

返回结果：

LastName FirstName Address City
Hansen Ola Timoteivn 10 Sandnes
Svendson Tove Borgvn 23 Sandnes
Pettersen Kari Storgt 20 Stavanger

Where

用途：

選択クエリの基準を規定するために使用されます。

语法：

SELECT column FROM table WHERE column condition value

以下の演算子は WHERE で使用できます：

=,<>,>,<,>=,<=,BETWEEN,LIKE

注意：一部の SQL のバージョンでは、不等号 < > は != と書くことができます。

解释：

SELECT ステートメントは、WHERE 句で条件が true であるデータを返します。

实例：

「Persons」テーブルから「Sandnes」に住んでいる人を選択します：

SELECT * FROM Persons WHERE City='Sandnes'

「Persons」テーブルには次のデータがあります：

LastName FirstName Address City Year
Hansen Ola Timoteivn 10 Sandnes 1951
Svendson Tove Borgvn 23 Sandnes 1978
Svendson Stale Kaivn 18 Sandnes 1980
Pettersen Kari Storgt 20 Stavanger 1960

返回结果：

LastName FirstName Address City Year
Hansen Ola Timoteivn 10 Sandnes 1951
Svendson Tove Borgvn 23 Sandnes 1978
Svendson Stale Kaivn 18 Sandnes 1980

And & Or

用途：

WHERE 句では、AND と OR が2つ以上の条件を結合するために使用されます。

解释：

AND は2つのブール式を結合するとき、両方の式が TRUE の場合にのみ TRUE を返します。

OR は2つのブール式を結合するとき、いずれか一方の条件が TRUE であれば、TRUE を返します。

实例：

「Persons」テーブルの元のデータ：

LastName FirstName Address City
Hansen Ola Timoteivn 10 Sandnes
Svendson Tove Borgvn 23 Sandnes
Svendson Stephen Kaivn 18 Sandnes

AND 演算子を使用して、「Persons」テーブルで FirstName が「Tove」かつ LastName が「Svendson」であるデータを検索します：

SELECT * FROM Persons
WHERE FirstName='Tove'
AND LastName='Svendson'

返回结果：

LastName FirstName Address City
Svendson Tove Borgvn 23 Sandnes

OR 演算子を使用して、「Persons」テーブルで FirstName が「Tove」または LastName が「Svendson」であるデータを検索します：

SELECT * FROM Persons
WHERE firstname='Tove'
OR lastname='Svendson'

返回结果：

LastName FirstName Address City
Svendson Tove Borgvn 23 Sandnes
Svendson Stephen Kaivn 18 Sandnes

AND と OR を組み合わせることもできます（括弧を使用して複雑な式を形成します）。例：

SELECT * FROM Persons WHERE
(FirstName='Tove' OR FirstName='Stephen')
AND LastName='Svendson'

返回结果：

LastName FirstName Address City
Svendson Tove Borgvn 23 Sandnes
Svendson Stephen Kaivn 18 Sandnes

Between…And

用途：

返すデータの範囲を指定する。

语法：

SELECT column_name FROM table_name
WHERE column_name
BETWEEN value1 AND value2

实例：

「Persons」テーブルの元のデータ：

LastName FirstName Address City
Hansen Ola Timoteivn 10 Sandnes
Nordmann Anna Neset 18 Sandnes
Pettersen Kari Storgt 20 Stavanger
Svendson Tove Borgvn 23 Sandnes

BETWEEN…AND を使用して、LastName が "Hansen" から "Pettersen" までのデータを返します：

SELECT * FROM Persons WHERE LastName 
BETWEEN 'Hansen' AND 'Pettersen'

返回结果：

LastName FirstName Address City
Hansen Ola Timoteivn 10 Sandnes
Nordmann Anna Neset 18 Sandnes
Pettersen Kari Storgt 20 Stavanger

指定された範囲外のデータを表示するために、NOT 演算子を使用することもできます：

SELECT * FROM Persons WHERE LastName 
NOT BETWEEN 'Hansen' AND 'Pettersen'

返回结果：

LastName FirstName Address City
Svendson Tove Borgvn 23 Sandnes

Distinct

用途：

DISTINCT キーワードは、一意の値を返すために使用されます。

语法：

SELECT DISTINCT column-name(s) FROM table-name

解释：

column-name(s) に重複する値が存在する場合、返される結果には1つだけ残す。

实例：

「Orders」テーブルの元のデータ：

Company OrderNumber
Sega 3412
サンプル 2312
Trio 4678
サンプル 6798

DISTINCT キーワードを使用して、Company フィールドの一意の値を返します：

SELECT DISTINCT Company FROM Orders

返回结果：

Company
Sega
サンプル
Trio

Order by

用途：

結果セットの並べ替えを指定します。

语法：

SELECT column-name(s) FROM table-name ORDER BY  { order_by_expression [ ASC | DESC ] }

解释：

結果セットの並び順を指定する。ASC（昇順、最低値から最高値へ）または DESC（降順、最高値から最低値へ）で並べ替えることができ、デフォルトは ASC である。

实例：

「Orders」テーブルの元のデータ：

Company OrderNumber
Sega 3412
ABC Shop 5678
サンプル 2312
サンプル 6798

Company フィールドの昇順で結果セットを返します：

SELECT Company, OrderNumber FROM Orders
ORDER BY Company

返回结果：

Company OrderNumber
ABC Shop 5678
Sega 3412
サンプル 6798
サンプル 2312

Company フィールドの降順で結果セットを返します：

SELECT Company, OrderNumber FROM Orders
ORDER BY Company DESC

返回结果：

Company OrderNumber
サンプル 6798
サンプル 2312
Sega 3412
ABC Shop 5678

Group by

用途：

結果セットをグループ化する。通常は集計関数と一緒に使用する。

语法：

SELECT column,SUM(column) FROM table GROUP BY column

实例：

「Sales」テーブルの元のデータ：

Company Amount
サンプル 5500
IBM 4500
サンプル 7100

Company フィールドでグループ化し、各 Company の Amout の合計を求めます：

SELECT Company,SUM(Amount) FROM Sales
GROUP BY Company

返回结果：

Company SUM(Amount)
サンプル 12600
IBM 4500

Having

用途：

グループまたは集計の検索条件を指定する。

语法：

SELECT column,SUM(column) FROM table
GROUP BY column
HAVING SUM(column) condition value

解释：

HAVING は通常 GROUP BY 句と同時に使用されます。GROUP BY を使用しない場合、HAVING は WHERE 句と機能が似ています。

实例：

「Sales」テーブルの元のデータ：

Company Amount
サンプル 5500
IBM 4500
サンプル 7100

Company フィールドでグループ化し、各 Company の Amout の合計が 10000 を超えるデータを求めます：

SELECT Company,SUM(Amount) FROM Sales
GROUP BY Company HAVING SUM(Amount)>10000

返回结果：

Company SUM(Amount)
サンプル 12600

Join

用途：

2つ以上のテーブルから結果セットを選択する場合は、JOIN を使用する。

实例：

"Employees" テーブルのデータは次のとおりです（ID は主キー）：

ID Name
01 Hansen, Ola
02 Svendson, Tove
03 Svendson, Stephen
04 Pettersen, Kari

「Orders」テーブルのデータは次のとおりです：

ID Product
01 Printer
03 Table
03 Chair

Employees の ID と Orders の ID を関連付けてデータを選択します：

SELECT Employees.Name, Orders.Product
FROM Employees, Orders
WHERE Employees.ID = Orders.ID

返回结果：

Name Product
Hansen, Ola Printer
Svendson, Stephen Table
Svendson, Stephen Chair

または、JOIN キーワードを使用して上記の操作を実行することもできます：

SELECT Employees.Name, Orders.Product
FROM Employees
INNER JOIN Orders
ON Employees.ID = Orders.ID

INNER JOINの構文：

SELECT field1, field2, field3
FROM first_table
INNER JOIN second_table
ON first_table.keyfield = second_table.foreign_keyfield

解释：

INNER JOIN が返す結果セットは、2つのテーブルのすべての一致するデータである。

LEFT JOINの構文：

SELECT field1, field2, field3
FROM first_table
LEFT JOIN second_table
ON first_table.keyfield = second_table.foreign_keyfield

「Employees」テーブルを「Orders」テーブルに左外部結合して、関連データを取得します：

SELECT Employees.Name, Orders.Product
FROM Employees
LEFT JOIN Orders
ON Employees.ID = Orders.ID

返回结果：

Name Product
Hansen, Ola Printer
Svendson, Tove
Svendson, Stephen Table
Svendson, Stephen Chair
Pettersen, Kari

解释：

LEFT JOIN は、"second_table" に一致するデータがない場合でも、"first_table" のすべての行を返します。

RIGHT JOINの構文：

SELECT field1, field2, field3
FROM first_table
RIGHT JOIN second_table
ON first_table.keyfield = second_table.foreign_keyfield

「Employees」テーブルを「Orders」テーブルに右外部結合して、関連データを取得します：

SELECT Employees.Name, Orders.Product
FROM Employees
RIGHT JOIN Orders
ON Employees.ID = Orders.ID

返回结果：

Name Product
Hansen, Ola Printer
Svendson, Stephen Table
Svendson, Stephen Chair

解释：

RIGHT JOIN は、"first_table" に一致するデータがない場合でも、"second_table" のすべての行を返します。

Alias

用途：

テーブル、結果セット、または列に使用でき、論理名を付けることができる。

语法：

列に別名を付けます：

SELECT column AS column_alias FROM table

テーブルに別名を付けます：

SELECT column FROM table AS table_alias

实例：

「Persons」テーブルの元のデータ：

LastName FirstName Address City
Hansen Ola Timoteivn 10 Sandnes
Svendson Tove Borgvn 23 Sandnes
Pettersen Kari Storgt 20 Stavanger

次の SQL を実行します：

SELECT LastName AS Family, FirstName AS Name
FROM Persons

返回结果：

Family Name
Hansen Ola
Svendson Tove
Pettersen Kari

次の SQL を実行します：

SELECT LastName, FirstName
FROM Persons AS Employees

返回结果：

Employees 内のデータは次のとおりです：

LastName FirstName
Hansen Ola
Svendson Tove
Pettersen Kari

Insert Into

用途：

テーブルに新しい行を挿入します。

语法：

1 行のデータを挿入します：

INSERT INTO table_name
VALUES (value1, value2,....)

指定したフィールドに行データを挿入する：

INSERT INTO table_name (column1, column2,...)
VALUES (value1, value2,....)

实例：

「Persons」テーブルの元のデータ：

LastName FirstName Address City
Pettersen Kari Storgt 20 Stavanger

次の SQL を実行して行データを挿入する：

INSERT INTO Persons 
VALUES ('Hetland', 'Camilla', 'Hagabakka 24', 'Sandnes')

挿入後、"Persons" テーブルのデータは次のとおりです：

LastName FirstName Address City
Pettersen Kari Storgt 20 Stavanger
Hetland Camilla Hagabakka 24 Sandnes

次の SQL を実行して、指定したフィールドに行データを挿入する：

INSERT INTO Persons (LastName, Address)
VALUES ('Rasmussen', 'Storgt 67')

挿入後、"Persons" テーブルのデータは次のとおりです：

LastName FirstName Address City
Pettersen Kari Storgt 20 Stavanger
Hetland Camilla Hagabakka 24 Sandnes
Rasmussen Storgt 67

Update

用途：

テーブル内の既存のデータを更新します。

语法：

UPDATE table_name SET column_name = new_value
WHERE column_name = some_value

实例：

「Person」テーブルの元のデータ：

LastName FirstName Address City
Nilsen Fred Kirkegt 56 Stavanger
Rasmussen Storgt 67

次の SQL を実行して、Person テーブルの LastName フィールドが「Rasmussen」である行の FirstName を「Nina」に更新します：

UPDATE Person SET FirstName = 'Nina'
WHERE LastName = 'Rasmussen'

更新後の「Person」テーブルのデータは次のとおりです：

LastName FirstName Address City
Nilsen Fred Kirkegt 56 Stavanger
Rasmussen Nina Storgt 67

同様に、UPDATE 文を使用して複数のフィールドを同時に更新することもできる：

UPDATE Person
SET Address = 'Stien 12', City = 'Stavanger'
WHERE LastName = 'Rasmussen'

更新後の「Person」テーブルのデータは次のとおりです：

LastName FirstName Address City
Nilsen Fred Kirkegt 56 Stavanger
Rasmussen Nina Stien 12 Stavanger

Delete

用途：

テーブル内のデータを削除します。

语法：

DELETE FROM table_name WHERE column_name = some_value

实例：

「Person」テーブルの元のデータ：

LastName FirstName Address City
Nilsen Fred Kirkegt 56 Stavanger
Rasmussen Nina Stien 12 Stavanger

Person テーブルで LastName が「Rasmussen」であるデータを削除します：

DELETE FROM Person WHERE LastName = 'Rasmussen'

削除ステートメントを実行した後、"Person" テーブルのデータは次のとおりです：

LastName FirstName Address City
Nilsen Fred Kirkegt 56 Stavanger

创建表 Create Table

用途：

新しいテーブルを作成します。

语法：

CREATE TABLE table_name 
(
column_name1 data_type, 
column_name2 data_type, 
.......
)

实例：

「Person」という名前のテーブルを作成します。このテーブルには "LastName", "FirstName", "Address", "Age" の4つのフィールドがあります：

CREATE TABLE Person 
(
LastName varchar,
FirstName varchar,
Address varchar,
Age int
)

フィールドの最大格納長を指定したい場合は、次のようにします：

CREATE TABLE Person 
(
LastName varchar(30),
FirstName varchar(30),
Address varchar(120),
Age int(3) 
)

以下の表に、SQL のデータ型の一部を示します：

数据类型 描述
integer(size)
int(size)
smallint(size)
tinyint(size)		 整数のみを格納します。数値の最大桁数は括弧内の size で指定します。
decimal(size,d)
numeric(size,d)		 小数を含む数値を格納します。数値の最大桁数は "size" で指定します。小数点の右側の最大桁数は "d" で指定します。
char(size) 固定長の文字列を格納します（文字、数字、特殊文字を含めることができます）。文字列のサイズは括弧内の size で指定します。
varchar(size) 可変長の文字列を格納します（文字、数字、特殊文字を含めることができます）。文字列の最大長は括弧内の size で指定します。
date(yyyymmdd) 存储日期。

テーブルの変更 Alter Table

用途：

既存のテーブルにフィールドを追加または削除します。

语法：

ALTER TABLE table_name 
ADD column_name datatype
ALTER TABLE table_name 
DROP COLUMN column_name

注意：一部のデータベース管理システムでは、テーブル内のフィールドの削除が許可されていません。

实例：

「Person」テーブルの元のデータ：

LastName FirstName Address
Pettersen Kari Storgt 20

Person テーブルに City という名前のフィールドを追加します：

ALTER TABLE Person ADD City varchar(30)

追加後のテーブル内のデータは以下のとおり：

LastName FirstName Address City
Pettersen Kari Storgt 20

Person テーブルから既存の Address フィールドを削除します：

ALTER TABLE Person DROP COLUMN Address

削除後のテーブル内のデータは以下のとおり：

LastName FirstName City
Pettersen Kari

テーブルの削除 Drop Table

用途：

データベース内のデータテーブル定義と、そのデータテーブル内のすべてのデータ、インデックス、トリガー、制約、および権限指定を削除します。

语法：

DROP TABLE table_name

データベースの作成 Create Database

用途：

新しいデータベースを作成します。

语法：

CREATE DATABASE database_name

データベースの削除 Drop Database

用途：

既存のデータベースを削除します。

语法：

DROP DATABASE database_name

聚集函数

count

用途：

選択した結果セット内の行数を返します。

语法：

SELECT COUNT(column_name) FROM table_name

实例：

"Persons" テーブルの元のデータは次のとおりです：

Name Age
Hansen, Ola 34
Svendson, Tove 45
Pettersen, Kari 19

レコードの総数を取得します：

SELECT COUNT(Name) FROM Persons

执行结果：

3

sum

用途：

式からすべての値の合計、または DISTINCT 値のみを返します。SUM は数値行にのみ使用できます。Null 値は無視されます。

语法：

SELECT SUM(column_name) FROM table_name

实例：

"Persons" テーブルの元のデータは次のとおりです：

Name Age
Hansen, Ola 34
Svendson, Tove 45
Pettersen, Kari 19

"Persons" テーブルの全員の年齢の合計を取得します：

SELECT SUM(Age) FROM Persons

执行结果：

98

"Persons" テーブルの年齢が20歳を超える人の年齢の合計を取得します：

SELECT SUM(Age) FROM Persons WHERE Age>20

执行结果：

79

avg

用途：

選択した結果セット内の値の平均値を返す。Null 値は無視される。

语法：

SELECT AVG(column_name) FROM table_name

实例：

"Persons" テーブルの元のデータは次のとおりです：

Name Age
Hansen, Ola 34
Svendson, Tove 45
Pettersen, Kari 19

"Persons" テーブルの全員の平均年齢を取得します：

SELECT AVG(Age) FROM Persons

执行结果：

32.67

"Persons" テーブルの年齢が20歳を超える人の平均年齢を取得します：

SELECT AVG(Age) FROM Persons WHERE Age>20

执行结果：

39.5

用途：

選択した結果セット内の値の最大値を返す。Null 値は無視される。

语法：

SELECT MAX(column_name) FROM table_name

实例：

"Persons" テーブルの元のデータは次のとおりです：

"Persons" テーブルの最大年齢を取得します：

選択した結果セット内の値の最小値を返す。Null 値は無視される。

abs

用途：

语法：

实例：

ABS(-1.0) ABS(0.0) ABS(1.0)

1.0         0.0        1.0
