Windows8 での MySQL 5.6 のインストールおよび設定の図解チュートリアル

カテゴリ プログラミング技術

一、インストール前の準備

1、インストールプログラムパッケージをダウンロードします。MySQL公式サイトwww.mysql.comからダウンロードします。図のように：

ダウンロードしたインストールファイルは図のようになります：

二、インストール

1、ダウンロードしたインストールファイルをダブルクリックします。このブログ記事でインストールするMySQLのバージョンは5.6.10.1です。図のようなページが表示されます：

2、「Install MySQL Products」をクリックして、図1-4のようなページに入ります：

3、チェックを入れる「I accept the license

terms」の後、「Next」をクリックすると、図のように最新製品の更新を検索するページが表示されます。更新が不要な場合は、下の「Skip the check for updates(not recommended)」を選択し、「Next」をクリックして続行します：

4、右側のインストールタイプの説明文書に従って、自分に合ったインストールタイプを選択します。図のように、インストールパスを変更してください。システムを再インストールした後に、MySQLを再度インストールする必要がないようにします：

5、選択したインストールタイプに応じて、いくつかのフレームワーク（framework）のインストールが必要になります。「Execute」をクリックして必要なフレームワークをインストールします。図のとおり：

6、フレームワークのインストール中の画面は、図のとおり：

7、フレームワークのインストールが成功した後のプロンプトは、図のとおり：

8、必要なフレームワークがすべてインストールされたら、図のように「Next」をクリックします：

9、インストールを開始します。図1-11のように「Execute」をクリックします。インストール中のインターフェースは図のとおり：

10、設定情報の確認です。図のように「Next」をクリックします：

11、サーバー構成タイプの選択、Developer

Machine——インストールされたMySQLサーバーは開発マシンの一部として動作し、3つのタイプの中で最も少ないメモリを占有します。Server Machine——インストールされたMySQLサーバーはサーバーマシンの一部として動作し、3つのタイプの中で中間のメモリを占有します。Dedicated MySQL Server Machine——専用のMySQLデータベースサーバーをインストールし、マシンの全有効メモリを占有します。変更は不要です。デフォルトのポート3306なども変更しなくて構いません。「Next」をクリックします：

12、管理者パスワードを設定します。図のように「Add User」を選択すると、ユーザーも作成できますが、セキュリティの観点からユーザーを作成しないことをお勧めします：

13、図のインターフェースで、システムサーバー名や、システム起動時にMySQLデータベースサーバーを自動的に起動するかどうかを設定できます。デフォルトのオプションを使用して「Next」をクリックします：

14、インストール完了を確認します。「Start MySQL Workbench after Setup」にチェックを入れると、インストールが成功したかどうかをテストできます。「Finish」をクリックします：

三、インストール成功

1、Workbench GUIページが表示されたら、図のように、インストール成功です：
