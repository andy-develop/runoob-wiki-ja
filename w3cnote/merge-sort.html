1.5 マージソート

カテゴリ アルゴリズム

マージソート（Merge sort）は、マージ操作に基づいた効率的なソートアルゴリズムです。このアルゴリズムは、分割統治法（Divide and Conquer）を採用した非常に典型的な応用例です。

典型的な分割統治の考え方によるアルゴリズム応用として、マージソートの実装には2つの方法があります：

  • トップダウンの再帰（すべての再帰メソッドは反復で書き直せるため、第2の方法が生まれました）；
  • ボトムアップの反復；

『データ構造とアルゴリズム JavaScript 記述』の中で、著者はボトムアップの反復方法を示しています。しかし再帰法については、著者は次のように考えています：

However, it is not possible to do so in JavaScript, as the recursion goes too deep for the language to handle.

しかし、JavaScript ではこの方法はあまり現実的ではありません。このアルゴリズムの再帰の深さが深すぎるからです。

正直に言うと、この言葉はあまり理解できません。JavaScript コンパイラのメモリが小さすぎて、再帰が深すぎるとメモリオーバーフローを引き起こしやすいという意味でしょうか？詳しい方にご教示いただければ幸いです。

選択ソートと同様に、マージソートの性能は入力データの影響を受けませんが、常に O(nlogn) の時間計算量であるため、選択ソートよりもはるかに優れています。代償として追加のメモリ空間が必要です。

マージソートの核となる考え方は、大きな問題をいくつかの小さな問題に分解し、それぞれの小さな問題を解決してから結果を結合し、最終的に全体の問題の解を得るというものです。具体的にソート問題に当てはめると、マージソートの手順は次のとおりです：

  1. 分解（Divide）：ソート対象の配列を2つの部分配列に分割し、各部分配列には約半分の要素が含まれます。
  2. 解決（Conquer）：各部分配列を再帰的にソートします。
  3. 結合（Combine）：2つのソート済みの部分配列を1つの順序付けられた配列に結合します。

分解と結合を繰り返すことで、最終的に配列全体がソートされます。

2. アルゴリズムの手順

  1. 2つのソート済みシーケンスの合計サイズの領域を確保し、その領域に結合後のシーケンスを格納します；

  2. 2つのポインタを設定し、初期位置はそれぞれ2つのソート済みシーケンスの開始位置とします；

  3. 2つのポインタが指す要素を比較し、相対的に小さい要素を結合領域に配置して、ポインタを次の位置に移動します；

  4. いずれかのポインタがシーケンスの末尾に達するまで手順3を繰り返します；

  5. もう一方のシーケンスの残りのすべての要素を結合シーケンスの末尾に直接コピーします。

3. アニメーションによるデモ

ソート対象のリスト [38, 27, 43, 3, 9, 82, 10] があるとします。マージソートの過程は次のとおりです：

  1. 分解：

    • リストを2つに分割します：[38, 27, 43, 3]と[9, 82, 10]。

    • さらに分解します：

      • [38, 27, 43, 3]分割[38, 27]と[43, 3]。

      • [9, 82, 10]分割[9]と[82, 10]。

    • さらに分解します：

      • [38, 27]分割[38]と[27]。

      • [43, 3]分割[43]と[3]。

      • [82, 10]分割[82]と[10]。

    • 最終的に単一要素のサブリストに分解されます。

  2. 結合：

    • 結合[38]と[27]得られる[27, 38]。

    • 結合[43]と[3]得られる[3, 43]。

    • 結合[27, 38]と[3, 43]得られる[3, 27, 38, 43]。

    • 結合[9]と[10, 82]得られる[9, 10, 82]。

    • 結合[3, 27, 38, 43]と[9, 10, 82]最終的なソート済みリストが得られます[3, 9, 10, 27, 38, 43, 82]。

例

def merge_sort(arr):
    if len(arr) <= 1:
        return arr

    # 分解：リストを2つに分割
    mid = len(arr) // 2
    left_half = merge_sort(arr[:mid])  # 左半分を再帰的にソート
    right_half = merge_sort(arr[mid:])  # 右半分を再帰的にソート

    # 結合：2つのソート済みサブリストを結合
    return merge(left_half, right_half)

def merge(left, right):
    sorted_arr = []
    i = j = 0

    # 2つのサブリストの要素を比較し、順番に結合
    while i < len(left) and j < len(right):
        if left[i] < right[j]:
            sorted_arr.append(left[i])
            i += 1
        else:
            sorted_arr.append(right[j])
            j += 1

    # 残りの要素を結果に追加
    sorted_arr.extend(left[i:])
    sorted_arr.extend(right[j:])
    return sorted_arr

# サンプル
arr = [38, 27, 43, 3, 9, 82, 10]
sorted_arr = merge_sort(arr)
print(sorted_arr)  # 出力: [3, 9, 10, 27, 38, 43, 82]

時間計算量

  • 分解：リストを毎回2つに分割するため、O(log n) 層の再帰が必要です。

  • 結合：各層の再帰でサブリストの結合に O(n) の時間が必要です。

  • 合計時間計算量：O(n log n)。

空間計算量

  • O(n)、マージソートは一時リストを格納するために追加の領域が必要です。

長所と短所

  • 長所：

    • 時間計算量が安定して O(n log n) であり、大規模なデータに適しています。

    • 安定ソートアルゴリズム（同じ要素の相対的な順序は変わりません）。

    • 外部ソートに適しています（ディスクファイルのソートなど）。

  • 短所：

    • 追加の記憶領域が必要で、空間計算量は O(n) です。

    • 小規模なデータの場合、挿入ソートなどの単純なアルゴリズムより性能があるかもしれません。

JavaScript

例

function mergeSort(arr) {  // トップダウンの再帰方法を採用
    var len = arr.length;
    if(len < 2) {
        return arr;
    }
    var middle = Math.floor(len / 2),
        left = arr.slice(0, middle),
        right = arr.slice(middle);
    return merge(mergeSort(left), mergeSort(right));
}

function merge(left, right)
{
    var result = [];

    while (left.length && right.length) {
        if (left[0] <= right[0]) {
            result.push(left.shift());
        } else {
            result.push(right.shift());
        }
    }

    while (left.length)
        result.push(left.shift());

    while (right.length)
        result.push(right.shift());

    return result;
}

func merge(left []int, right []int) []int {
        var result []int
        for len(left) != 0 && len(right) != 0 {
                if left[0] <= right[0] {
                        result = append(result, left[0])
                        left = left[1:]
                } else {
                        result = append(result, right[0])
                        right = right[1:]
                }
        }

public class MergeSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // arr をコピーし、パラメータの内容を変更しない
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        if (arr.length < 2) {
            return arr;
        }
        int middle = (int) Math.floor(arr.length / 2);

        int[] left = Arrays.copyOfRange(arr, 0, middle);
        int[] right = Arrays.copyOfRange(arr, middle, arr.length);

        return merge(sort(left), sort(right));
    }

    protected int[] merge(int[] left, int[] right) {
        int[] result = new int[left.length + right.length];
        int i = 0;
        while (left.length > 0 && right.length > 0) {
            if (left[0] <= right[0]) {
                result[i++] = left[0];
                left = Arrays.copyOfRange(left, 1, left.length);
            } else {
                result[i++] = right[0];
                right = Arrays.copyOfRange(right, 1, right.length);
            }
        }

        while (left.length > 0) {
            result[i++] = left[0];
            left = Arrays.copyOfRange(left, 1, left.length);
        }

        while (right.length > 0) {
            result[i++] = right[0];
            right = Arrays.copyOfRange(right, 1, right.length);
        }

        return result;
    }

}

void merge_sort_recursive(int arr[], int reg[], int start, int end) {
    if (start >= end)
        return;
    int len = end - start, mid = (len >> 1) + start;
    int start1 = start, end1 = mid;
    int start2 = mid + 1, end2 = end;
    merge_sort_recursive(arr, reg, start1, end1);
    merge_sort_recursive(arr, reg, start2, end2);
    int k = start;
    while (start1 <= end1 && start2 <= end2)
        reg[k++] = arr[start1] < arr[start2] ? arr[start1++] : arr[start2++];
    while (start1 <= end1)
        reg[k++] = arr[start1++];
    while (start2 <= end2)
        reg[k++] = arr[start2++];
    for (k = start; k <= end; k++)
        arr[k] = reg[k];
}

void merge_sort(int arr[], const int len) {
    int reg[len];
    merge_sort_recursive(arr, reg, 0, len - 1);
}

void Merge(vector<int> &Array, int front, int mid, int end) {
    // preconditions:
    // Array[front...mid] is sorted
    // Array[mid+1 ... end] is sorted
    // Copy Array[front ... mid] to LeftSubArray
    // Copy Array[mid+1 ... end] to RightSubArray
    vector<int> LeftSubArray(Array.begin() + front, Array.begin() + mid + 1);
    vector<int> RightSubArray(Array.begin() + mid + 1, Array.begin() + end + 1);
    int idxLeft = 0, idxRight = 0;
    LeftSubArray.insert(LeftSubArray.end(), numeric_limits<int>::max());
    RightSubArray.insert(RightSubArray.end(), numeric_limits<int>::max());
    // Pick min of LeftSubArray[idxLeft] and RightSubArray[idxRight], and put into Array[i]
    for (int i = front; i <= end; i++) {
        if (LeftSubArray[idxLeft] < RightSubArray[idxRight]) {
            Array[i] = LeftSubArray[idxLeft];
            idxLeft++;
        } else {
            Array[i] = RightSubArray[idxRight];
            idxRight++;
        }
    }
}

void MergeSort(vector<int> &Array, int front, int end) {
    if (front >= end)
        return;
    int mid = (front + end) / 2;
    MergeSort(Array, front, mid);
    MergeSort(Array, mid + 1, end);
    Merge(Array, front, mid, end);
}

public static List<int> sort(List<int> lst) {
    if (lst.Count <= 1)
        return lst;
    int mid = lst.Count / 2;
    List<int> left = new List<int>();  // 左側のListを定義
    List<int> right = new List<int>(); // 右側のListを定義
    // 以下の2つのループで lst を左右2つのListに分割します
    for (int i = 0; i < mid; i++)
        left.Add(lst[i]);
    for (int j = mid; j < lst.Count; j++)
        right.Add(lst[j]);
    left = sort(left);
    right = sort(right);
    return merge(left, right);
}
/// <summary>
/// ソート済みの2つのListを結合します
/// </summary>
/// <param name="left">左側List</param>
/// <param name="right">右側List</param>
/// <returns></returns>
static List<int> merge(List<int> left, List<int> right) {
    List<int> temp = new List<int>();
    while (left.Count > 0 && right.Count > 0) {
        if (left[0] <= right[0]) {
            temp.Add(left[0]);
            left.RemoveAt(0);
        } else {
            temp.Add(right[0]);
            right.RemoveAt(0);
        }
    }
    if (left.Count > 0) {
        for (int i = 0; i < left.Count; i++)
            temp.Add(left[i]);
    }
    if (right.Count > 0) {
        for (int i = 0; i < right.Count; i++)
            temp.Add(right[i]);
    }
    return temp;
}
