1.10 基数ソート

分類 アルゴリズム

基数ソート（Radix Sort）は比較型ではないソートアルゴリズムで、要素の各桁を（最下位桁から最上位桁まで）桁ごとに比較することでソートを実現します。基数ソートの中心的な考え方は、整数を桁ごとに分割して異なる数字にし、各桁ごとにソートを行うというものです。基数ソートの時間計算量は O(n * k) で、n はリストの長さ、k は最大の数字の桁数です。

アルゴリズムの手順：

  1. 最大桁数を決定する：リスト内の最大数字の桁数を見つけ、必要なソートのラウンド数を決定します。

  2. 桁ごとにソート：最下位桁から順に各桁をソートします（通常は計数ソートまたはバケットソートを部分ソートアルゴリズムとして使用します）。

  3. 結果をマージする：各ラウンドのソート後にリストの順序を更新し、すべての桁のソートが完了するまで繰り返します。

1. 基数ソート vs 計数ソート vs バケットソート

基数ソートには2つの方法があります：

これら3つのソートアルゴリズムはすべてバケットの概念を利用していますが、バケットの使用方法に明確な違いがあります：

  • 基数ソート：キーの各桁の数字に基づいてバケットを割り当てます；
  • 計数ソート：各バケットは単一のキーのみを格納します；
  • バケットソート：各バケットは一定範囲の数値を格納します；

2. LSD 基数ソートのアニメーションデモ

ソート対象のリスト [170, 45, 75, 90, 802, 24, 2, 66] があるとします。基数ソートの過程は次のとおりです：

  1. 最大桁数を決定：

    • 最大数字は802、3桁なので、3ラウンドのソートが必要です。

  2. 第1ラウンド（一の位でソート）：

    • 計数ソートを使用して一の位をソートします：

      • 一の位の集計：[0, 2, 4, 5, 6, 0, 2, 6]。

      • ソート後のリスト：[170, 90, 802, 2, 24, 45, 75, 66]。

  3. 第2ラウンド（十の位でソート）：

    • 計数ソートを使用して十の位をソートします：

      • 十の位の集計：[7, 9, 0, 0, 2, 4, 7, 6]。

      • ソート後のリスト：[802, 2, 24, 45, 66, 170, 75, 90]。

  4. 第3ラウンド（百の位でソート）：

    • 計数ソートを使用して百の位をソートします：

      • 百の位の集計：[8, 0, 0, 0, 1, 0, 0, 0]。

      • ソート後のリスト：[2, 24, 45, 66, 75, 90, 170, 802]。

  5. 最終結果：

    • リストが完全に整列されました：[2, 24, 45, 66, 75, 90, 170, 802]。

サンプル

def counting_sort(arr, exp):
    n = len(arr)
    output = [0] * n  # 初始化输出数组
    count = [0] * 10  # 初始化计数数组

    # 各数字の出現回数を集計する
    for num in arr:
        index = (num // exp) % 10
        count[index] += 1

    # 累積カウント配列で、各数値の最終位置を取得する
    for i in range(1, 10):
        count[i] += count[i - 1]

    # 将元素放入输出数组
    i = n - 1
    while i >= 0:
        index = (arr[i] // exp) % 10
        output[count[index] - 1] = arr[i]
        count[index] -= 1
        i -= 1

    # 将输出数组复制到原始数组
    for i in range(n):
        arr[i] = output[i]

def radix_sort(arr):
    # 最大数字の桁数を求める
    max_num = max(arr)
    exp = 1  # 一の位から始める
    while max_num // exp > 0:
        counting_sort(arr, exp)  # 現在の桁に対して計数ソートを行う
        exp *= 10  # 移动到下一位
    return arr

# 示例
arr = [170, 45, 75, 90, 802, 24, 2, 66]
sorted_arr = radix_sort(arr)
print(sorted_arr)  # 输出: [2, 24, 45, 66, 75, 90, 170, 802]

時間計算量

  • 各ラウンドのソート：O(n)。計数ソートを使用して各桁をソートします。

  • 総ラウンド数：k ラウンド。ここで k は最大数字の桁数です。

  • 総時間計算量：O(n * k)。

空間計算量

  • O(n + k)。計数配列と出力配列を格納するための追加の記憶領域が必要です。

長所と短所

  • 長所：

    • 時間計算量は O(n * k) で、k が小さい場合は性能が優れています。

    • 安定ソートアルゴリズムです（同じ要素の相対的な順序は変わりません）。

  • 短所：

    • 整数または固定長の文字列にのみ適用できます。

    • 最大数字の桁数 k が大きい場合、性能が低下します。

適用シーン

  • データ範囲が小さい整数のソート。

  • 安定ソートアルゴリズムが必要なシーン。

  • 外部ソート（ディスクファイルのソートなど）に適しています。

//LSD Radix Sort
var counter = [];
function radixSort(arr, maxDigit) {
    var mod = 10;
    var dev = 1;
    for (var i = 0; i < maxDigit; i++, dev *= 10, mod *= 10) {
        for(var j = 0; j < arr.length; j++) {
            var bucket = parseInt((arr[j] % mod) / dev);
            if(counter[bucket]==null) {
                counter[bucket] = [];
            }
            counter[bucket].push(arr[j]);
        }
        var pos = 0;
        for(var j = 0; j < counter.length; j++) {
            var value = null;
            if(counter[j]!=null) {
                while ((value = counter[j].shift()) != null) {
                      arr[pos++] = value;
                }
          }
        }
    }
    return arr;
}

/**
* 基数排序
* 負の数の場合については、こちらも参照できます： https://code.i-harness.com/zh-CN/q/e98fa9
 */
public class RadixSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // arr をコピーし、引数の内容を変更しない
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        int maxDigit = getMaxDigit(arr);
        return radixSort(arr, maxDigit);
    }

    /**
* 获取最高位数
     */
    private int getMaxDigit(int[] arr) {
        int maxValue = getMaxValue(arr);
        return getNumLenght(maxValue);
    }

    private int getMaxValue(int[] arr) {
        int maxValue = arr[0];
        for (int value : arr) {
            if (maxValue < value) {
                maxValue = value;
            }
        }
        return maxValue;
    }

    protected int getNumLenght(long num) {
        if (num == 0) {
            return 1;
        }
        int lenght = 0;
        for (long temp = num; temp != 0; temp /= 10) {
            lenght++;
        }
        return lenght;
    }

    private int[] radixSort(int[] arr, int maxDigit) {
        int mod = 10;
        int dev = 1;

        for (int i = 0; i < maxDigit; i++, dev *= 10, mod *= 10) {
            // 負の数を考慮する場合、ここではキューの数を2倍に拡張し、[0-9]は負の数、[10-19]は正の数に対応します (bucket + 10)
            int[][] counter = new int[mod * 2][0];

            for (int j = 0; j < arr.length; j++) {
                int bucket = ((arr[j] % mod) / dev) + mod;
                counter[bucket] = arrayAppend(counter[bucket], arr[j]);
            }

            int pos = 0;
            for (int[] bucket : counter) {
                for (int value : bucket) {
                    arr[pos++] = value;
                }
            }
        }

        return arr;
    }

    /**
* 自动扩容，并保存数据
     *
     * @param arr
     * @param value
     */
    private int[] arrayAppend(int[] arr, int value) {
        arr = Arrays.copyOf(arr, arr.length + 1);
        arr[arr.length - 1] = value;
        return arr;
    }
}

function radixSort($arr, $maxDigit = null)
{
    if ($maxDigit === null) {
        $maxDigit = max($arr);
    }
    $counter = [];
    for ($i = 0; $i < $maxDigit; $i++) {
        for ($j = 0; $j < count($arr); $j++) {
            preg_match_all('/\d/', (string) $arr[$j], $matches);
            $numArr = $matches[0];
            $lenTmp = count($numArr);
            $bucket = array_key_exists($lenTmp - $i - 1, $numArr)
                ? intval($numArr[$lenTmp - $i - 1])
                : 0;
            if (!array_key_exists($bucket, $counter)) {
                $counter[$bucket] = [];
            }
            $counter[$bucket][] = $arr[$j];
        }
        $pos = 0;
        for ($j = 0; $j < count($counter); $j++) {
            $value = null;
            if ($counter[$j] !== null) {
                while (($value = array_shift($counter[$j])) !== null) {
                    $arr[$pos++] = $value;
                }
          }
        }
    }

    return $arr;
}

void radixsort(int data[], int n) //基数排序
{
    int d = maxbit(data, n);
    int *tmp = new int[n];
    int *count = new int[10]; //计数器
    int i, j, k;
    int radix = 1;
    for(i = 1; i <= d; i++) //进行d次排序
    {
        for(j = 0; j < 10; j++)
            count[j] = 0; //每次分配前清空计数器
        for(j = 0; j < n; j++)
        {
            k = (data[j] / radix) % 10; //各バケット内のレコード数を集計する
            count[k]++;
        }
        for(j = 1; j < 10; j++)
            count[j] = count[j - 1] + count[j]; // tmp内の位置を各バケットに順番に割り当てる
        for(j = n - 1; j >= 0; j--) //将所有桶中记录依次收集到tmp中
        {
            k = (data[j] / radix) % 10;
            tmp[count[k] - 1] = data[j];
            count[k]--;
        }
        for(j = 0; j < n; j++) // 一時配列の内容を data にコピーする
            data[j] = tmp[j];
        radix = radix * 10;
    }
    delete []tmp;
    delete []count;
}

#include<stdio.h>
#define MAX 20
//#define SHOWPASS
#define BASE 10

void print(int *a, int n) {
  int i;
  for (i = 0; i < n; i++) {
    printf("%d\t", a[i]);
  }
}

void radixsort(int *a, int n) {
  int i, b[MAX], m = a[0], exp = 1;

  for (i = 1; i < n; i++) {
    if (a[i] > m) {
      m = a[i];
    }
  }

  while (m / exp > 0) {
    int bucket[BASE] = { 0 };

    for (i = 0; i < n; i++) {
      bucket[(a[i] / exp) % BASE]++;
    }

    for (i = 1; i < BASE; i++) {
      bucket[i] += bucket[i - 1];
    }

    for (i = n - 1; i >= 0; i--) {
      b[--bucket[(a[i] / exp) % BASE]] = a[i];
    }

    for (i = 0; i < n; i++) {
      a[i] = b[i];
    }

    exp *= BASE;

#ifdef SHOWPASS
    printf("\nPASS   : ");
    print(a, n);
#endif
  }
}

-- 获取表中位数
local maxBit = function (tt)
    local weight = 10;      -- 十進制
    local bit = 1;
   
    for k, v in pairs(tt) do
        while v >= weight do
            weight = weight * 10;
            bit = bit + 1;  
        end
    end
    return bit;
end
-- 基数排序
local radixSort = function (tt)
    local maxbit = maxBit(tt);

    local bucket = {};
    local temp = {};
    local radix = 1;
    for i = 1, maxbit do
        for j = 1, 10 do
            bucket[j] = 0;      --- 清空桶
        end
        for k, v in pairs(tt) do
            local remainder = math.floor((v / radix)) % 10 + 1;    
            bucket[remainder] = bucket[remainder] + 1;      -- 每個桶數量自動增加1
        end
       
        for j = 2, 10 do
            bucket[j] = bucket[j - 1] + bucket[j];  -- 各バケットの数量 = 以前のバケット数量の合計 + 自身の数量
        end
        -- バケットの位置に従ってソートします。これはバケットソートです。逆順を使用する必要があります。ソート方法は小さいものから大きいものへであるため、順に処理すると、大きいものが小さいものの上に残ってクリアされないことになります。
        for k = #tt, 1, -1 do
            local remainder = math.floor((tt[k] / radix)) % 10 + 1;
            temp[bucket[remainder]] = tt[k];
            bucket[remainder] = bucket[remainder] - 1;
        end
        for k, v in pairs(temp) do
            tt[k] = v;
        end
        radix = radix * 10;
    end
end;
