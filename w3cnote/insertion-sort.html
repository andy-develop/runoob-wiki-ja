1.3 挿入ソート

分類 アルゴリズム

挿入ソート（Insertion Sort）は、シンプルで直感的なソートアルゴリズムであり、その動作原理はトランプのカードを整理するのに似ています。

挿入ソートは順序付けられた列を構築し、未ソートのデータに対して、ソート済みの列を後ろから前へ走査し、該当する位置を見つけて挿入します。

挿入ソートのコード実装は、バブルソートや選択ソートほど単純で乱暴ではありませんが、その原理は最も理解しやすいはずです。トランプをやったことがある人なら誰でも即座に理解できるからです。

挿入ソートには、バブルソートと同様に、二分挿入と呼ばれる最適化アルゴリズムもあります。

1. アルゴリズムの手順

  1. 初期化：リストをソート済み部分と未ソート部分に分けます。初期状態では、ソート済み部分は最初の要素のみを含み、未ソート部分は残りの要素を含みます。

  2. 要素の選択：未ソート部分から最初の要素を取り出します。

  3. ソート済み部分への挿入：その要素をソート済み部分の要素と後ろから前に向かって順に比較し、適切な位置を見つけて挿入します。

  4. 手順の繰り返し：未ソート部分が空になり、リストが完全に整列するまで、上記の手順を繰り返します。

2. アニメーション図解

ソート待ちのリスト [5, 2, 4, 6, 1, 3] があると仮定すると、挿入ソートのプロセスは次のようになります：

  1. 初期状態：

    • ソート済み部分：[5]。

    • 未ソート部分：[2, 4, 6, 1, 3]。

  2. 第1ラウンド：

    • 未ソート部分の最初の要素を取り出します2。

    • 将 2ソート済み部分の5と比較し、2 < 5、挿入先は5の前です。

    • リストは次のようになります[2, 5, 4, 6, 1, 3]。

    • ソート済み部分：[2, 5]、未ソート部分：[4, 6, 1, 3]。

  3. 第2ラウンド：

    • 未ソート部分の最初の要素を取り出します4。

    • 将 4ソート済み部分の5と比較し、4 < 5、続けて2と比較し、4 > 2、挿入先は2と5の間です。

    • リストは次のようになります[2, 4, 5, 6, 1, 3]。

    • ソート済み部分：[2, 4, 5]、未ソート部分：[6, 1, 3]。

  4. 第3ラウンド：

    • 未ソート部分の最初の要素を取り出します6。

    • 将 6ソート済み部分の5と比較し、6 > 5、直接末尾に挿入します。

    • リストは次のようになります[2, 4, 5, 6, 1, 3]。

    • ソート済み部分：[2, 4, 5, 6]、未ソート部分：[1, 3]。

  5. 第4ラウンド：

    • 未ソート部分の最初の要素を取り出します1。

    • 将 1ソート済み部分の6と比較し、1 < 6、続けて5、4、2と比較し、1が最小なので、先頭に挿入します。

    • リストは次のようになります[1, 2, 4, 5, 6, 3]。

    • ソート済み部分：[1, 2, 4, 5, 6]、未ソート部分：[3]。

  6. 第5ラウンド：

    • 未ソート部分の最初の要素を取り出します3。

    • 将 3ソート済み部分の6と比較し、3 < 6、続けて5、4、2と比較し、3 > 2、挿入先は2と4の間です。

    • リストは次のようになります[1, 2, 3, 4, 5, 6]。

    • ソート済み部分：[1, 2, 3, 4, 5, 6]、未ソート部分は空です。

実例

def insertion_sort(arr):
    n = len(arr)
    for i in range(1, n):
        key = arr[i]  # 未ソート部分の最初の要素を取り出す
        j = i - 1
        # key をソート済み部分の正しい位置に挿入する
        while j >= 0 and key < arr[j]:
            arr[j + 1] = arr[j]  # 要素を後ろに移動する
            j -= 1
        arr[j + 1] = key  # key を挿入する
    return arr

# 例
arr = [5, 2, 4, 6, 1, 3]
sorted_arr = insertion_sort(arr)
print(sorted_arr)  # 出力: [1, 2, 3, 4, 5, 6]

時間計算量

  • 最悪の場合：O(n²)。リストが逆順の場合、毎回の挿入でソート済みの全要素を移動する必要があります。

  • 最良の場合：O(n)。リストがすでに整列している場合、リストを1回走査するだけで済みます。

  • 平均の場合：O(n²)。

空間計算量

  • O(1)。挿入ソートはインプレースソートアルゴリズムであり、追加の記憶領域を必要としません。

長所と短所

  • 長所：

    • 実装が簡単で、コードが理解しやすい。

    • 小規模データやほぼ整列済みのデータに対して効率が高い。

    • インプレースソートであり、追加の記憶領域を必要としない。

    • 安定ソートアルゴリズム（同じ要素の相対のな順序が変わらない）。

  • 短所：

    • 時間計算量が高く、大規模なデータセットには適さない。

適用シーン

  • データ量が少ない、またはほぼ整列済みのシーン。

  • 安定ソートアルゴリズムが必要なシーン。

  • より複雑なソートアルゴリズム（クイックソート、マージソートなど）の補助アルゴリズムとして。

コード実装

JavaScript

実例

function insertionSort(arr) {
    var len = arr.length;
    var preIndex, current;
    for (var i = 1; i < len; i++) {
        preIndex = i - 1;
        current = arr[i];
        while(preIndex >= 0 && arr[preIndex] > current) {
            arr[preIndex+1] = arr[preIndex];
            preIndex--;
        }
        arr[preIndex+1] = current;
    }
    return arr;
}

Java

実例

public class InsertSort implements IArraySort {

    @Override
    public int[] sort(int[] sourceArray) throws Exception {
        // arr をコピーし、パラメータの内容を変更しない
        int[] arr = Arrays.copyOf(sourceArray, sourceArray.length);

        // 添字が1の要素から適切な位置を選択して挿入する。添字が0の要素は1つだけなので、デフォルトで整列済みである
        for (int i = 1; i < arr.length; i++) {

            // 挿入するデータを記録する
            int tmp = arr[i];

            // ソート済みの列の右端から比較を始め、それより小さい数を見つける
            int j = i;
            while (j > 0 && tmp < arr[j - 1]) {
                arr[j] = arr[j - 1];
                j--;
            }

            // それより小さい数が存在する場合、挿入する
            if (j != i) {
                arr[j] = tmp;
            }

        }
        return arr;
    }
}

C#

実例

public static void InsertSort(int[] array)
{
    for(int i = 1;i < array.length;i++)
    {
        int temp = array[i];
        for(int j = i - 1;j >= 0;j--)
        {
            if(array[j] > temp)
            {
                array[j + 1] = array[j];
                array[j] = temp;
            }
            else
                break;
        }
    }
}
