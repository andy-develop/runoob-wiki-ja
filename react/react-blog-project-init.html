React ブログプロジェクト

この章では、ゼロから Vite を使って React ブログプロジェクトを作成し、JSX 構文とプロジェクト構造を理解します。

環境準備

始める前に、コンピューターに Node.js（v16 以上推奨）がインストールされていることを確認してください。

Node.js は JavaScript の実行環境であり、npm はその標準パッケージマネージャーです。

Node.js がインストールされているか確認

$ node -v
v20.10.0

バージョン番号が表示されれば、インストールされています。

ない場合は、次の場所へ移動してください：nodejs.orgLTS バージョンをダウンロードしてインストールします。

React プロジェクトを作成

Vite は現在最も高速なフロントエンドビルドツールの一つで、React をネイティブにサポートしています。

ターミナルでプロジェクトを保存したいディレクトリに移動し、次を実行します：

$ npm create vite@latest blog-app -- --template react

このコマンドは Vite に、blog-app という名前のプロジェクトを React テンプレートで作成するよう指示します。

プロジェクトディレクトリに移動し、依存関係をインストールして開発サーバーを起動します：

$ cd blog-app
$ npm install
$ npm run dev

ブラウザが自動的に http://localhost:5173 を開き、Vite + React のデフォルトのウェルカムページが表示されれば、プロジェクトの起動は成功です。

起動時に依存関係が不足しているというエラーが表示された場合は、次を実行してみてください：npm installその後、再実行します。

プロジェクトディレクトリ構造の詳細

blog-app フォルダーを開くと、以下の構造が表示されます：

blog-app/
├── index.html              # 入口 HTML 文件
├── package.json            # 项目配置与依赖列表
├── vite.config.js          # Vite 构建工具配置
├── public/                 # 不经过编译的静态资源
├── src/
│   ├── main.jsx            # JS 入口，将 React 组件挂载到 DOM
│   ├── App.jsx             # 根组件，所有页面的外壳
│   ├── App.css             # App 组件的样式
│   ├── index.css           # 全局样式
│   └── assets/             # 需要编译的静态资源（图片等）

主要ファイルの役割

index.html— ブラウザがアクセスするエントリーファイル。

その中には<div id="root"></div>、React アプリはこの div にマウントされます。

src/main.jsx— React アプリの起動ファイル。

それは#root要素を見つけて、次にcreateRootを<App />コンポーネントをレンダリングします。

実例

// ファイルパス：src/main.jsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App.jsx'
import './index.css'

// HTML 内の <div id="root"></div> を見つける
// createRoot で React ルートノードを作成し、<App /> をレンダリングする
ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
)

src/App.jsx— ルートコンポーネント。

これはすべてのページの最外層コンテナであり、返された JSX がページにレンダリングされます。

<React.StrictMode>StrictMode StrictMode は React の StrictMode で、開発環境でのみ有効です。コンポーネントに対して追加のチェック（例：重複レンダリング）を行い、潜在的な問題を発見するのに役立ちます。本番ビルドでは自動的に無視されます。

JSX とは？

JSXは JavaScript の構文拡張であり、JS 内で HTML に似たコードを書くことができます。

React コンポーネントは本質的には JSX を返す関数です。

JSX と HTML の主な違い

シナリオHTMLJSX
class 属性class="container"className="container"
自己終了タグ<img src="....html"><img src="....html" />
JS 式の埋め込みサポートしない<h1>{title}</h1>
style 属性style="color: red"style={{ color: 'red' }}
コメント<!-- コメント -->{/* コメント */}
イベントバインドonclick="fn()"onClick={fn}

なぜ使うのかclassNameではなくclass？なぜなら JSX は本質的に JavaScript であり、一方classは JS の予約語です。同様に、forは ... に変更します。htmlFor。

実例

// JSX は return の後のこの HTML 風のコードです
function Greeting() {
  const name = 'RUNOOB'
  const isLoggedIn = true

  return (
    <div className="greeting">
      {/* JSX コメント：波括弧内には任意の JS 式を置ける */}
      <h1>Hello, {name}!</h1>
      <p>現在時刻：{new Date().toLocaleDateString()}</p>
      {isLoggedIn && <p>おかえりなさい！</p>}
    </div>
  )
}

核心ルールを覚えてください：JSX の波括弧内には任意の JS 式を置けます——変数、関数呼び出し、三項演算、配列の map なども可能です。

React コンポーネント = 関数

React 関数コンポーネントの本質は：props を引数として受け取り、JSX を返す関数です。

実例

// コンポーネントを定義：JSX を返す関数
// コンポーネント名は大文字で始める必要があります
function BlogHeader() {
  return (
    <header>
      <h1>RUNOOB Blog</h1>
    </header>
  )
}

// コンポーネントの使用：HTML タグのように書き、自己終了またはペアのどちらでも可
function App() {
  return (
    <div>
      <BlogHeader />
      <main>
        <p>ブログの内容はここに表示されます</p>
      </main>
    </div>
  )
}

export default App

コンポーネント名は必ず大文字で始める必要があります。小文字で始まると React は通常の HTML タグ（div、span など）と見なし、大文字で始まるとカスタムコンポーネントとして処理します。

実践：テンプレートを空にしてブログの骨組みを書く

デフォルトで生成された App.jsx と App.css の内容を消して、ブログの基本構造に置き換えます。

実例

// ファイルパス：src/App.jsx
import './App.css'

function App() {
  return (
    <div className="app">
      {/* 上部ナビゲーションバー */}
      <header className="navbar">
        <h1 className="logo">RUNOOB Blog</h1>
        <nav>
          <a href="/">ホーム</a>
          <a href="#">について</a>
        </nav>
      </header>

      {/* メインコンテンツ領域 */}
      <main className="container">
        <p>ブログの内容はここに表示されます</p>
      </main>

      {/* フッター */}
      <footer className="footer">
        <p>© 2024 RUNOOB Blog. Powered by React.</p>
      </footer>
    </div>
  )
}

export default App

保存すると、ブラウザは自動的にリフレッシュされ、上部ナビゲーションバー + 中央コンテンツ領域 + 下部フッターというクリーンなブログの骨組みが表示されます。

本章のまとめ

この章では、3つのことを達成しました：Vite で React プロジェクトを作成し、JSX と HTML の主な違いを理解し、ブログの基本 JSX 骨組みを書きました。

核心的な収穫：React コンポーネントは JSX を返す関数であり、JSX の波括弧内には任意の JS 式を埋め込めます。
