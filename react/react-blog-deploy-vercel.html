ビルドして公開 — Vercel にデプロイ

この章では、ローカルで開発したブログプロジェクトをビルドし、無料でインターネットにデプロイして、公開アクセスリンクを取得する方法を学びます。

プロダクションビルドを作成

開発時はnpm run dev、Vite がローカルで開発サーバーを起動し、ホットリロードをサポートします。

デプロイ時に必要なのは最適化・圧縮されたプロダクションビルドです。

$ npm run build

実行すると、プロジェクトのルートディレクトリにdist/フォルダが生成されます：

dist/
├── index.html                # 入口 HTML
├── assets/
│   ├── index-Df3aBc9x.js    # 打包压缩后的 JS
│   ├── index-Gh7jKl2m.css   # 提取并压缩后的 CSS
│   └── ...
├── posts.json                # public 目录文件原样复制
└── favicon.svg               # 静态资源

主な変更点：

  • ファイル名に hash が付く（内容が変われば hash も変わり、ブラウザのキャッシュ制御に使用）
  • コードは圧縮され、Tree-shaking（未使用コードの除去）が行われます
  • public/ ディレクトリの内容はそのままルートディレクトリにコピーされる

ビルド結果のプレビュー：実行npx vite preview、ローカルでプロダクションモードのサーバーを起動し、本番環境をシミュレートします。

プロジェクトを GitHub にプッシュ

ステップ1：GitHub リポジトリを作成

GitHub で + → New repository をクリックし、以下を入力します：

  • Repository name：react-blog-app
  • Public に設定（無料デプロイ）
  • Initialize with README にはチェックを入れない

ステップ2：Git を初期化してプッシュ

$ cd blog-app
$ git init
$ git add .
$ git commit -m "初始化 React 博客项目"
$ git branch -M main
$ git remote add origin https://github.com/你的用户名/react-blog-app.git
$ git push -u origin main

プッシュ前に.gitignore含まれていることを確認。node_modulesとdistnode_modules はアップロードすべきではありません（npm install で復元可能）、dist はビルドプラットフォームが自動生成します。

Vercel デプロイ

Vercelは現在最も人気のあるフロントエンドデプロイプラットフォームで、React/Vite プロジェクトをゼロ設定でサポートします。

デプロイ手順

  1. アクセスvercel.com、GitHub アカウントでログイン
  2. "New Project" をクリック → Import Git Repository → react-blog-app を選択
  3. Vercel が Vite + React を自動認識し、設定が自動入力されます
  4. "Deploy" をクリックし、数十秒待ちます
  5. デプロイが成功すると、次のようなリンクが取得できます：https://react-blog-app.vercel.app
設定項目值説明
Framework PresetVite自動検出
Build Commandnpm run build自動検出
Output Directorydist自動検出

自動デプロイ

以降、毎回git push、Vercel が自動で：コードを取得 → npm install → npm run build → デプロイ公開。

プロセス全体が完全自動で、プッシュすればすぐに公開されます。

カスタムドメイン（オプション）

  1. Vercel プロジェクトの Dashboard → Settings → Domains
  2. 自分のドメインを入力（例：blog.example.com）
  3. DNS プロバイダーで CNAME レコードを追加し、次をポイントしますcname.vercel-dns.com
  4. DNS の反映を待つと、Vercel が自動的に SSL 証明書を申請します
