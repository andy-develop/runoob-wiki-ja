useEffect 上級 — リアルタイム検索

この章では、useEffect の依存関係変化のメカニズムを詳しく学び、検索ボックスのリアルタイムフィルタリングとデバウンス最適化を実装します。

useEffect 依存関係の変化によるトリガー

useEffect の依存配列内の値が変化すると、React は effect を再実行します。

例

import { useState, useEffect } from 'react'

function SearchDemo() {
  const [keyword, setKeyword] = useState('')
  const [results, setResults] = useState([])

  // keyword が変化するたびに、フィルタリングを再実行
  useEffect(() => {
    console.log('keyword が変化：', keyword)
    // ここで検索ロジックを実行できる
    setResults(/* フィルタリング結果 */)
  }, [keyword])  // keyword に依存

  return (
    <div>
      <input
        value={keyword}
        onChange={e => setKeyword(e.target.value)}
        placeholder="検索..."
      />
      <p>現在の検索：{keyword}</p>
    </div>
  )
}

このパターンは、特定の state を監視し、その変化時に自動的に対応する操作を実行するのに適しています。

イベント内での処理 vs useEffect

検索フィルタリングには2つの実装方法があります：

方法記述方法適用シーン
イベントハンドラ関数onChange 内で直接フィルタリングロジックが単純で、1箇所でのみトリガーされる
useEffect での応答useEffect が keyword に依存複数のデータソースがフィルタリング結果に影響を与える可能性がある

ブログのシナリオでは、検索ボックス入力のフィルタリングロジックは非常に単純なので、イベントハンドラ関数または useMemo に直接置く方が適切です。

useEffect は、外部システムと同期する必要があるシーン（API 呼び出し、localStorage への保存など）に適しています。

デバウンス最適化

キーを押すたびに検索がトリガーされる場合（ローカルフィルタリングならまだしも、ネットワークリクエストを送信する場合は）、大量の無駄が発生します。

デバウンス（Debounce）の考え方：ユーザーが一定時間入力を停止した後に、操作を実行します。

例

import { useState, useEffect } from 'react'

function useDebounce(value, delay = 300) {
  const [debouncedValue, setDebouncedValue] = useState(value)

  useEffect(() => {
    // タイマーを設定：delay ms 後に debouncedValue を更新
    const timer = setTimeout(() => {
      setDebouncedValue(value)
    }, delay)

    // クリーンアップ関数：value が delay 以内に再び変更された場合、前のタイマーをクリア
    return () => clearTimeout(timer)
  }, [value, delay])

  return debouncedValue
}

// デバウンスを使用
function SearchInput() {
  const [keyword, setKeyword] = useState('')
  const debouncedKeyword = useDebounce(keyword, 300)

  // デバウンス後の値が変化したときのみ実行（リクエスト送信など）
  useEffect(() => {
    if (debouncedKeyword) {
      console.log('実際に検索を実行：', debouncedKeyword)
      // fetch(`/api/search?q=${debouncedKeyword}`)
    }
  }, [debouncedKeyword])

  return (
    <input
      value={keyword}
      onChange={e => setKeyword(e.target.value)}
      placeholder="検索..."
    />
  )
}

デバウンスの原理：入力のたびに 300ms のタイマーをリセットし、300ms 以内に新しい入力がなかった場合のみタイマーが実行され、debouncedKeyword が更新されます。これにより、ユーザーが速く入力しても検索が頻繁にトリガーされません。

実践：ブログにリアルタイム検索を追加する

例

// ファイルパス：src/pages/HomePage.jsx
import { useState, useEffect, useMemo } from 'react'
import BlogCard from '../components/BlogCard'
import CategoryFilter from '../components/CategoryFilter'

function HomePage() {
  const [articles, setArticles] = useState([])
  const [isLoading, setIsLoading] = useState(true)
  const [error, setError] = useState(null)
  const [activeCategory, setActiveCategory] = useState('すべて')
  const [keyword, setKeyword] = useState('')   // 検索キーワード

  // データをロード
  useEffect(() => {
    let cancelled = false
    async function fetchPosts() {
      setIsLoading(true)
      try {
        const res = await fetch('/posts.json')
        const data = await res.json()
        if (!cancelled) setArticles(data)
      } catch (err) {
        if (!cancelled) setError(err.message)
      } finally {
        if (!cancelled) setIsLoading(false)
      }
    }
    fetchPosts()
    return () => { cancelled = true }
  }, [])

  const categories = useMemo(() => {
    return ['すべて', ...new Set(articles.map(a => a.category))]
  }, [articles])

  // フィルタリング + 検索：カテゴリとキーワードの両方でフィルタリング
  const filteredArticles = useMemo(() => {
    let result = articles

    // まずカテゴリでフィルタリング
    if (activeCategory !== 'すべて') {
      result = result.filter(a => a.category === activeCategory)
    }

    // 次にキーワードでフィルタリング
    if (keyword.trim()) {
      const kw = keyword.trim().toLowerCase()
      result = result.filter(a =>
        a.title.toLowerCase().includes(kw) ||
        a.summary.toLowerCase().includes(kw)
      )
    }

    return result
  }, [articles, activeCategory, keyword])

  return (
    <div>
      <h2 className="section-title">最新記事</h2>

      {/* 検索ボックス */}
      <div className="search-bar">
        <input
          type="text"
          value={keyword}
          onChange={e => setKeyword(e.target.value)}
          placeholder="記事のタイトルまたは要約を検索..."
          className="search-input"
        />
        {keyword && (
          <span className="clear-btn" onClick={() => setKeyword('')}>✕</span>
        )}
      </div>

      {isLoading && <p className="status-msg">読み込み中...</p>}

      {error && (
        <div className="status-msg error">
          <p>読み込み失敗：{error}</p>
          <button onClick={() => window.location.reload()}>再試行</button>
        </div>
      )}

      {!isLoading && !error && (
        <>
          <CategoryFilter
            categories={categories}
            activeCategory={activeCategory}
            onCategoryChange={setActiveCategory}
          />
          <p className="result-info">
            共 {filteredArticles.length} 篇
            {keyword &&`、検索「${keyword}」`}
          </p>
          {filteredArticles.length === 0 ? (
            <p className="empty-tip">一致する記事が見つかりません</p>
          ) : (
            <div className="article-grid">
              {filteredArticles.map(article => (
                <BlogCard key={article.id} {...article} />
              ))}
            </div>
          )}
        </>
      )}
    </div>
  )
}

export default HomePage

検索とカテゴリフィルタリングは同時に機能します——キーワードを入力した後、カテゴリボタンをクリックすると、2つの条件が重なってフィルタリングされます。

本章のまとめ

この章では、useEffect の依存関係変化のメカニズムを深く学びました：依存配列内の値が変化すると effect が再実行されること、デバウンスの原理と実装（setTimeout + cleanup）、そして useEffect vs イベントハンドラ関数の使い分けの境界線です。

検索ボックスのリアルタイムフィルタリングはスムーズな体験です——これが宣言的プログラミングの価値です：filteredArticles の計算ルールを宣言すると、React が依存関係の変化時に自動的に再計算します。
