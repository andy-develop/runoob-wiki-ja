React AJAX

React アプリケーションで AJAX リクエストを実装するには、通常 fetch API または axios、jquery などのサードパーティライブラリを使用してネットワークリクエストを行うことができます。

以下はこれら 2 つの方法の基本的な説明です：

fetch API を使用した AJAX リクエスト

fetchはブラウザに組み込まれている API であり、ネットワークリクエストを開始するために使用されます。以下はfetchReact コンポーネントで AJAX リクエストを開始するための基本的な手順：

  • fetch をインポートする- モダンブラウザを使用している場合は、通常インポートする必要はありませんfetch。ただし、古いブラウザをサポートする必要がある場合は、unfetchこのような polyfill を使用できます。

  • useEffect フックを使用する- 利用useEffectフックを使用して副作用（ネットワークリクエストなど）を処理します。

  • リクエストを開始する- 使用してfetchGET または POST リクエストを開始します。

  • レスポンスを処理する- 使用して.then()レスポンスデータを処理します。

  • エラー処理- 使用して.catch()エラーをキャッチして処理します。

  • 状態を更新する- 使用してuseStateフックを使用してリクエストデータを保存し、リクエスト成功後に状態を更新します。

例

import React, { useState, useEffect } from 'react';

const MyComponent = () => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch('https://api.example.com/data');
        const result = await response.json();
        setData(result);
        setLoading(false);
      } catch (error) {
        console.error('Error fetching data:', error);
      }
    };

    fetchData();
  }, []);

  if (loading) {
    return <div>Loading...</div>;
  }

  return (
    <div>
      <h1>Data from API:</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
};

export default MyComponent;

説明：

  • useState と useEffect：使用してuseStateAJAX リクエストが返すデータを保存する (data) とロード状態 (loading)、またuseEffectコンポーネントの読み込み後に AJAX リクエストを実行します。

  • fetch：使用してfetchGET リクエストを開始し、使用してresponse.json()返された JSON データを JavaScript オブジェクトに解析します。

  • 非同期処理：使用してasync/await非同期操作を処理し、リクエスト完了後に状態を更新します。

  • エラー処理：fetchリクエスト内でtry/catch発生する可能性のあるエラーをキャッチして処理します。

axios を使用する

axios は Promise ベースの HTTP クライアントであり、ブラウザと Node.js で使用できます。

以下は axios を使用する基本的な手順です：

  1. axios をインストールする- npm または yarn で axios をインストールします。

    npm install axios

  2. axios をインポートする- コンポーネントに axios をインポートします。

  3. リクエストを開始する- axios を使用して GET または POST リクエストを開始します。

  4. レスポンスとエラーを処理する- 使用して.then()と.catch()レスポンスを処理し、エラーをキャッチします。

  5. 状態を更新する- 使用と同様にfetch、使用してuseState状態を更新します。

例

import React, { useState, useEffect } from 'react';
import axios from 'axios';

const MyComponent = () => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await axios.get('https://api.example.com/data');
        setData(response.data);
        setLoading(false);
      } catch (error) {
        console.error('Error fetching data:', error);
      }
    };

    fetchData();
  }, []);

  if (loading) {
    return <div>Loading...</div>;
  }

  return (
    <div>
      <h1>Data from API:</h1>
      <pre>{JSON.stringify(data, null, 2)}</pre>
    </div>
  );
};

export default MyComponent;
