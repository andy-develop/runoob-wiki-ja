カスタムHook — 再利用可能なロジックをカプセル化

この章では、Reactのベストプラクティスを学びます。カスタムHookを使って再利用可能なロジックをカプセル化し、コンポーネントをより簡潔で保守しやすくします。

カスタムHookとは？

機能が増えるにつれて、useState と useEffect がコンポーネント内に散らばり、異なるコンポーネント間で重複するロジックが発生します。

カスタムHook複数のHookの組み合わせロジックを、useで始まる関数に抽出するものです。

その本質：内部でReact Hookを使用する通常のJS関数。

なぜカスタムHookが必要なのか？

カスタムHookがない場合カスタムHookがある場合
各コンポーネントが独自にfetch+フィルタリングロジックを書く1つのusePosts()をあらゆる場所で再利用する
データロジックとUIロジックが混在するデータロジックが独立し、コンポーネントはUIだけに集中する
1つのロジックを変更するのに複数のファイルを変更する必要がある1か所を変更すると、すべてのコンポーネントが同期して更新される
コンポーネントは簡単に200行以上になるコンポーネントは通常80行未満

命名規則とHookのルール

規則説明例
以 use先頭ReactはこれによりHookを認識し、lintルールを適用するusePosts、useDarkMode
hooks/ディレクトリに置く検索と保守が容易になるsrc/hooks/usePosts.js
関数コンポーネントのトップレベルでのみ呼び出せる条件分岐/ループ/ネストされた関数内では呼び出せない—
データまたはメソッドを返す呼び出し側がHook内部の状態とロジックを取得できるようにするreturn { data, isLoading }

Hookの使用規則：1. 関数コンポーネントのトップレベルでのみHookを呼び出す；2. React関数内（関数コンポーネントまたはカスタムHook）でのみHookを呼び出す。これにより、毎回のレンダリングでHookの呼び出し順序が一貫する。

usePosts — 記事データのロジックをカプセル化

例

// ファイルパス：src/hooks/usePosts.js
import { useState, useEffect, useMemo } from 'react'

export function usePosts() {
  const [articles, setArticles] = useState([])
  const [isLoading, setIsLoading] = useState(true)
  const [error, setError] = useState(null)
  const [activeCategory, setActiveCategory] = useState('すべて')
  const [keyword, setKeyword] = useState('')

  // データを読み込む
  useEffect(() => {
    let cancelled = false
    async function fetchPosts() {
      setIsLoading(true)
      setError(null)
      try {
        const res = await fetch('/posts.json')
        if (!res.ok) throw new Error(`HTTP ${res.status}`)
        const data = await res.json()
        if (!cancelled) setArticles(data)
      } catch (err) {
        if (!cancelled) setError(err.message)
      } finally {
        if (!cancelled) setIsLoading(false)
      }
    }
    fetchPosts()
    return () => { cancelled = true }
  }, [])

  // すべてのカテゴリを抽出する
  const categories = useMemo(() => {
    return ['すべて', ...new Set(articles.map(a => a.category))]
  }, [articles])

  // カテゴリ+キーワードでフィルタリング
  const filteredArticles = useMemo(() => {
    let result = articles
    if (activeCategory !== 'すべて') {
      result = result.filter(a => a.category === activeCategory)
    }
    if (keyword.trim()) {
      const kw = keyword.trim().toLowerCase()
      result = result.filter(a =>
        a.title.toLowerCase().includes(kw) ||
        a.summary.toLowerCase().includes(kw)
      )
    }
    return result
  }, [articles, activeCategory, keyword])

  // IDで記事を検索する
  function getArticleById(id) {
    return articles.find(a => a.id === Number(id))
  }

  // 再読み込み
  function refetch() {
    // useEffectをトリガーする別の方法：keyを使うかstateを拡張する
    window.location.reload()
  }

  return {
    articles, isLoading, error,
    activeCategory, setActiveCategory,
    keyword, setKeyword,
    categories,
    filteredArticles,
    getArticleById,
    refetch
  }
}

usePostsを使用するホームページ

例

// ファイルパス：src/pages/HomePage.jsx
import { usePosts } from '../hooks/usePosts'
import BlogCard from '../components/BlogCard'
import CategoryFilter from '../components/CategoryFilter'

function HomePage() {
  // 一行のコードで記事に関連するすべてのデータと操作を取得する
  const {
    isLoading, error,
    activeCategory, setActiveCategory,
    keyword, setKeyword,
    categories,
    filteredArticles,
    refetch
  } = usePosts()

  if (isLoading) return <p className="status-msg">読み込み中...</p>
  if (error) return (
    <div className="status-msg error">
      <p>読み込み失敗：{error}</p>
      <button onClick={refetch}>再試行</button>
    </div>
  )

  return (
    <div>
      <h2 className="section-title">最新記事</h2>

      <div className="search-bar">
        <input
          type="text"
          value={keyword}
          onChange={e => setKeyword(e.target.value)}
          placeholder="記事のタイトルまたは要約を検索..."
          className="search-input"
        />
        {keyword && <span className="clear-btn" onClick={() => setKeyword('')}>✕</span>}
      </div>

      <CategoryFilter
        categories={categories}
        activeCategory={activeCategory}
        onCategoryChange={setActiveCategory}
      />

      <p className="result-info">共 {filteredArticles.length} 篇</p>

      {filteredArticles.length === 0 ? (
        <p className="empty-tip">一致する記事がありません</p>
      ) : (
        <div className="article-grid">
          {filteredArticles.map(article => (
            <BlogCard key={article.id} {...article} />
          ))}
        </div>
      )}
    </div>
  )
}

export default HomePage

usePostsを使用する詳細ページ

例

// ファイルパス：src/pages/PostPage.jsx
import { useParams, Link } from 'react-router-dom'
import { usePosts } from '../hooks/usePosts'

function PostPage() {
  const { id } = useParams()
  const { isLoading, error, getArticleById } = usePosts()
  const article = getArticleById(id)

  if (isLoading) return <p className="status-msg">読み込み中...</p>
  if (error) return <p className="status-msg error">読み込み失敗：{error}</p>

  if (!article) {
    return (
      <div className="not-found">
        <h2>記事が存在しません</h2>
        <Link to="/">ホームページに戻る</Link>
      </div>
    )
  }

  return (
    <article className="post-view">
      <span className="category-tag">{article.category}</span>
      <h1>{article.title}</h1>
      <time>{article.date}</time>
      <div className="content" dangerouslySetInnerHTML={{ __html: article.content }} />
      <Link to="/" className="back-link">← ホームページに戻る</Link>
    </article>
  )
}

export default PostPage

注意：ユーザーが詳細ページのURLに直接アクセスした場合（ページを更新するなど）、usePostsはデータを再取得します。これは正しい動作です。ホームページのusePostsインスタンスと詳細ページのusePostsインスタンスは独立しており、それぞれが独自のuseEffectを呼び出すためです。

useDarkMode — 一行のコードでダークモードを切り替える

例

// ファイルパス：src/hooks/useDarkMode.js
import { useState, useEffect } from 'react'

export function useDarkMode() {
  // localStorageから以前の設定を読み込む
  const [isDark, setIsDark] = useState(() => {
    return localStorage.getItem('blog-theme') === 'dark'
  })

  // isDarkが変化したとき、DOMとlocalStorageに同期する
  useEffect(() => {
    if (isDark) {
      document.documentElement.classList.add('dark')
      localStorage.setItem('blog-theme', 'dark')
    } else {
      document.documentElement.classList.remove('dark')
      localStorage.setItem('blog-theme', 'light')
    }
  }, [isDark])

  function toggleDark() {
    setIsDark(!isDark)
  }

  return { isDark, toggleDark }
}

NavBarでの使用：

例

// ファイルパス：src/components/NavBar.jsx
import { useDarkMode } from '../hooks/useDarkMode'

function NavBar() {
  const { isDark, toggleDark } = useDarkMode()

  return (
    <header className="navbar">
      <a href="/" className="logo">サンプル Blog</a>
      <nav>
        <a href="/">ホーム</a>
        <button className="theme-btn" onClick={toggleDark}>
          {isDark ? '&#x2600; ライト' : '☾ ダーク'}
        </button>
      </nav>
    </header>
  )
}

export default NavBar

ReactカスタムHook vs Vue3 Composable

特性ReactカスタムHookVue3 Composable
命名規則useで始まるuseで始まる
本質React Hookを使用する関数Vue3 APIを使用する関数
リアクティブuseStateが返すsetterによってトリガーされるref/reactiveによって自動追跡される
呼び出し制限関数コンポーネントのトップレベルでのみ<script setup> のトップレベルでのみ
副作用useEffectwatch / watchEffect / onMounted

本章のまとめ

この章では、Reactの最も重要なデザインパターンであるカスタムHookを習得しました。useで始まり、内部で複数のReact Hookを組み合わせ、状態と操作を返します。

usePostsはデータ読み込み+フィルタリング+検索を一元管理し、useDarkModeは一行のコードでダークモードを導入できます。コンポーネントはUIレンダリングだけに集中できます。
