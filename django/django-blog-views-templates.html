ビューとテンプレート — 記事リストのレンダリング

この章では、Django ビューを使ってデータベースからデータを取得し、テンプレートと組み合わせてブログのホームページの記事カードリストをレンダリングする方法を学びます。

ビュー（View）の役割

ビューは Django の中核ロジック層であり、以下を担当します：

  • ユーザーのリクエスト（requestパラメータ）
  • データベースから必要なデータをクエリする
  • データをテンプレートに渡して HTML をレンダリングし、ユーザーに返す

Django ビューには2つの書き方があります：関数ビュー（FBV）とクラスビュー（CBV）。

これまでの8章では FBV を優先的に使用してきました。FBV はより直感的で、初心者がリクエスト処理の流れを理解するのに適しています。

関数ビューの基本

Django のビュー関数は、requestパラメータを受け取り、HttpResponseオブジェクトを返します。

実例

# ファイルパス：blog/views.py
from django.shortcuts import render
from .models import Post

def index(request):
    """ブログホームページ：すべての記事を表示"""
    # データベースからすべての記事をクエリ（時間の降順）
    posts = Post.objects.all().order_by('-created_at')

    # render の3つのパラメータ：
    # 1. request — リクエストオブジェクト
    # 2. テンプレートパス — blog/index.html
    # 3. context 辞書 — テンプレートに渡すデータ
    context = {
        'posts': posts,
        'title': 'RUNOOB ブログ - ホームページ'
    }
    return render(request, 'blog/index.html', context)

render()は Django で最もよく使われるショートカット関数で、テンプレートのロード → データの注入 → HTML の生成 → レスポンスの返却を組み合わせています。

Django テンプレート構文

Django テンプレート構文は Vue3 のテンプレート構文と非常に似ていますが、いくつかの重要な違いがあります。

用途Django テンプレートVue3 テンプレート
変数の出力{{ variable }}{{ variable }}
ループ{% for item in list %}...{% endfor %}v-for="item in list"
条件{% if cond %}...{% endif %}v-if="cond"
URL 生成{% url 'name' %}router-link to="name"
レイアウトの継承{% extends 'base.html' %}コンポーネントのネスト

重要な違い：Django テンプレートは{% %}制御タグを包みます。Vue3 はv-ディレクティブを使用します。サーバーサイドでレンダリングされます。HTML が生成されてからブラウザに送信されます。Vue3 はブラウザサイドでレンダリングされます。ブラウザが JS を受け取った後に HTML を組み立てます。

テンプレート継承：base.html

複数のページで同じナビゲーションバーとフッターを共有するには、テンプレート継承を使って重複を避けます。

親テンプレートは「ブロック（block）」を定義し、子テンプレートが具体的な内容を埋め込みます。

base.html 親テンプレートを作成

実例

<!-- ファイルパス：blog/templates/blog/base.html -->

        * { margin: 0; padding: 0; box-sizing: border-box; }

            padding: 16px 40px; background: #fff;

        }
        .navbar .logo { font-size: 22px; font-weight: bold; color: #2c3e50; text-decoration: none; }
        .navbar a { margin-left: 20px; text-decoration: none; color: #333; }

index.html 子テンプレートを作成

実例

<!-- ファイルパス：blog/templates/blog/index.html -->
<!-- extends は必ず先頭に置く必要があります -->
{% extends 'blog/base.html' %}

{% block title %}{{ title }}{% endblock %}

{% block content %}
<h2 class="section-title">最新の記事</h2>

{% if posts %}
    <div class="article-grid">
        {% for post in posts %}
        <div class="article-card">
            <div class="card-content">
                <span class="card-category">{{ post.category.name }}</span>
                <h3>{{ post.title }}</h3>
                <p>{{ post.summary|truncatechars:80 }}</p>
                <span class="card-date">{{ post.created_at|date:"Y-m-d" }}</span>
            </div>
        </div>
        {% endfor %}
    </div>
{% else %}
    <p class="empty-tip">まだ記事がありません。お楽しみに。</p>
{% endif %}
{% endblock %}

テンプレートで使ったいくつかの知識ポイント：

構文意味
{% extends 'blog/base.html' %}親テンプレートを継承。必ず最初の行に書く
{% block content %}...{% endblock %}親テンプレートで定義された content ブロックを埋め込む
{{ post.category.name }}外部キーを介して関連オブジェクトの属性にアクセス
{{ post.summary|truncatechars:80 }}フィルター：先頭80文字を切り出す
{{ post.created_at|date:"Y-m-d" }}フィルター：日付をフォーマット

Django テンプレートのフィルターはパイプ記号|で表し、変数の後に続けて出力をフォーマットします。よく使われるフィルター：date、truncatechars、length、default。

実践：ホームページの効果を確認

以下の点が完了していることを確認してください：

  • models.py で Post と Category モデルを定義し、migrate 済みである
  • Admin バックエンドに少なくとも3〜5件の記事（異なるカテゴリに属する）が登録されている
  • views.py の index 関数がデータベースから記事をクエリしてテンプレートに渡す
  • urls.py で / ルートが index ビューを指している

サーバーを起動してホームページにアクセスすると、データベースのデータから動的にレンダリングされた記事カードリストが表示されるはずです。

本章のまとめ

この章では、Django ビューとテンプレートの核となる連携を習得しました：views.py がデータベースからデータをクエリして context に渡す、render() がテンプレートをレンダリングする、base.html 親テンプレートがレイアウト + block を定義する、子テンプレートが extends で継承して内容を埋め込む、Django テンプレート構文（{{ }}、{% %}、フィルター）。

これでブログのホームページはデータベース駆動になり、ハードコーディングではなくなりました。
