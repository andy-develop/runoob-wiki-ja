Django Nginx+uwsgi インストール設定

前の章では、使用していたのはpython manage.py runserverサーバーを実行するためです。これはテスト環境でのみ使用できます。

正式にリリースするサービスには、安定して継続的に動作するサーバーが必要です。例えば apache、Nginx、lighttpd などです。この記事では Nginx を例にします。

直接参照することもできます：Python uwsgi インストール設定

基本開発パッケージのインストール

CentOS でのインストール手順は次のとおりです：

yum groupinstall "Development tools"
yum install zlib-devel bzip2-devel pcre-devel openssl-devel ncurses-devel sqlite-devel readline-devel tk-devel

CentOS には Python 2.4.3 が付属していますが、Python 2.7.5 を追加でインストールすることもできます：

cd ~
wget http://python.org/ftp/python/2.7.5/Python-2.7.5.tar.bz2
tar xvf Python-2.7.5.tar.bz2
cd Python-2.7.5
./configure --prefix=/usr/local
make && make altinstall

Python パッケージ管理のインストール

easy_install パッケージhttps://pypi.python.org/pypi/distribute

インストール手順：

cd ~
wget https://pypi.python.org/packages/source/d/distribute/distribute-0.6.49.tar.gz
tar xf distribute-0.6.49.tar.gz
cd distribute-0.6.49
python2.7 setup.py install
easy_install --version

pip パッケージ：https://pypi.python.org/pypi/pip

pip をインストールする利点は、pip list や pip uninstall を使用して Python パッケージを管理できることです。easy_install にはこの機能がなく、uninstall しかありません。

uwsgi のインストール

uwsgi:https://pypi.python.org/pypi/uWSGI

uwsgi パラメータの詳細：http://uwsgi-docs.readthedocs.org/en/latest/Options.html

pip install uwsgi
uwsgi --version    # 查看 uwsgi 版本

uwsgi が正常かどうかをテスト：

新しい test.py ファイルを作成し、内容は次のとおりです：

def application(env, start_response):
    start_response('200 OK', [('Content-Type','text/html')])
    return "Hello World"

その後、ターミナルで実行します：

uwsgi --http :8001 --wsgi-file test.py

ブラウザで http://127.0.0.1:8001 にアクセスし、"Hello World" と出力されるか確認してください。出力されない場合は、インストール手順を確認してください。

Django のインストール

pip install django

django が正常かどうかをテストするには、次を実行します：

django-admin.py startproject demosite
cd demosite
python2.7 manage.py runserver 0.0.0.0:8002

ブラウザで http://127.0.0.1:8002 にアクセスし、django が正常に動作するか確認してください。

Nginx のインストール

インストールコマンドは次のとおりです：

cd ~
wget http://nginx.org/download/nginx-1.5.6.tar.gz
tar xf nginx-1.5.6.tar.gz
cd nginx-1.5.6
./configure --prefix=/usr/local/nginx-1.5.6 \
--with-http_stub_status_module \
--with-http_gzip_static_module
make && make install

読むこともできます：Nginx インストール設定詳細を確認できます。

uwsgi 設定

uwsgi は ini、xml など複数の設定方式をサポートしています。この記事では ini を例とします。/etc/ ディレクトリに uwsgi9090.ini を作成し、次の設定を追加します：

[uwsgi]
socket = 127.0.0.1:9090
master = true         //主进程
vhost = true          //多站模式
no-site = true        //多站模式时不设置入口模块和文件
workers = 2           //子进程数
reload-mercy = 10     
vacuum = true         //退出、重启时清理文件
max-requests = 1000   
limit-as = 512
buffer-size = 30000
pidfile = /var/run/uwsgi9090.pid    //pid文件，用于下面的脚本启动、停止该进程
daemonize = /website/uwsgi9090.log

Nginx 設定

nginx のインストールディレクトリ（例：/usr/local/nginx/）を見つけ、conf/nginx.conf ファイルを開き、server 設定を修正します：

server {
        listen       80;
        server_name  localhost;
        
        location / {            
            include  uwsgi_params;
            uwsgi_pass  127.0.0.1:9090;              //必须和uwsgi中的设置一致
            uwsgi_param UWSGI_SCRIPT demosite.wsgi;  //入口文件，即wsgi.py相对于项目根目录的位置，“.”相当于一层目录
            uwsgi_param UWSGI_CHDIR /demosite;       //项目根目录
            index  index.html index.htm;
            client_max_body_size 35m;
        }
    }

読むこともできます：Nginx インストール設定詳細を確認できます。

設定が完了したら、ターミナルで実行します：

uwsgi --ini /etc/uwsgi9090.ini &
/usr/local/nginx/sbin/nginx
