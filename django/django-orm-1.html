この章を読む前に、まず読んでおく必要がありますDjango モデル基本設定を行い、よくある問題の解決策を理解します。

次に、プロジェクト app01 を再作成します（以前に作成済みの場合は、以下の操作は無視してください）:

django-admin.py startproject app01

次に、settings.py で INSTALLED_APPS の項目を次のように見つけます：

INSTALLED_APPS = (
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'app01',               # 添加此项
)

次に、Django に pymysql モジュールを使用して mysql データベースに接続するよう指示します：

例

# settings.py と同じディレクトリにある __init__.py でモジュールをインポートし、設定を行います
import pymysql
pymysql.install_as_MySQLdb()

モデルの作成

プロジェクトの models.py に以下のクラスを追加します：

app01/models.py

class Book(models.Model):
    id = models.AutoField(primary_key=True) # id は自動的に作成されます。手動で書き込むこともできます
    title = models.CharField(max_length=32) # 書籍名
    price = models.DecimalField(max_digits=5, decimal_places=2) # 書籍価格
    publish = models.CharField(max_length=32) # 出版社名
    pub_date = models.DateField() # 出版日時

次にコマンドラインで以下のコマンドを実行します：

$ python3 manage.py migrate   # 创建表结构

$ python3 manage.py makemigrations app01  # 让 Django 知道我们在我们的模型有一些变更
$ python3 manage.py migrate app01   # 创建表结构

よくあるエラーメッセージ

上記のコマンドを実行すると、次のようなエラーメッセージが表示される場合があります：

原因は、MySQLclient が現在 Python3.4 までしかサポートしていないためです。より高いバージョンの Python を使用している場合は、次のように修正する必要があります：

エラーメッセージのファイルパスから ...site-packages\Django-2.0-py3.6.egg\django\db\backends\mysql パス内の base.py ファイルを見つけ、この2行のコードをコメントアウトします（コードはファイルの先頭部分にあります）：

if version < (1, 3, 13):
    raise ImproperlyConfigured('mysqlclient 1.3.13 or newer is required; you have %s.' % Database.__version__)

通常、エラーメッセージのコードファイルパス情報をクリックすると、エラーファイルの該当行に自動的にジャンプします。そのとき、エラーが発生したコード行をコメントアウトします。

データベースへの追加

ルール設定：

app01/urls.py: ファイルコード：

from django.contrib import admin from django.urls import path from . import views urlpatterns = [ path('add_book/', views.add_book), ]

方法1：モデルクラスのインスタンス化オブジェクト

app ディレクトリから models.py ファイルをインポートする必要があります：

from app 目录 import models

また、インスタンス化した後は、次を実行する必要があります：オブジェクト.save()これでデータベースへの追加が成功します。

app01/views.py: ファイルコード：

from django.shortcuts import render,HttpResponse from app01 import models def add_book(request): book = models.Book(title="菜鸟教程",price=300,publish="菜鸟出版社",pub_date="2008-8-8") book.save() return HttpResponse("<p>データの追加に成功しました！</p>")

方法2：ORM が提供する objects の create メソッドを使用して実装します（推奨）

app01/views.py: ファイルコード：

from django.shortcuts import render,HttpResponse from app01 import models def add_book(request): books = models.Book.objects.create(title="如来神掌",price=200,publish="功夫出版社",pub_date="2010-10-10") print(books, type(books)) # Book object (18) return HttpResponse("<p>データの追加に成功しました！</p>")

検索

使用all()メソッドを使用してすべての内容を照会します。

返されるのは QuerySet 型データで、list に似ており、その中にはモデルクラスのオブジェクトが一つずつ入っています。インデックスを使用してモデルクラスのオブジェクトを取り出すことができます。

app01/views.py: ファイルコード：

from django.shortcuts import render,HttpResponse from app01 import models def add_book(request): books = models.Book.objects.all() print(books,type(books)) # QuerySet型、listに類似。url を訪問するとデータがコマンドラインウィンドウに表示されます。 return HttpResponse("<p>検索に成功しました！</p>")

filter()メソッドは、条件に一致するデータを照会するために使用します。

返されるのは QuerySet 型データで、list に似ており、その中には条件を満たすモデルクラスのオブジェクトが入っています。インデックスを使用してモデルクラスのオブジェクトを取り出すことができます。

pk=3 は主キー primary key=3 を意味し、id=3 に相当します。

id は pycharm では特別な意味を持ち、メモリのアドレスを見る組み込み関数 id() であるため、pk を使用します。

app01/views.py: ファイルコード：

from django.shortcuts import render,HttpResponse from app01 import models def add_book(request): books = models.Book.objects.filter(pk=5) print(books) print("//////////////////////////////////////") books = models.Book.objects.filter(publish='菜鸟出版社', price=300) print(books, type(books)) # QuerySet型、listに類似。 return HttpResponse("<p>検索に成功しました！</p>")

exclude() メソッドは、条件に一致しないデータを照会するために使用します。

返されるのは QuerySet 型データで、list に似ており、その中には条件を満たさないモデルクラスのオブジェクトが入っています。インデックスを使用してモデルクラスのオブジェクトを取り出すことができます。

app01/views.py: ファイルコード：

from django.shortcuts import render,HttpResponse from app01 import models def add_book(request): books = models.Book.objects.exclude(pk=5) print(books) print("//////////////////////////////////////") books = models.Book.objects.exclude(publish='菜鸟出版社', price=300) print(books, type(books)) # QuerySet型、listに類似。 return HttpResponse("<p>検索に成功しました！</p>")

get()メソッドは、条件に一致するモデルクラスのオブジェクトを返すために使用します。条件に一致するオブジェクトは1つだけである必要があります。条件に一致するオブジェクトが複数ある場合や、1つもない場合はエラーが発生します。

app01/views.py: ファイルコード：

from django.shortcuts import render,HttpResponse from app01 import models def add_book(request): books = models.Book.objects.get(pk=5) books = models.Book.objects.get(pk=18) # エラー：条件に一致するオブジェクトがありません books = models.Book.objects.get(price=200) # エラー：条件に一致するオブジェクトが複数あります print(books, type(books)) # モデルクラスのオブジェクト return HttpResponse("<p>検索に成功しました！</p>")

order_by()メソッドは、照会結果を並べ替えるために使用します。

返されるのは QuerySet 型データで、list に似ており、その中には並べ替え後のモデルクラスのオブジェクトが入っています。インデックスを使用してモデルクラスのオブジェクトを取り出すことができます。

注意：

  • a、パラメータのフィールド名は引用符で囲みます。
  • b、降順はフィールドの前にマイナス記号を付けます。-。

app01/views.py: ファイルコード：

from django.shortcuts import render,HttpResponse from app01 import models def add_book(request): books = models.Book.objects.order_by("price") # すべてを照会し、価格の昇順で並べる books = models.Book.objects.order_by("-price") # すべてを照会し、価格の降順で並べる return HttpResponse("<p>検索に成功しました！</p>")

reverse()メソッドは、照会結果を反転するために使用します。

返されるのは QuerySet 型データで、list に似ており、その中には反転後のモデルクラスのオブジェクトが入っています。インデックスを使用してモデルクラスのオブジェクトを取り出すことができます。

app01/views.py: ファイルコード：

from django.shortcuts import render,HttpResponse from app01 import models def add_book(request): # 価格の昇順で並べ替え：降順にしてから反転 books = models.Book.objects.order_by("-price").reverse() return HttpResponse("<p>検索に成功しました！</p>")

count() メソッドはデータの件数を照会するために使用します。返されるデータは整数です。

app01/views.py: ファイルコード：

from django.shortcuts import render,HttpResponse from app01 import models def add_book(request): books = models.Book.objects.count() # すべてのデータの件数を照会 books = models.Book.objects.filter(price=200).count() # 条件に一致するデータの件数を照会 return HttpResponse("<p>検索に成功しました！</p>")

first()メソッドは最初のデータを返します。返されるデータはモデルクラスのオブジェクトで、インデックスを使用することもできます。[0]。

app01/views.py: ファイルコード：

from django.shortcuts import render,HttpResponse from app01 import models def add_book(request): books = models.Book.objects.first() # すべてのデータの最初のデータを返す return HttpResponse("<p>検索に成功しました！</p>")

last() メソッドは最後のデータを返します。返されるデータはモデルクラスのオブジェクトで、インデックスは使用できません。[-1]ORM には逆順インデックスがありません。

app01/views.py: ファイルコード：

from django.shortcuts import render,HttpResponse from app01 import models def add_book(request): books = models.Book.objects.last() # すべてのデータの最後のデータを返す return HttpResponse("<p>検索に成功しました！</p>")

exists()メソッドは、照会結果の QuerySet リスト内にデータがあるかどうかを判定するために使用します。

返されるデータ型はブール型で、あれば true、なければ false です。

注意：判定できるデータ型は QuerySet 型データのみで、整数型やモデルクラスのオブジェクトは使用できません。

例

from django.shortcuts import render,HttpResponse
from app01 import models
def add_book(request):
    books = models.Book.objects.exists()
    # エラー：判定できるデータ型は QuerySet 型データのみで、整数型は使用できません
    books = models.Book.objects.count().exists()
    # エラーになります。判定するデータ型は QuerySet 型データのみで、モデルクラスのオブジェクトは指定できません。
    books = models.Book.objects.first().exists()  
    return HttpResponse("<p>検索に成功しました！</p>")

values()メソッドは一部のフィールドのデータを照会するために使用します。

返り値は QuerySet 型データで、list に似ています。中身はモデルクラスのオブジェクトではなく、反復可能な辞書のシーケンスです。辞書のキーはフィールド、値はデータです。

注意：

  • パラメータのフィールド名は引用符で囲む必要があります。
  • フィールド名とデータを取得したい場合に使用します。values

  • 例

    from django.shortcuts import render,HttpResponse
    from app01 import models
    def add_book(request):
        # すべてのidフィールドとpriceフィールドのデータを照会します
        books = models.Book.objects.values("pk","price")
        print(books[0]["price"],type(books)) # 取得するのは最初のレコードのpriceフィールドのデータです
        return HttpResponse("<p>検索に成功しました！</p>")

    values_list()メソッドは一部のフィールドのデータを照会するために使用します。

    返り値は QuerySet 型データで、list に似ています。中身はモデルクラスのオブジェクトではなく、タプル（tuple）の集まりで、タプルには照会したフィールドに対応するデータが格納されます。

    注意：

    • パラメータのフィールド名は引用符で囲む必要があります。
    • データだけが必要な場合は values_list を使用します。

    例


    from django.shortcuts import render,HttpResponse
    from app01 import models
    def add_book(request):
        # すべてのpriceフィールドとpublishフィールドのデータを照会します
        books = models.Book.objects.values_list("price","publish")
        print(books)
        print(books[0][0],type(books)) # 取得するのは最初のレコードのpriceフィールドのデータです
        return HttpResponse("<p>検索に成功しました！</p>")

    distinct() メソッドはデータの重複を除去するために使用します。

    返り値は QuerySet 型データです。

    注意：

    • モデルクラスのオブジェクトを重複除去しても意味がありません。各オブジェクトはそれぞれ異なる存在だからです。
    • distinct() は通常、values または values_list と組み合わせて使用します。

    例

    from django.shortcuts import render,HttpResponse
    from app01 import models
    def add_book(request):
        # 出版社が全部でいくつあるかを照会します
        books = models.Book.objects.values_list("publish").distinct() # モデルクラスのオブジェクトを重複除去しても意味がありません。各オブジェクトはそれぞれ異なる存在だからです。
        books = models.Book.objects.distinct()
        return HttpResponse("<p>検索に成功しました！</p>")

    filter()メソッドはダブルアンダースコアによる曖昧検索です（exclude も同様）。

    注意：filter 内の演算子は等号 = のみ使用でき、大なり > や小なり < など他の記号は使用できません。

    __in は範囲を指定するために使用し、= の後ろはリストです。

    例

    from django.shortcuts import render,HttpResponse
    from app01 import models
    def add_book(request):
        # 価格が200または300のデータを照会します
        books = models.Book.objects.filter(price__in=[200,300])
        return HttpResponse("<p>検索に成功しました！</p>")

    __gt大なり記号、= の後ろは数字です。

    # 查询价格大于200的数据 
books = models.Book.objects.filter(price__gt=200)

    __gte以上、= の後ろは数字です。 
    # 查询价格大于等于200的数据 
books = models.Book.objects.filter(price__gte=200)

    __lt小なり、= の後ろは数字です。

    # 查询价格小于300的数据 
books=models.Book.objects.filter(price__lt=300)

    __lte以下、= の後ろは数字です。

    # 查询价格小于等于300的数据 
books=models.Book.objects.filter(price__lte=300)

    __range... の間（両端を含む）、= の後ろは2つの要素のリストです。

    books=models.Book.objects.filter(price__range=[200,300])

    __contains包含、= の後ろは文字列です。

    books=models.Book.objects.filter(title__contains="菜")

    __icontains大文字小文字を区別しない包含、= の後ろは文字列です。

    books=models.Book.objects.filter(title__icontains="python") # 不区分大小写

    __startswith指定した文字で始まる、= の後ろは文字列です。

    books=models.Book.objects.filter(title__startswith="菜")

    __endswith指定した文字で終わる、= の後ろは文字列です。

    books=models.Book.objects.filter(title__endswith="教程")

    __yearDateField データ型の年、= の後ろは数字です。

    books=models.Book.objects.filter(pub_date__year=2008)

    __monthDateField データ型の月、= の後ろは数字です。

    books=models.Book.objects.filter(pub_date__month=10)

    __dayDateField データ型の日、= の後ろは数字です。

    books=models.Book.objects.filter(pub_date__day=01)

    削除

    方法1：モデルクラスのオブジェクト.delete()。

    戻り値：タプルで、最初の要素は影響を受けた行数です。

    books=models.Book.objects.filter(pk=8).first().delete()

    方法2：QuerySet を使用する型データ.delete()（推奨）

    戻り値：タプルで、最初の要素は影響を受けた行数です。

    books=models.Book.objects.filter(pk__in=[1,2]).delete()

    注意：

    • a. Django がデータを削除するとき、SQL の制約 ON DELETE CASCADE の動作を模倣します。つまり、オブジェクトを削除すると、それに関連する外部キーオブジェクトも削除されます。
    • b. delete() メソッドは QuerySet データ型のメソッドですが、Manager 自体には適用されません。つまり、すべてのデータを削除したい場合は、all を省略できません。
    books=models.Book.objects.delete()　 # 报错
books=models.Book.objects.all().delete()　　 # 删除成功

    変更

    方法1：

    模型类的对象.属性 = 更改的属性值
模型类的对象.save()

    戻り値：編集されたモデルクラスのオブジェクト。

    books = models.Book.objects.filter(pk=7).first() 
books.price = 400 
books.save()

    方法2：QuerySet 型データ.update(フィールド名=変更するデータ)（推奨）

    戻り値：整数で、影響を受けた行数

    例

    from django.shortcuts import render,HttpResponse
    from app01 import models
    def add_book(request):
        books = models.Book.objects.filter(pk__in=[7,8]).update(price=888)
        return HttpResponse(books)
