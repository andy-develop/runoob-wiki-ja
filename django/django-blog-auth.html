用户系统 — 注册、登录、登出 → ユーザーシステム — 登録、ログイン、ログアウト

本章你将学会使用 Django 内置的认证系统，实现用户注册、登录和登出功能。 → この章では、Django 組み込みの認証システムを使って、ユーザー登録・ログイン・ログアウト機能を実装します。

Django 内置 auth 系统 → Django 組み込み auth システム

Django 自带一套完整的用户认证模块： → Django には完全なユーザー認証モジュールが標準で用意されています：

  • 内置 → 組み込みUser模型（用户名、密码、邮箱等） → モデル（ユーザー名、パスワード、メールアドレスなど）
  • 内置登录/登出视图（无需自己写逻辑） → 組み込みのログイン/ログアウトビュー（自分でロジックを書く必要なし）
  • 内置的权限和组管理 → 組み込みの権限とグループ管理
  • 表单验证和安全防护（CSRF、XSS） → フォーム検証とセキュリティ対策（CSRF、XSS）

这个模块是 → このモジュールはdjango.contrib.auth，在创建项目时已经默认注册到了 INSTALLED_APPS。 → プロジェクト作成時にデフォルトで INSTALLED_APPS に登録されています。

注册页面 → 登録ページ

Django 内置了登录/登出视图，但没有内置注册视图，需要我们自己写。 → Django にはログイン/ログアウトビューは組み込まれていますが、登録ビューは組み込まれていないため、自分で作成する必要があります。

第一步：创建注册表单 → ステップ1：登録フォームを作成する

例

# 文件路径：blog/forms.py（新建文件） → # ファイルパス：blog/forms.py（新規ファイル）
from django import forms
from django.contrib.auth.forms import UserCreationForm
from django.contrib.auth.models import User

class RegisterForm(UserCreationForm):
    """自定义注册表单：继承 UserCreationForm，添加邮箱字段""" → """カスタム登録フォーム：UserCreationForm を継承し、メールアドレスフィールドを追加"""
    email = forms.EmailField(
        label='邮箱' → 'メールアドレス',
        required=True,
        help_text='请输入有效的邮箱地址。' → '有効なメールアドレスを入力してください。'
    )

    class Meta:
        model = User
        fields = ['username', 'email', 'password1', 'password2']
        labels = {
            'username': '用户名' → 'ユーザー名',
        }

第二步：编写注册视图 → ステップ2：登録ビューを書く

例

# 文件路径：blog/views.py 新增 → # ファイルパス：blog/views.py に追加
from django.shortcuts import render, redirect
from django.contrib.auth import login
from django.contrib import messages
from .forms import RegisterForm

def register(request):
    """用户注册视图""" → """ユーザー登録ビュー"""
    # 如果用户已登录，直接跳转首页 → # ユーザーがすでにログインしている場合は、そのままホームページへリダイレクト
    if request.user.is_authenticated:
        return redirect('index')

    if request.method == 'POST':
        # 用户提交了注册表单 → # ユーザーが登録フォームを送信した
        form = RegisterForm(request.POST)
        if form.is_valid():
            user = form.save()              # 保存用户到数据库 → # ユーザーをデータベースに保存
            login(request, user)            # 注册后自动登录 → # 登録後に自動ログイン
            messages.success(request, f'注册成功，欢迎你，{user.username}！' → '登録成功、ようこそ、{user.username}！')
            return redirect('index')
    else:
        # GET 请求：显示空白注册表单 → # GET リクエスト：空の登録フォームを表示
        form = RegisterForm()

    return render(request, 'blog/register.html', {
        'form': form,
        'title': '注册 - RUNOOB 博客' → '登録 - RUNOOB ブログ'
    })

Django 的 → Django のmessages框架用于在请求之间传递一次性消息（如「注册成功」）。在模板中渲染 messages 区域，用户就能看到操作反馈。它和 session 配合使用，消息显示一次后自动消失。 → フレームワークは、リクエスト間で一度きりのメッセージ（「登録成功」など）を渡すために使用されます。テンプレートで messages 領域を描画すると、ユーザーは操作フィードバックを確認できます。これはセッションと連携して動作し、メッセージは一度表示されると自動的に消えます。

登录与登出 → ログインとログアウト

Django 内置了登录和登出视图，只需在路由中引入即可。 → Django にはログインビューとログアウトビューが組み込まれているので、ルーティングで導入するだけで済みます。

例

# 文件路径：blog/urls.py → # ファイルパス：blog/urls.py
from django.urls import path
from django.contrib.auth import views as auth_views
from . import views

urlpatterns = [
    path('', views.index, name='index'),
    path('post/<int:pk>/', views.post_detail, name='post_detail'),
    path('register/', views.register, name='register'),

    # Django 内置登录视图 → # Django 組み込みログインビュー
    # template_name：指定使用哪个模板 → # template_name：使用するテンプレートを指定
    path('login/', auth_views.LoginView.as_view(
        template_name='blog/login.html',
        redirect_authenticated_user=True  # 已登录用户访问 login 直接跳转 → # ログイン済みユーザーが login にアクセスした場合は直接リダイレクト
    ), name='login'),

    # Django 内置登出视图 → # Django 組み込みログアウトビュー
    path('logout/', auth_views.LogoutView.as_view(), name='logout'),
]

在 settings.py 中配置登录登出的跳转地址： → settings.py でログイン・ログアウトのリダイレクト先を設定します：

例

# 文件路径：blog_project/settings.py 末尾添加 → # ファイルパス：blog_project/settings.py の末尾に追加
LOGIN_URL = 'login'                    # 未登录用户访问保护页面时跳转到登录页 → # 未ログインユーザーが保護ページにアクセスした場合、ログインページへリダイレクト
LOGIN_REDIRECT_URL = 'index'           # 登录成功后跳转到首页 → # ログイン成功後にホームページへリダイレクト
LOGOUT_REDIRECT_URL = 'index'          # 登出后跳转到首页 → # ログアウト後にホームページへリダイレクト

{% csrf_token %}是 Django 的安全机制，防止跨站请求伪造攻击。任何 POST 表单必须包含它，否则 Django 会拒绝请求（403 错误）。这个标签会生成一个隐藏的 input，包含随机的 CSRF token。 → は Django のセキュリティ機構であり、クロスサイトリクエストフォージェリ攻撃を防ぎます。すべての POST フォームにはこれを含める必要があります。そうしないと Django はリクエストを拒否します（403 エラー）。このタグは、ランダムな CSRF トークンを含む隠し input を生成します。

在导航栏显示登录状态 → ナビゲーションバーにログイン状態を表示する

更新 base.html 的导航栏，根据登录状态显示不同内容。 → base.html のナビゲーションバーを更新し、ログイン状態に応じて異なる内容を表示します。

例

<!-- 修改 blog/templates/blog/base.html 的导航栏部分 --> → <!-- blog/templates/blog/base.html のナビゲーションバー部分を変更 -->
<header class="navbar">
    <a href="/" class="logo">RUNOOB 博客 → RUNOOB ブログ</a>
    <nav>
        <a href="/">首页 → ホーム</a>

        {% if user.is_authenticated %}
{# 已登录：显示用户名和登出按钮（user 是 Django 自动注入的） #} → {# ログイン済み：ユーザー名とログアウトボタンを表示（user は Django によって自動的に注入されます） #}
            <span class="user-name">{{ user.username }}</span>
            <a href="{% url 'logout' %}">登出 → ログアウト</a>
        {% else %}
{# 未登录：显示登录和注册链接 #} → {# 未ログイン：ログインと登録リンクを表示 #}
            <a href="{% url 'login' %}">登录 → ログイン</a>
            <a href="{% url 'register' %}">注册 → 登録</a>
        {% endif %}
    </nav>
</header>

Django 的模板上下文处理器会自动将 → Django のテンプレートコンテキストプロセッサは自動的に{{ user }}注入到每个模板中，无需在 views.py 中手动传递。你可以通过 → を各テンプレートに注入します。views.py で手動で渡す必要はありません。あなたはuser.is_authenticated判断用户是否登录。 → ユーザーがログインしているかどうかを判断します。
