Django インストール

Django をインストールする前に、システムに Python の開発環境がインストールされている必要があります。

Python をまだインストールしていない場合は、まず Python 公式サイトからhttps://www.python.org/最新バージョンの Python をダウンロードしてインストールしてください。

Django のインストールもとても簡単で、パッケージ管理ツール pip を使うだけです：

pip install Django

インストールが完了したら、以下のコマンドを実行して Django が正常にインストールされたか確認できます：

python3 -m django --version

問題がなければ、インストールされた Django のバージョン番号が表示されます。例：4.2.7。

開発環境のおすすめ：

  • 1、VS Code 開発ツール
  • 2、PyCharm 開発ツール
  • 3、アリババ Qoder
  • 4、Trae 開発ツール

Windows での Django インストール

次に、さまざまなシステムでの Django のインストールについて詳しく見ていきましょう。

Python 環境をまだインストールしていない場合は、先に Python インストールパッケージをダウンロードする必要があります。

1、Python ダウンロード先：https://www.python.org/downloads/

2、Django ダウンロード先：https://www.djangoproject.com/download/

注意：現在、Django 1.6.x 以降のバージョンは Python 3.x と完全に互換性があります。

Python のインストール（インストール済みの場合はスキップ可）

Python のインストールは、python-x.x.x.msi ファイルをダウンロードして、「Next」ボタンをクリックし続けるだけです。

インストール完了後、Python の環境変数を設定する必要があります。 コンピューターを右クリック -> プロパティ -> 詳細設定 -> 環境変数 -> システム変数の path を変更し、Python のインストール先を追加します。この記事の例では C:\Python33 を使用していますが、実際の状況に応じてインストールしてください。

Django のインストール

Django の圧縮パッケージをダウンロードし、解凍して Python のインストールディレクトリと同じルートディレクトリに置きます。Django ディレクトリに入り、python setup.py install を実行すると、インストールが開始され、Django は Python の Lib 配下の site-packages にインストールされます。

次に環境変数を設定します。次のディレクトリをシステム環境変数に追加します：C:\Python33\Lib\site-packages\django;C:\Python33\Scripts。追加が完了すると、Django の django-admin.py コマンドを使用して新しいプロジェクトを作成できます。

インストールが成功したか確認する

以下のコマンドを入力して確認します：

>>> import django
>>> django.get_version()

Django のバージョン番号が出力されれば、インストールは正しく行われています。

Linux での Django インストール

yum でのインストール方法

以下のインストールは CentOS Linux 環境でのインストールです。Linux システムが Ubuntu の場合は、apt-get コマンドを使用してください。

デフォルトでは、Linux 環境は Python をサポートしています。ターミナルで python コマンドを入力すると、インストールされているかどうかを確認できます。

Python 3.7.4 (default, Aug  1 2012, 05:14:39) 
[GCC 4.6.3] on linux2
Type "help", "copyright", "credits" or "license" for more information.
>>>

setuptools のインストール

コマンド：

# Python3 安装
yum install python3-setuptools
# Python2 安装
yum install python2-setuptools

完了後、easy_install コマンドで django をインストールできます。

easy_install django

その後、Python インタープリターに以下のコードを入力します：

[root@solar django]# python
Python 3.7.4 (default, May 15 2014, 14:49:08)
[GCC 4.8.0] on linux2
Type "help", "copyright", "credits" or "license" for more information.
>>> import django
>>> django.VERSION
(3, 0, 6, 'final', 0)

Django のバージョン番号が出力されていれば、インストール成功です。

pip コマンドでのインストール方法

pip ツールをまだインストールしていない場合は、以下を参照してください：Python pip のインストールと使用方法。

sudo pip3 install Django -i https://pypi.tuna.tsinghua.edu.cn/simple

-i https://pypi.tuna.tsinghua.edu.cn/simple清華大学のミラーソースを指定すると、ダウンロード速度が速くなります。

Django のダウンロードバージョンを指定します（3.0.6 は任意のバージョンに変更可能）：

sudo pip3 install Django==3.0.6 -i https://pypi.tuna.tsinghua.edu.cn/simple

pip < 1.4 の場合、インストール方法は以下のとおりです：

pip install https://www.djangoproject.com/download/1.11a1/tarball/

ソースコードからのインストール方法

ソースコードパッケージをダウンロード：https://www.djangoproject.com/download/

以下のコマンドを入力してインストールします：

tar xzvf Django-X.Y.tar.gz    # 解压下载包
cd Django-X.Y                 # 进入 Django 目录
python setup.py install       # 执行安装命令

インストールが成功すると、Django は Python のインストールディレクトリの site-packages ディレクトリに配置されます。

Mac でのインストール

ダウンロード

からこちら最新の安定版：DJango-3.x.y.tar.gz をダウンロードします。ページ右側のリストからダウンロードしてください。下図のとおりです：

必ず最新の公式バージョンにしてくださいね。ここでx.yはバージョン番号です。ダウンロードしたファイルが置かれているフォルダーに移動し、次のコマンドを実行します：（Mac ではデフォルトで /Users/xxx/Downloads、xxx はあなたのユーザー名です）

$ tar zxvf Django-3.x.y.tar.gz

GitHub から最新版をダウンロードすることもできます。アドレス：https://github.com/django/django：

git clone https://github.com/django/django.git

インストール

解凍後のディレクトリに入ります：

cd Django-3.x.y
sudo python setup.py install

インストールが成功すると、以下の情報が出力されます：

……
Processing dependencies for Django==3.x.y
Finished processing dependencies for Django==3.x.y

次にサイトディレクトリに入り、Django プロジェクトを作成します：

$ django-admin.py startproject testdj

サービスを起動：

cd testdj # 切换到我们创建的项目
$ python manage.py runserver
……
Starting development server at http://127.0.0.1:8000/
Quit the server with CONTROL-C.

上記の情報は、プロジェクトが起動済みで、アクセスアドレスが http://127.0.0.1:8000/ であることを示しています。
