所属カテゴリ

インタラクション（Interactions）

使用方法

説明：マウスを使用して、リストまたはグリッド内の要素の並び順を調整します。

追加されたバージョン：1.0

依存関係：

  • UI コア（UI Core）
  • ウィジェットファクトリー（Widget Factory）
  • マウスインタラクション（Mouse Interaction）

注：jQuery UI ソータブル（Sortable）プラグインは、選択された要素をマウスのドラッグで並べ替えることができます。

注：テーブルの行を並べ替えるには、tbodyソータブル（sortable）である必要があり、～ではなくtable。

appendTo jQuery または Element または Selector または String ドラッグ中に、マウスで移動するヘルパーがどこに追加されるか（例：overlap/zIndex の問題を解決するため）。

複数の型をサポートします：

  • jQuery：ヘルパー（helper）を追加する要素を含む jQuery オブジェクト。
  • Element：ヘルパー（helper）を追加する要素。
  • Selector：ヘルパー（helper）をどの要素に追加するかを指定するセレクター。
  • String：文字列"parent"これにより、ヘルパー（helper）はソータブル（sortable）項目の兄弟になります。

コード例：

初期化：指定されたappendToオプションの sortable：

$( ".selector" ).sortable({ appendTo: document.body });
    

初期化後に、取得または設定するappendToオプション：

// getter
var appendTo = $( ".selector" ).sortable( "option", "appendTo" );
 
// setter
$( ".selector" ).sortable( "option", "appendTo", document.body );
    
 "parent"

serialize( options ) String sortable の項目をシリアライズidして、form/ajax で送信可能な文字列にします。このメソッドを呼び出すと、任意の URL に追加できるハッシュが生成され、新しい項目の順序を簡単にサーバーへ送信できます。

デフォルトでは、各項目のidを使用して動作し、id 形式は"setname_number"であり、次のような形式の"setname[]=number&setname[]=number"ハッシュを生成します。

注：シリアライズが空の文字列を返す場合は、id属性にアンダースコア（_）が含まれていることを確認してください。形式は"set_number"でなければなりません。例えば、id属性が"foo_1"、"foo_5"、"foo_2"である 3 要素のリストは、次のようにシリアライズされます。"foo[]=1&foo[]=5&foo[]=2"。アンダースコア（_）、等号（=）、またはハイフン（-）を使用してセットと数値を区切ることができます。例えば、"foo=1"、"foo-1"、"foo_1"はすべて次のようにシリアライズされます。"foo[]=1"。

  • options
    型：Object
    シリアライズをカスタマイズするためのオプション。
    • key（デフォルト値：属性内のセパレータより前の部分）
      型：String
      説明：part1[]を指定された値に置き換えます。
    • attribute（デフォルト値："id"）
      型：String
      説明：値に使用する属性名。
    • expression（デフォルト値：/(.+)[-=_](.+)/）
      型：RegExp
      説明：属性値をキーと値の 2 つの部分に分割するための正規表現。

コード例：
