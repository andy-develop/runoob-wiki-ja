カテゴリ

インタラクション（Interactions）

使用法

説明：マウスを使用して要素のサイズを変更します。

追加されたバージョン：1.0

依存：

  • UIコア（UI Core）
  • ウィジェットファクトリ（Widget Factory）
  • マウスインタラクション（Mouse Interaction）

注記：jQuery UI のリサイズ（Resizable）プラグインは、選択された要素をリサイズ可能にします（ドラッグ可能なサイズ変更ハンドルを持つことを意味します）。1つまたは複数のハンドルを指定でき、幅と高さの最小値と最大値も指定できます。

補足説明：このウィジェットは機能的なCSSを必要とします。そうでないと動作しません。カスタムテーマを作成する場合は、ウィジェット固有のCSSファイルを出発点として使用してください。

handles String または Object リサイズに使用できるハンドル。

複数の型をサポート：

  • String：カンマ区切りのリスト。値は以下のいずれか：n, e, s, w, ne, se, sw, nw, all。必要なハンドルはプラグインによって自動的に生成されます。
  • Object：次のキーをサポート：{ n, e, s, w, ne, se, sw, nw }。指定された値は、ハンドルとして使用する resizable の子要素に一致する jQuery セレクターである必要があります。

注記：独自のハンドルを作成する場合、各ハンドルにはui-resizable-handleclass、または適切なappropriate ui-resizable-{direction}class（例：ui-resizable-s）が必要です。

コード例：

指定のhandlesオプションで resizable を初期化：

// setter

 "e, s, se"
