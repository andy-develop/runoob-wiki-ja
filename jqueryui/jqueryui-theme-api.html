jQuery UI CSS フレームワーク

jQuery UI には、カスタム jQuery ウィジェットを作成するために設計された強力な CSS フレームワークが含まれています。このフレームワークには、一般的なユーザーインターフェースに必要なクラスが含まれており、jQuery UI ThemeRoller を使用して維持できます。jQuery UI CSS フレームワークを使用することで、独自の UI コンポーネントを作成できます。プラグインコミュニティでのコード統合のために、共有マークアップ規約を採用する必要があります。

フレームワーククラス

以下の CSS クラスは、スタイルが固定された構造化されたものであるか、テーマ化可能（色、フォント、背景など）であるかに応じて、それぞれui.core.cssとui.theme.css2つのファイルで定義されています。これらのクラスは、アプリケーション全体の視覚的な一貫性を実現するためにユーザーインターフェース要素に使用されるように設計されており、jQuery UI ThemeRoller を使用してコンポーネントをテーマ化できます。

レイアウトヘルパー

  • .ui-helper-hidden：要素に適用しますdisplay: none。
  • .ui-helper-hidden-accessible：要素にアクセス非表示を適用します（ページの絶対配置による）。
  • .ui-helper-reset：UI 要素の基本的なスタイルをリセットします。リセットされる要素の例：padding、margin、text-decoration、list-style など。
  • .ui-helper-clearfix：親要素にフロートラッパー属性を適用します。
  • .ui-helper-zfix：対象の<iframe>要素に iframe「fix」CSS を適用します。

ウィジェットコンテナ

  • .ui-widget：すべてのウィジェットの外部コンテナに適用されるクラス。ウィジェットにフォントとフォントサイズを適用し、Windows ブラウザでの継承問題に対処するため、フォーム要素自体にも同じフォントと 1em のフォントサイズを適用します。
  • .ui-widget-header：ヘッダーコンテナに適用されるクラス。要素とその子要素のテキスト、リンク、アイコンにヘッダーコンテナのスタイルを適用します。
  • .ui-widget-content：コンテンツコンテナに適用されるクラス。要素とその子要素のテキスト、リンク、アイコンにコンテンツコンテナのスタイルを適用します。（ヘッダーの親要素または兄弟要素に適用できます。）

インタラクション状態

  • .ui-state-default：クリック可能なボタン要素に適用されるクラス。要素とその子要素のテキスト、リンク、アイコンに「clickable default」コンテナスタイルを適用します。
  • .ui-state-hover：マウスがクリック可能なボタン要素の上にホバーされたときに適用されるクラス。要素とその子要素のテキスト、リンク、アイコンに「clickable hover」コンテナスタイルを適用します。
  • .ui-state-focus：キーボードフォーカスがクリック可能なボタン要素にあるときに適用されるクラス。要素とその子要素のテキスト、リンク、アイコンに「clickable hover」コンテナスタイルを適用します。
  • .ui-state-active：マウスがクリック可能なボタン要素上でクリックされたときに適用されるクラス。要素とその子要素のテキスト、リンク、アイコンに「clickable active」コンテナスタイルを適用します。

インタラクションのヒント（Cues）

  • .ui-state-highlight：ハイライトまたは選択された要素に適用されるクラス。要素とその子要素のテキスト、リンク、アイコンに「highlight」コンテナスタイルを適用します。
  • .ui-state-error：エラーメッセージコンテナ要素に適用されるクラス。要素とその子要素のテキスト、リンク、アイコンに「error」コンテナスタイルを適用します。
  • .ui-state-error-text：背景のないエラーテキストの色のみに適用されるクラス。フォームラベルに使用でき、子アイコンにもエラーアイコンの色を適用できます。
  • .ui-state-disabled：無効化された UI 要素に暗い不透明度を適用します。すでにスタイルが定義されている要素に追加のスタイルを加えることを意味します。
  • .ui-priority-primary：最優先のボタンに適用されるクラス。太字テキストを適用します。
  • .ui-priority-secondary：第二優先のボタンに適用されるクラス。通常の太さのテキストを適用し、要素にわずかな透明度を適用します。

アイコン

状態と画像

  • .ui-icon：アイコン要素に適用される基本クラス。サイズを16pxの正方形に設定し、内部テキストを非表示にし、「content」状態のスプライト画像に背景画像を設定します。注： .ui-iconclass は、その親コンテナに応じて異なるスプライト背景画像を取得します。例えば、ui-state-defaultコンテナ内のui-icon要素は、ui-state-defaultのアイコン色に応じて着色されます。

アイコンの種類

class を宣言した後に、.ui-iconアイコンの種類を記述する class を宣言できます。通常、アイコン class は構文に従います。.ui-icon-{icon type}-{icon sub description}-{direction}。

例えば、右向きの三角形アイコンは次のようになります：.ui-icon-triangle-1-e

jQuery UI のThemeRollerプレビュー欄には、CSS フレームワークのアイコンのフルセットが用意されています。アイコンにマウスをホバーすると class 名を確認できます。

その他の視覚効果

角丸半径ヘルパー

  • .ui-corner-tl：要素の左上隅に角丸半径を適用します。
  • .ui-corner-tr：要素の右上隅に角丸半径を適用します。
  • .ui-corner-bl：要素の左下隅に角丸半径を適用します。
  • .ui-corner-br：要素の右下隅に角丸半径を適用します。
  • .ui-corner-top：要素の上辺の左右の角に角丸半径を適用します。
  • .ui-corner-bottom：要素の下辺の左右の角に角丸半径を適用します。
  • .ui-corner-right：要素の右辺の上下の角に角丸半径を適用します。
  • .ui-corner-left：要素の左辺の上下の角に角丸半径を適用します。
  • .ui-corner-all：要素の4つの角すべてに角丸半径を適用します。

オーバーレイ & シャドウ

  • .ui-widget-overlay：オーバーレイ画面に100%の幅と高さを適用し、背景色/テクスチャと画面の不透明度を設定します。
  • .ui-widget-shadow：オーバーレイに適用されるクラス。不透明度、上/左オフセット、シャドウの「厚み」を設定します。厚みは、シャドウのすべての辺に padding（パディング）を設定することで適用されます。オフセットは、上 margin（マージン）と左 margin（マージン）を設定することで適用されます（正の数と負の数の両方を指定できます）。
