アセンブリ言語 - 基本構文

この章では、NASMアセンブラの基本構造、構文規則、記述規範を紹介し、アセンブリコードの骨格を理解するのに役立てます。

アセンブリプログラムの基本構造

完全なNASMアセンブリプログラムは通常、以下の部分から構成されます：

实例

; 文件路径：structure.asm
; NASM 程序基本结构示例

section .data                       ; 数据段：存放已初始化的数据
    ; 这里定义变量和常量
    msg db 'Hello, RUNOOB!', 0xA
    len equ $ - msg

section .bss                        ; BSS 段：存放未初始化的数据
    ; 这里预留内存空间
    buffer resb 64                  ; 预留 64 字节的缓冲区

section .text                       ; 代码段：存放可执行指令
    global _start

_start:
    ; 这里写程序逻辑
    mov eax, 4
    mov ebx, 1
    mov ecx, msg
    mov edx, len
    int 0x80

    mov eax, 1
    mov ebx, 0
    int 0x80
段（Section）用途特点
.data初期化済みのグローバル変数と定数を格納するコンパイル時にサイズと内容が決定され、実行ファイルに格納される
.bss初期化されていないグローバル変数を格納する実行時にのみ空間を割り当て、実行ファイルのサイズを占用しない
.text実行可能な機械命令を格納する読み取り専用で、プログラムのすべてのロジックコードを含む

至少需要.textセグメントがあって初めて有効なアセンブリプログラムを構成できます。データがなければ省略できます.data 和 .bss段。

アセンブリ文の書式

各アセンブリ文の一般的な形式は次のとおりです：

[标签:]   指令助记符   [操作数1 [, 操作数2 [, 操作数3]]]   [; 注释]

各部分の説明：

部分是否必须说明
标签（Label）可选メモリアドレスを表すシンボル名で、コロンで終わる
指令助记符必须mov、add、sub など、CPU に何をするかを伝える
操作数省略可能（一部の命令にはオペランドがない）命令が操作するデータオブジェクトであり、レジスタ、メモリアドレス、即値のいずれか
注释可选セミコロンで始まり、行末まで続く

实例

; 各种语句格式示例

; 只有指令，无操作数
ret                     ; 从子程序返回

; 指令 + 单个操作数
push eax                ; 将 eax 的值压入栈中
inc ecx                 ; ecx 加 1

; 指令 + 两个操作数（最常见）
mov eax, 42             ; 将 42 复制到 eax 寄存器
add ebx, ecx            ; ebx = ebx + ecx

; 带有标签
loop_start:             ; 标签：标记循环开始位置
    dec ecx             ; ecx 减 1
    jnz loop_start      ; 如果 ecx 不为 0，跳回 loop_start

注释规范

NASM 使用分号（;）コメントを表し、セミコロンから行末までの内容はアセンブラによって無視される。

实例

; 整行注释：说明下面代码块的用途
; 计算两个数的和并输出结果

mov eax, 10             ; 行内注释：将 10 放入 eax
add eax, 20             ; 行内注释：将 20 加到 eax，现在 eax = 30

アセンブリコードではコメントが極めて重要です。コメントのないアセンブリコードは、数週間後には作者自身でさえ理解できなくなる可能性があります。各命令にコメントを書く習慣を身につけましょう。

識別子の命名規則

識別子（ラベル、変数名、定数名など）は以下の規則に従う必要があります：

规则说明
组成字符英字、数字、アンダースコア _、ドット .、疑問符 ?、@、$、# など
起始字符英字、アンダースコア、ドット、または疑問符で始めなければならず、数字で始めることはできません
大小写デフォルトでは大文字と小文字を区別します（コンパイルオプションで変更可能）
保留字命令ニーモニック、レジスタ名、NASMキーワードと同じ名前は使用できません

实例

; 合法的标识符
my_variable:            ; 字母开头 + 下划线
.loop_start:            ; 点开头（局部标签）
?error_handler:         ; 问号开头
counter2:               ; 字母 + 数字

; 不合法的标识符（仅供参考，不要使用）
; 1st_value:            ; 错误：不能以数字开头
; mov:                  ; 错误：mov 是保留字
; my-variable:          ; 错误：减号不是合法字符

疑似命令（ディレクティブ）

伪指令アセンブラに対する命令であり、CPUに対する命令ではありません。アセンブル処理の制御とデータ構造の定義に使用されます。

伪指令用途示例
dbバイトを定義（1バイト）byte_val db 0x55
dwワード定義（2バイト）word_val dw 0x1234
ddダブルワードを定義（4バイト）dword_val dd 0x12345678
equ定义常量MAX_SIZE equ 256
resbバイト領域の予約buffer resb 128
resw预留字空间wbuf resw 64
resdダブルワード領域の予約dbuf resd 32
%define宏定义常量%define COUNT 10

大小写规范

NASMはデフォルトでラベルと識別子に対して区分大小写：

实例

; 大小写敏感的示例

section .data
    msg db 'RUNOOB', 0       ; 定义变量 msg

section .text
    global _start

_start:
    mov eax, MSG             ; 错误：MSG 和 msg 不同（除非开启忽略大小写）
    mov eax, msg             ; 正确：msg 与定义完全一致

    MOV EAX, 42              ; 语法正确：指令助记符不区分大小写
    mov eax, 42              ; 推荐写法：用小写，可读性更好

命令ニーモニックとレジスタ名は大文字と小文字を区別しません（MOV、Mov、mov効果は同じ）だが、推奨されるスタイルは統一して小文字を使うこと。

数値の表現方式

NASMは複数の基数による数値表現をサポートしています：

实例

; NASM 中不同进制的表示方式

mov eax, 42             ; 十进制：直接写数字
mov eax, 0x2A           ; 十六进制：0x 前缀（推荐写法）
mov eax, 2Ah            ; 十六进制：h 后缀
mov eax, 0o52           ; 八进制：0o 前缀
mov eax, 52o            ; 八进制：o 后缀
mov eax, 101010b        ; 二进制：b 后缀
mov eax, 0b101010       ; 二进制：0b 前缀

推荐使用0x接頭辞は16進数を表す（例：0x2A）、これによりラベルと混同しにくい。

完全な構文例

次のプログラムは上記の構文要素を総合的に使用し、1から10までの和を計算して出力します：

实例

; 文件路径：sum.asm
; 计算 1+2+...+10 并输出结果字符

section .data
    result db 0                 ; 存放计算结果（1字节）
    newline db 0xA              ; 换行符

section .text
    global _start

_start:
    ; 初始化寄存器和变量
    mov ecx, 10                 ; 循环计数器：从 10 开始倒数
    mov eax, 0                  ; eax 存放累加和，初始为 0

sum_loop:                       ; 循环开始标签
    add eax, ecx                ; eax = eax + ecx
    dec ecx                     ; ecx 减 1
    jnz sum_loop                ; 如果 ecx != 0，继续循环

    ; 此时 eax = 55（10+9+...+1）
    add eax, '0'                ; 将数字转为 ASCII 字符（'0'=48，55+48=103='g'，不对）
                                ; 实际演示需要更复杂的转换，见后续章节

    ; 这里只输出 result（简化演示）
    mov [result], al            ; 将累加结果存入 result

    ; 退出程序
    mov eax, 1
    mov ebx, 0
    int 0x80

注意：上記の例では、直接 '0' を加える方法は数字が0〜9の範囲内の場合のみ正しく機能します。2桁以上の数値の変換処理については、後の章で詳しく説明します。
