アセンブリ言語 - 変数

変数はプログラムでデータを格納する基本単位です。アセンブリ言語での変数の定義と使用は高水準言語よりも低レベルに近く、変数のサイズ、型、メモリレイアウトを直接制御する必要があります。

アセンブリにおける変数の概念

アセンブリ言語では、变量本質的には、メモリ内の名前付きストレージ位置です。

高水準言語とは異なり、アセンブリ変数には自動型チェックがありません。ラベルはメモリアドレスの単なる別名であり、任意のサイズで読み書きできます。

NASMは異なる種類の変数を格納するための3つのセクションを提供します：.data（初期化済み）、.bss（未初期化）および.rodata（只读）。

.data セクションで初期化済み変数を定義する

DB、DW、DD、DQ、DT 疑似命令を使用して異なるサイズの変数を定義します：

伪指令数据大小含义示例
DB1 字节Define Byteflag db 1
DW2 字节Define Wordcount dw 1000
DD4 字节Define Doublewordprice dd 9999
DQ8 字节Define Quadwordbig_val dq 0x1234567890ABCDEF
DT10 字节Define Ten Bytesext_val dt 3.14

实例

; 文件路径：variables_data.asm
; 演示 .data 段中各种变量的定义

section .data
    ; 字节变量
    status db 1                 ; 1 字节，值为 1
    grade db 'A'                ; 1 字节，字符 'A' = 0x41

    ; 字变量（2 字节）
    year dw 2026                ; 2 字节，值为 2026

    ; 双字变量（4 字节）
    salary dd 50000             ; 4 字节，值为 50000

    ; 多字节序列
    msg db 'Hello, runoob!', 0  ; 字符串以 0 结尾（C 风格）
    hex_bytes db 0x55, 0xAA, 0x00, 0xFF   ; 十六进制字节序列

    ; 重复值
    stars db 10 dup('*')        ; 10 个星号字符

    ; 带名称的多个变量
    x dd 10
    y dd 20
    z dd 30

section .text
    global _start

_start:
    ; 读取变量值到寄存器
    mov al, [status]            ; al = 1（读取 1 字节）
    mov ax, [year]              ; ax = 2026（读取 2 字节）
    mov eax, [salary]           ; eax = 50000（读取 4 字节）

    ; 修改变量值
    mov byte [status], 0        ; status = 0
    mov dword [x], 100          ; x = 100

    mov eax, 1
    mov ebx, 0
    int 0x80

使用変数にアクセスするときは、読み取り/書き込みのバイト数が変数定義時のバイト数と一致することを必ず確認してください。使用してmov al, [status]1バイトを読み、mov eax, [salary]4 バイトを読み取ります。NASM はオペランドサイズが一致するかどうかをチェックします。

.bss セクションで未初期化領域を予約する

RESB、RESW、RESD などの疑似命令を使用して領域を予約します（初期化しない）：

伪指令预留大小示例
RESB字节buffer resb 256
RESWワード（2バイト）wbuf resw 100
RESDダブルワード（4バイト）dbuf resd 50
RESQクワッドワード（8バイト）qbuf resq 25

实例

; 文件路径：variables_bss.asm
; 演示 .bss 段中预留空间

section .bss
    input_buf resb 128          ; 预留 128 字节的输入缓冲区
    numbers resd 100            ; 预留 100 个双字（400 字节）
    temp resb 1                 ; 预留 1 字节的临时变量

section .data
    prompt db 'Enter a number: '
    prompt_len equ $ - prompt

section .text
    global _start

_start:
    ; 输出提示
    mov eax, 4
    mov ebx, 1
    mov ecx, prompt
    mov edx, prompt_len
    int 0x80

    ; 读取输入到 .bss 段的缓冲区
    mov eax, 3
    mov ebx, 0
    mov ecx, input_buf           ; 使用 .bss 段预留的空间
    mov edx, 128
    int 0x80

    ; 向 numbers 数组填入数据
    mov dword [numbers], 42      ; numbers[0] = 42
    mov dword [numbers + 4], 100 ; numbers[1] = 100

    mov eax, 1
    mov ebx, 0
    int 0x80

バイト、ワード、ダブルワードのメモリレイアウトを

x86 使用小端序（Little Endian）——下位バイトは低アドレスに格納される。

例えば、定義するときvalue dd 0x12345678用いる場合、メモリ内のレイアウトは：

地址    ：[value]  [value+1]  [value+2]  [value+3]
内容    ：0x78     0x56       0x34       0x12

实例

; 文件路径：endianness.asm
; 演示小端序存储

section .data
    value dd 0x12345678        ; 双字，4 字节

section .text
    global _start

_start:
    ; 按不同大小读取同一个变量
    mov eax, [value]            ; 读 4 字节：eax = 0x12345678
    mov ax, [value]             ; 读 2 字节：ax = 0x5678（低2字节）
    mov al, [value]             ; 读 1 字节：al = 0x78（最低1字节）

    ; 验证小端序：低地址存放低字节
    mov al, [value]             ; al = 0x78
    mov bl, [value + 1]         ; bl = 0x56
    mov cl, [value + 2]         ; cl = 0x34
    mov dl, [value + 3]         ; dl = 0x12

    mov eax, 1
    mov ebx, 0
    int 0x80

変数の初期化とアクセス

アセンブリでは、変数の操作は「ロード-演算-ストア」の3ステップパターンに従います：

实例

; 文件路径：var_operations.asm
; 演示变量操作的三步模式

section .data
    a dd 100
    b dd 200
    result dd 0

section .text
    global _start

_start:
    ; result = a + b
    ; 第1步：加载
    mov eax, [a]                ; 加载 a 到 eax
    ; 第2步：运算
    add eax, [b]                ; eax = eax + b
    ; 第3步：存储
    mov [result], eax           ; 存储结果到 result

    ; result = a * 2 - b
    mov eax, [a]
    imul eax, 2                 ; eax = a * 2
    sub eax, [b]                ; eax = eax - b
    mov [result], eax

    mov eax, 1
    mov ebx, 0
    int 0x80

汇编不支持mov [result], [a] + [b]このような高水準構文。x86 の mov 命令は2つのメモリオペランドを同時に使用できず、必ずレジスタを経由して中継する必要があります。

変数サイズ演算子

アセンブラがオペランドサイズを推測できない場合は、明示的に指定する必要があります：

实例

; 使用大小操作符明确数据大小

section .data
    var dd 0

section .text
    global _start

_start:
    ; 大小操作符：byte, word, dword, qword
    mov byte [var], 1           ; 写入 1 字节
    mov word [var], 1000        ; 写入 2 字节
    mov dword [var], 999999     ; 写入 4 字节

    ; 当目标大小明确时（由寄存器决定），可以省略
    mov al, [var]               ; al 是 1 字节，自动按 byte 读取
    mov ax, [var]               ; ax 是 2 字节，自动按 word 读取
    mov eax, [var]              ; eax 是 4 字节，自动按 dword 读取

    ; 但下面这行会报错（大小不明确）：
    ; mov [var], 1              ; 错误！1 可以是字节/字/双字
    ; 必须写成：
    mov dword [var], 1          ; 明确指定 4 字节

    mov eax, 1
    mov ebx, 0
    int 0x80
