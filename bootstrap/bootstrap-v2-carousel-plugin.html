Bootstrap 轮播

描述

このチュートリアルでは、Bootstrap を使用してカルーセルを作成する方法を説明します。これにより、コンテンツスライダー、画像ギャラリーなどを作成できます。


用法

<div id="myCarousel" class="carousel slide">
    <!-- Carousel items -->
    <div class="carousel-inner">
        <div class="active item">…</div>
        <div class="item">…</div>
        <div class="item">…</div>
    </div>
    <!-- Carousel nav -->
    <a class="carousel-control left" href="../index.html" data-slide="prev">‹</a>
    <a class="carousel-control right" href="../index.html" data-slide="next">›</a>
</div>
            

したがって、表示したい項目（たとえば images）を循環順に "carousel-inner" div 内に配置し、"<!-- Carousel nav -->" を使用して項目のナビゲーションを作成します。カスタム data 属性 "data-slide" を使用して、前後の項目にナビゲーションします。

カルーセルを作成したいHTMLファイルで、jquery.jsとbootstrap-carousel.jsファイルを参照する必要があります。

使用 Javascript

以下の JavaScript コードを使用してカルーセルを作成できます。

$('.carousel').carousel()

以下は、使用できるものです。选项

  • interval: スライドの切り替えの待機時間をミリ秒単位で指定します。値の型は number で、デフォルト値は 5000 です。false の場合、カルーセルは自動的に循環を開始しません。
  • pause: マウスがスライド領域に留まっている間はカルーセルを一時停止し、マウスが離れるとカルーセルを再開します。値の型は string で、デフォルト値は 'hover' です。

以下は、使用できるカルーセルです。方法

  • .carousel(options): カルーセルコンポーネントを初期化し、オプションの object 型の options パラメータを受け取り、スライドの循環を開始します。
    • $('.carousel').carousel({
  interval: 2000 // in milliseconds
})
  • .carousel('cycle'): 各フレームを左から右へ循環します。
    • $('.carousel').carousel('cycle');
  • .carousel('pause'): 停止轮播。
    • $('#myCarousel').hover(function () { 
  $(this).carousel('pause') 
}
  • .carousel(number): カルーセルを指定したフレームに配置します（フレームのインデックスは0から始まり、配列に似ています）。
    • $("#carousel_nav").click(function(){ 
var item = 4; 
$('#home_carousel').carousel(item); 
return false; 
});
  • .carousel('prev'): カルーセルを前のフレームに移動します。
  • .carousel('next'): カルーセルを次のフレームに移動します。

ここに二つあります事件カルーセルの機能を強化するために使用されます。

  • slide: slide インスタンスメソッドが呼び出された後、このイベントが直ちにトリガーされます。
  • slid: すべてのスライドの再生が完了すると、このイベントがトリガーされます。
