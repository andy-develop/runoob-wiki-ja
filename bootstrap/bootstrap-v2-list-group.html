Bootstrap 使用清单组组件创建价格表

目标

価格表は、製品やサービスを販売するあらゆるWebサイトの主要な構成要素の1つです。Bootstrap 3（以前のバージョンと同様）は価格表コンポーネントを直接提供していませんが、リストグループコンポーネントを提供しています。このコンポーネントは、複雑なカスタムコンテンツをレンダリングするために設計されています。この機能を利用して、このチュートリアルではシンプルな価格表を作成し、リストグループの作成に使用されるCSSルールを説明し、それをカスタマイズする方法を説明します。

典型的な外観

您可以オンラインで表示演示、以下はサンプルコードです。

<div class="container">
<div class="row">
  <ul class="list-group col-lg-4">
  <li class="list-group-item">Unlimited Users</li>
  <li class="list-group-item">Unlimited storage</li>
  <li class="list-group-item">Forum support</li>
  <li class="list-group-item">More....</li>
  <li class="list-group-item">More.....</li>
</ul>
</div>
</div>

list-group と list-group-item

list-groupclass の CSS ルールは以下のとおりです。

.list-group {
  padding-left: 0;
  margin-bottom: 20px;
}

.list-group-item {
  position: relative;
  display: block;
  padding: 10px 15px;
  margin-bottom: -1px;
  background-color: #FFFFFF;
  border: 1px solid #DDDDDD;
}

.list-group-item:first-child {
  border-top-right-radius: 4px;
  border-top-left-radius: 4px;
}

.list-group-item:last-child {
  margin-bottom: 0;
  border-bottom-right-radius: 4px;
  border-bottom-left-radius: 4px;
}

徽章（badges）

您可以使用徽章（badges）コンポーネントを使って list-group を含めます。次のコードは、これを実装する方法を示しています。

<div class="container">
<div class="row">
  <ul class="list-group col-lg-4">
  <li class="list-group-item"><span class="badge">Very important</span>Unlimited Users</li>
  <li class="list-group-item">Unlimited storage</li>
  <li class="list-group-item">Forum support</li>
  <li class="list-group-item">More....</li>
  <li class="list-group-item">More.....</li>
</ul>
</div>
</div>

您可以ここをクリックして、オンラインでデモを表示以下は、リストグループ内のバッジを配置するためのCSSコードを示しています。

.list-group-item > .badge {
  float: right;
}

.list-group-item > .badge + .badge {
  margin-right: 5px;
}

float:right により、リストグループ項目内のコンテンツが右に強制的に寄せられることに注意してください。

  color: #555555;
}

a.list-group-item.active:hover .list-group-item-heading,

a.list-group-item.active .list-group-item-text,
a.list-group-item.active:hover .list-group-item-text,

自定义内容

オンラインでサンプルを見る、この例では、カスタムコンテンツを含むリストグループをデモンストレーションしています。以下に、Bootstrap の CSS に含まれる HTML および CSS コードを示します。

<div class="container">
<div class="row">
  <div class="list-group col-lg-4">
  <a href="../index.html" class="list-group-item active">
    <h4 class="list-group-item-heading">List group item heading</h4>
    <p class="list-group-item-text">...</p>
  </a>
</div>
</div>
</div>

CSS 代码

.list-group-item-heading {
  margin-top: 0;
  margin-bottom: 5px;
}

.list-group-item-text {
  margin-bottom: 0;
  line-height: 1.3;
}

次に、CSS クラスを追加することで、外観と感触を直接カスタマイズします。CSS コードの最初の部分は、ページの上部にいくつかのパディングを追加します。

body {
  padding-top: 70px
  }

次に、以下のCSSコードを追加することで、背景色、フォントの色、テキストの配置、リスト項目のコンテンツのフォントサイズをカスタマイズします。

ul.list-group.col-lg-4 > li {
  background-color: #C952CA;
  color: white;
  text-align: center;
  font-size:125%;
  }

しかし、中央の列の最初のリスト項目を目立たせたい場合は、以下のCSSコードを追加する必要があります。私たちは次を使用します。:first-child疑似要素を使用して、必要なリスト項目にアクセスします。

ul.list-group.col-lg-4 > li.list-group-item:first-child{
  background-color: #64086F;
  font-size: 200%; 
  }

バッジを目立たせるために、以下のCSSコードも追加します。

  .badge {
  background-color: #FAFAD2;
  color:#FF8C00;
  }
