Bootstrap 图标

简介

このチュートリアルでは、Bootstrap 2.0 ツールキットを使用してアイコンを作成する方法を学びます。Bootstrap アイコンは Glyphicons によって提供されています。プロジェクトでこれらのアイコンを使用する場合は、必ず提供してください。Glyphiconsのリンク。

CSSスプライトとして使用

すべてのアイコン画像はまとめてバンドルされ、...を介してbackground-position CSS 属性使用。画像ファイルは glyphicons-halflings.png で、Bootstrap メインフォルダー内の img フォルダーにあります。アイコンのスタイルおよび背景位置は、bootstrap.css の行番号 1168 から 1544 で規定されています。競合を避けるため、すべてのアイコン class は "icon-" をプレフィックスとしていることに注意してください。Bootstrap 2.0 では 120 個のアイコン class が定義されています。

自分のサイトやアプリでアイコンを使用する方法

サイトまたはアプリでアイコンを使うための一般的な構文は次のとおりです：

 <i class="icon_class_name"></i>

其中 "icon_class_name" は bootstrap.css で定義されているアイコンクラスの名前です（例：icon-music、icon-star、icon-user など）。

白色のアイコンを使用したい場合は、追加の icon-white クラスを次のように追加します：

<i class="icon_class_name icon-white"></i>  </i>

アイコンを使用する際に何らかの文字列を伴わせたい場合は、後ろにスペースを追加することを忘れないでください。ボタンや一部のナビゲーションリンクでアイコンを使用する場合にこれが起こる可能性があります。

例：検索フォーム

实例

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="utf-8">
<title>Bootstrap バージョン2.0 における検索アイコンの使用例</title>
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Example of using icons in search form - Bootstrap version 2.0 from w3cschool.cc">
    <meta name="author" content="">

    <!-- Le styles -->
    <link href="../bootstrap/twitter-bootstrap-v2/docs/assets/css/bootstrap.css.html" rel="stylesheet">
    <style type="text/css">
        form {
            margin-top: 50px;
        }
    </style>
    <!-- Le HTML5 shim, for IE6-8 support of HTML5 elements -->
    <!--[if lt IE 9]>
    <script src="//html5shim.googlecode.com/svn/trunk/html5.js"></script>
    <![endif]-->

    <!-- Le fav and touch icons -->
    <link rel="shortcut icon" href="../bootstrap/twitter-bootstrap-v2/docs/examples/images/favicon.ico.html">
    <link rel="apple-touch-icon" href="../bootstrap/twitter-bootstrap-v2/docs/examples/images/apple-touch-icon.png.html">
    <link rel="apple-touch-icon" sizes="72x72" href="../bootstrap/twitter-bootstrap-v2/docs/examples/images/apple-touch-icon-72x72.png.html">
    <link rel="apple-touch-icon" sizes="114x114" href="../bootstrap/twitter-bootstrap-v2/docs/examples/images/apple-touch-icon-114x114.png.html">
</head>
<body>
<div class="container">
    <div class="row">
        <div class="span12">
            <form class="well form-search">
                <input type="text" class="input-medium search-query">
<button type="submit" class="btn"><i class="icon-search"></i> 搜索</button>
            </form>
        </div>
    </div>
    <footer>
        <p>&copy; Company 2013</p>
    </footer>
</div>
</body>
</html>
