Bootstrap Dropdown（下拉菜单）

描述

Dropdown（ドロップダウンメニュー）JavaScript プラグインを使用すると、Bootstrap 内のあらゆる要素に Dropdown ドロップダウンメニューを作成できます。导航条、ナビゲーション（タブとピル）その中では、ドロップダウンメニューを作成するための完全なサポートが提供されています。

このプラグインを使用する際に必要なもの

jquery.js と bootstrap-dropdown.js ファイルを参照する必要があります。これらのファイルはどちらも twitter-bootstrap-v2/docs/assets/js フォルダ内にあります。その後、JavaScript を介してドロップダウンメニューを呼び出すことができます。以下の例は、その方法を示しています。

实例

实例

<div class="navbar">
    <div class="navbar-inner">
        <div class="container">
            <ul class="nav">
                <a class="brand" href="../index.html">サンプル</a>
                <li class="active"><a href="../index.html">Home</a></li>
                <li><a href="../index.html">Blog</a></li>
                <li><a href="../index.html">About</a></li>
                <li><a href="../index.html">Contact</a></li>
                <li class="dropdown" id="accountmenu">
                    <a class="dropdown-toggle" data-toggle="dropdown" href="../index.html">Tutorials<b class="caret"></b></a>
                    <ul class="dropdown-menu">
                        <li><a href="../index.html">PHP</a></li>
                        <li><a href="../index.html">MySQL</a></li>
                        <li class="divider"></li>
                        <li><a href="../index.html">JavaScript</a></li>
                        <li><a href="../index.html">HTML5</a></li>
                    </ul>
                </li>
            </ul>
        </div>
    </div>
</div>
<div class="container-fluid">
<h1>Dropdown Example下拉菜单实例</h1>
</div>
<script type="text/javascript" src="../twitter-bootstrap/twitter-bootstrap-v2/docs/assets/js/jquery.js.html"></script>
<script type="text/javascript" src="../twitter-bootstrap/twitter-bootstrap-v2/docs/assets/js/bootstrap-dropdown.js.html"></script>
<script type="text/javascript">
    $(document).ready(function () {
        $('.dropdown-toggle').dropdown();
    });
</script>

オンラインでサンプルを見る

上記の例では、JavaScript プラグインを使用して作成する方法を示しています。导航条上にドロップダウンメニューを作成します。

あなたもまたナビゲーション（タブとピル）上に Dropdown（ドロップダウンメニュー）JavaScript プラグインを適用します。以下の例は、その方法を示しています。

实例

实例

<ul class="nav nav-pills">
    <li class="dropdown all-camera-dropdown">
        <a class="dropdown-toggle" data-toggle="dropdown" href="../index.html">
            Tutorials
            <b class="caret"></b>
        </a>
        <ul class="dropdown-menu">
            <li data-filter-camera-type="all"><a data-toggle="tab" href="../index.html">HTML5</a></li>
            <li data-filter-camera-type="Alpha"><a data-toggle="tab" href="../index.html">PHP</a></li>
            <li data-filter-camera-type="Zed"><a data-toggle="tab" href="../index.html">MySQL</a></li>
            <li data-filter-camera-type="Bravo"><a data-toggle="tab" href="../index.html">JavaScript</a></li>

        </ul>
    </li></ul>
