Bootstrap 缩略图

本章ではBootstrapのサムネイルについて説明します。ほとんどのサイトでは、グリッド内に画像、ビデオ、テキストなどをレイアウトする必要があります。Bootstrapはサムネイルを通じて、これを簡単に行う方法を提供します。Bootstrapを使用してサムネイルを作成する手順は次のとおりです：

  • 画像の周りにclassを追加します.thumbnailの <a> タグ。
  • これにより、4ピクセルのパディングと灰色の境界線が追加されます。
  • マウスを画像の上に置くと、画像の輪郭がアニメーションで表示されます。

カスタムコンテンツを追加する

これで基本的なサムネイルができました。サムネイルにタイトル、段落、ボタンなどのさまざまなHTMLコンテンツを追加できます。具体的な手順は次のとおりです：

  • class 付きの.thumbnail<a> タグを <div> に変更します。
  • その <div> 内には、追加したいものを何でも追加できます。これは <div> であるため、デフォルトのspanベースの命名規則を使用してサイズを調整できます。
  • 複数の画像をグループ化する場合は、それらを順序なしリストに配置し、各リスト項目を左にフロートさせます。
