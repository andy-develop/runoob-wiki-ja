Bootstrap 标签页（Tab）插件

タブ（Tab）はBootstrap 导航元素第1章で紹介しました。いくつかのdata 属性を組み合わせることで、タブインターフェースを簡単に作成できます。このプラグインを使用すると、コンテンツをタブ、ピル型タブ、さらにはドロップダウンメニューのタブに配置できます。

このプラグインの機能を単独で読み込む場合は、次を読み込む必要があります。tab.js。または、ちょうどBootstrap 插件概览一章で述べたように、参照できますbootstrap.js或压缩版的bootstrap.min.js。

用法

タブを有効にするには、次の2つの方法があります。

  • 通过 data 属性：あなたは追加する必要がありますdata-toggle="tab" 或 data-toggle="pill"アンカーテキストリンクの中に。

    添加nav 和 nav-tabs类到ul中で、Bootstrapが適用されます标签样式，添加nav 和 nav-pills类到ul中で、Bootstrapが適用されます胶囊式样式。

    <ul class="nav nav-tabs">
    <li><a href="../index.html" data-toggle="tab">Home</a></li>
    ...
</ul>
  • 通过 JavaScript：JavaScript を使用してタブを有効にできます。次に示すとおりです：
    $('#myTab a').click(function (e) {
  e.preventDefault()
  $(this).tab('show')
})

    以下の例は、さまざまな方法で各タブをアクティブにする方法を示しています：

    // 通过名称选取标签页
$('#myTab a[href="../index.html"]').tab('show')

// 选取第一个标签页
$('#myTab a:first').tab('show')

// 选取最后一个标签页
$('#myTab a:last').tab('show')

// 选取第三个标签页（从 0 开始索引）
$('#myTab li:eq(2) a').tab('show')

事件

次の表は、タブ（Tab）プラグインで使用されるイベントを示しています。これらのイベントは、関数内でフックとして使用できます。

事件描述实例
show.bs.tabこのイベントはタブの表示時にトリガーされますが、新しいタブが表示される前に発生します。それぞれ使用してevent.target 和 event.relatedTargetアクティブなタブと、以前アクティブだったタブを特定します。 
$('a[data-toggle="tab"]').on('show.bs.tab', function (e) {
  e.target // 激活的标签页
  e.relatedTarget // 前一个激活的标签页
})
shown.bs.tabこのイベントはタブの表示時にトリガーされますが、あるタブが表示された後に発生します。それぞれ使用してevent.target 和 event.relatedTargetアクティブなタブと、以前アクティブだったタブを特定します。 
$('a[data-toggle="tab"]').on('shown.bs.tab', function (e) {
  e.target // 激活的标签页
  e.relatedTarget // 前一个激活的标签页
})
