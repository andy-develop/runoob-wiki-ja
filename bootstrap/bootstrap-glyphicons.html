Bootstrap 字体图标(Glyphicons)

この章では、フォントアイコン（Glyphicons）について説明し、いくつかの例を通じてその使用方法を理解します。Bootstrapには200種類以上のフォント形式のグリフがバンドルされています。まず、フォントアイコンとは何かを理解しましょう。

フォントアイコンとは何ですか？

フォントアイコンは、Web プロジェクトで使用されるアイコンフォントです。ただし、Glyphicons Halflings商用ライセンスが必要ですが、プロジェクトベースの Bootstrap を通じて、これらのアイコンを無料で使用できます。

アイコンの作者への感謝の意を表すため、使用時に GLYPHICONS ウェブサイトへのリンクを追加してください。

フォントアイコンを取得する

私たちはすでに环境安装この章では、Bootstrap 3.x バージョンをダウンロードし、そのディレクトリ構造を理解しました。fontsフォルダー内にはフォントアイコンがあり、以下のファイルが含まれています。

  • glyphicons-halflings-regular.eot
  • glyphicons-halflings-regular.svg
  • glyphicons-halflings-regular.ttf
  • glyphicons-halflings-regular.woff

関連するCSSルールは、次のように書かれていますdistフォルダー内の css フォルダー内のbootstrap.cssとbootstrap-min.css文件上。

CSSルールの説明

以下のCSSルールはglyphiconクラスを構成します。

@font-face { font-family: 'Glyphicons Halflings'; src: url('../fonts/glyphicons-halflings-regular.eot'); src: url('../fonts/glyphicons-halflings-regular.eot?#iefix') format('embedded-opentype'), url('../fonts/glyphicons-halflings-regular.woff') format('woff'), url('../fonts/glyphicons-halflings-regular.ttf') format('truetype'), url('../fonts/glyphicons-halflings-regular.svg#glyphicons_halflingsregular') format('svg'); } .glyphicon { position: relative; top: 1px; display: inline-block; font-family: 'Glyphicons Halflings'; -webkit-font-smoothing: antialiased; font-style: normal; font-weight: normal; line-height: 1; -moz-osx-font-smoothing: grayscale; }

したがって、font-faceルールは実際にはglyphiconsが見つかる場所でfont-familyとその場所を宣言しています。

.glyphicon`class` では、上部から1pxオフセットした相対位置を宣言し、`inline-block` として表示し、フォントを宣言し、`font-style` と `font-weight` を `normal` に指定し、行の高さを1に設定します。さらに、使用して-webkit-font-smoothing: antialiasedと-moz-osx-font-smoothing: grayscale;クロスブラウザの一貫性を獲得します。

そして、ここにある

.glyphicon:empty {
  width: 1em;
}

のは空のglyphiconです。

ここには 200 個のクラスがあり、各クラスは 1 つのアイコンに対応しています。これらのクラスの一般的な形式は次のとおりです。

.glyphicon-keyword:before {
  content: "hexvalue";
}

例えば、使用する user アイコンの class は次のとおりです。

.glyphicon-user:before {
  content: "\e008";
}

用法

アイコンを使用するには、以下のコードを使用するだけです。アイコンとテキストの間に適切なスペースを確保してください。

<span class="glyphicon glyphicon-search"></span>

フォントアイコンをカスタマイズする

フォントアイコンの使用方法を説明しました。次に、フォントアイコンのカスタマイズ方法を見てみましょう。

上記の例から始めて、フォントサイズ、色の変更、およびテキストシャドウの適用によってアイコンをカスタマイズします。

以下は開始時のコードです。

<button type="button" class="btn btn-primary btn-lg">
  <span class="glyphicon glyphicon-user"></span> User
</button>

効果は次のようになります。

フォントサイズをカスタマイズする

アイコンのフォントサイズを増減することで、アイコンを大きくしたり小さくしたりできます。

<button type="button" class="btn btn-primary btn-lg" style="font-size: 60px">
  <span class="glyphicon glyphicon-user"></span> User
</button>

フォントの色をカスタマイズする

<button type="button" class="btn btn-primary btn-lg" style="color: rgb(212, 106, 64);">
  <span class="glyphicon glyphicon-user"></span> User
</button>

テキストシャドウを適用する

<button type="button" class="btn btn-primary btn-lg" style="text-shadow: black 5px 3px 3px;">
  <span class="glyphicon glyphicon-user"></span> User
</button>
