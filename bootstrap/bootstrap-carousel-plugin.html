Bootstrap 轮播（Carousel）插件

Bootstrapカルーセル（Carousel）プラグインは、サイトにスライダーを追加するための柔軟でレスポンシブな方法です。さらに、コンテンツも十分に柔軟で、画像、インラインフレーム、ビデオ、その他お好みのあらゆるタイプのコンテンツを配置できます。

このプラグインの機能を単独で参照したい場合は、以下を参照する必要があります。carousel.js。或者，正如 → 。あるいは、ちょうど…のようにBootstrap 插件概览一章で述べたように、参照することができます。bootstrap.js或压缩版的bootstrap.min.js。

用法

  • 通过 data 属性：data属性を使用すると、カルーセル（Carousel）の位置を簡単に制御できます。
    • 属性data-slide接受关键字prev 或 next、現在の位置に対するスライドの位置を変更するために使用します。
    • 使用data-slide-toカルーセルに生のスライドインデックスを渡すために使用し、data-slide-to="2"スライダーを特定のインデックスに移動します。インデックスは0から始まります。
    • data-ride="carousel"属性は、ページ読み込み時にカルーセルのアニメーションを開始することを示すために使用します。
  • 通过 JavaScript：カルーセル（Carousel）はJavaScriptから手動で呼び出すことができます。以下に示すとおりです：
    $('.carousel').carousel()

选项

一部のオプションは、data属性またはJavaScriptを介して渡されます。次の表にこれらのオプションを示します：

选项名称类型/默认值Data 属性名描述
intervalnumber
默认值：5000		data-interval各項目間の遅延時間を自動的に循環します。falseの場合、カルーセルは自動的に循環しません。
pausestring
默认值："hover"		data-pauseマウスが入るとカルーセルの循環を一時停止し、マウスが離れるとカルーセルの循環を再開します。
wrapboolean
默认值：true		data-wrap轮播是否连续循环。 → カルーセルが連続してループするかどうか。

方法

以下は、カルーセル（Carousel）プラグインで役立つメソッドの一部です：

方法描述实例
.carousel(options)カルーセルをオプションのoptionsオブジェクトで初期化し、項目の循環を開始します。 
$('#identifier').carousel({
    interval: 2000
})
.carousel('cycle')カルーセル項目を左から右へ循環させます。 
$('#identifier').carousel('cycle')
.carousel('pause')停止轮播循环项目。 → カルーセルのループ項目を停止します。 
$('#identifier').carousel('pause')
.carousel(number)カルーセルを特定のフレームに循環させます（0から始まり、配列と同様です）。 
$('#identifier').carousel(number)
.carousel('prev')前の項目へ循環します。 
$('#identifier').carousel('prev')
.carousel('next')次の項目へ循環します。 
$('#identifier').carousel('next')

事件

次の表に、カルーセル（Carousel）プラグインで使用されるイベントを示します。これらのイベントは関数内でフックとして使用できます。

事件描述实例
slide.bs.carouselslideインスタンスメソッドが呼び出されたときに、このイベントが即座に発生します。 
$('#identifier').on('slide.bs.carousel', function () {
    // 执行一些动作...
})
slid.bs.carouselカルーセルがスライドのトランジション効果を完了したときに、このイベントがトリガーされます。 
$('#identifier').on('slid.bs.carousel', function () {
    // 执行一些动作...
})
