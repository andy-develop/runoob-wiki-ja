Bootstrap グリッドシステムの例：中型および大型デバイス

に例：水平スタックでは、既に基本的なグリッドシステムを見てきました。ここでは、2つのdivを使用し、ビューポート幅の中央でそれらを50%/50%に分割します。

<div class="col-md-6">....</div>
<div class="col-md-6">....</div>

ただし、大規模なデバイスでは、最終的に33%/66%に設計します。したがって、ブレークポイントで列の幅を変更できるように準備する必要があります。

<div class="col-md-6 col-lg-4">....</div>
<div class="col-md-6 col-lg-8">....</div>

さて、Bootstrapは中規模デバイスでは、次のものが付いたmdクラスを探して使用します。大規模デバイスでは、次のものが付いたlgのクラスを使用します。この例では、2 つの div が 50%/50% の分割から 33%/66% に変わります。下の例を確認して検証してください。（ここでは、各列にスタイルを個別に定義していますが、このようにする必要はありません。）
