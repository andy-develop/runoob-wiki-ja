Bootstrap 下拉菜单（Dropdown）插件

Bootstrap 下拉菜单この章ではドロップダウンメニューについて説明しましたが、インタラクション部分には触れていません。この章では、ドロップダウンメニューのインタラクションについて具体的に説明します。ドロップダウンメニュー（Dropdown）プラグインを使用すると、任意のコンポーネント（ナビゲーションバー、タブ、ピル型ナビゲーションメニュー、ボタンなど）にドロップダウンメニューを追加できます。

このプラグインの機能を単独で参照したい場合は、以下を参照する必要があります。dropdown.js。または、ちょうどBootstrap 插件概览第1章で述べたように、引用することができます。bootstrap.jsまたは圧縮版のbootstrap.min.js。

用法

ドロップダウン（Dropdown）プラグインの非表示コンテンツを切り替えることができます：

  • 通过 data 属性：リンクまたはボタンに追加data-toggle="dropdown"ドロップダウンを切り替えるには、次のようにします：
    <div class="dropdown">
  <a data-toggle="dropdown" href="../index.html">下拉菜单（Dropdown）触发器</a>
  <ul class="dropdown-menu" role="menu" aria-labelledby="dLabel">
    ...
  </ul>
</div>

    リンクを完全な状態に保つ必要がある場合（ブラウザでJavaScriptが無効な場合に有用）、次を使用してください。data-target属性代替href="../index.html"：

    <div class="dropdown">
  <a id="dLabel" role="button" data-toggle="dropdown" data-target="#" href="../page.html">
    下拉菜单（Dropdown） <span class="caret"></span>
  </a>


  <ul class="dropdown-menu" role="menu" aria-labelledby="dLabel">
    ...
  </ul>
</div>
  • 通过 JavaScript：JavaScriptを介してドロップダウンメニューの切り替えを呼び出すには、次の方法を使用してください：
    $('.dropdown-toggle').dropdown()

方法

ドロップダウンメニューの切り替えには、表示または非表示を切り替える簡単な方法があります。

$().dropdown('toggle')
