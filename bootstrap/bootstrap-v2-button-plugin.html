Bootstrap Button（按钮）

描述

Bootstrap Button（ボタン）JavaScript プラグインを使用すると、ボタンの機能を強化できます。ボタンの状態を制御したり、コンポーネントのボタングループ（ツールバーなど）を作成したりできます。

必須のものは何ですか

jquery.js と bootstrap-button.js の2つのJavaScriptファイルを参照する必要があります。これらは両方とも docs/assets/js フォルダ内にあります。

如何使用它

このプラグインは、JavaScript を一切記述せずマークアップのみで使用することも、JavaScript を使用してボタンを有効にすることもできます。

实例

JavaScript でボタンを有効にする

JavaScript でボタンを有効にするには、以下の JavaScript コードを使用してください。ここで、' .nav-tabs ' はボタンを含む div のクラスです。

$('.nav-tabs').button()

方法

このプラグインにはいくつかのメソッドがあります。ここでは使用コードに基づいて説明します。

$().button('toggle')

<button class="btn" data-toggle="button" >…</button>

このメソッドはボタンの状態を切り替えます。ボタンがアクティブ化されたときの状態と外観を与えます。'data-toggle="button"' を使用すると、自動的にボタンをアクティブ状態に切り替えます。

$().button('loading')

<button class="btn" data-loading-text="loading stuff..." >...</button>

このメソッドはボタンの状態を loading に設定します。つまり、ボタンを無効状態にし、テキスト内容を loading に切り替えます。'data-loading-text' 属性を使用することで、ボタン要素に loading テキストを定義できます。

Firefox ブラウザを使用している場合、ページ読み込み後に無効状態が自動的に解除されないことがあります。この問題を回避するには、'autocomplete="off"' を使用してください。

$().button('reset')

このメソッドはボタンの状態をリセットし、ボタン上のテキストを元の値に戻します。

$().button(string)

<button class="btn" data-loading-text="loading stuff..." >...</button>

このメソッドはボタンの状態をリセットし、ボタン上のテキストを渡された値にリセットします。

<button class="btn" data-complete-text="finished!" >...</button>
<script>
    $('.btn').button('complete')
</script>

ここをクリックして、本チュートリアルで使用するすべてのHTML、CSS、JSおよび画像ファイルをダウンロードしてください。
