Bootstrap Typeahead

简介

このチュートリアルでは、Bootstrapを使用してTypeaheadを作成する方法を説明します。

Typeaheadはユーザーがフォームに入力する際に、ヒントやデータを提供します。

Bootstrapを使用すると、見栄えの良いTypeaheadを作成でき、しかも拡張が容易なため、大きな変更を加えることなく機能を強化できます。

必須事項

TypeaheadはBootstrap 2.xバージョンの製品であるため、このチュートリアルではBootstrap 2.0を使用してテストしています。

jquery.js と bootstrap-typeahead.js の 2 つの JavaScript ファイルを参照する必要があります。どちらも docs/assets/js/ 内にあります。

以下の例は、JavaScriptを記述せずにマークアップのみでTypeaheadを作成する方法を示しています。

实例

实例

<div class="well">
    <input type="text" class="span3" style="margin: 0 auto;" data-provide="typeahead" data-items="4" data-source="[&quot;Ahmedabad&quot;,&quot;Akola&quot;,&quot;Asansol&quot;,&quot;Aurangabad&quot;,&quot;Bangaluru&quot;,&quot;Baroda&quot;,&quot;Belgaon&quot;,&quot;Berhumpur&quot;,&quot;Calicut&quot;,&quot;Chennai&quot;,&quot;Chapra&quot;,&quot;Cherapunji&quot;]">
</div>
<script src="../bootstrap/twitter-bootstrap-v2/docs/assets/js/jquery.js.html"></script>
<script src="../bootstrap/twitter-bootstrap-v2/docs/assets/js/bootstrap-typeahead.js.html"></script>

JavaScriptでtypeaheadを呼び出し、さまざまなオプションを使用して機能を強化できます。JavaScriptでtypeaheadを呼び出す方法は次のとおりです：

$('#example').typeahead()
ここで「example」は、typeaheadを適用するinputフィールドのidです。

实例

实例

<div class="well">
    <input type="text" class="span3" id="search" data-provide="typeahead" data-items="4" />
</div>
<script src="../bootstrap/twitter-bootstrap-v2/docs/assets/js/jquery.js.html"></script>
<script src="../bootstrap/twitter-bootstrap-v2/docs/assets/js/bootstrap-typeahead.js.html"></script>
<script>
    var subjects = ['PHP', 'MySQL', 'SQL', 'PostgreSQL', 'HTML', 'CSS', 'HTML5', 'CSS3', 'JSON'];
    $('#search').typeahead({source: subjects})
</script>

选项

さまざまなTypeaheadオプションを使用できます。以下で各オプションについて詳しく説明します：

source: クエリを含むときに表示する値のデータソースを指定します。値のタイプは配列（array）で、デフォルト値は [ ] です。

items: クエリ時に表示する項目の最大数を指定します。データ型はnumberで、デフォルト値は8です。

matcherクエリが項目と一致するかどうかを決定します。テスト対象のクエリ項目である単一のパラメータを持ちます。現在のクエリは this.query でアクセスします。クエリが一致することを示すブール値 true を返します。データ型はfunctionです。デフォルトでは大文字と小文字を区別しません。

sorter: 結果を自動的に分類するために使用します。typeaheadインスタンスのスコープを持つエントリという単一のパラメータを受け取ります。現在のクエリは this.query でアクセスします。データ型は function です。デフォルト値は完全一致で、その他の値では大文字と小文字を区別する、または区別しないを指定できます。

highlighter: 結果を自動的にハイライト表示するために使用します。typeaheadインスタンスのスコープを持つエントリという単一のパラメータを受け取ります。データ型は function です。デフォルトでは、すべてのデフォルトの一致項目がハイライト表示されます。
