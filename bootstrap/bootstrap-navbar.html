Bootstrap 导航栏

ナビゲーションバーは優れた機能であり、Bootstrap サイトの際立った特徴です。ナビゲーションバーは、アプリケーションやサイト内でナビゲーションヘッダーとして機能するレスポンシブな基本コンポーネントです。ナビゲーションバーはモバイルデバイスのビューでは折りたたまれ、利用可能なビューポート幅が増加するにつれて水平に展開します。Bootstrap ナビゲーションバーの中核では、ナビゲーションバーはサイト名と基本的なナビゲーション定義スタイルで構成されています。

デフォルトのナビゲーションバー

デフォルトのナビゲーションバーを作成する手順は次のとおりです。

  • <nav> タグに class を追加する.navbar、.navbar-default。
  • 上記の要素に追加するrole="navigation"、アクセシビリティを向上させるのに役立ちます。
  • <div> 要素に見出しクラスを追加します.navbar-header、内部には class を持つnavbar-brandの <a> 要素。これにより、テキストが一回り大きく表示されます。
  • ナビゲーションバーにリンクを追加するには、class を付けたものを追加するだけです。.nav、.navbar-navの順序なしリスト（ul）でよい。

以下の例はこれを示しています：

实例

<nav class="navbar navbar-default" role="navigation"> <div class="container-fluid"> <div class="navbar-header"> <a class="navbar-brand" href="#">菜鸟教程</a> </div> <div> <ul class="nav navbar-nav"> <li class="active"><a href="#">iOS</a></li> <li><a href="#">SVN</a></li> <li class="dropdown"> <a href="#" class="dropdown-toggle" data-toggle="dropdown"> Java <b class="caret"></b> </a> <ul class="dropdown-menu"> <li><a href="#">jmeter</a></li> <li><a href="#">EJB</a></li> <li><a href="#">Jasper Report</a></li> <li class="divider"></li> <li><a href="#">分离的链接</a></li> <li class="divider"></li> <li><a href="#">另一个分离的链接</a></li> </ul> </li> </ul> </div> </div> </nav>

レスポンシブなナビゲーションバー

ナビゲーションバーにレスポンシブ特性を追加するには、折りたたむコンテンツを class 付きのものでラップする必要があります。.collapse、.navbar-collapseの <div> 内に配置します。折りたたまれたナビゲーションバーは、実際には class を持つものです。.navbar-toggleと2つの data- 要素を持つボタンです。1つ目はdata-toggle、JavaScript にボタンに対して何を行う必要があるかを伝えるためのもので、2つ目はdata-target、どの要素に切り替えるかを示します。class を持つ3つの.icon-barの <span> が、いわゆるハンバーガーボタンを作成します。これらは切り替わります。.nav-collapse<div> 内の要素です。上記の機能を実装するには、次を含める必要があります。Bootstrap 折叠（Collapse）插件。
