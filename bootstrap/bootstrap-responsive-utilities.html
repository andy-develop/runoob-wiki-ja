Bootstrap 响应式实用工具

Bootstrapは、モバイルフレンドリーな開発をより迅速に実現するためのいくつかのヘルパークラスを提供しています。これらはメディアクエリと組み合わせることで、大型、小型、中型デバイスに応じてコンテンツの表示と非表示を切り替えることができます。

これらのツールは慎重に使用して、同じサイト内でまったく異なるバージョンを作成しないようにしてください。レスポンシブユーティリティは現在、ブロックとテーブルの切り替えにのみ対応しています。

v3.2.0以降、.visible-*-*形式のクラスには、各画面サイズに対して3つのバリエーションがあり、それぞれCSSの異なるdisplayプロパティに対応しています。一覧は次のとおりです。

类组 CSS display
.visible-*-block display: block;
.visible-*-inline display: inline;
.visible-*-inline-block display: inline-block;

したがって、超小画面（xs）を例にとると、使用可能な .visible-*-* クラスは、.visible-xs-block、.visible-xs-inline、.visible-xs-inline-block です。

.visible-xs、.visible-sm、.visible-md および .visible-lg クラスも同時に存在します。ただし、v3.2.0 バージョンからは非推奨となっています。<table> 関連の要素の特別な場合を除き、これらは .visible-*-block とほぼ同じです。
