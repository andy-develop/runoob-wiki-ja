描述

このチュートリアルでは、Bootstrap を使用して折りたたみ可能なコンポーネントを作成する方法を学びます。

何が必要か

jquery.js と bootstrap-collapse.js を参照する必要があります。これらの 2 つの JavaScript ファイルはどちらも docs/assets/js フォルダ内にあります。

大量のJavaScriptを書いたり、JavaScriptを呼び出したりせずに、折りたたみ可能なコンポーネントを作成できます。

解释

ここでは注意すべき点が3つあります。第一に、追加します。data-toggle="collapse"コンポーネントを展開または折りたたむためにクリックするリンクに。

第二に、追加しますhref或一个data-target親コンポーネントに属性を追加します。その値は子コンポーネントのidです。

第三に、追加しますdata-parentこの属性は、アコーディオン式の効果を作成するために使用されます。data-parent属性の値は、アコーディオンコンポーネント全体を保持するメインコンテナdivのid属性の値と同じです。アコーディオンほど複雑ではないシンプルな折りたたみコンポーネントを作成したい場合は、この属性を追加する必要はありません。

JavaScript による呼び出し

次のコードを使用して、JavaScriptで折りたたみをトリガーできます。

 $(".collapse").collapse()

オプション、メソッド、イベント

ここでは、Bootstrap Collapsible JavaScriptプラグインによって使用されるいくつかのオプション、メソッド、イベントを紹介します。具体的には以下のとおりです。

选项

parent:値の型はSelectorです。デフォルト値はfalseです。親要素が表示されている場合、その親要素の下にあるすべての折りたたみ可能な要素は閉じています。

toggle:値の型は Boolean です。デフォルト値は true です。呼び出されると、すべての折りたたみ可能な要素を切り替えます。

toggle:値の型は Boolean です。デフォルト値は true です。呼び出されると、すべての折りたたみ可能な要素を切り替えます。

方法

.collapse(options):折りたたみ可能なコンテンツをトリガーします。オプションのoptionオブジェクトを受け入れます。

.collapse('toggle'):折りたたみ可能なページ要素を表示または非表示にします。

.collapse('show'):折りたたみ可能なページ要素を表示します。

.collapse(hide):折りたたみ可能なページ要素を非表示にします。

事件

show:当 showインスタンスメソッドが呼び出された後、このイベントが直ちにトリガーされます。

shown:折りたたみ可能なページ要素が表示された後（CSSトランジション効果も完了した後）、このイベントがトリガーされます。

hide:当 hideインスタンスメソッドが呼び出された後、このイベントが直ちにトリガーされます。

hidden:折りたたみ可能なページ要素がユーザーに非表示になった後（CSSトランジション効果も完了した後）、このイベントがトリガーされます。
