Bootstrap CSS 概览

この章では、Bootstrapの基盤構造の主要部分について説明します。Web開発をより良く、より速く、より強固にするためのベストプラクティスも含まれます。

HTML 5 ドキュメントタイプ（Doctype）

Bootstrapは一部のHTML5要素とCSSプロパティを使用しています。これらを正常に機能させるには、HTML5のドキュメントタイプ（Doctype）を使用する必要があります。そのため、Bootstrapプロジェクトの先頭に以下のコードスニペットを含めてください。

<!DOCTYPE html>
<html>
....
</html>

Bootstrapで作成したWebページの先頭でHTML5のドキュメントタイプ（Doctype）を使用しない場合、ブラウザの表示が一貫しないという問題に直面する可能性があります。特定の状況下での不一致により、コードがW3C標準の検証を通過できない可能性もあります。

モバイルデバイス優先

モバイルファーストは、Bootstrap 3の最も顕著な変更点です。

以前のBootstrapバージョン（2.xまで）では、プロジェクト全体がモバイルデバイスを適切にサポートするために、別のCSSを手動で参照する必要がありました。

現在は異なります。Bootstrap 3のデフォルトCSS自体がモバイルデバイスを適切にサポートしています。

Bootstrap 3の設計目標は、モバイルデバイスを優先し、その後にデスクトップデバイスを対象とすることです。これは実際には非常にタイムリーな転換です。現在、ますます多くのユーザーがモバイルデバイスを使用しているためです。

Bootstrapで開発したWebサイトをモバイルデバイスに適したものにし、適切な描画とタッチスクリーンのズームを保証するには、Webページのheadセクションに以下を追加する必要があります。viewport metaタグは、次のようになります：

<meta name="viewport" content="width=device-width, initial-scale=1.0">

width属性はデバイスの幅を制御します。あなたのWebサイトが異なる画面解像度のデバイスで閲覧されると仮定すると、それを次のように設定します。device-widthこれにより、さまざまなデバイスで正しく表示されることを確認できます。

initial-scale=1.0Webページの読み込み時に1:1の比率で表示され、ズームが一切行われないことを保証します。

モバイルデバイスのブラウザ上では、viewport meta标签添加user-scalable=noこれにより、ズーム（zooming）機能を無効にできます。

通常の場合、maximum-scale=1.0user-scalable=noと一緒に使用します。このようにズーム機能を無効にすると、ユーザーは画面をスクロールするだけで、Webサイトがよりネイティブアプリのように見えます。

注意：この方法をすべてのウェブサイトで推奨するわけではありません。ご自身の状況に応じて判断してください！

<meta name="viewport" content="width=device-width, 
                                     initial-scale=1.0, 
                                     maximum-scale=1.0, 
                                     user-scalable=no">

响应式图像

<img src="....html" class="img-responsive" alt="响应式图像">

通过添加img-responsiveclassを使用すると、Bootstrap 3の画像がレスポンシブレイアウトをより適切にサポートできるようになります。

次に、このclassにどのようなCSSプロパティが含まれているかを見てみましょう。

以下のコードで確認できます：img-responsiveclassは画像にmax-width: 100%; と height: auto; のプロパティを付与し、画像が比率を保ったまま、親要素のサイズを超えないようにスケーリングできます。

.img-responsive {
  display: block;
  height: auto;
  max-width: 100%;
}

これは関連する画像が次のように表示されることを示しますblock要素のdisplayプロパティをblockに設定すると、ブロックレベル要素として表示されます。

设置height:auto、関連要素の高さはブラウザによって異なります。

设置max-width100%に設定すると、widthプロパティで指定された幅がすべて上書きされます。これにより、画像がレスポンシブレイアウトをより適切にサポートできるようになります。

.img-responsive クラスを使用した画像を水平方向に中央揃えにする必要がある場合は、.text-center ではなく .center-block クラスを使用してください。

グローバル表示、タイポグラフィ、およびリンク

基本的なグローバル表示

Bootstrap 3 使用body {margin: 0;}body のマージンを削除します。

以下のbodyに関する設定を見てください：

body {
  font-family: "Helvetica Neue", Helvetica, Arial, sans-serif;
  font-size: 14px;
  line-height: 1.428571429;
  color: #333333;
  background-color: #FFFFFF;
}

最初のルールは、bodyのデフォルトのフォントスタイルを次のように設定します。"Helvetica Neue", Helvetica, Arial, sans-serif。

2番目のルールは、テキストのデフォルトのフォントサイズを14ピクセルに設定します。

3番目のルールは、デフォルトの行の高さを1.428571429に設定します。

4番目のルールは、デフォルトのテキストの色を#333333に設定します。

最後のルールは、デフォルトの背景色を白に設定します。

排版

@font-family-base、@font-size-base、@line-height-base の各プロパティをタイポグラフィスタイルとして使用します。

链接样式

@link-colorプロパティを使用して、グローバルなリンクの色を設定します。

リンクのデフォルトスタイルについては、次のように設定します：

a:hover,
a:focus {
  color: #2A6496;
  text-decoration: underline;
}

a:focus {
  outline: thin dotted #333;
  outline: 5px auto -webkit-focus-ring-color;
  outline-offset: -2px;
}

そのため、マウスをリンクにホバーしたとき、またはクリックしたリンクでは、色が#2a6496に設定されます。同時に、下線が表示されます。

さらに、クリックしたリンクには、色コード#333の細い点線のアウトラインが表示されます。別のルールでは、アウトラインを5ピクセル幅に設定し、webkitベースのブラウザには-webkit-focus-ring-colorブラウザ拡張があります。アウトラインのオフセットは-2ピクセルに設定されています。

これらすべてのスタイルは、scaffolding.lessにあります。

クロスブラウザの不整合を回避

Bootstrap 使用Normalizeクロスブラウザの一貫性を確立するために。

Normalize.cssは非常に小さなCSSファイルであり、HTML要素のデフォルトスタイルにおいて、より優れたクロスブラウザ間の一貫性を提供します。

容器（Container）

<div class="container">
  ...
</div>

Bootstrap 3 のcontainerclassはページ上のコンテンツを包み込むために使用されます。bootstrap.cssファイル内のこれを一緒に見てみましょう。.container class。

.container {
   padding-right: 15px;
   padding-left: 15px;
   margin-right: auto;
   margin-left: auto;
}

上記のコードにより、containerの左右の外側マージン（margin-right、margin-left）をブラウザに決定させます。

内側のパディング（padding）が固定幅であるため、デフォルトではコンテナをネストできないことに注意してください。

.container:before,
.container:after {
  display: table;
  content: " ";
}

これにより擬似要素が生成されます。設定：displayためにtable匿名のtable-cellと新しいブロックフォーマットコンテキストを作成します。:before擬似要素は上マージンの崩れを防ぎ、:after疑似要素でフロートをクリアします。

如果conteneditable属性がHTMLに表示されると、一部のOperaのバグにより、上記の要素の周囲にスペースが作成されます。これは、次を使用することで回避できます。content: " "来修复。

.container:after {
  clear: both;
}

これにより疑似要素が作成され、すべてのコンテナがすべてのフローティング要素を含むことが保証されます。

Bootstrap 3 CSSにはレスポンシブ対応のメディアクエリがあり、さまざまなメディアクエリの閾値範囲内でcontainerにmax-widthを設定し、グリッドシステムに一致させています。

@media (min-width: 768px) {
   .container {
      width: 750px;
}
