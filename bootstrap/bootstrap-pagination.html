Bootstrap 分页

この章では、Bootstrap がサポートするページネーション機能について説明します。ページネーション（Pagination）は順序なしリストであり、Bootstrap は他のインターフェース要素と同じようにページネーションを処理します。

分页（Pagination）

次の表に、Bootstrap が提供するページネーションを処理するクラスを示します。

Class描述示例代码
.paginationこのクラスを追加すると、ページにページネーションが表示されます。 
<ul class="pagination">
  <li><a href="../index.html">&laquo;</a></li>
  <li><a href="../index.html">1</a></li>
  .......
</ul>
.disabled, .activeリンクは、～を使用してカスタマイズできます。.disabledクリックできないリンクを定義するには、使用します。.active現在のページを示すために。 
<ul class="pagination">
  <li class="disabled"><a href="../index.html">&laquo;</a></li>
  <li class="active"><a href="../index.html">1<span class="sr-only">(current)</span></a></li>
  .......
</ul>
.pagination-lg, .pagination-smこれらのクラスを使用して、異なるサイズの項目を取得します。 
<ul class="pagination pagination-lg">...</ul>
<ul class="pagination">...</ul>
<ul class="pagination pagination-sm">...</ul>

翻页（Pager）

ユーザーにナビゲーションを提供するためのシンプルなページネーションリンクを作成したい場合は、ページャーを使用して実現できます。ページネーションリンクと同様に、ページャーも順序なしリストです。デフォルトでは、リンクは中央揃えで表示されます。次の表に、Bootstrap がページャーを処理するクラスを示します。

Class描述示例代码
.pagerこのクラスを追加すると、ページャーリンクを取得できます。 
<ul class="pager">
  <li><a href="../index.html">Previous</a></li>
  <li><a href="../index.html">Next</a></li>
</ul>
.previous, .next使用 class.previousリンクを左揃えにするには、～を使用します。.nextリンクを右揃えにします。 
<ul class="pager">
  <li class="previous"><a href="../index.html">&larr; Older</a></li>
  <li class="next"><a href="../index.html">Newer &rarr;</a></li>
</ul>
.disabledこのクラスを追加すると、対応するボタンを無効に設定できます。 
<ul class="pager">
  <li class="previous disabled"><a href="../index.html">&larr; Older</a></li>
  <li class="next"><a href="../index.html">Newer &rarr;</a></li>
</ul>
