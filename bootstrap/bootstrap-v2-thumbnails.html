Bootstrap 缩略图

简介

このチュートリアルでは、Bootstrapを使用してサムネイル（つまり画像、ビデオ、テキストのグリッド）を作成する方法を説明します。

サムネイルにはシンプルで柔軟なマークアップがあります。また、既存のBootstrap CSSクラス（.span2や.span3など）を使用して、サムネイルの幅と高さを設定できます。

なぜサムネイルを使用するのか

Webでユーザーエクスペリエンスを作成する場合、通常は画像または動画のグリッドを作成する必要があります。良い例としては、製品画像を表示する必要がある企業のWebサイトがあり、そのような場合にはサムネイルが使用されることがあります。

デフォルトのサムネイルインスタンスを使用する

实例

<div class="container">
    <ul class="thumbnails">
        <li class="span3">
            <a href="../php/php-tutorial.html" class="thumbnail">
                <img src="../bootstrap/php-thumb.png.html" alt="php tutorial" width="260" height="180" />
            </a>
        </li>
        <li class="span4">
            <a href="../sql/sql-tutorial.html" class="thumbnail">
                <img src="../bootstrap/mysql-thumb.png.html" alt="mysql tutorial" width="300" height="180" />
            </a>
        </li>
        <li class="span5">
            <a href="../js/js-tutorial.html" class="thumbnail">
                <img src="../bootstrap/js-thumb.png.html" alt="js tutorial" width="380" height="180" >
            </a>
        </li>
    </ul>
    <hr>
</div> <!-- /container -->

オンラインでサンプルを見る

デフォルトのサムネイルをカスタマイズして、段落、見出しリスト、またはその他のタイプのHTMLコンテンツを追加できます。

                </div>
            </div>
        </li>
        <li class="span5">
            <div class="thumbnail">
                <img src="../bootstrap/shoes2.jpg.html" alt="product 2">
                <div class="caption">

    </footer>

</div> <!-- /container -->
