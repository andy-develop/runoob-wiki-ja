简介

このチュートリアルでは、Bootstrap 2.0 ツールキットを使用してフォームを作成する方法を学びます。

Bootstrap はすでに input、textarea、select などのフォームコントロールのスタイルを定義しており、リストやチェックボックスをサポートし、無効なフォームコントロールのスタイルも定義しています。各フォームコントロールのエラー、警告、成功状態も含まれます。

バージョン 2.0 以降、Bootstrap は4種類のフォームレイアウトを提供しています -

  • 垂直（デフォルト）
  • 搜索
  • 内联
  • 水平

前のバージョンの Bootstrap では、フォームレイアウトはデフォルトで水平レイアウトでした。しかし、バージョン 2.0 以降は、垂直レイアウトがデフォルトです。

垂直フォームレイアウトを作成する

bootstrap.css 内の .form-vertical クラスには、Bootstrap のデフォルトフォームレイアウト（つまり垂直フォーム）のスタイルが定義されています。ただし、これはデフォルトのフォームレイアウトであるため、デフォルトレイアウトでフォームを作成する場合は、.form-vertical クラスを指定する必要はありません。次の例は、Bootstrap 2.0 のデフォルトフォームレイアウトで作成されたフォームを示しています。

.well クラスはフォームのコンテナを作成するために使用されます（もちろん、他の用途もあります）。このクラスは bootstrap.css の1650行から1663行にあります。このレイアウトでは、入力ボックスはブロックレベルの（block level）。次の例は、Bootstrap を使用してデフォルトのフォームレイアウトを作成する方法を示しています。

实例

<form class="well">
<label>标签名称</label>
    <input type="text" class="span3" placeholder="Type something…">
<span class="help-inline">相关帮助文档 ！</span>
    <label class="checkbox">
<input type="checkbox"> 选中我
    </label>
<button type="submit" class="btn">提交</button>
</form>

検索フォームレイアウトを作成する

bootstrap.css 内の行番号 962 から 1003（これらの行には .form-inline のスタイルも含まれています）にある .form-search クラスを使用して、検索フォームを作成します。このレイアウトでは、入力ボックスはブロックレベルの（block level）。以下は一例です：

实例

<form class="well form-search">
    <input type="text" class="input-medium search-query">
<button type="submit" class="btn">搜索</button>
</form>

インラインフォームレイアウトを作成する

bootstrap.css の962行から1003行にある .form-inline クラス（これらの行には .form-search のスタイルも含まれています）を使用して、インラインフォームを作成します。このレイアウトでは、入力ボックスはインライン（inline）。以下は一例です：

实例

<form class="well form-inline">
    <input type="text" class="input-small" placeholder="Email">
    <input type="password" class="input-small" placeholder="Password">
    <label class="checkbox">
<input type="checkbox"> 记住我
    </label>
<button type="submit" class="btn">登录</button>
</form>

水平フォームレイアウトを作成する

bootstrap.css にある .form-horizontal クラスを使用して、水平フォームを作成します。このレイアウトでは、入力ボックスはブロックレベルの（block level）。以下は一例です：

实例

<form class="form-horizontal">
    <fieldset>
<legend>Bootstrap がサポートするコントロール</legend>
        <div class="control-group">
<label class="control-label" for="input01">文本输入</label>
            <div class="controls">
                <input type="text" class="input-xlarge" id="input01">
<p class="help-block">自由形式のテキストに加えて、いくつかのHTML5ベースのテキスト入力はこのように表示されます。</p>
            </div>
        </div>
        <div class="control-group">
<label class="control-label" for="optionsCheckbox">确认框</label>
            <div class="controls">
                <label class="checkbox">
                    <input type="checkbox" id="optionsCheckbox" value="option1">
选中选项，确认此项正确。
                </label>
            </div>
        </div>
        <div class="control-group">
<label class="control-label" for="select01">选择列表</label>
            <div class="controls">
                <select id="select01">
                    <option>something</option>
                    <option>2</option>
                    <option>3</option>
                    <option>4</option>
                    <option>5</option>
                </select>
            </div>
        </div>
        <div class="control-group">
<label class="control-label" for="multiSelect">多选</label>
            <div class="controls">
                <select multiple="multiple" id="multiSelect">
                    <option>1</option>
                    <option>2</option>
                    <option>3</option>
                    <option>4</option>
                    <option>5</option>
                </select>
            </div>
        </div>
        <div class="control-group">
<label class="control-label" for="fileInput">文件上传</label>
            <div class="controls">
                <input class="input-file" id="fileInput" type="file">
            </div>
        </div>
        <div class="control-group">
<label class="control-label" for="textarea">文本区域</label>
            <div class="controls">
                <textarea class="input-xlarge" id="textarea" rows="3"></textarea>
            </div>
        </div>
        <div class="form-actions">
<button type="submit" class="btn btn-primary">保存修改</button>
<button class="btn">取消</button>
        </div>
    </fieldset>
</form>

Bootstrap フォームコントロールのブラウザ状態

入力フィールドがフォーカスを取得したとき、または入力フィールドが無効化されているとき、またはフィールドが読み取り専用のとき、Bootstrap はこれらのスタイルをすでに定義しています。bootstrap.css の677行から697行で、フォーカスを取得した入力ボックスと入力フィールド要素のスタイルが定義されています。

まず、Webkitでは"outline"が":focus"の値として使用されていましたが、現在は"box-shadow"に変わっています。

以下は、フォーカスを取得した入力ボックス、読み取り専用の入力ボックス、無効化された入力ボックス、無効化されたチェックボックス、無効化されたボタンのスタイルがどのように変化するかを示す例です。

实例

<form class="form-horizontal">
    <fieldset>
<legend>Bootstrapがサポートするコントロール</legend>
        <div class="control-group">
<label class="control-label" for="input01">焦点输入</label>
            <div class="controls">
                <input type="text" class="input-xlarge" id="input01">
<p class="help-block">自由形式のテキストに加えて、いくつかのHTML5ベースのテキスト入力はこのように表示されます。</p>
            </div>
        </div>
        <div class="control-group">
<label class="control-label" for="input01">只读输入</label>
            <div class="controls">
                <input type="text" class="input-xlarge" id="input01" readonly="true">
<p class="help-block">自由形式のテキストに加えて、いくつかのHTML5ベースのテキスト入力はこのように表示されます。</p>
            </div>
        </div>
        <div class="control-group">
<label class="control-label" for="input01">禁用输入</label>
            <div class="controls">
                <input type="text" class="input-xlarge" id="input01" disabled>
<p class="help-block">自由形式のテキストに加えて、いくつかのHTML5ベースのテキスト入力はこのように表示されます。</p>
            </div>
        </div>
        <div class="control-group">
<label class="control-label" for="optionsCheckbox" reado>确认框 (禁用)</label>
            <div class="controls">
                <label class="checkbox">
                    <input type="checkbox" id="optionsCheckbox" value="option1" disabled>
选中选项，确认此项正确。
                </label>
            </div>
        </div>
        <div class="form-actions">
<button type="submit" class="btn btn-primary" disabled>保存修改 (禁用按钮)</button>
<button class="btn">取消</button>
        </div>
    </fieldset>
</form>

フォーム検証用のスタイルを定義する

Bootstrap 2.0 は、フォーム検証時のエラー、警告、成功状態のスタイルを定義できます。これは優れた機能です。ユーザーがフォームデータを送信したときにエラーが発生した場合、または警告を生成する必要がある場合、さらにはユーザーにデータ送信が成功したことを通知する場合に、ユーザーに異なるスタイルを表示する必要があるためです。

ここに一例があります：

实例

<form class="form-horizontal">
    <fieldset>
<legend>表单验证错误，警告或成功</legend>
        <div class="control-group error">
<label class="control-label" for="inputError">输入错误</label>
            <div class="controls">
                <input type="text" id="inputError">
<span class="help-inline">请纠正错误</span>
            </div>
        </div>
        <div class="control-group warning">
<label class="control-label" for="inputWarning">输入警告</label>
            <div class="controls">
                <input type="text" id="inputWarning">
<span class="help-inline">出现一些错误</span>
            </div>
        </div>
        <div class="control-group success">
<label class="control-label" for="inputSuccess">成功输入</label>
            <div class="controls">
                <input type="text" id="inputSuccess">
<span class="help-inline">成功输入</span>
            </div>
        </div>
        <div class="control-group success">
<label class="control-label" for="selectError">选择成功</label>
            <div class="controls">
                <select id="selectError">
                    <option>1</option>
                    <option>2</option>
                    <option>3</option>
                    <option>4</option>
                    <option>5</option>
                </select>
<span class="help-inline">选择成功</span>
            </div>
        </div>
    </fieldset>
</form>
