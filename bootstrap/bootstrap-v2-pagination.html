Bootstrap 分页

简介

このチュートリアルでは、Bootstrapを使用してページネーションを作成する方法を見ていきます。

複数ページのページネーション

オンラインアプリケーション、ウェブサイト、またはアプリの検索結果にページネーションを作成したい場合は、このタイプのページネーションを使用できます。

bootstrap.css の CSS class "pagination" は、行番号 2756 から 1814 に位置し、このタイプのページネーションを作成するためのスタイルを保存しています。

また、2つのCSSクラス "disabled" と "active" は、ページネーション内のリンクがクリック可能かどうかをカスタマイズするために使用できます。行番号2793から2797には、ページネーション用のクラス "disabled" およびその他のクラスのスタイルが保存されています。行番号2786から2792には、ページネーション用の "active" クラスのスタイルが保存されています。

ページネーションリンクの整列方法を設定するには、"pagination-centered" と "pagination-right" CSS class を使用してください。これらの2つのclassは、bootstrap.css の行番号 2809 から 2814（バージョン 2.0.1）に位置しています。

複数ページのページネーション例

实例

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="utf-8">
<title>Bootstrap 多页分页实例</title>
    <meta name="description" content="Twitter Bootstrap Multicon-page pagination example">
    <link href="../twitter-bootstrap/twitter-bootstrap-v2/docs/assets/css/bootstrap.css.html" rel="stylesheet">
    <style type="text/css">
        body {
            margin: 50px;
        }
    </style>
</head>
<body>
<div class="pagination">
    <ul>
        <li><a href="../index.html">Prev</a></li>
        <li class="active">
            <a href="../index.html">1</a>
        </li>
        <li><a href="../index.html">2</a></li>
        <li><a href="../index.html">3</a></li>
        <li><a href="../index.html">4</a></li>
        <li><a href="../index.html">Next</a></li>
    </ul>
</div>
</body>
</html>

body要素にマージンを追加する追加のスタイルは、デモンストレーションのためだけであることに注意してください。

翻页

場合によっては、このチュートリアルの最初の部分で説明した最初のタイプのページネーションが必要になるかもしれません。しかし、時には、ユーザーにナビゲーションを提供するために、next/previous や old/new のような単純なリンクだけが必要なこともあります。これはページングによって実現できます。

"pager" CSS class は、bootstrap.css の行番号 2815 から 2850（バージョン 2.0.1）に位置しています。ここでは、"disabled" CSS class を適用してリンクをクリック不可にすることができます。

nextとprevious付きのページ送り例

实例

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="utf-8">
<title>Bootstrap の next と previous 付きページネーションの例</title>
    <meta name="description" content="Twitter Bootstrap pager with next and previous example">
    <link href="../twitter-bootstrap/twitter-bootstrap-v2/docs/assets/css/bootstrap.css.html" rel="stylesheet">
    <style type="text/css">
        body {
            margin: 50px;
        }
    </style>
</head>
<body>
<ul class="pager">
    <li>
        <a href="../index.html">Previous</a>
    </li>
    <li>
        <a href="../index.html">Next</a>
    </li>
</ul>
</body>
</html>

oldとnew付きのページ送り例

实例

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="utf-8">
<title>Bootstrap を使った old と new のページネーションの例</title>
    <meta name="description" content="Twitter Bootstrap pager with older and newer example">
    <link href="../twitter-bootstrap/twitter-bootstrap-v2/docs/assets/css/bootstrap.css.html" rel="stylesheet">
    <style type="text/css">
        body {
            margin: 50px;
        }
    </style>
</head>
<body>
<ul class="pager">
    <li class="previous">
        <a href="../index.html">← Older</a>
    </li>
    <li class="next">
        <a href="../index.html">Newer →</a>
    </li>
</ul>
</body>
</html>
