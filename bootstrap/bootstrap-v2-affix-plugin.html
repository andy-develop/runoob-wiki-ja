Bootstrap Affix プラグイン - 付加ナビゲーション

Bootstrap Affixプラグインは、<div>要素をWebページ上に浮かせることができます。その<div>要素を画面に沿ってスクロールさせたり、指定した位置に固定したりできます。

用法：データ属性またはJavaScriptを介してAffixプラグインを使用できます。

1、data属性による使用

監視するページ要素にdata-spy="affix"を追加するだけです。次に、オフセットを使用して要素のオンとオフを決定します。

CSSによる位置指定

Affixプラグインは、affix、affix-top、affix-bottomの3つの状態を切り替えます。この3つの状態に対して、独自のスタイル（このプラグインに依存しない）を提供する必要があります。

affix-topクラスは通常のドキュメントフロー内の状態であるべきです。affixクラスはfixed方式で配置された時の状態であるべきです。affix-bottomはabsolute方式で配置された時の状態であるべきです。

选项

オプションの受け渡しはデータ属性またはJavaScriptで行えます。データ属性の場合、オプション名にdata-を付ける必要があります。例: data-offset-top="200"。

名称 类型 默认 描述
offset 数値|関数|オブジェクト 10 スクロール位置の先頭からのオフセット（ピクセル）を計算します。数値を設定した場合、そのオフセット値は上方向と左方向に適用されます。1つの方向または複数の方向のオフセットを設定する場合は、オブジェクトを指定するだけです。offset: { x: 10 }。 この関数を使用すると、オフセットを動的に指定できます(レスポンシブデザインに役立ちます)。
