Bootstrap 按钮

この章では、Bootstrapボタンの使用方法を例を通して説明します。classを持つ任意の要素は.btnの要素はすべて、角丸グレーのボタンのデフォルトの外観を継承します。ただし、Bootstrap にはボタンのスタイルを定義するためのいくつかのオプションが用意されており、詳細は次の表のとおりです。

以下のスタイルは<a>、<button>、または<input>要素に使用できます：

类 描述 实例
.btn ボタンに基本スタイルを追加する 尝试一下
.btn-default 默认/标准按钮 尝试一下
.btn-primary 元のボタンスタイル（未操作） 尝试一下
.btn-success 成功したアクションを示す 尝试一下
.btn-info このスタイルは情報をポップアップ表示させるボタンに使用できます。 尝试一下
.btn-warning 慎重な操作が必要なボタンを表します。 尝试一下
.btn-danger 危険な操作を行うボタンを表します。 尝试一下
.btn-link ボタンを見た目はリンクのようにする（ボタンの動作はそのまま保持されます） 尝试一下
.btn-lg 大きなボタンを作成する 尝试一下
.btn-sm 小さなボタンを作成する 尝试一下
.btn-xs 極小ボタンを作成する 尝试一下
.btn-block ブロックレベルボタン（親要素の100%の幅に引き伸ばす） 尝试一下
.active ボタンがクリックされた 尝试一下
.disabled 禁用按钮 尝试一下

以下の例は、上記のすべてのボタン class を示しています。

实例

<!--標準のボタン--> <button type="button" class="btn btn-default">默认按钮</button> <!--ボタンのグループ内の元のアクションを識別する追加の視覚効果を提供します。--> <button type="button" class="btn btn-primary">原始按钮</button> <!--成功した、または積極のなアクションを示します。--> <button type="button" class="btn btn-success">成功按钮</button> <!--情報・警告メッセージのコンテキストボタン--> <button type="button" class="btn btn-info">信息按钮</button> <!--慎重に行うべき動作を示します--> <button type="button" class="btn btn-warning">警告按钮</button> <!--危険な、または潜にのに否定のなアクションを表します。--> <button type="button" class="btn btn-danger">危险按钮</button> <!--ボタンであることを強調せず、リンクのように見えますが、ボタンの動作は保持します。--> <button type="button" class="btn btn-link">链接按钮</button>

Bootstrap には、アクティブ、無効などのボタン状態のクラスが用意されており、以下で詳しく説明します。

激活状态

ボタンはアクティブになると、押し込まれた外観（濃い背景、濃い枠線、影）になります。

次の表は、ボタン要素とアンカー要素をアクティブ状態にするためのクラスを示しています：

元素Class
按钮元素添加.activeクラスを使用して、アクティブであることを示します。
锚元素添加 .active<a> ボタンにクラスを指定して、アクティブであることを示します。

次の例はこれを示しています：
