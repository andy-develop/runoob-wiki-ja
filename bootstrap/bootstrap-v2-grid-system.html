简介

このチュートリアルでは、Bootstrap を使用してグリッドシステム（Grid System）を作成する方法を学びます。

ご存知かもしれませんが、グラフィックデザインにおいて、グリッドシステムとは、水平軸と垂直軸が交差する領域から構成される二次元の構造で、コンテンツを構築するために使用されます。これはグラフィックデザインのレイアウトやコンテンツ構造に広く応用されています。ウェブデザインにおいては、HTMLとCSSを使用して一貫性のあるレイアウトを迅速かつ効率的に作成するための非常に効果的な方法です。そのため、グリッドシステムはウェブデザインのフレームワークやワークフローの重要なコンポーネント/モジュールとなっています。

簡単に言うと、ウェブデザインでは、HTMLとCSSを使用して行と列を作成し、グリッドを実装します。そして、列には実際のコンテンツが含まれます。

バージョン2.3.2以降、Bootstrapは2種類のグリッドを提供しています。デフォルトのグリッドシステムは幅940px、12列です。レスポンシブなスタイルシートを追加することで、表示されるビューポートに応じて幅を724pxと1170pxに調整できます。

ここには、ピクセルベースではなくパーセンテージベースのフルードグリッドシステムもあります。これは、デフォルトの固定グリッドと同様にレスポンシブに拡張できます。このチュートリアルでは、いくつかの例を通じてデフォルトのグリッドについて説明します。フルードグリッドシステムは、別のチュートリアルで説明します。

"http://twitter.github.io/bootstrap/assets/bootstrap.zip" から最新版の Bootstrap ファイルをダウンロードしてください。あなたは私たちのところでできます。入门教程関連するファイル構造を理解します。

このようにして、各列に"span4"クラスを使用することで、3列のグリッドを作成しました。"container"クラスは構造全体を保持するために使用されます。ここでオンラインの実例を表示できます。このことから、指定した数の列を作成するためのCSSクラスの一般的な構文を導き出すことができます。

グリッドを作成する一般的な構文：

<div class=&quot;row&quot;>
<div class=&quot;spanx&quot;>
inline elements like span, block level elements like p, div.
</div>
repeat <div class=&quot;spanx&quot;> y times.

ここで、yは作成したい列の数であり、xの合計は12（作成できる最大の列数）です。xは正の整数で、値は1から12でなければなりません。

例えば、3つの等幅の列がある場合、各列はclass="span4"です。しかし、最初の列を他の2つより大きくしたい場合は、最初の列にclass="span6"を使用し、他の2つの列にはclass="span3"を使用できます。

固定グリッドで行を作成する方法

次に、他の例に進む前に、固定グリッドで行と列を作成するために使用する CSS ルールを見てみましょう。

row クラスは次のとおりです

.row {
    margin-left: -20px;
    *zoom: 1;
}

左マージンをマイナス20pxに設定し、"*zoom: 1;"を設定します。ここでの"*"は、すべての要素のzoomプロパティを1に設定することを意味し、IE6/7のバグを修正するために使用されます。zoomプロパティを1に設定することは、hasLayoutという内部プロパティを設定することであり、IE6/7の多くのズーム/レンダリングの問題を修正するために使用されます。

.row:before,
.row:after {
    display: table;
    line-height: 0;
    content: "";
}

Bootstrapは前述のCSSコードを使用して行を作成します。":before"と":after"というCSSプロパティを使用します。これらは擬似要素です。":before"は対象の要素の前にコンテンツを挿入するために使用され、":after"は対象の要素の後にコンテンツを挿入するために使用されます。"display:table;"は要素をテーブル形式で表示します。"line-height: 0;"を設定することで、各行が独自の行高を持たないようにし、'content: ""'を使用することで、要素の前後にコンテンツが挿入されないようにします。

次に、以下のルールを使用して、指定した要素の左右にフロート要素がないことを保証します。

.row:after {
    clear: both;
}

固定グリッドで列を作成する方法

[class*="span"] {
    float: left;
    min-height: 1px;
    margin-left: 20px;
}

これが使用するCSSルールです。'[class*="span"]'は、class属性値が'span'で始まるすべての要素を選択します。ここでは"float: left;"を使用して、各列を互いに隣接するように配置します。"min-height: 1px"を使用してすべての列の最小高さを1pxにし、"margin-left: 20px;"で左マージンを20pxに設定します。

デフォルトのグリッドにレスポンシブ性を追加する

Bootstrapのデフォルトグリッドにレスポンシブ機能を追加したい場合は、HTMLファイルのネイティブCSSの後に追加するだけです。

<meta name="viewport" content="width=device-width, initial-scale=1.0"><link href="bootstrap/css/bootstrap-responsive.min.css.html" rel="stylesheet">

レスポンシブ対応のデフォルトグリッドを確認するには、ここをクリックして、オンラインデモを表示。ここをクリックして、関連コードをダウンロード。

デフォルトのグリッドシステムがレスポンシブに機能するには2つの条件があります。ビューポート（グリッドレンダリングに利用可能なスペース）が1200pxより大きい場合[@media (min-width: 1200px) で取得]、ビューポートが768pxより大きく979px未満の場合[@media (min-width: 768px) および (max-width: 979px) で設定]。

オフセット列：デフォルトグリッド

オフセットを使用すると、列を元の位置の右側に移動できます。これは、列に左マージンを追加することで実現されます。Bootstrap では、"offsetx"（x の値は正の整数）クラスと "spany"（y の値は正の整数）クラスを使用できます。'offsetx' の 'x' の値に応じて、関連する列は 'x' 個の列幅分右に移動します。

オフセットの幅は Bootstrap CSS で定義されています。offset12 の最大左マージンは980px、offset1 の最小左マージンは100pxです。

デフォルトのグリッドシステムはピクセルベースであるため、オフセットを適用する際には、オフセットに使用するピクセルと列に使用するピクセルを知っておく必要があります。これら2つを合わせたピクセル数は、水平ビューポートのピクセル数を超えてはなりません。

结论

このチュートリアルでは、Bootstrap のデフォルトのグリッドシステムについて説明しました。このチュートリアルは Bootstrap V2.3.2 に基づいています。以下は、このチュートリアルでの関連ポイントのまとめです。

  • Bootstrapのデフォルトのグリッドシステムは幅940pxで、12列あります。
  • グリッドでは、行は'class="row"'で作成され、列は'class="spanx"'で作成されます。ここでxは正の整数です。すべての列のxの合計は12を超えてはなりません。
  • BootstrapのレスポンシブCSSを追加することで、デフォルトグリッドにレスポンシブ性を追加できます。
  • オフセットを使用して、列に追加のスペースを作成します。'class="offsetx"'を使用します。ここでxは正の整数です。オフセットを使用する場合、オフセットで使用する数を含めた列の合計数は11を超えることはできません。
  • 列はネストできます。ネストした列を使用する場合、グリッド（コンテナ内の1行）内の列の合計数を計算するとき、ネストした列もその計算に含める必要があります。
  • ネストされた列でもオフセットを使用できます。
