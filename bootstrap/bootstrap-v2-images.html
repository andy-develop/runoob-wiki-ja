Bootstrap 图像

目标

このチュートリアルでは、画像にスタイルを適用するための3つのBootstrap 3のクラスについて説明します。また、Bootstrap 3がレスポンシブ画像のために提供する内容についても説明します。

一般的样式

Bootstrap 3 が提供する画像スタイルを定義する特別なクラスについて説明する前に、Bootstrap 3 が提供する画像の一般的なスタイルを見ていきます。

img {
  border: 0;
}

これは、Bootstrap 3 の CSS で見つかった、画像に対して定義された最初の CSS ルールであり、画像がレンダリングされるときにボーダーを削除するために使用されます。

そして、印刷用のメディアクエリ内で、これらのルールが規定されています。

 img {
    page-break-inside: avoid;
  }
  img {
    max-width: 100% !important;
  }

page-break-inside: avoid;画像内の改ページを避けます。

max-width: 100% !important;画像に対して定義されたスタイルは明白です。ここでは、画像の幅がコンテナを超えていても、コンテナ内に表示されるように制限するために使用されます。これは!importantとともに使用され、このスタイルを壊す他のあらゆるスタイルを上書きします。開発者は、モバイルデバイスでの画像表示をより良くサポートするために、これら2つのルールを特に使用することがあります。

ここに画像に関する別のルールがあります。

img {
  vertical-align: middle;
}

このルールにより、画像はdivや他の要素内で垂直方向に中央揃えになります。以下の例のように表示されます。

特殊的样式

Bootstrap 3 は、特定のスタイルで画像を表示するための3つのクラスを提供しています。

img-rounded

このクラスを使用して、角が丸い画像を表示することができます。これを実現するために、Bootstrap はimg-roundedクラスを提供しています。このクラスのスタイルは次のように定義されています。

.img-rounded {
  border-radius: 6px;
}

所以，它把border-radius属性は6ピクセルの値に設定され、関連する画像の角丸を定義します。以下の例では、同じ2つの画像を示しています。最初の画像にはimg-roundedclassがなく、2番目の画像にはclassがあります。img-roundedクラス。なお、2番目の画像は角が丸くなっています。あなたは点击这里，在线查看实例。

响应式图像

Bootstrap 3 は、すぐに使用できるレスポンシブ画像を提供していません。。追加する必要がありますimg-responsiveクラスを画像に追加すると、レスポンシブになります。このクラスの CSS コードは次のとおりです。

.img-responsive {
  display: block;
  height: auto;
  max-width: 100%;
}

これは、画像をブロックレベル要素として表示し、高さを画像の高さと同じにし、画像の最大幅を100%にして、画像が配置されているデバイスに応じて表示を制限することを定義しています。

画像をデフォルトでレスポンシブにするには、次の CSS コードを追加できます。img{ }。

画像にレスポンシブ特性を追加する方法には制限があります。

それぞれ大画面デバイスとモバイルデバイス（画面サイズがより小さく、引き起こす可能性がある性能问题）上で同じ大きさの高解像度画像を読み込むことです。ブラウザは CSS と JS が読み込まれる前に画像を事前読み込みするため、低速なネットワーク接続ではパフォーマンスの問題も発生します。想像してみてください。大きな画像とその中の特定のオブジェクトがあるとき、モバイルデバイスで画像を表示すると、画像は小さいバージョンに縮小され、画像が小さく見えてしまいます。略して艺术指导问题。

開発者はこれらの制限を克服する解決策を考え出しました。私たちは、あるMarc Grabanski 和 Christopher Schmitt使用HiSRCの例です。これは、画像の低解像度、中解像度、高解像度のバージョンを自動的に作成するJqueryプラグインで、表示されるバージョンは画像を表示するデバイスの解像度と帯域幅に依存します。

後述のレスポンシブ画像チュートリアルその中で、これらすべての方法について詳しく説明します。
