Bootstrap 网格系统

この章では、Bootstrapのグリッドシステム（Grid System）について説明します。

Bootstrapはレスポンシブ対応、モバイルファーストのフルードグリッドシステムを提供しており、画面またはビューポートのサイズが大きくなるにつれて、システムは自動的に最大12列に分割されます。

グリッド（Grid）とは何ですか？

ウィキペディアより引用：

グラフィックデザインにおいて、グリッドとは、コンテンツを整理するための一連の交差する直線（垂直線、水平線）で構成される構造（通常は2次元）です。印刷デザインのレイアウトやコンテンツ構成に広く使用されています。ウェブデザインにおいては、一貫性のあるレイアウトを迅速に作成し、HTMLとCSSを効果的に使用するための方法です。

簡単に言えば、ウェブデザインにおけるグリッドはコンテンツを整理し、サイトを閲覧しやすくし、ユーザー側の負荷を軽減するために使用されます。

Bootstrapグリッドシステム（Grid System）とは何ですか？

Bootstrap公式ドキュメントにおけるグリッドシステムに関する説明：

Bootstrapには、レスポンシブ対応、モバイルファースト、固定幅ではないグリッドシステムが含まれており、デバイスまたはビューポートのサイズが大きくなるにつれて適切に12列まで拡張されます。シンプルなレイアウトオプション用の定義済みクラスと、よりセマンティックなレイアウトを生成するための強力なミックスインクラスが含まれています。

上記の文を理解しましょう。Bootstrap 3はモバイルファーストです。つまり、Bootstrapのコードは小さな画面のデバイス（モバイルデバイス、タブレットなど）から始まり、大きな画面のデバイス（ノートパソコン、デスクトップPCなど）のコンポーネントとグリッドに拡張されます。

モバイルデバイス優先戦略

  • 内容
    • 何が最も重要かを決定します。
  • 布局
    • より小さい幅の設計を優先します。
    • 基本のCSSはモバイルファーストであり、メディアクエリはタブレット、デスクトップPCを対象としています。
  • 渐进增强
    • 画面サイズが大きくなるにつれて要素が追加されます。

Bootstrapグリッドシステム（Grid System）の仕組み

グリッドシステムは、コンテンツを含む行と列の一連の組み合わせによってページレイアウトを作成します。以下に、Bootstrapグリッドシステムの仕組みを示します：

  • 行は配置する必要があります.containerclass 内で、適切な整列（alignment）とパディング（padding）を得るために。
  • 行を使用して列の水平グループを作成します。
  • コンテンツは列内に配置する必要があり、列のみが行の直接の子要素になることができます。
  • 事前定義されたグリッドクラス、例えば.rowと.col-xs-4グリッドレイアウトを迅速に作成するために使用できます。LESSミックスインクラスは、よりセマンティックなレイアウトに使用できます。
  • 列は、内側の余白（パディング）によって列コンテンツ間の間隔を作成します。このパディングは、.rows上の外側の余白（マージン）を負の値にすることで、最初の列と最後の列の行オフセットを表現します。
  • グリッドシステムは、使用したい12個の利用可能な列を指定することで作成されます。例えば、3つの等しい列を作成するには、3つの.col-xs-4。

媒体查询

メディアクエリは、非常に巧妙な「条件付きCSSルール」です。特定の規定条件に基づく一部のCSSにのみ適用されます。それらの条件が満たされた場合、対応するスタイルが適用されます。

Bootstrapのメディアクエリを使用すると、ビューポートのサイズに基づいてコンテンツを移動、表示、非表示にできます。以下のメディアクエリは、LESSファイルで使用され、Bootstrapグリッドシステムの重要なブレークポイント閾値を作成するために使用されます。

/* 超小设备（手机，小于 768px） */
/* Bootstrap 中默认情况下没有媒体查询 */

/* 小型设备（平板电脑，768px 起） */
@media (min-width: @screen-sm-min) { ... }

/* 中型设备（台式电脑，992px 起） */
@media (min-width: @screen-md-min) { ... }

/* 大型设备（大台式电脑，1200px 起） */
@media (min-width: @screen-lg-min) { ... }

メディアクエリコードにmax-widthを含めることもあり、これによりCSSの影響をより狭い範囲の画面サイズに限定できます。

@media (max-width: @screen-xs-max) { ... }
@media (min-width: @screen-sm-min) and (max-width: @screen-sm-max) { ... }
@media (min-width: @screen-md-min) and (max-width: @screen-md-max) { ... }
@media (min-width: @screen-lg-min) { ... }

メディアクエリには2つの部分があります。最初にデバイス仕様、次にサイズルールです。上記のケースでは、次のルールが設定されています：

次のコード行を見てみましょう：

@media (min-width: @screen-sm-min) and (max-width: @screen-sm-max) { ... }

すべての〜を含むものに対してmin-width: @screen-sm-minデバイスの場合、画面の幅が次の値より小さい場合@screen-sm-max、いくつかの処理が行われます。

偏移列

オフセットは、より専門的なレイアウトに役立つ機能です。列により多くのスペースを確保するために使用できます。例えば、.col-xs-*クラスはオフセットをサポートしていませんが、空のセルを使用することで簡単に同じ効果を実現できます。

大画面ディスプレイでオフセットを使用するには、.col-md-offset-*クラスを使用してください。これらのクラスは、列の左マージン（margin）を増加させます。*列，其中*範囲は1 到 11。

以下の例では、<div class="col-md-6">..</div>があります。次を使用します。.col-md-offset-3classを使用してこのdivを中央に配置します。

实例

<div class="container"> <h1>Hello, world!</h1> <div class="row" > <div class="col-md-6 col-md-offset-3" style="background-color: #dedef8;box-shadow: inset 1px -1px 1px #444, inset -1px 1px 1px #444;"> <p>Lorem ipsum dolor sit amet, consectetur adipisicing elit. </p> </div> </div> </div>

列排序

Bootstrapグリッドシステムのもう1つの優れた機能は、列をある順序で簡単に記述し、別の順序で表示できることです。

次を含む...を簡単に変更できます。.col-md-push-*と.col-md-pull-*クラスの組み込みグリッド列の順序。ここで*範囲は1 到 11。

以下の例では、2列のレイアウトがあり、左列は狭くサイドバーとして機能します。次を使用します。.col-md-push-*と.col-md-pull-*クラスを使用して、これら2つの列の順序を入れ替えます。

实例

<div class="container"> <h1>Hello, world!</h1> <div class="row"> <p>排序前</p> <div class="col-md-4" style="background-color: #dedef8; box-shadow: inset 1px -1px 1px #444, inset -1px 1px 1px #444;">私は左にいます</div> <div class="col-md-8" style="background-color: #dedef8; box-shadow: inset 1px -1px 1px #444, inset -1px 1px 1px #444;">私は右にいます</div> </div> <br> <div class="row"> <p>排序后</p> <div class="col-md-4 col-md-push-8" style="background-color: #dedef8; box-shadow: inset 1px -1px 1px #444, inset -1px 1px 1px #444;">私は左にいます</div> <div class="col-md-8 col-md-pull-4" style="background-color: #dedef8; box-shadow: inset 1px -1px 1px #444, inset -1px 1px 1px #444;">私は右にいます</div> </div> </div>
