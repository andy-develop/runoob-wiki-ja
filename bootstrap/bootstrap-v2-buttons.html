Bootstrap 按钮

目标

ボタンはウェブサイトやアプリケーションで広く使用されています。このチュートリアルでは、実例と実例の説明を通して、Bootstrap 3 ボタンの使用方法と、デフォルトのボタンをカスタマイズする方法を説明します。

デフォルトのボタンを使用する

以下の例では、Bootstrap 3を使用してボタンをすばやく作成する方法を説明します。

实例

<!DOCTYPE html>
<html>
<head>
<title>Bootstrap 3 默认按钮</title>
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <!-- Bootstrap -->
    <link href="dist/css/bootstrap.min.css.html" rel="stylesheet" media="screen">
    <style>
        body {
            padding: 50px
        }
    </style>
<!-- HTML5 Shim と Respond.js は、IE8 で HTML5 要素とメディアクエリをサポートします。 -->
<!-- WARNING: Respond。如果通过file://查看页面js将不工作。 -->
    <!--[if lt IE 9]>
    <script src="https://oss.maxcdn.com/libs/html5shiv/3.7.0/html5shiv.js"></script>
    <script src="https://oss.maxcdn.com/libs/respond.js/1.3.0/respond.min.js"></script>
    <![endif]-->
</head>
<body>
<!-- 标准按钮 -->
<button type="button" class="btn btn-default">默认</button>

<!-- 追加の視覚効果を提供し、ボタンのグループ内の元のアクションを識別します -->
<button type="button" class="btn btn-primary">原始</button>

<!-- 成功したアクションまたはポジティブなアクションを表示します -->
<button type="button" class="btn btn-success">成功</button>

<!-- 情報警告メッセージのコンテキストボタン -->
<button type="button" class="btn btn-info">信息</button>

<!-- 注意して実行すべきアクションを示す -->
<button type="button" class="btn btn-warning">警告</button>

<!-- 危険または潜にのなマイナスの動作を示します -->
<button type="button" class="btn btn-danger">危险</button>
<!-- ボタンであることを強調せず、リンクのように見えますが、同時にボタンの動作を保持します。 -->
<button type="button" class="btn btn-link">链接</button>
<!-- jQuery (BootstrapのJavaScriptプラグインに必要です--->
<script src="https://code.jquery.com/jquery.js"></script>
<!-- すべてのコンパイル済みプラグイン（下記参照）を含めるか、必要に応じて個別のファイルを含めます -->
<script src="dist/js/bootstrap.min.js.html"></script>
</body>
</html>

上記のコードの出力は以下のとおりです。あなたはできます。ここをクリックして、オンラインで実例を表示。

CSS

これらのボタンを作成するために使用されるCSSルールについて説明します。ボタンを作成するための主要なclassはbtn、以下のようになります。

.btn {
  display: inline-block;
  padding: 6px 12px;
  margin-bottom: 0;
  font-size: 14px;
  font-weight: normal;
  line-height: 1.428571429;
  text-align: center;
  white-space: nowrap;
  vertical-align: middle;
  cursor: pointer;
  background-image: none;
  border: 1px solid transparent;
  border-radius: 4px;
  -webkit-user-select: none;
     -moz-user-select: none;
      -ms-user-select: none;
       -o-user-select: none;
          user-select: none;
}

上記の CSS コードにより、btn class を持つボタンは inline-block として表示され、共通のベースラインを持つ隣接要素とインラインで表示されることが可能ですが、width と height 属性を追加することもできます。その上パディングと下パディングはそれぞれ 6 ピクセルと 12 ピクセルです。下マージンは 0 に設定されています。

フォントサイズは14ピクセルに設定され、フォントの太さはnormalに設定されます。btn classを持つボタンの行の高さは1.428571429で、デフォルトの高さ1より少し高くなっています。テキストは中央寄せです。

white-space プロパティは nowrap に設定されているため、改行、スペース、タブは折りたたまれます。関連する垂直方向に中央揃えされた要素は、高さの中央に配置されます。関連する要素の上にマウスを置くと、カーソルはポインタ形状になります。ここでは背景画像は表示されません。

ここには透明な1ピクセル幅の実線ボーダーが表示されます。border-radius: 4px;、関連するボタンの角は丸みを帯びます。値を 4px 増減することで、角丸の丸みをより大きくしたり、小さくしたりできます。〜によりuser-select: none、関連するボタンおよび子要素のテキストは選択できなくなります。クロスブラウザの一貫性を確保するため、同じプロパティは複数のベンダープレフィックスを付けて適用されます。

上記の例で表示されている各ボタンは、...を除いてbtn他にも別の CSS クラスがあり、たとえば btn-default、btn-primary などです。これらのクラスはボタンのcolor、background-colorとborderプロパティです。これらは、通常のボタンおよびリンク状態（hover、active、focusなど）を持つボタンのためのCSSルールです。

btn-primaryclass のコードは次のとおりです。

.btn-primary {
  color: #FFFFFF;
  background-color: #428BCA;
  border-color: #357EBD;
}

異なるサイズのボタン

ここでは3つのサイズを設定できます。各サイズを設定するには、追加のclassを1つ追加する必要があります。

btn-lg for setting large button.

<button type="button" class="btn btn-primary btn-lg">Large button</button>

btn-lg classのCSSコードは次のとおりです。

.btn-lg {
  padding: 10px 16px;
  font-size: 18px;
  line-height: 1.33;
  border-radius: 6px;
}

使用btn-smとbtn-xsさまざまなサイズのボタンを設定します。

<button type="button" class="btn btn-primary btn-sm">Large button</button>
<button type="button" class="btn btn-primary btn-xs">Large button</button>

btn-sm と btn-xs クラスの CSS コードは次のとおりです。

.btn-sm,
.btn-xs {
  padding: 5px 10px;
  font-size: 12px;
  line-height: 1.5;
  border-radius: 3px;
}

.btn-xs {
  padding: 1px 5px;
}

块级按钮

ボタンが配置されているコンテナの全幅を使用するには、Bootstrap 3はブロックレベルボタンオプションを提供しています。btn-block上記で説明したclassにclassを追加して、ブロックレベルボタンを作成します。

<button type="button" class="btn btn-primary btn-lg btn-block">Large button</button>
<button type="button" class="btn btn-success btn-lg btn-block">Large button</button>

ブロックレベルボタンを作成するためのCSS定義は次のとおりです

.btn-block {
  display: block;
  width: 100%;
  padding-right: 0;
  padding-left: 0;
}

.btn-block + .btn-block {
  margin-top: 5px;
}

無効なボタン

ボタンを少しぼやけさせるには、次のCSSルールを使用します（Chrome DevToolsで確認）

.btn[disabled], fieldset[disabled] .btn {
pointer-events: none;
cursor: not-allowed;
opacity: .65;
filter: alpha(opacity=65);
-webkit-box-shadow: none;
box-shadow: none;
}

定制按钮

ここでは、デフォルトのボタンから始めて、まったく異なる外観と感触を持つようにカスタマイズします。

以下のボタンコードから始めます。

<button type="button" class="btn btn-default">Default</button>

ここでCSS classを作成し、btn-w3rそれを使ってbtn-defaultを置き換えます。したがって、上記のコードの代わりに次のコードを記述します

<button type="button" class="btn btn-w3r">Default</button>

まず背景色を変更します。次のCSSを追加します

.btn-w3r {
    background: #CB60B3; /* Old browsers */
    background: -moz-linear-gradient(top,  #CB60B3 0%, #AD1283 50%, #DE47AC 100%); /* FF3.6+ */
    background: -webkit-gradient(linear, left top, left bottom, color-stop(0%,#CB60B3), color-stop(50%,#AD1283), color-stop(100%,#DE47AC)); /   *   Chrome,Safari4+ */
    background: -webkit-linear-gradient(top,  #CB60B3 0%,#AD1283 50%,#DE47AC 100%); /* Chrome10+,Safari5.1+ */
    background: -o-linear-gradient(top,  #CB60B3 0%,#AD1283 50%,#DE47AC 100%); /* Opera 11.10+ */
    background: -ms-linear-gradient(top,  #CB60B3 0%,#AD1283 50%,#DE47AC 100%); /* IE10+ */
    background: linear-gradient(to bottom,  #CB60B3 0%,#AD1283 50%,#DE47AC 100%); /* W3C */
    filter: progid:DXImageTransform.Microsoft.gradient( startColorstr='#CB60B3', endColorstr='#DE47AC',GradientType=0 ); /* IE6-9 */
    }

現在、ボタンは次のようになります。

フォントの色を変更するには、既存のbtn-w3rclassのCSSコードの後に次のCSSを追加します

color:#fff;

次に、ボタンの形状を円形にするために、既存のbtn-w3rclassのCSSコードの前に次のCSSを追加します

width: 200px;
    height: 200px;
    -moz-border-radius: 50%;
    -webkit-border-radius: 50%;
    border-radius: 50%;

ホバー効果を追加するには、次のCSSコードを追加します

.btn-w3r:hover {
    background: #333; 
    color:#E75616;
    }
