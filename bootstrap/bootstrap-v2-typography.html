简介

このチュートリアルでは、Bootstrapツールキットを使用して見出し、段落、リスト、その他のインライン要素を作成する方法を学びます。

解释

Bootstrap バージョン 2.0 の bootstrap.css の中のフォームの行番号 286 から行番号 515 には、タイポグラフィスタイルが含まれています。
