Bootstrap 滚动监听（Scrollspy）插件

スクロールスパイ（Scrollspy）プラグイン、つまり自動更新ナビゲーションプラグインは、スクロールバーの位置に応じて対応するナビゲーションターゲットを自動的に更新します。その基本的な実装は、スクロールに合わせてスクロールバーの位置に基づきナビゲーションバーに追加することです。.active class。

このプラグインの機能を単独で使用したい場合は、参照する必要がありますscrollspy.js。あるいは、まさにBootstrap 插件概览一章で述べたように、引用することができます。bootstrap.js或压缩版的bootstrap.min.js。

用法

上部ナビゲーションにスクロールスパイの動作を追加できます：

  • 通过 data 属性：監視したい要素（通常は body）に追加しますdata-spy="scroll"。そしてBootstrapを追加して.navコンポーネントの親要素の ID または class 属性data-target。正常に機能させるには、ページの本文に、監視したいリンクに対応する ID を持つ要素が存在することを確認する必要があります。
    <body data-spy="scroll" data-target=".navbar-example">
...
<div class="navbar-example">
    <ul class="nav nav-tabs">
        ...
    </ul>
</div>
...
</body>
  • 通过 JavaScript：JavaScript でスクロールスパイを呼び出し、監視したい要素を選択して、呼び出します.scrollspy()函数：
    $('body').scrollspy({ target: '.navbar-example' })

方法

.scrollspy('refresh')：当通过 JavaScript 调用 scrollspy 方法时，您需要调用.refresh方法来更新 DOM。这在 DOM 的任意元素发生变更（即，您添加或移除了某些元素）时非常有用。下面是使用该方法的语法。 
$('[data-spy="scroll"]').each(function () {
  var $spy = $(this).scrollspy('refresh')
})

水平スクロールスパイの作成

以下の例は、水平スクロールスパイの作成方法を示しています：

实例

<!-- The navbar: used to jump to a section in the scrollable area -->
<nav class="navbar navbar-inverse navbar-fixed-top">
...
  <ul class="nav navbar-nav">
    <li><a href="#section1">Section 1</a></li>
    ...
</nav>

<!-- The scrollable area -->
<div data-spy="scroll" data-target=".navbar" data-offset="12">
  <!-- Section 1 -->
  <div id="section1">
    <h1>Section 1</h1>
    <p>Try to scroll this page and look at the navigation bar while scrolling!</p>
  </div>
  ...
</div>
