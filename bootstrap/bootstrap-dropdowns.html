Bootstrap 下拉菜单（Dropdowns）

本章では、Bootstrap のドロップダウンメニューに焦点を当てます。ドロップダウンメニューは切り替え可能で、リンクをリスト形式で表示するコンテキストメニューです。これは、下拉菜单（Dropdown） JavaScript 插件のインタラクションによって実現します。

ドロップダウンメニューを使用するには、class に.dropdown内部にドロップダウンメニューを追加するだけで済みます。以下の例は、基本的なドロップダウンメニューを示しています：

实例

<div class="dropdown"> <button type="button" class="btn dropdown-toggle" id="dropdownMenu1" data-toggle="dropdown">主题<span class="caret"></span> </button> <ul class="dropdown-menu" role="menu" aria-labelledby="dropdownMenu1"> <li role="presentation"> <a role="menuitem" tabindex="-1" href="#">Java</a> </li> <li role="presentation"> <a role="menuitem" tabindex="-1" href="#">数据挖掘</a> </li> <li role="presentation"> <a role="menuitem" tabindex="-1" href="#">数据通信/网络</a> </li> <li role="presentation" class="divider"></li> <li role="presentation"> <a role="menuitem" tabindex="-1" href="#">分離されたリンク</a> </li> </ul> </div>
