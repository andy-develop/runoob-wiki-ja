Bootstrap 折叠（Collapse）插件

折りたたみ（Collapse）プラグインを使用すると、ページ領域を簡単に折りたたむことができます。折りたたみナビゲーションやコンテンツパネルを作成する場合でも、多くのコンテンツオプションが可能です。

このプラグインの機能を単独で参照したい場合は、以下を参照する必要があります：collapse.jsまた、お使いのBootstrapバージョンでも参照する必要があります。Transition（过渡）插件。あるいは、ちょうどBootstrap 插件概览一章で述べたように、参照することができます。bootstrap.jsまたは圧縮版のbootstrap.min.js。

折りたたみ（Collapse）プラグインは、次の2つの方法で使用できます：

  • 通过 data 属性：要素に追加しますdata-toggle="collapse"とdata-target、折りたたみ要素の制御を自動的に割り当てることもありません。data-target属性はCSSセレクターを受け入れ、それに折りたたみ効果を適用します。折りたたみ可能な要素にclassを追加してください：.collapseデフォルトで開いた状態にしたい場合は、追加のクラスを追加してください：.in。

    折りたたみ可能なコントロールにアコーディオン形式のグループ管理を追加するには、data属性を追加してください：data-parent="#selector"。

  • 通过 JavaScript：JavaScript を使用して collapse メソッドをアクティブ化できます。次に示すとおりです：
    $('.collapse').collapse()

选项

一部のオプションはdata属性またはJavaScriptで渡されます。次の表にこれらのオプションを示します：

选项名称类型/默认值Data 属性名描述
parentselector
默认值：false		data-parentセレクターが指定されている場合、折りたたみ可能な項目が表示されると、指定された親要素の下にあるすべての折りたたみ可能な要素が閉じられます。これは従来のアコーディオンの動作と似ています - これはaccordion-groupクラスに依存します。
toggleboolean
默认值：true		data-toggle折りたたみ可能な要素の切り替えを呼び出します。

方法

以下は、折りたたみ（Collapse）プラグインで使用できる便利なメソッドです：

方法描述实例
Options: .collapse(options)コンテンツを折りたたみ可能な要素としてアクティブ化します。オプションのoptionsオブジェクトを受け入れます。 
$('#identifier').collapse({
    toggle: false
})
Toggle: .collapse('toggle')切换显示/隐藏可折叠元素。 
$('#identifier').collapse('toggle')
Show: .collapse('show')折りたたみ可能な要素を表示します。 
$('#identifier').collapse('show')
Hide: .collapse('hide')折りたたみ可能な要素を非表示にします。 
$('#identifier').collapse('hide')

事件

次の表は、折りたたみ（Collapse）プラグインで使用されるイベントを示しています。これらのイベントは関数内でフックとして使用できます。

事件描述实例
show.bs.collapseshowメソッドの呼び出し後にこのイベントがトリガーされます。 
$('#identifier').on('show.bs.collapse', function () {
    // 执行一些动作...
})
shown.bs.collapse折りたたみ要素がユーザーに表示されたときにこのイベントがトリガーされます（CSSトランジション効果の完了を待ちます）。 
$('#identifier').on('shown.bs.collapse', function () {
    // 执行一些动作...
})
hide.bs.collapsehide インスタンスメソッドを呼び出すと、このイベントが直ちにトリガーされます。 
$('#identifier').on('hide.bs.collapse', function () {
    // 执行一些动作...
})
hidden.bs.collapse折りたたみ要素がユーザーに非表示になったときにこのイベントがトリガーされます（CSSトランジション効果の完了を待ちます）。 
$('#identifier').on('hidden.bs.collapse', function () {
    // 执行一些动作...
})
