Bootstrap 表格

Bootstrapは、テーブルを作成するための明確なレイアウトを提供します。以下の表は、Bootstrapがサポートするいくつかのテーブル要素を示しています。

标签描述
<table>テーブルに基本スタイルを追加します。
<thead>テーブルの見出し行のコンテナ要素（<tr>）。テーブルの列を識別するために使用します。
<tbody>テーブルの本体にあるテーブル行のコンテナ要素（<tr>）。
<tr>単一行に表示されるテーブルセルのグループのコンテナ要素（<td> または <th>）。
<td>デフォルトのテーブルセル。
<th>列または行を識別するための特別なテーブルセル（範囲と位置によって異なります）。<thead> 内で使用する必要があります。
<caption>テーブルに格納されている内容に関する説明または要約。

表格类

以下のスタイルはテーブルで使用できます：

类 描述 实例

上下文类

以下の表にリストされているコンテキストクラスを使用すると、テーブルの行または個々のセルの背景色を変更できます。

类描述
.active特定の行またはセルにホバー色を適用します。
.success成功または積極的なアクションを表します
.warning注意が必要な警告を表します
.danger危険な、または潜在的にマイナスのアクションを示します。

これらのクラスは <tr>、<td>、または <th> に適用できます。

实例

<table class="table"> <caption>上下文表格布局</caption> <thead> <tr> <th>产品</th> <th>付款日期</th> <th>状态</th></tr> </thead> <tbody> <tr class="active"> <td>产品1</td> <td>23/11/2013</td> <td>待发货</td></tr> <tr class="success"> <td>产品2</td> <td>10/11/2013</td> <td>发货中</td></tr> <tr class="warning"> <td>产品3</td> <td>20/10/2013</td> <td>待确认</td></tr> <tr class="danger"> <td>产品4</td> <td>20/10/2013</td> <td>已退货</td></tr> </tbody> </table>
