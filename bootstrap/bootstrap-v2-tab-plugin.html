Bootstrap タブプラグイン

タブはBootstrapのナビゲーションの章で既に紹介されています。この章では、データ属性を使用してタブインターフェースを作成します。

使用

以下の2つの方法でタブラベルを有効にすることができます：

  • data 属性を使用：追加することで data-toggle="tab" 或 data-toggle="pill"アンカーテキストのリンクに。

    添加nav とnav-tabsクラスを ul に。

    • <ul class="nav nav-tabs">
   <li><a href="../index.html" data-toggle="tab">Home</a></li>
...
</ul>

  • 通过 JavaScript:Javascriptを使用してタブを有効にすることができます：

    $('#myTab a').click(function (e) {
  e.preventDefault()
  $(this).tab('show')
})

    以下は、さまざまな方法で各タブをアクティブにする例です：

    • // 通过名称选取选项卡
$('#myTab a[href="../index.html"]').tab('show')
 
// 选取第一个选项卡
$('#myTab a:first').tab('show') 

// 选取最后一个选项卡
$('#myTab a:last').tab('show') 

// 选择第三个选项卡 (0-第一个选项)
$('#myTab li:eq(2) a').tab('show')

事件

次の表は、タブプラグインのイベントを一覧にしています。これらのイベントは関数内でフックとして使用できます。

事件描述实例
show.bs.tabこのイベントはタブでトリガーされ、タブが表示される前に発生します。それぞれ使用します。event.targetとevent.relatedTargetイベントは、ターゲットのアクティブなタブと前のタブに対して発生します。 
$('a[data-toggle="tab"]').on('show.bs.tab', function (e) {
  e.target // 激活选项卡
  e.relatedTarget // 前一个选项卡
})
shown.bs.tabこのイベントはタブが表示される前にトリガーされます。それぞれ使用します。event.targetとevent.relatedTargetイベントは、ターゲットのアクティブなタブと前のタブに対して発生します。 
$('a[data-toggle="tab"]').on('shown.bs.tab', function (e) {
  e.target // 激活选项卡
  e.relatedTarget // 前一个选项卡
})
