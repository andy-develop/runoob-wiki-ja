Bootstrap ScrollSpy（滚动监听）

描述

このチュートリアルでは、Bootstrap ScrollSpy（スクロールスパイ）プラグインを使用して、スクロールバーの位置に基づいて対応するナビゲーションターゲットを自動的に更新する方法を説明します。

必要なものは何ですか？

jQuery、Bootstrap CSS、およびJavaScriptファイル - bootstrap-scrollspy.js を参照する必要があります。これはBootstrapのメインフォルダ内の 'js' フォルダにあります。ドロップダウンメニューを使用する場合は、HTMLファイルに bootstrap-dropdown.js も参照する必要があります。

jQuery は Bootstrap のメインフォルダ内の docs > assets > js にあり、jquery.js という名前です。または、直接アクセスすることもできます。http://apps.bdimg.com/libs/jquery/1.7.1/jquery.min.js下载 jQuery。

解释

したがって、ターゲット div に 'data-spy="scroll" ' を追加する必要があります。

注意：インスタンスファイルのヘッダー領域に .scrollspy-example のスタイルを追加しました。bootstrap.css には .scrollspy-example が含まれておらず、docs.css に記述されているためです。

'data-offset' 属性の値は数値で、スクロールバーの位置を計算する際に上部からオフセットするピクセル数を決定します。

Call .scrollspy()

ScrollSpy（スクロールスパイ）を正常に動作させるには、JavaScript から .scrollspy() を呼び出します。以下のコードは、その方法を示しています：

$('#navbar').scrollspy();

ここで、#navbar は関連するナビゲーションの id です。

方法

DOM 上で要素を作成または削除する際に、scrollspy（スクロールスパイ）を使用できます。ただし、refresh メソッドを呼び出す必要があります。以下のコードは、その方法を示しています：

$('[data-spy="scroll"]').each(function () {
  var $spy = $(this).scrollspy('refresh')
});

选项

javaScript を介して scrollspy（スクロールスパイ）を呼び出す場合、'offset' メソッドを使用して、スクロールバーの位置を計算する際に上部からオフセットするピクセル数を決定できます。メソッドのタイプは number で、デフォルト値は 10 です。scrollspy（スクロールスパイ）を正常に動作させるには、この値を増減する必要があります。

事件

scrollspy（スクロールスパイ）によって新しい項目がトリガーされると、'activate' イベントが発生します。
