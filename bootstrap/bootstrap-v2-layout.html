Bootstrap 布局

简介

このチュートリアルでは、Bootstrapツールキットを使用して固定レイアウトと流動レイアウトを作成する方法を学びます。このチュートリアルはBootstrapバージョン2.0に基づいています。

バージョン2.0では、Bootstrapは携帯電話、タブレット、ノートパソコン、小型デスクトップ、大型ワイドスクリーンデスクトップなどにレスポンシブ機能を追加しました。
docs\assets\css にある bootstrap-responsive.css ファイルをページに追加することで、レイアウトをレスポンシブにすることができます。

Bootstrap 固定レイアウト

固定ピクセル数に基づくウェブページやアプリを作成したい場合は、こちらのチュートリアルをご覧ください。

用法

<body>
  <div class="container">
    ...
  </div>
</body>

解释

bootstrap.css（Bootstrapのメインフォルダのdocs\assets\cssにあります）の261行目から273行目は、メインコンテナのレンダリングスタイルを作成し、固定レイアウトを作成します。固定レイアウトの目的は、Webページまたはアプリに940ピクセル（デフォルト）幅のレイアウトを作成することです。

Bootstrap 固定レイアウトの例

以下のコードは、Webページの固定レイアウトを作成します。カスタマイズするには、デフォルトスタイルに加えて、bootstrap.cssと同じフォルダに新しいCSSファイルexample-fixed-layout.cssを作成する必要があります。

body {
padding-top: 60px;
padding-bottom: 40px;
}
.nav li {
padding-top: 5px;

border-radius: 6px;

line-height: 1;
letter-spacing: -1px;
color:#FF6600;
}
.leaderboard p {
font-size: 18px;
font-weight: 200;
line-height: 27px;
}

Bootstrap フルードレイアウト

非固定レイアウト、つまりパーセンテージベースのレイアウトを作成して、レイアウトをより柔軟にしたい場合は、こちらのチュートリアルをご覧ください。

用法

<div class="container-fluid">
  <div class="row-fluid">
    <div class="span2">
      <!--Sidebar content-->
    </div>
    <div class="span10">
      <!--Body content-->
    </div>
  </div>
</div>

解释

bootstrap.css（Bootstrapのメインフォルダのdocs\assets\cssにあります）の274行目から285行目は、メインコンテナのレンダリングスタイルを作成し、フルードレイアウトを作成します。フルードレイアウトの目的は、Webページまたはアプリにパーセンテージベースのレイアウト（例：width=20%）を作成することです。

Bootstrap フルードレイアウトの例

以下のコードは、Webページのフルードレイアウトを作成します。カスタマイズするには、デフォルトスタイルに加えて、bootstrap.cssと同じフォルダに新しいCSSファイルexample-fluid-layout.cssを作成する必要があります。

CSS 代码

      }
      .nav li {
      padding-top: 5px;
      }
      
      .sidebar-nav {
        padding: 9px 0;
      }
      .leaderboard {

  background-image: url('/twitter-bootstrap/images/gridbg.gif');
