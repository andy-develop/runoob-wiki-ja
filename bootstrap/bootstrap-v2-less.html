Bootstrap LESS

简介

Less は CSS プリプロセッサであり、CSS を動的にします。

一方、Bootstrap は Web アプリやサイトを迅速に開発するためのツールキットです。

このチュートリアルでは、Less CSS を使用した Bootstrap について説明します。これにより、CSS で Bootstrap の Less 変数、ミックスイン（mixins）、ネスト（nesting）を使用できます。

Less入門チュートリアルを表示

获取 Bootstrap 和 Less CSS

Bootstrap 官网：http://getbootstrap.com/

Less 官网：http://lesscss.org/

何が含まれているか

Bootstrap をダウンロードし、ファイルを解凍します。Bootstrap の Less コンポーネントは 'lib' ディレクトリにあります。Bootstrap v1.4.0 以降には、9 つの Less ファイルが含まれています。以下では、これら 9 つのファイルがそれぞれ何を含むのかを見ていきましょう。

bootstrap.less

これはメインの Less ファイルです。このファイルには他の less ファイルがいくつかインポートされています。このファイルにはコードは一切含まれていません。

forms.less

この Less ファイルには、フォームレイアウトや入力フィールドタイプのスタイルが含まれています。

mixins.less

この Less ファイルにより、CSS コードを再利用できます。

patterns.less

この Less ファイルには、繰り返し使用されるユーザーインターフェース要素の CSS コードが含まれており、scaffolding Less ファイル内の基本スタイルによって上書きされることはありません。

reset.less

このLessファイルにはCSSリセットが含まれています。これはEric MeyerのCSSリセットの更新版です。dfn、sampなどの一部のHTML要素のリセットは除外されています。

scaffolding.less

この Less ファイルには、グリッドシステム、構造化レイアウト、ページテンプレートを作成するために必要な基本スタイルが保存されています。

tables.less

この Less ファイルには、テーブルを作成するためのスタイルが含まれています。

type.less

この Less ファイルには、タイポグラフィ関連のスタイルがあります。見出し、段落、リスト、コードなどのスタイルはこのファイルに含まれています。

variables.less

この Less ファイルには、Bootstrap の外観と感触をカスタマイズするための変数が含まれています。

如何使用

これを使用する場合は、HTML ページに次のコードを含めてください：

<link rel="stylesheet/less" href="lib/bootstrap.less.html" media="all" />
<script src="js/less-1.1.5.min.js.html"></script>

less-1.1.5.min.js は js フォルダ内にはありませんので、ダウンロードして指定のフォルダに配置する必要があることに注意してください。

Bootstrap 混合

基本的混合

基本的なミックスインは、本質的にはコードスニペット全体または一部を含むものです。CSS クラスのように記述し、どこからでも呼び出すことができます。

.element {
  .clearfix();
}

パラメータ付きミックスイン

パラメータ付きミックスインは基本的なミックスインとよく似ていますが、前者は（名前による）パラメータを受け取ることができ、パラメータにはデフォルト値を設定できる点が異なります。

.element {
  .border-radius(4px);
}

易于定制

基本的に、Bootstrap のすべてのミックスインは mixins.less に保存されています。これは優れたツールクラスの .less ファイルであり、任意の .less ファイル内でそのミックスインを使用できます。

したがって、既存のミックスインを直接使用するか、新しいミックスインをカスタマイズするか、どちらでも構いません。

如何编译

带有makefile的Node.js

次のコマンドを実行して、npm を使用して LESS コマンドラインコンパイラと uglify-js をグローバル環境にインストールします：

$ npm install -g less uglify-js

インストールが成功したら、Bootstrap のルートディレクトリで make を実行すると CSS をコンパイルできます。

さらに、watchr をインストールしている場合は、make watch を実行できます。これにより、Bootstrap を変更するたびに、Bootstrap が自動的に再コンパイルされます。（必須ではありません。単に便宜のためです。）

使用 JavaScript

単に less.js ファイルを参照するだけで済みます（下载最新的 Less.js)してページを再読み込みします。

jsファイルがlessをコンパイルします。

<link rel="stylesheet/less" href="../path/to/bootstrap.less.html">
<script src="../path/to/less.js.html"></script>

命令行

Less コマンドライン（Command Line）をインストールしている場合、以下がコンパイルするコマンドです。

$ lessc ./lib/bootstrap.less > bootstrap.css

圧縮したコンパイルが必要な場合は、--compress コマンドを使用できます。
