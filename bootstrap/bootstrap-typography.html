Bootstrap 排版

Bootstrap 使用 Helvetica Neue、 Helvetica、 Arial 和 sans-serif 作为其默认的字体栈。

Bootstrap のタイポグラフィ機能を使用すると、見出し、段落、リスト、その他のインライン要素を作成できます。

标题

BootstrapではすべてのHTML見出し（h1〜h6）のスタイルが定義されています。次の例をご覧ください：

实例

列表

Bootstrap は順序付きリスト、順序なしリスト、定義リストをサポートしています。

  • 有序列表：順序付きリストとは、数字やその他の順序文字で始まるリストです。
  • 无序列表：順序なしリストとは、特定の順序がないリストで、伝統的なスタイルの箇条書き記号で始まるリストです。これらの箇条書き記号を表示したくない場合は、class を使用できます。.list-unstyledスタイルを削除します。また、class を使用することもできます。.list-inlineすべてのリスト項目を同じ行に配置します。
  • 定义列表：このタイプのリストでは、各リスト項目に `<dt>` と `<dd>` 要素を含めることができます。`<dt>` は表します。定义术语、辞書のように。次に、`<dd>` は `<dt>` の説明です。.dl-horizontal可以让<dl>内の語句とその説明が一行に並びます。始まりは次のようです。<dl>のデフォルトスタイルは積み重ねられ、ナビゲーションバーが展開されるにつれて 1 行に並びます。

次の例では、これらのタイプのリストを示しています：

实例

<h4>有序列表</h4> <ol> <li>Item 1</li> <li>Item 2</li> <li>Item 3</li> <li>Item 4</li> </ol> <h4>无序列表</h4> <ul> <li>Item 1</li> <li>Item 2</li> <li>Item 3</li> <li>Item 4</li> </ul> <h4>未定义样式列表</h4> <ul class="list-unstyled"> <li>Item 1</li> <li>Item 2</li> <li>Item 3</li> <li>Item 4</li> </ul> <h4>内联列表</h4> <ul class="list-inline"> <li>Item 1</li> <li>Item 2</li> <li>Item 3</li> <li>Item 4</li> </ul> <h4>定义列表</h4> <dl> <dt>Description 1</dt> <dd>Item 1</dd> <dt>Description 2</dt> <dd>Item 2</dd> </dl> <h4>水平的定义列表</h4> <dl class="dl-horizontal"> <dt>Description 1</dt> <dd>Item 1</dd> <dt>Description 2</dt> <dd>Item 2</dd> </dl>
