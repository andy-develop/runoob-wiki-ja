Bootstrap 附加导航（Affix）插件

追加ナビゲーション（Affix）プラグインは、<div> をページ上の特定の位置に固定できます。一般的な例はソーシャルアイコンです。これらは特定の位置から開始されますが、ページが何らかのマーカーを通過すると、その <div> は特定の位置にロックされ、ページの他の部分と一緒にはスクロールしません。

このプラグインの機能を単独で参照する場合は、次のものを参照する必要があります。affix.js。あるいは、まさにBootstrap 插件概览一章で述べたように、参照することができます。bootstrap.jsまたは圧縮版のbootstrap.min.js。

用法

追加ナビゲーション（Affix）プラグインは、data 属性または JavaScript を使用して利用できます。

  • 通过 data 属性要素に追加ナビゲーション（Affix）の動作を追加するには、監視したい要素に追加するだけです。data-spy="affix"それで十分です。オフセットを使用して、要素のロックと移動を切り替えるタイミングを定義してください。

CSSによる配置

上記の2つのAffixプラグインの使用方法のいずれでも、CSSを使用してコンテンツを配置する必要があります。Affixプラグインは、3つのクラスを切り替えます。各クラスは特定の状態を表します。.affix、.affix-top および .affix-bottom以下の手順に従って、これら3つの状態に対して独自のCSSを設定してください（このプラグインに依存しません）。

  • 開始時、プラグインは次のものを追加します。.affix-top要素が最上部の位置にあることを示します。このとき、CSSの位置指定は一切必要ありません。
  • 追加ナビゲーション（Affix）が追加された要素をスクロールが通過すると、実際の追加ナビゲーション（Affix）がトリガーされます。このとき.affix会替代.affix-top，同时设置position: fixed;（BootstrapのCSSコードによって提供されます）。
  • 底部のオフセットが定義されている場合、スクロールがその位置に達したとき、次のものを〜する必要があります。.affix〜に置き換える.affix-bottomオフセットはオプションであるため、オフセットを設定した場合は、適切なCSSも同時に設定する必要があります。この場合、必要に応じて追加してください。position: absolute;。
