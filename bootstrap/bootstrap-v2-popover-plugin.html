Bootstrap Popover（弹出框）

描述

Bootstrap Popover（ポップオーバー）は、カスタムされた Jquery プラグインを使用して作成されます。任意の要素に関する情報を表示するために使用できます。

このチュートリアルでは、Bootstrap Popoverの使用方法、および利用可能ないくつかのオプションを使用してカスタマイズする方法を説明します。

何が必要ですか

Jquery、Bootstrap CSS、および2つのJavaScriptファイル（1つはBootstrap Tooltip（ツールチッププラグイン）用、もう1つはBootstrap Popover（ポップオーバー）用）を参照する必要があります。

Tooltip（ツールチッププラグイン）用のJSファイルは、Bootstrapフォルダ内のjsフォルダにあり、bootstrap-tooltip.jsという名前です。Popover（ポップオーバー）用のJSファイルは、Bootstrapメインフォルダ内のjsフォルダにあり、bootstrap-popover.jsという名前です。Jqueryは、Bootstrapメインフォルダ内のdocs > assets > jsにあり、jquery.jsという名前です。または、https://ajax.googleapis.com/ajax/libs/jquery/1.7.1/jquery.min.js に直接アクセスしてJqueryをダウンロードすることもできます。

bootstrap-popover.js をダウンロードする前に、必ず bootstrap-tooltip.js を先にダウンロードしてください。ポップオーバーはツールチッププラグインに依存しているため、ツールチッププラグインを先に読み込む必要があります。

ウェブサイトで Bootstrap Popover（ポップオーバー）を使用する

实例

<div class="container">
<h2>使用Bootstrap创建弹出框</h2>
    <div class="well">
        <a href="../index.html" id="example" class="btn btn-danger" rel="popover" data-content="It's so simple to create a tooltop for my website!" data-original-title="Twitter Bootstrap Popover">hover for popover</a>
    </div>
</div>
<script src="https://ajax.googleapis.com/ajax/libs/jquery/1.7.1/jquery.min.js"></script>
<script src="../twitter-bootstrap/twitter-bootstrap-v2/js/bootstrap-tooltip.js.html"></script>
<script src="../twitter-bootstrap/twitter-bootstrap-v2/js/bootstrap-popover.js.html"></script>
<script>
    $(function ()
    { $("#example").popover();
    });
</script>

解释

以下の表は上記のコードを説明しています。Bootstrap Popover（ポップオーバー）の使い方を理解するのに役立ちます。

代码 解释
id="example" 関連するアンカーに割り当てられたid。idの値は、後でpopover（ポップオーバー）を実装するJavaScriptを指します。
class="btn btn-danger" ボタンを作成します。btn btn-danger は、例で使用されているclassです。Bootstrap CSS内の他の任意のclass、または独自に定義したclassを使用できます。
data-content="It's so simple to create a tooltip for my website!" data-content の値は popover（ポップオーバー）の本体に表示されます。
data-original-title="Bootstrap Popover" data-original-title の値は popover（ポップオーバー）のタイトルとして表示されます。
hover for popover 锚文本。
<script src="https://ajax.googleapis.com/ajax/libs/ jquery/1.7.1/jquery.min.js"></script> 引用 Jquery。
<script src="../bootstrap/twitter-bootstrap-v2/ js/bootstrap-tooltip.js"></script> Bootstrap Tooltip（ツールチッププラグイン）のJSファイルを参照します。
<script src="../bootstrap/twitter-bootstrap-v2/js/ bootstrap-popover.js"></script> Bootstrap Popover（ポップオーバー）のJSファイルを参照します。
$(function () ドキュメントを準備します。jQueryコマンド。
$("#example").popover(); id exampleにアクセスし、その上でpopover()を実装してください。

ここでは、box の外に popover（ポップオーバー）を作成せず、カスタマイズを一切行っていません。つまり、popover() を使用してオプションを指定していません。

用法

したがって、Bootstrap Popover（ポップオーバー）の使用方法は次のようにまとめられます。

$(function ()  
{ $("identifier").popover(options);  
});

其中identifierこれは、関連するコンテナ要素を識別するためのjQueryセレクタです。次に、見てみましょう。options都有哪些。

选项

以下は、popover() を介して Popover（ポップオーバー）の外観と感触をカスタマイズする際に使用できるオプションの一部です。

animation

animation の値の型は boolean で、デフォルト値は true です。tooltip（ツールチッププラグイン）に css のグラデーション遷移効果をもたらすために使用されます。

placement

placement の値の型は string または function で、デフォルト値は 'right' です。top、bottom、left は他に使用できる値です。このオプションは、アンカーテキストの周囲に表示されるPopover（ポップオーバー）の位置を決定するために使用されます。以下は、placementオプションを使用した例です。

实例

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="utf-8">
<title>Bootstrap 弹出框位置选择的实例</title>
    <meta name="description" content="Creating Modal Window with Twitter Bootstrap">
    <link href="../twitter-bootstrap/twitter-bootstrap-v2/docs/assets/css/bootstrap.css.html" rel="stylesheet">
    <style>
        a {
            margin-left : 400px;
        }
    </style>
</head>
<body>
<div class="container">
<h2>使用Bootstrap plcement 选项创建弹出框</h2>
    <div class="well">
<a href="../index.html" id="example" class="btn btn-success" rel="popover" data-content="为我的网站创建一个提示框如此简单！" data-original-title="Twitter Bootstrap 弹出框">悬停弹出</a>
    </div>
    <div class="well">
<a href="../index.html" id="example_left" class="btn btn-success" rel="popover" data-content="为我的网站创建一个提示框如此简单！" data-original-title="Twitter Bootstrap 弹出框">悬停弹出</a>
    </div>
    <div class="well">
<a href="../index.html" id="example_top" class="btn btn-success" rel="popover" data-content="为我的网站创建一个提示框如此简单！" data-original-title="Twitter Bootstrap 弹出框">悬停弹出</a>
    </div>
    <div class="well">
<a href="../index.html" id="example_bottom" class="btn btn-success" rel="popover" data-content="为我的网站创建一个提示框如此简单！" data-original-title="Twitter Bootstrap 弹出框">悬停弹出</a>
    </div>
</div>
<script src="https://ajax.googleapis.com/ajax/libs/jquery/1.7.1/jquery.min.js"></script>
<script src="../twitter-bootstrap/twitter-bootstrap-v2/js/bootstrap-tooltip.js.html"></script>
<script src="../twitter-bootstrap/twitter-bootstrap-v2/js/bootstrap-popover.js.html"></script>
<script>
    $(function ()
    { $("#example").popover();
        $("#example_left").popover({placement:'left'});
        $("#example_top").popover({placement:'top'});
        $("#example_bottom").popover({placement:'bottom'});
    });
</script>
</body>
</html>

selector

selector の値の型は string で、デフォルト値は false です。このオプションを使用すると、Tooltip オブジェクトを指定されたターゲットに割り当てることができます。

trigger

trigger の値の型は string で、デフォルト値は 'hover' です。focus と manual は他に使用できる値です。このオプションは、tooltip（ツールチッププラグイン）がどのように開始されるかを決定します。以下の例は、focusオプションを使用してPopover（ポップオーバー）をトリガーする方法を示しています。

实例

<div class="container">
<h2>使用Bootstrap trigger 选项创建弹出框</h2>
    <div class="well">
<a href="../index.html" id="example" class="btn btn-success" rel="popover" data-content="为我的网站创建一个提示框如此简单！" data-original-title="Twitter Bootstrap 弹出框">悬停弹出</a>
    </div>
</div>
<script src="https://ajax.googleapis.com/ajax/libs/jquery/1.7.1/jquery.min.js"></script>
<script src="../twitter-bootstrap/twitter-bootstrap-v2/js/bootstrap-tooltip.js.html"></script>
<script src="../twitter-bootstrap/twitter-bootstrap-v2/js/bootstrap-popover.js.html"></script>
<script>
    $(function ()
    { $("#example").popover({trigger: 'focus'});
    });
</script>

title

title の値の型は string または function で、デフォルト値は '' です。つまり、デフォルトでは title 属性の値は表示されません。

content

content の値の型は string または function で、デフォルト値は '' です。つまり、デフォルトでは data-content 属性の値は表示されません。以下は、title および data-content オプションを使用した例です。この例は、複数のオプションを一緒に使用する方法も示しています。

实例

<div class="container">
<h2>Bootstrap弹出框使用title和content选项</h2>
    <div class="well">
<a href="../index.html" id="example" class="btn btn-success" rel="popover">悬停弹出</a>
    </div>

    $(function ()
{ $("#example").popover({title: 'Twitter Bootstrap Popover', content: "为我的网站创建一个提示框如此简单！"});

delay

delay の値の型は number または object で、デフォルト値は 0 です。これは、popover（ポップオーバー）の表示と非表示の待機時間をミリ秒単位で決定します。値が数値に設定されている場合、待機時間は表示と非表示の両方に適用されます。値がオブジェクトに設定されている場合、構造は delay: { show: 500, hide: 100} となり、500 と 100 はミリ秒単位です。

popover（ポップオーバー）のデフォルトのマークアップとスタイルを変更する

Popover ポップアップのデフォルトのマークアップは、bootstrap-popover.js ファイルの行番号 92 にあります。以下に示します。

template: '<div class="popover"><div class="arrow"></div><div class="popover-inner"><h3 class="popover-title"></h3><div class="popover-content"><p></p></div></div></div>'
            

これを変更して、独自のマークアップを配置できます。

Popover ポップアップのデフォルトのスタイルは、行番号 3027 から 3118 にあります。これを変更して、独自のスタイルを配置できます。
