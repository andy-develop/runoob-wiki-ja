Bootstrap 3 CSS 概览

目标

このチュートリアルでは、Bootstrap 3 CSSの要点について説明しました。次に、Bootstrap 3が機能するためのいくつかの重要な要素について説明します。

HTML 5 文書型（Doctype）

Bootstrap 3 はいくつかの HTML5 要素と CSS プロパティを使用しています。これらを正しく動作させるには、HTML5 ドキュメントタイプ（Doctype）を使用する必要があります。

<!DOCTYPE html>
<html lang="en">
  ...
</html>

Bootstrap で作成した Web ページの先頭で HTML5 のドキュメントタイプ（Doctype）を使用しない場合、ブラウザの表示が一貫しない問題に直面する可能性があり、特定の状況下での不整合により、コードが W3C 標準の検証を通過できない可能性もあります。

モバイルファースト

これは Bootstrap 3 の最も顕著な変更点かもしれません。以前の Bootstrap バージョン（2.x まで）では、メインの CSS と一緒に別の CSS を手動で参照して、プロジェクトをモバイルデバイス対応にする必要がありました。現在は異なり、Bootstrap 3 のデフォルトの CSS 自体がモバイルデバイスに対応しています。

Bootstrap 3 の設計目標はモバイルデバイス優先であり、その次にデスクトップデバイスです。これは実際には非常に時宜を得た転換です。なぜなら、現在ますます多くのユーザーがモバイルデバイスを使用しているからです。

Bootstrap で開発した Web サイトをモバイルデバイス対応にし、適切な描画とタッチスクリーンのズームを確保するには、Web ページの head 内に viewport meta タグを追加する必要があります。次のようになります：

<meta name="viewport" content="width=device-width, initial-scale=1.0">

width属性はデバイスの幅を制御します。あなたの Web サイトが異なる画面解像度を持つデバイスで閲覧されることを想定している場合、それを次のように設定します。device-widthこれにより、異なるデバイス上で正しく表示されることが保証されます。

initial-scale=1.0Web ページの読み込み時に、1:1 の比率で表示され、ズームが一切行われないことを保証します。

モバイルデバイスのブラウザでは、viewport meta タグに次を追加することで、user-scalable=noそのズーム（zooming）機能を無効にできます。通常は、maximum-scale=1.0user-scalable=no と一緒に使用します。これによりズーム機能を無効にすると、ユーザーは画面をスクロールするだけでよくなり、あなたのウェブサイトをよりネイティブアプリのように見せることができます。なお、この方法はすべてのウェブサイトで推奨されるわけではなく、ご自身の状況によることに注意してください！

响应式图片

通过添加img-responsiveclass により、Bootstrap 3 の画像はレスポンシブレイアウトのサポートに対してよりフレンドリーになります。この class にどのような CSS プロパティが含まれているか見てみましょう。その実質は、画像に max-width: 100%; と height: auto; 属性を付与し、画像が親要素のサイズを超えないように比例してスケーリングできるようにすることです。

.img-responsive {
  display: inline-block;
  height: auto;
  max-width: 100%;
}

これは関連する画像が次のように表示されることを示しますinline-block。要素の display プロパティを inline-block に設定すると、要素は周囲のコンテンツに対してインライン形式で表示されますが、インラインとは異なり、この場合には幅と高さを設定できます。

设置height:auto、関連要素の高さはブラウザに依存します。

设置max-width100% に設定すると、width 属性で指定された幅が上書きされます。これにより、画像はレスポンシブレイアウトのサポートに対してよりフレンドリーになります。

グローバルな表示、タイポグラフィ、およびリンク

Bootstrap 3 使用body {margin: 0;}body のマージンを削除するために。

以下の body に関する設定をご覧ください。

body {
  font-family: "Helvetica Neue", Helvetica, Arial, sans-serif;
  font-size: 14px;
  line-height: 1.428571429;
  color: #333333;
  background-color: #FFFFFF;
}

最初のルールは、body のデフォルトのフォントスタイルを次のように設定します。"Helvetica Neue", Helvetica, Arial, sans-serif。

2 番目のルールは、テキストのデフォルトのフォントサイズを 14 ピクセルに設定します。

3 番目のルールは、デフォルトの行の高さを 1.428571429 に設定します。

4 番目のルールは、デフォルトのテキストの色を #333333 に設定します。

最後のルールは、デフォルトの背景色を白に設定します。

リンクのデフォルトスタイルについては、次のように設定します。

a:hover,
a:focus {
  color: #2A6496;
  text-decoration: underline;
}

a:focus {
  outline: thin dotted #333;
  outline: 5px auto -webkit-focus-ring-color;
  outline-offset: -2px;
}

したがって、マウスがリンクにホバーしたとき、またはクリック済みのリンクでは、色が #2a6496 に設定されます。同時に、下線が表示されます。

これに加えて、クリック済みのリンクには、カラーコード #333 の細い点線のアウトラインが表示されます。もう 1 つのルールは、アウトラインを 5 ピクセル幅に設定し、webkit ベースのブラウザに対しては、ブラウザ拡張があります。-webkit-focus-ring-colorアウトラインオフセットは -2 ピクセルに設定されます。

上記のこれらすべてのスタイルは、scaffolding.less の中にあります。

ブラウザ間の不整合を避ける

Bootstrap 3 は、それ以前のバージョンと同様に、Normalize を使用して、クロスブラウザの一貫性を確立しています。

Container

Bootstrap 3 のcontainerclass は、ページ上のコンテンツを包み込むために使用されます。次の class を一緒に見てみましょう。

.container {
  margin-right: auto;
  margin-left: auto;
}

上記のコードにより、container の左右のマージンはブラウザに委ねられます。

.container:before,
.container:after {
  display: table;
  content: " ";
}

これにより疑似要素が生成されます。設定displayためにtable、匿名の table-cell と新しいブロックフォーマットコンテキストを作成します。:before疑似要素は上マージンの崩れを防ぎます。:after疑似要素がフロートをクリアします。

如果conteneditable属性が HTML に出現する場合、いくつかの Opera のバグにより、上記の要素の周囲にスペースが作成されます。これは、次のものを使用することで解決できます。content: " "来修复。

.container:after {
  clear: both;
}

これは疑似要素を作成し、すべてのコンテナがすべてのフロート要素を含むことを保証します。

Bootstrap 3 CSS にはレスポンシブ対応のメディアクエリがあり、さまざまなメディアクエリのしきい値範囲内で container に max-width を設定して、グリッドシステムに一致させています。
