PHP vfprintf()関数

PHP String リファレンスマニュアル

例

テキストを "test.txt" という名前のテキストファイルに書き込みます：

<?php
$number = 9;
$str = "Beijing";
$file = fopen("test.txt","w");
echo vfprintf($file,"There are %u million bicycles in %s.",array($number,$str));
?>

上記のコードは次のように出力します：

40

以下のテキストがファイル "test.txt" に書き込まれます：

There are 9 million bicycles in Beijing.

定義と使用法

vfprintf() 関数は、フォーマットされた文字列を指定された出力ストリーム（例：ファイルやデータベース）に書き込みます。

fprintf() とは異なり、vfprintf() のパラメータは配列内にあります。配列要素は、メイン文字列のパーセント記号（%）の位置に挿入されます。この関数は段階的に実行されます。最初の % 記号には最初の配列要素が挿入され、2番目の % 記号には2番目の配列要素が挿入され、以下同様に続きます。

注記：% 記号が arg パラメータより多い場合は、プレースホルダを使用する必要があります。プレースホルダは % 記号の後に挿入され、数字と "\$" で構成されます。例 2 を参照してください。

ヒント：関連関数：fprintf()、 printf()、 sprintf()、vprintf()とvsprintf()

構文

vfprintf(stream,format,argarray)

パラメータ 説明
stream 必須。文字列を書き込む/出力する場所を指定します。
format 必須。文字列と、その中の変数をフォーマットする方法を指定します。

可能なフォーマット値：

  • %% - パーセント記号 % を返す
  • %b - 2進数
  • %c - ASCII 値に対応する文字
  • %d - 符号付き10進数（負数、0、正数）
  • %e - 小文字の科学的記数法（例：1.2e+2）
  • %E - 大文字の科学的記数法（例：1.2E+2）
  • %u - 符号なし10進数（0以上）
  • %f - 浮動小数点数（ロケール設定）
  • %F - 浮動小数点数（非ロケール設定）
  • %g - %e と %f のうち短い方
  • %G - %E と %f のうち短い方
  • %o - 8進数
  • %s - 文字列
  • %x - 16進数（小文字）
  • %X - 16進数（大文字）

追加のフォーマット値。% と文字の間に置く必要があります（例：%.2f）：

  • + （数値の前に + または - を付けて、数値の正負を指定します。デフォルトでは、負数にのみ記号が付き、正数には記号が付きません）
  • ' （埋め文字を指定します。デフォルトはスペースです。これは幅指定子と一緒に使用する必要があります。例：%'x20s（"x" を埋め文字として使用））
  • - （変数の値を左寄せにする）
  • [0-9] （変数の値の最小幅を指定）
  • .[0-9] （小数部の桁数または最大文字列長を指定）

注記：上記のフォーマット値を複数使用する場合、それらは上記の順序で使用する必要があり、順序を入れ替えることはできません。
argarray 必須。format 文字列の % 記号に挿入されるパラメータを持つ配列。

技術詳細

戻り値： 書き込まれた文字列の長さを返します。
PHP バージョン： 5+

その他の例

例 1

テキストをファイルに書き込みます：

<?php
$num1 = 123;
$num2 = 456;
$file = fopen("test.txt","w");
vfprintf($file,"%f%f",array($num1,$num2));
?>

以下のテキストがファイル "test.txt" に書き込まれます：

123.000000456.000000

例 2

プレースホルダを使用する：

<?php
$number = 123;
$file = fopen("test.txt","w");
vfprintf($file,"With 2 decimals: %1$.2f
nWith no decimals: %1$u",array($number));
?>

以下のテキストがファイル "test.txt" に書き込まれます：

With 2 decimals: 123.00
With no decimals: 123

例 3

printf() を使用して、すべての可能なフォーマット値を示します：

<?php
$num1 = 123456789;
$num2 = -123456789;
$char = 50; // The ASCII Character 50 is 2

// Note: The format value "%%" returns a percent sign
printf("%%b = %b <br>",$num1); // Binary number
printf("%%c = %c <br>",$char); // The ASCII Character
printf("%%d = %d <br>",$num1); // Signed decimal number
printf("%%d = %d <br>",$num2); // Signed decimal number
printf("%%e = %e <br>",$num1); // Scientific notation (lowercase)
printf("%%E = %E <br>",$num1); // Scientific notation (uppercase)
printf("%%u = %u <br>",$num1); // Unsigned decimal number (positive)
printf("%%u = %u <br>",$num2); // Unsigned decimal number (negative)
printf("%%f = %f <br>",$num1); // Floating-point number (local settings aware)
printf("%%F = %F <br>",$num1); // Floating-point number (not local settings aware)
printf("%%g = %g <br>",$num1); // Shorter of %e and %f
printf("%%G = %G <br>",$num1); // Shorter of %E and %f
printf("%%o = %o <br>",$num1); // Octal number
printf("%%s = %s <br>",$num1); // String
printf("%%x = %x <br>",$num1); // Hexadecimal number (lowercase)
printf("%%X = %X <br>",$num1); // Hexadecimal number (uppercase)
printf("%%+d = %+d <br>",$num1); // Sign specifier (positive)
printf("%%+d = %+d <br>",$num2); // Sign specifier (negative)
?>
