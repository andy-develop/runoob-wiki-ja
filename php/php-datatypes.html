PHP データ型

PHP 変数は異なるタイプのデータを格納でき、異なるデータ型は異なることを行えます。

PHP は以下のデータ型をサポートしています:

  • String（文字列）
  • Integer（整数型）
  • Float（浮動小数点数型）
  • Boolean（ブール型）
  • Array（配列）
  • Object（オブジェクト）
  • NULL（null 値）
  • Resource（リソース型）

PHP 文字列

文字列は、 "Hello world!" のような一連の文字の並びです。

任意のテキストをシングルクォートとダブルクォートで囲むことができます：

例

<?php $x = "Hello world!"; echo $x; echo "<br>"; $x = 'Hello world!'; echo $x; ?>

PHP 整数型

整数は小数部のない数です。

整数の規則:

  • 整数は少なくとも1桁の数字 (0-9) を含む必要があります
  • 整数にカンマやスペースは含められません
  • 整数は小数点を持ちません
  • 整数は正または負の値にできます
  • 整数型は3つの形式で指定できます: 10進数、16進数（0x をプレフィックスとする）、または8進数（プレフィックスは 0）です。

次の例では、さまざまな数値をテストします。

PHP var_dump() この関数は変数のデータ型と値を返します：

例

<?php $x = 5985; var_dump($x); echo "<br>"; $x = -345; //負数 var_dump($x); echo "<br>"; $x = 0x8C; //16進数 var_dump($x); echo "<br>"; $x = 047; //8進数 var_dump($x); ?>

PHP 浮動小数点数型

浮動小数点数は小数部を持つ数、または指数形式の数です。

次の例では、さまざまな数値をテストします。 PHP var_dump() 関数は変数のデータ型と値を返します：

例

<?php $x = 10.365; var_dump($x); echo "<br>"; $x = 2.4e3; var_dump($x); echo "<br>"; $x = 8E-5; var_dump($x); ?>

PHP ブール型

ブール型は TRUE または FALSE です。

$x=true;
$y=false;

ブール型は通常、条件判断に使用されます。次の章では、条件制御について詳しく学びます。

PHP 配列

配列は1つの変数に複数の値を格納できます。

次の例では配列を作成し、PHP var_dump() 関数を使用して配列のデータ型と値を返します：

例

<?php $cars=array("Volvo","BMW","Toyota"); var_dump($cars); ?>

PHP オブジェクト

オブジェクトデータ型はデータの格納にも使用できます。

PHP では、オブジェクトは宣言する必要があります。

まず、class キーワードを使用してクラスオブジェクトを宣言する必要があります。クラスはプロパティとメソッドを含むことができる構造です。

次に、クラス内でデータ型を定義し、インスタンス化したクラスでそのデータ型を使用します：

例

<?php class Car { var $color; function __construct($color="green") { $this->color = $color; } function what_color() { return $this->color; } } ?>

PHP NULL 値

NULL 値は変数に値がないことを示します。NULL はデータ型が NULL の値です。

NULL 値は変数が空かどうかを示します。同様に、データの空値と NULL 値の違いにも使用できます。

変数の値を NULL に設定することで、変数のデータをクリアできます：

例

<?php $x="Hello world!"; $x=null; var_dump($x); ?>

PHP リソース型

PHP のリソース (resource) は、外部リソースへの参照を保持する特別な変数です。

一般的なリソースデータ型には、開かれたファイル、データベース接続、グラフィックキャンバス領域などがあります。

リソース型変数は、開かれたファイル、データベース接続、グラフィックキャンバス領域などの特別なハンドルを保持するため、他の型の値をリソースに変換しても意味がありません。

使用get_resource_type()関数はリソース (resource) 型を返すことができます：

get_resource_type(resource $handle): string

この関数は、渡されたリソースの型を表す文字列を返します。引数が有効なリソースでない場合、エラーが発生します。

次の例のとおりです：

例

<?php
$c = mysql_connect();
echo get_resource_type($c)."\n";
// 出力：mysql link

$fp = fopen("foo","w");
echo get_resource_type($fp)."\n";
// 出力：file

$doc = new_xmldoc("1.0");
echo get_resource_type($doc->doc)."\n";
// 出力：domxml document
?>
