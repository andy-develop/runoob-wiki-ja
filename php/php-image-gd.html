PHP 画像処理

PHPは豊富な画像処理関数を提供しており、主に以下のものがあります：

関数説明
gd_info() 現在インストールされているGDライブラリの情報を取得する
getimagesize() 画像情報を取得する
getimagesizefromstring() 画像情報を取得する
image_type_to_extension() 画像の拡張子を取得する
image_type_to_mime_type() 画像のMIMEタイプを返す
image2wbmp() WBMP画像を出力する
imageaffine() アフィン変換後の画像を返す
imageaffinematrixconcat() 2つの行列を連結する
imageaffinematrixget() 行列を取得する
imagealphablending() 画像の混色モードを設定する
imageantialias() アンチエイリアス（antialias）機能を使用するかどうか
imagearc() 楕円弧を描画する
imagechar() 横書き文字を書き出す
imagecharup() 文字を垂直に描画する
imagecolorallocate() 画像に色を割り当てる
imagecolorallocatealpha() 画像に色と透明度を割り当てる
imagecolorat() 特定のピクセルの色インデックス値を取得する
imagecolorclosest() 指定した色に最も近い色のインデックス値を取得する
imagecolorclosestalpha() 指定した色と透明度に最も近い色のインデックスを取得する
imagecolorclosesthwb() 指定した色に最も近い色相、白、黒のインデックスを取得する
imagesx() 、imagesy() 画像の幅と高さを取得する

GD ライブラリ

PHPの画像処理関数を使用するには、GDサポートライブラリをロードする必要があります。php.iniでGDライブラリがロードされていることを確認してください：

Windowsサーバーの場合：

extension = php_gd2.dll

LinuxおよびMacシステムの場合：

extension = php_gd2.so

gd_info() 関数を使用すると、現在インストールされているGDライブラリの情報を確認できます：

<?php
var_dump(gd_info());
?>
