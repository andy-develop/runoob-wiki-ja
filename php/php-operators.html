PHP では、基本的な代入演算子は=です。これは、左のオペランドが右の式の値に設定されることを意味します。つまり、$x = 5の値は 5 です。

x /= y x = x / y 除
x %= y x = x % y 剰余（除算の余り）

三項演算子

もう 1 つの条件演算子は「?:」（または三項）演算子です。

構文

(expr1) ? (expr2) : (expr3)

expr1 が TRUE と評価された場合の値は expr2 で、expr1 が FALSE と評価された場合の値は expr3 です。

PHP 5.3 以降、三項演算子の中央部分を省略できます。式 expr1 ?: expr3 は、expr1 が TRUE と評価された場合に expr1 を返し、それ以外の場合に expr3 を返します。

例

以下の例では、$_GET リクエストに user 値が含まれているかどうかを判定し、含まれていれば $_GET['user'] を返し、そうでなければ nobody を返します：

例

<?php //通常の書き方 $username = isset($_GET['user']) ? $_GET['user'] : 'nobody'; echo $username, PHP_EOL; //PHP 5.3+ バージョンの書き方 $username = $_GET['user'] ?: 'nobody'; echo $username, PHP_EOL; ?>

注意：PHP_EOL改行文字であり、より多くのプラットフォームと互換性があります。

PHP7+ バージョンでは、NULL 合体演算子が追加されました。??、例は次のとおりです：

例

<?php //$_GET['user'] が存在しない場合は 'nobody' を返し、それ以外の場合は $_GET['user'] の値を返します。 $username = $_GET['user'] ?? 'nobody'; //類似した三項演算子 $username = isset($_GET['user']) ? $_GET['user'] : 'nobody'; ?>

組み合わせ比較演算子 (PHP7+)

PHP7+ は結合比較演算子（combined comparison operator）をサポートしており、これは宇宙船演算子とも呼ばれます。記号は<=>。結合比較演算子を使用すると、2つの変数を簡単に比較できます。もちろん、数値データの比較に限りません。

構文は次のとおりです：

$c = $a <=> $b;

説明は次のとおりです：

  • もし $a > $bの場合、$cの値は1。
  • もし$a == $bの場合、$cの値は0。
  • もし$a < $bの場合、$cの値は-1。

例は次のとおりです：

例

<?php //整数型 echo 1 <=> 1; // 0 echo 1 <=> 2; // -1 echo 2 <=> 1; // 1 //浮動小数点型 echo 1.5 <=> 1.5; // 0 echo 1.5 <=> 2.5; // -1 echo 2.5 <=> 1.5; // 1 //文字列 echo "a" <=> "a"; // 0 echo "a" <=> "b"; // -1 echo "b" <=> "a"; // 1 ?>

演算子の優先順位

次の表は、優先順位の高い順に演算子を一覧にしています。同じ行の演算子は同じ優先順位を持ち、この場合、それらの結合方向が評価の順序を決定します。

説明：左 ＝ 左から右、右 ＝ 右から左。

結合方向 演算子 追加情報
无 clone new clone と new
左 [ array()
右 ++ -- ~ (int) (float) (string) (array) (object) (bool) @ 型とインクリメント／デクリメント
无 instanceof 型
右 ! 論理演算子
左 * / % 算術演算子
左 + – . 算術演算子と文字列演算子
左 << >> ビット演算子
无 == != === !== <> 比較演算子
左 & ビット演算子と参照
左 ^ ビット演算子
左 | ビット演算子
左 && 論理演算子
左 || 論理演算子
左 ? : 三項演算子
右 = += -= *= /= .= %= &= |= ^= <<= >>= => 代入演算子
左 and 論理演算子
左 xor 論理演算子
左 or 論理演算子
左 , 複数の箇所で使用

演算子の優先順位では、or と ||、&& と and はすべて論理演算子であり、効果は同じですが、優先順位は異なります。

例

<?php //優先順位： && > = > and //優先順位： || > = > or $a = 3; $b = false; $c = $a or $b; var_dump($c); //ここでの $c は int 値 3 であり、boolean 値 true ではありません。 $d = $a || $b; var_dump($d); //ここでの $d は boolean 値 true です。 ?>

上記の例の出力結果は次のとおりです：

int(3)
bool(true)

括弧の使用

括弧の対応を使用して演算の順序を明確に示し、演算子の優先順位や結合性に頼らないことで、通常はコードの可読性を高めることができます。

例

<?php //括弧を優先する演算 $a = 1; $b = 2; $c = 3; $d = $a + $b * $c; echo $d; echo "\n"; $e = ($a + $b) * $c; //括弧を使用する echo $e; echo "\n"; ?>

上記の例の出力結果は次のとおりです：

7
9
