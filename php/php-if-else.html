PHP If...Elseステートメント

条件ステートメントは、異なる条件に応じて異なるアクションを実行するために使用されます。

PHP 条件ステートメント

コードを書くとき、さまざまな判断に応じて異なるアクションを実行する必要がよくあります。コード内で条件ステートメントを使用してこのタスクを実行できます。

PHP では、次の条件ステートメントが用意されています。

  • if ステートメント- 条件が成立するときにコードを実行します
  • if...else ステートメント- 条件が成立するときにあるコードブロックを実行し、条件が成立しないときに別のコードブロックを実行します
  • if...elseif....else ステートメント- 複数の条件のいずれかが成立するときにコードブロックを実行します
  • switch ステートメント- 複数の条件のいずれかが成立するときにコードブロックを実行します

PHP - if ステートメント

if ステートメントは、指定された条件が成立する場合にのみコードを実行します。。

構文

if (条件) {
    条件成立时要执行的代码;
}

現在時刻が 20 未満の場合、次の例は "Have a good day!" を出力します。

例

<?php $t=date("H"); if ($t<"20") { echo "Have a good day!"; } ?>

PHP - if...else ステートメント

条件が成立するときにあるコードブロックを実行し、条件が成立しないときに別のコードブロックを実行するには、if....else ステートメントを使用してください。

構文

if (条件) {
    条件成立时执行的代码;
} else {
    条件不成立时执行的代码;
}

現在時刻が 20 未満の場合、次の例は "Have a good day!" を出力し、それ以外の場合は "Have a good night!" を出力します。

例

<?php $t=date("H"); if ($t<"20") { echo "Have a good day!"; } else { echo "Have a good night!"; } ?>

例を実行 »

PHP - if...elseif....else ステートメント

複数の条件のいずれかが成立するときにコードブロックを実行するには、if....elseif...else ステートメントを使用してください。.

構文

if (条件) {
    if 条件成立时执行的代码;
} elseif (条件) {
    elseif 条件成立时执行的代码;
} else {
    条件不成立时执行的代码;
}

現在時刻が 10 未満の場合、次の例は "Have a good morning!" を出力します。現在時刻が 10 以上 20 未満の場合は "Have a good day!" を出力し、それ以外の場合は "Have a good night!" を出力します。

例

<?php $t=date("H"); if ($t<"10") { echo "Have a good morning!"; } elseif ($t<"20") { echo "Have a good day!"; } else { echo "Have a good night!"; } ?>

    最後の2つの例の実行結果が正しくないと感じる場合、それは PHP 5.0 以降、PHP でシステム時刻を取得すると、現在時刻より 8 時間少ないためです。理由は、PHP.ini で timezone が設定されていない場合、PHP は UTC 時刻を使用するため、中国時間では 8 時間少なくなります。したがって、あなたの時刻はすべて -8 する必要があります。なのでコードは問題ありません。

    解決方法：

    1. PHP.ini ファイルで設定を変更します。

    [Date]
; Defines the default timezone used by the date functions
date.timezone = Asia/Shanghai

    ここは本当に…設定でき、Shanghai,Chongqin,Hong_Kong,TaiBei...などがありますが、Beijing が見つからないんです。理由は分かりません。

    2. PHP プログラム実行時に設定します。

    <?php
if(date_default_timezone_get() != "1Asia/Shanghai") date_default_timezone_set("Asia/Shanghai");
?>

    注意：date_default_timezone_get取得した時刻設定の中には1があり、それもどういうわけかよく分かりません。

    3. 時刻を使用するときに自分でさらに8*3600秒を加えても大丈夫です。

    <?php
echo date("Y-m-d H:i:s",time()+8*3600);
?>

    ロジックが比較的単純な判定シナリオでは、判定の書き方の代わりに式を直接使用できます。コードの可読性を高めると同時に、コードをより美しくすることもできます。

    // Eg1
[$name, $age] = ['Jack', null];  // 解构赋值

// 普通写法
if ($name == 'Jack') {
    $age = 20;
}

// 免 if 写法
$name == 'Jack' and $age = 20;

[$a, $b] = [null, null];
$name == 'Jack' and ([$a, $b] = ['value', 'value']); // 多变量赋值写法

    この書き方は、関数やメソッドの呼び出しにも同様に適用できます。

    // Eg2
[$name, $list] = ['Jack', []];

class A_Class {
    public function _action() {}
}

// 普通写法
if ($name == 'Jack') {
    array_push($list, $name);
    (new A_Class) -> _action(); // 构造函数无参数实例化时无需写括号
}

// 免 if 写法
$name == 'Jack' and array_push($list, $name);
$name == 'Jack' and (new A_Class) -> _action();
