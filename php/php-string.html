PHP 文字列変数

文字列変数はテキストを保存および処理するために使用されます。

PHP の文字列変数

文字列変数は文字を含む値を保持するために使われます。

文字列を作成した後、それを操作できます。関数で直接文字列を使用するか、変数に保存することができます。

以下の例では、txt という名前の文字列変数を作成し、"Hello world!" を代入しています。次に、txt 変数の値を出力します：

例

<?php
$txt="Hello world!";
echo $txt;
?>

例を実行 »

注：変数にテキスト値を代入するときは、テキスト値を一重引用符または二重引用符で囲むことを忘れないでください。

次に、文字列を操作するために一般的に使用される関数と演算子を見てみましょう。

PHP 連結演算子

PHP では、文字列演算子は1つだけです。

連結演算子.2つの文字列値を連結するために使用されます。

以下の例では、2つの文字列変数を連結する方法を示しています：

例

<?php
$txt1="Hello world!";
$txt2="What a nice day!";
echo $txt1 . " " . $txt2;
?>

上記のコードは次のように出力されます：Hello world! What a nice day!

ヒント：上記のコードでは、連結演算子を2回使用しています。これは2つの文字列の間にスペースを挿入する必要があるためです。

PHP strlen() 関数

文字列値の長さを知ることが役立つ場合があります。

strlen() 関数は文字列の長さ（バイト数）を返します。

以下の例では、文字列 "Hello world!" の長さを返します：

例

<?php
echo strlen("Hello world!");
?>

例を実行 »

上記のコードは次のように出力されます：12

ヒント：strlen() はループや他の関数でよく使用されます。その場合、文字列がいつ終わるかを判断することが重要だからです。（例えば、ループでは、文字列の最後の文字の後にループを終了する必要があります。）

PHP strpos() 関数

strpos() 関数は、文字列内で特定の文字または指定されたテキストを検索するために使用されます。

文字列内で一致が見つかった場合、この関数は最初に一致した文字の位置を返します。一致が見つからない場合は FALSE を返します。

以下の例では、文字列 "Hello world!" 内でテキスト "world" を検索します：

例

<?php
echo strpos("Hello world!","world");
?>

例を実行 »

上記のコードは次のように出力されます：6

ヒント：上記の例では、文字列 "world" の位置は 6 です。6 であって 7 ではない理由は、文字列内の最初の文字の位置が 0 であり、1 ではないためです。
