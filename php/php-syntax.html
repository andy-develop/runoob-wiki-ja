PHP 構文

PHP スクリプトはサーバー上で実行され、純粋な HTML の結果をブラウザに送り返します。

PHP は<?php ?>コードを包みます。

基本的な PHP 構文

PHP スクリプトはドキュメント内の任意の場所に置くことができます。

PHP スクリプトは<?phpで始まり、?>で終わります：

<?php
// PHP 代码
?>

PHP ファイルのデフォルトの拡張子は.php。

PHP ファイルには通常、HTML タグと一部の PHP スクリプトコードが含まれます。

例

<?php
// PHP コードは <?php と ?> の間に書きます
echo "Hello, PHP!";
?>
  • <?php ...?>は標準の PHP タグです。
  • echo は内容を出力するために使われます。
  • 各ステートメントの末尾にはセミコロンを付ける必要があります。;。

以下に、ブラウザに「Hello World!」というテキストを出力する簡単な PHP ファイルの例を示します：

<!DOCTYPE html>
<html>
<body>

<h1>My first PHP page</h1>

<?php
echo "Hello World!";
?>

</body>
</html>

PHP の各コード行はセミコロンで終わる必要があります。セミコロンは命令セットを区切るための区切り文字です。

PHP には、ブラウザにテキストを出力するための基本的な命令が2つあります：echoとprint。

PHP のコメント

PHP では、コメントはコードの役割を説明するために使われ、実行されず、ページに出力されることもありません。

コメントには主に3つの形式があります：

1. 単行コメント（2 つの書き方）

使用//

<?php
// 这是单行注释
echo "Hello"; // 也可以放在语句后面
?>

使用#

<?php
# 这是另一种单行注释
echo "World";
?>

特徴：

  • から// 或 #で始まり、その行の終わりまで続きます。
  • 短い説明によく使われます。

2. 複数行コメント（ブロックコメント）

使用/* ... */</p> 

<?php
/*
这是多行注释
可以写多行文字
不会被执行
*/
echo "PHP";
?>

特徴：

  • 以 /*で始まり、*/で終わります。
  • 複数行にわたって書くことができます。
  • 長いコードの説明や関数のコメントなどによく使われます。

3. ドキュメントコメント（DocBlock コメント）

これは複数行コメントの特別な形式で、API ドキュメントの生成に使用され、クラスや関数などの説明に適しています。

<?php
/**
 * 打印问候语
 *
 * @param string $name 用户名
 * @return string 返回问候语
 */
function sayHello($name) {
    return "Hello, $name!";
}
?>

特徴：

  • 用 /** ... */で囲みます（アスタリスク2つに注意）
  • @param、@return、@var、@author をサポートします。
  • よく IDE やドキュメント生成ツール（phpDocumentor など）と組み合わせて使われます。
用途 推奨されるコメント形式 例
1行のコードを簡単に説明する // 或 # // 出力情報
コードブロックを説明する /* ... */ 論理ブロック分けに使うコメント
関数/クラスのドキュメント説明 /** ... */ DocBlock パラメータ、戻り値、用途などを説明するために使う

例

<html>
<body>

<?php
// これは PHP の単行コメントです

/*
これは

コメント
*/
?>

</body>
