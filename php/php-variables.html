PHP 変数

変数は情報を格納するための「コンテナ」です：

サンプル

<?php $x=5; $y=6; $z=$x+$y; echo $z; ?>

サンプルを実行 »

代数と同様に

x=5
y=6
z=x+y

代数では、文字（x など）を使用し、それに値（5 など）を代入します。

上記の式 z=x+y から、z の値が 11 であると計算できます。

PHP では、これらの文字は変数。

変数はデータを格納するためのコンテナです。

PHP 変数

代数と同様に、PHP 変数には値（x=5）または式（z=x+y）を代入できます。

変数名は非常に短い名前（x や y など）も、より説明的な名前（age、carname、totalvolume など）も使用できます。

PHP 変数の規則：

  • 変数は $ 記号で始まり、その後に変数名が続きます
  • 変数名は英文字またはアンダースコア文字で始まる必要があります
  • 変数名は英文字、数字、およびアンダースコア（A-z、0-9 および _ ）のみを含めることができます
  • 変数名にスペースを含めることはできません
  • 変数名は大文字と小文字を区別します（$y と $Y は別の変数です）
PHP の文と PHP 変数はどちらも大文字と小文字を区別します。

PHP 変数の作成（宣言）

PHP には変数を宣言するコマンドはありません。

変数は、最初に値を代入したときに作成されます：

サンプル

<?php $txt="Hello world!"; $x=5; $y=10.5; ?>

サンプルを実行 »

上記の文の実行中、変数txtは値を保存しますHello world!、かつ変数xは値を保存します5。

注：変数にテキスト値を代入するときは、テキスト値を引用符で囲んでください。

PHP は弱い型付けの言語です

上記のサンプルでは、PHP にその変数のデータ型を宣言する必要がないことに気付きます。

PHP は変数の値に基づいて、変数を自動的に正しいデータ型に変換します。

強い型付けのプログラミング言語では、変数を使用する前に、変数の型と名前を宣言（定義）する必要があります。

PHP 変数のスコープ

変数のスコープとは、スクリプト内で変数が参照・使用できる部分のことです。

PHP には4つの異なる変数スコープがあります：

  • local
  • global
  • static
  • parameter

ローカルスコープとグローバルスコープ

すべての関数の外部で定義された変数は、グローバルスコープを持ちます。関数内を除いて、グローバル変数はスクリプトのどの部分からでもアクセスできます。関数内でグローバル変数にアクセスするには、global キーワードを使用する必要があります。

PHP 関数の内部で宣言された変数はローカル変数であり、関数の内部でのみアクセスできます：

サンプル

<?php
$x=5; // グローバル変数

function myTest()
{
    $y=10; // ローカル変数
    echo "<p>関数内の変数をテスト:<p>";
    echo "変数 x は: "$x";
    echo "<br>";
    echo "変数 y は: "$y";
}

myTest();

echo "<p>関数外の変数をテスト:<p>";
echo "変数 x は: "$x";
echo "<br>";
echo "変数 y は: "$y";
?>

上記の例では、myTest() 関数は $x と $y 変数を定義しています。 $x 変数は関数の外で宣言されているため、グローバル変数です。 $y 変数は関数内で宣言されているため、ローカル変数です。

myTest() 関数を呼び出して2つの変数の値を出力すると、関数はローカル変数 $y の値を出力しますが、$x の値は出力できません。$x 変数は関数の外で定義されているため、関数内で使用できないからです。関数内でグローバル変数にアクセスするには、global キーワードを使用する必要があります。

次に、myTest() 関数の外で2つの変数の値を出力すると、関数はグローバル変数 $x の値を出力しますが、$y の値は出力できません。$y 変数は関数内で定義されており、ローカル変数であるためです。

異なる関数内で同じ変数名を使用できます。これらの関数内で定義された変数名はローカル変数であり、その関数内でのみ有効だからです。

PHP の global キーワード

global キーワードは、関数内でグローバル変数にアクセスするために使用します。

関数内で関数外に定義されたグローバル変数にアクセスするには、関数内の変数の前に global キーワードを付ける必要があります：

サンプル

<?php $x=5; $y=10; function myTest() { global $x,$y; $y=$x+$y; } myTest(); echo $y; //出力 15 ?>

サンプルを実行 »

PHP はすべてのグローバル変数を $GLOBALS[index] という名前の配列に格納します。index変数。変数の名前を保存します。この配列は関数の内部からアクセスでき、グローバル変数を直接更新するためにも使用できます。

上記の例は次のように書くこともできます：

サンプル

<?php $x=5; $y=10; function myTest() { $GLOBALS['y']=$GLOBALS['x']+$GLOBALS['y']; } myTest(); echo $y; ?>

サンプルを実行 »

Static スコープ

関数の実行が完了すると、そのすべての変数は通常削除されます。ただし、ローカル変数を削除したくない場合もあります。

これを行うには、変数を最初に宣言するときにstaticキーワードを使用します：

サンプル

<?php function myTest() { static $x=0; echo $x; $x++; echo PHP_EOL; //改行 } myTest(); myTest(); myTest(); ?>

サンプルを実行 »

その後、関数を呼び出すたびに、その変数は前回関数が呼び出されたときの値を保持します。

注：この変数は依然として関数のローカル変数です。

パラメータのスコープ

パラメータ（引数）は、呼び出し元のコードから関数に値を渡すためのローカル変数です。

パラメータは、関数宣言の一部としてパラメータリスト内で宣言されます：

サンプル

<?php function myTest($x) { echo $x; } myTest(5); ?>

これについては「PHP 関数」の章で詳しく説明します。

    PHP 変数のスコープ

    変数のスコープとは、スクリプト内で変数が参照および使用できる部分であり、PHP には4つの異なる変数スコープがあります：

    番号 スコープ 説明
    1 local ローカルスコープ
    2 global グローバルスコープ
    3 static 静的スコープ
    4 parameter 関数パラメータのスコープ

    1、local（ローカル）—— ローカル変数のスコープ

    PHP 関数の内部で宣言された変数はローカル変数であり、関数の内部でのみアクセスできます。

    <?php
function test()
{
    $a = 15;
    echo "内部输出结果：" . $a;
}
echo "外部输出结果：" . $a;  // 无法访问变量 a
echo PHP_EOL;
test();
?>

    出力結果：

    外部输出结果：
内部输出结果：15

    2、global（グローバル）—— グローバル変数のスコープ

    すべての関数の外部で定義された変数はグローバル変数であり、関数内を除いて、グローバル変数はスクリプトのどの部分からでもアクセスできます。関数内でグローバル変数にアクセスするには、global キーワードを使用する必要があります。

    <?php
$x = 5;
$y = 10;
$z = 0;

function test()
{
    global$x,$y,$z;
    $z = $x + $y;
}

test();
echo $z;
?>

    結果：15

    PHP はすべてのグローバル変数を$GLOBALS[index]という名前の配列に格納します。index変数の名前を保存します。

    この配列は関数の内部からアクセスでき、グローバル変数を直接更新するためにも使用できます。

    <?php
$x = 5;
$y = 10;
$z = 0;
function test()
{
    $GLOBALS['z'] = $GLOBALS['x']+$GLOBALS['y'];
}

Test();
echo $z;
?>

    結果：15

    3、static（静的）—— static スコープ

    関数の実行が完了すると、そのすべての変数は通常削除されます。

    ただし、ローカル変数を削除したくない場合があります。そのためには、最初に変数を宣言するときに static キーワードを使用してください。

    関数が完了すると、そのすべての変数は通常削除されます。ただし、ローカル変数を削除したくない場合もあります。

    <?php
function test() {
    static $x=0;
    echo $x . " ";
    $x++;
}

test();
test();
test();
test();
?>

    結果：0 1 2 3

    関数を呼び出すたびに、この変数は前回呼び出されたときの値を保持します。

    4、parameter（パラメータ）——パラメータスコープ

    パラメータは、呼び出しコードから関数に値を渡すためのローカル変数です。

    ローカル変数とグローバル変数の優先順位について：PHPでは関数にはそれぞれ独自のスコープがあるため、ローカル変数の優先順位はグローバル変数よりも高くなります（この変数を宣言する前の場合）。宣言すると、この変数はローカル変数になります。値を変更すると、グローバル変数の値も変わります。

    <?php
$a = 10;
$b = 5;
function test()
{
    $a = 15;
    $b = 5;
    $z = $a-$b;
    echo $z;
}

test();

function test1()
{
         global $a,$b;
         $a = 15;
         $b = 5;
         $z = $a-$b;
         echo PHP_EOL;
         echo $z;
}

test1();

function test2()
{
    global $a,$b;
    $z= $a-$b;
    echo PHP_EOL;
    echo $z;
}

test2();
?>

    結果：10 10 10

    生活の例を使ってクラスのプロパティとメソッドを説明する

    あなたがオンラインストアを開発しているとします。すべての製品を管理するために「Product」クラスを定義する必要があります。各製品には、名前、説明、価格などの共通の属性と、サイズ、色、重量などの異なる属性があります。

    このシナリオでは、各製品をクラスとみなし、各製品のプロパティとメソッドをそのクラスのプロパティとメソッドとみなすことができます。例えば、「Product」という名前のクラスを定義して製品を表すことができます。このクラスには次のプロパティとメソッドがあります。

    プロパティ：

    • $name: 製品名
    • $description: 製品の説明
    • $price: 製品価格
    • $size: 製品サイズ
    • $color: 製品の色
    • $weight: 製品の重量

    メソッド：

    • setName($name): 製品名を設定する
    • setDescription($description): 製品の説明を設定する
    • setPrice($price): 製品価格を設定する
    • setSize($size): 製品サイズを設定する
    • setColor($color): 製品の色を設定する
    • setWeight($weight): 製品の重量を設定する

    プログラミングに例えると、「Product」クラスを定義することで、すべての製品を管理できます。複数のインスタンスを作成して異なる製品を表すことができ、各インスタンスには独自のプロパティとメソッドのセットがあり、クラスのメソッドを呼び出すことでこれらのプロパティにアクセスして変更できます。このようにして、コードを論理的な単位に整理し、クラスのプロパティとメソッドを使用してさまざまな機能を実装できます。

    生活の例を使ってクラススコープを説明する

    あなたが学生だとします。あなたの学校には多くの教師がいます。各教師には絵を描く、バスケットボールをするなどの特別なスキルがあります。このシナリオでは、各教師をクラスとみなし、各スキルをこのクラスのプロパティまたはメソッドとみなすことができます。

    特定のスキルを学ぶ必要がある場合、そのスキルを持つ教師を見つけて学ぶ必要があります。この過程では、その教師のスキルにのみアクセスでき、他の教師のスキルにはアクセスできません。これは、各教師のスキルがその教師のクラススコープにのみ属しているためです。

    プログラミングに例えると、クラススコープとは、クラス内で定義されたプロパティとメソッドがそのクラス内でのみアクセスできることを意味します。つまり、クラスのプロパティやメソッドにアクセスする必要がある場合は、まずそのクラスのインスタンスを作成し、そのインスタンスを使用してプロパティやメソッドにアクセスする必要があります。生活の例と同様に、この制限はコードの安全性と保守性を向上させ、コードをより理解しやすく整理しやすくします。

    生活を使った

    あなたがある会社で働く従業員だとします。あなたの会社には、従業員の出勤日数を記録する装置があります。会社に到着して仕事を始めるたびに、この装置を使用して打刻し、出勤時間を記録する必要があります。

    このシナリオでは、この装置は複数回の打刻の間で状態を保持するため、静的変数とみなすことができます。打刻するたびに、装置は出勤日数を記録し、次回の打刻時に使用できるようにこの数値をメモリに保存します。これにより、初日であろうと100日目であろうと、この装置は正しく出勤日数を計算できます。

    プログラミングに例えると、静的変数は関数の複数回の呼び出し間で状態を共有し、次回関数を呼び出すときに使用できるため、コードの効率と保守性が向上します。

    生活の中の例を使って、パラメータースコープとは何かを説明する

    生活の中で、「部屋の賃貸」はパラメータースコープの概念のたとえとして使えます。

    あなたは不動産仲介業者だとします。あなたの顧客は家を借りたいと考えています。あなたの仕事は、彼らに適した家を見つけることです。この目標を達成するには、顧客の要件を理解する必要があります。例えば、寝室がいくつ欲しいか、バスルームがいくつ欲しいかなどです。これらの要件は関数のパラメーターとみなすことができます。

    顧客の要件を理解したら、それらの要件に合った家を見つけることができます。このプロセスでは、関数の内部でこれらの要件を処理するだけでよく、他の顧客が求める可能性のある要件を考慮する必要はありません。これがパラメータースコープの概念です。関数のパラメーターは関数の内部でのみ有効であり、関数の外部の他のコードからは見えません。

    プログラミングに例えると、パラメータースコープとは、関数のパラメーターが関数の内部でのみ有効であり、関数の外部のコードからは見えないことを意味します。つまり、関数の内部でこれらのパラメーターを使用していくつかの操作を実行しても、その操作が他のコードに影響を与えることを心配する必要はありません。
