PHP 画像処理

imagecolorclosest — 指定された色に最も近い色のインデックス値を取得します。

構文

int imagecolorclosest ( resource $image , int $red , int $green , int $blue )

画像パレット内で指定されたRGB値に最も「近い」色を返します。

指定された色とパレット内の各色の「距離」の計算方法は、RGB値を3次元空間内の点の座標とみなすものです。

ファイルから画像を作成した場合、画像で使用されている色のみが識別されます。パレットにのみ存在する色は識別されません。
