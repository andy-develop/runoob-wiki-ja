PHP PDO トランザクションと自動コミット

PHP PDO リファレンスマニュアル

これで PDO に接続されました。クエリを開始する前に、PDO がトランザクションをどのように管理するかを理解する必要があります。

トランザクションは4つの特性（ACID）をサポートしています：

  • 原子性（Atomicity）
  • 一貫性（Consistency）
  • 分離性（Isolation）
  • 永続性（Durability）

わかりやすく言うと、トランザクション内で実行される操作は、段階的に実行された場合でも、データベースに安全に適用されることが保証され、コミット時に他の接続からの干渉を受けません。

トランザクション操作は、リクエストに応じて自動的に取り消すこともできます（まだコミットされていない場合）。これにより、スクリプト内でのエラー処理が容易になります。

トランザクションは通常、一連の変更を「蓄積」してから同時に有効にすることで実現されます。これにより、これらの変更の効率を大幅に向上させることができます。

言い換えれば、トランザクションはスクリプトを高速化し、さらに堅牢にする可能性があります（ただし、この利点を得るにはトランザクションを正しく使用する必要があります）。

残念ながら、すべてのデータベースがトランザクションをサポートしているわけではありません。そのため、最初に接続を開くとき、PDO はいわゆる「自動コミット」モードで実行する必要があります。

自動コミットモードとは、データベースがサポートしている場合、実行される各クエリには独自の暗黙的なトランザクションがあり、データベースがトランザクションをサポートしていない場合はありません。

トランザクションが必要な場合は、PDO::beginTransaction() メソッドを使用して開始する必要があります。基盤となるドライバーがトランザクションをサポートしていない場合、PDOException 例外がスローされます（エラー処理設定に関係なく、これは重大なエラー状態です）。

トランザクションを開始したら、トランザクション内のコードが正常に実行されたかどうかに応じて、PDO::commit() または PDO::rollBack() で完了できます。

注意：PDO はドライバーレイヤーでのみトランザクション処理能力があるかどうかをチェックします。特定の実行時条件によりトランザクションが利用できず、データベースサービスがトランザクション開始要求を受け入れる場合、PDO::beginTransaction() はエラーなしで TRUE を返します。 MySQL データベースの MyISAM データテーブルでトランザクションを使用しようとすると、良い例になります。

スクリプトが終了するか接続が閉じられるときに、未完了のトランザクションがまだある場合、PDO はそのトランザクションを自動的にロールバックします。この安全策は、スクリプトが予期せず終了したときに不整合が発生するのを防ぐのに役立ちます。明示的にトランザクションをコミットしていない場合は、どこかでエラーが発生したと想定され、データの安全性を確保するためにロールバックが実行されます。

注意：PDO::beginTransaction() によってトランザクションを開始した後にのみ、自動ロールバックが発生する可能性があります。手動でクエリを発行してトランザクションを開始した場合、PDO はそれを認識できないため、必要に応じてロールバックできません。

トランザクションでのバッチ処理の実行：

次の例では、新しい従業員のために一連のエントリを作成し、ID として 23 を割り当てるとします。この人の基本データを登録するだけでなく、給与も記録する必要があります。

2 つの更新は個別に実行するのは簡単ですが、PDO::beginTransaction() と PDO::commit() の呼び出しで囲むことで、変更が完了するまで他の人にはこれらの変更が見えないことを保証できます。

エラーが発生した場合、catch ブロックはトランザクション開始以降に発生したすべての変更をロールバックし、エラーメッセージを出力します。

<?php
try {
  $dbh = new PDO('odbc:SAMPLE', 'db2inst1', 'ibmdb2', 
      array(PDO::ATTR_PERSISTENT => true));
  echo "Connected\n";
} catch (Exception $e) {
  die("Unable to connect: " . $e->getMessage());
}

try {  
  $dbh->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

  $dbh->beginTransaction();
  $dbh->exec("insert into staff (id, first, last) values (23, 'Joe', 'Bloggs')");
  $dbh->exec("insert into salarychange (id, amount, changedate) 
      values (23, 50000, NOW())");
  $dbh->commit();
  
} catch (Exception $e) {
  $dbh->rollBack();
  echo "Failed: " . $e->getMessage();
}
?>

トランザクション内での変更に限定されず、複雑なクエリを発行してデータを取得したり、その情報を使用してさらに多くの変更やクエリを構築したりすることもできます。トランザクションがアクティブな間、他の人は操作の進行中に変更を加えることができないことが保証されます。
