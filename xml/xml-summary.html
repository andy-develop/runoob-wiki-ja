XML まとめ

XML はデータの交換、共有、保存に使用できます。

XML文書形成ツリー構造、「ルート」と「リーフ」の分岐から始まります。

XML には非常に単純な構文規則があります。正しい構文を持つ XML は「整形式」です。有効な XML は、DTDに対して検証されます。

XSLTXML を HTML などの他の形式に変換するために使用されます。

すべての最新ブラウザには組み込みのXML パーサーがあり、XML を読み取って操作できます。

DOM（Document Object Model）は XML にアクセスする標準的な方法を定義します。

XMLHttpRequestこのオブジェクトは、Web ページの読み込み後にサーバーと通信する方法を提供します。

XML 名前空間要素名の衝突を避ける方法を提供します。

CDATA領域内のテキストはパーサーによって無視されます。

私たちのXML サンプルは、この XML チュートリアルのまとめも表しています。

次に何を学びますか？

XML DOM と XSLT を学ぶことをお勧めします。

XML の検証について学びたい場合は、DTD と XML Schema を学ぶことをお勧めします。

以下に各トピックの簡単な説明を示します。

XML DOM（Document Object Model）

XML DOM は、XML 文書にアクセスして処理する標準的な方法を定義します。

XML DOM はプラットフォームと言語に依存せず、Java、JavaScript、VBScript などの任意のプログラミング言語で使用できます。

DOM についてもっと学びたい場合は、当サイトのXML DOM チュートリアル。

XSLT（XMLスタイルシート言語変換）

XSLT は XML ファイルのスタイルシート言語です。

XSLT を使用すると、XML 文書を XHTML などの他の形式に変換できます。

XSLT についてもっと学びたい場合は、当サイトのXSLT チュートリアル。

XML DTD（文書型定義）

DTD の目的は、XML 文書内で有効な要素、属性、およびエンティティを定義することです。

DTD を使用すると、各 XML ファイルはそれ自身の形式の記述を携帯できます。

DTD は、受信したデータと自分のデータが有効かどうかを確認するために使用できます。

DTD についてもっと学びたい場合は、当サイトのDTD チュートリアル。

XML Schema

XML Schema は、XML ベースの DTD の代替です。

DTD とは異なり、XML Schema はデータ型をサポートし、XML 構文を使用します。

XML Schema についてもっと学びたい場合は、当サイトのXML Schema チュートリアル。
