CSS3 アニメーション

CSS3 はアニメーションを作成でき、多くのWebアニメーション画像、Flashアニメーション、JavaScriptで実装された効果を置き換えることができます。

CSS3
アニメーション

CSS3 @keyframes ルール

CSS3 アニメーションを作成するには、@keyframes ルールについて知る必要があります。

@keyframes ルールはアニメーションを作成します。

@keyframes ルール内で CSS スタイルを指定すると、アニメーションは現在のスタイルから新しいスタイルへ段階的に変更されます。

-webkit-, -ms- または -moz- の直前にある数字は、その接頭辞付きプロパティをサポートする最初のブラウザバージョン番号です。

CSS3 アニメーション

ときに@keyframesアニメーションを作成するときは、それをセレクタにバインドしないと、アニメーションは効果を発揮しません。

少なくともこれら2つのCSS3アニメーションプロパティをセレクタにバインドして指定します。

  • アニメーションの名前を指定します。
  • アニメーションの再生時間を指定します。

例

"myfirst" アニメーションを div 要素にバインドし、再生時間：5秒：

div { animation: myfirst 5s; -webkit-animation: myfirst 5s; /*Safari と Chrome*/ }

試してみる »

注意：アニメーションの名前と再生時間を定義する必要があります。再生時間を省略すると、デフォルト値が0のためアニメーションは実行されません。

CSS3アニメーションとは？

アニメーションは、要素があるスタイルから別のスタイルへ段階的に変化させる効果です。

スタイルは何回でも、何種類でも変更できます。

変化が発生する時間はパーセンテージで指定するか、キーワード "from" と "to" を使用します。これは 0% と 100% に相当します。

0% はアニメーションの開始、100% はアニメーションの完了です。

最適なブラウザサポートを得るには、常に 0% と 100% のセレクタを定義する必要があります。

例

アニメーションが 25% と 50% のときに背景色を変更し、100% 完了したときに再度変更します：

@keyframes myfirst { 0% {background: red;} 25% {background: yellow;} 50% {background: blue;} 100% {background: green;} } @-webkit-keyframes myfirst /*Safari と Chrome*/ { 0% {background: red;} 25% {background: yellow;} 50% {background: blue;} 100% {background: green;} }

試してみる »

例

背景色と位置を変更します：

@keyframes myfirst { 0% {background: red; left:0px; top:0px;} 25% {background: yellow; left:200px; top:0px;} 50% {background: blue; left:200px; top:200px;} 75% {background: green; left:0px; top:200px;} 100% {background: red; left:0px; top:0px;} } @-webkit-keyframes myfirst /*Safari と Chrome*/ { 0% {background: red; left:0px; top:0px;} 25% {background: yellow; left:200px; top:0px;} 50% {background: blue; left:200px; top:200px;} 75% {background: green; left:0px; top:200px;} 100% {background: red; left:0px; top:0px;} }

CSS3のアニメーションプロパティ

以下の表に、@keyframes ルールとすべてのアニメーションプロパティを示します：

プロパティ 説明 CSS
@keyframes アニメーションを指定します。 3
animation すべてのアニメーションプロパティの略記プロパティです。 3
animation-name @keyframes アニメーションの名前を指定します。 3
animation-duration アニメーションが1サイクル完了するのにかかる秒数またはミリ秒を指定します。デフォルトは 0 です。 3
animation-timing-function アニメーションの速度曲線を指定します。デフォルトは "ease" です。 3
animation-fill-mode アニメーションが再生されないとき（アニメーションが完了したとき、または遅延により再生が開始されていないとき）に要素に適用するスタイルを指定します。 3
animation-delay アニメーションがいつ開始するかを指定します。デフォルトは 0 です。 3
animation-iteration-count アニメーションが再生される回数を指定します。デフォルトは 1 です。 3
animation-direction アニメーションが次のサイクルで逆方向に再生されるかどうかを指定します。デフォルトは "normal" です。 3
animation-play-state アニメーションが実行中か一時停止中かを指定します。デフォルトは "running" です。 3

次の2つの例は、すべてのアニメーションプロパティを設定します：

例

myfirst アニメーションを実行し、すべてのプロパティを設定します：

div { animation-name: myfirst; animation-duration: 5s; animation-timing-function: linear; animation-delay: 2s; animation-iteration-count: infinite; animation-direction: alternate; animation-play-state: running; /*Safari と Chrome：*/ -webkit-animation-name: myfirst; -webkit-animation-duration: 5s; -webkit-animation-timing-function: linear; -webkit-animation-delay: 2s; -webkit-animation-iteration-count: infinite; -webkit-animation-direction: alternate; -webkit-animation-play-state: running; }

試してみる »

例

上記のアニメーションと同じですが、略記の animation プロパティを使用しています：

div { animation: myfirst 5s linear 2s infinite alternate; /*Safari と Chrome：*/ -webkit-animation: myfirst 5s linear 2s infinite alternate; }

    注意（1）：

    animation-play-state も animation の略記プロパティに含まれますが、-webkit- では適用されません：

    animation: myfirst 5s infinite linear paused;

    つまり：

    animation-name: myfirst;
animation-duration: 5s;
animation-iteration-count: infinite;
animation-timing-function: linear;
animation-play-state: paused;

    ただし、-webkit- では、-webkit-animation-play-state は独立しており、-webkit-animation に含めることはできません：

    -webkit-animation: myfirst 5s infinite linear paused;

    無効です！！！！！

    次のように記述する必要があります：

    -webkit-animation: myfirst 5s infinite linear;
-webkit-animation-play-state: paused;

    ---------------------------------------

    注意（2）：

    animation は構文の順序をあまり重視しません（【duration / アニメーション時間】が必ず【delay / アニメーション遅延】の前にある場合を除く）。ただし、-webkit-animation （主に "Safari" 向け）では、-webkit-animation-name で終わらせることはできません：

    animation: myfirst 5s linear 2s infinite alternate;
animation: 5s linear 2s infinite myfirst alternate;
animation: 5s 2s infinite alternate linear myfirst;
// etc... 都是可以的

    ただし Safari では、以下の文は実行できません：【アニメーション名で終わる】

    -webkit-animation: 5s linear 2s infinite alternate myfirst;

    【アニメーション名】は末尾のプロパティにできないため、以下の文は実行できます：

    -webkit-animation: myfirst 5s linear 2s infinite alternate;
-webkit-animation: 5s linear 2s infinite myfirst alternate;
-webkit-animation: 5s 2s infinite myfirst alternate linear;
