は文末の参考文献と一対一で対応しています。図と表にはそれぞれ番号があり、本文中の「図 1」「表 1」の引用はすべて正しく、数式 (1)(2) は \eqref によって括弧付きの形式で引用されています。

この記事では、前10回の知識をすべて組み合わせます。複数ファイル構成のプロジェクトを使い、ゼロから要旨・数式・図表・参考文献を備えた完全な小論文を組版します。

実際に一度やってみることをおすすめします。見て分かったつもりでも、書けるわけではありません。一連の流れを一度完全に経験すれば、LaTeX が本当に自分のものになります。

プロジェクト構成

まずディレクトリ構成を計画します。骨格と内容を分離し、各章を1つのファイルにします。

paper/
├── main.tex            # 骨架：导言区 + 按顺序组装各章节
├── refs.bib            # 参考文献数据库
├── figures/
│   └── fit.png         # 插图
└── sections/
    ├── abstract.tex    # 摘要
    ├── intro.tex       # 引言
    ├── method.tex      # 方法
    ├── result.tex      # 实验结果
    └── conclusion.tex  # 结论

main.tex：プロジェクトの骨格

骨格ファイルが行うのは3つだけです。マクロパッケージの読み込み、タイトルの宣言、順番どおりの組み立てです。

実例：main.tex

\documentclass[12pt, a4paper]{ctexart}

% ---------- ページと基本マクロパッケージ ----------
\usepackage{geometry}
\geometry{margin=2.5cm}
\usepackage{amsmath, amssymb}       % 数学
\usepackage{graphicx}               % 図の挿入
\usepackage{booktabs, multirow}     % 三線表
\usepackage[colorlinks=true, linkcolor=blue,
            citecolor=blue, urlcolor=blue]{hyperref}

% ---------- タイトル情報 ----------
\title{最小二乗法に基づく周期信号フィッティングの研究}
\author{RUNOOB}
\date{\today}

\begin{document}

\maketitle
\input{sections/abstract}           % 要旨
\input{sections/intro}              % 序論
\input{sections/method}             % 方法
\input{sections/result}             % 実験結果
\input{sections/conclusion}         % 結論

\bibliographystyle{plain}
\bibliography{refs}                 % 参考文献

\end{document}

各章の内容

各ファイルはそれぞれ通常の本文のひとまとまりです。要旨と序論を例に見てみましょう。

実例：sections/abstract.tex

\begin{abstract}
本稿では周期信号のパラメータ化モデリング手法を研究し、最小二乗基準に基づいて正弦モデル
$y = A\sin(\omega x + \varphi) + c$の推定手順を導出し、
合成データ上で本手法の有効性を検証しました。
実験により、低ノイズ条件下でのフィッティング相対誤差は1%未満であることが示されました。\%。

\medskip
\noindent\textbf{キーワード：}最小二乗法；周期信号；パラメータ推定
\end{abstract}

実例：sections/intro.tex

\section{序論}\label{sec:intro}
周期信号は、通信・振動解析・生体医用工学などの分野に広く存在しています。
このような信号のパラメータ化モデリングは、フィルタリング・予測・圧縮に共通する基盤です~\cite{oppenheim1997}。
古典的な最小二乗法は、モデルのパラメータ推定に体系化された求解フレームワークを提供します~\cite{bjorck1996}。

本稿の構成は以下のとおりです。第~\ref{sec:method}節でモデルを構築し、求解手順を示します。
節で実験結果を報告し、第~\ref{sec:result}節で実験結果を報告し、第~\ref{sec:conclusion}節で全文をまとめます。

方法の部分には数式を、実験の部分には図表を置く。このパターンはすでにすべて見てきました。

実例：sections/method.tex（数式部分）

\section{方法}\label{sec:method}
次の正弦モデルを考えます。
\begin{equation}\label{eq:model}
  y = A \sin(\omega x + \varphi) + c,
\end{equation}
ここで$A$は振幅、$\omega$は角周波数、$\varphi$は初期位相、$c$は直流成分です。

パラメータ推定の目標は、残差平方和を最小化することです。
\begin{equation}\label{eq:loss}
  S(A, \omega, \varphi, c)
    = \sum_{i=1}^{n} \left( y_i - A \sin(\omega x_i + \varphi) - c \right)^2 .
\end{equation}
固定された$\omega$に対して、式~\eqref{eq:loss}はその他のパラメータに関して線形最小二乗問題であり、
正規方程式によって直接解くことができます。

実例：sections/result.tex（図表部分）

\section{実験結果}\label{sec:result}
在 $[0, 2\pi]$上で等間隔にサンプリングし$n = 200$個の点から合成データを生成し、
さらに、標準偏差が$0.05$のガウスノイズを加えます。
フィッティング曲線とノイズ付きサンプル点の比較を図~\ref{fig:fit}に示します。
異なるノイズレベルにおける誤差指標を表~に示します。\ref{tab:err}。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.65\textwidth]{figures/fit}
  \caption{フィッティング曲線（実線）とノイズ付きサンプル点（散布点）}
  \label{fig:fit}
\end{figure}

\begin{table}[htbp]
  \centering
  \caption{異なるノイズレベルにおける二乗平均平方根誤差}
  \label{tab:err}
  \begin{tabular}{lccc}
    \toprule
ノイズの標準偏差& 0.01 & 0.05 & 0.10 \\
    \midrule
    RMSE & 0.011 & 0.053 & 0.104 \\
相対誤差& 1.1\% & 5.3\% & 10.4\% \\
    \bottomrule
  \end{tabular}
\end{table}

refs.bib には2件の参考文献データが入っています。本文では \cite{oppenheim1997}、\cite{bjorck1996} で引用します（完全な書き方は第9回を参照）。

コンパイルと出力結果

複数ファイル構成のプロジェクトでは main.tex をコンパイルするだけでよく、\input は自動的に展開されます。参考文献付きの完全な流れ：

$ cd paper
$ latexmk -xelatex main.tex      # 一键完成（推荐）
# 或者手动四步：xelatex → bibtex → xelatex → xelatex

実世界：テンプレートから始める

実際に論文を書くときは、ゼロから骨格を組み立てるべきではありません。ジャーナルや大学が既製のテンプレートを提供しています。

テンプレートの入手先どこで探すか特徴
Overleaf テンプレートライブラリOverleaf → Templates数千の学位論文・ジャーナル・ポスターテンプレートがあり、ワンクリックで開けます
ジャーナル公式サイトジャーナルの Author Guidelines ページ投稿指定フォーマット。必ずこれを基準にしてください
大学の学位論文テンプレート大学図書館 / GitHub で「大学名 + thesis」を検索学内の書式審査を満たす
GitHub「awesome-latex」などのコレクションを検索コミュニティが管理するテンプレートとリソースのまとめ

テンプレート活用の心得を一言で言うと：プレースホルダーに内容を入れるだけで、テンプレートの構造は変更しない。テンプレート内のよく分からないプリアンブル設定は、誰かが調整済みのフォーマットであり、1か所でも削除・変更すると全体が壊れる可能性があります。
