Kotlin 継承

Kotlin ではすべてのクラスが Any クラスを継承します。Any はすべてのクラスのスーパークラスであり、スーパータイプの宣言がないクラスにとってはデフォルトのスーパークラスです。

class Example // 从 Any 隐式继承

Any はデフォルトで 3 つの関数を提供します。

equals()

hashCode()

toString()

注意: Any は java.lang.Object ではありません。

クラスを継承できるようにするには、open キーワードで修飾します。

open class Base(p: Int)           // 定义基类

class Derived(p: Int) : Base(p)

コンストラクタ

サブクラスにプライマリコンストラクタがある場合

サブクラスにプライマリコンストラクタがある場合、基底クラスはプライマリコンストラクタ内で直ちに初期化する必要があります。

open class Person(var name : String, var age : Int){// 基类

}

class Student(name : String, age : Int, var no : String, var score : Int) : Person(name, age) {

}

// 测试
fun main(args: Array<String>) {
    val s =  Student("Runoob", 18, "S12346", 89)
    println("学生名： ${s.name}")
    println("年龄： ${s.age}")
    println("学生号： ${s.no}")
    println("成绩： ${s.score}")
}

出力結果：

学生名： Runoob
年龄： 18
学生号： S12346
成绩： 89

サブクラスにプライマリコンストラクタがない場合

サブクラスにプライマリコンストラクタがない場合、各セカンダリコンストラクタで super キーワードを使って基底クラスを初期化するか、または別のコンストラクタに委譲する必要があります。基底クラスを初期化する際は、基底クラスの異なるコンストラクタを呼び出すことができます。

class Student : Person {

    constructor(ctx: Context) : super(ctx) {
    } 

    constructor(ctx: Context, attrs: AttributeSet) : super(ctx,attrs) {
    }
}

例

/**用户基类**/
open class Person(name:String){
    /**次级构造函数**/
    constructor(name:String,age:Int):this(name){
        //初始化
        println("-------基类次级构造函数---------")
    }
}

/**子类继承 Person 类**/
class Student:Person{

    /**次级构造函数**/
    constructor(name:String,age:Int,no:String,score:Int):super(name,age){
        println("-------继承类次级构造函数---------")
        println("学生名： ${name}")
        println("年龄： ${age}")
        println("学生号： ${no}")
        println("成绩： ${score}")
    }
}

fun main(args: Array<String>) {
    var s =  Student("Runoob", 18, "S12345", 89)
}

出力結果：

-------基类次级构造函数---------
-------继承类次级构造函数---------
学生名： Runoob
年龄： 18
学生号： S12345
成绩： 89

オーバーライド

基底クラスで fun を使って関数を宣言する場合、その関数はデフォルトで final 修飾され、サブクラスでオーバーライドできません。サブクラスによるオーバーライドを許可するには、手動で open を追加して修飾する必要があります。サブクラスは override キーワードでメソッドをオーバーライドします。

/**用户基类**/
open class Person{
    open fun study(){       // 允许子类重写
        println("我毕业了")
    }
}

/**子类继承 Person 类**/
class Student : Person() {

    override fun study(){    // 重写方法
        println("我在读大学")
    }
}

fun main(args: Array<String>) {
    val s =  Student()
    s.study();

}

出力結果は次のとおりです。

私は大学に通っています。

同じメソッドが複数ある場合（他のクラスから継承または実装、例: A、B クラス）、そのメソッドをオーバーライドする必要があります。super ジェネリクスを使って、親クラスの実装を選択的に呼び出します。

open class A {
    open fun f () { print("A") }
    fun a() { print("a") }
}

interface B {
    fun f() { print("B") } //接口的成员变量默认是 open 的
    fun b() { print("b") }
}

class C() : A() , B{
    override fun f() {
        super<A>.f()//调用 A.f()
        super<B>.f()//调用 B.f()
    }
}

fun main(args: Array<String>) {
    val c =  C()
    c.f();

}

C が a() または b() から継承する場合、C は A または B から関数を継承できるだけでなく、A()、B() に共通する関数も継承できます。このとき、その関数は C 内にただ 1 つの実装しかありません。曖昧さを排除するために、その関数は A() と B() 内のその関数の実装を呼び出し、独自の実装を提供する必要があります。

出力結果は次のとおりです。

AB

プロパティのオーバーライド

プロパティのオーバーライドには override キーワードを使用します。プロパティは互換性のある型でなければなりません。宣言された各プロパティは、初期化子または getter メソッドによってオーバーライドできます。

open class Foo {
    open val x: Int get { …… }
}

class Bar1 : Foo() {
    override val x: Int = ……
}

var プロパティで val プロパティをオーバーライドすることはできますが、その逆はできません。val プロパティは getter メソッドを定義しているだけなので、var プロパティにオーバーライドすると、派生クラスに setter メソッドが追加で宣言されることになります。

プライマリコンストラクタ内で、プロパティ宣言の一部として override キーワードを使用できます。

interface Foo {
    val count: Int
}

class Bar1(override val count: Int) : Foo

class Bar2 : Foo {
    override var count: Int = 0
}

    いくつか補足：

    1. サブクラスが親クラスを継承するとき、親クラスと同じ名前の変数を持つことはできません。ただし、親クラスのその変数が private である場合、または親クラスのその変数が open でありサブクラスが override キーワードでオーバーライドする場合は除きます。

    open class Person(var name: String, var age: Int) {    
    open var sex: String = "unknow"    
    init {        
        println("基类初始化")    
    }
}
// 子类的主构造方法的 name 前边也加了 var，这是不允许的，会报'name' hides member of supertype and needs 'override' modifier
class Student(var name: String, age: Int, var no: String, var score: Int) : Person(name, age) {
    override var sex: String = "male"
}

    上記のコード片では、サブクラス Student のプライマリコンストラクタの最初のフィールド name の前に var キーワードを付けるとエラーになります。

    2. サブクラスは、親クラスとインターフェースが共通して持つ同名メソッドを必ずしも呼び出す必要はありません。

    記事からの引用: 「C が a() または b() から継承する場合、C は A または B から関数を継承できるだけでなく、A()、B() に共通する関数も継承できます。このとき、その関数は C 内にただ 1 つの実装しかありません。曖昧さを排除するために、その関数は A() と B() 内のその関数の実装を呼び出し、独自の実装を提供する必要があります。」

    試してみましたが、A() と B() のその関数の実装を呼び出す必要はありません。コードは次のとおりです。

    open class A {
    open fun f() {
        println("A")
    }
    fun a() {
        println("a")
    }
}
interface B {
    fun f() {
        println("B")
    }
    fun b() {
        println("b")
    }
}
class C : A(), B {
    override fun f() {
        // super<A>.f()
        // super<B>.f()
        println("C")
    }
}

    上記のコード片のように、コメントアウトしてsuper<A>.f() 和 super<B>.f()エラーにもなりません。

    3. サブクラスが val で親クラスの var をオーバーライドできないことについての私の推測: サブクラスが親クラスのプロパティをオーバーライドするということは、そのプロパティの getter と setter メソッドを必ずオーバーライドしなければならないことを意味します。しかし、サブクラスの val には setter メソッドを持たせることができないため、親クラスの var の setter メソッドをオーバーライドできません。これは親クラスの対応するプロパティの使用範囲を狭めることになり、許可されません。親クラスの public メソッドを private メソッドにオーバーライドできないのと同じです。

    4. 変数を定義時に初期化したい場合、その変数はバッキングフィールドを持つ必要があります。その変数のデフォルトの getter と setter メソッドには field フィールドが定義されています。しかし、この変数の getter メソッドと setter メソッドをオーバーライドし、その getter メソッドと setter メソッドのどちらにも field キーワードが現れない場合、コンパイラはエラーを報告します: 「Initializer is not allowed here because this property has no backing field」と表示されます。明示的に field キーワードを書かない限り（たとえそれが何もしなくても、そこに置いてあれば大丈夫です。私の理解では、一度現れれば「宣言」されたことになり、使用できるようになります。変数を定義するときの初期化には、field が「宣言」されていることが必要です）。

    var aaa: Int = 0
get() {
    field // 这里必须出现一下field关键字，否则 var aaa: Int = 0 会报错，除非你去掉 = 0这部分，不要给它赋初始化值
    return 0
}
set(value) {}
