Kotlin 基本構文

Kotlin ファイルは.ktを拡張子とします。

パッケージ宣言

コードファイルの先頭は通常、パッケージ宣言です：

package com.runoob.main

import java.util.*

fun test() {}
class Runoob {}

Kotlin ソースファイルは、ディレクトリとパッケージが一致している必要はありません。ソースファイルは任意のファイルディレクトリに配置できます。

上記の例では、test() の完全名は com.runoob.main.test、Runoob の完全名は com.runoob.main.Runoob です。

パッケージを指定しない場合、デフォルトはdefaultパッケージです。

デフォルトインポート

複数のパッケージが各 Kotlin ファイルにデフォルトでインポートされます：

  • kotlin.*
  • kotlin.annotation.*
  • kotlin.collections.*
  • kotlin.comparisons.*
  • kotlin.io.*
  • kotlin.ranges.*
  • kotlin.sequences.*
  • kotlin.text.*

関数定義

関数定義にはキーワード fun を使用します。パラメータの形式は：パラメータ : 型

fun sum(a: Int, b: Int): Int {   // Int 参数，返回值 Int
    return a + b
}

式を関数本体とする場合、戻り値の型は自動的に推論されます：

fun sum(a: Int, b: Int) = a + b

public fun sum(a: Int, b: Int): Int = a + b   // public 方法则必须明确写出返回类型

戻り値のない関数（Java の void に類似）：

fun printSum(a: Int, b: Int): Unit { 
    print(a + b)
}


// 如果是返回 Unit类型，则可以省略(对于public方法也是这样)：
public fun printSum(a: Int, b: Int) { 
    print(a + b)
}

可変長引数関数

関数の可変長引数はvarargキーワードで識別できます：

fun vars(vararg v:Int){
    for(vt in v){
        print(vt)
    }
}

// 测试
fun main(args: Array<String>) {
    vars(1,2,3,4,5)  // 输出12345
}

ラムダ（匿名関数）

ラムダ式の使用例：

// 测试
fun main(args: Array<String>) {
    val sumLambda: (Int, Int) -> Int = {x,y -> x+y}
    println(sumLambda(1,2))  // 输出 3
}

定数と変数の定義

可変変数の定義：var キーワード

var <标识符> : <类型> = <初始化值>

不変変数の定義：val キーワード。一度だけ代入できる変数（Java の final 修飾された変数に類似）

val <标识符> : <类型> = <初始化值>

定数と変数はどちらも初期値を持たなくても構いませんが、参照する前に初期化する必要があります。

コンパイラは自動型推論をサポートしています。つまり、宣言時に型を指定しなくても、コンパイラが判断します。

val a: Int = 1
val b = 1       // 系统自动推断变量类型为Int
val c: Int      // 如果不在声明时初始化则必须提供变量类型
c = 1           // 明确赋值


var x = 5        // 系统自动推断变量类型为Int
x += 1           // 变量可修改

コメント

Kotlin は単行コメントと複数行コメントをサポートしています。例は次のとおりです：

// これは単行コメントです

/* これは複数行の
   ブロックコメントです。 */

Java とは異なり、Kotlin のブロックコメントはネストを許可します。

文字列テンプレート

$ は変数名または変数値を表します

$varName は変数値を表します

${varName.fun()} は変数のメソッドの戻り値を表します：

var a = 1
// 模板中的简单名称：
val s1 = "a is $a" 

a = 2
// 模板中的任意表达式：
val s2 = "${s1.replace("is", "was")}, but now is $a"

NULLチェック機構

Kotlin の null 安全設計では、null を許容すると宣言されたパラメータは、使用する際に null チェック処理を行う必要があります。2 つの処理方法があります。フィールドの後に !! を付けると Java と同様に null 例外をスローします。もう 1 つは、フィールドの後に ? を付けると処理を行わず、戻り値はnull、または?:と組み合わせて null チェック処理を行います。

//类型后面加?表示可为空
var age: String? = "23" 
//抛出空指针异常
val ages = age!!.toInt()
//不做处理返回 null
val ages1 = age?.toInt()
//age为空返回-1
val ages2 = age?.toInt() ?: -1

参照が null の可能性がある場合、対応する型宣言は明示的に null 許容としてマークする必要があります。

str の文字列内容が整数でない場合、null を返します：

fun parseInt(str: String): Int? {
  // ...
}

次の例は、戻り値が null になり得る関数の使用方法を示しています：

fun parseInt(str: String): Int? {
    return str.toIntOrNull()
}

fun printProduct(arg1: String, arg2: String) {
    val x = parseInt(arg1)
    val y = parseInt(arg2)

    // 直接使用 `x * y` 会导致错误, 因为它们可能为 null
    if (x != null && y != null) {
        // 在进行过 null 值检查之后, x 和 y 的类型会被自动转换为非 null 变量
        println(x * y)
    }
    else {
        println("'$arg1' or '$arg2' is not a number")
    }    
}

fun main() {
    printProduct("6", "7")
    printProduct("a", "7")
    printProduct("a", "b")
}

または：

fun parseInt(str: String): Int? {
    return str.toIntOrNull()
}

fun printProduct(arg1: String, arg2: String) {
    val x = parseInt(arg1)
    val y = parseInt(arg2)
    
    // ...
    if (x == null) {
        println("Wrong number format in arg1: '$arg1'")
        return
    }
    if (y == null) {
        println("Wrong number format in arg2: '$arg2'")
        return
    }

    // 在进行过 null 值检查之后, x 和 y 的类型会被自动转换为非 null 变量
    println(x * y)
}

fun main() {
    printProduct("6", "7")
    printProduct("a", "7")
    printProduct("99", "b")
}

型チェックと自動型変換

私たちはis演算子を使用して、オブジェクトが指定された型のインスタンスであるかどうかを検出できます（Java の instanceof キーワードに類似）。

if (obj is Type) {
    // 如果 obj 是 Type 类型，则可以直接使用 Type 类型的属性和方法
} else {
    // 处理其他类型情况
}

当 isチェックを通過すると、Kotlin は自動的にobjを指定された型とみなします。したがって、if文の分岐内で明示的な型変換を行う必要はありません。これはスマートキャスト。

例

fun main() {
    val obj: Any = "Hello, Kotlin"

    if (obj is String) {
println("文字列の長さ: ${obj.length}") // ここで `obj` は `String` にスマートキャストされています
    } else {
println("文字列型ではありません")
    }
}

この例では、もしobjであるString型の場合、is演算子はtrueを返し、Kotlin はobjとして認識しString、これにより直接String型のプロパティとメソッドにアクセスできます。

その他の応用例：

fun getStringLength(obj: Any): Int? {
  if (obj is String) {
    // 做过类型判断以后，obj会被系统自动转换为String类型
    return obj.length 
  }

  //在这里还有一种方法，与Java中instanceof不同，使用!is
  // if (obj !is String){
  //   // XXX
  // }

  // 这里的obj仍然是Any类型的引用
  return null
}

または

fun getStringLength(obj: Any): Int? {
  if (obj !is String)
    return null
  // 在这个分支中, `obj` 的类型会被自动转换为 `String`
  return obj.length
}

さらには

fun getStringLength(obj: Any): Int? {
  // 在 `&&` 运算符的右侧, `obj` 的类型会被自动转换为 `String`
  if (obj is String && obj.length > 0)
    return obj.length
  return null
}

レンジ

レンジ式は、演算子形式の..を持つ rangeTo 関数と in および !in によって形成されます。

レンジはあらゆる比較可能な型に対して定義されていますが、整数のネイティブ型には最適化された実装があります。以下はレンジを使用した例です：

for (i in 1..4) print(i) // 输出“1234”

for (i in 4..1) print(i) // 什么都不输出

if (i in 1..10) { // 等同于 1 <= i && i <= 10
    println(i)
}

// 使用 step 指定步长
for (i in 1..4 step 2) print(i) // 输出“13”

for (i in 4 downTo 1 step 2) print(i) // 输出“42”


// 使用 until 函数排除结束元素
for (i in 1 until 10) {   // i in [1, 10) 排除了 10
     println(i)
}

例のテスト

fun main(args: Array<String>) {
    print("循环输出：")
    for (i in 1..4) print(i) // 输出“1234”
    println("\n----------------")
    print("设置步长：")
    for (i in 1..4 step 2) print(i) // 输出“13”
    println("\n----------------")
    print("使用 downTo：")
    for (i in 4 downTo 1 step 2) print(i) // 输出“42”
    println("\n----------------")
    print("使用 until：")
    // 使用 until 函数排除结束元素
    for (i in 1 until 4) {   // i in [1, 4) 排除了 4
        print(i)
    }
    println("\n----------------")
}
