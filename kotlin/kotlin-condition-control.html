IF 式

if 文は、ブール式と1つ以上の文を含みます。

// 传统用法
var max = a 
if (a < b) max = b

// 使用 else 
var max: Int
if (a > b) {
    max = a
} else {
    max = b
}
 
// 作为表达式
val max = if (a > b) a else b

IF 式の結果を変数に代入することもできます。

val max = if (a > b) {
    print("Choose a")
    a
} else {
    print("Choose b")
    b
}

これは、Javaのような三項演算子が不要であることも示しています。IF 式を使用して簡単に実装できるからです：

val c = if (condition) a else b

サンプル

fun main(args: Array<String>) {
    var x = 0
    if(x>0){
        println("x 大于 0")
    }else if(x==0){
        println("x 等于 0")
    }else{
        println("x 小于 0")
    }

    var a = 1
    var b = 2
    val c = if (a>=b) a else b
    println("c 的值为 $c")
}

出力結果は：

x 等于 0
c 的值为 2

範囲の使用

in 演算子を使用して、ある数値が指定された範囲内にあるかどうかを検出します。範囲の形式は次のとおりです：x..y ：

サンプル

fun main(args: Array<String>) {
    val x = 5
    val y = 9
    if (x in 1..8) {
        println("x 在区间内")
    }
}

出力結果は：

x 在区间内

When 式

when は、その引数をすべての分岐条件と順に比較し、いずれかの分岐が条件を満たすまで続けます。

when は式としても文としても使用できます。式として使用する場合、条件に一致する分岐の値が式全体の値となります。文として使用する場合は、個々の分岐の値は無視されます。

when は他の言語の switch 文に似ています。最も単純な形式は次のとおりです：

when (x) {
    1 -> print("x == 1")
    2 -> print("x == 2")
    else -> { // 注意这个块
        print("x 不是 1 ，也不是 2")
    }
}

when では、else は switch の default と同じです。他のどの分岐も条件を満たさない場合、else 分岐が評価されます。

多くの分岐を同じ方法で処理する必要がある場合は、複数の分岐条件をカンマで区切ってまとめることができます：

when (x) {
    0, 1 -> print("x == 0 or x == 1")
    else -> print("otherwise")
}

値が範囲またはコレクション内にあるか（in）、またはないか（!in）を検出することもできます：

when (x) {
    in 1..10 -> print("x is in the range")
    in validNumbers -> print("x is valid")
    !in 10..20 -> print("x is outside the range")
    else -> print("none of the above")
}

別の可能性として、値が特定の型であるか（is）、または特定の型でないか（!is）を検出できます。注意： スマートキャストにより、追加のチェックなしでその型のメソッドやプロパティにアクセスできます。

fun hasPrefix(x: Any) = when(x) {
    is String -> x.startsWith("prefix")
    else -> false
}

when は if-else if チェーンの代わりにも使用できます。パラメータを指定しない場合、すべての分岐条件は単純なブール式となり、分岐の条件が true のときにその分岐が実行されます：

when {
    x.isOdd() -> print("x is odd")
    x.isEven() -> print("x is even")
    else -> print("x is funny")
}

サンプル

fun main(args: Array<String>) {
    var x = 0
    when (x) {
        0, 1 -> println("x == 0 or x == 1")
        else -> println("otherwise")
    }

    when (x) {
        1 -> println("x == 1")
        2 -> println("x == 2")
        else -> { // 注意这个块
            println("x 不是 1 ，也不是 2")
        }
    }

    when (x) {
        in 0..10 -> println("x 在该区间范围内")
        else -> println("x 不在该区间范围内")
    }
}

出力結果：

x == 0 or x == 1
x 不是 1 ，也不是 2
x 在该区间范围内

when 内ではinin 演算子を使用して、コレクション内に特定のインスタンスが含まれているかどうかを判定します：

fun main(args: Array<String>) {
    val items = setOf("apple", "banana", "kiwi")
    when {
        "orange" in items -> println("juicy")
        "apple" in items -> println("apple is fine too")
    }
}

出力結果：

apple is fine too
