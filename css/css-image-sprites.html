CSS 图像拼合技术

图像拼合

画像スプライトは、単一の画像の集合です。

多くの画像を含むウェブページは、読み込みに長時間かかり、サーバーへの複数のリクエストが発生する可能性があります。

画像スプライトを使用すると、サーバーへのリクエスト数が減り、帯域幅を節約できます。

画像合成 - 簡単な例

3つの独立した画像を使う代わりに、この1つの画像（"img_navsprites.gif"）を使用します。

CSSを使用すれば、必要な画像の一部だけを表示できます。

以下の例では、CSSが "img_navsprites.gif" の画像の一部を表示するように指定しています。

实例

img.home
{
width:46px;
height:44px;
background:url(img_navsprites.gif) 0 0;
}

尝试一下 »

实例解析：

  • <img class="home" src="img_trans.gif.html" /> - 空にできないため、src属性は小さな透明画像だけを定義しています。表示される画像は、CSSで指定した背景画像になります。
  • 幅：46px; 高さ：44px; - 使用する画像の部分を定義します。
  • background:url(img_navsprites.gif) 0 0; - 背景画像とその位置（左0px、上0px）を定義します。

これは画像スプライトを使用する最も簡単な方法です。次に、リンクとホバー効果を使用します。

画像スプライト - ナビゲーションリストを作成する

スプライト画像 ("img_navsprites.gif") を使用して、ナビゲーションリストを作成します。

HTMLリストを使用します。リンクとして機能し、背景画像もサポートしているからです。

实例

#navlist{position:relative;}
#navlist li{margin:0;padding:0;list-style:none;position:absolute;top:0;}
#navlist li, #navlist a{height:44px;display:block;}

#home{left:0px;width:46px;}
#home{background:url('img_navsprites.gif') 0 0;}

#prev{left:63px;width:43px;}
#prev{background:url('img_navsprites.gif') -47px 0;}

#next{left:129px;width:43px;}
#next{background:url('img_navsprites.gif') -91px 0;}

尝试一下 »

实例解析：

  • #navlist{position:relative;} - 位置を相対配置に設定し、内部の絶対配置の基準とする
  • #navlist li{margin:0;padding:0;list-style:none;position:absolute;top:0;} - marginとpaddingは0に設定され、リストスタイルは削除され、すべてのリスト項目は絶対配置になります。
  • #navlist li, #navlist a{height:44px;display:block;} - すべての画像の高さは44pxです

次に、各セクションの配置とスタイルを設定します。

  • #home{left:0px;width:46px;} - 一番左に配置する方法と、画像の幅が46pxであること
  • #home{background:url(img_navsprites.gif) 0 0;} - 背景画像とその位置（左0px、上部0px）を定義します。
  • #prev{left:63px;width:43px;} - 左から63pxの位置（#homeの幅46px＋項目間の余分なスペース）、幅は43px
  • #prev{background:url('img_navsprites.gif') -47px 0;} - 背景画像の右側47pxを定義（＃homeの幅46px＋区切り線の1px）
  • #next{left:129px;width:43px;}- 右に129px配置(#prev 63px + #prevの幅43px + 残りのスペース)、幅は43px。
  • #next{background:url('img_navsprites.gif') no-repeat -91px 0;} - 背景画像の右側91pxを定義（#home 46px+1pxの区切り線+#prev幅43px+1pxの区切り線）

画像スプライト - ホバー効果。

次に、ナビゲーションリストにホバー効果を追加します。

:hover セレクタは、マウスを要素の上に置いたときに表示される効果に使用されます。

提示：:hover セレクタは、すべての要素に適用できます。

新しい画像 ("img_navsprites_hover.gif") には、3つのナビゲーション画像と3つの画像が含まれています。

これは単一の画像であり、6つの個別の画像ファイルではないため、ユーザーが画像の上にカーソルを置いても読み込みの遅延は発生しません。

ホバー効果を追加するには、3行のコードを追加するだけです。

实例

#home a:hover{background: url('img_navsprites_hover.gif') 0 -45px;}
#prev a:hover{background: url('img_navsprites_hover.gif') -47px -45px;}
#next a:hover{background: url('img_navsprites_hover.gif') -91px -45px;}

尝试一下 »

实例解析：

  • リスト項目にリンクが含まれているため、:hover疑似クラスを使用できます。
  • #home a:hover{background: transparent url(img_navsprites_hover.gif) 0 -45px;} - 3つのホバー画像すべてに対して同じ背景位置を指定し、それぞれをさらに45px下にずらすだけです。
