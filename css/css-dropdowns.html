CSS ドロップダウンメニュー

CSSを使用して、マウスを移動するとドロップダウンメニューが表示される効果を作成します。

基本ドロップダウンメニュー

マウスが指定した要素の上に移動すると、ドロップダウンメニューが表示されます。

实例

<style> .dropdown { position: relative; display: inline-block; } .dropdown-content { display: none; position: absolute; background-color: #f9f9f9; min-width: 160px; box-shadow: 0px 8px 16px 0px rgba(0,0,0,0.2); padding: 12px 16px; } .dropdown:hover .dropdown-content { display: block; } </style>
<div class="dropdown"> <span>マウスをここに移動してください！</span> <div class="dropdown-content"> <p>菜鸟教程</p> <p>www.runoob.com</p> </div> </div>

实例解析

HTML 部分：

ドロップダウンメニューを開くには、<span>や<button>要素など、任意のHTML要素を使用できます。

コンテナ要素（<div>など）を使用してドロップダウンメニューのコンテンツを作成し、任意の場所に配置します。

<div>要素でこれらの要素を囲み、CSSを使用してドロップダウンコンテンツのスタイルを設定します。

CSS 部分：

.dropdown类使用position:relative、これはドロップダウンメニューの内容をドロップダウンボタン（使用position:absolute) の右下隅の位置。

.dropdown-contentクラス内は実際のドロップダウンメニューです。デフォルトでは非表示で、マウスが指定された要素の上に移動すると表示されます。注意min-widthの値は160pxに設定されています。必要に応じて変更できます。注意:ドロップダウンの内容をドロップダウンボタンと同じ幅に設定したい場合は、次のように設定できます。width100% として (overflow:auto小さい画面でスクロールできるように設定します)。

我々は使用するbox-shadow属性により、ドロップダウンメニューが「カード」のように見えます。

:hoverセレクターは、ユーザーがマウスをドロップダウンボタンの上に移動したときにドロップダウンメニューを表示するために使用されます。

下拉菜单

ドロップダウンメニューを作成し、ユーザーがリストから項目を選択できるようにします：

菜鸟教程 1 菜鸟教程 2 菜鸟教程 3

この例は前の例と似ており、ドロップダウンリストにリンクを追加し、スタイルを設定したものです：

实例

<style>
/* 下拉按钮样式 */
.dropbtn {
    background-color: #4C7EAF;
    color: white;
    padding: 16px;
    font-size: 16px;
    border: none;
    cursor: pointer;
}

/* 容器 <div> - 需要定位下拉内容 */
.dropdown {
    position: relative;
    display: inline-block;
}

/* 下拉内容 (默认隐藏) */
.dropdown-content {
    display: none;
    position: absolute;
    background-color: #f9f9f9;
    min-width: 160px;
    box-shadow: 0px 8px 16px 0px rgba(0,0,0,0.2);
}

/* ドロップダウンメニューのリンク */
.dropdown-content a {
    color: black;
    padding: 12px 16px;
    text-decoration: none;
    display: block;
}

/* 鼠标移上去后修改下拉菜单链接颜色 */
.dropdown-content a:hover {background-color: #f1f1f1}

/* マウスオーバーでドロップダウンメニューを表示 */
.dropdown:hover .dropdown-content {
    display: block;
}

/* ドロップダウンコンテンツが表示されたら、ドロップダウンボタンの背景色を変更します */
.dropdown:hover .dropbtn {
    background-color: #4877A6;
}
</style>

<div class="dropdown">
  <button class="dropbtn">下拉菜单</button>
  <div class="dropdown-content">
    <a href="#">菜鸟教程 1</a>
    <a href="#">菜鸟教程 2</a>
    <a href="#">菜鸟教程 3</a>
  </div>
</div>

ドロップダウン内容の整列方法

float:left;

菜鸟教程 1 菜鸟教程 2 菜鸟教程 3

float:right;

菜鸟教程 1 菜鸟教程 2 菜鸟教程 3

右にフロートするドロップダウンメニューのコンテンツの方向を左から右ではなく右から左に設定したい場合は、次のコードを追加できます。right: 0;

实例

.dropdown-content {
    right: 0;
}

    文末の「ドロップダウンコンテンツの配置」の例で、.dropdown-content内の right:0; を left:0; に変更し、続いて例を真似て右側のボタンにインラインスタイル" style="right:0;" " を追加しました。理屈では、インラインスタイル(inline style)が内部スタイルシート(internal style sheet)を上書きして、例と同じ効果を実現できるはずです。

    しかし実際には"left"の優先度は ～ より高い"right"しかし、右側のボタンのスタイルは変わりませんでした。

    <div class="dropdown-content" "style="left:unset; right:0;">

    上のユーザーTOWERが説明したこの例はとても良いです。この例で、.dropdown-content 内の right:0; を left:0; に変更し、続いて例を真似て右側のボタンにインラインスタイル" style="right:0;" を追加しました。ある人は疑問に思うでしょう。right:0;はインラインスタイルの中にあり、left:0;は埋め込みスタイルの中にあります。インラインスタイルの優先順位は埋め込みスタイルより高いはずです。しかし、なぜ有効なのはleftなのでしょうか？

    通常、leftとrightは1つのスタイルで一度しか使用できません。同時に使用すると互換性の問題が発生します。ブラウザがコードを解釈するときにleftとrightが同時に存在することを検出すると、rightの解釈を放棄します。解釈を放棄すると優先順位は役に立たなくなり、最優先の!importantでさえも効果がありません。これはちょうど戦場で二人の兵士AとBがいて、Bが撃たれて死んだ場合、たとえ衛生兵の医療技術がどんなに優れていても彼を救えないのと同じです。

    したがってleftの優先度はrightより高い
