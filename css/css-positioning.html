CSS Position（位置指定）

positionプロパティは要素の位置指定方法を指定するために使用されます。

一般的な5つの値は次のとおりです：

值 説明 アンカー
static デフォルト値。要素は通常のドキュメントフローに従って配置され、top/right/bottom/left の影響を受けません。 例を見る
relative 自身の元の位置を基準にオフセットし、ドキュメントフローから離れません。 例を見る
absolute 最も近い位置指定済みの祖先要素に対して配置されます（そうでない場合は body に対して）。ドキュメントフローから離れます。 例を見る
fixed ブラウザウィンドウに対して配置され、ページをスクロールしても位置は変わりません。 例を見る
sticky 指定位置にスクロールするまでは relative のように動作し、その後は fixed のように動作します。 例を見る

要素はtop、right、bottom 和 leftプロパティで位置を調整できますが、これらのプロパティは設定されている場合にのみposition（かつ値がstatic）場合にのみ有効になります。 異なる位置指定方法は、これらのプロパティの参照対象と表現形式に影響します。

static 位置指定

HTML要素のデフォルト値であり、位置指定がない、つまり通常のドキュメントフローオブジェクトに従います。

静的配置された要素は top, bottom, left, right の影響を受けません。

例

div.static { position: static; border: 3px solid #2167AD; }

試してみる »

fixed 位置指定

要素の位置はブラウザウィンドウに対して固定位置です。

ウィンドウをスクロールしても移動しません：

例

p.pos_fixed { position:fixed; top:30px; right:5px; }

試してみる »

注意：Fixed 配置は IE7 および IE8 では !DOCTYPE の記述が必要です。

Fixed 配置は要素の位置をドキュメントフローから切り離すため、スペースを占有しません。

Fixed 配置された要素は他の要素と重なります。

relative 位置指定

相対配置された要素の位置は、その通常の位置を基準にします。

例

h2.pos_left { position:relative; left:-20px; } h2.pos_right { position:relative; left:20px; }

試してみる »

相対配置された要素を移動しても、元のスペースは変わりません。

例

h2.pos_top { position:relative; top:-50px; }

試してみる »

相対配置された要素は、絶対配置された要素のコンテナブロックとしてよく使用されます。

absolute 位置指定

絶対配置された要素の位置は、最も近い位置指定済みの親要素を基準にします。要素に位置指定済みの親要素がない場合、その位置は <html> を基準にします：

例

h2 { position:absolute; left:100px; top:150px; }

試してみる »

absolute 配置は要素の位置をドキュメントフローから切り離すため、スペースを占有しません。

absolute 配置された要素は他の要素と重なります。

sticky 位置指定

sticky は英語で「粘る、貼り付く」という意味なので、粘着配置と呼ぶことができます。

position: sticky;ユーザーのスクロール位置に基づいて配置されます。

粘着配置された要素はユーザーのスクロールに依存し、position:relative 与 position:fixed位置指定の間を切り替えます。

その動作は次のようになります：position:relative;そしてページがターゲット領域を超えてスクロールすると、その動作は次のようになります：position:fixed;、ターゲット位置に固定されます。

要素の位置指定は、特定のしきい値を超えるまでは相対配置のように動作し、その後は固定配置のように動作します。

この特定のしきい値とは、top, right, bottom または left のいずれかを指します。言い換えると、top, right, bottom, left の4つのしきい値のいずれかを指定して初めて粘着配置が有効になります。それ以外の場合、その動作は相対配置と同じです。

注意：Internet Explorer、Edge 15 およびそれ以前の IE バージョンは sticky 配置をサポートしていません。Safari では -webkit- prefix を使用する必要があります（以下の例を参照）。

例

div.sticky { position: -webkit-sticky; /* Safari */ position: sticky; top: 0; background-color: green; border: 2px solid #4C7EAF; }

試してみる »

重なり合う要素

要素の位置指定はドキュメントフローと無関係なため、ページ上の他の要素を覆うことができます。

z-index プロパティは要素の重なり順（どの要素を前面に置くか、または後面に置くか）を指定します。

要素は正または負の重なり順を持つことができます：

例

img { position:absolute; left:0px; top:0px; z-index:-1; }

試してみる »

より高い重なり順を持つ要素は、常により低い重なり順の要素の前面に表示されます。

注意：2つの位置指定された要素が重なり、z-index が指定されていない場合、HTMLコード内で最後に配置された要素が最前面に表示されます。

    relative：位置指定は自身の位置を基準にします（オフセットを設定すると、自身の位置を基準に偏移します）。relative を設定した要素はまだドキュメントフロー内にあり、要素の幅と高さは変わらず、オフセットを設定しても他の要素の位置には影響しません。最外側のコンテナを relative 配置にした場合、幅を設定していなければ、幅はブラウザ全体の幅になります。

    absolute：位置指定は、要素に最も近い、絶対配置または相対配置が設定された親要素を基準に決定されます。親要素に絶対配置や相対配置が設定されていない場合、要素はルート要素である html 要素を基準に配置されます。absolute を設定した要素はドキュメントフローから離れ、幅を設定していない場合、幅は要素内のコンテンツによって決まります。離れた後、元の位置は空になり、下の要素がその位置を占めます。

    階層問題（どちらが上か）

    まとめ：標準フローのボックスは、フロートしたボックスより低く、フロートしたボックスは、配置（position）されたボックスより低い。

    配置（position）はフロートより高く、フロートは標準フローより高い。（高低は、位置を占めるかどうかとは無関係）

    使い方：

    1、配置（position）が必要。（static以外）。

    2、z-indexの値を階層の値として指定する。（指定しない場合、デフォルトは0）

    • a. 階層が0のボックスも、標準フローやフロートより高い。
    • b. 階層が負の数のボックスは、標準フローやフロートより低い。
    • c. 階層は小数を使用しない）
    • d. 階層が同じ場合、後ろのボックスの方が前のボックスより階層が高い。
    • e. フロートまたは標準フローのボックスの場合も、後ろのボックスの方が前のボックスより階層が高い。
    • f. absoluteは位置を占めず、relativeは位置を占める。そして、階層の高低は、位置を占めるかどうかとは関係がない。

    ドキュメントフローが分かればとても簡単です。簡単にまとめると：

    1. static:デフォルト値で、ドキュメントフローから離脱しない。

    2. relative:ドキュメントフローから離脱せず、位置の基準は要素自身の通常時の位置。

    4. absolute: ドキュメントフローから離脱し、位置の基準は非staticの親要素。

    5. sticky: a. 表示がページを超えない場合は、～と等しいrelative。b. 表示がページを超える場合は、～と等しいfixed
