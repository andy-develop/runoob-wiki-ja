CSS テキスト書式


テキスト書式

This text is styled with some of the text formatting properties. The heading uses the text-align, text-transform, and color properties. The paragraph is indented, aligned, and the space between characters is specified. The underline is removed from the 「試してみる」 link.

テキストの色

colorプロパティはテキストの色を設定するために使用されます。

色はCSSで最も頻繁に指定されます：

  • 16進数値 - 例:＃FF0000
  • RGB値 - 例:RGB(255,0,0)
  • 色の名前 - 例:red

参照CSS 色の値完全な色の値を参照してください。

ウェブページの背景色は、body要素内の選択を指します：

例

body {color:red;} h1 {color:#0080FF;} h2 {color:rgb(255,0,0);}

試してみる »

W3C標準のCSSでは：colorプロパティを定義する場合、background-colorプロパティも定義する必要があります。

テキストの配置

text-alignプロパティは、テキストの水平方向の配置を設定するために使用されます。

テキストは中央揃え、左揃え、右揃え、両端揃えにできます。

text-alignが"justify"に設定されている場合、各行は幅が等しくなるように展開され、左右の余白が揃います（雑誌や新聞のように）。

例

h1 {text-align:center;} p.date {text-align:right;} p.main {text-align:justify;}

試してみる »

テキストの装飾

text-decorationプロパティは、テキストの装飾を設定または削除するために使用されます。

デザインの観点から見ると、text-decorationプロパティは主にリンクの下線を削除するために使用されます：

例

a {text-decoration:none;}

試してみる »

次のように文字を装飾することもできます：

例

h1 {text-decoration:overline;} h2 {text-decoration:line-through;} h3 {text-decoration:underline;}

試してみる »

リンクではないテキストを強調することはお勧めしません。これはしばしばユーザーを混乱させるためです。

テキストの変換

text-transformプロパティは、テキスト内の大文字と小文字を指定するために使用されます。

すべての文字を大文字または小文字に変換したり、各単語の先頭文字を大文字にしたりするために使用できます。

例

p.uppercase {text-transform:uppercase;} p.lowercase {text-transform:lowercase;} p.capitalize {text-transform:capitalize;}

試してみる »

テキストのインデント

text-indentプロパティは、テキストの最初の行のインデントを指定するために使用されます。

例

p {text-indent:50px;}

    letter-spacing文字間隔を調整する：

    • 1、英語の場合、各文字と各文字の間隔を調整します
    • 2、漢字の場合、各漢字と各漢字の間隔を調整します

    word-spacing単語間隔を調整する：

    • 1、英語の場合、各単語と各単語の間隔を調整します
    • 2、漢字の場合、自動解析できません。テキスト内でスペースで区切る必要があります
