CSS 字体

CSSのフォントプロパティは、フォント、太字、サイズ、テキストスタイルを定義します。

serifとsans-serifフォントの違い

コンピュータ画面上では、sans-serifフォントはserifフォントよりも読みやすいと考えられています。

CSS字型

CSSには、2種類のフォントファミリ名があります。

  • 通用字体系列- 似た外観を持つフォントの組み合わせ（例: "Serif" や "Monospace"）
  • 特定字体系列- 特定のフォントファミリー（例：「Times」や「Courier」）
Generic family 字体系列 说明
Serif Times New Roman
Georgia		 Serifフォントでは、文字の線の端に余分な飾りがあります。
Sans-serif Arial
Verdana		 "Sans"は「なし」を意味します - これらのフォントには線の端に飾りがありません。
Monospace Courier New
Lucida Console		 すべての等幅文字は同じ幅を持ちます

字体系列

font-family プロパティは、テキストのフォントファミリを設定します。

font-family 属性はいくつかのフォント名を「フォールバック」メカニズムとして設定する必要があります。ブラウザが最初のフォントをサポートしていない場合、次のフォントを試行します。

注意: フォントファミリ名が複数の単語からなる場合は、引用符で囲む必要があります。例: Font Family: "宋体"。

複数のフォントファミリはカンマで区切って指定します：

实例

p{font-family:"Times New Roman", Times, serif;}

字体样式

主にイタリック体のテキストを指定するためのフォントスタイルプロパティです。

この属性には3つの値があります：

  • 正常 - テキストを正常に表示します
  • 斜体 - 斜体で表示されるテキスト
  • 傾斜したテキスト - 文字が片側に傾きます（イタリックに非常に似ていますが、あまりサポートされていません）

实例

p.normal {font-style:normal;}
p.italic {font-style:italic;}
p.oblique {font-style:oblique;}

字体大小

font-size プロパティは、テキストのサイズを設定します。

文字のサイズを管理できるかどうかは、Webデザインにおいて非常に重要です。ただし、フォントサイズを調整して段落を見出しのように見せたり、見出しを段落のように見せたりすることはできません。

必ず正しいHTMLタグを使用してください。<h1> - <h6>は見出し、<p>は段落を表します：

フォントサイズの値は、絶対サイズまたは相対サイズにできます。

绝对大小：

  • 指定されたサイズのテキストを設定します
  • すべてのブラウザでユーザーがテキストサイズを変更できないようにする
  • 出力の物理的なサイズが決まっている場合、絶対サイズは便利です。

相对大小：

  • 周囲の要素に対してサイズを設定します
  • ユーザーがブラウザでテキストサイズを変更できるようにする

フォントサイズを指定しない場合、デフォルトサイズは通常のテキスト段落と同じ16ピクセル（16px=1em）です。

フォントサイズをピクセルで設定する

フォントサイズをピクセルで設定すると、文字サイズを完全に制御できます：

实例

h1 {font-size:40px;}
h2 {font-size:30px;}
p {font-size:14px;}

尝试一下 »

上記の例は、Internet Explorer 9、Firefox、Chrome、Opera、Safariでブラウザのズームを使用してテキストサイズを調整できます。

ブラウザのズームツールでテキストサイズを調整することもできますが、この調整はページ全体に対して行われ、テキストだけに適用されるわけではありません。

emを使用してフォントサイズを設定します

Internet Explorer でテキストサイズを調整できない問題を避けるため、多くの開発者はピクセルの代わりに em 単位を使用しています。

emのサイズ単位はW3Cによって推奨されています。

1em は現在のフォントサイズに等しいです。ブラウザのデフォルトの文字サイズは16pxです。

したがって、1em のデフォルトサイズは16pxです。次の式でピクセルを em に変換できます：px/16=em

实例

h1 {font-size:2.5em;} /* 40px/16=2.5em */
h2 {font-size:1.875em;} /* 30px/16=1.875em */
p {font-size:0.875em;} /* 14px/16=0.875em */

尝试一下 »

上記の例では、em の文字サイズは前の例のピクセルと同じです。ただし、em 単位を使用すると、すべてのブラウザでテキストサイズを調整できます。

残念ながら、依然としてIEブラウザの問題があります。テキストサイズを調整すると、通常のサイズよりも大きくなったり小さくなったりします。

パーセンテージとEMの組み合わせを使用します

すべてのブラウザで機能する解決策としては、<body> 要素のデフォルトのフォントサイズをパーセンテージで設定します：

实例

body {font-size:100%;}
h1 {font-size:2.5em;}
h2 {font-size:1.875em;}
p {font-size:0.875em;}

尝试一下 »

私たちのコードは非常に効果的です。すべてのブラウザで同じテキストサイズを表示でき、すべてのブラウザでテキストサイズの拡大縮小が可能です。

    italicとobliqueの違い

    フォントには太字、斜体、下線、取り消し線など多くのプロパティがあります。

    しかし、すべてのフォントがこれらに対応しているわけではありません。あまり使われないフォントには通常のスタイルしかない場合があり、italic を使用しても効果がありません。

    その場合は oblique を使用します。italic はフォントの斜体を使用することであり、oblique は斜体プロパティを持たない文字を強制的に傾けることだと理解できます。

    また、CSS2.0 の説明を参考にしてください：italic と oblique はどちらも右に傾いた文字ですが、違いは italic が斜体字を指すのに対し、oblique は傾いたテキストを指します。斜体がないフォントには oblique プロパティ値を使用して傾きの効果を実現すべきです。

    接楼上。

    italic は、デフォルトの斜体設定を使用すると理解できます。斜体になるかどうか、斜体の角度がどうなるかは、デフォルト設定によって決まります。

    而 oblique（oblique は）斜体を強制的に使用します。斜体の角度もまた...oblique设置：

    <div style="font-style: oblique 5deg;">This is a sentence.</div>
<div style="font-style: oblique 10deg;">This is a sentence.</div>
<div style="font-style: oblique 20deg;">This is a sentence.</div>
<div style="font-style: oblique 30deg;">This is a sentence.</div>
<div style="font-style: oblique 40deg;">This is a sentence.</div>

    为了确保fontショートハンドプロパティが正しく解析されるには、以下のルールに注意する必要があります：

    1. 字体族必须放在最后

    在 font省略構文では：

    • 最後はフォントファミリ（font-family）でなければなりません
    • フォントサイズ（font-size）はフォントファミリの前に置く必要があります
    • 行の高さ（line-height）はオプションです。存在する場合はフォントサイズの後に書き、スラッシュ（/）で区切ります。/分隔
    • その他のプロパティ（font-style、font-weight、font-variant など）は先頭に書くことができ、順序は比較的自由です。

    つまり全体の構造は次のようになります：

    font: [其他字体属性] font-size [/line-height] font-family;
    2. 同类属性不能重复声明

    一部のキーワードは本質的に同じ種類のプロパティに属するため：

    • bold 与 font-weight的数值（如700）効果は同じで、互換性がありますが、同時に指定することはできません。
    • italic 与 oblique どちらも font-style に属し、同時に指定することはできません。
    3. 合法但较少见的示例
    font: bold small-caps oblique 100%/1.5em Georgia, serif;

    上述写法是完全合法的、その意味は次の通りです：

    • bold→ 粗体
    • small-caps→ スモールキャップス
    • oblique→ 斜体フォント
    • 100%→ フォントサイズ
    • 1.5em→ 行高
    • Georgia, serif→ 字体族

    構文は正しいですが、この書き方は実際の開発ではあまり使用されず、可読性も低いです。
