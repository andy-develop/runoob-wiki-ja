入力ボックス(input)スタイル

width 属性を使用して入力フィールドの幅を設定します。

CSS 实例

input { width: 100%; }

尝试一下 »

上記の例では、すべての <input> 要素の幅を 100% に設定しています。特定のタイプの入力フィールドのみを設定したい場合は、以下の属性セレクターを使用できます：

  • input[type=text]- テキスト入力ボックスを選択する
  • input[type=password]- パスワードの入力フィールドを選択
  • input[type=number]- 数字の入力フィールドを選択
  • ...

输入框填充

使用padding属性を使用すると、入力フィールドに内側の余白（パディング）を追加できます。

CSS 实例

input[type=text] { width: 100%; padding: 12px 20px; margin: 8px 0; box-sizing: border-box; }

尝试一下 »

設定していることに注意してくださいbox-sizing属性为border-boxこれにより、ブラウザは指定された幅と高さの入力フィールドを、ボーダーとパディングを含めて描画することができます。
詳細は〜で読むことができますCSS3 框大小 。

入力ボックス(input)のボーダー（枠線）

使用border属性を使用すると、input のボーダーのサイズや色を変更できます。使用border-radius属性を使用すると、input に角丸を追加できます。

CSS 实例

input[type=text] { border: 2px solid red; border-radius: 4px; }

尝试一下 »

下部のボーダーだけを追加したい場合は、〜を使用できますborder-bottom属性:

CSS 实例

input[type=text] { border: none; border-bottom: 2px solid red; }

入力ボックス(input)のフォーカス

デフォルトでは、一部のブラウザでは入力フィールドがフォーカスを取得したとき（入力フィールドをクリックしたとき）に青いアウトラインが表示されます。 input のスタイルを次のように設定できます。outline: none;この効果を無効にするには

使用:focusセレクタを使用すると、入力フィールドがフォーカスを取得したときのスタイルを設定できます。

CSS 实例

input[type=text]:focus { background-color: lightblue; }

尝试一下 »

CSS 实例

input[type=text]:focus { border: 3px solid #555; }

尝试一下 »

入力ボックス(input)のアイコン

入力フィールドにアイコンを追加したい場合は、次を使用できます。background-imageプロパティと位置指定用のbackground-position属性を使用します。アイコンに余裕を持たせるため、アイコンの左マージンを設定することに注意してください。

CSS 实例

input[type=text] { background-color: white; background-image: url('searchicon.png'); background-position: 10px 10px; background-repeat: no-repeat; padding-left: 40px; }

アニメーション付きの検索ボックス

以下の例ではCSSを使用していますtransition属性は、入力フィールドがフォーカスを取得したときに右に伸びるように設定します。次の方法で確認できます。CSS 动画章で詳細を参照してください

CSS 实例

input[type=text] { -webkit-transition: width 0.4s ease-in-out; transition: width 0.4s ease-in-out; } input[type=text]:focus { width: 100%; }
