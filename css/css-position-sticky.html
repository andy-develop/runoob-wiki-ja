CSS position: sticky プロパティ値

CSS position プロパティ

position: stickyCSSのpositionプロパティの中では比較的新しい値です。粘着位置指定はである相対位置指定とと固定位置の指定の混合体です。要素は指定されたしきい値を越えるまでは相対位置指定のように動作し、越えた後は固定位置指定のように動作します。

これは「上部固定ナビゲーション」「テーブル見出しの固定」などの効果を実現する現代的な解決策です。

単語の説明：sticky「粘着的な」という意味で、要素が特定の位置に「貼り付いて」動かなくなることを表します。

基本構文

position: sticky少なくとも1つの方向（top、right、bottom、left）のしきい値と組み合わせて、「粘着」が有効になる位置を指定する必要があります。

/* 语法 */
position: sticky;

/* 常用组合：滚动到距离顶部 10px 时固定 */
.sticky-header {
    position: sticky;
    top: 10px;
}

動作原理

stickypositionの動作は2つの段階に分けることができます：

段階 1：通常スクロール（相対位置指定）

要素がビューポート内で指定されたしきい値に達していない場合、要素は通常のドキュメントフローに従ってレイアウトされ、ページのスクロールに合わせて移動します。このとき、相対位置指定に相当します。position: relative。

段階2：固定表示（固定位置の指定）

要素がスクロールして指定されたしきい値を超えると、要素は固定されその位置に留まり、ページのスクロールに追従しなくなります。このとき、固定位置指定に相当します。position: fixed。

しきい値の条件

プロパティ 発動条件
top: 10px 要素の上端がビューポートの上端から10pxを超えたら固定
bottom: 10px 要素の下端がビューポートの下端から10pxを超えたら固定
left: 10px 要素の左端がビューポートの左端から10pxを超えたら固定
right: 10px 要素の右端がビューポートの右端から10pxを超えたら固定

中核となる特徴

特徴 1：双方向の動作

stickyはrelativeとfixedの両方の特性を兼ね備え、両者の完璧な組み合わせです。

特徴 2：親要素のposition指定が不要

とabsoluteとは異なり、sticky要素は親要素にpositionプロパティを設定する必要はありません。

特徴 3：親コンテナのoverflowによる制限

親要素にoverflowが設定されている場合、overflow: hidden、overflow: auto 或 overflow: scrollsticky位置指定は機能しなくなる可能性があります。

特徴 4：z-indexが有効になる

sticky位置指定はz-indexz-indexプロパティを有効にします。

例 3：サイドバーの粘着効果

ページのコンテンツが長い場合、スクロールして一定の位置に達したサイドバーを固定できます：

例

<!DOCTYPE html>
<html>
<head>
    <style>
        * {
            margin: 0;
            padding: 0;
            box-sizing: border-box;
        }

        body {
            font-family: Arial, sans-serif;
        }

        .container {
            display: grid;
            grid-template-columns: 1fr 200px;
            max-width: 900px;
            margin: 0 auto;
        }

        .main-content {
            padding: 20px;
        }

/* 粘着サイドバー */
        .sidebar {
            position: sticky;
top: 20px; /* 上部から20pxの位置で固定 */
            height: fit-content;
            background-color: #3498db;
            color: white;
            padding: 15px;
            border-radius: 4px;
        }

        .content-block {
            background-color: #f5f5f5;
            padding: 20px;
            margin-bottom: 20px;
            border-radius: 4px;
        }

        .tall-block {
            height: 800px;
        }
    </style>
</head>

    <div class="container">
        <div class="main-content">

注意事項

ブラウザ互換性：position: stickyモダンブラウザでは良好にサポートされていますが、IEブラウザではまったくサポートされていません。IEをサポートする必要がある場合は、JavaScriptまたは他のpolyfill方式をフォールバックとして使用する必要があります。

親要素のoverflowの影響

親要素に以下の属性が設定されている場合、sticky 配置は無効になります：

overflow: hidden
overflow: auto
overflow: scroll

しきい値の設定が必要

少なくとも設定が必要ですtop、right、bottom 或 leftのうち1つを設定しないと、sticky は有効になりません（要素は通常の文書フローに従ってレイアウトされます）。

しきい値の計算

sticky 配置のしきい値はビューポートに対して計算され、親要素に対してではありません。

他のposition値との比較

position 値 文書フローから外れるか 固定条件 互換性
static 否 无 すべてのブラウザ
relative 否 无 すべてのブラウザ
absolute である 无 すべてのブラウザ
fixed である 常に固定 すべてのブラウザ
sticky しきい値前：いいえ、しきい値後：はい しきい値を超えてスクロール モダンブラウザ（IE は非対応）

よくある適用シナリオ

シナリオ 1：上部固定ナビゲーション

.nav {
    position: sticky;
    top: 0;
}

シナリオ 2：テーブル見出しの固定

th {
    position: sticky;
    top: 0;
}

シナリオ 3：サイドバーの固定

.sidebar {
    position: sticky;
    top: 20px;
}

シナリオ 4：記事の章見出し

.chapter-header {
    position: sticky;
    top: 0;
    background: white;  /* 固定时显示背景 */
}

まとめ

position: stickyは、現代のWebレイアウトにおいて非常に実用的な技術です：

  • である相対配置と固定配置の組み合わせ
  • 少なくとも1つの方向のしきい値（top/right/bottom/left）を設定する必要があります
  • スクロールがしきい値を超える前：通常の文書フローに従ってレイアウト（相対配置）
  • スクロールがしきい値を超えた後：現在の位置に固定（固定配置）
  • 親要素に配置の設定は必要ありません
  • 親要素に overflow を設定すると無効になります
  • モダンブラウザでのサポートは良好、IE では非対応
  • 上部固定ナビゲーション、ヘッダー固定、サイドバー固定、セクション見出し固定によく使用されます
