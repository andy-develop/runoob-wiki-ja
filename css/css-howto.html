CSS 创建

スタイルシートを読み込むと、ブラウザはそれに基づいてHTMLドキュメントをフォーマットします。

スタイルシートの挿入方法

スタイルシートを挿入する方法は3つあります：

  • 外部样式表(External style sheet)
  • 内部样式表(Internal style sheet)
  • インラインスタイル

外部样式表

スタイルを多くのページに適用する必要がある場合、外部スタイルシートが理想的な選択です。外部スタイルシートを使用する場合、1つのファイルを変更するだけでサイト全体の外観を変更できます。各ページは <link> タグを使用してスタイルシートにリンクします。<link> タグは（ドキュメントの）ヘッド内に置きます：

<head> <link rel="stylesheet" type="text/css" href="mystyle.css"> </head>

ブラウザは mystyle.css ファイルからスタイル宣言を読み取り、それに基づいてドキュメントをフォーマットします。

外部スタイルシートは任意のテキストエディタで編集できます。ファイルには html タグを含めることはできません。スタイルシートは .css 拡張子で保存する必要があります。以下はスタイルシートファイルの例です：

hr {color:sienna;} p {margin-left:20px;} body {background-image:url("/images/back40.gif");}

属性値と単位の間にスペースを入れないでください（例："margin-left: 20 px"）。正しい書き方は "margin-left: 20px" です。

内部样式表

単一のドキュメントに特別なスタイルが必要な場合は、内部スタイルシートを使用する必要があります。<style> タグを使用して、ドキュメントのヘッド内で内部スタイルシートを定義できます。次のように：

<head> <style> hr {color:sienna;} p {margin-left:20px;} body {background-image:url("images/back40.gif");} </style> </head>

内联样式

インラインスタイルは、表現と内容を混在させるため、スタイルシートの多くの利点を失わせます。この方法は慎重に使用してください。例えば、スタイルを1つの要素に一度だけ適用する必要がある場合などです。

インラインスタイルを使用するには、関連するタグ内でスタイル（style）属性を使用する必要があります。style属性には任意のCSSプロパティを含めることができます。この例では、段落の色と左マージンを変更する方法を示しています：

<p style="color:sienna;margin-left:20px">これは段落です。</p>

多重样式

異なるスタイルシートで同じセレクタによって定義された属性がある場合、属性値はより詳細なスタイルシートから継承されます。

例えば、外部スタイルシートには h3 セレクタに対する3つの属性があります：

h3 { color:red; text-align:left; font-size:8pt; }

一方、内部スタイルシートには h3 セレクタに対する2つの属性があります：

h3 { text-align:right; font-size:20pt; }

内部スタイルシートを持つこのページが外部スタイルシートにもリンクしている場合、h3 が取得するスタイルは次のようになります：

color:red; text-align:right; font-size:20pt;

つまり、色属性は外部スタイルシートから継承され、text-alignment（文字配置）と font-size（フォントサイズ）は内部スタイルシートのルールによって置き換えられます。

多重スタイルの優先順位

スタイルシートでは、スタイル情報をさまざまな方法で指定できます。スタイルは、個々のHTML要素内、HTMLページのhead要素内、または外部CSSファイル内で指定できます。さらに、同じHTMLドキュメント内で複数の外部スタイルシートを参照することもできます。

一般的に、優先順位は次のとおりです：

（内联样式）Inline style > （内部样式）Internal style sheet >（外部样式）External style sheet > 浏览器默认样式

style.cssファイルスタイルのコードは次のとおりです：

h3 {
    color:blue;
}

实例

<head> <!--外部样式 style.css--> <link rel="stylesheet" type="text/css" href="style.css"/> <!--设置：h3{color:blue;}--> <style type="text/css">/* 内部样式 */ h3{color:green;}</style> </head> <body> <h3>緑色で表示され、内部スタイルです</h3> </body>

    多重スタイルの優先順位の詳細な概念

    優先順位とは、ブラウザーがどの属性値が要素に最も関連しているかを判断し、その要素に適用して決定するものです。優先順位は、セレクターで構成されるマッチングルールによってのみ決定されます。

    優先度とは、特定のCSS宣言に割り当てられる重みであり、一致するセレクタに含まれる各セレクタタイプの数値によって決定されます。

    优先级顺序

    以下は、優先度が段階的に増加するセレクタのリストです：

    • ユニバーサルセレクタ（*）
    • 要素（タイプ）セレクタ
    • 类选择器
    • 属性选择器
    • 伪类
    • IDセレクタ
    • 内联样式

    !important ルールの例外

    !important ルールがスタイル宣言に適用されると、そのスタイル宣言は、宣言リスト内のどこにあるかに関係なく、CSS内の他のすべての宣言を上書きします。それでも、!important ルールは優先度とはまったく関係ありません。!important を使用するのは良い習慣ではありません。スタイルシート本来のカスケードルールを変更し、デバッグを困難にするからです。

    いくつかの経験則：

    • Always問題を解決するには、スタイルルールの優先度を使用することを優先的に検討すべきであり、!important
    • Onlyサイト全体または外部 CSS（例えば、参照している ExtJs や YUI）を上書きする必要がある特定のページでのみ使用するのではなく、!important
    • Neverサイト全体の CSS には決して使用しないでください。 !important
    • Neverプラグインでは決して使用しないでください!important

    权重计算:

    解释：

    • 1. インラインスタイルの重みは最高で 1000；
    • 2. IDセレクタの重みは100
    • 3. クラスセレクタの重みは 10
    • 4. HTML タグセレクタの重みは 1

    セレクタの重みを計算して比較すると、em は青色で表示されます。例は次のとおりです：https://c.runoob.com/codedemo/3048

    CSS優先順位の法則：

    • A セレクタにはそれぞれ重みがあり、重みが大きいほど優先されます。
    • B 重みが等しい場合は、後から指定されたスタイルシートの設定が先に指定されたスタイルシートの設定よりも優先されます。
    • C 作成者のルールは閲覧者のルールよりも高い：つまり、Webページ作成者が設定したCSSスタイルの優先権は、ブラウザが設定したスタイルよりも高い。
    • D 継承されたCSSスタイルは、後から指定されたCSSスタイルには及ばない。
    • E 同じグループの属性設定内で、「!important」ルールが付けられたものは優先度が最大です。例は次のとおりです：https://c.runoob.com/codedemo/3049
      結果：Firefoxでは青で表示され、IE 6では赤で表示されます。
