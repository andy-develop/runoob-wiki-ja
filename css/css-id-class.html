CSS idとclass

id と class セレクタ

HTML要素にCSSスタイルを設定する場合、要素に「id」と「class」セレクターを設定する必要があります。

id セレクタ

idセレクターは、特定のidが付けられたHTML要素に特定のスタイルを指定できます。

HTML要素はid属性でidセレクターを設定します。CSSではidセレクターは「#」で定義します。

以下のスタイルルールは、属性 id="para1" の要素に適用されます。

实例

#para1 { text-align:center; color:red; }

尝试一下 »

ID属性は数字で始めてはいけません。数字で始まるIDはMozilla/Firefoxブラウザーでは機能しません。

class セレクタ

classセレクターは一組の要素のスタイルを記述するために使用します。classセレクターはidセレクターとは異なり、classは複数の要素で使用できます。

classセレクターはHTMLではclass属性で表します。CSSでは、クラスセレクターはドット（.）で.号显示：

以下の例では、center クラスを持つすべてのHTML要素が中央揃えになります。

实例

.center {text-align:center;}

尝试一下 »

特定のHTML要素にclassを使用するよう指定することもできます。

以下の例では、すべての p 要素が class="center" を使用して、その要素のテキストを中央揃えにします：

实例

p.center {text-align:center;}

尝试一下 »

複数のclassセレクターはスペースで区切ることができます：

实例

.center { text-align:center; } .color { color:#ff0000; }

尝试一下 »

クラス名の最初の文字に数字は使用できません！Mozilla や Firefox では機能しません。

    CSS セレクタ

    HTMLタグにCSSスタイルを設定する場合、4つの方法があります。つまりCSSセレクターには4種類あります。

    前述のidセレクターとclassセレクターの他に、3つ目のセレクターはタグセレクターです。これはHTMLタグをCSS修飾に使用するセレクターです。

    实例

    <style>
h3{
    color:red;
}
</style>
<h3>菜鸟教程</h3>

    4つ目のセレクターは、タグの内部に直接CSSコードを書く方法です。

    实例

    <h3 style="color:red;">菜鸟教程</h3>

    この4つのCSSセレクターには修飾上の優先順位があり、すなわち：

    第四种 > id > class > 第三种

    チュートリアルで説明したIDセレクタとクラスセレクタの他に、要素セレクタ、属性セレクタ、包含セレクタ、子セレクタ、そしてCSS3で新たに追加された兄弟セレクタがあります。以下ではIDセレクタとクラスセレクタも含めて例を挙げます。

    1.IDセレクタ（ID selector、IS）：セレクタを表すために # を使用します。構文形式：#S{...}（Sはセレクター名です）。例：idがnameのタグは以下のスタイルにマッチします。

    <style>
#name{
  color:red;
}
</style>
<!--下面文字是红色的-->
<p id="name">red text</p>

    2.クラスセレクタ（class selector、CS）：セレクタを表すために . を使用します。構文形式：.S{...}（Sはセレクター名です）。例：class属性の値がvalueのタグは以下のスタイルにマッチします。

    <style>
.value{
  text-align:center;
}
</style>
<!--下面的文字是居中对齐的-->
<p class="value">center text</p>

    3. 要素セレクター（element selector、ES）：タグセレクターとも呼ばれ、タグ名をセレクター名として使用します。構文形式：S{...}（Sはセレクター名です）。例：すべてのpタグは以下のスタイルにマッチします。

    <style>
p{
  font-style:italic;
}
</style>
<!--下面的文字是斜体的-->
<p style="font-style:italic">italic text</p>

    4. 属性セレクター（attribute selector、AS）：ESは実際にはASの特殊なケースです。ASに基づいてセレクターをより具体的に記述できます。構文形式はE[attr[~=][|=][^=][$=][*=]VALUE]{...}、これはすべてのブラウザーでサポートされているわけではないセレクターのため、例は挙げません。

    5. 包含セレクター（package selector、PS）：ターゲットセレクターが、特定のセレクターに対応する要素の内部にあることを指定します。構文形式：A B{...}（A、BはHTML要素/タグで、Aの中にあるBタグに対して有効であることを示します）。例：以下のdiv内のpタグとdiv外のpタグはそれぞれ異なるスタイルにマッチします。

    <style>
p{
  color:red;
}
div p{
  color:yellow;
}
</style>
<p>red text</p><!--文字是红色的-->
<div>
  <p>yellow text</p><!--文字是黄色的-->
</div>

    6. 子セレクター（sub-selector、SS）：PSに似ており、ターゲットセレクターが特定のセレクターに対応する要素の内部にあることを指定します。両者の違いは、PSは「子タグ」だけでなく「孫タグ」やさらに深くネストされたタグにも対応するスタイルのマッチを許可するのに対し、SSはターゲットセレクターを包含セレクターに対応するタグの内部のタグとして強制指定することです。構文形式：A>B{...}（A、BはHTML要素/タグです）。例：以下のdiv内のpタグはスタイルにマッチしますが、div内のtable内のpはマッチしません。

    <style>
div>p{
  color:red;
}
</style>
<div>
  <p>red text</p><!--文字是红色的-->
  <table>
    <tr>
      <td>
        <p>no red text;</p><!--文字是非红色的-->
      </td>
    </tr>
  </table>
</div>

    7.兄弟セレクタ（brother selector、BS）：BSはCSS3.0で新しく追加されたセレクタです。構文形式：A~B{...}（A、BはHTML要素/タグで、AタグがセレクターのAにマッチし、BタグがセレクターのBにマッチするとき、Bタグがスタイルにマッチすることを示します）

    <style>
div~p{
  color:red;
}
</style>
<div>
  <p>no red text</p><!--文字是非红色的-->
  <div>no red text</div>
  <p>red text</p><!--文字是红色的-->
</div>

    上記のノートに基づき、タグセレクターに関するいくつかの補足：

    1. 包含セレクタの補足：

    子孫セレクタには、他にもA B{...}の形式（AとBはどちらもタグ）以外に、次のような形式もあります：.A B{...}の形式（Aはクラス名、Bはタグ）。

    作用は上記で紹介したものと同じで、class名がAのタグ内にある、名前がBのすべての子孫タグの内容を設定した内容に従って表示します。

    <style>
.first span{
  color:red;
}
</style>
<body>
<p class="first"><span>内容为红色</span>
<ol>
  <li><span>内容也是红色</span></li>
  <li><span>内容也是红色</span></li>
</ol></p>

</body>

    2. 子セレクタの補足

    子セレクタには、他にもA >B{...}の形式（AとBはどちらもタグ）以外に、次のような形式もあります：.A >B{...}の形式（Aはクラス名、Bはタグ）。

    作用は上記で紹介したものと同じで、classがAのタグ内にある、名前がBのすべての直接の子タグの内容を設定した内容に従って表示します。直接の子ではないBタグの内容は変更されません。

    <style>
.first>span{
  color:red;
}
</style>
<body>
<p class="first"><span>内容为红色</span>
<ol>
  <li><span>内容不是红色</span></li>
  <li><span>内容不是红色</span></li>
</ol></p>

</body>
    3.通用选择器

    構文形式は次のとおりです：*{属性：属性值}。その作用はHTML内のすべての要素タグにマッチすることです。

    <!--使用html中任意标签元素字体颜色全部设置为红色：-->
<style>
*{color:red;}
</style>

<body>
<h1>标题为红色</h1>
<p>段落也为红色</p>
</body>

    構文形式は次のとおりです：

    A+B{
    声明1; 
    声明;
    ...

    <!--相邻选择器选择每个div紧邻后的一个元素p-->
<style>
   div+p{
     color: red;
   }
</style>
<div>
   <p>not red text</p>
   <p>not red text</p>
</div>
<p>red text</p>

    CSSにおけるカンマ、スペース、コロン、ドットの意味

    一：#a,b{…………｝

    二：#a b{…………｝

    三：#a:b{…………｝

    四：#a.b{…………｝

    これら4つはそれぞれ何を意味するのでしょうか？

    一、idがaの要素と、タグがbの要素のスタイル

    二、idがaの要素の下にある、タグがbの要素のスタイル

    三、idがaの要素の疑似クラスb、例：a:hover

    四、idがaの要素の下にある、classがbの要素のスタイル

    上記の説明はどれも詳細なので、ここでまとめと参考までに。

    1. タグセレクター       説明：指定したタグを選択します。要素セレクターとも呼ばれます。
    2. idセレクタ # 説明：id属性を選択
    3. classセレクタ . 説明：class属性を選択
    4. 属性セレクター   []       説明：このように「a[id]」と書くと、指定したルールの属性を持つタグを選択します。
    5. 包含セレクター （スペース）   説明：すべての子、孫などを選択します....
    6. 子セレクター  >       説明：すべての子を選択し、孫などは選択しません...
    7. 兄弟セレクター  ~      説明：後続の1つまたは複数の兄弟を選択します。
    8. 隣接セレクター  +       説明：後続の1つの兄弟を選択します。
    9. 疑似クラスセレクター   :      説明：主にユーザーの操作、タグの位置、タグの状態に基づいて選択します。
    10. 疑似要素セレクター ::     説明：主にテキストの1行、最初の文字を選択したり、前後にスタイルを追加します。

    各種セレクターは優先順位と互換性に関わりますが、ここではまとめません。
