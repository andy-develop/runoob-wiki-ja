CSS Float(浮动)

CSS Float（フロート）とは何ですか？



CSS の Float（フロート）は、要素を左または右に移動させ、その周囲の要素も再配置されます。

Float（フロート）は、よく画像に使用されますが、レイアウトの際にも同様に非常に役立ちます。

要素はどのようにフロートするか

要素の水平方向のフロートは、要素が左右にのみ移動でき、上下には移動できないことを意味します。

フロート要素は、その外側の端が包含ボックスまたは別のフロートボックスの境界線に触れるまで、できるだけ左または右に移動しようとします。

フロート要素の後の要素は、その周りを囲みます。

フロート要素の前にある要素は影響を受けません。

画像が右にフロートされている場合、後続のテキストフローはその左側を囲みます：

实例

img { float:right; }

互いに隣接するフロート要素

複数のフロート要素を一緒に配置すると、スペースがあればそれらは互いに隣接します。

ここでは、イメージギャラリーに float プロパティを使用します：

实例

.thumbnail { float:left; width:110px; height:90px; margin:5px; }

尝试一下 »

フロートの解除 - clearを使用

要素がフロートした後、周囲の要素が再配置されます。この状況を避けるために、clear プロパティを使用します。

clear プロパティは、要素の両側にフロート要素が表示されないように指定します。

clear プロパティを使用して、テキストにイメージギャラリーを追加します：

实例

.text_line { clear:both; }
