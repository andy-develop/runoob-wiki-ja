JSP アクション要素

JSPディレクティブ要素とは異なり、JSPアクション要素はリクエスト処理フェーズで機能します。JSPアクション要素はXML構文で記述されます。

JSPアクションを使用すると、ファイルを動的に挿入したり、JavaBeanコンポーネントを再利用したり、ユーザーを別のページにリダイレクトしたり、Javaプラグイン用のHTMLコードを生成したりできます。

アクション要素にはXML標準に準拠した唯一の構文があります：

<jsp:action_name attribute="value" />

アクション要素は基本的にすべて事前定義された関数です。JSP仕様は一連の標準アクションを定義しており、JSPをプレフィックスとして使用します。利用可能な標準アクション要素は次のとおりです：

構文説明
jsp:includeページがリクエストされたときにファイルをインクルードします。
jsp:useBeanJavaBeanを検索またはインスタンス化します。
jsp:setPropertyJavaBeanのプロパティを設定します。
jsp:getPropertyあるJavaBeanのプロパティを出力します。
jsp:forwardリクエストを新しいページに転送します。
jsp:pluginブラウザの種類に応じて、Javaプラグイン用のOBJECTまたはEMBEDタグを生成します。
jsp:element動的XML要素を定義します。
jsp:attribute動的に定義されたXML要素の属性を設定します。
jsp:body動的に定義されたXML要素の内容を設定します。
jsp:textJSPページおよびドキュメントでテキストを書き込むためのテンプレートを使用します。

一般的な属性

すべてのアクション要素には、id属性とscope属性の2つの属性があります。

  • id属性：

    id属性はアクション要素の一意の識別子であり、JSPページ内で参照できます。アクション要素によって作成されたid値はPageContextを介して呼び出すことができます。

  • scope属性：

    この属性は、アクション要素のライフサイクルを識別するために使用されます。id属性とscope属性には直接的な関係があり、scope属性は関連付けられたidオブジェクトの寿命を定義します。scope属性には4つの可能な値があります: (a) page, (b) request, (c) session, (d) application。

<jsp:include> アクション要素

<jsp:include> アクション要素は、静的および動的なファイルをインクルードするために使用されます。このアクションは、指定されたファイルを生成中のページに挿入します。構文形式は次のとおりです：

<jsp:include page="相对 URL 地址" flush="true" />

前述のincludeディレクティブは、JSPファイルがServletに変換されるときにファイルをインクルードしますが、ここでのjsp:includeアクションは異なり、ファイルが挿入されるのはページがリクエストされたときです。

以下はincludeアクションに関連する属性のリストです。

属性説明
pageページに含まれる相対URLアドレス。
flushブール属性で、リソースをインクルードする前にバッファーをフラッシュするかどうかを定義します。

例

以下では2つのファイルを定義します。date.jsp 和 main.jspコードは次のとおりです：

date.jspファイルのコード：

<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<p>
   今天的日期是: <%= (new java.util.Date()).toLocaleString()%>
</p>

main.jspファイルのコード：

<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>菜鸟教程(runoob.com)</title>
</head>
<body>

<h2>include 动作实例</h2>
<jsp:include page="date.jsp" flush="true" />

</body>
</html>

上記2つのファイルをサーバーのルートディレクトリに置き、main.jspファイルにアクセスします。表示結果は次のとおりです：

<jsp:useBean> アクション要素

jsp:useBeanこのアクションは、JSPページで使用されるJavaBeanをロードするために使用されます。

この機能は、Javaコンポーネントの再利用という利点を活かすことができるため、非常に便利です。

jsp:useBeanアクションの最も簡単な構文は次のとおりです：

<jsp:useBean id="name" class="package.class" />

クラスがロードされた後、jsp:setProperty および jsp:getProperty アクションを使用して、Beanのプロパティを変更および取得できます。

以下はuseBeanアクションに関連する属性のリストです。

属性説明
classBeanの完全なパッケージ名を指定します。
typeこのオブジェクトを参照する変数の型を指定します。
beanNamejava.beans.Beans の instantiate() メソッドを使用してBeanの名前を指定します。

具体的な例を示す前に、jsp:setProperty と jsp:getProperty アクション要素を見てみましょう。

<jsp:setProperty> アクション要素

jsp:setPropertyは、すでにインスタンス化されたBeanオブジェクトのプロパティを設定するために使用され、2つの使い方があります。まず、jsp:useBean要素の外側（後ろ）でjsp:setPropertyを使用できます。次のようになります：

<jsp:useBean id="myName" ... />
...
<jsp:setProperty name="myName" property="someProperty" .../>

この場合、jsp:useBeanが既存のBeanを見つけたか、新しいBeanインスタンスを作成したかに関係なく、jsp:setPropertyは実行されます。2番目の使い方は、jsp:setPropertyをjsp:useBean要素の内部に置くことです。次のようになります：

<jsp:useBean id="myName" ... >
...
   <jsp:setProperty name="myName" property="someProperty" .../>
</jsp:useBean>

この場合、jsp:setPropertyは新しいBeanインスタンスが作成されたときのみ実行され、既存のインスタンスを使用する場合はjsp:setPropertyは実行されません。

jsp:setPropertyアクションには次の4つの属性があります。下表のとおりです：

属性説明
namename属性は必須です。プロパティを設定するBeanを指定します。
propertyproperty属性は必須です。どのプロパティを設定するかを指定します。特別な使い方として、propertyの値が"*"の場合、Beanのプロパティ名と一致するすべてのリクエストパラメータが、対応するプロパティのsetメソッドに渡されます。
valuevalue属性はオプションです。この属性はBeanプロパティの値を指定するために使用されます。文字列データは、ターゲットクラス内で標準のvalueOfメソッドによって、数値、boolean、Boolean、byte、Byte、char、Characterに自動変換されます。例えば、booleanおよびBoolean型のプロパティ値（"true"など）はBoolean.valueOfによって変換され、intおよびInteger型のプロパティ値（"42"など）はInteger.valueOfによって変換されます。 　　valueとparamは同時に使用できませんが、どちらか一方を使用できます。
paramparamはオプションです。どのリクエストパラメータをBeanプロパティの値として使用するかを指定します。現在のリクエストにパラメータがない場合は何も行われず、システムはnullをBeanプロパティのsetメソッドに渡しません。したがって、Bean自身にデフォルトのプロパティ値を提供させ、リクエストパラメータが新しい値を明示的に指定した場合にのみデフォルト値を変更させることができます。

<jsp:getProperty> アクション要素

jsp:getPropertyアクションは、指定されたBeanプロパティの値を抽出し、文字列に変換して出力します。構文形式は次のとおりです：

<jsp:useBean id="myName" ... />
...
<jsp:getProperty name="myName" property="someProperty" .../>

下表はgetPropertyに関連する属性です：

属性説明
name取得するBeanプロパティ名。Beanが定義されている必要があります。
propertyBeanプロパティの値を抽出することを示します。

例

以下の例ではBeanを使用しました：

package com.runoob.main;

public class TestBean {
   private String message = "菜鸟教程";
 
   public String getMessage() {
      return(message);
   }
   public void setMessage(String message) {
      this.message = message;
   }
}

上記のサンプルファイル TestBean.java をコンパイルします：

$ javac TestBean.java

コンパイルが完了すると、現在のディレクトリにTestBean.classファイルが生成されます。このファイルを現在のJSPプロジェクトのWebContent/WEB-INF/classes/com/runoob/main配下（com/runoob/main パッケージパス、存在しない場合は手動で作成する必要があります）にコピーします。

<jsp:forward> アクション要素

jsp:forwardアクションは、リクエストを別のページに転送します。jsp:forwardタグにはpageという1つの属性だけがあります。構文形式は次のとおりです：

<jsp:forward page="相对 URL 地址" />

以下はforwardに関連する属性です：

属性説明
pagepage属性には相対URLが含まれます。pageの値は直接指定することも、リクエスト時に動的に計算することもできます。JSPページまたはJava Servletを指定できます。

例

以下の例では、date.jsp と main.jsp の2つのファイルを使用しました。

date.jsp ファイルのコードは次のとおりです：

<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<p>
   今天的日期是: <%= (new java.util.Date()).toLocaleString()%>
</p>

main.jspファイルのコード：

<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>菜鸟教程(runoob.com)</title>
</head>
<body>

<h2>forward 动作实例</h2>
<jsp:forward page="date.jsp" />
</body>
</html>

<jsp:plugin> アクション要素

jsp:pluginアクションは、ブラウザの種類に応じて、Javaプラグインを介してJavaアプレットを実行するために必要なOBJECTまたはEMBED要素を挿入します。

必要なプラグインが存在しない場合、プラグインをダウンロードしてからJavaコンポーネントを実行します。 Javaコンポーネントは、アプレットまたはJavaBeanにすることができます。

pluginアクションには、JavaコンポーネントをフォーマットするためのHTML要素に対応する複数の属性があります。param要素は、アプレットまたはBeanにパラメータを渡すために使用できます。

以下は、pluginアクション要素を使用した典型的な例です:

<jsp:plugin type="applet" codebase="dirname" code="MyApplet.class"
                           width="60" height="80">
   <jsp:param name="fontcolor" value="red" />
   <jsp:param name="background" value="black" />
 
   <jsp:fallback>
      Unable to initialize Java Plugin
   </jsp:fallback>
 
</jsp:plugin>

興味があれば、アプレットを使用してjsp:pluginアクション要素をテストしてみてください。<fallback>要素は新しい要素で、コンポーネントでエラーが発生したときにユーザーにエラーメッセージを送信します。

<jsp:element> 、<jsp:attribute>、<jsp:body> アクション要素

`<jsp:element>`、 `<jsp:attribute>`、 `<jsp:body>`アクション要素はXML要素を動的に定義します。動的であることは非常に重要です。つまり、XML要素はコンパイル時に静的にではなく動的に生成されることを意味します。

以下の例はXML要素を動的に定義しています:

<%@ page language="java" contentType="text/html; charset=UTF-8"
    pageEncoding="UTF-8"%>
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>菜鸟教程(runoob.com)</title>
</head>
<body>
<jsp:element name="xmlElement">
<jsp:attribute name="xmlElementAttr">
   属性值
</jsp:attribute>
<jsp:body>
   XML 元素的主体
</jsp:body>
</jsp:element>
</body>
</html>

<jsp:text> アクション要素

`<jsp:text>`アクション要素は、JSPページやドキュメントでテキストを書き込むためのテンプレートを使用することを許可します。構文形式は次のとおりです:

<jsp:text>模板数据</jsp:text>

上記のテキストテンプレートには重複する要素を含めることはできず、テキストとEL式のみを含めることができます（注：EL式については後続の章で説明します）。XMLファイルでは、${whatever > 0}のような式は使用できないことに注意してください。>記号は不正だからです。${whatever gt 0}式またはCDATAセクションに埋め込まれた値を使用できます。

<jsp:text><![CDATA[<br>]]></jsp:text>

XHTMLでDOCTYPEを宣言する必要がある場合は、<jsp:text>アクション要素を使用する必要があります。例は次のとおりです:

<jsp:text><![CDATA[<!DOCTYPE html
PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN"
"DTD/xhtml1-strict.dtd">]]>
</jsp:text>
<head><title>jsp:text action</title></head>
<body>

<books><book><jsp:text>  
    Welcome to JSP Programming
</jsp:text></book></books>

</body>
</html>

上記の例で、<jsp:text>を使用した場合と使用しない場合の実行結果の違いを試すことができます。
