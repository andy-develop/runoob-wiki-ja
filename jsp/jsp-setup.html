JSP 開発環境の構築

JSP開発環境は、JSPプログラムを開発・テスト・実行するための場所です。

このセクションでは、JSP開発環境の構築方法を説明します。具体的には以下の手順が含まれます。

Eclipse 環境を使用している場合は、次のページを参照してください：Eclipse JSP/Servlet 環境の構築。

Java開発ツール（JDK）の設定

この手順では、Java JDKのダウンロードとPATH環境変数の設定を行います。

Oracle社のJavaページからJDKをダウンロードできます：Java SE Downloads

Java JDKのダウンロードが完了したら、指定された指示に従ってJDKをインストールおよび設定してください。最後に、PATH環境変数とJAVA_HOME環境変数を設定して、javaおよびjavacを含むフォルダーのパスを指定します。通常はjava_install_dir/binとjava_install_dirです。

Windowsシステムを使用していて、JDKのインストールディレクトリがC::\jdk1.5.0_20の場合、C:\autoexec.batファイルに以下の2行を追加する必要があります：

set PATH=C:\jdk1.5.0_20\bin;%PATH%
set JAVA_HOME=C:\jdk1.5.0_20

または、Windows NT/2000/XPでは、[マイ コンピュータ]アイコンを右クリックし、[プロパティ]を選択して、[詳細設定]をクリックし、[環境変数]をクリックすると、PATH変数を簡単に設定して、[OK]をクリックして終了できます。

Linux/Unixシステムで、JDKのインストールディレクトリが/usr/local/jdk1.5.0_20で、Cシェルを使用している場合は、.cshrcファイルに以下の2行を追加する必要があります：

setenv PATH /usr/local/jdk1.5.0_20/bin:$PATH
setenv JAVA_HOME /usr/local/jdk1.5.0_20

または、Borland JBuilder、Eclipse、IntelliJ IDEA、Sun ONE Studioなどの統合開発環境（IDE）を使用している場合は、簡単なプログラムをコンパイルして実行し、IDEがJDKのインストールディレクトリを認識しているかどうかを確認できます。

この手順では、当サイトのJava開発環境の設定の章のチュートリアルも参照できます。

Webサーバーの設定：Tomcat

現在、市場にはJSPおよびServletsの開発をサポートするWebサーバーが多数あります。その一部は無料でダウンロードして使用でき、Tomcatもその1つです。

Apache Tomcatはオープンソースソフトウェアであり、JSPおよびServletsを実行するためのスタンドアロンサーバーとして使用できるほか、Apache Web Serverに統合することもできます。以下はTomcatの設定方法です：

  • 最新バージョンのTomcatをダウンロードします：http://tomcat.apache.org/。
  • インストールファイルのダウンロードが完了したら、圧縮ファイルを便利な場所に解凍します。たとえば、WindowsではC:\apache-tomcat-5.5.29ディレクトリ、Linux/Unixでは/usr/local/apache-tomcat-5.5.29ディレクトリです。次に、CATALINA_HOME環境変数を作成してこれらのディレクトリを指定します。

Windowsマシンでは、Tomcatは次のコマンドを実行して起動できます：

%CATALINA_HOME%\bin\startup.bat
或者
C:\apache-tomcat-5.5.29\bin\startup.bat

Linux/Unixマシンでは、Tomcatは次のコマンドを実行して起動できます：

$CATALINA_HOME/bin/startup.sh
或者
/usr/local/apache-tomcat-5.5.29/bin/startup.sh

Tomcatが正常に起動したら、http://localhost:8080/ にアクセスすると、Tomcatに付属のWebアプリケーションを使用できます。すべてが正常に動作すれば、次のページが表示されるはずです：

Tomcatの設定と実行に関する詳細は、Tomcatに付属のドキュメントを参照するか、Tomcatの公式サイト（http://tomcat.apache.org）で確認できます。

Windowsマシンでは、Tomcatは次のコマンドを実行して停止できます：

%CATALINA_HOME%\bin\shutdown.bat
或者
C:\apache-tomcat-5.5.29\bin\shutdown.bat

Linux/Unixマシンでは、Tomcatは次のコマンドを実行して停止できます：

$CATALINA_HOME/bin/shutdown.sh
或者
/usr/local/apache-tomcat-5.5.29/bin/shutdown.sh

CLASSPATH環境変数の設定

サーブレットはJava SEの一部ではないため、サーブレットクラスのコンパイラーを指定する必要があります。

Windowsマシンを使用している場合は、C:\autoexec.batファイルに以下の2行を追加する必要があります：

set CATALINA=C:\apache-tomcat-5.5.29
set CLASSPATH=%CATALINA%\common\lib\jsp-api.jar;%CLASSPATH%

または、Windows NT/2000/XPでは、[マイ コンピュータ]を右クリックして[プロパティ]を選択し、[詳細設定]をクリックして[環境変数]をクリックすると、CLASSPATH変数を設定して[OK]をクリックして終了できます。

Linux/UnixマシンでCシェルを使用している場合は、.cshrcファイルに以下の2行を追加する必要があります：

setenv CATALINA=/usr/local/apache-tomcat-5.5.29
setenv CLASSPATH $CATALINA/common/lib/jsp-api.jar:$CLASSPATH

注意：開発パスがC:\JSPDev（Windows）または/usr/JSPDev（Linux/Unix）の場合は、これらのパスをCLASSPATH変数に追加する必要があります。

    Tomcat環境変数Catalina_Homeの設定

    1、CATALINA_HOMEはTOMCATのインストールパスの別名であり、TOMCATを便利に使用するためのものです。

    2、[コンピュータ] > [プロパティ] > [環境変数] で、新しい環境変数を作成します。変数名はCATALINA_HOME、変数値はTomcatの解凍ディレクトリです。私のコンピュータでは「D:\apache-tomcat-7.0.12」です。最後に「\」や「;」を追加する必要はありません。

    3、環境変数Pathに「%CATALINA_HOME%\bin\ 」を追加します。

    3、Tomcatを起動します。コマンドプロンプト（cmd）を開き、startup.batを入力します。

    4、ブラウザを開いて、次のように入力します：http://localhost:8080、（ポート番号を変更した場合は、対応するポートを追加してください）Tomcatが正常に起動したかどうかを確認します。

    5、Tomcatを停止します。コマンドプロンプト（cmd）を開き、shutdown.batを入力します。

    Tomcatの8080ポートは頻繁に占有されることがあります。解決策は2つあります：

    • 1、8080ポートを占有しているプロセスを終了します。8080ポートが占有されているとstartup.batを実行するとエラーが発生します。cmdでnetstat -anoコマンドを実行して8080が占有されているかどうかを確認できます。占有されている場合は、対応するPID番号に基づいてタスクマネージャーで該当プロセスを探して終了し、Tomcatを再起動します。この方法の欠点は、ポートが占有されるたびに上記の操作を繰り返す必要があることです。
    • 2、Tomcatのポートを変更します。Tomcatのインストールディレクトリ\confフォルダーに移動し、service.xmlをメモ帳で開き、以下に示す場所で新しいポート番号を指定してTomcatを再起動します。
      <Connector port="8022" protocol="HTTP/1.1"
    connectionTimeout="20000" 
    redirectPort="8443" />

    protocolパラメータは次のように変更できます：org.apache.coyote.http11.Http11NioProtocol、Tomcatの同時処理能力を向上させることができます。この設定を変更した後、Tomcatを再起動して有効にする必要があります。

    <Connector port="8022" protocol="org.apache.coyote.http11.Http11NioProtocol"
    connectionTimeout="20000" 
    redirectPort="8443" />

    指定されたポートを占有しているアプリケーションを調べる方法

    CMDコマンドプロンプトを管理者として実行します。

    netstat -ano |findstr 3306      # 查看3306端口是否存在
tasklist |findstr 3036（PID号）  # 查看pid为3036的是什么程序在用
taskkill /T /F /PID 3036        # 强制（/F参数）杀死pid为3036的所有进程包括子进程（/T参数）

    詳細については、次を参照してください：Windowsで特定のポートが誰に占有されているかを確認する方法
