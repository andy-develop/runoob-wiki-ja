OpenCV 画像輪郭検出

輪郭検出は画像処理における重要なタスクであり、画像内の物体の境界を抽出するために使用されます。

OpenCV は強力な輪郭検出機能を提供しており、物体認識、形状分析、対象追跡などのアプリケーションに使用できます。以下は OpenCV 画像輪郭検出の詳細な説明です。

輪郭検出の基本概念

  • 輪郭:画像内の物体の境界であり、一連の点で構成されます。

  • 輪郭の階層構造:輪郭間のネスト関係。例えば、ある輪郭が別の輪郭を含むかどうか。

  • 輪郭の特徴:輪郭の面積、周長、境界矩形、最小外接矩形、最小外接円など。

輪郭検出でよく使う関数

関数名 機能説明
cv2.findContours() 画像内の輪郭を検出する
cv2.drawContours() 画像上に輪郭を描画する
cv2.contourArea() 輪郭の面積を計算する
cv2.arcLength() 輪郭の周長または弧長を計算する
cv2.boundingRect() 輪郭の境界矩形を計算する
cv2.minAreaRect() 輪郭の最小外接矩形を計算する
cv2.minEnclosingCircle() 輪郭の最小外接円を計算する
cv2.approxPolyDP() 輪郭を多角形近似する

関数の詳細説明

1. cv2.findContours()

機能説明:
この関数は、二値画像内の輪郭を検出するために使用されます。輪郭とは、画像内で同じ色または強度を持つ連続した点の曲線です。

関数定義: 

contours, hierarchy = cv2.findContours(image, mode, method[, contours[, hierarchy[, offset]]])

パラメータの説明:

  • image: 入力の二値画像（通常は閾値処理またはエッジ検出後の画像）。
  • mode: 輪郭検索モード。一般的なものは次の通り：
    • cv2.RETR_EXTERNAL: 最外側の輪郭のみを検出します。
    • cv2.RETR_LIST: すべての輪郭を検出しますが、階層関係は構築しません。
    • cv2.RETR_TREE: すべての輪郭を検出し、完全な階層構造を構築します。
  • method: 輪郭近似方法。一般的なものは次の通り：
    • cv2.CHAIN_APPROX_NONE: すべての輪郭点を格納します。
    • cv2.CHAIN_APPROX_SIMPLE: 水平、垂直、対角線分を圧縮し、端点のみを保持します。
  • contours: 出力される輪郭リスト。各輪郭は点の集合です。
  • hierarchy: 出力される階層構造情報。
  • offset: オプションのパラメータで、輪郭点のオフセット。

戻り値:

  • contours: 検出された輪郭のリスト。
  • hierarchy: 輪郭の階層構造情報。

サンプル

import cv2
import numpy as np

# 画像を読み込んでグレースケールに変換する
image = cv2.imread('image.png', 0)
# 二値化処理
_, binary = cv2.threshold(image, 127, 255, cv2.THRESH_BINARY)
# 輪郭を検出する
contours, hierarchy = cv2.findContours(binary, cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE)

2. cv2.drawContours()

機能説明:
この関数は、検出された輪郭を画像上に描画するために使用されます。

関数定義: 

cv2.drawContours(image, contours, contourIdx, color[, thickness[, lineType[, hierarchy[, maxLevel[, offset]]]]])

パラメータの説明:

  • image: 輪郭を描画する画像。
  • contours: 輪郭リスト。
  • contourIdx: 描画する輪郭のインデックス。負の場合はすべての輪郭を描画します。
  • color: 輪郭の色。
  • thickness: 輪郭線の太さ。負の場合は輪郭の内部を塗りつぶします。
  • lineType: 線種。
  • hierarchy: 輪郭の階層構造情報。
  • maxLevel: 描画する最大階層深度。
  • offset: 輪郭点のオフセット。

戻り値:
戻り値はありません。入力画像に直接輪郭を描画します。

サンプル

# 空白の画像を作成する
output = np.zeros_like(image)
# すべての輪郭を描画する
cv2.drawContours(output, contours, -1, (255, 0, 0), 2)
cv2.imshow('Contours', output)
cv2.waitKey(0)

3. cv2.contourArea()

機能説明:
この関数は、輪郭の面積を計算するために使用されます。

関数定義: 

area = cv2.contourArea(contour[, oriented])

パラメータの説明:

  • contour: 入力の輪郭点セット。
  • oriented: オプションのパラメータ。True の場合、符号付きの面積を返します。

戻り値:
輪郭の面積。

サンプル

for contour in contours:
    area = cv2.contourArea(contour)
    print(f"Contour area: {area}")

4. cv2.arcLength()

機能説明:
この関数は、輪郭の周長または弧長を計算するために使用されます。

関数定義: 

length = cv2.arcLength(curve, closed)

パラメータの説明:

  • curve: 入力の輪郭点セット。
  • closed: 輪郭が閉じているかどうかを示すブール値。

戻り値:
輪郭の周長または弧長。

サンプル

for contour in contours:
    perimeter = cv2.arcLength(contour, True)
    print(f"Contour perimeter: {perimeter}")

5. cv2.boundingRect()

機能説明:
この関数は、輪郭の境界矩形を計算するために使用されます。

関数定義: 

x, y, w, h = cv2.boundingRect(points)

パラメータの説明:

  • points: 入力の輪郭点セット。

戻り値:
境界矩形の左上隅の座標(x, y)と幅w、高さh。

サンプル

for contour in contours:
    x, y, w, h = cv2.boundingRect(contour)
    cv2.rectangle(image, (x, y), (x + w, y + h), (0, 255, 0), 2)
cv2.imshow('Bounding Rectangles', image)
cv2.waitKey(0)

6. cv2.minAreaRect()

機能説明:
この関数は、輪郭の最小外接矩形（回転矩形）を計算するために使用されます。

関数定義: 

rect = cv2.minAreaRect(points)

パラメータの説明:

  • points: 入力の輪郭点セット。

戻り値:
回転矩形を返します。中心点(x, y)、幅、高さ、回転角度を含みます。

サンプル

for contour in contours:
    rect = cv2.minAreaRect(contour)
    box = cv2.boxPoints(rect)
    box = np.int0(box)
    cv2.drawContours(image, [box], 0, (0, 0, 255), 2)
cv2.imshow('Min Area Rectangles', image)
cv2.waitKey(0)

7. cv2.minEnclosingCircle()

機能説明:
この関数は、輪郭の最小外接円を計算するために使用されます。

関数定義: 

(center, radius) = cv2.minEnclosingCircle(points)

パラメータの説明:

  • points: 入力の輪郭点セット。

戻り値:
円の中心(x, y)と半径を返します。radius。

サンプル

for contour in contours:
    (x, y), radius = cv2.minEnclosingCircle(contour)
    center = (int(x), int(y))
    radius = int(radius)
    cv2.circle(image, center, radius, (255, 0, 0), 2)
cv2.imshow('Min Enclosing Circles', image)
cv2.waitKey(0)

8. cv2.approxPolyDP()

機能説明:
この関数は、輪郭を多角形近似するために使用されます。

関数定義: 

approx = cv2.approxPolyDP(curve, epsilon, closed)

パラメータの説明:

  • curve: 入力の輪郭点セット。
  • epsilon: 近似精度。値が小さいほど、近似が正確になります。
  • closed: 輪郭が閉じているかどうかを示すブール値。

戻り値:
近似後の多角形の点セットを返します。

サンプル

for contour in contours:
    epsilon = 0.01 * cv2.arcLength(contour, True)
    approx = cv2.approxPolyDP(contour, epsilon, True)
    cv2.drawContours(image, [approx], 0, (0, 255, 0), 2)
cv2.imshow('Approx Polygons', image)
cv2.waitKey(0)

輪郭検出の応用

  • 物体認識: 輪郭検出により、画像内の物体を認識できます。例えば、円形や矩形などの検出。
  • 形状分析: 輪郭の特徴（面積、周長、境界矩形など）を計算することで、物体の形状を分析できます。
  • 対象追跡: 動画内で、輪郭検出により移動する対象を追跡できます。
  • 画像分割: 輪郭検出により、画像内の物体を分割することができます。

OpenCV は強力な輪郭検出機能を提供しており、画像内の物体の境界を抽出し、輪郭の特徴を計算することができます。

以下は、輪郭検出の主な手順と関数です：

手順関数説明
画像の前処理cv2.cvtColor()画像をグレースケールに変換します。
二値化処理cv2.threshold()グレースケール画像を二値画像に変換します。
輪郭を検出するcv2.findContours()画像内の輪郭を検出する
輪郭を描画するcv2.drawContours()検出された輪郭を描画する
輪郭の面積を計算するcv2.contourArea()輪郭の面積を計算します。
輪郭の周長を計算するcv2.arcLength()輪郭の周長を計算します。
境界矩形を計算するcv2.boundingRect()輪郭の境界矩形を計算します。
最小外接矩形を計算するcv2.minAreaRect()輪郭の最小外接矩形を計算します。
最小外接円を計算するcv2.minEnclosingCircle()輪郭の最小外接円を計算します。
多角形近似cv2.approxPolyDP()輪郭を多角形近似します。

以下は、完全な輪郭検出のサンプルコードです：

サンプル

import cv2

# 画像を読み込む
image = cv2.imread("path/to/image")

# グレースケールに変換する
gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)

# 二値化処理
ret, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)

# 輪郭を検出する
contours, hierarchy = cv2.findContours(binary, cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE)

# 輪郭を描画する
cv2.drawContours(image, contours, -1, (0, 255, 0), 2)

# 結果を表示する
cv2.imshow("Contours", image)
cv2.waitKey(0)
cv2.destroyAllWindows()
