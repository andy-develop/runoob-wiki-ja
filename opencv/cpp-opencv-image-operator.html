C++ OpenCV 画像処理

画像フィルタリング

画像フィルタリングは画像処理における基本的な操作の一つで、主に画像のノイズを除去したり、画像の特定の特徴を強調したりするために使用されます。一般的なフィルタリング方法には、平均値フィルタ、ガウシアンフィルタ、メディアンフィルタ、カスタムフィルタなどがあります。

平均値フィルタ

平均値フィルタは単純な線形フィルタリング手法で、画像の各ピクセルの値をその近傍の全ピクセルの平均値に置き換えます。この方法はノイズを効果的に除去できますが、画像がぼやけるという欠点もあります。

cv::Mat src = cv::imread("image.jpg", cv::IMREAD_GRAYSCALE);
cv::Mat dst;
cv::blur(src, dst, cv::Size(3, 3));  // 3x3的均值滤波

ガウシアンフィルタ

ガウシアンフィルタは非線形フィルタリング手法で、ガウス関数を用いて近傍ピクセルの重みを計算し、画像を平滑化します。ガウシアンフィルタはノイズを除去しながら、画像のエッジ情報をよりよく保持できます。

cv::GaussianBlur(src, dst, cv::Size(5, 5), 0);  // 5x5的高斯滤波

メディアンフィルタ

メディアンフィルタは非線形フィルタリング手法で、画像の各ピクセルの値をその近傍の全ピクセルの中央値に置き換えます。この方法は、ごま塩ノイズ（インパルスノイズ）の除去に非常に効果的です。

cv::medianBlur(src, dst, 5);  // 5x5的中值滤波

カスタムフィルタ

OpenCVではユーザーがフィルタカーネルをカスタマイズでき、cv::filter2D関数を使用してカスタムフィルタリング操作を実現できます。

cv::Mat kernel = (cv::Mat_<float>(3, 3) << 1, 0, -1, 0, 0, 0, -1, 0, 1);
cv::filter2D(src, dst, -1, kernel);

画像エッジ検出

エッジ検出は画像処理における重要なタスクであり、画像内の物体の境界を識別するために使用されます。一般的なエッジ検出方法には、SobelオペレータとCannyエッジ検出があります。

Sobelオペレータ

Sobelオペレータは勾配に基づくエッジ検出方法で、画像内の水平エッジと垂直エッジを検出できます。

cv::Mat grad_x, grad_y;
cv::Sobel(src, grad_x, CV_16S, 1, 0);  // 水平方向
cv::Sobel(src, grad_y, CV_16S, 0, 1);  // 垂直方向
cv::convertScaleAbs(grad_x, grad_x);
cv::convertScaleAbs(grad_y, grad_y);
cv::addWeighted(grad_x, 0.5, grad_y, 0.5, 0, dst);  // 合并结果

Canny エッジ検出

Cannyエッジ検出は多段階のエッジ検出アルゴリズムで、画像内のエッジを効果的に検出でき、ノイズに対して高いロバスト性を持ちます。

cv::Canny(src, dst, 100, 200);  // 阈值1=100，阈值2=200

画像モルフォロジー操作

モルフォロジー操作は画像の形状に基づく一連の操作で、画像の前景と背景の分離、ノイズ除去などのタスクによく使用されます。一般的なモルフォロジー操作には、収縮、膨張、オープニング、クロージング、モルフォロジー勾配があります。

収縮

収縮操作は画像内の小さな物体や詳細を除去し、前景オブジェクトを小さくします。

cv::Mat kernel = cv::getStructuringElement(cv::MORPH_RECT, cv::Size(3, 3));
cv::erode(src, dst, kernel);

膨張

膨張操作は画像内の前景オブジェクトを拡大し、前景オブジェクトの穴を埋めるためによく使用されます。

cv::dilate(src, dst, kernel);

オープニング

オープニングは収縮を行ってから膨張を行う操作で、小さな物体やノイズの除去によく使用されます。

cv::morphologyEx(src, dst, cv::MORPH_OPEN, kernel);

クロージング

クロージングは膨張を行ってから収縮を行う操作で、前景オブジェクトの小さな穴を埋めるためによく使用されます。

cv::morphologyEx(src, dst, cv::MORPH_CLOSE, kernel);

モルフォロジー勾配

モルフォロジー勾配は膨張と収縮の差分であり、物体のエッジを抽出するために使用できます。

cv::morphologyEx(src, dst, cv::MORPH_GRADIENT, kernel);

画像閾値処理

画像閾値処理は画像を二値画像に変換するプロセスで、画像分割によく使用されます。一般的な閾値処理方法には、二値化、適応的閾値、大津の閾値法があります。

二値化

二値化は、設定された閾値に基づいて画像のピクセル値を2つのクラスに分類するもので、通常は単純な画像分割に使用されます。

cv::threshold(src, dst, 127, 255, cv::THRESH_BINARY);

適応的閾値処理

適応的閾値は画像の局所領域に基づいて動的に閾値を計算するため、照明が不均一な画像に適しています。

cv::adaptiveThreshold(src, dst, 255, cv::ADAPTIVE_THRESH_MEAN_C, cv::THRESH_BINARY, 11, 2);

大津の閾値法

大津の閾値法は閾値を自動的に決定する方法で、二峰性ヒストグラムを持つ画像に適しています。

cv::threshold(src, dst, 0, 255, cv::THRESH_BINARY | cv::THRESH_OTSU);

画像ヒストグラム

ヒストグラムは、画像処理において画像の輝度分布を解析するためのツールです。一般的なヒストグラム操作には、ヒストグラムの計算、ヒストグラム均等化、ヒストグラム比較があります。

ヒストグラムの計算

ヒストグラムは画像内のピクセル値の分布を反映します。

cv::Mat hist;
int histSize = 256;
float range[] = {0, 256};
const float* histRange = {range};
cv::calcHist(&src, 1, 0, cv::Mat(), hist, 1, &histSize, &histRange);

ヒストグラム均等化

ヒストグラム均等化は画像のコントラストを向上させ、輝度分布をより均一にします。

cv::equalizeHist(src, dst);

ヒストグラム比較

ヒストグラム比較は、2つの画像の類似性を比較するために使用できます。

double compare = cv::compareHist(hist1, hist2, cv::HISTCMP_CORREL);

例

OpenCVにおける一般的な画像処理操作には、フィルタリング、エッジ検出、閾値処理、モルフォロジー操作、輪郭検出などがあります。これらの技術を使用することで、より複雑な画像処理タスクを実現できます。

以下は、C++ OpenCVにおける一般的な画像処理操作とそのコード例です：

1. 画像フィルタリング

画像フィルタリングは、ノイズの除去や画像特徴の強調に使用されます。

1.1 平均値フィルタ

例

#include <opencv2/opencv.hpp>
#include <iostream>

using namespace cv;
using namespace std;

int main() {
    Mat image = imread("test.jpg");
    if (image.empty()) {
        cout << "エラー：画像を読み込めませんでした。パスが正しいか確認してください。" << endl;
        return -1;
    }

    // 平均値フィルタ
    Mat blurredImage;
    blur(image, blurredImage, Size(5, 5)); // 5x5 のカーネル

    imshow("Original Image", image);
    imshow("Blurred Image", blurredImage);
    waitKey(0);
    destroyAllWindows();

    return 0;
}

2. エッジ検出

エッジ検出は、画像内のエッジ情報を抽出するために使用されます。

2.1 Canny エッジ検出

例

#include <opencv2/opencv.hpp>
#include <iostream>

using namespace cv;
using namespace std;

int main() {
    Mat image = imread("test.jpg");
    if (image.empty()) {
        cout << "エラー：画像を読み込めませんでした。パスが正しいか確認してください。" << endl;
        return -1;
    }

    // グレースケール画像に変換
    Mat grayImage;
    cvtColor(image, grayImage, COLOR_BGR2GRAY);

    // Canny エッジ検出
    Mat edges;
    Canny(grayImage, edges, 100, 200); // 閾値1と閾値2

    imshow("Original Image", image);
    imshow("Canny Edges", edges);
    waitKey(0);
    destroyAllWindows();

    return 0;
}

3. 画像閾値処理

閾値処理は、画像を二値画像に変換するために使用されます。

3.1 単純な閾値処理

例

#include <opencv2/opencv.hpp>
#include <iostream>

using namespace cv;
using namespace std;

int main() {
    Mat image = imread("test.jpg");
    if (image.empty()) {
        cout << "エラー：画像を読み込めませんでした。パスが正しいか確認してください。" << endl;
        return -1;
    }

    // グレースケール画像に変換
    Mat grayImage;
    cvtColor(image, grayImage, COLOR_BGR2GRAY);

    // 単純な閾値処理
    Mat binaryImage;
    threshold(grayImage, binaryImage, 127, 255, THRESH_BINARY);

    imshow("Original Image", image);
    imshow("Binary Image", binaryImage);
    waitKey(0);
    destroyAllWindows();

    return 0;
}

3.2 適応的閾値処理

4. モルフォロジー操作

モルフォロジー操作は、画像の形状と構造を処理するために使用されます。

4.1 収縮と膨張

例

#include <opencv2/opencv.hpp>
#include <iostream>

using namespace cv;
using namespace std;

int main() {
    Mat image = imread("test.jpg");
    if (image.empty()) {
        cout << "エラー：画像を読み込めませんでした。パスが正しいか確認してください。" << endl;
        return -1;
    }

    // グレースケール画像に変換
    Mat grayImage;
    cvtColor(image, grayImage, COLOR_BGR2GRAY);

    // 二値化
    Mat binaryImage;
    threshold(grayImage, binaryImage, 127, 255, THRESH_BINARY);

    // 収縮操作
    Mat erodedImage;
    Mat kernel = getStructuringElement(MORPH_RECT, Size(5, 5));
    erode(binaryImage, erodedImage, kernel);

    // 膨張操作
    Mat dilatedImage;
    dilate(binaryImage, dilatedImage, kernel);

    imshow("Original Image", image);
    imshow("Eroded Image", erodedImage);
    imshow("Dilated Image", dilatedImage);
    waitKey(0);
    destroyAllWindows();

    return 0;
}

5. 輪郭検出

輪郭検出は、画像内のオブジェクトの輪郭を抽出するために使用されます。

例


#include <opencv2/opencv.hpp>
#include <iostream>

using namespace cv;
using namespace std;

int main() {
    Mat image = imread("test.jpg");
    if (image.empty()) {
        cout << "エラー：画像を読み込めませんでした。パスが正しいか確認してください。" << endl;
        return -1;
    }

    // グレースケール画像に変換
    Mat grayImage;
    cvtColor(image, grayImage, COLOR_BGR2GRAY);

    // 二値化
    Mat binaryImage;
    threshold(grayImage, binaryImage, 127, 255, THRESH_BINARY);

    // 輪郭の検出
    vector<vector<Point>> contours;
    vector<Vec4i> hierarchy;
    findContours(binaryImage, contours, hierarchy, RETR_TREE, CHAIN_APPROX_SIMPLE);

    // 輪郭の描画
    Mat contourImage = Mat::zeros(image.size(), CV_8UC3);
    for (size_t i = 0; i < contours.size(); i++) {
        drawContours(contourImage, contours, i, Scalar(0, 255, 0), 2);
    }

    imshow("Original Image", image);
    imshow("Contours", contourImage);
    waitKey(0);
    destroyAllWindows();

    return 0;
}
