OpenCV 画像算術演算

画像処理において、算術演算とビット演算は非常に基礎的で重要な操作です。

この記事では、OpenCVを使用して画像の加算、減算、乗算、除算、ビット演算、および画像ブレンド操作を実行する方法を詳しく紹介します。

1、基礎演算

画像加算

画像加算は、2つの画像の対応するピクセル値を加算して、新しい画像を生成します。

OpenCVでは、cv2.add()関数を使用して画像加算を実行できます。

例

import cv2
import numpy as np

# 2つの画像を読み込む
img1 = cv2.imread('image1.jpg')
img2 = cv2.imread('image2.jpg')

# 画像加算
result = cv2.add(img1, img2)

# 結果を表示
cv2.imshow('Result', result)
cv2.waitKey(0)
cv2.destroyAllWindows()

注意：ピクセル値の加算結果が255を超える場合、OpenCVは自動的に255に切り詰めます。

画像減算

画像減算は、2つの画像の対応するピクセル値を減算して、新しい画像を生成します。

OpenCVでは、cv2.subtract()関数を使用して画像減算を実行できます。

例

# 画像減算
result = cv2.subtract(img1, img2)

# 結果を表示
cv2.imshow('Result', result)
cv2.waitKey(0)
cv2.destroyAllWindows()

注意：ピクセル値の減算結果が0未満の場合、OpenCVは自動的に0に切り詰めます。

画像乗算

画像乗算は、2つの画像の対応するピクセル値を乗算して、新しい画像を生成します。

OpenCVでは、cv2.multiply()関数を使用して画像乗算を実行できます。

例

# 画像乗算
result = cv2.multiply(img1, img2)

# 結果を表示
cv2.imshow('Result', result)
cv2.waitKey(0)
cv2.destroyAllWindows()

注意：ピクセル値の乗算結果が255を超える場合、OpenCVは自動的に255に切り詰めます。

画像除算

画像除算は、2つの画像の対応するピクセル値を除算して、新しい画像を生成します。OpenCVでは、cv2.divide()関数を使用して画像除算を実行できます。

例

# 画像除算
result = cv2.divide(img1, img2)

# 結果を表示
cv2.imshow('Result', result)
cv2.waitKey(0)
cv2.destroyAllWindows()

注意：除数が0の場合、OpenCVは自動的に結果を0に設定します。

2、画像ビット演算 (AND, OR, NOT, XOR)

ビット演算は、画像の各ピクセルに対して2進数のビット単位操作を行います。

OpenCVは、cv2.bitwise_and()、cv2.bitwise_or()、cv2.bitwise_not() 和 cv2.bitwise_xor()関数を提供して、画像のビット演算を実現します。

関数機能適用シーン
cv2.bitwise_and()ビット単位AND演算マスク操作、画像分割
cv2.bitwise_or()ビット単位OR演算画像オーバーレイ
cv2.bitwise_not()ビット単位NOT演算画像の色反転
cv2.bitwise_xor()ビット単位XOR演算画像の差分検出

ビットAND演算 (AND)

ビットAND演算は、2つの画像の各ピクセルに対してビット単位のAND演算を行います。

例

# ビットAND演算
result = cv2.bitwise_and(img1, img2)

# 結果を表示
cv2.imshow('Result', result)
cv2.waitKey(0)
cv2.destroyAllWindows()

ビットOR演算 (OR)

ビットOR演算は、2つの画像の各ピクセルに対してビット単位のOR演算を行います。

例

# ビットOR演算
result = cv2.bitwise_or(img1, img2)

# 結果を表示
cv2.imshow('Result', result)
cv2.waitKey(0)
cv2.destroyAllWindows()

ビットNOT演算 (NOT)

ビットNOT演算は、画像の各ピクセルに対してビット単位の否定演算を行います。

例

# ビットNOT演算
result = cv2.bitwise_not(img1)

# 結果を表示
cv2.imshow('Result', result)
cv2.waitKey(0)
cv2.destroyAllWindows()

ビットXOR演算 (XOR)

ビットXOR演算は、2つの画像の各ピクセルに対してビット単位のXOR演算を行います。

例

# ビットXOR演算
result = cv2.bitwise_xor(img1, img2)

# 結果を表示
cv2.imshow('Result', result)
cv2.waitKey(0)
cv2.destroyAllWindows()

3、画像ブレンド (cv2.addWeighted())

画像ブレンドは、2つの画像を特定の重みに従って線形結合し、新しい画像を生成します。

OpenCVでは、cv2.addWeighted()関数を使用して画像ブレンドを実行できます。

例

# 画像ブレンド
alpha = 0.7  # 1つ目の画像の重み
beta = 0.3   # 2つ目の画像の重み
gamma = 0    # オプションのスカラー値

result = cv2.addWeighted(img1, alpha, img2, beta, gamma)

# 結果を表示
cv2.imshow('Result', result)
cv2.waitKey(0)
cv2.destroyAllWindows()

パラメータの説明：

  • alpha：1つ目の画像の重み。
  • beta：2つ目の画像の重み。
  • gamma：オプションのスカラー値。通常は0に設定します。

数式：

result = img1 * alpha + img2 * beta + gamma
