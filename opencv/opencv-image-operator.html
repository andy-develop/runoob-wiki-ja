OpenCV 画像の基本操作

この記事では、画像の4つの基本操作について詳しく説明します。画素値へのアクセスと変更、画像ROI（Region of Interest）操作、画像チャンネルの分離と結合、そして画像の拡大縮小、回転、平行移動、反転です。

よく使うメソッド：

操作関数/メソッド説明
画素値へのアクセスimage[y, x]画素値を取得または変更します。
画像ROIimage[y1:y2, x1:x2]画像内の矩形領域を取得または変更します。
チャンネルの分離と結合cv2.split() / cv2.merge()画像チャンネルを分離または結合します。
画像の拡大縮小cv2.resize()画像のサイズを調整します。
画像の回転cv2.getRotationMatrix2D()画像を回転します。
画像の平行移動cv2.warpAffine()画像を平行移動します。
画像の反転cv2.flip()画像を反転します。
画像の加算cv2.add()2つの画像に対して加算演算を行います。
画像の減算cv2.subtract()2つの画像に対して減算演算を行います。
画像のブレンドcv2.addWeighted()2つの画像に対して重み付き混合を行います。
閾値処理cv2.threshold()画像に対して閾値処理を行います。
平滑化処理cv2.blur() / cv2.GaussianBlur()画像に対して平滑化処理を行います。

1. 画素値へのアクセスと変更

画像は画素で構成される行列であり、各画素は色またはグレースケールを表す1つ以上の値を持ちます。グレースケール画像では、各画素はグレースケール強度を表す1つの値のみを持ちます。カラー画像では、各画素は通常、赤、緑、青（RGB）チャンネルの強度を表す3つの値を持ちます。

画素値へのアクセス

Pythonでは、OpenCVライブラリを使用して画像の画素値にアクセスできます。グレースケール画像があると仮定しますimg。次に、img[y, x]を使用して(x, y)にある位置の画素値にアクセスできます。カラー画像の場合は、img[y, x, c]を使用して特定のチャンネルcの画素値にアクセスできます。ここで、cは0（青）、1（緑）、または2（赤）です。

例

import cv2

# 画像を読み込む
img = cv2.imread('image.jpg')

# 画素値にアクセスする
pixel_value = img[100, 150]  # (150, 100) 位置の画素値にアクセスする
print(pixel_value)

画素値の変更

画素値の変更も同様に簡単で、新しい値を対応する画素位置に代入するだけです。

例

# 画素値を変更する
img[100, 150] = [255, 255, 255]  # (150, 100) 位置の画素値を白に設定する

2. 画像ROI（Region of Interest）操作

ROIとは、画像の中で私たちが関心を持つ領域のことです。ROIを抽出することで、画像の特定の部分だけを処理でき、処理効率を向上させることができます。

ROIの抽出

OpenCVでは、スライス操作を使用してROIを抽出できます。画像の左上隅にある100x100画素の領域を抽出したいと仮定します：

例

# ROIを抽出する
roi = img[0:100, 0:100]

ROIの変更

ROIを抽出した後、それを変更し、変更後のROIを元の画像に戻すことができます。

例

# ROIを変更する
roi[:, :] = [0, 255, 0]  # ROI領域を緑色に設定する

# 変更後のROIを元の画像に戻す
img[0:100, 0:100] = roi

3. 画像チャンネルの分離と結合

カラー画像は通常、RGB画像の3つのチャンネルのように、複数のチャンネルで構成されています。これらのチャンネルを分離して個別に処理し、その後、元の画像に結合する必要がある場合があります。

チャンネル分離

OpenCVでは、cv2.split()関数を使用して画像のチャンネルを分離できます。

例

# チャンネルを分離する
b, g, r = cv2.split(img)

チャンネル結合

分離したチャンネルは、cv2.merge()関数を使用して元の画像に結合できます。

例

# チャンネルを結合する
merged_img = cv2.merge([b, g, r])

4. 画像の拡大縮小、回転、平行移動、反転

画像の幾何学的変換は、画像処理でよく行われる操作であり、拡大縮小、回転、平行移動、反転が含まれます。

画像の拡大縮小

画像の拡大縮小は、cv2.resize()関数を使用して実現できます。拡大縮小後の画像サイズまたは拡大縮小率を指定できます。

例

# 画像を拡大縮小する
resized_img = cv2.resize(img, (200, 200))  # 画像を200x200画素に拡大縮小する

画像の回転

画像の回転は、cv2.getRotationMatrix2D() 和 cv2.warpAffine()関数を使用して実現できます。回転中心と回転角度を指定する必要があります。

例

# 画像を回転する
(h, w) = img.shape[:2]
center = (w // 2, h // 2)
M = cv2.getRotationMatrix2D(center, 45, 1.0)  # 45度回転する
rotated_img = cv2.warpAffine(img, M, (w, h))

画像の平行移動

画像の平行移動は、cv2.warpAffine()関数を使用して実現できます。平行移動行列を指定する必要があります。

例

# 画像を平行移動する
M = np.float32([[1, 0, 100], [0, 1, 50]])  # 右に100画素、下に50画素平行移動する
translated_img = cv2.warpAffine(img, M, (w, h))

画像の反転

画像の反転は、cv2.flip()関数を使用して実現できます。反転方向（水平、垂直、またはその両方）を指定できます。

例

# 画像を反転する
flipped_img = cv2.flip(img, 1)  # 水平反転する
