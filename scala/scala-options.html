Scala Option（オプション）

Scala コレクション

Scala Option（オプション）型は、値がオプション（値があるか無いか）であることを表すために使われます。

Option[T] は、型 T のオプションの値を保持するコンテナです。値が存在する場合、Option[T] は Some[T] になり、存在しない場合、Option[T] はオブジェクト None になります。

次に、コードを見てみましょう。

// Scala では変数の型を定義しなくてもよいですが、明確にするために、私は
// それを明示的に定義しています。
 
val myMap: Map[String, String] = Map("key1" -> "value")
val value1: Option[String] = myMap.get("key1")
val value2: Option[String] = myMap.get("key2")
 
println(value1) // Some("value1")
println(value2) // None

上記のコードでは、myMap はキーの型が String、値の型が String のハッシュマップですが、異なる点は、その get() が Option[String] という型を返すことです。

Scala は Option[String] を使って、「String を返す方法を考えるが、String を渡せない可能性もある」ことを伝えます。

myMap には key2 というデータが存在しないため、get() メソッドは None を返します。

Option には2つのサブタイプがあります。1つは Some、もう1つは None です。Some が返されたときは、この関数が String を正常に渡したことを意味し、get() 関数を使ってその String を取得できます。None が返された場合は、渡せる文字列がないことを意味します。

別の例：

例

object Test {
   def main(args: Array[String]) {
      val sites = Map("サンプル" -> "www.example.com", "google" -> "www.google.com")
     
      println("sites.get( \"サンプル\" ) : " +  sites.get( "サンプル" )) // Some(www.example.com)
      println("sites.get( \"baidu\" ) : " +  sites.get( "baidu" ))  //  None
   }
}

上記のコードを実行すると、出力結果は次のようになります：

$ scalac Test.scala 
$ scala Test
sites.get( "サンプル" ) : Some(www.example.com)
sites.get( "baidu" ) : None

パターンマッチングを使用して、一致する値を出力することもできます。例は次のとおりです：

例

object Test {
   def main(args: Array[String]) {
      val sites = Map("サンプル" -> "www.example.com", "google" -> "www.google.com")
     
      println("show(sites.get( \"サンプル\")) : " +  
                                          show(sites.get( "サンプル")) )
      println("show(sites.get( \"baidu\")) : " +  
                                          show(sites.get( "baidu")) )
   }
   
   def show(x: Option[String]) = x match {
      case Some(s) => s
      case None => "?"
   }
}

上記のコードを実行すると、出力結果は次のようになります：

$ scalac Test.scala 
$ scala Test
show(sites.get( "サンプル")) : www.example.com
show(sites.get( "baidu")) : ?

getOrElse() メソッド

getOrElse() メソッドを使用して、タプル内に存在する要素を取得するか、デフォルト値を使用することができます。例は次のとおりです：

例

object Test {
   def main(args: Array[String]) {
      val a:Option[Int] = Some(5)
      val b:Option[Int] = None
     
      println("a.getOrElse(0): " + a.getOrElse(0) )
      println("b.getOrElse(10): " + b.getOrElse(10) )
   }
}

上記のコードを実行すると、出力結果は次のようになります：

$ scalac Test.scala 
$ scala Test
a.getOrElse(0): 5
b.getOrElse(10): 10

isEmpty() メソッド

isEmpty() メソッドを使用して、タプル内の要素が None であるかどうかを検出できます。例は次のとおりです：

例

object Test {
   def main(args: Array[String]) {
      val a:Option[Int] = Some(5)
      val b:Option[Int] = None
     
      println("a.isEmpty: " + a.isEmpty )
      println("b.isEmpty: " + b.isEmpty )
   }
}

上記のコードを実行すると、出力結果は次のようになります：

$ scalac Test.scala 
$ scala Test
a.isEmpty: false
b.isEmpty: true

Scala Option のよく使うメソッド

次の表に、Scala Option の一般的なメソッドを示します：

番号 メソッドと説明
1

def get: A

オプションの値を取得する
2

def isEmpty: Boolean

オプション型の値が None かどうかを検出し、None の場合は true を返し、それ以外の場合は false を返します。
3

def productArity: Int

要素の数を返します。A(x_1, ..., x_k) の場合は k を返します。
4

def productElement(n: Int): Any

指定されたオプション要素を取得します。0 から始まります。つまり、A(x_1, ..., x_k) の場合は x_(n+1) を返します。0 < n < k です。
5

def exists(p: (A) => Boolean): Boolean

オプションに指定された条件を満たす要素が存在し、None でない場合は true を返し、それ以外の場合は false を返します。
6

def filter(p: (A) => Boolean): Option[A]

オプションが値を持ち、かつ filter に渡された条件関数が true を返す場合、filter は Some インスタンスを返します。それ以外の場合、戻り値は None です。
7

def filterNot(p: (A) => Boolean): Option[A]

オプションが値を持ち、かつ filter に渡された条件関数が false を返す場合、filter は Some インスタンスを返します。それ以外の場合、戻り値は None です。
8

def flatMap[B](f: (A) => Option[B]): Option[B]

オプションが値を持つ場合、関数 f に渡して処理した結果を返し、それ以外の場合は None を返します。
9

def foreach[U](f: (A) => U): Unit

オプションが値を持つ場合、各値を関数 f に渡します。それ以外の場合は何も処理しません。
10

def getOrElse[B >: A](default: => B): B

オプションが値を持つ場合は値を返し、それ以外の場合は設定されたデフォルト値を返します。
11

def isDefined: Boolean

オプション値が Some のインスタンスである場合は true を返し、それ以外の場合は false を返します。
12

def iterator: Iterator[A]

オプションが値を持つ場合、オプション値を反復処理します。オプション値が空の場合は空のイテレータを返します。
13

def map[B](f: (A) => B): Option[B]

オプションが値を持つ場合、関数 f で処理された Some を返し、それ以外の場合は None を返します。
14

def orElse[B >: A](alternative: => Option[B]): Option[B]

Option が None の場合、orElse メソッドは名前渡しパラメータの値を返します。それ以外の場合は、この Option をそのまま返します。
15

def orNull

オプションが値を持つ場合は値を返し、それ以外の場合は null を返します。
