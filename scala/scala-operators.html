Scala 演算子

演算子は、コンパイラに指定された数学的演算および論理的演算を実行するように指示する記号です。

Scala には豊富な組み込み演算子があり、以下の種類があります。

  • 算術演算子

  • 関係演算子

  • 論理演算子

  • ビット演算子

  • 代入演算子

次に、上記の各種演算子の応用について詳しく説明します。

算術演算子

次の表は、Scala がサポートする算術演算子を示しています。

変数 A が 10、B が 20 であると仮定します：

演算子 説明 例
+ 加算 A + B の演算結果は 30
- 減算 A - B の演算結果は -10
* 乗算 A * B の演算結果は 200
/ 除算 B / A の演算結果は 2
% 剰余 B % A の演算結果は 0

例

例

object Test {
   def main(args: Array[String]) = {
      var a = 10;
      var b = 20;
      var c = 25;
      var d = 25;
      println("a + b = " + (a + b) );
      println("a - b = " + (a - b) );
      println("a * b = " + (a * b) );
      println("b / a = " + (b / a) );
      println("b % a = " + (b % a) );
      println("c % a = " + (c % a) );
     
   }
}

ビット演算子

ビット演算子はバイナリビットに対して演算を行うために使用され、~,&,|,^それぞれ否定（NOT）、ビットごとのAND、ビットごとのOR、ビットごとのXOR演算であり、次の表の例のとおりです：

p q p & q p | q p ^ q
0 0 0 0 0
0 1 0 1 1
1 1 1 1 0
1 0 0 1 1

A = 60; および B = 13; と指定した場合、2つの変数に対応するバイナリは次のとおりです：

A = 0011 1100

B = 0000 1101

-------位运算----------

A&B = 0000 1100

A|B = 0011 1101

A^B = 0011 0001

~A  = 1100 0011

Scala のビット演算の規則は次のとおりです：

演算子説明例
&ビットごとのAND演算子(a & b) の出力結果は 12、バイナリ解釈： 0000 1100
|ビットごとのOR演算子(a | b) の出力結果は 61、バイナリ解釈： 0011 1101
^ビットごとのXOR演算子(a ^ b) の出力結果は 49、バイナリ解釈： 0011 0001
~ビットごとの否定演算子(~a ) の出力結果は -61、バイナリ解釈： 1100 0011、符号付きバイナリ数の2の補数形式です。
<<左シフト演算子a << 2 の出力結果は 240、バイナリ解釈： 1111 0000
>>右シフト演算子a >> 2 の出力結果は 15、バイナリ解釈： 0000 1111
>>> 符号なし右シフト A >>>2 の出力結果は 15、バイナリ解釈: 0000 1111

例

例

object Test {
   def main(args: Array[String]) = {
      var a = 60;           /* 60 = 0011 1100 */  
      var b = 13;           /* 13 = 0000 1101 */
      var c = 0;

      c = a & b;            /* 12 = 0000 1100 */
      println("a & b = " + c );

      c = a | b;            /* 61 = 0011 1101 */
      println("a | b = " + c );

      c = a ^ b;            /* 49 = 0011 0001 */
      println("a ^ b = " + c );

      c = ~a;               /* -61 = 1100 0011 */
      println("~a = " + c );

      c = a << 2;           /* 240 = 1111 0000 */
      println("a << 2 = " + c );

      c = a >> 2;           /* 15 = 1111 */
      println("a >> 2  = " + c );

      c = a >>> 2;          /* 15 = 0000 1111 */
      println("a >>> 2 = " + c );
   }
}

上記のコードを実行すると、出力結果は次のようになります：

$ scalac Test.scala 
$ scala Test
a & b = 12
a | b = 61
a ^ b = 49
~a = -61
a << 2 = 240
a >> 2  = 15
a >>> 2 = 15

代入演算子

以下は、Scala 言語がサポートする代入演算子です:

演算子 説明 例
= 単純な代入演算で、右辺のオペランドを左辺のオペランドに代入します。 C = A + B は、A + B の演算結果を C に代入します。
+= 加算してから代入します。左右のオペランドを加算した後、その結果を左辺のオペランドに代入します。 C += A は C = C + A と同じです。
-= 減算してから代入します。左右のオペランドを減算した後、その結果を左辺のオペランドに代入します。 C -= A は C = C - A と同じです。
*= 乗算してから代入します。左右のオペランドを乗算した後、その結果を左辺のオペランドに代入します。 C *= A は C = C * A と同じです。
/= 除算してから代入します。左右のオペランドを除算した後、その結果を左辺のオペランドに代入します。 C /= A は C = C / A と同じです。
%= 剰余を求めてから代入します。左右のオペランドの剰余を求めた後、その結果を左辺のオペランドに代入します。 C %= A is equivalent to C = C % A
<<= ビット単位で左シフトしてから代入 C <<= 2 は C = C << 2 と同じです。
>>= ビット単位で右シフトしてから代入 C >>= 2 は C = C >> 2 と同じです。
&= ビット単位のAND演算後に代入 C &= 2 は C = C & 2 と同じです。
^= ビット単位のXOR演算後に代入 C ^= 2 は C = C ^ 2 と同じです。
|= ビット単位のOR演算後に代入 C |= 2 は C = C | 2 と同じです。

例

例

object Test {
   def main(args: Array[String]) = {
      var a = 10;      
      var b = 20;
      var c = 0;

      c = a + b;
      println("c = a + b  = " + c );

      c += a ;
      println("c += a  = " + c );

      c -= a ;
      println("c -= a = " + c );

      c *= a ;
      println("c *= a = " + c );

      a = 10;
      c = 15;
      c /= a ;
      println("c /= a  = " + c );

      a = 10;
      c = 15;
      c %= a ;
      println("c %= a  = " + c );

      c <<= 2 ;
      println("c <<= 2  = " + c );

      c >>= 2 ;
      println("c >>= 2  = " + c );

      c >>= a ;
      println("c >>= a  = " + c );

      c &= a ;
      println("c &= 2  = " + c );
     
      c ^= a ;
      println("c ^= a  = " + c );

      c |= a ;
      println("c |= a  = " + c );
   }
}

上記のコードを実行すると、出力結果は次のようになります：

$ scalac Test.scala 
$ scala Test
c = a + b  = 30
c += a  = 40
c -= a = 30
c *= a = 300
c /= a  = 1
c %= a  = 5
c <<= 2  = 20
c >>= 2  = 5
c >>= a  = 0
c &= 2  = 0
c ^= a  = 10
c |= a  = 10

演算子の優先順位は所属する演算子グループによって決まり、式の計算に影響を与えます。

例： x = 7 + 3 * 2; この場合、x の計算結果は 20 ではなく 13 になります。なぜなら、乗算（*）は加算（+）よりも優先順位が高いため、最初に 3*2 が計算され、それから 7 が加算されるからです。

次の表を参照してください。優先順位は上から下へ順に低くなり、最上部が最も高い優先順位を持ち、カンマ演算子が最も低い優先順位を持ちます。

4 + - 左から右
5 >> >>> << 左から右
6 > >= < <= 左から右
7 == != 左から右

10 | 左から右
