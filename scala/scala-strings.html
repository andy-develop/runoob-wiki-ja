Scala 文字列

次の例では、文字列を定数に代入します。

例

object Test {
   val greeting: String = "Hello,World!"

   def main(args: Array[String]) {
      println( greeting )
   }
}

上記の例では、変数 greeting を文字列定数として定義しています。その型は次のとおりです。String (java.lang.String)。

Scala では、文字列の型は実際には Java String であり、Scala 自体には String クラスはありません。

Scala では、String は不変オブジェクトであり、そのオブジェクトは変更できません。つまり、文字列を変更すると、新しい文字列オブジェクトが生成されることを意味します。

ただし、配列などの他のオブジェクトは可変オブジェクトです。次に、よく使われる java.lang.String メソッドを紹介します。

文字列の作成

文字列を作成する例は次のとおりです。

val greeting = "Hello World!";

或

val greeting:String = "Hello World!";

文字列に String 型を指定する必要は必ずしもありません。Scala コンパイラが文字列の型を String として自動的に推論するからです。

もちろん、次の例のように文字列を String 型として明示的に宣言することもできます。

例

object Test {
   val greeting: String = "Hello, World!"

   def main(args: Array[String]) {
      println( greeting )
   }
}

上記のコードを実行すると、出力結果は次のようになります。

$ scalac Test.scala
$ scala Test
Hello, world!

先ほど String オブジェクトは不変であると述べました。変更可能な文字列を作成する必要がある場合は、String Builder クラスを使用できます。次の例を参照してください。

例

object Test {
   def main(args: Array[String]) {
      val buf = new StringBuilder;
      buf += 'a'
      buf ++= "bcdef"
      println( "buf is : " + buf.toString );
   }
}

サンプルを実行 »

上記のコードを実行すると、出力結果は次のようになります。

$ scalac Test.scala
$ scala Test
buf is : abcdef

文字列の長さ

length() メソッドを使用して文字列の長さを取得できます。

例

object Test {
   def main(args: Array[String]) {
      var palindrome = "www.runoob.com";
      var len = palindrome.length();
      println( "String Length is : " + len );
   }
}

上記のコードを実行すると、出力結果は次のようになります。

$ scalac Test.scala
$ scala Test
String Length is : 14

文字列の連結

String クラスでは、concat() メソッドを使用して2つの文字列を連結します。

string1.concat(string2);

例によるデモ：

scala> "菜鸟教程官网： ".concat("www.runoob.com");
res0: String = 菜鸟教程官网： www.runoob.com

同様に、プラス記号(+)を使用して連結することもできます。

scala> "菜鸟教程官网： " + " www.runoob.com"
res1: String = 菜鸟教程官网：  www.runoob.com

完全な例を見てみましょう。

例

object Test {
   def main(args: Array[String]) {
      var str1 = "菜鸟教程公式サイト：";
      var str2 =  "www.runoob.com";
      var str3 =  "菜鸟教程のスローガンは：";
      var str4 =  "学ぶのは技術だけではなく、夢でもあります！";
      println( str1 + str2 );
      println( str3.concat(str4) );
   }
}

上記のコードを実行すると、出力結果は次のようになります。

$ scalac Test.scala
$ scala Test
菜鸟教程官网：www.runoob.com
菜鸟教程的 Slogan 为：学的不仅是技术，更是梦想！

フォーマット文字列の作成

String クラスでは、printf() メソッドを使用して文字列をフォーマットして出力できます。String format() メソッドは PrintStream オブジェクトではなく String オブジェクトを返します。次の例は printf() メソッドの使用法を示しています。

例

object Test {
   def main(args: Array[String]) {
      var floatVar = 12.456
      var intVar = 2000
      var stringVar = "菜鸟教程!"
      var fs = printf("浮動小数点型の変数は " +
                   "%f、整数型の変数は %d、文字列は " +
                   " %s", floatVar, intVar, stringVar)
      println(fs)
   }
}

上記のコードを実行すると、出力結果は次のようになります。

$ scalac Test.scala
$ scala Test
浮点型变量为 12.456000, 整型变量为 2000, 字符串为  菜鸟教程!()
