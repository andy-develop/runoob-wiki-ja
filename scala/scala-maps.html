Scala Map（マッピング）

Scala コレクション

Map（マッピング）は反復可能なキーと値のペア（key/value）構造です。

すべての値はキーを介して取得できます。

Map 内のキーはすべて一意です。

Map はハッシュテーブル（Hash tables）とも呼ばれます。

Map には可変と不変の2つのタイプがあります。違いは、可変オブジェクトは変更できますが、不変オブジェクトは変更できないことです。

デフォルトでは、Scala は不変 Map を使用します。可変コレクションを使用する必要がある場合は、明示的にインポートする必要があります。import scala.collection.mutable.Map 类

Scala では、可変と不変の両方の Map を使用できます。不変のものは直接 Map を使用し、可変のものは mutable.Map を使用します。以下の例では、不変 Map の適用を示します。

// 空哈希表，键为字符串，值为整型
var A:Map[Char,Int] = Map()

// Map 键值对演示
val colors = Map("red" -> "#FF0000", "azure" -> "#F0FFFF")

Map を定義するときは、キーと値のペアに型を定義する必要があります。key-value ペアを追加する必要がある場合は、+ 記号を使用できます。次のようになります。

A += ('I' -> 1)
A += ('J' -> 5)
A += ('K' -> 10)
A += ('L' -> 100)

Map の基本操作

Scala Map には3つの基本操作があります：

メソッド 説明
keys Map のすべてのキー（key）を返す
values Map のすべての値（value）を返す
isEmpty Map が空の場合に true を返す

実例

以下の例では、上記3つのメソッドの基本的な適用を示します。

実例

object Test {
   def main(args: Array[String]) {
      val colors = Map("red" -> "#FF0000",
                       "azure" -> "#F0FFFF",
                       "peru" -> "#CD853F")

      val nums: Map[Int, Int] = Map()

      println( "colors のキーは : " + colors.keys )
      println( "colors の値は : " + colors.values )
      println( "colors が空かどうかを検出 : " + colors.isEmpty )
      println( "nums が空かどうかを検出 : " + nums.isEmpty )
   }
}

上記のコードを実行すると、出力結果は次のようになります：

$ scalac Test.scala 
$ scala Test
colors 中的键为 : Set(red, azure, peru)
colors 中的值为 : MapLike(#FF0000, #F0FFFF, #CD853F)
检测 colors 是否为空 : false
检测 nums 是否为空 : true

Map のマージ

使用できるのは++演算子またはMap.++()メソッドで2つの Map を接続できます。Map をマージするときに重複するキーは削除されます。以下に2つの Map のマージの例を示します:

実例

object Test {
   def main(args: Array[String]) {
      val colors1 = Map("red" -> "#FF0000",
                        "azure" -> "#F0FFFF",
                        "peru" -> "#CD853F")
      val colors2 = Map("blue" -> "#0033FF",
                        "yellow" -> "#FFFF00",
                        "red" -> "#FF0000")

      // ++ を演算子として
      var colors = colors1 ++ colors2
      println( "colors1 ++ colors2 : " + colors )

      // ++ をメソッドとして
      colors = colors1.++(colors2)
      println( "colors1.++(colors2) : " + colors )

   }
}

上記のコードを実行すると、出力結果は次のようになります：

$ scalac Test.scala 
$ scala Test
colors1 ++ colors2 : Map(blue -> #0033FF, azure -> #F0FFFF, peru -> #CD853F, yellow -> #FFFF00, red -> #FF0000)
colors1.++(colors2) : Map(blue -> #0033FF, azure -> #F0FFFF, peru -> #CD853F, yellow -> #FFFF00, red -> #FF0000)

Map の keys と values を出力

以下では、foreach ループを使用して Map 内の keys と values を出力します：

実例

object Test {
   def main(args: Array[String]) {
      val sites = Map("runoob" -> "http://www.runoob.com",
                       "baidu" -> "http://www.baidu.com",
                       "taobao" -> "http://www.taobao.com")

      sites.keys.foreach{ i =>  
                           print( "Key = " + i )
                           println(" Value = " + sites(i) )}
   }
}

上記のコードを実行すると、出力結果は次のようになります：

$ scalac Test.scala 
$ scala Test
Key = runoob Value = http://www.runoob.com
Key = baidu Value = http://www.baidu.com
Key = taobao Value = http://www.taobao.com

Map に指定された Key が存在するか確認

使用できるのはMap.containsメソッドで、Map に指定された Key が存在するかどうかを確認できます。例は次のとおりです：

実例

object Test {
   def main(args: Array[String]) {
      val sites = Map("runoob" -> "http://www.runoob.com",
                       "baidu" -> "http://www.baidu.com",
                       "taobao" -> "http://www.taobao.com")

      if( sites.contains( "runoob" )){
           println("runoob キーが存在し、対応する値は :"  + sites("runoob"))
      }else{
           println("runoob キーは存在しません")
      }
      if( sites.contains( "baidu" )){
           println("baidu キーが存在し、対応する値は :"  + sites("baidu"))
      }else{
           println("baidu キーは存在しません")
      }
      if( sites.contains( "google" )){
           println("google キーが存在し、対応する値は :"  + sites("google"))
      }else{
           println("google キーは存在しません")
      }
   }
}

上記のコードを実行すると、出力結果は次のようになります：

$ scalac Test.scala 
$ scala Test
runoob 键存在，对应的值为 :http://www.runoob.com
baidu 键存在，对应的值为 :http://www.baidu.com
google 键不存在

Scala Map のメソッド

次の表は、Scala Map でよく使われるメソッドの一覧です：

番号 メソッドと説明
1

def ++(xs: Map[(A, B)]): Map[A, B]

新しい Map を返します。新しい Map は xs で構成されます。
2

def -(elem1: A, elem2: A, elems: A*): Map[A, B]

キーが elem1, elem2 または他の elems を削除した新しい Map を返します。
3

def --(xs: GTO[A]): Map[A, B]

xs オブジェクト内の対応するキーを削除した新しい Map を返します。
4

def get(key: A): Option[B]

指定された key の値を返す
5

def iterator: Iterator[(A, B)]

新しいイテレータを作成し、key/value ペアを出力する

def addString(b: StringBuilder): StringBuilder

Map 内のすべての要素を StringBuilder に追加します。区切り文字を追加できます。
7

def addString(b: StringBuilder, sep: String): StringBuilder

Map 内のすべての要素を StringBuilder に追加します。区切り文字を追加できます。
8

def apply(key: A): B

指定されたキーの値を返します。存在しない場合は Map のデフォルト値を返します。

def clear(): Unit

10

def clone(): Map[A, B]

ある Map から別の Map にコピーする
11

def default(key: A): B

def drop(n: Int): Map[A, B]

最初の n 個の要素を破棄して新しいコレクションを返す

def dropRight(n: Int): Map[A, B]

最後の n 個の要素を破棄して新しいコレクションを返す

def dropWhile(p: ((A, B)) => Boolean): Map[A, B]

左から右へ要素を破棄し、条件 p が成立しなくなるまで続ける
18

def empty: Map[A, B]

同じ型の空の Map を返す
19

def equals(that: Any): Boolean

2つの Map が等しい場合（key/value がすべて等しい）、true を返し、それ以外の場合は false を返します。

コレクション内に指定された条件の要素が存在するかどうかを判定する

def filter(p: ((A, B))=> Boolean): Map[A, B]

指定された条件を満たすすべてのコレクションを返す
22

def filterKeys(p: (A) => Boolean): Map[A, B]

指定された条件に一致する不変 Map を返す
23

def find(p: ((A, B)) => Boolean): Option[(A, B)]

コレクション内で指定された条件を満たす最初の要素を検索する

def foreach(f: ((A, B)) => Unit): Unit

関数をコレクションのすべての要素に適用する

def remove(key: A): Option[B]

    使用++または.++()メソッドで2つの Map をマージします。

    注意すべき点: Map に同じ key が存在する場合、マージ後の Map の value は最も右側の Map の値に置き換えられます。

    var suit1 = Map("red"->"#FFF","blue"->"#FED","yellow"->"#00F","green"->"#0F0")
var suit2 = Map("red"->"#FF1","green"->"#1F1")
var suit3 = suit1++suit2
println("the value of suit1 is:" +suit1)
println("the value of suit2 is:" +suit2)
println("the value of after ++ is:" +suit3)
println("the value of after .++() is:" +suit1.++(suit2))

    結果：

    the value of suit1 is:Map(red -> #FFF, blue -> #FED, yellow -> #00F, green -> #0F0)
the value of suit2 is:Map(red -> #FF1, green -> #1F1)
the value of after ++ is:Map(red -> #FF1, blue -> #FED, yellow -> #00F, green -> #1F1)
the value of after .++() is:Map(red -> #FF1, blue -> #FED, yellow -> #00F, green -> #1F1)
