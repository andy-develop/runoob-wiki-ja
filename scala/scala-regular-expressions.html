Scala 正規表現

Scala は scala.util.matching パッケージのRegexクラスを使用して正規表現をサポートします。次の例は、正規表現を使用して単語を検索する方法を示しています。Scala :

例

import scala.util.matching.Regex

object Test {
   def main(args: Array[String]) {
      val pattern = "Scala".r
      val str = "Scala is Scalable and cool"
     
      println(pattern findFirstIn str)
   }
}

上記のコードを実行すると、出力結果は次のようになります：

$ scalac Test.scala 
$ scala Test
Some(Scala)

この例では、String クラスの r() メソッドを使用して Regex オブジェクトを構築しています。

次に、findFirstIn メソッドを使用して最初の一致項目を見つけます。

すべての一致項目を表示する必要がある場合は、findAllIn メソッドを使用できます。

mkString() メソッドを使用して正規表現の一致結果の文字列を連結でき、パイプ(|)を使用して異なるパターンを設定できます：

例

import scala.util.matching.Regex

object Test {
   def main(args: Array[String]) {
      val pattern = new Regex("(S|s)cala")  // 最初の文字は大文字の S または小文字の s にすることができます
      val str = "Scala is scalable and cool"
     
      println((pattern findAllIn str).mkString(","))   // カンマ , を使用して戻り結果を連結します
   }
}

上記のコードを実行すると、出力結果は次のようになります：

$ scalac Test.scala 
$ scala Test
Scala,scala

一致したテキストを指定したキーワードに置き換える必要がある場合は、次を使用できますreplaceFirstIn( )メソッドで最初の一致項目を置き換え、次を使用しますreplaceAllIn( )メソッドですべての一致項目を置き換えます。例は次のとおりです：

例

object Test {
   def main(args: Array[String]) {
      val pattern = "(S|s)cala".r
      val str = "Scala is scalable and cool"
     
      println(pattern replaceFirstIn(str, "Java"))
   }
}

上記のコードを実行すると、出力結果は次のようになります：

$ scalac Test.scala 
$ scala Test
Java is scalable and cool

正規表現

Scala の正規表現は Java の文法規則を継承しており、Java は主に Perl 言語の規則を使用しています。

以下の表に、一般的な正規表現の規則をいくつか示します：

式 一致規則
^ 入力文字列の先頭の位置に一致します。
$ 入力文字列の末尾の位置に一致します。
. "\r\n" 以外の任意の1文字に一致します。
[...] 文字セット。含まれる任意の文字に一致します。例："[abc]" は "plain" の "a" に一致します。
[^...] 否定文字セット。含まれない任意の文字に一致します。例："[^abc]" は "plain" の "p"、"l"、"i"、"n" に一致します。
\\A 入力文字列の先頭の位置に一致します（複数行サポートなし）
\\z 文字列の末尾（$ に似ていますが、複数行オプションの影響を受けません）
\\Z 文字列の末尾または行末（複数行オプションの影響を受けません）
re* 0回以上の繰り返し
re+ 1回以上の繰り返し
re? 0回または1回の繰り返し
re{ n} n回の繰り返し
re{ n,}
re{ n, m} n回からm回までの繰り返し
a|b a または b に一致
(re) re に一致し、テキストを自動的に名前が付けられたグループにキャプチャします
(?: re) re に一致しますが、一致したテキストをキャプチャせず、このグループにグループ番号も割り当てません
(?> re) 貪欲な部分式
\\w 英字、数字、アンダースコアに一致
\\W 英字、数字、アンダースコア、漢字以外の任意の文字に一致
\\s 任意の空白文字に一致。[\t\n\r\f] と同等です
\\S 空白文字以外の任意の文字に一致
\\d 数字に一致。[0-9] と類似
\\D 数字以外の任意の文字に一致
\\G 現在の検索の先頭
\\n 改行文字
\\b 通常は単語の境界位置ですが、文字クラス内で使用するとバックスペースを表します
\\B 単語の先頭または末尾ではない位置に一致
\\t タブ文字
\\Q 開始引用符：\Q(a+b)*3\Eテキスト "(a+b)*3" に一致します。
\\E 終了引用符：\Q(a+b)*3\Eテキスト "(a+b)*3" に一致します。

正規表現の例

例 説明
. "\r\n" 以外の任意の1文字に一致します。
[Rr]uby "Ruby" または "ruby" に一致
rub[ye] "ruby" または "rube" に一致
[aeiou] 小文字に一致：aeiou
[0-9] 任意の数字に一致。
[a-z] 任意の ASCII 小文字に一致
[A-Z] 任意の ASCII 大文字に一致
[a-zA-Z0-9] 数字、大文字小文字の英字に一致
[^aeiou] aeiou 以外の文字に一致
[^0-9] 数字以外の文字に一致
\\d 数字に一致、例: [0-9]
\\D 非数字に一致、例: [^0-9]
\\s 空白に一致、例: [ \t\r\n\f]
\\S 非空白に一致、例: [^ \t\r\n\f]
\\w 英字、数字、アンダースコアに一致、例: [A-Za-z0-9_]
\\W 英字、数字、アンダースコア以外に一致、例: [^A-Za-z0-9_]
ruby? "rub" または "ruby" に一致: y は省略可能
ruby* "rub" に加えて y が0個以上続くものに一致。
ruby+ "rub" に加えて y が1個以上続くものに一致。
\\d{3} ちょうど3桁の数字に一致。
\\d{3,} 3個以上の数字に一致。
\\d{3,5} 3個、4個、または5個の数字に一致。
\\D\\d+ グループ化なし：+ は \d を繰り返す
(\\D\\d)+/ グループ化：+ は \D\d のペアを繰り返す
([Rr]uby(, )?)+ "Ruby"、"Ruby, ruby, ruby" などに一致

上表の各文字は2つのバックスラッシュを使用していることに注意してください。これは、Java と Scala では文字列中のバックスラッシュがエスケープ文字であるためです。したがって、出力したい場合は\文字列内で次のように記述する必要があります\\これで1つのバックスラッシュを取得できます。次の例を参照してください：

例

import scala.util.matching.Regex

object Test {
   def main(args: Array[String]) {
      val pattern = new Regex("abl[ae]\\d+")
      val str = "ablaw is able1 and cool"
     
      println((pattern findAllIn str).mkString(","))
   }
}

上記のコードを実行すると、出力結果は次のようになります：

$ scalac Test.scala 
$ scala Test
able1
