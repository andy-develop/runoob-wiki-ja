Scala エスケープ文字

Scala では、エスケープ文字は、文字列リテラルに直接記述できない特殊文字を表すために使用されます。

エスケープ文字はバックスラッシュ\で始まり、その後に特定の文字が続き、何らかの特殊な意味や効果を表します。

次の表に、一般的なエスケープ文字を示します：

エスケープ文字説明
\bバックスペース
\tタブ文字 (Tab)
\n改行文字 (Line Feed)
\f改ページ文字 (Form Feed)
\r復帰文字 (Carriage Return)
\"二重引用符
\'単一引用符
\\バックスラッシュ

文字または文字列では、0 から 255 の範囲の Unicode 文字は、8進数のエスケープシーケンスで表すことができます。つまり、バックスラッシュ\の後に最大3桁の8進数が続きます。

バックスラッシュの\後の文字シーケンスが正当なエスケープシーケンスを構成できない場合、コンパイルエラーが発生します。

以下の例は、いくつかのエスケープ文字の使用法を示しています：

例

object Test {
   def main(args: Array[String]) {
      println("Hello\tWorld\n\n" );
   }
}

例を実行 »

上記のコードを実行すると、出力結果は次のようになります：

$ scalac Test.scala
$ scala Test
Hello    World

以下は、さまざまなエスケープ文字の使用法を示す Scala プログラムの例です：

例

object EscapeCharacterExamples {
  def main(args: Array[String]): Unit = {
    val backspace = "Hello\bWorld"     // "HelloWorld"
    val tab = "Hello\tWorld"           // "Hello    World"
    val newline = "Hello\nWorld"       // "Hello
                                       // World"
    val formFeed = "Hello\fWorld"      // "Hello World"
    val carriageReturn = "Hello\rWorld"// "World"
    val doubleQuote = "He said, \"Hello, World!\""  // "He said, "Hello, World!""
    val singleQuote = '\"'             // '"'
    val backslash = "This is a backslash: \\"  // "This is a backslash: \"

    // 出力例
    println(s"Backspace: $backspace")
    println(s"Tab: $tab")
    println(s"Newline: $newline")
    println(s"FormFeed: $formFeed")
    println(s"CarriageReturn: $carriageReturn")
    println(s"DoubleQuote: $doubleQuote")
    println(s"SingleQuote: $singleQuote")
    println(s"Backslash: $backslash")
  }
}

上記のコードを実行すると、出力結果は次のようになります：

、 
Backspace: HelloWorld
Tab: Hello    World
Newline: Hello
World
FormFeed: HelloWorld
CarriageReturn: World
DoubleQuote: He said, "Hello, World!"
SingleQuote: "
Backslash: This is a backslash: \

例の説明：

  • \b(バックスペース): カーソルを1つ後退させますが、文字は削除しません。例えば、"Hello\bWorld"結果はHelloWorld、ここでの\bは "o" を削除しないため、実際の表示効果は端末または出力デバイスに依存します。

  • \t(タブ文字): 水平タブを挿入します。これは一定数のスペースに相当します。"Hello\tWorld""Hello" と "World" の間にタブを挿入します。通常は4つまたは8つのスペースです。

  • \n(改行文字): 次の行に移動して新しい出力を開始します。"Hello\nWorld""Hello" と "World" を2行に分けて表示します。

  • \f(改ページ文字): 改ページ文字を挿入します。通常はプリンターの改ページを制御するために使われますが、コンソール出力では通常、明確な効果はありません。

  • \r(復帰文字): 現在の行の先頭に戻ります。"Hello\rWorld"現在の行の内容を上書きして "World" を表示します。

  • \"(二重引用符): 二重引用符を挿入します。"He said, \"Hello, World!\""表示He said, "Hello, World!"。

  • \'(単一引用符): 単一引用符を挿入します。通常、文字リテラルで使用されます。例：'\'\''は単一引用符の文字を表します。

  • \\(バックスラッシュ): バックスラッシュを挿入します。"This is a backslash: \\"表示This is a backslash: \。
