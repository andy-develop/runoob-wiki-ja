Python3 文字列

文字列は Python で最もよく使われるデータ型です。引用符(' 或 ")で文字列を作成します。

文字列の作成はとても簡単で、変数に値を代入するだけです。例：

var1 = 'Hello World!' var2 = "サンプル"

Python で文字列の値にアクセスする

Python は単一文字型をサポートしていません。単一文字も Python では文字列として扱われます。

Python で部分文字列にアクセスするには、角括弧を使用して[]文字列を切り出します。文字列の切り出しの構文は次のとおりです。

変数[先頭インデックス:末尾インデックス]

インデックス値は0を開始値とし、-1は末尾からの開始位置です。

以下の例のとおりです。

例(Python 3.0+)

#!/usr/bin/python3 var1 = 'Hello World!' var2 = "サンプル" print ("var1[0]: ", var1[0]) print ("var2[1:5]: ", var2[1:5])

上記の例の実行結果：

var1[0]:  H
var2[1:5]:  unoo

Python の文字列更新

文字列の一部を切り出して他のフィールドと連結することができます。以下の例のとおりです。

例(Python 3.0+)

#!/usr/bin/python3 var1 = 'Hello World!' print ("更新された文字列:", var1[:6] + 'サンプル!')

上記の例の実行結果

已更新字符串 :  Hello サンプル!

Python の文字列フォーマット

Python はフォーマット済み文字列の出力をサポートしています。非常に複雑な式を使うこともありますが、最も基本的な使い方は、文字列フォーマット指定子 %s を含む文字列に値を挿入することです。

Python では、文字列フォーマットは C の sprintf 関数と同じ構文を使用します。

例(Python 3.0+)

#!/usr/bin/python3 print ("私の名前は %s、今年 %d 歳です!" % ('小明', 10))

上記の例の出力結果：

我叫 小明 今年 10 岁!

python 文字列フォーマット指定子:

記号 説明
      %c文字とそのASCIIコードをフォーマット
      %s文字列をフォーマット
      %d整数をフォーマット
      %u符号なし整数をフォーマット
      %o符号なし8進数をフォーマット
      %x符号なし16進数をフォーマット
      %X符号なし16進数（大文字）をフォーマット
      %f浮動小数点数をフォーマットし、小数点以下の精度を指定できます
      %e科学的記数法で浮動小数点数をフォーマット
      %E%e と同じ働きで、科学的記数法で浮動小数点数をフォーマット
      %g%f と %e の省略形

      %p変数のアドレスを16進数でフォーマット

f-string

f-string は python3.6 以降のバージョンで追加されたもので、リテラルフォーマット文字列と呼ばれ、新しい文字列フォーマットの構文です。

以前はパーセント記号 (%) を使うのが慣例でした：

例

>>> name = 'サンプル'
>>> 'Hello %s' % name
'Hello サンプル'

f-stringフォーマット文字列はf先頭の文字で始まり、その後に文字列が続きます。文字列内の式は波括弧 {} で囲み、変数や式を計算した値に置き換えます。例は次のとおりです：

例

>>> name = 'サンプル'
>>> f'Hello {name}'  # 変数を置換
'Hello サンプル'
>>> f'{1+2}'         # 式を使用
'3'

>>> w = {'name': 'サンプル', 'url': 'www.example.com'}
>>> f'{w["name"]}: {w["url"]}'
'サンプル: www.example.com'

この方法を使うと明らかに簡単になり、%s を使うか %d を使うかを判断する必要がなくなります。

Python 3.8 のバージョンでは、=記号を使用して演算式と結果を連結できます：

例

>>> x = 1
>>> print(f'{x+1}')   # Python 3.6
2

>>> x = 1
>>> print(f'{x+1=}')   # Python 3.8
x+1=2

Unicode 文字列

Python2 では、通常の文字列は8ビットASCIIコードで格納され、Unicode文字列は16ビットUnicode文字列として格納されるため、より多くの文字セットを表すことができます。使用する構文は、文字列の前にプレフィックスを付けることです。u。

Python3 では、すべての文字列はUnicode文字列です。

Python の文字列組み込み関数

Python の文字列でよく使われる組み込み関数は次のとおりです：

番号メソッドと説明
1

capitalize()
文字列の最初の文字を大文字に変換します。

center(width, fillchar)

指定された幅 width で中央揃えされた文字列を返します。fillchar は埋める文字で、デフォルトはスペースです。

string 内で str が出現する回数を返します。beg または end を指定すると、指定範囲内で str が出現する回数を返します。
4

bytes.decode(encoding="utf-8", errors="strict")


Python3 には decode メソッドはありませんが、bytes オブジェクトの decode() メソッドを使用して、指定された bytes オブジェクトをデコードできます。この bytes オブジェクトは str.encode() でエンコードして取得できます。
5

encode(encoding='UTF-8',errors='strict')


encoding で指定されたエンコード形式で文字列をエンコードします。エラーが発生した場合、デフォルトでは ValueError 例外が発生します。ただし、errors に 'ignore' または 'replace' が指定されている場合は除きます。
6

文字列が suffix で終わっているかどうかを確認します。beg または end を指定すると、指定された範囲内で suffix で終わっているかを確認し、そうであれば True を返し、そうでなければ False を返します。

文字列 string 内のタブ記号をスペースに変換します。タブ記号のデフォルトのスペース数は 8 です。

str が文字列に含まれているかどうかを検出します。範囲 beg と end を指定すると、指定範囲内に含まれているかを確認し、含まれていれば開始インデックス値を返し、そうでなければ -1 を返します。

文字列が英数字で構成されているかどうかを確認します。つまり、文字列内のすべての文字が英字または数字であるかどうかです。文字列に少なくとも1文字あり、すべての文字が英字または数字である場合は True を返し、それ以外の場合は False を返します。
