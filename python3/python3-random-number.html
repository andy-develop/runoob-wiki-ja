Python の乱数生成

Python3 例

Python では、組み込みの random モジュールを使用して乱数を生成できます。

import random

random.random()

random.random()0.0 と 1.0 の間のランダムな小数を返します：

例

import random

random_number = random.random()
print(random_number)

上記のコードを実行すると、出力結果は次のようになります：

0.7597072251250637

random.randint(a, b)

random.randint(a, b) は、a と b の間の整数（a と b を含む）を返すために使用されます。

random.randint(a,b)

関数は数値 N を返します。N は a から b の間の数値（a <= N <= b）で、a と b を含みます。

次の例では、0〜9 の間の乱数を生成する方法を示します：

例

# -*- coding: UTF-8 -*- # Filename : test.py # author by : www.runoob.com # 0〜9 の間の乱数を生成 # random（乱数）モジュールをインポートする import random print(random.randint(0,9))

上記のコードを実行すると、出力結果は次のようになります：

4

random.choice(sequence)

random.choice(sequence)シーケンスからランダムに1つの要素を選択するために使用されます：

例

import random

list1 = [1, 2, 3, 4, 5]
random_element = random.choice(list1)
print(random_element)

例

import random

list1 = [1, 2, 3, 4, 5]
random_element = random.choice(list1)
print(random_element)

上記のコードを実行すると、出力結果は次のようになります：

4

random.shuffle(sequence)

random.shuffle(sequence)シーケンス内の要素をランダムに並べ替えるために使用されます：

例

import random

list1 = [1, 2, 3, 4, 5]
random.shuffle(list1)
print(list1)

上記のコードを実行すると、出力結果は次のようになります：

[3, 2, 4, 5, 1]

import re
from sys import exit

                print('现在就放弃太可惜了')

                print('超出范围')

                print('太大')

                print('太小')

                elif count == 2:
                    print('赞')
                else:
                    print('好')
                break

            time -= 1
            count += 1  # 奖励机制计数

            if time == 0:
                print('正确答案：%s' % secret)
                break
            else:
                print('还有[%s]次机会:' % time)
        else:
            print('要崩溃了!!!')
    print('游戏结束!')

if __name__ == '__main__':

    このプログラムは、キャラクタ端末の 1〜24 の位置にランダムにアスタリスクを表示します。*、そしてプロンプトを表示します「アスタリスクを移動するコマンドを入力してください(L/l または R/r)):」、ユーザーが入力した場合LEnter を押すと、アスタリスクは左に1文字分移動して再出力されます。ユーザーが入力した場合REnter を押すと、アスタリスクは右に1文字分移動します。プログラムはユーザーに入力を促すループを続け、ユーザーが入力するまで“EXIT”、プログラムは終了します。

    import random
class computer(object):

    def __init__(self):
        pass

    g_num = 0
    def ger_num(start,end):
        return random.randint(start,end)

    def contrl(ctl_str):
        global g_num
        if ctl_str == 'l' or ctl_str == 'L':
            g_num -= 1
            if g_num < 0:
                g_num = 23
        elif ctl_str == 'r' or ctl_str == 'R':
            g_num += 1
            if g_num > 23:
                g_num = 0
        return g_num

    @staticmethod
    def print_space(space_num):
        print_content = ['-']*24
        print_content = ''.join(print_content)
        l_content = list(print_content)
        l_content[space_num] = '*'
        l_content = ''.join(l_content)
        print(l_content)

if __name__ == '__main__':
    #生成随机数，确定星号的位置
    g_num = computer.ger_num(0,24)
    computer.print_space(g_num)
    while True:
        ctrl_str = input("请输入移动星星的指令(L/l or R/r):")
        if ctrl_str == 'EXIT' or ctrl_str == 'exit':
            break
        g_num = computer.contrl(ctrl_str)
        computer.print_space(g_num)

    random.randint(1,10)

    random.random()

    random.uniform(1.1, 5.4)

    random.choice(' ')
