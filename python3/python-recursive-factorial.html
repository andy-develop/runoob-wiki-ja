Python で再帰を使用して階乗を計算する

Python3 实例

階乗は数学の概念であり、1からある正の整数 n までを掛け合わせた積を表します。例えば、5の階乗（5!と表記）は1 2 3 4 5 = 120です。再帰の方法を使用して階乗を計算できます。再帰は、関数が自分自身を呼び出す技術です。

实例

def factorial(n):
    if n == 1:
        return 1
    else:
        return n * factorial(n - 1)

# 5の階乗を計算する
result = factorial(5)
print(result)

代码解析：

  • factorialこの関数は、整数を受け取る再帰関数ですnパラメータとして。
  • 如果nその整数が1に等しい場合、関数は1を返します。これが再帰の終了条件です。
  • そうでなければ、関数は戻ります。n乘以factorial(n - 1)の結果、すなわちn乘以n-1の階乗。
  • コードの最後に、私たちは呼び出しますfactorial(5)5の階乗を計算し、その結果を出力します。

输出结果：

120
