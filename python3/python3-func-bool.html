Python bool() 関数

Python3 組み込み関数

bool()Python で値をブール値に変換するための組み込み関数です。

ブール値には2つの値しかありません：True（真）またはFalse（偽）。

用語の意味： boolboolean（ブール）の略で、論理値の型を表します。

基本構文とパラメータ

構文形式

bool(x)

パラメータの説明

  • パラメータ x：
    • 型： 任意の値
    • 説明： ブール値に変換する値。

関数の説明

  • 戻り値： 返すTrue 或 False。
  • 偽の値： 以下の値はブール変換時に False になります：None、False、0、""、()、[]、{}、frozenset()。

例

例 1：基本的な使い方

例

# 様々な型から変換
print(bool(1))          # 出力: True
print(bool(0))          # 出力: False
print(bool(-1))         # 出力: True

print(bool(""))         # 出力: False
print(bool("hello"))    # 出力: True

print(bool([]))         # 出力: False
print(bool([1, 2]))     # 出力: True

print(bool(None))       # 出力: False

print(bool(True))       # 出力: True
print(bool(False))      # 出力: False

実行結果の予想：

True
False
True
False
True
False
True
False
True
False

コードの解説：

  1. 数値 0 は False、0 以外は True です。
  2. 空文字列は False、空でない文字列は True です。
  3. 空のリストは False、空でないリストは True です。

例 2：よくある応用

例

# リストが空かどうかを判定
items = []
if bool(items):
    print(リストは空ではありません)
else:
    print(リストは空です)  # 出力: リストは空です

# 文字列に内容があるかどうかを判定
name = ""
if bool(name.strip()):
    print(fこんにちは, {name})
else:
    print(名前を入力してください)  # 出力: 名前を入力してください

# 値が存在するかどうかを判定
data = {"name": "Tom"}
if bool(data.get("email")):
    print(メールアドレスあり)
else:
    print(メールアドレスなし)  # 出力: メールアドレスなし

実行結果の予想：

リストが空です
名前を入力してください
メールアドレスがありません

bool()値の存在や内容の有無を確認する条件判断によく使われます。
