Python3 集合

集合（set）は順序を持たない重複のない要素の集まりです。

集合の要素は重複せず、共通部分（交差）、和集合、差集合などの一般的な集合演算を行うことができます。

中括弧を使用できます{ }集合を作成し、要素間はカンマで,区切り、またはset()関数を使用して集合を作成することもできます。

作成形式：

parame = {value01,value02,...}
或者
set(value)

以下は簡単な例です：

set1 = {1, 2, 3, 4}            # 直接使用大括号创建集合
set2 = set([4, 5, 6, 7])      # 使用 set() 函数从列表创建集合

注意：空の集合を作成するには必ず set()ではなく{ }、なぜなら{ }空の辞書を作成するために使われるからです。

さらに例のデモ：

例(Python 3.0+)

>>> basket = {'apple', 'orange', 'apple', 'pear', 'orange', 'banana'}
>>> print(basket)                      # ここでは重複除去機能を示しています
{'orange', 'banana', 'pear', 'apple'}
>>> 'orange' in basket                 # 要素が集合内にあるかを素早く判定します
True
>>> 'crabgrass' in basket
False

>>> # 以下は2つの集合間の演算を示しています。
...
>>> a = set('abracadabra')
>>> b = set('alacazam')
>>> a                                  
{'a', 'r', 'b', 'c', 'd'}
>>> a - b                              # 集合aには含まれるが集合bには含まれない要素
{'r', 'd', 'b'}
>>> a | b                              # 集合aまたはbに含まれるすべての要素
{'a', 'c', 'r', 'd', 'b', 'm', 'z', 'l'}
>>> a & b                              # 集合aとbの両方に含まれる要素
{'a', 'c'}
>>> a ^ b                              # aとbに同時に含まれない要素
{'r', 'd', 'b', 'm', 'z', 'l'}

リスト内包表記と同様に、集合も集合内包表記（Set comprehension）をサポートしています：

例(Python 3.0+)

>>> a = {x for x in 'abracadabra' if x not in 'abc'}
>>> a
{'r', 'd'}

集合の基本操作

1、要素の追加

構文は次のとおりです：

s.add( x )

要素 x を集合 s に追加します。要素がすでに存在する場合は何も操作しません。

例(Python 3.0+)

>>> thisset = set(("Google", "Runoob", "Taobao"))
>>> thisset.add("Facebook")
>>> print(thisset)
{'Taobao', 'Facebook', 'Google', 'Runoob'}

もう1つの方法でも要素を追加できます。引数にはリスト、タプル、辞書などを指定できます。構文は次のとおりです：

s.update( x )

x は複数指定でき、カンマで区切ります。

例(Python 3.0+)

>>> thisset = set(("Google", "Runoob", "Taobao"))
>>> thisset.update({1,3})
>>> print(thisset)
{1, 3, 'Google', 'Taobao', 'Runoob'}
>>> thisset.update([1,4],[5,6])  
>>> print(thisset)
{1, 3, 4, 5, 6, 'Google', 'Taobao', 'Runoob'}
>>>

2、要素の削除

構文は次のとおりです：

s.remove( x )

要素 x を集合 s から削除します。要素が存在しない場合はエラーが発生します。

例(Python 3.0+)

>>> thisset = set(("Google", "Runoob", "Taobao"))
>>> thisset.remove("Taobao")
>>> print(thisset)
{'Google', 'Runoob'}
>>> thisset.remove("Facebook")   # 存在しない場合はエラーが発生
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'Facebook'
>>>

他にも集合の要素を削除する方法があります。要素が存在しなくてもエラーは発生しません。構文は次のとおりです：

s.discard( x )

例(Python 3.0+)

>>> thisset = set(("Google", "Runoob", "Taobao"))
>>> thisset.discard("Facebook")  # 存在しなくてもエラーは発生しない
>>> print(thisset)
{'Taobao', 'Google', 'Runoob'}

集合内の要素をランダムに削除するように設定することもできます。構文は次のとおりです：

s.pop()

スクリプトモードの例(Python 3.0+)

thisset = set(("Google", "Runoob", "Taobao", "Facebook"))
x = thisset.pop()

print(x)

出力結果：

Runoob

複数回実行すると、テスト結果は毎回異なります。

set 集合の pop メソッドは、集合を順不同に並べ、その順不同に並んだ集合の左端の最初の要素を削除します。

3、集合の要素数を計算する

構文は次のとおりです：

len(s)

集合 s の要素数を計算します。

例(Python 3.0+)

>>> thisset = set(("Google", "Runoob", "Taobao"))
>>> len(thisset)
3

4、集合を空にする

構文は次のとおりです：

s.clear()

集合 s を空にします。

例(Python 3.0+)

>>> thisset = set(("Google", "Runoob", "Taobao"))
>>> thisset.clear()
>>> print(thisset)
set()

5、要素が集合内に存在するかを判定する

構文は次のとおりです：

x in s

要素 x が集合 s 内に存在するかを判定します。存在すれば True を返し、存在しなければ False を返します。

例(Python 3.0+)

>>> thisset = set(("Google", "Runoob", "Taobao"))
>>> "Runoob" in thisset
True
>>> "Facebook" in thisset
False
>>>

    集合で set.pop() メソッドを使って要素を削除する際の所感は次のとおりです：

    1、Python のリスト list、タプル tuple 型の要素を集合に変換すると、重複した要素は取り除かれます。次のとおりです：

    >>> list = [1,1,2,3,4,5,3,1,4,6,5]
>>> set(list)
{1, 2, 3, 4, 5, 6}
>>> tuple = (2,3,5,6,3,5,2,5)
>>> set(tuple)
{2, 3, 5, 6}

    2、集合は list と tuple に対してソート（昇順）を行います。例を以下に示します：

    >>> set([9,4,5,2,6,7,1,8])
{1, 2, 4, 5, 6, 7, 8, 9}
>>> set([9,4,5,2,6,7,1,8])
{1, 2, 4, 5, 6, 7, 8, 9}

    3、集合の set.pop() に関する異なる見解

    set.pop() は集合内の要素をランダムに削除するという人もいますが、それは違います！辞書や文字列から変換された集合の場合はランダムに削除されます。リストやタプルから構成された集合の場合、set.pop() は左端から要素を削除します。次のとおりです：

    リストの例：

    set1 = set([9,4,5,2,6,7,1,8])
print(set1)
print(set1.pop())
print(set1)

    出力結果：

    {1, 2, 4, 5, 6, 7, 8, 9}
1
{2, 4, 5, 6, 7, 8, 9}

    タプルの例：

    set1 = set((6,3,1,7,2,9,8,0))
print(set1)
print(set1.pop())
print(set1)

    出力結果：

    {0, 1, 2, 3, 6, 7, 8, 9}
0
{1, 2, 3, 6, 7, 8, 9}

a.sort()
print(a)

s.sort()

    a=[1, 51, 31, -3, 10]
a.sort()
print(a)

print(b)

c=['a','ab','3ae','zaaa','1']
c.sort(key=len)
print(c)

    出力：

['1', '3ae', 'a', 'ab', 'zaaa']

    この課を一言で分かりやすく関数をまとめると：

    要素の追加

    setx.add(string|tuple|bool|number):void
setx.update(y [,z...]):void # y、z 为 list|tuple|dict

setx.clear():void
setx.copy():set # 深拷贝（指向新的内存地址）

    要素の削除

    setx.remove(y):void|KeyError #如删除不存在的元素，有报错
setx.discard(y):void
setx.pop():mixed #随机删除集合元素，并返回被删除的元素

    右完全包含ブール値 True：setx 集合のすべての要素が sety 集合に含まれているかを判定する

    setx.issubset(sety):bool
>>> x = {"a", "b", "c"}
>>> y = {"f", "e", "d", "c", "b", "a"}
>>> x.issubset(y)
True

    左完全包含ブール値 True: sety 集合のすべての要素が元の setx 集合に含まれているかを判定する

    setx.issuperset(sety):bool
>>> x = {"a", "b", "c"}
>>> y = {"f", "e", "d", "c", "b", "a"}
>>> y.issuperset(x)
True

    右半包含ブール値の否定：集合 sety の中に集合 setx のいずれかの要素が含まれるかを判定します（含む場合は False を返し、含まない場合は True を返します）

    setx.isdisjoint(sety):bool

    集合の併合（和集合）：（注意：集合要素の重複除去、一意性）

    setx.union(sety [, setz...]):set
>>> x = {"a", "b", "c"}
>>> y = {"f", "d", "a"}
>>> z = {"c", "d", "e"}
>>> x.union(y, z) 
{'c', 'd', 'f', 'e', 'b', 'a'}

    左包含差集合：集合の差集合を返します。つまり、返される集合の要素は最初の集合 x に含まれますが、2番目の集合 y（メソッドのパラメータ）には含まれません。

    setx.difference(sety):set

    左参照で積集合を削除（戻り値なし、つまり元のメモリ参照を直接変更）

    setx.difference_update(sety):void
    >>> x,y
({'banana', 'cshit', 'vipkwd.com', 'alipay'}, {'google', 'runoob', 'facebook', 'alipay'})>>> type(x.difference_update(y))
<class 'NoneType'>
>>> x,y
({'banana', 'cshit', 'vipkwd.com'}, {'google', 'runoob', 'facebook', 'alipay'})

    左右差集合：2つの集合の中で重複しない要素の集合を返します。つまり、両方の集合に存在する要素を除去します。

    setx.symmetric_difference(sety):set

    左参照で積集合を削除し、参照で右差集合を追加（参照操作、戻り値なし）

    setx.symmetric_difference_update(sett):void

    左右の積集合：2つ以上の集合すべてに含まれる要素、つまり積集合を返します。

    setx.intersection(sety[, seyz....]):set

    左参照で積集合

    setx.intersection_update(sety):void

    補足理解：「引用」という言葉が出てくるものはすべて、関数内部でメモリ参照を直接操作するため、戻り値がありません。逆に、実質的な戻り値がない関数は、必ず関数内部で他の位置の内容を変更しています。そうでない場合、その関数は実質的な意味を持たないため、犬の糞も同然です。
