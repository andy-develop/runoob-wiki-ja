Python3 入力と出力

前のいくつかの章で、実際にPythonの入力と出力の機能に触れてきました。この章では、Pythonの入力と出力について具体的に紹介します。

出力フォーマットの美化

Pythonには出力値を表示する2つの方法があります: 式文と print() 関数です。

3つ目の方法は、ファイルオブジェクトの write() メソッドを使用することです。標準出力ファイルは sys.stdout で参照できます。

出力形式をより多様にしたい場合は、str.format() 関数を使用して出力値をフォーマットできます。

出力値を文字列に変換したい場合は、repr() または str() 関数を使用して実現できます。

  • str()：関数はユーザーが読みやすい表現を返します。
  • repr()：インタープリタが読みやすい表現を生成します。

例

>>> s = 'Hello, サンプル'
>>> str(s)
'Hello, サンプル'
>>> repr(s)
"'Hello, サンプル'"
>>> str(1/7)
'0.14285714285714285'
>>> x = 10 * 3.25
>>> y = 200 * 200
>>> s = 'x の値: ' + repr(x) + ', y の値:' + repr(y) + '...'
>>> print(s)
x の値:32.5,y の値:40000...
>>> # repr() 関数は文字列内の特殊文字をエスケープできます
... hello = 'hello, サンプル\n'
>>> hellos = repr(hello)
>>> print(hellos)
'hello, サンプル\n'
>>> # repr() の引数は Python の任意のオブジェクトにできます
... repr((x, y, ('Google', 'サンプル')))
"(32.5, 40000, ('Google', 'サンプル'))"

平方と立方の表を出力する方法は2つあります:

>>> for x in range(1, 11):
...     print(repr(x).rjust(2), repr(x*x).rjust(3), end=' ')
...     # 前の行の 'end' の使用に注意
...     print(repr(x*x*x).rjust(4))
...
 1   1    1
 2   4    8
 3   9   27
 4  16   64
 5  25  125
 6  36  216
 7  49  343
 8  64  512
 9  81  729
10 100 1000

>>> for x in range(1, 11):
...     print('{0:2d} {1:3d} {2:4d}'.format(x, x*x, x*x*x))
...
 1   1    1
 2   4    8
 3   9   27
 4  16   64
 5  25  125
 6  36  216
 7  49  343
 8  64  512
 9  81  729
10 100 1000

注意:最初の例では、各列間のスペースは print() によって追加されます。

この例では、文字列オブジェクトの rjust() メソッドを示しています。これは文字列を右寄せにして、左側にスペースを埋めます。

同様のメソッドとして、ljust() や center() もあります。これらのメソッドは何も書き込まず、新しい文字列を返すだけです。

もう1つのメソッド zfill() は、数字の左側に0を埋めます。次のようになります:

>>> '12'.zfill(5)
'00012'
>>> '-3.14'.zfill(7)
'-003.14'
>>> '3.14159265359'.zfill(5)
'3.14159265359'

str.format() の基本的な使用法は次のとおりです:

>>> print('{}ウェブサイト: "{}!"'.format('サンプル', 'www.example.com'))
サンプルウェブサイト:"www.example.com!"

括弧とその中の文字（フォーマットフィールドと呼ばれます）は、format() 内の引数で置き換えられます。

括弧内の数字は、format() に渡されたオブジェクトの位置を指すために使用されます。次のようになります:

>>> print('{0} と {1}'.format('Google', 'サンプル'))
Google と サンプル
>>> print('{1} と {0}'.format('Google', 'サンプル'))
サンプル と Google

format() でキーワード引数を使用した場合、その値はその名前の引数を指します。

>>> print('{name}ウェブサイト: {site}'.format(name='サンプル', site='www.example.com'))
サンプルウェブサイト: www.サンプル.com

位置引数とキーワード引数は任意に組み合わせることができます:

>>> print('サイトリスト {0}, {1}, と {other}。'.format('Google', 'サンプル', other='Taobao'))
サイトリスト Google, サンプル,と Taobao。

!a(使用ascii()), !s(使用str()) と!r(使用 repr()) は、値をフォーマットする前に変換するために使用できます:

>>> import math
>>> print('定数 PI の値はおおよそ {} です。'.format(math.pi))
定数 PI の値はおおよそ:3.141592653589793。
>>> print('定数 PI の値はおおよそ {!r} です。'.format(math.pi))
定数 PI の値はおおよそ:3.141592653589793。

オプション:とフォーマット指定子はフィールド名の後に続けることができます。これにより、値をより適切にフォーマットできます。次の例では、Pi を小数点以下3桁まで保持します:

>>> import math
>>> print('定数 PI の値はおおよそ {0:.3f} です。'.format(math.pi))
定数 PI の値はおおよそ3.142。

に:後に整数を渡すと、そのフィールドの幅を少なくともその値に保証できます。表を美しく整形するのに役立ちます。

>>> table = {'Google': 1, 'サンプル': 2, 'Taobao': 3}
>>> for name, number in table.items():
...     print('{0:10} ==> {1:10d}'.format(name, number))
...
Google     ==>          1
サンプル     ==>          2
Taobao     ==>          3

長いフォーマット文字列があり、それを分割したくない場合、フォーマット時に位置ではなく変数名で指定するとよいでしょう。

最も簡単なのは、辞書を渡し、角括弧を使用することです。[]キー値にアクセスします:

>>> table = {'Google': 1, 'サンプル': 2, 'Taobao': 3}
>>> print('サンプル: {0[サンプル]:d}; Google: {0[Google]:d}; Taobao: {0[Taobao]:d}'.format(table))
サンプル: 2; Google: 1; Taobao: 3

また、table 変数の前に**を使用して同じ機能を実現することもできます:

>>> table = {'Google': 1, 'サンプル': 2, 'Taobao': 3}
>>> print('サンプル: {サンプル:d}; Google: {Google:d}; Taobao: {Taobao:d}'.format(**table))
サンプル: 2; Google: 1; Taobao: 3

旧式の文字列フォーマット

%演算子でも文字列フォーマットを実現できます。左側の引数を類似のsprintf()フォーマット文字列として、右側を代入し、フォーマットされた文字列を返します。例:

>>> import math
>>> print('定数 PI の値はおおよそ：%5.3f。' % math.pi)
定数 PI の値はおおよそ:3.142。

str.format() は比較的新しい関数ですが、ほとんどの Python コードは依然として % 演算子を使用しています。しかし、この旧式のフォーマットは最終的に言語から削除されるため、より多くの str.format() を使用するべきです。

キーボード入力の読み取り

Python はinput() 組み込み関数を標準入力から1行のテキストを読み取ります。デフォルトの標準入力はキーボードです。

例

#!/usr/bin/python3

str = input("入力してください：");
print ("入力した内容は: ", str)

これにより、入力に対応する次のような結果が生成されます:

入力してください：サンプル
入力された内容は: サンプル

ファイルの読み書き

Python では、ファイル操作はopen()関数によって完了します。この関数はファイルオブジェクトを返し、後続の読み取りまたは書き込み操作に使用されます。

open()の基本構文は次のとおりです:

open(filename, mode)
  • filename：アクセスするファイルのパス（文字列）。
  • mode：ファイルを開くモード。読み書きの方法（読み取り専用、書き込み、追記など）を指定します。この引数はオプションで、デフォルト値はr（読み取り専用）です。

一般的なファイルを開くモードは次のとおりです（r / w / a を重点的に習得することをお勧めします）:

モード 説明
r 読み取り専用でファイルを開きます（デフォルトモード）。ファイルは存在している必要があり、ファイルポインタは先頭にあります。
rb バイナリ形式で読み取り専用としてファイルを開きます（画像、動画など）。ファイルポインタは先頭にあります。
r+ 読み書きモードでファイルを開きます。ファイルは存在している必要があり、ファイルポインタは先頭にあります。
rb+ バイナリ形式で読み書きモードとしてファイルを開きます。ファイルポインタは先頭にあります。
w 書き込み専用でファイルを開きます。ファイルが存在する場合は空にされます; 存在しない場合は新しいファイルを作成します。
wb バイナリ形式で書き込み専用としてファイルを開きます。ファイルが存在する場合は空にされます; 存在しない場合は新しいファイルを作成します。
w+ 読み書きモードでファイルを開きます。ファイルが存在する場合は空にされます; 存在しない場合は新しいファイルを作成します。
wb+ バイナリ形式で読み書きモードとしてファイルを開きます。ファイルが存在する場合は空にされます; 存在しない場合は新しいファイルを作成します。
a 追記モードでファイルを開きます。ファイルが存在する場合、書き込まれた内容は末尾に追加されます; 存在しない場合は新しいファイルを作成します。
ab バイナリ形式で追記書き込みとしてファイルを開きます。書き込まれた内容は末尾に追加されます; 存在しない場合は新しいファイルを作成します。
a+ 読み書きモードでファイルを開きます。ファイルポインタはデフォルトで末尾にあります（追記モード）; 存在しない場合は新しいファイルを作成します。
ab+ バイナリ形式で読み書きモードとしてファイルを開きます。ファイルポインタはデフォルトで末尾にあります; 存在しない場合は新しいファイルを作成します。

説明:モードの後にbは、バイナリモードでファイルを操作することを意味します。画像、音声などの非テキストファイルの処理によく使用されます。

次の図は、これらのモードをよくまとめています:

モード r r+ w w+ a a+
读 + + + +
写 + + + + +
作成 + + + +
上書き + +
ポインタは先頭 + + + +
ポインタは末尾 + +

次の例では、文字列をファイル foo.txt に書き込みます:

例

#!/usr/bin/python3

# ファイルを開く
f = open("/tmp/foo.txt", "w")

f.write( "Python は非常に優れた言語です。\nはい、本当に素晴らしいです!!\n" )

# 開いたファイルを閉じる
f.close()
  • 最初の引数は、開きたいファイル名です。
  • 2番目のパラメータは、ファイルの使用方法を説明する文字列です。mode は、ファイルが読み取り専用の場合は 'r'、書き込み専用の場合は 'w'（同じ名前のファイルが存在する場合は削除されます）、ファイル内容の追記には 'a' を使用します。書き込まれたデータはすべて自動的に末尾に追加されます。'r+' は読み書きの両方に使用します。mode パラメータはオプションです。'r' がデフォルト値になります。

このとき、ファイル foo.txt を開くと、次のように表示されます：

$ cat /tmp/foo.txt 
Python 是一个非常好的语言。
是的，的确非常好!!

ファイルオブジェクトのメソッド

このセクションの残りの例では、f という名前のファイルオブジェクトが作成済みであると仮定します。

f.read()

ファイルの内容を読み取るには、f.read(size) を呼び出します。これにより、一定量のデータを読み取り、文字列またはバイトオブジェクトとして返します。

size はオプションの数値型パラメータです。size が省略されるか負の値の場合、ファイルのすべての内容が読み取られ、返されます。

以下の例では、ファイル foo.txt が既に存在する（上記の例で作成済み）と仮定します：

例

#!/usr/bin/python3

# ファイルを開く
f = open("/tmp/foo.txt", "r")

str = f.read()
print(str)

# 開いたファイルを閉じる
f.close()

上記のプログラムを実行すると、出力結果は次のようになります：

Python 是一个非常好的语言。
是的，的确非常好!!

f.readline()

f.readline() はファイルから1行を読み取ります。改行文字は '\n' です。f.readline() が空文字列を返す場合、最後の行まで読み取ったことを示します。

例

#!/usr/bin/python3

# ファイルを開く
f = open("/tmp/foo.txt", "r")

str = f.readline()
print(str)

# 開いたファイルを閉じる
f.close()

上記のプログラムを実行すると、出力結果は次のようになります：

Python 是一个非常好的语言。

f.readlines()

f.readlines() は、ファイル内のすべての行を返します。

オプションのパラメータ sizehint を設定すると、指定した長さのバイト数を読み取り、それらのバイトを行ごとに分割します。

例

#!/usr/bin/python3

# ファイルを開く
f = open("/tmp/foo.txt", "r")

str = f.readlines()
print(str)

# 開いたファイルを閉じる
f.close()

上記のプログラムを実行すると、出力結果は次のようになります：

['Python 是一个非常好的语言。\n', '是的，的确非常好!!\n']

別の方法として、ファイルオブジェクトを反復処理して各行を読み取る方法があります：

例

#!/usr/bin/python3

# ファイルを開く
f = open("/tmp/foo.txt", "r")

for line in f:
    print(line, end='')

# 開いたファイルを閉じる
f.close()

上記のプログラムを実行すると、出力結果は次のようになります：

Python 是一个非常好的语言。
是的，的确非常好!!

この方法は簡単ですが、細かい制御はできません。両者の処理メカニズムが異なるため、混用しないほうがよいでしょう。

f.write()

f.write(string) は string をファイルに書き込み、書き込んだ文字数を返します。

例

#!/usr/bin/python3

# ファイルを開く
f = open("/tmp/foo.txt", "w")

num = f.write( 「Python は非常に素晴らしい言語です。\nそうです、本当に素晴らしいです!!」\n" )
print(num)
# 開いたファイルを閉じる
f.close()

上記のプログラムを実行すると、出力結果は次のようになります：

29

文字列ではないものを書き込む場合は、事前に変換する必要があります：

例

#!/usr/bin/python3

# ファイルを開く
f = open("/tmp/foo1.txt", "w")

value = ('www.example.com', 14)
s = str(value)
f.write(s)

# 開いたファイルを閉じる
f.close()

上記のプログラムを実行し、foo1.txt ファイルを開くと：

$ cat /tmp/foo1.txt 
('www.example.com', 14)

f.tell()

f.tell() は、ファイルの現在の読み取り/書き込み位置（つまりファイルポインタの位置）を返します。ファイルポインタは、ファイルの先頭からのバイト数オフセットを表します。f.tell() は、ファイルポインタの現在位置を表す整数を返します。

f.seek()

ファイルポインタの現在位置を変更するには、f.seek(offset, from_what) 関数を使用できます。

f.seek(offset, whence) は、ファイルポインタを指定した位置に移動するために使用します。

offset は whence パラメータからの相対オフセットを表します。from_what の値が 0 の場合は先頭、1 の場合は現在位置、2 の場合はファイルの末尾を表します。例：

  • seek(x,0) ： 開始位置、つまりファイルの先頭行の最初の文字から x 文字移動します。
  • seek(x,1) ： 現在位置から後ろに x 文字移動します。
  • seek(-x,2)：ファイルの末尾から前に x 文字移動します。

from_what の値のデフォルトは 0、つまりファイルの先頭です。以下に完全な例を示します：

>>> f = open('/tmp/foo.txt', 'rb+')
>>> f.write(b'0123456789abcdef')
16
>>> f.seek(5)     # ファイルの6番目のバイトに移動
5
>>> f.read(1)
b'5'
>>> f.seek(-3, 2) # ファイルの末尾から3バイト目に移動
13
>>> f.read(1)
b'd'

f.close()

テキストファイル（ファイルを開くモードに b が含まれていないもの）では、ファイルの先頭位置からの位置決めのみが行われます。

ファイルの処理が終わったら、f.close() を呼び出してファイルを閉じ、システムリソースを解放します。その後、そのファイルを再度呼び出そうとすると、例外がスローされます。

>>> f.close()
>>> f.read()
Traceback (most recent call last):
  File "<stdin>", line 1, in ?
ValueError: I/O operation on closed file

ファイルオブジェクトを扱うときは、with キーワードを使用するのが非常に良い方法です。処理が終わると、自動的にファイルを正しく閉じてくれます。また、try - finally 文よりも簡潔に記述できます：

>>> with open('/tmp/foo.txt', 'r') as f:
...     read_data = f.read()
>>> f.closed
True

ファイルオブジェクトには他にも isatty() や trucate() などのメソッドがありますが、これらは通常あまり使用されません。

pickle モジュール

Python の pickle モジュールは、基本的なデータのシリアライズとデシリアライズを実装しています。

pickle モジュールのシリアライズ操作により、プログラム内で実行中のオブジェクト情報をファイルに保存し、永続的に保存できます。

pickle モジュールのデシリアライズ操作により、前回のプログラムで保存されたオブジェクトをファイルから作成できます。

基本インターフェース：

pickle.dump(obj, file, [,protocol])

pickle を使用すると、file を読み取り用に開くことができます：

x = pickle.load(file)

注記：file から文字列を読み取り、それを元の Python オブジェクトに再構築します。

file:ファイルライクオブジェクトであり、read() と readline() インターフェースを持ちます。

例1

#!/usr/bin/python3
import pickle

# pickleモジュールを使用してデータオブジェクトをファイルに保存する
data1 = {'a': [1, 2.0, 3, 4+6j],
         'b': ('string', u'Unicode string'),
         'c': None}

selfref_list = [1, 2, 3]
selfref_list.append(selfref_list)

output = open('data.pkl', 'wb')

# Pickle dictionary using protocol 0.
pickle.dump(data1, output)

# Pickle the list using the highest protocol available.
pickle.dump(selfref_list, output, -1)

output.close()

例2

#!/usr/bin/python3
import pprint, pickle

# pickleモジュールを使用してファイルからPythonオブジェクトを再構築する
pkl_file = open('data.pkl', 'rb')

data1 = pickle.load(pkl_file)
pprint.pprint(data1)

data2 = pickle.load(pkl_file)
pprint.pprint(data2)

pkl_file.close()
