Python Set pop() メソッド

Python 集合

説明

pop() メソッドは、集合からランダムな要素を1つ削除して返すために使用します。集合が空の場合は、KeyError 例外が発生します。

構文

pop() メソッドの構文：

set.pop()

パラメータ

  • 无

戻り値

削除された要素を返します。

例

ランダムに1つの要素を削除します：

例 1

fruits = {"apple", "banana", "cherry"} fruits.pop() print(fruits)

出力結果は次のとおりです：

{'apple', 'banana'}

戻り値の出力：

例 1

fruits = {"apple", "banana", "cherry"} x = fruits.pop() print(x)

出力結果は次のとおりです：

banana

注意事項

  • 集合の要素は順序付けられていないため、呼び出しのたびにpop()メソッドが実行されると、削除される要素はランダムです。
  • 特定の要素を削除する必要がある場合は、使用すべきはremove() 或 discard()メソッドであって、pop()。

    私が学習中に発見したのは、set 集合の pop() メソッドは、上記のようにただランダムに要素を削除するだけではなく、一定の規則性があるということです。発見した規則を以下にまとめます。

    # 执行下面的代码,并查看输出结果:
print('pop()函数的输出结果 看这里:')
s1={4,2,1,5} # 集合里只有数字
s2={'你','我','他'} # 集合里无数字
s3={3,2,4,'你','X'} # 集合里既有数字又有非数字
s1.pop() # 元素是数字时, 删除最小的数字, 其余数字升序排列
s2.pop() # 元素非数字时, 随机删除一个元素, 其余元素随机排序
s3.pop() # 元素既有数字又含非数字时, 如果删除的是数字, 则一定删最小的, 否则随机删除一个非数字元素
print(s1)
print(s2)
print(s3) # 这个代码执行后, 输出的结果是随机的

    以下は出力結果 1 です（数字以外の要素をランダムに削除した場合）:

    pop()函数的输出结果 看这里:
{2, 4, 5}
{'你', '我'}
{2, 3, 4, 'X'}

    以下は結果 2 です（削除されるのは数字ですが、最小の数字が削除され、残りの数字要素は昇順に並び、数字以外の要素はランダムに並びます）:

    pop()函数的输出结果 看这里:
{2, 4, 5}
{'我', '你'}
{3, 4, 'X', '你'}

    以下は結果 3 です（削除されるのは数字ですが、最小の数字が削除され、残りの数字要素は昇順に並び、数字以外の要素はランダムに並びます）:

    pop()函数的输出结果 看这里:
{2, 4, 5}
{'他', '你'}
{3, 4, '你', 'X'}

    まとめ:

    1、集合の要素がすべて数字の場合、削除時には最小の数字が削除され、残りの数字は昇順に並びます

    2、集合の要素が数字以外の場合、削除時にはランダムな要素が削除され、残りの要素はランダムに並びます

    3、集合に数字と数字以外の要素の両方がある場合、削除時は:

    • 削除されたのが数字の場合は、必ず最小のものが削除され、他の数字は昇順に並び、数字以外の要素はランダムに並びます。
    • 削除されたのが数字以外の場合は、必ずランダムに1つ削除され、他の数字は昇順に並び、数字以外はランダムに並びます。

    補足します。バージョンは 3.11.2 です：

    のset.pop()削除順序について、それがその集合がメモリ内に実際に保存されている順序と関係していることを発見しました。次のようなコードがあります：

    >>>d = {1,10,20,100,101,200}
>>>d
   {1,100,101,20,200,10}
>>>d.pop()
   1
>>>d.pop()
   100
>>>d.pop()
   101
>>>d.pop()
   20
>>>d.pop()
   200
>>>d.pop()
   10

    すると、set.pop() は毎回 set の最初の要素を削除することがわかります。しかし、d の内容の保存順序が 1、100、101、20、200、10 であるため、この順序に従って順番に削除されます。set の中に数字以外の要素しかない場合、ランダムなのは実際には集合内容の保存順序であり、代入のたびに内容の順序が変わりますが、pop は依然として左から右の順序で順番に削除するため、繰り返し代入すると削除結果が異なって見えます。

    >>>d = {'你','我','他'}
>>>d
   {'你','他','我'}
>>>d.pop()
   '你'
>>>d.pop()
   '他'
>>>d.pop()
   '我'
