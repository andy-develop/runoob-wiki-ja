    以下の考え方でループの回数を減らすことができます：

    1. 最小値が最大公約数である場合、直接返します；

    2. 最小値が最大公約数でない場合、最大公約数は最小値の1/2より大きくなりません；

    3. 最大公約数を求めるには、大きい方から小さい方へループして減少させながら最大値を求めるべきです。

    実例：

    def gcd(a, b):
    if b > a:
        a, b = b, a   # b为最小值
    if a % b == 0:
        return b      # 判断b是否为最大公约数
    for i in range(b//2+1, 1, -1):    # 倒序求最大公约数更合理
        if b % i == 0 and a % i == 0:
            return i
    return 0

while(True):
    a = int(input("Input 'a':"))
    b = int(input("Input 'b':"))
    print(gcd(a, b))

    2つの数の最大公約数はユークリッドの互除法を使って実装できます。すなわち、2つの数の最大公約数は、小さい方の数と、その2つの数を割った余りとの最大公約数に等しい。

    def gcd(a, b):
  if a == 0:
    a, b = b, a
  while b != 0:
    a, b = b, a % b
  return a

print(gcd(54, 24))

    ユークリッドの互除法を用いて2つの正の数の最大公約数を求めることができます。コードは次のとおりです：

    #!/usr/bin/python3
# -*- coding: UTF-8 -*-

# find the greatest common divisor of two integer

def find_GCD(x, y):
  find_GCD = y
  while (x % y) != 0:
    find_GCD = x % y
    x, y = y, find_GCD
  return find_GCD

int1 = int(input('Input 1st integer: '))
int2 = int(input('Input 2nd integer: '))

print('The greatest common divisor of {} and {} is {}'.format(int1, int2, find_GCD(int1, int2)))

    コードの実行結果は次のとおりです：

    Input 1st integer: 54
Input 2nd integer: 24
The greatest common divisor of 54 and 24 is 6

for i in num:
    ss.append(int(i))   #将输入的数字存入列表
for j in ss:

        if(j % m ==0):

for q in kk:
    if(kk.count(q)==len(ss)):
            ee.append(q)      #将所有的公约数存入列表
