Python3 イテレータとジェネレータ

イテレータ

イテレーションは Python の最も強力な機能の一つであり、コレクションの要素にアクセスする方法です。

イテレータは、走査位置を記憶できるオブジェクトです。

イテレータオブジェクトはコレクションの最初の要素からアクセスを開始し、すべての要素にアクセスし終えると終了します。イテレータは前方にのみ進み、後戻りはできません。

イテレータには2つの基本的なメソッドがあります：iter()とnext()。

文字列、リスト、タプルオブジェクトはすべて、イテレータの作成に使用できます：

例(Python 3.0+)

>>> list=[1,2,3,4]
>>> it = iter(list)    # イテレータオブジェクトを作成
>>> print (next(it))   # イテレータの次の要素を出力
1
>>> print (next(it))
2
>>>

イテレータオブジェクトは、通常の for 文を使用して走査できます：

例(Python 3.0+)

#!/usr/bin/python3 list=[1,2,3,4] it = iter(list) # イテレータオブジェクトを作成 for x in it: print (x, end=" ")

上記のプログラムを実行すると、出力結果は次のようになります：

1 2 3 4

next() 関数を使用することもできます：

例(Python 3.0+)

#!/usr/bin/python3 import sys # sys モジュールをインポート list=[1,2,3,4] it = iter(list) # イテレータオブジェクトを作成 while True: try: print (next(it)) except StopIteration: sys.exit()

上記のプログラムを実行すると、出力結果は次のようになります：

1
2
3
4

イテレータを作成する

クラスをイテレータとして使用するには、クラス内で __iter__() と __next__() の2つのメソッドを実装する必要があります。

すでにオブジェクト指向プログラミングを理解しているなら、クラスにはコンストラクタがあり、Python のコンストラクタは __init__() であり、オブジェクトの初期化時に実行されることを知っているでしょう。

詳細は次を参照してください：Python3 オブジェクト指向

__iter__() メソッドは特別なイテレータオブジェクトを返します。このイテレータオブジェクトは __next__() メソッドを実装し、StopIteration 例外によってイテレーションの完了を通知します。

__next__() メソッド（Python 2 では next()）は、次のイテレータオブジェクトを返します。

数値を返すイテレータを作成します。初期値は 1 で、1 ずつ増加します：

例(Python 3.0+)

class MyNumbers: def __iter__(self): self.a = 1 return self def __next__(self): x = self.a self.a += 1 return x myclass = MyNumbers() myiter = iter(myclass) print(next(myiter)) print(next(myiter)) print(next(myiter)) print(next(myiter)) print(next(myiter))

実行すると出力結果は次のようになります：

1
2

4

StopIteration

StopIteration 例外はイテレーションの完了を示すために使用され、無限ループを防ぎます。__next__() メソッド内で、指定した反復回数を完了した後に StopIteration 例外を発生させてイテレーションを終了するように設定できます。

20回の反復後に実行を停止します：

例(Python 3.0+)

class MyNumbers: def __iter__(self): self.a = 1 return self def __next__(self): if self.a <= 20: x = self.a self.a += 1 return x else: raise StopIteration myclass = MyNumbers() myiter = iter(myclass) for x in myiter: print(x)

ジェネレータ

Python では、yield を使用したyield関数はジェネレータ（generator）と呼ばれます。

yieldyield はキーワードであり、ジェネレータ関数を定義するために使用されます。ジェネレータ関数は特別な関数で、反復処理中に値を段階的に生成でき、すべての結果を一度に返すのではありません。

通常の関数とは異なり、ジェネレータはイテレータを返す関数であり、反復操作にのみ使用できます。より簡単に理解すると、ジェネレータはイテレータそのものです。

ジェネレータ関数内で yield 文をyield使用すると、関数の実行は一時停止し、yield のyield後ろの式が現在の反復の値として返されます。

次に、ジェネレータの next()next()メソッドまたは for ループをfor使用して反復すると、関数は前回中断した場所から再開し、再び yield 文にyield遭遇するまで実行を続けます。こうして、ジェネレータ関数は値を段階的に生成でき、すべての結果を一度に計算して返す必要はありません。

ジェネレータ関数を呼び出すと、返されるのはイテレータオブジェクトです。

以下は、ジェネレータ関数の使用例を示す簡単な例です：

例

def countdown(n): while n > 0: yield n n -= 1 # ジェネレータオブジェクトを作成 generator = countdown(5) # ジェネレータを反復して値を取得 print(next(generator)) # 出力: 5 print(next(generator)) # 出力: 4 print(next(generator)) # 出力: 3 # for ループを使用してジェネレータを反復 for value in generator: print(value) # 出力: 2 1

上記の例では、countdowncountdown 関数はジェネレータ関数です。yield 文を使用して、n から 1 までの逆順の数値を段階的に生成します。yield 文を呼び出すたびに、関数は現在の逆順の値を返し、次回の呼び出しでは前回中断した場所から実行を続けます。

ジェネレータオブジェクトを作成し、next() 関数または for ループを使用してジェネレータを反復することで、ジェネレータ関数が生成する値を段階的に取得できます。この例では、最初に next() 関数を使用して最初の3つの逆順の値を取得し、次に for ループで残りの2つの逆順の値を取得しています。

ジェネレータ関数の利点は、必要に応じて値を生成できるため、一度に大量のデータを生成して大量のメモリを消費することを避けられることです。さらに、ジェネレータは for ループなどの他の反復ツールとシームレスに連携でき、簡潔で効率的な反復方法を提供します。

上記のプログラムを実行すると、出力結果は次のようになります：

5
4
3
2
1

以下の例では、yield を使用してフィボナッチ数列を実装しています：

例(Python 3.0+)

#!/usr/bin/python3 import sys def fibonacci(n): # ジェネレータ関数 - フィボナッチ a, b, counter = 0, 1, 0 while True: if (counter > n): return yield a a, b = b, a + b counter += 1 f = fibonacci(10) # f はジェネレータによって返されるイテレータです while True: try: print (next(f), end=" ") except StopIteration: sys.exit()

上記のプログラムを実行すると、出力結果は次のようになります：

    どのような場合に yield を使用する必要がありますか？

    関数 f があり、f は list を返します。この list は動的に計算され（数学的な計算でも、論理的な読み取りやフォーマットでも）、かつその list は非常に大きくなります（固定で大きい場合も、入力パラメータの増加に伴って大きくなる場合もあります）。このような場合、毎回この関数を呼び出してイテレータでループするときに、完全な list を直接取得するのではなく、list の各要素を一つずつ取得してメモリを節約したいと思います。このときに yield が非常に役立ちます。

    yield の具体的な使い方はこちらを参照：Python yield の使用法の簡単な分析

    フィボナッチ関数を例にとると、通常は n から n 個の要素を持つ list を返したいとします：

    def fab(max): 
   n, a, b = 0, 0, 1 
   L = [] 
   while n < max: 
       L.append(b) 
       a, b = b, a + b 
       n = n + 1 
   return L

    上記の fab 関数はパラメータ max から max 個の要素を持つ list を返します。この max が非常に大きい場合、メモリを非常に消費します。

    通常、使用するときは次のような形です。例えば：

    f = iter(fab(1000))
while True:
    try:
        print (next(f), end=" ")
    except StopIteration:
        sys.exit()

    このようにすると、実際にはまず 1000 個の要素を持つ list f を生成してから、その f を使用しています。

    では、別の方法に変えてみましょう：

    実際に使用しているのは list の走査、つまり list のイテレータです。そこで、この関数 fab に、完全な list ではなく、毎回1つのイテレータ（1つの計算結果）だけを返させることができます：

    def fab(max): 
    n, a, b = 0, 0, 1 
    while n < max: 
        yield b 
        # print b 
        a, b = b, a + b 
        n = n + 1

    このようにすると、fab 関数を呼び出すたびに、例えば次のように：

    for x in fab(1000):
    print(x)

    または next 関数などを呼び出すと、実際の実行方式は、呼び出しのたびに yield の位置で中断して1つの結果を返し、再度呼び出されたときに中断を再開して実行を続けるというものです。

    カスタムイテレータを使用してフィボナッチ数列を実装する

    class Fibonacci:
  def __init__(self, count):
    self.count = count

  def __iter__(self):
    self.i = 0
    self.a, self.b = 0, 1
    return self

  def __next__(self):
  if self.i < self.count:
    self.i += 1
    a_old = self.a
    self.a, self.b = self.b, self.a + self.b
    return a_old
  else:
    raise StopIteration

for i in Fibonacci(10):
  print(i, end=" ")

    チュートリアルで述べられているように、イテレータとジェネレータは Python の大きな特徴であり、その核心はイテレータプロトコルに基づいています。

    そして、普段私たちがよく使用するfor inループ本体は、本質的にイテレータプロトコルの大きな応用の1つです。

    また、Python の組み込みコレクション型（文字列、リスト、タプル、辞書）はすべてイテレータプロトコルを実装しているため、for in 文を使用して反復処理ができます。for in ループ本体は StopIteration 例外に遭遇すると、反復と走査を終了します。

    次に、イテラブル（反復可能）、イテレータ、ジェネレータの3つの概念の関係と違いについて説明します。

    1、イテラブルの概念は範囲が最も広く、ジェネレータとイテレータは間違いなくイテラブルですが、イテラブルが必ずしもイテレータやジェネレータであるとは限りません。たとえば、上で述べた組み込みのコレクション型データ型です。Python では、コレクションの特性を持つものであれば、すべてイテラブルと考えることができます。

    2、イテレータの特徴は、for in と next を使用して1つずつ走査できることです。

    3、ジェネレータは必ずイテレータであり、必ずイテラブルでもあります。

    Python にイテレータとジェネレータを導入する理由は、メモリ空間を節約するだけでなく、コードの実行速度も大幅に向上させることができるからです。

    カスタムイテレータクラスの例と説明は次のとおりです：

    class MyIter():
  def __init__(self):
    #为了示例，用一个简单的列表作为需迭代的数据集合，并且私有化可视情况变为其他类型集合
    self.__list1=[1,2,3,4]
    self.__index=0

  def __iter__(self):
    #该魔法方法，必须返回一个迭代器对象，如果self已经定义了__next__()魔法方法，则只需要返回self即可
    #因为如上面所述，生成器一定是迭代器
    return iter(self.list1)    

  def __next__(self):
    #此处的魔法函数，python会自动记忆每次迭代的位置，无需再使用yield来处理
    #在使用next(obj)时，会自动调用该魔法方法
    res=self.__list1[self.__index]
    self.__index+=1
    return res

    以上がカスタムイテレータクラスの仕組みです。

    次に、ジェネレータ関数をカスタマイズする方法を例で説明します。実際の開発シーンの大半では、ジェネレータ関数を使用する方が多いかもしれません：

    def my_gene_func():
  index=0
  li=[1,2,3,4,5]
  yield li[index]
  index+=1

    上記の関数を呼び出すと、ジェネレータオブジェクトが返されます。その後、そのジェネレータオブジェクトに対して next() を使用して1つずつ返します：

    gene=my_gene_func()
next(gene)

    実際、中核となる概念は前回の反復位置を記憶することです。クラスでは __next__ マジックメソッドを直接使用して実装し、関数では yield を使用して実装します。また、クラスの __next__ マジックメソッドの内部実装も yield を使用しているのではないかと疑っています。

    イテレータとジェネレータの具体的な適用シーンとしては、実行効率の向上やメモリリソースの節約が必要で、かつ走査するデータがコレクション形式である場合、すべて検討できます。

    もう1つのニッチな使用シーンは、間接的にコルーチンの効果を実現することです。つまり、同じスレッド内で異なるタスクを交互に実行することです。

    def mytask1():
  print('task1 开始执行')
  '''
  task code
  '''
  yield

def mytask2():
  print('task2 开始执行')
  '''
  task code
  '''
  yield

gene1=mytask1()
gene2=mytask2()

for i in range(100):
  next(gene1)
  next(gene2)

    Python における yield の使い方は return とよく似ており、どちらも戻り値を提供します。しかし yield と return の最大の違いは、return は値を返すとコードブロックの実行が終了するのに対し、yield は値を返した後、CPU の使用権を譲り渡し、コードブロックは直接終了せず、その場で中断します。send() または next() メソッドを呼び出すと、yield は以前中断した場所から実行を継続できます。

    関数内で yield キーワードを使用すると、その関数はジェネレータになります。

    次にフィボナッチ数列を生成します。

    def fib(n):
    index = 0
    a = 0
    b = 1

    while index < n:
        yield b
        a,b = b, a+b
        index += 1

    ジェネレータオブジェクト：

    fib = fib(100)
print(fib)

    出力された結果はジェネレータオブジェクトであり、望んだ値が直接出力されるわけではありません。
