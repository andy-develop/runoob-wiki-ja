Python3 条件制御

Pythonプログラミングでは、ifif文は最も基本的かつ重要な条件制御構造です。条件の真偽に基づいて、特定のコードブロックを実行するかどうかを決定します。

Pythonのifif文は非常に直感的で読みやすく、インデントによってコードブロックを定義します。これはPythonが他の言語と異なる大きな特徴です。

単語の意味： if「もし」という意味で、条件判断の入り口です。

基本構文とパラメータ

ifif文は独立したコードブロックであり、条件式と組み合わせて使用する必要があります。

構文形式

if 条件表达式:
    代码块

構文の説明

  • 条件式: 任意のブール値を返す式（0以外、空でない文字列、空でないコンテナなどは真とみなされます）。
  • コロン: 条件式の後にはコロンを付けなければなりません。
  • インデント: コードブロックはインデント（通常はスペース4つ）する必要があります。インデントされたコードはif文のサブブロックに属します。

戻り値/効果

  • 戻り値なし: if文は制御フロー文であり、値を返しません。
  • 効果: 条件がTrueの場合、インデントされたコードブロックを実行し、それ以外の場合はスキップします。

例

簡単なものから複雑なものまでの一連の例を通して、完全にマスターしましょう。ifif文の使い方。

例1：基本の使い方 - 数字の大小を判定

例

# 基础 if 语句
age = 18

if age >= 18:
    print(成年人)

print(程序结束)

想定される実行結果:

大人
プログラム終了

コード解説:

  1. age >= 18これは条件式であり、Trueを返します。
  2. 条件が成立するため、実行します。print("成年人")。
  3. print("程序结束")if文のインデントブロック内にないため、条件に関係なく実行されます。

例2：文字列が空かどうかを判定

例

# 判断字符串
name = ""

# 文字列が空の場合は False
if name:
    print(f你好, {name})
else:
    print(请输入名字)

# 非空字符串
name = "Tom"
if name:
    print(f你好, {name})

想定される実行結果:

请输入名字
你好, Tom

コード解説:

  • Pythonでは、空文字列、空リスト、空辞書などは条件判定時にFalseとみなされます。
  • 空でない文字列はTrueとみなされます。

例3：複数条件の判定

例

# 复合条件判断
score = 85

# 使用逻辑运算符
if score >= 60 and score < 90:
    print(合格した)

# 判断多个条件（简化写法）
if 60 <= score < 90:  # Python 特有のチェーン比較
    print(成績は 60-90 の間)

# 使用 in 判断
colors = ["red", "green", "blue"]
if "red" in colors:
    print(包含红色)

想定される実行結果:

及格了
成绩在 60-90 之间
包含红色

コード解説:

  • Pythonはチェーン比較をサポートしています。例えば、60 <= score < 90。
  • inin演算子は、要素がシーケンス内に存在するかどうかを判定するために使用されます。

例4：1行のif式（三項演算子）

例

# Python の三項演算子
age = 20

# 格式：value1 if 条件 else value2
result = 成年 if age >= 18 else 未成年
print(result)  # 输出: 成年

# より複雑な例
x = 10
y = 20
max_val = x if x > y else y
print(f较大值: {max_val})  # 输出: 较大值: 20

想定される実行結果:

成年
较大值: 20

Pythonの三項式は従来の言語よりも簡潔で、書式は次のとおりです。value1 if condition else value2。
