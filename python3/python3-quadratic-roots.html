Python 二次方程式

Python3 例

二次方程式の形式は次のとおりです：ax2+bx+c=0。

その解は判別式を求めることでΔ=b2−4ac\Delta = b^2 - 4acΔ=b2−4ac決定されます：

  1. もしΔ>0\Delta > 0Δ>0の場合、方程式には2つの実数解があります。
  2. もしΔ=0\Delta = 0Δ=0の場合、方程式には1つの実数解（重解）があります。
  3. もしΔ<0\Delta < 0Δ<0の場合、方程式には実数解はありませんが、2つの複素数解があります。

以下の例は、ユーザーが数値を入力して二次方程式を計算するものです：

例（Python 3.0+）

import math
import cmath

def solve_quadratic(a, b, c):
    """
二次方程式 ax^2 + bx + c = 0 を解く
:param a: 二次の係数
:param b: 一次の係数
:param c: 定数項
:return: 方程式の解（実数または複素数の場合があります）
    """
    if a == 0:
        # 二次方程式以外の処理
        if b == 0:
            return "解なし" if c != 0 else "方程式には無限に多くの解があります"
        return f"方程式は一次方程式であり、解は x = {-c / b} です"
   
    # 判別式を計算
    delta = b**2 - 4*a*c
   
    if delta > 0:
        # 2つの実数解
        root1 = (-b + math.sqrt(delta)) / (2 * a)
        root2 = (-b - math.sqrt(delta)) / (2 * a)
        return f"方程式には2つの実数解があります：x1 = {root1}, x2 = {root2}"
    elif delta == 0:
        # 1つの実数解
        root = -b / (2 * a)
        return f"方程式には1つの重解（実数）があります：x = {root}"
    else:
        # 2つの複素数解
        root1 = (-b + cmath.sqrt(delta)) / (2 * a)
        root2 = (-b - cmath.sqrt(delta)) / (2 * a)
        return f"方程式には2つの複素数解があります：x1 = {root1}, x2 = {root2}"

# サンプル呼び出し
a, b, c = 1, -3, 2
result = solve_quadratic(a, b, c)
print(result)

    try:
        float(s)
        return True
    except ValueError:
        pass
    try:
        unicodedata.digit(s)    # digit 把一个合法的数字字符串转换为数字值
        return True
    except (TypeError, ValueError):
        pass
    return False

    b = float(b)
    c = float(c)
    if a == 0 and b == 0:
        print('不是方程式，不需要解！')
    elif a == 0 and b != 0:
        x = -c / b
        print('为一次方程式，x 结果为：%.2f'%(x))
    elif a != 0 and b == 0:
        d = -c / a
        if d >= 0:
            x = math.sqrt(d)
            print('为一次方程式，x 结果为：%.2f' % (x))
        else:
            print('警告：该方程式无解！！！')

        # 计算

            x1 = (-b - math.sqrt(d)) / (2 * a)
