Python3 File next() メソッド

Python3 File(ファイル) メソッド

概要

Python 3 の File オブジェクトは next() メソッドをサポートしていません。

Python 3 の組み込み関数 next() は、イテレータを介して __next__() メソッドを呼び出し、次の項目を返します。ループ内では、next() メソッドがループのたびに呼び出され、ファイルの次の行を返します。末尾（EOF）に達すると、トリガーが発生します。StopIteration

構文

next() メソッドの構文は次のとおりです：

next(iterator[,default])

パラメータ

  • 无

戻り値

ファイルの次の行を返します。

例

以下の例では、next() メソッドの使用方法を示しています：

ファイル runoob.txt の内容は次のとおりです：

これは1行目です
これは2行目です
これは3行目です
これは4行目です
これは5行目です

ループでファイルの内容を読み取ります：

#!/usr/bin/python3

# 打开文件
fo = open("runoob.txt", "r")
print ("文件名为: ", fo.name)

for index in range(5):
    line = next(fo)
    print ("第 %d 行 - %s" % (index, line))

# 关闭文件
fo.close()

上記の例の出力結果は次のとおりです：

文件名为:  runoob.txt
第 0 行 - 这是第一行

第 1 行 - 这是第二行

第 2 行 - 这是第三行

第 3 行 - 这是第四行

第 4 行 - 这是第五行
