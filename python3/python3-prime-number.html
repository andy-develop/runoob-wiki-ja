Python3 サンプル

1より大きい自然数で、1とその数自身以外には、他の自然数（素数）では割り切れない数（2、3、5、7など）。言い換えれば、その数は1とその数自身以外に他の約数を持たない。

# -*- coding: UTF-8 -*- # Filename : test.py # author by : www.runoob.com # ユーザーが入力した数字が素数であるかどうかを判定するPythonプログラム # ユーザーが数字を入力 num = int(input("数字を入力してください:")) # 素数は 1 より大きい if num > 1: # 約数を調べる for i in range(2,num): if (num % i) == 0: print(num,"素数ではありません") print(i,"かける",num//i,"である",num) break else: print(num,"素数です") # 入力された数字が 1 以下の場合、素数ではない else: print(num,"素数ではありません")

    原作者のアルゴリズムは基本的に正しいですが、時間計算量が高めです。大きな数が素数か合成数かを判断する場合、約数を調べるループで平方根を使用すべきです。コードは次のとおりです：

    # Python 程序用于检测用户输入的数字是质数还是合数
import math
# 用户输入数字
num = int(input("请输入一个数字: "))
# 质数大于 1
if num > 1:
    # 找到其平方根（ √ ），减少算法时间
    square_num = math.floor( num ** 0.5 )
    # 查找其因子
    for i in range(2, (square_num+1)): #将平凡根加1是为了能取到平方根那个值
        if (num % i) == 0:
            print(num, "是合数")
            print(i, "乘于", num // i, "是", num)
            break
    else:
        print(num, "是质数")
        # 如果输入的数字小于或等于 1，不是质数
else:
    print(num, "既不是质数，也不是合数")

    原理は平方根を使う方法です：

    ある数 N が合成数である場合、約数 a があり、a×b=N が成り立ちます。

    すると a、b の2つの数のうち、一方は √N 以上であり、もう一方は √N 以下です。

    したがって、√N 以下の数（1を除く）が N を割り切れないならば、N は必ず素数です。

    素数表を使って素数であるかどうかを判定する

    # -*- coding: UTF-8 -*-
# Python 程序用于检测用户输入的数字是否为质数
# 用户输入数字
num = int(input("请输入一个数字: "))
# 获取小于等于num平方根的质数表
def getPrimeList(n, oldPrimeList):
    for prime in oldPrimeList:
        if (n % prime) == 0:
            break
    if prime == oldPrimeList[-1]:
        oldPrimeList.append(n)
# 2,3是质数
if num == 2 or num == 3:
    print(num, "是质数")
# 对大于3的数用质数表来判断
elif num > 3:
    judge_num = int(num ** 0.5) + 1
    primeList = [2]
    for i in range(2, judge_num):
        getPrimeList(i, primeList)
    for i in primeList:
        if (num % i) == 0:
            print(num, "不是质数")
            break
    else:
        print(num, "是质数")
# 如果输入的数字小于或等于 1，不是质数
else:
    print(num, "不是质数")

    Python3 素数を計算する （エラトステネスの篩）

    # ls3[1:6:2] -- 起始位置为 2，终止位置为 6，步长为2 
def countPrimes(self, n: int) -> int:
        if n < 3:
            return 0     
        else:
            # 首先生成了一个全部为1的列表
            output = [1] * n
            # 因为0和1不是质数,所以列表的前两个位置赋值为0
            output[0],output[1] = 0,0
             # 此时从index = 2开始遍历,output[2]==1,即表明第一个质数为2,然后将2的倍数对应的索引
             # 全部赋值为0. 此时output[3] == 1,即表明下一个质数为3,同样划去3的倍数.以此类推.
            for i in range(2,int(n**0.5)+1): 
                if output[i] == 1:
                    output[i*i:n:i] = [0] * len(output[i*i:n:i])
         # 最后output中的数字1表明该位置上的索引数为质数,然后求和即可.
        return sum(output)

    平方根アルゴリズムとエラトステネスの篩を組み合わせて使おうとしましたが、コードがかなり複雑になります。よく考えると、倍数を走査して取り除く操作が、一つ一つ割り切れるか判定する操作に比べてそれほど時間を節約できないのであれば、直接平方根アルゴリズムを使ったほうがよいでしょう。

    hizmz のコードの原理に賛成です。コメントを補足しておきます。すごいですね。

    # 用平方根算法减少时间
import math
# 用户输入数字
num = int(input("请输入一个数字: "))
# 质数大于 1
if num > 1:
    #因为向上向下取整的函数对于整数来说都是自身，所以要想查找因子必须+1来包括自身
    #所以用的是向下取整函数，否则向上取整后比如平方根是5.2>>6>>7多算一个6
    pingfanggeng = math.floor( num ** 0.5 )
    # 查找其因子
    for i in range(2, pingfanggeng+1): #向下取整后需要加一来判断平方根位的因数，包括平方根
        if (num % i) == 0:
            print(num, "是合数")
            print(i, "乘于", num // i, "是", num)
            break
    else:
        print(num, "是质数")
        # 如果输入的数字小于或等于 1，那就不是质数
else:
    print(num, "既不是质数，也不是合数")
