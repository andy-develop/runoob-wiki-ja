Python リスト内の重複要素を削除

Python3 実例

Pythonでは、リスト内の重複要素を削除するために複数の方法を使用できます。一般的な方法には、setデータ構造、リスト内包表記、およびdict.fromkeys()メソッドがあります。以下では、これらの方法を使用してリスト内の重複要素を削除する方法を説明します。

実例

# 方法1: setを使用
original_list = [1, 2, 2, 3, 4, 4, 5]
unique_list = list(set(original_list))
print("方法1の結果:", unique_list)

# 方法2: リスト内包表記を使用
original_list = [1, 2, 2, 3, 4, 4, 5]
unique_list = []
[unique_list.append(x) for x in original_list if x not in unique_list]
print("方法2の結果:", unique_list)

# 方法3: dict.fromkeys()を使用
original_list = [1, 2, 2, 3, 4, 4, 5]
unique_list = list(dict.fromkeys(original_list))
print("方法3の結果:", unique_list)

コード解説：

  1. 方法1：使用set

    • setするsetはPythonのデータ構造であり、重複要素を許可しません。リストをsetに変換すると、重複要素を自動的に削除し、その後リストに変換し直すことができます。
    • list(set(original_list)) 将 original_listに変換してset、その後リストに変換し直します。

  2. 方法2: リスト内包表記を使用

    • リスト内包表記は、リストを簡潔に作成する方法です。私たちはoriginal_listを走査し、unique_listに含まれない要素をunique_listに追加します。
    • [unique_list.append(x) for x in original_list if x not in unique_list]このコード行はoriginal_listを走査し、重複しない要素をunique_listに追加します。

  3. 方法3：使用dict.fromkeys()

    • dict.fromkeys()するメソッドは辞書を作成します。辞書のキーは一意であるため、重複要素を削除できます。その後、辞書のキーをリストに変換し直します。
    • list(dict.fromkeys(original_list)) 将 original_list辞書のキーに変換してから、リストに変換し直します。

出力結果：

方法1结果: [1, 2, 3, 4, 5]
方法2结果: [1, 2, 3, 4, 5]
方法3结果: [1, 2, 3, 4, 5]

すべての方法でリスト内の重複要素を正常に削除し、元のリストの順序を保持しました（方法1を除きます。なぜならsetは順序を保証しないためです。）
