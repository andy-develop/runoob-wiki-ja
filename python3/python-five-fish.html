Python 五人での魚分け

Python3 例

A、B、C、D、E の5人は、ある夜に共同で魚を捕りに行き、翌朝の未明には皆疲れ果てて、それぞれ寝る場所を探しました。

日が高く昇り、A が最初に目を覚まし、魚を5つに分けて、余った1匹の魚を捨て、自分の分を持ち去りました。

B が2番目に目を覚まし、同じく魚を5つに分けて、余った1匹の魚を捨てて自分の分を持ち去りました。

C、D、E も順に目を覚まし、同じ方法で魚を取りました。

彼らは最低で何匹の魚を捕ったのでしょうか？

例

def main():
    fish = 1
    while True:
        total, enough = fish, True
        for _ in range(5):
            if (total - 1) % 5 == 0:
                total = (total - 1)  //  5 * 4
            else:
                enough = False
                break
        if enough:
            print(f'总共有{fish}条鱼')
            break
        fish += 1


if __name__ == '__main__':
    main()

実行結果：

总共有3121条鱼

    規則に基づいて1つの公式を導き出すことができます：

    # n个人总共捕鱼数量为：S = Kn^n-(n-1) K为正整数
# 最后一个人分得鱼的数量为：S(n) = K(n-1)^(n-1)-1 K为正整数

# 至少捕鱼数（即K为1）
def min_fish(n):
    return n ** n - (n - 1)

if __name__ == '__main__':
    n = int(input('请输入人数:'))
    print('至少捕了{0}条鱼'.format(min_fish(n)))
