Python print() 関数

Python3 組み込み関数

print()Python で情報を出力するために使用される組み込み関数です。

print()Python プログラミングで最もよく使われる関数の一つで、コンテンツを標準出力（通常はコンソール）に出力します。さまざまな型のデータを出力でき、豊富なフォーマットオプションをサポートしています。

単語の意味： print 意为"打印"，用于输出信息。

基本構文とパラメータ

構文形式

print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)

パラメータの説明

  • パラメータ objects：
    • 型： 任意のオブジェクト
    • 説明： 出力するオブジェクト。複数指定でき、カンマで区切ります。
  • パラメータ sep（オプション）：
    • 型： 文字列
    • 説明： 複数のオブジェクトを出力する際の区切り文字。デフォルトはスペースです。
  • パラメータ end（オプション）：
    • 型： 文字列
    • 説明： 出力終了時の文字。デフォルトは改行文字です。
  • パラメータ file（オプション）：
    • 型： ファイルオブジェクト
    • 説明： 出力先。デフォルトは標準出力です。
  • パラメータ flush（オプション）：
    • 型： ブール値
    • 説明： 出力をすぐにフラッシュするかどうか。デフォルトは False です。

関数の説明

  • 戻り値： 戻り値なし。

例

例 1：基本の使い方

例

# 文字列を出力
print("Hello, World!")

# 数値を出力
print(42)
print(3.14159)

# 複数のオブジェクトを出力（カンマで区切る）
print("My name is", "Tom")
# 出力: My name is Tom

# 変数を出力
name = "Alice"
age = 25
print(name, "is", age, "years old")
# 出力: Alice is 25 years old

実行結果の想定:

Hello, World!
42
3.14159
My name is Tom
Alice is 25 years old

コードの解説:

  1. 文字列、数値、変数など、さまざまなオブジェクトを出力できます。
  2. 複数のオブジェクトはカンマで区切り、出力時にはスペースで区切られます。

例 2：sep と end パラメータ

例

# sep を使用して区切り文字をカスタマイズ
print("a", "b", "c", sep="-")  # 出力: a-b-c
print("1", "2", "3", sep=" -> ")  # 出力: 1 -> 2 -> 3

# end を使用して終了文字をカスタマイズ
print("Hello", end=" ")
print("World")  # 出力: Hello World（改行なし）

# 改行せずに区切りをカスタマイズ
for i in range(5):
    print(i, end=" ")
# 出力: 0 1 2 3 4

実行結果の想定:

a-b-c
1 -> 2 -> 3
Hello World
0 1 2 3 4

コードの解説:

  • sepオブジェクト間の区切り文字を制御します。
  • end出力の終了文字を制御します。

例 3：ファイルへの出力

例

# ファイルに出力
with open("output.txt", "w") as f:
    print("Hello, File!", file=f)

# 読み出して確認
with open("output.txt", "r") as f:
    print(f.read())  # 出力: Hello, File!

# 標準エラーに出力
import sys
print("エラーメッセージ", file=sys.stderr)

# 出力をすぐにフラッシュ
print("読み込み中", end="", flush=True)
import time
time.sleep(1)
print(完了!)

実行結果の想定:

コンテンツをファイルまたは標準エラーストリームに出力できます。
