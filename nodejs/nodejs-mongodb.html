Node.js で MongoDB に接続

MongoDBは、C++で書かれたドキュメント指向データベース管理システムです。

この章では、Node.js を使用して MongoDB に接続し、データベースを操作する方法を紹介します。

MongoDB の基礎知識がない場合は、次のチュートリアルを参照してください：MongoDB チュートリアル。

ドライバーのインストール

本チュートリアルでは淘宝がカスタマイズした cnpm コマンドを使用してインストールします：

$ cnpm install mongodb

インストールが成功すると、MongoClient オブジェクトを使用してデータベースに接続できます：

例

const { MongoClient } = require('mongodb');

async function main() {
    // MongoDB 接続 URI
    const uri = "mongodb://localhost:27017"; // リモートの MongoDB を使用している場合は、URI を適宜変更してください

    // 新しい MongoClient を作成
    const client = new MongoClient(uri, { useNewUrlParser: true, useUnifiedTopology: true });

    try {
        // MongoDB サーバーに接続
        await client.connect();

        console.log("Connected successfully to server");

     
    } finally {
        // 完了後に接続を閉じることを確認
        await client.close();
    }
}

main().catch(console.error);

上記のコードを実行すると、出力結果は次のようになります：

Connected successfully to server

接続パラメータの説明：

  • MongoClient：これは MongoDB のクライアントで、データベースに接続するために使用します。
  • uri：これは MongoDB の接続文字列で、形式は次のとおりです。mongodb://[username:password@]host1[:port1][,...hostN[:portN]][/[defaultauthdb][?options]]。
  • useNewUrlParserとuseUnifiedTopologyは、いくつかの古い接続動作を避けるためのオプションです。

次に、追加・削除・更新・検索（CRUD）機能を実装します。

データベースの作成

MongoDB にデータベースを作成するには、まず MongoClient オブジェクトを作成し、指定した URL とポート番号を設定する必要があります。

データベースが存在しない場合、MongoDB はデータベースを作成し、接続を確立します。

接続の作成

const { MongoClient } = require('mongodb'); async function main() { //MongoDB 接続 URI const uri = "mongodb://localhost:27017"; //MongoDB サーバーのアドレスに応じて変更してください //新しい MongoClient を作成 const client = new MongoClient(uri, { useNewUrlParser: true, useUnifiedTopology: true }); try { //MongoDB サーバーに接続 await client.connect(); console.log("サーバーへの接続に成功"); //データベースを指定 const database = client.db('runoob'); //ここでは、コレクションの作成やドキュメントの挿入などのデータベース操作を実行できます const collection = database.collection('exampleCollection'); const doc = { name: "Example", type: "Test" }; const result = await collection.insertOne(doc); console.log(`新しいドキュメントが作成されました。IDID は: ${result.insertedId}`); } finally { //完了後に接続を閉じるようにしてください await client.close(); } } main().catch(console.error);

上記のコードを実行すると、出力結果は次のようになります：

成功连接到服务器
新文档已创建，ID 为: 6678e18e0bb3f4247be610d8

データのクエリ

find() を使用してデータを検索できます。find() は一致する条件のすべてのデータを返します。 条件を指定しない場合、find() はコレクション内のすべてのデータを返します。

find()

const { MongoClient } = require('mongodb'); async function main() { //MongoDB 接続 URI const uri = "mongodb://localhost:27017"; //MongoDB サーバーのアドレスに応じて変更してください //新しい MongoClient を作成 const client = new MongoClient(uri, { useNewUrlParser: true, useUnifiedTopology: true }); try { //MongoDB サーバーに接続 await client.connect(); console.log("サーバーへの接続に成功"); //データベースを指定 const database = client.db('runoob'); //createCollection メソッドを使用してコレクションを作成 const collectionName = 'exampleCollection'; await database.createCollection(collectionName); console.log(`コレクション ${collectionName}作成成功`); //コレクションを取得 const collection = database.collection(collectionName); //複数の新しいドキュメントを作成 const docs = [ { name: "Alice", age: 25, address: "Wonderland" }, { name: "Bob", age: 30, address: "Builderland" }, { name: "Charlie", age: 35, address: "Chocolate Factory" } ]; //複数のドキュメントをコレクションに挿入 const result = await collection.insertMany(docs); console.log(`${result.insertedCount}件の新しいドキュメントが作成されました。IDID は:`); Object.keys(result.insertedIds).forEach((id, index) => { console.log(`ドキュメント ${index + 1}: ${id}`); }); //コレクション内のすべてのドキュメントをクエリ const query = {}; //空のクエリオブジェクトは、すべてのドキュメントをクエリすることを意味します const options = { projection: { _id: 0, name: 1, age: 1, address: 1 } }; //必要なフィールドのみを選択 const cursor = collection.find(query, options); //クエリされたすべてのドキュメントを出力 const allValues = await cursor.toArray(); console.log("クエリされたドキュメント:"); console.log(allValues); } finally { //完了後に接続を閉じるようにしてください await client.close(); } } main().catch(console.error);

const { MongoClient } = require('mongodb'); async function main() { //MongoDB 接続 URI const uri = "mongodb://localhost:27017"; //お使いの MongoDB サーバーのアドレスに合わせて変更してください //新しい MongoClient を作成します const client = new MongoClient(uri, { useNewUrlParser: true, useUnifiedTopology: true }); try { //MongoDB サーバーに接続します await client.connect(); console.log("サーバーへの接続に成功しました"); //データベースを指定します const database = client.db('runoob'); //createCollection メソッドを使用してコレクションを作成します const collectionName = 'exampleCollection'; await database.createCollection(collectionName); console.log(`コレクション ${collectionName}作成に成功しました`); //コレクションを取得します const collection = database.collection(collectionName); //複数の新しいドキュメントを作成します const docs = [ { name: "Alice", age: 25, address: "Wonderland" }, { name: "Bob", age: 30, address: "Builderland" }, { name: "Charlie", age: 35, address: "Chocolate Factory" } ]; //複数のドキュメントをコレクションに挿入します const result = await collection.insertMany(docs); console.log(`${result.insertedCount}件の新しいドキュメントが作成されました、ID次のとおりです:`); Object.keys(result.insertedIds).forEach((id, index) => { console.log(`ドキュメント ${index + 1}: ${id}`); }); //条件を指定して、name パラメータに基づいてデータを更新します const filter = { name: "Alice" }; //検索条件 const updateDoc = { $set: { age: 28, address: "New Wonderland" }, }; const updateResult = await collection.updateOne(filter, updateDoc); console.log(`${updateResult.matchedCount}件のドキュメントがフィルター条件に一致しました`); console.log(`${updateResult.modifiedCount}件のドキュメントが更新されました`); //更新されたドキュメントをクエリします const updatedDocument = await collection.findOne(filter); console.log("更新されたドキュメント:"); console.log(updatedDocument); } finally { //完了後、必ず接続を閉じてください await client.close(); } } main().catch(console.error);

接続操作

mongoDB はリレーショナルデータベースではありませんが、私たちは使用できます$lookupを使用して左結合を実装できます。

$lookup は、MongoDB で左外部結合（left outer join）を実行するための集約パイプライン演算子です。あるコレクション内で、別のコレクションの条件に一致するドキュメントを検索し、それらを結合するために使用できます。

例えば、次の2つのコレクションデータがあるとします：

コレクション1：orders

[
  { "_id": 1, "product_id": 101, "quantity": 2 },
  { "_id": 2, "product_id": 102, "quantity": 1 },
  { "_id": 3, "product_id": 103, "quantity": 4 }
]

コレクション2：products

[
  { "_id": 101, "name": "Product A", "price": 50 },
  { "_id": 102, "name": "Product B", "price": 70 },
  { "_id": 103, "name": "Product C", "price": 100 },
  { "_id": 104, "name": "Product D", "price": 120 }
]

ここで、$lookup 操作を使用して orders コレクションの product_id フィールドと products コレクションの _id フィールドを関連付け、各注文の製品詳細情報を取得したいとします。

以下は、この機能を実装するための MongoDB 集約の例です：

例

const { MongoClient } = require('mongodb'); async function main() { //MongoDB 接続 URI const uri = "mongodb://localhost:27017"; //MongoDB サーバーのアドレスに応じて変更してください //新しい MongoClient を作成します const client = new MongoClient(uri, { useNewUrlParser: true, useUnifiedTopology: true }); try { //MongoDB サーバーに接続します await client.connect(); console.log("サーバーへの接続に成功しました"); //データベースを指定します const database = client.db('mydatabase'); //orders コレクション const ordersCollection = database.collection('orders'); //products コレクション const productsCollection = database.collection('products'); //集約パイプラインを定義し、$lookup を使用して左外部結合を実行します const pipeline = [ { $lookup: { from: 'products', //関連付けるコレクション名 localField: 'product_id', //ローカルコレクション内で関連付けに使用するフィールド foreignField: '_id', //関連付けるコレクション内で関連付けに使用するフィールド as: 'productDetails' //出力結果に含めるフィールド名 } } ]; //集約操作を実行します const result = await ordersCollection.aggregate(pipeline).toArray(); //クエリ結果を出力します console.log("左外部結合のクエリ結果："); console.log(result); } finally { //完了後に接続を閉じることを確認します await client.close(); } } main().catch(console.error);
