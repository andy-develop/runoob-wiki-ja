SVG シャドウ

<feOffset>

<feOffset>これは SVG フィルター内の要素の 1 つで、画像上にオフセット効果を作成します。シャドウ、輪郭、その他の視覚効果を作成するために使用できます。その機能は、入力画像の各ピクセルを指定した水平方向と垂直方向に一定距離移動させ、その結果の画像をフィルター効果の出力とすることです。

基本構文

<feOffset dx="x-offset" dy="y-offset" />

  • dx属性は、シャドウの水平方向のオフセット量を定義します。

  • dy属性は、シャドウの垂直方向のオフセット量を定義します。

次のコードはオフセットフィルターを定義し、それを赤色で塗りつぶした矩形に適用します。これにより、矩形はオフセット効果を持つシャドウを表示し、シャドウは水平方向と垂直方向にそれぞれ 5 ピクセルずつオフセットされます。

例

<svg width="200" height="200" xmlns="http://www.w3.org/2000/svg">
  <!-- オフセットフィルターを定義 -->
  <filter id="offset_filter">
    <feOffset dx="5" dy="5" />
  </filter>
 
  <!-- オフセットフィルターを適用した矩形 -->
  <rect x="50" y="50" width="100" height="80" fill="red" filter="url(#offset_filter)" />
</svg>

<feDropShadow>

SVG シャドウ効果は、<feDropShadow>要素を使用して実現できます。これは SVG グラフィック要素にシャドウ効果を追加でき、より立体的でリアルに見せることができます。

基本構文

<feDropShadow dx="offset-x" dy="offset-y" stdDeviation="blur-radius" flood-color="color" flood-opacity="opacity" />

  • dx属性は、シャドウの水平方向のオフセット量を定義します。

  • dy属性は、シャドウの垂直方向のオフセット量を定義します。

  • stdDeviation属性は、シャドウのぼかし半径を定義します。通常、シャドウのぼかし具合を制御するために使用されます。

  • flood-color属性は、シャドウの色を定義します。デフォルトは黒です。

  • flood-opacity属性は、シャドウの不透明度を定義します。デフォルトは 1（完全に不透明）です。

次のコードはシャドウフィルターを定義し、それを赤色で塗りつぶした矩形に適用します。矩形に灰色のシャドウが付いた効果を表示し、シャドウは水平方向と垂直方向にそれぞれ 5 ピクセルずつオフセットされ、ぼかし半径は 5 ピクセル、色は灰色、不透明度は 0.5 です。

例

<svg width="200" height="200" xmlns="http://www.w3.org/2000/svg">
  <!-- シャドウフィルターを定義 -->
  <filter id="shadow_filter">
    <feDropShadow dx="5" dy="5" stdDeviation="5" flood-color="gray" flood-opacity="0.5" />
  </filter>
 
  <!-- シャドウフィルターを適用した矩形 -->
  <rect x="50" y="50" width="100" height="80" fill="red" filter="url(#shadow_filter)" />
</svg>

例1

`<feOffset>` 要素はシャドウ効果を作成するために使用されます。概念としては、SVG グラフィック（画像または要素）を取り、それを xy 平面上で少し移動させることです。

最初の例では、矩形をオフセットし（`<feOffset>` を使用）、次にオフセットした画像を上部にブレンドします（`<feBlend>` を使用）：

以下は SVG コードです：

例

<svg xmlns="http://www.w3.org/2000/svg" version="1.1">
  <defs>
    <filter id="f1" x="0" y="0" width="200%" height="200%">
      <feOffset result="offOut" in="SourceGraphic" dx="20" dy="20" />
      <feBlend in="SourceGraphic" in2="offOut" mode="normal" />
    </filter>
  </defs>
  <rect width="90" height="90" stroke="green" stroke-width="3"
  fill="yellow" filter="url(#f1)" />
</svg>

試してみる »

クリックして表示：SVG ファイルを表示。

コードの解説：

  • `<filter>` 要素の id 属性は、フィルターの一意の名前を定義します。
  • `<rect>` 要素のフィルター属性は、要素を "f1" フィルターにリンクするために使用します。

例2

次に、オフセットした画像をぼかします（`<feGaussianBlur>` を使用）：

以下は SVG コードです：

例

<svg xmlns="http://www.w3.org/2000/svg" version="1.1">
  <defs>
    <filter id="f1" x="0" y="0" width="200%" height="200%">
      <feOffset result="offOut" in="SourceGraphic" dx="20" dy="20" />
      <feGaussianBlur result="blurOut" in="offOut" stdDeviation="10" />
      <feBlend in="SourceGraphic" in2="blurOut" mode="normal" />
    </filter>
  </defs>
  <rect width="90" height="90" stroke="green" stroke-width="3"
  fill="yellow" filter="url(#f1)" />
</svg>

コードの解説：

  • `<feGaussianBlur>` 要素の stdDeviation 属性は、ぼかし量を定義します。

例3

次に、黒いシャドウを作成します：

以下は SVG コードです：

例

<svg xmlns="http://www.w3.org/2000/svg" version="1.1">
  <defs>
    <filter id="f1" x="0" y="0" width="200%" height="200%">
      <feOffset result="offOut" in="SourceAlpha" dx="20" dy="20" />
      <feGaussianBlur result="blurOut" in="offOut" stdDeviation="10" />
      <feBlend in="SourceGraphic" in2="blurOut" mode="normal" />
    </filter>
  </defs>
  <rect width="90" height="90" stroke="green" stroke-width="3"
  fill="yellow" filter="url(#f1)" />
</svg>

試してみる »

クリックして表示：SVG ファイルを表示。

コードの解説：

  • `<feOffset>` 要素の属性を "SourceAlpha" に変更すると、RGBA ピクセル全体ではなく Alpha チャンネルの残像を使用します。

例4

次に、シャドウに色を付けます：

以下は SVG コードです：

例

<svg xmlns="http://www.w3.org/2000/svg" version="1.1">
  <defs>
    <filter id="f1" x="0" y="0" width="200%" height="200%">
      <feOffset result="offOut" in="SourceGraphic" dx="20" dy="20" />
      <feColorMatrix result="matrixOut" in="offOut" type="matrix"
      values="0.2 0 0 0 0 0 0.2 0 0 0 0 0 0.2 0 0 0 0 0 1 0" />
      <feGaussianBlur result="blurOut" in="matrixOut" stdDeviation="10" />
      <feBlend in="SourceGraphic" in2="blurOut" mode="normal" />
    </filter>
  </defs>
  <rect width="90" height="90" stroke="green" stroke-width="3"
  fill="yellow" filter="url(#f1)" />
</svg>

試してみる »

クリックして表示：SVG ファイルを表示。

コードの解説：

  • `<feColorMatrix>` フィルターは、オフセットした画像を黒に近い色に変換するために使用されます。「0.2」行列の 3 つの値は、それぞれ赤、緑、青のチャンネルに乗算されます。値を下げると、色は黒（黒は 0）になります。

注意事項

  • <feOffset>要素は、ぼかし、カラーマトリックスなど、他のフィルター効果と組み合わせて使用できます。

  • オフセット効果のオフセット量dxとdy正の値（右または下へのオフセットを表す）または負の値（左または上へのオフセットを表す）にすることができます。

  • <feOffset>要素は通常、シャドウ効果の作成に使用され、他のフィルター効果と組み合わせることで、より複雑な視覚効果を実現できます。

を使用することにより、<feOffset>要素を使用すると、SVG グラフィック要素にオフセット効果を作成でき、より生き生きとして立体的な外観にすることができます。
