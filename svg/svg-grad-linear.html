SVG グラデーション

グラデーションは、ある色から別の色への滑らかな遷移です。また、複数の色の遷移を同じ要素に適用することもできます。

SVG グラデーションには主に2つのタイプがあります：

  • 線形グラデーション - <linearGradient>
  • 放射状グラデーション - <radialGradient>

SVG 線形グラデーション - <linearGradient>

SVG 内の<linearGradient><linearGradient> 要素は線形グラデーションを作成するために使用され、直線に沿ってある色から別の色へ遷移することで、滑らかなグラデーション効果を作成します。

線形グラデーションは、SVG グラフィック要素の塗りつぶしやストロークに使用でき、豊かな色の変化をもたらします。

基本構文

<linearGradient id="gradient_id" x1="x1" y1="y1" x2="x2" y2="y2">
  <stop offset="offset1" stop-color="color1" />
  <stop offset="offset2" stop-color="color2" />
  <!-- 更多的 <stop> 元素 -->
</linearGradient>

パラメータの説明：

  • id属性は線形グラデーションの一意の識別子を定義し、SVG 画像内でそのグラデーションを参照するために使用されます。

  • x1 和 y1属性はグラデーションの開始点の座標を定義します。

  • x2 和 y2属性はグラデーションの終了点の座標を定義します。

  • <stop>要素は、グラデーション内の色と色の位置を指定するために使用されます。

線形グラデーションは、水平、垂直、または斜めのグラデーションとして定義できます。

  • y1 と y2 が等しく、x1 と x2 が異なる場合、水平グラデーションを作成できます。
  • x1 と x2 が等しく、y1 と y2 が異なる場合、垂直グラデーションを作成できます。
  • x1 と x2 が異なり、かつ y1 と y2 も異なる場合、斜めグラデーションを作成できます。

次のコードは、赤から青への水平線形グラデーションを定義し、それを塗りつぶした長方形に適用して、長方形にグラデーションの塗りつぶし効果を表示させます。

例

<svg width="200" height="200" xmlns="http://www.w3.org/2000/svg">
  <!-- 線形グラデーションを定義 -->
  <linearGradient id="gradient" x1="0%" y1="0%" x2="100%" y2="0%">
    <stop offset="0%" stop-color="red" />
    <stop offset="100%" stop-color="blue" />
  </linearGradient>
 
  <!-- 線形グラデーションを適用した長方形 -->
  <rect x="50" y="50" width="100" height="80" fill="url(#gradient)" />
</svg>

例 1

黄色から赤への水平線形グラデーションを持つ楕円を定義：

以下は SVG コードです：

例

<svg xmlns="http://www.w3.org/2000/svg" version="1.1"> <defs> <linearGradient id="grad1" x1="0%" y1="0%" x2="100%" y2="0%"> <stop offset="0%" style="stop-color:rgb(255,255,0);stop-opacity:1" /> <stop offset="100%" style="stop-color:rgb(255,0,0);stop-opacity:1" /> </linearGradient> </defs> <ellipse cx="200" cy="70" rx="85" ry="55" fill="url(#grad1)" /> </svg>

試してみる »

クリックして表示：SVG ファイルを表示。

コードの解説：

  • <linearGradient> タグの id 属性は、グラデーションに一意の名前を定義できます。
  • <linearGradient> タグの X1、X2、Y1、Y2 属性は、グラデーションの開始位置と終了位置を定義します。
  • グラデーションの色の範囲は、2つ以上の色で構成できます。各色は <stop> タグで指定します。offset 属性は、グラデーションの開始位置と終了位置を定義するために使用されます。
  • 塗りつぶし属性は ellipse 要素をこのグラデーションにリンクします。

例 3

楕円を定義し、黄色から赤への水平線形グラデーションを設定し、楕円内にテキストを追加します：

以下は SVG コードです：

例

<svg xmlns="http://www.w3.org/2000/svg" version="1.1"> <defs> <linearGradient id="grad1" x1="0%" y1="0%" x2="100%" y2="0%"> <stop offset="0%" style="stop-color:rgb(255,255,0);stop-opacity:1" /> <stop offset="100%" style="stop-color:rgb(255,0,0);stop-opacity:1" /> </linearGradient> </defs> <ellipse cx="200" cy="70" rx="85" ry="55" fill="url(#grad1)" /> <text fill="#ffffff" font-size="45" font-family="Verdana" x="150" y="86"> SVG</text> </svg>

試してみる »

クリックして表示：SVG ファイルを表示。

コードの解説：

  • <text> 要素はテキストを追加するために使用されます。

注意事項

  • グラデーションには複数の<stop>要素を含めることができ、各<stop>要素はグラデーション内の色と位置を表します。

  • グラデーションの開始点と終了点は任意の位置に配置でき、グラデーションは定義された開始点と終了点の間の直線に沿って補間されます。

  • グラデーションの座標値にはパーセンテージまたは具体的な長さの値を使用でき、パーセンテージ値はグラフィック要素のサイズに対する相対値です。

  • 線形グラデーションは、SVG グラフィック要素の塗りつぶしまたはストロークに適用できます。
