SVG リファレンスマニュアル

SVG 仕様には、さらに多くの要素と属性が定義されています。

一般的な SVG 属性：

  • id: 要素の一意の識別子。
  • class: 要素のクラス名。CSS スタイルに使用します。
  • style: 要素のインラインスタイル。
  • transform: 要素に適用される変換。
  • x, y: 要素の位置。
  • width, height: 要素のサイズ。
  • fill: 塗りつぶしの色。
  • stroke: ストロークの色。
  • stroke-width: ストロークの幅。
  • opacity: 不透明度。
  • visibility: 要素の可視性。
