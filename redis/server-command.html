Redis Command コマンド

Redis サーバー

Redis Command コマンドは、すべてのRedisコマンドの詳細情報を配列形式で返すために使用されます。

構文

redis Command コマンドの基本構文は次のとおりです：

redis 127.0.0.1:6379> COMMAND

利用可能なバージョン

>= 2.8.13

戻り値
