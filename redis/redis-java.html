JavaでRedisを使用

インストール

JavaでRedisを使用し始める前に、RedisサービスとJava Redisドライバーがインストールされていること、およびお使いのマシンでJavaが正常に使用できることを確認する必要があります。Javaのインストール設定については、当サイトのJava開発環境の設定次に、Java Redisドライバーをインストールしましょう。

  • まず、ドライバーパッケージをダウンロードする必要があります。jedis.jarをダウンロード最新のドライバーパッケージをダウンロードしてください。
  • このドライバーパッケージをクラスパスに含めてください。

当サイトでは2.9.0のjarバージョンのダウンロードを提供しています：jedis-2.9.0.jar

Redisサービスに接続する

例

import redis.clients.jedis.Jedis; public class RedisJava { public static void main(String[] args) { //ローカルのRedisサービスに接続 Jedis jedis = new Jedis("localhost"); //Redisサービスにパスワードが設定されている場合は次の行が必要です。設定されていない場合は不要です。 // jedis.auth("123456"); System.out.println("接続成功"); //サービスが実行されているか確認 System.out.println("サービスは実行中："+jedis.ping()); } }

上記のJavaプログラムをコンパイルし、ドライバーパッケージのパスが正しいことを確認してください。

服务正在运行: PONG

Redis Java String(文字列) 例

例

import redis.clients.jedis.Jedis; public class RedisStringJava { public static void main(String[] args) { //ローカルのRedisサービスに接続 Jedis jedis = new Jedis("localhost"); System.out.println("接続成功"); //Redisの文字列データを設定 jedis.set("runoobkey", "www.runoob.com"); //保存されたデータを取得して出力 System.out.println("Redisに保存された文字列："+ jedis.get("runoobkey")); } }

上記のプログラムをコンパイルしてください。

连接成功
redis 存储的字符串为: www.runoob.com

Redis Java List(リスト) 例

例

import java.util.List; import redis.clients.jedis.Jedis; public class RedisListJava { public static void main(String[] args) { //ローカルのRedisサービスに接続 Jedis jedis = new Jedis("localhost"); System.out.println("接続成功"); //リストにデータを保存 jedis.lpush("site-list", "Runoob"); jedis.lpush("site-list", "Google"); jedis.lpush("site-list", "Taobao"); //保存されたデータを取得して出力 List<String> list = jedis.lrange("site-list", 0 ,2); for(int i=0; i<list.size(); i++) { System.out.println("リスト項目："+list.get(i)); } } }

上記のプログラムをコンパイルしてください。

连接成功
列表项为: Taobao
列表项为: Google
列表项为: Runoob

例

import java.util.Iterator; import java.util.Set; import redis.clients.jedis.Jedis; public class RedisKeyJava { public static void main(String[] args) { //ローカルのRedisサービスに接続 Jedis jedis = new Jedis("localhost"); System.out.println("接続成功"); //データを取得して出力 Set<String> keys = jedis.keys("*"); Iterator<String> it=keys.iterator() ; while(it.hasNext()){ String key = it.next(); System.out.println(key); } } }

    private static boolean TEST_ON_BORROW = true;

    private static JedisPool jedisPool = null;
    //数据库模式是16个数据库 0~15 
    public static final int DEFAULT_DATABASE = 0;
    /**
     * 初始化Redis连接池
     */

    static {

        try {

            JedisPoolConfig config = new JedisPoolConfig();
            config.setMaxTotal(MAX_ACTIVE);
            config.setMaxIdle(MAX_IDLE);
            config.setMaxWaitMillis(MAX_WAIT);
            config.setTestOnBorrow(TEST_ON_BORROW);
            jedisPool = new JedisPool(config, ADDR, PORT, TIMEOUT,AUTH,DEFAULT_DATABASE);

        } catch (Exception e) {

            e.printStackTrace();
        }

    }

    /**
     * 获取Jedis实例
     */

    public synchronized static Jedis getJedis() {

        try {

            if (jedisPool != null) {
                Jedis resource = jedisPool.getResource();
                System.out.println("redis--服务正在运行: "+resource.ping());
                return resource;
            } else {
                return null;
            }

        } catch (Exception e) {
            e.printStackTrace();
            return null;
        }

    }

    /***
     * 
     * 释放资源
     */
    
    public static void returnResource(final Jedis jedis) {
            if(jedis != null) {
                jedisPool.returnResource(jedis);
            }
        
    }
}

    Exception in thread "main" redis.clients.jedis.exceptions.JedisDataException: NOAUTH Authentication required.
at redis.clients.jedis.Protocol.processError(Protocol.java:127)
at redis.clients.jedis.Protocol.process(Protocol.java:161)
at redis.clients.jedis.Protocol.read(Protocol.java:215)
at redis.clients.jedis.Connection.readProtocolWithCheckingBroken(Connection.java:340)
at redis.clients.jedis.Connection.getStatusCodeReply(Connection.java:239)
at redis.clients.jedis.BinaryJedis.ping(BinaryJedis.java:196)
at com.RedisJava.main(RedisJava.java:10)

    これは、Redisにパスワード認証が設定されているのに、パスワード認証が行われていないために発生する例外です。パスワード認証を設定します：

    CONFIG set requirepass "runoob"

    対処方法1：ソースコードにコードを追加します：

    jedis.auth("runoob");//此处为你设置的密码

    対処方法2：パスワード認証を無効にします：

    CONFIG set requirepass ""
