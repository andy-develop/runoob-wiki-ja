Pi Agent CLI リファレンスマニュアル

以下は Pi Agent の一般的なコマンドライン引数のリファレンスです。

モードオプション

以下の引数は Pi Agent の実行モードを制御します。未指定の場合はデフォルトでインタラクティブインターフェースに入ります。

引数説明例
（デフォルト）インタラクティブモード、ターミナル TUI インターフェースpi
-p, --printPrint モード、結果を出力して終了pi -p "コードを要約"
--mode jsonJSON モード、すべてのイベントが JSON 行として出力されるpi --mode json -p "要約"
--mode rpcRPC モード、stdin/stdout JSONL プロトコルpi --mode rpc
--export <入力> [出力]セッションを HTML としてエクスポート、出力パスは省略可能pi --export abc123 session.html

モデルオプション

以下の引数はプロバイダー、モデル、推論レベルを指定するために使用し、設定ファイルを変更せずに一時的に切り替えるのに適しています。

引数説明例
--provider nameAI プロバイダーを指定pi --provider anthropic
--model patternモデル ID、provider/id および :thinking 形式に対応pi --model openai/gpt-4o
pi --model sonnet:high
--api-key keyAPI Key を直接渡す、優先度最高。例の値は自分の Key に置き換える必要がありますpi --api-key sk-ant-api03-xxxx
--thinking level推論レベル：off/minimal/low/medium/high/xhigh/maxpi --thinking high
--models patternsカンマ区切りのモデルリスト、Ctrl+P の循環を制限pi --models "claude-*,gpt-4o"
--list-models利用可能なすべてのモデルを一覧表示pi --list-models

セッションオプション

以下の引数は、今回の実行でどのセッションを使用するか、およびセッションファイルの保存場所を決定します。

引数説明例
-c, --continue最近のセッションを続行pi -c
-r, --resume履歴セッションを参照して選択pi -r
--session path|id指定したセッションファイルまたは UUID を使用pi --session abc123
--fork path|id指定したセッションから新しいセッションをフォークpi --fork abc123
--session-dir dirセッション保存ディレクトリをカスタマイズ、デフォルトディレクトリは ~/.pi/agent/sessions/。この引数はそれを一時的に置き換えるために使用しますpi --session-dir .pi/sessions
--no-session一時モード、セッションを保存しないpi --no-session
-n, --name nameセッションの表示名を設定pi --name "認証モジュールをリファクタリング"

ツールオプション

以下の引数は組み込みツールの利用範囲を制御し、権限を厳しくしたり純粋な会話を行うために使用します。

引数説明例
-t, --tools listホワイトリストでツールを指定、カンマ区切りpi --tools read,bash,edit,write
-xt, --exclude-tools list指定したツールを無効化、カンマ区切りpi --exclude-tools bash
-nbt, --no-builtin-toolsすべての組み込みツールを無効化、拡張ツールは保持pi --no-builtin-tools
-nt, --no-toolsすべてのツールを無効化、純粋な会話モードpi --no-tools

リソースオプション

以下の引数は拡張機能、Skill、テンプレート、テーマの読み込みを制御します。--no- プレフィックス付きの引数は自動検出を無効にするために使用します。

引数説明例
-e, --extension source拡張機能を読み込む、繰り返し使用可能pi -e ./my-ext.ts -e npm:@foo/bar
--no-extensions拡張機能の自動検出を無効化pi --no-extensions
--skill pathSkill を読み込む、繰り返し使用可能pi --skill ./my-skill
--no-skillsSkill の自動検出を無効化pi --no-skills
--prompt-template pathプロンプトテンプレートを読み込む、繰り返し使用可能pi --prompt-template ./review.md
--no-prompt-templatesテンプレートの自動検出を無効化pi --no-prompt-templates
--theme pathテーマを読み込む、繰り返し使用可能pi --theme ./my-theme.json
--no-themesテーマの自動検出を無効化pi --no-themes
-nc, --no-context-filesAGENTS.md/CLAUDE.md の読み込みを無効化pi -nc

その他のオプション

以下の引数はシステムプロンプト、プロジェクト信頼、ヘルプ情報などの動作を上書きします。

引数説明例
--system-prompt textデフォルトのシステムプロンプトを置き換えpi --system-prompt "あなたは Python の専門家です"
--append-system-prompt textシステムプロンプトに追加pi --append-system-prompt "中国語で返信してください"
--tui-modeインターフェースモード、例: fullscreen。未指定の場合は通常（regular）モードpi --tui-mode fullscreen
--use-themeテーマを指定して読み込む、今回の実行のみ有効で設定は変更しないpi --use-theme "dark-plus"
--verbose詳細な起動情報を強制的に表示pi --verbose
-a, --approve今回の実行でプロジェクトのローカルファイルを信頼pi -a
-na, --no-approve今回の実行でプロジェクトのローカルファイルを信頼しないpi -na
--区切り文字。その後の内容はそのまま prompt に渡されるpi -- @notes.md このノートを要約
-h, --helpヘルプ情報を表示pi -h
-v, --versionバージョン番号を表示pi -v

-a 与 -na相互排他です。同じ実行で指定できるのはそのうちの1つのみです。

両方の有効範囲は今回の実行のみに限られ、trust.json には書き込まれません。

pi サブコマンド

起動引数の他に、pi は拡張パッケージと自身の更新を管理する一連のサブコマンドを提供します。

サブコマンド説明
pi install <source>拡張パッケージをインストール、-l を付けるとプロジェクトローカルにインストール
pi remove <source>インストール済みの拡張パッケージを削除
pi uninstall <source>remove のエイリアス、同じ効果
pi listインストール済みの拡張パッケージを一覧表示
pi updatepi 自身と拡張パッケージを更新、--self、--all、--models、--extensions、--extension <source> に対応
pi config拡張パッケージが提供する各種リソースを有効化または無効化

関連環境変数

以下の環境変数は認証、ネットワーク、ターミナルの表示に影響し、コマンドライン引数以外の補足設定として使用できます。

変数作用例
ANTHROPIC_API_KEYAnthropic 認証の代替方法。/login によるサブスクリプションログインを行っていない場合に使用sk-ant-api03-xxxx
HTTP_PROXY / HTTPS_PROXYAPI リクエストにプロキシサーバーを指定http://127.0.0.1:7890
NO_PROXYプロキシホワイトリスト。一致したホストはプロキシを経由しないlocalhost,127.0.0.1
COLORTERMtruecolor 自動検出の参考値の1つ。検出に失敗した場合は PI_TRUE_COLOR=1 で強制的に有効化するか、terminal.trueColor を設定truecolor

長期的に使用するプロキシは書き込むことを推奨します~/.pi/agent/settings.json 的 httpProxy。

この設定はグローバル設定ファイルでのみ有効です。プロジェクトレベルに記述しても.pi/settings.jsonでは無効です。

ファイルパラメータ

使用@プレフィックスでファイルを参照：

$ pi @prompt.md "回答这个问题"
$ pi -p @screenshot.png "图中有什么"
$ pi @src/code.ts @src/test.ts "对比这两个文件"
