Pi Agent の対話モード

Pi Agent 最初の対話

インストールと認証設定が完了したら、この章では初めての完全な対話体験を案内します。

インターフェースのレイアウトと基本操作に慣れていきます。

Pi Agent の起動

プロジェクトディレクトリに移動して、Pi Agent を起動します：

$ cd ~/projects/サンプル-demo
$ pi

ターミナルに Pi Agent の対話インターフェースが表示されます。

インターフェースは4つの主要な領域に分かれています：

領域位置表示内容
起動ヘッダー上部ショートカットキーのヒント、読み込まれたコンテキストファイル、プロンプトテンプレート、Skills、拡張機能
メッセージ領域中央ユーザーメッセージ、AI の返信、ツール呼び出しの詳細、通知、エラー
編集領域下部の入力行入力位置です。枠線の色は現在の推論レベルを示します
下部ステータスバー最下部作業ディレクトリ、セッション名、トークン/キャッシュ使用量、コンテキスト使用量、費用、現在のモデル名（合計には AI の返信、ツールの報告使用量、要約生成の消費が含まれます）

起動時に表示されるヘッダー情報が多すぎると感じる場合は、設定でquietStartup非表示にするオプションを有効にできます。

最初のタスク

インターフェースに入ったら、最初の要件を入力して Enter キーを押します：

このプロジェクトの構造と主要な機能をまとめてください。

Pi Agent は組み込みツールを使ってプロジェクトファイルを読み取り、コード構造を分析し、要約を返します。

メッセージ領域で AI が実行中の操作を確認できます。どのツールを呼び出したか、どのファイルを読み取ったかが含まれます。

完全な対話の出力は次のようになります：

> read README.md（1.2k 字符）
> read src/main.ts（3.4k 字符）

这是一个基于 TypeScript 的终端编程助手，主要功能分为会话管理、工具调度和扩展加载三部分。
Tokens: 2.4k 输入 / 410 输出  |  费用 $0.0152

Pi Agent はデフォルトで read、write、edit、bash の4つの組み込みツールを提供します。詳細は「中核概念の概要」の章を参照してください。

ファイルの参照

対話中に特定のファイルを参照できます。2つの方法があります：

方法1：@構文（エディタ内検索）

編集領域に@と入力すると、プロジェクトファイルのあいまい検索が自動的に表示されます：

@src/app.ts 解释这个文件的功能

方法2：コマンドライン引数

起動時にファイル参照を直接渡します：

$ pi @README.md "总结一下这个文档"
$ pi @src/app.ts @src/app.test.ts "对比这两个文件"

画像ファイルも参照できます：

$ pi -p @screenshot.png "这张截图里显示了什么"

画像の貼り付け

Pi Agent は対話中に画像を送信できます。プラットフォームによって操作方法が少し異なります。

プラットフォーム操作説明
macOS / LinuxCtrl+Vクリップボードの画像を貼り付け
WindowsAlt+Vクリップボードの画像を貼り付け
対応端末画像をターミナルウィンドウにドラッグファイルとして対話に渡す

対話中にコマンドを実行

編集領域から直接 shell コマンドを実行できます。Pi Agent を終了する必要はありません：

!npm run lint
!git diff

以 !で始まるコマンドは実行され、出力結果は自動的に AI に送信されて確認されます。

実行!npm run lintの結果は次のようになります：

> pi-agent@1.0.0 lint
> eslint .
0 errors, 0 warnings

以 !!で始まるコマンドも実行されますが、AI には送信されません：

!!echo "这只在本地显示"
这只在本地显示

「」プレフィックスを!!使用して、AI が確認する必要のないコマンド（ファイルを開く、環境変数を確認するなど）を実行すると、コンテキストウィンドウの無駄遣いを避けられます。

複数行入力と外部エディタ

長いテキストは複数行入力または外部エディタで作成できます。関連するショートカットキーは以下のとおりです。

操作ショートカットキー
改行を挿入Shift+Enter（Windows Terminal では Ctrl+Enter）
外部エディタを開くCtrl+G

長いテキストを入力する必要がある場合は、Ctrl+Gを押すとシステムのデフォルトエディタ（nano、vim、VS Code など）が開きます。編集して保存すると、内容が自動的に Pi Agent の編集領域に反映されます。

メッセージキュー

Pi Agent は AI が作業中でもメッセージを送信できます。完了を待つ必要はありません：

ショートカットキー動作説明
Entersteering メッセージを送信現在のツールの実行が完了したらすぐに AI に送信
Alt+Enterfollow-up メッセージを送信AI がすべての作業を完了してから送信
Escapeキューに入ったメッセージをキャンセルキュー内のメッセージを編集領域に戻す
Alt+Upキュー内のメッセージを取り出すキューに入ったメッセージを編集領域に戻して修正する

Windows Terminal では、Alt+Enter はデフォルトで全画面表示のショートカットキーです。Pi Agent にこのショートカットキーを受け取らせたい場合は、次の資料を参照してください。マルチプラットフォーム展開の説明に従って再マッピングしてください。

非対話モード

対話モード以外にも、以下の方法で Pi Agent をすばやく利用できます：

例

# 一回限りの質問応答。出力後に終了
pi -p "このコードベースを要約して"

# パイプ入力：ファイルの内容を AI に渡す
cat README.md | pi -p "このテキストを要約して"

# 画像付きの一回限りの質問応答
pi -p @screenshot.png "この画像には何が写っていますか"

# 名前付きセッション（後で続けるのに便利）
pi --name "コードレビュー" -p "src/ ディレクトリのコードをレビューして"

# 読み取り専用モード（ファイルの変更は不可）
pi --tools read,grep,find,ls -p "コードをレビューして変更しないで"

Print モード（-p）は、スクリプトや CI フローへの統合に最適です。

プロジェクト指示ファイルの作成

AI がプロジェクトをより理解できるように、AGENTS.md ファイルを作成することをお勧めします。

以下の内容を Markdown ファイルとして保存します。ファイルのパスは次のとおりです。プロジェクトルート/AGENTS.md：

例

# プロジェクト指示

- コード変更後は `npm run check` を実行
- 本番環境のマイグレーションをローカルで直接実行しない
- 返信は簡潔にし、過剰な説明はしない
- TypeScript の厳格モードでコードを記述
- プロジェクトの既存のコードスタイルに従う

Pi Agent は起動時にこのファイルを自動的に読み込みます。

また、~/.pi/agent/AGENTS.mdのグローバル指示と親ディレクトリ内の指示ファイルも読み込みます。

AGENTS.md を更新したら、/reloadコマンドでホットリロードできます。再起動は不要です。

以前 Claude Code を使用していた場合、既存の CLAUDE.md ファイルは Pi Agent にそのまま認識されて使用できます。名前を変更する必要はありません。
