Pi Agent インストール

この章では、さまざまなプラットフォームで Pi Agent をインストールし、基本環境を構成する方法を説明します。

環境要件

Pi Agent をインストールする前に、システムが以下の要件を満たしていることを確認してください。

依存項目最低バージョン説明
Node.js推奨：18 LTS 以上Pi Agent は Node.js 上で動作し、最新の JavaScript 機能をサポートする実行環境が必要です。
npmNode.js に同梱Pi Agent と拡張パッケージのインストールに使用
ターミナルTrue Color 対応推奨：iTerm2（macOS）、Windows Terminal、Kitty、WezTerm

Node.js がインストールされているか確認します：

node --version

出力例：

v20.11.0

npm が一緒にインストールされているか確認します（Node.js に同梱されています）：

npm --version

出力例：

10.2.4

Node.js のバージョンが 18 未満の場合は、先にアップグレードしてください。nvm（Node Version Manager）を使用すると、複数の Node.js バージョンを管理できます。

インストール

方法1：npm グローバルインストール

これは最も汎用的で簡単なインストール方法で、macOS、Linux、Windows に対応しています：

# 全局安装 Pi Agent
# --ignore-scripts 禁用依赖包的生命周期脚本，提高安装安全性
npm install -g --ignore-scripts @earendil-works/pi-coding-agent

インストール後、バージョンを確認します：

pi --version

インストールが完了すると、piコマンドがターミナルで直接使用できるようになります。

方法2：curl ワンクリックスクリプト

Linux または macOS では、公式インストールスクリプトも使用できます：

# 使用 curl 下载并执行安装脚本
curl -fsSL https://pi.dev/install.sh | sh

このスクリプトはシステムを自動検出してインストールを完了します。本質的には npm グローバルインストールと同じです。

方法3：その他のパッケージマネージャー

pnpm、Yarn、Bun を使用している場合は、対応するコマンドでもインストールできます：

# 使用 pnpm 安装
pnpm add -g @earendil-works/pi-coding-agent

# 使用 Yarn 安装
yarn global add @earendil-works/pi-coding-agent

# 使用 Bun 安装
bun install -g @earendil-works/pi-coding-agent

アンインストール方法

Pi Agent をアンインストールするときは、インストール時と同じパッケージマネージャーを使用してください：

# npm 或 curl 安装的用 npm 卸载
npm uninstall -g @earendil-works/pi-coding-agent

# pnpm 安装的
pnpm remove -g @earendil-works/pi-coding-agent

# Yarn 安装的
yarn global remove @earendil-works/pi-coding-agent

# Bun 安装的
bun uninstall -g @earendil-works/pi-coding-agent

Pi Agent をアンインストールしても、設定、認証情報、セッション記録は削除されません。これらのデータは~/.pi/agent/ディレクトリ内に保存されています。完全に削除する場合は、手動でそのディレクトリを削除してください。

ターミナルの推奨

Pi Agent は 24 ビット RGB カラーでターミナル画面を描画します。最適な体験を得るには、以下のターミナルを推奨します：

プラットフォーム推奨ターミナル説明
macOSiTerm2、Kitty、WarpTrue Color をネイティブサポートし、インライン画像の表示品質が高い
WindowsWindows Terminal、WezTermWindows Terminal は公式推奨のモダンなターミナルです
LinuxKitty、WezTerm、Alacrittyいずれも True Color と GPU アクセラレーションに対応

その他のターミナルツールはこちらを参照：https://www.example.com/w3cnote/terminal-tools.html

ターミナルが True Color に対応しているか確認します：

$ echo $COLORTERM
truecolor

出力がtruecolor 或 24bitの場合、ターミナルは完全な色描画をサポートしています。

初回実行

インストール後、プロジェクトディレクトリに入り Pi Agent を起動します：

$ cd /path/to/your-project
$ pi

初回起動時に、Pi Agent のウェルカム画面が表示されます。

この時点では AI プロバイダーが設定されていないため、先に認証を完了する必要があります。これについては次の章で詳しく説明します。

Pi Agent は起動時に現在の作業ディレクトリ（cwd）をプロジェクトルートとします。ディレクトリ内のファイルに対する読み書き権限を持つため、git によるバージョン管理下で使用し、いつでも変更をロールバックできるようにすることをお勧めします。

Pi Agent の更新

Pi Agent を最新バージョンに保つには：

# 仅更新 Pi Agent 本身
pi update --self

# 更新 Pi Agent 和所有已安装的扩展包
pi update --all

# 更新模型目录（获取最新的可用模型列表）
pi update --models

使用：--self --forcePi Agent を強制的に再インストールできます（現在が最新バージョンであっても）：

$ pi update --self --force

注意：install.sh などのインストールスクリプトで管理されるインストールは対応していません--force。

このような管理されたインストールを修復する必要がある場合は、インストールスクリプトを再度実行するだけです。
