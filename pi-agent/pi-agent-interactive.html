Pi Agent インタラクティブモード

この章では、Pi Agent インタラクティブモードの中心的な操作について、Slash コマンド、モデル管理、キーボード操作を含めて詳しく説明します。

Slash コマンド大全

編集エリアで / を入力すると、/コマンドの自動補完がトリガーされます。

以下は Pi Agent インタラクティブモードでよく使用される組み込みコマンドです：

コマンド機能説明
/loginプロバイダーのログインOAuth サブスクリプションまたは API Key プロバイダーを選択して認証します
/logoutログアウト保存されている認証情報を消去します
/modelモデル切り替えモデルセレクターを開き、名前で検索します。セレクター内で Ctrl+S を押すと起動時のデフォルトとして保存できます
/thinking推論レベルの切り替え推論レベルセレクターを開きます。セレクター内で Ctrl+S を押すと起動時のデフォルトとして保存できます
/scoped-modelsモデル範囲の管理Ctrl+P での循環切り替え時に使用可能なモデルリストを設定します
/settings設定パネル組み込みの設定インターフェースを開きます：推論レベル、テーマ、メッセージ配信、転送プロトコルなど
/resumeセッションの復元履歴セッションから選択して復元します
/new新しいセッション新しい対話を開始します
/nameセッションに名前を付ける現在のセッションにわかりやすい名前を設定します
/sessionセッション情報セッションファイルのパス、ID、メッセージ数、トークン使用量、費用を表示します
/treeセッションツリーナビゲーション対話ツリーの任意のノードに移動して対話を続けます
/trustプロジェクトを信頼プロジェクトの信頼決定を保存し、起動のたびに確認されないようにします
/forkセッションのフォーク以前のユーザーメッセージから新しいセッションファイルをフォークします
/cloneセッションのクローン現在のアクティブなブランチを新しいセッションファイルにコピーします
/compactコンテキストの圧縮対話履歴を手動で圧縮し、コンテキストウィンドウのスペースを解放します
/copy返信をコピーAI の最後の返信をクリップボードにコピーします
/exportセッションのエクスポートHTML または JSONL ファイルとしてエクスポートします
/importセッションのインポートJSONL ファイルからインポートしてセッションを復元します
/shareセッションの共有プライベート GitHub Gist としてアップロードし、共有可能な HTML リンクを生成します
/reloadホットリロード拡張機能、Skills、プロンプトテンプレート、テーマ、コンテキストファイル、キーボードショートカット設定を再読み込みします
/hotkeysショートカットキーヘルプすべてのキーボードショートカットのリストを表示します
/changelog更新ログバージョン更新履歴を表示します
/quit終了Pi Agent を終了します

組み込みコマンドに加えて、Extensions（拡張機能）もカスタムコマンドを登録できます。

Skills は自動的に/skill:名前コマンドとして登録されます。プロンプトテンプレートは/テンプレート名を使用して呼び出されます。

モデル管理

モデル管理には、モデルの切り替え、循環切り替え範囲の設定、推論レベルの調整という3つの側面があります。

以下で、それぞれのコマンドとショートカットキーを説明します。

モデル切り替え（/model と Ctrl+L）

/model コマンドまたは/modelCtrl+L を使用して、Ctrl+Lモデルセレクターを開き、利用可能なすべての AI モデルを閲覧できます。

モデルセレクターでは、名前で検索でき、選択後に Ctrl+S を押すと起動時のデフォルトとして保存できます。

以下はモデルセレクターを開いてモデルを切り替える操作手順です：

/model
┌ 选择模型（输入关键词过滤，↑/↓ 移动，Enter 确认）：
│ > anthropic/claude-sonnet-4-5
│   anthropic/claude-opus-4-1
│   openai/gpt-4o
│   google/gemini-2.5-pro
└
已切换到 anthropic/claude-sonnet-4-5

リスト内のモデルは、設定済みのプロバイダーによって異なります。実際の表示はサンプルとは異なる場合があります。

クイック循環切り替え（Ctrl+P）

Ctrl+Pモデルを前方に循環切り替えし、Shift+Ctrl+P後方に切り替えます。

切り替え範囲は/scoped-models/model コマンドまたはenabledModels設定によって制御されます。

推論レベル（Shift+Tab）

Shift+Tab推論レベルを循環切り替えします。

エディタの枠線の色がレベルに応じて変化し、現在の推論の深さを直感的に把握できます：

レベル適用シーン
off推論なし（一般的なタスク）
minimal / low軽度の推論（一般的なコーディング）
medium中度の推論
high / xhigh深い推論（複雑な問題）
max最大の推論（非常に複雑なロジック）

/thinking セレクター内で Ctrl+S を押すと、現在のレベルを起動時のデフォルトとして保存できます。

モデルがサポートしていない推論レベルは有効にならず、切り替えリストにも表示されません。

モデルの能力が推論レベルの上限を決定します。

Shell コマンド統合

編集エリアで直接 shell コマンドを実行できます。Pi Agent を離れる必要はありません：

プレフィックス動作出力処理使用シーン
!コマンドを実行し、出力を AI に送信AI から参照可能AI にテスト結果、lint 出力、git ステータスを確認させる
!!コマンドを実行し、出力を AI に送信しないローカルのみに表示ファイルを開く、環境を確認する、クイックチェック

使用例：

!npm test
!git diff --stat
!python -m pytest -v

!!cat ~/.zshrc
!!ls -la

以下で実行した!npm test後の実際の効果です。出力はローカルに表示されると同時に AI に渡されます：

!npm test
> pi-demo@1.0.0 test
> vitest run

 PASS  src/utils/format.test.ts (6 tests) 12ms
 PASS  src/utils/parse.test.ts (4 tests) 8ms

 Test Files  2 passed (2)
      Tests  10 passed (10)

!コマンドの出力は AI のコンテキストウィンドウを消費します。

出力が大きい場合（完全なログなど）、使用を検討してください!!または出力をファイルにリダイレクトしてから AI に読み取らせてください。

メッセージキューの詳細

メッセージキューを使用すると、AI が作業中でも指示を送信でき、対話効率が大幅に向上します：

メッセージタイプショートカットキートリガーのタイミング代表的なシナリオ
Steering（誘導）Enter現在のラウンドのツール呼び出しがすべて実行された後、次のラウンドの LLM 呼び出しの前に挿入されますAI が read → edit → bash の一連の呼び出しを実行しているときに、途中で方向を修正したい場合
Follow-up（フォローアップ）Alt+EnterAI がすべての作業を完了した後（実行すべきツール呼び出しがなくなった後）に挿入されますAI が現在のタスクを完了した後に新しい要件を追加する
中止して取り戻すEscape現在の操作を中止し、キューに入ったメッセージを編集エリアに取り戻しますAI の方向が逸れたときにすぐに停止し、同時にキューに入った指示を取り戻す
キューのメッセージのみ取り戻すAlt+Up現在の操作を中止せず、キューに入ったメッセージのみ編集エリアに取り戻しますキューの内容を書き換えたいが、AI を中断する必要はない場合

設定のsteeringMode 和 followUpModeを使用して、メッセージの送信ポリシーを制御できます。

Windows と WSL では、Alt+Enter はターミナルに占有されることがよくあります（例：Windows Terminal ではデフォルトで全画面切り替えにバインドされています）。この場合、実際にはデフォルトで Ctrl+Q を使用して follow-up メッセージを送信できます。

エディタ機能

編集エリアは、ファイル参照、パス補完、複数行入力などの強化された機能を提供し、ツールを切り替える回数を減らします。

機能操作方法
ファイル参照検索@ を入力すると、プロジェクトファイルのあいまい検索がトリガーされます
パスの自動補完Tab を押すとパスが自動補完されます
複数行入力Shift+Enter で改行（Windows Terminal では Ctrl+Enter）
画像の貼り付けCtrl+V（Windows では Alt+V、WSL でも同様に Alt+V）、または画像をターミナルにドラッグ＆ドロップ
AI の返信をコピーCtrl+X で /tree 内の現在選択中のメッセージをコピーし、その他のシーンでは最後の AI の返信をコピーします
外部エディタCtrl+G で外部エディタを開いて現在の内容を編集します

複数行入力の「Windows Terminal 用 Ctrl+Enter」は Windows Terminal での自動適応であり、keybindings.json のデフォルト値ではありません。
