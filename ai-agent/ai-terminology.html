AI Agent 用語

大規模言語モデル（LLM）とエージェント（Agent）技術の急速な発展に伴い、プログラミングパラダイムは深い変革を遂げつつある。Vibe Coding、Agentic Coding、Harness Engineer、Loop Engineer……新しい概念や新しい用語が次々と登場している。次に、どのような新しい用語があるのか、それぞれが何を意味するのかを見ていこう。

AI AgentArtificial Intelligence（人工知能）と Agent（エージェント）から構成される。

一、プログラミングパラダイム（Coding Paradigm）

用語 中国語 コアの意味 例（レストラン経営）
Vibe Coding 雰囲気プログラミング 自然言語/音声で要件を記述し、AI にコードを生成させる 家で感覚でチャーハンを炒める。何を入れたいかは自由
Context Engineering コンテキストエンジニアリング コンテキスト、知識、記憶、ツールを整理することでモデルの効果を高める 事前に食材を準備し、メニューと厨房環境を整える
Agentic Coding エージェントプログラミング Agent が自律的にプログラミングタスクを完了する（設計→実装→テスト→検収） 正式なレストランを経営し、メニューから仕込み、出品までの全プロセスを管理する
AI Native Development AI ネイティブ開発 デフォルトで AI が設計、開発、テストの全プロセスに関与する そのままスマートレストランを経営する

二、エンジニアリング役割（Engineer Role）

用語 中国語 コアの意味 例（レストラン経営）
Harness Engineer ハーネスエンジニア さまざまな Harness コンポーネントを呼び出し、自分で作業し自分で検収する プロの料理人で、さまざまな調理器具や技法に精通し、作り終えたら自分で味見をして品質を確認する
Loop Engineer ループエンジニア 自動化オーケストレーションシステムを構築し、自律進化させる レストラン運営管理システムで、シフト管理、仕入れ、提供のペースとコストを統括する
Context Engineer コンテキストエンジニア コンテキスト、知識ソース、記憶システムの設計を担当する 厨房の総合ディスパッチャー
AI Product Engineer AI プロダクトエンジニア AI 機能とビジネスのクローズドループ設計を担当する レストランのオーナー兼運営者
Agent Operator エージェント運用エンジニア Agent の実行効果を継続的に監視し最適化する 店長が経営データを継続的に最適化する

三、モデルと基盤（Model & Fundamentals）

用語 中国語 コアの意味 備考
LLM（Large Language Model） 大規模言語モデル 膨大なテキストに基づいて訓練された言語予測モデル GPT、Claude、Gemini はすべて LLM である
GPT 生成的事前学習トランスフォーマー OpenAI のモデルアーキテクチャのパラダイム Generative Pre-trained Transformer
Token トークン モデルがテキストを処理する最小単位（約 ¾ 英単語） 課金とコンテキスト長の計量単位
Context Window コンテキストウィンドウ モデルが一度に「見る」ことができる最大トークン数 ウィンドウが大きいほど、覚えられる量が多い
Inference 推論 モデルが出力を生成するプロセス トレーニングとは区別される
Hallucination ハルシネーション モデルが存在しない情報をもっともらしく作り出す 事実、コンテキスト、または目標と一致しない内容を生成する
Temperature 温度（Temperature） サンプリング確率分布を制御し、値が高いほど多様になり、低いほど安定する コードを書くときは低めに設定することを推奨
Top-p / Top-k サンプリングパラメータ 候補トークンのサンプリング範囲を制御する 出力の多様性に影響する
Embedding ベクトル埋め込み（Embedding） テキスト/画像を数値ベクトルに変換し、類似度計算に使用する RAG の基盤
Fine-tuning ファインチューニング 汎用モデルを特定のデータでさらに訓練する モデルを特定の分野に詳しくさせる
RLHF 人間のフィードバックに基づく強化学習 人間の好みでモデルの振る舞いを調整する AI を「言うことを聞かせる」
MoE（Mixture of Experts） 混合エキスパート（MoE） 毎回一部のパラメータのみを活性化し、効率を高める より少ない計算リソースでより強力なモデルを実行する
Multimodal マルチモーダル テキスト、画像、音声、動画を同時に処理する GPT-4o、Gemini はどちらも該当する
Transformer Transformer アーキテクチャ 現代の LLM の基盤となるニューラルネットワーク構造 注意力メカニズム（Attention）が中核である
KV Cache KV キャッシュ（Key-Value キャッシュ） コンテキストの計算結果をキャッシュして推論速度を向上させる レシピを何度もめくり直す手間を省く
Latency レイテンシー モデルの応答にかかる時間 ユーザー体験に影響する
Throughput スループット 単位時間あたりに処理できるタスク数 並行処理能力に影響する

四、プロンプトエンジニアリング（Prompt Engineering）

用語 中国語 コアの意味
Prompt プロンプト モデルに与える入力命令
System Prompt システムプロンプト Agent の役割、境界、行動を定義する基盤となる命令
Prompt Engineering プロンプトエンジニアリング より良い出力を得るためにプロンプトを設計・最適化する技術
Zero-shot ゼロショット 例を示さずに、直接モデルにタスクを実行させる
Few-shot フューショット いくつかの例を示し、モデルをフォーマット/スタイルに沿った出力に導く
Chain of Thought（CoT） 思考の連鎖（Chain of Thought） モデルに中間推論プロセスを生成させ、複雑な推論能力を向上させる
ReAct 推論+行動（Reasoning + Acting） Reasoning + Acting を交互に行い、考えながら実行する。Agent の中核パラダイムである
Role Prompting ロールプレイ モデルに特定の役割を演じさせる（例：「あなたはシニアアーキテクトです」）
Structured Output 構造化出力 モデルに JSON/XML などの形式で出力を強制する
Prompt Chaining プロンプトチェーン 複数のプロンプトを直列につなぎ、複雑なタスクを完了する
Self-Consistency 自己整合性（Self-Consistency） 複数の推論結果を生成した後、投票で選択する
Tree of Thoughts（ToT） 思考の木（Tree of Thoughts） 複数の推論経路を同時に探索する

五、Agent アーキテクチャ（Agent Architecture）

用語 中国語 コアの意味 例（レストラン経営）
Agent エージェント 自律的に知覚、意思決定、タスク実行ができる AI プログラム 中華鍋を操る料理長
Multi-Agent マルチエージェント 複数の Agent が役割分担して協力する 料理人チームが連携して料理を提供する
Subagent サブエージェント メイン Agent から派生した専門サブ Agent 専門担当の料理人（例：切り込み、冷菜、デザート）
Tool Use / Function Calling ツール呼び出し / 関数呼び出し Agent が外部ツール/API を呼び出してアクションを実行する 包丁、コンロ、オーブンなどの調理器具を使用する
Planning プランニング Agent が目標を分解し、実行手順を策定する 仕込みと提供の計画を立てる
Reflection リフレクション Agent が自分の行動を振り返り改善する 試食後にフィードバックに基づいて味を調整する
Memory 記憶 セッションをまたいで再利用する長期情報を保存する（短期/長期） レシピ帳と経営データの蓄積
Agent Loop エージェントループ 思考→行動→観察→再思考の反復メカニズム 仕込み→調理→試食→提供のサイクル
Environment 環境 Agent が知覚しアクションを実行する現実世界 厨房環境
Observation 観察 実行後にフィードバック情報を取得する 試食フィードバック
Execution 実行 計画を実際の動作に変換する 料理を始める
Long-term Memory 長期記憶 経験知識を長期的に保存する データベースを運用する

六、Harness コンポーネント（AI Agent 機能モジュール）

用語 日本語 核心的な意味 例（レストラン経営）
Harness ハーネス / 制御フレームワーク Agentの実行・コンテキスト管理・ツールオーケストレーションを担う実行フレームワーク 厨房システム全体（厨房本体）
Skills スキル Agentが呼び出せる専門能力モジュール 各種調理技法（炒める・煮る・揚げるなど）
Context コンテキスト 現在のタスクで取得できる情報の範囲 現在の注文、食材在庫、顧客の要望
MCP（Model Context Protocol） モデルコンテキストプロトコル Agentが外部ツール・データソースに接続するための標準化プロトコル 食材サプライヤーやデリバリープラットフォームと連携する標準化インターフェース
Permission 権限制御 Agentができること・できないことを制御する安全メカニズム 厨房の操作権限と仕入れ承認
RAG（Retrieval-Augmented Generation） 検索拡張生成 まず知識ベースから検索し、その後モデルに生成させることで幻覚（ハルシネーション）を減らす 料理をする前にレシピ本をめくって標準的な作り方を確認する
Tool Registry ツール登録センター Agentが呼び出せるツールを一元的に管理する 厨房の道具棚
Session セッション 1つのタスクのライフサイクル 1回の営業プロセス
Knowledge Base 知識ベース Agentが照会するための外部知識の集合 レストランのレシピライブラリ

七、Loop ツール（自動化オーケストレーションと自律進化）

用語 日本語 核心的な意味 例（レストラン経営）
/loop ループ命令 Agentに継続的にループ実行させる 継続的に稼働する料理提供ライン
/goal 目標命令 目標を設定してAgentを駆動し、自律的に達成させる 当日の営業目標
Cron 定期タスク 時間計画に従って自動的にトリガーする 営業時間帯と仕込みのスケジュール
Worktree ワークツリー Gitのマルチブランチ並行ワークスペース 複数のコンロで同時に調理し、互いに干渉しない
Workflow ワークフロー 事前定義されたマルチステップ自動化プロセス 標準提供SOP
Scheduler スケジューラー 複数のタスクの実行順序を調整する 厨房のシフト管理システム
Checkpoint チェックポイント 実行状態を保存して復元に使用する 営業を一時停止した後に作業を再開する
Human-in-the-loop ヒューマン・イン・ザ・ループ 重要なステップで人間の介入を許可する 料理長が最終確認して提供する

九、評価と安全性（Evaluation & Safety）

用語 日本語 核心的な意味
Eval 評価 テストセットを用いてモデル・Agentの能力を測定する
Alignment アライメント AIの行動を人間の意図と価値観に適合させる
Guardrail ガードレール AIの出力範囲を制限する安全メカニズム
Red Teaming レッドチームテスト 積極的にAIを攻撃・誘導して脆弱性を発見する
Prompt Injection プロンプトインジェクション 悪意のある入力でAIの動作を乗っ取る（例：「上記の指示を無視」）
Context Poisoning コンテキスト汚染 コンテキストに悪意のある情報を混入させてAgentを誤誘導する
Sandbox サンドボックス 隔離された実行環境で、AIの誤操作によるシステム破壊を防ぐ

十、AI エンジニアリング進化ロードマップ（Evolution）

AIエンジニアリングの能力は段階的に上昇している：モデル出力の制御から、コンテキストの制御へ、さらにシステムの制御へ、最終的には持続的自律システムへと進化する。

段階 注目点 重要な能力
Prompt Engineering どう問いかけるか プロンプト設計
Context Engineering どのような情報を与えるか コンテキストの編成
Harness Engineering 能力をどう編成するか ツールオーケストレーション
Loop Engineering どう継続的に結果を生み出すか 自動実行とフィードバック
