OpenClaw 設定ディレクトリ

OpenClaw（別名 Clawdbot）のすべての設定、状態データ、ワークスペース、スキルは、ユーザーのホームディレクトリ下の ~/.openclaw/（Linux/macOS）または %USERPROFILE%\.openclaw\（Windows）というコアディレクトリに集約されます。

~/.openclaw/システム全体のルート設定ディレクトリであり、初回インストール/実行時にopenclaw onboard 或 openclaw onboard --install-daemon自動的に作成されます。

~/.openclaw/
├── openclaw.json                 # 主配置文件（JSON/JSON5）
├── workspace/                    # 你的 AI “灵魂”文件夹（推荐 git 版本控制）
│   ├── SOUL.md                   # 人格设定（语气、风格）
│   ├── USER.md                   # 你的个人信息（让 AI 更懂你）
│   ├── MEMORY.md                 # 长期记忆（手动可编辑）
│   ├── IDENTITY.md               # Agent 名称、形象
│   ├── AGENTS.md                 # 多 Agent 路由规则
│   ├── BOOT.md                   # 启动提示词
│   ├── HEARTBEAT.md              # 每日检查清单
│   └── skills/                   # 已安装技能（每个技能一个子文件夹）
├── agents/<cid>/                 # 每个 Agent 的独立状态
├── memory/<cid>.sqlite           # 向量记忆库
├── credentials/                  # API Key、OAuth（旧版）
├── skills/                       # 全局技能包
└── secrets.json                  # 加密凭证（可选）

最も重要なファイル：

  • openclaw.json：全体設定（モデル、チャネル、ポート、セキュリティポリシー）
  • workspace/下のすべて.mdファイル：VS Code で直接編集するだけで即座に反映されます！

設定を表示/変更するコマンド：

openclaw configure      # 交互式配置向导
openclaw config file          # 显示完整路径
openclaw config get agent.model
openclaw config set agent.model "anthropic/claude-3-5-sonnet"
openclaw config validate      # 校验合法性
パス 用途の説明
~/.openclaw/openclaw.json メイン設定ファイル（最も重要！）
全体設定（モデル、Gateway モード、バインドアドレス、Agents のデフォルト値、プラグインなど）を保存します。
コマンドで表示/変更できます：
• openclaw config file（完全なパスを表示）
• openclaw config get <json路径>
• openclaw config set <json路径> <值>
~/.openclaw/workspace/ デフォルトワークスペース（Agentの"魂"の居場所）
以下の Markdown ファイルを保存します（直接編集して反映できます）：
• SOUL.md：AIの人格/口調の設定
• USER.md：あなたの個人的な好みと背景
• MEMORY.md：長期記憶の記録
• AGENTS.md：指示の説明
• IDENTITY.md：名前/テーマ
• BOOT.md：起動設定
• HEARTBEAT.md：定期チェックリスト
~/.openclaw/agents/<cid>/ 単一のエージェント（Agent）の状態ディレクトリ（<cid>はインスタンス ID）
~/.openclaw/agents/<agentId>/agent/auth-profiles.json API Key と OAuth 資格情報（新バージョンの推奨場所）
旧バージョンは~/.openclaw/credentials/
~/.openclaw/memory/<cid>.sqlite ベクトルインデックスストレージ（記憶検索用）
~/.openclaw/skills/ グローバルスキルディレクトリ
を通じてopenclaw skills install 或 clawhub installインストールされたスキルパックはすべてここに置かれます（各スキルはサブフォルダーで、SKILL.md を含みます）
~/.openclaw/memory/ 長期記憶関連ファイル（SQLite + ベクトル埋め込み）
/tmp/openclaw/*.log Gateway サービスのログ（デバッグ用）

1. メイン設定ファイル

パス: ~/.openclaw/openclaw.json

説明:OpenClaw のコア設定ファイルで、すべてのシステムレベル設定を含みます。

主要な設定項目：

  • gateway- ゲートウェイサービス設定
    • mode：ゲートウェイモード（例: "local"）
    • port：ゲートウェイのポート番号（デフォルト 18789）
    • bind：バインドアドレス（デフォルト 127.0.0.1）
    • token：アクセストークン、Web UI 認証用
  • models- AI モデル設定
    • デフォルトモデル設定
    • API認証情報
  • messages- メッセージ処理設定
    • TTS（テキスト読み上げ）設定
    • メッセージ形式設定

設定例の抜粋：

{
  "gateway": {
    "mode": "local",
    "port": 18789,
    "bind": "127.0.0.1",
    "token": "c9917c5a066beeb26266d09baed99495e7563b33c771e89a"
  }
}

操作の推奨事項：

  • 初回インストール後にopenclaw onboardウィザードが自動生成
  • 設定変更後はゲートウェイサービスを再起動して反映する必要があります
  • token 値は Web UI アクセスに使用されるため、大切に保管してください

2. ワークスペースディレクトリ

パス: ~/.openclaw/workspace/

説明:OpenClaw のデフォルト作業ディレクトリで、AI が生成したすべてのファイル、一時ファイル、ユーザーリクエストの出力ファイルがここに保存されます。

主な用途：

  • AI エージェントがファイルを読み書きするデフォルトの場所
  • コード実行出力の保存
  • ドキュメントの生成と編集
  • 一時データの保存

権限の説明：

  • デフォルトでは、AI はこのディレクトリとそのサブディレクトリにのみアクセスできます
  • 他のパスにアクセスする必要がある場合は、設定が必要ですfilesystem-mcpスキルを設定し、追加の権限を付与します
  • Windows ユーザーは、ファイルをワークスペースから他の場所にコピーする必要がある場合があります

使用上の推奨事項：

  • 不要な一時ファイルを定期的に削除する
  • 重要な出力はワークスペース外にバックアップすることを推奨
  • ここにプロジェクトのサブディレクトリを作成して整理管理できます

3. エージェント状態ディレクトリ

パス: ~/.openclaw/agents/<cid>/

説明:各会話（Conversation）のエージェント状態と設定を保存するディレクトリです。<cid>はセッション ID であり、各セッションには独立した設定スペースがあります。

ディレクトリ構造：

~/.openclaw/agents/<cid>/
├── agent/
│   ├── auth-profiles.json    # 该会话的 OAuth 和 API 密钥
│   └── ...
└── ...

auth-profiles.json の説明：

  • そのエージェントが使用する API 認証情報を保存します
  • 各サービスの OAuth token を含みます
  • 新バージョンはこのパスを使用し、旧バージョンは~/.openclaw/credentials/

データの分離：

  • 各セッションの認証情報は互いに独立しています
  • セッションごとに異なる API キーを設定できます
  • 複数エージェントの並列実行をサポートします

4. 認証資格情報ディレクトリ（旧版）

パス: ~/.openclaw/credentials/

説明:旧バージョンの OpenClaw の資格情報の保存場所です。

移行の説明：

  • 新バージョンでは~/.openclaw/agents/<agentId>/agent/auth-profiles.json
  • 旧バージョンのユーザーはアップグレード後、資格情報の再設定が必要な場合があります
  • を使用することを推奨openclaw models auth setup再設定してください

5. メモリストレージディレクトリ

パス: ~/.openclaw/memory/

説明:OpenClaw の永続メモリシステムの保存場所で、ベクトルインデックスと会話履歴を含みます。

主要ファイル：

  • <cid>.sqlite- ベクトルインデックスデータベース

    • 会話の意味ベクトルを保存します
    • 意味検索機能をサポートします
    • 長期記憶の検索に使用されます

  • YYYY-MM-DD.md- 日次会話ログ

    • 日付で命名された Markdown ファイル
    • その日のすべての会話内容を記録します
    • 人間が確認してアーカイブしやすい

メモリ機能：

  • ベクトル検索：を使用してmemory search "关键词"過去の会話を検索します
  • コンテキスト関連付け：セッションをまたいだコンテキスト理解をサポートします
  • 長期記憶：エージェントはユーザーの好みや習慣を「覚えます」

メンテナンスの推奨事項：

  • memory ディレクトリを定期的にバックアップする
  • 大規模なデータベースはパフォーマンスに影響する可能性があるため、定期的なアーカイブを検討してください
  • ログファイルは監査と問題解決に利用できます

6. スキルディレクトリ

パス: ~/.openclaw/skills/

説明:グローバル共有スキル（Skills）のインストール場所です。スキルは OpenClaw の機能を拡張するプラグインです。

スキル管理：

  • スキルのインストール： npx clawhub install <skill-name>
  • スキルの一覧表示： openclaw skills list
  • スキルの検索： npx clawhub search <关键词>

一般的なスキルの例：

  • filesystem-mcp- ファイルシステム操作
  • github- GitHub 統合
  • nano-pdf- PDF 編集
  • notion / obsidian- ノート同期
  • weather- 天気予報
  • summarize- コンテンツ要約生成

スキルエコシステム：

  • コミュニティスキルライブラリ ClawHub は 500 以上のスキルを提供しています
  • カスタムスキル開発をサポートします
  • スキルは外部 API やシステムリソースにアクセスできます

設定の説明：

  • 各スキルには個別の API Key 設定が必要な場合があります
  • 一部のスキルはシステムツール（GitHub CLI など）に依存します
  • macOS 専用スキルは Windows/Linux では利用できません

7. ゲートウェイログディレクトリ

パス: /tmp/openclaw/*.log

説明:ゲートウェイサービスの実行ログで、システムの一時ディレクトリに保存されます。

ログタイプ:

  • ゲートウェイ起動/停止ログ
  • API リクエスト/レスポンスログ
  • エラーおよび例外ログ
  • パフォーマンス監視情報

ログ管理:

  • 一時ディレクトリのログはシステム再起動後に削除される可能性があります
  • 使用openclaw gateway --verbose詳細なログを確認できます
  • 問題を調査する際は、まずログファイルを確認してください

ゲートウェイサービス管理:

openclaw gateway start    # 启动网关
openclaw gateway status   # 查看状态
openclaw gateway stop     # 停止网关

その他の重要なファイル

USER.md

パス:通常はワークスペースまたはユーザー定義の場所にあります

説明:ユーザー情報ファイル。ユーザーに関するパーソナライズ情報が含まれており、AIがユーザーのニーズをより良く理解するのに役立ちます。

内容例:

  • ユーザーの嗜好設定
  • よく使用するワークフロー
  • プロジェクトの背景情報
  • カスタム指示

設定ファイル管理のベストプラクティス

1. バックアップ戦略

重要なディレクトリのバックアップ:

# 备份整个配置目录
tar -czf openclaw-backup-$(date +%Y%m%d).tar.gz ~/.openclaw/

# 仅备份核心配置
cp ~/.openclaw/openclaw.json ~/backups/
cp -r ~/.openclaw/memory/ ~/backups/memory/

推奨バックアップ頻度:

  • メイン設定ファイル:変更のたびに
  • メモリデータベース:毎週1回
  • スキル設定:新しいスキルのインストール後

2. セキュリティの推奨事項

機密情報の保護:

  • openclaw.jsonゲートウェイのトークンが含まれているため、公開すべきではありません
  • auth-profiles.jsonAPI キーが含まれているため、暗号化して保護する必要があります
  • API キーを定期的に変更してください
  • 設定ファイルをバージョン管理システムにコミットしないでください

権限設定:

# 确保配置目录仅用户可访问
chmod 700 ~/.openclaw/
chmod 600 ~/.openclaw/openclaw.json
chmod 600 ~/.openclaw/agents/*/agent/auth-profiles.json

3. 移行とアップグレード

バージョンアップグレード時の注意事項:

  • アップグレード前に全体をバックアップ~/.openclaw/ディレクトリ
  • リリースノートを確認して設定変更を把握する
  • 旧バージョンの認証情報の移行が必要な場合があります

デバイス間の同期:

  • 設定ファイルを同期して複数デバイス間の一貫性を実現できます
  • パスの違いに注意してください(Windows vs Unix)
  • 機密情報は個別に設定することをお勧めします

4. トラブルシューティング

設定問題の診断:

# 检查配置文件语法
cat ~/.openclaw/openclaw.json | json_pp

# 深度检查
openclaw doctor --deep

# 查看网关状态
openclaw gateway status

よくある問題:

  • 認証の無効化:実行openclaw models auth setup再設定
  • ゲートウェイが起動できない:ポートの占有を確認し、ログファイルを確認する
  • スキルが使用できない:スキルの依存関係がインストールされているか確認し、API キーを確認する

環境変数の設定

OpenClaw は環境変数による設定をサポートしています:

# API 密钥环境变量
export ANTHROPIC_API_KEY="your-key-here"
export OPENAI_API_KEY="your-key-here"
export DEEPSEEK_API_KEY="your-key-here"

# 自定义配置目录
export OPENCLAW_HOME="~/custom-path/.openclaw"

環境変数の優先順位:

  • 環境変数内の API キーはオンボードウィザードによって自動検出されます
  • 設定ファイルのデフォルト値を上書きできます
  • CI/CD 環境やコンテナ化されたデプロイに適しています

ネットワークとデプロイ設定

ローカルデプロイ

デフォルト設定:

  • バインドアドレス: 127.0.0.1(ローカルマシンのみアクセス可能)
  • ゲートウェイポート: 18789

アクセス方法:

http://127.0.0.1:18789/#token=<your-token>

クラウドデプロイ

OpenClaw はクラウドサーバーへのデプロイをサポートしています:

サポートプラットフォーム:

  • 阿里云(Alibaba Cloud):https://www.aliyun.com/activity/ecs/clawdbot
  • 腾讯云(Tencent Cloud):https://cloud.tencent.com/developer/article/2624973
  • 1Panel
  • Docker コンテナ

クラウド設定の特徴:

  • パブリックアクセス権限の設定が必要です
  • ファイアウォールルールの設定が必要な場合があります
  • ドメイン名のバインドと SSL 証明書をサポート

統合プラットフォーム設定

OpenClaw は複数のインスタントメッセージングプラットフォームをサポートしています:

対応プラットフォーム

  • 海外: WhatsApp, Telegram, Discord, Slack, iMessage
  • 国内:飞书(Feishu)、钉钉(DingTalk)

設定場所

チャットチャネル設定はopenclaw.jsonに保存され、以下を含みます:

  • チャネルタイプ(Slack/飞书など)
  • 認証トークン
  • チャネルのホワイトリスト/ブラックリスト
  • 応答モード(DM/グループチャット)

設定管理

# 添加新渠道
openclaw channels add

# 列出已配置渠道
openclaw channels list

# 配对管理
openclaw pairing list
openclaw pairing approve <platform> <code>
