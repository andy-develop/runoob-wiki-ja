最初のAI Agent

AI Agent プラットフォームは多種多様ですが、核となる目的は同じです。モデルを質問への回答から自動タスク実行へと進化させることです。ノーコードのドラッグ＆ドロップを売りにするものもあれば、エンジニアリング的なカスタマイズを重視するもの、プロセス統合やマルチエージェント連携に特化したものもあります。

異なるレベルの利用シーンを「構築速度」「システム連携」「制御深度」という3つの側面に分けます。

0 アプリケーションコードを生成

まず、最も簡単な秒哒を使ってアプリを生成できます。 先に公式サイトへアクセスして登録しましょう。秒哒公式サイト、ログイン後、入力ボックスに生成したいアプリを入力します。

次に秒哒が要件ドキュメントを生成します。かなり詳細です。そして右側の「ドキュメントを編集」または「アプリを生成」ボタンをクリックすると、その要件に基づいてそのままアプリの生成が始まります。

次にコード生成が始まります。その間、一行のコードも書く必要はありません。そのまま生成されます。

インターフェースと使用感を見てみましょう。非常に使いやすいです。

また、プラグイン部分では他の高度な機能もサポートしています。例えば動画などです。

もし何を見ればいいか分からない場合は、アプリ広場で他の人が作った優れたプロダクトを見ることもできます。
