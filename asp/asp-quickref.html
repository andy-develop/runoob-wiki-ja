ASP クイックリファレンス

サンプルによる ASP クイックリファレンスです。印刷してポケットに入れ、いつでも使用できるようにしましょう。

基本構文

ASP スクリプトは <% と %> で囲まれます。ブラウザへの出力を書き込むには：

<html>
<body>
<% response.write("Hello World!") %>
</body>
</html>

ASP の既定言語は VBScript です。他のスクリプト言語を使用する場合は、ASP ページの先頭に言語の指定を挿入します：

<%@ language="javascript" %>
<html>
<body>

<%
....
%>

フォームとユーザー入力

Request.QueryString は、method="get" のフォーム内の値を収集するために使用します。GET メソッドを使用してフォームから送信された情報は、すべてのユーザーに表示され（ブラウザのアドレスバーに表示されます）、送信できる情報量にも制限があります。

Request.Form は、method="post" を使用するフォーム内の値を収集するために使用します。POST メソッドを使用してフォームから送信された情報は、ユーザーには見えず、送信する情報量に制限はありません。

ASP Cookies

Cookie はユーザーを識別するためによく使用されます。Cookie は、サーバーがユーザーのコンピュータに残す小さなファイルです。同じコンピュータがブラウザを介してページを要求するたびに、そのコンピュータは Cookie を送信します。

Response.Cookies コマンドは、Cookie を作成するために使用します：

<%
Response.Cookies("firstname")="Alex"
Response.Cookies("firstname").Expires="May 10,2002"
%>

注：Response.Cookies コマンドは <html> タグの前に記述する必要があります！

"Request.Cookies" コマンドは、Cookie の値を取得するために使用します：

<%
fname=Request.Cookies("firstname")
response.write("Firstname=" & fname)
%>

ファイルのインクルード

#include ディレクティブを使用すると、サーバーが ASP ファイルを実行する前に、別の ASP ファイルの内容をその ASP ファイルに挿入できます。#include ディレクティブは、関数、ヘッダー、フッター、または他の複数のページで繰り返し使用する必要がある要素などを作成するために使用します。

構文：

<!--#include virtual="somefile.inc"-->
または
<!--#include file ="somefile.inc"-->

仮想ディレクトリで始まるパスを指定するには、キーワード virtual を使用します。仮想ディレクトリ /html に "header.inc" という名前のファイルがある場合、次のコード行は "header.inc" ファイルの内容を挿入します。

<!-- #include virtual ="/html/header.inc" -->

相対パスを指定するには、キーワード file を使用します。相対パスは、参照するファイルを含むディレクトリから始まります。html ディレクトリ内にファイルがあり、html ディレクトリ内に "header.inc" ファイルがある場合、次のコード行はファイルに "header.inc" の内容を挿入します。

<!-- #include file ="headersheader.inc" -->

上位レベルディレクトリ内のファイルを参照するには、構文 (..) を伴うキーワード file を使用します。

Global.asa

Global.asa ファイルはオプションのファイルで、ASP アプリケーション内のすべてのページからアクセスできるオブジェクト、変数、メソッドの宣言を含めることができます。

注：Global.asa ファイルは ASP アプリケーションのルートディレクトリに配置する必要があり、各アプリケーションに配置できる Global.asa ファイルは 1 つだけです。

Global.asa ファイルには、次の内容のみを含めることができます：

  • Application イベント
  • Session イベント
  • <object> 宣言
  • TypeLibrary 宣言
  • #include ディレクティブ

Application および Session イベント

Global.asa では、application オブジェクトと session オブジェクトに対して、application/session の開始時に何を行うか、application/session の終了時に何を行うかを指定できます。このタスクを実行するコードは、イベントハンドラ内に配置されます。注：Global.asa ファイルでは ASP のスクリプト区切り文字（<% と %>）を使用してスクリプトを挿入できないため、サブルーチンを HTML の <script> タグ内に配置する必要があります：

<script language="vbscript" runat="server">
sub Application_OnStart
' some code
end sub
sub Application_OnEnd
' some code
end sub
sub Session_OnStart
' some code
end sub
sub Session_OnEnd
' some code
end sub
</script>

<object> 宣言

<object> タグを使用して、Global.asa ファイル内に session または application スコープを持つオブジェクトを作成できます。注：<object> タグは <script> タグの外側に配置する必要があります！

構文：

<object runat="server" scope="scope" id="id"
{progid="progID"|classid="classID"}>
.......
</object>

TypeLibrary 宣言

TypeLibrary（タイプライブラリ）は、COM オブジェクトに対応する DLL ファイルを格納するコンテナです。Global.asa ファイルに TypeLibrary の呼び出しを含めることで、COM オブジェクトの定数にアクセスでき、ASP コードのエラー報告も向上します。Web アプリケーションがタイプライブラリで宣言されたデータ型の COM オブジェクトに依存している場合は、Global.asa でタイプライブラリを宣言できます。

構文：

<!--METADATA TYPE="TypeLib"
file="filename"
uuid="typelibraryuuid"
version="versionnumber"
lcid="localeid"
-->

Session オブジェクト

Session オブジェクトは、ユーザーセッションに関する情報を格納したり、ユーザーセッションの設定を変更したりするために使用します。Session オブジェクトに格納された変数は、単一のユーザーの情報を保持し、アプリケーション内のすべてのページで使用できます。

コレクション

  • Contents - スクリプトコマンドによってセッションに追加されたすべてのアイテムを含みます。
  • StaticObjects - HTML の <object> タグを使用してセッションに追加されたすべてのオブジェクトを含みます。
  • Contents.Remove(item/indexContents.Remove() - Contents コレクションから項目を削除します。
  • Contents.RemoveAll() - Contents コレクションからすべての項目を削除します。

プロパティ

  • CodePage - 動的コンテンツを表示するときに使用する文字セットを指定します。
  • LCID - 動的コンテンツの表示に使用するロケール識別子を設定します。
  • SessionID - session id を返します。
  • Timeout - session のタイムアウト時間を設定または返します。

メソッド

  • Abandon - session オブジェクト内のすべてのオブジェクトを破棄します。

Application オブジェクト

一緒に連携して特定のタスクを実行する ASP ファイルのグループをアプリケーションと呼びます。Application オブジェクトは、これらのファイルをまとめるために使用します。すべてのユーザーが 1 つの Application オブジェクトを共有します。Application オブジェクトには、アプリケーション内の多くのページで使用される情報（データベース接続情報など）が格納されます。

コレクション

  • Contents - スクリプトコマンドによってアプリケーションに追加されたすべての項目を含みます。
  • StaticObjects - HTML の <object> タグを使用してアプリケーションに追加されたすべてのオブジェクトを含みます。
  • Contents.Remove - Contents コレクションから項目を削除します。
  • Contents.RemoveAll - Contents コレクションからすべての項目を削除します。

メソッド

  • Lock - ユーザーが Application オブジェクトのプロパティを変更するのを防ぎます。
  • Unlock - ユーザーが Application オブジェクトのプロパティを変更することを許可します。

Response オブジェクト

Response オブジェクトは、サーバーからユーザーに出力結果を送信するために使用します。

コレクション

  • Cookies(name) - cookie の値を設定します。cookie が存在しない場合は、cookie を作成して指定された値を設定します。

プロパティ

  • Buffer - 出力をバッファリングするかどうかを指定します。出力がバッファリングに設定されている場合、サーバーはすべてのサーバースクリプトが処理されるまで、またはスクリプトが Flush または End メソッドを呼び出すまで、ブラウザへの応答をブロックします。このプロパティを設定する場合、ASP ファイル内の <html> タグの前に置く必要があります。
  • CacheControl - プロキシサーバーが ASP によって生成された出力をキャッシュできるかどうかを設定します。Public に設定すると、プロキシサーバーはページをキャッシュします。
  • Charset(charset_name) - Charset - 文字セットの名前（例："ISO8859-1"）を Response オブジェクトの Content-Type ヘッダーに追加します。
  • ContentType - Response オブジェクトの HTTP コンテンツタイプ（例："text/html"、"image/gif"、"image/jpeg"、"text/plain"）を設定します。デフォルトは "text/html" です。
  • Expires - ページが失効するまでのブラウザキャッシュ時間（分）を設定します。
  • ExpiresAbsolute - ブラウザ上でページキャッシュが失効する日時を設定します。
  • IsClientConnected - クライアントがサーバーから切断されているかどうかを示します。
  • Pics(pics_label) - response ヘッダーの PICS タグに値を追加します。
  • Status - サーバーによって返されるステータス行の値を指定します。

メソッド

  • AddHeader(name, value) - HTTP レスポンスに新しい HTTP ヘッダーと値を追加します。
  • AppendToLog string - サーバーログエントリの末尾に文字列を追加します。
  • BinaryWrite(data_to_write) - 文字変換を行わずに、出力に直接データを書き込みます。
  • Clear - バッファリングされた出力をクリアします。このメソッドを使用してエラーを処理します。Response.Buffer が true に設定されていない場合、このメソッドはランタイムエラーを発生させます。
  • End - スクリプトの処理を停止し、現在の結果を返します。
  • Flush - バッファリングされた出力を直ちに送信します。Response.Buffer が true に設定されていない場合、このメソッドはランタイムエラーを発生させます。
  • Redirect(url) - ユーザーを別の URL にリダイレクトします。
  • Write(data_to_write) - ユーザーにテキストを書き込みます。

Request オブジェクト

ブラウザがサーバーにページを要求するとき、この動作は request（リクエスト）と呼ばれます。Request オブジェクトはユーザーから情報を取得するために使用されます。

コレクション

  • ClientCertificate - クライアント証明書に格納されているすべてのフィールド値を含みます。
  • Cookies(name) - HTTP リクエストで送信されたすべての cookie 値を含みます。
  • Form(element_name) - post メソッドを使用してフォームから送信されたすべてのフォーム（入力）値を含みます。
  • QueryString(variable_name) - HTTP クエリ文字列内のすべての変数値を含みます。
  • ServerVariables(server_variable) - すべてのサーバー変数値を含みます。

プロパティ

  • TotalBytes - リクエスト本文でクライアントが送信した合計バイト数を返します。

メソッド

  • BinaryRead - post リクエストの一部としてクライアントからサーバーに送信されたデータを取得します。

Server オブジェクト

Server オブジェクトはサーバー上のプロパティとメソッドにアクセスするために使用されます。

プロパティ

  • ScriptTimeout - スクリプトが終了するまでに実行できる最大時間（秒）を設定または返します。

メソッド

  • CreateObject(type_of_object) - オブジェクトのインスタンスを作成します。
  • Execute(path) - ASP ファイル内から別の ASP ファイルを実行します。呼び出された ASP ファイルの実行が完了すると、制御は元の ASP ファイルに戻ります。
  • GetLastError() - 発生したエラー状態を説明する ASPError オブジェクトを返します。
  • HTMLEncode(string) - 文字列に HTML エンコードを適用します。
  • MapPath(path) - 相対パスまたは仮想パスを物理パスにマップします。
  • Transfer(path) - 処理のためにすべての状態情報を別のファイルに送信します。転送後、プログラムの制御は元の ASP ファイルには戻りません。
  • URLEncode(string) - 文字列に URL エンコード規則を適用します。
