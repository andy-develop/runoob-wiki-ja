Julia 正規表現

正規表現（regular expression）は、文字列のマッチングパターンを記述したものであり、文字列が特定の部分文字列を含むかどうかを調べたり、マッチした部分文字列を置換したり、ある文字列から条件に合う部分文字列を取り出したりするために使用できます。

Julia は Perl 互換の正規表現（regexes）を備えています。

Julia の正規表現には、マッチ、置換、変換の3つの形式があります。

  • マッチ：m//（さらに / と略記でき/、m を省略します）

  • 置換：s///

  • 変換：tr///

これら3つの形式は通常、=~ 或 !~組み合わせて使用します。=~ はマッチを表し、!~ はマッチしないことを表します。

Julia では、正規表現の入力は接頭辞 r を使ってr始まります：

例

julia> re = r"^\s*(?:#|$)"
r"^\s*(?:#|$)"


julia> typeof(re)
Regex

正規表現が文字列にマッチするかどうかを確認するには、次を使用します。occursin：

例

julia> occursin(r"^\s*(?:#|$)", "not a comment")
false

julia> occursin(r"^\s*(?:#|$)", "# a comment")
true

見てわかるように、occursintrue または false のみを返し、指定した正規表現がその文字列内に出現するかどうかを示します。しかし、通常は文字列がマッチするかどうかだけでなく、どのようにマッチするのかも知りたいものです。マッチした情報を取得するには、代わりに次の関数を使用します。match関数：

例

julia> match(r"^\s*(?:#|$)", "not a comment")

julia> match(r"^\s*(?:#|$)", "# a comment")
RegexMatch("#")

正規表現が指定された文字列にマッチしない場合、match は nothing を返します。nothing は、対話型プロンプトでは何も表示しない特別な値です。表示されないことを除けば、完全に通常の値であり、プログラムでテストできます。

例

m = match(r"^\s*(?:#|$)", line)
if m === nothing
    println("not a comment")
else
    println("blank or comment")
end

正規表現がマッチした場合、match の戻り値は RegexMatch オブジェクトです。このオブジェクトは、式がどのようにマッチしたか、つまりパターンがマッチした部分文字列や、キャプチャされた可能性のある部分文字列を記録します。上記の例ではマッチした部分文字列だけをキャプチャしていますが、コメント文字の後にある空でないテキストをキャプチャしたい場合もあるでしょう。そのようにするには、次のようにします：

例

julia> m = match(r"^\s*(?:#\s*(.*?)\s*$|$)", "# a comment ")
RegexMatch("# a comment ", 1="a comment")

match を呼び出すときに、検索を開始するインデックスを指定することもできます。例：

例

julia> m = match(r"[0-9]","aaaa1aaaa2aaaa3",1)
RegexMatch("1")

julia> m = match(r"[0-9]","aaaa1aaaa2aaaa3",6)
RegexMatch("2")

julia> m = match(r"[0-9]","aaaa1aaaa2aaaa3",11)
RegexMatch("3")

RegexMatch オブジェクトから次の情報を抽出できます：

  • マッチした部分文字列全体：m.match
  • 文字列配列としてキャプチャされた部分文字列：m.captures
  • マッチ全体の開始オフセット：m.offset
  • キャプチャされた部分文字列のオフセット（ベクトルとして）：m.offsets

キャプチャがマッチしない場合、m.capturesその位置には部分文字列は含まれず、何も含まれません。さらに、m.offsetsのオフセットは 0 です（Julia のインデックスは 1 から始まることを思い出してください。したがって、文字列のオフセット 0 は無効です）。次に、やや無理のある例を2つ示します：

例

julia> m = match(r"(a|b)(c)?(d)", "acd")
RegexMatch("acd", 1="a", 2="c", 3="d")

julia> m.match
"acd"

julia> m.captures
3-element Vector{Union{Nothing, SubString{String}}}:
 "a"
 "c"
 "d"

julia> m.offset
1

julia> m.offsets
3-element Vector{Int64}:
 1
 2
 3

julia> m = match(r"(a|b)(c)?(d)", "ad")
RegexMatch("ad", 1="a", 2=nothing, 3="d")

julia> m.match
"ad"

julia> m.captures
3-element Vector{Union{Nothing, SubString{String}}}:
 "a"
 nothing
 "d"

julia> m.offset
1

julia> m.offsets
3-element Vector{Int64}:
 1
 0
 2

キャプチャを配列として返すと便利です。そうすれば、分割代入構文を使ってキャプチャをローカル変数にバインドできます。便宜上、RegexMatch オブジェクトは captures フィールドに委譲するイテレータメソッドを実装しているため、マッチオブジェクトを直接分割代入できます：

例

julia> first, second, third = m; first
"a"

キャプチャグループの番号または名前で RegexMatch オブジェクトにインデックスを付けることでも、キャプチャにアクセスできます：

例

julia> m=match(r"(?<hour>\d+):(?<minute>\d+)","12:45")
RegexMatch("12:45", hour="12", minute="45")

julia> m[:minute]
"45"

julia> m[2]
"45"

replace を使用するとき、`\n` を使って n 番目のキャプチャグループを参照し、置換文字列に接頭辞 `s` を付けることで、置換文字列内でキャプチャを参照できます。キャプチャグループ 0 はマッチ全体を指します。置換内では `\g` を使用して、名前付きキャプチャグループを参照できます。例：

julia> replace("first second", r"(\w+) (?<agroup>\w+)" => s"\g<agroup> \1")
"second first"

明確にするため、番号付きキャプチャグループも `\g` を使用して参照できます。例：

julia> replace("a", r"." => s"\g<0>1")
"a1"

終わりの二重引用符の後に i、m、s、x などのフラグを付けることで、正規表現を変更できます。
