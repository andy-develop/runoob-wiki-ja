Eclipse チュートリアル

Eclipse はオープンソースで、Java ベースの拡張可能な開発プラットフォームです。

Eclipse は Java の統合開発環境（IDE）ですが、もちろん C、C++、PHP、Ruby などの他の開発言語の統合開発環境としても使用できます。

Eclipse には標準のプラグインセットが付属しており、Java 開発ツール（Java Development Kit、JDK）が含まれています。

ライセンス

Eclipse プラットフォームとそのプラグインは、Eclipse Public License（EPL）に基づいて公開されています。

Eclipse Public License（略称 EPL）はオープンソースソフトウェアの公開ライセンスであり、Eclipse 財団が所有する統合開発環境 Eclipse に適用されています。

リリース版

2006年以降、Eclipse 財団は毎年同時リリースを計画しています。現在、同時リリースは主に6月に行われ、続く9月と2月に SR1 および SR2 バージョンがリリースされます。
