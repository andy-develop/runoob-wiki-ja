AngularJS 式

AngularJS の使用式データを HTML にバインドします。

}}

AngularJS 式は二重中括弧内に記述します：{{ expression }}。

AngularJS 式はデータを HTML にバインドします。これはng-bindディレクティブと似た働きをします。

AngularJS は式が書かれた位置でデータを「出力」します。

AngularJS 式非常に似ていますJavaScript 式：それらはリテラル、演算子、変数を含むことができます。

例 {{ 5 + 5 }} または {{ firstName + " " + lastName }}

AngularJS 例

<!DOCTYPE html> <html> <head> <meta charset="utf-8"> <script src="http://cdn.static.runoob.com/libs/angular.js/1.4.6/angular.min.js"></script> </head> <body> <div ng-app=""> <p>私の最初の式: {{ 5 + 5 }}</p> </div> </body> </html>

AngularJS 数値

AngularJS の数値は JavaScript の数値と同様です：

AngularJS 例

<div ng-app="" ng-init="quantity=1;cost=5"> <p>合計金額： {{ quantity * cost }}</p> </div>

試してみる »

ng-bind を使用した同じ例：

AngularJS 例

<div ng-app="" ng-init="quantity=1;cost=5"> <p>合計金額：<span ng-bind="quantity * cost"></span></p> </div>

試してみる »

使用はng-initあまり一般的ではありません。コントローラーの章で、より良いデータ初期化方法を学びます。

AngularJS 式と JavaScript 式

JavaScript 式と同様に、AngularJS 式は文字、演算子、変数を含むことができます。

JavaScript 式とは異なり、AngularJS 式は HTML 内に記述できます。

JavaScript 式とは異なり、AngularJS 式は条件分岐、ループ、例外をサポートしません。

JavaScript 式とは異なり、AngularJS 式はフィルターをサポートします。
