AngularJS 指令

このチュートリアルで使用する AngularJS ディレクティブ:

指令 描述
ng-app アプリケーションのルート要素を定義します。
ng-bind HTML要素をアプリケーションデータにバインドする
ng-bind-html HTML要素のinnerHTMLをアプリケーションデータにバインドし、HTML文字列中の危険な文字を除去する
ng-bind-template テンプレートで置き換えるテキストコンテンツを指定します。
ng-blur blur イベントの動作を指定する
ng-change コンテンツが変更されたときに実行する式を指定する
ng-checked 要素がチェックされているかどうかを指定する
ng-class HTML要素が使用するCSSクラスを指定する
ng-class-even ng-classに似ているが、偶数の行でのみ機能する
ng-class-odd ng-classに似ているが、奇数の行でのみ機能する
ng-click 要素がクリックされたときの動作を定義します。
ng-cloak アプリケーションのロード中にちらつきを防ぎます。
ng-controller アプリケーションのコントローラーオブジェクトを定義します。
ng-copy コピーイベントの動作を指定する
ng-csp コンテンツのセキュリティポリシーを変更する
ng-cut カットイベントの動作を指定する
ng-dblclick ダブルクリックイベントの動作を指定する
ng-disabled 要素が無効かどうかを指定します。
ng-focus フォーカスイベントの動作を指定する
ng-form HTMLフォームがコントローラーフォームを継承することを指定する
ng-hide HTML 要素を非表示または表示する
ng-href <a> 要素にリンクを指定する
ng-if 条件がfalseの場合、HTML要素を削除する
ng-include アプリケーションに HTML ファイルを含める
ng-init アプリケーションの初期化値を定義する
ng-jq アプリケーションが使用する必要があるライブラリ（例：jQuery）を定義する
ng-keydown キーを押したときのイベント動作を指定します。
ng-keypress キーを押したときのイベント動作を指定します。
ng-keyup キーを離したときのイベント動作を指定します。
ng-list テキストをリスト（配列）に変換します。
ng-model HTMLコントローラーの値をアプリケーションデータにバインドする
ng-model-options モデルの更新方法を指定する
ng-mousedown マウスボタンを押したときの動作を指定します。
ng-mouseenter マウスポインターが要素を通過したときの動作を指定します。
ng-mouseleave マウスポインターが要素から離れたときの動作を指定します。
ng-mousemove マウスポインターが指定された要素内を移動するときの動作を指定する
ng-mouseover マウスポインターが要素の上にあるときの動作を指定する
ng-mouseup 要素上でマウスボタンを離したときの動作を指定する
ng-non-bindable 要素または子要素がデータをバインドできないことを指定します。
ng-open 要素の open 属性を指定する
ng-options <select> リスト内の <options> を指定する
ng-paste ペーストイベントの動作を指定する
ng-pluralize ローカライズルールに基づいて情報を表示します。
ng-readonly 要素の readonly 属性を指定する
ng-repeat コレクション内の各データ項目のテンプレートを定義します。
ng-selected 要素の selected 属性を指定する
ng-show HTML 要素を表示または非表示にする
ng-src <img> 要素の src 属性を指定する
ng-srcset <img> 要素の srcset 属性を指定する
ng-style 要素の style 属性を指定する
ng-submit onsubmitイベントが発生したときに実行する式を指定する
ng-switch 子要素を表示または非表示にする条件を指定します。
ng-transclude 埋め込み先の位置を指定する
ng-value input 要素の値を指定する

AngularJS 全局 API

转换

API 描述
angular.lowercase() 文字列を小文字に変換する
angular.uppercase() 文字列を大文字に変換する
angular.copy() 配列またはオブジェクトのディープコピー
angular.forEach() オブジェクトまたは配列の反復関数。

比较

API 描述
angular.isArray() 参照が配列の場合にtrueを返す
angular.isDate() 参照が日付の場合にtrueを返す
angular.isDefined() 参照が定義されている場合にtrueを返す
angular.isElement() 参照がDOM要素の場合にtrueを返す
angular.isFunction() 参照が関数の場合にtrueを返す
angular.isNumber() 参照が数値の場合にtrueを返す
angular.isObject() 参照がオブジェクトの場合にtrueを返す
angular.isString() 参照が文字列の場合にtrueを返す
angular.isUndefined() 参照が未定義の場合にtrueを返す
angular.equals() 2つのオブジェクトが等しい場合にtrueを返す

JSON

API 描述
angular.fromJson() JSON 文字列をデシリアライズする
angular.toJson() JSON 文字列をシリアライズする

基础

API 描述
angular.bootstrap() AngularJS を手動で起動する
angular.element() 一部のDOM要素またはHTML文字列をラップして、jQuery要素として処理する
angular.module() AngularJS モジュールを作成、登録、または取得します。

グローバル API の解説:Angular API。
