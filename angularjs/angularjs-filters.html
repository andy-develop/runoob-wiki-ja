AngularJS フィルター

フィルターはパイプ文字（|）を使用して式やディレクティブに追加できます。

AngularJS フィルター

AngularJS フィルターはデータの変換に使用できます：

フィルター 説明
currency 数値を通貨形式にフォーマットします。
filter 配列項目からサブセットを選択します。
lowercase 文字列を小文字にフォーマットします。
orderBy 特定の式に基づいて配列を並べ替えます。
uppercase 文字列を大文字にフォーマットします。

式にフィルターを追加する

フィルターは、パイプ文字（|）とフィルターを使用して式に追加できます。

（以下の2つのサンプルでは、前の章で説明した person コントローラーを使用します。）

uppercaseフィルターは文字列を大文字にフォーマットします：

AngularJS サンプル

<div ng-app="myApp" ng-controller="personCtrl">

<p>名前は{{ lastName | uppercase }}</p>

</div>

lowercaseフィルターは文字列を小文字にフォーマットします：

AngularJS サンプル

<div ng-app="myApp" ng-controller="personCtrl">

<p>名前は{{ lastName | lowercase }}</p>

</div>

currency フィルター

currencyフィルターは数値を通貨形式にフォーマットします：

AngularJS サンプル

<div ng-app="myApp" ng-controller="costCtrl">

<input type="number" ng-model="quantity">
<input type="number" ng-model="price">

<p>合計価格 ={{ (quantity * price) | currency }}</p>

</div>

ディレクティブにフィルターを追加する

フィルターは、パイプ文字（|）とフィルターを使用してディレクティブに追加できます。

orderByフィルターは式に基づいて配列を並べ替えます：

AngularJS サンプル

<div ng-app="myApp" ng-controller="namesCtrl">

<ul>
  <li ng-repeat="x in names | orderBy:'country'">
    {{ x.name + ', ' + x.country }}
  </li>
</ul>

</div>

試してみる »

入力のフィルタリング

入力フィルターは、パイプ文字（|）とフィルターを使用してディレクティブに追加できます。フィルターの後にはコロンとモデル名が続きます。

filterフィルターは配列からサブセットを選択します：

AngularJS サンプル

<div ng-app="myApp" ng-controller="namesCtrl">

<p><input type="text" ng-model="test"></p>

<ul>
  <li ng-repeat="x in names | filter:test | orderBy:'country'">
    {{ (x.name | uppercase) + ', ' + x.country }}
  </li>
</ul>

</div>

AngularJS サンプル

var app = angular.module('myApp', []); app.controller('myCtrl', function($scope) { $scope.msg = "Runoob"; }); app.filter('reverse', function() { //依存関係を注入できます return function(text) { return text.split("").reverse().join(""); } });

    1、uppercase、lowercase 大文字小文字変換

    {{ "lower cap string" | uppercase }}   // 结果：LOWER CAP STRING
{{ "TANK is GOOD" | lowercase }}      // 结果：tank is good

    2、date フォーマット

    {{1490161945000 | date:"yyyy-MM-dd HH:mm:ss"}} // 2017-03-22 13:52:25

    {{149016.1945000 | number:2}}

    {{ 250 | currency }}            // 结果：$250.00
{{ 250 | currency:"RMB ￥ " }}  // 结果：RMB ￥ 250.00

    入力フィルターは、パイプ文字（|）とフィルターを使用してディレクティブに追加できます。フィルターの後にはコロンとモデル名が続きます。

    filter フィルターは配列からサブセットを選択します

     // 查找name为iphone的行
{{ [{"age": 20,"id": 10,"name": "iphone"},
{"age": 12,"id": 11,"name": "sunm xing"},
{"age": 44,"id": 12,"name": "test abc"}
] | filter:{'name':'iphone'} }}

    6、limitTo 切り取り

    {{"1234567890" | limitTo :6}} // 从前面开始截取6位
{{"1234567890" | limitTo:-4}} // 从后面开始截取4位

{"age": 12,"id": 11,"name": "sunm xing"},
{"age": 44,"id": 12,"name": "test abc"}
] | orderBy:'id':true }}

// 根据id升序排
{{ [{"age": 20,"id": 10,"name": "iphone"},
{"age": 12,"id": 11,"name": "sunm xing"},
{"age": 44,"id": 12,"name": "test abc"}
] | orderBy:'id' }}

    date フィルターは、指定された形式に基づいて日付を文字列にフォーマットします。

    フォーマット文字列の基本的なパラメータ：

    • yyyy: 年を4桁の数字で表します（例：AD 1 => 0001、AD 2010 => 2010）
    • yy: 年を2桁の数字で表します（00-99）（例：AD 2001 => 01、AD 2010 => 10）
    • y: 年を1桁の数字で表します（例：AD 1 => 1、AD 199 => 199）
    • MMMM: 月を英語の完全な名前で表します（January-December）
    • MMM: 月を英語の略称で表します（Jan-Dec）
    • MM: 月を2桁の数字で表します（01-12）
    • M: 月（1-12）
    • dd: 日を2桁の数字で表します（01-31）
    • d: 日（1-31）
    • EEEE: 曜日を英語の完全な名前で表します（Sunday-Saturday）
    • EEE: 曜日を英語の略称で表します（Sun-Sat）
    • HH: 24時間制の時を2桁の数字で表します（00-23）
    • H: 24時間制の時（0-23）
    • hh: 午前/午後の時を2桁の数字で表します（01-12）
    • h: 午前/午後の時（1-12）
    • mm: 分を2桁の数字で表します（00-59）
    • m: 分（0-59）
    • ss: 秒を2桁の数字で表します（00-59）
    • s: 秒（0-59）
    • sss: ミリ秒（000-999）
    • a: AM/PM
    • Z: 4桁の数字（+記号）でタイムゾーンオフセットを表します（-1200～+1200）
    • ww: 年の週番号を2桁の数字で表します（00-53）。第1週（01）はその年の最初の木曜日です。
    • w: 年の週番号（0-53）。第1週（1）はその年の最初の木曜日です。
    • G,GG,GGG: 年代を示す文字列の略称形式。例：AD（西暦）
    • GGGG: 年代を示す文字列の完全な名前。例：Anno Domini（西暦）

    上記のパラメータは、自分の好みに合わせて自由に組み合わせて、希望する形式を得ることができます。例：yyyy-MM-dd など。

    フォーマット文字列には、すぐに使用できる事前定義されたローカライズ形式も用意されています：

    • medium：'MMM d,y h:mm:ss a' 例：Sep 3, 2010 12:05:08 PM
    • short：'M/d/yy h:mm a' 例： 9/3/10 12:05 PM
    • fullDate: 'EEEE,MMMM d,y' 例：Friday, September 3, 2010
    • longDate: 'MMMM d,y' 例：September 3, 2010
    • mediumDate: 'MMM d,y' 例： Sep 3, 2010
    • shortDate: 'M/d/y' 例： 9/3/10
    • mediumTime: 'h:mm:ss a' 例：12:05:08 PM
    • shortTime: 'h:mm a' 例：12:05 PM

    フォーマット文字列にはテキスト値を含めることができます。これらは単一引用符で囲む必要があります（例："h 'in the morning'"）。単一引用符を出力したい場合は、シーケンス内で単一引用符を2つ使用します（例："h 'o''clock'"）。

    date フィルターの使い方：

    1. HTMLでの使い方：{{ date_expression | date : format : timezone}}

    サンプル：

    <span>{{1288323623006 | date:'medium'}}</span><br>
<span>{{1288323623006 | date:'yyyy-MM-dd HH:mm:ss Z'}}</span><br>
<span>{{'1288323623006' | date:'MM/dd/yyyy @ h:mma'}}</span><br>
<span>{{'1288323623006' | date:"MM/dd/yyyy 'at' h:mma"}}</span><br>

    試してみる »

    2. JavaScriptでの使い方：$filter('date')(date, format, timezone)

    サンプル：

    var today = new Date();
$scope.formatDate = $filter('date')(today, 'yyyy-MM-dd');
