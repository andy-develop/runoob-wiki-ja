AngularJS 服务(Service)

AngularJS では、独自のサービスを作成するか、組み込みサービスを使用できます。

サービスとは何ですか？

AngularJS において、サービスは関数またはオブジェクトであり、AngularJS アプリケーション内で使用できます。

AngularJSには30以上のサービスが組み込まれています。

有个$locationサービスは、現在のページのURLアドレスを返すことができます。

实例

var app = angular.module('myApp', []);
app.controller('customersCtrl', function($scope, $location) {
    $scope.myUrl = $location.absUrl();
});

注意$locationサービスは controller にパラメータとして渡されます。それを使用するには、controller 内で定義する必要があります。

なぜサービスを使用するのか？

多くのサービス、例えば $location サービスでは、DOM に存在するオブジェクトを使用できます。これは window.location オブジェクトに似ていますが、window.location オブジェクトは AngularJS アプリケーションにおいていくつかの制限があります。

AngularJS は常にアプリケーションを監視し、イベントの変化を処理します。AngularJS は使用します。$location服务比使用window.location对象更好。

$http 服务

$httpAngularJS アプリケーションで最もよく使用されるサービスです。サービスはサーバーにリクエストを送信し、アプリケーションはサーバーから送信されたデータに応答します。

实例

使用$httpサービスはサーバーにデータをリクエストする：

var app = angular.module('myApp', []);
app.controller('myCtrl', function($scope, $http) {
    $http.get("welcome.htm").then(function (response) {
        $scope.myWelcome = response.data;
    });
});

$timeout 服务

AngularJS $timeoutサービスはJSに対応しています window.setTimeout函数。

实例

2秒後に情報を表示：

var app = angular.module('myApp', []);
app.controller('myCtrl', function($scope, $timeout) {
    $scope.myHeader = "Hello World!";
    $timeout(function () {
        $scope.myHeader = "How are you today?";
    }, 2000);
});

$interval 服务

AngularJS $intervalサービスはJSに対応していますwindow.setInterval函数。

实例

毎秒情報を表示：

var app = angular.module('myApp', []);
app.controller('myCtrl', function($scope, $interval) {
    $scope.theTime = new Date().toLocaleTimeString();
    $interval(function () {
        $scope.theTime = new Date().toLocaleTimeString();
    }, 1000);
});

カスタムサービスの作成

カスタムサービスを作成し、モジュールにリンクできます:

创建名为hexafy的服务:

app.service('hexafy', function() {
    this.myFunc = function (x) {
        return x.toString(16);
    }
});

カスタムサービスを使用するには、コントローラーを定義する際に独立して追加し、依存関係を設定する必要があります:

实例

カスタムサービスの使用hexafy数値を16進数に変換する：

app.controller('myCtrl', function($scope, hexafy) {
    $scope.hex = hexafy.myFunc(255);
});

フィルター内で、カスタムサービスを使用する

カスタムサービスを作成してアプリケーションに接続すると、コントローラー、ディレクティブ、フィルター、または他のサービスでそれを使用できます。

在过滤器myFormat中使用服务hexafy:

app.filter('myFormat',['hexafy', function(hexafy) {
    return function(x) {
        return hexafy.myFunc(x);
    };
}]);

    Angular の多くのサービスには DOM 内に対応するオブジェクトがあります。では、なぜこれらのオブジェクトを使わずにサービスを使うのでしょうか?

    以下のコードは、$interval サービスを使用せずに、$apply を使用して、毎秒情報を表示する機能を実現します。

    var app = angular.module('myApp', []);
app.controller('myCtrl', function($scope) {
    $scope.theTime = new Date().toLocaleTimeString();
    $scope.setTime = function() {
        // $apply 方法可以修改数据
        $scope.$apply(function() {
            $scope.theTime = new Date().toLocaleTimeString();
        });
    };
    setInterval($scope.setTime, 1000);
});

    $watch：データの変化を継続的に監視し、UIを更新する。例：

    <div ng-app="myApp" ng-controller="myCtrl">
   <b>请输入姓名：</b><br>
   <b>姓：</b><input type="text" ng-model="lastName"><br>
   <b>名：</b><input type="text" ng-model="firstName"><br>
   <h1>{{ lastName + " " + firstName }}</h1>
   <h2>{{ fullName }}</h2>
</div>
<script>
var app = angular.module('myApp', []);
app.controller('myCtrl', function($scope) {
   $scope.lastName = "";
   $scope.firstName = "";

   //监听lastName的变化，更新fullName
   $scope.$watch('lastName', function() {
      $scope.fullName = $scope.lastName + " " + $scope.firstName;
   });

   //监听firstName的变化，更新fullName
   $scope.$watch('firstName', function() {
      $scope.fullName = $scope.lastName + " " + $scope.firstName;
   });
});
</script>

    controller には2つの書き方があります。2つの書き方の違いについて説明します:

    写法 1：

    app.controller('myCtrl', function($scope, $location) {
    $scope.myUrl = $location.absUrl();
});

    写法2：

    app.controller('myCtrl', ["$scope","$location",function($scope,$location) {
    $scope.myUrl = $location.absUrl();
}]);

    どちらの書き方も正しいが、2番目の書き方を推奨する。なぜなら、1番目の書き方はjs圧縮後に問題が発生するからだ。2番目の書き方はjs圧縮に完全に対応できる。その理由は：js圧縮後、変数名がリネームされるため、1番目の書き方はエラーになるからだ。

    上記の例の2番目の書き方は、次のようにも書けます:

    app.controller('myCtrl', ["$scope","$location",function(a, b) {
    a.myUrl = b.absUrl();
}]);
