AngularJS API

API とはApplication Programming Interface（アプリケーションプログラミングインターフェース）。

AngularJS グローバル API

AngularJS グローバル API は、一般的なタスクを実行するための JavaScript 関数のコレクションです。例：

  • オブジェクトの比較
  • オブジェクトの反復処理
  • オブジェクトの変換

グローバル API 関数は angular オブジェクトを使用してアクセスします。

以下に一般的な API 関数をいくつか示します：

API 説明
angular.lowercase (<angular1.7）
angular.$$lowercase()（angular1.7+）		 文字列を小文字に変換する
angular.uppercase() (<angular1.7）
angular.$$uppercase()（angular1.7+）		 文字列を大文字に変換する
angular.isString() 指定されたオブジェクトが文字列かどうかを判定し、文字列の場合は true を返します。
angular.isNumber() 指定されたオブジェクトが数値かどうかを判定し、数値の場合は true を返します。

注意：AngularJS 1.7 以降、angular.lowercase と angular.uppercase メソッドは削除され、angular.$$lowercase と angular.$$uppercase に変更されました。

    Angular は一連のパブリックメソッドをカプセル化しており、JS をより簡単に使用するのに役立ちます。

    1、angular.bind()

    angular.bind は Function.prototype.bind に似ており、関数のカリー化を実装し、関数のプロキシを返します。例：

    //函数原型
angular.bind(/*this对象*/self, /*要封装的function*/fn, /*参数列表*/args);
//原始函数

function fun(arg1, arg2, arg3) {
  console.log(this);
  console.log(arg1);
  console.log(arg2);
  console.log(arg3);
}
fun('arg1', 'arg2', 'arg3');
//如果几个常用参数都是固定的，而且该函数被调用频繁，那么就可以包装一下
var fun2 = angular.bind(window, fun, 'arg1', 'arg2');
//新的调用方式
fun2('arg3');

    2、angular.bootstrap()

    angular を使用して要素のレンダリングを実行するために使用します。これは angular の起動メソッドでもあり、ページに ng-app を指定していない場合は、この関数を手動で呼び出して起動する必要があります。

    angular.bootstrap(/*Dom元素*/element, /*Array/String/Function*/[modules], /*Object*/[config]);

//常规用法
angular.bootstrap(document, ['app'])
//带配置项
angular.bootstrap(document, ['app'], {strictDi: true/*Defaults: false*/})

    3、angular.copy()

    Angular.copy はオブジェクトをコピーするために使用します。angular の双方向バインディングの特性により、$scope オブジェクトを直接操作すると UI の表示が簡単に変わってしまいます。その場合は、angular.copy を使ってオブジェクトのコピーを作成してから操作する必要があります。

    //原型
angular.copy(source, [destination]);

var obj = {a: 1};
var obj2 = angular.copy(obj);
var obj3;
angular.copy(obj, obj3);
console.log(obj2 === obj) //false
console.log(obj3 === obj) //false
var obj4;
//第二个和参数和返回值是相等的，而且第二个参数不管以前是什么，都会被重新赋值
var obj5 = angular.copy(obj, obj4);
console.log(obj4 === obj5); //true

    4、angular.element()

    jQuery のセレクタと同等です。angular の前に jQuery を読み込んでいない場合は、jqLite でラップされます。

    angular.element('body');
//等价于
$('body');

//用法
var $body = angular.element('body');

    5、angular.equals()

    2 つのオブジェクトが等しいかどうかを比較するために使用します。以下の例のルールは JS とは異なるので、注意して見分けてください。

    var obj1 = {a: 1};
var obj2 = obj1;
//引用一致，则相等
console.log(angular.equals(obj1, obj2)); // true

obj2 = {a: 1};
//引用不一致，对象表现一致，则相等
console.log(angular.equals(obj1, obj2)); // true

obj2 = {a: 1,$a: 2};
//对象比较时，忽略以$开头的属性
console.log(angular.equals(obj1, obj2)); // true

obj1 = /aa/;
obj2 = /aa/;
//正则表达式表现相等，则相等
console.log(angular.equals(obj1, obj2)); // true

//NaN与NaN比较，则相等
console.log(angular.equals(NaN, NaN)); // true

    6、angular.extend()

    機能は jQuery.extend とほぼ同じです：

    //原型-第一个参数为目标，之后的参数为源，同时返回dst
angular.extend(dst, src);

//示例
var obj1 = {a: 1};
var obj2 = angular.extend(obj1, {a: 2}, {b: 3});
console.log(obj1)
console.log(obj1 === obj2); //true

    7、angular.forEach()

    angular.forEach はオブジェクトまたは配列を反復処理するために使用します。ES5 の Array.prototype.forEach に似ています。

    //原型
angular.forEach(obj, iterator, [context]);

var values = {name: 'misko', gender: 'male'};
var arr = ['misko', 'male'];
angular.forEach(values, function (value, key) {
  console.log(key + ' = ' + value);
});
angular.forEach(arr, function (value, i) {
  console.log(i + ' = ' + value);
});
//还可以传递this
var obj = {};
angular.forEach(values, function (value, key) {
  obj[key] = value;
}, obj);
console.log(obj);

    8、angular.fromJson()

    angular.fromJson は JSON 文字列を JSON オブジェクトに変換します。注意：JSON 形式を厳密に満たす必要があります。たとえば、プロパティは二重引用符で囲む必要があります。この関数の内部実装は JSON.parse() を利用しています。

    //原型
angular.fromJson(/*string*/ jsonString)

var jsonString = '{"p1": "xx", "p2": 1, "p3": true}';
var jsonObj = angular.fromJson(jsonString);
console.log(jsonObj);

    9、angular.toJson()

    angular.toJson はオブジェクト、配列、日付、文字列、数値を JSON 文字列に変換できます。

    //原型
angular.toJson(obj, pretty);

var obj = {p1: 1, p2: true, p3: '2'};
var jsonString = angular.toJson(obj);
console.log(jsonString);
//美化输出格式（设置为true，默认采用2个字符缩进）
jsonString = angular.toJson(obj, true);
console.log(jsonString);
//还可以设置缩进字符数
jsonString = angular.toJson(obj, 10);
console.log(jsonString);

    10、angular.identity()

    angular.identity は、その関数の引数の最初の値を返します。関数型コードを記述する際に非常に便利です（未使用）。

    //官方示例
function transformer(transformationFn, value) {
  return (transformationFn || angular.identity)(value);
};
//简单演示
var value = angular.identity('a', 1, true);
console.log(value); // 'a'

    11、angular.injector()

    angular.injector は injector オブジェクトを作成でき、サービスを検索したり、依存性注入に使用したりできます。

    //原型，[strictDi]默认false，如果true，表示执行严格依赖模式，
//angular则不会根据参数名称自动推断类型，必须使用['xx', function(xx){}]这种形式。
angular.injector(modules, [strictDi]); 

//定义模块A
var moduleA = angular.module('moduleA', [])
  .factory('F1', [function () {
    return {
      print: function () {
        console.log('I\'m F1 factory');
      }
    }
  }]);
var $injector = angular.injector(['moduleA'])
$injector.invoke(function (F1) {
  console.log(F1.print());
});
//此种写法会报错，因为是严格模式
var $injector2 = angular.injector(['moduleA'], true)
$injector2.invoke(function (F1) {
  console.log(F1.print());
});
//可以采用如下写法
$injector2.invoke(['F1', function (F1) {
  console.log(F1.print());
}]);

    12、angular.module()

    angular.module 可以说是最常用的 function 了。通过它，可以实现模块的定义，模块的获取。

//定义模块A
var moduleA = angular.module('moduleA', []);
//定义模块B，模块B依赖moduleA
var moduleB = angular.module('moduleB', ['moduleB']);

//可以在第三个参数上设置配置函数
var moduleB = angular.module('moduleB', ['moduleB'], ['$locationProvider', function ($locationProvider) {
  console.log($locationProvider);
}]);
//等价于
var moduleB = angular.module('moduleB', ['moduleB'])
.config(['$locationProvider', function ($locationProvider) {
  console.log($locationProvider);
}]);

//获取模块
angular.bootstrap(document, ['moduleB']);

    13、angular.isArray()

    angular.isArray はオブジェクトが配列かどうかを判定するために使用します。Array.isArray と同等です。

    console.log(angular.isArray([])); // true
console.log(angular.isArray({0: '1', 1: '2', length: 2})); // false

    14、angular.isDate()

    toString.call(value) が '[object Date]' と等しいかどうかを判定することで、オブジェクトが Date オブジェクトかどうかを判断します。

    console.log(angular.isDate(new Date())); // true
console.log(angular.isDate(223)); // false

    15、angular.isDefined()

    オブジェクトまたはプロパティが定義されているかどうかを判定する

    var obj = {a: 1, b: null, c: undefined};
console.log(angular.isDefined(obj.a)); // true
console.log(angular.isDefined(obj.b)); // true
console.log(angular.isDefined(obj.c)); // false
console.log(angular.isDefined(obj.d)); // false

    16、angular.isElement()

    このメソッドは、要素が要素であるかどうかを判定します（DOM 要素や jQuery 要素を含みます）。

    console.log(angular.isElement(document.getElementsByTagName('body')[0])); // true
console.log(angular.isElement($('body'))); // true

    17、angular.isFunction()

    このメソッドは、オブジェクトが function であるかどうかを判定します。次と同等です：typeof fn === 'function'

    console.log(angular.isFunction(new Function('a', 'return a'))); // true
console.log(angular.isFunction(function(){})); // true
console.log(angular.isFunction({})); // false

    18、angular.isNumber()

    数値かどうかを判定する

    function isNumber(value) {
  return typeof value === 'number';
}

    19、angular.isObject()

    オブジェクトかどうかを判定する

    function isObject(value) {
  return value !== null && typeof value === 'object';
}

    20、angular.isString()

    文字列かどうかを判定する

    function isString(value) {
    return typeof value === 'string';
}

    21、angular.isUndefined()

    変数が未定義かどうかを判定する

    function isUndefined(value) {
    return typeof value === 'undefined';
}

    22、angular.lowercase()

    文字列を小文字に変換します。引数が文字列でない場合は、そのまま返します。

    var lowercase = function(string) {
  return isString(string) ? string.toLowerCase() : string;
};

console.log(angular.lowercase(1)); // 1
console.log(angular.lowercase('ABCdef')); // 'abcdef'

    23、angular.uppercase()

    文字列を大文字に変換します。引数が文字列でない場合は、そのまま返します。

    var uppercase = function(string) {
  return isString(string) ? string.toUpperCase() : string;
};

console.log(angular.uppercase(1)); // 1
console.log(angular.uppercase('ABCdef')); // 'ABCDEF'

    24、angular.merge()

    複数のオブジェクトをディープコピーします。extend() とは異なり、merge は再帰的にディープコピーを行います。このコピーは完全なディープコピーであり、オブジェクトの参照も異なります。

    var o = {};
var obj1 = {a1: 1, a2: 2, a3: [1]};
var obj2 = {b1: [2], b2: /abc/};
var obj3 = [o];
var obj4 = {d: o};
var result = angular.merge({}, obj1, obj2, obj3);
console.log(result);
console.log(result[0] === o); // false
console.log(result.d === o); // false

    25、angular.noop()

    空の関数です。デバッグ時に非常に便利です。callback が未定義の場合に発生するエラーを回避できます。

    function foo(callback) {
  var result = calculateResult();
  (callback || angular.noop)(result);
}

    26、angular.reloadWithDebugInfo()

    DebugInfo を有効にします。この設定の優先順位は高くなります。$compileProvider.debugInfoEnabled(false)

    最初のコメントで言われている angular.isNumber が無効という問題については、解決方法は次のとおりです：

    <script>
var app = angular.module('myApp', []);
app.controller('myCtrl', function($scope) {
    $scope.blur = function(){
        $scope.x1 = angular.lowercase($scope.myInput);
        $scope.x2 = angular.uppercase($scope.myInput);
        $scope.x3 = angular.isString($scope.myInput);
        // 针对angular.isNumber($scope.myInput) 一直返回为false 
        // 这里无效原因是：input标签的输入值本身就为字符串，所以不能直接进行判断 需要做如下更改
           let isNum = String(Number($scope.myInput)) == 'NaN' ? '' : Number($scope.myInput);
         $scope.x4 = angular.isNumber(isNum);
       // $scope.x4 = !isNaN($scope.myInput);
    }
});
</script>
