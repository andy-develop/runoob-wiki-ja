AngularJS ディレクティブ

AngularJS は、ディレクティブと呼ばれる新しい属性によって HTML を拡張します。

AngularJS は組み込みのディレクティブを使用してアプリケーションに機能を追加します。

AngularJS ではカスタムディレクティブを定義できます。

AngularJS ディレクティブ

AngularJS ディレクティブは、接頭辞（プレフィックス）を持つ拡張 HTML 属性です。ng-。

ng-appディレクティブは AngularJS アプリケーションを初期化します。

ng-initディレクティブはアプリケーションデータを初期化します。

ng-modelディレクティブは要素の値（入力フィールドの値など）をアプリケーションにバインドします。

完全なディレクティブの内容は、AngularJS リファレンスマニュアル。

AngularJS サンプル

<div ng-app="" ng-init="firstName='John'"> <p>入力ボックスに入力してみてください：</p> <p>名前：<input type="text" ng-model="firstName"></p> <p>あなたが入力したのは： {{ firstName }}</p> </div>

試してみる »

ng-appディレクティブは AngularJS に、<div> 要素が AngularJSアプリケーションの「所有者」であることを伝えます。

データバインディング

上記のサンプルの{{ firstName }}式は AngularJS データバインディング式です。

AngularJS のデータバインディングは、AngularJS 式と AngularJS データを同期します。

{{ firstName }}によってng-model="firstName"同期されます。

次のサンプルでは、2 つのテキストフィールドが 2 つの ng-model ディレクティブによって同期されます：

AngularJS サンプル

<div ng-app="" ng-init="quantity=1;price=5"> <h2>価格計算機</h2>数量：<input type="number" ng-model="quantity">価格：<input type="number" ng-model="price"> <p><b>合計：</b> {{ quantity * price }}</p> </div>

試してみる »

使用ng-initはあまり一般的ではありません。コントローラの章で、より良いデータ初期化方法を学びます。

HTML 要素の繰り返し

ng-repeatディレクティブは HTML 要素を繰り返します：

AngularJS サンプル

<div ng-app="" ng-init="names=['Jani','Hege','Kai']"> <p>ng-repeat を使用して配列をループする</p> <ul> <li ng-repeat="x in names"> {{ x }} </li> </ul> </div>

試してみる »

ng-repeatディレクティブをオブジェクトの配列に使用する：

AngularJS サンプル

<div ng-app="" ng-init="names=[ {name:'Jani',country:'Norway'}, {name:'Hege',country:'Sweden'}, {name:'Kai',country:'Denmark'}]"> <p>オブジェクトをループする：</p> <ul> <li ng-repeat="x in names"> {{ x.name + ', ' + x.country }} </li> </ul> </div>

AngularJS はデータベースの CRUD（Create=作成、Read=読み取り、Update=更新、Delete=削除）アプリケーションを完全にサポートします。
サンプルの中のオブジェクトをデータベースのレコードと考えてください。

ng-app ディレクティブ

ng-appディレクティブは AngularJS アプリケーションのルート要素を定義します。。

ng-appディレクティブはウェブページの読み込みが完了すると自動的にブートストラップ（自動初期化）アプリケーションを起動します。

後ほど、ng-app値（例: ng-app="myModule"）をコードモジュールに接続する方法を学びます。

ng-init ディレクティブ

ng-initディレクティブは AngularJS アプリケーションの初期値を定義します。。

通常、ng-init は使用しません。代わりにコントローラまたはモジュールを使用します。

コントローラとモジュールについては後ほど詳しく学びます。

ng-model ディレクティブ

ng-modelディレクティブはHTML 要素をアプリケーションデータにバインドします。

ng-modelディレクティブは次のこともできます：

  • アプリケーションデータに型検証（number、email、required）を提供します。
  • アプリケーションデータに状態（invalid、dirty、touched、error）を提供します。
  • HTML 要素に CSS クラスを提供します。
  • HTML 要素を HTML フォームにバインドします。

ng-repeat ディレクティブ

ng-repeatディレクティブはコレクション（配列）内の各項目に対してHTML 要素を 1 回クローンします。。


カスタムディレクティブの作成

AngularJS の組み込みディレクティブに加えて、カスタムディレクティブを作成することもできます。

あなたは.directive関数を使用してカスタムディレクティブを追加できます。

カスタムディレクティブを呼び出すには、HTML 要素にカスタムディレクティブ名を追加する必要があります。

ディレクティブの命名にはキャメルケースを使用します。 runoobDirectiveただし、使用するときは-で区切る必要があります。runoob-directive:

AngularJS サンプル

<body ng-app="myApp">

<runoob-directive></runoob-directive>

<script>
var app = angular.module("myApp", []);
app.directive("runoobDirective", function() {
    return {
template : "<h1>自定义指令!</h1>"
    };
});
</script>

</body>

試してみる »

ディレクティブは次の方法で呼び出すことができます：

  • 要素名
  • 属性
  • クラス名
  • コメント

次のサンプルでも同じ結果が出力されます：

要素名

<runoob-directive></runoob-directive>

属性

<div runoob-directive></div>

試してみる »

クラス名

試してみる »

コメント

使用の制限

ディレクティブを特定の方法でのみ呼び出せるように制限できます。

サンプル

を追加し、restrict属性を設定し、値を"A"に設定することで、ディレクティブを属性の方法でのみ呼び出せるようにします:

var app = angular.module("myApp", []);
app.directive("runoobDirective", function() {
    return {
        restrict : "A",
        template : "<h1>自定义指令!</h1>"
    };
});

試してみる »

restrict値は次のいずれかになります：

  • E要素名として使用
  • A属性として使用
  • Cクラス名として使用
  • Mコメントとして使用

restrictデフォルト値はEAで、要素名と属性名の両方でディレクティブを呼び出せます。

    また、ディレクティブ設定項目（link や controller など）は、プロジェクトで実際に遭遇したことがあります：

    angular.module('myApp', []).directive('first', [ function(){
    return {
        // scope: false, // 默认值，共享父级作用域
        // controller: function($scope, $element, $attrs, $transclude) {},
        restrict: 'AE', // E = Element, A = Attribute, C = Class, M = Comment
        template: 'first name:{{name}}',
    };
}]).directive('second', [ function(){
    return {
        scope: true, // 继承父级作用域并创建指令自己的作用域
        // controller: function($scope, $element, $attrs, $transclude) {},
        restrict: 'AE', // E = Element, A = Attribute, C = Class, M = Comment
        //当修改这里的name时，second会在自己的作用域中新建一个name变量，与父级作用域中的
        // name相对独立，所以再修改父级中的name对second中的name就不会有影响了
        template: 'second name:{{name}}',
    };
}]).directive('third', [ function(){
    return {
        scope: {}, // 创建指令自己的独立作用域，与父级毫无关系
        // controller: function($scope, $element, $attrs, $transclude) {},
        restrict: 'AE', // E = Element, A = Attribute, C = Class, M = Comment
        template: 'third name:{{name}}',
    };
}])
.controller('DirectiveController', ['$scope', function($scope){
    $scope.name="mike";
}]);

    時にはバインドをngModelgetter/setter 関数に使用すると便利な場合があります。getter はモデル表現を返す引数なしの関数で、setter はモデルの内部状態を設定するための引数が1つの関数です。モデル内部とビュー表示で使用されるデータ形式が一致しない場合に非常に役立ちます。

    これを使用するには、次を追加する必要がありますng-model-options="{ getterSetter: true }"があるng-model要素上に。追加することもできますng-model-options="{ getterSetter: true }" 到 <form>上に、フォーム内のすべての<input>を有効にします。参照してngModelOptions詳細を取得してください。

    以下の例は、getter/setter を使用する方法を示していますngModel ：

    <div ng-controller="ExampleController">
  <form name="userForm">
    <label>
      Name:
      <input type="text" name="userName"
             ng-model="user.name"
             ng-model-options="{ getterSetter: true }" />
    </label>
  </form>
<p>user.name = <span ng-bind="user.name()"></span></p>
</div>

    ngInit ディレクティブは、現在のスコープ内で式を実行することを可能にします。ngInit は ngRepeat のような特別な性質の属性にのみ適用されます。それ以外の場合は、スコープ内の値を初期化するために ngInit ではなくコントローラーを使用する必要があります。

    <body ng-app="initExample">
  <script>
  angular.module('initExample', [])
    .controller('ExampleController', ['$scope', function($scope) {
      $scope.list = [['a', 'b'], ['c', 'd']];
    }]);
</script>
<div ng-controller="ExampleController">
  <div ng-repeat="innerList in list" ng-init="outerIndex = $index">
    <div ng-repeat="value in innerList" ng-init="innerIndex = $index">
       <span class="example-init">list[ {{outerIndex}} ][ {{innerIndex}} ] = {{value}};</span>
    </div>
  </div>
</div>
</body>
