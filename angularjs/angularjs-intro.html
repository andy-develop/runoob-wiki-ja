AngularJS 简介

AngularJS はJavaScript 框架。これは <script> タグを使用して HTML ページに追加できます。

AngularJS 通过指令HTMLを拡張し、表达式データを HTML にバインドします。

AngularJS は JavaScript フレームワークです

AngularJS は JavaScript フレームワークです。JavaScript で書かれたライブラリです。

AngularJS は JavaScript ファイルとして配布されており、script タグでウェブページに追加できます：

<script src="https://cdn.staticfile.org/angular.js/1.4.6/angular.min.js"></script>

スクリプトは <body> 要素の末尾に配置することをお勧めします。
これにより、HTML の読み込みがスクリプトの読み込みに制約されないため、ウェブページの読み込み速度が向上します。

各 angular.js バージョンのダウンロード：https://github.com/angular/angular.js/releases

AngularJS は HTML を拡張します

AngularJS 通过ng-directivesHTML を拡張します。

ng-appディレクティブは AngularJS アプリケーションを定義します。

ng-modelディレクティブは要素の値（入力フィールドの値など）をアプリケーションにバインドします。

ng-bindディレクティブはアプリケーションデータを HTML ビューにバインドします。

AngularJS 实例

<!DOCTYPE html> <html> <head> <meta charset="utf-8"> <script src="https://cdn.staticfile.org/angular.js/1.4.6/angular.min.js"></script> </head> <body> <div ng-app=""> <p>名字 :<input type="text" ng-model="name"></p> <h1>Hello {{name}}</h1> <p ng-bind="name"></p> </div> </body> </html>

ウェブページの読み込みが完了すると、AngularJS が自動的に起動します。

ng-appディレクティブはAngularJSに、<div>要素がAngularJSアプリケーションのコンテナであることを伝えます。应用程序の「所有者」。

ng-modelディレクティブは入力フィールドの値をアプリケーション変数にバインドします。name。

ng-bindディレクティブはアプリケーション変数 name を段落の innerHTML にバインドします。

もし削除したらng-appディレクティブにより、HTMLは式の結果を計算せずに直接表示します。

AngularJS とは何ですか？

AngularJS は、モダンなシングルページアプリケーション（SPAs：Single Page Applications）の開発をより容易にします。

  • AngularJS はアプリケーションデータを HTML 要素にバインドします。
  • AngularJS は HTML 要素をクローンして繰り返すことができます。
  • AngularJS は HTML 要素を非表示にしたり表示したりできます。
  • AngularJS は HTML 要素の「背後」にコードを追加できます。
  • AngularJS は入力検証をサポートします。

AngularJS 指令

ご覧のとおり、AngularJS ディレクティブはngプレフィックスとしての HTML 属性。

ng-initディレクティブは AngularJS アプリケーション変数を初期化します。

AngularJS 实例

<div ng-app="" ng-init="firstName='John'"> <p>氏名は<span ng-bind="firstName"></span></p> </div>

有効な HTML5：

AngularJS 实例

<div data-ng-app="" data-ng-init="firstName='John'"> <p>氏名は<span data-ng-bind="firstName"></span></p> </div>

AngularJS 式

AngularJS の式は二重中括弧内に記述します：{{ expression }}。

AngularJS の式はデータを HTML にバインドします。これはng-bindディレクティブと似た効果があります。

AngularJS は式が記述された位置でデータを「出力」します。

AngularJS 式很像JavaScript 式：それらにはテキスト、演算子、変数を含めることができます。

实例 {{ 5 + 5 }} 或 {{ firstName + " " + lastName }}

AngularJS 实例

<!DOCTYPE html> <html> <head> <meta charset="utf-8"> <script src="https://cdn.staticfile.org/angular.js/1.4.6/angular.min.js"></script> </head> <body> <div ng-app=""> <p>私の最初の式： {{ 5 + 5 }}</p> </div> </body> </html>

AngularJS 应用

AngularJS 模块（Module）AngularJS アプリケーションを定義します。

AngularJS コントローラ（Controller）AngularJS アプリケーションの制御に使用されます。

ng-appディレクティブはアプリケーションを指定し、ng-controllerコントローラを指定します。

AngularJS 实例

<div ng-app="myApp" ng-controller="myCtrl">名:<input type="text" ng-model="firstName"><br>姓:<input type="text" ng-model="lastName"><br> <br>姓名: {{firstName + " " + lastName}}</div> <script> var app = angular.module('myApp', []); app.controller('myCtrl', function($scope) { $scope.firstName= "John"; $scope.lastName= "Doe"; }); </script>

尝试一下 »

AngularJS モジュールはアプリケーションを定義します：

AngularJS 模块

var app = angular.module('myApp', []);

AngularJS コントローラはアプリケーションを制御します：

AngularJS コントローラ

app.controller('myCtrl', function($scope) { $scope.firstName= "John"; $scope.lastName= "Doe"; });
