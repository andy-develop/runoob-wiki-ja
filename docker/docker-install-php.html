Nginx + PHP デプロイ

Nginx のデプロイは次を参照してください：Docker Nginx のインストール、Nginx の設定についてはこの記事を参照してください。

PHP を起動：

$ docker run --name  myphp-fpm -v ~/nginx/www:/www  -d php:5.6-fpm

コマンドの説明：

  • --name myphp-fpm: コンテナを myphp-fpm と命名します。

  • -v ~/nginx/www:/www: ホスト内のプロジェクトディレクトリ www をコンテナの /www にマウントします

~/nginx/conf/conf.d ディレクトリを作成：

mkdir ~/nginx/conf/conf.d

このディレクトリに~/nginx/conf/conf.d/runoob-test-php.confファイルを追加します。内容は以下の通りです：

server {
    listen       80;
    server_name  localhost;

    location / {
        root   /usr/share/nginx/html;
        index  index.html index.htm index.php;
    }

    error_page   500 502 503 504  /50x.html;
    location = /50x.html {
        root   /usr/share/nginx/html;
    }

    location ~ \.php$ {
        fastcgi_pass   php:9000;
        fastcgi_index  index.php;
        fastcgi_param  SCRIPT_FILENAME  /www/$fastcgi_script_name;
        include        fastcgi_params;
    }
}

設定ファイルの説明：

  • php:9000: php-fpm サービスの URL を示します。詳細は後述します。
  • /www/: はmyphp-fpm内の php ファイルの保存パスで、ローカルの ~/nginx/www ディレクトリにマッピングされます。

nginx を起動：

docker run --name runoob-php-nginx -p 8083:80 -d \
    -v ~/nginx/www:/usr/share/nginx/html:ro \
    -v ~/nginx/conf/conf.d:/etc/nginx/conf.d:ro \
    --link myphp-fpm:php \
    nginx
  • -p 8083:80: ポートマッピングで、nginx内の 80 をローカルの 8083 ポートにマッピングします。
  • ~/nginx/www: ローカル html ファイルの保存ディレクトリで、/usr/share/nginx/html はコンテナ内 html ファイルの保存ディレクトリです。
  • ~/nginx/conf/conf.d: ローカル nginx 設定ファイルの保存ディレクトリで、/etc/nginx/conf.d はコンテナ内 nginx 設定ファイルの保存ディレクトリです。
  • --link myphp-fpm:php:myphp-fpmのネットワークをnginxに統合し、nginxの /etc/hosts を変更して、ドメイン名phpを 127.0.0.1 にマッピングし、nginx が php:9000 を介して php-fpm にアクセスできるようにします。

次に ~/nginx/www ディレクトリに index.php を作成します。コードは以下の通りです：

<?php
echo phpinfo();
?>

    Docker で nginx、php-fpm、mysql を設定

    実行環境

    ディレクトリを作成

    mkdir -p /Users/sui/docker/nginx/conf.d && mkdir /Users/sui/www &&  cd /Users/sui/docker/nginx/conf.d && sudo touch default.conf

    php-fpm を起動

    php を解釈・実行するには php-fpm が必要です。まず起動させます：

    docker run --name sui-php -d \
    -v /Users/sui/www:/var/www/html:ro \
    php:7.1-fpm

    --name sui-phpはコンテナの名前です。

    /Users/sui/wwwはローカル php ファイルの保存ディレクトリで、/var/www/html はコンテナ内 php ファイルの保存ディレクトリです。ro は読み取り専用を意味します。

    nginx 設定ファイルを編集

    設定ファイルの場所：/Users/sui/docker/nginx/conf.d/default.conf。

    server {
    listen       80;
    server_name  localhost;

    location / {
        root   /usr/share/nginx/html;
        index  index.html index.htm;
    }

    error_page   500 502 503 504  /50x.html;
    location = /50x.html {
        root   /usr/share/nginx/html;
    }

    location ~ \.php$ {
        fastcgi_pass   php:9000;
        fastcgi_index  index.php;
        fastcgi_param  SCRIPT_FILENAME  /var/www/html/$fastcgi_script_name;
        include        fastcgi_params;
    }
}

    説明：

    • php:9000 は php-fpm サービスへのアクセスパスを示します。後述でも触れます。
    • /var/www/html は sui-php内の php ファイルの保存パスで、docker のマッピングによりローカルパス /Users/sui/www になります（php-fpm の起動コマンドをもう一度確認してください

    nginx を起動：

    docker run --name sui-nginx -p 80:80 -d \
    -v /Users/sui/www:/usr/share/nginx/html:ro \
    -v /Users/sui/docker/nginx/conf.d:/etc/nginx/conf.d:ro \
    --link sui-php:php \
    nginx
    • -p 80:80 はポートマッピングを追加し、sui-nginx内の 80 ポートを公開します。
    • /Users/sui/www はローカル html ファイルの保存ディレクトリで、/usr/share/nginx/html はコンテナ内 html ファイルの保存ディレクトリです。
    • /Users/sui/docker/nginx/conf.d はローカル nginx 設定ファイルの保存ディレクトリで、/etc/nginx/conf.d はコンテナ内 nginx 設定ファイルの保存ディレクトリです。
    • --link sui-php:php はsui-phpのネットワークをsui-nginxに統合し、sui-nginxの /etc/hosts を変更して、ドメイン名phpを 127.0.0.1 にマッピングし、nginx が php:9000 を介して php-fpm にアクセスできるようにします。

    テスト結果

    /Users/sui/www に2つのファイルを置きます：index.html と index.php

    mysql と phpmyadmin

    mysql サーバー

    sudo mkdir -p /Users/sui/docker/mysql/data /Users/sui/docker/mysql/logs /Users/sui/docker/mysql/conf
    • data ディレクトリは mysql コンテナのデータファイル保存パスにマッピングされます
    • logs ディレクトリは mysql コンテナのログディレクトリにマッピングされます
    • conf ディレクトリ内の設定ファイルは mysql コンテナの設定ファイルにマッピングされます
    docker run -p 3307:3306 --name sui-mysql -v /Users/sui/docker/mysql/conf:/etc/mysql -v /Users/sui/docker/mysql/logs:/logs -v /Users/sui/docker/mysql/data:/mysql_data -e MYSQL_ROOT_PASSWORD=123456 -d --link sui-php mysql

    mysql クライアントに入る：

    docker run -it --link sui-mysql:mysql --rm mysql sh -c 'exec mysql -h"$MYSQL_PORT_3306_TCP_ADDR" -P"$MYSQL_PORT_3306_TCP_PORT" -uroot -p"$MYSQL_ENV_MYSQL_ROOT_PASSWORD"'

    注意：ローカルの 3306 ポートに mysql があるため、ここでは 3307 ポートを使用します。

    phpmyadmin

    docker run --name sui-myadmin -d --link sui-mysql:db -p 8080:80 phpmyadmin/phpmyadmin

    これで完了です：
