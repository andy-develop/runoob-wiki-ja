Docker Hello World

Docker はコンテナ内でアプリケーションを実行できます。使用するのはdocker runコンテナ内でアプリケーションを実行するためのコマンドです。

Hello world を出力する

サンプル@サンプル:~$ docker run ubuntu:15.10 /bin/echo "Hello world"
Hello world

各パラメータの解説：

  • docker:Docker のバイナリ実行ファイル。

  • run:前述の docker と組み合わせてコンテナを実行します。

  • ubuntu:15.10実行するイメージを指定します。Docker はまずローカルホスト上にそのイメージが存在するかどうかを確認します。存在しない場合、Docker はイメージレジストリ Docker Hub からパブリックイメージをダウンロードします。

  • /bin/echo "Hello world": 起動したコンテナ内で実行するコマンド

上記のコマンドの完全な意味は次のように説明できます。Docker は ubuntu15.10 イメージで新しいコンテナを作成し、コンテナ内で bin/echo "Hello world" を実行して、結果を出力します。

インタラクティブなコンテナを実行する

docker の2つのパラメータ -i -t を使用して、docker が実行するコンテナに「対話」の能力を実現させます：

サンプル@サンプル:~$ docker run -i -t ubuntu:15.10 /bin/bash
root@0123ce188bd8:/#

各パラメータの解説：

  • -t:新しいコンテナ内で疑似端末または端末を指定します。

  • -i:コンテナ内の標準入力 (STDIN) との対話を可能にします。

2行目に注意してくださいroot@0123ce188bd8:/#、この時点で ubuntu15.10 システムのコンテナに入っています。

コンテナ内でコマンドを実行してみましょう cat /proc/versionとls現在のシステムのバージョン情報と現在のディレクトリ内のファイル一覧をそれぞれ確認します。

root@0123ce188bd8:/#  cat /proc/version
Linux version 4.4.0-151-generic (buildd@lgw01-amd64-043) (gcc version 5.4.0 20160609 (Ubuntu 5.4.0-6ubuntu1~16.04.10) ) #178-Ubuntu SMP Tue Jun 11 08:30:22 UTC 2019
root@0123ce188bd8:/# ls
bin  boot  dev  etc  home  lib  lib64  media  mnt  opt  proc  root  run  sbin  srv  sys  tmp  usr  var
root@0123ce188bd8:/#

exit コマンドを実行するか、CTRL+D を使用してコンテナを終了できます。

root@0123ce188bd8:/#  exit
exit
root@サンプル:~#

3行目に注意してくださいroot@サンプル:~#現在のコンテナを終了し、現在のホストに戻ったことを示しています。

コンテナを起動する（バックグラウンドモード）

以下のコマンドを使用して、プロセスとして実行されるコンテナを作成します。

サンプル@サンプル:~$ docker run -d ubuntu:15.10 /bin/sh -c "while true; do echo hello world; sleep 1; done"
2b1b7a428627c51ab8810d541d759f072b4fc75487eed05812646b8534a2fe63

出力には、期待していた "hello world" ではなく、長い文字列が表示されています。

2b1b7a428627c51ab8810d541d759f072b4fc75487eed05812646b8534a2fe63

この長い文字列はコンテナ ID と呼ばれ、各コンテナごとに一意です。コンテナ ID を使用して、対応するコンテナで何が起こったのかを確認できます。

まず、コンテナが実行中であることを確認する必要があります。確認するのに使用するのはdocker ps次のコマンドです：

サンプル@サンプル:~$ docker ps
CONTAINER ID        IMAGE                  COMMAND              ...  
5917eac21c36        ubuntu:15.10           "/bin/sh -c 'while t…"    ...

出力の詳細説明：

CONTAINER ID:コンテナ ID。

IMAGE:使用されているイメージ。

COMMAND:コンテナ起動時に実行されるコマンド。

CREATED:コンテナの作成時間。

STATUS:コンテナの状態。

状態は7種類あります：

  • created（作成済み）
  • restarting（再起動中）
  • running または Up（実行中）
  • removing（移行中）
  • paused（一時停止）
  • exited（停止）
  • dead（死亡）

PORTS:コンテナのポート情報と使用される接続タイプ（tcp\udp）。

NAMES:自動的に割り当てられたコンテナ名。

ホストマシン上で使用するのはdocker logsコンテナ内の標準出力を確認するためのコマンドです：

サンプル@サンプル:~$ docker logs 2b1b7a428627


サンプル@サンプル:~$ docker logs amazing_cori

コンテナを停止する

私たちが使用するのはdocker stopコンテナを停止するためのコマンドです：

次のコマンドでdocker ps確認すると、コンテナはすでに停止しています：

サンプル@サンプル:~$ docker ps

コンテナがもう存在しないことがわかります。

次のコマンドを使用して停止することもできます：

サンプル@サンプル:~$ docker stop amazing_cori
