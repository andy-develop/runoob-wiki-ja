Docker save コマンド

Docker コマンド大全

docker saveこのコマンドは、1つ以上のDockerイメージをtarアーカイブファイルに保存し、他の環境で配布またはバックアップできるようにするために使用します。

構文

docker save [OPTIONS] IMAGE [IMAGE...]
  • IMAGE: 保存する1つ以上のイメージ名またはID。

OPTIONS の説明：

  • -o, --output: 出力ファイルのパスを指定します。

1. 単一のイメージをファイルに保存する

docker save -o myimage.tar myimage:latest

これにより、myimage:latest イメージが myimage.tar ファイルとして保存されます。

2. 複数のイメージを同じファイルに保存する

docker save -o multiple_images.tar myimage:latest anotherimage:latest

これにより、myimage:latest と anotherimage:latest のイメージが multiple_images.tar ファイルに保存されます。

実例

サンプルイメージを構築する

1. Dockerfile を作成します：

# 使用 Ubuntu 作为基础镜像
FROM ubuntu:20.04

# 添加维护者信息
LABEL maintainer="yourname@example.com"

# 更新包列表并安装 Nginx
RUN apt-get update && apt-get install -y nginx

# 复制自定义网页到 Nginx 的默认网页目录
COPY index.html /var/www/html/

# 设置启动时的默认命令
CMD ["nginx", "-g", "daemon off;"]

イメージを構築します：

docker build -t mynginx:latest .

2. イメージをファイルに保存する

docker save -o mynginx.tar mynginx:latest

これにより、mynginx:latest イメージが mynginx.tar ファイルとして保存されます。

3. 保存されたファイルを検証する

ls -lh mynginx.tar

出力例：

-rw-r--r-- 1 user user 200M Jul 24 14:00 mynginx.tar

4. 保存されたイメージをロードする

保存したイメージを別のDocker環境にロードするには、docker load コマンドを使用できます：

docker load -i mynginx.tar

注意事項

  • イメージを保存する際、イメージのすべてのレイヤーが含まれるため、生成される tar ファイルは非常に大きくなる可能性があります。
  • 複数のイメージを同じファイルに保存する場合、docker loadコマンドを使用すると、含まれているすべてのイメージがロードされます。
  • ファイルサイズを減らすには、保存前にdocker image pruneコマンドを使用して未使用のイメージとレイヤーをクリーンアップします。

docker saveこのコマンドは、Dockerイメージをtarファイルとして保存するための便利なツールであり、バックアップ、配布、移行に適しています。組み合わせてdocker loadコマンドを使用することで、保存したイメージを異なる環境で簡単に復元して使用できます。
