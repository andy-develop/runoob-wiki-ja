Windows Docker インストール

Docker は汎用的なコンテナツールではなく、既に存在して実行中の Linux カーネル環境に依存しています。

Docker は実質的に、既に実行中の Linux 上に隔離されたファイル環境を作り出すものであり、その実行効率はデプロイ先の Linux ホストとほぼ同等です。

したがって、Docker は Linux カーネルのシステム上にデプロイする必要があります。他のシステムで Docker をデプロイしたい場合は、仮想 Linux 環境をインストールする必要があります。

Windows 上で Docker をデプロイする方法は、まず仮想マシンをインストールし、Linux システムをインストールした仮想マシン内で Docker を実行するものです。

Win10 システム

Docker Desktop は、Docker が Windows 10 と macOS オペレーティングシステム上で提供する公式のインストール方法です。この方法も、まず仮想マシンに Linux をインストールしてから Docker をインストールする方法に属します。

Docker Desktop 公式ダウンロードアドレス：https://docs.docker.com/desktop/install/windows-install/

注意：この方法は Windows 10 オペレーティングシステムの Pro 版、Enterprise 版、Education 版、および一部の Home 版にのみ適用されます！

Hyper-V のインストール

Hyper-V は、VMWare や VirtualBox に似た、マイクロソフトが開発した仮想マシンであり、Windows 10 にのみ対応しています。これは Docker Desktop for Windows が使用する仮想マシンです。

ただし、この仮想マシンを有効にすると、QEMU、VirtualBox、または VMWare Workstation 15 以下のバージョンは使用できなくなります！コンピューターで他の仮想マシンを使用する必要がある場合（例えば Android アプリ開発に必須のエミュレーターなど）、Hyper-V を使用しないでください！

Hyper-V を有効にする

プログラムと機能

Windows の機能の有効化または無効化

Hyper-V にチェックを入れる

コマンドで Hyper-V を有効にすることもできます。スタートメニューを右クリックし、管理者として PowerShell を実行して、以下のコマンドを実行してください：

Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V -All

win7、win8 システム

win7、win8 などでは docker toolbox を使用してインストールする必要があります。国内では Alibaba Cloud のミラーを使用してダウンロードできます。ダウンロードアドレス：http://mirrors.aliyun.com/docker-toolbox/windows/docker-toolbox/

インストールは比較的簡単で、ダブルクリックして実行し、次へをクリックするだけです。必要なコンポーネントをチェックできます：

docker toolbox はツールセットであり、主に以下の内容が含まれています：

  • Docker CLI - クライアント。docker エンジンを実行してイメージとコンテナを作成するために使用します。
  • Docker Machine - Windows のコマンドラインで docker エンジンコマンドを実行できるようにします。
  • Docker Compose - docker-compose コマンドを実行するために使用します。
  • Kitematic - Docker の GUI バージョンです。
  • Docker QuickStart shell - Docker が設定済みのコマンドライン環境です。
  • Oracle VM Virtualbox - 仮想マシンです。

ダウンロードが完了したら直接クリックしてインストールします。インストールが成功すると、デスクトップに3つのアイコンが表示されます。下図のとおりです：

システムが User Account Control ウィンドウを表示して VirtualBox がコンピューターを変更することを許可するか尋ねてきた場合は、Yes を選択します。
