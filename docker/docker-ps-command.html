Docker ps コマンド

Docker コマンド大全

docker ps コマンドは Docker コンテナを一覧表示します。

デフォルトでは、docker ps コマンドは実行中のコンテナのみを表示しますが、オプションを指定することで、停止中のコンテナを含むすべてのコンテナを表示することもできます。

構文

docker ps [OPTIONS]

OPTIONS の説明：

  • -a, --all: 停止中のコンテナを含む、すべてのコンテナを表示します。
  • -q, --quiet: コンテナ ID のみを表示します。
  • -l, --latest: 最近作成された1つのコンテナを、すべての状態を含めて表示します。
  • -n: 最近作成された n 個のコンテナを、すべての状態を含めて表示します。
  • --no-trunc: 出力を切り詰めません。
  • -s, --size: コンテナのサイズを表示します。
  • --filter, -f: 条件に基づいて表示するコンテナをフィルタリングします。
  • --format: 出力をフォーマットします。

例

1. 実行中のすべてのコンテナ情報を一覧表示

デフォルトでは、docker ps は実行中のコンテナのみを表示します。

docker ps
CONTAINER ID   IMAGE          COMMAND                ...  PORTS                    NAMES
09b93464c2f7   nginx:latest   "nginx -g 'daemon off" ...  80/tcp, 443/tcp          myrunoob
96f7f14e99ab   mysql:5.6      "docker-entrypoint.sh" ...  0.0.0.0:3306->3306/tcp   mymysql

出力詳細の説明：

CONTAINER ID:コンテナ ID。

IMAGE:使用されているイメージ。

COMMAND:コンテナ起動時に実行されるコマンド。

CREATED:コンテナの作成時間。

STATUS:コンテナの状態。

状態は7種類あります：

  • created（作成済み）
  • 再起動中
  • 実行中
  • 移行中
  • 一時停止
  • exited（停止）
  • dead（死亡）

PORTS:コンテナのポート情報と使用している接続タイプ（tcp\udp）。

NAMES:自動的に割り当てられたコンテナ名。

2. すべてのコンテナ（停止中のコンテナを含む）を一覧表示

docker ps -a

停止中のコンテナを含む、すべてのコンテナを表示します。

3. コンテナ ID のみを表示

docker ps -q

コンテナ ID のみを表示します。

4. 最近作成された1つのコンテナを表示

docker ps -l

最近作成された1つのコンテナを、すべての状態を含めて表示します。

5. 最近作成された n 個のコンテナを表示

docker ps -n 3

最近作成された3つのコンテナを、すべての状態を含めて表示します。

6. コンテナのサイズを表示

docker ps -s

コンテナのサイズを表示します。

7. 条件に基づいて表示するコンテナをフィルタリング

docker ps -f "status=exited"

状態が exited のコンテナを表示します。

docker ps -f "name=my_container"

名前に my_container を含むコンテナを表示します。

8. 出力のフォーマット

docker ps --format "table {{.ID}}\t{{.Names}}\t{{.Status}}"

コンテナの ID、名前、状態をテーブル形式で表示します。

一般的なフィルター

  • status: コンテナの状態（例：running、paused、exited）。
  • name: コンテナ名。
  • id: コンテナ ID。
  • label: コンテナラベル。
  • ancestor: コンテナイメージ。

使用シナリオ

  • コンテナ状態の監視: 実行中のコンテナの状態とリソース使用状況をリアルタイムで監視します。
  • デバッグと管理: 停止中のコンテナを含むすべてのコンテナを表示し、デバッグや管理操作を行います。
  • 自動化スクリプト: フィルターとフォーマットオプションを使用すると、自動化スクリプトで特定のコンテナ情報を取得しやすくなります。
