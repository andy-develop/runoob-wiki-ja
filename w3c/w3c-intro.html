W3C 入門

W3C はどのようにして作られたのですか？

ワールド・ワイド・ウェブ（World Wide Web）は、欧州原子核研究機構（CERN）のプロジェクトとして発展し、そこでティム・バーナーズ＝リーがワールド・ワイド・ウェブの原型を開発しました。

ティム・バーナーズ＝リー - ワールド・ワイド・ウェブの発明者 - 現在はワールド・ワイド・ウェブ・コンソーシアムのディレクターです。

W3C は 1994 年に、マサチューセッツ工科大学（MIT）と欧州原子核研究機構（CERN）との間の協調作業を実現するために設立され、米国防総省高等研究計画局（DARPA）と欧州委員会（European Commission）の支援を受けました。

Web の標準化

W3C は、すべてのユーザーが（文化的・教育的背景、能力、経済力、身体障害に関わらず）Web を利用できるようにすることに取り組んでいます。

W3C はまた、Internet Engineering Task Force（IETF）、Wireless Application Protocol（WAP）、Unicode Consortium などの他の標準化団体と協力して活動しています。

W3C は、米国マサチューセッツ工科大学の計算機科学・人工知能研究所（MIT CSAIL）に設立され、フランスの欧州情報数学研究コンソーシアム（ERCIM）と日本の慶應義塾大学（Keio University）が共同で運営し、世界中に支部事務所を持っています。

W3C メンバー

Web は非常に重要である（その影響範囲においても投資においても）ため、単一の組織がその未来をコントロールすべきではありません。したがって、W3C は会員組織としての役割を果たしています。

一部の有名な会員には以下のような組織があります：

  • IBM
  • Microsoft
  • America Online
  • Apple
  • Adobe
  • Macromedia
  • Sun Microsystems

W3C の会員ソフトウェア開発者、コンテンツプロバイダー、企業ユーザー、通信会社、研究機関、研究ラボ、標準化団体、政府などが含まれます。

W3C Recommendations

W3C の最も重要な仕事は、Web の通信プロトコル（HTML や XHTML など）やその他の構成要素を記述する Web 標準（勧告、Recommendations と呼ばれる）を開発することです。

各 W3C 勧告の開発は、会員と招待された専門家からなるワーキンググループによって行われます。ワーキンググループの資金は企業や他の組織から提供され、作業草案（Working Draft）を作成し、最終的には勧告案（Proposed Recommendation）を作成します。一般的に、正式な承認を得るために、勧告は W3C 会員とディレクターに提出されます。
