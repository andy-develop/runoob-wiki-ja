W3C XHTMLアクティビティ

XHTML はより厳密で、よりクリーンな HTML バージョンです。

XHTML チュートリアル

Web サイトを XHTML に変換する方法については、当サイトのXHTML チュートリアルをお読みください。

XHTML バージョン

XHTML 1.0

W3C 勧告として、XHTML 1.0 は 2000 年 1 月 26 日に公開されました。

XHTML 1.0 Revision

W3C 勧告として、XHTML 1.0 第2版は 2002 年 8 月 1 日に公開されました。これは新しいバージョンではなく、更新とバグ修正です。

XHTML 1.1

W3C 勧告として、XHTML 1.1 は 2001 年 5 月 31 日に公開されました。

XHTML 1.1 第2版

W3C 勧告として、XHTML 1.1 (SE) は 2010 年 11 月 23 日に公開されました。

XHTML 1.0 について

XHTML 1.0 は、1997 年以来の HTML に対する最初の主要な変更であり、デスクトップコンピュータ、モバイルデバイス、携帯電話などのより幅広いユーザーエージェントに、よりリッチな Web ページを提供する上で非常に重要な一歩でもありました。

XHTML は、HTML 4.01 からスムーズに移行できる XML アプリケーションです。W3C が HTML 4.01 を XML に再構築する最初のステップにより、XHTML 1.0 が誕生しました。XHTML 1.0 は、HTML 4.01 のタグが提供するセマンティクスに依存しています。

次のステップは、XHTML をより小さな要素の集合にモジュール化し、XHTML と他のマークアップ言語（ベクターグラフィックスやマルチメディアなど）の統合をより容易にすることでした。

同時に、XHTML のモジュール化は開発コストを削減し、他のアプリケーション（データベースなど）との連携を改善し、さまざまなユーザーエージェント（ブラウザ）との通信を容易にし、HTML とさまざまな XML 標準との間のよりクリーンな統合を実現することもできます。

W3C XHTML アクティビティ

XHTML 1.0

XHTML 1.0 は、XML を使用して HTML 4.01 を再表現したものです。

XHTML についてさらに詳しく学ぶには、当サイトのXHTML チュートリアルをご覧ください。

XHTML 1.1（モジュール化された XHTML）

小型デバイス（携帯電話など）は XHTML のすべての機能をサポートできません。XHTML 1.1 は仕様を限られた機能を持つモジュールに分割します。小型ブラウザは選択したモジュールをサポートすることで複雑さを軽減できます（ただし、モジュールを一度選択すると、そのすべての機能をサポートしなければなりません）。

XHTML 1.1 は厳格な言語です。XHTML 1.1 は HTML 4 と後方互換性がありません。

XHTML ベーシック

XHTML Basic は XHTML 1.1 の小さなサブセットです。テキスト構造、画像、基本的なフォーム、基本的なテーブルなどの基本的な XHTML 機能のみを含みます。これは小型ブラウザ（ハンドヘルドデバイスなど）向けに設計されています。

XHTML イベント

XHTML が W3C ドキュメントオブジェクトモデルレベル 2 をサポートしているため、イベントハンドラを XHTML 要素に付加でき、親要素が子要素の前後でイベントを処理できるようになります。

DOM についてさらに詳しく学ぶには、当サイトのDOM チュートリアルをご覧ください。

XHTML プリント

XHTML-Print は XHTML 1.1（モジュール化された XHTML）の一部です。

XHTML-Print は、モバイルデバイスと低価格プリンタ向けに設計されています。これらのデバイスは通常、プリントバッファやデバイス専用のプリンタドライバなしで、1 枚のページを最初から最後まで印刷できます。

XForms

XHTML フォームを使用すると、ユーザーはページにアクセスし、情報をページに追加した後、Web サーバーにページを送信できます。

XForms は HTML フォームの後継であり、より堅牢でプレゼンテーションから独立した Web インタラクションの処理方法を提供します。XHTML と統合されるように設計されているため、将来の eコマースアプリケーションでは XForms が必要になると予想されます。

XHTML モジュール化

XHTML モジュール化とは、XHTML 1.0 を特定の機能を提供する小さなモジュールの集合に分割することです。

XHTML 1.0 のモジュール化は、XML DTD (Document Type Definition) を使用して実現されました。

XHTML 2.0 のモジュール化は、XML Schema を使用して実現されます。

DTD についてさらに詳しく学ぶには、当サイトのDTD チュートリアルをご覧ください。

XML Schema についてさらに詳しく学ぶには、当サイトのXML Schema チュートリアルをご覧ください。

XHTML 2.0

XHTML 2.0 は次世代のマークアップ言語です。その機能は XHTML 1.1 と非常に似ていると予想されていましたが、XML Linking や XML Schema などの XML 標準の要件に準拠するために変更される可能性があります。

XLink

XLink は XML 文書内でハイパーリンクを作成するための言語です。XLink は HTML のリンクに非常に似ていますが、単純なリンク（HTML など）と拡張リンク（複数のリソースをリンクするためのもの）をより強力にサポートします。

当サイトのXLink チュートリアルで XLink についてさらに詳しく学ぶことができます。

HLink

HLink は、XHTML 内のどの要素がハイパーリンクを表すことができるかを指定し、ハイパーリンクをどのように辿るかを指定する機能を追加します。

HLink は XLink の拡張です。
