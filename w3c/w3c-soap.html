W3C Soap活動

SOAP は、アプリケーションが HTTP を介して情報を交換するための、XML ベースのシンプルなプロトコルです。

または簡単に言うと、SOAP は XML ベースの Web サービス間の通信プロトコルです。

SOAP

SOAP（Simple Object Access Protocol）は、プラットフォームや言語に依存しない軽量な通信プロトコルであり、プログラムが標準のインターネット HTTP を介して通信できるようにします。

SOAP についてさらに学ぶには、私たちのSOAP チュートリアル。

SOAP 1.1

2000年5月、SOAP 1.1 は分散環境で情報を交換するためのプロトコルとして、W3C にノートとして提案されました（開発者: IBM, Lotus, Microsoft, Userland）。

W3C SOAP 1.1 文書は、議論のためのノート（NOTE）にすぎません。このノートの公開は、W3C がいかなる程度でもこれを承認することを意味するものではありません。

SOAP 1.2

W3C の XML Protocol ワーキンググループは現在 SOAP 1.2 に取り組んでいます。

最初のワーキングドラフトは 2001年12月17日に公開されました。

SOAP 1.2 は 2003年6月24日に W3C 勧告として公開されました。
