HTML バージョン

HTML 2.0

HTML 2.0 は、1996 年に Internet Engineering Task Force (IETF) の HTML ワーキンググループによって開発されました。

HTML 2.0 は時代遅れの HTML バージョンです。現在市場で入手できるブラウザは、より新しいバージョンの HTML に依存しています。Web 開発者にとって、HTML 2.0 標準を必要とする理由はありません。

HTML 3.2

HTML 3.2 は、1997 年 1 月 14 日に W3C 標準として公開されました。HTML 3.2 は、HTML 2.0 標準に、フォント、テーブル、アプレット、画像の周りのテキストフロー、上付き文字、下付き文字など、広く使用されている機能を追加しました。

1997 年の HTML 3.2 標準に追加されたこれらの要素の 1 つである <font> タグは、HTML のコンテンツと表現の分離という重要なタスクに不必要な問題をもたらしました。

HTML 4.0

HTML 4.0 は、W3C 勧告として 1997 年 12 月 18 日に公開されました。そして、いくつかの編集上の修正のみが行われた第 2 版が 1998 年 4 月 24 日に公開されました。

HTML 4.0 の最も重要な特徴は、スタイルシート（CSS）の導入です。

私たちのW3C CSSセクションでは、W3C CSS 活動を要約しています。

HTML 4.01

HTML 4.01 は、W3C 勧告として 1999 年 12 月 24 日に公開されました。

HTML 4.01 は HTML 4.0 のマイナーアップデートであり、後者の修正とバグ修正が行われました。

W3C は HTML をこれ以上発展させることはありません。将来の W3C の作業は XHTML に集中します。

XHTML 1.0 (最新版のHTML)

XHTML 1.0 は XML を使用して HTML 4.01 を再表現しました。

XHTML 1.0 は、W3C 勧告として 2000 年 1 月 20 日に公開されました。

私たちのW3C XHTMLセクションでは、W3C XHTML 活動を要約しています。

HTML 5

W3C は、2008 年 1 月 22 日に HTML 5 のワーキングドラフトを公開しました。

すべての HTML 要素の処理方法とエラーからの回復方法に関する正確なルールを制定することで、HTML 5 は相互運用性を向上させ、開発コストを削減しました。

HTML 5 の新機能には、オーディオ、ビデオ、グラフィックを埋め込む機能、クライアント側データストレージ、インタラクティブドキュメントが含まれます。

HTML 5 には、<nav>、<header>、<footer>、<figure> などの新しい要素も含まれています。

HTML 5 ワーキンググループには、AOL、Apple、Google、IBM、Microsoft、Mozilla、Nokia、Opera、およびその他数百のベンダーが含まれます。
