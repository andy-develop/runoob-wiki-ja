PyTorch データ処理と読み込み

PyTorch では、データの処理と読み込みは深層学習トレーニングプロセスにおける重要なステップです。

データを効率的に処理するために、PyTorch は強力なツールを提供しています。含まれるもの：torch.utils.data.Datasetとtorch.utils.data.DataLoader、データセットの管理、バッチ読み込み、データ拡張などのタスクを支援します。

PyTorch データ処理と読み込みの紹介：

  • カスタム Dataset：継承によってtorch.utils.data.Dataset自分のデータセットを読み込む。
  • DataLoader：DataLoaderバッチごとにデータを読み込み、マルチスレッド読み込みをサポートし、データをシャッフルします。
  • データ前処理と拡張：使用するtorchvision.transforms一般的な画像前処理と拡張操作を行い、モデルの汎化能力を向上させます。
  • 標準データセットの読み込み：torchvision.datasets多くの一般的なデータセットを提供し、データ読み込みプロセスを簡素化します。
  • 複数のデータソース：複数の ... を組み合わせることでDatasetインスタンスを使用して、異なるソースからのデータを処理します。

カスタム Dataset

torch.utils.data.Datasetは抽象クラスであり、自分のデータソースからデータセットを作成できます。

このクラスを継承し、次の2つのメソッドを実装する必要があります：

  • __len__(self)：データセット内のサンプル数を返します。
  • __getitem__(self, idx)：インデックスによってサンプルを1つ返します。

簡単な CSV ファイルまたはいくつかのリストデータがあると仮定すると、Dataset クラスを継承して独自のデータセットを作成できます。

例

import torch
from torch.utils.data import Dataset

# カスタムデータセットクラス
class MyDataset(Dataset):
    def __init__(self, X_data, Y_data):
        """
データセットを初期化します。X_data と Y_data は2つのリストまたは配列です。
X_data: 入力特徴
Y_data: ターゲットラベル
        """
        self.X_data = X_data
        self.Y_data = Y_data

    def __len__(self):
        """データセットのサイズを返す"""
        return len(self.X_data)

    def __getitem__(self, idx):
        """指定されたインデックスのデータを返す"""
        x = torch.tensor(self.X_data[idx], dtype=torch.float32)  # Tensor に変換
        y = torch.tensor(self.Y_data[idx], dtype=torch.float32)
        return x, y

# サンプルデータ
X_data = [[1, 2], [3, 4], [5, 6], [7, 8]]  # 入力特徴
Y_data = [1, 0, 1, 0]  # ターゲットラベル

# データセットインスタンスを作成
dataset = MyDataset(X_data, Y_data)

DataLoader を使用してデータを読み込む

DataLoader は PyTorch が提供する重要なツールであり、Dataset からバッチごとにデータを読み込むために使用します。

DataLoader を使用すると、データをバッチで読み取り、マルチスレッド読み込みを行うことができ、トレーニング効率を向上させます。

例

from torch.utils.data import DataLoader

# DataLoader インスタンスを作成。batch_size は毎回読み込むサンプル数を設定します。
dataloader = DataLoader(dataset, batch_size=2, shuffle=True)

# 読み込んだデータを出力
for epoch in range(1):
    for batch_idx, (inputs, labels) in enumerate(dataloader):
        print(f'Batch {batch_idx + 1}:')
        print(f'Inputs: {inputs}')
        print(f'Labels: {labels}')
  • batch_size：毎回読み込むサンプル数。
  • shuffle：データをシャッフルするかどうか。通常、トレーニング時にはデータをシャッフルする必要があります。
  • drop_last：データセット内のサンプル数がbatch_size割り切れない場合、True に設定するとTrue、最後の不完全なバッチを破棄します。

出力：

Batch 1:
Inputs: tensor([[3., 4.], [1., 2.]])
Labels: tensor([0., 1.])
Batch 2:
Inputs: tensor([[7., 8.], [5., 6.]])
Labels: tensor([0., 1.])

各ループで、DataLoader は入力特徴（inputs）とターゲットラベル（labels）を含む1つのバッチのデータを返します。

前処理とデータ拡張

データの前処理と拡張は、モデルのパフォーマンスを向上させるために非常に重要です。

PyTorch は torchvision.transforms モジュールを提供しており、回転、切り抜き、正規化などの一般的な画像前処理と拡張操作を行います。

一般的な画像前処理操作：

例

import torchvision.transforms as transforms
from PIL import Image

# データ前処理のパイプラインを定義
transform = transforms.Compose([
    transforms.Resize((128, 128)),  # 画像を 128x128 にリサイズ
    transforms.ToTensor(),  # 画像をテンソルに変換
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])  # 標準化
])

# 画像を読み込む
image = Image.open('image.jpg')

# 前処理を適用
image_tensor = transform(image)
print(image_tensor.shape)  # テンソルの形状を出力
  • transforms.Compose()：複数の変換操作を1つに組み合わせます。
  • transforms.Resize()：画像のサイズを調整します。
  • transforms.ToTensor()：画像を PyTorch テンソルに変換し、値は [0,1] の範囲に[0, 1]正規化されます。
  • transforms.Normalize()：画像データを標準化します。通常、事前学習済みモデルを使用する際には標準化処理が必要です。

画像データ拡張

データ拡張技術は、トレーニングデータにランダムな変換を施すことでデータの多様性を高め、モデルの汎化を促進します。例えば、ランダムフリップ、回転、切り抜きなどです。

例

transform = transforms.Compose([
    transforms.RandomHorizontalFlip(),  # ランダムな水平反転
    transforms.RandomRotation(30),  # ランダムに30度回転
    transforms.RandomResizedCrop(128),  # ランダムに切り抜き、128x128 にリサイズ
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])
])

これらのデータ拡張方法は transforms.Compose() を使用して組み合わせることができ、各画像がトレーニング時に異なる変換を持つことを保証します。

画像データセットの読み込み

画像データセットについて、torchvision.datasets は多くの一般的なデータセット（CIFAR-10、ImageNet、MNIST など）と、画像データを読み込むためのツールを提供しています。

MNIST データセットを読み込む：

例

import torchvision.datasets as datasets
import torchvision.transforms as transforms

# 前処理操作を定義
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5,), (0.5,))  # グレースケール画像を標準化
])

# MNIST データセットをダウンロードして読み込む
train_dataset = datasets.MNIST(root='./data', train=True, download=True, transform=transform)
test_dataset = datasets.MNIST(root='./data', train=False, download=True, transform=transform)

# DataLoader を作成
train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True)
test_loader = DataLoader(test_dataset, batch_size=64, shuffle=False)

# トレーニングデータを反復処理
for inputs, labels in train_loader:
    print(inputs.shape)  # 各バッチの入力データの形状
    print(labels.shape)  # 各バッチのラベルの形状
  • datasets.MNIST()自動的に MNIST データセットをダウンロードして読み込みます。
  • transformパラメータを使用すると、データの前処理が可能になります。
  • train=Trueとtrain=Falseそれぞれトレーニングセットとテストセットを表します。

複数のデータソースを使用する（Multi-source Dataset）

データセットが複数のファイルや複数のソース（例えば複数の画像フォルダ）で構成されている場合、Dataset クラスを継承して複数のデータソースをカスタムで読み込むことができます。

PyTorch は、複数のデータセットを結合するための ConcatDataset や ChainDataset などのクラスを提供しています。

例えば、複数の画像フォルダのデータがある場合、それらを1つのデータセットに結合できます：

例

from torch.utils.data import ConcatDataset

# dataset1 と dataset2 は2つの Dataset オブジェクトと仮定
combined_dataset = ConcatDataset([dataset1, dataset2])
combined_loader = DataLoader(combined_dataset, batch_size=64, shuffle=True)
