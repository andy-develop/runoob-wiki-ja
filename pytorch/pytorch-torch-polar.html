PyTorch torch.polar 関数

Pytorch torch リファレンスマニュアル

torch.polarPyTorch において極座標から複素テンソルを作成するための関数です。

関数定義

torch.polar(abs, angle)

使用例

実例

import torch

# 絶対値（モジュラス）テンソルを作成
abs_val = torch.tensor([1.0, 2.0, 3.0])

# 角度（ラジアン）テンソルを作成
angle = torch.tensor([0.0, torch.pi/2, torch.pi])

# 極座標から複素テンソルを作成
x = torch.polar(abs_val, angle)

print(x)
print("絶対値:", x.abs())
print("角度:", x.angle())
