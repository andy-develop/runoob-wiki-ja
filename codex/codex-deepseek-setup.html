Codex Deepseek 設定 -- CC Switch 経由の中継

この記事では、CC Switch を使用して、Codex が DeepSeek、Qwen、ZLM などのサードパーティモデルを利用できるようにする方法を紹介します。

CC Switch は、無料でオープンソースのクロスプラットフォームデスクトップツールです。Codex などの AI プログラミングアシスタントで、ワンクリックでサードパーティの API プロバイダーに切り替えることができ、より低いコストで AI プログラミング機能を利用できます。

この記事は CC Switch v3.16.0（最新バージョンのインストールを推奨）に基づいており、Codex にバックエンド API として DeepSeek を設定する方法を紹介します。他のモデルもこの設定を参考にできます。

公式 API インターフェースの他に、Coding Plan/Token Planプランを通じてDeepSeek、Kimi、GLM、Doubao、MiniMaxなどの主要な大規模モデルに直接接続でき、各社のAPIを個別に購入する必要はありません。

動作原理

CC Switch はローカルマシンでプロキシサービスを起動し、Codex が送信したリクエストを指定したバックエンド（例：DeepSeek）に透過的に転送し、レスポンスを Codex に返します。

転送プロセス全体は完全に透過的であり、Codex にとっては、依然として OpenAI 公式インターフェースにアクセスしているように見えます。実際には、リクエストは CC Switch によって指定したサードパーティモデルサービスに転送されています。

前提条件

設定を開始する前に、以下の条件を満たしていることを確認してください：

条件 説明
Codex がインストールされていること 以下からhttps://openai.com/zh-Hans-CN/codex/ダウンロードしてインストール
DeepSeek API Key アクセスしてplatform.deepseek.com登録して取得
オペレーティングシステム Windows 10+、macOS 12+、または主要な Linux ディストリビューション

ステップ1：CC Switch のインストール

インストールパッケージのダウンロード URL はhttps://github.com/farion1231/cc-switch/releases/latest、ページ下部までスクロールすると、各プラットフォームのダウンロードリンクが表示されます：

お使いのオペレーティングシステムに応じて、対応するインストール方法を選択してください。

ディストリビューション 推奨形式 インストール方法
Ubuntu / Debian / Linux Mint / Pop!_OS .deb sudo dpkg -i CC-Switch-*.deb 或 sudo apt install ./CC-Switch-*.deb
Fedora / RHEL / CentOS / Rocky Linux .rpm sudo rpm -i CC-Switch-*.rpm 或 sudo dnf install ./CC-Switch-*.rpm
openSUSE .rpm sudo zypper install ./CC-Switch-*.rpm
Arch Linux / Manjaro .AppImage 実行権限を追加して直接実行するか、AUR を使用します
その他のディストリビューション / 不明な場合 .AppImage chmod +x CC-Switch-*.AppImage && ./CC-Switch-*.AppImage

macOS（推奨）

macOS 版は公証済みのため、Homebrew で直接インストールできます：

brew install --cask cc-switch

インストールが完了したら CC Switch を起動します。メインインターフェースがデスクトップまたはシステムトレイに表示されます。

CC Switch の詳細については、次を参照してください：https://www.runoob.com/ai-agent/cc-switch.html

ステップ2：DeepSeek プロバイダーの追加

CC Switch に DeepSeek を API プロバイダーとして追加し、Codex のリクエストを DeepSeek に転送できるようにします。

操作手順は次のとおりです：

  1. CC Switch を開き、上部のアプリ切り替えバーで「Codex」を選択しますCodex。

  2. 左側の「Providers」領域の[+]をクリックします+ Add Provider。

  3. プリセットリストで検索しDeepSeek、対応するプリセットを選択します（v3.16.0 には DeepSeek V4 flash と pro の2つのバージョンが組み込まれています）。

  4. 選択したら、下のフォームにあなたのDeepSeek API Keyを入力し、残りのフィールドはデフォルト値のままで問題ありません。

  5. ローカルルーティングマッピングを有効にすることを忘れずに、「保存」をクリックします保存。

ルーティングを有効にする

DeepSeek に切り替えると、システムがルーティングの有効化を促します。左上隅の設定ボタンをクリックして設定ページに入り、有効にすることができます：

「ルーティング設定」メニューをクリックし、ルーティングを有効にします：

次に「Codex」を選択します：

次に Codex を開き直すと、DeepSeek のモデルマークが表示されます：

モデルの選択：flash か pro か？

DeepSeek V4 には2つのバージョンがあり、適用シーンが異なります。適切なモデルを選択することで、コストと能力のバランスを取ることができます。

モデル 特徴 適用シーン
flash 高速・低コスト 日常的なコード補完、簡単なQ&A
pro 能力が高く、推論コンテンツに対応 複雑なアーキテクチャ設計、マルチステップ推論

CC Switch のプロバイダー編集画面では、使用するモデルをいつでも変更できます。変更後すぐに反映され、Codex の再起動は不要です。

よくある質問

プロバイダー切り替え後に Codex が接続エラーを報告する

CC Switch の Local Routing が実行中（緑色のアイコン）であることを確認してください。

インストールしたばかりの場合は、環境変数を有効にするためにターミナルを再起動する必要があるかもしれません。

公式 OpenAI エンドポイントを再び使用したい場合

CC Switch で Local Routing のオーバーライドをオフにするか、公式 OpenAI プロバイダーに切り替えると、Codex は自動的に元の設定を使用します。

CC Switch は私の API Key を記録しますか？

CC Switch はローカルアプリケーションであり、すべての設定はローカルマシンに保存されます。API Key がサーバーにアップロードされることはありません。
