Codex コマンドラインツール

Codex CLI は公式のコマンドラインツールで、Rust で書かれており、軽量で効率的、ターミナル愛好家に適しています。

CLI のインストール

Codex CLI は macOS、Linux、Windows（実験的）に対応しています。

npm によるインストール

npm でグローバルインストール

# npm を使用してインストール
npm install -g @openai/codex

# インストールの確認
codex --version

Homebrew によるインストール

Homebrew によるインストール

# macOS では Homebrew を使用
brew install codex

CLI の更新

バージョンの更新

# npm で更新
npm install -g @openai/codex@latest

# Homebrew で更新
brew upgrade codex

初回使用

初回に Codex を実行すると、認証が案内されます：

Codex を起動

# 対話型インターフェースを起動
codex

# または初期タスクを指定
codex 「このプロジェクト構造を説明してください」

Codex はブラウザを開いて認証を行います：

  1. ChatGPT アカウントでログイン
  2. または OpenAI API Key を使用
  3. 認証後、ターミナルに戻って続行します

対話型 TUI

CLI はデフォルトで端末ユーザーインターフェース（TUI）モードに入り、没入感のある体験を提供します。

TUI インターフェースの領域

領域機能
メッセージ領域会話履歴、ツール呼び出し、実行結果を表示
入力領域下部の入力ボックスで、プロンプトを送信
ステータスバーモデル、コンテキスト使用量、スレッド情報を表示

TUI モード設定

TUI 設定

# ~/.codex/config.toml

[tui]
# 代替スクリーンモード
alternate_screen = "auto"  # auto | always | never

# 代替スクリーンを無効にする場合、スクロール履歴を保持
# alternate_screen = "never"

代替スクリーンモードでは Codex が独立した画面を使用し、終了時に元のターミナル状態に復元されます。

Approval モード

Approval モードは、Codex が操作を実行する前の確認動作を制御します。

4つのモード

モード説明動作
suggest提案モードCodex は提案を提供するが実行しない
auto-edit自動編集ファイル編集を自動実行し、コマンドは確認が必要
full-auto全自動すべての操作を自動実行（注意して使用）
interactive対話モード敏感な操作の前に確認（デフォルト）

Approval モードの設定

# コマンドラインでモードを指定
codex --approval-mode full-auto

# またはセッション内で切り替え
/approval full-auto

full-auto モードでは、Codex はファイルの削除を含むすべての操作を自動実行します。注意して使用してください。

Sandbox モード

Sandbox モードは、Codex のファイルとコマンドのアクセス範囲を制限します。

モードファイル変更コマンド実行ネットワークアクセス
read-only禁止禁止禁止
workspace-writeワークスペースのみ許可禁止
danger-full-access許可許可許可

Sandbox モードの設定

# 読み取り専用モード
codex --sandbox read-only

# ワークスペース書き込みモード（推奨）
codex --sandbox workspace-write

# 完全アクセスモード（危険）
codex --sandbox danger-full-access

スラッシュコマンド

CLI は豊富なスラッシュコマンドを提供します：

コマンド機能
/modelモデルを切り替え（例: /model gpt-5.4-mini）
/fastFast モードに切り替え
/planプランモードに入る
/reviewコード変更をレビュー
/new新しいセッションを開始
/resume履歴セッションを復元
/fork現在のセッションを新しいスレッドにクローンしますします
/compactコンテキスト履歴を圧縮
/statusセッション状態を表示
/clear画面をクリア
/quitCodex を終了

コマンド使用例

スラッシュコマンド

# モデルを切り替え
/model gpt-5.4-mini

# プランモード
/plan ユーザー認証システムを実装

# 状態を確認
/status

Shell コマンドの実行

CLI で Shell コマンドを直接実行できます：

コマンドを実行

# ! で始まるコマンドを実行
! ls -la

# git コマンドを実行
! git status

# プロセスを表示
! ps aux

コマンドの確認

危険なコマンドは確認が必要です：

  • ファイルの削除（rm）
  • プロセスの終了（kill）
  • システム設定の変更

画像の入力

CLI は画像をコンテキストとして添付できます：

画像を添付

# スクリーンショットを添付
codex -i screenshot.png

# デザイン案を添付
codex --image design.png 「このデザインに基づいてページを実装してください」

# 複数の画像
codex -i img1.png -i img2.png

画像の用途

  • スクリーンショットでエラー情報を分析
  • UI デザインをコードに変換
  • グラフデータの解釈

非対話モード（exec）

exec コマンドを使用して単発タスクを実行します。スクリプトや CI/CD に適しています：

exec コマンド

# 単発タスクを実行
codex exec 「コードをレビューしてレポートを出力してください」

# ファイルに出力
codex exec 「README を生成してください」 -o README.md

# 特定のモデルを使用
codex exec -m gpt-5.4-mini 「プロジェクト構造を分析してください」

# 全自動モード
codex exec --full-auto 「テストを実行して失敗を修正してください」

exec のよく使うパラメータ

パラメータ説明
-mモデルを指定
-oファイルに出力
--full-auto全自動で実行
--ephemeralセッションファイルを保存しない
--jsonJSON 出力形式

よくある質問

Q: Windows のサポート状況は？

Windows のネイティブサポートは実験的です。最適な体験を得るには WSL2 の使用を推奨します。

Q: 代替スクリーンを無効にするには？

使用codex --no-alt-screenまたは設定alternate_screen = "never"。

Q: コマンドが見つからない場合は？

PATH に npm のグローバルインストールディレクトリが含まれていることを確認するか、Homebrew を使用してインストールしてください。

Q: 詳細ログを確認するには？

ログは次の場所にあります。~/.codex/log/ディレクトリ。
