例1: 新機能の作成

Codex に完全な機能モジュールを作成させましょう：

タスク

文字列のリストを受け取り、最も長い文字列とそのインデックス位置を返す Python 関数を作成してください

Codex は以下のようなコードを生成します：

生成されたコード

def find_longest_string(strings):
    """
文字列リスト内の最も長い文字列とそのインデックス位置を見つけます。

    Args:
strings: 文字列リスト

    Returns:
tuple: (最長の文字列, インデックス位置)
リストが空の場合は (None, -1) を返します
    """
    if not strings:
        return None, -1

    longest = max(strings, key=len)
    index = strings.index(longest)

    return longest, index


# テスト例
if __name__ == "__main__":
    test_list = ["apple", "banana", "cherry", "dragonfruit"]
    result, idx = find_longest_string(test_list)
    print(f最長の文字列: {result}, インデックス: {idx})
    # 出力: 最長の文字列: dragonfruit, インデックス: 3
Codex が生成したコードには詳細なドキュメントコメントとテスト例が含まれており、そのまま使用できます。

例2: コードのリファクタリング

Codex に既存のコードのリファクタリングを依頼します：

タスク

この関数をジェネレータを使うようにリファクタリングしてください：
def get_squares(n):
    result = []
    for i in range(n):
        result.append(i * i)
    return result

Codex はリファクタリング後のコードを提供します：

リファクタリング後のコード

def get_squares(n):
    """
0 から n-1 までの平方数を生成します。

    Args:
n: 生成する平方数の個数

    Yields:
int: 0 から n-1 までの平方数
    """
    for i in range(n):
        yield i * i


# 使用例
for square in get_squares(5):
    print(square)
# 出力: 0, 1, 4, 9, 16

コードレビュー

例1: コードの問題をレビューする

Codex にコードをレビューして改善提案を依頼します：

タスク

以下のコードの問題をレビューしてください：
def process_data(data):
    result = []
    for item in data:
        if item['type'] == 'a':
            result.append(item['value'] * 2)
        elif item['type'] == 'b':
            result.append(item['value'] + 10)
        elif item['type'] == 'c':
            result.append(item['value'])
    return result

Codex は分析し、レビュー報告を提供します：

## 代码审查报告

### 问题
1. **缺少错误处理**：没有检查 item 是否包含必要的键
2. **类型不一致**：'c' 类型直接返回原值，而其他类型做了处理
3. **硬编码值**：乘数和加数应该作为参数或配置

### 改进建议
1. 添加默认字典或 try-except 处理
2. 统一处理逻辑
3. 将 magic numbers 提取为常量

例2: デバッグログの追加

Codex にデバッグコードの追加を依頼します：

タスク

この関数にデバッグログを追加してください：
def calculate(a, b):
    return a + b * (a - b)

Codex はデバッグログ付きのバージョンを生成します：

デバッグログの追加

import logging

# ログの設定
logging.basicConfig(level=logging.DEBUG)
logger = logging.getLogger(__name__)


def calculate(a, b):
    """デバッグログ付きの計算関数"""
    logger.debug(f"calculate called with a={a}, b={b}")

    result = a + b * (a - b)

    logger.debug(f"a + b = {a} + {b} = {a + b}")
    logger.debug(f"a - b = {a} - {b} = {a - b}")
    logger.debug(f"b * (a - b) = {b} * {a - b} = {b * (a - b)}")
    logger.debug(f"final result: {result}")

    return result
