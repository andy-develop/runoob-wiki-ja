よくある質問

インストールと認証

Q: Codex CLI をインストールするには？

npm または Homebrew を使用します：

npm install -g @openai/codex
# 或
brew install codex

Q: 初回使用時の認証方法は？

codex コマンドを実行するとブラウザが自動的に開いて認証が行われ、ChatGPT アカウントまたは API Key でログインします。

Q: Windows のサポート状況は？

Windows のネイティブサポートは実験的であり、最適な体験を得るには WSL2 の使用を推奨します。

使用方法の問題

Q: 現在の設定を確認するには？

使用します/statusコマンドで現在のセッションの設定と状態を確認します。

Q: 代替スクリーンを無効にするには？

使用するかcodex --no-alt-screenまたは設定しますalternate_screen = "never"。

Q: コマンドが見つからない場合は？

PATH に npm のグローバルインストールディレクトリが含まれていることを確認するか、Homebrew を使用してインストールしてください。

Q: ログを確認するには？

ログは~/.codex/log/ディレクトリにあります。

機能の問題

Q: exec と対話モードの違いは？

exec は単回実行後に終了し、自動化スクリプトに適しています。対話モードは継続的な会話ができ、日常の開発に適しています。

Q: 履歴セッションを復元するには？

使用するか/resumeコマンドまたはcodex resume --last。

Q: GitHub Action でファイルを変更できますか？

はい、sandbox: workspace-write を設定してください。

Q: CI/CD ではどのように認証しますか？

CODEX_API_KEY 環境変数を Secrets として保存して使用します。

セキュリティの問題

Q: Codex が重要なファイルを削除しないようにするには？

read-only または workspace-write サンドボックスモードを使用し、Rules を設定して危険なコマンドを禁止します。

Q: full-auto モードは安全ですか？

full-auto はファイルの削除を含むすべての操作を自動的に実行するため、注意して使用してください。

Q: 機密データをどのように扱いますか？

Secrets ストレージを使用し、セットアップスクリプト内でのみ利用可能です。

用語集

用語説明
AgentCodex の中核となる実行ユニットで、タスクを理解して操作を実行できる
Promptユーザーが Codex に送信するタスク指示
Threadセッションのシーケンスで、完全な会話履歴を含む
ContextCodexが利用可能な情報範囲（ファイル、会話、設定を含む）

AGENTS.mdプロジェクト指示ファイルで、Codexの行動規範を定義
Skill再利用可能なカスタム機能モジュール
Subagent複雑なタスクを並行処理するためのサブエージェント
Rulesコマンド実行権限を定義するルールエンジン
