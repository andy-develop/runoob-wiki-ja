Codex IDE拡張

Codex IDE拡張を使用すると、慣れ親しんだ開発環境で直接Codexを利用でき、日常のコーディングワークフローにシームレスに統合できます。

対応IDE

Codexは公式に以下のIDEをサポートしています：

IDE拡張機能IDインストール方法
VS Codeopenai.chatgptvscode:extension/openai.chatgpt
VS Code Insidersopenai.chatgpt拡張機能マーケットプレイス
Cursoropenai.chatgptcursor:extension/openai.chatgpt
Windsurfopenai.chatgptwindsurf:extension/openai.chatgpt

拡張機能のインストール

VS Code インストール

VS Code インストール

# 方法1：コマンドラインでインストール
code --install-extension openai.chatgpt

# 方法2：VS Code内で
# 1. 拡張機能パネルを開く (Cmd+Shift+X)
# 2. "Codex" または "ChatGPT" を検索
# 3. インストールをクリック

Cursor インストール

Cursor インストール

# 方法1：コマンドライン
cursor --install-extension openai.chatgpt

# 方法2：Cursor内で
# 1. 拡張機能パネルを開く
# 2. "Codex" を検索
# 3. インストールをクリック

インストール後、ChatGPTアカウントまたはOpenAI APIキーでログインする必要があります。

コア機能

自動コンテキスト

IDE拡張は自動的に以下の内容をコンテキストとしてCodexに渡します：

  • 現在開いているファイルのリスト
  • エディターで選択したテキスト範囲
  • 現在の作業ディレクトリ情報

AI対話

IDE内で直接Codexと対話できます：

  • Codexパネルを開く（ショートカットキーまたはサイドバー）
  • 質問またはタスクの説明を入力
  • Codexが現在のファイルとプロジェクトを分析して返信

コード操作

コードを選択して右クリックで実行できます：

操作機能
説明Codexが選択したコードの機能を説明
書き換え要件に応じて選択したコードを書き換え
レビューコードの問題点と改善提案をチェック
テスト生成選択したコードのユニットテストを生成

スラッシュコマンド

Codexパネルでスラッシュコマンドを使用：

コマンド機能
/explain選択したコードを説明
/fix選択したコードの問題を修正
/test選択したコードのテストを生成
/review選択したコードをレビュー
/plan計画してから実行

スラッシュコマンドの例

# コードを説明
/explain

# バグを修正
/fix this function throws error for null input

# 新機能を計画
/plan implement user authentication with JWT

モデル選択

入力欄の下でモデルを切り替えられます：

モデル特徴
GPT-5.4フラッグシップモデル、複雑なタスクに適しています
GPT-5.4-mini軽量で高速、簡単なタスクに適しています
GPT-5.3-Codexプロフェッショナル向けコーディングモデル

ショートカットキー

ショートカットキー機能
Cmd+Shift+CCodexパネルを開く
Cmd+Shift+Enterコード補完
Cmd+Shift+R選択したコードを書き換え
Cmd+Shift+E選択したコードを説明

ショートカットキーはIDE設定でカスタマイズでき、他の拡張機能との競合を回避できます。

クラウドタスク委任

IDE拡張からクラウドタスクを起動：

  • Cloudモードを選択してスレッドを作成
  • タスクはクラウドの隔離環境で実行
  • 完了後、通知またはPRで結果を確認

適用シーン

  • 複数のタスクを並行処理する必要がある
  • 低スペックデバイスから大規模タスクを委任
  • デバイス間での連携作業

IDE設定

ファイルの開き方の設定

ファイルを開く設定

# ~/.codex/config.toml

# ファイルを開くエディターを指定 # 選択肢: vscode, vscode-insiders, windsurf, cursor, none
file_opener = "vscode"

デフォルトモデルの設定
