Codex 統合と接続

Codex は多様な開発ツールやプラットフォームとの統合をサポートし、その能力と適用シナリオを拡張します。

GitHub 統合

Codex は GitHub と深く統合されており、PR 内で直接コードレビューを行うことができます。

機能概要

機能説明
PR レビューPR コメントで @codex review と入力してレビューを取得
自動レビュー新しい PR ごとに自動的にレビューをトリガー
CI 修正@codex fix the CI failures
クラウドタスク他の @codex 指令でクラウドタスクを起動

GitHub 統合の設定

  1. Codex Cloud を設定
  2. 設定ページに移動して Code Review を有効にする
  3. あなたの GitHub リポジトリへのアクセスを承認
  4. 有効にするリポジトリを選択

レビューをリクエスト

PR での使用

# PR コメントに入力
@codex review

# レビューの重点を指定
@codex review for security issues

# パフォーマンスの問題をレビュー
@codex review for performance regressions

Codex の応答

Codex は次のことを行います：

  1. PR に反応 👀
  2. コード変更を分析
  3. レビューコメントを投稿
  4. 発見された問題をマーク（デフォルトは P0 と P1）

レビューガイドラインのカスタマイズ

リポジトリの AGENTS.md でレビュールールを定義：

レビューガイドライン

## Review guidelines

- PII（個人識別情報）をログに記録しない
- Verify authentication middleware wraps every route
- Check for SQL injection vulnerabilities
- Ensure error messages don't leak sensitive info
- Treat typos in docs as P1 issues

Codex はデフォルトで P0 と P1 の問題のみをマークします。AGENTS.md で調整できます。

Slack 統合

Linear 統合

Linear はプロジェクト管理ツールであり、Codex はそれと連携して Issue を処理できます。

Linear 統合の設定

  1. Codex 設定ページに移動
  2. Linear 統合を追加
  3. Linear ワークスペースへのアクセスを承認
  4. Issue 処理ルールを設定

MCP（Model Context Protocol）

MCP は Codex と外部ツールを接続するプロトコルです。

MCP 概要

  • STDIO サーバー：ローカルプロセス。標準入出力で通信
  • HTTP サーバー：リモートサーバー。HTTP API で通信

MCP サーバーの設定

MCP 設定

# ~/.codex/config.toml

# STDIO サーバー
[mcp_servers.filesystem]
command = "npx"
args = ["-y", "@modelcontextprotocol/server-filesystem", "./docs"]

# HTTP サーバー
[mcp_servers.api]
url = "https://api.example.com/mcp"
bearer_token_env_var = "API_TOKEN"

よく使われる MCP サーバー

サーバー機能
filesystemファイルシステムアクセス
githubGitHub API
postgresPostgreSQL データベース
fetchウェブスクレイピング
openai-docsOpenAI ドキュメント

MCP ツール権限

ツール権限の設定

# ツールのホワイトリスト
[mcp_servers.filesystem]
enabled_tools = ["read_file", "write_file"]

# ツールのブラックリスト
disabled_tools = ["delete_file"]

# ツールの承認モード
[mcp_servers.filesystem.tools.write_file]
approval_mode = "ask"  # ask | approve | deny

OAuth 認証設定

一部の MCP サーバーは OAuth 認証を必要とします：

OAuth 設定

[mcp_servers.figma]
url = "https://api.figma.com/mcp"
scopes = ["file:read"]
oauth_resource = "codex-integration"

# OAuth コールバックポート
mcp_oauth_callback_port = 8080

# 資格情報の保存
mcp_oauth_credentials_store = "keyring"

よくある質問

Q: GitHub 統合にはどのプランが必要ですか？

Codex Cloud サブスクリプション（Plus 以上）が必要です。

Q: Codex がアクセスできるリポジトリを制限できますか？

設定でリポジトリを選択的に承認できます。

Q: MCP サーバーはどのようにインストールしますか？

ほとんどの MCP サーバーは npm でインストールされ、Codex が自動的に管理します。

Q: 他の統合はサポートされていますか？

Codex は新しい統合を継続的に追加しています。公式アップデートに注目してください。
