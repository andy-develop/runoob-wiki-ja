常用数学記号

AI論文やチュートリアルを読み解く最初のハードルは、たいてい数学そのものではなく、ページ中に並ぶ数学記号である。

この章では、AI学習で最もよく使う記号を表にまとめた。ざっと目を通してもよいし、後で必要になったときに調べに来てもよい：

  • 順番に通読する：各記号に「いつ使うか」の説明を付けているので、ざっと目を通して全体像をつかもう。

  • その都度調べて使う：論文やチュートリアルを読んでいて、ある記号で詰まったら、この表を調べに戻ろう。

ほとんどの記号には実行可能なPythonサンプルが付いている。自分で手を動かして一度計算してみる方が、10回見るより効果的だ。

指数と対数

AIで最も登場頻度の高い関数のペアである。

sigmoidとsoftmaxに登場し、数値を「拡大または圧縮」する役割を担う；交差エントロピー損失に登場し、「掛け算を足し算にする」役割を担う。

記号意味例
aのn乗
任意の非ゼロ数の0乗
eを底とする指数関数
aを底とするxの対数
自然対数（eを底とする）
論文では通常、暗黙にこの自然対数を指す

4つの演算規則はしっかり使いこなせるようにしておく必要がある。損失関数の導出で繰り返し使われる：

底の変換公式を使えば、任意の底の対数を自然対数に変換できる。プログラミングでもよく使われる：

例

# 底の変換公式を使って log_2(100) を計算する
# Pythonのmath.log(x, base)は内部でこのようにしている
import math

x = 100
base = 2

# 直接呼び出す
print(math.log(x, base))

# 底の変換公式を手書き：log_2(100) = ln(100) / ln(2)
print(math.log(x) / math.log(base))

上記のコードを実行すると出力結果は次のようになる：

6.643856189774725
6.643856189774725

そのため実装では通常、次のように書く：、ただしは非常に小さな正の数、例えば0.0000001である。

関数関連の記号

関数とは「入力から出力への対応規則」である。ニューラルネットワークは本質的に、多くの層の関数を合成したものである。

記号意味例 / 説明
関数。xをfで写した結果
fは集合Aの要素を集合Bに写す関数の「型シグネチャ」を表す
逆関数。fの操作を取り消す
合成関数。g(x)を先に計算してからfに代入する
xの変化量
yの予測値（y-hatと読む）真のラベルyと区別する
sigmoid活性化関数

機械学習では（y-hatと読む）は専らモデルの予測値を指し、は真のラベルを指す。両者の差が予測誤差である。

合成関数はニューラルネットワークを理解するための鍵である：2層ネットワークは本質的にであり、逆伝播で層ごとに勾配を計算する際に頼るのは、まさに合成関数の微分における連鎖律である。

例

# 合成関数の計算：y = f(g(x))
# g(x) = x + 1、f(x) = x^2 とする

def g(x):
    return x + 1          # 内側の関数

def f(x):
    return x ** 2         # 外側の関数

# 合成：g(x)を先に計算し、その結果をfに代入する
print(f(g(3)))            # g(3)=4, f(4)=16
print(f(g(3)) == (3 + 1) ** 2)

上記のコードを実行すると出力結果は次のようになる：

16
True

例

# コードで総和記号を体感する：z = sum(w_i * x_i) + b
w = [0.5, -1.0, 2.0]   # 重み。公式のw_iに対応
x = [2.0,  3.0, 1.0]   # 入力。公式のx_iに対応
b = 0.1                # バイアス

# sum_{i=1}^{3} w_i * x_i は次の行に相当する

print(0.5*2 + (-1.0)*3 + 2.0*1 + 0.1)

0.1
0.1

集合記号は「データがどの集合に属するか」を表し、論理記号は「条件をどのように組み合わせるか」を表す。確率と機械学習の理論で多用される。

記号意味例

属さない

これらの記号は論文の定理や仮定の部分で最もよく現れる。例えば「「任意の0より大きいepsilonに対して、あるNが存在する」と読む。

線形代数

ニューラルネットワークの基盤となる構造です。ディープラーニングフレームワークの毎回の行列演算は、これらの記号を使っています。

記号意味例 / 説明
ベクトル（太字小文字）
行列（太字大文字）m 行 n 列の数の表
転置：行と列を入れ替える行ベクトルが列ベクトルになる
行列の掛け算要素ごとの掛け算ではない
要素ごとの積（アダマール積）同じ形状の行列の対応する位置どうしを掛ける

ドット積（内積）

ドット積は attention 機構の骨格です。transformer の各層はクエリベクトルとキーベクトルのドット積を計算し、それらの「類似度」を測っています。

例

# ドット積とL2ノルムの記号対照
# x · y = sum(x_i * y_i)，||x||_2 = sqrt(sum(x_i^2))
import math

x = [1.0, 2.0, 3.0]
y = [4.0, 0.0, -1.0]

# ドット積 x · y
dot = sum(xi * yi for xi, yi in zip(x, y))
print(dot)

# L2ノルム ||x||_2
norm2 = math.sqrt(sum(xi ** 2 for xi in x))
print(norm2)

# 展開して検証
print(1.0*4.0 + 2.0*0.0 + 3.0*(-1.0))
print(math.sqrt(1 + 4 + 9))

上記のコードを実行すると、出力は次のようになります：

1.0
3.7416573867739413
1.0
3.7416573867739413

微分積分

トレーニングの本質は「勾配の反対方向にパラメータを調整する」ことなので、論文の最適化の章はこれらの記号なしには成り立ちません。

今すぐ計算できなくても構いません。それぞれの記号を読み解ければ十分です。

記号意味例 / 説明
導関数：x に対する y の変化率
導関数のもう一つの表記
偏微分：x だけが変化するときの f の変化率多変数関数では
勾配：すべての偏微分からなるベクトル
積分。微分の逆演算
極限：x が a に近づくときの値

ディープラーニングで最も重要な公式は、上の表の2行だけを使っています。勾配降下法のパラメータ更新規則です：

記号を1つずつ分解すると：はパラメータで、は「右辺の値で左辺を更新する」ことを表し、は学習率で、は損失関数 J のパラメータ θ に対する勾配です。

一言で言うと：新しいパラメータ = 古いパラメータ − 学習率 × 勾配、すなわち損失を最も速く減らす方向へ小さく一歩踏み出すことです。

これは「ナブラ」または「勾配オペレータ」と読みます。数値ではなく、「後ろのすべての変数に対して偏微分を取る」という操作命令であり、プログラミングにおける高階関数によく似ています。

分類モデルが予測するときに行っているのはまさにです。確率が最大のクラスを取り出し、argmax が返すのはクラスの番号であって、確率の数値ではありません。

学習のアドバイス

記号表を丸暗記する必要はありません。記憶よりも方法のほうが効果的です。

第一に、記号を1つずつ分解する習慣をつけましょう。公式に出合ったら、各記号が演算子・変数・関数のどれかをまず問い、次にその記号が現在の文脈で何を表すかを問います。分解し終えると、たいてい謎ではなくなります。

第二に、次の3つを優先的に徹底的に理解しましょう：総和、指数と対数、添え字の記法。これらは線形代数と微分積分の公式を読み解くための前提条件であり、本稿ではそれぞれ専用の節を設けています。

第三に、知らない記号に出合ったら「記号名 + 数学的な意味」を直接検索するのが、教科書に粘り強く取り組むより速いです。

記号は地図であり、地形そのものではありません。本当の理解は、それらを使って具体的な例を計算した経験から得られます。本稿の Python の例はすべて、実際に手を動かして実行する価値があります。
