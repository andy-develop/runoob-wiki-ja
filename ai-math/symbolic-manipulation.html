記号演算能力

前の章ではさまざまな規則や概念を学びました。この章では、皆さんの熟練度、つまり自分で公式を一通り導出できるかどうかを確認します。

この能力は、論文の導出を追っていけるかどうかを直接決定します。著者が途中のステップを省略した場所で詰まらずに済むかどうかです。各知識ポイントにはインタラクティブなデモが付いており、特に (a+b)² の幾何学的分割アニメーションは、一度見れば「交差項 2ab がどこから来るのか」を理解できます。

なぜ「記号演算能力」が重要なのか

論文を読んでいるとよくこういう場面に遭遇します：著者が「整理すると、……が得られる」と書き、途中の3、5ステップを省略しているのです。

記号演算に熟練していないと、この数ステップの飛躍があなたを直接門前払いにしてしまいます。

熟練していれば、自分でその数ステップを補い、著者の考えに本当に「ついていく」ことができます。結論を受け身で受け入れるのではなく。

同じ規則でも、「知っている」と「目をつぶっても使いこなせる」は異なる能力レベルです。この章で鍛えるのは後者です。

(a+b)² から多変数展開へ

もっとも基本的な恒等式

幾何的な視点：なぜ「2ab」が現れるのか

把 「一辺が a+b の正方形の面積」ととらえると、この正方形を4つの部分に切り分けられます：

領域形面積
左上一辺が a の正方形
右上縦 b、横 a の長方形
左下縦 a、横 b の長方形
右下一辺が b の正方形

4つの面積を合計すると。

この「2ab」は突然現れたのではなく、2つの交差する長方形によるものです。下の「展開」ボタンをクリックすると、4つの面積がどのように分かれるかを見られます。

ベクトルへの拡張

この規則はベクトル演算の中で別の形で繰り返し登場します。たとえば、2つのベクトルの差のノルムの2乗を計算する場合：

本質は、の中の「数」を「ベクトル」に、「乗法」を「内積」に置き換えたものです。

論文で似たような展開を見かけたら、ここで学んだ規則を連想してください。新しい公式はたいてい古い規則が姿を変えただけです。これこそ「記号演算能力」が新しい公式を「見抜く」手助けになる方法です。

実例

# 数値で恒等式を検証：公式を覚え間違えていないか確認する良い習慣
# 考え方：適当な数をいくつか代入し、等式の両辺が等しいか確認する

for a, b in [(2, 3), (5, 1), (0.5, 2.5), (-1, 4)]:
    lhs = (a + b) ** 2                 # 左辺：(a+b)²
    rhs = a ** 2 + 2 * a * b + b ** 2  # 右辺：a² + 2ab + b²
    print(a, b, abs(lhs - rhs) < 1e-12)

# ついでにベクトル版も検証：‖x - y‖² = ‖x‖² - 2x·y + ‖y‖²
import math
x, y = (3, 4), (1, 2)
lhs = (x[0]-y[0])**2 + (x[1]-y[1])**2
rhs = (x[0]**2 + x[1]**2) - 2*(x[0]*y[0] + x[1]*y[1]) + (y[0]**2 + y[1]**2)
print(abs(lhs - rhs) < 1e-12)

上記のコードを実行すると、出力結果は次のようになります：

2 3 True
5 1 True
0.5 2.5 True
-1 4 True
True

この「ランダム代入検証」の方法はとても実用的です。公式の詳細を忘れたとき、数をいくつか代入すれば、覚えているバージョンが正しいか確認できます。

整理・変形・平方完成

平方完成：一般式を「頂点形」に変換する

平方完成の目標は、という「何かが足りない」形の式を、完全な平方にまとめることです：

例題：を平方完成して、。

検証：を展開すると、確かに等しくなります。

平方完成の代表的な用途は2つあります：

用途方法例
二次関数の頂点を求める頂点 (-3, -7) を直接読み取れる。グラフを描いたり微分したりする必要がない
完全平方にまとめて導出を簡略化する複雑な多項式を平方の形にまとめる最小二乗法、正規分布の最尤推定の途中ステップ
インタラクティブデモ：平方完成と頂点
スライダーをドラッグして b を変え、放物線 y = x² + bx の頂点がどう動くか、また頂点の x 座標が常に -b/2 になることを観察しましょう。

整理するときの一般的な考え方

複雑な式に遭遇したら、通常は次の順序で試します：

順序テクニック説明
1同類項をまとめる同じ変数のべき乗をまとめる
2共通因数をくくり出すすべての項に共通する因数を見つけてくくり出す
3恒等式を利用するを適用する、などの既成の公式
4置換繰り返し現れる複雑な部分式を新しい変数で置き換える

置換法の例題：整理せよ。

令 t = x² + 1
原式 = t² - 3t + 2 = (t-1)(t-2)
代回 t：
     = (x²+1-1)(x²+1-2)
     = x² · (x²-1)
     = x⁴ - x²

公式を自分で導出できるかどうかが分かれ目

「理解する」と「導出できる」は異なる能力レベル

レベル様子
読んで理解できる導出のステップを見て、「このステップがなぜ成り立つのか」を理解できる
導出できる本を閉じて、自分でその数ステップをやり直すことができる

多くの人が論文を読むときに詰まるのは、「新しい知識」ではなく、このレベルです。公式に使われているのはすべて第1章から第3章までに学んだ規則であり、ヒントなしで自分で正しいステップの順序を組み立てる必要があるだけです。

完全な導出練習：平均二乗誤差の最小値

問題：n 個のデータ点が与えられたとき、すべての点から c への「平方距離の和」を最小にする最適な c を求めよ。

導出過程：

设 f(c) = Σᵢ (xᵢ - c)²

展开每一项（用到 (a-b)² 公式）：
f(c) = Σᵢ (xᵢ² - 2cxᵢ + c²)
     = Σᵢ xᵢ² - 2c·Σᵢxᵢ + n·c²    （把 Σ 拆到每一项，c 是常数可以提出来）

这是关于 c 的二次函数，开口向上（c² 系数为 n > 0），
顶点（最小值点）在 c = -B/2A，这里 B = -2Σxᵢ，A = n

代入：c = -(-2Σxᵢ) / (2n) = Σxᵢ / n

結論：最適な c は、ちょうどすべてのデータ点の平均値になります。

この導出は、この章と第1章の知識（平方展開、Σ の和、二次関数の頂点公式）だけを使って、統計学における「なぜ平均値が平方誤差を最小化する最適点なのか」という重要な結論を導いています。

スライダーをドラッグして実際に確かめてみましょう：c が平均値からずれると、平方距離の和がどのように大きくなるか。

インタラクティブデモ：なぜ平均値が平方誤差を最小にするのか
5つのデータ点は 1, 3, 4, 8, 9（平均値 5）に固定されています。スライダーをドラッグして c を動かし、f(c) = Σ(xᵢ-c)² の変化を観察しましょう。c = 5 のとき誤差が最小になります。
灰色の点はデータ点、赤い放物線は f(c)、青い点は現在の c の位置です。c がどちらにずれても、誤差は c = 5 のときの最小値より大きくなります。

実例

# 数値検証：平均値は Σ(xᵢ-c)² を最小にする c である
data = [1, 3, 4, 8, 9]
mean = sum(data) / len(data)

def sq_error(c):
    """f(c) = Σ(xᵢ - c)²"""
    return sum((x - c) ** 2 for x in data)

print(mean)            # 平均値 = 5
print(sq_error(mean))  # c = 平均値 のときの誤差

# 平均値からずれたいくつかの c と比較：誤差はすべて大きい
for c in [0, 3, 5, 7, 10]:
    print(c, sq_error(c))

上記のコードを実行すると、出力結果は次のようになります：

5.0
46.0
0 171
3 66
5 46
7 66
10 171

c=3 と c=7 の誤差が等しい（ともに 66）ことに注目してください。これらは平均値 5 までの距離が同じだからです。これはまさに放物線が「頂点に関して対称」であることの表れです。

練習：上記の説明を見ずに、「平均値が平方誤差を最小化する」過程を独立して一通り導出してみましょう。使ってよいのは、平方展開の公式、Σ の線形性、二次関数の頂点公式の3つだけです。

本章のまとめ

平方完成「欠けた部分」のある式を完全平方に整え、頂点を求めたり導出を簡略化するのに使う
簡略化の考え方同類項をまとめる → 共通因数をくくり出す → 恒等式を適用する → 置換する
自力での導出答えを見ずにもう一度導出を辿れることが、論文の数式を読み解く分かれ目である
