交叉熵与 KL 散度 -- 衡量分布之间的差距 → 交差エントロピーとKLダイバージェンス -- 分布間の乖離を測る

交叉熵是分类任务最常用的损失函数。 → 交差エントロピーは分類タスクで最もよく使われる損失関数です。KL 散度衡量两个概率分布有多不像。 → KLダイバージェンスは2つの確率分布がどれだけ異なるかを測ります。

概念解析 → 概念の解説

上一章学了熵——衡量单个分布自身的混乱程度。本章的两个概念衡量的是 → 前章ではエントロピー——単一の分布自体の乱雑さを測る——を学びました。本章の2つの概念が測るのは两个分布之间的差距 → 2つの分布間の乖離，这直接决定了分类任务中损失函数的设计。 → であり、これが分類タスクにおける損失関数の設計を直接決定します。

交叉熵 → 交差エントロピー

\[ H(p, q) = -\sum_x p(x) \log q(x) \]

含义：用预测分布 q 去编码真实分布 p 的数据，平均花多少信息量。 → 意味：予測分布 q で実際の分布 p のデータを符号化するとき、平均でどれだけの情報量を使うか。

KL 散度（相对熵） → KLダイバージェンス（相対エントロピー）

\[ D_{KL}(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)} = \underbrace{H(p,q)}_{\text{交差エントロピー}} - \underbrace{H(p)}_{\text{真のエントロピー}} \]

含义：q 代替 p 后额外浪费的信息量。KL ≥ 0，等于 0 时 p=q。 → 意味：q が p の代わりになったときに余分に浪費される情報量。KL ≥ 0 で、0 に等しいとき p=q。

KL 散度 → KLダイバージェンス不对称 → 非対称：D_KL(p||q) ≠ D_KL(q||p)，它不是真正的「距离」。 → ：D_KL(p||q) ≠ D_KL(q||p) であり、真の「距離」ではありません。

当真实分布 p 是 one-hot（确定）时，H(p)=0，此时交叉熵 = KL 散度。 → 実際の分布 p が one-hot（確定的）の場合、H(p)=0 となり、このとき交差エントロピー = KLダイバージェンス です。

为什么分类用交叉熵而不是 MSE？ → なぜ分類にはMSEではなく交差エントロピーを使うのか？

交叉熵 + Softmax 的梯度 = \( \hat{y} - y \)（预测 - 真实），简洁高效。 → 交差エントロピー + Softmax の勾配 = \( \hat{y} - y \)（予測 - 実際）で、簡潔かつ効率的です。

MSE + Softmax 的梯度在预测自信时趋近于 0——梯度消失，学不动。 → MSE + Softmax の勾配は予測に自信があるときに 0 に近づきます——勾配消失で学習が進みません。

生活例子 → 身近な例

密码本设计 → コードブック（暗号表）の設計

你用一套密码（短码代表常见字，长码代表生僻字）写信。 → あなたはあるコード（短いコードは一般的な文字、長いコードは珍しい文字を表す）を使って手紙を書きます。

但如果你的密码基于英文频率设计，而写的是中文——编码效率低下。 → しかし、あなたのコードが英語の頻度に基づいて設計されていて、中国語を書く場合——符号化効率が低くなります。

用错误的分布 q 去编码真实分布 p 的数据，额外浪费的比特 = KL 散度。 → 誤った分布 q で実際の分布 p のデータを符号化するとき、余分に浪費されるビット = KLダイバージェンス です。

Python 动手实践 → Pythonで実践

実例

import numpy as np

def cross_entropy(p, q):
    return -np.sum(p * np.log(q + 1e-10))

p_true = np.array([1.0, 0.0, 0.0])  # 真实：类别0 → # 実際：クラス0

for q, desc in [([0.9,0.05,0.05],"好预测" → "良い予測"),
                ([0.4,0.3,0.3],"模糊" → "曖昧"),
                ([0.1,0.8,0.1],"错误" → "誤り")]:
    print(f"{desc}: 交叉熵={cross_entropy(p_true, q):.4f}" → "{desc}: 交差エントロピー={cross_entropy(p_true, q):.4f}")

# 对比 CE 和 MSE 的梯度 → # CE と MSE の勾配を比較
print("\n预测很差(y_pred=0.01, 真=1): CE梯度=-100, MSE梯度=-1.98" → "予測が大きく外れた場合(y_pred=0.01, 真=1): CE勾配=-100, MSE勾配=-1.98")
print("CE在预测错误时给出大梯度 → 学得快" → "CEは予測が誤っているときに大きな勾配を与える → 学習が速い")

実行結果：

好预测: 交叉熵=0.1054
模糊: 交叉熵=0.9163
错误: 交叉熵=2.3026

预测很差(y_pred=0.01, 真=1): CE梯度=-100, MSE梯度=-1.98
CE在预测错误时给出大梯度 → 学得快

AI 中的应用场景 → AIでの応用シーン

分类任务标配：交叉熵损失 → 分類タスクの標準：交差エントロピー損失

PyTorch 的 nn.CrossEntropyLoss 和 TensorFlow 的 categorical_crossentropy 是分类任务的默认损失函数。它内部集成了 Softmax + 负对数似然——一个损失函数同时完成激活和损失计算，且梯度形式极简：\( \nabla = \hat{y} - y \)。 → PyTorch の nn.CrossEntropyLoss と TensorFlow の categorical_crossentropy は分類タスクのデフォルト損失関数です。内部で Softmax + 負の対数尤度を統合しており——1つの損失関数が活性化と損失計算を同時に実行し、勾配の形も極めて簡潔です：\( \nabla = \hat{y} - y \)。

为什么分类不用 MSE？梯度特性决定效率 → なぜ分類にMSEを使わないのか？勾配の特性が効率を決める

当模型预测错误时（如真实类别概率应接近 1 但预测为 0.01），交叉熵梯度约为 -100——给出极强的纠正信号。而 MSE 在同样情况下梯度只有 -1.98——几乎学不动。这解释了为什么分类任务中 MSE 收敛极慢甚至不收敛。 → モデルが誤った予測をしたとき（例：実際のクラスの確率は 1 に近いべきなのに予測が 0.01 の場合）、交差エントロピーの勾配は約 -100 で——非常に強い修正信号を与えます。一方 MSE は同じ状況で勾配が -1.98 しかなく——ほとんど学習が進みません。これが、分類タスクで MSE の収束が極めて遅いか、収束すらしない理由を説明しています。

知识蒸馏中的 KL 散度 → 知識蒸留におけるKLダイバージェンス

知识蒸馏：用大模型（教师）的 Softmax 输出作为软标签训练小模型（学生）。学生不仅要匹配真实标签，还要通过 KL 散度最小化自己与教师的输出分布差距。软标签包含了类别之间的相似性信息（如「猫」和「虎」输出概率都比「汽车」高），这是 one-hot 标签没有的暗知识。 → 知識蒸留：大規模モデル（教師）の Softmax 出力をソフトラベルとして使い、小規模モデル（生徒）を訓練します。生徒は実際のラベルに一致するだけでなく、KLダイバージェンスを通じて教師との出力分布の乖離も最小化する必要があります。ソフトラベルにはクラス間の類似性情報（例：「猫」と「虎」の出力確率がどちらも「自動車」より高い）が含まれており、これは one-hot ラベルにはない暗黙の知識です。

VAE 的 KL 散度正则项 → VAEのKLダイバージェンス正則化項

VAE 的损失函数 = 重构误差 + KL(N(μ,σ²) || N(0,I))。KL 项约束编码器输出的潜在分布在每个样本上不偏离标准正态太远——这起到正则化作用，确保潜在空间连续且平滑，不同类别的样本能在潜在空间中平滑过渡。 → VAE の損失関数 = 再構成誤差 + KL(N(μ,σ²) || N(0,I))。KL 項はエンコーダーが出力する潜在分布が各サンプルで標準正規分布から離れすぎないように制約します——これは正則化の役割を果たし、潜在空間が連続で滑らかであることを保証し、異なるクラスのサンプルが潜在空間内で滑らかに移行できるようにします。

RLHF 中的 KL 约束 → RLHFにおけるKL制約

ChatGPT 等模型使用 RLHF（人类反馈强化学习）微调时，在优化目标中加入 KL 散度约束：不要让当前策略偏离初始的 SFT 模型太远。这防止模型为了迎合奖励模型而输出奇怪的文本，保持生成质量。 → ChatGPT などのモデルが RLHF（人間のフィードバックからの強化学習）でファインチューニングする際、最適化目標に KLダイバージェンス制約を追加します：現在のポリシーが初期の SFT モデルから離れすぎないようにする、というものです。これにより、モデルが報酬モデルに迎合して奇妙なテキストを出力するのを防ぎ、生成品質を維持します。
