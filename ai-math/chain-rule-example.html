手动实现链式法则 → 手動による連鎖律の実装

构造复合函数，手动逐层计算局部梯度并相乘，再用 sympy 验证。 → 複合関数を構築し、手動で層ごとに局所勾配を計算して乗算し、sympyで検証します。

学完本案例你将理解： → このケースを学び終えると、以下のことが理解できます：反向传播的核心就是链式法则——每一层只算自己的局部梯度，最终梯度是各层梯度的乘积。 → 逆伝播の核心は連鎖律です——各層は自分自身の局所勾配だけを計算し、最終的な勾配は各層の勾配の積になります。

生活引入 → 生活からの導入

多米诺骨牌的生产线 → ドミノの生産ライン

一个工厂有三道工序：原料 → 半成品 A → 半成品 B → 成品。你想知道「原料多用 1 公斤，最终成品多几个？」 → ある工場には3つの工程があります：原材料 → 半製品A → 半製品B → 完成品。「原材料を1kg多く使うと、最終的な完成品はいくつ増えるか」を知りたいとします。

你不需要从头推导整个流程的公式。每道工序只算自己的「局部比例」：半成品 A 增产 1 个 → 半成品 B 多几个？半成品 B 多 1 个 → 成品多几个？三个比例相乘就是答案。 → プロセス全体の公式を最初から導出する必要はありません。各工程は自分自身の「局所的な比率」だけを計算します：半製品Aが1個増える → 半製品Bはいくつ増える？半製品Bが1個増える → 完成品はいくつ増える？3つの比率を掛け合わせると答えになります。

这就是 → これが链式法则 → 連鎖律——每层只关心自己，最终影响 = 各层影响的乘积。 → ——各層は自分自身だけに注目し、最終的な影響 = 各層の影響の積です。

実例

import sympy as sp
import numpy as np

def g(x):    return x ** 2 + 1
def f(u):    return 3 * np.sin(u)
def g_prime(x): return 2 * x
def f_prime(u): return 3 * np.cos(u)

x0 = 1.5

# ---- 手动链式法则 ---- → # ---- 手動による連鎖律 ----
u0 = g(x0)
dy_du = f_prime(u0)    # 第2层局部梯度 → # 第2層の局所勾配
du_dx = g_prime(x0)    # 第1层局部梯度 → # 第1層の局所勾配
manual_grad = dy_du * du_dx

print("=" * 55)
print("RUNOOB 手动链式法则" → "RUNOOB 手動による連鎖律")
print(f"x0 = {x0}, u = g(x0) = {u0:.4f}")
print(f"dy/du = 3*cos(u) = {dy_du:.4f}")
print(f"du/dx = 2*x0     = {du_dx:.4f}")
print(f"链式相乘: dy/dx = {manual_grad:.4f}" → "連鎖乗算: dy/dx = {manual_grad:.4f}")

# ---- sympy 自动求导（标准答案） ---- → # ---- sympyによる自動微分（標準解答） ----
x = sp.Symbol('x')
y_expr = 3 * sp.sin(x**2 + 1)
auto_grad = float(sp.diff(y_expr, x).subs(x, x0))
print(f"\nRUNOOB sympy 自动求导 = {auto_grad:.4f}" → RUNOOB sympy 自動微分 = {auto_grad:.4f}")
print(f"两种方法一致: {np.isclose(manual_grad, auto_grad)}" → "2つの方法は一致: {np.isclose(manual_grad, auto_grad)}")

# ---- 拓展：三层复合 ---- → # ---- 発展：3層複合 ----
def h(v):     return v ** 2
def h_prime(v): return 2 * v
v0 = f(u0)
dy_dv = h_prime(v0)
grad_3layer = dy_dv * dy_du * du_dx

print(f"\nRUNOOB 三层梯度传递：" → RUNOOB 3層勾配の伝達：")
print(f" 第3层: {dy_dv:.4f} x 第2层: {dy_du:.4f} x 第1层: {du_dx:.4f} = {grad_3layer:.4f}" → " 第3層: {dy_dv:.4f} x 第2層: {dy_du:.4f} x 第1層: {du_dx:.4f} = {grad_3layer:.4f}")
