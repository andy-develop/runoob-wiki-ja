Python 入門ガイド¶

Release:3.6.3
Date:Nov 26, 2017

Python は簡単に習得でき、しかも強力なプログラミング言語です。効率的な高水準データ構造を備え、シンプルかつ効率的な方法でオブジェクト指向プログラミングを行うことができます。Python のエレガントな構文と動的型付けは、そのインタープリタ型である性質と組み合わさり、ほとんどのプラットフォームの多くの分野でスクリプト作成やアプリケーション開発に理想的な言語となっています。

Python 公式サイトから自由にダウンロードできます: http://www.python.orgPython インタプリタとその標準拡張ライブラリは、ソースコード形式またはバイナリ形式で入手でき、自由に再配布できます。また、このサイトでは、多数のサードパーティ製の Python モジュール、プログラム、ツール、および追加ドキュメントも提供されています。

C または C++（C から呼び出せる他の言語）を使って、Python インタプリタに新しい関数やデータ型を簡単に追加できます。また、Python はカスタムアプリケーションの拡張言語としても使用できます。

このマニュアルは、Python 言語とその体系に関連する基本的な知識と概念について、非公式に読者に紹介します。学習や実践で Python インタプリタを併用すると役立ちます。ただし、すべての例は完全なものなので、このマニュアルはオフラインでも読むことができます。

関連する標準ライブラリまたはオブジェクトの詳細については、参照してください。 Python リファレンスドキュメント 。Python リファレンスマニュアル 言語に関するより詳しい正式な説明が提供されています。C または C++ で拡張機能を作成する場合は、参照してください。 Python インタプリタの拡張と統合の章 和 C API リファレンスマニュアル 。もちろん、Python の知識を深く紹介する図書を読むこともできます。

このマニュアルは、Python の全知識とすべての機能を網羅しようとするものではなく、よく使われる機能のすべてさえも網羅しようとはしません。逆に、Python の多くの最も注目すべき機能を紹介し、言語の特色やスタイルについての認識を与えてくれます。読み終えた後には、Python のモジュールやプログラムを読み書きできるようになり、今後の使用に備えることができます。 Python リファレンスマニュアル 多くの Python モジュールライブラリの学習を続ける準備をします。
