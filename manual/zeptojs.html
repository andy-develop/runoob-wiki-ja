CSSセレクターを実行し、DOMノードをラップし、またはHTML文字列から複数の要素を作成することで、Zeptoコレクションオブジェクトを作成します。

Zeptoコレクションは配列のようなオブジェクトであり、それが指すDOMノードを操作するためのチェーン可能なメソッドを持っています。$（Zepto)オブジェクト上の直接メソッド以外に（例えば$.extend）を除き、documentオブジェクト内のすべてのメソッドはコレクションメソッドです。

セレクターにcontentパラメータ（CSSセレクター、DOM、またはZeptoコレクションオブジェクト）が存在する場合、指定されたノードのコンテキスト内でのみCSSセレクターを実行します。この機能は$(context).find(selector)是一样的。

HTML文字列フラグメントが与えられてDOMノードを作成する場合。属性マップのセットを指定してノードを作成することもできます。最も速く要素を作成するには、使用<div> 或 <div/>形式。

関数が〜に付加されたDOMContentLoadedイベントの処理フローにおいて。ページがすでに読み込み完了している場合、このメソッドは直ちに実行されます。

$('#foo') //=> ID 为 "foo" 的元素

// 创建元素:
$("<p>Hello</p>") //=> 新的p元素
// 创建带有属性的元素:
$("<p />", { text:"Hello", id:"greeting", css:{color:'darkblue'} })
//=> <p id=greeting style="color:darkblue">Hello</p>

// 当页面ready的时候，执行回调:
Zepto(function($){
  alert('Ready to Zepto!')
})

Ajaxコールバック関数

以下のコールバック関数を指定できます。これらは指定された順序で実行されます：

  1. beforeSend(xhr, settings)：リクエスト送信前に呼び出されます。xhrオブジェクトとsettingsをパラメータオブジェクトとして受け取ります。もしfalseを返した場合。false、リクエストはキャンセルされます。

  2. success(data, status, xhr)：リクエスト成功後に呼び出されます。返されたデータと、成功コードを含む文字列が渡されます。
