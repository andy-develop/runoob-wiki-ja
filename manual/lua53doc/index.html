关于 Lua

Lua は、強力で高速、軽量な組み込みスクリプト言語です。ブラジルのリオデジャネイロにあるポンティフィカル・カトリック大学のPUC-Rio 团队開発。Lua は自由软件、世界中の無数の製品やプロジェクトで広く使用されています。

Lua の官方网站上でLuaに関する完全な情報が提供されており、以下を含みます。综合概要と最新の文档、注意が必要です。参考手册可能なとここのバージョン 有所不同。

安装 Lua

Lua 以 源代码の形式でリリースされており、使用する前にビルドする必要があります。Luaのビルドは非常に簡単です。Luaは純粋なANSI Cで実装されているため、ANSI Cコンパイラを備えたすべてのプラットフォームで直接コンパイルできます。また、LuaはC++形式でも直接コンパイルできます。以下はUnix系プラットフォームでのビルド手順です。さらに其它系统构建介绍と配置选项 以作参考。

もしLuaを自分でコンパイルする時間や興味がない場合は、LuaBinariesコンパイル済みのバイナリファイルを入手できます。LuaDistここからLuaのマルチプラットフォーム版（バッテリー同梱）を入手できます。

Lua の構築

ほとんどのUnix系プラットフォームでは、"make" に適切なプラットフォーム名を加えるだけです。手順は以下のとおりです：

  1. コンソールウィンドウを開き、lua-5.3.0ディレクトリ。ディレクトリ内のMakefileファイルにはビルドとインストールの手順が含まれています。

  2. 运行 "makeを実行し、あなたのプラットフォームがリストに含まれているか確認してください。現在サポートされているプラットフォームは次のとおりです：

    aix bsd c89 freebsd generic linux macosx mingw posix solaris

    お使いのプラットフォームが含まれている場合は、「make xxx" を実行するだけでOKです。xxxはあなたのプラットフォーム名を表します。

    ご利用のプラットフォームが含まれていない場合は、まず最も近いプラットフォームを試し、次に posix generic c89 の順で試してください。

  3. コンパイル処理は非常に短く、最終的にsrcディレクトリに3つのファイルが生成されます：lua（インタプリタ）、luac（コンパイラ）、liblua.a（静的ライブラリ）。

  4. ビルドが完了したら、「make test" を使用して成功を確認します。インタプリタが実行され、バージョン番号が出力されます。

Linuxシステムを使用していてコンパイルエラーが発生した場合は、インストールされているかどうか確認してください。readline （也可能叫 libreadline-dev 或者 readline-devel）開発パッケージ。その後、リンクエラーがまだある場合は、次を試してください。 "make linux MYLIBS=-ltermcap" 。

Lua のインストール

ビルドが完了したら、Luaをシステムのデフォルトの場所にインストールしたいと思うかもしれません。その場合は、make install" を実行します。システムのデフォルト位置とインストール方法は、次の場所に定義されています。Makefile中。この処理には関連する権限が必要な場合があります。

运行 "make xxx install" でビルドとインストールを一度に行うことができます。xxxはあなたのプラットフォーム名を指します。

Lua をローカルにインストールしたい場合は、次のコマンドを実行してください: "make local」を実行すると、〜が作成されますinstall 目录，内有 bin, include, lib, man, share"、サブディレクトリに次のファイルをインストールします。 ローカルの別のディレクトリにインストールしたい場合は、 次のコマンドを実行してください: "make install INSTALL_TOP=xxx"、xxx は選択したディレクトリを指します。インストール処理中に切り替わるためsrc 以及 docディレクトリで行われるため、INSTALL_TOP絶対パスでない場合は十分に注意してください。

bin:
lua luac
include:
lauxlib.h lua.h lua.hpp luaconf.h lualib.h
lib:
liblua.a
man/man1:
lua.1 luac.1

これらは開発時に必要なディレクトリです。単に Lua プログラムを実行したいだけなら、必要なのはbinとman下のファイル。includeとlib下のファイルは、LuaをCまたはC++プログラムに埋め込むために使用されます。

定制

カスタマイズには3つの種類があり、ファイルを編集することで実現できます：

  • Luaをどのようにインストールするか、どこにインストールするか — 編集Makefile。
  • Luaのビルド方法 — 編集src/Makefile。
  • Luaの機能 — 編集src/luaconf.h。

実際、Makefile を編集する必要はありません。make 時にコマンドラインで関連する変数を指定すればよいのです。もちろん、Makefile を編集して保存しておけば、カスタマイズの記録として残せます。

一方、Luaのいくつかの機能をカスタマイズする必要がある場合は、Luaをビルド・インストールする前に編集します。src/luaconf.h。編集したファイルは一貫性を保証しなければなりません。つまり、1つの場所にだけインストールし、コンパイルしたLuaを使用するすべてのプログラムがその唯一のコピーを使用するようにします。専門家はLuaのソースコードを編集することで、さらに多くのことをカスタマイズできます。

他のシステム上で Lua をビルドする

通常の Unix ツールを使用しない場合、Lua のビルド手順は使用するコンパイラに依存します。ライブラリ、インタプリタ、コンパイラなどをビルドするためのプロジェクトを複数作成する必要があります。関連するプロジェクトに次のソースファイルを追加してください：

库:
lapi.c lcode.c lctype.c ldebug.c ldo.c ldump.c lfunc.c lgc.c llex.c lmem.c lobject.c lopcodes.c lparser.c lstate.c lstring.c ltable.c ltm.c lundump.c lvm.c lzio.c lauxlib.c lbaselib.c lbitlib.c lcorolib.c ldblib.c liolib.c lmathlib.c loslib.c lstrlib.c ltablib.c lutf8lib.c loadlib.c linit.c
解释器:
library, lua.c
编译器:
library, luac.c

Luaをライブラリとしてプログラムで使用するには、コンパイラでライブラリを作成し使用する方法を知っている必要があります。たとえば、動的にロードされるCライブラリとしてLuaを使用する場合、動的ライブラリを作成し、Lua API関数を動的ライブラリ内で可視にする方法を理解する必要があります —不要Luaライブラリを各動的ライブラリにリンクします。Unixでは、Luaライブラリをホストプログラムに静的にリンクし、動的リンク用にシンボルをエクスポートすることをお勧めします。src/MakefileこのようにしてLuaインタプリタを処理します。Windowsでは、LuaライブラリをDLLとしてコンパイルすることをお勧めします。いずれにしても、コンパイラのluacは静的リンクされるべきです。

上記のように、Luaをビルドする前に編集できます。src/luaconf.hいくつかの機能をカスタマイズするためです。

Lua 5.2 以降の変更

ここでは、Lua 5.3で導入された主な変更を列挙します。参考手册中にリストされている互換性のない箇所。

主な変更点

  • 整数（デフォルト64ビット）
  • 32 ビット整数の公式サポート
  • 位操作符
  • 基本的なutf-8サポート
  • 値のパックおよびアンパック関数
これらは、Lua 5.3で導入されたその他の変更です：

言語

  • ユーザーデータは任意のLua値にすることができます。
  • 整数除法
  • 一部のメタメソッドにはより柔軟な規則が導入されました

库

  • ipairsおよびテーブル操作ライブラリはメタメソッドを考慮します
  • string.dump削減オプションが増えました
  • テーブル操作ライブラリはメタメソッドを考慮しました
  • 新函数 table.move
  • 新函数 string.pack
  • 新函数 string.unpack
  • 新函数 string.packsize

C API

  • 継続ポイント API が簡素化されました
  • lua_gettableおよび類似の関数が結果として返す値の型
  • lua_dump削減オプションを追加しました
  • 新函数： lua_geti
  • 新函数： lua_seti
  • 新函数： lua_isyieldable
  • 新函数： lua_numbertointeger
  • 新函数： lua_rotate
  • 新函数： lua_stringtonumber

Lua スタンドアロンインタプリタ

  • 計算機として使用できます。前置の '=' は不要になりました。
  • argテーブルはすべてのコードで利用可能です
