Markdown リスト

Markdown サポート番号付きリスト和番号なしリスト。

番号なしリスト

番号なしリストはアスタリスク（*）、プラス記号（+）またはマイナス記号（-）をリストマーカーとして使用します。これらのマーカーの後ろにはスペースを追加してから内容を記入します。

* 項目1
* 項目2
* 項目3

+ 項目1
+ 項目2
+ 項目3


- 項目1
- 項目2
- 項目3

表示結果は次のとおりです。

選択の推奨事項：

  • 統一してマイナス記号を使用することをお勧めします-、視覚的により明確だからです。
  • 同じ文書内で一貫したマーカー方式を維持する
  • マーカー記号の後にはスペースが必要です

番号付きリスト

番号付きリストは、順序が要求される手順や項目を示すために使用します。

番号付きリストは数字に.ピリオドを付けて表します。例：

1. 第一项
2. 第二项
3. 第三项

表示結果は次のとおりです。

数字は連続していなくてもよい

Markdown は数字の順序を自動的に修正します：

1. 第一项
3. 第二项（实际显示为2）
7. 第三项（实际显示为3）

指定した数字から始める：

5. 第五项
6. 第六项
7. 第七项

リストのネスト

リスト入れ子のテクニック

リストは入れ子にして使用でき、多層構造を作成できます：

番号なしリストのネスト：

- 果物
  - りんご
    - 赤りんご
    - 青りんご
  - バナナ
  - オレンジ
- 野菜
  - にんじん
  - 白菜

番号付きリストのネスト：

1. 准备阶段
   1. 收集资料
   2. 制定计划
2. 执行阶段
   1. 开始实施
   2. 监控进度
3. 总结阶段

混合ネスト：

1. 主要任务
   - 子任务A
   - 子任务B
     1. 详细步骤1
     2. 详细步骤2
   - 子任务C
2. 次要任务

リストの混合ネストは、子リスト内のオプションの前に2つまたは4つのスペースを追加するだけで済みます：

1. 第一项：
    - 第一项嵌套的第一个元素
    - 第一项嵌套的第二个元素
2. 第二项：
    - 第二项嵌套的第一个元素
    - 第二项嵌套的第二个元素

表示結果は次のとおりです。

ネストのルール：

  • 子リストは2〜4スペースのインデントが必要です（推奨は2つ）
  • 一貫したインデント幅を維持する
  • 無限にネストできますが、実際には3層を超えないことをお勧めします

タスクリスト（チェックボックスリスト）

タスクリストは GitHub スタイル Markdown の拡張機能であり、現在広くサポートされています：

基本構文：

- [ ] 未完成的任务
- [x] 已完成的任务
- [ ] 另一个未完成的任务

レンダリング結果：

実際の応用例：

## 项目待办清单

### 设计阶段
- [x] 需求分析
- [x] 原型设计
- [ ] UI 设计

### 开发阶段
- [ ] 前端开发
  - [x] 页面布局
  - [ ] 交互功能
  - [ ] 响应式适配
- [ ] 后端开发
  - [ ] 数据库设计
  - [ ] API 开发
  - [ ] 性能优化

### 测试阶段
- [ ] 单元测试
- [ ] 集成测试
- [ ] 用户验收测试

使用テクニック：

  • 角括弧内のスペースと x は重要です：[ ] 和 [x]
  • ネストリストと組み合わせて使用できます
  • プロジェクト管理、学習計画、生活リストで特に役立ちます
  • 一部のエディターはチェックボックスをクリックして状態を切り替えることをサポートしています

高度なリストテクニック：

リスト項目に複数段落の内容を含める：

1. 第一项

   这是第一项的详细说明，需要与列表项对齐缩进。
   
   还可以包含第二段内容。

2. 第二项

   > 可以在列表项中使用引用

リスト項目内の改行：

- これは非常に長いリスト項目で、
  改行して表示する必要があります。2行目は1行目と揃える必要があることに注意してください。
- もう一つのリスト項目

これらの基本構文をマスターすることで、構造が明確で形式が整った Markdown ドキュメントを作成できるようになります。これらの構文は日常の文章作成で最もよく使われるものであり、それらをしっかり習得すれば、ドキュメント作成の効率が大幅に向上するでしょう。
