ビジネス委譲パターン

ビジネス委譲パターン（Business Delegate Pattern）は、プレゼンテーション層とビジネス層を分離（デカップリング）するために使用されます。基本的には、プレゼンテーション層のコードにおけるビジネス層コードへの通信やリモートクエリ機能を減らすために使用されます。ビジネス層には以下のエンティティがあります。

  • クライアント（Client）- プレゼンテーション層のコードは、JSP、サーブレット、または UI Java コードです。
  • ビジネス委譲（Business Delegate）- クライアントエンティティに提供されるエントリクラスであり、ビジネスサービスのメソッドへのアクセスを提供します。
  • ルックアップサービス（LookUp Service）- ルックアップサービスオブジェクトは、関連するビジネス実装を取得し、ビジネスオブジェクトからビジネス委譲オブジェクトへのアクセスを提供します。
  • ビジネスサービス（Business Service）- ビジネスサービスインターフェース。このビジネスサービスを実装するエンティティクラスは、実際のビジネス実装ロジックを提供します。

概要

意図

アプリケーションのアクセスロジックを抽象化およびカプセル化し、プレゼンテーション層にビジネスロジック層へのアクセスを提供します。

主な解決課題

  • プレゼンテーション層とビジネスロジック層の間の結合問題を解決し、プレゼンテーション層がビジネス委譲を通じてビジネスロジック層に間接的にアクセスできるようにします。

使用シーン

  • マルチレイヤーアプリケーションでプレゼンテーション層とビジネスロジック層を明確に分離する必要がある場合。

実装方法

  • ビジネス委譲インターフェース：ビジネスロジックにアクセスするメソッドを定義します。
  • ビジネス委譲実装：ビジネス委譲インターフェースを実装し、ビジネスロジック層を呼び出すロジックをカプセル化します。
  • ビジネスサービス：ビジネスロジック層のインターフェースまたはクラスで、ビジネス操作を含みます。

重要なコード

  • ビジネス委譲インターフェース：ビジネスロジックにアクセスするメソッドを宣言します。
  • ビジネス委譲実装：インターフェースを実装し、ビジネスサービスを呼び出すコードを含みます。
  • ビジネスサービス：ビジネスロジックの具体的な実装。

応用事例

  • Web アプリケーション：Web層をプレゼンテーション層として、ビジネス委譲を通じてバックエンドのサービス層にアクセスします。

メリット

  • プレゼンテーション層とビジネスロジック層の分離：ビジネス委譲が中間層として機能し、結合度を低減します。
  • アクセスロジックの集中：プレゼンテーション層のコードを簡素化し、アクセスロジックをビジネス委譲に集中させます。
  • 保守と拡張が容易：新しいビジネスロジックへのアクセスを追加する場合、ビジネス委譲のみを修正すればよい。

デメリット

  • 複雑性が増す可能性がある：単純なアプリケーションの場合、不必要な抽象レイヤーが増える可能性があります。

使用に関するアドバイス

  • マルチレイヤーアプリケーションを開発する際、プレゼンテーション層とビジネスロジック層の間に明確な分離を提供する必要がある場合は、ビジネス委譲パターンの使用を検討してください。

注意事項

  • ビジネス委譲はできるだけ簡潔にし、複雑なロジックを含めないようにしてください。

含まれる主要な役割

  • ビジネス委譲インターフェース（Business Delegate Interface）：

    • ビジネスロジックにアクセスするメソッドを宣言します。

  • ビジネス委譲実装（Business Delegate Implementation）：

    • ビジネス委譲インターフェースを実装し、ビジネスサービスへの呼び出しをカプセル化します。

  • ビジネスサービス（Business Service）：

    • ビジネスロジック層のインターフェースまたはクラスで、実際のビジネス操作を含みます。

  • プレゼンテーション層（Presentation Layer）：

    • アプリケーションのフロントエンドであり、ビジネス委譲を通じてビジネスロジックにアクセスします。

  • ビジネスロジック層（Business Logic Layer）：

    • アプリケーションのコアビジネスロジックを含みます。

ビジネス委譲パターンは、ビジネスロジックにアクセスするための抽象レイヤーを提供することで、アプリケーションの柔軟性と保守性を維持するのに役立ちます。

実装

以下を作成しますClient、BusinessDelegate、BusinessService、LookUpService、JMSServiceとEJBServiceビジネス委譲パターンにおけるさまざまなエンティティを表します。

BusinessDelegatePatternDemoクラスを使用してBusinessDelegateとClientビジネス委譲パターンの使用方法をデモンストレーションします。

ステップ 1

BusinessService インターフェースを作成します。

BusinessService.java

public interface BusinessService { public void doProcessing(); }

ステップ 2

具体的なサービスを作成します。

EJBService.java

public class EJBService implements BusinessService { @Override public void doProcessing() { System.out.println("Processing task by invoking EJB Service"); } }

JMSService.java

public class JMSService implements BusinessService { @Override public void doProcessing() { System.out.println("Processing task by invoking JMS Service"); } }

ステップ 3

ビジネスルックアップサービスを作成します。

BusinessLookUp.java

public class BusinessLookUp { public BusinessService getBusinessService(String serviceType){ if(serviceType.equalsIgnoreCase("EJB")){ return new EJBService(); }else { return new JMSService(); } } }

ステップ 4

ビジネス委譲を作成します。

BusinessDelegate.java

public class BusinessDelegate { private BusinessLookUp lookupService = new BusinessLookUp(); private BusinessService businessService; private String serviceType; public void setServiceType(String serviceType){ this.serviceType = serviceType; } public void doTask(){ businessService = lookupService.getBusinessService(serviceType); businessService.doProcessing(); } }

ステップ 5

クライアントを作成します。

Client.java

public class Client { BusinessDelegate businessService; public Client(BusinessDelegate businessService){ this.businessService = businessService; } public void doTask(){ businessService.doTask(); } }

ステップ 6

BusinessDelegate クラスと Client クラスを使用して、ビジネス委譲パターンをデモンストレーションします。

BusinessDelegatePatternDemo.java

public class BusinessDelegatePatternDemo { public static void main(String[] args) { BusinessDelegate businessDelegate = new BusinessDelegate(); businessDelegate.setServiceType("EJB"); Client client = new Client(businessDelegate); client.doTask(); businessDelegate.setServiceType("JMS"); client.doTask(); } }

ステップ 7

プログラムを実行して、結果を出力します：

Processing task by invoking EJB Service
Processing task by invoking JMS Service
