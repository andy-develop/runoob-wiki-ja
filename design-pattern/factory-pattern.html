ファクトリーパターン

ファクトリーパターン（Factory Pattern）は Java で最もよく使われるデザインパターンの一つであり、オブジェクトを作成する方法を提供し、オブジェクトの作成プロセスと使用プロセスを分離します。

ファクトリーパターンは、作成する具体的なクラスを指定せずにオブジェクトを作成する方法を提供します。

ファクトリーパターンを使用することで、オブジェクトの作成ロジックをファクトリークラスにカプセル化し、クライアントコードで直接オブジェクトをインスタンス化するのではなく、コードの保守性と拡張性を向上させることができます。

ファクトリーパターンの種類

1、シンプルファクトリーパターン（Simple Factory Pattern）：

  • シンプルファクトリーパターンは正式なデザインパターンではありませんが、ファクトリーパターンの基礎です。単一のファクトリークラスを使用して異なるオブジェクトを作成し、渡されたパラメータに基づいて作成するオブジェクトのタイプを決定します。

2、ファクトリーメソッドパターン（Factory Method Pattern）：

  • ファクトリーメソッドパターンは、オブジェクトを作成するためのインターフェースを定義しますが、どのクラスをインスタンス化するかはサブクラスが決定します。ファクトリーメソッドはオブジェクトの作成をサブクラスに遅延させます。

3、抽象ファクトリーパターン（Abstract Factory Pattern）：

  • 抽象ファクトリーパターンは、関連する一連のオブジェクトまたは相互に依存するオブジェクトを作成するためのインターフェースを提供し、それらの具体的なクラスを指定する必要はありません。

概要

意図

オブジェクトを作成するためのインターフェースを定義し、そのサブクラスにどの具体的なクラスをインスタンス化するかを決定させます。ファクトリーパターンは、オブジェクトの作成プロセスをサブクラスに遅延させます。

主な解決課題

インターフェース選択の問題。

使用时机

異なる条件で異なるインスタンスを作成する必要がある場合。

解決方法

サブクラスにファクトリーインターフェースを実装させ、抽象的な製品を返すようにします。

キーコード

オブジェクトの作成プロセスはサブクラスで実装されます。

応用实例

  1. 自動車製造：車が必要な場合、工場から受け取るだけでよく、車の製造プロセスや内部実装を気にする必要はありません。
  2. Hibernate：データベースを変更する場合、方言（Dialect）とデータベースドライバ（Driver）を変更するだけで、異なるデータベースへの切り替えを実現できます。

利点

  1. 呼び出し元はオブジェクトの名前を知っているだけでオブジェクトを作成できます。
  2. 拡張性が高く、新しい製品を追加する必要がある場合、ファクトリークラスを拡張するだけで済みます。
  3. 製品の具体的な実装を隠蔽し、呼び出し元は製品のインターフェースのみを気にします。

欠点

製品を追加するたびに、具体的なクラスと対応するファクトリーを追加する必要があり、システム内のクラスの数が倍増し、システムの複雑さと具体的なクラスへの依存が増加します。

使用シーン

  1. ログ記録：ログはローカルハードディスク、システムイベント、リモートサーバーなどに記録される可能性があり、ユーザーはログを記録する場所を選択できます。
  2. データベースアクセス：ユーザーが最終的にシステムがどのデータベースを使用するかわからない場合、またはデータベースが変更される可能性がある場合。
  3. サーバーに接続するフレームワークの設計："POP3"、"IMAP"、"HTTP" の3つのプロトコルをサポートする必要があり、これら3つのプロトコルを製品クラスとして、共通のインターフェースを実装できます。

注意事項

ファクトリーパターンは、複雑なオブジェクトを生成するシーンに適しています。オブジェクトが比較的単純で、new で作成を完了できる場合は、ファクトリーパターンを使用する必要はありません。ファクトリーパターンを使用するとファクトリークラスが導入され、システムの複雑さが増加します。

構造

ファクトリーパターンには、以下の主要な役割が含まれます：

  • 抽象製品（Abstract Product）：製品の共通インターフェースまたは抽象クラスを定義します。具体的な製品クラスの親クラスまたはインターフェースであり、製品オブジェクトの共通メソッドを規定します。
  • 具体的な製品（Concrete Product）：抽象製品インターフェースを実装し、具体的な製品の特定の動作と属性を定義します。
  • 抽象ファクトリー（Abstract Factory）：製品を作成するための抽象メソッドを宣言し、インターフェースまたは抽象クラスにすることができます。異なるタイプの製品を作成するための複数のメソッドを持つことができます。
  • 具体的なファクトリー（Concrete Factory）：抽象ファクトリーインターフェースを実装し、実際に具体的な製品のオブジェクトを作成する責任を負います。

実装

私たちはShapeインターフェースとShapeインターフェースを実装するエンティティクラスを作成します。次のステップはファクトリークラスを定義することです。ShapeFactory。

FactoryPatternDemoクラスはShapeFactoryを使用してShapeオブジェクトを取得します。それはShapeFactoryに情報（CIRCLE / RECTANGLE / SQUARE）を渡し、必要なオブジェクトのタイプを取得します。

ステップ 1

インターフェースを作成します:

Shape.java

public interface Shape { void draw(); }

ステップ 2

インターフェースを実装するエンティティクラスを作成します。

Rectangle.java

public class Rectangle implements Shape { @Override public void draw() { System.out.println("Inside Rectangle::draw() method."); } }

Square.java

public class Square implements Shape { @Override public void draw() { System.out.println("Inside Square::draw() method."); } }

Circle.java

public class Circle implements Shape { @Override public void draw() { System.out.println("Inside Circle::draw() method."); } }

ステップ 3

与えられた情報に基づいてエンティティクラスのオブジェクトを生成するファクトリーを作成します。

ShapeFactory.java

public class ShapeFactory { //getShape メソッドを使用してシェイプタイプのオブジェクトを取得します public Shape getShape(String shapeType){ if(shapeType == null){ return null; } if(shapeType.equalsIgnoreCase("CIRCLE")){ return new Circle(); } else if(shapeType.equalsIgnoreCase("RECTANGLE")){ return new Rectangle(); } else if(shapeType.equalsIgnoreCase("SQUARE")){ return new Square(); } return null; } }

ステップ 4

そのファクトリーを使用して、タイプ情報を渡すことでエンティティクラスのオブジェクトを取得します。

FactoryPatternDemo.java

public class FactoryPatternDemo { public static void main(String[] args) { ShapeFactory shapeFactory = new ShapeFactory(); //Circle のオブジェクトを取得し、その draw メソッドを呼び出します Shape shape1 = shapeFactory.getShape("CIRCLE"); //Circle の draw メソッドを呼び出します shape1.draw(); //Rectangle のオブジェクトを取得し、その draw メソッドを呼び出します Shape shape2 = shapeFactory.getShape("RECTANGLE"); //Rectangle の draw メソッドを呼び出します shape2.draw(); //Square のオブジェクトを取得し、その draw メソッドを呼び出します Shape shape3 = shapeFactory.getShape("SQUARE"); //Square の draw メソッドを呼び出します shape3.draw(); } }

ステップ 5

プログラムを実行し、出力結果：

Inside Circle::draw() method.
Inside Rectangle::draw() method.
Inside Square::draw() method.
