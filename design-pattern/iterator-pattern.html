迭代器模式 → イテレータパターン

迭代器模式（Iterator Pattern）是 Java 和 .Net 编程环境中非常常用的设计模式。 → イテレータパターン（Iterator Pattern）は、Java および .Net プログラミング環境で非常に一般的に使用されるデザインパターンです。

迭代器模式提供一种方法顺序访问一个聚合对象中的各个元素，而又不暴露其内部的表示。 → イテレータパターンは、集約オブジェクト内の各要素に順番にアクセスする方法を提供し、その内部表現を公開しません。

迭代器模式属于行为型模式。 → イテレータパターンは、振る舞いパターンに属します。

紹介

意図

允许顺序访问一个聚合对象中的元素，同时不暴露对象的内部表示。 → オブジェクトの内部表現を公開せずに、集約オブジェクト内の要素に順番にアクセスすることを許可します。

主要解决的问题 → 主に解決する問題

  • 提供一种统一的方法来遍历不同的聚合对象。 → 異なる集約オブジェクトを走査するための統一された方法を提供します。

使用场景 → 使用シーン

  • 当需要遍历一个聚合对象，而又不希望暴露其内部结构时。 → 集約オブジェクトを走査する必要があるが、その内部構造を公開したくない場合。

実装方法

  • 定义迭代器接口 → イテレータインターフェースを定義する：包含 → ：含むhasNext()和next()等方法，用于遍历元素。 → などのメソッド。要素を走査するために使用します。
  • 创建具体迭代器 → 具体的なイテレータを作成する：实现迭代器接口，定义如何遍历特定的聚合对象。 → ：イテレータインターフェースを実装し、特定の集約オブジェクトをどのように走査するかを定義します。
  • 聚合类 → 集約クラス：定义一个接口用于返回一个迭代器对象。 → ：イテレータオブジェクトを返すためのインターフェースを定義します。

关键代码 → キーコード

  • 迭代器接口 → イテレータインターフェース：规定了遍历元素的方法。 → ：要素を走査するメソッドを規定します。
  • 具体迭代器 → 具体的なイテレータ：实现了迭代器接口，包含遍历逻辑。 → ：イテレータインターフェースを実装し、走査ロジックを含みます。

応用例

  • Java中的Iterator → JavaのIterator：Java集合框架中的迭代器用于遍历集合元素。 → ：Javaコレクションフレームワークのイテレータは、コレクションの要素を走査するために使用されます。

長所

  1. 支持多种遍历方式 → 複数の走査方法をサポート：不同的迭代器可以定义不同的遍历方式。 → ：異なるイテレータは異なる走査方法を定義できます。
  2. 简化聚合类 → 集約クラスの簡素化：聚合类不需要关心遍历逻辑。 → ：集約クラスは走査ロジックを考慮する必要がありません。
  3. 多遍历支持 → 複数走査のサポート：可以同时对同一个聚合对象进行多次遍历。 → ：同じ集約オブジェクトを同時に複数回走査できます。
  4. 拡張性：增加新的聚合类和迭代器类都很方便，无需修改现有代码。 → ：新しい集約クラスとイテレータクラスの追加が容易で、既存のコードを変更する必要がありません。

短所

  • 系统复杂性 → システムの複雑性：每增加一个聚合类，就需要增加一个对应的迭代器类，增加了类的数量。 → ：集約クラスを追加するたびに対応するイテレータクラスを追加する必要があり、クラスの数が増加します。

使用建议 → 使用上のアドバイス

  • 当需要访问聚合对象内容而不暴露其内部表示时，使用迭代器模式。 → 集約オブジェクトの内容にアクセスする必要があり、その内部表現を公開したくない場合は、イテレータパターンを使用します。
  • 当需要为聚合对象提供多种遍历方式时，考虑使用迭代器模式。 → 集約オブジェクトに複数の走査方法を提供する必要がある場合は、イテレータパターンの使用を検討します。

注意事項

  • 迭代器模式通过分离集合对象的遍历行为，使得外部代码可以透明地访问集合内部数据，同时不暴露集合的内部结构。 → イテレータパターンは、コレクションオブジェクトの走査動作を分離することで、外部コードがコレクションの内部構造を公開せずに、コレクション内部のデータに透過的にアクセスできるようにします。

構造

迭代器模式包含以下几个主要角色： → イテレータパターンには、以下の主要な役割が含まれます：

  • 迭代器接口（Iterator） → イテレータインターフェース（Iterator）：定义了访问和遍历聚合对象中各个元素的方法，通常包括获取下一个元素、判断是否还有元素、获取当前位置等方法。 → ：集約オブジェクト内の各要素にアクセスおよび走査するメソッドを定義します。通常、次の要素を取得する、要素がまだあるかどうかを判断する、現在位置を取得するなどのメソッドが含まれます。

  • 具体迭代器（Concrete Iterator） → 具体的なイテレータ（Concrete Iterator）：实现了迭代器接口，负责对聚合对象进行遍历和访问，同时记录遍历的当前位置。 → ：イテレータインターフェースを実装し、集約オブジェクトの走査とアクセスを担当し、走査の現在位置を記録します。

  • 聚合对象接口（Aggregate） → 集約オブジェクトインターフェース（Aggregate）：定义了创建迭代器对象的接口，通常包括一个工厂方法用于创建迭代器对象。 → ：イテレータオブジェクトを作成するためのインターフェースを定義します。通常、イテレータオブジェクトを作成するためのファクトリメソッドが含まれます。

  • 具体聚合对象（Concrete Aggregate） → 具体的な集約オブジェクト（Concrete Aggregate）：实现了聚合对象接口，负责创建具体的迭代器对象，并提供需要遍历的数据。 → ：集約オブジェクトインターフェースを実装し、具体的なイテレータオブジェクトを作成し、走査に必要なデータを提供します。

from abc import abstractmethod,ABCMeta

# 创建Iterator接口
class Iterator(metaclass=ABCMeta):
    @abstractmethod
    def hasNext(self):
        pass
    @abstractmethod
    def next(self):
        pass
# 创建Container接口
class Container(metaclass=ABCMeta):
    @abstractmethod
    def getIterator(self):
        pass

# 创建实现了Iterator接口的类NameIterator
class NameIterator(Iterator):
    index = 0
    aNameRepository = None
    def __init__(self, inNameRepository):
        self.aNameRepository = inNameRepository

    def hasNext(self):
        if self.index < len(self.aNameRepository.names):
            return True
        return False
    def next(self):
        if self.hasNext() :
            theName = self.aNameRepository.names[self.index]
            self.index += 1
            return theName
        return None

#创建实现了Container接口的实体类。
class NameRepository(Container):
    names = ["Robert","John","Julie","Lora"]

    def getIterator(self):
        return NameIterator(self)

namespace DesignPattern.IteratorPatttern
{
    /// <summary>
    /// 迭代器
    /// </summary>
    public interface Iterator<T>
    {
        bool HasNext();
        T Next();
    }

    /// <summary>
    /// 容器集装箱
    /// </summary>
    public interface IContainer<T>
    {
        Iterator<T> GetIterator();
    }

    /// <summary>
    /// 对象库
    /// </summary>
    public class ObjectRepository<T> : IContainer<T>
    {
        ObjectIterator<T> m_ObjectIterator;

        public ObjectRepository()
        {
            m_ObjectIterator = new ObjectIterator<T>();
        }
        public Iterator<T> GetIterator()
        {
            return m_ObjectIterator;
        }

        public void AddObject(T obj)
        {
            m_ObjectIterator.m_ObjectRepository.Add(obj);
        }

        /// <summary>
        /// 对象迭代器
        /// </summary>
        class ObjectIterator<Tobjcet> : Iterator<Tobjcet>
        {
            public ObjectIterator()
            {
                m_ObjectRepository = new List<Tobjcet>();
            }

            int index;
            public List<Tobjcet> m_ObjectRepository;

            public bool HasNext()
            {
                if (index < m_ObjectRepository.Count)
                {
                    return true;
                }
                return false;
            }

            Tobjcet Iterator<Tobjcet>.Next()
            {
                if (HasNext())
                {
                    return m_ObjectRepository[index++];
                }
                return default;
            }
        }
    }
}
