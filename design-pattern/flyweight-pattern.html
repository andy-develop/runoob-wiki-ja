フライウェイトパターン

フライウェイトパターン（Flyweight Pattern）は、主に生成するオブジェクトの数を減らして、メモリ使用量を減らしパフォーマンスを向上させるために使用されます。このタイプのデザインパターンは構造型パターンに属し、オブジェクトの数を減らしてアプリケーションに必要なオブジェクト構造を改善する方法を提供します。

フライウェイトパターンは、既存の同種オブジェクトを再利用しようとし、一致するオブジェクトが見つからない場合は新しいオブジェクトを作成します。このパターンを説明するために、5つのオブジェクトを作成して、異なる位置に配置された20個の円を描画します。利用可能な色は5色のみなので、color属性は既存のCircleオブジェクトを確認するために使用されます。

概要

意図

オブジェクトの共有により、大量の類似オブジェクトを作成する際のメモリ消費を削減します。

主な解決課題

  • 大量のオブジェクトの作成によるメモリ不足の問題を回避します。
  • オブジェクトを共有することで、メモリ使用効率を向上させます。

使用シーン

  • システム内に大量の類似または同一のオブジェクトが存在する場合。
  • オブジェクトの生成と破棄のコストが高い場合。
  • オブジェクトの状態を外部化できる場合、つまりオブジェクトの一部の状態がオブジェクト自体から独立して存在できる場合。

実装方法

  • フライウェイトインターフェースを定義する：フライウェイトインターフェースを作成し、共有可能な状態を規定します。
  • 具体的なフライウェイトクラスを作成する：そのインターフェースを実装する具体的なクラスで、内部状態を含みます。
  • フライウェイトファクトリを使用する：フライウェイトオブジェクトの生成と再利用を管理するファクトリクラスを作成します。

キーコード

  • HashMap：ハッシュテーブルを使用して作成済みのフライウェイトオブジェクトを保存し、高速に検索できるようにします。

応用例

  1. JavaのStringオブジェクト：文字列定数プールに既に存在する文字列は再利用されます。
  2. データベース接続プール：データベース接続が再利用され、接続の頻繁な生成と破棄を回避します。

利点

  • メモリ消費の削減：オブジェクトを共有することで、メモリ内のオブジェクト数を減らします。
  • 効率の向上：オブジェクト生成の時間を短縮し、システム効率を向上させます。

欠点

  • システムの複雑さが増す：内部状態と外部状態を分離する必要があり、設計と実装の複雑さが増します。
  • スレッドセーフティの問題：外部状態の処理が適切でない場合、スレッドセーフティの問題を引き起こす可能性があります。

使用上のアドバイス

  • 大量の類似オブジェクトを作成する場合は、フライウェイトパターンの使用を検討してください。
  • フライウェイトオブジェクトの内部状態は共有され、外部状態はオブジェクトから独立していることを確認してください。

注意事項

  • 状態の分離：内部状態と外部状態を明確に区別し、混同を避けます。
  • フライウェイトファクトリ：フライウェイトファクトリを使用してオブジェクトの生成と再利用を制御し、オブジェクトの一貫性と完全性を確保します。

構造

フライウェイトパターンには、以下の主要な役割が含まれます：

  • フライウェイトファクトリ（Flyweight Factory）:

    • フライウェイトオブジェクトの生成と管理を担当し、通常は作成済みのフライウェイトオブジェクトを保存・再利用するためのプール（キャッシュ）を含みます。

  • 具体的なフライウェイト（Concrete Flyweight）:

    • 抽象フライウェイトインターフェースを実装し、内部状態と外部状態を含みます。内部状態は共有可能であり、外部状態はクライアントによって渡されます。

  • 抽象フライウェイト（Flyweight）:

    • 具体的なフライウェイトと非共有フライウェイトのインターフェースを定義し、通常は外部状態を設定するメソッドを含みます。

  • クライアント（Client）:

    • フライウェイトファクトリを使用してフライウェイトオブジェクトを取得し、外部状態を設定してフライウェイトオブジェクトを操作します。クライアントは通常、フライウェイトオブジェクトの具体的な実装を気にする必要はありません。

実装

作成するのはShapeインターフェースと、それを実装したShapeインターフェースの具象クラスCircle。次のステップは、ファクトリクラスを定義することですShapeFactory。

ShapeFactoryを持っていますCircle 的 HashMap、そのキー名はCircleオブジェクトの色です。ShapeFactoryその...を確認しますHashMap内のcircleオブジェクトを見つけた場合Circleそのオブジェクトを返し、それ以外の場合は、後で使用するためにhashmapに保存される新しいオブジェクトを作成して、クライアントに返します。

FlyWeightPatternDemoクラスは使用しますShapeFactoryを取得するためにShapeオブジェクト。それは...にShapeFactory情報を渡します（red / green / blue/ black / white）、必要なオブジェクトの色を取得するためです。

ステップ 1

インターフェースを作成します。

Shape.java

public interface Shape { void draw(); }

ステップ 2

インターフェースを実装する具象クラスを作成します。

Circle.java

public class Circle implements Shape { private String color; private int x; private int y; private int radius; public Circle(String color){ this.color = color; } public void setX(int x) { this.x = x; } public void setY(int y) { this.y = y; } public void setRadius(int radius) { this.radius = radius; } @Override public void draw() { System.out.println("Circle: Draw() [Color : " + color +", x : " + x +", y :" + y +", radius :" + radius); } }

ステップ 3

指定された情報に基づいて具象クラスのオブジェクトを生成するファクトリを作成します。

ShapeFactory.java

import java.util.HashMap; public class ShapeFactory { private static final HashMap<String, Shape> circleMap = new HashMap<>(); public static Shape getCircle(String color) { Circle circle = (Circle)circleMap.get(color); if(circle == null) { circle = new Circle(color); circleMap.put(color, circle); System.out.println("Creating circle of color : " + color); } return circle; } }

ステップ 4

そのファクトリを使用して、色情報を渡すことで具象クラスのオブジェクトを取得します。

FlyweightPatternDemo.java

public class FlyweightPatternDemo { private static final String colors[] = { "Red", "Green", "Blue", "White", "Black" }; public static void main(String[] args) { for(int i=0; i < 20; ++i) { Circle circle = (Circle)ShapeFactory.getCircle(getRandomColor()); circle.setX(getRandomX()); circle.setY(getRandomY()); circle.setRadius(100); circle.draw(); } } private static String getRandomColor() { return colors[(int)(Math.random()*colors.length)]; } private static int getRandomX() { return (int)(Math.random()*100 ); } private static int getRandomY() { return (int)(Math.random()*100); } }

    フライウェイトパターンは、言い換えればオブジェクトの共有です。一部のオブジェクトを繰り返し作成する必要があり、最終的に単一の結果だけを得る必要がある場合に使用します。このパターンは、以前に作成された既存のオブジェクトを利用し、何らかのルールに基づいて、現在必要なオブジェクトが元のオブジェクトを変更して目的の効果を得られるかどうかを判断します。上記のチュートリアルの例のように、異なる効果を持つ20個の円を作成しますが、同じ色の円は一度だけ作成すればよく、同じ色の場合は元のオブジェクトを参照して座標値を変更するだけで済みます。このパターンでは、同じ色の円は位置が異なっていても、そのアドレスはすべて同じです。したがって、このパターンは単一の結果を重視する場合に適しています。

    簡単な例を挙げると、ゲームにはさまざまな英雄キャラクターがいます。同じタイプのキャラクターにも異なる属性の英雄がいます。例えば、アサシンタイプの英雄はたくさんいます。このパターンで設計する場合、英雄が属するタイプを利用して元の同じタイプの英雄インスタンスを参照し、その対応する属性を変更することで、最終的に欲しい最新の英雄を得ることができます。例えば、最初のアサシン英雄を作成し、次に2番目のアサシン英雄を設計する必要があるとします。最初の英雄の属性を変更して2番目のアサシン英雄を得ると、最新のアサシン英雄は誕生しましたが、最初のアサシン英雄の属性も2番目と同じに変わってしまいます。このような場合は明らかに問題です。

from abc import abstractmethod,ABCMeta
import random

#创建一个Shape接口
class Shape(metaclass=ABCMeta):
    @abstractmethod
    def draw(self):
        pass
# 创建实现接口的实体类Circle
class Circle(Shape):
    _color=""
    _x =0
    _y =0
    _radius = 0

    def __init__(self, inColor):
        self._color = inColor
    def setX(self, inX):
        self._x = inX
    def setY(self,inY):
        self._y = inY
    def setRadius(self,inRadius):
        self._radius = inRadius
    def draw(self):
        print("Circle: Draw() [Color : {0}, x : {1}, y : {2}, radius : {3}]".format(self._color,self._x,self._y,self._radius))

# 创建一个工厂，生成基于给定信息的实体类的对象
class ShapeFactory():
    circleMap = {}
    @staticmethod
    def getCircle(inColor):
        circle = None
        if inColor in ShapeFactory.circleMap :
            circle = ShapeFactory.circleMap[inColor]
        else:
            circle = Circle(inColor)
            aCircle = {inColor:circle}
            ShapeFactory.circleMap.update(aCircle)
            print("Creating circle of color : " + inColor)
        return circle
# 调用输出

    C++ 実装：

    // 享元模式
#include <iostream>
#include <map>
#include <ctime>

using namespace std;

class Shape {
public:
    virtual void draw() = 0;
};
class Circle : public Shape {
private:
    string color;
    int x;
    int y;
    int radius;
public:
    Circle(string color): color(color), x(0), y(0), radius(0) {}

    void setX(int newx) {
        x = newx;
    }

    void setY(int newy) {
        y = newy;
    }

    void setRadius(int newradius) {
        radius = newradius;
    }

    void draw() {
        cout << "Circle: Draw() [Color : " << color
             << ", x : " << x << ", y :" << y << ", radius :" << radius
             << endl;
    }
};
class ShapeFactory {
public:
    static map<string, Shape*> circleMap;

    static Shape* getCircle(string color) {
        if (circleMap.count(color) > 0) {
            return circleMap[color];
        }
        auto shape = new Circle(color);
        circleMap[color] = shape;
        cout << "Creating circle of color : " << color << endl;
        return shape;
    }

    static void cleanup() {
        for (auto e : circleMap) {
            delete e.second;
        }
    }
};

// 生成随机数
double random() {
    return (rand() % 10) * 0.1;
}

string colors[] = {"Red", "Green", "Blue", "White", "Black"};
string getRandomColor() {
    return colors[(int)(random() * sizeof(colors) / sizeof(colors[0]))];
}
int getRandomX() {
    return (int)(random() * 100);
}
int getRandomY() {
    return (int)(random() * 100);
}

// 定义circleMap
map<string, Shape*> ShapeFactory::circleMap;

int main() {
    srand(time(0));
    for (int i = 0; i < 20; ++i) {
        Circle circle = *(Circle*)ShapeFactory::getCircle(getRandomColor());
        circle.setX(getRandomX());
        circle.setY(getRandomY());
        circle.setRadius(100);
        circle.draw();
    }
    ShapeFactory::cleanup();
    return 0;
}
