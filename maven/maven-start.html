Maven 最初のプロジェクト

Maven プロジェクトの作成

Maven Archetype を使用してプロジェクトを生成

Maven はプロジェクトテンプレート（Archetype）を提供しており、標準的なプロジェクト構造をすばやく生成できます。最もよく使われるのは maven-archetype-quickstart（基本的な Java プロジェクトテンプレート）です。

コマンドを実行：

mvn archetype:generate \
    -DgroupId=com.example \
    -DartifactId=my-first-app \
    -DarchetypeArtifactId=maven-archetype-quickstart \
    -DinteractiveMode=false

パラメータの説明：

パラメータ 説明
-DgroupId 組織名（例：会社のドメイン名を逆順にしたもの）
-DartifactId プロジェクト名（プロジェクトフォルダ名になります）
-DarchetypeArtifactId 使用するテンプレート（quickstartは基本的な Java プロジェクトです）
-DinteractiveMode=false 非対話モード（手動での確認を避ける）

実行後に生成されるプロジェクト構造：

my-first-app/
├── pom.xml           # Maven 项目配置文件
├── src/
│   ├── main/         # 主代码目录
│   │   └── java/     # Java 源代码
│   │       └── com/example/App.java  # 自动生成的示例类
│   └── test/        # 测试代码目录
│       └── java/     # 测试类
│           └── com/example/AppTest.java  # 自动生成的测试类

プロジェクト構造の解説

pom.xml の詳細解説

これは Maven の中核となる設定ファイルで、プロジェクトの基本情報と依存関係を定義します。

生成された pom.xml の例：

<project>
    <!-- POM 模型版本，固定 4.0.0 -->
    <modelVersion>4.0.0</modelVersion>

    <!-- 项目坐标（唯一标识） -->
    <groupId>com.example</groupId>
    <artifactId>my-first-app</artifactId>
    <version>1.0-SNAPSHOT</version>

    <!-- 项目打包方式（默认 jar，也可以是 war、pom 等） -->
    <packaging>jar</packaging>

    <!-- 项目名称和 URL（可选） -->
    <name>my-first-app</name>
    <url>http://www.example.com</url>

    <!-- 依赖管理 -->
    <dependencies>
        <!-- JUnit 测试依赖 -->
        <dependency>
            <groupId>junit</groupId>
            <artifactId>junit</artifactId>
            <version>4.12</version>
            <scope>test</scope>  <!-- 仅用于测试 -->
        </dependency>
    </dependencies>
</project>

ディレクトリ 役割

src/main/resources 設定ファイル（例：application.properties）
src/test/java テストコード
src/test/resources テストリソースファイル

サンプルコード：

メインクラス App.java

例

package com.example;

public class App {
    public static void main(String[] args) {
        System.out.println("Hello Maven!");
    }
}

テストクラス AppTest.java：

例

package com.example;

import org.junit.Test;
import static org.junit.Assert.*;

public class AppTest {
    @Test

        assertTrue(true);  // サンプルテスト
    }
}

ビルドと実行

よく使う Maven コマンド

コマンド役割
mvn compileソースコードのコンパイル
mvn testテストの実行
mvn packageパッケージ化（.jarファイルを生成）
mvn installローカルリポジトリにインストール（他のプロジェクトから依存できるようにする）
mvn cleanクリーンtargetディレクトリ

完全なビルドフロー

1. プロジェクトのコンパイル：

mvn compile

コンパイルされた .class ファイルは target/classes ディレクトリに置かれます。

2. テストの実行：

mvn test

src/test/java 配下のテストクラスを実行します。

テストレポートは target/surefire-reports に生成されます。

3. パッケージ化：

mvn package

target/my-first-app-1.0-SNAPSHOT.jar を生成します。

4. プログラムの実行：

java -cp target/my-first-app-1.0-SNAPSHOT.jar com.example.App

5. 出力：

Hello Maven!

拡張：プロジェクトの変更

依存関係の追加

例えば、GsonJSON 処理に使用します：

pom.xml を変更：

<dependencies>
    <!-- 原有 JUnit 依赖 -->
    <dependency>
        <groupId>junit</groupId>
        <artifactId>junit</artifactId>
        <version>4.12</version>
        <scope>test</scope>
    </dependency>

    <!-- 新增 Gson 依赖 -->
    <dependency>
        <groupId>com.google.code.gson</groupId>
        <artifactId>gson</artifactId>
        <version>2.8.9</version>
    </dependency>
</dependencies>

mvn compile を実行すると、Maven が自動的に Gson をダウンロードします。

メインクラスを Gson を使用するように変更

例

package com.example;

import com.google.gson.Gson;

public class App {
    public static void main(String[] args) {
        Gson gson = new Gson();
        String json = gson.toJson("Hello Maven with Gson!");
        System.out.println(json);
    }
}

再パッケージ化して実行：

mvn package
java -cp target/my-first-app-1.0-SNAPSHOT.jar com.example.App

出力：

"Hello Maven with Gson!"

よくある問題

依存関係のダウンロード失敗

原因：ネットワークの問題、またはリポジトリが利用できません。

解決策：

ネットワーク接続を確認します。

中国国内のミラーリポジトリ（例：Alibaba Cloud）を設定します：

<!-- 在 settings.xml 或 pom.xml 中配置 -->
<mirror>
    <id>aliyun</id>
    <url>https://maven.aliyun.com/repository/public</url>
    <mirrorOf>central</mirrorOf>
</mirror>

Alibaba Cloud リポジトリの紹介：https://developer.aliyun.com/mvn/guide。

コンパイルバージョンの問題

エラー：javac: invalid target release: 11

解決策：pom.xml で Java バージョンを指定します：

<properties>
    <maven.compiler.source>11</maven.compiler.source>
    <maven.compiler.target>11</maven.compiler.target>
</properties>

まとめ

  1. プロジェクトの作成：mvn archetype:generate標準構造を生成します。

  2. プロジェクト構造：

    • pom.xml依存関係と設定を定義します。

    • src/main/javaメインコードを置き、src/test/javaテストコードを置きます。

  3. ビルドコマンド：

    • mvn compile → mvn test → mvn package。

  4. 実行：java -jar 或 java -cp実行.jarファイル。
