C++ 参照

ポインタを使用して参照呼び出しを実装する方法についてはすでに説明しました。次のサンプルでは、参照を使用して参照呼び出しを実装します。

サンプル

#include <iostream> using namespace std; // 関数宣言 void swap(int& x, int& y); int main () { // ローカル変数宣言 int a = 100; int b = 200; cout << "交換前の a の値：" << a << endl; cout << "交換前の b の値：" << b << endl; /*関数を呼び出して値を交換します*/ swap(a, b); cout << "交換後の a の値：" << a << endl; cout << "交換後の b の値：" << b << endl; return 0; } // 関数定義 void swap(int& x, int& y) { int temp; temp = x; /*アドレス x の値を保存*/ x = y; /*y を x に代入*/ y = temp; /*x を y に代入*/ return; }

上記のコードをコンパイルして実行すると、次の結果が生成されます。

交换前，a 的值： 100
交换前，b 的值： 200
交换后，a 的值： 200
交换后，b 的值： 100

    参照を関数パラメータとして使用

    C++ が参照型を追加したのは、主に関数パラメータとして使用し、関数へデータを渡す機能を拡張するためです。

    C++ 関数の引数渡し：

    (1) 変数名を実引数と仮引数として使用します。このとき仮引数に渡されるのは変数の値であり、受け渡しは一方向です。関数の実行中に仮引数の値が変わっても、実引数には戻りません。関数呼び出し時に仮引数と実引数は同じ記憶領域ではないためです。// C と同じ

    (2) 変数のポインタを渡します。仮引数はポインタ変数、実引数は変数のアドレスです。関数呼び出し時に、仮引数（ポインタ変数）は実引数の変数領域を指します。この仮引数ポインタを通じて実引数の値を変更できます。// C と同じ

    (3) C++ は変数の参照を渡す機能を提供します。仮引数は参照変数であり、実引数と同じ変数です。関数呼び出し時に、仮引数（参照変数）は実引数の変数領域を指します。この仮引数参照を通じて実引数の値を変更できます。

    参照をパラメータとする関数には、変数を渡すことができますが、定数を渡すことはできません。

    #include <iostream>
using namespace std;

int hls(int& a1, int& a2, int& b1, int& b2) //定义行列式函数
{
   int temp;
   temp=a1*b2-a2*b1;
   return temp;
}

int main()
{
   int x1=11; int x2=9;
   int y1=15; int y2=14;  //定义矩阵
   int result;  //行列式运算结果
   result=hls(x1,x2,y1,y2);   //result=hls(11,9,15,14)会报错
   cout << result << endl;
   return 0;
}

    例えば、次のような構造体があるとします。

    struct Demo 
{
  char name[10000];
  int  count;
};

int main()
{
  Demo my_demo = {0};
  Demo *my_demo_p = &my_demo;
  Demo &my_demo_ref = my_demo;
  
  // 方式1：传递实参  
  func1(my_demo);

  // 方式2：传递指针  
  func2(my_demo_p);

  // 方式3：传递引用  
  func3(my_demo_ref);

  return 0;
}
如上所示，参数传递可以有三种方式，则三种函数可以这样定义：

// 方式1：传递实参 
void func1(Demo demo)
{
  cout << demo.name;
}

// 方式2：传递指针  
void func2(const Demo *demo_p)
{
  cout << demo->name;
}

// 方式3：传递引用  
void func3(const Demo &demo_ref)
{
  cout << demo.name;
}

    参照と実引数は使用方法がよく似ていますが、次の点に注意してください。

    • メモリ使用の観点から言うと、実引数を渡すとデータがコピーされる（コピーが作成される）ため、func1 が渡されたデータにどのような変更を加えても my_demo には影響しません。
    • 実引数を渡すとコピーが作成されるということは、効率が低くなることを意味します。例の構造体の name メンバーが長さ 10000 なのは、この効率の問題を強調するためです。

    参照とポインタもよく似ています。どちらもコピーを作成しないため、効率はともに高いです。主な違いは次のとおりです。

    • メンバーを選択するとき、参照はドット.で検索し、ポインタは->で検索します。
    • ポインタは NULL が渡される可能性があるため、使用前に有効性をチェックする必要があります。参照は必ず何らかのオブジェクトを表すため、そのようなチェックは不要です。

    PS:コードに const キーワードを追加する目的は、func2 と func3 が元のデータを変更しないようにするためです。関数は単に name を出力するだけだからです。

    1、単なる値渡し

    #include <iostream>
using namespace std;
 
// 函数声明
void swap(int x, int y);
 
int main ()
{
   // 局部变量声明
   int a = 100;
   int b = 200;
 
   cout << "交换前，a 的值：" << a << endl;
   cout << "交换前，b 的值：" << b << endl;
 
   /* 调用函数来交换值 */
   swap(a, b);
 
   cout << "交换后，a 的值：" << a << endl;
   cout << "交换后，b 的值：" << b << endl;
 
   return 0;
}
 
// 函数定义
void swap(int x, int y)
{
   int temp;
   cout << "调用的函数中的交换:"<<endl;
   cout  << x <<endl;
   cout << y <<endl;
   temp = x; /* 保存地址 x 的值 */
   x = y;    /* 把 y 赋值给 x */
   y = temp; /* 把 x 赋值给 y  */
   cout  << x <<endl;
   cout << y <<endl;
   return;
}
    単純な値渡しでは、呼び出された関数内でのみ値が変更され、元の値は変わりません。

    3、ポインタ渡し

    #include <iostream>
using namespace std;
 
// 函数声明
void swap(int *x, int *y);
 
int main ()
{
   // 局部变量声明
   int a = 100;
   int b = 200;
   int *c,*d;
   c=&a;
   d=&b;
   cout << "交换前，a 的值：" << *c << endl;
   cout << "交换前，b 的值：" << *d << endl;
 
   /* 调用函数来交换值 */
   swap(c, d);
   //swap(&a,&b);
   cout << "交换后，a 的值：" << *c << endl;
   cout << "交换后，b 的值：" << *d << endl;
 
   return 0;
}
 
// 函数定义
void swap(int *x, int *y)
{
   int temp;
   cout << "调用的函数中的交换:"<<endl;
   cout  << *x <<endl;
   cout << *y <<endl;
   temp = *x; /* 保存地址 x 的值 */
   *x = *y;    /* 把 y 赋值给 x */
   *y = temp; /* 把 x 赋值给 y  */
   cout  << *x <<endl;
   cout << *y <<endl;
   return;
}

    ポインタ渡しは、宣言したポインタに変数のアドレスを代入する必要があり、変数の数が増えるため、参照のほうがポインタより簡潔です。

    ポインタの指し先を交換する方法では、実際の交換はできません。関数が終了して戻ると、これら2つのポインタ自体が消滅するためです（それらの値は main() 関数に戻りません）。したがって、最終結果は交換されません。ポインタの指し先を交換するのではなく、ポインタが指す先の値を変更することで交換を達成すべきです。
