C++ 参照

参照変数はエイリアスです。つまり、既に存在する変数の別名です。

参照をある変数に初期化すると、その参照名または変数名を使用して変数を指すことができます。

参照は定義時に初期化する必要があり、いったん変数にバインドされると、他の変数にバインドし直すことはできません。

参照の構文は次のとおりです：

int a = 10;
int &ref = a;  // ref 是 a 的引用

  • int &ref示しますrefは...ですint型の参照。

  • refであるaの別名であり、...に対するref操作は直接...に作用しますa。

C++ 参照 vs ポインタ

参照はポインタと混同されやすいですが、両者には3つの大きな違いがあります：

  • 空の参照は存在しません。参照は有効なメモリに接続されている必要があります。
  • 参照がいったんオブジェクトに初期化されると、別のオブジェクトを指すことはできません。ポインタはいつでも別のオブジェクトを指すことができます。
  • 参照は作成時に初期化する必要があります。ポインタはいつでも初期化できます。
  • 参照の対象は変数でなければならず、ポインタはアドレスでなければなりません。
特性参照ポインタ

構文使用&宣言します。例：int &ref = a;使用*宣言します。例：int *ptr = &a;
再バインド再バインドはできません。初期化後は常に同じオブジェクトを参照します。他のオブジェクトを指し直すことができます。例：ptr = &b;
ヌル値（Nullability）...になることはできませんnull有効なオブジェクトにバインドする必要があります。...にすることができますnullどのオブジェクトも指していないことを示します。
メモリ使用量追加のメモリを消費しません（コンパイラは通常、参照されるオブジェクトを直接操作するように最適化します）。追加のメモリを消費します（アドレスを格納します。通常はマシンワード長、例えば4バイトまたは8バイトです）。

内部実装通常はポインタを介して実装されますが、コンパイラは参照されるオブジェクトを直接操作するように最適化します。ターゲットオブジェクトのメモリアドレスを直接格納します。

C++ での参照の作成

変数名は変数がメモリ内の位置に付けたラベルだと考えてください。参照は、変数がメモリ内の位置に付ける2番目のラベルと見なすことができます。したがって、元の変数名または参照を使って変数の内容にアクセスできます。例：

int i = 17;

以下のように、i の参照変数を宣言できます。

int&  r = i;
double& s = d;

これらの宣言では、&は...と読みます参照。

したがって、最初の宣言は次のように読めます。「r は i に初期化された整数型の参照です」、2番目の宣言は次のように読めます。「s は d に初期化された double 型の参照です」。

以下の例では int と double の参照を使用しています。

例

#include <iostream> using namespace std; int main () { // 単純な変数を宣言 int i; double d; // 参照変数を宣言 int& r = i; double& s = d; i = 5; cout << "Value of i : " << i << endl; cout << "Value of i reference : " << r << endl; d = 11.7; cout << "Value of d : " << d << endl; cout << "Value of d reference : " << s << endl; return 0; }

上記のコードをコンパイルして実行すると、次の結果が生成されます。

Value of i : 5
Value of i reference : 5
Value of d : 11.7
Value of d reference : 11.7

参照は通常、関数のパラメータリストと関数の戻り値に使用されます。以下に、C++ プログラマーが必ず理解しておくべき、C++ 参照に関連する2つの重要な概念を示します。

概念説明
参照を引数として使用C++ は、参照を引数として関数に渡すことをサポートしています。これは通常の引数を渡すよりも安全です。
参照を戻り値として使用C++ 関数から、他のデータ型を返すのと同様に参照を返すことができます。

    1. 参照は宣言時に初期化する必要があり、先に宣言して後から代入することはできません。

    #include <iostream>

using namespace std;

int main()
{
  int rats = 10;
  
  //声明引用，旦未初始化
  int &rodents;

  rodents = rats;

  return 0;
}

    上記のコードをコンパイルすると、次のエラーが発生します。

    error: ‘rodents’ declared as reference but not initialized

    エラー：「rodents」は参照として宣言されていますが、初期化されていません。

    2. 参照は const ポインタに近く、作成時に初期化する必要があります。参照がいったん変数に関連付けられると、その参照はずっとその変数を指し続けます。

    int rats = 10;
int &rodents = rats;

    上記のコードは、実際には次のコードの偽装表現です。

    int rats = 10;
int * const pr = &rats;

    参照についての私の理解を皆さんと共有します。例えば、クラスメートに「舞法少女」というあだ名を付けられたとします。このあだ名は、あなたの名前の参照のようなものです。クラスメートから見ると、どちらで呼んでもあなたを呼んでいることになります。

    その他に、関数で参照を引数として使用する場合、次の例のように：a を実引数として関数 func に渡し、x は関数 func の仮引数であり参照です。関数 func 内で x に新しい値 3 が代入されると、a の値も 3 に変わります。

    #include <iostream>
using namespace std;

int func(int &x)//函数func将引用当作形参
{
    x=3;
    return 0;
} 

int main ()
{
    int a=1;//声明整型变量
    func(a);////给函数func传参
    cout<<"a的值为: "<<a<<endl;//输出a的值，结果为“a的值为3”
    return 0;
}

    C++11追加された新機能 --右辺値参照、記述例：

    int &&rvalueReference = 1 + 2;

    右辺値参照が導入された目的は、主に次のような問題を解決することです。関数の値渡しや戻り値の際に、あるオブジェクトが別のオブジェクトにコピーされ、その直後にそのオブジェクトが破棄されます。明らかに時間の無駄です。右辺値参照を使用すると、コピーコンストラクタやデストラクタを呼び出すことなく、オブジェクトの所有権を別のオブジェクトに「譲渡」できます。
