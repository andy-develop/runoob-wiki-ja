C++ 参照

参照変数はエイリアスです。つまり、既に存在する変数の別名です。

参照をある変数に初期化すると、その参照名または変数名を使用して変数を指すことができます。

参照は定義時に初期化する必要があり、いったん変数にバインドされると、他の変数にバインドし直すことはできません。

参照の構文は次のとおりです：

int a = 10;
int &ref = a;  // ref 是 a 的引用

  • int &ref示しますrefは...ですint型の参照。

  • refであるaの別名であり、...に対するref操作は直接...に作用しますa。

C++ 参照 vs ポインタ

参照はポインタと混同されやすいですが、両者には3つの大きな違いがあります：

  • 空の参照は存在しません。参照は有効なメモリに接続されている必要があります。
  • 参照がいったんオブジェクトに初期化されると、別のオブジェクトを指すことはできません。ポインタはいつでも別のオブジェクトを指すことができます。
  • 参照は作成時に初期化する必要があります。ポインタはいつでも初期化できます。
  • 参照の対象は変数でなければならず、ポインタはアドレスでなければなりません。

C++ での参照の作成

変数名は変数がメモリ内の位置に付けたラベルだと考えてください。参照は、変数がメモリ内の位置に付ける2番目のラベルと見なすことができます。したがって、元の変数名または参照を使って変数の内容にアクセスできます。例：

int i = 17;

以下のように、i の参照変数を宣言できます。

int&  r = i;
double& s = d;

これらの宣言では、&は...と読みます参照。

したがって、最初の宣言は次のように読めます。「r は i に初期化された整数型の参照です」、2番目の宣言は次のように読めます。「s は d に初期化された double 型の参照です」。

以下の例では int と double の参照を使用しています。

例

#include <iostream> using namespace std; int main () { // 単純な変数を宣言 int i; double d; // 参照変数を宣言 int& r = i; double& s = d; i = 5; cout << "Value of i : " << i << endl; cout << "Value of i reference : " << r << endl; d = 11.7; cout << "Value of d : " << d << endl; cout << "Value of d reference : " << s << endl; return 0; }

上記のコードをコンパイルして実行すると、次の結果が生成されます。

Value of i : 5
Value of i reference : 5
Value of d : 11.7
Value of d reference : 11.7

参照は通常、関数のパラメータリストと関数の戻り値に使用されます。以下に、C++ プログラマーが必ず理解しておくべき、C++ 参照に関連する2つの重要な概念を示します。

概念説明
参照を引数として使用C++ は、参照を引数として関数に渡すことをサポートしています。これは通常の引数を渡すよりも安全です。
参照を戻り値として使用C++ 関数から、他のデータ型を返すのと同様に参照を返すことができます。
