C++ 类 & 对象

クラスのメンバ関数とは、定義とプロトタイプをクラス定義内に記述する関数のことです。クラス定義内の他の変数と同じです。クラスメンバ関数はクラスのメンバであり、クラスの任意のオブジェクトを操作でき、オブジェクト内のすべてのメンバにアクセスできます。

前に定義したクラス Box を見てみましょう。今回は、クラスのメンバに直接アクセスするのではなく、メンバ関数を使用してクラスのメンバにアクセスします。

class Box { public: double length; // 长度 double breadth; // 宽度 double height; // 高度 double getVolume(void);// 返回体积 };

メンバ関数はクラス定義内で定義するか、単独で使用して范围解析运算符 ::定義します。クラス定義内で定義されたメンバ関数は、関数を内联として宣言します。たとえ inline 識別子を使用しなくてもです。したがって、次のように定義できます。getVolume()函数：

class Box { public: double length; // 长度 double breadth; // 宽度 double height; // 高度 double getVolume(void) { return length * breadth * height; } };

クラスの外部でも使用できます范围解析运算符 ::その関数を次のように定義します：

double Box::getVolume(void) { return length * breadth * height; }

ここで、一点強調しておきます。:: 演算子の前にはクラス名を使用する必要があります。メンバ関数の呼び出しは、オブジェクトに対してドット演算子（.）、これによりそのオブジェクトに関連するデータを操作できるようになります。次のようになります：

Box myBox; // 创建一个对象 myBox.getVolume(); // 调用该对象的成员函数

上記の概念を使用して、クラスのさまざまなメンバの値を設定および取得してみましょう。

实例

#include <iostream> using namespace std; class Box { public: double length; // 长度 double breadth; // 宽度 double height; // 高度 // 成员函数声明 double getVolume(void); void setLength( double len ); void setBreadth( double bre ); void setHeight( double hei ); }; // 成员函数定义 double Box::getVolume(void) { return length * breadth * height; } void Box::setLength( double len ) { length = len; } void Box::setBreadth( double bre ) { breadth = bre; } void Box::setHeight( double hei ) { height = hei; } // 程序的主函数 int main( ) { Box Box1; // 声明 Box1，类型为 Box Box Box2; // 声明 Box2，类型为 Box double volume = 0.0; // 用于存储体积 // box 1 详述 Box1.setLength(6.0); Box1.setBreadth(7.0); Box1.setHeight(5.0); // box 2 详述 Box2.setLength(12.0); Box2.setBreadth(13.0); Box2.setHeight(10.0); // box 1 的体积 volume = Box1.getVolume(); cout << "Box1 的体积：" << volume <<endl; // box 2 的体积 volume = Box2.getVolume(); cout << "Box2 的体积：" << volume <<endl; return 0; }

上記のコードをコンパイルして実行すると、次の結果が生成されます：

Box1 的体积： 210
Box2 的体积： 1560

    ::これはスコープ解決演算子と呼ばれ、ある関数がどのクラスに属するか、あるいはあるデータがどのクラスに属するかを示します。

    ::クラス名を付けずに使用すると、グローバルデータまたはグローバル関数（つまり非メンバ関数）を表します。

    int month;//全局变量
int day;
int year;
void Set(int m,int d,int y)
{
    ::year=y; //给全局变量赋值，此处可省略
    ::day=d;
    ::month=m;
}

Class Tdate
{
    public:
        void Set(int m,int d,int y) //成员函数
        {
            ::Set(m,d,y); //非成员函数
        }
    private:
        int month;
        int day;
        int year;
}

    クラス内のメンバ関数と inline

    クラス内で定義されたメンバ関数は、デフォルトですべてインラインです。クラス定義時にクラス内で関数定義を与えれば、それが最も良いでしょう。クラス内でメンバ関数の定義を与えずに、その関数をインラインにしたい場合は、クラス外でinline、そうでなければインラインではないと見なされます。例えば：

    class A
{
    public:void Foo(int x, int y) {  } // 自动地成为内联函数
}

    メンバ関数の定義本体をクラス宣言内に置くと記述上の便利さは得られますが、良いプログラミングスタイルとは言えません。上記の例は次のように変更すべきです：

    // 头文件
class A
{
    public:
    void Foo(int x, int y);
}
// 定义文件
inline void A::Foo(int x, int y){}

    inline は実装に使用するキーワードです

    キーワード inline は関数定義本体と一緒に置く必要があり、そうすることで初めて関数をインラインにできます。inline を関数宣言の前に置くだけでは何の効果もありません。

    以下のスタイルの関数Fooインライン関数になれない：

    inline void Foo(int x, int y); // inline 仅与函数声明放在一起
void Foo(int x, int y){}

    一方、次のようなスタイルの関数 Foo はインライン関数になります：

    void Foo(int x, int y);
inline void Foo(int x, int y) {}  // inline 与函数定义体放在一起

    inline のその他の使用方法については、次を参照してください：C++ 中的 inline 用法

    C++ における、非仮想メンバ関数の呼び出しと仮想関数の呼び出しの違い：

    1. 非仮想メンバ関数の呼び出し：非メンバ関数の呼び出しと同様に、オブジェクトによってオブジェクトが属するクラスを特定し、クラスのメンバ関数を見つけます。このプロセスはオブジェクトの内容には関与せず、オブジェクトの型のみに関与します。これは静的バインドです。

    2. 仮想関数の呼び出しは非仮想メンバー関数の呼び出しとは異なり、仮想関数テーブルを通じて仮想関数のアドレスを見つける必要があります。仮想関数テーブルは各オブジェクトに格納されているため、コンパイル時に実装することはできません。実行時にのみバインドされ、これは動的バインディングです。

    代码：

    #include<iostream>
using namespace std;

int year = 55;   //全局变量
int month = 56;
int day = 57;

void Set(int y, int m,int d)  //全局函数
{
    year=y;     //给全局变量赋值
    month=m;
    day=d;    
}

void PPP()  //全局函数
{
    cout << "*****global*****" << endl;
    cout << year << " " << month  << " " << day << endl;
}
class TimeDate
{
    public:
        void Set(int y,int m,int d)  //成员函数
        {
            year=y;     //给成员变量赋值
            ::month=m;  //给全局变量赋值
            day=d;
            //使用::表明是全局函数
            //不使用:: 按先成员函数后全局函数的顺序查找函数
            ::PPP();  //使用全局函数，而不是成员函数
            PPP();    //使用成员函数，而不是全局函数
        }
        void PPP()
        {
            cout << "*****local*****" << endl;
            cout << year << " " << month  << " " << day << endl;
        }
        void PPP1()
        {
            cout << "*****local->global*****" << endl;
            cout << ::year << " " << ::month  << " " << ::day << endl;
        }
    private:
        int year;  //成员变量
        int month;
        int day;
};

int main(int argc, const char** argv) {
    TimeDate t;
    cout << "origin value" << endl;
    t.PPP();
    t.PPP1();
    PPP();
    cout << "after global function Set work" << endl;
    Set(1,2,3);
    t.PPP();
    PPP();
    cout << "after member function Set work" << endl;
    t.Set(4,5,6);
    t.PPP();
    PPP();
    cout << "program end" << endl;
    return 0;
}

    分析と結論：

    1. グローバル変数とメンバ変数が同名の場合：グローバル関数はデフォルトでグローバル変数を使用します。オブジェクトのメンバにアクセスすることによってのみメンバ変数の値を取得できます。一方、メンバ関数はメンバ変数を優先的に使用しますが、メンバ変数名の前に :: を付けることで、これがグローバル変数であることを明示できます。この場合、メンバ関数はグローバル変数を使用します。また、メンバ関数はメンバ変数を優先し、次にグローバル変数という順序で変数を使用します。言い換えれば、メンバ関数はメンバ変数を優先的に使用し、メンバ変数の中に変数名が見つからない場合にのみグローバル変数を検索して使用します。グローバル変数にも変数名が存在しない場合はエラーになります。

    2. グローバル関数とメンバ関数が同名の場合：クラスの外では、通常はグローバル関数が呼び出されます。オブジェクトのメンバ関数にアクセスすることによってのみメンバ関数を使用できます。クラスの内側では、メンバ関数が呼び出されますが、メンバ関数名の前に :: を付けることで、呼び出す必要があるのがグローバル関数であることを明示できます。また、メンバ関数を優先し、次にグローバル関数という順序で関数を呼び出します。言い換えれば、メンバ関数を優先的に使用し、メンバ関数が存在しない場合にのみグローバル関数を検索して使用します。グローバル関数にもその関数が存在しない場合はエラーになります。
