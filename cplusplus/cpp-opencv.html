C++ OpenCV

OpenCV（Open Source Computer Vision Library）は、オープンソースのコンピュータビジョンおよび機械学習ソフトウェアライブラリです。一連のC関数と少数のC++クラスで構成されており、Python、Java、MATLABなどの言語のインターフェースも提供しています。

OpenCV の設計目標は、開発者が複雑なビジョンアプリケーションを迅速に構築できるよう、汎用的なコンピュータビジョンライブラリを提供することです。

OpenCV は当初 Intel によって開発され、その後 Willow Garage と Itseez によってサポートされ、現在は OpenCV.org によってメンテナンスされています。

OpenCV は、画像処理、ビデオ解析、物体検出、顔認識、機械学習などの分野で広く利用されています。

OpenCV のコア機能

OpenCV のコア機能は次のとおりです。

  • 画像処理：画像フィルタリング、幾何変換、色空間変換、エッジ検出など。

  • ビデオ処理：ビデオキャプチャ、背景差分、オプティカルフロー計算など。

  • 特徴検出と記述：SIFT、SURF、ORB などのアルゴリズム。

  • 物体検出と追跡：Haarカスケード検出、HOG検出、深層学習モデルなど。

  • カメラキャリブレーションと3D再構成：カメラキャリブレーション、ステレオビジョン、点群処理など。

  • 機械学習：KNN、SVM、決定木などの従来の機械学習アルゴリズム。

  • 深層学習：TensorFlow、PyTorch、Caffe などのフレームワークのモデルの読み込みと実行をサポートします。

OpenCV の機能は複数のモジュールに編成されており、各モジュールは異なるタスクに特化しています。以下は主要モジュールの概要です。

OpenCV の主要モジュール

OpenCV ライブラリは複数のモジュールで構成されており、各モジュールは異なる機能に特化しています。以下は OpenCV の主要モジュールの一部です。

1. Core モジュール

Core モジュールは OpenCV の中心的なモジュールであり、最も基本的なデータ構造と関数を含みます。OpenCV で最もよく使われるデータ型を定義しています。例えば、Mat（行列）、Point、Rectなど。Core モジュールはまた、基本的な数学演算、メモリ管理、ファイルI/Oなどの機能を提供します。

  • Mat クラス：Matは OpenCV で最もよく使われるデータ構造で、画像や行列データを格納するために使用されます。多次元配列であり、グレースケール画像、カラー画像、3D行列などを表現できます。
  • 基本操作：Core モジュールは行列の加減乗除、転置、逆行列などの基本操作を提供します。

2. Imgproc モジュール

Imgproc モジュールは画像処理モジュールであり、多数の画像処理関数を提供します。これらの関数は、画像のフィルタリング、幾何変換、色空間変換、ヒストグラム計算などに使用できます。

  • 画像フィルタリング：平均値フィルタ、ガウシアンフィルタ、メディアンフィルタなどを含み、画像のノイズ除去に使用されます。
  • 幾何変換：画像のスケーリング、回転、アフィン変換など。
  • エッジ検出：Cannyエッジ検出、Sobelオペレーターなど。
  • ヒストグラム均等化：画像のコントラストを強調するために使用されます。

3. Highgui モジュール

Highgui モジュールはグラフィカルユーザーインターフェース（GUI）機能を提供し、開発者がウィンドウの作成、画像の表示、マウスやキーボードイベントの処理などを行うことを可能にします。

  • 画像表示： 使用imshow関数を使用すると、ウィンドウに画像を表示できます。
  • ビデオキャプチャ： 使用VideoCaptureクラスを使用すると、カメラまたはビデオファイルからビデオフレームをキャプチャできます。
  • イベント処理：マウスクリック、キーボード入力などのイベントを処理できます。

4. Video モジュール

Video モジュールはビデオ解析に特化しており、ビデオキャプチャ、背景差分、オプティカルフロー計算などの機能を提供します。

  • ビデオキャプチャ： 使用VideoCaptureクラスを使用すると、カメラまたはビデオファイルからビデオフレームを読み取ることができます。
  • 背景差分：ビデオから前景オブジェクトを抽出するために使用されます。
  • オプティカルフロー計算：画像内の物体の動きを推定するために使用されます。

5. Calib3d モジュール

Calib3d モジュールは、カメラキャリブレーション、3D再構成、ステレオビジョンなどの機能を提供します。主にカメラに関連する幾何学的問題を処理するために使用されます。

  • カメラキャリブレーション：カメラの内部パラメータと外部パラメータを推定するために使用されます。
  • 3D再構成：複数の画像から3次元シーンを再構成します。
  • ステレオビジョン：深度マップの計算に使用されます。

6. Features2d モジュール

Features2d モジュールは、特徴検出と記述子抽出の機能を提供します。SIFT、SURF、ORB などのさまざまな特徴検出アルゴリズムが含まれています。

  • 特徴検出：画像内のキーポイントを検出します。
  • 記述子抽出：各キーポイントに対して記述子を生成し、異なる画像間の特徴マッチングに使用します。

7. Objdetect モジュール

Objdetect モジュールは物体検出機能を提供します。特に、Haar特徴とLBP特徴に基づくカスケード分類器です。

  • 顔検出：Haar特徴とカスケード分類器を使用して、画像内の顔を検出します。
  • 物体検出：目、車両など他の種類の物体を検出できます。

8. ML モジュール

ML モジュールは機械学習モジュールであり、サポートベクターマシン（SVM）、K近傍法（KNN）、決定木など、さまざまな機械学習アルゴリズムを提供します。

  • 分類：SVM、KNN などのアルゴリズムを使用して分類します。
  • 回帰：線形回帰などのアルゴリズムを使用して回帰分析を行います。
  • クラスタリング：K-means などのアルゴリズムを使用してクラスタリング分析を行います。

9. DNN モジュール

DNN モジュールは深層学習モジュールであり、深層学習モデルの読み込みと実行機能を提供します。TensorFlow、Caffe、ONNX などの複数の深層学習フレームワークをサポートしています。

  • モデルの読み込み：事前学習済みの深層学習モデルを読み込むことができます。
  • 推論：読み込んだモデルを使用して、画像分類、物体検出などのタスクを実行します。

OpenCV のインストールと設定

OpenCVを使用する前に、開発環境をインストールして設定する必要があります。

以下はOpenCVをインストールする基本的な手順です：

3.1 OpenCV のインストール

Linuxシステムでは、パッケージマネージャーを使用してOpenCVをインストールできます：

sudo apt-get install libopencv-dev

Windowsシステムでは、OpenCV公式サイトからプリコンパイル済みライブラリをダウンロードするか、vcpkgを使用してインストールできます。

開発環境の設定

C++プロジェクトでOpenCVを使用する場合、コンパイル時にOpenCVライブラリをリンクする必要があります。

以下は簡単なCMake設定の例です：

cmake_minimum_required(VERSION 3.10)
project(OpenCVExample)

find_package(OpenCV REQUIRED)

add_executable(OpenCVExample main.cpp)

target_link_libraries(OpenCVExample ${OpenCV_LIBS})

シンプルな OpenCV の例

以下はOpenCVを使用して画像を読み込み表示する簡単な例です：

例

#include <opencv2/opencv.hpp>
#include <iostream>

int main() {
    // 画像を読み込む
    cv::Mat image = cv::imread("example.jpg");

    // 画像が正常に読み込まれたか確認する
    if (image.empty()) {
        std::cout << "画像を読み込めません！" << std::endl;
        return -1;
    }

    // ウィンドウを作成して画像を表示する
    cv::namedWindow("Example", cv::WINDOW_AUTOSIZE);
    cv::imshow("Example", image);

    // キー入力を待つ
    cv::waitKey(0);

    return 0;
}

上記のコードでは、次を使用していますimread関数で画像を読み込み、imshow関数で画像を表示し、waitKey関数でユーザーのキー入力を待ちます。
