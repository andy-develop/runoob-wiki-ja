C++ ポインタを関数に渡す

C++ ポインタ

C++ では、関数パラメータをポインタ型として宣言するだけで、ポインタを関数に渡すことができます。

次の例では、unsigned long型のポインタを関数に渡し、関数内でその値を変更します：

サンプル

#include <iostream> #include <ctime> using namespace std; // 関数を書くときは、慣習的に関数を先に宣言してから定義します void getSeconds(unsigned long *par); int main () { unsigned long sec; getSeconds( &sec ); // 実際の値を出力 cout << "Number of seconds :" << sec << endl; return 0; } void getSeconds(unsigned long *par) { // 現在の秒数を取得 *par = time( NULL ); return; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

Number of seconds :1294450468

ポインタをパラメータとして受け取れる関数は、配列をパラメータとして受け取ることもできます。次のようになります：

サンプル

#include <iostream> using namespace std; // 関数宣言 double getAverage(int *arr, int size); int main () { // 5つの要素を持つ整数配列 int balance[5] = {1000, 2, 3, 17, 50}; double avg; // 配列を指すポインタをパラメータとして渡す avg = getAverage( balance, 5 ) ; // 戻り値を出力 cout << "Average value is: " << avg << endl; return 0; } double getAverage(int *arr, int size) { int i, sum = 0; double avg; for (i = 0; i < size; ++i) { sum += arr[i]; } avg = double(sum) / size; return avg; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

Average value is: 214.4
