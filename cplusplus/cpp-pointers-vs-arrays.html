C++ ポインタ vs 配列

C++ ポインタ

ポインタと配列は密接に関連しています。実際、ポインタと配列は多くの場合において互換性があります。例えば、配列の先頭を指すポインタは、ポインタの算術演算や配列インデックスを使用して配列にアクセスできます。次のプログラムを見てください：

サンプル

#include <iostream> using namespace std; const int MAX = 3; int main () { int var[MAX] = {10, 100, 200}; int *ptr; // ポインタにおける配列のアドレス ptr = var; for (int i = 0; i < MAX; i++) { cout << "var[" << i << "]のメモリアドレスは"; cout << ptr << endl; cout << "var[" << i << "] の値は"; cout << *ptr << endl; // 次の位置に移動する ptr++; } return 0; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

var[0]的内存地址为 0x7fff59707adc
var[0] 的值为 10
var[1]的内存地址为 0x7fff59707ae0
var[1] 的值为 100
var[2]的内存地址为 0x7fff59707ae4
var[2] 的值为 200

ただし、ポインタと配列は完全に交換可能というわけではありません。例えば、次のプログラムを見てください：

サンプル

#include <iostream> using namespace std; const int MAX = 3; int main () { int var[MAX] = {10, 100, 200}; for (int i = 0; i < MAX; i++) { *var = i; // これは正しい構文です var++; // これは正しくありません } return 0; }

ポインタ演算子 * を var に適用することは完全に可能ですが、var の値を変更することは不正です。これは、var が配列の先頭を指す定数であり、左辺値として使用できないためです。

配列名はポインタ定数に対応するため、配列の値を変更しない限り、ポインタ形式の式を引き続き使用できます。例えば、以下の文は有効で、var

*(var + 2) = 500;

上記の文は有効であり、var が変更されていないため、正常にコンパイルできます。

    チュートリアルへのいくつかの拡張：

    #include <iostream>

using namespace std;

int *ptr = new int(), n = 0;

int main(int argc,char* argv[])
{
    cout << "设置输入多少个数字: "<< endl;
    cin >> n;
     cout << "开始输入: "<< endl;
    for(int i = 0; i < n; ++i)
    {
        cin >> ptr[i];
    }

    cout << "输入的数字为: "<< endl;
    for(int i = 0; i < n; ++i)
    {
        cout << *(ptr + i) << " ";
    }
    return 0;
}

    1. ポインタを初期化する際には、newキーワードを使用できます。形式は「new 型名(引数)」です。int型の引数は空またはint値にすることができ、newキーワードはその変数のポインタを返します。

    2. ポインタ自体を配列として使用できます。最初のforループでは、入力の形式がすでにこのことを示しています。ptr[i] は実際には *(ptr + i) であり、int ptr[] は const int* ptr を表します。初期アドレスが定数でありサイズが確定していることを除けば、ほとんど違いはありません。

    3. まさにこの理由から、ポインタを可変長の配列として使用でき、事前に大きな配列を用意せずに任意の数の数値を渡すことができ、スペースを節約できます。初期化時にptrポインタ（配列）の長さが決まっていないため、RAMが尽きるまで無限に変数を追加できます。

    4. 初期化する変数の型はポインタを含みません。main関数の前の変数定義では、最初にint*を型としてptrを定義し、次にint型でnを定義しました。明らかに、これは複数の変数を定義する際、変数の型はデフォルトではポインタを含まないことを示しています。実際、ポインタ記号*の作用対象は1つだけなので、型の隣に置いて括弧を付けても（ただし型を括弧で囲むとエラーになります）、この法則は変わりません。（マクロの話はしないでください）

    ちなみに、forループの最後の文では、++iはi++よりも高速です。したがって、これら2つの演算子の優先順位の特性を利用する必要がない限り、文の中のインクリメント演算子として++iを使用することをお勧めします。実は、iをポインタ変数にして、最初の文でiを配列の先頭を指すポインタに初期化し、その後*iを配列変数として使用することもできます。

    配列名a 是 a[0]のアドレスは、(a+n)つまりa[0]のアドレスに値を加えたものであり、&はアドレス取得を表し、*は値の取得を表すとすると、a[i]と等価になり、*(a+i)，&a[i]と等価です。(a+i)。

    次のようになります：

    #include<iostream>
using namespace std;
int main()
{
    int a[5];// 在"int main()"中定义数组 ，数组若没有定义初始值，其初始值是随机的 
    a[2]=100;
    for(int i=-5;i<=10;i++)// 无论i是负数，还是过大溢出，都只是改变数组地址 
    cout<<"a["<<i<<"]="<<a[i]<<" "<<endl;
    cout<<endl;
    for(int i=-5;i<=10;i++)
    cout<<"*(a+"<<i<<")="<<*(a+i)<<" "<<endl;// 取(a+i)地址所存的值 
    cout<<endl;
    for(int i=-5;i<=10;i++)
    cout<<"&a["<<i<<"]="<<&a[i]<<" "<<endl;// 取a[i]的地址 
    cout<<endl;
    for(int i=-5;i<=10;i++)
    cout<<"(a+"<<i<<")="<<a+i<<" "<<endl;// 取(a+i)的地址 
    //最好不要用负数数组和溢出数组，否则可能出问题
}

    これは、なぜint main()で配列を定義する際、配列に初期値を定義しなければ、その初期値がランダムになるという問題をうまく説明しています。なぜなら、どんな型であれ、どんな変数や定数であれ、すべてコンピュータ内に存在し、アドレスはそれらの位置であり、アドレスにはそれらの値が格納されているからです。アドレス値を定義していない場合、強制的にアドレス値を取得すると、アドレスが元々持っていた値を取得します。そして、int main()の外側の数値は、その初期値は0値です。

    よく観察すると気づくでしょう、a[10] 与 (a+10)のアドレスは同じですが値が異なります。それは、このアドレスがa[10]の宣言によって占有されておらず、他人のアドレスだからです。そうなると、他人は好きなように変更でき、a[10]は干渉する権利がありません。なぜなら、そのような配列自体が非合法だからです（したがって、負の配列やオーバーフロー配列は使わない方がよいでしょう）。
