C++ 関数

関数は、一緒にタスクを実行する文の集まりです。すべての C++ プログラムには少なくとも 1 つの関数、つまりメイン関数がありますmain()、すべての単純なプログラムは、他の追加の関数も定義できます。

コードをさまざまな関数に分割できます。コードをどのように関数に分割するかはあなた次第ですが、論理的には、通常は各関数が特定のタスクを実行するように分割します。

関数宣言コンパイラに関数の名前、戻り値の型、パラメータを伝えます。関数定義は関数の実際の本体を提供します。

C++ 標準ライブラリには、プログラムが呼び出せる多数の組み込み関数があります。たとえば、関数strcat()は2つの文字列を連結するために使われ、関数memcpy()はメモリを別の場所にコピーするために使われます。

関数には、メソッド、サブルーチン、プロシージャなど、さまざまな呼び方もあります。

関数の定義

C++ における関数定義の一般的な形式は次のとおりです：

return_type function_name( parameter list ) { body of the function }

C++ では、関数は関数ヘッダと関数本体で構成されます。以下に関数のすべての構成要素を示します：

  • 戻り値の型：関数は値を1つ返すことができます。return_typeは関数が返す値のデータ型です。一部の関数は必要な操作を実行しても値を返しません。この場合、return_type はキーワードvoid。
  • 関数名：これは関数の実際の名前です。関数名とパラメータリストは一緒になって関数シグネチャを構成します。
  • パラメータ：パラメータはプレースホルダのようなものです。関数が呼び出されるとき、パラメータに値を渡します。この値を実引数と呼びます。パラメータリストには、関数パラメータの型、順序、数が含まれます。パラメータは省略可能であり、つまり関数はパラメータを含まない場合もあります。
  • 関数本体：関数本体には、関数が実行するタスクを定義する一連の文が含まれます。

例

以下はmax()関数のソースコードです。この関数には num1 と num2 の2つのパラメータがあり、これら2つの数値のうち大きい方を返します：

// 2つの数値のうち大きい方を返す関数 int max(int num1, int num2) { // ローカル変数の宣言 int result; if (num1 > num2) result = num1; else result = num2; return result; }

関数の宣言

関数宣言はコンパイラに関数名と関数の呼び出し方を伝えます。関数の実際の本体は個別に定義できます。

関数の宣言には次の部分が含まれます：

return_type function_name( parameter list );

上で定義した関数 max() について、以下が関数の宣言です：

int max(int num1, int num2);

関数の宣言では、パラメータ名は重要ではなく、パラメータの型のみが必要です。したがって、次も有効な宣言です：

int max(int, int);

あるソースファイルで関数を定義し、別のファイルでその関数を呼び出す場合、関数の宣言が必要です。この場合、関数を呼び出すファイルの先頭で関数を宣言する必要があります。

関数の呼び出し

C++ 関数を作成するとき、関数が何を行うかを定義し、それから関数を呼び出して定義したタスクを実行します。

プログラムが関数を呼び出すと、プログラムの制御は呼び出された関数に移ります。呼び出された関数は定義されたタスクを実行し、関数の return 文が実行されるか、関数の終了中括弧に達すると、プログラムの制御はメインプログラムに戻されます。

関数を呼び出すとき、必要なパラメータを渡します。関数が値を返す場合は、戻り値を保存できます。例：

例

#include <iostream> using namespace std; // 関数の宣言 int max(int num1, int num2); int main () { // ローカル変数の宣言 int a = 100; int b = 200; int ret; // 関数を呼び出して最大値を取得する ret = max(a, b); cout << "Max value is : " << ret << endl; return 0; } // 2つの数値のうち大きい方を返す関数 int max(int num1, int num2) { // ローカル変数の宣言 int result; if (num1 > num2) result = num1; else result = num2; return result; }

max() 関数と main() 関数を一緒に置いて、ソースコードをコンパイルします。最終的な実行可能ファイルを実行すると、次の結果が生成されます：

Max value is : 200

関数のパラメータ

関数がパラメータを使用する場合、パラメータ値を受け取る変数を宣言する必要があります。これらの変数は関数の仮引数。

仮引数は関数内の他のローカル変数と同様に、関数に入るときに作成され、関数を出るときに破棄されます。

関数を呼び出すとき、関数にパラメータを渡す方法は3つあります：

呼び出しの種類説明
値渡しこの方法では、パラメータの実際の値を関数の仮引数に代入します。この場合、関数内で仮引数を変更しても実引数には影響しません。
ポインタ渡しこの方法では、パラメータのアドレスを仮引数に代入します。関数内では、そのアドレスを使用して呼び出しで使用される実引数にアクセスします。つまり、仮引数を変更すると実引数に影響します。
参照渡しこの方法では、パラメータの参照を仮引数に代入します。関数内では、その参照を使用して呼び出しで使用される実引数にアクセスします。つまり、仮引数を変更すると実引数に影響します。

デフォルトでは、C++ は値渡しを使用してパラメータを渡します。一般に、これは関数内のコードが関数の呼び出しに使用された引数を変更できないことを意味します。前述の例では、max() 関数を呼び出すときに同じ方法が使用されました。

パラメータのデフォルト値

関数を定義するとき、パラメータリストの後ろにある各パラメータにデフォルト値を指定できます。関数を呼び出すときに、実引数の値を空のままにすると、このデフォルト値が使用されます。

これは、関数定義で代入演算子を使用してパラメータに値を割り当てることによって行われます。関数を呼び出すとき、パラメータの値が渡されない場合はデフォルト値が使用され、値が指定された場合はデフォルト値は無視されて渡された値が使用されます。次の例を参照してください：

例

#include <iostream> using namespace std; int sum(int a, int b=20) { int result; result = a + b; return (result); } int main () { // ローカル変数の宣言 int a = 100; int b = 200; int result; // 関数を呼び出して値を追加する result = sum(a, b); cout << "Total value is :" << result << endl; // 関数を再度呼び出す result = sum(a); cout << "Total value is :" << result << endl; return 0; }

上記のコードをコンパイルして実行すると、次の結果が生成されます：

Total value is :300
Total value is :120

Lambda 関数と式

C++11 は匿名関数のサポートを提供します。これは Lambda 関数（Lambda 式とも呼ばれます）と呼ばれます。

Lambda 式は関数をオブジェクトとして扱います。Lambda 式はオブジェクトのように使用でき、変数に代入したりパラメータとして渡したり、関数のように評価したりできます。

Lambda 式は本質的に関数宣言と非常によく似ています。Lambda 式の具体的な形式は次のとおりです：

[capture](parameters)->return-type{body}

例：

[](int x, int y){ return x < y ; }

戻り値がない場合は次のように表すことができます：

[capture](parameters){body}

例：

[]{ ++global_x; }

より複雑な例では、戻り値の型を次のように明示的に指定できます：

[](int x, int y) -> int { int z = x + y; return z + x; }

この例では、中間結果を格納するために一時的なパラメータ z が作成されます。通常の関数と同様に、z の値は、次にこの匿名関数が再び呼び出されたときに保持されることはありません。

lambda 関数が値を返さない場合（void など）、その戻り値の型は完全に無視できます。

Lambda 式内では現在のスコープの変数にアクセスできます。これは Lambda 式のクロージャ（Closure）動作です。JavaScript のクロージャとは異なり、C++ の変数渡しには値渡しと参照渡しの違いがあります。先頭の [] で指定できます：

[]      // 沒有定义任何变量。使用未定义变量会引发错误。
[x, &y] // x以传值方式传入（默认），y以引用方式传入。
[&]     // 任何被使用到的外部变量都隐式地以引用方式加以引用。
[=]     // 任何被使用到的外部变量都隐式地以传值方式加以引用。
[&, x]  // x显式地以传值方式加以引用。其余变量以引用方式加以引用。
[=, &z] // z显式地以引用方式加以引用。其余变量以传值方式加以引用。

もう1点注意が必要です。[=] または [&] の形式では、lambda 式は this ポインタを直接使用できます。ただし、[] の形式では、this ポインタを使用する場合は明示的に渡す必要があります：

[this]() { this->someFunc(); }();

    Lambda 関数と式

    Lambda 関数の構文定義は次のとおりです：

    [capture](parameters) mutable ->return-type{statement}

    ここで：

    • [capture]：キャプチャリスト。キャプチャリストは常に lambda 式の先頭に現れます。実際、[] は lambda の導入記号です。コンパイラはこの導入記号に基づいて、後続のコードが lambda 関数であるかどうかを判断します。キャプチャリストはコンテキスト内の変数をキャプチャして lambda 関数で使用できるようにします。
    • (parameters)：パラメータリスト。通常の関数のパラメータリストと同じです。パラメータ渡しが不要な場合は、括弧 () と一緒に省略できます。
    • mutable：mutable 修飾子。デフォルトでは、lambda 関数は常に const 関数ですが、mutable を使用するとその定数性を解除できます。この修飾子を使用する場合、パラメータリストは省略できません（パラメータが空でも）。
    • ->return_type：戻り値の型。トレーリング戻り値型の形式で関数の戻り値の型を宣言します。便利なため、戻り値が不要な場合は記号 -> とともに省略することもできます。さらに、戻り値の型が明確な場合は、その部分を省略してコンパイラに戻り値の型を推論させることもできます。
    • {statement}：関数本体。内容は通常の関数と同じですが、パラメータを使用できるだけでなく、キャプチャしたすべての変数も使用できます。

    lambda 関数の定義では、パラメータリストと戻り値の型はどちらも省略可能な部分であり、キャプチャリストと関数本体はどちらも空にできます。C++ で最も単純な lambda 関数は次のように宣言するだけです：

    []{};

    文字列を出力できるlambda式を定義します。式は通常、角括弧[]で始まり、波括弧{}で終わります。波括弧の中は関数を定義するように、lambda式の本体を含みます：

    // 定义简单的lambda表达式
auto basicLambda = [] { cout << "Hello, world!" << endl; };

// 调用
basicLambda();
// 输出：Hello, world!

    パラメータが必要な場合、関数のように丸括弧の中に置きます。戻り値がある場合は、戻り値の型を->の後、つまりトレーリング戻り値型に置きます。もちろん戻り値の型を省略して、lambdaに自動的に推論させることもできます：

    // 指明返回类型
auto add = [](int a, int b) -> int { return a + b; };

// 自动推断返回类型
auto multiply = [](int a, int b) { return a * b; };
int sum = add(2, 5);   // 输出：7
int product = multiply(2, 5);  // 输出：10

    Lambda関数はとても簡潔ですが、バリエーションが多いです。

    1、何もキャプチャしない、または意図的にLambda関数の外部の変数を使わない

    #include <iostream>
using namespace std;
 
int main()
{
    int i = 1024;
    auto func = [] { cout << i; };
    func();
}  // 结果报错，因为未指定默认捕获模式

    正しい例は次のとおりです：

    #include <iostream>
using namespace std;
 
int main()
{
    int i = 1024;
    auto func = [=]{  // [=] 表明将外部的所有变量拷贝一份到该Lambda函数内部
        cout << i;
    };
    func();
}

    2、参照キャプチャ

    #include <iostream>
using namespace std;
 
int main()
{
    int i = 1024;
    cout << &i << endl;
    auto fun1 = [&]{
        cout << &i << endl;
    };
    fun1();
}

    3、コピーと参照キャプチャ

    #include <iostream>
using namespace std;
 
int main()
{
    int i = 1024, j = 2048;
 
    cout << "i:" << &i << endl;
    cout << "j:" << &j << endl;
 
    auto fun1 = [=, &i]{ // 默认拷贝外部所有变量，但引用变量 i
        cout << "i:" << &i << endl;
        cout << "j:" << &j << endl;
    };
    fun1();
}

    4、参照またはコピーを指定

    #include <iostream>
using namespace std;
 
int main()
{
    int i = 1024, j = 2048;
 
    cout << "outside i value:" << i << " addr:" << &i << endl;
 
    auto fun1 = [i]{
        cout << "inside  i value:" << i << " addr:" << &i << endl;
        // cout << j << endl; // j 未捕获
    };
    fun1();
}

    5、thisポインタをキャプチャ

    #include <iostream>
using namespace std;
 
class test
{
public:
    void hello() {
        cout << "test hello!n";
    };
    void lambda() {
        auto fun = [this]{ // 捕获了 this 指针
            this->hello(); // 这里 this 调用的就是 class test 的对象了
        };
        fun();
    }
};
 
int main()
{
    test t;
    t.lambda();
}

    初心者が犯しがちな間違い

    実際にコードを書く過程で、関数の定義と宣言が同じファイルになく、宣言がヘッダーファイルに現れる状況に遭遇することがあります。

    この場合、デフォルト値を持つ関数の宣言と定義では、デフォルト値は宣言のコードに記述し、定義ではパラメータにデフォルト値を再度与えてはいけません。そうしないとエラーになります。

    <Plus.h> //声明在头文件中
int Plus(int a, int b = 10)
<Plus.cpp>//定义在cpp文件中
int Plus(int a, int b)//不能再对b赋值了
{
    return a + b;

    特別な説明

    [this]: 現在のオブジェクトを参照でキャプチャします（オブジェクト自体）

    [*this]: 現在のオブジェクトを値でキャプチャします（オブジェクトのコピーであり、単なるアドレス値に過ぎないため、意味がないと言えます）

    例で説明します：

    #include <iostream>
using namepsace std;

//定义一个类
class MM 
{
public:
  void print() {}
};

int main()
{
  MM mm;

  //打印对象地址作对比
  cout << "对象本身地址：" << &mm << endl;
  
  [&mm](){cout << "[&mm]: " << &mm << endl;}();    //相当于[this]
  [mm](){cout << "[mm]: " << &mm << endl;}();      //相当于[*this]
  [mm](){cout << "[mm]: " << &mm << endl;}();      //相当于[*this]

  return 0;
}

    結果：

    对象本身地址：012FF984
[&mm]: 012FF984
[mm]: 012FF878
[mm]: 012FF850

    キャプチャしたポインタを使ってメンバ関数を呼び出そうとする：

    [&mm](){cout << this->print();}();    //相当于[this]
//[mm](){cout << this->print();}();    //相当于[*this]，无法调用，因为传入的只是一个值
