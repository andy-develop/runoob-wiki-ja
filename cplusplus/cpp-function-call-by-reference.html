C++ 参照呼び出し

C++ 関数

関数にパラメータを渡す参照呼び出しこの方法では、参照のアドレスを仮引数にコピーします。関数内では、その参照は呼び出しで使用される実引数にアクセスするために使用されます。つまり、仮引数を変更すると実引数に影響を与えます。

参照によって値を渡すと、パラメータの参照が関数に渡されます。これは、他の値を関数に渡すのと同じです。したがって、次の関数swap()では、関数のパラメータを参照型として宣言する必要があります。この関数は、パラメータが指す2つの整数変数の値を交換するために使用されます。

// 函数定义
void swap(int &x, int &y)
{
   int temp;
   temp = x; /* 保存地址 x 的值 */
   x = y;    /* 把 y 赋值给 x */
   y = temp; /* 把 x 赋值给 y  */
  
   return;
}

では、参照によって値を渡して関数を呼び出してみましょう。swap()：

サンプル

#include <iostream> using namespace std; // 関数の宣言 void swap(int &x, int &y); int main () { // ローカル変数の宣言 int a = 100; int b = 200; cout << "交換前のaの値：" << a << endl; cout << "交換前のbの値：" << b << endl; /*関数を呼び出して値を交換する*/ swap(a, b); cout << "交換後のaの値：" << a << endl; cout << "交換後のbの値：" << b << endl; return 0; } // 関数の定義 void swap(int &x, int &y) { int temp; temp = x; /*アドレスxの値を保存する*/ x = y; /*yをxに代入する*/ y = temp; /*xをyに代入する*/ return; }

上記のコードをコンパイルして実行すると、次の結果が生成されます：

交换前，a 的值： 100
交换前，b 的值： 200
交换后，a 的值： 200
交换后，b 的值： 100

キーポイント

  1. 参照定義：を使用して&記号で参照型を定義します。例えばint &ref。
  2. 参照の受け渡し：関数のパラメータリストで参照型を使用します。これにより、関数内部の変更が実際に渡された変数に影響を与えます。
  3. コピーのオーバーヘッドを回避：参照渡しは、大きなオブジェクトを渡す際のコピーのオーバーヘッドを回避し、効率を向上させます。

参照呼び出しの適用場面

  • 外部変数の変更：上記の例のように、関数を介して渡された変数を変更します。
  • オーバーヘッドの削減：特に大きなオブジェクトや複雑なデータ構造を渡す場合、参照渡しは不要なコピー操作を回避できます。
  • 戻り値の最適化：参照によって関数のローカル変数を返すことで、戻り値のコピーのオーバーヘッドを回避します。

参照呼び出しはC++における重要な技術であり、コードの効率と柔軟性を向上させることができます。参照呼び出しを理解し、熟練して使用することは、効率的なC++プログラムを書く上で非常に役立ちます。
