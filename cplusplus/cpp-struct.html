C++ 構造体(struct)

C/C++ の配列は同じ型のデータ項目を格納できる変数を定義できますが、構造体はC++ におけるもう一つのユーザー定義のデータ型であり、異なる型のデータ項目を格納することができます。

構造体はレコードを表すために使用されます。図書館の本の動きを追跡したい場合、各本について次の属性を追跡する必要があるかもしれません：

  • Title ：タイトル
  • Author ：著者
  • Subject ：カテゴリ
  • Book ID ：本の ID

構造体の定義

C++ では、struct 文は構造体（structure）を定義するために使用されます。

構造体はユーザー定義のデータ型であり、異なる型のデータをまとめるために使用されます。クラス（class）と同様に、構造体ではメンバー変数とメンバー関数を定義できます。

構造体を定義するには、struct 文を使用する必要があります。structstruct 文は、複数のメンバーを含む新しいデータ型を定義します。struct 文の形式は次のとおりです：

struct type_name { member_type1 member_name1; member_type2 member_name2; member_type3 member_name3; . . } object_names;

type_nameは構造体型の名前です。member_type1 member_name1は標準的な変数定義です。たとえばint i;またはfloat f;またはその他の有効な変数定義です。構造体定義の末尾、最後のセミコロンの前に、1つ以上の構造体変数を指定できます。これはオプションです。次は構造体型を宣言する例です。Books、変数はbook：

struct Books { char title[50]; char author[50]; char subject[100]; int book_id; } book;

構造体の利点：

  • シンプルなデータカプセル化：複数の型のシンプルなデータをカプセル化するのに適しており、通常はデータの保存に使用されます。
  • 軽量：クラスと比べてclass構造体の構文はより簡潔で、小規模なデータオブジェクトに適しています。
  • オブジェクト指向のサポート：コンストラクター、メンバー関数、アクセス権限の制御をサポートし、オブジェクト指向の設計を実現できます。

構造体メンバーへのアクセス

構造体のメンバーにアクセスするには、メンバーアクセス演算子（.）を使用します。メンバーアクセス演算子は、構造体変数名とアクセスしたい構造体メンバーとの間にあるピリオドです。

以下の例は構造体の使い方を示しています：

例

#include <iostream> #include <cstring> using namespace std; // 構造体型 Books を宣言 struct Books { char title[50]; char author[50]; char subject[100]; int book_id; }; int main( ) { Books Book1; // 構造体型 Books の変数 Book1 を定義 Books Book2; // 構造体型 Books の変数 Book2 を定義 // Book1 の詳細 strcpy( Book1.title, "C++ チュートリアル"); strcpy( Book1.author, "サンプル"); strcpy( Book1.subject, "プログラミング言語"); Book1.book_id = 12345; // Book2 の詳細 strcpy( Book2.title, "CSS チュートリアル"); strcpy( Book2.author, "サンプル"); strcpy( Book2.subject, "フロントエンド技術"); Book2.book_id = 12346; // Book1 の情報を出力 cout << "最初の本のタイトル :" << Book1.title <<endl; cout << "最初の本の著者 :" << Book1.author <<endl; cout << "最初の本のカテゴリ :" << Book1.subject <<endl; cout << "最初の本の ID :" << Book1.book_id <<endl; // Book2 の情報を出力 cout << "2冊目の本のタイトル :" << Book2.title <<endl; cout << "2冊目の本の著者 :" << Book2.author <<endl; cout << "2冊目の本のカテゴリ :" << Book2.subject <<endl; cout << "2冊目の本の ID :" << Book2.book_id <<endl; return 0; }

この例では、構造体型 Books とその2つの変数 Book1 および Book2 を定義しています。上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

第一本书标题 : C++ 教程
第一本书作者 : サンプル
第一本书类目 : 编程语言
第一本书 ID : 12345
第二本书标题 : CSS 教程
第二本书作者 : サンプル
第二本书类目 : 前端技术
第二本书 ID : 12346

関数の引数としての構造体

構造体を関数の引数として渡すことができます。渡し方は他の型の変数やポインタと同様です。上記の例と同じ方法で構造体変数にアクセスできます：

例

#include <iostream> #include <cstring> using namespace std; void printBook( struct Books book ); // 構造体型 Books を宣言 struct Books { char title[50]; char author[50]; char subject[100]; int book_id; }; int main( ) { Books Book1; // 構造体型 Books の変数 Book1 を定義 Books Book2; // 構造体型 Books の変数 Book2 を定義 // Book1 の詳細 strcpy( Book1.title, "C++ チュートリアル"); strcpy( Book1.author, "サンプル"); strcpy( Book1.subject, "プログラミング言語"); Book1.book_id = 12345; // Book2 の詳細 strcpy( Book2.title, "CSS チュートリアル"); strcpy( Book2.author, "サンプル"); strcpy( Book2.subject, "フロントエンド技術"); Book2.book_id = 12346; // Book1 の情報を出力 printBook( Book1 ); // Book2 の情報を出力 printBook( Book2 ); return 0; } void printBook( struct Books book ) { cout << "本のタイトル :" << book.title <<endl; cout << "本の著者 :" << book.author <<endl; cout << "本のカテゴリ :" << book.subject <<endl; cout << "本の ID :" << book.book_id <<endl; }

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

书标题 : C++ 教程
书作者 : サンプル
书类目 : 编程语言
书 ID : 12345
书标题 : CSS 教程
书作者 : サンプル
书类目 : 前端技术
书 ID : 12346

構造体の各部分の詳細説明

  • struct キーワード：構造体を定義するために使用され、コンパイラーにこれから定義するのがユーザー定義型であることを伝えます。

  • メンバー変数：メンバー変数は構造体内で定義されるデータ項目であり、任意の基本型や他のユーザー定義型を使用できます。struct では、これらのメンバーはデフォルトで public であり、直接アクセスできます。

  • メンバー関数：構造体にはメンバー関数を含めることもでき、これにより構造体は機能的にクラスに似たものになります。メンバー関数は構造体のメンバー変数を操作でき、データのカプセル化と操作を提供します。

  • アクセス権限：class と同様に、struct 内で public、private、protected を使用してメンバーのアクセス権限を定義できます。struct ではデフォルトで全てのメンバーが public ですが、class ではデフォルトで private です。

構造体を指すポインタ

構造体を指すポインタを定義できます。他の型の変数を指すポインタを定義する方法と似ています。次のようにします：

struct Books *struct_pointer;

上記のコードは、Books 構造体を指すポインタ struct_pointer を定義しています。

次に、上記で定義したポインタ変数に構造体変数のアドレスを格納できます。構造体変数のアドレスを取得するには、&演算子を構造体名の前に置きます。次のようにします：

struct_pointer = &Book1;

上記のコードは、Book1 構造体変数のアドレスを struct_pointer に代入します。

構造体を指すポインタを使用して構造体のメンバーにアクセスするには、->演算子を使用する必要があります。次のようにします：

struct_pointer->title;

上記のコードは、struct_pointer を介して Book1 構造体の title メンバーにアクセスします。

構造体ポインタを使用して上記の例を書き直してみましょう。これにより、構造体ポインタの概念を理解しやすくなります：

例

#include <iostream> #include <string> using namespace std; // 構造体型 Books を宣言 struct Books { string title; string author; string subject; int book_id; // コンストラクター Books(string t, string a, string s, int id) : title(t), author(a), subject(s), book_id(id) {} }; // 書籍情報を出力する関数。Books 構造体へのポインタを受け取る void printBookInfo(const Books* book) { cout << "書籍タイトル:" << book->title << endl; cout << "書籍著者:" << book->author << endl; cout << "書籍カテゴリ:" << book->subject << endl; cout << "書籍 ID:" << book->book_id << endl; } int main() { // 2冊の本のオブジェクトを作成 Books Book1("C++ チュートリアル", "サンプル", "プログラミング言語", 12345); Books Book2("CSS チュートリアル", "サンプル", "フロントエンド技術", 12346); // ポインタを使用してこれら2冊の本のオブジェクトを指す Books* ptrBook1 = &Book1; Books* ptrBook2 = &Book2; // 書籍情報を出力し、ポインタを渡す printBookInfo(ptrBook1); printBookInfo(ptrBook2); return 0; }

説明：

  • 構造体の定義：Books構造体の定義は以前と同じで、title、author、subjectとbook_id4つのメンバー変数と、これらのメンバーを初期化するためのコンストラクターがあります。

  • printBookInfo関数：この関数はBooks構造体へのポインタを受け取ります。const Books* book関数内部では、->-> 演算子を使用して、構造体ポインタが指すメンバー変数にアクセスします。

  • main関数：

    • は2つのBooks型のオブジェクトを作成します。Book1とBook2。

    • & 演算子を使用して&これら2つのオブジェクトのアドレスを取得し、それらをポインタに代入します。ptrBook1とptrBook2。

    • 関数を呼び出すとき、printBookInfo渡されるのはBooksオブジェクトへのポインタです。

上記のコードがコンパイルおよび実行されると、次の結果が生成されます：

书籍作者: サンプル
书籍类目: 编程语言
书籍 ID: 12345
书籍标题: CSS 教程
书籍作者: サンプル
书籍类目: 前端技术
书籍 ID: 12346

typedef キーワード

次は構造体を定義するより簡単な方法です。作成した型に「エイリアス」を付けることができます。例：

typedef struct Books
{
   char  title[50];
   char  author[50];
   char  subject[100];
   int   book_id;
}Books;

これで、BooksBooks を直接使用してBooksBooks 型の変数を定義できます。struct キーワードは不要です。以下に例を示します：

Books Book1, Book2;

typedef キーワードを使用してtypedef非構造体型を定義することができます。次に例を示します：

typedef long int *pint32;
 
pint32 x, y, z;

x、y、z はすべて long int（長整数型）を指すポインタです。

構造体とクラスの違い

C++ では、struct と class は本質的に非常に似ており、唯一の違いはデフォルトのアクセス権限です：

  • structデフォルトのメンバーと継承はpublic。
  • classデフォルトのメンバーと継承はprivate。

あなたは ... をstructの簡略化された形式として見なすことができますclass、複雑な機能がそれほどない単純なデータのカプセル化に適しています。

構造体と関数の組み合わせ

コンストラクタを使って構造体を初期化でき、参照渡しで構造体を渡すことで不要なコピーを避けることもできます。

例

struct Books {
    string title;
    string author;
    string subject;
    int book_id;

    // コンストラクタ
    Books(string t, string a, string s, int id)
        : title(t), author(a), subject(s), book_id(id) {}

    void printInfo() const {
        cout << "書籍タイトル: " << title << endl;
        cout << "書籍著者: " << author << endl;
        cout << "書籍カテゴリ: " << subject << endl;
        cout << "書籍 ID: " << book_id << endl;
    }
};

void printBookByRef(const Books& book) {
    book.printInfo();
}
