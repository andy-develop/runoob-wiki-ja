クラスのコンストラクタ

クラスのコンストラクタクラスの特別なメンバ関数であり、クラスの新しいオブジェクトを作成するたびに自動的に実行されます。

コンストラクタの名前はクラス名と完全に同じで、戻り値の型はありません（voidvoid でさえも持つことはできません）。コンストラクタは通常、メンバ変数に初期値を設定するために使用されます。

コンストラクタを明示的に定義しない場合、コンパイラは何も実行しないデフォルトコンストラクタを自動的に生成します。

以下の例は、コンストラクタの概念をよりよく理解するのに役立ちます。

例

#include <iostream> using namespace std; class Line { public: Line(); // コンストラクタの宣言 void setLength(double len); double getLength() const; private: double length; }; // コンストラクタの定義 Line::Line() { cout << "Object is being created" << endl; length = 0.0; // メンバ変数を明示的に初期化 } void Line::setLength(double len) { length = len; } double Line::getLength() const { return length; } // プログラムのメイン関数 int main() { Line line; // 長さを設定 line.setLength(6.0); cout << "Length of line : " << line.getLength() << endl; return 0; }

上記のコードをコンパイルして実行すると、次の結果が生成されます。

Object is being created
Length of line : 6

引数付きコンストラクタ

デフォルトのコンストラクタは引数を持ちませんが、必要に応じてコンストラクタに引数を持たせることもできます。これにより、オブジェクトを作成するときに初期値をオブジェクトに設定でき、個別に呼び出す必要はありません。set関数は、次の例のとおりです。

例

#include <iostream> using namespace std; class Line { public: Line(double len); // 引数付きコンストラクタの宣言 void setLength(double len); double getLength() const; private: double length; }; // コンストラクタの定義 Line::Line(double len) { cout << "Object is being created, length = " << len << endl; length = len; } void Line::setLength(double len) { length = len; } double Line::getLength() const { return length; } // プログラムのメイン関数 int main() { Line line(10.0); // オブジェクト作成時に初期長さを直接渡す // 初期長さを取得 cout << "Length of line : " << line.getLength() << endl; // 長さを再設定 line.setLength(6.0); cout << "Length of line : " << line.getLength() << endl; return 0; }

上記のコードをコンパイルして実行すると、次の結果が生成されます。

Object is being created, length = 10
Length of line : 10
Length of line : 6

初期化リストを使用してフィールドを初期化する

C++ では、次の使用を推奨していますメンバ初期化リストを使用してメンバ変数を初期化します。その構文は、コンストラクタのパラメータリストの後にコロン（:）を付け、その後ろに書きますメンバー変数名(初期値)。

以下の例では、: length(len)の意味は、渡されたパラメータを使用してlenメンバ変数を直接初期化することですlength。注意cout出力されるのはメンバ変数lengthであり、パラメータではありませんlen。これにより、メンバ変数が正しく代入されたことを直感的に確認できます：

Line::Line(double len) : length(len) { // この時点で length は初期化リストによって代入済みなので、length を出力して結果を確認する cout << "Object is being created, length = " << length << endl; }

上記の構文は、次に示す関数本体内で代入する書き方と同等であり、両者の出力結果は完全に同じです：

Line::Line(double len) { length = len; // パラメータ len をメンバ変数 length に代入する cout << "Object is being created, length = " << length << endl; }

2つの書き方の違いは、初期化リストが関数本体に入る前にメンバ変数の初期化を完了することです。一方、関数本体内の代入は、最初にデフォルト構築を行ってから代入するため、1ステップ多くなります。constconst メンバ、参照メンバ、およびデフォルトコンストラクタを持たないオブジェクトメンバにとって、初期化リストは唯一の初期化方法です。

クラス C に、初期化が必要な複数のフィールド X、Y、Z などがあるとします。各フィールドをカンマで区切るだけです。次のようになります：

C::C(double a, double b, double c) : X(a), Y(b), Z(c) { // その他の初期化ロジック（存在する場合） }

注意：初期化リスト内の各メンバの初期化順序は、クラス内での宣言順序によって決まり、記述順序ではありません。混乱を避けるため、宣言順序と一致させることをお勧めします。

クラスのデストラクタ

クラスのデストラクタはクラスの特別なメンバ関数であり、オブジェクトのライフサイクルが終了するとき（スコープを離れるか、またはdeletedelete されたときに）自動的に実行され、オブジェクトが占有するリソース（動的メモリやファイルハンドルなど）を解放するために使用されます。

デストラクタの名前はクラス名と完全に同じですが、先頭にチルダ（~）をプレフィックスとして付けます。デストラクタは値を返さず、引数も持つことができません。各クラスはデストラクタを1つだけ持つことができます。

以下の例は、デストラクタの概念をよりよく理解するのに役立ちます。

例

#include <iostream> using namespace std; class Line { public: Line(); // コンストラクタの宣言 ~Line(); // デストラクタの宣言 void setLength(double len); double getLength() const; private: double length; }; // コンストラクタの定義 Line::Line() { cout << "Object is being created" << endl; length = 0.0; } // デストラクタの定義 Line::~Line() { cout << "Object is being deleted" << endl; // 動的割り当てされたリソースがあれば、ここで解放します。例：delete[] data; } void Line::setLength(double len) { length = len; } double Line::getLength() const { return length; } // プログラムのメイン関数 int main() { Line line; // プログラム終了時に、デストラクタが自動的に呼び出される // 長さを設定 line.setLength(6.0); cout << "Length of line : " << line.getLength() << endl; return 0; }

上記のコードをコンパイルして実行すると、次の結果が生成されます。

Object is being created
Length of line : 6
Object is being deleted

    #include<iostream>
#include<string>
using namespace std;

class Student
{
public:
    string name;
    string number;
    char X;
    int year;
    Student(string,string,char,int);      //构造函数声明
    void xianshi(void);     //用于输出类成员的值
};

//成员函数定义，包括构造函数
Student::Student(string N,string n,char x,int y)    //利用构造函数给类的成员赋值
{
    name = N;
    number = n;
    X = x;
    year = y;
}

void Student::xianshi()     //输出成员的值
{
    cout<<name<<endl;
    cout<<number<<endl;
    cout<<X<<endl;
    cout<<year<<endl;
}

int main()                             //主函数
{
    cout<<"输入姓名：";
    string N;
    cin>>N;
    cout<<"输入学号：";
    string n;
    cin>>n;
    cout<<"输入性别（M 或 W）:";
    char x;
    cin>>x;
    cout<<"输入年龄：";
    int y;
    cin>>y;
    Student S(N,n,x,y);               //定义对象并对构造函数赋值
    S.xianshi();                           //引用输出函数
    return 0;
}

    初期化リストのメンバ初期化順序：

    C++ ではクラスのメンバを初期化するとき、初期化リストに出現する順序ではなく、宣言された順序で初期化されます。

    class CMyClass {
    CMyClass(int x, int y);
    int m_x;
    int m_y;
};

CMyClass::CMyClass(int x, int y) : m_y(y), m_x(m_y)
{
};

    あなたは、上記のコードが最初に m_y=I を実行し、次に m_x=m_y を実行して、最終的にそれらが同じ値になると思うかもしれません。しかし、コンパイラは m_x を最初に初期化し、その後に m_y を初期化します。なぜなら、それらはこの順序で宣言されているからです。結果として、m_x は予測不可能な値になります。これを回避するには2つの方法があります。1つは、常に初期化したい順序でメンバを宣言することです。もう1つは、初期化リストを使用する場合は、常に宣言された順序でメンバを列挙することです。これにより混乱を排除できます。

    初期化順序は、変数のクラス内での宣言順序と一致させるのが最善です。そうしないと、次のような特別な状況が発生します：

    #include<iostream>
 
using namespace std;

class Student1 {
    public:
        int a;
        int b;
        void fprint(){
            cout<<" a = "<<a<<" "<<"b = "<<b<<endl;
         }
         
         Student1(int i):b(i),a(b){ }    //异常顺序：发现a的值为0  b的值为2  说明初始化仅仅对b有效果，对a没有起到初始化作用 
//         Student1(int i):a(i),b(a){ } //正常顺序：发现a = b = 2 说明两个变量都是初始化了的  

         Student1()                         // 无参构造函数
        { 
            cout << "默认构造函数Student1" << endl ;
        }
    
        Student1(const Student1& t1) // 拷贝构造函数
        {
            cout << "拷贝构造函数Student1" << endl ;
            this->a = t1.a ;
        }
    
        Student1& operator = (const Student1& t1) // 赋值运算符
        {
            cout << "赋值函数Student1" << endl ;
            this->a = t1.a ;
            return *this;
        }
      
 };
class Student2
{
    public:
     
    Student1 test ;
    Student2(Student1 &t1){
        test  = t1 ;
    }
//     Student2(Student1 &t1):test(t1){}
};
int main()
{
    
    Student1 A(2);        //进入默认构造函数 
    Student2 B(A);        //进入拷贝构造函数 
    A.fprint();            //输出前面初始化的结果 
}

    正常な初期化順序：

    上記の例からわかるように、初期化リストの順序はクラス内での宣言順序と一致させる必要があります。そうしないと、上記のような特殊な状況で一部の変数が初期化されなくなります。テストの結果、クラスの変数が次のような場合でも正常に初期化できることがわかりました。つまり、メンバ変数の初期化が他のメンバ変数に依存しない限り、順序が異なっていても正しく初期化できます。

Student1(int i):b(i),a(i),c(i){}

    Student1 A(2);    
    A.fprint();

Student1(int i,int j,int k):b(i),a(j),c(k){}

    ここでは、コンストラクタの理解を深めるために、コンストラクタの呼び出し回数に関する問題を追加します。

    問題：AB をクラスとすると、文「AB a(2), b

    解説：

    AB a(2) はコンストラクタを1回呼び出します；

    AB b

    AB *p

    補足：

    1. AB *a = new AB; はデフォルトコンストラクタの呼び出しを表します：

    2. AB b(*a); は、括弧内の内容 *a を使って Test 型のオブジェクト b を初期化し、コピーコンストラクタを呼び出します；

    3. AB c; は AB 型のオブジェクト c を定義し、初期値を代入せずにデフォルトコンストラクタを呼び出します；

    4. c = a; は a オブジェクトを使って c オブジェクトに代入することを表します。ここでの代入演算子は、実際には代入コンストラクタを呼び出しています。

    5. AB d = a; は変数 d の定義と初期化操作を表します。代入演算子 = がありますが、その実質は初期化であり、代入の範疇には属しません。したがって、ここで呼び出されるのはコピーコンストラクタであり、代入コンストラクタではありません。
