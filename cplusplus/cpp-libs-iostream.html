C++ 標準入出力 -- <iostream>

<iostream><iostream> ライブラリは、C++ 標準ライブラリの入出力操作に使用されるヘッダーファイルです。

<iostream> は、いくつかの一般的なストリームクラスと演算子を定義しており、プログラムが標準入出力デバイス（キーボードや画面など）と対話することを可能にします。

以下は<iostream>ライブラリの詳細な使用説明です。主要なクラスとよくある使用例が含まれます。

主要クラス

  • std::istream：入力操作に使用される抽象基底クラス。
  • std::ostream：出力操作に使用される抽象基底クラス。
  • std::iostream：から継承std::istream和std::ostream、入出力操作を同時に行うために使用されます。
  • std::cin：標準入力ストリームオブジェクト。通常、キーボードに関連付けられています。
  • std::cout：標準出力ストリームオブジェクト。通常、画面に関連付けられています。
  • std::cerr：標準エラー出力ストリームオブジェクト。バッファなしで、通常、画面に関連付けられています。
  • std::clog：標準ログストリームオブジェクト。バッファ付きで、通常、画面に関連付けられています。

一般的な演算子

  • >>：入力演算子。入力ストリームからデータを読み取ります。
  • <<：出力演算子。データを出力ストリームに書き込みます。

基本的な使い方

標準入力と出力:

例

#include <iostream>

int main() {
    int age;
    std::string name;

    // std::cout を使用して画面に出力
    std::cout << "Enter your name: ";
    // std::cin を使用してキーボードから入力を受け取る
    std::cin >> name;

    std::cout << "Enter your age: ";
    std::cin >> age;

    // 読み取ったデータを出力
    std::cout << "Hello, " << name << "! You are " << age << " years old." << std::endl;

    return 0;
}

標準エラー出力:

例

#include <iostream>

int main() {
    std::cerr << "An error occurred!" << std::endl;
    return 0;
}

標準ログ出力:

例

#include <iostream>

int main() {
    std::clog << "This is a log message." << std::endl;
    return 0;
}

整形出力:

使用する<iomanip>ライブラリを使用すると、出力をフォーマットできます。例えば、幅、精度、配置を設定できます。

例

#include <iostream>
#include <iomanip>

int main() {
    double pi = 3.14159;

    // 出力精度を設定
    std::cout << std::setprecision(3) << pi << std::endl;

    // 出力幅と配置を設定
    std::cout << std::setw(10) << std::left << pi << std::endl;
    std::cout << std::setw(10) << std::right << pi << std::endl;

    return 0;
}

ストリームの状態チェック:

入出力ストリームの状態をチェックして、操作が成功したかどうかを確認できます。

例

#include <iostream>

int main() {
    int num;
    std::cout << "Enter a number: ";
    std::cin >> num;

    // 入力操作が成功したかどうかを確認
    if (std::cin.fail()) {
        std::cerr << "Invalid input!" << std::endl;
    } else {
        std::cout << "You entered: " << num << std::endl;
    }

    return 0;
}

文字列入力の処理

使用するstd::getline関数はスペースを含む行全体の入力を読み取ることができます。

例

#include <iostream>
#include <string>

int main() {
    std::string fullName;
    std::cout << "Enter your full name: ";
    std::getline(std::cin, fullName);
    std::cout << "Hello, " << fullName << "!" << std::endl;

    return 0;
}

上記の例は示しています<iostream>ライブラリの基本的な使い方と一般的な操作を示しており、C++プログラムでの入出力処理に役立ちます。
