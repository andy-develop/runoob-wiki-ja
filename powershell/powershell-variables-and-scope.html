PowerShell 変数とスコープ

変数はあらゆるプログラミング言語の基本ツールであり、PowerShell も例外ではありません。

変数を使って数値、文字列、オブジェクト、配列、ハッシュテーブルなどを格納できます。そして PowerShell の変数を本当に強力にしているのは、そのスコープ（有効範囲）の仕組みです。スコープを理解することで、より安定し、構造が明確なスクリプトを作成し、変数の競合や意図しない上書きを防ぐことができます。

このセクションでは、PowerShell における変数の使い方、データ型、スコープの規則、そしてベストプラクティスについて詳しく解説します。

一、変数の基礎

変数の定義

PowerShell では、変数はドル記号（$）で始まり、その後に変数名が続きます。

$greeting = "Hello, PowerShell"
$number = 100

変数の代入に型の事前宣言は不要で、PowerShell が自動的にデータ型を推論します。

変数の読み取り

変数を直接参照することで値を読み取れます：

Write-Output $greeting

文字列に挿入することもできます：

Write-Output "提示信息：$greeting"

文字列が一重引用符（シングルクォート）で囲まれている場合は、変数は解析されません：

Write-Output '提示信息：$greeting'   # 输出字面值

変数の型を確認

$number.GetType()

よく使う変数型の例

例 型 例の値
$str = "abc" 文字列（String） "abc"
$num = 123 整数（Int32） 123
$arr = 1, 2, 3 配列（Array） [1, 2, 3]
$obj = Get-Process オブジェクトのコレクション（Object[]） プロセス一覧
$hashtable = @{} ハッシュテーブル（Hashtable） @{Name="Tom";Age=30}

二、特殊変数

PowerShell には便利な組み込み変数が多数用意されています：

変数名 説明
$_ パイプラインで現在処理中のオブジェクト
$? 直前のコマンドが成功したかどうか
$LASTEXITCODE 直前の外部プログラムの終了コード
$PSVersionTable PowerShell のバージョン情報
$env:PATH 環境変数 PATH

三、変数のスコープの概念

スコープとは？

スコープ（Scope）変数がどこで有効かを示します。PowerShell は複数のスコープ階層をサポートしており、変数が意図せず上書きされるのを防ぎます。

よく使うスコープは次のとおりです：

スコープ 説明
Global グローバルスコープ。スクリプトまたはシェルの最上位のスコープ。
Local 現在の関数またはコードブロック内の変数（デフォルトのスコープ）
Script 現在のスクリプトファイル内で有効な変数
Private 現在のスコープ内でのみ有効で、外部からはアクセスできない

例で見る：変数スコープの違い

$global:name = "Tom"       # 全局变量
$name = "Alice"            # 本地变量
function Show-Name {
    $name = "Bob"          # 函数内的局部变量
    Write-Output "函数内部：$name"
}

Show-Name
Write-Output "函数外部：$name"
Write-Output "全局变量：$global:name"

出力結果：

函数内部：Bob
函数外部：Alice
全局变量：Tom

スコープを明示的に設定する

変数名の前にスコープ識別子を付けることで、変数の有効範囲を明確にできます：

$script:dbName = "MyDatabase"  # 仅对当前脚本可见
$global:apiKey = "abcdef12345" # 对所有位置可用

現在のスコープ内の変数を確認する

Get-Variable

またはグローバル変数を一覧表示する：

Get-Variable -Scope Global

四、よくあるエラーと注意点

問題の状況 原因とアドバイス
関数内で設定した変数に外部からアクセスできない を使用していないglobal: 或 script:明示的な宣言
同名の変数が上書きされる 重要な変数はスコーププレフィックスで区別することを推奨
環境変数の変更が反映されない を使用してください$env:変更し、スコープと永続性に注意してください

五、実践例

例 1：関数を作成し、グローバル変数を設定として使用する

$global:Threshold = 80

function Check-CPU {
    $usage = (Get-Counter '\Processor(_Total)\% Processor Time').CounterSamples[0].CookedValue
    if ($usage -gt $global:Threshold) {
        Write-Output "CPU 使用率过高：$([math]::Round($usage, 2))%"
    } else {
        Write-Output "CPU 使用率正常：$([math]::Round($usage, 2))%"
    }
}

例 2：関数内で定義した変数は外部から見えない（ローカルスコープ）

function Say-Hello {
    $message = "你好，PowerShell！"
    Write-Output $message
}

Say-Hello
Write-Output $message   # 报错：$message 不存在

例 3：$env:環境変数を設定する（一時的）

$env:MY_ENV = "HelloWorld"
Write-Output $env:MY_ENV

注意：この方法は現在の PowerShell セッションでのみ有効で、ウィンドウを閉じると無効になります。

六、まとめ

  • PowerShell では$変数名を使用して変数を定義し、型は自動的に推論されます
  • 文字列、配列、ハッシュテーブル、オブジェクトなど、あらゆるデータ型を格納できます
  • スコープは変数の「有効範囲」を制御します。よく使われるものにはLocal、Script、Global
  • スコープを正しく理解することは、構造が明確で保守性の高いスクリプトの作成に役立ちます
  • 組み込み変数と環境変数は非常に便利ですが、そのスコープの制限に注意する必要があります
