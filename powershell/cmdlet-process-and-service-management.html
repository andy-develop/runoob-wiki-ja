Cmdlet プロセスとサービス管理

プロセスとサービスの管理は、システム保守と自動化運用において非常に重要な部分です。

PowerShellは、ローカル（またはリモート）コンピュータ上のプロセスとサービスを表示、起動、停止、フィルタリング、制御するための、簡潔で強力なCmdletのセットを提供しています。

このセクションでは、PowerShellを使用してプロセスとサービスを管理する方法について詳しく説明します。基本的な操作コマンド、典型的な適用シナリオ、よくある問題を含み、システム管理の効率向上に役立てます。

一、プロセス管理（Process）

PowerShellは.NETのプロセスオブジェクトを使用してプロセス操作を処理します。よく使われるCmdletには以下のものがあります：

Cmdlet 機能
Get-Process 実行中のプロセスを取得
Stop-Process 指定したプロセスを停止
Start-Process 新しいプロセス（プログラム）を起動
Wait-Process 特定のプロセスの終了を待機

プロセスを表示：Get-Process

実行中のすべてのプロセスを表示：

Get-Process

特定のプロセス（例：notepad）を表示：

Get-Process -Name notepad

複数のプロセスを表示：

Get-Process -Name chrome, notepad

プロセスの詳細情報を取得して並べ替え：

Get-Process | Sort-Object CPU -Descending | Select-Object -First 5
Stop-Process

プロセス名で停止：

Stop-Process -Name notepad

プロセスIDで停止：

Stop-Process -Id 1234

プロセスを強制終了（対話型プロンプトを回避）：

Stop-Process -Name notepad -Force

プロセスを起動：Start-Process

メモ帳を開く：

Start-Process notepad

管理者としてPowerShellを開く（現在のウィンドウに権限が必要）：

Start-Process powershell -Verb RunAs

Webブラウザを起動してURLにアクセス：

Start-Process "https://learn.microsoft.com"

プロセスを待機：Wait-Process

プロセスの実行が完了するまで待ってから続行：

Start-Process notepad
Wait-Process -Name notepad
Write-Output "记事本已关闭"

二、サービス管理（Service）

PowerShellのサービス管理サポートは非常に充実しています。よく使われるCmdletは次のとおりです：

Cmdlet 機能説明
Get-Service サービスの状態を表示
Start-Service サービスを起動
Stop-Service サービスを停止
Restart-Service サービスを再起動
Set-Service サービスのプロパティを変更

サービスを表示：Get-Service

すべてのサービスを表示：

Get-Service

実行中のサービスをフィルタリング：

Get-Service | Where-Object {$_.Status -eq "Running"}

特定のサービスを表示：

Get-Service -Name W32Time

サービスの起動と停止

Windows Timeサービスを起動：

Start-Service -Name W32Time

サービスを停止（権限が不十分な場合はエラーが発生する可能性があります）：

Stop-Service -Name W32Time

サービスを再起動：Restart-Service

Restart-Service -Name W32Time

サービスの設定を変更：Set-Service

サービスのスタートアップの種類を自動に設定：

Set-Service -Name W32Time -StartupType Automatic

サービスを無効にする：

Set-Service -Name W32Time -StartupType Disabled

三、サービスとプロセスの違い

比較項目 サービス（Service） プロセス（Process）
起動方法 自動起動 / 手動起動 / 無効 ユーザーが手動またはプログラムでトリガー
実行状態 継続的にバックグラウンドで実行され、通常はインターフェースなし フォアグラウンドでの対話が可能で、ライフサイクルが短い
管理方法 Get-Service, Start-Service 等 Get-Process, Start-Process 等
例 Windows Update（wuauserv） Notepad、chrome.exe など

四、実践例

例1：異常停止したサービスを検出して再起動する

$svc = Get-Service -Name Spooler
if ($svc.Status -ne "Running") {
    Restart-Service -Name Spooler
    Write-Output "服务已重启"
}

例2：CPU使用率が50を超えるすべてのプロセスを終了する（注意が必要）

Get-Process | Where-Object { $_.CPU -gt 50 } | Stop-Process -Force

注意：このような操作は、必ずテスト環境またはリスクがないことを確認した上で行ってください。

五、よくある質問と注意事項

問題 原因と推奨事項の説明
サービスを停止できない 管理者権限が必要です。「管理者として実行」を使用することをお勧めします
プロセス名またはサービス名のスペルミス 最初にGet-Process 或 Get-Serviceを使用して正確な名前を取得してください
サービスは停止しているが、まだRunningと表示される 一部のサービスには保護メカニズムがあります。次の使用をお勧めしますRestart-Service再起動を試みる

六、まとめ

PowerShellは標準化されたコマンドセットにより、プロセスとサービスの管理を簡単かつ効率的にします：

  • 使用してGet-*情報を表示し、Start-*/Stop-*動作を制御し、Set-*プロパティを変更する
  • パイプライン + 条件フィルタリング + オブジェクト操作は、一括管理タスクに適しています
  • タスクスケジューラや監視スクリプトと組み合わせて、自動化運用体制を構築できます
