MongoDB PHP

PHPでMongoDBを使用するには、MongoDBのPHPドライバーを使用する必要があります。

MongoDB PHPの各プラットフォームでのインストールとドライバーパッケージのダウンロードは以下を参照してください：PHPへのMongoDB拡張ドライバーのインストール

PHP7を使用している場合は、以下を参照してください：PHP7 MongoDB のインストールと使用。

接続を確認し、データベースを選択する

正しい接続を確保するには、データベース名を指定する必要があります。データベースがMongoDBに存在しない場合、MongoDBが自動的に作成します。

コードスニペットは次のとおりです：

<?php
$m = new MongoClient(); // 连接默认主机和端口为：mongodb://localhost:27017
$db = $m->test; // 获取名称为 "test" 的数据库
?>

コレクションを作成する

コレクションを作成するコードスニペットは次のとおりです：

<?php
$m = new MongoClient(); // 连接
$db = $m->test; // 获取名称为 "test" 的数据库
$collection = $db->createCollection("サンプル");
echo "集合创建成功";
?>

上記のプログラムを実行すると、出力結果は次のとおりです：

コレクションの作成に成功しました

ドキュメントを挿入する

MongoDBでinsert()メソッドを使用してドキュメントを挿入します：

ドキュメントを挿入するコードスニペットは次のとおりです：

<?php
$m = new MongoClient();    // 连接到mongodb
$db = $m->test;            // 选择一个数据库
$collection = $db->サンプル; // 选择集合
$document = array( 
    "title" => "MongoDB", 
    "description" => "database", 
    "likes" => 100,
    "url" => "http://www.example.com/mongodb/",
    "by", "サンプル"
);
$collection->insert($document);
echo "数据插入成功";
?>

上記のプログラムを実行すると、出力結果は次のとおりです：

データの挿入に成功しました

ドキュメントを検索する

find()メソッドを使用して、コレクション内のドキュメントを読み取ります。

ドキュメントを読み取るコードスニペットは次のとおりです：

<?php
$m = new MongoClient();    // 连接到mongodb
$db = $m->test;            // 选择一个数据库
$collection = $db->サンプル; // 选择集合

$cursor = $collection->find();
// 迭代显示文档标题
foreach ($cursor as $document) {
    echo $document["title"] . "\n";
}
?>

上記のプログラムを実行すると、出力結果は次のとおりです：

MongoDB

ドキュメントを更新する

update()メソッドを使用してドキュメントを更新します。

次の例では、ドキュメント内のタイトルが「MongoDB チュートリアル」のものを更新します。コードスニペットは次のとおりです：

<pre>
<?php
$m = new MongoClient();    // 连接到mongodb
$db = $m->test;            // 选择一个数据库
$collection = $db->サンプル; // 选择集合
// 更新文档
$collection->update(array("title"=>"MongoDB"), array('$set'=>array("title"=>"MongoDB 教程")));
// 显示更新后的文档
$cursor = $collection->find();
// 循环显示文档标题
foreach ($cursor as $document) {
    echo $document["title"] . "\n";
}
?>

上記のプログラムを実行すると、出力結果は次のとおりです：

ドキュメントを削除する

remove()メソッドを使用してドキュメントを削除します。

次の例では、'title' が 'MongoDB チュートリアル' であるデータレコードを1件削除します。コードスニペットは次のとおりです：

<?php
$m = new MongoClient();    // 连接到mongodb
$db = $m->test;            // 选择一个数据库
$collection = $db->サンプル; // 选择集合
   
// 移除文档
$collection->remove(array("title"=>"MongoDB 教程"), array("justOne" => true));

// 显示可用文档数据
$cursor = $collection->find();
foreach ($cursor as $document) {
    echo $document["title"] . "\n";
}
?>

上記の例の他に、PHPではfindOne(), save(), limit(), skip(), sort()などのメソッドを使用してMongoDBデータベースを操作することもできます。

さらに多くの操作方法については、MongoDBコアクラスを参照してください：http://php.net/manual/zh/mongo.core.php。
